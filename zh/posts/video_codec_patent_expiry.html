一个视频打不开的年代留下了什么

装好 Linux、打开手头存着的视频,却弹出 找不到编解码器,这种经历跨越了好几代用户。解决办法也总是相似的形状:再挂一个软件源,装上一堆名字陌生的软件包,然后才终于能播。有时浏览器里流畅播放的视频,偏偏在本地播放器里卡住;有时同一个文件在某个发行版上直接就能开,在另一个发行版上却不行。

这一症状的原因不在技术。解码器代码早就写好了,源码是公开的,性能也足够。挡在中间的是专利——更准确地说,不是专利本身,而是把那段代码分发给数百万人的主体所要承担的责任。

2026年7月,这一结构中的一块随着期满而合上。一件撑了25年的专利结束了,有消息称一个旧标准在全球范围内摆脱了专利负担。这是好消息,但这里到底什么结束了、什么照旧,很容易被搅在一起。本文要做的就是把这条界线划出来。

专利挂在编解码器上意味着什么 - 与著作权不同的一层

越是长期打交道开源的人,越容易在这里卡一下。源码公开、许可证自由,不就完事了吗?可专利处在另一层。

  • 著作权保护的是表达。它约束的是复制、修改与分发某个人写下的那段代码。
  • 专利保护的是方法。就算你把代码从头重写一遍,只要用了那个方法,照样落在权利范围内。
  • 所以自由软件许可证并不等同于专利实施许可。拿到著作权那一侧的许可,不代表专利那一侧也一并解决了。
  • 有些许可证确实为贡献者的专利设了明示的授权条款,但那只覆盖贡献者本人持有的专利。与之无关的第三方专利完全在该条款之外。

编解码器之所以尤其棘手,和标准的构成方式有关。视频压缩标准不是一项发明,而是数百项技术手段的组合。运动预测、变换、量化、熵编码、环路滤波,每个环节都有细分手段,而每一项手段上都可能挂着不同公司的专利。

由此便产生了标准必要专利这一性质。只要遵循标准,就没有不用那项手段的余地,也就无法通过设计绕开。实现了标准这件事本身,就等于实施了那些专利。这与可以规避的普通专利在性质上根本不同,也正是编解码器领域另立许可窗口的原因。

专利池与许可费 - 把窗口并成一个的装置

设想一个标准上有数百件专利,分散在数十家公司手里。若实现方要逐一去谈,光谈判就能耗完产品寿命。为解决这一点而出现的装置就是专利池。

  • 权利人把自家专利交给一个管理方,管理方以一份许可打包出售。
  • 实现方只与一个窗口签约,收上来的许可费由管理方分配给各权利人。
  • 费率大多按设备台数计,或像流媒体那样按服务规模计,也有两者并用的。
  • 设置年度上限的情形很常见,目的是让大批量出货的厂商不至于被无限计费。

在视频领域反复出现的管理方就那么几家。MPEG LA 长期运营 MPEG 系列专利池,这一脉络后来延续到 Via Licensing Alliance。HEVC 一侧,Access Advance 表示自己运营 HEVC Advance 池,并为更新的标准运营 VVC Advance 池。Sisvel 则另设了覆盖 VP9 与 AV1 的计划。

这里有一点在实务中经常被忽略。拿到池子的许可,并不等于该标准上的全部权利都理清了。没有加入池子的权利人始终存在,同一个标准上同时存在多个池子的情况也有。池子是降低交易成本的装置,不是免责证书。

费率也不是固定的。据 Streaming Media 报道,Via LA 调整了 AVC 的流媒体费率结构,以分层取代了2010年8月定下的每年十万美元单一上限。最高一档据报道为每年四百五十万美元,其后两档分别是三百三十七万五千美元与两百二十五万美元,而小型与新兴服务维持在十万美元。值得注意的是,该调整被说明为适用于2026年起新申请许可的实现方,截至2025年底持有有效许可的公司则保留原有的流媒体条款。

这条消息的实质是这样的。到期的是一件专利,但它之所以重要,是因为它是MPEG-4 Visual 专利池中最后一项存续权利。用标准的语言说是 MPEG-4 Part 2,用实物来说就是 Xvid 与 DivX 所用的那个格式。

为何只有巴西撑满了25年

同一项发明,在欧洲2021年就结束了,在巴西却活到2026年。原因在于专利期限的计算方式不同。

  • 多数国家按自申请日起二十年计算。审查拖得越久,实际能行使权利的时间就越短。
  • 巴西工业产权法(第9.279/96号法律)第40条但书在此设了下限,保障发明专利自授权日起至少十年。
  • 这件专利2001年申请、2016年授权。审查耗时十五年,下限条款适用,届满日便被推到了2026年。

而这一条款其实早已被判违宪。在2016年提起的违宪之诉 ADI 5529 中,巴西联邦最高法院于2021年5月6日宣告该但书违宪。理由沿着宪法中专利具有临时性的条文展开,并指出期限随审查延迟而参差不齐会损害法律确定性与竞争。

那这件专利当时为何没有被缩短?据报道,溯及效力被限定在医药与卫生领域的专利,巴西专利局缩短保护期的也正是该范围内的3,341件。编解码器专利落在这一范围之外,于是按旧算法一路跑到了2026年7月。

这正是整件事里最具实务价值的一课。专利的地理分布并不均匀。在美国和欧洲结束,并不意味着在全世界结束;某一个法域的一处制度特殊性,就足以把整个标准可自由使用的时点往后推五年。

发行版无法默认内置的真正原因 - 再分发责任

到这里,用户所经历的症状与发行版的处境就接上了。关键在于使用与分发是两回事。

  • 个人在自己机器上播放视频,并不是许可费体系瞄准的那个位置。
  • 而发行版是制作软件并大范围分发的主体。把受专利保护的实现随包送出去,这一分发行为本身就可能成为暴露点。
  • 分发主体的性质也有分别。在美国设有法人实体并有营收的组织容易成为目标,不具备这些条件的则实务风险低得多。
  • LWN 的文章把这个差别写得很直白:诉讼风险低的分发方一直照常附带同样的编解码器。

于是各家发行版各自找到了不同的折中点。

  • 推到独立软件源。本体不收录,交由另一个主体运营的软件源,让用户自己取。用户反复经历的加源仪式,来历就在这里。
  • 由第三方代付许可费的二进制。思科为一个名为 OpenH264 的特定 H.264 实现承担了专利费用并免费分发,不过附带的条件是思科所分发的那个二进制。
  • 按运行时切分。把编解码器放在应用分发运行时那一侧,让发行版本体与运行时各自承担不同的责任。

这次消息里还带出了一个有意思的例外:早在巴西专利仍然有效的2023年,Fedora 就已经在分发 xvidcore 了。这说明各家发行版一直在权衡法域与实际风险后作出不同判断,同时也说明政策并不会自动跟着专利期满日走。

2022年那次关掉硬件加速的改动

这一结构表现得最清楚的一次,发生在2022年。那年9月,Fedora 改变了图形库 Mesa 的构建方式,关闭了 H.264、H.265 与 VC-1 的硬件加速路径。openSUSE 不久后也走了同一方向。

当时的逻辑是这样的。

  • Mesa 作为视频加速 API 的一部分,实现了解码与编码的软件部分。
  • 单独的硬件不构成侵权,但硬件与软件的组合才真正完成工作,因此以这种形态交付的实现有可能构成侵权。
  • 硬件供应商销售自家产品时,并未把许可覆盖到终端用户软件,而是以客户另行取得许可为前提。
  • 于是移除代码,消除了故意侵权主张得以成立的余地。

对用户而言,这次改动表现为硬件解码忽然消失。替代方案是有的:第三方软件源提供了把编解码器恢复回来的 Mesa 与 FFmpeg 构建,而经由应用运行时分发的程序则在运行时那一侧保住了编解码能力。

从中该拿走的不是对某个发行版的评价,而是对结构的理解。专利风险挂在组合上,而不是挂在某一坨代码上。仅凭自家代码里没有编码器就安心是不够的;你送出去的软件在遇到特定硬件后会完成什么工作,同样落在判断范围之内。

逐个编解码器看现状 - 混为一谈必然出错

把这条消息读成编解码器已经自由了,几乎必然出错,因为每个标准的许可结构都不一样。下面只整理截至2026年8月在公开发布与报道中能够确认的范围。

HEVC 一侧的结构尤其复杂。Access Advance 表示,其 HEVC Advance 池许可两万九千件以上 HEVC 必要专利,VVC Advance 池许可四千五百件以上 VVC 必要专利。它还说明自己收购了此前由 Via LA 运营的 HEVC 与 VVC 池的管理方,并以独立计划的形式延续。窗口确实在走向整合,但这并不意味着实现方需要核查的对象减到了一个。

免版税编解码器的由来,以及它并不安静的原因

网络需要编解码器,而按设备台数计费的模式与网络的商业模式并不契合。浏览器要免费分发数亿份,视频又无处不在。这道缝隙催生了免版税编解码器这个方向。

  • 谷歌以收购来的技术为基础,把 VP8 与随后的 VP9 作为开放格式推出。
  • 2015年 AOMedia 成立,已知参与方包括谷歌、Netflix、苹果、微软、亚马逊、Meta、英伟达、英特尔、ARM、三星、思科与 Mozilla 等。
  • 其成果就是 AV1,并附带了成员无偿开放自家专利的免版税专利许可。

不过这里有一处必须读准。免版税是制定标准那批人的承诺,而不是第三方专利不存在的保证。这个区分在实务里被抹平的频率最高。

  • Sisvel 表示,自2019年3月起分别针对 VP9 与 AV1 运营独立的许可计划。
  • 公开说明中介绍,VP9 计划有12家权利人参与,AV1 计划有14家。
  • 标准费率方面,VP9 为显示设备0.24欧元、非显示设备0.08欧元,AV1 则为0.32欧元与0.11欧元。
  • 2026年3月24日,Access Advance 发布消息称,其池中的许可人杜比就 AV1 与 HEVC 相关专利侵权在美国与巴西起诉了 Snap。
  • 该公告将其描述为其许可人首次针对 AV1 实现提出的专利主张,也是首次针对流媒体平台的 AV1 主张。

此案孰是孰非由法院裁断,这里没有理由代为判断。实务要带走的只有一条。选了免版税标准这件事,不等于许可审查可以省掉。与其说它取消了判断的依据,不如说它改变了审查的性质,这样理解更准确。

这次期满改变了什么、又没触及什么

整理下来是这样的。

类别内容
会变围绕 MPEG-4 Part 2 实现的最后一处法域不确定性,据报道已经理清
会变处理2000年代影像资料的数字保存工作,对旧格式支持的负担减轻
会变发行版限制旧编解码器组件的依据减少。不过实际是否改政策仍由各项目自行判断
不变H.264/AVC 是另一个标准,另有专利池仍在运作
不变HEVC、VVC、VP9 与 AV1 的许可结构与这次期满无关
不变多数播放工具早已支持该格式,用户能感知的变化很小
不变AAC 等音频系列,以及其他 MPEG 技术的状态

可感知的变化很小,听上去或许有些扫兴,但这件事的价值在别处。2001年提交的一件申请,能把某个标准的自由分发按住到2026年,这一点作为具体数字留了下来。当你衡量正在设计的系统要依赖哪些标准时,这种时间尺度的直觉可以直接拿来用。

实务上的四条判断轴

结论先说:你在做什么,决定了你该看什么,因为同一个编解码器暴露的位置并不相同。

  • 第一,是哪个标准。装在 MP4 容器里这件事本身什么也说明不了。容器与编解码器是两层。先确定实际码流是 H.264、HEVC 还是 AV1。
  • 第二,是编码还是解码。费率体系通常把两者分开,你把哪一侧当作产品功能来卖,决定了要审查的对象。
  • 第三,分发到哪些法域。这正是本次事件所展示的。在一个国家理清了,不等于在全世界理清了。
  • 第四,这项能力从哪来。使用已获许可的操作系统或部件所提供的功能,与自己把解码器随包送出去,位置并不一样。

把自己的处境放到这四条轴上,大致会得到这样一幅图。

  • 个人用户基本无需操心。发行版不默认提供的话,也就是加个软件源的事。
  • 做内部工具分发范围窄、也不涉及销售,相对简单,但有些组织仍会按内部制度要求走一遍确认。
  • 公开分发开源项目时,分发主体与法域会成为焦点。编解码器实现是收进本体还是作为可选组件剥离,会变成一个真实的设计决策。
  • 销售硬件设备会直接撞上按台数计的费率。要核实的是部件供应商的许可到底覆盖到哪一层,这写在合同里。
  • 运营流媒体服务则同时受服务规模费率与签约时点的影响。前面提到的 AVC 费率调整以新签许可方为界,就是这类时点效应。

而所有这些判断都附带同一句话。这里写的是从公开资料中确认的结构性说明,针对特定产品与特定法域的结论属于法律专业人士的领域。如果编解码器的选择确实会影响产品成本或分发结构,那正是该请专业人士介入的时点。

未能确认的内容

以下是写作过程中公开资料未能触及的项目,这也是正文中没有使用这些数值的原因。

  • H.264/AVC 池最后一件专利的预计期满日。未能查到池运营方公开的完整期满时间表。
  • HEVC 与 VVC 各池的期满时间表。同上。
  • 韩国是否存在对应专利、若有则何时终止。未能确认 MPEG-4 Visual 系列在韩国的登记状况。
  • BR PI0113271-7 的权利要求范围。除期满日外,所覆盖技术的细节未能确认。
  • 本次期满后各发行版是否调整了政策。未能确认各项目的官方公告。
  • 进行中纠纷的后续进展。前述起诉一事仅确认到公告内容,之后的程序未能确认。
  • Sisvel 计划当前的费率与参与权利人数量。所引数值为计划早期公开的内容,最新数值未能确认。

结论 - 今天带走的三点

第一,结束的是一个标准。覆盖 MPEG-4 Part 2 的那个池,其最后一项权利据报道已经理清;而今天真正在用的 H.264、HEVC 与 VVC,各自仍立在独立的结构之上。把这一条消息扩展成整个编解码器领域,错就出在那一刻。

第二,专利的地理与时间都不均匀。同一项发明在欧洲2021年终止,在巴西却跑到了2026年。一条计算保护期的规则、一处违宪判决溯及范围的边界,就造出了五年。评估标准依赖时,不只要问何时到期,还要问在哪里到期。

第三,免版税不等于没有风险。制定标准者的无偿开放承诺,与实现该标准时世上全部专利都已理清的保证,是两句不同的话。这个差别在2026年以一起公开的纠纷显现了出来。

选编解码器这件事,长期以来被当作压缩率与硬件支持的问题。如果要再加一条轴,那就是该标准的许可结构是否与自己的分发方式相合。一件撑了25年的专利若留下了什么,那就是这条轴有效的时间比想象中长得多。
