用可交互图形学线性代数 - Immersive Linear Algebra 学习指南

超越静态图片，用可直接操作的图形学习 - 为什么难、为什么重要、按什么顺序学

2026-07-19 IT/技术

引言：为什么现在又要谈线性代数

不久前，GeekNews(韩国版Hacker News)上一个十年前的网站再次被热议 - 那就是2015年首次发布的免费在线线性代数教材Immersive Linear Algebra。一份十年前的资料如今重新受到关注，原因说来讽刺却很简单：在AI和机器学习已成为日常工具的2026年，支撑它们的数学反而被更频繁地提起，而大多数人当年只是在大学课堂上把这些数学当作生硬的符号匆匆掠过。

这篇文章不只是介绍一本书。我想以自己的视角整理：线性代数为什么重要、为什么这门课偏偏让很多人感觉像一堵墙、「交互式可视化」这种学习方式究竟能带来什么效果，以及该按什么顺序把这本书和3Blue1Brown、MIT课程这类代表性资源组合起来，才能提高学完的概率。在机器学习自学路线图一文中，我写过数学「不必学到完美，够用就好」。这篇文章正是那篇的续篇，把第一阶段前置知识中的线性代数部分再往深处走一步。

1. 线性代数为什么重要 - AI、图形学、数据、工程的共同语言

1.1 数据的语言：向量与矩阵

线性代数是处理成组数字的数学。向量表示一个数据点，矩阵表示一组数据点的集合，或者施加在数据上的变换。表格数据、图像像素值，乃至把文本转成数值的词嵌入 - 如今计算机处理的几乎所有数据，最终都以向量和矩阵的形式存储和运算。懂线性代数，就是拥有了一套语言，能读懂这些数据「以什么形状」存在、「如何被变换」。

1.2 AI、机器学习流水线中的线性代数

神经网络的一层，本质上就是输入向量乘以权重矩阵、再经过一个非线性函数的运算。Transformer的注意力机制由查询、键、值矩阵之间的点积与矩阵乘法构成。降维方法PCA本质上是求协方差矩阵的特征值和特征向量；推荐系统以及LoRA这类轻量微调方法，则利用奇异值分解(SVD)把一个大矩阵近似为几个小矩阵的乘积。不懂线性代数就使用这些模型，和理解这些运算为何如此设计再使用，在调试能力和应用能力上会有明显差距。

1.3 图形学与工程领域也是同一种语言

线性代数的用途不止于AI。3D图形学中物体的旋转、缩放、平移，全部都是矩阵乘法 - 实际上，Immersive Linear Algebra的共同作者之一Tomas Akenine-Möller本人就是实时渲染领域的知名研究者。机器人学的坐标变换、信号处理中的滤波运算、结构工程的荷载计算 - 不同领域共用同一套数学语言，这个事实本身就足以说明学习线性代数的价值。

2. 为什么很多人觉得线性代数难

2.1 先遇到符号和形式主义

许多课程和教材一开始就按顺序列出向量空间的公理、矩阵运算规则、定理和证明。对初学者来说，还没来得及感受「为什么要这样定义」，就得先把符号记下来。形式上的严谨固然重要，但如果它成为学习的第一道门槛，很多人会在这里失去兴趣。

2.2 缺乏几何直觉，只处理数字

如果只把向量当成「一串数字」而不是「箭头」来学，矩阵乘法之类的运算就只剩下手算步骤。但一旦能把向量画成空间中的箭头，把矩阵理解为拉伸、旋转、扭曲这个空间的变换，那么「行列式为0为什么没有逆矩阵」「为什么特征向量是方向不变的向量」这类问题，就能先靠图形直观理解。缺乏这种几何直觉，被普遍认为是线性代数特别难学的核心原因。

2.3 只讲计算步骤、缺少「为什么」的课程设计

反复用手算高斯消元法确实是必要的训练，但如果不同时学习这个计算意味着什么 - 不只是求出方程组的解，而是「这个变换如何压缩空间」 - 那就只记住了步骤，却没有培养出应用能力。结果常常是考试能通过，但面对真实数据问题时，却不知道该在什么时候、怎么用上这些知识。

3. 交互式可视化对学习的作用 - 从操作到直觉

3.1 静态图片与可操作图形的区别

教科书上的静态图只呈现一张快照。而用鼠标直接拖动向量、实时观察结果变化，是完全不同的体验。当你能像亲手触摸一样，看到改变矩阵数值时空间如何伸展和旋转、改变两个向量的夹角时点积如何变化，这个概念就不再是需要死记硬背的东西，而变成了可以观察的对象。

3.2 操作 → 直觉 → 概念的学习循环

交互式学习的核心价值就在这个顺序上。先通过操作图形积累「这样做就会这样」的具体经验，经验累积后形成对模式的直觉，最后形式化的定义和定理才自然地建立在这份直觉之上。Immersive Linear Algebra把每一章都设计成「先从具体直观的例子入手，再推广到形式化数学」，正是遵循了这个原理。

3.3 可视化的局限也要说清楚

但可视化并不能让学习就此完结。正如相关的Hacker News讨论中提到的，以直觉为中心的学习方式，往往会相对轻视形式化证明和一般化定理。也有评论认为，对实践者来说最重要的是「知道自己的理解到什么程度算够用」的判断力；但如果要走向研究或深入应用，严谨的理论学习仍需另行补上。

4. 认识Immersive Linear Algebra - 世界上第一本完全交互式图形的线性代数书

4.1 概览

Immersive Linear Algebra(immersivemath.com/ila)是J. Ström、K. Åström、T. Akenine-Möller于2015年发布的在线教材，自称是「世界上第一本使用完全交互式图形的线性代数书」。发布时只有4章，此后几年逐步扩展，目前是包含前言在内共10章的v1.1版本(ISBN 978-91-637-9354-7)。可以直接在浏览器中免费阅读，无需安装或付费。

4.2 章节结构

目录在导言(Introduction)之后，依次是向量(Vectors)、点积(The Dot Product)、叉积(The Vector Product)、高斯消元法(Gaussian Elimination)、矩阵(The Matrix)、行列式(Determinants)、秩(Rank)、线性映射(Linear Mappings)，最后是特征值与特征向量(Eigenvalues and Eigenvectors) - 从简单的向量运算逐步自然过渡到更抽象的概念。

4.3 适合什么人

对于第一次接触线性代数、想快速建立几何直觉的人，或者曾经学过但「为什么会这样」始终模糊、想找回感觉的人来说，这本书特别有用。反过来，如果目标是深入钻研形式化证明和理论推导，仅靠这本书是不够的，最好搭配下面介绍的正规课程一起学习。

5. 值得搭配的代表性免费资源

5.1 3Blue1Brown - Essence of Linear Algebra

由Grant Sanderson运营的YouTube频道3Blue1Brown推出的Essence of Linear Algebra系列，用动画讲解向量、线性组合与基、线性变换与矩阵、矩阵乘法、行列式、逆矩阵与列空间・零空间、点积与叉积、基变换，直至特征值与特征向量，是一套免费视频课程。它和Immersive Linear Algebra一样把几何直觉放在首位，两者可以互相补强。

5.2 Gilbert Strang - MIT 18.06 Linear Algebra

MIT传奇教授Gilbert Strang主讲的18.06 Linear Algebra，通过MIT OpenCourseWare免费公开了全部课程视频和习题资料。作为一门正规大学课程，它系统性地讲解方程组、向量空间、特征值、正定矩阵等主题及其理论。Strang教授在2023年结束了长达61年的MIT教职生涯，讲完最后一堂18.06课程，那段影像同样可以在OpenCourseWare上找到。想把直觉巩固成理论时，这是首选资源。

5.3 Khan Academy线性代数课程

Khan Academy的线性代数课程以简短的讲解视频，配合分步练习题和即时反馈见长，适合在已经用眼睛理解了概念之后，动手反复练习巩固的阶段。三个资源都免费且完成度很高，完全不需要再额外推荐付费课程替代。

5.4 如何组合这三种资源

我推荐的组合方式是：先用Immersive Linear Algebra或3Blue1Brown建立某个概念的几何直觉，再用MIT 18.06的课程把同一概念扩展为系统的理论和习题，最后在Khan Academy上动手做题，巩固计算的手感。顺序是直觉 → 理论 → 反复练习。

6. 按什么顺序学 - 从向量到SVD

6.1 向量与点积、叉积

一切从向量开始。先把加法、数乘这类基本运算画成空间中的箭头，再掌握衡量两个向量相似度的点积，以及在三维空间中生成新的垂直向量的叉积。

6.2 矩阵与高斯消元法

把多个向量组合起来就是矩阵。掌握用高斯消元法求解方程组的步骤，同时理解行列式、秩这类矩阵性质究竟意味着什么(比如秩表示变换保留了多少信息)。

6.3 线性映射 - 作为函数的矩阵

这是把矩阵不当作单纯的数字表，而看作「把一个空间映射到另一个空间的函数」的视角。理解旋转、缩放、投影这类变换都可以用矩阵表示并组合之后，也就自然明白了为什么神经网络的每一层都要用矩阵表示。

6.4 特征值与特征向量

无论施加什么变换，方向都不改变、只有大小按某个倍数变化的特殊向量就是特征向量，那个倍数就是特征值。PCA中寻找数据分布最分散的方向，以及分析图的稳定性，最终都归结为特征值与特征向量的问题。

6.5 奇异值分解(SVD) - 下一步

Immersive Linear Algebra的目录里没有这一节，但学完特征值和特征向量之后，自然而然会接上奇异值分解(SVD)。任意矩阵(不只是方阵)都可以分解为三个特殊矩阵的乘积，这个想法是推荐系统的矩阵分解、图像压缩，以及LoRA这类轻量微调方法的数学基础。通常会在MIT 18.06的后半部分或Strang的其他课程中继续讲解。

7. 与AI/ML学习路径的衔接

在此前整理的机器学习自学路线图第一阶段前置知识部分，我写过：线性代数只需要「能想象向量和矩阵如何表示数据，大致理解特征值、特征向量为什么会用在PCA这类降维方法中」就够了。这篇文章正是那句话的续篇，具体讲清楚该如何建立这份想象。它也很契合路线图中「需要时再学」的策略 - 不必一开始就想把线性代数全部学完，而是在PCA或梯度下降之类的具体概念卡住时，去Immersive Linear Algebra或3Blue1Brown找对应章节看就好。反过来，如果想先把线性代数打牢，也可以先按本文的顺序(向量→矩阵→线性映射→特征值→SVD)学完，再进入路线图第二阶段的经典机器学习，同样是不错的路径。

8. 实用学习建议

  • 每天花一点时间亲手操作图形 - 拖动向量、改变矩阵数值，同时问自己「为什么会这样」，这种记忆比死记硬背更持久。
  • 先手绘，再用代码复现 - 在纸上画出向量和变换，再用NumPy之类的库把同样的运算写成代码，直觉就和计算连接起来了。
  • 证明可以以后再补 - 不要一开始就想完全弄懂形式化证明，先建立直觉，需要时再用理论书补强。
  • 让同一个概念在多个资源中反复出现 - 同样是特征向量的概念，Immersive的图形、3Blue1Brown的动画、Strang的课程会从不同角度讲解。一次没理解，就在另一个资源里再遇到一次。
  • 马上应用到真实数据上 - 比如用PCA给一个简单的数据集做可视化，把学到的概念立刻用在小项目里，「为什么要学这个」马上就清楚了。

结语：免费开始学线性代数最直观的方式

截至2026年7月，对于初学线性代数或想找回直觉的人来说，入门门槛比以往任何时候都低。Immersive Linear Algebra是一本只要有浏览器就能立刻开始的免费交互式教材，3Blue1Brown的动画、MIT 18.06的系统课程，加上Khan Academy的反复练习 - 全部都是零成本就能组合使用的资源。重要的不是把某一个资源完美学完，而是坚持操作 → 直觉 → 概念这个顺序，从向量到SVD一点点搭建起来。无论是做AI、机器学习，还是图形学、工程，一旦掌握了这门语言，在它之上能理解的东西会多得多。
