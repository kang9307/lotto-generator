サブネット (Subnet) とは？

サブネットは IP ネットワークの論理的な分割です。サブネッティングを行うことで、大きなネットワークを複数の小さなネットワークに分割でき、ネットワーク管理と効率を向上させられます。

主要用語

  • IP アドレス: インターネットプロトコルで使用されるアドレスで、デバイスを識別する固有の番号です。
  • サブネットマスク: IP アドレスにおいてネットワーク部分とホスト部分を区別する値です。
  • CIDR (Classless Inter-Domain Routing): IP アドレス割り当て方式で、/24 のようなプレフィックス長で表現します。
  • ネットワークアドレス: 該当サブネットの先頭アドレスで、ホスト部分がすべて 0 のアドレスです。
  • ブロードキャストアドレス: 該当サブネットの末尾アドレスで、ホスト部分がすべて 1 のアドレスです。

サブネット計算機の使い方

  1. IP アドレス入力欄に有効な IPv4 アドレスを入力します (例: 192.168.1.0)。
  2. CIDR 記法またはサブネットマスクのいずれかを選択して入力します:
    • CIDR: ドロップダウンリストから適切なプレフィックス長を選択します (例: /24)。
    • サブネットマスク: 有効なサブネットマスクを入力します (例: 255.255.255.0)。
  3. 「計算する」ボタンをクリックして結果を確認します。

計算結果の見方

  • ネットワークアドレス: 該当サブネットの開始アドレスです。
  • ブロードキャストアドレス: 該当サブネットの末尾アドレスです。
  • ホスト数: ネットワーク内で利用可能な IP アドレスの数です (ネットワークアドレスとブロードキャストアドレスを除く)。
  • ホスト範囲: 実際にデバイスに割り当てられる IP アドレスの範囲です。
  • 2 進数表現: IP アドレスとサブネットマスクの 2 進数表現です。
