孩子说话比同龄人晚，还能再等吗 - 自闭症谱系的早期信号与可以确认的路

不是替你下判断的文章，而是把你带到能够确认的地方的文章

2026-08-01 生活/健康

引言: 在「再等等看」与「去确认一下」之间

在游乐场上，看到一个月龄相仿的孩子用手指着天空，然后回头看向大人。自己的孩子月龄一样，却从没有过这样的举动。叫名字要叫三四次才回头。会说几个词，但明显比同龄孩子少。托儿所说「再观察一段时间吧」，家里有人说「本来就有孩子说话晚」。上网一搜，有的文章让你今天就去医院，有的文章说没关系。于是什么都没决定，几个月就过去了。

这篇文章正是为了缩短那几个月而写的。而且它并不认为缩短的办法是「尽快贴上一个诊断名称」。恰恰相反。这篇文章不做判断。这里没有「超过几项就说明什么」的标准，也不会为你造出这样的标准。

它想做的只有一件事。把你带到能够确认的地方。把父母独自苦苦想要得出答案的时间，换成整理好观察、带到能给出答案的人面前的时间。

先把贯穿全文的一句话写在这里。早期支持的价值不在于尽快贴上诊断名称，而在于尽快开始所需要的支持。标签不是目的。帮助孩子把此刻用得吃力的能力用得轻松一些，才是目的。

免责说明。本文仅以提供信息为目的。它不是诊断，也不能代替诊断。包括自闭症谱系在内的发育方面的判断，只能通过儿科医生和发育领域专业人员的评估作出。本文的任何一句话都不是为了充当自我检查工具而写的，也没有收录任何筛查工具的条目。如果有让你担心的地方，请不要根据本文下结论，而是沿着下面整理的路径去接受确认。

1. 值得把咨询提前的观察 - 是契机而不是判定

先把这一节的性质说清楚。下面不是一份「这样就是自闭」的清单。这里写到的表现，在没有自闭症谱系的孩子身上也很常见。反过来，即使这些表现几乎都没有，也可能需要确认。一旦开始数数，这份清单就失去了用处。

这一节只有一个用途。如果这些观察反复让你放不下心，那就不要含糊地等下去，而是把咨询的时间提前。英国国民保健服务把自闭的主要信号说明为「与非自闭者相比，在沟通、行为和反应方式上的差异」，同时补充说，每个自闭者都不一样，很多人不会表现出所有信号，信号也未必总是明显。这个补充很重要。

观察领域父母常说的话咨询中实际会处理什么
对名字的反应要叫好几次才回头不同情境下的差异。是否需要先确认听力
目光与表情不太看着人的眼睛是完全不看，还是只在某些情境下才看
指示与手势想要什么就拉着大人的手过去要求性的指与分享性的指之间的区别
语言发育会的词比同龄孩子少是理解还是表达。是否曾增多后又减少
玩耍的样子排列东西能玩很久沉浸的对象，以及转换的困难程度
重复动作甩手，或者重复同一个动作它在什么情况下增多、什么情况下减少
日常安排的变化顺序一变就非常难受可预测性对这个孩子起的作用
感觉非常讨厌某些声音或布料过敏与迟钝影响到生活的范围有多大

读这张表也有规矩。不要去数左边一栏符合几项。请看右边一栏。右边写的是专业人员实际在试图区分什么，而这种区分不是父母在家里能做出来的。这张表的目的不是「我家孩子占了几项」，而是让你事先知道「去咨询会谈到这些内容」。

  • 只有一项也可能成为咨询的契机。仅仅是说话慢这一项观察，就可能需要先确认听力
  • 即使有好几项，也可能有别的解释。听力、环境变化、双语环境、其他发育领域的问题都是候选
  • 随时间的变化比数量更重要。尤其是原本会用的词或手势减少了的情况，请记下时间并且一定要说出来
  • 如果是机构先提出来的，请给予不同的分量。每天看很多孩子的人，比较的基准更宽
  • 父母自身的不安本身也是信息。如果同一个画面已经困扰你好几个月，仅此就构成咨询的理由

2. 「谱系」这个词实际指的是什么

这个词常被理解为「程度各有不同」，但它的实际含义要更宽。世界卫生组织把自闭症谱系说明为「与大脑发育相关的一组多样状态」。这不是同一种样子有浓有淡，而是表现方式本身彼此不同。

该组织给出的跨度相当大。有的人能够独立生活，有的人则有严重的障碍，需要终身的照护与支持。智力功能的范围也从严重受损一直延伸到优异水平。据估计，2021年全球的患病率约为每127人中有1人。

  • 同样的诊断名称并不意味着同样的未来。别的孩子的经过并不能预测你的孩子
  • 共病很常见。世界卫生组织说明癫痫、抑郁、焦虑和注意缺陷多动问题经常同时出现。因此评估不会只看自闭
  • 有时从外表看不出来。英国国民保健服务说明，由于掩饰，也就是不把信号表现出来，在女孩身上尤其更难看出信号
  • 存在其他状态时表现会不一样。该机构写到，当同时存在注意方面的困难、进食问题或学习障碍等其他状态时，自闭看起来会有所不同
  • 所以网上的个人经历很危险。把某一个孩子当作标准，你的孩子几乎总会得出「不一样」的结论

这一节的实用结论是这样的。试图通过与别的孩子比较来得到答案，在结构上注定失败。比较的对象不应是别的孩子，而应是同一个孩子的时间。把三个月前和现在有什么不同写下来，比在网上看一百个别人家孩子的视频更有用。

3. 发育的个体差异 - 为什么父母无法分辨

要分辨「只是晚一点」和「发育上的差异」，确实很难。而这份难，并不是因为父母的观察力不够。而是因为有些信息在结构上父母就无法拥有。

  • 正常范围比想象中宽。即使是同一月龄的孩子，语言和玩耍的发育也散布在相当大的幅度里
  • 父母的观察偏向单一情境。在家里和父母在一起的孩子，关系熟悉，困难可能不容易显露出来
  • 孩子在不同场所、面对不同的人会显得不同。所以评估会一并收集机构和学校的观察
  • 背后可能藏着别的原因。尤其是说话慢的情况，可能需要先确认听力
  • 偏差的方向是错过时机。每天见面的人不容易感受到变化的坡度，所以往往是很久没见的人先提出来

世界卫生组织说明，自闭的特征可能在幼年期就被发现，但确诊往往要晚得多。这句话同时说了两件事。早期的观察是有意义的，以及这种观察并不会直接变成判断。

3.1 如何分辨「再等等看」是计划还是搁置

当周围的人劝你再等等时，判断这句话是否安全的标准不在内容，而在形式。

  • 下一次什么时候再看，定下来了吗。没有日期就不是计划
  • 那时依据什么来判断，定下来了吗。没有标准，下次还会重复同样的对话
  • 这期间要观察什么，定下来了吗。没有记录，下次咨询同样只能靠记忆
  • 这个判断是谁作出的。家人和邻居的安慰很珍贵，但那不是评估

四点都具备的等待是安全的等待。一点都没有的等待，只是时间在流走。确认之后再等待，和没有确认就等待，只是名字相同，其实完全是两回事。

4. 在韩国确认的路径 - 按顺序

从这里开始，全部以韩国的制度为准。照这个顺序走一遍，就不会再停留在「不知道该去哪里」的状态。

阶段在哪里做什么这一步能得到什么
1. 确认体检结果婴幼儿健康检查查看国家健康检查中包含的发育筛查结果单你已经拥有的客观记录。下一次咨询的起点
2. 初级诊疗儿科带上结果单和发育记录去咨询。必要时确认听力排除其他原因。下一步的方向
3. 进一步确认依转诊进行的精密检查可能根据筛查结果被建议的追加评估比筛查更详细的发育信息
4. 发育专科诊疗儿童青少年精神科、康复医学科、大学医院发育相关门诊把多个领域合在一起看的评估关于诊断与否以及支持方向的判断
5. 对接地区资源辖区保健所、育儿综合支援中心、发育障碍人士支援中心、地区残疾人福利馆咨询可以使用的服务与制度一份真正能用得上的支持清单
6. 教育衔接特殊教育支援中心就学前后的教育支持咨询在机构和学校中的具体支持方案

这张表里最常被跳过的是第一行。很多人明明抽屉里就放着已经做过的体检结果单，却不去打开，只在网上搜索。首先要做的不是搜索，而是打开抽屉。

把没能确认的部分写清楚。各项制度的适用对象、支持金额、申请期限会因地区和年度而不同。写这篇文章时，我没能直接打开相关机构的官方页面加以确认，所以没有写出具体金额和期限。出于同样的原因也没有列出电话号码。号码和条件请通过户籍所在地辖区保健所与国民健康保险公团的官方指引直接确认。只要知道机构名称，确认并不难。

4.1 预约第一次就诊时有帮助的几件事

  • 按照可能要等很久来安排。先把号预约上，在等待期间收集资料更好
  • 预约时顺便问清楚需要准备什么。各机构要求的材料不一样
  • 提前请托儿所或幼儿园写观察记录。对方也需要时间
  • 不要只问一家就停下。等待时间有时相差很大
  • 等待期间也可以接受地区机构的咨询。并不是有了诊断才能咨询

5. 诊断过程中实际会发生什么

面临评估的父母最惊讶的一点是不会一次就结束。看看英国国民保健服务的说明就明白原因了。评估由多个专业人员组成的团队进行，对孩子而言包括以下内容。

  • 关于发育经过的详细询问。包括什么时候开始说话这类问题
  • 了解病史并进行身体检查。因为需要一并考察其他原因
  • 观察孩子玩耍的样子以及与成人互动的样子
  • 必要时到机构或学校访问。也会观察课堂上和课间的样子
  • 写有评估结果的报告。记录发现了什么，以及在哪些方面需要帮助

该机构说明，转介被接受之后，到评估可能需要几个月甚至更久。韩国的制度与此不同，但必须汇集多个场合中多个人所看到的情况，这一原理是相同的。

把不会一次确定的原因整理一下，是这样的。

  • 孩子的表现随场所和相处对象而变化。在陌生诊室里的三十分钟只能呈现孩子的一部分
  • 发育是移动中的对象。几个月后的样子有时正是判断所需要的信息
  • 需要一并确认其他可能性。听力、其他发育领域以及可能共存的状态都会被审视
  • 同样的观察在不同脉络中含义不同。所以会同时听取父母和机构的说法

这里有一点父母容易误解。需要时间并不等于什么都不做地干等。即使在评估进行期间，也可以向负责的专业人员询问，在语言和玩耍方面有没有现在就能开始的支持。认为必须有了诊断名称才能开始做点什么，这种想法往往并不属实。

6. 早期干预究竟是在做什么

首先要把框架摆正。把早期干预理解成「治好就没事了」，方向就偏了。目的是让孩子当下觉得吃力的事情变得容易一些，也就是功能与生活质量。

世界卫生组织说明，及时获得有循证依据的早期心理社会干预，可以提高自闭儿童有效沟通和进行社会互动的能力。这句话值得逐段拆开看。有循证依据的、及时的，而目标是沟通与互动的能力。「消除」这个词一处都没有出现。

  • 沟通支持。不只是说话，还包括语言之前的沟通。手势和图片同样是沟通手段
  • 玩耍与互动。朝着增加共同注意和一来一往的经验这个方向推进
  • 日常功能。吃、睡、穿衣、出行在孩子与家庭的生活中占据的比重非常大
  • 面向父母的支持。陪伴孩子时间最长的是父母，因此常常包含对父母的指导
  • 环境的调整。世界卫生组织明确指出，需要在社区与社会层面采取行动，以提升可及性、包容性与支持。干预不只是改变孩子，也包括一并调整环境

本文不推荐任何特定项目或机构。市面上的各种方法循证水平差异很大，而且用着同一个名称，各家实际做的内容往往并不相同。什么适合某个孩子，取决于这个孩子的特点和你们的优先顺序，因此从哪个方向、按什么顺序开始，请与负责的专业人员商量后决定。本文能说的只到方向的性质为止。

该组织还说明，对自闭者的照护需要卫生、教育、就业与社会福利各部门之间的协作。这正是前面那张表把地区机构和教育衔接一并写进去的原因。这不是一家医院就能了结的问题。

7. 为什么要警惕未经验证的方法

在走确认路径的过程中，父母一定会遇到另一类提议。快速的、确定的、今天就能开始的提议。在迫切与信息不对称重叠的地方，这类提议听起来格外有说服力。

这里不写任何产品或方法的名称。取而代之的是用来判断的问题。因为名称会不断变，问题却不会变。

遇到这样的推荐时这样问为什么可能有害
说短期内就会好转能用书面材料给我看那个期限和标准吗发育本来就会变，变化容易被算到干预的功劳上
用数字给出康复率能看看这个数字出自哪份资料吗没有出处的数字是说服工具，不是依据
建议限制饮食我可以和主治儿科医生商量吗生长期的营养限制本身就可能制造风险
推荐排毒或特殊补充剂医学依据是否已经确立依据未经确认的处置，可能没有益处只留下负担
先提高额预付或长期合同中途解约的条件是什么家庭资源有限，这些资源也许本该用在别处
劝你不要和主治医生商量为什么不能商量要求你切断信息，这本身就是不可信的信号
用别的孩子的例子来说明适用于我孩子的依据是什么谱系因人而异。个案不能当作预测

问题不只在费用。更大的损失是时间。花在未经验证的方法上的六个月，本来可以用在别处，而孩子在那段时间本可以获得的支持无法追回。而且承担这份负担的是孩子。陌生的处置、被限制的饮食、反复的奔波，对孩子而言都是实实在在的压力。

7.1 已被明确否定的两种错误信息

  • 疫苗会引起自闭的说法。世界卫生组织明确指出，大量研究已经表明麻疹腮腺炎风疹疫苗不会引起自闭。声称存在关联的那项研究已被撤稿，其作者也被吊销了行医资格。这不是仍在争论中的事项
  • 父母的养育方式是原因的说法。世界卫生组织列举的相关因素包括父母年龄、妊娠期的某些健康状况、妊娠期暴露于空气污染物以及早产等。养育态度和爱的多少并不在其中

8. 这是为整个家庭准备的 - 兄弟姐妹与父母

一旦开始走确认的路径，家里的日常也会随之改变。这一节讲的是围绕在孩子身边的人，而不是孩子本身。

8.1 关于父母的内疚

有一句话必须写在最前面。不是因为你做错了什么才会这样。怀孕时吃的东西、出去工作、看屏幕的时间、生了第二个孩子、那天发了脾气，这些都不是原因。父母的养育方式会造成自闭症谱系，这样的证据并不存在。这不是安慰的话，而是已被确认的事实。

还有一个实际的理由。内疚对孩子毫无帮助，却只会让父母的判断力变得模糊。内疚很重的时候，人更容易被「快速让一切恢复原样」的承诺打动，而真正需要的确认反而会因为「怕坐实是自己的错」被一再推迟。放下内疚不是为了让心里舒服，而是为了能够作出孩子所需要的判断。

也请重新看待你已经察觉到这件事本身。能读到这里，说明你早已经在观察，也早已经开始行动。这不是晚了，而是已经开始了。

8.2 兄弟姐妹

  • 按年龄来解释，但一定要解释。没有解释，孩子会自己编出一个解释，而那个解释多半是自己的错
  • 不要把「你是哥哥你要理解」当成默认。反复下去，忍耐就变成了他的角色
  • 把单独相处的时间写进真正的日程表。只放在心里的计划总会被推迟
  • 兄弟姐妹的反应可能会晚一些出现。当时看起来没事，几个月后才显露出来
  • 把情况告诉学校。学校里一点小小的照顾就能带来很大的差别

8.3 父母的倦怠

  • 倦怠不是意志力的问题。查资料、预约、奔波、办手续堆在一起，谁都会被消耗
  • 分工可以，但记录要共享。如果只有一个人掌握信息，这个人就会成为瓶颈
  • 让父母双方各自把看到的写下来。看法不同的地方，会成为咨询中有用的信息
  • 提前把可以求助的人的名字写下来。难受的那一天，连想起谁都是困难的
  • 每周检查一次自己的睡眠和饮食。这也是照顾孩子的一部分
  • 地区机构的咨询往往在诊断之前就可以接受。它能减少你独自查资料的时间

世界卫生组织指出，自闭者会遭遇污名与歧视，并且未被满足的医疗需求更多。这句话同样落在家庭身上，因为应对周围目光的工作最终也由家庭承担。从承认这份负担是真实存在的开始，会更好。

9. 咨询时值得准备的资料

这一节的清单不是对照症状，而是准备资料。决定咨询质量的，不是父母猜得有多准，而是你给专业人员带去了多少可以看的材料。

资料类型具体是什么为什么有帮助
发育记录第一个词的时间、两词连说的时间、运动发育的时间记忆会淡去。带上日期就变成了信息
变化的记录原本在增加的词或手势是否减少过，以及大致时间变化的方向有时比某一时点的状态更重要
视频平常场面的一到两分钟片段三到五段能把难以用语言说清的东西直接呈现出来
机构观察带班老师的记录，与同龄孩子在一起时的样子家庭之外的眼睛，比较的基准更宽
体检资料婴幼儿健康检查结果单原件这是一份已经存在的标准化记录
家族史语言迟缓、发育迟缓、学习困难、相关诊断史这些是评估中真的会被问到的项目
环境变化近半年的搬家、更换机构、家庭结构变化可以一并考察其他解释的可能性
问题清单提前写下想问的事情的便条就诊时间很短，紧张起来就会忘

关于视频再补充一句。不要挑拍得好的场面。刻意安排的场面信息量很少。吃饭的场面、玩着玩着开始厌烦的场面、日常安排被打乱而不知所措的场面，这些平常而未经整理的场面要有用得多。

下面的资料整理成了可以直接复制到备忘录应用或文档里使用的形式。再强调一次，这是资料准备清单，不是症状评分表。

# 自闭症谱系咨询准备备忘 — 资料整理 · 确认路径 · 家庭支持

来源: braindetox.kr — 自闭症谱系的早期信号与通向支持的路
仅供参考。本文不是诊断，判断属于儿科医生和发育专业人员。
这里没有症状对照表。这是一份资料准备备忘，用来提前收集专业人员在咨询中会问到的内容。
路径说明以韩国的制度为准。

## 1. 关于孩子的基本记录

- [ ] 出生日期与咨询当天的月龄 (早产儿请一并写上矫正月龄)
- [ ] 妊娠与分娩记录: 孕周、出生体重、新生儿期是否住院
- [ ] 婴幼儿健康检查的受检记录，以及每一轮的结果单原件
- [ ] 疫苗接种记录
- [ ] 是否做过听力与视力检查，如果做过是在什么时候
- [ ] 在其他机构做过的检查或诊疗记录的复印件

## 2. 发育记录 — 带日期的最有用

- [ ] 抬头、独坐、走路等运动发育的时间 (在能回忆的范围内)
- [ ] 说出第一个词的时间，开始把两个词连起来说的时间
- [ ] 现在使用的词和句子，写下五个左右的真实例子
- [ ] 语言是否曾经增多后又减少，如果有大概在什么时候
- [ ] 叫名字时的反应，分场景记录 (安静时 / 嘈杂时 / 正专注于喜欢的东西时)
- [ ] 是否会用手指指给你看，从什么时候开始
- [ ] 需要帮助时如何叫大人
- [ ] 和同龄孩子在一起的场景、独自玩耍的场景，各写一段

## 3. 视频 — 比用语言描述更准确

- [ ] 不是特别的场面，而是平常的场面 (吃饭、玩耍、睡前等)
- [ ] 一到两分钟的片段，三到五个就够
- [ ] 一段能听到叫孩子名字的视频
- [ ] 一段孩子在玩喜欢的游戏的视频
- [ ] 一段处于陌生情境或日常安排被改变时的视频
- [ ] 不要刻意安排。平常的样子本身就是信息

## 4. 托育机构的观察 — 为什么需要家庭之外的眼睛

- [ ] 托儿所或幼儿园带班老师的观察记录
- [ ] 与同龄孩子在一起时的样子，尤其是与在家不同的地方
- [ ] 午睡、进餐、如厕等日常环节中值得注意的地方
- [ ] 如果机构曾建议去咨询，具体说了什么、在什么时候

## 5. 家族史与近期环境

- [ ] 家族中是否有语言迟缓、发育迟缓、学习困难或神经发育相关诊断
- [ ] 兄弟姐妹的发育经过
- [ ] 家里使用的语言是否不止一种
- [ ] 近半年内的重大变化 (搬家、更换托育机构、家庭结构变化、重大疾病等)

## 6. 在韩国的确认路径 (按顺序)

1. 婴幼儿健康检查 — 先看国家健康检查中包含的发育筛查结果单
2. 儿科就诊 — 带上结果单和记录。如果语言发育慢，可能需要先确认听力
3. 深度评估与精密检查 — 可能会根据筛查结果被建议。费用支持的对象与期限请向辖区保健所确认
4. 发育专科诊疗 — 儿童青少年精神科、康复医学科、大学医院的发育相关门诊
5. 地区机构 — 辖区保健所、育儿综合支援中心、发育障碍人士支援中心、地区残疾人福利馆
6. 需要教育方面的咨询时 — 特殊教育支援中心

## 7. 咨询时要问的问题

- [ ] 现阶段已经清楚的是什么，还不清楚的是什么
- [ ] 到下一次确认之间，间隔多久比较合适
- [ ] 在诊断确定之前，是否有现在就能开始的支持
- [ ] 该向托儿所或幼儿园传达什么、怎样传达
- [ ] 在家里观察什么、下次带来什么会有帮助
- [ ] 如果需要进一步检查，检查什么、为什么、在哪里做
- [ ] 目前的情况是否适合再听一次其他医疗机构的意见

## 8. 给家庭的条目

- [ ] 父母双方各自把看到的写下来。两边看法不同的地方本身就是信息
- [ ] 按兄弟姐妹的年龄，提前准备好向他们解释的话
- [ ] 把与兄弟姐妹单独相处的时间真正写进日程表
- [ ] 每周检查一次父母自己的睡眠和饮食状况
- [ ] 把难受时可以联系的三个人的名字写下来
- [ ] 没有证据表明养育方式会造成自闭症谱系。内疚不是资料

## 9. 需要警惕的推荐

- 在评估之前就使用确定性说法的地方
- 承诺短期内好转，或用数字给出所谓康复率的地方
- 被问到依据时拿不出来，或者转移话题的地方
- 推荐限制饮食、排毒、补充剂等医学依据尚未确立的方法的地方
- 先要求高额预付或长期合同的地方
- 劝阻你与主治医生商量的地方
- 用别人家孩子的例子来预测你孩子经过的地方

## 10. 值得记住的几句话

- 早期支持的价值不在于尽快贴上一个诊断名称，而在于尽快开始所需要的支持
- 「再等等看」和「去确认一下」并不对立。确认之后再等待，才是安全的等待
- 谱系这个词的意思是每个孩子的表现差别很大。别的孩子的经过并不能预测你的孩子
- 咨询不是去接受判定的地方，而是去整理观察的地方
- 孩子需要的不是标签，而是合适的支持

10. 小结: 这篇文章想把你带到的地方

回到开头的画面。在游乐场上看到别的孩子指着天空的那一刻，需要的并不是判定。而是关于下一步该做什么的一句话。

  • 观察让你放不下心，就不要数项目，而要把时间提前。那是契机，不是判定
  • 比较的对象不是别的孩子，而是同一个孩子的时间。把三个月前和现在写下来
  • 等待要配上日期、标准和观察计划。没有这些，那就不是计划
  • 先打开抽屉。婴幼儿健康检查的结果单是第一步
  • 一次得不出结论是正常的。在此期间请询问有没有已经可以开始的支持
  • 越是说快速而确定的提议，越要追问依据。失去的是时间，多过金钱
  • 整个家庭都在范围之内。兄弟姐妹和父母的状态也是孩子的环境
  • 内疚没有依据。请把那份力气用在观察和确认上

最后再写一遍本文的主旨。这篇文章不会替你判断「我的孩子是不是自闭」。那种判断本文做不到，也不应该做。本文想做的只是把你带到能够确认的那条路上。

而尽快走上那条路的理由，并不是为了早点拿到一个标签。而是为了早点开始所需要的支持。确认的结果也可能是被告知现在可以先观察。那同样是好结果，因为有依据的安心，和含糊的等待完全是两回事。

再次说明。本文以提供信息为目的，不是诊断。包括自闭症谱系在内的发育方面的判断与支持计划，务必与儿科医生和发育领域的专业人员商量后决定。如果有关于孩子让你担心的地方，请不要依据本文下结论，而要去就诊。
