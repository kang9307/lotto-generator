双極性障害の理解と治療へのアプローチ - 気分の変化が疾患であるとき

自分で判断できる病ではない - 観察と診断、そして受診への道

2026-08-01 生活/健康

はじめに: 性格なのか病なのかわからないという言葉

ある月はすべてがうまく回る。深夜三時に眠って六時に目が覚めるのに疲れを感じず、先延ばしにしていた計画を一気に始める。ところが数週間後には何もできなくなる。身支度すら重く、親しい人からの連絡にも返事ができない。こうした話をする人がそろって最後に付け加える言葉がある。「これが自分の性格なのか、それとも病なのかわからない。」

この問いに対して、インターネットはあまりにも簡単に答えを渡してくる。気分の浮き沈みが激しければ躁うつ病だという説明があふれ、項目をいくつ数えろという表もありふれている。それこそがこの記事がやらないことである。双極性障害は表に出る浮き沈みの大きさで見分けられる状態ではなく、似て見える別の状態がいくつも存在し、そして何より、本人が自分の状態をもっとも正確に見られない時期がこの疾患の中心にある。

したがってこの記事の目的は一つである。読者に自分で結論を出させることではなく、診察室までの距離を短くすること。何を観察しておけばよいのか、なぜ周囲の人の記憶が重要なのか、受診の際に何を持っていけば会話が先に進むのかを整理した。判定はここでは行わない。

この記事の性格。この記事は情報提供を目的とする一般的な健康情報であり、医学的な診断や治療に代わるものではない。個人の状態についての判断と治療方針は、必ず医療者による診療を通じて決められなければならない。この記事は薬剤の名称や用量、服用方法を扱わず、ここに書かれたどの内容も自己診断の根拠として使ってはならない。

出典の方針。以下の内容は、世界保健機関、米国国立精神衛生研究所、英国国民保健サービス、および韓国保健福祉部の相談窓口の公開資料を直接開いて確認した範囲だけで書いている。確認できなかった数値や主張は載せていない。

1. いま危険なら、この項目を先に読んでほしい

次のいずれかに当てはまるなら、この記事を読み続けるよりいま連絡することが優先である。本人であっても、そばにいる人であっても同じである。

一人で判断せず、すぐに連絡すべき状況

  • 自傷や自殺についての考えが浮かぶとき。計画が具体的かどうかを自分で吟味しないでほしい。考えが浮かぶこと自体が連絡する理由になる
  • じっとしていられないほど焦燥感が強いとき。ほとんど眠らない日が数日続いたあとであれば、なおさらである
  • 現実と思考の境界が曖昧になるとき。他の人には聞こえないものが聞こえる、周囲が自分を害そうとしていると確信する、自分に特別な力があると確信する、といった場合がここに当たる
  • 本人や他の人が傷つきうる行動が始まったとき。判断力が落ちた状態での運転、突然の大きな支出、衝動的な人間関係の清算も含まれる
  • 周囲の人が「いつものあなたではない」と繰り返し言うとき。本人が平気だと感じていても、その言葉が繰り返されること自体が信号である

2. 気分の変化と疾患の境界はどこにあるのか

まず整理しておきたいことがある。気分が上下すること自体は病ではない。よいことがあれば浮つき、悪いことがあれば沈むのは人の基本動作である。試験の結果、別れ、昇進、引っ越しといった出来事に数日揺れるのも同じである。

公的な保健機関が疾患として扱うのは、それとは構造の異なる状態である。世界保健機関はこの状態を気分とともにエネルギー、活動、思考が一緒に動く状態として説明している。つまり気分だけが変わるのではなく、その人全体の動き方が一つの塊として変わる時期があるという意味である。英国国民保健サービスは、そうした時期が通常数日から数週間単位で続き、その間の安定した期間は数週間から数か月、長ければ数年に及ぶこともあると案内している。

ここで実際に重みがかかる軸は二つである。

  • 期間。一日のうちに何度も上下することと、ある状態が数日から数週間続くこととは性格が異なる。世界保健機関はうつ側のエピソードを説明する際、ほぼ毎日、少なくとも2週間以上続く形について述べている
  • 機能への影響。その期間に仕事、学業、人間関係、金銭管理といった実際の生活が揺らいだかどうかが重要である。気分は悪かったがやることはやったというのと、その期間に仕事を辞めた、関係が切れたというのとは、まったく別の情報である
  • 変化の向きではなく幅。よい方向への変化も観察の対象である。「気分がよくなったのだから大丈夫」という判断が、この疾患ではとくに外れやすい
  • 周囲と本人の認識のずれ。本人は最高の調子だと感じているのに周囲は心配している、という状況が繰り返されるなら、そのずれ自体が記録しておく価値のある情報である

この二つの軸を自己判定の道具として使わないでほしい。期間と機能への影響は診断の材料であって診断そのものではない。同じ期間、同じ程度の困難がまったく別の原因から生じることがあり、それを見分けるのが診療の中身である。ここに書いた軸は、診察室で何を話せばよいかを知るための案内としてだけ使うのが正しい。

3. 躁・軽躁・うつのエピソードで観察されること

この節は意図的に箇条書きではなく叙述で書く。項目を数えさせる形式は、この主題では有害だからである。

3.1 高揚した時期 - 躁として説明される状態

世界保健機関と英国国民保健サービスの案内を総合すると、この時期は気分がはっきり高揚するか、逆に苛立ちやすい状態が続き、エネルギーが目立って増えると説明されている。睡眠が少なくても疲れを感じない状態が併せて報告され、話す速度が上がる、考えが次々につながって一つのことにとどまりにくくなる、といった様子が観察されると記述されている。自分への評価が普段より大きく膨らみ、結果を十分に測らない決定 — たとえば抱えきれない支出や突然の計画変更 — が増える場合が報告されている。状態が重いときには、現実とずれた確信や、他の人にはない知覚の体験を伴う場合もあると案内されている。

ここでこの記事が強調したいのは症状の一覧ではなく、この時期の主観的な体験である。この時期は本人にとってつらい時期として記憶されないことが多い。むしろ物事がうまく運び、頭がよく回る時期として残る。そのため後に診察室で「そのころはどうでしたか」と尋ねられても、問題として報告する材料が本人の側にない。この構造が、次節で扱う診断の遅れの根にある。

3.2 軽躁として説明される状態

英国国民保健サービスは高揚した状態を程度によって分けて説明し、相対的に軽いほうを軽躁という名前で案内している。表に出る方向は似ているが、強さが弱く、生活が完全に崩れるわけではない形として記述されている。問題はまさにその点である。生活が崩れないので受診の理由として認識されず、周囲も「最近調子がよさそうだ」で流してしまいやすい。もっとも見落とされやすい時期がここだと理解するほうが実用的である。

3.3 沈んだ時期 - うつエピソードとして説明される状態

沈んだ側は相対的に気づきやすい。世界保健機関はこの時期を、気分が落ち込み以前は楽しめていたことへの興味が失われる状態がほぼ毎日、少なくとも2週間以上続く形として説明し、集中が難しくなる、罪責感や無価値感が強まる、睡眠と食欲が変わる、気力が落ちるといった様子を併せて記述している。英国国民保健サービスは、この時期に自傷や自殺についての考えが現れることがあると明示している。この一文が、この記事の1節が前に置かれている理由である。

重要なのは、この二つの時期が別々の人が経験する二つの病ではなく、一人の経過のなかで交互に現れうる局面として説明されているという点である。そのため沈んだ時期だけを見ると他の状態と区別しにくい。この記事がうつに関する記事とは別に存在する理由がここにあり、二つの記事の内容を重ねて読むべきでない理由でもある。

4. なぜ診断が遅れるのか

この疾患で診断が遅れるのは、個人の不注意のせいではなく構造的な理由による。順に見ると次のようになる。

  • 受診のきっかけになるのは沈んだ時期である。つらいから助けを求める。そのため初診の話題がうつ側だけで埋まりやすい
  • 高揚した時期は問題として申告されない。本人の記憶に「調子のよかったころ」として残っていれば、診察室で言及される理由がない。医療者は言及されないものを見ることができない
  • 重なって見える状態がいくつもある。英国国民保健サービスは、この疾患が人によって現れ方が異なり、他のメンタルヘルスの状態と症状が似ているため見分けが難しい場合があると明示している
  • 一度の診療で終わらない。同じ案内は、専門医が気分、行動、健康状態、家族歴を詳しく確認する過程を経ると説明している。時間がかかるのは不十分だからではなく必要だからである

診断まで数年かかるという報告は、複数の研究や専門団体の資料で言及されている。ただしこの記事では具体的な平均年数を引用しない。その数値を含む一次資料の本文を直接確認できず、確認できていない数字を書き写すことはこの記事の方針に反するからである。ここで必要な結論は数字ではなく方向である。遅れることがありふれていて、その理由が「高揚した時期が報告されない構造」にあるのなら、その構造を壊す方法も決まっている。高揚した時期についての情報を診察室に入れることである。その方法が9節である。

世界保健機関は、この疾患に対する偏見と差別が地域社会と保健医療の現場の両方に広く存在すると指摘している。そして世界的に治療を受けている割合そのものが低いと記述している。診断の遅れを個人の問題としてだけ見てはいけない理由がここにある。

5. 治療へのアプローチ - 一つではなく組み合わせである

公的資料の説明は一貫している。一つの方法ではなく複数の要素を併せて用いる形である。世界保健機関は効果的な管理を薬物と心理社会的介入の組み合わせとして整理し、心理教育や認知行動的アプローチ、生活習慣の調整、ピアサポートを併記している。英国国民保健サービスも、気分を安定させる薬物療法と対話による治療を並べて案内している。米国国立精神衛生研究所は効果的な治療計画が症状の管理と生活の質の改善に役立つと記述している。

構成要素公的資料が説明する役割よくある誤解
薬物療法気分の揺れを安定させる方向の治療があると説明されている。継続して使うものと必要なときに使うものが併せて言及されている「薬を飲むと感情がなくなる」 — 目標は感情をなくすことではなく振れ幅を扱うことだと説明されている
心理社会的介入対話による治療、心理教育、認知行動的アプローチなどが併せて用いられると案内されている「相談は薬が使えないときにするもの」 — 資料は並列に置いており、代替品として扱っていない
生活リズムの調整規則的な睡眠と活動、ストレス管理などが管理の一部として言及されている「生活を正せばよい」 — 資料はこれを補助として位置づけている
周囲の支えピアサポートや家族の関与が管理の構成要素として言及されている「家族がしっかりすれば治る」 — 支えは治療を助けるものであって治療の代わりではない

ここで必ず押さえておきたいことがある。この記事はどの方法が優れているとは言わない。そう言う根拠がなく、そう言った瞬間にこの記事が診療の真似ごとになるからである。組み合わせの構成と比重は人によって異なり、その調整自体が治療の中身である。

もう一つ。この記事は薬剤の名称、用量、服用方法を扱わない。それは個人の状態と他の健康条件、併用している薬をすべて並べて決められる領域であり、文章に移し替えられない情報である。インターネットで特定の薬についての体験談を探して自分に当てはめることも、同じ理由で危険である。

5.1 継続がなぜ重要なのか

この疾患はよくなったり悪くなったりを繰り返す経過として説明される。つまりいま調子がよいことが治療の終了を意味しないということでもある。米国国立精神衛生研究所は、この状態が長期的な治療を必要とする場合が多いと記述している。安定した期間が長いことは、管理が働いている合図として読むほうが事実に近い。

6. 再発と維持治療 - よくなったときが山場である

実務的にもっとも頻繁に起きるのはこれである。状態が安定すると治療を続ける理由を感じにくくなる。理解できる流れである。副作用が不快で、費用がかかり、通院すること自体が自分の状態を確認させ続ける負担になる。

英国国民保健サービスの案内はこの点で明確である。気分がよくなったとしても医師に言われるまで自分の判断で薬をやめないようにという文がそのまま載っている。

この一文を怖がらせる用途では使わない。必要なのは恐怖ではなく次の行動である。

  • やめたいという考えが浮かんだら、その考えを診察室で口に出してほしい。この節はそれがすべてである。考えを隠して一人で調整することだけを避ければよい
  • 副作用は我慢するものではなく報告するものである。何がいつからどのように不快なのかが調整の材料になる
  • 費用や時間の負担も診療の主題になりうる。現実的な制約を話さなければ、現実に合う計画は出てきにくい
  • 自己判断で減らしたり飛ばしたりしたことがあれば、それもそのまま話すほうがよい。隠された情報は次の判断を誤らせる

再発は失敗ではない。慢性的な経過をとる状態で再び悪くなることは、管理の過程に含まれる出来事である。再発したという事実よりも、再発をどれだけ早く気づき、どれだけ早くつなげるかが実際に結果を変える部分である。その気づきを助けるのが次節の記録であり、8節の周囲の観察である。

7. 日常の管理 - 治療の代わりではなく補助である

先に釘を刺しておく。以下の内容は治療の代わりにはならない。公的な保健機関が生活の管理に言及する仕方は、治療の代案としてではなく治療と併走する要素としてである。この順序を逆にすると危険である。

英国国民保健サービスは自分でできることとして、規則的な生活、十分な睡眠、バランスのとれた食事、運動、ストレス管理を案内し、気分に影響しうる要因を避けることも併せて言及している。世界保健機関も規則的な睡眠と身体活動、食事、ストレスの軽減、気分のモニタリングをセルフケアの項目として記述している。

  • 睡眠を固定変数として扱ってほしい。就寝・起床の時刻が揺れることが状態変化の前触れとして現れる場合が報告されている。睡眠そのものが難しいなら、それも診療で扱う主題である(睡眠の問題に関する記事は別にある)
  • 記録は簡単なほど長く続く。一日一行、その日の気分を0から10の数字で、そして眠った時刻と目覚めた時刻だけ残しても、数か月分が集まれば非常に有用な資料になる
  • 記録の目的は自己判定ではない。数字が数日高いからといって自分で結論を出すためのものではなく、診察室で記憶に頼らないための資料である
  • 変化の大きい時期ほど大きな決定を先送りするほうがよい。転職、引っ越し、大きな支出、人間関係の清算といった取り返しのつきにくい決定は、状態が安定してからに回すほうが安全である
  • 酒や刺激性の物質は判断を鈍らせる。公的資料が共通して節制を勧めている項目である

8. 家族と周囲の人ができることと、してはいけないこと

この節がこの記事でもっとも実用的な部分かもしれない。高揚した時期に本人が自分の状態を問題として認識しにくい構造のために、そばにいる人の観察が代えのきかない情報になるからである。

支える側自身が疲れ切ったとき消耗を認めて支援を探す。ケアは一人で背負うものではない我慢した末に関係そのものが切れてしまうこと

「意志で乗り越えろ」という言葉がなぜとくに有害なのかは、別に書いておく価値がある。

  • この言葉は状態を努力不足として定義し直す。すると助けを求める行動が失敗の自白のように感じられる
  • すでにつらい時期に罪責感をもう一つ重ねる。沈んだ時期に罪責感が強まることは資料が共通して記述する特徴である
  • 世界保健機関が指摘する偏見が、もっとも近い関係のなかで再生産される形である
  • 実際に役立つ情報 — 観察と記録 — をつくる機会を言い争いで消費する。
  • 高揚した時期にはとくに逆効果が大きい。説得は目標ではなく、受診につなげることが目標である。

付け加えると、支える側自身の状態も管理の対象である。長く続くケアは消耗に関する記事が扱う問題と重なる。

9. 受診の際に準備していくもの

ここからはチェックリストにしてよい部分である。症状を数える一覧ではなく持っていく資料の一覧だからである。この準備が、前の節で述べた「診断が遅れる構造」を実際に壊す方法である。

  • 気分の記録。一日一行で十分である。日付とその日の気分を数字で、そして変わったことがあれば一文
  • 睡眠の記録。眠った時刻、目覚めた時刻、そして睡眠が短かったのに疲れていなかった日があったかどうか
  • いつからか。正確な日付でなくてよい。「去年の秋ごろから」という程度でも診療では役に立つ
  • 高揚した時期についてのメモ。これがもっとも重要である。睡眠が短くなった時期、支出が普段と違った時期、計画を急に大きく広げた時期
  • 周囲の人の観察。家族や近しい人が書いてくれた内容を一緒に持っていく。本人の記憶と違っていても、そのまま持っていくほうがよい
  • いま服用しているすべての薬。精神保健と関係のない薬も含める。健康補助食品や漢方も書いておく
  • 他の健康上の問題。診断された疾患、最近の検査結果があれば一緒に
  • 家族歴。家族のなかに気分に関する困難で治療を受けた人がいるかどうか。英国国民保健サービスは専門医が家族歴を確認すると案内している
  • 酒とカフェインの摂取の程度。判断や睡眠に影響する要素なので、ありのままに書いておく
  • もっとも気がかりなこと一つ。診療の時間は短い。いちばん知りたいことをあらかじめ一行にしておけば、そこから扱ってもらえる

受診したあとにすることも一つある。何を聞いたのかをその日のうちに短く書き留めておくことである。次の診療を「前回はこうすることにしたが、こうなった」から始められると、会話の密度がまったく変わる。

10. おわりに: この記事の目的は判別ではなく受診である

最初の問いに戻ろう。「これが性格なのか病なのかわからない。」

この記事が渡せるのは、その問いへの答えではなく問いを持っていく先である。理由は前に出そろっている。この状態の中心には本人が自分の状態をもっとも正確に見られない時期があり、その時期こそ診断に必要な情報が入っている時期である。自己観察だけでは閉じない構造だという意味である。

そこで残る結論は三つの文である。

  • 浮き沈みの大きさで自分で結論を出さないでほしい。その判断はこの記事ではなく診察室から出てくる
  • 高揚した時期の記録を残してほしい。それが診断の遅れる構造を壊す唯一確実な方法である
  • いま危険なら読むのをやめて1節の窓口に連絡してほしい。一人で判断しないことが第一の原則である

もう一度明記する。この記事は情報提供を目的とする一般的な健康情報であり、医学的な診断や治療に代わるものではない。ここに書かれたどの内容も自己診断や治療の決定の根拠として使ってはならない。個人の状態についての判断、治療の開始・変更・中止は、すべて医療者による診療を通じて行われなければならない。関連する主題としてはうつ、不安、成人の注意の問題についての記事が別にある。

# 双極性障害 - 危機時の連絡先 · 受診準備 · 家族の対応

> この文書は情報提供を目的とする一般的な健康情報であり、医学的な診断や治療に代わるものではない。
> どの項目も自己診断の根拠として使ってはならない。判断と治療方針は必ず医療者による診療を通じて決められなければならない。
> 以下の連絡先は**韓国**のものであり、2026年8月1日に保健福祉相談センターの案内ページで直接確認したものである。韓国以外にお住まいの場合は、お住まいの国の緊急通報番号と相談窓口を利用してほしい。

## 1. いま危険なとき - 連絡経路

一人で判断しないこと。次のいずれかに当てはまるなら、読むのをやめて連絡する。

- 自傷や自殺についての考えが浮かぶとき(計画が具体的かどうかを自分で吟味しない)
- じっとしていられないほど焦燥感が強いとき。とくにほとんど眠らない日が数日続いたあと
- 現実と思考の境界が曖昧になるとき
- 本人や他の人が傷つきうる行動が始まったとき
- 周囲から「いつものあなたではない」という言葉が繰り返されるとき

| 状況 | 連絡先 | 受付 |
| --- | --- | --- |
| 生命が危険、または意識がはっきりしないとき | 119 | 24時間 |
| 自殺や自傷の考えがあり、話す相手が必要なとき | 109(自殺予防相談電話) | 24時間 |
| どこに行けばよいかわからないとき | 129(保健福祉相談センター) | 平日09:00~18:00 / 精神保健などの緊急支援相談は24時間 |
| すぐに医学的な処置が必要なとき | 最寄りの救急外来 | 24時間 |
| 地域で継続する支援が必要なとき | 地域の精神保健福祉センター | 機関により異なる |

- 韓国以外では、お住まいの国の**緊急通報番号**、**自殺予防・こころの健康の相談窓口**、または**最寄りの救急外来**を利用する。
- 番号を覚えるより**機関の名前**を覚えておくほうが安全である。相談電話は統合や改編が実際に起きている。
- そばの人が危険に見えるときは、一人で説得しようとせず**一緒に電話をかける。**

## 2. 受診の際に持っていく資料

症状を数える一覧ではなく、**持っていく資料**の一覧である。

- [ ] 気分の記録 - 一日一行。日付 + 気分を0~10の数字 + 変わったことがあれば一文
- [ ] 睡眠の記録 - 眠った時刻、目覚めた時刻、睡眠が短かったのに疲れていなかった日があったか
- [ ] いつからか - 正確な日付でなくてよい。「去年の秋ごろから」で十分
- [ ] **高揚した時期についてのメモ** - もっとも重要。睡眠が短くなった時期、支出が普段と違った時期、計画を急に大きく広げた時期
- [ ] 周囲の人の観察 - 家族や近しい人が書いてくれた内容。本人の記憶と違ってもそのまま
- [ ] いま服用しているすべての薬 - 精神保健と関係のない薬、健康補助食品、漢方も含む
- [ ] 他の健康上の問題 - 診断された疾患、最近の検査結果
- [ ] 家族歴 - 家族のなかに気分に関する困難で治療を受けた人がいるか
- [ ] 酒とカフェインの摂取の程度 - ありのままに
- [ ] もっとも気がかりなこと一つ - あらかじめ一行にしておけば、そこから扱ってもらえる

**受診のあとにも一つ。**その日のうちに聞いた内容を短く書き留めておく。次の診療を「前回はこうすることにしたが、こうなった」から始められる。

## 3. 気分・睡眠の記録の書式(一行形式)

日付 / 気分(0~10) / 眠った時刻 / 目覚めた時刻 / メモ

書式の例:
- 2026-08-01 / 6 / 01:30 / 07:00 / 特記事項なし
- 2026-08-02 / 8 / 03:00 / 06:00 / 睡眠は短かったが疲れていなかった

**記録の目的は自己判定ではない。**数字が数日高いからといって自分で結論を出すためのものではなく、診察室で記憶に頼らないための資料である。

## 4. 家族・周囲の人の対応

| 状況 | 役に立つこと | 害になること |
| --- | --- | --- |
| 普段と違う高揚 | 日付とともに事実を記録(睡眠・話す速度・支出・計画) | その場で断定して言い争いを始める |
| 沈んで何もできない | 小さく具体的な手助け(一緒に予約を取る、一食を用意する) | 「気持ちを強く持て」「意志の問題だ」 |
| 治療をやめたいと言う | 理由を聞き、**診察室で話せるように**助ける | 代わりに決める、こっそり確認して問い詰める |
| 危険の兆候 | 1の窓口につなげ、一緒に電話をかける | 秘密にしてほしいという求めにそのまま応じる |
| 支える側が疲れ切る | 消耗を認めて支援を探す | 我慢した末に関係が切れる |

**「意志で乗り越えろ」が有害な理由**

- 状態を努力不足として定義し直す → 助けを求めることが失敗の自白のように感じられる
- すでにつらい時期に罪責感をもう一つ重ねる
- 偏見がもっとも近い関係のなかで再生産される
- 実際に役立つ情報(観察・記録)をつくる機会を言い争いで消費する
- 高揚した時期にはとくに逆効果が大きい。目標は説得ではなく**受診につなげること**である

## 5. 覚えておくこと

- 浮き沈みの大きさで自分で結論を出さない
- 高揚した時期は本人が問題と感じないことが多い → 周囲の観察と記録が必要になる
- 治療は一つではなく組み合わせであり、どれが優れているとは決まっていない
- よくなったからといって**医療者と相談せずに調整しない**
- 生活の管理(睡眠・規則性・記録)は**補助**であって治療の代わりではない
- いま危険なら読むのをやめて1の窓口に連絡する
