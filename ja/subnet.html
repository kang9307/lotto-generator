サブネット(Subnet)이란?

サブネット은 IP ネットワーク의 논리적 分할입니다. サブネット팅을 を通じて 하나의 큰 ネットワーク를 여러 개의 작은 ネットワーク로 나눌 수 있으며, 이는 ネットワーク 관리와 효율성을 향상시킵니다.

週요 용어

  • IPアドレス: 인터넷 프로토콜에 使用되는 アドレス로, 장치를 식별하는 고유 番号입니다.
  • サブネットマスク: IPアドレス에서 ネットワーク 부分과 ホスト 부分을 구分하는 値입니다.
  • CIDR (Classless Inter-Domain Routing): IPアドレス 할당 방법으로, /24와 같은 접두사 長さ로 표현됩니다.
  • ネットワークアドレス: 해당 サブネット의 첫 번째 アドレス로, ホスト 부分이 すべて 0인 アドレス입니다.
  • ブロードキャストアドレス: 해당 サブネット의 最後 アドレス로, ホスト 부分이 すべて 1인 アドレス입니다.

サブネット計算機 使用법

  1. IPアドレス 入力 필드에 유효한 IPv4 アドレス를 入力합니다 (はい: 192.168.1.0).
  2. CIDR表記 또는 サブネットマスク 중 하나를 選択하여 入力합니다:
    • CIDR: 드롭다운 목록에서 적절한 프리픽스 長さ를 選択합니다 (はい: /24).
    • サブネットマスク: 유효한 サブネットマスク를 入力합니다 (はい: 255.255.255.0).
  3. "計算する" 버튼을 클릭하여 結果를 確認합니다.

計算 結果 해석

  • ネットワークアドレス: 해당 サブネット의 開始 アドレス입니다.
  • ブロードキャストアドレス: 해당 サブネット의 最後 アドレス입니다.
  • ホスト 수: ネットワーク 내에서 使用 可能한 IPアドレス의 수입니다 (ネットワークアドレス와 ブロードキャストアドレス 除外).
  • ホスト範囲: 실제로 장치에 할당할 수 있는 IPアドレス의 範囲입니다.
  • 바이너리 표현: IPアドレス와 サブネットマスク의 2진수 표현입니다.
