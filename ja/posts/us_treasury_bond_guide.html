米国債は安全資産なのになぜ損失が出るのか - 金利・価格・デュレーション・為替

デフォルトの可能性が低いという話と価格が動かないという話は別である。その差を計算で広げてみる

2026-08-01 金融・経済

序論: 「安全」という単語が指しているもの

米国債は安全資産と呼ばれる。ところが実際に買った人たちの間では正反対の話が回る。口座を開いてみたらマイナスが表示されていた、というものだ。二つの記述は矛盾に見えるが、実は別のことを言っている。「安全である」は発行体が約束した金を返すかどうかの問題であり、「損失が出た」は今日の市場でいくらで売れるかの問題だ。この二つはそもそも別の軸である。

本記事の論旨は三行にまとまる。

  • 「国債は安全」とはデフォルトの可能性が低いという意味であって、価格が動かないという意味ではない。信用リスクと市場リスクは互いに独立して存在する
  • 損失の多くは満期前に売る時に生まれる。満期まで持てば名目ベースでは約束されたキャッシュフローを受け取る
  • その損失の大きさはデュレーションが決める。同じ1%pの金利変化が2年債と30年債では8倍以上違って効く。そしてウォン建ての投資家には為替が軸としてもう一つ加わる

本記事はその算数を最後まで追う。「金利が上がれば債券価格は下がる」という文はどこにでもあるが、どれだけ下がるのかを数字で言う記事は少ない。そこで計算機を自分で書いて回し、出た値を表に移した。債券とは何かから知りたいなら、債券投資の入門と社債投資を先に見てほしい。ここでは基礎を説明し直さず、米国債の価格変動の構造一点だけを掘る。

免責事項。本記事は情報提供を目的として書かれている。特定の銘柄や商品を推奨せず、金利や為替の行方を予測しない。本文のすべての金利・利回り数値は計算構造を示すための仮定値であり、特定時点の市場金利ではない。投資判断とその結果に対する責任はすべて本人にある。税金は韓国居住者基準で、韓国国税庁の資料で確認した範囲だけを書き、確認できなかった項目は「確認必要」として残した。実際の申告は国税庁の案内と税務専門家の確認に従うこと。

1. 安全資産なのになぜ損失が出るのか - 信用リスクと価格リスク

まず用語を割らなければならない。債券を持っている人が金を失う経路は大きく二つあり、その二つは原因も対応も全く違う。

  • 信用リスク。発行体が利息や元本を約束通り渡せない状況だ。米国債を安全資産と呼ぶ時に指しているのがまさにこの軸で、ここでの「安全」は発行体の支払能力に対する市場の評価を言う
  • 価格リスク(市場リスク)。発行体は健全なのに今日の市場でつけられる値が下がる状況だ。国債も毎日取引される資産なので価格があり、その価格は市場金利に応じて動き続ける
  • この二つの軸は互いに独立だ。発行体が一度も揺らいだことのない債券でも、価格はいくらでも下がりうる。逆に信用が悪化しているのに金利環境のおかげで価格が持ちこたえる場合もある

ここで決定的な区別が一つ出てくる。価格リスクは「売る時」にだけ確定する。

  • 満期まで保有。債券には満期があり、その日に発行体は額面を返す。途中で価格がいくらで表示されていようと、名目ベースでは約束された利息と元本が入る。口座に出ていた評価損はその間の「過ぎた数字」として残る
  • 途中売却。その日の市場価格で売る。この時評価損が実現損になる。本記事で扱う損失はほぼすべてこの経路である
  • ただし満期保有は万能ではない。名目の元本が戻ることとその金の購買力が維持されることは別の問題だ。物価が上がれば同じ額の実質価値は減る
  • そして満期保有は選択できて初めて成り立つ。急に金が必要になれば満期を待てない。この場合、満期保有戦略は計画書の上にしか存在しない

整理するとこうなる。「安全資産なのに損失が出た」という文は矛盾ではなく、二つの軸を一つの単語で呼んだ結果だ。発行体は安全だったが、自分が売った日の価格が買った時より低かった。ではその価格はなぜ低くなったのか。次節がその算数である。

2. 金利と価格が逆に動く理由 - 算数で

債券の表面利率(クーポン)は発行時点で固定される。この一つの事実がすべてを作る。

額面100ドル、表面利率年4.00パーセントの債券を買ったとする。この債券は満期まで毎年4ドルをくれる。市場に新しく出る債券が年5.00パーセントをくれるなら、誰も4ドルの方を100で買わない。ところがこの債券のクーポンは契約で固定されており、4ドルから上げられない。動けるのは価格だけだ。価格が下がり、その下がった価格で買えば満期までの総収益率が新発債と釣り合う地点で取引が成立する。

その地点を計算する式が現在価値の合算だ。米国債は利息を半年ごとに渡すので、期間を半年単位に刻む。

3. デュレーション - 同じ1%pが満期別に違って痛む理由

2節の表を見ると同じ金利変化に対して満期別の反応の大きさが違う。その差を測る数字がデュレーションだ。

デュレーションの直観は「いつ金を受け取るかの重心」である。30年債は元本100を30年後に受け取る。その遠い未来の100を今日の値に換算する時、割引率が少し変わるだけで結果が大きく変わる。2年債は元本が目の前にあり、割引率が変わる余地がほとんどない。だから満期が長いほど金利に敏感だ。

  • マコーレー・デュレーション。各キャッシュフローをその現在価値で加重平均した平均回収期間である。単位は「年」だ
  • 修正デュレーション。マコーレーを(1 + 最終利回り / 年間利払い回数)で割ったもので、金利1パーセントポイントの変化で価格が何パーセント動くかをそのまま読めるようにした値だ
  • コンベクシティ。デュレーションは曲線に引いた接線なので大きな変化ではずれる。そのずれを補正する2次の項である
  • 表面利率が低いほどデュレーションが長い。途中で返ってくる利息が少なく、重心が後ろに押されるためだ
満期マコーレー・デュレーション修正デュレーションコンベクシティ+1%p 実際の価格変化
2年1.942年1.904年4.62-1.88%
10年8.339年8.176年78.90-7.79%
30年17.728年17.380年420.81-15.45%

注目すべき点が一つある。30年債のデュレーションは30年ではなく17.38年だ。満期とデュレーションは同じものではない。半年ごとにクーポンが入るので重心が満期より前に引っ張られる。「30年債だから金利1%pに30パーセント動くだろう」は間違った計算で、実際にはその半分ほどである。

  • コンベクシティを足せばほぼ合う。30年債基準でマイナス17.38パーセントがマイナス15.28パーセントまで縮まり、正確値のマイナス15.45パーセントに寄る

  • ただしこの非対称を「だから長期債が有利だ」と読んではいけない。同じ満期の中での方向別の差であって、満期間の優劣を言うものではない

4. 満期まで保有するとどうなるか - 額面への収束

1節で「満期まで持てば名目ベースでは約束された金を受け取る」と述べた。これも計算で確認できる。金利が上がった後そのままの位置に留まっていると仮定し、時間だけを流してみよう。

この表が「満期保有」の構造を見せる。金利が全く戻らなくても価格は84.55から100へ上がってくる。残りの期間が短くなり、割引の対象期間が減るためだ。これを額面への収束(pull to par)と呼ぶ。評価損が時間とともに自然に減る理由がここにある。

  • ただしこれは名目金額の話だ。30年後の100ドルが今日の100ドルと同じ物を買えるかどうかは別の問題である
  • そして機会費用が残る。低いクーポンに縛られている間、新しく出た高いクーポンの債券を買えなかったという事実は消えない
  • 満期保有は「売らずにいられる状態」が前提だ。生活資金が必要な時点と満期がずれれば、この戦略は成り立たない
  • 満期のない構造で保有すると、この収束は同じようには働かない。8節で改めて扱う

5. 米国債の種類 - 確認された範囲だけ

「米国債」は一つではない。満期と利払いの方式が違う複数の種類があり、同じ発行体でもデュレーションが違うので金利への反応が全く異なる。以下は米財務省のTreasuryDirectで確認した範囲だけを移したものだ。

種類満期(公式表記)利払い構造上の金利感応度
Bills (短期)4週間 ~ 52週間、5種類の満期クーポンなし。割引発行で満期に額面支払最も低い
Notes (中期)2・3・5・7・10年6か月ごとに利払い中間
Bonds (長期)20年物が追加で提供されると明記6か月ごとに利払い最も高い
FRN (変動金利)2年のみ3か月ごとに利払い構造上低い
TIPS (物価連動)5・10・30年6か月ごと、固定利率を調整後元本に適用実質金利に反応

表の二つのセルはそのまま読んではいけない。Bondsについて公式ページは「now offered in 20-year terms, as well」と記している。つまり既存の満期の上に20年物が乗ったという記述だ。TIPSのページで30年満期が確認できるので長期の区間が存在するのは明らかだが、本記事は名目Bondsの満期の全一覧を断定しない。発行日程と最低購入単位も確認したページになかったため「確認必要」として残す。

5.1 物価連動債(TIPS)の構造

TIPSは他の種類と作動の仕方が根本的に違う。TreasuryDirectが説明する構造はこうだ。

  • 元本が動く。公式の説明は「The principal (called par value or face value) of a TIPS goes up with inflation and down with deflation」である。つまり物価が上がれば元本が増え、下がれば減る
  • 利率は固定、利息額は変動。「TIPS pay a fixed rate of interest every six months until they mature」だが、その固定利率が調整後の元本に掛かるので、実際に受け取る利息の金額は変わる
  • 満期時に下限がある。「If the principal is equal to or lower than the original amount, you get the original amount」だ。物価が下がって元本が当初金額を下回っても満期には当初金額を受け取る
  • 満期は5・10・30年。公式表記は「We sell TIPS for a term of 5, 10, or 30 years」である
  • ただしこの下限は満期時点の話だ。途中で売る価格が当初金額以上という保証ではない。TIPSも途中売却時には価格リスクをそのまま負う

ここでよくある誤解を一つ整理する。TIPSを「物価が上がっても損をしない債券」と読んではいけない。元本が物価に連動するだけで、市場でつけられる価格は実質金利の変化に反応する。名目債が名目金利で揺れるようにTIPSは実質金利で揺れる。軸が変わっただけで価格リスクが消えたわけではない。

6. ウォン建て投資家に加わる第二の軸 - 為替

ここまでの計算はすべてドル基準だ。ウォンで稼ぎウォンで使う人には軸がもう一つ加わる。債券で出た損益と為替で出た損益が掛け合わされる。

式は単純だ。

ウォン基準収益率 = (1 + ドル基準収益率) x (1 + 為替変動率) - 1

  為替変動率 = 売却時点の為替 / 購入時点の為替 - 1
  (+)はドルウォン為替の上昇 = ウォン安 = ウォン換算額の増加
  (-)はドルウォン為替の下落 = ウォン高 = ウォン換算額の減少

--- ウォン基準収益率マトリクス (すべて仮定値) ---
ドル収益率     為替+10%     為替+5%     為替 0%     為替-5%     為替-10%
------------------------------------------------------------------------
  +5.0%        +15.50%     +10.25%      +5.00%      -0.25%      -5.50%
  +3.0%        +13.30%      +8.15%      +3.00%      -2.15%      -7.30%
   0.0%        +10.00%      +5.00%       0.00%      -5.00%     -10.00%
  -3.0%         +6.70%      +1.85%      -3.00%      -7.85%     -12.70%

--- ドルの利益をちょうど打ち消す為替変動幅 (損益分岐) ---
  ドル +5.0%  →  為替 -4.76% でウォン基準の損益ゼロ
  ドル +3.0%  →  為替 -2.91% でウォン基準の損益ゼロ
  ドル -3.0%  →  為替 +3.09% でウォン基準の損益ゼロ

マトリクスの右上の対角線を見てほしい。ドル基準で5パーセント儲けたのに為替が10パーセント下がればウォンではマイナス5.50パーセントだ。債券の判断が当たっていてもウォン口座には損失が出る。損益分岐点は為替マイナス4.76パーセントである。つまりドルの利益5パーセントは為替の4.76パーセント下落までしか耐えられない。

逆方向も同じように成り立つ。2節で計算した10年債のマイナス7.79パーセントに為替を乗せてみよう。

--- 10年債 金利 +1.00%p (ドル -7.79%) に為替を掛けた結果 ---
  債券 -7.79%   為替 +10%   →   ウォン基準   +1.43%
  債券 -7.79%   為替  +5%   →   ウォン基準   -3.18%
  債券 -7.79%   為替   0%   →   ウォン基準   -7.79%
  債券 -7.79%   為替  -5%   →   ウォン基準  -12.40%
  債券 -7.79%   為替 -10%   →   ウォン基準  -17.02%

同じ債券、同じ金利変化なのにウォン基準の結果はプラス1.43パーセントからマイナス17.02パーセントまで開く。最初の行が特に重要だ。債券で7.79パーセント失ったのにウォン口座はプラスである。逆に最後の行では債券の損失が2倍以上に増幅されている。

  • 為替は債券の損益を隠しもするし大きくもする。ウォン口座の数字だけを見るとどちらが原因なのか分からない
  • だから二つの軸を分けて記録しなければならない。購入・売却時点のドル金額と適用為替を別々に残さなければ、事後に何が当たり何が外れたかを復元できない
  • 為替の変動は方向が決まっていない。本記事は為替の行方を予測しない。上の表は与えられた為替変化で算数がどうなるかだけを見せる
  • 為替ヘッジの有無は構造を変える。ヘッジがかかった構造は為替の軸を減らす代わりにヘッジコストという項目が新たに生じる。どちらが良いとは言えず、自分が持っているものがどちらなのかを確認することが先だ
  • 短期物だから為替の軸が小さくなるわけではない。デュレーションは満期が短ければ縮むが、為替は満期と無関係に全額に掛かる。4週間物のBillsにも為替は100パーセント付く

最後の項目が実務上最もよく見落とされる部分だ。短期国債で「安全に」行ったつもりなのにウォン基準の変動がむしろ大きかったなら、たいていは為替の軸が残っていたからである。為替への露出はデュレーションが減らしてくれない。

7. 税金 - 韓国居住者基準、確認されたものと確認必要なもの

本節は韓国居住者基準であり、韓国国税庁の資料で確認した範囲だけを書く。海外投資の税制全般は海外ファンド投資と米国株の税金計算でより詳しく扱ったので、ここでは米国債に直接触れる部分だけを短く整理する。

7.1 国税庁の資料で確認したこと

  • 国外債券の利子は利子所得である。国税庁は金融所得に該当する利子所得として「国外金融機関などに預金して国外で受け取る預金の利子と信託の利益」と「外国法人が発行した債券を保有して受け取る利子と割引額」を挙げている
  • 国内で源泉徴収されなければ無条件で総合課税だ。国税庁の文言は「利子所得として国内で源泉徴収されない場合は無条件で総合課税の対象です」である
  • 2千万ウォン以下でも例外がある。「源泉徴収されていない金融所得(例示 : 国外源泉の利子・配当所得)と出資共同事業者の配当所得は2千万ウォン以下でも総合課税します」と案内している
  • 居住者の利子所得の源泉徴収税率。国税庁は非営業貸金の利益25パーセント、その他の利子所得14パーセントと明示している
  • 有価証券の売買差益は金融所得ではない。「株式や債券など有価証券の売買差益は金融所得ではないため金融所得総合課税の対象ではありません」という案内がある

7.2 確認できず「確認必要」として残すもの

  • 地方所得税を含むかどうか。確認した国税庁のページは14パーセント・25パーセントを提示しながら地方所得税を含む数値かどうかを明示していない。したがって本記事は実効税率を断定しない
  • 海外債券の売買差益が譲渡所得に当たるかどうか。上の文言は「金融所得総合課税の対象ではない」までしか言っていない。他の所得区分で課税されるかどうかは確認した資料にない
  • 為替差益の個別の取り扱い。債券自体の為替差益がどう扱われるか、売却代金を両替する時点の損益がどの項目なのかは確認した資料にない
  • 外国納付税額控除の適用方法。米国で源泉徴収があった場合の処理は本記事で確認できなかった
  • 保有形態による違い。直接保有とファンド・上場投資商品経由の課税方式がどう分かれるかは確認の範囲外だ

税金は個別事情に大きく左右される。所得の構成、居住者判定、口座の種類、保有形態によって結論が変わる。上で「確認」と書いた項目も引用した案内の文言自体を移したものにすぎず、個人の事案にそのまま適用されるという意味ではない。実際の申告は国税庁の案内と税務専門家の確認に従うこと。

8. 直接買うのとファンド・ETFで買うのと - 構造の違い

米国債にアクセスする経路は大きく個別債券を直接保有することと複数の債券を入れた商品を通じて保有することに分かれる。本記事はどちらが良いとは言わない。代わりに構造が何が違うかだけを置く。有利不利は保有期間、資金計画、税制、コストによって人ごとに違って決まるからだ。

項目個別債券の直接保有ファンド・上場投資商品経由

表で最も実質的な行は額面への収束だ。4節で見た「金利が戻らなくても価格が100へ上がる」という性質は満期という仕組みが構造の中にあって初めて成り立つ。組入債券を入れ替え続けて目標デュレーションを維持する構造では、「待てば額面に戻る」を個別債券と同じ形で適用できない。

  • これは優劣ではなく性質の違いだ。分散と利便性を得る代わりに満期という仕組みが抜ける
  • 逆に個別債券は満期を得る代わりに一銘柄に集中し、満期の構造を自分で設計しなければならない
  • どちらにせよ自分が持っているもののデュレーションは知らなければならない。その数字が3節の計算にそのまま入る入力値だ
  • 商品経由なら満期のある構造か、為替ヘッジがかかっているかを商品資料で確認するのが最初の一歩である

9. 確認の手順 - イールドカーブと公式データ

ここまでは構造の話だった。実際に確認するにはどこで何を見るかが必要だ。

9.1 イールドカーブの読み方

イールドカーブは横軸に満期、縦軸に利回りを置き、同じ発行体の債券を満期順に結んだ図だ。読む時のコツはこうである。

  • 一点ではなく曲線全体を見る。「米国の金利」という単一の数字はない。満期ごとに違う利回りがあり、そのどの区間が自分のデュレーションと接するかが重要だ
  • 利回りは価格の別の表現だ。曲線のある点が上がったということは、その区間の債券の価格が下がったという意味である。2節の算数がそのまま適用される
  • 曲線の形の変化と平行移動は違う。本記事の計算はすべて平行移動を仮定した。実際には短期と長期が互いに違う幅で動くことが多く、その場合は満期別の結果が表と変わる
  • 本記事は曲線から行方を予測しない。形を見て未来を読む解釈もあるが、ここでは「自分が持つ満期区間の利回りがどこにあるかを確認する」という用途にだけ使う

9.2 公式データはどこにあるか

  • 発行条件・種類・満期。米財務省のTreasuryDirect 流通国債の案内。5節の表はこのページとTIPSの案内で確認した
  • 日次の利回り。米財務省がDaily Treasury Par Yield Curve Ratesを配信している(金利統計ページ)。ただし本記事を書いている間に当該ページに接続できず、収録された満期区間と算出方法論は確認できなかった。したがって本記事はその内容を引用せず、数値は各自が接続して直接確認する必要がある
  • 時系列の照会。米連邦準備制度系列の公開データベースが国債利回りの時系列を提供している。これも作成中に接続できなかったため、本記事ではいかなる値も引用しない
  • 税制。韓国居住者なら韓国国税庁の案内が一次出典だ。7節に引用した文言がそれである
  • 重要。本記事は2026-08-01現在の金利水準を断定しない。本文の4.00パーセントなどは計算構造を示すための仮定値である

9.3 購入前の確認リスト

  1. 買おうとしているものの種類を確認した。BillsかNotesかBondsかTIPSかFRNか
  2. 満期を確認した。そしてその満期が自分の資金計画と合うかを確認した
  3. デュレーションを確認した。満期ではなくデュレーションだ。商品経由ならポートフォリオ加重平均デュレーションを資料で探した
  4. 金利が1%p上がればいくらになるか計算してみた。その数字に耐えられるか確認した
  5. 2%p・3%pのシナリオも計算してみた。30年債なら仮定条件でマイナス27.68パーセント、マイナス37.42パーセントだ
  6. 満期まで保有できるか確認した。途中で売る可能性があるなら4節の収束は計画から外す必要がある
  7. 為替の露出を確認した。為替ヘッジがかかった構造か、かかっているならコストがどこに反映されるか確認した
  8. 為替マイナス10パーセントのシナリオを計算してみた。6節のマトリクスを自分の予想収益率に当てはめた
  9. 満期の構造を確認した。個別債券なら満期があり、商品なら満期のある構造か確認した
  10. コストを確認した。売買コストと継続コストを別々に確認した
  11. 税制を確認した。7節の「確認必要」項目は国税庁の案内や専門家に尋ねて個別に確認した
  12. 記録の体系を作った。ドル金額と適用為替を分けて残すことにした
  13. 公式データで現在の利回りを確認した。ブログや要約記事ではなく発行元・統計配信元で見た

10. 計算コード - 自分で回してみること

本文のすべての数値は下の関数で計算した。半年単位のキャッシュフローをそのまま割り引く正直な実装で、特別なライブラリは要らない。

const F = 2; // 年間の利払い回数 (米国債は半年ごと)

// 債券の理論価格: クーポンの現在価値の合計 + 額面の現在価値
function price(face, cpn, ytm, years) {
  const n = Math.round(years * F);
  const c = face * cpn / F;
  const y = ytm / F;
  let p = 0;
  for (let t = 1; t <= n; t++) p += c / Math.pow(1 + y, t);
  return p + face / Math.pow(1 + y, n);
}

// マコーレー・デュレーション: 現在価値で加重した平均回収期間(年)
function macaulay(face, cpn, ytm, years) {
  const n = Math.round(years * F);
  const c = face * cpn / F;
  const y = ytm / F;
  let pv = 0, w = 0;
  for (let t = 1; t <= n; t++) {
    const v = c / Math.pow(1 + y, t);
    pv += v; w += v * (t / F);
  }
  const vf = face / Math.pow(1 + y, n);
  pv += vf; w += vf * (n / F);
  return w / pv;
}

// 修正デュレーション = マコーレー / (1 + ytm / F)
// 価格変化率の近似 = -修正デュレーション x 金利変化 + 0.5 x コンベクシティ x 金利変化^2
// ウォン基準収益率 = (1 + ドル収益率) x (1 + 為替変動率) - 1

// 検証: price(100, 0.04, 0.05, 30) → 84.55 (本文2節と一致)

注意すべき点。この関数は理論価格を計算する。実際の取引では経過利子、気配のスプレッド、決済慣行、税金が乗るので画面に見える値と正確に同じではない。それでも金利変化が価格をどの方向にどれだけ動かすかを見積もるには十分だ。

12. まとめ - 数行で

  • 「安全である」は発行体が返すという意味だ。価格が動かないという意味ではない。二つの軸は独立で、口座に出るマイナスはほぼいつも二つ目の軸である
  • 損失は売る時に確定する。満期まで持てば価格は額面に収束する。計算では30年債が金利1%p上昇後84.55まで下がり、残存10年で92.21、残存2年で98.12まで戻った。ただしこれは名目の話であり、売らずにいられて初めて成り立つ
  • 損失の大きさはデュレーションが決める。同じ1%pで2年債マイナス1.88パーセント、30年債マイナス15.45パーセントだ。8倍を超える。満期ではなくデュレーションを見るべきである
  • ウォン建ての投資家には軸がもう一つある。為替はデュレーションが減らしてくれず、全額に掛かる。債券でマイナス7.79パーセントでもウォンではプラス1.43パーセントにもマイナス17.02パーセントにもなりうる
  • だから買うか買わないかではなく、「自分が持つデュレーションと為替の露出はいくらか」が先だ。その数字が分からなければ計算自体が始まらない

## 4. ウォン基準の収益率 (為替の軸)

ウォン収益率 = (1 + ドル収益率) x (1 + 為替変動率) - 1

| ドル収益率 | 為替+10% | 為替+5% | 為替 0% | 為替-5% | 為替-10% |
|---|---|---|---|---|---|
| +5.0% | +15.50% | +10.25% | +5.00% | -0.25% | -5.50% |
| +3.0% | +13.30% | +8.15% | +3.00% | -2.15% | -7.30% |
| 0.0% | +10.00% | +5.00% | 0.00% | -5.00% | -10.00% |
| -3.0% | +6.70% | +1.85% | -3.00% | -7.85% | -12.70% |

- 損益分岐: ドル +5.0% は為替 **-4.76%** までしか耐えない
- 10年債の -7.79% に為替を掛けると **+1.43% ~ -17.02%** に開く
- **為替はデュレーションが減らしてくれない。** 4週間物にも全額に掛かる

## 5. 種類 (米財務省で確認した範囲)

| 種類 | 満期 | 利払い |
|---|---|---|
| Bills | 4週間~52週間、5種類 | 割引発行、満期に額面 |
| Notes | 2・3・5・7・10年 | 6か月ごと |
| Bonds | 20年物の追加提供を明記 | 6か月ごと |
| FRN | 2年のみ | 3か月ごと |
| TIPS | 5・10・30年 | 6か月ごと、調整後元本に固定利率 |

- TIPSの元本は物価に応じて上下し、**満期時は当初金額が下限**
- ただしその下限は満期時点の話で **途中売却の価格は保証されない**

## 6. 計算コード (Node/ブラウザでそのまま実行)

```js
const F = 2;
function price(face, cpn, ytm, years) {
  const n = Math.round(years * F);
  const c = face * cpn / F;
  const y = ytm / F;
  let p = 0;
  for (let t = 1; t <= n; t++) p += c / Math.pow(1 + y, t);
  return p + face / Math.pow(1 + y, n);
}
function macaulay(face, cpn, ytm, years) {
  const n = Math.round(years * F);
  const c = face * cpn / F;
  const y = ytm / F;
  let pv = 0, w = 0;
  for (let t = 1; t <= n; t++) {
    const v = c / Math.pow(1 + y, t);
    pv += v; w += v * (t / F);
  }
  const vf = face / Math.pow(1 + y, n);
  pv += vf; w += vf * (n / F);
  return w / pv;
}
// 修正デュレーション = macaulay(...) / (1 + ytm / F)
// 検証: price(100, 0.04, 0.05, 30) → 84.55
```

- [ ] 種類を確認した (Bills / Notes / Bonds / FRN / TIPS)

- [ ] **満期ではなくデュレーション** を確認した

- [ ] 税制を国税庁の案内・専門家に個別確認した

## 10. やってはいけないこと

- 満期とデュレーションを同じものとして扱う (30年債のデュレーションは17.38年)
- 「安全資産だから価格も動かない」と読む
- ウォン口座の数字だけで債券判断の成否を評価する (為替が混ざっている)
- 短期物だから為替の露出まで小さくなったと仮定する
- 商品経由の保有に個別債券の額面収束をそのまま適用する
- 確認できていない税制を確認済みのように計算に入れる
