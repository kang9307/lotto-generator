引言：全租诈骗与反向全租之后的保证金返还现实

自2022年韩国全租（전세）诈骗事件和反向全租危机全面爆发以来，合同到期后仍无法按时拿回保证金的承租人越来越多。反映损失规模的担保事故统计每年都在变化，最新数据请以HUG（住宅都市保证公社）和国土交通部的公布为准。如果已成为全租诈骗受害者，《全租诈骗受害者支援及居住稳定特别法》的有效期已延长至2027年5月31日，在此之前可以申请受害者认定。但2025年6月1日以后首次签订租赁合同的承租人不在适用范围内（大韩民国政策简报，2025-05-02）。

合同到期后，房东以"要等找到下一个租客才能还"或"没有资金"为由拖延返还保证金的情况已不少见。因为保证金被套住而无法签新房，或贷款利息不断累积的损失也随之出现。在这种情况下，承租人仅靠等待很难保护自己的权利。

下面依据韩国制度，按步骤整理从承租权登记命令、内容证明、支付命令、本案诉讼到强制执行的保证金返还程序。法令、印花税额和送达费以2026年9月29日国家法令信息中心的现行条文和"易查生活法令信息"为准；没有官方依据的期间和费用示例另行标注。租客权利的整体内容请参阅租赁保护法·租客权利完全指南，签约阶段的检查请参阅2026年全租·月租合同检查清单。

1. 要求返还保证金之前的准备阶段

在起诉之前，有一些必须做好的准备。错过这一阶段，合同可能被自动续约，或失去对抗力和优先受偿权，在法律上处于不利地位。

1.1 合同结束前发出拒绝续约通知

韩国《住宅租赁保护法》第6条第1款规定，出租人在租赁期满前6个月至2个月期间未发出拒绝续约通知的，以及承租人在租赁期满前2个月之前未发出通知的，视为以与原租赁相同的条件重新租赁（默示续约）。此时租赁期间视为2年（同条第2款）。

  • 通知时间：承租人须在期满前2个月之前告知不续约的意思。这一"期满前2个月之前"是2020年6月9日修订的条文（国家法令信息中心，2026-09-29核实）
  • 通知方式：短信、KakaoTalk、电子邮件也可以，但要留下送达事实和内容，内容证明邮件是最可靠的证据
  • 措辞示例：写明"不续签合同，并请求于到期日返还全部保证金"，把拒绝续约和返还请求一并说清楚
  • 已发生默示续约时：承租人可随时通知解除合同，出租人收到通知之日起经过3个月，解除即生效（第6条之2）
  • 保存证据：寄送收据、送达记录、回复截图等都应另存一个文件夹

1.2 申请承租权登记命令（维持对抗力）

如果合同已结束却在拿不回保证金的情况下必须搬家，应首先考虑承租权登记命令。完成承租权登记后，即使之后搬走而失去对抗要件，已取得的对抗力和优先受偿权也不会丧失（《住宅租赁保护法》第3条之3第5款）。反之，在登记完成前迁出户籍可能失去这一保护，因此最稳妥的做法是先在登记事项证明书上确认"住宅承租权"的记载后再搬家。

  • 申请法院：管辖租赁住宅所在地的地方法院、地方法院支院或市·郡法院（第3条之3第1款）
  • 申请要件与材料：租赁结束后保证金未返还时可以申请，须释明申请理由和构成承租权登记原因的事实（同条第1款、第2款）。租赁合同复印件、居民登记誊本、建筑物登记事项证明书等准确的附件清单请以申请法院的说明为准
  • 送达前执行：根据2023年4月18日的修订，准用《民事执行法》第292条第3款，即使决定尚未送达出租人，也可以执行承租权登记（同条第3款）
  • 费用：申请和登记所花的费用可以向出租人请求（同条第8款）。印花、送达费、登记许可税等实际缴纳金额请以法院说明为准
  • 所需时间：作出决定和完成登记所需时间因法院情况而异，搬家日期最好在确认登记完成之后再定
  • 注意事项：登记完成前迁出户籍，对抗力可能消灭。务必在登记事项证明书上确认"住宅承租权"的记载后再迁出

1.3 寄送内容证明

内容证明邮件本身没有强制力，但在日后的诉讼中可以证明承租人曾正式请求返还保证金。请求履行的内容证明可以构成韩国《民法》第174条规定的"催告"，但如果6个月内不进行诉讼请求、扣押、假扣押等，就不产生时效中断的效力。撰写方法和寄送流程详见内容证明撰写方法完整指南。

  • 记载内容：合同概要、到期日、请求返还的金额、返还期限（例如送达后14天）、不履行时计划采取的法律程序
  • 寄送方式：可在邮局窗口或通过网上邮局寄送
  • 费用：按韩国邮政事业本部的说明（2026-09-29核实），普通邮件500韩元（25克以下规格）＋挂号2,400韩元＋内容证明手续费誊本1页1,300韩元（每超过1页加650韩元）。A4纸1页为4,200韩元，2页为4,850韩元，会因重量和附加服务而变化
  • 保管：寄出后退回的誊本和收据可作为诉讼证据，务必保管

2. 申请支付命令（简易程序）

支付命令是法院对以支付金钱等为目的的请求，不讯问债务人、仅根据债权人申请作出的命令（韩国《民事诉讼法》第462条、第467条）。在金额和债权关系明确的保证金返还案件中可以优先考虑。但只有在韩国境内能以公示送达以外的方式送达时才能适用（第462条但书），因此需要知道房东的地址。

2.1 申请方式与所需材料

支付命令也可以通过韩国法院电子诉讼系统（ecfs.scourt.go.kr）申请，无需前往法院。

  • 管辖法院：由债务人（房东）普通审判籍所在地的地方法院，或依《民事诉讼法》第7条至第9条、第12条、第18条确定的管辖法院专属管辖（第463条）
  • 所需材料：连同支付命令申请书，提交租赁合同复印件、内容证明复印件、承租权登记相关材料、不动产登记事项证明书等支持请求的资料
  • 撰写要点：写明本金和迟延损害金。金钱债务不履行的损害赔偿额在无约定时按《民法》法定利率年5%计算（《民法》第379条、第397条），自支付命令申请书等相当于起诉状的文书送达债务人的次日起为年12%（《诉讼促进等相关特例法》第3条第1款）。起算日可能因案件而异
  • 电子诉讼：无需去法院即可申请并查看进度。以电子文书提交时，只需贴付印花税额的十分之九（《民事诉讼等印花法》第16条）

2.2 印花税额与送达费（2026年9月核实）

支付命令申请书须贴付相当于起诉状印花税额十分之一的印花（《民事诉讼等印花法》第7条第2款）。截至2026年9月29日的计算如下。

  • 起诉状印花税额：诉讼标的额不足1千万韩元的为万分之五十；1千万韩元以上不足1亿韩元的为万分之四十五加5,000韩元；1亿韩元以上不足10亿韩元的为万分之四十加55,000韩元；10亿韩元以上的为万分之三十五加555,000韩元。不足1千韩元按1千韩元计，1千韩元以上的不足100韩元部分不计（同法第2条）
  • 示例（保证金1亿韩元）：起诉状印花税额455,000韩元的十分之一即45,500韩元为支付命令印花税额。通过电子诉讼提交则为其十分之九（约4万1千韩元）
  • 送达费：1次送达费×当事人人数×6次。1次送达费公布为5,640韩元（易查生活法令信息，2026-09-15基准），承租人和出租人2人时为67,680韩元
  • 因异议转入诉讼时：须补缴起诉状印花税额减去已贴印花税额的差额（《民事诉讼法》第473条第1款，印花法第7条第3款）。以1亿韩元为例为455,000−45,500＝409,500韩元，期限内不补缴的，申请书将被驳回（第473条第2款）
  • 合计示例（保证金1亿韩元，纸质提交）：支付命令阶段印花45,500韩元＋送达费67,680韩元＝约11万3千韩元

2.3 异议申请与转入诉讼

债务人自收到支付命令送达之日起2周内提出异议的，支付命令在该范围内失效（《民事诉讼法》第470条第1款），并视为在申请支付命令时已提起诉讼（第472条第2款）。

  • 异议期间：自支付命令送达之日起2周内，属于不变期间（第470条）
  • 无异议时：支付命令与确定判决具有同等效力（第474条）。基于已确定支付命令的强制执行，原则上无需取得执行文，凭支付命令正本进行（《民事执行法》第58条第1款）
  • 有异议时：转入诉讼，补缴印花后案卷移送管辖法院（第473条第3款）。督促程序的费用成为诉讼费用的一部分（同条第4款）
  • 无法送达时：支付命令不能通过公示送达。收到法院的地址补正命令后，债权人可以申请提起诉讼；只能通过公示送达的，法院可依职权将案件转入诉讼程序（第466条）。如果已联系不上房东，也可以考虑一开始就提起本案诉讼

3. 保证金返还请求的本案诉讼

房东对支付命令提出异议，或一开始就选择诉讼的，将按正式民事诉讼进行。虽然耗费更多时间和费用，但会经过证据调查和辩论后作出判决。请求金额在3,000万韩元以下的金钱请求一审案件按小额案件处理（《小额案件审判规则》第1条之2），相关程序整理在小额诉讼完全指南2026中。

3.1 起诉状撰写要点

起诉状应明确写明诉讼请求和请求原因，并一并提交证据材料。

  • 诉讼请求示例："被告应向原告支付○○○韩元，及自○年○月○日起至本案起诉状副本送达之日止按年5%、自次日起至清偿之日止按年12%计算的款项"
  • 请求原因：按时间顺序叙述租赁合同的签订、期间届满、保证金返还义务的发生、返还请求及未履行的事实
  • 附件证据：租赁合同、内容证明、登记事项证明书、承租权登记命令决定书、短信和KakaoTalk对话、转账记录
  • 迟延损害金利率：自起诉状或相当文书送达债务人的次日起为年12%（《诉讼促进等相关特例法》第3条第1款，2019年6月1日施行的法定利率规定）。但如果认为债务人对履行义务的存在或范围提出争议是合理的，则在该范围内不适用（同条第2款）
  • 委托律师：保证金金额较大或涉嫌全租诈骗时，建议咨询专业人士。律师费由各事务所自定，委托前应以书面约定确认

3.2 预计所需时间

以下期间是旧版中给出的一般示例，并非有法院统计支持的数值（2026年4月基准，未能更新核实）。实际期间会因法院情况和案件复杂程度而有很大差异。

  • 起诉状受理至被告提交答辩状：约1至2个月
  • 第一次辩论期日：起诉状受理后2至3个月
  • 追加辩论与证据调查：2至3次，每次间隔1至2个月
  • 宣判期日：辩论终结后2至4周
  • 整体：简单案件约6个月，房东争辩或需要公示送达的案件在1年以上
  • 上诉时：可能再需要数月至1年以上

3.3 胜诉不等于实际收回

在合同、承租权登记、内容证明等证据齐全的案件中，与取得判决本身相比，判决后实际收回款项往往更难。旧版中的"一审胜诉率约92%"和"实际收回率55%至65%"因无法核实出处已删除。

  • 收回失败的主要原因：(1)房东无资力或破产，(2)先顺位抵押过多，(3)拍卖反复流拍
  • 保全处分：如果担心房东在判决前处分财产，可以考虑通过假扣押冻结财产
  • 执行准备：取得命令支付金钱的执行依据后，可以向债务人普通审判籍所在地法院申请财产明示（《民事执行法》第61条）

4. 强制执行（判决之后）

取得确定判决或已确定的支付命令等执行依据后，即可据此申请强制执行。这是真正拿回保证金的阶段。

4.1 不动产强制拍卖

对房东所有的租赁住宅或其他不动产进行强制拍卖，是最直接的收回手段。

  • 申请法院：管辖不动产所在地的地方法院
  • 所需材料：具有执行力的正本（判决须附执行文，已确定的支付命令原则上即正本本身）、送达证明、登记事项证明书等
  • 无需履行对待义务：承租人依据保证金返还请求诉讼的确定判决等执行依据对租赁住宅申请拍卖时，不以腾退房屋这一对待义务的履行或履行提供作为执行开始要件（《住宅租赁保护法》第3条之2第1款）。但要通过优先受偿权领取保证金，须将住宅交付给买受人（同条第3款）
  • 费用：拍卖申请登记的登记许可税为债权金额的千分之二（《地方税法》第28条第1款第1项第4目），地方教育税为其百分之二十（第151条第1款第2项），合计为债权金额的0.24%。拍卖预缴金由法院确定，请向申请法院咨询
  • 分配顺位：抵押权、税收债权等先顺位优先，承租人按基于对抗要件和确定日期的优先受偿权顺位参与分配。小额承租人最优先受偿标准请参阅租赁保护法·租客权利完全指南
  • 期间与流拍：从申请到分配的期间以及流拍时降低最低拍卖价的比例因法院和案件而异，请以拍卖期日公告为准。先顺位债权过多时可能分不到款项

4.2 存款与工资扣押

除不动产外，还可以对房东的存款、工资、经营收入等金钱债权强制执行。但法律规定的生活费相当额不得扣押，这一基准金额自2026年2月1日起已上调。

  • 债权扣押及收取命令：使债权人可直接向第三债务人（银行等）收取的命令。作出决定所需时间因法院情况而异
  • 财产查询：在财产明示程序中债务人提交的财产目录不足以清偿等情形下，可根据债权人申请向金融机构等查询债务人名下财产。须指定查询机构并预缴费用（《民事执行法》第74条）
  • 工资扣押限度：工资债权的二分之一不得扣押。若该二分之一金额不足每月250万韩元，则250万韩元以内禁止扣押；若超过每月300万韩元，则仅在300万韩元加上（二分之一金额−300万韩元）的二分之一以内禁止扣押（《民事执行法》第246条第1款第4项，施行令第3条、第4条）。250万韩元标准适用于2026年2月1日以后受理的扣押命令（原为185万韩元）
  • 禁止扣押的存款：个人余额250万韩元以下的存款等不得扣押（施行令第7条），并新设了只存入禁止扣押生活费的"生活费账户"制度（《民事执行法》第246条之2，施行令第8条）
  • 经营者销售额扣押：信用卡销售债权、租金收入、客户应收款也可能成为扣押对象
  • 实务提示：如果知道房东的往来银行，同时对多家银行申请更有效

4.3 利用全租保证金返还担保

如果签约时加入了HUG（住宅都市保证公社）或SGI首尔保证等的全租保证金返还担保，可以向担保机构请求履行担保，而不必对房东进行漫长的诉讼。要件和材料以担保条款为准，请求前须向担保机构确认现行标准。

  • 履行请求要件：以担保条款和HUG说明为准。旧版将"合同期满后经过1个月、完成承租权登记命令"列为要件（2026年4月基准，未能更新核实），请求前请向HUG确认现行要件
  • 所需材料：担保书、租赁合同、承租权登记相关材料、居民登记誊本等（2026年4月基准，未能更新核实）
  • 支付时间：发生担保事故后到领取保证金可能需要数个月，搬家和贷款日程应留有余地
  • 追偿权：担保机构向承租人支付后，对房东行使追偿权
  • 加入标准：HUG返还担保的全租价格比率标准自2023年5月1日起对新合同适用90%（大韩民国政策简报，2023-02-02）。担保费率年0.115%至0.154%基于2022年11月政策简报资料，加入前请确认现行费率
  • 其他担保机构：SGI首尔保证等其他机构的产品要件和限额不同，请以该机构的条款为准

结论：快速收回保证金的五步策略

收回全租保证金拼的是程序而不是情绪。与其只把时间花在和房东的协商上，不如按期限依次走完法律程序，结果往往能更早收回。一般流程如下。

  • 第一步（期满前6个月至2个月）：最迟在期满前2个月之前通知拒绝续约，并确认是否加入返还担保
  • 第二步（到期前后）：寄送请求返还的内容证明，制定新房签约和搬家计划
  • 第三步（到期后立即）：申请承租权登记命令（搬家前确认登记），已加入返还担保的向担保机构确认请求程序
  • 第四步（此后）：未加入返还担保的，知道房东地址可申请支付命令，不知道或争议较大则提起诉讼。若已通过内容证明催告，须在6个月内采取后续程序
  • 第五步（取得执行依据后）：申请不动产强制拍卖和债权扣押，必要时通过财产明示和财产查询寻找执行对象

最重要的原则是"不拖延、有证据"。以上内容仅供一般信息参考，不构成法律意见。同样的程序也会因个案事实不同而结果不同，如果难以独自处理，请咨询律师、大韩法律救助公团（直拨132）、住宅租赁纠纷调解委员会、HUG全租受害支援中心等。

# 全租保证金返还程序检查表（韩国标准）

基准日：2026-09-29。法令、印花税额和送达费均通过韩国国家法令信息中心和"易查生活法令信息"核实。本文为一般信息，不构成法律意见。具体案件请咨询律师或大韩法律救助公团（132）。

---

## 1. 分步检查表

### 期满前
- [ ] 已在期满前2个月之前通知不续约（《住宅租赁保护法》第6条第1款）
- [ ] 通知方式能留下送达和内容记录（如内容证明）
- [ ] 已确认是否加入返还担保及担保机构
- [ ] 若已默示续约：通知解除后经过3个月生效（第6条之2）

### 到期后立即、搬家前
- [ ] 已申请承租权登记命令（住宅所在地管辖的地方法院、支院或市郡法院）
- [ ] 在登记事项证明书上确认"住宅承租权"记载后再搬家
- [ ] 已保存申请和登记费用收据（可向出租人请求，第3条之3第8款）
- [ ] 已寄送请求返还的内容证明（催告后6个月内无后续程序则无时效中断效力，《民法》第174条）

### 收回程序
- [ ] 知道房东地址 → 考虑支付命令（只能公示送达时不可申请）
- [ ] 不知道地址或争议较大 → 考虑本案诉讼
- [ ] 请求金额3,000万韩元以下 → 小额案件（《小额案件审判规则》第1条之2）
- [ ] 担心判决前财产被处分 → 考虑假扣押

### 取得执行依据后
- [ ] 已确定的支付命令原则上无需执行文，凭正本执行（《民事执行法》第58条）
- [ ] 申请拍卖租赁住宅时无需先腾退（《住宅租赁保护法》第3条之2第1款）
- [ ] 但要按优先受偿领取分配款须交付住宅（同条第3款）
- [ ] 找不到财产时：财产明示（第61条）→ 财产查询（第74条）

## 2. 费用计算表（以保证金1亿韩元为例）

| 项目 | 计算 | 金额 |
|---|---|---|
| 起诉状印花税额 | 1亿×万分之四十＋55,000韩元 | 455,000韩元 |
| 支付命令印花税额 | 起诉状印花税额的十分之一 | 45,500韩元 |
| 电子诉讼提交 | 上述金额的十分之九 | 约41,000韩元 |
| 送达费（2人） | 5,640韩元×2人×6次 | 67,680韩元 |
| 支付命令阶段合计（纸质） | 45,500＋67,680 | 约113,000韩元 |
| 异议后补缴印花 | 455,000−45,500 | 409,500韩元 |
| 拍卖申请登记税 | 债权金额的0.2%＋其20% | 债权金额的0.24% |

| 诉讼标的额 | 印花税额 |
|---|---|
| 不足1千万韩元 | 标的额×万分之五十 |
| 1千万韩元以上不足1亿韩元 | 标的额×万分之四十五＋5,000韩元 |
| 1亿韩元以上不足10亿韩元 | 标的额×万分之四十＋55,000韩元 |
| 10亿韩元以上 | 标的额×万分之三十五＋555,000韩元 |

不足1千韩元按1千韩元计，1千韩元以上的不足100韩元部分不计。
