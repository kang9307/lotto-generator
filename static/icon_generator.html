📋 사용 방법

  1. 각 도구의 아이콘 버튼을 클릭하여 개별 다운로드하거나, "모든 아이콘 다운로드"를 클릭하세요.
  2. 다운로드된 파일들을 static/images/ 폴더에 복사하세요.
  3. 파일 이름은 자동으로 올바르게 지정됩니다:
    • random_menu_icon_192.png, random_menu_icon_512.png, random_menu_og.png
    • nickname_icon_192.png, nickname_icon_512.png, nickname_og.png
    • age_icon_192.png, age_icon_512.png, age_calculator_og.png
    • char_counter_icon_192.png, char_counter_icon_512.png, char_counter_og.png
    • token_counter_icon_192.png, token_counter_icon_512.png, token_counter_og.png

자주 묻는 질문

이 도구로 무엇을 만들 수 있나요?

braindetox.kr 도구들을 위한 PWA 아이콘(192×192, 512×512)과 OG 이미지(1200×1200)를 브라우저 캔버스로 그려서 PNG 파일로 다운로드할 수 있습니다. 개별 다운로드와 전체 일괄 다운로드를 모두 지원합니다.

이미지가 서버로 업로드되나요?

아니요. 모든 아이콘은 브라우저의 Canvas API로 로컬에서 그려지고, 다운로드 파일도 브라우저 안에서 직접 생성됩니다. 서버로 전송되는 데이터는 없습니다.

제 PNG 이미지를 올려서 아이콘으로 변환할 수 있나요?

현재 버전은 미리 정의된 도구 아이콘 세트를 생성하는 전용 도구라서 사용자 이미지 업로드·변환 기능은 제공하지 않습니다.
