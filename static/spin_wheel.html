돌림판은 어떻게 사용하나요?

항목을 한 줄에 하나씩 입력한 후 ▶ 버튼이나 룰렛 중앙을 클릭하면 회전이 시작됩니다. 모바일에서는 룰렛을 손가락으로 빠르게 스와이프해도 회전합니다. 결과는 자동으로 히스토리에 저장됩니다.

가중치는 어떤 의미인가요?

가중치 옵션을 켜면 각 항목의 확률을 조정할 수 있습니다. 기본값은 1이며, 숫자가 클수록 해당 항목이 당첨될 확률이 높아집니다. 예: A=3, B=1일 경우 A가 B보다 3배 자주 당첨됩니다.

당첨자 자동 제거란?

이 옵션을 켜면 룰렛에서 당첨된 항목이 자동으로 제거되어, 중복 없이 순서대로 모든 항목을 한 번씩 추첨할 수 있습니다. 발표 순서 정하기, 당번 정하기 등에 유용합니다.

URL 공유는 어떻게 작동하나요?

🔗 버튼을 누르면 현재 항목들이 URL에 인코딩됩니다. 그 링크를 친구·동료에게 보내면 같은 룰렛을 공유할 수 있어 회식 자리, 온라인 미팅에서 유용합니다.

결과는 공정한가요?

브라우저의 암호학적 난수(crypto.getRandomValues)를 우선 사용합니다. 룰렛 회전 각도와 결과 판정이 완전히 무작위이며, 시각적 회전 애니메이션은 결과를 보여주기 위한 것입니다. 가중치를 조정하지 않으면 모든 항목이 동일한 확률입니다.

키보드 단축키가 있나요?

스페이스바 또는 엔터키로 룰렛을 돌릴 수 있습니다. F키로 전체화면 모드 전환, M키로 음소거 토글이 가능합니다.
