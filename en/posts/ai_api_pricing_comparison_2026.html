2026 AI API Pricing Comparison - Per-Million-Token Costs

Input/output rates, context, multimodal and caching for GPT, Claude, Gemini, Grok and open models - a value guide for developers and startups

Jun 15, 2026 Tech & IT

Introduction: Pricing Is Architecture

In 2026, choosing an AI model is no longer just about "which one is smartest." Build the same feature on two different APIs and the monthly bill can differ by more than 10x. For high-volume workloads - B2B products and startups especially - the per-million-token rate sets your unit economics, and unit economics decide whether the business survives.

This guide gathers the major LLM API prices, verified on August 24, 2026, into one table, split by input and output, and then looks at the other axes that matter: context window, multimodal support and caching discounts. It closes with use-case picks across three lanes - top performance, best value, and open - and practical tips for cutting cost with caching and routing.

Pricing disclaimer (important): Every figure below reflects official pricing verified on August 24, 2026. LLM API rates change frequently - quarterly or monthly - and vary by promotion, region and tier, with cache and batch discount structures differing per model. The table mixes in time-limited promotional rates with stated end dates (GPT-5.6 Sol, Gemini 3.7 Flash) and rates that double by time of day (DeepSeek), so even one row can bill differently depending on when you call it. Before any real adoption or quote, verify the latest rates on each provider's official pricing page. This article is a starting point for decisions, not a basis for contract pricing.

2. Beyond Price - Context, Multimodal, Caching

Rates alone tell half the story. Real cost and fit diverge along three more axes.

2.1 Context Window and the "Long-Context Premium"

The context window is how much input fits in one request. Watch the long-context premium: GPT-5.5 steps up above 272K, and every GPT-5.6 model carries a separate long-context rate ($8.00/$30.00 for Sol, $4.00/$18.00 for Terra, $0.40/$1.80 for Luna). Gemini 2.5 Pro rises to $2.50/$15.00 above 200K, and Grok 4.6 to $4.00/$12.00 at 200K and above. The Claude models, by contrast, carry no such tiered surcharge on the price list. If your workload feeds whole long documents, this premium structure drives your effective rate - quote from the first two columns alone and the real bill can come in more than double.

2.2 Multimodal Support

Irrelevant if you handle text only, but decisive for images, audio and documents. Gemini 2.5 Flash supports text, vision, audio, function calling and structured output cheaply, making it strong value for multimodal. GPT-5 mini also handles text, vision and function calling. Image tokens are billed separately, and high-resolution inputs can consume far more tokens, so never estimate multimodal cost from the text rate alone.

2.3 Caching Discounts and Speed

For workloads that resend the same prefix (system prompt, long reference docs, tool definitions), prompt caching cuts cost sharply. Several providers reduce cached input by about 90%, billing cached tokens at roughly one-tenth of list price. Where low latency matters for real-time UX, small fast models like Haiku 4.5, Gemini 2.5 Flash and GPT-5 mini win. Speed and price usually move together - smaller, cheaper models tend to be faster.

3. Use-Case Picks - Top Performance vs Value vs Open

The answer is not a single model but per-workload placement. Three lanes.

3.1 Top Performance - Complex Reasoning, High-Stakes Code

Where accuracy is trust and mistakes are expensive - production migrations, security-sensitive code, long-horizon autonomous agents - flagships are the safe choice. In the current generation, Claude Opus 5 ($5.00 input / $25.00 output) and GPT-5.6 Sol ($4.00 input / $20.00 output) are the headline picks, with GPT-5.6 Cyber ($12.50 input / $75.00 output) and Claude Fable 5 ($10.00 input / $50.00 output) above them. Output is pricey, so agent workloads with frequent long outputs need a cap to stop token runaway. Claude Sonnet 5 at $2.00 input / $10.00 output is the low-rate end of the top tier, a balance point when you need high performance but are cost-sensitive - and a case where the introductory price became the list price.

3.2 Best Value - High Volume, Real-Time Replies

Low-difficulty, high-volume tasks - classification, summarization, extraction, structured replies - belong on small, cheap models. In the current generation, GPT-5.6 Luna ($0.20 input / $1.20 output) is the low end of this table, followed by Gemini 3.5 Flash-Lite ($0.30 input / $2.50 output) and Gemini 3.7 Flash ($0.75 input / $3.75 output) - though the 3.7 Flash rate holds only through December 31, 2026 and doubles the following year. From the previous generation, Gemini 2.5 Flash ($0.30 input / $2.50 output) and GPT-5 mini ($0.25 input / $2.00 output) still pair value with multimodal. Claude Haiku 4.5 ($1.00 input / $5.00 output) suits low-latency real-time UX. Among the Grok models, 4.3 is $1.25 input / $2.50 output and 4.6 is $2.00 input / $6.00 output - the rate rose with the generation.

3.3 Open-Weight - Lowest Cost, Data Control

If you want the cost floor or can't send data outside, open-weight models are attractive. DeepSeek V4 Flash still sits near the floor at $0.22 input / $0.66 output off-peak on its hosted API, but doubles to $0.44 / $1.32 during peak hours - so "the cheapest model" is not true around the clock. The GLM family prices 5.1 and 5.3 identically at $1.40 input / $4.40 output, and the Kimi K2.7 figure ($0.95 input / $4.00 output, 256K, automatic caching) is a June 2026 number this update could not re-verify. The real open-weight advantage - self-hosting - carries GPU capital and operations overhead, so a cheap hosted rate and cheap self-hosting are separate break-even calculations.

4. Practical Cost-Cutting Tips

Even on the same model, design can cut cost substantially.

4.1 Bake Prompt Caching In From the Start

Put unchanging prefixes - system prompt, tool definitions, long reference docs - first, and the per-request question last, to raise cache hit rate. Caching is prefix-matched, so a single timestamp or UUID slipped into the front breaks the cache. For chatbots, RAG and agents with a repeated fixed context, caching alone cuts input cost sharply.

4.2 Model Routing - Cheap for Easy, Pricey for Hard

Sending every request to a flagship is the most common waste. Add a difficulty classifier, route easy work to small models like Gemini 2.5 Flash, GPT-5 mini or Haiku 4.5, and reserve the flagship for complex reasoning and high-stakes work; average rates drop fast. A provider-agnostic gateway turns a price-driven model swap into a config change rather than a rewrite.

4.3 Trim Output and Use Batches

Output is 3 to 6 times pricier than input, so trimming needlessly verbose output alone reduces cost. Use structured output (JSON schema) to cut filler, and lower the effort level on models that over-emit reasoning tokens to control invisible output. Latency-tolerant bulk work goes through batch APIs (typically 50% off), halving the rate.

5. Conclusion - Judge by Effective Cost, Not the Sticker Table

The 2026 LLM market is bipolar: flagships fight for performance at the top while small and open models collapse rates at the bottom. The point is not to memorize a single rate table but to compare effective cost - each rate multiplied by your input-to-output ratio and cache hit rate. The same "$5 per million" produces a wildly different bill for a cache-friendly RAG versus an agent whose reasoning tokens run away.

Three concrete moves this week: first, measure the real input and output tokens of 100 representative requests and compute the effective rate per model. Second, apply caching to fixed prefixes and verify the hit rate. Third, add a gateway that routes easy work to small models and shrinks your flagship share. And above all, remember that every rate here was verified on August 24, 2026 and shifts with promotions and timing - verify the official pricing page before any quote.
