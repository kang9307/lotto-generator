起因 — 「公开预览」与「月底的权重」之间

Mistral 在 2026 年 10 月 6 日发布了题为「Introducing Mistral Large 4」的公告，GeekNews 在同一天做了介绍。公告的署名不是个人，而是「By Mistral」。第一段把三件事分开来写。今天推出的是 Mistral Large 4 的公开预览(public preview)，预览 API 今天起就可以在 Mistral Studio 上试用，权重则在本月底发布。模型的简称是 ML4，公告给它起的昵称是 le Chonk。

公告写道 ML4 把开放权重性能的前沿向前推进，文档的模型页也把这个模型介绍为 open-weight。不过在同一页面的 Weights 标签页里，权重一栏和许可证一栏都是「Coming soon」。截至 2026 年 10 月 6 日，能用的是 Mistral 运营的 API，还没有可以下载的权重文件。开放权重这个说法在这个时点是一项预告，公告自己把时间写成「by the end of the month」。

现在能读到的和需要等待的由此分开。规格、价格、提供形式和 Mistral 自己拿出的基准数值在公告和文档里；权重文件、许可证条件、架构细节、更多基准和训练后方法论，要随权重发布才给出。大型 MoE 模型以「权重即将公开」的状态发布时该怎么读，见Reflection Beam 501B 发布的分析，这里只看 ML4 公告和文档写明的值。

  • 发布日期与主体。 2026 年 10 月 6 日，署名「By Mistral」。
  • 目前提供的形式。 Mistral Studio 上的预览 API。文档的模型页带有 Public Preview、Open、v26.10 的标注。
  • 权重。 公告写本月底前发布，文档的 Weights 标签页是「Coming soon」。
  • 在那之前。 公告写道，正与网络安全领域的领先机构、经过审核的合作伙伴和国家机关一起在真实环境中做红队评估。

规格 — 公告的 1 万亿、490 亿与文档的 1.05T、52B

规格数字在不同文档里写法不同。公告正文把 ML4 写成「1 万亿参数的原生多模态模型，激活参数为 490 亿」(1 trillion-parameter natively multimodal model with 49 billion active parameters)。文档的模型页写的是「激活参数 52B、总参数 1.05T、视觉编码器 1.6B」，Weights 标签页的表格里也写着 Parameters (T) 1.05、Active (B) 52、Vision Encoder (B) 1.6。GeekNews 摘要里的「总计 1.05 万亿中激活 490 亿」，是把文档的总量和公告的激活数放进了同一句话。

关于结构，两份文档用的词都是 Mixture-of-Experts。文档写的是「granular Mixture-of-Experts architecture」，公告末尾的模型卡则概括为兼具指令执行与推理的混合型 MoE，接受多模态输入。更细的内容两份文档里都没有。公告两次写到，关于模型架构的进一步信息会随权重发布一并给出。

上下文长度没有出现在公告正文里，只在文档中有。模型页的 Context 一栏是 1M，Weights 标签页的 Context Size (tokens) 也是 1M。Mistral 文档的术语说明把这个值定义为模型在一次请求中能处理的最大令牌数，输入(提示词和文件)与输出合并计算。输入输出形式标为四项，即 Text input、Image input、Reasoning output、Text output。

  • 功能列表。 文档的 Features 标签页列出 Structured Outputs、Function Calling、Document QnA、Prefix、Chat Completions、Batching、Agents & Conversations、Built-In Tools。

价格与调用 — $1.36、$4.18 与文档的 Original、Sale 标注

公告末尾的模型卡用两行写了价格。输入每百万令牌 1.36 美元，输出每百万令牌 4.18 美元。货币符号是美元，单位写作「/M tokens」。公告没有另外说明这组数值是只适用于预览期的价格，还是正式价格。

文档一侧的数值有两层。模型页把 1.36 美元和 0.68 美元并排显示，价格页则在同一格里写着「Original price: $1.36」和「Sale price: $0.68」。缓存输入的 Original 是 0.14 美元、Sale 是 0.07 美元，输出的 Original 是 4.18 美元、Sale 是 2.09 美元。三项的 Sale 值都是 Original 值的一半(计算)。在价格页上，带有 Sale 标注的只有 Mistral Large 4 这一行。

同一个价格页上还有可以并排读的值。上一代的 Mistral Large 3 是输入 0.5 美元、输出 1.5 美元，由 Mistral 托管的第三方模型 Z.ai GLM 5.3 是输入 1.4 美元、输出 4.4 美元。ML4 的 Original 值略低于 GLM 5.3，高于 Large 3。价格页除了 Standard 之外还有 Batch 和 Priority 标签页，上面的值是 Standard 标签页显示的值。

调用方式写在文档的 Usage 标签页里。其中写道，向 Chat Completions API 发送请求时使用模型名 mistral-large-4，示例代码把 reasoning_effort 设为 high。模型页上显示的名称有 mistral-large-4 和 mistral-large-4-0 两个。

  • 公告的值。 Input (/M tokens) $1.36，Output (/M tokens) $4.18。
  • 文档的值。 输入从 $1.36 到 $0.68，缓存输入从 $0.14 到 $0.07，输出从 $4.18 到 $2.09。前者是 Original，后者是 Sale。
  • 模型名。 mistral-large-4、mistral-large-4-0。
  • 比较成本时。 Original 与 Sale 相差一倍，所以要写明用的是哪一个。核对开放权重模型成本主张中分母的顺序，见如何核验开放权重模型的性能与成本主张。

训练基础设施与提供区域 — 3,800 块 GPU 与 160 多种语言

公告写道，ML4 是在位于欧洲的 Mistral 自有数据中心里，用 3,800 块 NVIDIA Grace Blackwell GPU 从头(from scratch)训练的。公开预览也由同一套基础设施提供。公告把这称为在基础设施、研究和产品开发上长期投入的一个里程碑。

关于训练数据有一句话。训练数据中相当大的一部分是多语言的，覆盖 160 多种语言，包括欧盟的每一种官方语言。各语言的占比和数据规模没有写。公告还写道，Mistral 与金融、工程、制造、物流、制药、科学、航运、公共部门的企业合作训练 ML4，使用的训练、定制和强化学习环境与通过 Mistral Forge 提供给客户的是同一套。

训练后阶段在强化学习部分给了数值。在目前的规模(3k GPUs)下，一次训练每天约产生 330 亿令牌，过滤和掩码之后用于训练的补全令牌约为其中的 160 亿。训练后阶段写成监督微调和强化学习两段。公告写道，这次预览背后的强化学习仍在进行，没有饱和的迹象，预期未来几周到几个月会有大而快的改进。预览时点的基准数值建立在这个前提之上。

关于提供区域，公告写的是模型将在全球多个区域提供。其中包括一个由 Mistral 端到端运营、不依赖其他数字服务提供商、并处于欧洲法律之下的欧洲部署。时态是将来时(will be available)。

  • 训练设备。 3,800 块 NVIDIA Grace Blackwell GPU，位于欧洲的 Mistral 自有数据中心，从头训练。
  • 语言。 160 多种，包含全部欧盟官方语言。模型卡的写法是「160+ languages」。
  • 强化学习规模。 在 3k GPUs 上每天约 330 亿令牌，其中可用于训练的补全令牌约 160 亿。
  • 资金。 公告把 ML4 写成由 30 亿欧元 D 轮融资支撑的路线图上的第一个里程碑。

编码方面的三个数值分别对应软件工程、代码仓库理解和复杂的终端工作流。公告写道，把三者合在一起的 Coding Agent Index 为 49.8%，领先 DeepSeek V4 Pro 0813 和 Qwen3.8 Max。与 Surge AI 做的评估性质不同。专业评审在不知道模型名称的情况下，对输出的编码质量按 1 到 5 分打分，「ML4 Preview」在五个模型中排第二。第一名是得 4.22 分的 Claude Opus 5。

在智能体工作和知识工作方面，给出数值的是 AutomationBench 的 59.9% 和 AA-Briefcase 的 1,393 Elo。法律和金融只有文字描述。公告写道，Mistral 通过第三方评估者(vals.ai)对法律和金融的代表性任务做了评估，两种情况下模型都超过了 GPT-6-Astra，并写道在 HarveyAI 的 Legal Agent 基准上 ML4 超过所有开源模型。这两句话都没有附得分。

视觉方面以文字写出的数值是 Dense 200 上的 42% 对 41%。公告的说法是，ML4 是 Mistral 测试过的模型中最有能力的一档，例如在 Dense 200 上超过 GPT-6-Astra。两个值相差 1 个百分点(计算)。ChartQA Pro 和 GDP.pdf 只作为图表标题出现。科学方面，公告写的是在 SciCode-Verified 上处于开放权重模型中的最高水平，没有写得分。

公告开头那几句概括性的话，范围是分开的。与全球最强的开源模型相比，写的是性能「有竞争力」；与美国或欧洲开发的开放权重模型相比，写的是「显著领先」。对于网络安全、金融和法律，写的是 Mistral「认为(we find)」它处于开放模型中的最高水平。超过闭源模型的那句话，限定在「视觉定位等部分领域」。

网络安全部分 — 原文写的句子与归属

这是公告篇幅最长的领域。Mistral 写道，ML4 是全球在网络安全方面最强的 AI 模型之一。它拿出的依据是 Artificial Analysis Cyber Index。公告把这个指数介绍为一项独立评估，衡量 AI 模型在真实软件中发现并修复安全缺陷的能力，并写道 ML4 位列全球前五个模型，在中国以外开发的开放权重模型中以较大差距领先。

82% 不是整个指数的得分。它是指数中一项测试的得分，这项测试要求模型复现开源软件中的一个真实漏洞并随后打上补丁，公告写这个值高于任何模型。在 Cybench 上，公告写的是解出了取自安全竞赛的 40 道题目中的 93%，并把这表述为开放权重模型已报告得分中最高的一档。

关于闭源模型的那句话要连同归属一起读。公告写道，在同一项测试上，包括 Claude Opus 5.5 和 GPT-6 Astra 在内的若干领先闭源模型得分接近于零，原因是「它们拒绝执行该任务」。这句话不是对那些模型能力的评价，而是 Mistral 对该项测试中拒绝行为的描述。公告的论点在下一句。防护软件往往从证明缺陷真实存在开始，而闭源模型的安全过滤器可能挡住这类工作。另一处写到，提供方层面的拒绝可能阻碍正当的漏洞研究和事件响应，事件中途失去某项能力的访问本身就可能成为安全风险。

红队部分的措辞如下。公告写道，权重发布之前，公司正与网络安全领先机构、经过审核的合作伙伴和国家机关在真实环境中对模型做红队测试，这些参与方将访问「减少了 moderation、扩展了网络能力的同一个模型」(the same model with reduced moderation and expanded cyber capabilities)。这读起来是说它们访问的配置与一般的预览 API 不同，但哪里不同、如何不同，公告没有写。

安全性一节里有一个方向相反的数值。公告写道，尽管在网络安全基准上成绩很高，模型在 JailbreakBench、StrongREJECT、AgentHarm 的网络相关提示词上的平均拒绝率仍高于所有 OSS 模型。把两处放在一起，Mistral 提出的是这样一种区分，即防御性的工作会执行，恶意的请求会拒绝(解读)。这条界线在实际使用中划在哪里，要等权重和更多材料出来之后才能检验。

  • AA Cyber Index。 按公告的说法，位列全球前五个模型，在中国以外开发的开放权重模型中领先。
  • 82%。 指数中一项测试的得分，即复现真实漏洞后再打补丁的那项测试。
  • Cybench。 40 道题目中的 93%。
  • 内部测试。 公告写道，它在分析恶意软件、为漏洞排定优先级、编写检测规则方面被证明有用，并说明这些能力超出了明确训练的范围。
  • 自行部署。 公告用将来时写道，它将能够在私有云或本地环境中运行。

安全性指标与人工评估

公告的 Model Safety 一节写了三件事。第一是对间接提示注入的稳健性。Mistral 写道 ML4 已经使自家在这方面的基准达到饱和，并列出 GLM-5.2、GLM-5.3、Kimi-K2.6、Kimi-K3、DS-V4-Pro-0813 作为比较对象。在 Lakera 的公开 B3 AI Security Benchmark 上，公告写的是抵御了 93.3% 的攻击，并且在竞争对手中没有看到更高的得分。

第二是 KORA Benchmark。公告写道 ML4 得到 1.691，这是 Mistral 所测 OSS 模型中最高的得分。量表的最大值是 2，这一等级的名称是「Exemplary」。第三就是上一节看到的网络相关提示词的拒绝率。

人工评估分为各自独立的两种。一种是与 Surge AI 共同进行的编码质量盲评，另一种是 Mistral 的内部评估。在内部评估中，来自编码、CAD、金融、数学和物理领域的专业评审把 ML4 与 GLM-5.3 做了比较。公告写道，在 CAD 和 STEM 方面 ML4 更受青睐，在金融和编码方面则与 GLM-5.3 持平或接近。内部评估的比较对象只有 GLM-5.3 一个。

按评估主体分为三类。外部建立、由 Mistral 引用或运行的指标(AA Cyber Index、Lakera B3、KORA、HarveyAI Legal Agent)，与外部共同进行或经外部评估者完成的(Surge AI、vals.ai)，以及 Mistral 内部做的(专家对比评估、间接提示注入基准、STEM 评估)。无论哪一类，发布数值的都是 Mistral，公告之外的独立复现要等权重出来之后。

  • Lakera B3。 抵御 93.3% 的攻击。
  • KORA。 1.691，最高为 2。
  • 网络相关提示词的拒绝率。 写的是 JailbreakBench、StrongREJECT、AgentHarm 上的平均值高于所有 OSS 模型，没有以文字给出数值。
  • 内部人工评估。 相对 GLM-5.3，在 CAD 和 STEM 方面更受青睐，在金融和编码方面持平或接近。

未能确认的事项

  • 参数写法不同的原因。 公告的 1 万亿、490 亿与文档的 1.05T、52B 为什么不同，两份文档里都没有解释。
  • 许可证。 文档的 License 一栏是 Coming soon，公告里没有出现许可证的名称。商业使用的条件未能确认。
  • 架构细节。 专家的数量、路由方式、视觉编码器的结构不在依据材料中。公告写的是随权重发布一并给出。
  • Sale 价格的条件。 Sale 值的适用期限和条件，以及公告中的 $1.36、$4.18 是否仅限预览期，价格页和公告里都没有写。Batch、Priority 标签页上 ML4 的值也没有纳入依据材料。
  • 最大输出令牌数。 模型页上只有 1M 的上下文长度，没有找到输出上限的项目。
  • 图表中的具体数值。 CyberGym-E2E、ChartQA Pro、GDP.pdf、Finance Agent v2、Finch、Harvey Legal Agent 的图表数值没有以文字写出。Artificial Analysis、vals.ai、HarveyAI、Lakera 一侧的原始发布没有纳入依据材料。

  • 发布的日期与位置。 权重发布的确切日期和分发位置，除了「本月底」这一表述之外没有写明。
