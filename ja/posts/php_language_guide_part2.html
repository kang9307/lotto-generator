PHPの基本文法とデータ型

PHPの基本文法

PHPタグ

PHPコードは特別な開始タグと終了タグで囲まれており、PHPエンジンがコードを認識できるようになっています。

<?php
  // PHPコードを記述
?>

または短縮 echo タグ（PHP 7.0+ でデフォルト有効）:

<?= $変数 ?>  // これは <?php echo $変数; ?> と同じ

コメント

PHPでは1行コメントと複数行コメントの両方がサポートされています。

<?php
// 1行コメント

# 別の1行コメントのスタイル

/*
 複数行コメントは
 このように記述します
*/
?>

文の区切り

PHPでは各文をセミコロン（;）で終える必要があります。

<?php
echo "こんにちは";
$x = 5;
$y = 10;
$z = $x + $y;
?>

PHPとHTMLの混在

PHPはHTML内に簡単に埋め込むことができます。

<!DOCTYPE html>
<html>
<head>
    <title>PHPの例</title>
</head>
<body>
    <h1>こんにちは！</h1>
    <?php
        echo "<p>今日の日付: " . date("Y-m-d") . "</p>";
    ?>
    <p>これはHTMLの内容です。</p>
    <p>現在の時刻: <?= date("H:i:s") ?></p>
</body>
</html>

変数とデータ型

変数の宣言

PHPでは変数はドル記号（$）で始まり、型を明示的に宣言する必要はありません。

<?php
$name = "山田太郎";     // 文字列
$age = 25;             // 整数
$height = 175.5;       // 浮動小数点数
$isStudent = true;     // 真偽値
?>

変数の命名規則

  • 変数名はドル記号（$）で始まらなければなりません。
  • 変数名は文字またはアンダースコア（_）で始める必要があります。
  • 変数名には文字、数字、アンダースコアのみ使用できます。
  • 変数名は大文字と小文字を区別します（$name と $Name は別の変数）。
<?php
$name = "有効な変数名";
$_name = "有効な変数名";
$name1 = "有効な変数名";
$name_1 = "有効な変数名";

// $1name = "不正な変数名";  // 数字で始めることはできない
// $name-1 = "不正な変数名"; // ハイフンは使用不可
?>

変数のスコープ

PHPの変数は3種類のスコープを持ちます:

  1. ローカル変数: 関数内で宣言された変数で、関数内でのみアクセス可能です。
  2. グローバル変数: 関数外で宣言された変数で、関数内では global キーワードを使ってアクセスできます。
  3. 静的変数: 関数内で static キーワードにより宣言された変数で、関数の実行が終わっても値が保持されます。
<?php
$globalVar = 10;  // グローバル変数

function testScope() {
    $localVar = 5;  // ローカル変数
    global $globalVar;  // グローバル変数へアクセス

    echo "ローカル変数: $localVar<br>";
    echo "グローバル変数: $globalVar<br>";

    static $staticVar = 0;  // 静的変数
    $staticVar++;
    echo "静的変数: $staticVar<br>";
}

testScope();  // 出力: ローカル変数: 5, グローバル変数: 10, 静的変数: 1
testScope();  // 出力: ローカル変数: 5, グローバル変数: 10, 静的変数: 2

// echo $localVar;  // エラー: ローカル変数は関数外からアクセス不可
?>

スーパーグローバル変数

PHPにはグローバルにアクセス可能な組み込み変数が用意されています:

<?php
// スーパーグローバル変数の例
echo $_SERVER['HTTP_USER_AGENT'];  // ブラウザ情報
echo $_GET['name'];                // URLパラメータ
echo $_POST['email'];              // POSTデータ
echo $_REQUEST['id'];              // GET、POST、COOKIEデータ
echo $_SESSION['user_id'];         // セッションデータ
echo $_COOKIE['preference'];       // クッキーデータ
echo $_FILES['upload'];            // アップロードされたファイル情報
echo $_ENV['HOME'];                // 環境変数
?>

データ型

PHPは以下の基本データ型をサポートしています:

  1. 文字列（String）

    $name = "山田太郎";
$address = '東京都渋谷区';  // シングルクォートも使用可能

  2. 整数（Integer） 

    $age = 25;
$negativeNum = -10;
$hex = 0x1A;  // 16進数 (値: 26)
$oct = 057;   // 8進数 (値: 47)
$bin = 0b11;  // 2進数 (値: 3)

  3. 浮動小数点数（Float または Double）

    $height = 175.5;
$scientificNotation = 1.5e3;  // 1500

  4. 真偽値（Boolean）

    $isActive = true;
$hasPermission = false;

  5. 配列（Array）

    $colors = array("赤", "緑", "青");
$colors = ["赤", "緑", "青"];  // PHP 5.4+ の短縮構文

// 連想配列
$person = [
    "name" => "山田太郎",
    "age" => 25,
    "city" => "東京"
];

  6. オブジェクト（Object）

    class Person {
    public $name;
    public $age;

    function __construct($name, $age) {
        $this->name = $name;
        $this->age = $age;
    }

    function introduce() {
        return "こんにちは、私は{$this->name}、{$this->age}歳です。";
    }
}

$person = new Person("山田太郎", 25);
echo $person->introduce();

  7. NULL

    $var = NULL;  // 値がないことを表す

  8. リソース（Resource）

    $file = fopen("test.txt", "r");  // ファイルリソース

型の確認と変換

PHPでは変数の型を確認および変換するための様々な関数が提供されています。

<?php
$var = "42";

// 型の確認
var_dump($var);                // string(2) "42"
echo gettype($var);            // string
echo is_string($var);          // 1 (true)
echo is_int($var);             // (空の出力, false)

// 型の変換
$varInt = (int)$var;           // 整数に変換
$varFloat = (float)$var;       // 浮動小数点数に変換
$varBool = (bool)$var;         // 真偽値に変換
$varString = (string)$varInt;  // 文字列に変換

// 型チェック関数
echo is_int($varInt);          // 1 (true)
echo is_float($varFloat);      // 1 (true)
echo is_bool($varBool);        // 1 (true)
echo is_string($varString);    // 1 (true)
?>

定数

定数は一度定義すると変更できない値です。定数は define() 関数または const キーワードを用いて定義します。

<?php
// define() 関数の使用
define("PI", 3.14159);
define("SITE_NAME", "PHPチュートリアル");

// const キーワードの使用 (PHP 5.3+)
const MAX_USERS = 100;
const DB_HOST = "localhost";

echo PI;           // 3.14159
echo SITE_NAME;    // PHPチュートリアル
echo MAX_USERS;    // 100

// PI = 3.15;      // エラー: 定数は変更できない
?>

マジック定数

PHPには特別な組み込み定数（マジック定数）が用意されています:

<?php
echo __LINE__;     // 現在の行番号
echo __FILE__;     // 現在のファイルのフルパスとファイル名
echo __DIR__;      // 現在のファイルのディレクトリ
echo __FUNCTION__; // 現在の関数名
echo __CLASS__;    // 現在のクラス名
echo __METHOD__;   // 現在のクラスのメソッド名
echo __NAMESPACE__; // 現在の名前空間名
?>
