序論：利息負担を減らすチャンス、韓国の住宅担保ローン借り換え

韓国の多くの家庭において、住宅担保ローン（주택담보대출／주담대）は最大の負債です。金利がわずかに変わるだけで、数十年にわたって数百万ウォンから数千万ウォンもの利息の差が生じます。2023年5月に信用ローンから始まったオンラインワンストップ大換（借り換え）インフラが2024年1月に住宅担保ローンへ広がったことで、スマートフォンアプリ一つで複数の金融機関の金利を比較し、より低い金利へ乗り換えることが格段に容易になりました。

しかし、手続きが簡便になったからといって、借り換えが常に有利なわけではありません。繰上返済手数料・DSR規制・登記費用・ローン期間の再設定など、慎重に検討すべき要素は少なくありません。本記事では、公信力ある機関の情報をもとに韓国の住宅担保ローン大換制度を整理し、借り換えが本当に有利な状況とそうでない状況を見極めることに焦点を当てます。

なお、本記事は2026年6月に初めて作成し、規制・繰上返済手数料・大換インフラに関する事実は2026年9月29日に金融委員会・韓国銀行の原文で再確認しました（いずれも韓国基準）。韓国銀行の基準金利は2026年8月27日に年3.00%となりました。金融環境は随時変動します。実際の意思決定の前に、必ず金融機関または金融監督院の金融商品統合比較公示（finlife.fss.or.kr）で最新情報をご確認ください。

1. 大換貸出（借り換え）とは何か

大換貸出（대환대출）とは、現在利用中のローンを別の金融機関のローンに切り替えることを指します。住宅担保ローンの場合、既存のローンを解約し、より有利な条件（低金利・固定金利への切り替え・返済方法の変更など）の新規ローンを実行して既存の債務を返済する方式です。

1.1 借り換えが必要な理由

  • 金利差の解消：高金利期に実行したローンが現在の市場金利より高い場合、より低い金利商品へ移行して利息負担を軽減できます。
  • 変動金利→固定金利への転換：金利上昇リスクが懸念される際、変動金利から固定金利に切り替えて月々の返済額を予測可能にします。
  • 返済方式の変更：満期一括返済から元利均等・元金均等方式に変更して元本返済を早めることができます。
  • ローン限度の再調整：物件価格の上昇で担保価値が高まった場合、追加の余裕資金を確保できる場合があります。ただし、オンライン大換インフラでは増額の借り換えはできず、新しいローンの限度は既存ローンの残高以内に制限されます（金融委員会、2024年1月9日）。

1.2 オンラインワンストップ大換インフラ

2023年に信用ローンから始まった韓国のオンライン大換インフラは、2024年1月から住宅担保ローンと賃貸ローンに拡大されました。金融委員会が制度をリードし、金融決済院がシステムを運営、フィンテックプラットフォーム（トス・カカオペイ・フィンダなど）と多数の銀行が参加しています。

このインフラの核心はマイデータ（マイデータ）連携です。既存のローン情報を自動取得し、複数の金融機関の金利を一画面で比較でき、選択した金融機関での審査・約定・実行まで一括処理できます。以前は各銀行窓口を訪問したり個別アプリで別々に申請したりする必要があった手続きを大幅に簡素化しました。

3. 借り換え条件とDSR規制

3.1 基本資格条件

  • 現在の住宅担保ローンが実行中であること
  • 新規金融機関のLTV（担保認定比率）要件を充足：規制地域の住宅担保ローンは2025年10月16日から40%、その他の地域は地域・物件種別により異なる
  • DSR（총부채원리금상환비율）40%以下（第1金融圏の水準として知られる値、2026年6月作成時点）
  • 金融機関別の信用スコア基準を充足
  • 最低借入金額：金融機関により概ね2,000万〜3,000万ウォン以上

3.2 DSRとは何か

DSR（Debt Service Ratio、총부채원리금상환비율）は、年収に占める全ローンの年間元利金返済額の割合です。韓国の第1金融圏（銀行）では通常40%以下が要件で、これを超えると新規ローン（借り換えを含む）が制限されます。第2金融圏は50%まで許容される場合があります。借り換えは新規ローンの実行とみなされるため、申請時に現在の収入・負債状況でDSRが再算定されます。

3.3 ストレスDSR第3段階とその後の強化

ストレスDSRは、実際の金利に仮想の「ストレス金利」を上乗せしてDSRを計算する方式です。現在の金利ではDSR要件を満たしても、ストレス金利を加えると満たせない場合があります。韓国の第3段階は2025年5月20日に確定・発表され、2025年7月1日に施行されました。基本ストレス金利は1.50%です。

  • 首都圏・規制地域の住宅担保ローン：2025年10月15日の対策により、ストレス金利の下限が1.5%から3.0%に引き上げられました（2025年10月16日施行）
  • 地方（ソウル・京畿・仁川を除く）の住宅担保ローン：第2段階のストレス金利0.75%が2025年12月末まで適用され、金融委員会は2026年上半期（1月1日〜6月30日）も第2段階を適用する計画だと発表しました（2025年12月10日）。

借り換え申請時には現時点の収入・負債状況でDSRが再算定されます。元のローン実行後に収入が減少したり他の借入が増加したりした場合、元のローン審査時は余裕があったとしても借り換え審査で落ちる可能性があります。申請前に自身のDSRを事前に計算しておくことが重要です。

3.4 借り換えにも規制は適用されるか（2026年9月29日確認・韓国基準）

金融委員会は、借り換えローンは新しい金融会社が取り扱う新規ローンであるため、借り換え時点でLTVを再算定するのは各業権の監督規定に基づく当然の措置だと説明しています（2025年10月27日）。つまり借り換えは既存ローンの延長ではなく、新たな審査を受けるものと考えるのが基本です。規制ごとに原文で確認した内容は次のとおりです。

規制借り換えについて原文が述べていること根拠

原文が借り換えを個別に扱っていない規制は、適用の有無を断定できません。申請前に借り換え先の金融機関に、①どの時点のLTVを適用するか、②ストレス金利をいくら上乗せするか、③住宅担保ローンの上限額が適用されるかを確認しましょう。

4. 繰上返済手数料 — 中核コストの計算

4.1 繰上返済手数料とは

繰上返済手数料（중도상환수수료）は、満期前にローン原本を全額または一部返済する際に金融機関に支払う手数料です。借り換え時には既存ローンを全額早期返済する必要があるため、繰上返済手数料が発生します。これが借り換えにかかる最大のコストになることが多いです。

4.2 2025年以降の手数料引下げ

金融委員会によると、2025年1月13日以降に新規締結するローンから、繰上返済手数料は資金運用の支障による機会費用、ローン関連の事務・募集費用などの実費の範囲内でのみ課されます。5大市中銀行の住宅担保ローン平均手数料率は次のとおり下がりました（2025年1月9日発表）：

  • 固定金利ローン：平均0.65%（旧1.4%から引下げ）
  • 変動金利ローン：平均0.65%（旧1.2%から引下げ）

2025年1月13日より前に締結した既存ローンには、改定後の料率ではなくその契約の約定が適用されます。金融機関別の手数料率は各金融協会のホームページで公示され、金融委員会は相互金融圏でも2026年1月1日から実費のみを反映する繰上返済手数料の改編を施行すると発表しました（2025年12月30日）。ローン契約書で正確な数値を必ず確認してください。

4.3 計算式

繰上返済手数料 = 繰上返済額 × 手数料率 × （残存期間 ÷ ローン期間）

例：借入元本3億ウォン、手数料率0.65%、30年満期ローンを1年後に全額返済する場合：3億 × 0.0065 × (29/30) ≒ 約188万ウォンの手数料が発生します。この金額と借り換えによる利息節約額を比較して、実際のメリットを確認してください。

4.4 免除条件

  • 3年規定：金融委員会の説明によると、韓国の金融消費者保護法上、繰上返済手数料は消費者が貸出日から3年以内に返済する場合に課すことができます。「多くの金融機関が免除する慣行」ではなく、手数料を課せる期間そのものが法律で貸出日から3年と定められています。
  • 年間10%枠：毎年当初借入元本の10%以内の元本返済は手数料なしで可能な場合が多いです（金融機関・約定により異なります）。
  • 特別イベント：一部の金融機関が期間限定で繰上返済手数料を免除するキャンペーンを実施することがあります（条件は変動するため約定書で確認）。

5. 借り換え手続き：ステップバイステップガイド

5.1 申請前の準備（借り換え前に必ず確認）

  1. 現在のローン条件の把握：現在の金利（固定/変動）・残存元本・満期・繰上返済手数料率を確認
  2. DSRの事前計算：年収に対する全借入の年間元利金合計でDSRを計算
  3. 利息節約額の見積もり：金利差×残存年数×残存元本で概算節約額を計算
  4. コスト項目の把握：繰上返済手数料＋登記費用（根抵当権設定・抹消）＋印紙税等の付随費用

5.2 オンライン申請手順

  1. プラットフォームアプリを起動：トス・カカオペイ・フィンダ・カカオバンク等で「ローン乗り換え」（대출 갈아타기）を選択
  2. マイデータ連携：既存ローン情報を自動取得（金融機関への同意が必要）
  3. 金利比較：参加金融機関の予想金利・限度・条件を比較（この段階では信用スコアに影響なし）
  4. 商品選択・審査申請：希望の金融機関を選択→オンライン審査申請→必要書類提出（在職証明書・所得証明等）
  5. 電子署名：審査通過後、新規ローンの電子約定を締結
  6. 新規ローン実行・既存ローン自動返済：新規ローンが実行されると既存ローンが自動的に返済される
  7. 登記移転：根抵当権の抹消・新設登記（数日〜数週間かかる場合あり、費用発生）

6. 借り換えが有利な場合 vs. 慎重になるべき場合

6.1 借り換えが有利な状況

  • 新金利が現行より0.5%p以上低く、利息節約がコストを明確に上回る場合
  • 貸出日から3年が過ぎて繰上返済手数料の対象外である場合、または残る手数料が非常に低い場合
  • ローンの残存期間が10年以上あり節約効果が十分に累積できる場合
  • 変動金利から長期固定金利に切り替えて金利リスクをヘッジしたい場合
  • DSRに余裕があり信用スコアが良好な場合

6.2 慎重になるべき状況

  • 残存期間が短く（3〜5年以内）利息節約額がコストを下回る場合
  • 繰上返済手数料が多額で金利差が小さく、損益分岐点が遠い場合
  • 収入減少でDSRが高まり審査落ちの可能性がある場合
  • 根抵当権設定費用・印紙税等の付随費用が想定より大きい場合
  • 更なる金利低下が期待できる状況で変動金利の維持が有利な場合

7. 主な落とし穴と注意点

7.1 総コスト計算の落とし穴

借り換えのメリットを計算する際、金利差だけを見てコストを過小評価しがちです。実際に考慮すべきコスト項目：

  • 繰上返済手数料：残存期間に比例して計算
  • 根抵当権設定・抹消登記費用：司法書士費用＋登録免許税・地方教育税等（数十万ウォン規模）
  • 印紙税：借入金額に応じて数万〜数十万ウォン
  • 鑑定評価手数料：一部の金融機関では別途要求される場合あり

7.2 DSR再算定リスク

借り換え申請時には現在の収入・負債基準でDSRが再算定されます。ローン実行後に収入が減少したり、信用カード限度・当座貸越・自動車ローン等の他の負債が増加したりした場合、DSRが上昇して審査落ちになる可能性があります。特に自営業者・フリーランスの方は所得証明が変動する可能性があるため注意が必要です。

7.3 ローン期間の再設定

新規ローンへの乗り換えではローン期間が再設定されます。既存ローンの残存期間がそのまま引き継がれるのではなく、新規に最長30年の設定が可能な場合もあります。期間を延長すると月々の返済額は減りますが、総利息は増える可能性があるため注意が必要です。

8. 公信力ある金利比較ソース

  • 金融監督院 金融商品統合比較公示： finlife.fss.or.kr — 金融機関別の住宅担保ローン金利比較
  • 金融委員会 大換インフラ報道資料（2024）： fsc.go.kr — 制度の公式説明
  • 銀行連合会 消費者ポータル：銀行金利・手数料比較情報

結論：借り換えは計算が先決

住宅担保ローンの借り換えは利息節約の機会ですが、無条件に有利なわけではありません。繰上返済手数料・DSR再算定・登記費用・ローン期間の再設定を総合的に計算して初めて、実際のメリットを確認できます。

最も重要なのは総コスト計算です。利息節約額（年間節約額×残存年数）が乗り換えコスト（繰上返済手数料＋付随費用）を上回るか、損益分岐点はいつかを先に確認しましょう。繰上返済手数料は貸出日から3年以内に返済する場合に課されるため、3年の前後で手数料と節約利息を並べて計算してみましょう。オンライン大換インフラは既存の住宅担保ローンを受けてから6か月が経過しないと利用できない点も確認してください。

オンラインワンストップ大換インフラにより、金利比較と申請手続きが大幅に簡素化されました。複数のプラットフォームを比較した上で、最終的には金融監督院の金融商品統合比較公示で交差確認することをお勧めします。住宅ローンは数十年にわたる意思決定です。十分な情報と必要に応じた専門家への相談をもとに、慎重に判断することをお勧めします。

## 2. 申請資格のチェック

- [ ] 既存の住宅担保ローンを受けてから6か月が過ぎたか（オンラインインフラの利用条件）
- [ ] 増額せず既存ローン残高の範囲内で借り換えるか（オンラインインフラは増額不可）
- [ ] 担保住宅は相場照会ができる住宅か
- [ ] 担保住宅が規制地域かどうか確認したか（規制地域ならLTV 40%、増額しない借り換えの特例対象かは別途確認）
- [ ] 現在の収入・負債でDSRを再計算したか（ストレス金利を加えた金利で計算される）

---

## 3. 借り換え先の金融機関に聞くこと

- [ ] どの時点のLTVを適用するか（現時点か、既存ローンの取扱時点か）
- [ ] DSRにストレス金利をいくら上乗せするか
- [ ] 首都圏・規制地域の住宅担保ローン上限（6億・4億・2億ウォン）はこの借り換えにも適用されるか
- [ ] 金利方式（固定・変動）とローン期間はどう新たに決まるか

---

## 4. 損益計算

| 段階 | 計算 |
|---|---|
| 繰上返済手数料 | 繰上返済額 × 手数料率 × （残存期間 ÷ ローン期間） |
| 例 | 3億ウォン × 0.65% × (29/30) ≒ 188万ウォン |
| 付随費用 | 根抵当権設定・抹消登記費用 + 印紙税 + （求められる場合）鑑定評価手数料 |
| 節約利息 | 金利差 × 残存元本 × 残存期間（概算） |
| 判断 | 節約利息 > 繰上返済手数料 + 付随費用か、損益分岐点はいつか |

- [ ] 貸出日から3年が過ぎたか（過ぎていれば繰上返済手数料の対象外）
- [ ] 2025-01-13より前の契約なら、その契約の約定料率を確認したか
- [ ] 新しいローン期間を延ばして月々の返済額だけを見て、総利息を見落としていないか

---

## 5. 判断表

| 自分の状況 | まず見るもの |
|---|---|
| 新金利が0.5%p以上低く、残存期間が10年以上 | 手数料・付随費用を含めた損益分岐点 |
| 貸出日から3年がもうすぐ | 3年の前後で手数料の差を比較 |
| 残存期間が3〜5年以内 | 節約利息がコストより小さい可能性 |
| 収入が減った、または他の借入が増えた | DSR再算定の結果 |
| 追加資金が必要 | オンラインインフラは増額不可 - 別途相談 |
