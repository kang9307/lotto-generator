葛・葛根・クズ — 同じ根を指す複数の名前

葛（クズ）は東アジアの山野に広く育つマメ科のつる植物です。薬として使うのは根で、その生薬名が葛根（カッコン）です。学名は長く Pueraria lobata とされ、近年の分類では Pueraria montana var. lobata として扱われることが増えています。論文で二つの名前が混在するのはこのためです。

名前が複数あること自体は問題ではありません。問題は名前の似た別の植物が同じ売り場に並ぶことです。次の表を先に見ておくと、この記事の後半がずっと速く読めます。

粉葛（フンカツ）Pueraria thomsonii中国南部。澱粉が多く食用の比重が大きい部分的に。成分含量が異なる

いちばん下の行がこの記事で最も重い安全項目です。属が同じなので名前が並んで語られますが、エストロゲン作用の強さがまったく違います。詳しくは7番の節で扱います。

  • 根は秋から翌春の早い時期に掘ります。つるが葉を落とし、貯蔵物質が根に集まる時期です
  • 夏の根は繊維が硬く澱粉が少ないため、煎じても取れる量が少なくなります
  • 花（葛花）は根とは別の生薬として扱われます。この記事は根だけを扱います
  • 茎の繊維は葛布や縄の材料でした。食べる部位ではありません

指標成分という言葉 — プエラリン含量は生薬の品質を判定する基準として使われます。中国薬典は葛根と粉葛に異なる最低含量を求めています。含量規格は同じ生薬かどうかを見分ける物差しであって、効き目の大きさを測る目盛りではありません。

整理するとこうなります。

  • ヒト試験がついている項目は2つ — 飲酒量の減少と更年期症状。どちらも標本が小さく設計に限界がある
  • 処方単位でのみ承認されている項目は2つ — 感冒の初期と肩こり。葛根湯という複合処方の承認であって、葛根単独の根拠ではない
  • 伝統的な用法として残る項目は5つ — 血糖、心血管、頭痛、止瀉、抗酸化・肌
  • 向きを訂正すべき項目は1つ — 肝臓の保護。根拠がないだけでなく、監視される側に名前が挙がっている

この表の読み方

「伝統の記録にある」と「ヒト試験がある」は互いの代わりになりません。両者の関係を取り違えると表が無意味になります。

この読み方は誤りこう読む
古典にあるのだから効く古典は長く使われてきたという事実を教えてくれる。効果の大きさと安全性は別に測る必要がある
ヒト試験がないのだから嘘だ研究がないのはまだ測っていないということ。効果がないと証明されたのとは違う
動物実験で効いたのだからヒトでも効く動物実験の用量はヒトの摂取量と桁が違うことが多い。そのままは移らない
論文が多いから根拠が厚い論文の数よりどの層の研究かが重要。細胞実験100本はヒト試験1本の代わりにならない
エキスの試験結果は葛汁にも当てはまる標準化エキスは成分含量を揃えた製剤である。家で煎じた汁は含量が分からない

最後の行がこの記事で最も誤解されやすい点です。飲酒量が減ったという試験は成分含量を揃えた標準化エキスを決められた量で服用させています。家で煎じた葛汁は根の産地・樹齢・煎じ時間で成分が大きく揺れます。同じ結果を期待する根拠はありません。

安全性が先 — 効能と禁忌は同じ原因から出ている

葛の安全性の項目を記事の最後に置くのは順番が逆です。葛に期待される効果のうち最もデータが厚いのが更年期症状の緩和ですが、その効果の原因と禁忌の原因が同じだからです。

葛のイソフラボンは植物性エストロゲンです。ヒトのエストロゲン受容体に結合し、弱いエストロゲン信号を出します。この性質のために更年期症状に使われ、同じ性質のためにホルモン依存性の疾患では避けるべきものになります。一方が正しく他方が誤りなのではなく、一つの作用が状況によって別の意味に読まれるということです。

状況判断理由
乳がん・子宮体がん・卵巣がんなどホルモン依存性疾患の既往避ける。主治医に先に相談するエストロゲン様作用が疾患や治療の方向とぶつかる可能性がある
妊娠中避ける妊娠中の安全性データがない。データがないことは安全の確認ではない
授乳中避ける母乳への移行や影響についての資料がない
小児すすめない小児の用量基準がない。成人量を体重で割る方法は根拠ではない
手術の予定がある2週間前から中止し、医療者に伝える止血や麻酔の管理に影響する可能性が指摘されている
肝疾患の既往、または肝機能値の異常避けるか医療者に相談する8番の節を参照
大豆アレルギー注意。少量から確認する葛はマメ科の植物である
低血圧・降圧薬の服用注意血圧がさらに下がる可能性が指摘されている
ホルモン治療中主治医に相談する治療と重なる、あるいは打ち消し合う可能性がある

薬物相互作用 — 始める前に確認する

葛を食品として見ていると相互作用は思い浮かびません。しかしエストロゲン様作用や血液・代謝への影響が指摘されている以上、次の薬を服用中なら始める前に確認したほうが確実です。

薬のグループ懸念される点どうするか
タモキシフェンなどの抗エストロゲン薬植物性エストロゲンが薬の作用の向きとぶつかる可能性主治医の確認が取れるまで始めない
ホルモン補充療法・経口避妊薬ホルモン信号が重なる服用していることを伝えて判断を仰ぐ
ワルファリンなどの抗凝固薬止血の指標に影響する可能性自己判断で始めたり止めたりせず、数値を見ながら調整する
降圧薬血圧がさらに下がることがある開始後2週間は血圧を記録してみる
糖尿病薬・インスリン血糖の変動が重なることがある自己測定の記録を残し、異常があれば相談する
メトトレキサートなど肝負荷の大きい薬肝機能値の変化の原因が重なり、判別が難しくなる服用中は新しい生薬を増やさないほうがよい

薬剤師に伝えるとき — 「健康食品を飲んでいる」ではなく、「葛の根を煎じた汁を一日何ミリリットル飲んでいる」のように形と量を伝えないと判断ができません。製品なら箱をそのまま持っていくのが最も早いです。

葛とプエラリア・ミリフィカは別の植物である

この節がこの記事でもっとも実際的な安全項目です。葛に植物性エストロゲンが含まれるという話を聞いて、それならもっと強いものを、という経路が現実に存在するからです。

プエラリア・ミリフィカ（Pueraria mirifica、タイ名ガウクルア）は葛と同じプエラリア属ですが別の種です。タイ原産で、エストロゲン作用は葛よりはるかに強いものです。女性向けの健康食品として流通し、問題が繰り返されました。

原産・分布日本・韓国・中国などの東アジアタイ・ミャンマー
主な用途生薬（葛根）、葛粉や葛茶などの食品女性向け健康食品の原材料
エストロゲン作用弱いほう。大豆イソフラボンと同じ系統はるかに強い。ミロエストロールなど強力な成分を含む
公的に受け付けられた危害情報散発的国民生活センターに2012年度以降の5年間で209件
報告された症状主に消化器症状腹痛・嘔吐・下痢、発疹・蕁麻疹、月経不順・不正出血
製品検査の結果—調査対象12銘柄のうち10銘柄でエストロゲン活性を確認

国民生活センターは2017年7月13日の公表で、若い女性に危害が多発しているとして安易な摂取を控えるよう呼びかけました。厚生労働省は同年の薬事・食品衛生審議会でこの原材料を審議し、自治体および関係事業者団体に通知しています。食品安全委員会も女性ホルモン様作用が原因と考えられる健康被害情報が多数報告されているとしています。体調に異常を感じたら直ちに摂取をやめて受診するというのが三機関に共通する呼びかけです。

見分けるための実務的な手順

  • 学名を見る。表示に Pueraria mirifica とあれば葛ではありません
  • 原産国を見る。タイ産ならまずミリフィカを疑います
  • うたい文句を見る。バストやボディラインの変化を前面に出す製品は、葛の製品の文法ではありません
  • 剤形を見る。葛は葛湯・葛茶・葛粉のような食品の形が多く、ミリフィカは錠剤やカプセルで流通する比率が高いです
  • ガウクルア・ホワイトガウクルアといった名前が見えたらミリフィカです

肝障害の監視 — 肝臓に良いという話の実際の位置

葛の話でもっとも多く流れる文が「肝臓に良い」です。この文の出発点は東医宝鑑の酒毒を解くという記録で、そこから酒 → 肝臓 → 肝保護へと飛んでいます。その中間を埋めるヒトでの根拠は確認されていません。

米国国立衛生研究所が運営する薬物性肝障害のデータベース LiverTox には Chinese and other Asian Herbal Medicines という章があります。アジアの生薬による肝障害を扱う文書です。そこに引用された系統的レビューの要約では、生薬由来の肝障害194件のうち2件が Pueraria lobata に帰属すると整理されています。

この数字を誇張する必要はありません。194件中2件なら、この文書で大きく扱われている生薬ではありません。ただし向きははっきりしています。葛はこの文書のなかで肝臓を守る側ではなく、監視される側の一覧にあります。葛が肝臓に良いという記述の根拠としてこの文書を引くのは、文書の内容と反対のことをしています。

よくある記述実際に確認できること
葛が肝臓を保護するヒトでの根拠が確認されていない
葛がアルコール性肝障害を防ぐ動物実験の水準。ヒトに移った結果がない
天然物だから肝臓に負担がない生薬による肝障害は独立した研究分野である。天然かどうかは安全の根拠にならない
葛を飲めば酒を飲んでも大丈夫どの資料にも支持されていない。9番の節を参照

葛酒は酒である

葛酒の漬け方は下にそのまま載せます。ただし順番としてこの一文が先です。葛酒は酒です。25〜35度の焼酎に根を漬けたものであり、漬ける過程でアルコールは消えません。

  • 葛が入っているからといってアルコールの危険が相殺されるわけではありません。肝臓・血圧・睡眠・依存のリスクはそのまま残ります
  • 健康酒という呼び名は成分の説明ではなく慣習的な呼称です
  • 世界保健機関をはじめとする保健当局は健康上安全とされる飲酒量の線を示していません
  • 漬けた酒は度数が分かりにくいものです。砂糖や材料が入ると体感の度数は実際より低くなります
  • 肝疾患がある、あるいは肝臓に負荷のかかる薬を飲んでいるなら、葛酒は選択肢から外したほうがよいです
  • 運転の予定があるとき、妊娠中・授乳中は飲みません

葛の成分を得ることが目的なら、酒より茶や汁のほうが理にかなっています。葛酒は味と漬ける楽しみが目的のときに選ぶものに近いです。

日本での葛 — 葛根湯と食品としての葛

日本で葛根といえば、多くの人がまず葛根湯を思い浮かべます。それは制度の結果です。葛根湯は漢方処方として医薬品の枠内にあり、葛粉や葛湯は食品の枠内にあります。同じ根なのに通る道が違い、書ける文言も違います。

区分表示で確認すること効能をうたえるか
医療用漢方製剤（葛根湯エキス）医師の処方に基づく。添付文書に効能・効果と用法・用量が定められている承認された効能・効果の範囲で可能
一般用医薬品の葛根湯リスク区分の表示、添付文書の使用上の注意承認基準に定められた効能・効果の範囲で可能
食品としての葛（葛粉・本葛・葛湯）原材料名、製造者、賞味期限、栄養成分できない
健康食品・サプリメントとしての葛根原材料名と含有量、届出の有無医薬品的な効能をうたうことはできない

実務的に重要なのは二つです。

  • 葛根湯の承認は「七つの生薬を定められた比率で組み合わせた処方」に対するもので、葛根単独の根拠ではありません。厚生労働省の一般用漢方製剤承認基準に葛根湯は第23処方として収載され、構成生薬は葛根・麻黄・大棗・桂皮・芍薬・甘草・生姜です。承認された効能・効果は、体力中等度以上のものの感冒の初期（汗をかいていないもの）、鼻かぜ、鼻炎、頭痛、肩こり、筋肉痛、手や肩の痛みです。医療用の製剤ではここに熱性疾患の初期、炎症性疾患、上半身の神経痛、蕁麻疹が加わります
  • 葛湯を飲むことと葛根湯を服用することは別の行為です。葛根湯にはエフェドリンを含む麻黄と甘草が入っているため、心臓病・高血圧・甲状腺機能亢進症では注意が必要で、甘草による偽アルドステロン症も知られた有害事象です。用量と使用上の注意は製品ごとの添付文書に従ってください

日本で流通する食品としての葛

  • 葛粉・本葛 — 葛根から取った澱粉。原材料名が葛のみのものが本葛で、甘藷澱粉などを混ぜた製品も流通しています
  • 吉野葛 — 奈良の吉野地方に由来する製法・産地の呼称。品質の目安として使われますが、規格そのものではありません
  • 葛湯 — 葛粉を湯で溶いたもの。体を温める飲み物として親しまれていますが、これは食品であり薬ではありません
  • 葛切り・葛餅 — 和菓子の材料としての葛。ここでの葛は食感を作る澱粉です
  • 韓国の葛ジュース — 根を長時間煎じて濃縮した液体で、パウチ入りで売られます。原料の植物は日本の葛と同じですが、澱粉を取り出した葛粉とは中身が違います。葛粉は澱粉が主体、煎じた汁はイソフラボンなど水に出る成分を含みます

葛汁の作り方 — 材料から保存まで

家で煎じるやり方は昔から変わっていません。以下は伝統的な方法であり、成分含量の定まった製剤とは別のものだという点は前に書いたとおりです。

材料分量用途
葛の根1kg主材料
水2〜3L抽出用
なつめ10個（お好みで）甘みと香り
しょうが30g（お好みで）風味
はちみつまたは砂糖適量（お好みで）甘みの調整

1段階：下ごしらえと洗浄

  • 流水で洗い、土や異物を落とします
  • 皮はむかなくてもかまいませんが、傷んだ部分や厚すぎる部分は切り落とします
  • 0.5〜1cmの厚さに薄く切ります。厚いと出が大きく落ちます
  • 乾燥葛を使う場合はそのまま使います

2段階：煎じる

  • 大きな鍋に切った葛を入れ、かぶるくらいの水を注ぎます（葛1kgに水2〜3L）
  • 強火で沸かし、沸いたら中火に落とします
  • 2〜3時間煎じます。水が減ったら少しずつ足します
  • なつめやしょうがを入れるならこの段階で一緒に入れます
  • アルミ鍋よりステンレス・ガラス・土鍋のほうが向いています

3段階：漉して煮詰める

  • さらしや細かい濾し器で固形分を取り除きます
  • 漉した液を弱火に戻し、1〜2時間煮詰めます
  • 濃くなりすぎたら水を少し足します
  • 浮いてくるアクは取り除きます

4段階：冷ましと保存

  • 完全に冷ましてから消毒したガラス瓶に移します
  • 冷蔵し、2週間以内に飲みきります
  • それ以上置くなら小分けにして冷凍します。解凍したものは再冷凍しません
  • 酸っぱくなったり表面に膜が張ったら捨てます

保存で失敗する箇所 — 糖を加えた汁は常温で早く傷みます。熱いうちに瓶に詰めて蓋をすると結露が出て、かえって危険です。冷ましてから詰めてください。

葛汁の飲み方とその限界

伝統的に使われてきた量は以下のとおりです。ただしこの数値は臨床試験で検証された用量ではなく慣習です。標準化エキスを使った試験の用量を、家で煎じた汁に換算する方法はありません。

  • 日常的に — 1日2〜3回、1回30〜50mlを水で薄めて飲みます
  • 初めて飲むとき — 半分以下から始めて消化器の反応を見ます
  • 飲むタイミング — 空腹時に濃いまま飲むと胃にこたえることがあります。食後が無難です
  • 期間 — 数か月続ける予定なら途中に休む区間を置き、定期健診の肝機能値を確認してください

期待値を整理するとこうなります。

期待現実的な答え
飲めば二日酔いが消えるヒトでの根拠が確認されていない。飲酒量そのものを減らすほうが確実である
血糖の薬を減らせるいいえ。薬の調整は医療者の領域である
更年期症状がなくなる症状スコアが改善した試験はあるがプラセボ対照がない。なくなるとは言えない
たくさん飲むほど良いいいえ。過量は下痢や腹痛につながる
薬の代わりに使えるいいえ。診断のついた疾患は治療の領域である

葛酒の漬け方

9番の節の前提を保ったうえで、伝統的な漬け方をそのまま載せます。

材料分量備考
葛の根500g生または乾燥品
焼酎（25〜35度）1.8L漬け込み用
砂糖またははちみつ200〜300g（お好みで）甘みの調整
なつめ10〜15個（お好みで）香り

1段階：材料の準備

  • 生の葛は洗って水気を完全に取ります。水気が残ると傷みやすくなります
  • 日陰で2〜3日乾かします
  • 3〜5cmの大きさに切ります
  • 乾燥葛はそのまま使います

2段階：漬け込み

  • ガラス瓶を熱湯かアルコールで消毒し、完全に乾かします
  • 葛を入れ、材料が完全に浸かるまで酒を注ぎます
  • なつめを入れるなら洗って水気を取ってから加えます
  • 砂糖やはちみつを入れて混ぜ、溶かします
  • 蓋を閉め、涼しく日の当たらない場所に置きます

3段階：熟成

  • 最低3か月置きます
  • 週に一度、瓶を軽く振ります
  • 6か月から1年がよくすすめられる区間です
  • 2〜3年置くと香りがさらに深くなるといわれます
  • 材料が酒の上に浮いてきたら押さえて沈めます。露出した部分にカビが出ます

4段階：漉して保存

  • さらしで漉して固形分を取り除きます
  • 清潔な瓶に移し、涼しく暗い場所に置きます
  • 濁ったり異臭がしたら飲みません

葛茶の煮出し方

いちばん負担の少ない形です。量の調整がしやすく、濃度を低く保ちやすいという利点があります。

材料

  • 乾燥葛根 30〜50g（または生の葛 100g）
  • 水 2L
  • なつめ 5個（お好みで）
  • しょうが 20g（お好みで）

作り方

  1. 葛をさっと洗います
  2. 鍋に葛と水を入れて火にかけます
  3. 沸いたら弱火にして30分から1時間煮出します
  4. 水が半分ほどに減ったら火を止めます
  5. 漉して飲みます

飲み方

  • 温かいまま1日2〜3回
  • 夏は冷やしてもかまいませんが、2〜3日で飲みきります
  • 甘みを足すならはちみつを。ただし糖の摂取量には数えてください
  • 濃く出した茶を空腹時に飲むと胃にこたえることがあります

良い葛の選び方

形態確認すること避けること
生の葛根切り口が白く澱粉が見えるもの、硬いもの柔らかくなった部分、カビ臭、細すぎるもの
乾燥スライス密封包装、製造日と賞味期限の表示不自然に白いもの（漂白の疑い）、変色、異物
葛ジュースのパウチ葛の含有量表示、原産地、添加物の一覧含有量の未表示、効能を前面に出した表示
錠剤・粉末原材料名が葛単独か混合か構成のはっきりしない混合物
葛粉他の澱粉が混ざっていないか甘藷澱粉や馬鈴薯澱粉が主成分の製品
  • 産地の表示は品質の絶対的な基準ではありません。地名がついているだけで成分が保証されるわけではありません
  • 無添加の表示は何を入れていないのか裏面で確認してください。表面の文言だけでは分かりません
  • 極端に安いジュースは葛の含有量が低く、水と糖が主成分のことがあります
  • 輸入品だから問題というわけではありません。表示が明確かどうかが基準です

合わせる材料 — 相乗効果という言葉の限界

葛に何かを混ぜて飲む組み合わせは古くからの慣習です。ただし相乗効果という言葉はたいてい味と飲みやすさを指しています。二つの材料を混ぜると効果が掛け算になるというヒトでの根拠は確認されていません。

材料実際に得られるものよくある組み合わせ
なつめ甘みと香り。葛特有の渋みを抑える葛茶に一緒に入れて煮出す
しょうが辛みの香りで後味を整える葛汁にしょうが汁を少量
はちみつ甘み。糖の摂取量に数えること葛茶に溶かして
ケンポナシ慣習的な組み合わせ。効果が加わるというヒトでの根拠は確認されていないブレンド茶
クコの実色と香り。慣習的な組み合わせ葛酒に少量
かりん香り。冬のブレンド茶として一般的ブレンド茶

もう一つ付け加えると、複数の生薬を一度に増やすやり方は、問題が起きたときに原因を特定しにくくします。新しく始めるときは一つずつ増やすほうが安全です。

季節ごとの使い方

春・夏

  • 冷ました葛茶を冷蔵して飲みます。保存期間は2〜3日と短めに見ます
  • 葛粉で葛切りや葛餅を作ります。これは薬ではなく料理です
  • 夏の常温放置は変質に直結します。パウチ製品も開封後は冷蔵してください

秋・冬

  • 温かい葛湯や葛茶。風邪の引きはじめののどの違和感に慣習的に使われてきました
  • 葛粉を使ったとろみ料理。澱粉を食材として使うやり方です
  • 秋に掘った根を煎じるのが伝統的な時期です
  • 冬に漬けた酒は翌年の秋以降に漉す日程が一般的です

歴史と文化 — 救荒作物から薬材へ

葛は薬である前に食べ物でした。凶作の年には根を掘って澱粉を沈め、それで食いつなぎ、茎の繊維からは布と縄を作りました。山に自生し掘れば出てくる作物だったため、飢饉の記録に繰り返し登場します。

  • 東医宝鑑 — 葛根について性は平、味は甘く毒がないと記し、消渇を止め体を軽くし酒毒を解くと書いています
  • 本草綱目 — 葛根と葛花を分けて扱い、それぞれの用例を記しています
  • 救荒 — 朝鮮時代の飢饉の記録に葛の澱粉が繰り返し現れます
  • 葛布 — 茎から取った繊維で織った布。夏の衣類や縄に使われました

国ごとに違う位置づけ

地域主な形制度上の位置
日本葛粉・本葛・葛湯・葛切り和菓子の材料であり、漢方処方 葛根湯の構成生薬
韓国葛ジュース・葛茶・葛酒・葛粉生薬 葛根であると同時に食品原料
中国葛根粉など薬と食品の両方に使われる原料として扱われる
米国サプリメント形態が中心ダイエタリーサプリメント。南部では侵略的外来種としても有名

韓国で葛が身近なのは、日本で葛といえば葛粉や葛根湯を思い浮かべるのとちょうど対をなす現象です。韓国では根をそのまま長時間煎じた葛ジュースが市場やスーパーでパウチで売られ、家庭で煎じる文化も残っています。同じ植物でありながら、日本では澱粉と漢方処方、韓国では煎じ汁という形で日常に入り込んでいます。

ここで一つ注意しておくことがあります。韓国の葛ジュースは医薬品ではなく食品です。食品の表示規則では効能をうたうことができません。旅行先や通信販売で効能を大きく打ち出した葛製品を見かけたら、それは表示規則の外にあるという意味であり、その売り手の他の説明も同じ重さで読む理由はありません。

確認できなかったこと

この記事で確認できなかった項目を一か所にまとめます。節ごとに散らすと読みにくくなるためです。

  • 家で煎じた葛汁の成分含量 — 産地・樹齢・煎じ時間で変わります。標準化エキス試験の用量と対応させる方法がありません
  • 長期摂取の安全性 — 数か月以上続けた場合のヒトでの資料を確認できませんでした
  • 小児の用量 — 基準がありません
  • 妊娠中・授乳中の安全性 — 資料がありません。資料がないことは安全の確認ではありません
  • 葛と他の生薬を混ぜたときの相互作用 — 組み合わせごとの資料を確認できませんでした
  • 葛根単独の感冒関連のヒト研究 — 処方単位の承認は確認しましたが、単独の試験は確認できませんでした
  • 葛汁と葛酒の成分差 — 水抽出とアルコール抽出でどの成分がどれだけ違って出るかの定量比較を確認できませんでした

まとめ — 葛とどう付き合うか

葛は長く食べられてきた根で、多くの人にとって茶や汁くらいの量なら差し支えありません。問題は期待値です。効能十項目をそのまま信じて薬の代わりに使い始めると、そこから危険が生まれます。

まとめると三つの文になります。

  • ヒトでの根拠がついているのは飲酒量の減少と更年期症状の二項目だけで、どちらも限界がはっきりしています。残りは伝統的な用法です
  • 植物性エストロゲンという性質が、効能と禁忌を同時に作っています。ホルモン関連の疾患や治療中なら、始める前に主治医に伝えてください
  • プエラリア・ミリフィカは葛ではありません。より強いものを探す方向へ進まないでください

葛湯を一杯楽しむことと、葛で病気を治そうとすることは別です。前者ならこの記事の作り方をそのまま使ってください。後者なら、飲んでいる薬と診断名を整理して医師や薬剤師に見せるほうが早いです。

始めるときは — 少量で2週間ほど反応を見て、消化器・皮膚・月経に関する変化がないか確認してから量を調整してください。服用中の薬があるなら、その前に確認を取ってください。

  • Frontiers in Pharmacology（2021）「The Efficacy and Safety of Multiple Dose Regimens of Kudzu (Pueraria lobata) Root Extract on Bone and Cartilage Turnover and Menopausal Symptoms」 - 3番の節4項のヒト試験。骨吸収マーカーと更年期症状スコアが改善し重大な有害事象はなかったが、プラセボ対照群がないという限界を著者自身が述べている: pmc.ncbi.nlm.nih.gov
  • Chinese Herbal Medicines（2019）「Applications of Pueraria lobata in treating diabetics and reducing alcohol drinking」 - 3番の節3項の根拠水準。糖尿病関連の結果は動物・機序研究が中心でヒト臨床試験は非常に少なく、飲酒減少の研究も標本が小さく製品の標準化が一定でないという限界を併せて指摘している: pmc.ncbi.nlm.nih.gov
  • Frontiers in Pharmacology（2025）「Unveiling the power of Pueraria lobata: a comprehensive exploration of its medicinal and edible potentials」 - 2番の節の根拠。薬理作用の一覧表が細胞株と動物モデルの研究で埋まっており、葛の研究がどの層に偏っているかを確認できる: pmc.ncbi.nlm.nih.gov
  • 米国国立衛生研究所 LiverTox「Chinese and other Asian Herbal Medicines」 - 8番の節の根拠。アジアの生薬による肝障害を扱う文書であり、引用された系統的レビューでは生薬由来の肝障害194件のうち2件が Pueraria lobata に帰属すると整理されている。葛が肝臓を保護するという記述の根拠に使える文書ではない: www.ncbi.nlm.nih.gov
  • 国民生活センター（2017-07-13）「プエラリア・ミリフィカを含む健康食品」 - 7番の節の根拠。2012年度以降の5年間で209件の危害情報が寄せられ、調査対象12銘柄のうち10銘柄でエストロゲン活性が確認された: www.kokusen.go.jp
  • 厚生労働省「プエラリア・ミリフィカを含む健康食品に関するQ＆A」 - 7番の節の根拠。薬事・食品衛生審議会でこの原材料が審議され、自治体および関係事業者団体に通知されたことを確認できる: www.mhlw.go.jp
  • 食品安全委員会「プエラリア・ミリフィカ」 - 7番の節の根拠。女性ホルモン様作用が原因と考えられる健康被害情報が多数報告されている点と、異常を感じたら摂取をやめて受診するようにという呼びかけを載せている: www.fsc.go.jp
  • 厚生労働省（2008-09-30）「一般用漢方製剤承認基準の制定について」 - 10番の節の根拠。葛根湯が第23処方として収載され、構成生薬（葛根・麻黄・大棗・桂皮・芍薬・甘草・生姜）と承認された効能・効果が明記されている: www.mhlw.go.jp
  • 世界保健機関 欧州地域事務局（2023-01-04）「No level of alcohol consumption is safe for our health」 - 9番の節の根拠。健康に影響を与えない飲酒量は存在せず、リスクは最初の一滴から始まるとしている: www.who.int
  • 厚生労働省（2021-05-13）「一般用漢方製剤の添付文書等に記載する使用上の注意の一部改正について」 - 10番の節の根拠。葛根湯は第32項として収載されており、麻黄や甘草を含む処方の使用上の注意が定められている: www.mhlw.go.jp

# 葛 判断シート — 伝統の記録とヒト試験を分けて見る表

> 出典: braindetox.kr — 葛の効能と葛汁・葛酒の作り方
> 根拠: ヒト試験2件、系統的レビュー2件、総説1件、米国NIHの肝障害データベース1章、日本の公的機関文書4件、韓国・米国の表示規定2件、WHOの発表1件
> このファイルをAIに貼り付けて「この基準で、買おうとしている葛製品と今飲んでいる薬を点検して」と書けばよい。
> ⚠ これは診断でも処方でもない。薬を飲んでいる、あるいは診断のついた疾患があるなら、医師・薬剤師の判断が先である。

## 0. 一行でいうと

葛の効能十項目のうち、ヒト試験がついているのは二つ。残りは伝統的な用法であり、それ自体は欠点ではない。欠点になるのは、両者を同じ重さで語ることである。

## 1. 根拠の等級表

| 項目 | 伝統の記録 | ヒト試験 | どこまで言えるか |
|---|---|---|---|
| 1. 酒毒を解く | あり（東医宝鑑） | あり — ただし結果は飲酒量の減少 | 週あたり飲酒量が減った小規模試験。二日酔いを消す根拠ではない |
| 2. 肝臓の保護 | 間接（酒毒の記録から派生） | 確認されていない | 根拠なし。むしろ生薬由来の肝障害の一覧に登場する |
| 3. 血糖の調整 | あり（消渇） | 非常に少ない（動物・機序中心） | 伝統的な用法。血糖の薬の代わりにはならない |
| 4. 更年期症状 | 弱い（近代以降） | あり — プラセボ対照なし | ヒトのデータが最も厚い項目。著者自身が限界を述べている |
| 5. 心血管 | 部分的 | 確認されていない | 伝統的な用法 |
| 6. 感冒の初期 | 強い（葛根湯） | 処方単位のみ | 葛根湯は七つの生薬の処方。葛汁とは別のもの |
| 7. 頭痛・めまい | あり | 確認されていない | 伝統的な用法 |
| 8. 止瀉 | あり | 確認されていない | 伝統的な用法。過量はむしろ下痢を招く |
| 9. 肩こり・首のこり | 強い（葛根湯） | 処方単位のみ | 6番と同じ |
| 10. 抗酸化・肌 | 弱い | 確認されていない | 伝統的な用法。根拠は試験管内の活性のみ |

集計: ヒト試験2 ・ 処方単位2 ・ 伝統的な用法5 ・ 向きの訂正1。

## 2. 表を読むときの規則

| この読み方は誤り | こう読む |
|---|---|
| 古典にあるから効く | 長く使われてきたという事実にすぎない。効果と安全は別に測る |
| ヒト試験がないから嘘だ | まだ測っていないという意味。効果がないと証明されたのとは違う |
| 動物で効いたから人でも効く | 用量の桁が違う。そのままは移らない |
| 論文が多いから根拠が厚い | 層が重要。細胞100本はヒト1本に及ばない |
| エキスの結果が家で煎じた汁にも当てはまる | 標準化エキスは含量を揃えた製剤。煎じた汁は含量が不明 |

## 3. 安全チェックリスト — 始める前に一度

- [ ] 妊娠中、または妊娠の予定がある → 始めない
- [ ] 授乳中である → 始めない
- [ ] 乳がん・子宮体がん・卵巣がんなどホルモン依存性疾患の既往がある → 主治医の確認が取れるまで始めない
- [ ] ホルモン治療を受けている → 主治医に先に伝える
- [ ] 18歳未満である → すすめない（小児の用量基準がない）
- [ ] 2週間以内に手術の予定がある → 中止して手術チームに伝える
- [ ] 肝疾患の既往、または肝機能値の異常がある → 避けるか相談する
- [ ] 大豆アレルギーがある → 少量から確認する
- [ ] 低血圧、または降圧薬を飲んでいる → 開始後2週間は血圧を記録する
- [ ] 今飲んでいる薬をすべて書き出した → 下の5番の表と照合する
- [ ] 飲もうとしている形が酒（葛酒）である → アルコールの危険は葛で相殺されない

一つでも該当するなら、始める前に確認を取るほうがよい。

## 4. 中止して受診すべきサイン

- 不正出血、月経周期のはっきりした変化
- 皮膚や白目が黄色くなる、尿が濃くなる
- 理由のない疲労が続き、食欲が落ちる
- 右上腹部の持続する違和感
- 蕁麻疹が広がる、息苦しさが出る

## 5. 薬物相互作用の照合表

| 今飲んでいる薬 | 懸念 | すること |
|---|---|---|
| タモキシフェンなどの抗エストロゲン薬 | 作用の向きがぶつかる | 確認が取れるまで始めない |
| ホルモン補充療法・経口避妊薬 | ホルモン信号の重複 | 服用していることを伝える |
| ワルファリンなどの抗凝固薬 | 止血指標の変化 | 自己判断で始めたり止めたりしない |
| 降圧薬 | 血圧のさらなる低下 | 2週間の血圧記録 |
| 糖尿病薬・インスリン | 血糖変動の重複 | 自己測定の記録を残す |
| メトトレキサートなど肝負荷の大きい薬 | 原因の判別ができなくなる | 新しい生薬を増やさない |

## 6. 葛とプエラリア・ミリフィカの区別表

| 項目 | 葛（Pueraria lobata） | プエラリア・ミリフィカ（P. mirifica） |
|---|---|---|
| 原産 | 東アジア | タイ・ミャンマー |
| 用途 | 生薬 葛根、葛粉・葛湯などの食品 | 女性向け健康食品の原材料 |
| エストロゲン作用 | 弱い（大豆イソフラボン系統） | はるかに強い（ミロエストロールなど） |
| 公的な危害情報 | 散発的 | 国民生活センターに2012年度以降の5年間で209件 |
| 報告された症状 | 主に消化器 | 腹痛・嘔吐・下痢、発疹・蕁麻疹、月経不順・不正出血 |
| 製品検査 | — | 12銘柄中10銘柄でエストロゲン活性を確認 |

表示で弾く五つ: ①学名に mirifica ②原産国がタイ ③バストや体型の変化をうたう文言 ④錠剤・カプセル中心 ⑤ガウクルア、ホワイトガウクルアの表記。

## 7. 国ごとの形の比較

| 地域 | よくある形 | 制度上の位置 | 買うときに見る点 |
|---|---|---|---|
| 日本 | 葛粉・本葛・葛湯・葛切り、葛根湯 | 食品であり、漢方処方の構成生薬 | 葛根湯は医薬品、葛粉は食品 |
| 韓国 | 葛ジュースのパウチ、葛茶、葛丸、葛粉、葛酒 | 生薬 葛根であり食品原料 | 健康機能食品ではない旨の表記と葛の含有量 |
| 中国 | 葛根粉、乾燥スライス、生葛根 | 薬材と食材の両方 | 葛根（野葛）と粉葛は別の薬材 |
| 米国 | エキスのカプセル・錠剤 | ダイエタリーサプリメント | 疾病の治療をうたえない。免責文の有無を確認 |

## 8. 表示の確認項目

- [ ] 葛の含有量が数字で書かれている
- [ ] 原材料名が葛単独か混合かが分かる
- [ ] 原産地が明確である
- [ ] 添加物と糖の量を裏面で確認した
- [ ] 学名の記載があれば lobata か mirifica かを確認した
- [ ] 効能を前面に出した表示がない（あれば表示規則の外である）
- [ ] 製造日と賞味期限がある
- [ ] 開封後の保存条件が書かれている
