LLM 6个月演进总结 2026 - 11月到5月所有重要变化一目了然

2025年11月到2026年5月重塑AI地形的6个月,凝缩为一张矩阵

2026-05-21 IT/技术

引言: 为什么6个月的整理是2026年合适的颗粒度

6个月前的2025年11月,LLM的版图看起来稳定。GPT-4.5o是默认,Claude 4.5 Sonnet刚刚发布,Gemini 2.0 Flash是低价档的主力。市场谈论的是"扩展律正在变缓,曲线已经平坦"。6个月后,那一段的几乎所有假设都被打破了。11月到5月这个窗口是自初代GPT-4以来最忙的LLM发布周期,速度之快连AI全职构建者也跟不上。和周围的资深开发者聊,他们的栈里仍然嵌着2025年的假设,正在悄悄丢掉可用质量、成本与速度的30~50%。

本文是笔者为自己工作做的6个月回顾。它逐一梳理主要实验室与开源权重家族,把变化压缩为矩阵与表格,并以五条具体的实务启示和H2 2026展望收尾。结构是有意的: 按角色 → 趋势 → 基准 → 建议。只看矩阵就翻到两张大表; 想看上下文就从头读到尾。全文不写任何实验室的市场用语,只写笔者真实滚动这些工具的感受。

在角色逐一回顾前,放三条框架笔记。第一,模型版本号不是进步的衡量单位。一个实验室的"0.1"可能比另一家的"2.0"更大。本文聚焦"实际发生了什么变化"。第二,闭源与开源权重的进步曲线现在在并行,某些轴上差距已缩到数周。第三,最具决定性的变化不是任何单一模型发布,而是周边栈: 智能体外壳、编码代理、记忆原语,以及作为事实标准落地的Model Context Protocol。本文会反复回到这一点。

OpenAI: GPT-5、Codex Goals与Operator轨道

OpenAI的H1 2026由两个动作主导。第一是1月底GPT-5发布,把此前散在o系列的推理轨整合起来,不再是"独立的推理模型开关",而是同一个产品内自适应配置思考预算。仅此简化就为开发者抹掉了大量混乱。第二是2月底到4月分阶段释放的Codex Goals,把Codex子产品从单纯的聊天补全,变为接收高级目标后在仓库上工作数小时的自主编码代理。

更安静的变化在生产中更重要。3月Operator栈普遍可用,计算机使用API稳定,损坏页面状态下的恢复明显改善。Realtime API原生支持工具使用,在语音工作流上缩小了对Anthropic的差距。记忆持久化从实验功能升级为带显式存储、检索、遗忘原语的文档化表面,"助手跨会话记得我"从一季度的工程变成一周的工程。这些没有占据新闻周期,但生产栈实际就是建在这些上面。

价格上,GPT-5以输入与2025年末GPT-4.5o基本持平、输出因缓存窗延长而显著降低的形式上线。4o家族按计划在Q3 2026之前完成弃用,现在仍在4o上的团队应当立刻安排迁移窗口。关于Codex Goals本身以及如何嵌入日常循环,本博客的OpenAI Codex Goals实战指南 2026更深入。

Anthropic: Claude 4.5、4.6、4.7与Claude Code之年

Anthropic 6个月内有三次有分量的发布。2025年12月底的Claude 4.6收紧了工具使用,加入原生长文档处理。2026年3月的Claude 4.7 Sonnet把计算机使用纳入默认产品,在编码基准上明确拉开了与其他家的差距。2026年5月的Claude 4.7 Opus是当前在大多数智能体与长上下文任务上的前沿模型,也是笔者本人多小时自主编码会话的默认选择。每次发布在名字上都是渐进的,但累积起来在"把代理放出去2小时还能信任"这个类别上拉大了Anthropic的领先。

模型周围,Claude Code进化为完整产品。Skills、Hooks、Sub-agents和稳定的settings.json schema把CLI从高级用户玩具变成团队部署到整个代码库的工具。Anthropic在2024年末发起的Model Context Protocol在H1 2026成为事实上的行业标准,OpenAI、Google与大多数主流IDE厂商都已原生支持MCP。这可能是本期最具结果意义的单一标准变化。通过安静地拿下协议层,无论调用谁的模型,Anthropic都把自己放到了开发者工具栈的中心。

Anthropic的另一个话题是人而非产品。2月Andrej Karpathy加入Anthropic是当年最受讨论的AI招募。撇开长期研究影响不谈,这件事对资深研究者吸引力的短期效应即刻可见。关于Claude Code自身的日常使用,我们的常驻指南Claude Code Skills完全指南覆盖了在4.6与4.7迁移后仍可用的模式。

Google: Gemini 3.0、3.5 Flash与价格战

Google的H1 2026战略不是顶端质量,而是性价比上的激进压力。12月的Gemini 2.5是相对2.0的安静质量提升。2月的Gemini 3.0是让Google重新明确回到前沿对话的第一个版本,有强多模态表现和实用的200万token上下文。然而本期的头条仍是4月的Gemini 3.5 Flash,相比2.0 Flash把输出成本砍掉约60%同时质量足够,让它成为高吞吐低关注度流量的明显默认。

Google搜索的AI Overviews从"还在争论是不是好主意"过渡到"十亿人以上的搜索方式中永久的默认成分"。这一含义超出模型本身: AI生成的答案现在是用户与大多数开放网之间的一层,2026年的内容策略必须先为这一层写作。在Google开发者表面上,5月中旬I/O 2026公告预告了Gemini对Workspace、Android以及新Code Assist代理层的更深整合。单独看不算震撼,累积效应是Google重新成为默认而非备选。

价格点对运行重型自动化的团队最重要。如果你正在构建每月调用LLM超过百万次的东西,那么在你流量的下70%里,账已倾向Gemini。把前沿模型留给真正需要的上30%。这个两层模式现在已是认真做LLM产品的默认架构,趋势节我们会回到这一点。

Meta: Llama 4系列与开源战略的规模化

Meta的H1 2026就是Llama 4家族。12月到4月的Llama 4 7B、30B、200B单独看并未撼动前沿,但作为一次协调的下落,在三条轴上有意义地推进了开源权重: 更长上下文(256K稳定)、30B尺寸上与闭源对等的工具使用、200B尺寸在很多任务上能与Claude 4.5 Sonnet进入同一话题的质量。Meta也开放了比此前Llama 3.x更能满足企业法务的清晰许可制度。

Meta没有做的事同样重要。2026年初没有正面针对500B+规模闭源前沿的Llama 4发布,公司在公开信息里把这定位为有意的战略选择而非能力不足。赌注是: "在常用尺寸足够好"的开源权重加上自托管成本下降,最终能拉回比追绝对前沿更大的推理工作负载份额。这个赌注成不成是6个季度的问题,不是6个月的; 但企业自托管部署的早期信号是利好的。

从实务者视角,行动级的教训是Llama 4 30B是必须知道的尺寸。单卡H100或Blackwell B200上以生产速度跑得很舒服,工具使用稳定,提供托管API级体验且零厂商锁定。配合vLLM 0.7的批处理改进,自托管Llama 4 30B的token单价在纯推理上已和Gemini 3.5 Flash竞争,不算自有栈的战略价值。

中国三巨头: DeepSeek、Qwen、Doubao

H1 2026的中国故事对外部观察者最为意外。2025年11月底DeepSeek V3已经强,2026年2月V4真正与前沿闭源模型竞争。671B MoE每token激活约37B参数,把推理成本压在合理区间,同时在按任务衡量的质量上推到顶级。开源权重、MIT风格许可与训练配方异常详尽的论文,使DeepSeek V4成为Q1 2026部署最多的单一开源模型。

阿里巴巴的2026年3月Qwen 3家族主攻编码。Qwen 3 Coder 32B在笔者自己的基准跑分里是现存最强的小型开源编码者。与通用Qwen 3 235B一起,阿里被估为全球开源权重推理服务量最大的来源。字节跳动的2026年4月Doubao 1.6在中国以外知名度较低,但带原生跨模态能力和TikTok集成出货,在中文市场重要。是否使用这些模型很大程度取决于你的数据立场,但假装它们不存在已经不是站得住的姿态。完整图景见我们的常驻对比DeepSeek vs Qwen vs Doubao 中国LLM比较 2026。

技术上的一句旁注: 近期DeepSeek V4的steering vectors研究打开了小而重要的可解释性之门,外部团队已在编码评测上展示了可复现的行为漂移。这是半期更有意思的研究故事之一,我们的LLM steering vectors与DeepSeek V4讨论实务含义。

xAI: 从Grok 3到Grok 4,黑马叙事

xAI悄悄走出了meme。2025年11月底的Grok 3是第一次进入推理基准前沿圈的版本,2026年4月的Grok 4缩小了剩余差距。模型仍主要通过X和独立消费者App分发,这一分发差距阻碍它成为开发者默认。但技术工作是真的: 公司的训练集群Colossus扩到没有微软-OpenAI那种新型大单几乎无人能匹敌的规模,这一硬件基底如今反映在模型上。

从实务者视角,Grok 4是有效的备用模型,在需要实时网络落地却不想自建检索层时也是意外强的选择。价格属中档,API已稳定。约束主要是文化层面: 不少企业因为采购原因仍把xAI看作与X过于紧绑,这种认知变化比底层技术地位所证明的更慢。如果你的栈已通过路由器在多家供应商间负载均衡,把Grok 4加入只需几小时,就能换来面向下一次供应商故障的可衡量韧性。

Mistral、Cohere与二线整合

二线前沿实验室在H1 2026真正经历了整合。1月的Mistral Large 3以欧盟在地基础设施和满足美方仍难达的合规许可重申了Mistral作为欧洲前沿首选的地位。Mistral的更小开源发布(Codestral 2、Pixtral 2)维持了开发者声量。Cohere的Command R-Plus 2026更新在企业RAG工作流上加码,在落地检索任务上继续超过头条前沿模型。

到2025年末仍在对话中的若干较小角色实质退出。AI21的Jamba家族只剩超长上下文这一小众。Inflection完全转向不再做前沿消费者模型。Reka等几家仍在出技术上有趣的工作但已不在任何受关注基准上竞争头部。市场全球收敛到约7家认真LLM供应商: OpenAI、Anthropic、Google、Meta(开源)、DeepSeek、阿里/Qwen、xAI。Mistral与Cohere作为强地区或垂直选项保留。这相比2024年末12家以上明显收窄。

本地LLM: Llama.cpp、Ollama、vLLM、MLX

本地与自托管生态快速移动。Llama.cpp加入稳定的Vulkan和ROCm路径,打破了一年前还成立的"只能NVIDIA"的假设。Strix Halo PC(AMD的大内存APU笔电平台)以可用速度跑70B模型,Q1 2026成为真实的产品类。Ollama跨入主流开发者工具,带稳定模型注册表、可预测的更新通道、与VS Code和JetBrains IDE的紧密集成。vLLM 0.7和0.8通过PagedAttention v3与投机解码改进,削减了生产部署的推理成本。Apple的MLX 0.20让M系列Mac成为30B到70B参数带的内存每美元最强本地推理选项,M5 Max机型今天就以足够统一内存出货,可无妥协承载Llama 4 30B与Qwen 3 32B。

合在一起的效果是低关注度LLM流量的实质份额正在离开API。个人笔记助手、IDE自动补全、内部文档摘要,凡是数据敏感、延迟、成本比绝对前沿更重的任务都在迁向本地推理。完整硬件画像在我们的本地LLM硬件选择指南 2026中按季度刷新。

AI编码工具: Cursor、Claude Code、Codex、Aider、Cline

AI编码工具是半期最快变化的子类。Cursor的代理模式在11月和12月成熟为可靠处理多文件重构的东西,在竞争激化中价格保持稳定。Claude Code成为严肃自主编码工作流的主导CLI工具; 跑超过30分钟的任务时,通过Claude 4.7 Opus调用Claude Code是当前默认。OpenAI Codex子产品的Codex Goals是最强的一次性生成表面; 在你想看模型输出并快速调整的紧迭代循环里,几乎难以击败。

Aider继续作为开源基线保持强势,Cline填补了希望不离开IDE使用代理的VS Code内嵌生态位。三个月混用后的诚实评估是没有任何单一工具支配全部工作流: 编辑器内结对用Cursor,长时自主任务用Claude Code,一次性生成用Codex,需要完全可检查工具时用Aider做开源备份。三个月对比详见我们的Claude Code vs Codex 三个月评测 2026,展开轮换模式。

6个月的核心趋势

从单个实验室退一步,四条趋势定义了这段时间。

智能体AI从演示走向生产。本半期每次前沿模型发布的定义性特征都是更长更稳的自主链。Claude 4.7 Opus下2小时自主编码会话已经现实,GPT-5与Gemini 3.0下模型自主提议、浏览、汇总、迭代的多步研究可用。剩下的失败模式是真的,但不再阻断生产使用。

推理模型不再是单独的产品类目。o系列融入GPT-5的自适应思考预算,Claude的扩展思考默认开启,Gemini 3.0透明使用内部链。过去一年困扰用户的"思考模型开关"基本消失,这个简化本身就是质量提升。

多模态成为底线配置。视觉在所有前沿模型上都可用,音频输入输出是标配,视频理解在前三家实验室中都已胜任。差异化不再是"是否有多模态",而是"多模态输入与工具使用拼得有多好"。

30B级"更小即更好"是真的。本半期按部署频率衡量的最大受益者是30B参数带。Qwen 3 32B Coder、Llama 4 30B以及更小的DeepSeek蒸馏版都在这一区间,实际处理70~80%不真正需要前沿IQ的任务。

基准变化: MMLU饱和,SWE-bench激增

基准格局也实质变化。MMLU基本饱和,所有前沿模型落在88~91之间,基准自身的噪声地板也在此区间。SWE-bench在6个月内顶分大致翻倍,从2025年11月的49%涨到2026年5月Verified子集超过90%,这是本期最具结果意义的单一基准变化。GPQA顶分从60s早段移到70s晚段。ARC-AGI v2仍是当前最难的公共基准,也是实验室如今最显眼竞争之处。

给读基准的工程师的教训是: SWE-bench现在是回答"这个模型擅长编码吗"最有用的单一数字,而MMLU表现与现实效用的差距比以往更大。一个模型可以MMLU 90但在生产调试上失败,而Claude 4.7能一遍处理。基准数字始终要与你自己工作负载的任务级评测一起看。

每个开发者都应内化的5条启示

从6个月画面压缩出的建议。

  1. 至少轮换两套编码工具。Claude Code+Codex或Claude Code+Cursor是最有韧性的模式。失败模式不同,某家供应商挂了你也能继续工作。
  2. 建一层两档路由。把60~80%的流量送到Gemini 3.5 Flash或Claude Haiku级,把前沿模型留给真正需要的调用。一周省下的钱就能回收工程成本。
  3. 至少在本地跑一个模型。M系列Mac或带Blackwell的工作站上的30B模型可以覆盖离线工作、敏感数据,并给你"没API也能做吗"的地基。没有本地经验的构建者会被他们提问的方式逐渐认出。
  4. 把MCP当默认。Model Context Protocol是新的"AI界REST"。给ChatGPT、Claude、Gemini分别造定制集成已是浪费; 一个MCP服务器一次连三家。
  5. 按季度重评基准。11月在你评测里第一的模型,今天大概率是次档。最少每三个月跑一次评测套件,睁眼挑新默认。

对2026年下半年的预期

预测很难,大多数预言年久会褪色,但过去6个月的轨迹支持三条以合理信心做出的判断。

第一,智能体系统成为高级用户的默认UI而非小众。UI演进与聊天机器人在2023年走过的路相同: Q1实验、Q4主流。预计到年末,所有主要实验室都会把智能体表面作为默认产品的一部分发布,而不是可选beta。

第二,模型差异化从纯IQ转向记忆、工具使用、单任务价格。闭源模型纯基准之争在闭源端正在平台化,竞争上移到周边栈。谁先把记忆做对(让模型跨会话记住你,但是有用而不是令人不适),很可能拿到大量消费者心智份额。

第三,设备端与笔电级推理悄悄吃下低关注度流量的大份额。M系列Mac与Strix Halo PC以可用速度跑30~70B模型,把相当部分消费使用从API彻底分走。这对低价层API营收是坏消息,对用户隐私是好消息。

如果你在为H2 2026做路线图,就为这三条做。跳出"等下一代模型"的陷阱。你需要的能力,今天就在能跑的栈里。

结语: 6个月的结构性位移

11月到5月这个窗口不是又一个升级周期,而是智能体系统变成真的、开源权重在足够多的轴上追上前沿、价格降到改变架构模式、MCP锁定为未来两年工具构建的标准层的时段。其中任何一条都相当于一个平年的进步,四条同时发生,使这段时间成为结构性位移。
