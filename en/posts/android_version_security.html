Android Security Enhancements by Version: A Complete Summary (Android 10~14)

As smartphones become essential to everyday life, protecting personal data and device security has never been more important. Each year, Google continues to strengthen Android's security capabilities, introducing an evolving set of mechanisms to protect user data. In this post, we take an in-depth look at the major security improvements in each Android release, from Android 10 (Q) through the latest Android 14 (Upside Down Cake), and walk through the security settings you can apply yourself.

Deep Dive: Key Security Features per Android Version

1. Android 10 (Q) - 2019

  • Stronger storage encryption: File-Based Encryption (FBE) is now the default, with a separate encryption key used for each file
  • Granular location permissions: Apps must request a separate permission before accessing location data in the background
  • Project Mainline introduced: Security patches can be rolled out via Google Play system updates without a full OS update
  • Scoped storage: Limits apps' file access permissions, preventing indiscriminate data access
  • Default TLS 1.3 support: Faster, more secure encrypted communication protocol adopted

2. Android 11 (R) - 2020

  • Per-session permissions: Location/microphone/camera access can be granted with a one-time "Only this time" option
  • Automatic permission reset: Permissions are automatically revoked for apps that have not been used for an extended period (several months)
  • Background location access restrictions: Blocks background location collection without a foreground service
  • Stronger biometric authentication: Upgraded to the Class 3 biometric standard for higher-assurance authentication
  • Wireless device isolation: Data separation between Bluetooth devices prevents exploit attacks

3. Android 12 (S) - 2021

  • Privacy Dashboard: Visualizes each app's permission usage over time for easy, at-a-glance review
  • Adjustable location precision: Option added to provide apps with approximate location instead of precise location
  • Microphone/camera indicators: Shows a real-time indicator in the status bar when an app uses the mic or camera
  • Private Compute Core: Builds a dedicated secure environment for handling sensitive data
  • App Hibernation: Automatically optimizes and restricts permissions for long-unused apps
  • Android Private Compute Core: Provides an isolated environment that protects data while AI features are in use

4. Android 13 (T) - 2022

  • Mandatory notification permission: All apps must receive explicit user permission before sending notifications
  • Granular media file access: Independent permissions can be granted for photos, videos, and audio as separate categories
  • Automatic clipboard clearing: Clipboard contents are automatically cleared after a set time
  • Stronger developer-option security: Additional authentication is required when accessing sensitive developer options
  • Per-app language settings: Support for different languages per app makes phishing apps easier to spot
  • Improved Advertising ID reset: Better management of advertising identifiers to limit user tracking

5. Android 14 (U) - 2023-2024

  • AI-based threat detection: A real-time smishing/spam call-blocking system powered by machine learning
  • Enhanced PIN security: Progressive delays when PINs are entered incorrectly in succession, with 6+ digit PINs recommended
  • API level restrictions: Blocks installation of apps targeting outdated API levels to prevent exploitation of known vulnerabilities
  • Background sensor restrictions: Limits background sensor data collection to prevent behavioral tracking
  • Partial screen sharing: Allows sharing a single app's screen only, preventing unintentional exposure of sensitive information
  • ARM Memory Tagging Extension (MTE): Real-time detection and defense against memory-vulnerability attacks
  • Improved photo picker: Enables selective photo sharing without granting apps access to all photos

Essential Security Settings Guide: A Step-by-Step Approach

1. Basic Security Hardening (Beginner)

  • Keep OS and apps up to date
    • Settings > System > System update
    • Play Store > Profile > Manage apps & device > Update all
  • Enable Google Play Protect
    • Settings > Security > Google Play Protect > Enable app scanning
    • Turn on the option to detect harmful apps
  • Strengthen screen lock settings
    • Set a PIN or pattern of 6 or more digits
    • When enrolling biometrics (fingerprint/face), set a strong backup password

2. Permissions and Privacy Management (Intermediate)

  • Regularly review app permissions
    • Settings > Privacy > Permission manager
    • Check which apps have sensitive permissions such as location, camera, and microphone
  • Enable optimization for unused apps
    • Settings > Apps > Special access > Unused apps > Remove permissions and pause notifications
  • Set per-app location precision
    • Settings > Location > App permissions > Adjust the "Use precise location" option for each app
  • Make use of Digital Wellbeing
    • Settings > Digital Wellbeing > Review app usage patterns on the dashboard

3. Advanced Security Settings (Advanced)

  • Strengthen Google account security
    • Enable 2-Step Verification: accounts.google.com > Security
    • Register a security key (a physical security key or the smartphone itself)
  • Manage network security
    • Settings > Network & internet > Advanced > Private DNS
    • Use a secure DNS provider such as dns.google or Cloudflare 1.1.1.1
  • Encryption and backup
    • Settings > Security > Encryption & credentials > Check the encryption status
    • Enable Google Drive backups and configure backup encryption
  • Manage developer-option security (advanced users)
    • Disable USB debugging when it is not needed
    • Disable OEM unlocking (to prevent rooting)

Strategies for Defending Against Android Security Threats

Phishing and Smishing Prevention

  • Enable spam protection in the Google Messages app
    • Messages app > ⋮ > Settings > Spam protection > Turn on "Enable spam protection"
  • Avoid clicking URLs from unknown senders
    • Do not visit suspicious links directly; instead, use the official app or website
  • Ignore messages requesting financial information
    • Never provide personal information in response to SMS or messenger messages that impersonate financial institutions

App Installation Security

  • Use official stores only
    • Apps from sources other than the Play Store require thorough vetting before install
    • Settings > Apps > Special app access > Restrict "Install unknown apps"
  • Check app reviews and ratings
    • Look at download counts, developer reputation, and the date of the last update
  • Be cautious of apps requesting excessive permissions
    • Be suspicious when an app asks for many more permissions than its features justify

Public Wi-Fi Security

  • Limit auto-connecting to Wi-Fi
    • Settings > Network & internet > Wi-Fi > Wi-Fi preferences > Manage auto-connect
  • Make VPN use a habit
    • Enable a trustworthy VPN service when using public Wi-Fi
    • Settings > Network & internet > VPN > Consider the "Always-on VPN" option

Closing Thoughts: The Importance of Proactive Security Management

The Android OS continues to evolve with increasingly robust security mechanisms, but ultimate security begins with the user's active participation and proper configuration. Simply keeping your device on the latest version addresses many vulnerabilities, and making a habit of periodically reviewing the settings presented in this guide is equally important.

Threats in the digital world continue to evolve, but as long as user security awareness evolves alongside them, a safe mobile life remains well within reach. We hope this guide serves as a first step toward protecting your valuable digital assets and personal information.
