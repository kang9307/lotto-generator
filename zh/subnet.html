什么是子网 (Subnet)？

子网是 IP 网络的逻辑划分。通过子网划分，可以将一个大型网络分割为多个较小的网络，从而提升网络管理效率与运行性能。

核心术语

  • IP 地址：用于互联网协议的地址，是识别设备的唯一编号。
  • 子网掩码：用于在 IP 地址中区分网络部分与主机部分的数值。
  • CIDR（无类别域间路由）：一种 IP 地址分配方式，使用 /24 之类的前缀长度表示。
  • 网络地址：子网的第一个地址，其主机部分全部为 0。
  • 广播地址：子网的最后一个地址，其主机部分全部为 1。

子网计算器使用方法

  1. 在 IP 地址输入框中输入有效的 IPv4 地址（例如：192.168.1.0）。
  2. 在 CIDR 表示法和子网掩码中任选其一进行输入：
    • CIDR：在下拉列表中选择合适的前缀长度（例如：/24）。
    • 子网掩码：输入有效的子网掩码（例如：255.255.255.0）。
  3. 点击"开始计算"按钮查看结果。

计算结果解读

  • 网络地址：该子网的起始地址。
  • 广播地址：该子网的末尾地址。
  • 主机数量：网络中可用的 IP 地址数量（不包括网络地址和广播地址）。
  • 主机范围：可实际分配给设备的 IP 地址范围。
  • 二进制表示：IP 地址与子网掩码的二进制形式。
