育儿费用与政府支援制度 - 韩国有资格却因未申请而错过的补助

申请制、期限，以及每年都在变动的金额该怎么应对

2026-07-31 生活/实用

引子: 那一项已经过了期限，办不了

在政务窗口，有一句话最不想听到。那一项已经过了申请期限，办不了。不是不符合资格，也不是材料不齐，只是不知道有这么一项，等知道时已经晚了。不是因为没钱而没领到，而是因为没有信息而没领到，这种损失格外让人不甘。

谈育儿费用的文章通常从「要花多少钱」开始。那个数字因各家情况差异过大，其实用处有限。本文把重点放在别处: 把有资格却因为没人去申请而领不到的部分消除掉。

要做到这一点，先要了解韩国制度的三个性质。这三行可以说就是本文的全部。

  • 采用申请制。具备资格与实际领取是两回事。连接两者的只有申请这一个动作，而且没有人会替你去做
  • 有期限。部分项目一旦过期就不再补发。也有像消费券那样不使用就会失效的形式
  • 每年都在变。金额会变，年龄要件会变，申请方式也会变。按去年标准做的计划今年不成立，是常有的事

所以本文不是让人背金额的文章，而是要留下何时该核对什么。金额一年就过时，而核对的习惯可以一直用到孩子上学。

适用范围与免责。本文仅说明韩国的制度。如果您身处其他国家，这里的数字并不适用于您所在国。本文以提供信息为目的，不构成法律、税务或行政方面的咨询意见，也不是对个案的判定。文中所有金额与要件均为截至2026年7月31日在官方资料中核实的内容，此后可能变更。实际能否领取及金额，取决于收入、家庭构成、居住地、雇佣形态与申请时点。申请前务必向主管机构确认自身要件。

没能核实的内容没有写。凡是无法从一手资料确定的数字，本文都不用推测去填补，而是标注为需要核实，并给出核实路径。第10节汇总了这份清单。本文没有的项目并不代表它不存在，只代表笔者未能核实。

1. 把育儿费用分成三段

把费用当成一整块来看就无从应对。各时期大额支出的性质不同，公共支援介入的位置也不同。分成三段之后，什么时候该核对什么就清楚了。

区段费用性质公共支援介入之处核对时点
妊娠与生育短而重。集中在诊疗与分娩，时间窗固定医疗费支援、生育相关休假与津贴确认怀孕之后
婴幼儿期按月重复。总额随照护方式差异很大现金类支援、托育支援、工时制度办理出生申报时
学龄前机构费用与时间成本混杂，与父母的工作形态纠缠托育与教育支援、看护服务、税额扣除机构使用发生变化时

这张表里最重要的是最右一栏。支援制度大体上都要在「状态发生变化的时点」去申请或申报。确认怀孕时、孩子出生时、开始上机构时、退出机构时、搬家时。错过这些时点，中间那段时间的支援就可能整块落空。

反过来说，需要留意的时刻并不多。不必每天盯新闻，只要在上述四五个时点各打开一次官方渠道，大部分就能兜住。

2. 妊娠与生育 - 先确认医疗费支援

妊娠阶段首先要确认的是健康保险的妊娠生育医疗费支援。以国民健康保险公团与政府24的指引为准，每次妊娠支援100万韩元，多胎为140万韩元。居住在分娩服务薄弱地区的，追加20万韩元，即单胎120万韩元、多胎160万韩元。

这一项排在最前，不是因为金额大，而是因为它带着期限。支援金以消费券形式发放，使用期限内没花掉的余额会失效。也就是说，即便有资格、即便已经申请，没在期限内用掉也会消失。

  • 使用截止日务必直接向公团核实。在查阅的官方资料之间，截止日的表述也不一致，有的写成「自分娩日起1年」，有的写成「自预产期或分娩日起2年」。这类事项要看自己那张消费券上的实际截止日，而不是别人的摘要
  • 是否多胎、是否居住在分娩服务薄弱地区，要在申请阶段说明。追加支援只有在这些事实被记录后才会附加
  • 指引提到，如果已经持有相关卡片，可以不再走发卡流程，只申请消费券即可
  • 预产期前后紧接着是产前产后休假与育儿休假。这两项在第5节单独讨论
  • 配偶陪产假的天数与申请期限，本文未能核实。请向雇佣劳动部与雇佣保险确认

这一段的一条原则。妊娠生育阶段的支援多为限期型。也就是说，它不是「领到了」就结束，而要走到「在期限内用掉了」才算完成。申请当天就把使用起始日与截止日写进日历，是这一段能做的最实在的防守。

3. 现金类支援 - 儿童津贴与父母津贴

这是孩子出生后按月到账的那一类支援。已核实的两根支柱是父母津贴与儿童津贴。下表的数字都标注了基准年度与出处。不要直接背下来，而要在申请时用它来重新核对。

制度对象金额依据出处
父母津贴0岁 (0个月至11个月)每月100万韩元2023年施行，整理时点仍有效保健福祉部
父母津贴1岁 (12个月至23个月)每月50万韩元2023年施行，整理时点仍有效保健福祉部
儿童津贴未满9岁 / 首都圈每月10万韩元2026年保健福祉部 (2026-04-23)
儿童津贴未满9岁 / 非首都圈每月10万5千韩元2026年保健福祉部 (2026-04-23)
儿童津贴未满9岁 / 人口减少地区优待区每月11万韩元 (地区消费券12万韩元)2026年保健福祉部 (2026-04-23)
儿童津贴未满9岁 / 人口减少地区特别区每月12万韩元 (地区消费券13万韩元)2026年保健福祉部 (2026-04-23)

儿童津贴值得留意的是年龄门槛逐年上调。按保健福祉部资料，2026年为未满9岁，2027年未满10岁，2028年未满11岁，2029年未满12岁，2030年未满13岁，每年上调一岁。这意味着现在不是对象，过几年可能就是; 反过来，「我家孩子已经超龄」这个判断明年可能就不成立了。

  • 同一份资料显示，原本已在领取儿童津贴的家庭无需另行申请即可获得扩大部分，2017年1月至2018年3月出生的约43万名儿童还补发了1月至3月的份额
  • 但这是对已在领取者适用的例外，并不意味着首次申领的人可以不申请
  • 按保健福祉部的指引，父母津贴的结构是在现金与消费券(托育费、全日托育)之间选择。上托儿所不会让支援消失，而是改变了形式
  • 指引说明可通过邑面洞社区服务中心现场办理或福祉路线上办理申请
  • 父母津贴的申请期限与补发规定未能核实。不要想当然地认为「晚申请也会补发」，请向福祉路或社区服务中心确认

4. 托育与教育 - 取决于孩子去哪里

婴幼儿期支援的结构建立在一个简单原理之上: 使用机构，支援就挂在机构一侧; 不使用机构，就挂在家庭一侧。上托儿所或幼儿园对应托育费与幼儿学费类支援，不上则由居家养育一侧的支援来对应。

实务上重要的不是金额，而是存在不能叠加领取的结构。制度并不设计成同一种性质的支援能通过两条渠道同时领取，因此在两者之间切换时需要办理变更申报。漏掉这个申报，是这一段最典型的事故。

  • 开始使用机构时支援方式会改变。不申报，领取金额就会出现偏差
  • 退出机构时同理，此时需要申报切回居家养育一侧
  • 最好假定同一期间不存在两次领取同一性质支援的路径。能否叠加请在申请窗口确认
  • 中途退出或转换的月份可能产生按日折算或结算。为避免日后被要求退还，还是随时申报为好
  • 居家养育津贴的金额与年龄区间，以及托儿所托育费、幼儿园幼儿学费的分龄单价，本文未能核实。请通过育儿门户、福祉路、教育厅或社区服务中心确认
  • 育儿帮助服务的收入标准与自付比例同样未能核实。这是需要另行确认的事项

5. 工作与育儿 - 育儿休假与缩短工时

换不成账面数字、实际上却最大的一项是时间。把时间变成制度的，是育儿休假与育儿期缩短工时。以下是按雇佣劳动部公布的2025年施行标准核实到的内容。

读这张表时有一点必须分清: 上面的金额是上限额，不是实发额。实际发放金额由通常工资与个人核算标准决定，把上限直接写进家庭预算就会算错。

  • 废止事后支付金是感受最明显的变化。过去有一部分要复职后才拿到，现在的说明是休假期间全额发放
  • 延长到1年6个月是有条件的。并非人人无条件1年6个月，而是父母各自使用满一定期间等情形才适用，需要确认自己是否符合
  • 缩短工时的适用年龄已提高到小学六年级。这意味着它不只是托儿所阶段的制度，可以成为应对小学低年级看护空档的一张牌
  • 育儿期缩短工时津贴的实际计算未能核实。所查阅的官方资料之间对基准金额的表述互不一致，因此本文不予确定。请到雇佣劳动部与雇佣保险按本人基准核实
  • 领取还另有雇佣保险方面的要件。在职并不等于自动符合

6. 税务 - 子女在年末结算中的位置

这部分不会以现金形式进账，而是以少缴税的方式回来。以下是在国税厅指引中核实到的项目。

项目已确认内容出处
子女税额扣除8岁以上基本扣除对象子女1人 每年25万韩元国税厅
子女税额扣除2人 每年55万韩元国税厅

这里容易被忽略的是年龄区间。子女税额扣除是以8岁以上为基准来说明的。也就是说，把它理解为婴幼儿期靠现金类支援、之后靠税额扣除的衔接结构会比较清楚。并不是「有孩子就当然有扣除」，而是适用的项目随年龄而不同。

  • 产后护理机构费用属于医疗费扣除对象这一点经常被漏掉。留好票据是最实在的做法
  • 年末结算的简化资料并不会自动收录全部医疗费。遗漏的项目需要自行提交票据
  • 生育与收养税额扣除只在当年度适用，因此必须在那一年的年末结算中申报
  • 医疗费税额扣除的扣除率与起扣要件、学龄前子女教育费扣除限额，本文未能核实。请向国税厅确认

7. 最容易错过的部分 - 申请制、期限、补发

这一节是本文的核心。顺序按过期之后无法挽回的程度排列。

  • 1. 期限内不用就失效的。医疗费支援这类以消费券形式发放的项目属于此类。即便已经完成申请，不使用就会消失。这是最该先写进日历的一项
  • 2. 申请之后才开始的。现金类支援大多如此。办了出生申报并不会自动跟上。提前列好在出生申报时一并处理的清单是最好的防守
  • 3. 状态变化就要申报的。开始或停止使用机构、搬家、更换账户都属此类。不申报就会领不到，或者领错之后还要退还
  • 4. 每年都要重新核对的。金额与年龄要件会变。去年不是对象，今年可能是; 反过来也一样
  • 5. 能否补发因项目而异。有的项目晚申请仍可部分追溯，有的则不行。「以后一次性领回来就行」是危险的假设，必须在申请窗口逐项确认
  • 6. 核实要看官方渠道，而不是别人的摘要。由于制度每年变动，搜索到的摘要随时可能是去年标准。没有标注日期的摘要不值得信赖

8. 地方政府支援 - 并不存在全国标准

与中央政府制度并行的，还有地方政府自行运营的支援。这里有一个必须点明的结构: 地方政府支援没有全国统一标准。项目、金额、申请窗口、资格要件都因地区而异。

因此本文不举任何特定地区的金额作为例子。一旦把某地的数字写下来，别处的读者读到就会误以为「我们这里也差不多」。那不是帮忙，是添乱。

  • 以户籍登记上的居住地为准核实。在市郡区政府网站上查找生育或养育栏目最为可靠
  • 也可以在福祉路指定地区后检索，在一个界面上同时浏览中央与地方的项目
  • 搬家时风险最高。原地区有的项目新地区可能没有，只有新地区才有的项目也可能被错过。办迁入申报时顺手通读一遍
  • 地方项目中可能有附带居住期间要件的情形。申请资格与期限要一并确认
  • 名称相似的支援，中央制度与地方制度也可能是两回事。不要只看名字就当作「已经在领的那个」而略过

9. 按时期排列的申请流程清单

把前面的内容按时点重新排列如下。把这份清单直接带到窗口，就是本文的用法。下面可复制的资料中也是同样的内容。

9.1 确认怀孕之后

  • 申请妊娠生育医疗费支援，并把使用起始日与截止日写进日历
  • 在申请阶段说明是否多胎、是否居住在分娩服务薄弱地区
  • 如果在职，向公司确认能否使用孕期缩短工时

9.2 预产期之前

  • 与公司理清产前产后休假与育儿休假的计划，并确认能否合并申请
  • 决定夫妻如何分配育儿休假。这与期限延长的要件直接相关
  • 向机构确认配偶陪产假的天数与申请期限

9.3 办理出生申报时 (最重要)

  • 把可与出生申报同时办理的项目一次性处理完
  • 申请儿童津贴与父母津贴
  • 在窗口确认初次见面类支援的适用与金额
  • 另行确认居住地方政府的生育相关项目

9.4 婴幼儿期及之后

  • 决定父母津贴按现金还是按消费券领取
  • 开始或停止使用机构时办理变更申报
  • 更换账户或搬家后更新支付信息
  • 年初核对当年的变化，年末结算时完整申报与子女相关的扣除

警告: 以下数字依据整理时点的官方资料。金额与年龄要件每年都会变化。

## 0. 五条原则

1. 韩国的育儿支援大多采用申请制。符合资格与实际领取是两回事。
2. 有期限。部分项目一旦过期便不再补发。
3. 金额与年龄门槛每年变动。不要背诵，而要定下查核的时点。
4. 中央政府的制度与地方政府的制度彼此独立。地方项目因地区而异。
5. 与其记住金额，不如记住何时该去核对什么，这样更耐用。

## 1. 按时期排列的申请清单

### 1-1. 确认怀孕之后

- [ ] 已申请健康保险的妊娠生育医疗费支援
- [ ] 在申请阶段已告知是否为多胎
- [ ] 已确认居住地是否属于分娩服务薄弱地区
- [ ] 已把使用起始日与终止日写在日历上 (期限内未使用的部分会失效)
- [ ] 因不同资料对终止日的表述不一致，已直接向公团核实
- [ ] 若在职，已向公司确认能否使用孕期缩短工时

### 1-2. 预产期之前

- [ ] 已与公司理清产前产后休假与育儿休假的使用计划
- [ ] 已确认如何把生育休假与育儿休假合并申请
- [ ] 已向机构确认配偶陪产假的天数与申请期限
- [ ] 已决定夫妻双方如何分配育儿休假 (与可用期限相关)
- [ ] 已确认雇佣保险参保期间等给付领取要件

### 1-3. 办理出生申报时 — 这是最关键的节点

- [ ] 已把可与出生申报一并办理的项目一次处理完毕
- [ ] 已申请儿童津贴
- [ ] 已申请父母津贴
- [ ] 已向机构确认初次见面消费券的适用与金额
- [ ] 已另行确认居住地方政府提供的生育相关支援项目
- [ ] 已记下每个项目的申请期限与补发规定

### 1-4. 出生后0个月至23个月

- [ ] 已决定父母津贴按现金领取还是按托育券领取
- [ ] 开始或停止使用托儿所时已申报支援方式的变更
- [ ] 已确认儿童津贴每月正常到账
- [ ] 更换账户或迁居后已更新支付信息

### 1-5. 满2岁至入学之前

- [ ] 已确认托儿所、幼儿园、居家养育三种情形下支援项目并不相同
- [ ] 已确认不使用机构期间所对应的支援项目
- [ ] 开始或退出机构时已提交变更申报
- [ ] 已确认育儿帮助服务的使用资格与自付标准

### 1-6. 每年都要重复的事

- [ ] 年初已查看当年制度有哪些变化
- [ ] 年末结算时已完整申报与子女相关的扣除项目
- [ ] 已核对医疗费记录在国税厅简化资料中没有遗漏
- [ ] 若已迁居，已重新确认新地方政府的支援项目
- [ ] 已确认随着子女年龄变化而新增或失效的项目

## 5. 五种常见的失误

1. 只办了出生申报，却没有另行申请儿童津贴或父母津贴
2. 医疗费消费券在期限内没用完而失效
3. 开始上托儿所却没有申报支援方式的变更
4. 迁居之后没有重新确认新地方政府的支援项目
5. 沿用去年的金额来安排今年的计划

本文档仅供参考，不构成法律、税务或行政方面的咨询意见。所有金额与要件均以整理时点的官方资料为准，之后可能变更。实际能否领取及领取金额，取决于收入、家庭构成、居住地、雇佣形态与申请时点。申请前务必向主管机构确认。

常见问题

韩国的育儿补助不申请也会自动发放吗?

大多数情况下不会。韩国与育儿相关的支援绝大多数采用申请制。办了出生申报并不意味着现金类补助会自动跟上。也有例外: 根据保健福祉部2026年4月23日的资料，儿童津贴扩大时，原本已在领取的家庭无需另行申请即获发放。但这是对已在领取者适用的例外。

2026年韩国的儿童津贴发放到几岁?

按同一份资料，2026年为未满9岁，此后每年上调一岁，到2030年扩大到未满13岁。金额按居住地区从首都圈每月10万韩元到人口减少地区特别区每月12万韩元不等。这些数字以整理时点为准，申请前请重新核对。

孩子上托儿所还能领韩国的父母津贴吗?

按保健福祉部的指引，这是在现金与消费券之间选择的结构，支援不会消失，只是形式改变。关键在于变更申报。开始或停止使用时不申报，可能导致金额偏差或日后的结算问题。具体处理请向福祉路或社区服务中心确认。

韩国的育儿休假津贴能领多少?

按雇佣劳动部自2025年1月1日起施行的标准，上限为第1至3个月每月250万韩元、第4至6个月每月200万韩元、第7个月起每月160万韩元，事后支付金已废止。这是上限额而非实发额。实际金额取决于通常工资与个人核算标准，另外还有雇佣保险方面的要件。

韩国地方政府的补助在哪里查?

户籍登记居住地的市郡区政府网站最为可靠，也可以在福祉路指定地区后检索。地方支援的项目与金额因地区而异，并不存在全国标准。搬家之后尤其容易漏掉，建议在办迁入申报时一并通读。
