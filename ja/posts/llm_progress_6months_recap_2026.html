序論: なぜ6ヶ月単位の整理が2026年に合う解像度なのか

6ヶ月前の2025年11月、LLMの風景は安定して見えました。GPT-4.5oが既定で、Claude 4.5 Sonnetが出たばかり、Gemini 2.0 Flashが低価格帯の働き者でした。市場は「スケーリング則が緩み、曲線が平坦化した」と語っていました。その後の6ヶ月で、その段落のほぼすべての前提が崩れています。11月から5月までのウィンドウは初代GPT-4以降で最も忙しいLLMリリースサイクルであり、その速度はAIフルタイムビルダーですら追いつけないほどでした。周囲のシニア開発者と話すと、スタックには2025年の前提がまだ刺さっており、利用可能な品質・コスト・速度の30〜50%を静かに失っているケースが大半です。

本稿は筆者が自分の作業のためにまとめた6ヶ月レビューです。主要ラボとオープンウェイトファミリーを漏れなく回し、変化をマトリクスと表で圧縮し、最後に5つの具体的な実務示唆とH2 2026展望で締めます。構造は意図的です。企業別 → トレンド → ベンチマーク → アドバイス。マトリクスだけ要るなら大きな表2つを見てください。背景まで知りたければ通読をどうぞ。本文はどのラボのマーケトーンでもなく、筆者が実際に回した感覚に基づいて書きました。

本格的な整理の前に3つのフレームを置きます。第一に、モデル番号は進歩の測定単位ではありません。あるラボの「0.1」は別ラボの「2.0」より大きい跳躍であり得ます。本稿は「実際に何が変わったか」を中心に据えます。第二に、クローズドとオープンウェイトの進歩曲線は今や並行して走っています。一部の軸では差が数週単位に縮まっています。第三に、最も決定的な変化は単一モデルのリリースではなく、周辺スタックです。エージェントハーネス、コーディングエージェント、メモリプリミティブ、そして事実上の標準として定着したModel Context Protocolがそれです。本文全体でこの点に繰り返し戻ります。

OpenAI: GPT-5、Codex Goals、Operatorトラック

OpenAIのH1 2026は2つの大きな動きに集約されます。第一は1月末のGPT-5リリースです。これまでoシリーズに分かれていた推論トラックを統合し、「推論モデル別トグル」構造ではなく1つの製品の中で適応的に思考予算を自動配分する形になりました。この単純化だけで、開発者から見て巨大な混乱が消えました。第二は2月末から4月にかけて段階的に解放されたCodex Goalsです。Codexサブ製品を単純なチャット補完から、「高レベル目標を受け取ってリポジトリ上で数時間作業する」自律コーディングエージェントに近いものへ変貌させました。

静かな変化が現場ではより効きます。3月のOperatorスタックの一般公開でコンピュータ使用APIが安定し、壊れたページ状態からの復帰力が目に見えて向上しました。Realtime APIにネイティブのツール使用が追加され、音声ワークフローでのAnthropicとの差が縮みました。メモリ永続性は実験機能から、明示的な保存・取得・忘却プリミティブを持つドキュメント化された表面へ昇格し、「アシスタントがセッションを越えて私を覚えている」を作るのが1四半期プロジェクトから1週間プロジェクトに変わりました。これらは報道サイクルを支配しませんでしたが、実際の本番スタックはこの上に建っています。

価格面ではGPT-5が2025年後半のGPT-4.5o比で入力はほぼ据え置き、出力はキャッシュ窓延長で意味のある安値で出ました。4oファミリーはQ3 2026に終わる予定で段階的に廃止されており、まだ4oに留まっているチームは今のうちに移行ウィンドウを取るべきです。Codex Goalsの変化自体と日常ループへの組み込み方は、本ブログのOpenAI Codex Goals実践ガイド 2026でより深く扱っています。

Anthropic: Claude 4.5、4.6、4.7とClaude Codeの年

Anthropicは6ヶ月で意味のある3回のリリースを行いました。2025年12月末のClaude 4.6はツール使用を精緻化し、長文書処理にネイティブ対応を加えました。2026年3月のClaude 4.7 Sonnetはコンピュータ使用を既定製品に組み込み、コーディングベンチマークを他モデルとの差を作りつつ押し上げました。2026年5月のClaude 4.7 Opusはエージェントと長コンテキストの大半のタスクで現状のフロンティアモデルであり、筆者もマルチ時間の自律コーディングセッションではこれを既定で使っています。各リリースは名前上は漸進的ですが、累積として「エージェントを2時間放っておいて信頼できるか」のカテゴリーでAnthropicの差を広げました。

モデル周辺でClaude Codeは完成された製品に進化しました。Skills、Hooks、Sub-agents、安定したsettings.jsonスキーマがCLIをパワーユーザーのおもちゃから、チームがコードベース全体に展開するツールに変えました。2024年後半にAnthropicが始めたModel Context ProtocolはH1 2026に事実上の業界標準になり、OpenAI、Google、主要IDEベンダーの大半がMCPをネイティブサポートします。これは本期間で最も意味のある単一の標準シフトです。プロトコルレイヤを静かに押さえることで、Anthropicはどのモデルを呼ぶかに関係なく開発者ツールスタックの中心に陣取りました。

Anthropicのもう1つの話題は人事面です。2月のAndrej KarpathyのAnthropic合流はその年最も話題になったAIの採用でした。長期的な研究インパクトとは別に、シニア研究者の引き寄せ力に与えた短期効果は即座で可視的でした。Claude Code自体の日常活用についてはClaude Code Skills完全ガイドで、4.6と4.7の移行後にも生き残ったパターンを扱っています。

Google: Gemini 3.0、3.5 Flashと価格戦争

GoogleのH1 2026戦略はピーク品質より価格対性能での急進的な圧力でした。12月のGemini 2.5は2.0比の静かな品質向上でした。2月のGemini 3.0はGoogleを再びフロンティアの議論の中心に置いた最初のリリースで、強力なマルチモーダル性能と実用的な200万トークンのコンテキストウィンドウを提供しました。しかし期間のヘッドラインは4月のGemini 3.5 Flashでした。2.0 Flash比で出力コストを約60%カットしつつ品質も十分に上げ、高ボリューム低関与トラフィックには明らかな既定値になりました。

Google検索のAI Overviewsは「良いアイデアかどうかを議論する段階」から「10億人以上が検索する仕方の恒久的な既定要素」へと位置を移しました。これはモデル自体を超えた含意があります。AIが生成した回答がユーザーと大半のオープンウェブの間に挟まるレイヤになり、2026年のコンテンツ戦略はこのレイヤを先に狙って書かれなければなりません。Googleの開発者表面では5月中旬のI/O 2026発表がGeminiのWorkspace、Android、新Code Assistエージェント階層への統合を予告しました。個別では衝撃的ではありませんが、累積効果はGoogleが再び既定の選択肢に戻ったということです。

価格ポイントは重い自動化を回すチームに最も重要です。LLMを月100万回以上呼ぶ何かを作っているなら、トラフィック下位70%では算盤がGemini側に傾きました。フロンティアモデルはマージン品質差がコストを正当化する上位30%にだけ残してください。この2層パターンが真剣なLLM製品の既定アーキテクチャになり、トレンド節で再び触れます。

Meta: Llama 4シリーズとオープン戦略のスケール化

MetaのH1 2026はLlama 4ファミリーでした。12月から4月にわたるLlama 4 7B、30B、200Bのリリースは個別にはフロンティアを揺らしませんでしたが、一貫したドロップとしてオープンウェイトを3つの軸で意味ある程度に押し上げました。より長いコンテキスト(256Kまで安定)、30Bサイズでクローズドと同等のツール使用、そして200Bで多くのタスクについてClaude 4.5 Sonnetと同じ話題に入れる品質向上。Metaはまた、これまでのLlama 3.x条項では満足できなかったエンタープライズの法務をより多く満足させる明確なライセンス体系を開きました。

Metaがやらなかったことも重要です。500B以上の規模で正面からフロンティアクローズドモデルを狙うLlama 4リリースはなく、2026年初の公開メッセージで会社はこれを無能ではなく意図的な戦略選択と位置付けました。「共通サイズで十分に良い」オープンウェイトと自家ホスティングコストの低下が組み合わされば、絶対フロンティアを追うよりはるかに大きな推論ワークロードのシェアを最終的に取れるという賭けです。その賭けが効くかは6ヶ月の問題でなく6四半期の問題ですが、エンタープライズの自家ホスティング配備の初期信号は良好です。

実務者の観点で行動可能な教訓はLlama 4 30Bが知っておくべきサイズということです。単一H100またはBlackwell B200で本番速度で楽に動き、ツール使用をうまくこなし、ベンダーロックインなしでホスト型APIクラスの体験を与えます。vLLM 0.7のバッチング改善と組み合わせれば、自家ホスティングLlama 4 30Bのトークン単価は純粋推論でGemini 3.5 Flashと競合する水準で、スタックを自分で持つ戦略価値は別途です。

中国ビッグ3: DeepSeek、Qwen、Doubao

H1 2026の中国の物語は外部観察者にとって最も驚くべきものです。2025年11月末のDeepSeek V3が既に強く、2026年2月のV4はフロンティアクローズドモデルと本当に競合します。671B MoE構造はトークンあたり約37Bパラメータを活性化させ、推論コストを合理的に保ちつつタスク単位で最上位に品質を押し上げました。オープンウェイト、MITスタイルライセンス、そして訓練レシピを珍しく詳細に文書化した論文のおかげで、DeepSeek V4はQ1 2026最多に配備された単一オープンモデルとなりました。

Alibabaの2026年3月Qwen 3ファミリーはコーディングを直撃しました。Qwen 3 Coder 32Bバリアントは筆者の自前ベンチマークで現存最強の小型オープンコーダーです。汎用Qwen 3 235Bとともに、Alibabaはグローバルで最多のオープンウェイト推論をサーブする主体になったとの推計もあります。ByteDanceの2026年4月Doubao 1.6は中国外では知名度が低いですが、ネイティブのクロスモーダル能力とTikTok統合を持って出荷され、中国語圏市場で重要です。これらのモデルを使うかどうかはデータ扱いの立場に大きく依存しますが、存在しないふりはもはや守れる立場ではありません。全体地形は本ブログのDeepSeek vs Qwen vs Doubao 中国LLM比較 2026で扱っています。

技術的な余談として、最近のDeepSeek V4のステアリングベクトル研究は小さくとも意味のある解釈可能性の扉を開き、外部チームがコーディング評価で再現可能な振る舞いシフトを示しています。これは半期の興味深い研究話題の1つで、LLMステアリングベクトルとDeepSeek V4で実務的含意を扱っています。

xAI: Grok 3からGrok 4へ、アンダードッグ叙事

xAIは静かにミームから抜け出しました。2025年11月末のGrok 3は推論ベンチマークで初めてフロンティア圏に入った版であり、2026年4月のGrok 4は残った差を縮めました。依然として主にXとスタンドアロンの消費者向けアプリで配布されており、その配布ギャップが開発者の既定選択肢になることを妨げています。しかし技術的な仕事は本物です。会社の訓練クラスタColossusはマイクロソフト・OpenAI級の新規ディールなしでは競合がマッチしづらい規模に拡張され、そのハードウェアベースが今やモデルに反映されています。

実務者の観点でGrok 4は自前の取得レイヤを作らずにリアルタイムのウェブグラウンディングが要るときに意外に強い選択肢で、バックアップモデルとして有効です。価格は中位帯、APIは安定しました。制約は主に文化的なものです。多くのエンタープライズが調達上の理由でいまだにxAIをXに近すぎるとして扱い、その認識変化は基盤技術の位置が正当化するより遅いです。スタックが既にプロバイダー間でロードバランスするルーターを呼んでいるなら、Grok 4をオプションに加えるのは数時間で、次のプロバイダー障害に対する測定可能なレジリエンスを得ます。

Mistral、Cohereと2層の統合

2層のフロンティアラボはH1 2026に本物の統合を経ました。1月のMistral Large 3はEU居住インフラとUSラボがいまだに難儀するやり方で規制を満足させるライセンス条件で、Mistralの最強の欧州フロンティア選択肢としての位置を再確認しました。Mistralのより小さなオープンリリース(Codestral 2、Pixtral 2)は開発者認知を維持させました。CohereのCommand R-Plus 2026アップデートはエンタープライズRAGワークフローに二重に集中し、グラウンデッド検索タスクではヘッドラインフロンティアモデルを上回り続けています。

2025年末まで対話にあったいくつかの小さな主体は実質的に退きました。AI21のJambaファミリーはもう非常に長いコンテキストだけが必要なニッチ選択肢です。Inflectionはフロンティア消費者向けモデルから完全にピボットしました。Rekaほか数社は技術的に興味深い仕事を出し続けていますが、誰もが気にするベンチマークの上位ではもう競っていません。市場はグローバルに真剣なLLMプロバイダー約7社へと統合されています。OpenAI、Anthropic、Google、Meta(オープン)、DeepSeek、Alibaba/Qwen、xAI。MistralとCohereは強い地域・垂直オプションとして残ります。2024年末の12社以上から意味ある程度に絞り込まれた格好です。

ローカルLLM: Llama.cpp、Ollama、vLLM、MLX

ローカルと自家ホスティングの生態系は速く動きました。Llama.cppが安定したVulkanとROCm経路を追加し、1年前まで真だったNVIDIA専用の前提が崩れました。Strix Halo PC(AMDの高メモリAPUノートプラットフォーム)で70Bモデルを実用速度で動かすことがQ1 2026に本物の製品カテゴリになりました。Ollamaが主流の開発者ツールに進入し、安定したモデルレジストリ、予測可能な更新チャネル、VS CodeとJetBrains IDEとの密な統合を備えました。vLLM 0.7と0.8はページドアテンションv3と投機的デコーディングの改善で本番配備の推論コストを削減しました。AppleのMLX 0.20リリースはM系列Macを30B〜70Bパラメータ帯のメモリ対価格最強のローカル推論オプションにし、M5 Max機は今日Llama 4 30BとQwen 3 32Bを妥協なくホストするに十分な統合メモリで出荷されます。

組み合わせ効果は低関与LLMトラフィックの実質シェアがAPIから離れていることです。個人ノートアシスタント、IDEのオートコンプリート、社内文書の要約。データ感度、レイテンシ、コストが絶対フロンティアより重要なすべての作業がローカル推論へ移住中です。ハードウェア全体地形は本ブログのローカルLLMハードウェア選択ガイド 2026がこのトレンドに対し四半期ごとに更新されます。

AIコーディングツール: Cursor、Claude Code、Codex、Aider、Cline

AIコーディングツールは半期で最も速く動いたサブカテゴリでした。Cursorのエージェントモードが11月と12月でマルチファイルリファクタリングを安定処理する何かに成熟し、競合激化のなかでも価格を維持しました。Claude Codeは本格的な自律コーディングワークフローの支配的CLIツールになりました。30分以上かかるタスクを回すなら、Claude 4.7 Opus経由のClaude Codeが現状の既定です。OpenAI Codexサブ製品のCodex Goalsは最強のワンショット生成表面です。モデルの出力を見て素早く調整するタイトな反復ループでは勝ちにくい。

Aiderはオープンソースのベースラインとして強さを維持し、ClineはIDEを離れずインエディタ体験を望む開発者向けにVS Code統合エージェントのニッチを埋めました。3ヶ月混ぜて使った正直な評価はどの単一ツールもすべてのワークフローを支配しないです。インエディタのペアプログラミングはCursor、長い自律タスクはClaude Code、ワンショット生成はCodex、完全検査が要るときはAiderをオープンフォールバックに。3ヶ月比較は本ブログのClaude Code vs Codex 3ヶ月レビュー 2026でローテーションパターンを詳細に扱っています。

6ヶ月の核心トレンド

個別ラボから一歩引くと、4つのトレンドがこの期間を定義します。

エージェントAIがデモから本番へ移りました。半期中のすべてのフロンティアモデルリリースの定義的特徴はより長く、より安定した自律チェーンでした。Claude 4.7 Opusで2時間の自律コーディングセッションが現実的になり、GPT-5とGemini 3.0でモデルが自分で計画を提案・ブラウジング・要約・反復するマルチステップ研究が動きます。残った失敗モードは本物ですが本番使用を妨げません。

推論モデルが別製品カテゴリから消えました。oシリーズはGPT-5の適応的思考予算の一部になり、Claudeの拡張思考は既定オン、Gemini 3.0は内部チェーンを透過的に使います。過去1年ユーザーを混乱させた「思考モデル」トグルはほぼ消え、その単純化自体が品質改善です。

マルチモーダルが標準装備になりました。ビジョンはすべてのフロンティアモデルで動き、音声入出力は標準、ビデオ理解は上位3ラボ全般で有能です。差別化要素はもう「マルチモーダルがあるか」ではなく「マルチモーダル入力とツール使用をどれだけ良く編むか」です。

30B級で「より小さくてより良い」が本物です。半期で配備頻度ベースの単一最大の受益は30Bパラメータ帯です。Qwen 3 32B Coder、Llama 4 30B、より小さなDeepSeek蒸留がすべてこの範囲にあり、実際にフロンティアIQが要らないタスクの70〜80%を処理します。

ベンチマークの変化: MMLU飽和、SWE-bench急増

ベンチマーク地形も実質的に変わりました。MMLUは事実上飽和し、すべてのフロンティアモデルが88〜91の間にあり、ベンチマーク自体のノイズフロアもその範囲です。SWE-benchは6ヶ月で上位スコアが約2倍に跳ね、2025年11月の49%から2026年5月のVerified部分90%超まで上昇したのが本期間最も決定的な単一ベンチマークシフトです。GPQAの上位スコアは60台前半から70台後半に移動しました。ARC-AGI v2は依然として現存最難の公開ベンチマークで、今やラボが最も可視的に競う場所です。

ベンチマークを読むエンジニアへの教訓はSWE-benchが今や「このモデルはコーディングに良いか」を問う最も有用な単一の数字であり、MMLU性能と実世界の有用性の差が過去のどの時点よりも広いということです。あるモデルがMMLUで90を取りつつClaude 4.7が単一パスで処理する本番デバッグで失敗することがあります。ベンチマーク数値は常に自分のワークロードに対するタスク別評価とともに見るべきです。

価格表から最も重要な1つの示唆は低価格ティアが十分に安くなって、大半の製品に正しいアーキテクチャは今や2モデルになったことです。Flashクラスが呼び出しの60〜80%を処理し、難しい呼び出しにだけフロンティアモデルを予約します。単一フロンティアモデルにすべてをルーティングするスタックなら、必要コストの3〜5倍を払っている可能性が高いです。

開発者が内在化すべき5つの示唆

6ヶ月の絵から圧縮された助言です。

  1. コーディングツールを最低2つローテーションしてください。Claude Code + Codex、またはClaude Code + Cursorが最もレジリエントなパターンです。失敗モードが違い、1つのプロバイダーが障害でも作業が続きます。
  2. 2層ルーティングレイヤを立ててください。トラフィックの60〜80%をGemini 3.5 FlashまたはClaude Haikuクラスに送り、本当に必要な呼び出しにだけフロンティアモデルを予約します。コスト削減は1週間でエンジニアリング費を回収します。
  3. モデルを1つはローカルで回してみてください。M系列MacまたはBlackwellカードを刺したワークステーションで30Bモデルはオフライン作業、機微データをカバーし、「このタスクはAPIなしで可能か」の基準を与えます。ローカル経験のないビルダーは質問の仕方で次第に見分けられます。
  4. MCPを既定として扱ってください。Model Context Protocolは新しい「AIのためのREST」です。ChatGPT、Claude、Geminiにそれぞれ独自統合を作るのはもう浪費です。MCPサーバ1つが3つすべてにつながります。
  5. ベンチマークを四半期ごとに再評価してください。11月にあなたの評価で勝ったモデルは今日2層の可能性が高いです。最低四半期ごとに評価スイートを回し、目を開けたまま新しい既定を選んでください。

2026年下半期の展望

予測は難しく、大半の予言は早く色あせますが、過去6ヶ月の軌跡は合理的な確信で3つを呼べます。

第一に、エージェントシステムがパワーユーザーの既定UIになります。UI進化はチャットボットが2023年に経たものと同じです。Q1で実験的、Q4で主流。年末までにすべての主要ラボがオプトインベータではなく既定製品の一部としてエージェント表面を出すと予想します。

第二に、モデル差別化の軸が純粋IQからメモリ、ツール使用、タスク単価へ移ります。クローズドモデルの純粋ベンチマーク競争は平坦化しており、競争は周辺スタックへ移ります。メモリを最初にうまく解くラボ(不気味でなく有用と感じる仕方でセッションを越えて覚える)が消費者マインドシェアの意味あるシェアを取る可能性が高いです。

第三に、オンデバイスとラップトップクラスの推論が低関与トラフィックの大きなシェアを静かに取ります。M系列MacとStrix Halo PCが30〜70Bモデルを実用速度で回すことで、消費者使用の相当部分がAPIから完全に離脱します。低価格ティアAPI収益には悪く、ユーザープライバシーには非常に良い。

H2 2026のロードマップを立てるなら、この3つのために作ってください。「次のモデルを待とう」の罠を避けてください。必要な能力はすでに今日回せるスタックに入っています。

結論: 6ヶ月の構造的シフト

11月から5月までのウィンドウはもう1つのアップグレードサイクルではありませんでした。エージェントシステムが本物になった時点、オープンウェイトが意味ある軸でフロンティアの差を縮めた時点、価格がアーキテクチャパターンを変えるほど落ちた時点、そしてMCPが今後2年のツールが建てられる標準レイヤとしてロックインされた時点でした。そのいずれか1つでも平年1年分の進歩です。4つが同時に起こったことが本期間を構造的シフトにします。

ビルダーの実用的姿勢はサイクル初期から変わりません。ツールに近くいて、最低2つをローテーションし、四半期ごとにスタックを評価し、完璧な既定が出てくるのを待つ誘惑に抵抗してください。フロンティアはそれが可能なほどゆっくりは動きません。あなたの競争優位は使えるピースを本物の問題を解く何かにどれだけ速く組み合わせるかにあり、どのラボのロゴがAPI呼び出しに刻まれているかにはありません。マトリクスを読み、算盤を回し、次のものを出荷してください。
