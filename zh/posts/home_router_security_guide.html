家用路由器安全完全指南 — 设置·检查·防止黑客攻击

WPA3·密码·固件·IoT隔离实用检查清单 — 2026年6月基准

2026年6月24日 IT/技术

前言：家中最脆弱的设备——路由器

家中所有的互联网流量都要经过一台路由器。电脑、手机、电视、冰箱、IP摄像头——路由器一旦被攻破，家里所有设备都将面临风险。然而，大多数家庭的路由器自安装后从未更改过设置，默认管理员密码、过时固件、脆弱的加密方式一直保持原样。

2026年，利用这一现状的攻击日益自动化。Mirai僵尸网络变种每秒扫描数百万个互联网IP地址，寻找仍使用出厂密码的路由器，一旦登录成功便立即植入恶意软件并将其纳入僵尸网络。2026年4月，有报告指出多个新型Mirai变种利用已知旧漏洞同时攻击路由器和DVR设备。华硕紧急修补了AiCloud路由器的严重认证绕过漏洞（CVE-2025-59366，CVSS 9.2），TP-Link修复了允许未经授权上传固件的漏洞（CVE-2025-15517，CVSS 8.6）。

本指南基于美国网络安全机构CISA的官方建议和最新安全研究，以普通用户可自行操作的实用检查清单为核心。内容以2026年6月为基准，不涉及攻击他人设备的任何方法，目的是帮助用户自主保护自己的路由器。

1. 家用路由器面临的主要安全威胁

1.1 默认密码——最常见的入侵途径

路由器厂商出厂时设置的默认管理员账号（如 admin / admin）在互联网上已公开。Mirai正是利用这一点，数十万台僵尸机器自动扫描整个互联网的IP段，尝试使用默认密码登录，一旦成功便立即植入恶意软件并将其加入僵尸网络。2025年，Juniper的Session Smart Router因未更改默认密码而遭Mirai感染，并被用于DDoS攻击。

1.2 固件漏洞——持续发现的严重缺陷

路由器软件（固件）每年都会发现大量安全漏洞。仅2025至2026年，华硕、TP-Link、NETGEAR、D-Link等主要厂商就接连公开了认证绕过、远程代码执行、命令注入等高危漏洞。问题在于，许多用户从不更新固件，长期暴露在已知漏洞威胁之下。已停止支持的停产型号更为严重——即便发现漏洞也不会有补丁。

1.3 僵尸网络感染——你的路由器成为DDoS武器

路由器被纳入僵尸网络后，用户通常毫无察觉。网速略微变慢可能是唯一的表现。但在内部，路由器正在向其他网站或服务器发动大规模流量攻击。2016年Mirai首次出现时，利用默认密码感染了数十万台IoT设备，发动了当时规模最大的DDoS攻击。此后，变种不断涌现。

1.4 中间人攻击与DNS劫持

攻击者控制路由器后，可修改DNS查询，将用户引导至与真实网银或购物网站外观相同的钓鱼网站。WPA2的KRACK漏洞允许攻击者在不知道密码的情况下拦截Wi-Fi通信。开放远程管理端口则为攻击者提供了直接访问路由器管理界面的通道。

2. 立即需要更改的7项必备设置

2.1 更改管理员密码

登录路由器管理页面（通常为 192.168.0.1 或 192.168.1.1），立即更改管理员密码。强密码标准如下：

  • 至少12位，混合大小写字母、数字和特殊符号
  • 不得与其他账号密码相同
  • 使用密码管理器保存
  • 如有可能，同时修改默认管理员用户名
注意：路由器标签或说明书上印着的默认密码，黑客也知道。切勿继续使用。

2.2 将Wi-Fi加密设置为WPA3（或WPA2）

在路由器的无线设置中检查安全协议。WPA3 Personal是目前最安全的选项。WPA3采用SAE认证方式，从结构上阻断离线字典攻击，并提供前向保密性——每个会话使用独立的加密密钥。

如有旧设备不支持WPA3，可选择WPA3/WPA2混合模式。绝对避免使用WEP和WPA（TKIP）。

协议安全性建议
WPA3 Personal非常高首选推荐
WPA3/WPA2混合高有旧设备时的选择
WPA2（AES/CCMP）一般配合强密码使用
WPA（TKIP）低禁止使用
WEP极低立即更换

2.3 SSID不要泄露个人信息或型号

Wi-Fi网络名称（SSID）中不要包含个人姓名、住址或路由器型号。像 Zhang_TP-Link_2025 这样的名称会直接告诉攻击者厂商信息和可利用的漏洞。建议使用难以识别个人身份的中性名称。隐藏SSID的安全效果微乎其微，不推荐。

2.4 禁用远程管理

远程管理功能允许从互联网任何地方访问路由器管理页面，但攻击者也能通过同样的路径入侵。CISA明确建议禁用此功能。如果确实需要远程访问，请使用VPN替代。

2.5 禁用WPS

WPS（Wi-Fi保护设置）通过按钮或PIN轻松连接设备，但PIN方式存在已知的暴力破解漏洞。建议禁用WPS，通过直接输入密码的方式连接新设备。

2.6 禁用UPnP

UPnP（通用即插即用）允许设备自动在路由器上开放端口。虽然方便，但恶意软件可能滥用此功能悄悄开放对外访问的端口。禁用UPnP对日常使用影响不大，却能消除一个真实的攻击面。

2.7 将固件更新至最新版本

在路由器管理页面找到固件更新菜单，定期检查并应用最新版本——建议每月一次。如路由器支持自动更新，请开启。已停止安全支持的停产型号，应考虑更换。

提示：路由器管理页面的地址通常印在设备背面的贴纸上。在Windows命令提示符中输入 ipconfig，查找"默认网关"地址即可。

3. 访客网络与IoT设备隔离

3.1 为什么必须使用访客网络

大多数现代路由器支持访客Wi-Fi功能，应积极利用。将主网络密码告知访客后，访客设备可能访问家中电脑、NAS、打印机等内部设备。访客网络仅提供互联网访问，阻断内部网络访问，从而解决这一问题。

3.2 IoT设备应隔离至访客网络或专用SSID

智能电视、智能音箱、IP摄像头、智能家电等IoT设备的安全更新往往不规律，厂商也可能提前终止支持。若这些设备与主网络共用，一旦某台设备被攻破，攻击者就能以此渗透电脑和手机。解决方案很简单：创建IoT专用访客网络，将所有智能设备迁移至此，并启用「客户端隔离」选项，防止IoT设备之间相互通信。

3.3 理想的家庭网络分段结构

网络连接设备安全设置
主Wi-Fi电脑、手机、平板、笔记本WPA3，强密码
IoT访客网络智能电视、音箱、摄像头、家电启用客户端隔离
访客专用网络来访者设备阻断内部网络访问

4. 入侵迹象排查 — 如何判断路由器是否被黑

4.1 出现这些迹象时需警惕

路由器被攻破通常悄无声息，但若以下多个迹象同时出现，需立即排查。

  • 管理员密码突然失效 — 攻击者可能已更改密码将你锁在外面
  • 网速突然大幅下降 — 路由器带宽被僵尸网络活动消耗时会出现
  • 连接设备列表中出现陌生设备 — 在管理页面查看设备列表，检查陌生的MAC地址或设备名
  • 浏览器自动跳转至陌生网站 — DNS劫持的典型症状
  • DNS设置被更改 — 在管理页面直接核对DNS地址
  • 防火墙被禁用或出现从未设置的端口转发规则 — 明显的异常信号

4.2 怀疑被入侵时应采取的措施

  1. 访问路由器管理页面，检查连接设备列表和DNS设置
  2. 若无法登录，执行恢复出厂设置（按住重置按钮10秒以上）
  3. 重置后，从头开始应用本指南的所有安全设置
  4. 先从厂商官网下载并安装最新固件
  5. 更新所有已连接设备的Wi-Fi密码

4.3 养成每月定期检查的习惯

建议每月花5分钟登录路由器管理页面，检查以下内容：连接设备列表中是否有陌生设备、是否有固件更新、DNS设置是否被更改、是否有自己未设置的端口转发规则。

5. 实用安全检查清单

5.1 今天立即执行（30分钟内可完成）

  • 登录路由器管理页面，将管理员密码改为强密码
  • 确认Wi-Fi加密方式为WPA3或WPA2（AES）
  • 将Wi-Fi密码更换为12位以上的强密码
  • 确认远程管理功能已禁用
  • 禁用WPS功能
  • 检查并应用最新固件更新

5.2 本周内完成

  • 创建并启用访客网络
  • 将智能电视、音箱等IoT设备迁移至IoT访客网络
  • 在访客/IoT网络中启用客户端隔离选项
  • 禁用UPnP

5.3 每月定期检查

  • 检查连接设备列表，确认无陌生设备
  • 检查固件是否为最新版本
  • 确认DNS设置未被更改
  • 检查端口转发规则中是否有未知条目
  • 查阅厂商安全公告

6. 常见问题解答（FAQ）

问：路由器管理员密码和Wi-Fi密码是同一个吗？

不是。管理员密码用于登录路由器设置页面（如192.168.x.x）；Wi-Fi密码是设备连接无线网络时输入的密码。两者都需要设置强密码，且应使用不同的值。

问：隐藏SSID能提高安全性吗？

不能。即使隐藏SSID，攻击者也能用简单工具检测到。而且，试图连接隐藏SSID的设备会主动广播该SSID名称，可能增加位置追踪风险。不如专注于强密码和WPA3加密，效果更为实际。

问：什么时候应该更换路由器？

如果厂商不再为该型号提供安全更新（停产/停服），就应考虑更换。一般来说，使用超过5年的路由器可能已不支持WPA3、安全补丁已停止、性能也有所下降。可在厂商官网查询所用型号的支持截止日期。

问：ISP提供的路由器和自购路由器哪个更好？

ISP提供的路由器固件更新往往不定期，安全控制功能也有限。从安全意识较强的厂商自行购买的路由器，通常在固件更新频率、WPA3支持、访客网络控制和客户端隔离等方面更具优势。若使用ISP路由器，也应按本指南完整配置安全设置。
