Cephストレージのバケット監視自動化スクリプトを構築する

Enterprise Storage Monitoring with Slack Integration

2025-06-29 ストレージ

現代のITインフラにおいて、ストレージ監視は欠かせない運用要素です。特にCephのような分散ストレージシステムでは、バケットごとの容量やオブジェクト数をリアルタイムに追跡し、キャパシティプランニングとパフォーマンス最適化を行う必要があります。

本記事では、Ceph Object Storageの特定バケットを監視し、変化の推移を分析してSlackへ通知を送る自動化スクリプトの構築方法を詳しく見ていきます。

📋 システム要件

スクリプトを実行するには、以下のような環境を整える必要があります。

  • Ceph Cluster: radosgw-adminコマンドへのアクセス可能
  • jq: JSONパース用ツール
  • curl: HTTPリクエスト送信
  • Slack Webhook URL: 通知チャンネルの設定

2. バケット情報の収集

# バケットの容量とオブジェクト数を取得
BUCKET_INFO=$(radosgw-admin bucket stats --bucket=${BUCKET_NAME})

BUCKET_SIZE=$(echo "$BUCKET_INFO" | jq -r '.usage."rgw.main".size')
BUCKET_NUM_OBJECTS=$(echo "$BUCKET_INFO" | jq -r '.usage."rgw.main".num_objects')

💡 Pro Tip

radosgw-adminコマンドはCeph Object Gatewayの管理ツールで、バケットの詳細な統計情報をJSON形式で提供します。jqを使って必要なフィールドだけを抽出できます。

3. データフォーマット関数

# 人間が読みやすい単位に変換
function human_readable_size() {
  local size=$1

  if ! [[ "$size" =~ ^[0-9]+$ ]]; then
    echo "0 Bytes"
    return
  fi

  local result=$(awk -v size="$size" '
  BEGIN {
    units[0] = "Bytes"; units[1] = "KB"; units[2] = "MB"
    units[3] = "GB"; units[4] = "TB"; units[5] = "PB"

    i = 0
    while (size >= 1000 && i < 5) {
      size = size / 1000
      i++
    }

    if (i == 0) {
      printf "%.0f %s", size, units[i]
    } else {
      printf "%.2f %s", size, units[i]
    }
  }')

  echo "$result"
}

4. 変化量の計算

# 統計計算関数
function calculate_change() {
  local current=$1
  local previous=$2

  if ! [[ "$current" =~ ^[0-9]+$ ]] || ! [[ "$previous" =~ ^[0-9]+$ ]] || [ "$previous" -eq 0 ]; then
    echo "N/A"
    return
  fi

  local change=$((current - previous))
  local percentage=$(awk -v curr="$current" -v prev="$previous" 'BEGIN { printf "%.2f", ((curr - prev) / prev) * 100 }')

  if [ "$change" -gt 0 ]; then
    echo "+$(add_commas $change) (+${percentage}%)"
  elif [ "$change" -lt 0 ]; then
    echo "$(add_commas $change) (${percentage}%)"
  else
    echo "変化なし (0%)"
  fi
}

  • 数値にカンマを追加して可読性を向上

# 統計情報の追加
if [ -n "$SIZE_CHANGE" ] && [ -n "$OBJECTS_CHANGE" ]; then
    MESSAGE_TEXT="${MESSAGE_TEXT}

========== 前回との比較 ==========
- 前回計測: ${PREV_TIME}
- 容量変化: ${SIZE_CHANGE}
- オブジェクト変化: ${OBJECTS_CHANGE}"
fi

# JSON payload生成

  \"text\": \"\`\`\`${MESSAGE_TEXT_ESCAPED}\`\`\`\"
