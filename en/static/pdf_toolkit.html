🔒 Why this is safe

Most online PDF services upload your file to a server, do the work there and send the result back. That is convenient, but it is a different story for a contract, a scanned ID or a payslip. This tool removes that step entirely.

  • Files are read with the File API only. The browser loads them into memory and never posts them to an address.
  • The result is built here too. The merged PDF is assembled by the JavaScript on this page, and the download link points at a temporary in-memory address.
  • The only network traffic is the program itself. Apart from fetching the PDF library once when the page opens, nothing related to your document is transmitted.
  • Closing the tab wipes everything. Nothing is kept on a server, and nothing is written to browser storage.

Want to verify it yourself? Open the Network tab in your browser developer tools (F12) and run a merge. Not a single request carrying your file appears.

How each tool works and how output is named
  • Merge — add several PDF files, set the order with the arrows and press Merge. The result is saved as merged.pdf.
  • Split — type a range such as 「1-3,5,8-10」 or click pages in the preview. One PDF gives you pages_1-3,5,8-10.pdf, single pages give you filename_p1.pdf and so on.
  • Edit pages — select pages, apply rotation or deletion, and use ◀ ▶ on each page to change the order. The result is filename_edited.pdf.
  • Image → PDF — add photos in order and pick page size, orientation and margin. The result is images.pdf.
Limitations worth knowing
  • Password protected PDF files will not open. A document with an open password or a permissions password is encrypted at the structure level and cannot be read. Remove the password in the original application first.
  • Bookmarks, annotations, forms and signatures may be dropped. Pages are copied into a brand new document, so information attached at document level does not follow. Editing a signed document breaks the signature.
  • Large files depend on your device. A warning appears above 50 MB in total. All work happens on this machine, so a shortage of memory can slow the tab down.
  • Only the first pages are drawn as thumbnails. For very long documents the first 200 pages are rendered and the rest are shown as page numbers. Extraction and editing still cover every page.
  • No OCR and no compression. This tool focuses on rearranging pages; it does not read text out of scans or shrink file size.
Keep the original of anything important. The tool never modifies your source file and always writes a new one, but it is still wise to hold on to the original until you have checked the result. A browser extension or ad blocker that blocks the processing library will stop the tool from working.
