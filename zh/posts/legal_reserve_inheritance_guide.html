一、什么是遗留分

在韩国，人们原则上可以自由地在生前赠与财产，或通过遗嘱将财产留给希望的人。然而，如果这种自由毫无限制，法定继承人可能一无所得。为防止此类情况，韩国民法设立了遗留分（유류분）制度。

遗留分是指，无论被继承人（去世者）生前赠与或遗嘱如何处分，法律对特定范围继承人所保障的最低继承份额。它体现了被继承人的财产处分自由与继承人最低限度保护之间的平衡。

遗留分制度规定于民法第1112条至第1118条。2024年宪法裁判所决定及其后两次民法修订（2024年9月20日法律第20432号、2026年3月17日法律第21454号）带来了重大变化。本文以2026年9月29日的现行条文为中心进行说明。

二、遗留分权利人 — 谁可以主张遗留分

并非所有继承人都可主张遗留分。民法第1112条规定的是"继承人的遗留分"，并对其范围作了限定。

2.1 现行遗留分权利人

依现行民法第1112条，遗留分权利人如下。

  • 直系卑属：子女、孙子女等下行直系血亲
  • 配偶：法律婚姻配偶（事实婚姻不适用）
  • 直系尊属：父母、祖父母等上行直系血亲

直系卑属或配偶为继承人时，直系尊属不成为继承人，因此也不具有遗留分权利。直系尊属成为遗留分权利人，仅限于无直系卑属和配偶、由直系尊属担任继承人的情形。

遗留分是继承人享有的权利，因此经家庭法院作出继承权丧失宣告（民法第1004条之2）而失去继承人地位者，也不能主张遗留分。2026年3月17日修订后，该宣告的对象从直系尊属扩大到直系卑属、配偶等所有继承人（参见7.2）。

2.2 兄弟姐妹：2024年违宪决定后被排除

修订前民法第1112条第4号规定，被继承人的兄弟姐妹亦享有法定继承份额1/3的遗留分。然而宪法裁判所于2024年4月25日对该条款作出单纯违宪决定（2020헌가4等）。

宪法裁判所认为，兄弟姐妹对继承财产形成的贡献及对继承财产的期待几乎无法认定，却仍赋予其遗留分权，难以找到正当理由。被宣告违宪的条款自决定之日起失效，因此自2024年4月25日起兄弟姐妹不再享有遗留分。此后，2024年9月20日修订的民法（法律第20432号）从条文中删除了该号，现行条文中留有"删除〈2024.9.20〉"字样。

三、遗留分比例 — 可获保障多少

遗留分以各继承人的法定继承份额为基础，乘以一定比例计算。比例因权利人类型而异（民法第1112条）。

遗留分权利人遗留分比例
直系卑属法定继承份额的1/2
配偶法定继承份额的1/2
直系尊属法定继承份额的1/3

示例：假设被继承人有配偶和两名子女。依韩国民法法定继承份额为配偶3/7、每名子女2/7。则配偶的遗留分为3/14（3/7的一半），每名子女的遗留分为1/7（2/7的一半）。即使被继承人通过遗嘱将全部财产遗赠给第三人，上述家属仍可就其遗留分对应金额提出返还请求。

法定继承份额随共同继承人的构成而变化，准确的遗留分须先从法定继承份额算起。

四、遗留分的计算方法

计算遗留分，首先需确定作为基础的财产规模。民法第1113条第1项规定如下（译文）。

遗留分以被继承人在继承开始时所有财产的价额加上赠与财产的价额，再扣除债务全额后计算。

4.1 计算公式

遗留分基础财产 = （继承开始时的财产）+（赠与财产）-（债务）

依民法第1114条，赠与原则上仅计入继承开始前1年内所为者；但双方均知悉将损害遗留分权利人而为的赠与，1年前的亦计入。而判例认为，对共同继承人（继承人之一）的赠与不论时间均全部计入。

4.2 遗留分不足额的计算

实际可请求返还的金额为遗留分不足额，即遗留分额减去已获得的部分。

遗留分不足额 = 遗留分额 - 特别受益（继承人生前受领的赠与、遗赠等）- 纯继承份额（实际继承的金额）

因计算较为复杂，建议寻求专业人士协助。

4.3 与扶养、贡献报偿的关系

贡献份额（民法第1008条之2）是对在继承财产形成方面有特别贡献的继承人额外认定的份额。但遗留分的准用规定第1118条并未准用第1008条之2，因此长期扶养被继承人而获得的报偿性赠与，也照样计入遗留分计算。宪法裁判所于2024年认定该部分与宪法不符。

2026年3月17日修订的民法在第1008条新增但书：赠与或遗赠系作为以长期同居、护理或其他方式特别扶养被继承人，或对维持、增加被继承人财产作出特别贡献的报偿而为时，在与贡献相当的范围内不视为特别受益。由于第1118条将第1008条准用于遗留分，现行条文的注释也写明此次修订反映了对第1118条宪法不符决定的宗旨。依附则第2条，该但书也适用于2024年4月25日以后开始的继承。

五、遗留分返还请求权的行使方式

遗留分权利人在遗留分受到侵害时，可依民法第1115条行使遗留分返还请求权，追回不足部分。

5.1 请求对象

请求对象是接受了侵害遗留分的赠与或遗赠的人。

  • 受遗赠人：通过被继承人遗嘱获得财产者
  • 受赠人：从被继承人处获得生前赠与者

民法第1116条规定，对于赠与，非在遗赠返还之后不得请求。因此应先向受遗赠人（遗赠）请求，仅在遗赠不足以弥补不足额时，方可就剩余部分向受赠人（赠与）请求。受赠与及遗赠者有多人时，按各自所得价额的比例返还（第1115条第2项）。

5.2 请求方式

遗留分返还请求并非必须通过诉讼，也可在法院外行使。

  • 法院外方式：可通过挂号信（内容证明邮件）或口头通知等方式请求。为明确时效中断效果，建议以书面形式（挂号信）进行。
  • 民事诉讼：对方不自愿返还时，可向有管辖权的法院提起民事诉讼。

返还方式因2026年3月17日施行的修订民法而发生重大变化。修订后的民法第1115条第1项规定，遗留分权利人可在不足的限度内请求支付该财产的价额，且自请求支付价额之日起加算利息（法律第21454号，2026年3月17日公布并施行）。也就是说，返还义务人原则上不再交付不动产、股票等财产本身（原物），而是支付相应的金钱。韩国法制处提供的修订理由也将"把遗留分不足额的返还方式规定为价额返还"列为主要内容。

此前的条文仅规定可请求返还该财产，判例上以原物返还为原则，仅在原物返还不可能或极为困难时才认可价额返还。其结果是不动产形成多人共有、股权分散，纠纷久拖不决；为解决这一问题才转为价额支付方式。

但此次修订不溯及既往。修订民法附则第3条（关于遗留分保全的适用例）规定，第1115条第1项的修订条文自该法施行后开始的继承起适用。因此判断基准是继承开始日（被继承人死亡日），据此适用的法律与返还方式各不相同。若死亡日接近该分界点，务必与律师一同确认现行条文。

继承开始日（被继承人死亡日）适用法律遗留分返还方式
2026年3月16日以前修订前的民法第1115条以原物返还为原则（判例）。仅在原物返还不可能或极为困难时采价额返还
2026年3月17日以后修订后的民法第1115条第1项
（法律第21454号）		以请求支付价额（金钱）为原则。自请求之日起加算利息

六、消灭时效 — 须在何时前提出请求

遗留分返还请求权并非永久有效。民法第1117条规定：返还请求权自遗留分权利人知悉继承开始及应返还的赠与或遗赠事实之时起1年内不行使的，因时效而消灭；自继承开始之时起经过10年的，亦同。

6.1 短期消灭时效：知悉之日起1年

自知悉继承开始及存在侵害遗留分的赠与或遗赠之日起1年内不行使，请求权因时效消灭。"知悉"是指同时了解继承开始事实与遗留分被侵害的赠与或遗赠存在，并非仅知悉赠与的存在。

6.2 长期消灭时效：继承开始之日起10年

即使不知悉侵害事实，自继承开始之日（被继承人死亡之日）起10年经过后，请求权亦告消灭。此为绝对期间，10年届满后即使才知悉侵害事实，亦无法提出请求。

6.3 实务注意事项

两个期限中任一先届满，请求权即消灭。例如继承开始9年后才知悉侵害，10年期限可能先于1年期限届满，须立即应对。提起诉讼、申请假扣押、债务人承认等可中断时效进行。

七、2024年宪法裁判所决定与2024年、2026年民法修订

2024年是遗留分制度的重大转折点。以下整理宪法裁判所的决定及其后的立法。

7.1 宪法裁判所2024年4月25日决定（2020헌가4等）

宪法裁判所按条文分别作出判断。第1113条至第1116条（计算、计入的赠与、保全、返还顺序）被认定合宪，其余如下。

  • 兄弟姐妹遗留分（第1112条第4号）— 单纯违宪：裁判官全体一致作出违宪决定，自决定之日起失效。
  • 未规定遗留分丧失事由（第1112条第1号至第3号）— 与宪法不符：对长期遗弃或虐待被继承人的继承人仍认可遗留分并不合理，问题在于未另行规定遗留分丧失事由。在以2025年12月31日为期限修订之前继续适用。
  • 未准用贡献份额（第1118条）— 与宪法不符：由于未将关于贡献份额的第1008条之2准用于遗留分，扶养被继承人者所受赠与也被计入遗留分基础财产。同样继续适用至上述期限。

7.2 2024年、2026年修订的主要内容

相关立法分两个阶段完成。修订民法（法律第21454号）于2026年3月17日公布，并自同日起施行。

  • 删除兄弟姐妹遗留分 — 2024年修订：民法第1112条第4号经2024年9月20日修订（法律第20432号，2025年1月31日施行）删除。同一修订新设了以直系尊属为对象的继承权丧失宣告制度（第1004条之2），自2026年1月1日起施行。
  • 扩大继承权丧失宣告的对象 — 2026年修订：严重违反对被继承人的扶养义务，或对被继承人等实施重大犯罪行为或其他严重不当对待时，直系尊属、直系卑属及配偶等所有继承人都可能成为继承权丧失宣告的对象（第1004条之2）。并非另设"遗留分丧失"条文，而是失去继承权后也就无法主张遗留分。
  • 作为贡献报偿的赠与、遗赠不视为特别受益 — 2026年修订：作为特别扶养被继承人或对维持、增加其财产作出特别贡献之报偿的赠与、遗赠，在与贡献相当的范围内不视为特别受益（新设第1008条但书，参见4.3）。
  • 转为价额返还 — 2026年修订：经第1115条第1项修订，由原物返还原则转为请求支付价额（金钱）原则，自请求之日起加算利息。依附则第3条，自2026年3月17日以后开始的继承起适用，不溯及既往（参见5.2）。

修订条文的适用范围依附则按条文而不同。附则第2条规定，第1008条但书的修订条文也适用于2024年4月25日以后开始的继承；第1004条之2的修订条文也适用于2024年4月25日以后开始、且施行前已有相关行为的继承。附则第4条为在2024年4月25日以后至施行前开始的继承中、于施行前已知悉具有丧失事由者成为继承人的共同继承人，另设了自施行日起6个月内的请求期间。与此相对，附则第3条规定第1115条第1项的修订条文自施行后开始的继承起适用，因此转为价额返还不溯及既往。不能笼统地说"2026年修订具有溯及力"，结论取决于涉及哪一条文。

八、常见问题

立了遗嘱就能防止遗留分请求吗？

原则上不能。即使有明确遗嘱，遗留分权利人仍可就其遗留分相当金额向受遗赠人提出请求。但若将成为继承人者严重违反扶养义务等、符合第1004条之2的事由，被继承人可通过公证遗嘱表示使其丧失继承权的意思，遗嘱执行人须向家庭法院请求宣告继承权丧失。丧失宣告确定后，该人不再是继承人，也就不能主张遗留分。是否准许，由家庭法院综合事由的经过与程度等因素判断。

放弃继承等于放弃遗留分吗？

是的。放弃继承的继承人因失去继承人资格，也无法主张遗留分。限定承认时继承人地位得以保留，但情况较为复杂，请咨询专业人士。

20年前的赠与也是遗留分返还的对象吗？

对第三人的赠与，原则上仅限继承开始前1年内；若双方均知悉将损害遗留分权利人，则1年前的赠与亦可计入。而对共同继承人（继承人之一）的赠与，不论时间均全部计入。若该赠与是对扶养或贡献的报偿，依2026年新设的第1008条但书，可在与贡献相当的范围内不计为特别受益。

遗留分返还请求必须通过诉讼进行吗？

不必须。也可通过内容证明邮件等法院外方式提出。但对方不自愿返还时须提起诉讼。请务必注意消灭时效（知悉之日起1年、继承开始之日起10年）。

配偶与子女同为继承人时，遗留分如何计算？

配偶与直系卑属共同继承时，依韩国民法，配偶的法定继承份额为子女一人份额再加五成（例如配偶与两名子女：子女各2/7，配偶3/7）。遗留分为各自法定继承份额的二分之一，因此每名子女的遗留分为1/7，配偶为3/14。实际计算可能因财产构成而变得复杂。

# 韩国遗留分核对表 - 权利人、适用法律、请求期限

基准日: 2026-09-29
本表以韩国民法（法律第21454号，2026年3月17日施行）为基础，仅供一般信息参考，不构成法律建议。个案结论由法院判断，提出请求前请咨询熟悉韩国法的律师等专业人士。

---

## 1. 我是遗留分权利人吗

| 与被继承人的关系 | 遗留分 | 依据 |
|---|---|---|
| 直系卑属（子女、孙子女等） | 法定继承份额的1/2 | 民法第1112条第1号 |
| 配偶（法律婚姻） | 法定继承份额的1/2 | 民法第1112条第2号 |
| 直系尊属（父母、祖父母等） | 法定继承份额的1/3（仅限无直系卑属和配偶而成为继承人时） | 民法第1112条第3号 |
| 兄弟姐妹 | 无 | 宪法裁判所2024年4月25日决定（2020헌가4等），2024年9月20日删除（法律第20432号） |
| 被宣告丧失继承权者 | 无（不是继承人） | 民法第1004条之2 |
| 放弃继承者 | 无（失去继承人地位） | - |

---

## 2. 适用哪部法律 - 以继承开始日（死亡日）区分

| 项目 | 2026年3月16日以前开始 | 2026年3月17日以后开始 | 依据 |
|---|---|---|---|
| 返还方式 | 以原物返还为原则（判例），困难时价额返还 | 以请求支付价额（金钱）为原则，自请求之日起加算利息 | 第1115条第1项、附则第3条 |
| 报偿性赠与、遗赠不视为特别受益 | 2024年4月25日以后开始的继承适用 | 适用 | 第1008条但书、附则第2条 |
| 继承权丧失宣告（所有继承人） | 2024年4月25日以后开始、且施行前已有相关行为的继承适用 | 适用 | 第1004条之2、附则第2条 |

---

## 3. 请求前核对

- [ ] 已确认被继承人的死亡日（继承开始日）
- [ ] 已记录知悉继承开始及应返还赠与、遗赠之日（自该日起1年，第1117条）
- [ ] 自继承开始起未满10年（第1117条）
- [ ] 已先计算法定继承份额（配偶为子女一人份额加五成）
- [ ] 基础财产 = 继承开始时财产 + 赠与财产 - 债务（第1113条第1项）
- [ ] 对第三人的赠与仅计入继承开始前1年内的（双方知悉损害时更早的也计入，第1114条）
- [ ] 对共同继承人的赠与不论时间均已计入（判例）
- [ ] 已单独标注该赠与是否为扶养、贡献的报偿（第1008条但书）
- [ ] 已按先受遗赠人（遗赠）、不足部分再受赠人（赠与）的顺序整理请求对象（第1116条）

---

## 4. 请求方式判断表

| 情形 | 首先要做的事 | 备注 |
|---|---|---|
| 与对方尚有协商余地 | 以内容证明邮件表示返还请求 | 管理时效并保全证据 |
| 对方拒绝或不回应 | 提起遗留分返还诉讼 | 确认管辖法院 |
| 知悉之日起1年即将届满 | 立即起诉或采取中断时效措施 | 以两个期间中先届满者为准 |
| 死亡日接近2026年3月17日 | 与专业人士确认适用条文 | 附则按条文而不同 |
