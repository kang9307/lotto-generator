1. Grok 4.7 공개와 주요 포지셔닝

인공지능 연구 개발 기업 xAI는 2026년 9월 21일 공식 발표를 통해 새로운 대형 언어 모델인 Grok 4.7을 정식으로 선보였다. 이번 릴리스는 개발자와 기업 사용자를 대상으로 복잡한 소프트웨어 개발 과업과 지식 집약적 업무를 수행하도록 설계된 최신 모델이다. xAI는 자사의 직전 주력 플래그십 모델이었던 Grok 4.6을 계승하면서도, 더 긴 시간 동안 고난도 문제를 지속적으로 해결할 수 있는 추론 구조를 정립했다고 밝혔다.

원문 발표문에서 xAI는 Grok 4.7을 두고 「코딩과 지식 업무를 위한 당사의 가장 유능한 모델(most capable model for coding and knowledge work)」이라는 명확한 표현을 사용했다. 단순한 질의응답이나 보편적인 텍스트 요약 성능에 머무르지 않고, 엔지니어가 수 시간에 걸쳐 다단계로 해결해야 하는 복잡한 디버깅, 시스템 설계, 코드베이스 전반의 리팩토링 등 실질적인 작업 완결 능력에 초점을 맞추었다고 설명한다.

일반적으로 최신 인공지능 모델의 성능이 향상될 때에는 연산량 증가에 따라 API 호출 비용이 함께 인상되는 흐름이 관측되곤 한다. 하지만 xAI는 Grok 4.7을 공개하면서 기존 Grok 4.6과 동일한 가격 정책과 동일한 처리 속도를 그대로 유지한다고 밝혔다. 이는 대규모 트래픽을 처리하는 상용 서비스 개발자들에게 비용 증가 없는 모델 전환 경로를 제공함으로써 개발 생태계 내 점유율을 확장하려는 시도로 읽힌다.

원문 발표를 통해 확인되는 Grok 4.7의 주요 포지셔닝과 목표 방향은 다음과 같다.

  • 공식 발표 일자는 2026년 9월 21일이며, 주요 용도를 고난도 소프트웨어 개발과 지식 집약적 전문 실무로 명시했다.
  • 단순 단답형 응답 속도보다 긴 시간 집중을 요하는 과제에서의 자체 검증 능력과 컨텍스트 연속성 관리를 전면에 배치했다.
  • 기존 버전인 Grok 4.6과 동일한 수준의 기본 토큰 단가와 기본 속도를 유지하여 상용 도입의 경제성을 유지했다.

2. 코딩·소프트웨어 엔지니어링 벤치마크 수치

Grok 4.7의 실제 역량 향상은 xAI가 함께 공개한 소프트웨어 엔지니어링 벤치마크 지표를 통해 정량적으로 제시되었다. 그중에서도 실시간 코딩 지원 도구 환경에서 장기 과제를 얼마나 안정적으로 완수하는지 측정하는 CursorBench 4.0의 결과가 상세히 공개되었다. 이 평가는 단순한 알고리즘 풀이가 아닌 대규모 코드 프로젝트에서의 다단계 수정과 테스트 통과 역량을 다룬다.

원문 도표에 따르면 Grok 4.7(xHigh 추론 설정)은 CursorBench 4.0에서 46.3%의 해결 성공률을 기록했다. 이는 동일 벤치마크에서 이전 세대인 Grok 4.6(High 설정)이 달성했던 40.4%에 비해 5.9%포인트 향상된 결과다. xAI는 작업당 평균 비용과 작업 점수의 상관관계를 산점도 형태로 제시하며, Grok 4.7이 작업당 약 6.01달러 수준의 평균 비용으로 46.3%의 성과를 내어 가격 대비 성능 곡선에서 선두권에 위치한다고 적는다.

실제 깃허브의 공개 이슈를 해결하는 역량을 평가하는 DeepSWE v1.1 벤치마크에서도 성능 개선이 확인되었다. Grok 4.7은 높은 추론 노력을 투입하는 고노력 조건(high effort)에서 71.0%의 점수를 달성했다. 이는 이전 Grok 4.6의 65.2%보다 5.8%포인트 높은 수치다. 또한 개발자가 셸 터미널에서 여러 단계의 명령어를 입력하고 상호작용하는 환경을 시뮬레이션한 Terminal-Bench 4.0에서도 Grok 4.6의 20.3%에 비해 두 배 가까이 향상된 38.0%를 기록했다.

소프트웨어 엔지니어링 및 코딩 영역에서 확인되는 핵심 지표는 다음과 같다.

  • CursorBench 4.0: Grok 4.7이 46.3%를 달성하여 이전 모델 Grok 4.6의 40.4% 대비 5.9%포인트 상승했다.
  • DeepSWE v1.1: 고난도 추론 모드(high effort)에서 71.0%를 기록하여 Grok 4.6의 65.2%를 상회했다.
  • Terminal-Bench 4.0: 다단계 터미널 상호작용 평가에서 38.0%를 달성하여 기존 20.3% 대비 대폭 개선되었다.

3. 전문 지식 및 실무 벤치마크 결과

Grok 4.7의 벤치마크 평가는 소프트웨어 프로그래밍에만 국한되지 않는다. xAI는 하드웨어 엔지니어링, 전문 법률 실무, 임상 의학 추론, 장시간 사무 행정 등 실제 전문직 종사자들이 다루는 실무 과업을 대상으로 한 종합 평가 지표를 폭넓게 공개했다. 이는 범용 언어 모델이 전문 영역의 복합 워크플로를 얼마나 자율적으로 지원할 수 있는지를 측정한 것이다.

전자공학 및 하드웨어 회로 설계를 다루는 EEBench 벤치마크에서 Grok 4.7은 64.0%의 해결 점수를 기록했다. 이는 이전 세대인 Grok 4.6이 기록했던 53.0%에서 11.0%포인트 상승한 수치다. 전기 전자 이론, 회로 분석, 하드웨어 기술 명세서 해석과 같은 영역에서 모델의 물리적 추론과 수학적 계산 정합성이 개선되었음을 보여준다.

법률 사무 및 계약 분석 역량을 시험하는 Harvey Legal Agent Benchmark에서는 19.6%를 획득했다. Grok 4.6의 15.8%보다 3.8%포인트 상승한 점수다. 더불어 복합 사무 과제를 평가하는 AA Briefcase v1.1에서는 1,657점을 기록하여 Grok 4.6의 1,546점을 넘어섰으며, 전문 지식 업무를 평가하는 GDPval 지표에서도 이전 대비 향상된 성능을 나타냈다. 임상 의학적 의사결정과 지식 추론을 다루는 HealthBench Professional 평가에서는 56.7%를 기록하여 Grok 4.6의 48.5%를 웃돌았다.

전문 실무 영역과 관련하여 원문 공지에 수록된 대표적인 결과는 다음과 같다.

  • EEBench(전자공학): Grok 4.7이 64.0%를 기록하여 Grok 4.6의 53.0% 대비 11.0%포인트 향상되었다.
  • Harvey Legal Agent Benchmark: 법률 분석 대리 평가에서 19.6%를 달성하여 기존 15.8%를 상회했다.
  • 사무 및 의료 지표: AA Briefcase v1.1에서 1,657점, HealthBench Professional에서 56.7%를 기록했다.

5. 아키텍처 개선과 Grok Bot 하네스 연동

Grok 4.7의 성능 개선을 뒷받침하는 기술적 메커니즘과 관련하여, 원문은 기초 모델(Base Model)의 규모 확장과 강화학습(RL) 훈련의 설계를 핵심 원인으로 설명한다. xAI는 구체적인 파라미터 총량을 밝히지는 않았으나, 「Grok 4.6 대비 더 크고 새로운 기본 모델(new, larger base model compared to Grok 4.6)」을 토대로 사전 훈련을 진행했다고 적는다.

기초 모델의 확장에 이어 사후 학습 단계에서는 강화학습(Reinforcement Learning) 공정이 심화되었다. xAI는 단순한 패턴 매칭을 넘어 문제를 푸는 데 여러 시간이 걸리는 고난도 복합 과업에 가중치를 둔 장기 강화학습 런을 수행했다고 설명한다. 이를 통해 모델이 중간 추론 단계에서 오류를 발견하면 스스로 바로잡는 작업 자체 검증(verifying its own work) 능력과, 수만 토큰에 이르는 긴 문맥을 일관성 있게 다루는 긴 컨텍스트 관리(managing longer context) 능력이 강화되었다고 강조했다.

이에 더해 Grok 4.7은 xAI의 대화형 실행 도구인 Grok Bot 하네스(Grok Bot harness)를 네이티브 수준에서 기본 이해하도록 직접 학습되었다. 대화형 인터페이스를 통해 복합적인 작업을 위임받거나 여러 툴을 조율할 때, 하네스의 내부 규격을 자연스럽게 이해함으로써 도구 호출의 오차를 줄이고 일반 지식 작업의 일관성을 높이도록 설계되었다.

모델 구조와 아키텍처 개선의 핵심 축은 다음과 같이 요약된다.

  • 기본 모델 확장: Grok 4.6 대비 물리적 규모가 커진 새로운 베이스 모델을 채택하여 기본 역량을 확장했다.
  • 장기 강화학습: 수 시간이 소요되는 난도 높은 과업 중심의 강화학습을 진행하여 작업 자체 검증 능력을 길렀다.
  • 하네스 네이티브 지원: Grok Bot 하네스 규격을 사전에 네이티브로 학습시켜 대화형 도구 연동 안정성을 확보했다.

6. 안전성 스택과 사이버보안 자체 평가

xAI의 발표에서 많은 지면이 할애된 또 다른 핵심 축은 안전성(Safety)과 사이버보안 방어 체계다. 고성능 추론 모델이 악의적인 공격자에게 악용되는 것을 방지하면서도, 정당한 보안 엔지니어링이나 학술 연구 활동을 부당하게 가로막지 않도록 설계된 새로운 안전성 스택(safeguard stack)을 도입했다고 밝혔다.

안전성 전반에 대한 평가와 관련하여 xAI는 원문에서 「거부 및 탈옥 저항성 측면에서 당사가 테스트한 모델 중 가장 강력하다(strongest model we've tested on refusals and jailbreak resistance)」고 평가했다. 이러한 진술은 xAI 자체 벤치마크 환경에서 도출된 기업 내부의 평가 결과이며, 독립적인 제3자 검증 기관의 인증과는 구별되어 이해되어야 한다.

이중 용도(Dual-use) 위험을 다루는 사이버보안 영역에서는 자체 보안 벤치마크인 HackerBench v0.3 결과를 제시했다. 이 평가에서 Grok 4.7은 악의적이거나 위험한 프롬프트 중 3.3%만을 통과시키며 높은 차단율을 보였다고 발표했다. 반면 합법적인 침투 테스트나 보안 분석 요청에 대해서는 불필요한 거부(false refusal)를 최소화하도록 튜닝되었다고 덧붙였다. 아울러 LatchBio의 바이오 안전성 벤치마크에서도 62.4%의 수치를 기록했으며, 방어 목적의 사이버 연구를 위해 선별된 보안 파트너들에게 Grok 4.7의 레드팀 기능을 초대 기반으로 비공개 제공하기 시작했다고 명시했다.

안전성 및 사이버보안 관련 확정 사실은 아래와 같이 정리된다.

  • 자체 평가 지표: xAI는 거부 처리 및 탈옥 시도 방어력에서 자사 테스트 기준 최고 수준의 안전성을 갖추었다고 평가했다.
  • 위험 프롬프트 억제: 자체 사이버 벤치마크 HackerBench v0.3에서 위험한 프롬프트의 통과율을 3.3%로 제한했다.
  • 파트너십 제공: 방어적 보안 연구 역량 강화를 위해 선별된 파트너에게 레드팀 기능의 비공개 접근권을 부여했다.

7. 가격 체계, 옵션 및 API 제공 환경

Grok 4.7의 상용 서비스 정책에서 가장 주목받는 요소 중 하나는 가격 동결이다. xAI는 더 커진 베이스 모델과 고도화된 강화학습이 적용되었음에도 불구하고, 표준 API 이용 요금을 이전 버전인 Grok 4.6과 완전히 동일한 수준으로 유지한다고 발표했다.

공개된 기본 가격표에 따르면 Grok 4.7의 토큰 단가는 입력 100만 토큰당 2달러($2 per million input tokens), 출력 100만 토큰당 6달러($6 per million output tokens)로 책정되었다. 이에 더해 처리 속도가 중요한 대화형 애플리케이션이나 실시간 에이전트 시스템을 위해, 기본 모델 대비 출력 생성 속도가 2배 빠른 고속 옵션(Fast Variant)도 함께 제공된다. 이 고속 옵션은 2배의 속도를 제공하는 대신 토큰 단가 또한 2배인 입력 4달러, 출력 12달러로 책정된다.

구분 기본 모델 (xHigh) 고속 옵션 (Fast Variant)
입력 토큰 가격 (1M 토큰당) $2.00 $4.00 (2배 단가)
출력 토큰 가격 (1M 토큰당) $6.00 $12.00 (2배 단가)
출력 생성 속도 Grok 4.6과 동일한 기준 속도 기본 모델 대비 2배 빠른 출력 속도
지원 환경 Cursor, Grok Build, Grok API Cursor, Grok Build, Grok API

플랫폼 접근성 측면에서 Grok 4.7은 발표 당일부터 개발 도구인 Cursor와 xAI의 개발자 플랫폼인 Grok Build에 즉시 연동되었다. 개발자는 공식 Grok API 콘솔을 통해 키를 발급받아 프로젝트에 즉시 투입할 수 있으며, 서드파티 코딩 하네스, 모델 라우터 및 주요 클라우드 인프라를 통해서도 제공된다. xAI는 로컬 터미널 환경에서 Grok CLI 환경을 구축할 수 있는 공식 설치 셸 명령어를 아래와 같이 안내했다.

curl -fsSL https://x.ai/cli/install.sh | bash

가격 및 배포 체계와 관련된 핵심 사실은 다음과 같다.

  • 기본 가격표: 100만 토큰당 입력 2달러, 출력 6달러로 이전 세대인 Grok 4.6과 동일한 기준을 적용한다.
  • 고속 유료 옵션: 2배 빠른 속도를 제공하는 대신 2배의 단가를 부과하는 고속 모델을 선택적으로 제공한다.
  • 지원 생태계: Cursor 에디터, Grok Build, Grok API 콘솔 및 클라우드 플랫폼을 통해 즉시 배포된다.

8. 확인하지 못한 것

본 기술 분석은 xAI의 공식 릴리스 공지와 1차 출처 페이지에서 명시적으로 확인된 데이터만을 근거로 작성되었다. 기술적 신뢰성을 확보하고 추측성 서술을 배제하기 위해, 공식 문서에 명시되지 않은 아래의 항목들은 확인하지 못한 사실로 분류하여 본 절에 유보 사항으로 정리한다.

  • Grok 4.7의 총 매개변수(parameter) 수와 활성 파라미터 규모: xAI는 Grok 4.6보다 큰 베이스 모델이라는 사실만 언급했을 뿐, 정확한 파라미터 수치, 어텐션 헤드 수, 레이어 깊이 등 아키텍처 수치를 공개하지 않았다.
  • 강화학습 훈련에 투입된 총 컴퓨팅 연산량(FLOPs) 및 하드웨어 구성: 모델 학습에 사용된 GPU 클러스터 규모, 총 전력 소비량, 전체 학습 일수 등 인프라의 정량적 지표는 원문에 기재되지 않았다.
  • 제3자 독립 감사 기관의 안전성 및 벤치마크 교차 검증 보고서: 탈옥 저항성과 HackerBench v0.3 결과는 xAI 내부 자체 평가에 기반하며, 외부 보안 기관의 독립적인 교차 검증 결과는 원문에 수록되지 않았다.
