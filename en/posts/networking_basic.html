TCP/IP Networking Basics

A primer on how TCP/IP networks work

2025-06-01 Dev & Infra

Networking sits at the heart of modern computing. This article walks through the basic concepts and operating principles of TCP/IP networks.

TCP/IP Protocol Stack

The TCP/IP protocol stack is organized into four layers:

  1. Application Layer: HTTP, FTP, DNS, SMTP, and similar protocols
  2. Transport Layer: TCP, UDP
  3. Internet Layer: IP, ICMP, ARP
  4. Network Interface Layer: Ethernet, Wi-Fi, and similar link-layer technologies

IP Address

An IP address is a unique identifier for a device on a network.

IPv4 (Internet Protocol version 4)

IPv4 addresses are 32 bits long and are typically written as four decimal numbers separated by dots.

192.168.1.1

IPv6 (Internet Protocol version 6)

IPv6 addresses are 128 bits long and are written as eight groups of hexadecimal digits separated by colons.

2001:0db8:85a3:0000:0000:8a2e:0370:7334

Subnet Mask

A subnet mask is used to separate the network portion from the host portion of an IP address.

IP Address:      192.168.1.10
Subnet Mask:     255.255.255.0
Network Address: 192.168.1.0

Port Numbers

Port numbers are used to identify individual processes on a host. Common well-known ports include:

  • HTTP: 80
  • HTTPS: 443
  • FTP: 21
  • SSH: 22
  • SMTP: 25
  • DNS: 53

Network Commands

The following commands are useful for diagnosing network issues:

# Test connection to a host
ping google.com

# Trace the network path to a host
traceroute google.com

# Show network interface information
ifconfig    # Unix/Linux
ipconfig    # Windows

# DNS lookup
nslookup google.com

A solid grasp of networking fundamentals will help you troubleshoot a wide variety of network problems far more effectively.
