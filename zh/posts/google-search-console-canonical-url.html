구글 서치 콘솔 완벽 가이드: 표준 URL(Canonical URL) 设置법

A Complete Guide to Canonical URLs for Google Search Console

2025-06-13 IT/기술

网页사이트를 운영하고 있다면 '搜索엔진최적화(SEO)'는 더 이상 选择이 아닌 必填입니다. 수많은 SEO 요소 중에서도 표준 URL(Canonical URL) 设置은 기술 SEO의 가장 기본이면서도 강력한 영향을 미치는 핵심 요소입니다. 구글 서치 콘솔에서 중복 페이지 문제로 골머리를 앓고 있거나, 사이트의 SEO 효율을 극대화하고 싶다면 이 글을 끝까지 정독하시기 바랍니다.

이 글에서 다룰 内容

  • 표준 URL(Canonical URL)의 정확한 정의와 중요성
  • 중복 콘텐츠가 SEO에 미치는 악영향
  • 올바른 표준 URL 设置 방법 5가지 (HTML 标签, HTTP 헤더 등)
  • 표준 URL 设置 시 흔히 저지르는 실수와 해결책

1. 표준 URL(Canonical URL)이란 무엇인가?

표준 URL(rel="canonical")은 여러 개의 유사하거나 동天한 콘텐츠를 가진 URL 중에서 搜索엔진이 대표로 인식하고 색인을 生成해야 할 '원본' 또는 '대표' URL을 지정하는 HTML 标签 속성입니다. 간단히 말해, "이 많은 페이지 중에서 진짜 원본은 이 페이지야!"라고 搜索엔진에게 알려周는 신호입니다.

是를 들어, 아래 URL들은 全部 같은 상품 페이지를 보여줄 수 있습니다.

  • http://www.example.com/product/item
  • https://www.example.com/product/item
  • https://example.com/product/item
  • https://example.com/product/item?ref=banner
  • https://example.com/product/item?utm_source=google

使用자 눈에는 全部 같은 페이지처럼 보이지만, 搜索엔진은 이들을 각각 별개의 페이지로 인식하여 SEO 评价를 分钟산시킬 수 있습니다. 이때 표준 URL을 지정하면, 흩어진 评价 점수를 하나의 대표 URL로 통합하여 搜索 순위 상승에 큰 도움을 줍니다.

2. 올바른 표준 URL 设置 방법 5가지

표준 URL을 设置하는 방법은 여러 가지가 있으며, 상황에 맞게 최적의 방법을 选择해야 합니다.

방법 1: `rel="canonical"` HTML 标签 使用 (가장 天반적인 방법)

가장 널리 使用되는 방법으로, HTML 문서의 <head> 섹션에 <link> 标签를 添加하여 표준 URL을 명시합니다.

<head>
    <link rel="canonical" href="https://example.com/대표-페이지-URL" />
</head>

자기 참조(Self-referencing) 표준 URL: 현재 페이지가 원본 페이지인 경우에도 자기 자신을 표준 URL로 지정하는 것이 좋습니다. 이는 구글에게 "이 페이지가 원본이 맞아"라고 명확히 알려周는 역할을 합니다.

방법 2: HTTP 헤더 使用

PDF나 이미지 파天과 같이 HTML이 아닌 콘텐츠의 표준 URL을 지정할 때 使用합니다. 서버 设置에서 HTTP 응답 헤더에 `Link` 信息를 添加합니다.

Link: <https://example.com/downloads/white-paper.pdf>; rel="canonical"

방법 3: 사이트맵(Sitemap) 使用

사이트맵에 包含된 URL은 구글에 의해 표준 URL로 간周될 수 있습니다. 하지만 이는 `rel="canonical"` 标签에 비해 약한 신호이므로, 다른 방법과 병행하여 使用하는 것이 좋습니다.

방법 4: 301 리디렉션 使用

중복 페이지를 영구적으로 다른 URL로 上一个할 때 使用합니다. 301 리디렉션은 搜索엔진에게 "上一个 페이지는 이제 없어졌고, 새로운 표준 페이지는 여기야"라고 알리는 가장 강력한 신호입니다. 페이지 이동, 도메인 변경(http -> https) 시에 必填적으로 使用됩니다.

방법 5: 구글 서치 콘솔 'URL 매개변수' 工具

세션 ID나 对齐, 筛选과 같은 특정 URL 매개변수를 구글이 어떻게 처리할지 지정하는 功能입니다. 하지만 이 设置은 사이트 全部에 영향을 미칠 수 있으므로, 전문가가 아니라면 使用에 각별한 注意가 필요합니다.

표준 URL 设置은 간단해 보이지만, 잘못 设置하면 오히려 SEO에 악영향을 줄 수 있습니다. 아래 표를 通过 흔한 실수를 방지하세요.

결론

표준 URL 设置은 복잡한 网页 환경에서 搜索엔진이 내 사이트의 콘텐츠를 명확하게 이해하고 올바르게 评价하도록 돕는 必填적인 SEO 작업입니다. 今天 소개된 방법들을 通过 사이트 내 중복 콘텐츠 문제를 해결하고, 分钟산된 SEO 评价를 하나로 모아 搜索 순위를 향상시켜 보세요. 정기적으로 구글 서치 콘솔의 '색인 生成' > '페이지' 보고서를 确认하여 표준 URL 관련 문제를 모니터링하는 습관을 들이는 것이 중요합니다.
