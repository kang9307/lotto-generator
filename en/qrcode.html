QR Code Generator Use법

  1. QR Code 유형을 드롭다운 Menu에서 Select합니다 (URL, Text, Contact, WiFi 등).
  2. Select한 유형에 따른 Info를 Input합니다:
    • URL: Web사이트 Address를 Input합니다 (Yes: https://example.com).
    • Text: Day반 Text Content을 Input합니다.
    • Contact: 이름, 전화Number, Email 등의 Info를 Input합니다.
    • WiFi: Network 이름(SSID), Password, Security 유형을 Input합니다.
  3. "QR Code Generate" 버튼을 클릭하여 코드를 Generate합니다.

QR Code Settings Guide

  • Size: QR Code의 Size를 픽셀 Unit로 조정합니다 (100-500px).
  • Error Edit 레벨: QR Code가 손상되어도 읽을 수 있는 복원력을 Settings합니다.
  • 전경색: QR Code 자체의 Color을 변경합니다.
  • 배경색: QR Code 배경의 Color을 변경합니다.
  • Settings 적용: 변경한 Settings을 적용하려면 "Settings 적용하기" 버튼을 클릭합니다.

QR Code 활용 팁

  • 인쇄 Size: 실물로 인쇄할 때는 Minimum 2x2cm 이상의 Size로 인쇄하세요.
  • 여백 확보: QR Code Week변에 충Minutes한 여백을 두어 스캔 Success률을 높이세요.
  • 대비 유지: Color을 변경할 때는 배경과 코드 간 충Minutes한 대비를 유지하세요.
  • 짧은 URL: 긴 URL은 단축 URL 서비스를 Use하여 QR Code를 단순화하세요.
  • Download: Generate된 QR Code는 "PNG Download" 버튼을 클릭하여 Save할 수 있습니다.
