🔒 왜 안전한가

대부분의 온라인 PDF 서비스는 파일을 서버로 올린 뒤 그쪽에서 처리하고 결과를 돌려줍니다. 편리하지만 계약서·신분증 사본·급여명세서처럼 남에게 보이면 안 되는 문서라면 이야기가 달라집니다. 이 도구는 그 단계를 아예 없앴습니다.

  • File API로만 읽습니다. 브라우저가 파일을 읽어 메모리에 올릴 뿐, 어떤 주소로도 보내지 않습니다.
  • 결과도 브라우저가 만듭니다. 합쳐진 PDF는 이 페이지의 자바스크립트가 직접 조립하고, 내려받기는 메모리에 만든 임시 주소를 여는 것입니다.
  • 네트워크로 나가는 것은 프로그램 파일뿐입니다. 페이지를 열 때 PDF 처리 라이브러리를 한 번 내려받는 것 외에 문서와 관련된 통신은 없습니다.
  • 탭을 닫으면 사라집니다. 서버는 물론 브라우저 저장소에도 문서를 남기지 않습니다.

직접 확인하고 싶다면 브라우저 개발자 도구(F12)의 네트워크 탭을 연 채로 합치기를 실행해 보세요. 파일이 오가는 요청이 하나도 뜨지 않습니다.

기능별 사용법과 결과 파일 이름
  • 합치기 — PDF를 여러 개 넣고 화살표로 순서를 맞춘 뒤 합치기를 누릅니다. 결과는 merged.pdf로 저장됩니다.
  • 나누기 — 범위를 「1-3,5,8-10」처럼 적거나 쪽 그림을 눌러 고릅니다. 한 개 PDF로 저장하면 pages_1-3,5,8-10.pdf 형태, 낱장으로 나누면 파일명_p1.pdf 형태가 됩니다.
  • 페이지 편집 — 쪽을 눌러 고른 뒤 회전·삭제를 적용하고, 각 쪽의 ◀ ▶로 순서를 바꿉니다. 결과는 파일명_edited.pdf입니다.
  • 이미지 → PDF — 사진을 순서대로 넣고 용지·방향·여백을 고릅니다. 결과는 images.pdf입니다.
알아 두면 좋은 한계
  • 암호가 걸린 PDF는 열리지 않습니다. 열기 암호나 권한 암호가 설정된 문서는 구조 자체가 암호화되어 있어 읽지 못합니다. 원본 프로그램에서 암호를 푼 뒤 다시 시도하세요.
  • 책갈피·주석·양식·전자서명은 사라질 수 있습니다. 페이지를 복사해 새 문서를 만드는 방식이라 문서 단위로 붙어 있던 정보는 따라오지 않습니다. 전자서명이 있는 문서는 편집하면 서명이 깨집니다.
  • 큰 파일은 기기 성능을 탑니다. 합계 50MB를 넘으면 경고가 뜹니다. 처리는 모두 이 기기에서 일어나므로 메모리가 부족하면 탭이 느려질 수 있습니다.
  • 미리보기는 앞쪽 일부만 그립니다. 쪽 수가 아주 많으면 앞의 200쪽까지만 그림을 그리고 나머지는 쪽 번호로 표시합니다. 추출·편집 자체는 전체 쪽에 대해 정상 동작합니다.
  • 글자 인식(OCR)이나 압축은 없습니다. 이 도구는 쪽 단위 재구성에 집중하며, 스캔 이미지의 글자를 뽑아내거나 용량을 줄이는 기능은 제공하지 않습니다.
중요한 문서는 원본을 남겨 두세요. 이 도구는 원본 파일을 고치지 않고 새 파일을 만들어 주지만, 결과물을 확인하기 전까지는 원본을 지우지 않는 편이 안전합니다. 브라우저의 확장 프로그램이나 광고 차단기가 처리 라이브러리를 막으면 도구가 동작하지 않을 수 있습니다.
