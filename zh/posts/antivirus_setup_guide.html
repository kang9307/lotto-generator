Windows安全中心应用与Microsoft Defender防病毒——名称与适用范围

Windows上默认运行的杀毒功能有两个名字。用户打开的界面是Windows安全中心应用，负责扫描文件并处理威胁的引擎则是Microsoft Defender防病毒。概述文档指出，Microsoft Defender防病毒可用于Windows 10、Windows 11和各个Windows Server版本，并且内置于Windows之中。

关闭Windows安全中心应用，与关闭引擎并不是一回事。文档明确说明，禁用Windows安全中心应用并不会禁用Microsoft Defender防病毒或Windows防火墙。不过，如果关闭该应用，或通过相关的组策略阻止它启动或运行，应用可能会显示设备上所装防病毒和防火墙产品的过时或不准确信息，卸载非Microsoft防病毒软件时，Microsoft Defender防病毒也可能不会重新启用。文档提醒，禁用该应用会大幅降低设备的保护级别，并可能导致恶意软件感染。

  • 适用的操作系统：兼容性文档列出的是Windows 11、Windows 10、Windows Server 2016及更高版本、Windows Server 1803及更高版本，以及Azure Stack HCI OS 23H2及更高版本。在Windows安全中心应用里运行扫描、检查更新、添加排除项和配置勒索软件防护的功能，适用于Windows 10 1703及更高版本。脱机扫描不适用于Windows Server。
  • 进程与服务：在任务管理器的“详细信息”选项卡中，如果能看到MsMpEng.exe（服务名称为WinDefend），说明引擎正在运行。此外还有Microsoft Defender核心服务MdCoreSvc（MpDefenderCoreService.exe）、网络实时检查服务WdNisSvc（NisSrv.exe）以及命令行实用工具MpCmdRun.exe。
  • 不要修改这些服务：兼容性文档建议不要禁用、停止或修改wscsvc、SecurityHealthService、MsSense、Sense、WinDefend和MsMpEng这些服务与进程，并指出手动修改可能导致设备严重不稳定。
  • 由策略管理的设备：通过组策略配置并部署设置后，Windows安全中心应用中的“病毒和威胁防护”设置会显示为灰色，无法在单台终结点上更改。组策略对象所做的更改必须先部署到设备，Windows设置中才会反映出来。

关于杀毒软件与恶意软件应对的背景知识，另有个人网络安全基础完全指南和恶意软件与勒索软件应对两篇文章可供参考。

打开Windows安全中心应用与“病毒和威胁防护”界面

在“开始”菜单中搜索Windows 安全中心并打开应用，然后选择病毒和威胁防护。运行扫描、检查安全智能更新、验证实时保护、添加排除项、查看威胁检测历史记录以及配置勒索软件防护，都在这个界面中完成。

  • 快速扫描与扫描选项：选择“快速扫描”即开始扫描，完全扫描等其他类型则在“扫描选项”中选择。
  • 病毒 & 威胁防护更新：显示已安装的安全智能（以前称为定义）的版本及下载日期。选择“检查更新”会下载新的保护更新（如有）。
  • 病毒和威胁防护设置：进入“管理设置”，处理实时保护开关和排除项。
  • 保护历史记录：列出所有最近的项目。脱机扫描的结果也在这里查看。
  • 勒索软件防护：在“管理勒索软件防护”中设置受控文件夹访问，在“勒索软件数据恢复”中连接或设置OneDrive帐户。
  • 管理提供程序：在“谁保护我？”下选择“管理提供程序”，安全提供程序页面的“防病毒”下应显示Microsoft Defender防病毒已打开。
  • 任务管理器检查：在“详细信息”选项卡中查找MsMpEng.exe，也是判断引擎是否正在运行的一种办法。

检查更新有一个前提条件。如果设备指向WSUS或软件更新点，且Windows更新策略设置为“3 - 自动下载并通知安装”，选择“检查更新”就会安装所有可用的Microsoft Defender防病毒更新，包括安全智能、引擎和平台。

保护设置——实时保护、云提供的保护、自动样本提交与防篡改保护

打开“病毒和威胁防护设置”下的管理设置，就能看到核心保护功能的开关。有文档依据的项目共有四个。

实时保护是始终开启的保护，会在文件被打开和关闭时，以及用户每次浏览到某个文件夹时检查文件。在“病毒和威胁防护设置”中把“实时保护”开关切换为“打开”即可确认。关闭该开关后，它会在短暂延迟后自动重新打开，文档解释说，这种自动启用是为了确保设备不受恶意软件和威胁的侵害。

云提供的保护是云保护服务，也称为Microsoft高级保护服务（MAPS），用来增强标准的实时保护。按文档的说法，有了这项服务，即使在单个终结点被感染之前，也能快速识别新的威胁。云服务并不只是保护存储在云中的文件，而是利用分布式资源和机器学习，以远快于传统安全智能更新的速度交付保护。云保护默认已启用，文档建议保持开启，因为Microsoft Defender for Endpoint的部分安全功能只有在启用云保护时才能工作。在非托管设备上，请在“管理设置”中打开“云提供的保护”和“自动样本提交”。Windows安全中心应用中没有设置云保护级别的选项。

自动样本提交会把文件和可执行文件发送到Microsoft Defender防病毒云服务进行分析。它依赖云保护，但也可以作为独立设置来配置。在管理工具中，样本提交同意选项可在“自动发送安全样本”（默认）和“自动发送所有样本”之间选择。按组策略的说明，发送安全样本时，大多数样本会自动发送，而对可能包含个人信息的文件，则会要求用户另行确认。

防篡改保护有助于防止重要安全设置被禁用或更改。文档交代的背景是：在网络攻击期间，攻击者往往会禁用设备上的安全功能，以便访问数据并安装恶意软件。文档列出了防篡改保护开启后无法更改的项目：病毒和威胁防护、实时保护、行为监视、包括IOfficeAntivirus（IOAV）在内的防病毒保护、云保护、安全智能更新、对检测到的威胁采取的自动操作，以及对存档文件的扫描。排除项无法修改或添加，通过注册表修改Microsoft Defender防病毒设置的尝试也会被阻止。通过组策略等管理工具所做的更改可能看似成功，但防篡改保护会将其阻止。确实需要更改时，可使用故障排除模式临时禁用防篡改保护。

扫描方式——快速扫描、完全扫描、自定义扫描与脱机扫描

按需扫描文档区分了三种类型：快速扫描、完全扫描和自定义扫描。扫描会立即开始，并且可以定义位置或类型之类的参数。除此之外，Windows安全中心应用的“扫描选项”中还有脱机扫描。

快速扫描会检查所有可能存在随系统启动而注册的恶意软件的位置，例如注册表项和已知的Windows启动文件夹。计划扫描文档说明，它会检查设备的进程、内存、配置文件和特定位置，并补充说在已装载的U盘等可移动设备上也会运行。与始终开启的实时保护结合使用，它能为抵御从系统和内核级别启动的恶意软件提供有力的保护。两篇文档都表示，大多数情况下快速扫描就已足够，并且是计划扫描和按需扫描的推荐选项。恶意文件可能存放在快速扫描未涵盖的位置，但实时保护会扫描每个被打开或关闭的文件，以及用户访问的文件夹中的文件。

完全扫描先执行快速扫描，然后扫描所有已装载的固定磁盘以及可移动或网络驱动器。根据需要扫描的数据量和类型，可能需要数小时甚至数天。它使用扫描开始时已安装的安全智能，因此如果扫描期间发布了新的更新，要检测其中包含的新威胁，需要再进行一次完全扫描。由于涉及的时间和资源，文档说明一般不建议安排完全扫描。

自定义扫描针对指定的文件和文件夹运行。文档给出的例子是U盘或本地驱动器上的某个特定文件夹。

Microsoft Defender脱机扫描是一种可以从受信任的环境启动并运行扫描的反恶意软件扫描工具。由于扫描在正常的Windows内核之外运行，它能够针对试图绕过Windows外壳的恶意软件，例如感染或覆盖主引导记录（MBR）的病毒和rootkit。怀疑感染恶意软件，或希望在恶意软件爆发后彻底确认终结点已清理干净时，可以使用它。路径是：在Windows安全中心应用中依次选择“病毒和威胁防护”“扫描选项”，选中“Microsoft Defender脱机扫描”，再选择“立即扫描”。在提示保存工作的消息中选择“扫描”，在询问是否允许对设备进行更改的提示中选择“是”，随后会出现通知，说明将被注销，Windows会在一分钟内关闭。扫描前必须保存文件并关闭正在运行的程序，扫描大约需要15分钟。完成后终结点会重新启动，Windows正常加载。结果可在“保护历史记录”中查看，在事件查看器的Microsoft-Windows-Windows Defender/Operational日志中，事件ID 2030表示已配置脱机扫描。

脱机扫描有五项先决条件。

  • 硬件：可用于x64的Windows 11和x64/x86的Windows 10。不适用于ARM版Windows 11、ARM版Windows 10以及Windows Server库存单位（SKU）。
  • 帐户与模式：必须以本地管理员权限登录，并且Microsoft Defender防病毒必须是主要防病毒软件，而不是处于被动模式。
  • WinRE：必须启用Windows恢复环境（WinRE）。如果它被禁用，脱机扫描不会运行，也不会显示错误消息，即使手动重新启动计算机也没有任何反应。可用reagentc /info检查状态，若为禁用，则用reagentc /enable启用。
  • BitLocker：如果系统驱动器使用了BitLocker，请在运行脱机扫描之前暂停BitLocker保护。否则，系统重新启动进入脱机环境时，可能会提示输入BitLocker恢复密钥。
  • 更新：按平时的方式获取平台、引擎和安全智能更新。最新的保护更新也可以从Microsoft恶意软件防护中心手动下载并安装。

安装第三方杀毒软件后的三种模式

兼容性文档说明，Microsoft Defender防病毒会处于活动模式、被动模式或禁用三种状态之一。在活动模式下，Defender是设备的主要防病毒软件，文件会被扫描，威胁会被修正，检测结果会列在安全报告和Windows安全中心应用中。在被动模式下，Defender不是主要防病毒软件，它会扫描文件并报告检测到的威胁，但不会删除威胁。在禁用或已卸载状态下，文件不会被扫描，威胁也不会被修正，文档一般不建议禁用或卸载Defender。

被动模式通常只能在已加入Defender for Endpoint的终结点上设置。要以被动模式运行，必须安装另一款防病毒产品并将其用作主要防病毒软件，终结点必须已加入，并且必须启用Windows安全中心服务。下表是文档整理的各种场景。

主要防病毒软件 是否已加入Defender for Endpoint 智能应用控制 Microsoft Defender防病毒状态
Microsoft Defender防病毒 是 开启、评估或关闭 活动模式
Microsoft Defender防病毒 否 关闭或评估 活动模式
Microsoft Defender防病毒 否 开启 混合模型
非Microsoft防病毒软件 是或否 评估或开启 被动模式
非Microsoft防病毒软件 否 关闭 禁用
  • 默认行为：在Windows 10和11上，当非Microsoft防病毒软件成为主要防病毒软件时，Defender会进入禁用模式，而且这种切换是自动发生的。开启智能应用控制后，它会进入被动模式而不是禁用，但文档把这种情况与已加入Defender for Endpoint的设备的被动模式区分开来。
  • 有限的定期扫描：安装其他防病毒软件后，Microsoft Defender防病毒会自动禁用自身，并在Windows安全中心应用中显示出来。此时会出现一个可以启用有限的定期扫描的设置。
  • 重新开启的条件：如果非Microsoft防病毒软件到期、被卸载，或停止提供实时保护，Microsoft Defender防病毒可能会被自动重新启用。
  • 两个引擎的冲突：在Windows客户端上禁用Windows安全中心服务后，Defender无法检测到第三方防病毒软件的安装，会一直保持活动。两者都会尝试提供实时保护，这会影响性能，文档称这是不受支持的配置。

Windows Server则不同。在Windows Server 2016及更高版本、1803及更高版本以及Azure Stack HCI OS 23H2及更高版本上，安装非Microsoft防病毒软件不会让Defender自动进入被动模式，表格中把状态写作“禁用（手动设置）”。在运行非Microsoft防病毒软件的服务器上，可以在提升权限的PowerShell中运行Uninstall-WindowsFeature Windows-Defender来删除Defender（Windows Server 2016还需同时执行Windows-Defender-Gui），并且必须重新启动服务器才能完成删除。要让已加入的服务器保持被动模式，需在注册表项HKLM\SOFTWARE\Policies\Microsoft\Windows Advanced Threat Protection下把ForceDefenderPassiveMode值设为DWORD 1，并且要在加入之前设置。

排除项与勒索软件防护——受控文件夹访问

排除项要从“病毒和威胁防护设置”下的“管理设置”开始。在“排除项”部分选择“添加或删除排除项”，再选择“+ 添加排除项”，就会出现以下选项。

  • 文件或文件夹：也称为路径排除。
  • 文件类型：按文件类型扩展名排除，适用于具有该扩展名的任何文件，无论位于何处。
  • 进程：对指定进程所打开文件的排除。进程本身不会被排除，因此要排除某个进程，请使用文件或文件夹排除。

防篡改保护文档的模式说明中包含这样一项：防篡改保护开启期间，无法修改或添加排除项。

受控文件夹访问（CFA）是Microsoft Defender防病毒中有助于保护文件免受勒索软件侵害的功能，也是Defender for Endpoint的攻击面减少功能之一。在“勒索软件防护”的“管理勒索软件防护”中打开它。

  • 组成部分：CFA由受保护的文件夹（不受信任的应用无法修改或删除其中文件的文件夹）、受信任的应用（可以更改受保护文件夹中文件的应用）和磁盘扇区（存储启动记录的低级别扇区）构成。不受信任的应用尝试操作时，CFA会阻止并可以显示通知，Windows安全中心应用的“保护历史记录”中也会出现相应条目。
  • 默认值与模式：CFA默认关闭。Windows安全中心应用只支持“开”（相当于启用即阻止模式）和“关”，审核模式和仅磁盘修改模式需要用PowerShell、组策略或Intune等其他方式设置。Microsoft建议先在审核模式下评估影响，再转入启用（阻止）模式。
  • 默认保护位置：硬盘启动扇区，以及用户帐户和系统帐户的Documents、Favorites、Music、Pictures、Videos文件夹，还有C:\Users\Public下的Documents、Music、Pictures、Videos文件夹。文件夹被重定向后，CFA会保护重定向后的位置，文档举的例子是OneDrive文件夹重定向把文档、图片或桌面文件夹移到OneDrive文件夹中。默认列表无法修改，但可以再添加更多文件夹。
  • 工作条件：Microsoft Defender防病毒必须是处于活动模式的主要防病毒软件，并且实时保护必须开启。在被动模式、带阻止模式EDR的被动模式、有限的定期扫描以及关闭状态下，CFA不起作用。

对于受信任的应用，Microsoft Defender防病毒会评估.exe、.scr、.dll等所有类型的可执行文件，并根据普及度和信誉自动信任大多数应用。自动信任的应用列表不会显示在Windows安全中心应用或相关cmdlet中，只有当某个应用被阻止、并且能确认其可信时，才需要把它添加到允许列表。添加允许的应用时必须指明其位置，路径中的文件夹部分可以使用环境变量和通配符（*）。而添加要保护的文件夹时，支持网络共享、映射驱动器和环境变量，但不支持通配符，也不要添加本地共享路径（环回），应改用本地路径。

用PowerShell查看状态并运行扫描

不打开界面也可以查看状态。兼容性文档要求通过AMRunningMode的值来确认Defender的模式，受控文件夹访问文档则给出了在提升权限的PowerShell中显示当前CFA模式和默认受保护文件夹的命令。

Get-MpComputerStatus | select AMRunningMode
                    Get-MpPreference | Format-Table EnableControlledFolderAccess
                    (Get-MpPreference).ControlledFolderAccessDefaultProtectedFolders
  • AMRunningMode：“普通（Normal）”表示Microsoft Defender防病毒正以活动模式运行；“被动”表示它在运行但不是主要防病毒软件；“EDR阻止模式”表示正在使用阻止模式下的EDR；“SxS被动模式”表示它与另一款防病毒软件并行运行，并使用了有限的定期扫描。
  • EnableControlledFolderAccess：0或Disabled为默认值，其后依次是1 Enabled、2 AuditMode、3 BlockDiskModificationOnly、4 AuditDiskModificationOnly。默认受保护文件夹列表只有在CFA开启时才会返回。

用Start-MpScan启动扫描，用Start-MpWDOScan启动脱机扫描。后者会把设备重新启动到隔离环境中，以查找持久性恶意软件。

Start-MpScan
                    Start-MpWDOScan

要先以审核模式开启CFA，请使用Set-MpPreference -EnableControlledFolderAccess AuditMode。要把受保护文件夹追加到现有列表，应使用Add-MpPreference -ControlledFolderAccessProtectedFolders，而不是Set-MpPreference，因为Set-MpPreference会用指定的值覆盖现有的值。
