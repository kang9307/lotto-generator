葛根、野葛、粉葛——同一条根的不同名字

葛是东亚山野常见的豆科藤本植物，入药部位是根，药材名就是葛根。学名长期写作 Pueraria lobata，近年的分类多归入 Pueraria montana var. lobata，这就是文献里两个名字并存的原因。

名字多本身不是问题。问题在于名字相近的另一种植物会摆在同一个货架上。先看下面这张表，本文后半部分会好读得多。

常见叫法学名产地与主要用途是否本文对象
葛根、野葛Pueraria lobata（= P. montana var. lobata）中国、韩国、日本。煎煮或制粉是

日本的葛Pueraria lobata日本。葛粉、本葛，以及汉方处方的组成药材是
泰国葛根、白高颗Pueraria mirifica泰国。作为女性保健食品流通不是。是另一种植物

最后一行是本文最重的安全事项。两者同属，名字常被绑在一起，但雌激素活性的强度完全不同。详见第7节。

采收时间与使用部位

  • 根在秋季至次年早春采挖，此时藤蔓落叶、贮藏物质集中于根部
  • 夏季的根纤维粗、淀粉少，煎出量明显偏低
  • 葛花是与葛根分开的另一味药材，本文只谈根
  • 茎的纤维旧时用于织葛布和搓绳，不是可食用部位

主要成分及其被验证到什么程度

谈葛根总会提到四类成分。这里同时写明各自被研究到哪一层。含有某种成分，与该成分在人体内做到你期待的事，是两句话。

淀粉根干重的重要组成，是葛根粉与葛条的原料作为食品成分已确立，与药理主张无关
皂苷与黄酮类植物中常见的次生代谢产物体外抗氧化活性反复得到确认，人体临床获益未获确认

2025年发表于 Frontiers in Pharmacology 的葛根综述列出四张药理作用表，所引研究几乎全部是细胞株与动物模型，人体临床试验在该汇总中基本缺席。这正好说明：葛根论文多，与葛根在人体上被证实有效，是两回事。

指标成分的含义 — 葛根素含量用于判定药材质量，中国药典对葛根与粉葛规定了不同的最低含量。含量标准是辨别是不是同一味药材的尺子，不是衡量疗效大小的刻度。

证据分级表——十项功效拆成三列

常见的十项功效全部保留，只是每项拆成三列。没有删掉任何一项。只在传统记载中出现的，就如实写成只在传统记载中出现。

项目传统记载中有吗有人体研究吗能说到什么程度
1. 解酒毒 有。韩国古籍《东医宝鉴》记葛根解酒毒 有。但可重复的结果是饮酒量下降，不是缓解宿醉 有小规模试验显示，服用标准化提取物的大量饮酒者每周饮酒量减少。没有确认到能消除酒后宿醉的人体证据
2. 保护肝脏 间接。由解酒毒的记载推衍而来 未获确认。反而出现在中草药相关肝损伤的病例清单中 没有依据说葛根护肝。见第8节
3. 调节血糖 有。止消渴的记载 非常少。糖尿病相关结果以动物与机制研究为主 属传统用法，人体证据未获确认。不能代替降糖药
4. 缓解更年期症状 明确记载偏弱，属近代以后附加的用法 有。但该试验没有安慰剂对照组 这是葛根人体数据最厚的一项。骨吸收指标与症状评分有改善，作者自己指出缺少安慰剂对照的局限
5. 心血管健康 部分。与气血运行相关的记述 未获确认。血管扩张与血脂资料来自动物与细胞 属传统用法，人体证据未获确认
6. 感冒初期与退热 强。是葛根汤的核心用途 处方层面有。葛根单味的人体试验未获确认 日本将葛根汤作为药品批准，但那是七味药组成的处方，与葛根汁不是一回事
7. 头痛与眩晕 有。头项强痛相关记载 未获确认 属传统用法，人体证据未获确认
8. 止泻 有。见于葛根黄连汤等处方语境 未获确认 属传统用法，人体证据未获确认。反而是过量摄入导致腹泻的情况有报告
9. 项背与肩颈僵硬 强。写入葛根汤的功能主治 处方层面有。葛根单味未获确认 同第6项。不要把处方与单味药互换着读
10. 抗氧化与皮肤 弱。属近代以后附加的说法 未获确认。体外抗氧化活性就是全部依据 属传统用法，人体证据未获确认

归纳如下。

  • 有人体试验的两项——饮酒量下降与更年期症状。两者样本都小，设计都有局限
  • 只在处方层面获批的两项——感冒初期与肩颈僵硬。那是复方获批，不是葛根单味的证据
  • 作为传统用法保留的五项——血糖、心血管、头痛、止泻、抗氧化与皮肤
  • 需要纠正方向的一项——护肝。不仅没有支持证据，反而列在被监测的一侧

这张表怎么读

「传统记载中有」与「有人体研究」互相替代不了。搞错两者的关系，这张表就失去意义。

这样读是错的应该这样读
古籍里有，所以有效古籍告诉你的是被长期使用过。疗效大小与安全性仍需另行测量
没有人体研究，所以是假的没有研究意味着还没有被测量，与被证明无效不是一回事
动物实验有效，人也一样动物实验剂量常与人的摄入量相差一个数量级，不会直接平移
论文多，所以证据厚比数量更重要的是研究处在哪一层。一百篇细胞实验替代不了一项人体试验
提取物的试验结果适用于自制葛根汁标准化提取物是把成分含量固定下来的制剂，家里煎的汁含量未知

最后一行是本文最常被误读的地方。饮酒量下降的试验使用的是成分含量固定的标准化提取物，按规定剂量服用。家里煎的葛根汁会随产地、根龄与煎煮时间大幅波动，没有理由期待同样的结果。

安全性优先——功效与禁忌出自同一个原因

把安全性放在文章最后，顺序是反的。葛根身上人体数据最厚的一项是缓解更年期症状，而这项效果的原因与禁忌的原因是同一个。

葛根的异黄酮属植物雌激素，会与人体雌激素受体结合并发出较弱的雌激素信号。正因为这个性质，它被用于更年期症状；也正因为同一个性质，在激素依赖性疾病中应当回避。不是一个成立一个不成立，而是同一个作用在不同处境下读法不同。

处境判断原因
乳腺癌、子宫内膜癌、卵巢癌等激素依赖性疾病病史回避。先与主治医生商量类雌激素作用可能与疾病或治疗方向冲突
妊娠期回避没有妊娠期安全性数据。没有数据不等于确认安全
哺乳期回避缺少乳汁转移与影响方面的资料
儿童不建议没有儿童剂量依据。把成人量按体重折算不是证据
计划手术提前两周停用并告知医疗团队可能影响止血与麻醉管理
肝病史或肝功能指标异常回避或先咨询医生见第8节
大豆过敏谨慎，从小量开始试葛是豆科植物
低血压或服用降压药谨慎有指出可能使血压进一步下降
正在接受激素治疗与主治医生商量信号可能与治疗重叠或相抵

常见不良反应

  • 消化道——过量时腹泻、腹痛、恶心。这是最常见的一类
  • 过敏——荨麻疹、皮疹。有豆科过敏者尤其注意
  • 与女性激素相关的表现——乳房胀痛、月经周期改变。出现即停用并就医
  • 头晕——可能与血压下降叠加

应当停用并就医的信号

  • 不规则出血，或月经周期明显改变
  • 皮肤或眼白发黄，尿色变深
  • 无缘由的疲乏持续，并伴食欲下降
  • 右上腹持续不适
  • 荨麻疹扩散，或呼吸不畅

更年期的整体管理另见更年期症状与管理完全指南。葛根只是其中的一个选项，而且不是优先级高的那个。

药物相互作用——开始之前先确认

把葛根当食品看，就很难想到相互作用。但既然类雌激素作用与血液、代谢方面的影响被提出过，正在服用下列药物时，开始之前确认一下更稳妥。

药物类别担心的地方怎么做
他莫昔芬等抗雌激素药植物雌激素可能与药物作用方向冲突未获主治医生确认前不要开始
激素替代治疗、口服避孕药激素信号叠加告知正在服用的药物并交由医生判断
华法林等抗凝药可能影响凝血指标不要自行开始或停用，依指标调整
降压药血压可能进一步下降开始后两周内记录血压
降糖药与胰岛素对血糖的影响可能叠加保留自测记录，异常时咨询
甲氨蝶呤等肝负担较重的药肝指标变化的原因重叠，难以判别服药期间不宜再增加新的草药

怎样向药师描述 — 不要只说「在吃保健品」，而要说「每天喝多少毫升葛根煎煮液」。形态与用量才让判断成为可能。如果是成品，直接把包装带过去最快。

葛根与泰国葛根是两种植物

这一节是本文最具实操意义的安全内容。因为听说葛根含植物雌激素之后，转而去找更强的东西，这条路径是真实存在的。

Pueraria mirifica（泰国称白高颗）与葛根同属，却是不同的种。原产泰国，雌激素活性远强于葛根。作为面向女性的保健食品流通后，问题反复出现。

比较项葛根（Pueraria lobata）泰国葛根（P. mirifica）
产地与分布中国、韩国、日本等东亚地区泰国、缅甸
主要用途药材葛根，以及葛根粉、葛根茶等食品面向女性的保健食品原料
雌激素活性较弱，与大豆异黄酮属同一量级强得多，含米罗雌酚等强效成分
公开受理的危害信息零星日本国民生活中心在2012年度起的五年内收到209件
报告的症状以消化道症状为主腹痛、呕吐、腹泻，皮疹、荨麻疹，月经紊乱与不规则出血
产品检测结果—受检12个品牌中10个确认存在雌激素活性

日本国民生活中心在2017年7月13日的发布中指出危害集中于年轻女性，呼吁不要轻易摄取。厚生劳动省同年在药事与食品卫生审议会上审议了该原料，并向地方政府与相关行业团体发出通知；食品安全委员会也表示，被认为由类雌激素作用引起的健康损害信息有多起报告。一旦感到身体异常应立即停止摄取并就医，是三个机构共同的提醒。

实际分辨的办法

  • 看学名。标签上写 Pueraria mirifica 的就不是葛根
  • 看产地。泰国产的应首先怀疑是这一种
  • 看宣传语。把胸部或身材变化摆在前面的产品，不是葛根产品的说法方式
  • 看剂型。葛根多以汁、茶、粉等食品形态出现，而这一种以片剂、胶囊流通的比例更高
  • 看别名。出现白高颗、Kwao Krua 之类名称的即是它

肝损伤监测——护肝这个说法的真实位置

关于葛根流传最广的一句是「护肝」。这句话起点是古籍中解酒毒的记载，然后从酒跳到肝、再跳到护肝。填补中间那一步的人体证据并未获得确认。

美国国立卫生研究院维护的药物性肝损伤数据库 LiverTox 中有一章名为 Chinese and other Asian Herbal Medicines，处理的是亚洲草药引起的肝损伤。其中引用的一项系统综述的汇总显示，194例草药相关肝损伤中有2例归因于 Pueraria lobata。

没有必要夸大这个数字。194例中的2例，说明它并不是该文档重点讨论的药材。但方向是清楚的：在这份资料里，葛根位于被监测的一侧，而不是提供保护的一侧。把这份文档当作葛根护肝的依据来引用，与文档本身所说的正好相反。

常见说法实际可确认的内容
葛根保护肝脏人体证据未获确认
葛根能防止酒精性肝损伤停留在动物实验层面，没有移到人体的结果
天然的东西不会给肝脏负担草药相关肝损伤本身就是一个研究领域。天然与否不是安全依据
吃了葛根就可以照常喝酒没有任何资料支持。见第9节

葛根酒终究是酒

葛根酒的泡法下面照录。但顺序上这句话在前：葛根酒是酒。它是把根泡在25至35度的烧酒里，泡制过程不会让酒精消失。

  • 加了葛根并不能抵消酒精的风险。对肝脏、血压、睡眠与依赖的风险原样保留
  • 「保健酒」是习惯性的叫法，不是成分说明
  • 包括世界卫生组织在内的卫生机构并未给出所谓安全饮酒量的界线
  • 自泡酒难以判断度数，加了糖和材料之后口感度数会低于实际
  • 有肝病或在服用加重肝负担的药物时，最好把葛根酒直接排除在选项之外
  • 准备开车时，以及妊娠期、哺乳期不要饮用

如果目的是摄取葛根的成分，茶或汁比酒更合理。葛根酒更接近于为了风味和泡制乐趣而选择的东西。

中国的葛根——药食同源与流通形态

在中国，葛根长期同时走两条路：一条是作为中药材的葛根，一条是作为食材的葛根。同一条根，用途不同，能说的话也不同。

类别需要确认什么能否标注功效
普通食品（葛根粉、葛根茶）品名、配料表、生产者、保质期、营养成分不能
保健食品批准文号与规定的标示内容只能在批准范围内标注保健功能
中药材葛根按药材标准把关，属处方与调剂的范围不属于食品标示规则的范围
进口的葛根汁等成品中文标签、原产国、配料与含量依进口地与销售地规则而定

有两点在实际购买时最有用。

  • 葛根与粉葛在药材层面是分开的两味。中国药典按不同来源与葛根素含量分别收载，野葛偏药用、粉葛淀粉更多而偏食用。市面上混用普遍，买来煲汤和买来入药并不总是同一种东西
  • 普通食品上不能写功效。如果一款葛根粉或葛根汁把疗效放在包装正面，那说明它已经越出了标示规则，这个卖家的其他说明也没有理由用更重的分量去读

常见的流通形态

  • 葛根粉——最常见的形态，用开水冲成糊。注意配料表是否只有葛根，有的会掺入其他淀粉
  • 葛根干片——用于煲汤和煎煮，便于分量控制
  • 鲜葛根——菜市场可见，多用于煲汤，此时它是食材而非药
  • 葛根茶包与葛根丸——注意是单一原料还是复配
  • 韩国产的葛根汁——把根长时间煎煮浓缩后的袋装液体。原料植物与中国的野葛相同，但与葛根粉的内容物不同：葛根粉以淀粉为主，煎煮液则含异黄酮等可溶出的成分。韩国的标示规则中，普通食品不能标注功能性，标有「非保健功能食品」字样的产品即属此类，值得在下单前看清

葛根汁的做法——从材料到保存

家庭煎煮的方法多年未变。以下是传统做法，与成分含量固定的制剂不是一回事，这一点前面已经写明。

材料用量用途
葛根1公斤主材料
水2至3升提取用
红枣10颗（可选）甜味与香气
生姜30克（可选）风味
蜂蜜或糖适量（可选）调整甜度

第一步：清洗与处理

  • 用流水冲洗，去掉泥土与杂质
  • 皮可以不去，但要切掉损伤和过厚的部分
  • 切成0.5至1厘米的薄片，太厚会明显拖慢煎出
  • 使用干葛根时可直接下锅

第二步：煎煮

  • 大锅里放入切好的葛根，加水没过（每公斤葛根加水2至3升）
  • 大火烧开后转中火
  • 煎煮2至3小时，水少了少量补入
  • 要加红枣和生姜的话，在这一步一起放
  • 不锈钢、玻璃或砂锅比铝锅更合适

第三步：过滤与浓缩

  • 用纱布或细滤网滤去固形物
  • 滤液回锅小火再收1至2小时
  • 太浓可以补一点水
  • 浮沫及时撇掉

第四步：放凉与保存

  • 完全放凉后装入消毒过的玻璃瓶
  • 冷藏并在两周内喝完
  • 要放更久就分装冷冻，解冻后不再复冻
  • 发酸或表面起膜就丢弃

保存最容易出问题的地方 — 加糖的汁在常温下变质很快。趁热装瓶拧盖会产生冷凝水，反而更危险。请放凉后再装。

葛根汁的服用方式与其局限

传统上使用的量如下。但这些数字是习惯，不是临床试验验证过的剂量。没有办法把标准化提取物试验的剂量换算成家里煎的汁。

  • 日常——每天2至3次，每次30至50毫升，用水稀释后饮用
  • 第一次喝——从一半以下开始，观察消化道反应
  • 时间——空腹喝浓汁可能不适，饭后更稳妥
  • 周期——若打算连续喝几个月，中间安排间歇，并留意体检时的肝功能指标

把期待值理一理。

期待现实的回答
喝了宿醉就没了人体证据未获确认。少喝酒本身更可靠
可以减少降糖药不行。调整药物属于医生的范围
更年期症状会消失有试验显示症状评分改善，但没有安慰剂对照，谈不上消失
喝得越多越好不是。过量会导致腹泻和腹痛
可以代替药物不能。已确诊的疾病属于治疗的范围

葛根酒的泡制方法

在保留第9节前提的基础上，照录传统泡法。

材料用量备注
葛根500克鲜品或干品
烧酒（25至35度）1.8升泡制用
糖或蜂蜜200至300克（可选）调整甜度
红枣10至15颗（可选）增香

第一步：材料准备

  • 鲜葛根洗净后彻底沥干，残留水分会明显提高变质风险
  • 阴凉处晾2至3天
  • 切成3至5厘米的块
  • 干葛根可直接使用

第二步：装罐

  • 玻璃罐用沸水或酒精消毒并完全晾干
  • 放入葛根，倒酒至完全没过材料
  • 要加红枣的话，洗净沥干后一起放入
  • 加糖或蜂蜜并搅拌溶解
  • 盖紧后置于阴凉避光处

第三步：陈化

  • 至少放置3个月
  • 每周轻轻摇动一次
  • 6个月到1年是常被推荐的区间
  • 据说放2至3年香气会更深
  • 材料浮出酒面时要压下去，露出的部分会长霉

第四步：过滤与保存

  • 用纱布滤掉固形物
  • 换到干净瓶子里，置于阴凉避光处
  • 变浑浊或有异味就不要再喝

葛根茶的煮法

这是负担最轻的形态，分量好控制，浓度也容易保持在低位。

材料

  • 干葛根30至50克（或鲜葛根100克）
  • 水2升
  • 红枣5颗（可选）
  • 生姜20克（可选）

做法

  1. 把葛根冲洗一下
  2. 锅中放入葛根与水，开火
  3. 水开后转小火，煮30分钟至1小时
  4. 水收到一半左右即可关火
  5. 过滤后饮用

喝法

  • 温热饮用，每天2至3次
  • 夏天可以放凉冷藏，但要在2至3天内喝完
  • 要加甜味用蜂蜜，但请把糖计入摄入量
  • 浓茶空腹饮用可能不适

怎样挑选葛根

形态需要确认需要避开
鲜葛根切面发白有淀粉感、质地硬实发软的部位、霉味、过细的根
干片密封包装、生产日期与保质期过分发白（疑似漂白）、变色、杂质
袋装葛根汁葛根含量标示、原产地、添加物清单不标含量、把功效放在正面的标示
丸剂与粉剂配料表是单一葛根还是复配成分交代不清的复配品
葛根粉是否掺入其他淀粉以红薯或马铃薯淀粉为主的产品
  • 产地标示不是绝对的质量标准，写上地名并不保证成分
  • 无添加的标示要翻到背面看究竟没加什么，正面文案说明不了问题
  • 价格极低的汁有时葛根含量很低，主要成分是水和糖
  • 进口不等于有问题，标示是否清楚才是判断标准

搭配的材料——协同这个词的边界

把别的材料掺进葛根一起喝是很久以来的习惯。但这里的「协同」多数时候指的是口感与好入口。两种材料相加会让效果相乘，这在人体层面并未获得确认。

材料实际得到的是什么常见组合
红枣甜味与香气，压住葛根特有的涩味与葛根茶一同煮
生姜辛香收住尾味葛根汁里加少量姜汁
蜂蜜甜味。请计入糖的摄入量冲入葛根茶
枳椇子习惯性搭配。效果相加在人体层面未获确认混合茶
枸杞颜色与香气，属习惯性搭配葛根酒中少量加入
木瓜（榠楂）香气，冬季混合茶的常见搭配混合茶

再补一句：一次同时增加多种草药，出问题时会很难定位原因。新开始时一次只加一样更稳妥。

分季节的用法

春夏

  • 放凉的葛根茶冷藏后饮用，保存期按2至3天来算
  • 用葛根粉做凉糕或面食，这属于烹饪而不是用药
  • 夏天常温放置直接导致变质，袋装成品开封后也要冷藏

秋冬

  • 热的葛根茶，习惯上用于感冒初起时的咽部不适
  • 葛根粉用于羹汤勾芡，这是把淀粉当食材用
  • 秋天采挖的根是传统上用来煎汁的原料
  • 冬天泡的酒，通常在第二年秋天以后过滤

历史与文化——从救荒作物到药材

葛在成为药之前先是吃的东西。荒年时人们挖根沉淀出淀粉充饥，茎的纤维用来织布搓绳。因为山野自生、随挖随有，它在饥荒记载中反复出现。

  • 《东医宝鉴》——记葛根性平味甘无毒，止消渴、轻身、解酒毒
  • 《本草纲目》——把葛根与葛花分开处理，各自列出用法
  • 救荒——朝鲜时代的饥荒记录中葛根淀粉反复出现
  • 葛布——用茎纤维织成的布，用于夏衣与绳索

各地不同的位置

地区主要形态制度上的位置
中国葛根粉、葛根干片、鲜葛根既作药材也作食材使用的原料
韩国葛根汁、葛根茶、葛根酒、葛根粉既是药材葛根，也是食品原料
日本葛粉、本葛、葛汤、葛条和菓子材料，同时是汉方处方葛根汤的组成药材
美国以膳食补充剂形态为主膳食补充剂，在南部也是有名的入侵物种

葛根汤出自《伤寒论》，在东亚各地一直沿用，而日本把它纳入了现代药品制度。日本厚生劳动省的一般用汉方制剂批准基准把葛根汤收作第23个处方，组成药材为葛根、麻黄、大枣、桂皮、芍药、甘草、生姜；批准的功能主治是体力中等以上者的感冒初期（未出汗）、鼻塞流涕、鼻炎、头痛、肩颈僵硬、肌肉痛、手与肩的疼痛。医疗用制剂在此基础上还加上热性疾病初期、炎症性疾病、上半身神经痛与荨麻疹。

这里有一点必须分清：葛根汤获批的是七味药按固定比例组成的处方，不是葛根单味的证据。喝葛根汁与服用葛根汤是两件事。葛根汤中含有提供麻黄碱的麻黄以及甘草，因此在心脏病、高血压、甲状腺功能亢进时需要注意，甘草引起的假性醛固酮增多症也是已知的不良反应。

没能确认的内容

本文没能确认的项目集中放在这里，散在各节里反而不好读。

  • 家庭煎煮葛根汁的成分含量——随产地、根龄与煎煮时间变化，无法与提取物试验的剂量对应
  • 长期摄取的安全性——没有找到连续数月以上的人体资料
  • 儿童剂量——没有依据
  • 妊娠期与哺乳期的安全性——没有资料。没有资料不等于确认安全
  • 葛根与其他草药合用的相互作用——没有找到按组合区分的资料
  • 葛根单味用于感冒的人体研究——处方层面的批准已确认，单味试验未能确认
  • 葛根汁与葛根酒的成分差异——没有找到水提与醇提各溶出多少的定量比较

结语——该怎样对待葛根

葛根是被吃了很久的一条根，对多数人来说喝点茶或汁并无特别之处。问题在期待值。把十项功效照单全收、拿它替代药物，风险就从那里开始。

归纳成三句话。

  • 有人体证据的只有饮酒量下降与更年期症状两项，而且局限都很明显。其余属于传统用法
  • 植物雌激素这个性质同时造出了功效与禁忌。有激素相关疾病或正在接受相关治疗，开始之前先告诉主治医生
  • 泰国葛根不是葛根。不要顺着「找更强的」这个方向走下去

享受一杯葛根茶，和试图用葛根治病，是两件不同的事。前者照本文的做法用就好。后者的话，把在吃的药和确诊的病整理出来给医生或药师看，会更快。

开始的时候 — 先用小量观察两周，确认消化道、皮肤与月经方面没有变化后再调整用量。若正在服药，请先做确认。

## 0. 一句话

葛根的十项功效中，有人体试验支撑的只有两项。其余属于传统用法，这本身不是缺点。缺点在于把两者用同样的分量去讲。

| 项目 | 传统记载 | 人体研究 | 能说到什么程度 |
|---|---|---|---|
| 1. 解酒毒 | 有（《东医宝鉴》） | 有 — 但结果是饮酒量下降 | 每周饮酒量减少的小规模试验。不是能消除宿醉的依据 |
| 2. 保护肝脏 | 间接，由解酒毒记载推衍 | 未获确认 | 没有依据。反而出现在中草药相关肝损伤清单中 |
| 3. 调节血糖 | 有（消渴） | 非常少，以动物与机制研究为主 | 属传统用法。不能代替降糖药 |
| 4. 缓解更年期症状 | 偏弱，属近代以后附加 | 有 — 无安慰剂对照 | 人体数据最厚的一项。作者自己写明局限 |
| 5. 心血管 | 部分 | 未获确认 | 属传统用法 |
| 6. 感冒初期 | 强（葛根汤） | 仅处方层面 | 葛根汤是七味药的处方，与葛根汁不是一回事 |
| 7. 头痛与眩晕 | 有 | 未获确认 | 属传统用法 |
| 8. 止泻 | 有 | 未获确认 | 属传统用法。过量反而导致腹泻 |
| 9. 项背与肩颈僵硬 | 强（葛根汤） | 仅处方层面 | 同第6项 |
| 10. 抗氧化与皮肤 | 弱 | 未获确认 | 属传统用法。依据只有体外活性 |

统计: 人体试验2 · 仅处方层面2 · 传统用法5 · 需纠正方向1。

## 2. 读这张表的规则

| 这样读是错的 | 应该这样读 |
|---|---|
| 古籍里有，所以有效 | 只说明被长期使用过。疗效与安全要另行测量 |
| 没有人体研究，所以是假的 | 意思是还没被测量，与被证明无效不同 |
| 动物有效，人也有效 | 剂量差一个数量级，不会直接平移 |
| 论文多，证据就厚 | 层次更重要。一百篇细胞实验不及一项人体试验 |
| 提取物的结果适用于自制的汁 | 标准化提取物含量固定，煎煮的汁含量未知 |

## 3. 安全核对清单 — 开始之前过一遍

- [ ] 妊娠期或有备孕计划 → 不要开始
- [ ] 哺乳期 → 不要开始
- [ ] 有乳腺癌、子宫内膜癌、卵巢癌等激素依赖性疾病病史 → 未获主治医生确认前不要开始
- [ ] 正在接受激素治疗 → 先告诉主治医生
- [ ] 未满18岁 → 不建议（没有儿童剂量依据）
- [ ] 两周内有手术安排 → 停用并告知手术团队
- [ ] 有肝病史或肝功能指标异常 → 回避或先咨询
- [ ] 对大豆过敏 → 从小量开始观察
- [ ] 低血压或在服用降压药 → 开始后两周记录血压
- [ ] 已把在吃的药全部写下来 → 与下面第5项表格核对
- [ ] 打算喝的形态是酒（葛根酒） → 加了葛根并不能抵消酒精的风险

只要有一项符合，开始之前先取得确认更稳妥。

## 4. 应当停用并就医的信号

- 不规则出血，或月经周期明显改变
- 皮肤或眼白发黄，尿色变深
- 无缘由的疲乏持续，并伴食欲下降
- 右上腹持续不适
- 荨麻疹扩散，或呼吸不畅

## 5. 药物相互作用核对表

| 正在吃的药 | 担心的地方 | 该做什么 |
|---|---|---|
| 他莫昔芬等抗雌激素药 | 作用方向冲突 | 未获确认前不要开始 |
| 激素替代治疗、口服避孕药 | 激素信号叠加 | 告知正在服用的药 |
| 华法林等抗凝药 | 凝血指标变化 | 不要自行开始或停用 |
| 降压药 | 血压进一步下降 | 记录两周血压 |
| 降糖药与胰岛素 | 血糖影响叠加 | 保留自测记录 |
| 甲氨蝶呤等肝负担重的药 | 原因无法判别 | 不要再增加新的草药 |

## 6. 葛根与泰国葛根的区分表

| 项目 | 葛根（Pueraria lobata） | 泰国葛根（P. mirifica） |
|---|---|---|
| 产地 | 东亚 | 泰国、缅甸 |
| 用途 | 药材葛根，以及葛根粉、葛根茶等食品 | 面向女性的保健食品原料 |
| 雌激素活性 | 弱，与大豆异黄酮同量级 | 强得多，含米罗雌酚等 |
| 公开的危害信息 | 零星 | 日本国民生活中心在2012年度起五年内收到209件 |
| 报告的症状 | 以消化道为主 | 腹痛、呕吐、腹泻，皮疹、荨麻疹，月经紊乱与不规则出血 |
| 产品检测 | — | 受检12个品牌中10个确认存在雌激素活性 |

从标签上排除的五点: ①学名里有 mirifica ②产地为泰国 ③宣传语主打胸部或身材变化 ④以片剂胶囊为主 ⑤出现白高颗、Kwao Krua 等名称。

## 7. 各地形态对照

| 地区 | 常见形态 | 制度上的位置 | 购买时看什么 |
|---|---|---|---|
| 中国 | 葛根粉、干片、鲜葛根 | 药材与食材两用 | 葛根（野葛）与粉葛是两味不同药材 |
| 韩国 | 袋装葛根汁、葛根茶、葛根丸、葛根粉、葛根酒 | 既是药材也是食品原料 | 标注非保健功能食品的字样与葛根含量 |
| 日本 | 葛粉、本葛、葛汤、葛条，以及葛根汤 | 食品，同时是汉方处方的组成药材 | 葛根汤属药品，葛粉属食品 |
| 美国 | 提取物胶囊与片剂 | 膳食补充剂 | 不得宣称治疗疾病，注意免责声明 |

## 8. 标签核对项目

- [ ] 葛根含量以数字标出
- [ ] 配料表能看出是单一葛根还是复配
- [ ] 原产地清楚
- [ ] 已在背面确认添加物与含糖量
- [ ] 若标有学名，已确认是 lobata 而非 mirifica
- [ ] 没有把功效放在正面的标示（有则已越出规则）
- [ ] 有生产日期与保质期
- [ ] 写明开封后的保存条件
