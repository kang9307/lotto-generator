メニュー名とショートカットキーは、Microsoft サポートの韓国語版ドキュメントに書かれている語句をもとに日本語へ置き換えたものである。基準は Windows 版 Microsoft 365 の PowerPoint で、ドキュメントを参照した日は 2026年10月5日である。参照したドキュメントの更新日は確認できなかった。リボン名やメニューの位置はバージョンやアップデートで変わりうるため、画面と違う場合は公式ドキュメントの該当項目をあらためて探す必要がある。この案内は画面を実際に見た結果ではなくドキュメントの記述に基づいており、ドキュメントで確認できなかった項目は後半の「確認できなかったこと」にまとめた。

最初に決めること - 基準バージョンと「何を・なぜ・どこで」

初めて PowerPoint を使う人がつまずくのは、機能が足りないからではなく、どのメニューをどの順序で使うのかがわからないからである場合が多い。同じフォントのない PC で開くとフォント・レイアウト・スタイルが変わることがあり、埋め込みはそれを防ぐ方法だとドキュメントは説明している。以下はスライド一式を作る順序に沿って、項目ごとに何をするのか、なぜその段階でするのか、どのメニューでするのかを書く。

  • 基準の製品: Windows 版 Microsoft 365 の PowerPoint。新しいプレゼンテーションの作成、テーマ、ファイルサイズのドキュメントの対象製品の一覧には PowerPoint 2024・2021・2019・2016 も並び、PDF のドキュメントの一覧には Mac 版の製品も並んでいる。
  • メニューの表記と macOS: 「ホーム > 新しいスライド」のようにタブ > ボタンの順で書く。名前は韓国語ドキュメントの語句を日本語にしたもので、日本語版の画面の表記と少し違う場合は項目の位置を手がかりにする。ドキュメントが macOS の手順を別に書いている項目(PDF 保存・マスター表示を閉じる・オブジェクトの配置のスマートガイド)だけ違いを添え、それ以外の macOS と Web の違いは扱わない。
  • 範囲: ドキュメントで確認できた項目(新しいプレゼンテーション・レイアウト・スライドマスター・テーマ・オブジェクトの配置・スライド一枚あたりのテキスト量・発表のショートカット・発表者ツール・PDF・フォント埋め込み・ファイルサイズ)だけを扱い、確認できない項目を推測で埋めない。

スライド一式を作る順序の全体像

次の表は作業の順序と各段階のメニュー位置である。アニメーションを付ける段階は、ドキュメントで確認した範囲にないため含めていない。順序はドキュメントが定めたものではなく、項目どうしが依存する向きに沿って並べたものである。

順序何をするかなぜこの段階かどこで(ドキュメントの表記)
1スライドマスターで色・フォント・ロゴを決めるドキュメントはマスターを、色・フォント・タイトル・ロゴなどのスタイルに一貫性を加え、形を統一する道具と説明している表示 > スライドマスター
2スライドごとにレイアウトを選ぶテキスト・図・グラフを入れるプレースホルダーの配置があらかじめ定義されているホーム > 新しいスライド / ホーム > スライドのレイアウト
3発表のやり方を覚える開始・終了・空白画面のキーを知っていれば、本番中にマウスを探さずに済むF5 · Shift+F5 · Esc など
4発表者ツールを有効にする聴衆にはスライドだけ、発表者には次のスライド・ノート・タイマーが見えるスライドショー > 発表者ツールを使用する
5PDF として保存するPDF にすると書式とレイアウトが固定され、PowerPoint がなくてもスライドを見られる(変更はできない)ファイル > エクスポート > PDF/XPS ドキュメントの作成
6フォントを埋め込むフォントがない PC で開いたときに見た目が変わるのを防ぐファイル > オプション > 保存
7図を圧縮するメールやアップロードの上限に引っかかる大きなファイルを小さくする図の形式 > 調整 > 図の圧縮

マスターを先に決める理由は、ドキュメントがマスターを説明する一文に集約される。色、フォント、タイトル、ロゴなどのスタイルに一貫性を加え、プレゼンテーションの形を統一するというものである。

実際の作業順序は新しいプレゼンテーションの作成、1、2、内容の作成、3・4 の練習、5・6・7 の配布準備である。新しいプレゼンテーションは PowerPoint を開いてサイドペインで新規を選んで始め、メニューの詳細は下のレイアウトの節に書いた。1 を飛ばして 2 から始めてもファイルはできる。ただしドキュメントはマスターを一貫性を加え形を統一する道具と説明しており、共通スタイルを使うなら、マスターを先に開く順序がその説明に合う。

スライドのレイアウト - スライドごとに選ぶ枠

ドキュメントはレイアウトを次のように定義している。PowerPoint の各テーマには、スライドの内容のためにあらかじめ定義された配置であるレイアウトの集まりが含まれる。レイアウトの中のプレースホルダーのボックスは、テキスト、ビデオ、図、グラフなどを置く場所である。つまり「タイトルとコンテンツ」のような枠を選べば、タイトルのボックスと本文のボックスの位置と大きさはすでに決まっていて、使う人はその中を埋める。

  • 新しいプレゼンテーションを始めるとき: PowerPoint を開き、サイドペインで新規を選ぶ。最初から作るには空白のプレゼンテーション、用意されたデザインを使うにはテンプレートのいずれか、PowerPoint の使い方のヒントを見るにはツアーを選んでから作成を選ぶ。ドキュメントは、Microsoft Create のプロがデザインしたテンプレートから始めることもできると付け加えている。スライドの追加は、サムネイルで直前に置くスライドを選び、ホームタブのスライドのグループで新しいスライドを選ぶ。内容はテキストボックスの中にカーソルを置いて入力し、書式はテキストを選んでホームタブのフォントのグループで決める。図は挿入タブの画像のグループから、図形・アイコン・3D モデル・SmartArt・グラフはイラストのグループから入れる。
  • 新しいスライドにレイアウトを決めるとき: ホームタブで新しいスライドを選び、希望のレイアウトを選ぶ。新しいスライドを追加する時点で枠が決まる。
  • 作成済みのスライドの枠を変えるとき: スライドを選んでから、ホーム > スライドのレイアウトで希望のレイアウトを選ぶ。
  • 形が崩れたとき: ホーム > リセットを選ぶと元のレイアウトに戻る。ドキュメントは、この操作が追加した内容を削除しないと書いている。
  • プレースホルダーの役割: ドキュメントの定義では、プレースホルダーはテキスト、ビデオ、図、グラフなどの内容が入る決まった枠である。枠が決まっているので、毎回ボックスを描かなくても、同じ位置に同じ種類の内容を置ける。手で描いたテキストボックスがマスターの変更にどう反応するかは、ドキュメントでは確認できなかった。レイアウトでプレースホルダーを追加・編集・削除する方法は別のドキュメントにあり、参照していない。
  • レイアウトに含まれるもの: ドキュメントは、レイアウトにテキスト、ビデオ、図、グラフ、図形、クリップアート、背景などのためのプレースホルダーがあり、テーマの色、フォント、効果などの書式も含まれると書いている。定義済みレイアウトの例は、開始用のタイトルスライド、一般的なタイトルとコンテンツ、並べて比べる比較、キャプション付きの図である。標準のレイアウトは、標準表示のホームタブでレイアウトをクリックし、スライドの内容に最もよく合うものを選ぶ。
  • 図形・図の配置: 複数のオブジェクトを選ぶには、最初のオブジェクトを選び、Ctrl キーを押したまま他のオブジェクトを選ぶ。図なら図の形式タブ、図形・テキストボックス・WordArt なら図形の書式タブの配置グループで配置を選び、メニューから左揃え、中央揃え、右揃え、上揃え、中央揃え、下揃えのいずれかを選ぶ。中央揃えは二度並び、説明はオブジェクトの中心を通る縦方向と、中央を通る横方向の配置である。配置のオプションが使えないときは、一つしか選ばれていない可能性があると書かれている。等間隔に並べるには三つ以上を選び、左右に整列または上下に整列を選ぶ。テキストの後ろに隠れたり重なったりしているオブジェクトを選ぶには、ホームタブで選択を選び、オブジェクトの選択を選んで、オブジェクトの上に枠を描く。macOS の PowerPoint の節では、図形の書式タブ > 配置でスライドに合わせるを選ぶ方法と、オブジェクトをドラッグすると現れるスマートガイド(表示メニュー > グリッドとガイド > スマートガイド)が説明されている。
  • スライド一枚あたりのテキスト量: ドキュメントは行数や単語数のような数値は示していない。「テキストをシンプルに保つ」の項目で、箇条書きか短い文を使い各行を1行に収める(折り返さない)よう述べ、聴衆に画面を読ませず発表を聞かせたいからだと理由を書いている。一部のプロジェクターはスライドの端を切るため、長い文が切れることがあるという点も挙げる。フォントは Arial や Calibri のような単純なものを選び、非常に細いものや装飾的なものは避け、18pt より小さいフォントサイズは使わないよう書いている(聴衆が遠くにいる大きな部屋ではもっと大きく)。背景色とテキストの色の間には高いコントラストを使うよう述べ(テーマが明るい背景に暗いテキスト、またはその逆のコントラストを自動で設定する)、スペルと文法の確認も勧めている。

スライドマスター - なぜ先に決めるのか

ドキュメントによれば、スライドマスターは色、フォント、タイトル、ロゴなどのスタイルに一貫性を加え、プレゼンテーションの形を統一する道具である。同じドキュメントは、マスターで色・フォント・効果を編集し、プレースホルダーを移動・非表示・表示し、スライドの向きを縦から横へ(またはその逆に)変えられると書いている。ドキュメントはマスターを一つ以上作成できると書き、再利用するテンプレートとして保存する方法(ファイル > 名前を付けて保存でファイルの種類をテンプレートに変える)も案内している。

「なぜ先に」というドキュメントの答えは、マスターの定義にある。色、フォント、タイトル、ロゴなどのスタイルに一貫性を加え、プレゼンテーションの形を統一する道具なので、共通のスタイルをマスターで決めるのがドキュメントの説明に合う。ドキュメントは、マスターで変えた内容がすでに作ったスライドにどう伝わるかは説明していない。

  1. 表示タブでスライドマスターを選ぶ。Windows と macOS のどちらも同じタブ名がドキュメントに書かれている。
  2. スライドのサムネイル窓では、マスターは上の大きなスライド画像で、つながったレイアウトはその下に置かれる。組み込みのレイアウトを削除するには、削除するレイアウトを選び、スライドマスタータブで削除を選ぶ。
  3. マスターで色、フォント、効果を変える。スライドの向きは、スライドマスタータブのスライドのサイズ > ユーザー設定のスライドのサイズで向きを選んで決める。
  4. 必要なプレースホルダーを移動し、非表示にし、または表示する。特定の種類のスライドにフッター(スライド番号・日付・フッターのテキスト)を出すかどうかは、サムネイル窓でレイアウトを選び、スライドマスタータブのフッターを選ぶかオフにして決める。
  5. 作業が終わったら、スライドマスタータブでマスター表示を閉じるを選ぶ。macOS では同じ位置にマスターを閉じるがある。
  • テーマで色とフォントを変える方法: マスターのドキュメントが別のドキュメントとして案内している「テーマを使ってスライドに色とデザインを追加する」によれば、PowerPoint は調整された配色、背景、フォントスタイル、プレースホルダーの配置を備えたデザインテーマを提供する。新しいプレゼンテーションを始めるときはファイル > 新規でテーマを選べ、後からはデザインタブで好みの色・フォント・効果のテーマを選ぶか、バリアントのグループで別の色のバリエーションを適用する。バリアントの下向き矢印から色、フォント、効果、背景のスタイルを選ぶか自分で指定でき、終えたら現在のテーマを保存で名前を付けて保存すると、ユーザー設定の見出しの下のテーマのグループに表示される。組み込みテーマはワイドスクリーン(16:9)と標準画面(4:3)のどちらにも使え、バリアントが表示されないときはユーザー設定テーマや旧バージョン用のテーマを使っているか、そうしたテーマのスライドを取り込んだためかもしれないとドキュメントは書いている。
  • マスターに触れていないスライド: すでに作ったスライドで個別に付けた書式は、マスターの変更とは別に残ることがある。ドキュメントはこれを明記していないので、マスターを変えた後は数枚のスライドを開いて見た目を確かめるのが安全である。
  • 一つのプレゼンテーションに複数のマスター: スライドのサムネイル窓で新しいマスターを置く位置をクリックし、スライドマスタータブでスライドマスターの挿入を選ぶ。「一つのプレゼンテーションで複数のスライドマスターを使う」という別のドキュメントがあるが、参照していない。

発表の開始 - スライドショーのショートカットと発表者ツール

発表用のショートカットは、Microsoft サポートのショートカットのドキュメントで確認できたものだけを書く。ドキュメントは Windows、macOS、Web のショートカットを別々に扱い、プレゼンテーション中にショートカットの一覧を開くキーが Windows は F1、macOS はスラッシュ(/)で違うと書いている。以下の表記は Windows 基準である。

キー動作(ドキュメントの語句)使う場面
F5プレゼンテーションを最初から開始する最初のスライドからの通しリハーサルや本番
Shift+F5現在のスライドからプレゼンテーションを開始する編集中のスライドの見た目をすぐショー画面で確認する
Alt+F5発表者ツールでプレゼンテーションを開始するノートとタイマーを見ながら練習する
Escプレゼンテーションを終了するショーを終えて編集画面に戻る
N、Enter、Page Down、右矢印、下矢印、スペースバー次のアニメーションを実行するか、次のスライドに進む先へ進めるとき
P、Page Up、左矢印、上矢印、Backspace前のアニメーションを実行するか、前のスライドに戻る前に戻るとき
B またはピリオド(.)黒い空白のスライドを表示する、またはそこから戻る聴衆の視線を話し手に集めるとき
W またはカンマ(,)白い空白のスライドを表示する、またはそこから戻る明るい画面で一時的に画面を空けるとき

F5 と Shift+F5 の違いは、編集中に最もよく使われる。作業中のスライドが15番なら、F5 は1番から15番まで進める必要があるが、Shift+F5 は15番からすぐ始まる。次・前のスライドへ進むキーは、表の最後の二行にドキュメントの語句のまま書いた。特定のスライドへ移動するにはスライド番号を入力して Enter キーを押し、すべてのスライドのダイアログは Ctrl+S、最初のスライドは Home、最後のスライドは End で移動すると同じドキュメントは書いている。ショー中は Ctrl+L でレーザーポインター、Ctrl+P でペンを開始し、E キーで画面の注釈を消すとも書いている。

  • 発表者ツールの有効化: スライドショータブで発表者ツールを使用するチェックボックスを選び、発表者ツールを表示するモニターを選んでから、F5 を押すか最初からを選ぶ。
  • 発表者ツールに表示されるもの: 現在のスライド、次のスライド、発表者ノートである。スライド番号の横の矢印でスライド間を移動し、タイマーの一時停止・リセットをし、現在の時刻を確認し、ノートのフォントを拡大・縮小し、描画とレーザーポインターのツールを使い、スライドを拡大し、画面を一時的に黒くできるとドキュメントは書いている。
  • なぜ使うのか: ショートカットのドキュメントは、発表者ツールを、一つの画面(たとえばノート PC)で発表者ノートと一緒にプレゼンテーションを見て、聴衆は別の画面でノートのないプレゼンテーションを見る方式だと説明している。
  • モニターが一つのとき: 二つ目のディスプレイにつながっていると、スライドショーの開始時に発表者ツールが自動で表示される。自動で始まらない場合は、スライドショータブで発表者ツールを使用するチェックボックスを選び、メインのモニターを選ぶ。ディスプレイが一つだけのときも、発表者ツールで開始するには Alt+F5 を押すとショートカットのドキュメントは書いている。発表者ツールの中では、F6 キーで領域を巡回し、Tab キーで領域内のツールを巡回し、Esc キーで発表者ツールを閉じる。
  • ノートとスライド間の移動: 発表者ツールのドキュメントは、プレビューのアイコンでプレゼンテーションのすべてのスライドを表示し、別のスライドにすばやく移動できると書いている。発表者ノートを追加する方法は「プレゼンテーションを開始して発表者ツールでノートを見る」という別のドキュメントにあり、参照していない。

PDF として保存・エクスポートする

PDF 保存のドキュメントの対象製品は、Microsoft 365 の PowerPoint、Mac 版 Microsoft 365 の PowerPoint、PowerPoint 2024、Mac 版 PowerPoint 2024、PowerPoint 2021、Mac 版 PowerPoint 2021、PowerPoint 2019、PowerPoint 2016 である。ドキュメントは、PDF として保存すると書式とレイアウトが固定され、PowerPoint がなくてもスライドを見られるが変更はできないと説明している。

  1. ファイル > エクスポートを選び、PDF/XPS ドキュメントの作成を選んで、続けて PDF/XPS の作成を選ぶ。
  2. 保存場所を選び、ファイル名を入力する。
  3. 最終的な PDF の見た目を決める。最適化では、印刷のように高品質が必要なときは標準、ファイルをより小さくするときは最小サイズを選ぶ。
  4. 発行を選ぶ。
  • オプションボタン: 同じダイアログのオプションを選ぶと PDF としての表示方法を設定でき、ドキュメントは、現在のスライドだけを保存することや開始と終了の番号で範囲を決めること、スライドの代わりにノート・配布資料・アウトライン表示だけを保存すること、1ページに入れるスライド数、スライドの枠線・非表示スライド・ノート・インク・ドキュメントのプロパティ・ドキュメント構造タグを PDF に含めることを例に挙げる。
  • macOS: ファイル > 名前を付けて保存でファイル形式を PDF にするか、ファイル > エクスポートでファイル形式メニューの PDF を選ぶ。二つの方法がドキュメントに書かれている。
  • 標準と最小サイズの選択: 印刷品質が必要なら標準、メール添付のような容量制限が優先なら最小サイズである。二つの設定で実際にファイルがどれだけ違うかの数値は、ドキュメントにない。
  • PDF を送る前に見ること: 非表示スライドが含まれるか、スライドの枠線が入るかはオプションで決まる。書き出した PDF を一度開いてページ数とフォントの見た目を確認してから送るのが安全である。
  • PDF を修正する必要があるとき: PDF のドキュメントは、PDF として保存したファイルは見ることだけができ、変更はできないと書いている。PDF そのものを直す方法はPDF 編集入門の記事で扱う。

別の PC でフォントが崩れるとき - フォントを埋め込んで保存する

ドキュメントがフォントの埋め込みが役に立つ場合として挙げる状況は二つである。標準ではないフォントを使った場合と、他の人がプレゼンテーションをオフラインで編集したり見たりすると予想される場合である。資料をメールで送ったり別の PC に移して開いたりするのは、どちらにも当てはまる。フォントが崩れる問題は、ファイルを作った PC にしかないフォントが相手の PC にないときに起き、埋め込み保存はそのフォントをファイルの中にも一緒に入れておく設定である。ドキュメントは、最近 Office のフォントがクラウドに移り、インターネットに接続できる購読者は埋め込む必要がないと述べ、それでも標準外のフォントを使う場合や他の人がオフラインで編集・閲覧する場合には、埋め込みが今も役に立つと書いている。ユーザー設定フォントをドキュメントに埋め込むと、オンラインで PDF に変換するときにも役立つとも付け加えている。

  1. ファイルタブを選び、オプションを選ぶ。
  2. 左側で保存を選ぶ。
  3. ファイルにフォントを埋め込むチェックボックスを選ぶ。他の Microsoft ドキュメントは同じ項目を「ファイルにフォントを埋め込む」、または「このプレゼンテーションを共有するときに忠実性を保つ」の下のフォントの埋め込みと書いているので、ドキュメントとバージョンによって表記が少し違うことがある。
  4. OK を選ぶ。
  • プレゼンテーションで使われている文字だけを埋め込む: ファイルサイズは小さくなるが、編集に制限が出る。受け取る人が開いて見るだけでよい場合に合う。
  • すべての文字を埋め込む(他の人が編集するのに最適): 受け取る人が内容を直す可能性があるときにドキュメントが勧める側である。ファイルは大きくなる。
  • 埋め込めないフォント: 一部の TrueType フォントは、フォント制作者の権限設定により埋め込めない。Windows のコントロールパネルのフォントの項目で、埋め込み可能性の情報を見られるとドキュメントは案内している。
  • Mac のユーザー: ドキュメントは Mac 版 Microsoft 365 の Word、Mac 版 Microsoft 365 の PowerPoint、Mac 版 PowerPoint 2024、Mac 版 PowerPoint 2021 を対応の一覧に挙げ、OpenType(.OTF)か TrueType(.TTF)の形式を使い、PostScript(.PFB、.PFM)は避けるように書いている。
  • ファイルサイズとの兼ね合い: 大きなフォントはファイルサイズを大きく増やすことがあり、問題になれば別のフォントに置き換えるようドキュメントは勧めている。

フォントの埋め込みと PDF 保存は目的が違う。相手がファイルを開いて編集する必要があるならフォント埋め込み、見た目が同じならよいなら PDF が合う。両方を使えば、編集用と提出用を別々に作れる。

ファイルサイズを減らす - 図の圧縮と設定

ファイルサイズのドキュメントの対象製品は、Microsoft 365 の PowerPoint、PowerPoint 2024、2021、2019、2016 である。ドキュメントが紹介する方法は次の表のとおりである。プレゼンテーションに音声やビデオがあれば、メディアを圧縮してファイルサイズを大きく減らせるとも書いている。

方法メニュー(ドキュメントの表記)設定注意
図の圧縮図の形式タブ > 調整グループ > 図の圧縮図のトリミングされた部分を削除するを選び、解像度は既定の解像度を使用するこの図にのみ適用を選ばないと、すべての図に適用される
編集データの削除ファイル > オプション > 詳細設定 > イメージのサイズと画質編集データを破棄するを選び、既定の解像度は150ppi 以下を選ぶ削除した編集データは元に戻せない
埋め込みフォントの最適化ファイル > オプション > 保存ファイルにフォントを埋め込んだうえで、使用されている文字だけを埋め込む他の人の編集が制限される
メディアの圧縮音声・ビデオの圧縮機能メニューの位置は確認していない-
  • 図の圧縮の仕組み: トリミングされた部分の削除は、図を切り取って見えなくした部分のデータをファイルから消す。ドキュメントは、画像を編集しても既定では元のデータが保持されると説明し、このデータを削除すると元に戻せない代わりにファイルサイズが減り、画像の既定の解像度を下げても全体のファイルサイズが減ると書いている。
  • 150ppi 以下の意味: ドキュメントは、既定の解像度を150ppi 以下で選ぶよう書いている。印刷品質が必要な図では低い値が画質に影響することがあるが、その限界はドキュメントで確認できなかった。
  • 元に戻せない作業: 編集データやトリミングされた部分を削除すると元に戻せないとドキュメントは書いている。元のファイルを別名でコピーしてから小さくする順序が安全である。
  • フォント埋め込みとの衝突: フォントの埋め込みは安定性を与えるがファイルを大きくし、小さくするには使用文字のみの埋め込みに変える必要がある。二つは同じ設定画面でバランスを取る。
  • PDF との関係: PDF のドキュメントは、最適化でファイルをより小さくするには最小サイズを選ぶよう書き、メールに添付して送る場合を例に挙げている。

作業順序の点検 - 最初から最後まで

  1. PowerPoint を開き、サイドペインで新規 > 空白のプレゼンテーションを選んで、すぐに表示 > スライドマスターを開く。
  2. マスターで色、フォント、タイトルの形、ロゴを決め、必要ないプレースホルダーは隠す。
  3. マスター表示を閉じて編集画面に戻る。
  4. ホーム > 新しいスライドで内容に合うレイアウトを選び、スライドを追加する。
  5. 形が崩れたスライドは、ホーム > リセットで元に戻す。
  6. Shift+F5 で現在のスライドを、F5 で全体をショー画面で確認する。
  7. 発表の直前にファイル > オプション > 保存でフォントの埋め込みを決め、提出用はファイル > エクスポートで PDF を作る。大きな図があれば、先に図の圧縮を適用する。

この順序の根拠は、各項目が依存する方向である。マスターがレイアウトの土台で、レイアウトがスライドの枠であり、フォント埋め込み・PDF・圧縮は完成した内容に適用する仕上げである。図の圧縮の編集データの削除とトリミング部分の削除は元に戻せないとドキュメントが書いているので、圧縮の前に元のファイルをコピーしておくことが最後の点検項目である。
