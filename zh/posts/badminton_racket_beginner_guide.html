规格表上的五个项目

球拍的规格表最长也就五行：重量、手柄尺寸、平衡点、中杆硬度、建议拉线磅数。其中前两项由厂商用代号打上去，后三项要么用文字写出来，要么根本不写。价格越低的拍子，后三项空着的情况越多。

另外还有一项，印在中杆侧面的小字上，也就是建议磅数区间。这不是宣传语，而是厂商标注的、拍框能够承受的区间，不同型号差别不小。

  • 重量 - 在U前面加数字的等级代号，例如3U、4U、5U
  • 手柄尺寸 - G4、G5、G6，手柄粗细的等级
  • 平衡点 - 头重、平衡、头轻，指重心落在哪里
  • 中杆硬度 - 从软到超硬，指中杆有多容易弯曲
  • 建议磅数 - 以磅为单位的区间，是厂商写明拍框能承受的范围
  • 材质 - 拍框和中杆分别用什么做的，通常写在表格最下面

重量 - U前面的数字越大越轻

U是重量等级代号，绝大多数人在这里会先绕一次。数字越大越轻。3U比4U重，5U比它们都轻。这和日常直觉相反，所以在店里说错、结果拿回一支并不想要的拍子，是真会发生的事。

看厂商公布的数字，间隔很清楚。尤尼克斯在产品页上把平均重量和等级写在一起：3U型号平均88克，4U平均83克，5U平均78克，也就是每个等级差5克。

代号厂商公布平均值拿在手里的感觉常见的定位
3U88克压手，挥拍轨迹会被拍子自身的重量带着走靠力量压制的单打，或者偏好重量感的人
4U83克不轻也不重店里挂得最多的等级，单打双打都用
5U78克光靠手腕就能转过来前后转换很急的双打，或者想减轻手腕负担
2U及更重公布的型号很少明显偏重普通店面不太容易遇到

5克看着不算什么，但整支拍子只有80克出头。折算下来大约百分之六，而且球拍是以手柄为轴旋转的物体，那点重量挂在哪里，体感差别会比数字更大。

标注的重量是球拍本身的重量。在这之上还要加线、原装底胶、手胶和避震器。真正拿在手里的重量比标注的更沉。

轻拍并非永远占优的原因

让新手用轻拍这条建议只对了一半。作用在球上的力量由拍子质量和挥拍速度共同产生，其中一项小了，另一项就得相应变大才能得到同样的结果。挥拍还没成形时拿起轻拍，从自己后场打到对方后场的长球就打不到位。

接下来会怎样。打不到位就打得更用力，手臂和肩膀跟着发力，一发力挥拍就僵。轻拍反而养成用蛮力打球的习惯，路径就是这样形成的。

反方向同样存在。重拍会让本来就晚到的拍面更晚。球落下来时拍面赶不到位置，重量根本没有机会作用上去。所以实际判断分成这样几种。

  • 挥拍出得来，但球送不到后场 - 拍子可能偏轻
  • 球落下来时拍子到得太晚 - 拍子可能偏重
  • 两者都不是，而是打不到拍面中间 - 这不是重量的问题，此时球拍还不是变量
  • 打完之后手腕或肘部发胀 - 先看中杆硬度和磅数，再看重量

球馆里也常听到重拍能帮你把动作定型的说法。这话流传很广，但我没能确认到支撑它的依据。可以确定的只是，重量会造成感受上的差别，到此为止。

手柄尺寸 - G也是数字越大越细

G的方向是一样的，数字越大手柄越细。既然U和G用同一条规则，那就只需要记住一件事：羽毛球拍的代号，数字越大，东西越小。

看厂商产品页会发现，每个型号提供的尺寸并不相同。入门系列是G4和G5，高端系列则出到G5和G6。也就是说，你想要的粗细如果那个型号没有就没有，而这个限制在便宜的一端更常撞上。

手柄可逆的方向只有一个。把细手柄变粗，缠一层手胶即可；把粗手柄变细，就要拆掉原装底胶，拆掉之后很难还原。拿不准时从细的一端开始更稳妥。

如果想用数字找感觉，可以用手胶厚度。尤尼克斯公布的自家手胶规格是宽25毫米、长1200毫米、厚0.6毫米。把这个厚度均匀缠在手柄外面，周长大约增加3.8毫米。不过手胶是叠着缠的，实际增加量可能比这更多。

  • 指尖能碰到掌心且还有余量，说明手柄偏细
  • 手指被撑开、握不拢，说明偏粗
  • 偏粗时手腕转动受限，挥拍末端可能变钝
  • 偏细时会怕脱手而握紧，握紧则前臂很快就累
  • 出汗多的人往往要缠两层手胶，那也会变粗

平衡点 - 进攻型和防守型实际指什么

平衡点就是重心的位置，用手柄末端到重心的距离表示，距离越长说明重量越靠拍头。同样重量的两支拍子，重量挂在哪里会让挥动它所需的力气不同。就像同样长的棍子，末端加个配重就更难挥。

类型重心位置挥拍时发生什么代价
头重靠近拍头同样挥拍带出的动量更大，球容易到后场转起来沉，前后转换和快速防守会慢
平衡接近中间两种性质混合，没有极端在任何一端都不是最好的
头轻靠近手柄改变拍面朝向很快，网前和防守占优同样挥拍送不到那么远

那么商品说明里的进攻型和防守型又是什么。厂商自己的资料就把答案露出来了。尤尼克斯在自家的球拍选择资料里，把系列分成力量、速度、精准三类，再把每个系列的型号排在一张双轴坐标上。纵轴是从头重到头轻，横轴是从硬手感到软手感。

也就是说，进攻型大体上是头重加硬中杆的另一种叫法，防守型则是头轻加软中杆的另一种叫法。不是两种彼此独立的性质，而是同一张坐标换了说法。同一份资料还给每个型号标了熟练度，分成基础阶段、技术成长阶段、熟练阶段三级。这个标注比商品介绍的说辞诚实得多。

中杆硬度 - 必须和挥拍速度匹配的一项

中杆在挥拍过程中向后弯曲，在击球前一瞬弹回来。只有这个弹回的时刻和球接触线床的时刻重合，力量才会作用上去。所以选中杆硬度不是口味问题，而是时机问题。

挥拍快，中杆弯得多，弹回来也就更有力。给这样的人一支软中杆，它会弯过头，弹回的时机偏晚，出球方向就飘。反过来，挥拍慢却用硬中杆，中杆几乎不弯，从弹回里得不到任何东西，就只能靠手臂打，冲击也照样传到手臂上。肘部或肩部可能承受负担的，正是这种组合。

标注弯曲程度适合的挥拍不匹配时会怎样
软性一类弯得多较慢的挥拍，入门阶段挥拍变快之后方向会飘
中等居中挥拍正在成形的阶段两种性质可能都显得不上不下
硬弯得少较快的挥拍，重视方向控制慢挥拍时力量作用不上去
超硬几乎不弯已经成形的挥拍冲击原样传到手臂

把同一家公司的产品页并排看，差别立刻显现。以尤尼克斯为例，两款入门系列型号的标注都是高弹性，属于容易弯曲的一端；而顶级进攻系列型号是超硬。所谓高端拍不适合新手，实质大多就在这一行上。

有一点要留意。硬度标注是品牌内部的相对刻度。换一家公司，同样的名称也不保证是同样的刚性，而我没能找到测定硬度的标准试验规格。

拉线磅数 - 磅的写法与球拍的上限

磅数是把线拉紧的力，用磅来写。新手在这里最常听到的错误说法，就是24磅是基准之类的数字。磅数上限因拍而异，厂商会按型号公布不同的值。

把尤尼克斯产品页上确认到的值排在一起，跨度就看得出来。铝合金拍框的入门型号在3U下是16到20磅，碳素入门型号是20到27磅和20到28磅，顶级碳素型号在4U下是20到28磅、3U下是21到29磅。给铝合金入门拍拉24磅，意味着已经超出厂商写明的上限。

类别拍框材质公布重量中杆标注建议磅数
入门铝合金型号铝合金，中杆为碳素3U，平均88克未标注16 - 20 磅
入门碳素型号A碳素5U，平均78克高弹性20 - 27 磅
入门碳素型号B碳素4U，平均83克高弹性20 - 28 磅
顶级碳素型号高模量碳素复合材料3U，平均88克超硬21 - 29 磅

低磅在入门阶段占优，道理很简单。松一些的线床在接触瞬间拉伸更大，会把球兜住再弹出去。反弹的相当一部分来自线而不是手臂，所以同样的距离更省力；而且整个线床都在拉伸，打点不在正中也还能出球。

高磅正相反。线拉伸少，球停留在拍面的时间短，因此更能按照瞄准的方向走。代价是线不再替你出力，需要挥拍速度补上，而且好打的区域变窄，一旦打偏就掉得很厉害。提高磅数是一笔交易：用容错换控制。

保修条款也值得看一眼。尤尼克斯美国的保修页面在承诺一年保修材料与做工缺陷的同时，把断线和不当穿线列为除外情形，并把偏离官方穿线路径举为不当穿线的例子。磅数数值本身并没有作为条件写进去。同一家公司还把各型号的穿线路径精确到孔位编号公开，这一点和上面是连着的。球拍不能随便找个地方拉线，原因就在这里。

磅数放着不动也会掉

这一条不在规格表上，却是实际使用中影响最大的。球线厂商Ashaway写道，球拍在拉线后第二天会损失大约百分之十的张力，而且是在完全没打、只是立着放的情况下。原因是蠕变，也就是线在分子层面缓慢伸长。

更要紧的是它不可逆。同一份资料说明，把松掉的线重新收紧也无法恢复原来的弹性。所以所谓拉了25磅，是拉线那一刻的数值。一个月之后，那支拍子已经不是25磅了。

球线为什么会断，同一家厂商也整理过。最常见的原因是被拉伸超过了弹性极限，断的位置多在靠近拍头的中央主线，发生在打点落到甜区之外的时候。也就是说，经常断线未必是线不好，更可能是打点在飘的信号。同一份资料还指出，线孔里的塑料护线管一旦破裂立起边缘，就会把线割坏。

  • 拉线后的头几天掉得最快，刚下机的手感很难当作基准
  • 一周打几次就一年换几次线，这个经验说法流传很广，但我在厂商和协会资料里没能找到依据
  • 能用的信号是击球声变闷，声音对磅数变化很敏感
  • 第二个是同样的挥拍打不远，先从后场球上显出来
  • 第三个是线床错位后回不去，推正之后很快又错开
  • 断一根线，那支拍子当天就用不了。这是需要备用拍的第一个理由

材质 - 铝合金和碳素分道扬镳的地方

入门球拍说明里最常出现的材质区分是铝合金和碳素。这个差别先体现在磅数上限而不是手感上。看上一节的表，铝合金拍框的上限是20磅，碳素是27到29磅。拍框承受的力不同，能拉的范围自然不同。

有意思的是，这跟重量无关。那支铝合金型号也是3U平均88克，和顶级碳素型号的3U同一个等级。差别在于同样的重量能用在哪里。碳素能用更少的质量达到同样的刚性，所以才有4U、5U这些等级，也才有余地把剩下的重量分配到拍头或手柄去设计平衡。

那么价格上去之后，实际改变的是什么。大致是这些。

  • 拍框材质 - 从铝合金到碳素，再到高模量复合材料
  • 磅数上限 - 拍框能承受多少，区间就有多宽
  • 可选项数量 - 重量与手柄的组合从一种变成好几种
  • 设计的窄度 - 针对特定挥拍做了优化，不是那种挥拍反而不合适
  • 不会变的部分 - 长度和线床面积，这两项由竞赛规则定了上限

最后一条是要点。高端拍不是更合适的拍，而是合适范围更窄的拍。落在那个范围里的人用起来确实更好，落在外面的人则连便宜拍都不如。

规格 - 规则定了什么，又没定什么

到这里看过的项目，竞赛规则一个都没有规定。重量、平衡、中杆硬度、磅数全是厂商自己定的。U和G不是国际规格而是行业标注，所以换一家公司可能会有细微出入。

规则规定的是尺寸和附着物。竞赛规则第4条把球拍框架的总长限制在680毫米以内、总宽230毫米以内。线床长度不超过280毫米、宽度不超过220毫米；如果把线延伸到拍喉部位，该延伸部分宽度不得超过35毫米，且线床总长不得超过330毫米。4.3条禁止除了防磨损、防震或分配重量之外的附着物与突起，也禁止任何能够实质改变球拍形状的装置。手胶和避震器之所以被允许，依据就是前面那项例外。

球本身的规定细得多。同一规则第2条对羽毛球是这样定的。

项目规定值条款
羽毛数量16根2.2.1
羽毛长度62 - 70毫米2.2.2
羽毛顶端围成的圆直径58 - 68毫米2.2.3
球托直径25 - 28毫米2.2.5
重量4.74 - 5.50克2.2.6
人造球的允许偏差同样尺寸下最多百分之十2.3.3

还有速度测试条款。从底线之外用完整的低手击球，速度合格的球会落在对面底线之前530毫米以上、990毫米以下的范围内。球筒上写的速度编号，就是为了让球通过这项测试而存在的标注。

新手把钱花错的三个地方

第一个是第一支拍就砸大钱。如前所述，高端拍多是头重加超硬的组合，那是以已经很快的挥拍为前提做的设计。它不但帮不上忙，还容易把冲击原样传到手臂。而且断线之后当天就打不了，只有一支拍就没有备用。过了某个阶段，两支合适的拍胜过一支贵的。

第二个是不算耗材的账。球拍买一次就完了，球和线却一直在消耗。羽毛球是消耗品，尼龙球耐用得多，但飞行和手感都不一样。要紧的不是单价，而是先把一年的总额算出来。

每周耗球量 = 每周场次 x 每场消耗个数
每年球费   = 每周耗球量 x 52 x (一筒价格 ÷ 12)
每年线费   = 每年换线次数 x (线材 + 工费)
第一年支出 = 球拍 + 球鞋 + 以上两项 + 手胶

算过一次之后，结论通常是同一个：球拍在第一年总支出里占的比例比想象中小。而第三个地方就是球鞋，三者之中最常被往后拖，拖了之后得到的好处也最少。

为什么拖着不买鞋是最贵的选择

羽毛球里身体做的大部分工作不是击球，而是停住再蹬出去。向前两步急停，向侧压出去再回来，向后退开再往前弹。

跑鞋不是按这种动作做的。为了承接向前跑的力量，它后跟缓震厚、底面偏圆。体重往侧向压过去时，脚可能在鞋里滑动，鞋本身也可能整个歪掉，在那种状态下有可能出现脚踝翻折的情况。

室内球鞋的方向正相反。鞋底低而平，让脚掌贴住地板，侧面有在横向受力时托住脚的结构。外底是不留痕的生胶，意思是既能在室内地板上产生摩擦，又不会留下印子，很多室内场馆把这一条当作入场条件。

  • 球鞋很难借，球拍可以借，这个不对称决定了顺序
  • 是否不留痕直接关系到场馆规定，买之前先确认要去的场馆怎么规定
  • 它托住脚宽和脚背，尺码可能和平时不同，试穿之后再买更好
  • 如果要穿厚运动袜，就穿着那双袜子试
  • 外底磨损之后摩擦会下降，觉得打滑先怀疑鞋
  • 顺序只有一个：球鞋、球拍、球线，然后才是第二支拍

球拍寿命与保养

球拍不是磨到不能用的东西，多数是因为事故结束的。双打里和搭档的拍子相撞最常见，其次是地板和网柱。保养的一半是不去撞它的习惯，另一半是下面这些。

  • 断线之后尽快剪掉剩下的线。断一根之后那个方向的张力消失，拍框上就留下不对称的载荷。做穿线的店家一致这样建议。不过我没能在厂商资料里确认到因此真的导致拍框变形的案例
  • 看护线管。线孔里的塑料圈破裂立起边缘，会把新拉的线割坏。送去拉线时请对方一并检查即可
  • 避开高温。尤尼克斯的保修除外项里列有暴露于过高温度。夏天放在汽车后备箱就属于这一项
  • 把手胶当成消耗品。打滑的手胶会让人下意识握得更紧，握紧则挥拍变僵
  • 看看漆面之下。细裂纹是从漆下开始的，不容易察觉。如果撞过之后击球声变了，就值得怀疑

如果在考虑二手拍，要检查的项目和上面这份清单完全重合。问题在于其中大部分没法通过照片确认。入门阶段不太推荐二手，理由不是价格，而是这种无法确认。

不必买的情况

前面所有内容都建立在要买拍这个前提上，有时值得先回头审视这个前提。多数俱乐部和全民健身项目都备有租借球拍，用那样的拍子撑过学基本挥拍和步法的几个月完全够用。用借来的拍子过三四周，判断所需的信息就凑齐了，而那时要确认的不是球拍性能，而是自己这一边的状态。

  • 四周之内实际去了四次以上吗。没去的话，问题不在球拍
  • 握过别人的拍子时感觉到差别了吗。没感觉到，说明球拍还不是变量
  • 球大体上能打在拍面中间吗。不能的话，换磅数还是换重量，结果都差不多
  • 租借的拍子对你来说是重还是轻。这是决定第一支拍等级最好的线索
  • 球鞋已经有了吗。没有的话，它排在球拍前面

球拍开始妨碍进步的时间点通常很清楚，就是脑子里已经有想打的那一拍，而球拍跟不上的时候。在那之前，买哪支拍结果差别都不大；到了那时候，你自己就能说出缺的是什么。在那种状态下买的拍子会合适得多。

小结

规格表的规则只需要记住一条：U和G都是数字越大，东西越小。3U平均88克、4U平均83克、5U平均78克，G的数字越大手柄越细。光凭这两点，就不至于在店里拿错东西回家。

剩下三项彼此纠缠。平衡点和中杆硬度在厂商资料里被当作同一张坐标的两个轴处理，进攻型和防守型就是给那张坐标起的名字。磅数的上限因拍而异，有些拍子上24磅根本在范围之外；而且这个磅数从拉线第二天起就开始掉，掉了不会回来。

花钱的顺序和规格无关，早就定好了：先买鞋；球拍可以借着用几周再买也不迟；第一年支出里最大的一项通常是耗材。带着这三点站到球拍墙前，贴纸上那串字符才第一次成为可以拿来做选择的信息。

未能确认的部分

  • U等级的克数区间边界没能在厂商官方页面上确认。3U为85.0到89.9克这样的区间写法在流通资料里用得很广，但我直接确认到的只有厂商按型号公布的平均值88克、83克、78克
  • 没能在厂商资料里找到手柄尺寸的实际周长数值。不同来源互相矛盾，有的把G4写成86毫米，有的写成3.25英寸。本文用到的只是数字越大越细这个方向，以及公布的手胶厚度0.6毫米
  • 平衡点的区间边界，也就是从多少毫米起算头重，只在销售资料里见到。厂商产品页多数没有把平衡点写成数值
  • 没能找到中杆硬度标注对应的标准试验规格。不同品牌的标注是否可比，无法确认
  • 公布重量是否为未穿线状态，产品页上没有写明。通常按那样理解，但我没能确认到相应文字
  • 超过磅数上限就失去保修的说法很常听到，但我查看的保修页面上并没有把磅数数值写成条件，写在那里的只有断线与不当穿线的除外
  • 球线更换周期的经验说法，我没能在厂商或协会资料里找到出处
  • 关于羽毛球损伤部位的统计虽有系统综述，但我未能访问到摘要原文，因此没有引用脚踝损伤比例之类的数值
  • 羽毛球的零售价格与每个球能撑几局，都找不到厂商或协会公布的数值，所以只写了计算方法而没有写金额
  • 竞赛规则条文因联合会官方PDF拒绝访问而未能打开，改用全文转载的资料确认，条款编号以该转载版本为准
