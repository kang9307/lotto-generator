前言：让闲置资金动起来

将资金存放在活期存款账户中却几乎拿不到利息，实质上是一种机会损失。在活期存款利率极低的环境下，停车账户（파킹통장）和CMA（综合资产管理账户）是两种能够在保持随时存取自由的同时，获得远高于活期存款利息的代表性短期资金管理工具。

两种产品表面上看似相近，但在发行机构、存款人保护适用与否、资金运作机制上存在重要差异。本文对两种产品的概念与区别、各类型特征、与活期存款及定期存款的比较、实用活用策略及注意事项进行梳理。初稿写于2026年6月，存款人保护限额、受保护产品、韩国银行基准利率和利息所得税已按2026年9月29日的情况更新。制度数字均以韩国制度为准（两种产品均为韩国金融产品）。

注意：金融产品的利率、限额、优惠条件因金融机构、时间及个人条件而异。本文为一般性教育信息，具体数字请务必直接向相关金融机构确认。

1. 什么是停车账户

停车账户借用了短暂停车的比喻——将资金短暂存入，获得较高利息，随时可以取出。与普通活期存款不同，哪怕只存一天也会产生利息，且可随时自由取款。

1.1 核心特点

  • 随时存取：无需设置到期日，随时可存入或取出
  • 按日计息：哪怕只存一天，当天的利息也会计入（日复利还是单利因产品而异）
  • 利率高于活期存款：大多数情况下远高于普通活期账户
  • 存款人保护适用：属于银行或储蓄银行存款，在韩国同一存款人在一家金融机构的存款本金与规定利息合并计算，最高保护1亿韩元（自2025年9月1日起，由原来的5千万韩元上调）

1.2 发行机构

停车账户主要由互联网专属银行（韩国如Kakao Bank、Toss Bank、K Bank等）和储蓄银行竞争性提供，部分市中银行也推出类似产品。不同机构的利率和优惠条件有所不同，建议比较多个产品后再选择。

1.3 利率结构与注意事项

停车账户的利率大多为浮动利率，金融机构可根据市场利率变化随时调整。很多产品采用"阶梯利率"方式，仅对一定余额以内适用高利率，超出部分适用较低利率。要获得优惠利率，往往需要满足特定条件（如使用特定信用卡、设置工资自动转入等），因此需仔细阅读条款。

2. 什么是CMA（综合资产管理账户）

CMA（Cash Management Account，综合资产管理账户）主要是证券公司经营的账户，将客户资金投入短期金融产品进行运营并支付利息。综合金融公司经营的票据管理账户也称为CMA。其特点是可与股票、基金投资相结合，高效管理待机资金。

2.1 关键区别：存款人保护

韩国存款保险公社明确将证券公司CMA列为不受保护产品的例子，并将MMF等金融投资产品、回购协议（RP）、包管账户列为证券公司（投资买卖业者、投资中介业者）领域的不受保护产品。与此相对，在综合金融公司领域，它将票据管理账户（CMA）与发行票据、表纸票据一起列为受保护产品（2026-09-29确认）。也就是说，同样叫CMA，由哪类公司发行决定了是否受存款人保护。各运营类型的风险性质也不同。

3. CMA各类型详解

CMA按运营方式主要分为四类，加入前务必确认所属类型。

3.1 RP型（附买回条件债券型）

证券公司以持有的国公债、优质公司债为担保提供固定利率的产品。到期时证券公司将债券买回（即回购）。因有担保，该类型相对其他类型安全性较高，但韩国存款保险公社将回购协议（RP）列为不受保护产品，不受存款人保护。

3.2 MMF型（货币市场基金型）

将客户资金投入资产管理公司运营的MMF（货币市场基金）。基金持有短期国公债、企业商业票据（CP）、可转让定期存单（CD）等安全性较高的短期金融资产，按实际收益分配。理论上存在本金损失的可能性。韩国存款保险公社不保护支付金额随运营业绩变动的金融产品，不受存款人保护。

3.3 MMW型（货币市场包型）

证券公司与客户签订全权委托（包管）合同，将客户资金投入存放于韩国证券金融公司（KSFC）等短期流动资产的方式。韩国金融委员会将MMW说明为以金融机构存款、商业票据、同业拆借、RP、债券等流动资产运用委托财产的包管账户。由于投资对象是短期、高流动性资产，风险通常被认为较低，但并非保本产品。韩国存款保险公社将包管账户列为不受保护产品，因此不受存款人保护。实际投资对象因产品而异，需通过产品说明书确认。

3.4 综合金融公司型

由综合金融公司（综金社）发行的票据管理账户（CMA），是韩国存款保险公社列为受保护产品的类型。与在同一综金社的其他受保护产品合并计算，每人最高保护1亿韩元。但经营该产品的公司不多，实际选择有限。由于与证券公司CMA同名，加入前通过产品说明书上的存款保护标识确认属于哪一种最为稳妥。

4. 与活期存款、定期存款的比较

4.1 与活期存款的比较

活期存款是最基本的存取款账户，利率极低。虽然同样可以随时存取，但在利息收益方面停车账户优势明显。日常转账、工资转入、账单自动扣款等主交易功能适合使用活期存款，而短期保管闲置资金则停车账户更为合适。

4.2 与定期存款的比较

定期存款通过将资金锁定一定期限（3个月、6个月、1年等）来换取高于停车账户的固定利率。提前支取会适用远低于约定利率的违约利率。因此，确定一段时间内无需使用的资金选择定期存款更有利；而随时可能需要动用的紧急资金或待机资金，则停车账户或CMA更为适合。

5. 活用策略

5.1 紧急资金管理

紧急资金需要应对突发支出（医疗费、车辆维修、失业等），必须随时可以提取，流动性至关重要。通常建议保留3至6个月生活费作为紧急资金（这是常见的经验法则，并非法规或公共机构规定的标准，具体金额因个人情况而异）。将这部分资金放在活期存款中几乎相当于放弃利息收益。停车账户可在保管紧急资金的同时每天积累利息，是最简单高效的升级方式。

5.2 投资待机资金管理

对于频繁进行股票、ETF或其他证券交易的投资者，CMA尤为适合。与证券账户相关联，资金在等待下一个投资机会时自动生息，需要时可立即使用。这正是CMA产品的原始设计初衷。

5.3 分散保管策略

在韩国，存款人保护按每位存款人每家机构1亿韩元的上限执行。如果在同一机构的存款总额接近或超过保护上限，可考虑分散至多家机构。例如，将紧急资金存入一家银行的停车账户，其余储蓄放入另一家机构，以最大化受保护的金额。决定分配比例时还应考虑，存放在证券公司CMA中的资金与这一限额无关，本就不受存款人保护。

5.4 定期比较利率

停车账户和CMA的利率会随市场变化频繁调整，建议每季度比较一次主要产品的利率，避免留在已不具竞争力的产品中。韩国可使用金融监督院金融产品综合比较公示网站（finlife.fss.or.kr）进行比较。

6. 注意事项

6.1 浮动利率风险

两类产品大多采用浮动利率，今天看起来具有吸引力的利率明天可能下降。广告中强调的优惠利率往往需要满足特定条件才能获得，务必仔细阅读细则。

6.2 存款人保护限额

韩国的存款人保护限额自2025年9月1日起为每人1亿韩元。根据韩国存款保险公社的说明，这1亿韩元是同一存款人在一家金融机构的全部存款本金与规定利息的合计。超过上限的部分在机构破产时不受保护，将资金分散至不同机构可分别享受各机构的保护上限。此外，确定缴费型及个人型（IRP）退休金、年金储蓄（信托、保险）、事故保险金，即使在同一金融机构，也与一般存款分开，各自最高保护1亿韩元（2026-09-29确认）。

6.3 CMA无存款人保护的实际风险

证券公司的RP型、MMF型、MMW型CMA不受存款人保护。但这些产品运营的资产（国公债、短期优质债券等）通常被认为安全性较高。在极端市场情况下理论上仍可能产生损失，因此必须在理解存款人保护状况和运营方式的前提下加入。另外，韩国存款保险公社将证券账户中未用于买入证券、以现金形式留存的客户存款列为受保护产品，这与放入CMA后以RP、MMF等方式运营的资金不同。

6.4 利息税

在韩国，停车账户和CMA产生的利息收入一般按15.4%预扣利息所得税。根据韩国国税厅的说明，这是14%的所得税加上个人地方所得税；利息、股息等金融所得年合计超过2千万韩元时，将适用金融所得综合课税（2026-09-29确认）。免税产品另有资格要求，不要混淆。

7. 常见问题解答

问：可以同时使用停车账户和CMA吗？

可以，同时使用两者往往更为高效。例如，将紧急资金存入受存款人保护的停车账户，将投资待机资金放入与证券账户关联的CMA，这种组合兼顾了安全性和便利性。分配时要清楚证券公司CMA一侧的资金不受存款人保护。

问：CMA可以像普通银行账户一样日常使用吗？

部分证券公司提供与CMA账户绑定的借记卡，可用于日常消费。但服务内容因证券公司而异，加入前需核实可用功能。

问：利率多久变化一次？

利率会随中央银行政策利率决策和金融机构自身产品策略的变化随时调整。韩国银行基准利率自2025年5月29日起为年2.50%，2026年7月16日上调至年2.75%，8月27日上调至年3.00%（2026-09-29确认），与本文6月初稿时已不相同。金融机构调整利率没有固定周期，建议定期比较。

问：适用高利率有余额上限吗？

许多停车账户仅对一定余额内适用高利率，超出部分适用较低利率。这一利率适用上限与存款人保护限额（1亿韩元）是两个不同的概念。请务必在产品条款中确认阶梯利率结构。

8. 总结：不让短期资金闲置

停车账户和CMA是让短期资金获取可观利息的两大实用工具，远优于将资金搁置在活期存款中。核心区别在于存款人保护的有无与发行机构的不同：需要安全保管的紧急资金适合使用受存款人保护的停车账户；与证券投资相关联的待机资金则更适合CMA。

两种产品的利率大多为浮动型，要获得最大收益需确认优惠条件是否满足。本文不推荐任何特定产品，建议比较多个产品，并根据自身资金规模、目的和风险承受能力做出选择——或将两者结合使用。

## 2. CMA类型判断表

| 类型 | 运营方式 | 存款人保护 | 加入前需确认 |
|---|---|---|---|
| RP型（证券公司） | 以国公债、优质债券为担保的固定利率 | 不适用 | 利率固定期限、担保债券 |
| MMF型（证券公司） | 分散投资短期债、CP、CD，按实绩分配 | 不适用 | 本金损失的可能性 |
| MMW型（证券公司） | 全权委托（包管），存放韩国证券金融公司等短期运营 | 不适用 | 投资对象，非保本 |
| 综合金融型（综合金融公司） | 票据管理账户 | 适用（该公司合并计算1亿韩元） | 发行方是否为综金社，产品说明书上的保护标识 |

## 3. 放在哪里 - 按用途判断表

| 资金性质 | 基本存放处 | 理由 |
|---|---|---|
| 紧急资金 | 银行、储蓄银行的停车账户 | 随时存取，受存款人保护 |
| 证券投资待机资金 | 证券公司CMA | 与证券账户关联，等待期间计息；但不受保护 |
| 一段时间内不用的钱 | 定期存款 | 固定利率，但提前支取利率低 |
| 工资与自动扣款 | 活期存款 | 主交易功能，利率极低 |
| 同一机构超过1亿韩元 | 分散到多家机构 | 保护限额按机构分别适用 |

## 4. 加入前检查

- [ ] 是否确认发行方是银行或储蓄银行、证券公司还是综合金融公司
- [ ] 是否在产品说明书中看到存款人保护标识
- [ ] 如果是CMA，是否清楚属于RP型、MMF型、MMW型还是综合金融型
- [ ] 在同一金融机构的存款本金与利息合计是否未超过1亿韩元
- [ ] 是否在条款中看过高利率适用的余额上限及超出部分的利率
- [ ] 能否真正满足优惠利率条件（使用信用卡、工资转入等）
- [ ] 是否按税后（预扣15.4%之后）利率进行比较
- [ ] 是否在金融监督院金融产品综合比较公示网站（finlife.fss.or.kr）与其他产品比较
