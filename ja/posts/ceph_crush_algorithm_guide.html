This guide provides an easy-to-understand explanation of CRUSH algorithm principles and practical implementation methods.

🎯 CRUSHアルゴリズムとは?

CRUSHは、Ceph分散ストレージシステムにおいてデータの保存先を決定するためのコアアルゴリズムです。従来の中央集権的なメタデータサーバ方式とは異なり、CRUSHは数学的計算によってデータの位置を決定するため、優れた拡張性とパフォーマンスを発揮します。

CRUSHの主な特徴

  • 分散処理: 中央サーバを介さず、各クライアントが独立してデータの位置を計算
  • 拡張性: 数千台規模のストレージノードまで線形にスケール可能
  • 障害復旧: 障害ノードを自動的に回避してデータを配置
  • ポリシーベース: ビジネス要件に合わせた柔軟な配置ポリシー構成

CRUSH Mapの構成要素

構成要素 説明 例
Device 実際のストレージデバイス (OSD) osd.0, osd.1, osd.2...
Bucket デバイスの論理的なグループ host, rack, datacenter
Weight 保存容量の比率 1TB = 1.0, 2TB = 2.0
Type 階層構造のレベル root, rack, host, osd

⚙️ CRUSHアルゴリズムの動作原理

CRUSHアルゴリズムは次のような手順でデータ配置を決定します。

1. ハッシュ計算

オブジェクト名とプールIDをハッシュ化し、一意のplacement group (PG)を生成します。

# 擬似コード例
def calculate_pg(object_name, pool_id, pg_num):
    hash_value = hash(object_name + str(pool_id))
    pg_id = hash_value % pg_num
    return pg_id

2. CRUSH Ruleの適用

配置ポリシーに従って適切なOSDを選択します。

# CRUSH Rule例
rule replicated_rule {
    ruleset 0
    type replicated
    min_size 1
    max_size 10
    step take default
    step chooseleaf firstn 0 type host
    step emit
}

3. 障害ドメインの考慮

同じ物理的位置に複製が保存されないように保証します。

🔧 CRUSH Mapの実際の構成方法

現在のCRUSH Mapを確認

# CRUSH Mapの取得
ceph osd getcrushmap -o crushmap.bin
crushtool -d crushmap.bin -o crushmap.txt
cat crushmap.txt

# 簡単なツリー構造の表示
ceph osd tree

新しいホストの追加

# 新規ホストをCRUSH Mapに追加
ceph osd crush add-bucket new-host host
ceph osd crush move new-host root=default

# OSDを新しいホストに追加
ceph osd crush add osd.8 1.0 host=new-host

カスタムCRUSH Ruleの作成

# SSD専用プール用のCRUSH Rule
ceph osd crush rule create-simple ssd-rule default host firstn

# イレイジャーコーディング用CRUSH Rule
ceph osd crush rule create-erasure ec-rule ec-profile

📊 CRUSHアルゴリズムの性能最適化

Weight調整による負荷分散

各OSDのWeightをストレージ容量に比例して設定すれば、均等なデータ分散を実現できます。

# OSD Weightの調整 (容量ベース)
ceph osd crush reweight osd.0 1.8  # 1.8TB容量
ceph osd crush reweight osd.1 3.6  # 3.6TB容量

# 使用率ベースの自動調整
ceph osd reweight-by-utilization 110

🚨 一般的なCRUSHトラブルシューティング

データ不均衡の問題

# 不均衡の診断
ceph osd df | sort -k7 -n

# Weightの再調整
for osd in $(ceph osd ls); do
    size=$(ceph osd df | grep "osd.$osd" | awk '{print $2}')
    weight=$(echo "scale=2; $size/1024/1024" | bc)
    ceph osd crush reweight osd.$osd $weight
done
