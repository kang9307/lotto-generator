How to Use the Password Generator

  1. Use the password length slider to set the desired length (6-32 characters).
  2. Select the password options:
    • Include uppercase: includes uppercase letters in the A-Z range.
    • Include lowercase: includes lowercase letters in the a-z range.
    • Include numbers: includes digits in the 0-9 range.
    • Include special characters: includes symbols such as !@#$%^&*().
    • Exclude similar characters: excludes easily-confused characters like 1, l, I, 0, O.
  3. Click the "Generate Password" button to create a result.

How to Interpret the Result

  • Password Strength: indicates the security level of the generated password.
  • Weak (red): a short password or one that uses only a single character type.
  • Medium (orange): at least 8 characters and includes 2 or more character types.
  • Strong (green): at least 10 characters and includes 3 or more character types.
  • Very Strong (dark green): at least 12 characters and includes all character types.

Secure Password Tips

  • Variety: include uppercase, lowercase, numbers, and special characters.
  • Length: use passwords that are at least 12 characters long.
  • Uniqueness: use a different password for every account.
  • Regular rotation: change your passwords every 3-6 months.
  • Password manager: use a password manager to securely store complex passwords.
