古いPCをLinuxで蘇らせる — 2026年実践ガイド

Windows 10サポート終了後、遅くなった古いPCを軽量Linuxで復活させるスペック別選択と実践移行法

2026-06-29 開発・インフラ

はじめに：廃棄されそうなPCに新しいOSを

2025年10月14日、マイクロソフトはWindows 10の無料セキュリティアップデートを終了した。この日から数億台のPCが事実上のセキュリティ空白状態に置かれることになった。Windows 11へのアップグレードにはTPM 2.0と特定世代のCPUが必要だが、2014〜2019年に購入した多くのデバイスはこの条件を満たせない。ハードウェア自体は正常に動作しているにもかかわらず、OSのポリシーが線引きをしているわけだ。

選択肢は三つある。新しいPCを購入するか、有料のESU（延長セキュリティアップデート）を購入するか、Linuxに移行するかだ。この記事は三番目の選択肢を具体的に掘り下げる。「Linuxを使ってみよう」という勧めではなく、手元のPCのスペックを基準にどのディストロを選ぶべきか、インストール前に何を準備するか、古いハードウェアでどこまで使えるかを2026年6月時点で実際に分析した内容だ。

まず一点、正直に伝えておく。LinuxはWindowsの完全な代替ではない。Adobe製品群、一部のゲーム、特定の業務ソフトはLinuxでそのまま動かない。この記事はその限界を率直に指摘しつつ、その範囲内でLinuxが古いPCにとってどれほど実用的な選択肢になるかを検討する。

1. なぜ今、古いPCにLinuxなのか

1.1 Windows 11のハードウェア障壁

Windows 11はTPM 2.0、UEFIセキュアブート、Intelなら第8世代以降、AMDならRyzen 2000以降のCPUを必須要件としている。これは2017〜2018年以前のデバイスのほとんどを実質的に除外する。技術的な回避インストールは可能だが、マイクロソフトは公式サポートを提供していない。一方、Linuxにはそのようなハードウェアのロックアップは存在しない。ディストロによっては512MBのRAMを搭載した機器でも動作する。

1.2 RAM消費量：Linuxの核心的な優位性

Windows 11のアイドル時のRAM消費量は約2〜4GBに達する。一方、XfceやLXQtといった軽量デスクトップ環境を持つLinuxは300〜800MBで動作する。同じハードウェアで、OSを変えただけで体感速度が大きく変わるのはこのためだ。マシンが速くなったのではなく、OSが軽くなったのだ。

1.3 電子廃棄物の規模

PC1台には約30〜50kgの電子部品と希少金属が含まれている。2026年初頭の分析によると、Windows 10のサポート終了により、世界全体で2億台以上のデバイスが早期廃棄の危機に直面する可能性があると推定されている。Linuxで2〜3年の延命が実現すれば、廃棄サイクルから一度は外れることができる。これは環境的にも経済的にも意味のある選択だ。

2. スペック別ディストロ選定 — 2026年6月時点

ディストロ選択において最も実用的な軸はRAM容量だ。CPUの世代は、64ビット対応（2007年以降のほぼすべてのPCが該当）であれば、RAMほど決定的ではない。

2.1 RAM 4GB以上：選択肢は広い

4GB以上あれば、ほぼすべての軽量ディストロが快適に動作する。Windowsから移行するユーザーに最初に薦めるのはLinux Mint 22 XfceとXubuntu 26.04 LTSだ。どちらもXfceデスクトップ環境を使用しており、タスクバーとスタートメニューのレイアウトがWindowsに似ているため、移行の心理的ハードルが低い。Linux MintのソフトウェアマネージャーはLinux世界でも特に完成度の高いUIを持つ。Xubuntu 26.04はXfce 4.20を搭載しUbuntuの豊富なパッケージエコシステムを活用できる。

2.2 RAM 2〜4GB：LXQtが有利

2GB帯ではデスクトップ環境の選択が体感に直結する。Lubuntu 24.04 LTSはLXQtデスクトップを採用し、最低1GHz CPUで動作するよう設計されている。アイドル時のRAM使用量が700〜900MB程度で、2GB環境でもブラウザと文書作業を同時に使う余裕が生まれる。Linux Lite 8.0も同帯域での選択肢として挙げられる。WindowsユーザーのUI移行を特に意識した設計が特徴だ。

2.3 RAM 1GB以下：antiXとPuppy Linux

1GB以下になると選択肢は絞られるが、なくなるわけではない。antiX 26 "Stephen Kapos"（2026年3月リリース、Debian 13 Trixieベース）はアイドル時に約256MBのRAMしか使用しない。systemdを使用しない設計により起動が速くリソース効率が高い。512MBのハードウェアでも実用的に動作する。さらに極端なケースではPuppy Linuxが選択肢だ。システム全体をRAMに展開して実行するため、ディスクI/Oなしに非常に高速に動作する。

3. インストール前の準備 — このステップを飛ばさないこと

3.1 まずバックアップを取る

Linuxのインストールはディスクのパーティションを再構成するプロセスだ。設定を誤るとWindowsとデータが一緒に消える可能性がある。インストール開始前に、重要なファイル（写真、文書、ブラウザのブックマーク、ソフトウェアのライセンスキーなど）をすべて外付けストレージまたはクラウドにコピーしておくことが必須だ。

3.2 起動可能なUSBを作成する

ISOファイルをUSBに書き込むツールとしてVentoyを推薦する。VentoyはUSB1本に複数のISOを格納してブートメニューから選択する方式で、複数のディストロをテストする際に便利だ。単一ISOであればbalenaEtcherがシンプルで信頼性が高い。8GB以上のUSBを使用し、公式サイトからのみISOをダウンロードしてSHA256チェックサムを確認する習慣をつけよう。

3.3 BIOS/UEFIでUSB起動を有効化する

多くの古いPCは起動順序がHDD/SSD優先になっている。起動時にF2、Del、F12のいずれかを押してBIOS画面に入り、USBを最優先の起動デバイスに設定する。UEFIモードのデバイスでSecure Bootが有効になっている場合、一部のディストロが起動できないことがある。テスト時はSecure Bootを一時的に無効化するのが安全だ。

3.4 まずLiveモードでテストする

ほぼすべてのLinuxディストロは、内蔵ドライブを変更せずにUSBから直接起動するLiveモードを提供している。このモードでWi-Fi接続、画面解像度、音声出力、タッチパッドが正常に動作するかを確認する。Liveモードで問題なく動作すれば、実インストール後もほぼ同様に動作する。このステップをスキップしてインストールに進むと、ドライバ問題を後から対処することになるリスクが高まる。

4. 古いハードウェアのドライバ互換性 — どこで詰まるか

4.1 有線LANとIntel/AMDグラフィックス：ほぼ自動認識

IntelおよびRealtek製の有線LANカード、Intel内蔵グラフィックス、AMD内蔵グラフィックス（オープンソースのamdgpuドライバ）はLinuxカーネルに内蔵されたドライバで自動認識される。過去15年以内のデバイスの大部分がこの範疇に入る。

4.2 Wi-Fi：Broadcomに注意

古いノートPCで最も多いドライバ問題はBroadcom製Wi-Fiチップ（BCM43xxシリーズ）だ。Liveモードでつながらない場合はこのチップが原因の可能性が高い。解決策は有線LANで接続後、Additional Drivers（Linux MintやUbuntu系で提供）から独自ドライバをインストールすることだ。または、Linuxサポートの良いUSB Wi-FiアダプタでWi-Fiカードを代替する方法もある。

4.3 NVIDIA GPU：二つのドライバパス

NVIDIA GPUはオープンソースのNouveauドライバがデフォルトでインストールされる。基本的な画面出力と2D作業は問題ないが、3Dアクセラレーションやハードウェア動画デコードには制限がある。より高いパフォーマンスが必要な場合は、NVIDIA公式独自ドライバをインストールできる。Ubuntu/Mint系ではubuntu-drivers autoinstallコマンドか、Additional Drivers GUIで対応可能だ。

4.4 HDDからSSDへ：体感速度への最大の影響

古いPCが遅い原因として、CPUやRAMよりHDDがボトルネックになっているケースが多い。Linuxインストールの機会にSSD（60〜120GB）に交換するだけで体感速度が劇的に変わる。軽量ディストロ＋SSDの組み合わせは、重いディストロ＋HDDよりはるかに速い実体験をもたらす。これは単一の変数として、ディストロ選択より日常的な満足度に大きく影響することがある。

5. 日常用途でLinuxはどこまで使えるか

5.1 ウェブブラウジング：完全対応

FirefoxとChromiumはすべての主要ディストロで利用可能だ。Google Docs、YouTube、Netflix、その他の主要ウェブサービスはLinuxのブラウザで同様に動作する。古いデバイスでは多数のタブを開くとRAM不足が生じるが、これはLinuxの問題ではなくハードウェアの制約だ。

5.2 文書作業：LibreOfficeの正直な評価

LibreOffice 24.xは.docx、.xlsx、.pptx形式の読み書きができる。シンプルな文書なら互換性は高い。ただし複雑な書式設定、マクロ、フォームフィールド、特殊フォントを含む文書ではレイアウトが崩れることがある。Windowsユーザーとの文書のやり取りには、LibreOfficeよりもブラウザ上のGoogle DocsやMicrosoft 365の方が信頼性が高い場合が多い。

5.3 メディア再生：VLCで十分

VLC 3.xはLinux上でほぼすべての動画・音声フォーマットを追加コーデックなしに再生できる。ストリーミングはブラウザ、ローカルファイルはVLCで対応可能だ。古いデバイスでの4K再生はハードウェアデコードサポートに依存するが、1080pまでは概ね問題ない。

5.4 正直な限界

Adobe Photoshop、Illustrator、Premiere ProはLinuxネイティブ版が存在しない。GIMP、Inkscape、Kdenliveなどのオープンソース代替品はあるが、機能の差と学習曲線は無視できない。スチームゲームはProton経由でかなりの割合が動作するが、アンチチートを使用したマルチプレイヤーゲームはまだ制限がある。これらの限界を認識した上で移行すれば、失敗に終わるリスクが大幅に下がる。

6. 実践移行手順 — ステップバイステップ

ステップ1：スペック確認＋ディストロ選択

Windowsのタスクマネージャーの「パフォーマンス」タブでRAM容量とCPUモデルを確認する。上記の表から適切なディストロを選択する。初回移行なら、4GB以上はLinux Mint Xfce、2GB以上はLubuntu、1GB以下はantiXが無難だ。

ステップ2：バックアップ＋ISOダウンロード

重要ファイルを外付けストレージにバックアップする。公式サイトからISOをダウンロードしてSHA256を確認。VentoyまたはbalenaEtcherで8GB以上のUSBに書き込む。

ステップ3：Liveモードでテスト

BIOSでUSBを起動優先に設定して再起動。LiveモードでWi-Fi、画面、音声、タッチパッドを確認。テストをパスしたらインストールへ進む。

ステップ4：インストール

インストールウィザードはグラフィカルUIが主流だ。パーティション設定で「ディスク全体を使用」を選ぶ前に、バックアップの完了を再確認すること。言語、タイムゾーン、ユーザーアカウントを設定すれば20〜30分でインストールが完了する。

ステップ5：インストール後の必須作業

初回起動後にインターネットに接続し、システムアップデートを実行する。Additional Driversでドライバを確認し、必要なら追加インストールする。Firefox、LibreOffice、VLCはほとんどのディストロでデフォルト含まれているか、ワンクリックで利用可能だ。

7. まとめ

自宅や職場に遅くなった古いPCがあるなら、廃棄する前に30分かけてLive USBを作り起動テストをしてみる価値は十分にある。テストをパスすれば、さらに30〜60分のインストールでそのPCが2026年基準で十分に使える日常ツールとして蘇る可能性がある。

ディストロ選択は複雑に考えなくていい。4GB以上ならLinux Mint Xfce、2GBならLubuntu、1GB以下ならantiX。この3行で90%以上のケースはカバーできる。ドライバ問題は以前より格段に少なくなり、発生しても解決パスは概ねドキュメント化されている。廃棄寸前だったPCが、まだ数年の実用寿命を持っているかもしれない。
