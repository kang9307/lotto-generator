Microsoft 지원(support.microsoft.com) 문서 여덟 건(2026-10-06 열람, 문서별 갱신일은 참고 자료에 병기)에 적힌 한국어 메뉴 명칭과 절차만 다루며, 기준 환경은 Microsoft 365용 Word(Windows)이다.

Word 문서 작업의 적용 대상과 표기 기준

Word 로 문서 한 편을 만드는 작업은 새 문서 시작, 스타일 적용, 페이지 번호, 목차, PDF 저장, 자동 저장의 여섯 가지 기능으로 나뉜다. 기능마다 Microsoft 문서가 밝히는 적용 대상이 조금씩 다르므로, 같은 메뉴라도 Word 의 버전에 따라 화면이 다를 수 있다.

  • 새 문서: 「Word에서 문서 만들기」의 적용 대상은 Microsoft 365용 Word, Word 2024, Word 2021이다. 문서는 그 내용과 단계가 Microsoft 365용 Word와 Windows용 Word의 다른 데스크톱 버전에 적용된다고 밝힌다.
  • 페이지 번호·목차·필드: 페이지 번호 문서는 Microsoft 365용 Word, Word 2024, 2021, 2019, 2016과 각각의 Mac 판을 적용 대상으로 나열하고 Windows와 macOS 단계를 따로 둔다. 목차 문서는 Microsoft 365용 Word, Word 2024, 2021이며 Windows, macOS, 웹 단계가 있다. 필드 업데이트 문서는 Microsoft 365용 Word, Word 2024, 2021, 2019, 2016이다.
  • 스타일·PDF: 스타일 문서는 Word 와 Outlook 의 Microsoft 365, 2024, 2021, 2019, 2016 이 적용 대상이다. PDF 문서는 여러 Office 앱을 함께 다루며 Word 는 Microsoft 365, 2021, 2019, 2016 이 나열된다.
  • 자동 저장: 문서는 자동 저장을 Microsoft 365 구독자가 사용할 수 있는 기능이라고 설명한다. 구독자가 아니어도 자동 복구는 그대로 동작한다.

바로 가기 키는 「Word의 바로 가기 키」 문서에 적힌 Windows 기준 조합만 쓴다. 메뉴 경로는 「삽입 > 페이지 번호」처럼 문서의 한국어 표기를 따른다.

문서 한 편을 완성하는 순서 한눈에

새 문서를 열고, 제목과 본문에 스타일을 입히고, 페이지 번호와 목차를 넣은 다음, PDF 로 내보내거나 저장 위치를 정하는 순서로 작업이 이어진다. 아래 표는 각 단계의 메뉴 위치와 문서가 서술하는 내용, 그리고 적용 대상을 한곳에 모은 것이다.

작업 메뉴 위치 Microsoft 문서의 서술 적용 대상 또는 조건
새 문서 시작 파일 탭 > 새로 만들기 빈 문서를 선택하거나, 서식 파일 이미지를 두 번 클릭하거나, 온라인 서식 파일 검색 상자에 문서 종류를 입력하고 Enter Microsoft 365용 Word, Word 2024, Word 2021
스타일 적용 홈 탭의 스타일 갤러리 서식을 지정할 텍스트를 선택하고 갤러리에서 원하는 스타일을 클릭 Word 365, 2024, 2021, 2019, 2016
페이지 번호 삽입 삽입 > 페이지 번호 위치와 스타일을 선택하고, 첫 페이지 번호는 「첫 페이지를 다르게 지정」으로 숨김 Word 365, 2024, 2021, 2019, 2016
목차 삽입 참조 > 목차 자동 스타일을 고르면 문서의 제목을 기준으로 목차가 만들어짐 Word 365, 2024, 2021
PDF 저장 파일 > 복사본 저장 또는 다른 이름으로 저장 형식 드롭다운에서 PDF 를 선택하고 추가 옵션 > 옵션으로 사용자 지정 Word 365, 2021, 2019, 2016
자동 저장 제목 표시줄 왼쪽 위의 자동 저장 스위치 OneDrive, 비즈니스용 OneDrive, SharePoint Online 의 파일을 몇 초마다 자동 저장 Microsoft 365 구독자

이어지는 절은 이 표의 순서를 따라 각 단계에서 문서가 말하는 절차와 조건을 정리한다.

새 문서 시작하기 — 빈 문서와 서식 파일

새 문서는 파일 탭에서 새로 만들기를 선택하는 데서 시작한다. 문서는 Word 로 할 수 있는 일로 문서 만들기(처음부터 또는 서식 파일에서), 텍스트·이미지·아트·비디오 추가, 주제 조사와 신뢰할 수 있는 출처 찾기, OneDrive 를 통한 컴퓨터·태블릿·휴대폰 접근, 공유와 공동 작업, 변경 내용 추적과 검토를 든다.

  • 빈 문서: 새로 만들기 화면에서 빈 문서를 선택한다.
  • 서식 파일: 같은 화면에서 서식 파일 이미지를 두 번 클릭한다.
  • 온라인 서식 파일 검색: 온라인 서식 파일 검색 상자에 문서 종류를 입력하고 Enter 키를 누른다.
  • 텍스트 입력과 서식: 새 빈 페이지를 클릭해 텍스트를 입력하고, 서식을 지정할 텍스트를 선택한 뒤 홈 탭에서 굵게, 기울임꼴, 글머리 기호, 번호 매기기 같은 글꼴 옵션을 고른다.
  • 삽입 탭: 표(원하는 크기 위로 마우스를 가져가 선택), 그림(컴퓨터의 이미지, 온라인 스톡 이미지, Bing 이미지 검색), 도형, 아이콘, 3D 모델, SmartArt, 차트, 스크린샷을 추가한다.

이전 버전의 Word 에서는 리본의 그림 옆에 온라인 그림이 있을 수 있다고 문서는 덧붙인다. 새 문서는 바로 가기 키 Ctrl+N 으로도 만든다. 문서는 Word 기능을 연습하는 학습 가이드로 「Word 시작」과 「첫 번째 목차 삽입」을 추천한다.

스타일 — 갤러리·수정·바로 가기 키

스타일을 쓰면 문서 전체에 일관된 서식 선택 항목을 빠르게 적용할 수 있다. 스타일 갤러리는 홈 탭에 있는 시각적 메뉴이며, 서식을 지정할 텍스트를 선택한 다음 갤러리에서 원하는 스타일을 클릭하면 적용된다. 글자 크기와 굵기를 손으로 바꾸는 방식과 달리, 스타일로 지정한 제목은 뒤에서 다룰 목차의 기준이 된다.

  • 스타일 수정: 홈 탭의 스타일 갤러리에서 스타일을 마우스 오른쪽 단추로 클릭하고 수정을 선택한다. 서식 섹션에서 글꼴 스타일, 크기, 색, 맞춤, 줄 간격, 들여쓰기를 바꾸고, 변경을 현재 문서에만 적용할지 이후의 모든 문서에 적용할지 고른다.
  • 서식과 일치하도록 업데이트: 제목 1처럼 스타일이 적용된 텍스트를 선택해 서식을 바꾼 뒤, 홈 탭의 스타일 그룹에서 그 스타일을 오른쪽 단추로 클릭하고 「[스타일 이름] 업데이트」의 선택 항목 일치를 고른다. 그 스타일이 적용된 모든 텍스트가 새 서식에 맞춰 바뀐다. 문서의 예는 제목 1의 크기를 16포인트에서 14포인트로 바꾸는 것이다.
  • 새 스타일 만들기: 서식이 지정된 텍스트를 오른쪽 단추로 클릭하고 미니 도구 모음에서 스타일, 스타일 만들기를 차례로 선택한 뒤 이름을 붙인다. 모든 새 문서에 보이게 하려면 갤러리에서 수정을 열고 대화 상자 아래쪽의 「이 템플릿을 기반으로 새 문서」를 선택한다.
  • 바로 가기 키: 제목 1은 Ctrl+Alt+1, 제목 2는 Ctrl+Alt+2, 일반 스타일은 Ctrl+Shift+N 이다.

목차에서 항목이 빠지는 경우는 대개 제목의 형식이 제목으로 지정되지 않아서라고 목차 문서가 설명한다. 그럴 때는 목차에 넣을 제목 텍스트를 선택하고 홈 > 스타일에서 제목 1을 선택한 뒤 목차를 업데이트한다.

페이지 번호와 머리글·바닥글

페이지 번호는 삽입 탭에서 시작한다. 아래는 페이지 번호 문서의 Windows 단계다.

  • 삽입: 삽입 탭에서 페이지 번호를 선택한 다음 원하는 위치와 스타일을 선택한다.
  • 첫 페이지 번호 숨기기: 첫 번째 페이지에 페이지 번호가 표시되지 않게 하려면 「첫 페이지를 다르게 지정」을 선택한다.
  • 번호 시작값: 번호 매기기를 두 번째 페이지에서 1로 시작하려면 페이지 번호 > 페이지 번호 서식으로 가서 시작 위치를 0으로 설정한다.
  • 편집 종료: 머리글 또는 바닥글 닫기를 선택하거나 Esc 키를 누른다.
  • 다시 편집: 변경할 머리글 또는 바닥글로 돌아가려면 머리글 또는 바닥글 영역을 두 번 클릭한다.

macOS 단계는 조금 다르다. 삽입 탭에서 페이지 번호를 선택하고 다시 페이지 번호를 선택한 다음, 위치와 맞춤 스타일을 고른다. Word 는 지정된 제목 페이지를 제외한 모든 페이지에 자동으로 번호를 매긴다. 번호 매기기 스타일은 위쪽 도구 모음에서 서식을 선택해 바꾸고, 확인을 두 번 선택해 두 대화 상자를 닫는다.

표지가 있는 문서에서는 Windows 의 두 단계를 이어서 적용하면 된다. 첫 페이지를 다르게 지정하면 첫 페이지에 번호가 나타나지 않고, 시작 위치를 0으로 두면 두 번째 페이지가 1로 시작한다.

목차 만들기와 필드 업데이트

Word 의 목차는 문서의 제목을 기준으로 한다. 제목 텍스트, 순서, 수준을 바꾸면 자동 목차가 그에 맞춰 업데이트될 수 있다.

  • 삽입: 목차를 넣을 위치(보통 문서의 앞부분)에 커서를 놓고 참조 > 목차를 선택한 다음 목록에서 자동 목차 스타일을 고른다.
  • 서식과 사용자 지정: 글꼴, 제목 수준의 수, 항목과 페이지 번호 사이에 점선을 표시할지 여부를 바꿀 수 있다.
  • 수동 목차 스타일: 수동 목차 스타일을 쓰면 Word 가 제목으로 목차를 만들지 않고 자동으로 업데이트하지도 못한다. 개체 틀 텍스트로 목차 모양만 만들어 주므로 각 항목을 직접 입력해야 한다.
  • 목차 업데이트: 목차에 영향을 주는 변경을 했다면 목차를 마우스 오른쪽 단추로 클릭하고 업데이트 필드를 선택한다. 목차 업데이트 대화 상자에서는 페이지 번호만 업데이트할지 전체 표를 업데이트할지 고르며, 페이지 번호만 업데이트하면 기존 구역의 번호만 바뀌고 새 구역은 목차에 추가되지 않는다.
  • 모든 필드 업데이트: Ctrl+A 를 누른 뒤 F9 키를 누른다. 필드나 수식이 있는 표는 각 표를 따로 선택해 F9 를 눌러야 할 수 있다. 인쇄 전에 목차 업데이트를 잊지 않으려면 파일 > 옵션 > 표시의 인쇄 옵션에서 「인쇄 전에 필드 업데이트」를 선택한다.
  • 웹용 Word: 목차 문서의 웹 단계는 참조를 선택한 다음 목차 삽입을 선택하는 것이다.

필드는 목차, 머리글과 바닥글, 상호 참조, 책갈피, 표의 수식에 쓰이며 가끔 수동으로 업데이트해야 한다. 텍스트의 어느 부분이 필드인지 알아보기 어렵다면 파일 > 옵션 > 고급의 문서 콘텐츠 표시에서 필드 음영을 「항상」으로 바꿔 회색 배경으로 볼 수 있다. 필드가 업데이트되지 않는 이유는 필드가 참조하는 항목이 더 이상 없거나 링크나 책갈피가 끊어졌기 때문일 수 있다.

PDF 로 저장하기 — Word 에서의 절차와 옵션

Office 프로그램으로 파일을 PDF 로 저장하거나 변환할 수 있고, 다른 소프트웨어나 추가 기능은 필요하지 않다. 문서는 대부분의 컴퓨터에서 모양이 같은 문서, 파일 크기가 작은 문서, 산업 형식을 따르는 문서가 필요할 때 PDF 포맷을 쓰라고 하며, 예로 이력서, 법적 문서, 뉴스레터, 읽기용이나 인쇄용 파일, 전문 인쇄용 파일을 든다. 다만 PDF 로 공유한다고 받는 사람이 편집할 수 없다는 보장은 없다. Word 를 비롯한 많은 프로그램이 PDF 를 열어 편집할 수 있기 때문이다. 이 문서는 Access, Excel, OneNote, PowerPoint, Project, Word 의 절차를 한 페이지에 나눠 싣고 있어서, Word 에 해당하는 부분은 일부다.

Word 에서는 파일이 이미 저장되어 있으면 파일 > 복사본 저장을, 저장되지 않았으면 다른 이름으로 저장 또는 복사본 저장을 선택한다. 찾아보기로 저장 위치를 고르고 드롭다운 목록에서 PDF 를 선택한 다음 저장한다. 추가 옵션 > 옵션을 선택하면 PDF 를 사용자 지정할 수 있다.

암호로 문서 암호화 암호를 아는 사람만 PDF 를 열 수 있도록 제한
  • PDF 열기: 파일 > 열기에서 PDF 파일을 찾으면 Word 가 PDF 콘텐츠를 새 파일로 열고, 이미지와 다이어그램을 포함해 필요한 내용을 복사할 수 있다.
  • Mac: 파일 > 다른 이름으로 저장 또는 복사본 저장에서 창 아래쪽의 파일 형식을 PDF 로 고른다. 문서는 Best for printing 을 쓰면 하이퍼링크가 올바르게 변환되지 않을 수 있으며 이것이 Mac용 Word 의 알려진 문제라고 적는다.
  • 웹용 Word: 파일 > 인쇄에서 프린터 드롭다운의 PDF 로 저장을 선택한다. 책갈피 같은 PDF 옵션이 더 필요하면 편집 드롭다운에서 데스크톱 앱에서 열기를 선택해 데스크톱 앱으로 변환한다. 온라인 서비스에서는 Microsoft 가 법적 권한을 가진 글꼴만 쓸 수 있어 사용자 지정 글꼴이 대체될 수 있다.

PDF 저장 절차는 PowerPoint 에도 같은 문서가 적용되지만 단계와 옵션이 다르다. 슬라이드 문서의 PDF 저장은 파워포인트 처음 쓰는 순서에서 따로 다루고, Word 문서에는 위 절차와 옵션이 해당한다.

자동 저장과 버전 기록 — 켜지는 조건

자동 저장은 Excel, Word, PowerPoint 에서 작업하는 동안 몇 초마다 파일을 자동으로 저장하는 기능이며, 문서는 Microsoft 365 구독자가 쓸 수 있다고 설명한다. 켜지는 조건과 끌 수 있는 조건은 저장 위치가 가른다.

  • 켜지는 조건: 파일이 OneDrive, 비즈니스용 OneDrive, SharePoint Online 에 저장되어 있으면 Microsoft 365 에서 자동 저장이 기본으로 켜진다. 최신 Windows 용 Word 를 쓰는 구독자는 제목 표시줄 왼쪽 위에 자동 저장 스위치가 보인다.
  • 꺼지는 조건: SharePoint 온-프레미스 사이트, 파일 서버, 일부 다른 클라우드 저장소 서비스, C:\ 같은 로컬 경로에 있거나 아직 저장하지 않은 파일에서는 비활성화된다. 이 밖에 .doc 같은 이전 형식의 파일, 일시 중지된 OneDrive 동기화, 이전 버전의 OneDrive 동기화 앱, 다른 Office 파일에 포함된 파일도 이유로 꼽힌다.
  • 수동 저장: Ctrl+S, 저장 단추, 파일 > 저장으로 언제든 직접 저장할 수 있다. 구독자가 아니어도 자동 복구가 충돌 때 파일을 보호하며, 충돌 뒤 다시 열면 문서 복구 창에 최근 변경이 적용된 버전이 나타난다.
  • 버전 기록: 창 맨 위의 파일 이름을 클릭하고 버전 기록을 선택한 다음 날짜와 시간을 보고 버전 열기, 복원을 차례로 선택한다. 파일을 열고 처음 변경하면 새 버전이 기록에 추가되고, 이후에는 편집이 이어지는 동안 약 10분마다 새 버전이 추가된다.
  • 복사본 저장: OneDrive 등에서 문서를 열면 파일 메뉴에서 다른 이름으로 저장이 사라지고 복사본 저장이 대신 나타난다. 원본이 아닌 복사본에 변경을 남기려면 편집 전에 파일 > 복사본 저장을 쓰는 편이 안전하다.

개별 파일의 자동 저장을 끄면 프로그램이 그 상태를 기억해 다시 열 때도 꺼진 채로 둔다. 모든 파일의 기본값을 끄려면 파일 > 옵션 > 저장에서 OneDrive 및 SharePoint Online 파일 자동 저장 옆의 확인란을 해제하고 Word 를 다시 시작한다. 변경 내용을 다른 사람에게 보이지 않게 잠시 시험해 보려면 저장하기 전에 자동 저장 스위치를 끄고, 저장하지 않으려면 파일을 닫으면서 저장 여부를 묻는 메시지에 아니요를 선택한다. 소유자는 파일 > 정보 > 문서 보호의 「항상 읽기 전용으로 열기」로 실수로 인한 변경을 막을 수도 있다.

확인하지 못한 것

  • Word 2024, 2021, 2019, 2016 사이의 리본 화면과 메뉴 위치 차이. 문서는 적용 대상을 나열할 뿐 버전별 화면 차이를 서술하지 않는다.
  • 목차 갤러리에 표시되는 개별 스타일의 이름, 그리고 디자인·레이아웃 탭 기능. 문서는 「자동 목차 스타일」이라고만 쓰고 두 탭은 다루지 않는다.
  • Word 의 PDF 절차에서 표준과 최소 크기 최적화를 고르는 단계. 이 선택은 같은 문서의 Access, Excel, PowerPoint 절차에만 나온다.
  • Word 2021과 Word 2024 비구독 버전에서 자동 저장을 쓸 수 있는지 여부. 적용 대상 목록에는 해당 버전이 나열되지만 본문은 Microsoft 365 구독자 기능이라고 설명한다.
  • 자동 저장이 꺼지는 「일부 다른 클라우드 저장소 서비스」가 구체적으로 어떤 서비스인지. 문서는 서비스 이름을 밝히지 않는다.
