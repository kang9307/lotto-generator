FAQ

Is the text or URL I enter sent to a server?

No. The QR code is drawn directly onto a canvas in your browser by the qrcodejs JavaScript library. The page makes no network request containing your input; only the library file itself is loaded from a CDN.

Do the generated QR codes expire or have usage limits?

No. This tool creates static QR codes that encode your input directly, so they never expire, and the downloaded PNG is yours to use freely. To change the content, simply generate a new code.

What should I do if my QR code will not scan?

Increase the contrast between foreground and background colors (dark pattern on a light background works best), make the code larger, or shorten the input. Longer content produces a denser pattern that is harder for cameras to read.
