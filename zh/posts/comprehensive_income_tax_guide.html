前言：每年5月，韩国综合所得税申报概述

在韩国，每年5月是综合所得税（종합소득세）申报季。在公司完成年末结算（연말정산）的上班族通常无需另行申报，但自由职业者、YouTuber、讲师、有副业收入者、有不动产租赁收入者等均须依法申报。

本文基于韩国国税厅官方资料及Hometax申报指引，系统整理2025年度（2025年1月至12月产生的所得）综合所得税申报要点，依次说明申报对象、所得种类、税率、扣除项目、必要费用、Hometax申报步骤及罚款税。

本文于2026年6月首次撰写，并于2026年9月29日更新。变更内容集中列在文末附近的更新记录中。税法可能修订，个人情况各异。申报前请务必通过韩国国税厅最新公告或税务专业人士进行确认。

综合所得税简介及所得种类

综合所得税是个人将一年内从多个来源取得的所得合并申报缴纳的税种。韩国《所得税法》将所得大致分类如下。

纳入综合所得的所得类型

  • 利息所得：存款利息、债券利息等。与股息所得合计超过年2000万韩元时，适用综合课税
  • 股息所得：股票股息、基金分红等。与利息所得合计超过2000万韩元时，适用综合课税
  • 事业所得：个体工商户、自由职业者（人力劳务）、不动产租赁等。原则上无论金额大小均适用综合课税
  • 劳动所得（工资）：公司薪资、奖金等。完成年末结算后通常无需另行申报。在两处以上任职且未合并结算，或需与其他所得合并时须申报
  • 年金所得：公共年金（国民年金、公务员年金等）年末结算完成后无需申报。私人年金超过年1500万韩元（2023年12月31日以前为1200万韩元）时适用综合课税，也可在申报综合所得税时选择15%分离课税
  • 其他所得：讲课费、稿费、奖金、咨询费等。扣除必要费用后的其他所得金额在年300万韩元以下且已预扣税款时，可在分离课税与综合课税之间选择（无条件分离课税·综合课税项目除外）

从综合所得中分离的所得

  • 退休所得：适用退休所得税，分离课税
  • 转让所得：适用转让所得税，分离课税
  • 分离课税的金融所得：利息与股息合计2000万韩元以下，源头预扣即完成纳税

无需申报的情形

符合以下情形之一时，一般无需申报综合所得税（以没有其他所得为前提）。

  • 仅有劳动所得且已在公司完成年末结算
  • 仅有公共年金且已完成年末结算
  • 金融所得（利息＋股息）合计在年2000万韩元以下
  • 其他所得金额（收入减去必要费用）在年300万韩元以下、已预扣税款且选择了分离课税

申报期限与缴纳期限

综合所得税须在每年规定期间内完成申报与缴纳，超过期限将被加收罚款税。

一般申报与缴纳期限

  • 申报期间：原则上为次年5月1日至5月31日。截止日遇周六或公休日时顺延至次日，2025年度因5月31日为星期日，截止日为2026年6月1日（星期一）
  • 诚实申报确认书提交者：次年6月30日前（2025年度为2026年6月30日）
  • 缴纳：在申报截止日前缴纳。针对2025年度，韩国国税厅已依职权将增值税缴纳期限获延长者等部分纳税人的缴纳期限延长至2026年8月31日

分期缴纳制度

应缴税额超过1000万韩元时，可在缴纳期限届满后2个月内分期缴纳部分税款。可分期缴纳的金额取决于应缴税额的规模，请以申报画面及国税厅指引中显示的可分期金额为准。

逾期申报

错过截止日期后，办理期限后申报可减轻无申报罚款税。韩国《国税基本法》第48条规定的减免只有法定申报期限届满后1个月内减免50%、1个月以上3个月以内减免30%、3个月以上6个月以内减免20%三档，因此即使逾期也应尽早申报。

综合所得税税率表（2025年度基准）

韩国综合所得税采用8档累进税率结构，所得越高税率越高。以应纳税所得额（所得减去各类扣除）乘以对应税率，再减去累进扣除额，计算出应纳税额。

税额计算示例

应纳税所得额为3000万韩元时：3000万 × 15% − 126万 = 324万韩元为应纳税额。

再减去税额扣除项，并抵扣已预扣税款（如3.3%），即可得出最终应补缴或应退税额。

所得扣除与税额扣除主要项目

综合所得税可通过各类扣除减少实际应缴税额。扣除大致分为所得扣除（减少应纳税所得额，间接降低税负）和税额扣除（直接从应纳税额中减除）。

本节中子女税额扣除与黄伞共济（노란우산공제）扣除上限为2026年9月时点的数值，其他金额和比率为2026年6月时点的数值（本次未能再次核实）。各项扣除适用的所得类型（劳动所得、事业所得等）不同，请通过国税厅指引确认是否适用于本人。

主要所得扣除

  • 人身扣除（基本扣除）：本人150万韩元。受抚养家属（配偶、直系亲属等）每人150万韩元。老年人、残障人士、单亲家庭等可追加扣除
  • 年金保险费扣除：国民年金及职域年金缴纳额全额扣除
  • 特别所得扣除：健康保险费、就业保险费缴纳额（劳动所得者）
  • 黄伞共济扣除（노란우산공제）：小企业·小工商业者共济缴款可扣除。上限为事业所得金额4000万韩元以下600万韩元，4000万韩元以上1亿韩元以下400万韩元，超过1亿韩元200万韩元（以韩国国税厅国税咨询中心说明为准）
  • 所得扣除综合上限：信用卡等使用金额扣除等部分所得扣除合计不超过年2500万韩元

主要税额扣除

  • 标准税额扣除：劳动所得者13万韩元，事业所得者（诚实申报确认书提交者除外）7万韩元
  • 子女税额扣除：基本扣除对象子女1名年25万韩元，2名年55万韩元，3名及以上在55万韩元基础上每超出1名加40万韩元。当年生育或收养的，第一胎30万韩元、第二胎50万韩元、第三胎及以上70万韩元另行追加（韩国法制处生活法令信息，基准日2026-08-31）
  • 教育费税额扣除：教育费支出额的15%（仅限劳动所得者等特定对象的特别税额扣除）
  • 医疗费税额扣除：医疗费（超过总所得3%的部分）的15%至30%（适用对象有限的特别税额扣除）
  • 捐赠金税额扣除：按捐赠类型和金额区间适用15%至30%
  • 电子申报税额扣除：纳税人本人电子申报时扣除2万韩元

2026年度以后的变化——已确定修订与政府方案的区别

  • 已写入法律的内容：子女税额扣除的对象年龄将分阶段提高：2026年9岁以上、2027年10岁以上、2028年11岁以上、2029年12岁以上，此后为13岁以上（韩国法制处生活法令信息）。韩国国家法令信息中心已刊载2025年12月23日部分修订的《所得税法》（法律第21221号，2026年7月1日施行）
  • 仍为政府方案的内容：2026年9月1日确定的政府2026年税制改革方案包括：放宽配偶及受抚养家属基本扣除的所得要件（所得金额100万韩元以下→300万韩元以下；仅有劳动所得的，总工资500万韩元以下→750万韩元以下）、青年月租税额扣除优惠、取消信用卡所得扣除中的公共交通追加扣除等。国会审议过程中内容与施行时间可能变化
  • 保持不变的内容：2025年度申报适用的税率表（8档，6%~45%）在上述改革方案介绍文章中未被列为变更事项

事业所得必要费用处理

有事业所得时，以收入减去必要费用后的金额为课税对象。必要费用有两种处理方式：以账簿证明实际费用的账簿申报，以及适用国税厅规定比率的推算申报。

账簿申报（기장신고）

上一纳税期间收入低于行业基准（例如：批发零售业3亿韩元、制造业1.5亿韩元、不动产租赁业7500万韩元）的为简易账簿对象，达到或超过基准的须按每笔交易分借方和贷方记录，即负有复式记账义务。依据账簿可扣除实际发生的全部费用（房租、人工费、材料费、广告费等），实际支出较多时更为有利。未记账时可能被处以账簿记录·保管不诚实罚款税（无账簿罚款税），计算方式为「应纳税额 ×（未记账·记账不足所得金额 ÷ 综合所得金额）× 20%」，小规模事业者除外。

推算申报（单纯经费率·基准经费率）

无账簿申报时，适用国税厅按行业规定的经费率。

  • 单纯经费率（단순경비율）：适用于上一年收入低于基准金额的小规模事业者。以收入乘以单纯经费率所得金额认定为费用
  • 基准经费率（기준경비율）：主要费用（采购费、租金、人工费）凭实际票据扣除，其余费用按基准经费率处理

预填申报（모두채움）

国税厅预先填写收入与扣除明细并发出通知。适用于有人力劳务所得（自由职业者、讲师等）的情形，核实内容无误后可直接提交。如有追加扣除项目，需自行修改或补充。

Hometax综合所得税申报步骤

通过Hometax（www.hometax.go.kr）进行电子申报是最常见的方式。现场申报是指前往税务署直接提交申报表。

Hometax申报流程

  1. 登录Hometax：使用共同（公认）证书、简便认证（Kakao、Naver、PASS等）或金融证书登录
  2. 进入申报菜单：进入综合所得税申报菜单。菜单名称和位置可能随Hometax界面改版而变化，请按画面指引操作
  3. 选择申报类型：
    • 预填/单纯经费率申报：适合小规模事业者，国税厅已预填数据
    • 账簿申报（一般·简易账簿）：以实际账簿核算费用
    • 金融所得申报：金融所得超过2000万韩元时适用
  4. 填写申报表：输入收入金额、必要费用、所得扣除、税额扣除，利用自动计算功能
  5. 提交申报表并缴税：提交后确认缴款书，通过虚拟账户、网银或银行卡缴纳
  6. 申报地方所得税：根据国税厅说明，在Hometax完成综合所得税申报后，可通过画面上方的「转至地方所得税申报」按钮继续申报地方所得税。地方所得税为所得税的10%

手机申报（Sontax App）

预填申报等简单类型也可通过Sontax（손택스）手机App完成。账簿申报、金融所得申报等复杂类型建议使用PC操作。

罚款税：逾期或错误申报的后果

未能按期准确申报和缴纳时将被处以罚款税。罚款税因类型不同而金额各异，并可能同时适用。

主要罚款税类型

罚款税类型触发情形税率（一般标准）
无申报罚款税在申报期限内未申报无申报应缴税额的20%（不正当无申报40%）
少报罚款税申报税额低于实际应缴少报应缴税额的10%（不正当行为40%）
滞纳罚款税超过缴纳期限未缴税额 × 逾期天数 × 2.2/10,000（每日0.022%）
账簿记录·保管不诚实罚款税（无账簿）未记账或记账不足应纳税额 ×（未记账·记账不足所得金额 ÷ 综合所得金额）× 20%，小规模事业者除外

同时符合无申报罚款税和无账簿罚款税时，只适用金额较大的一项；金额相同时适用无申报罚款税（韩国国税厅综合所得税罚款税说明）。

罚款税税率及适用方式可能随税法修订而变化。具体金额计算请向韩国国税厅或税务师确认。

主动申报减免

逾期后主动办理期限后申报的，无申报罚款税在法定申报期限届满后1个月内减免50%、3个月内减免30%、6个月内减免20%（《国税基本法》第48条第2款第2项）。在期限内已申报、事后更正的修正申报另有减免规定，按1个月内90%至2年内10%的多个区间减免少报罚款税（同条第2款第1项）。请勿将两种制度的减免区间混用。

常见问题解答（FAQ）

问1：自由职业者（3.3%预扣）也必须申报吗？

是的。3.3%为预扣税款，不是最终税款。实际税额需根据总所得和扣除项确定，差额须补缴或退还，因此必须申报综合所得税。若充分利用必要费用与扣除项，可能退还部分已扣的3.3%。

问2：有副业收入也需要申报吗？

若在公司完成年末结算的工资所得之外另有事业所得，或扣除必要费用后的其他所得金额超过300万韩元，须合并申报综合所得税。若副业为其他所得且其他所得金额在300万韩元以下并已预扣税款，可选择分离课税。

问3：地方所得税需要单独申报吗？

需要。完成综合所得税申报后，还须另行申报缴纳地方所得税（所得税的10%）。在Hometax申报完成画面可直接转至地方所得税申报。

问4：无法一次性缴清税款怎么办？

先在期限内完成申报，即可避免无申报罚款税。缴纳困难时，可利用分期缴纳（应缴税额超过1000万韩元，2个月内），或向国税厅申请延长缴纳期限、暂缓征收。申请条件与流程请在国税厅网站确认。

问5：没有税务师，能自己完成申报吗？

单纯经费率或预填申报对象可在Hometax相对便捷地自行完成申报。事业所得复杂或需要记账时，为充分享受合法的节税项目，委托税务师也是不错的选择。

总结：按时申报，充分利用扣除项目

韩国综合所得税申报看似复杂，但最重要的是掌握自身适用的申报类型并按时申报。自由职业者、个体工商户、有副业收入者尤其要仔细核查必要费用和扣除项目，避免多缴税款。

请记住以下三点。

  • 遵守期限：5月31日（一般；遇周末或公休日顺延至次日，2025年度为6月1日），6月30日（诚实申报确认书提交者）。逾期时应在6个月内、最好1个月内办理期限后申报
  • 最大化扣除：人身扣除、年金保险费、子女税额扣除、黄伞共济等适用于本人的项目均不可遗漏
  • 善用专业资源：情况复杂时，向税务师咨询以制定合法的节税方案

税法每年可能修订。申报时请务必确认韩国国税厅最新指引，或向税务专业人士咨询。

# 韩国综合所得税申报核对表（2025年度基准）

基准日：2026-09-29。数值来自韩国国税厅、国家法令信息中心及韩国法制处生活法令信息，可能随税法修订而变化。本文不构成税务建议——申报前请向韩国国税厅或持牌税务师确认。

---

## 1. 我是否需要申报

| 我的所得 | 是否需要申报 |
|---|---|
| 仅有劳动所得，已完成年末结算 | 原则上无需 |
| 仅有公共年金，已完成年末结算 | 原则上无需 |
| 事业所得（含3.3%预扣的自由职业者） | 无论金额均须申报 |
| 利息＋股息年超过2000万韩元 | 须申报（综合课税） |
| 私人年金年超过1500万韩元 | 综合课税，或申报时选择15%分离课税 |
| 其他所得金额（扣除必要费用后）年300万韩元以下且已预扣 | 可选择分离课税 |
| 其他所得金额年超过300万韩元 | 综合课税 |
| 两处以上任职且未合并年末结算 | 须申报 |

---

## 2. 期限核对清单

- [ ] 一般申报缴纳期限：次年5月31日（遇周六或公休日顺延至次日——2025年度为2026年6月1日）
- [ ] 诚实申报确认书提交者：次年6月30日
- [ ] 确认是否属于国税厅依职权延长对象（2025年度部分纳税人缴纳期限为2026年8月31日）
- [ ] 应缴税额超过1000万韩元可分期缴纳（缴纳期限后2个月内）——金额以申报画面为准
- [ ] 地方所得税（所得税的10%）须另行申报——Hometax申报后点击「转至地方所得税申报」按钮

---

## 3. 逾期时——期限后申报减免（《国税基本法》第48条）

| 法定申报期限届满后 | 无申报罚款税减免 |
|---|---|
| 1个月以内 | 50% |
| 1个月以上~3个月以内 | 30% |
| 3个月以上~6个月以内 | 20% |
| 超过6个月 | 无此减免区间 |

注意：「1年内10%」等较长区间属于**修正申报**（期限内已申报、事后更正）的减免，不得混用于期限后申报。

---

## 4. 罚款税一览

| 类型 | 计算方式 |
|---|---|
| 无申报 | 无申报应缴税额 × 20%（不正当无申报40%） |
| 少报 | 少报应缴税额 × 10% |
| 滞纳 | 未缴税额 × 逾期天数 × 2.2/10,000（每日0.022%） |
| 无账簿（账簿记录·保管不诚实） | 应纳税额 ×（未记账·记账不足所得金额 ÷ 综合所得金额）× 20%，小规模事业者除外 |

无申报罚款税与无账簿罚款税同时适用时，只适用金额较大的一项。

## 5. 税率表（韩国国税厅「2023~2025年度」）

| 应纳税所得额 | 税率 | 累进扣除 |
|---|---|---|
| 1400万韩元以下 | 6% | - |
| 1400万~5000万韩元 | 15% | 126万韩元 |
| 5000万~8800万韩元 | 24% | 576万韩元 |
| 8800万~1.5亿韩元 | 35% | 1544万韩元 |
| 1.5亿~3亿韩元 | 38% | 1994万韩元 |
| 3亿~5亿韩元 | 40% | 2594万韩元 |
| 5亿~10亿韩元 | 42% | 3594万韩元 |
| 超过10亿韩元 | 45% | 6594万韩元 |

计算：应纳税所得额 × 税率 − 累进扣除 = 应纳税额。例：3000万 × 15% − 126万 = 324万韩元。

## 6. 扣除遗漏核查

- [ ] 子女税额扣除：1名25万·2名55万韩元·3名及以上55万韩元＋每超出1名40万韩元
- [ ] 当年生育或收养：第一胎30万·第二胎50万·第三胎及以上70万韩元另行追加
- [ ] 黄伞共济：事业所得金额4000万韩元以下600万·1亿韩元以下400万·超过1亿韩元200万韩元为上限
- [ ] 人身扣除·年金保险费扣除（2026年6月时点数值：每人150万韩元）
- [ ] 电子申报税额扣除（2026年6月时点数值：2万韩元）
- [ ] 教育费·医疗费税额扣除为适用对象有限的特别税额扣除——确认本人所得类型是否适用
