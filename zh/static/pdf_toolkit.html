🔒 为什么是安全的

大多数在线 PDF 服务都会先把文件上传到服务器，在那边处理后再把结果传回来。这很方便，但如果是合同、证件复印件、工资单这类不能给别人看的文件，情况就完全不同了。本工具直接去掉了这一步。

  • 只用 File API 读取。 浏览器把文件读进内存，不会向任何地址发送。
  • 结果也由浏览器生成。 合并后的 PDF 由本页面的 JavaScript 直接组装，下载只是打开内存里的临时地址。
  • 只有程序本身会走网络。 除了打开页面时下载一次 PDF 处理库之外，没有任何与文档相关的通信。
  • 关闭标签页就全部消失。 不仅服务器上没有，浏览器存储中也不会留下文档。

想自己验证的话，打开浏览器开发者工具（F12）的网络面板再执行一次合并，你会看到没有任何传输文件的请求。

各功能用法与输出文件名
  • 合并 — 添加多个 PDF，用箭头排好顺序后点击开始合并。结果保存为 merged.pdf。
  • 拆分 — 像「1-3,5,8-10」这样填写范围，或直接点击页面缩略图。合成一个 PDF 时文件名为 pages_1-3,5,8-10.pdf，拆成单页时为 文件名_p1.pdf。
  • 页面编辑 — 选中页面后应用旋转或删除，并用每页的 ◀ ▶ 调整顺序。结果为 文件名_edited.pdf。
  • 图片 → PDF — 按顺序添加照片，选择纸张、方向与页边距。结果为 images.pdf。
需要了解的限制
  • 加密的 PDF 无法打开。 设置了打开密码或权限密码的文档在结构上已被加密，无法读取。请先在原始软件中解除密码再试。
  • 书签、批注、表单与电子签名可能丢失。 由于是复制页面生成新文档，附着在文档层面的信息不会跟随。带电子签名的文档一旦编辑，签名就会失效。
  • 大文件受设备性能影响。 合计超过 50MB 会出现警告。全部处理都在本机进行，内存不足时标签页会变慢。
  • 预览只绘制前面部分。 页数非常多时只绘制前 200 页的缩略图，其余以页码显示。提取与编辑本身对全部页面都有效。
  • 没有文字识别（OCR）与压缩。 本工具专注于页面级重组，不提供从扫描件中提取文字或缩小体积的功能。
重要文件请保留原件。 本工具不会修改源文件而是生成新文件，但在确认结果之前不要删除原件更为稳妥。如果浏览器扩展或广告拦截器屏蔽了处理库，工具可能无法运行。
