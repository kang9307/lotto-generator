「陌生的智能」有多少是观测 - 把主张分成三层来读

被观测到的行为、关于模型内部的主张，还有比喻。三者混在一起，调查就停了

2026-09-07 潮流/文化

2026年9月6日，openai.com 上出现了一篇题为 An Alien Mind 的文章。中文可以理解成「一种与人不同的、陌生的智能」。多家媒体把这篇文章记在 OpenAI 首席科学家雅库布帕霍茨基名下。

这类文章读完之后，反应大致落在两种里。一种是「果然是没法弄懂的东西」，另一种是「说到底不过是按概率挑下一个词，讲得太夸张」。两种看着相反，做的却是同一件事。都是用一句话把事情盖住，然后停止调查。

所以这里用的尺子不是赞成或反对。轴只有一条：说它陌生的这些主张里，哪些经由观测得到确认，哪些是比喻。把这把尺子按上去，同一篇文章里也会出现逐句不同的处理方式。有的句子可以重新测，有的句子还没有数值，有的句子本来就不是数值的对象。

下面只把原文的主张分层，不做别的。既不评价对错，也不比较不同公司或不同模型的高下。处理观测那几处时所引的数值全部来自公开的论文和评测文档，并附上样本与条件。文面无法确认的条目不写进正文，而是连同理由集中放在后面的一节。

「陌生」这个词实际指的是什么

原文由六节构成：我们并未完全理解的智能、教机器去爱、对泛化的监控、可扩展的防御、递归自我改进的节奏，以及接下来是什么。光看标题就能判定这篇文章属于哪一类。政策评论，不是实验报告。

先把类别钉住是有理由的。在政策评论里，观测、预判和规范会在同一段里自然衔接，这是这种体裁的语法，不是毛病。问题出在文章被转述的时候。转述的人通常挑最强的那句，而最强的那句几乎总是比喻。「陌生的智能」留了下来，原本挨着它的条件掉了。一句话要成为命题需要挂上哪些条件，这种清点在这里同样必须做一遍。

而且「陌生」本身就不是一种句子。至少有三样东西叠在这个词底下：与人不同的行为确实被观测到；模型内部的构造与人的内部不同；以及把这种不同比作外星人或陌生人。三者判定真假的方式各不相同。第一种测一下就有答案，第二种要先有可操作的定义才谈得上处理，第三种本来就不是真假的对象。

把主张分成三层

层是这样划的。标准只有一条：第三方要做什么，才能处理这句话。

  • 层 ⓐ 被观测到的行为 - 给输入、收输出、数一数就能出数值的东西。基准分数、错误分布、改变条件后的变化都在这一层。判定的方法已经写在句子里了。
  • 层 ⓑ 关于内部的主张 - 权重与激活里放着什么、怎么放的。要处理这类句子，必须先把那样东西定义成可测量的形式。没有定义，谈真假之前问题本身就不成立。
  • 层 ⓒ 比喻与借喻 - 「陌生的智能」「长出来的」「教它去爱」。这是帮助理解的工具，作为工具是有用的。只要别忘记它不是能挂上数值的对象就行。

用这把尺子拆开原文的句子，就得到下面这张表。左栏是把原文的主张搬过来，右栏是第三方能拿它怎么办。

数下来是这样。十七句里，具备观测形式的有五句，处在交界的有两句，关于内部的有四句，比喻四句，规范两句。而这五句观测形式里，能从外部直接确认的只有一句，就是早期推理模型的产品设计。剩下四句只有观测的形式，没有挂上数值。

这不必称作缺陷。要求政策评论给出基准测试的表格，是读错了体裁。要紧的是读的人在读的时候知道这件事。没有数值的句子放进的是「尚未公开数值」那一栏，而不是「假」那一栏。两栏完全不同。

层在这一层能问什么问了也得不到答案的
ⓐ 被观测到的行为是哪一项评测。样本与条件是什么。换个条件还一样吗为什么会出这个数值
ⓑ 关于内部的主张这个概念用什么来测。能不能做因果干预模型是否感觉到或想要它

可观测之处 ① 错误落在哪里

下到层 ⓐ。「与人不同」真正变成数值的第一处，是错误落在哪里。人和机器都会犯错，这不是新鲜事。不同的是犯错位置的分布。

只留下对人容易、对机器困难的任务

ARC-AGI 就是冲着这个分布差异造出来的基准。它的设计原则本身就是「对人容易，对 AI 困难」。2025年5月发布的 ARC-AGI-2 技术报告附上人类测试结果，把这个性质钉死。摘要的说法是：这个基准对人类智能仍然可及，对当时的 AI 系统却很困难。

关键在于任务筛选标准是公开的。基准的介绍文档写明，2025年初在圣迭戈对四百多名参与者做过测试，而且所有任务都被至少两个人在两次以内解出。也就是说，留在这份题集里的任务，人这一侧的难度是事先验证过低的。如果这样一份题集在机器一侧依然像一堵墙，那么这堵墙就不是「难」的问题，而是「难度的轴不在同一条线上」的问题。

多加一句话就塌了

同样的性质在别处以简单得多的形式出现。2024年10月公开的 GSM-Symbolic 把小学水平的数学题集改成符号模板，批量生成同一道题的变体。摘要给出两点结果。一点是只改题目里的数值，所有模型的表现都会下滑；另一点是加进一句看起来相关、实际却不影响答案的从句，最多会掉65个百分点。

65这个数字指的是哪一处，需要读准。摘要的文面是在若干最新模型上观察到的下滑上限，并不是说每个模型都掉那么多。但方向是清楚的。在人会一眼扫过、判定「这句不用读」的地方，数值大幅晃动。

两份材料合起来说的是同一件事。人的难度曲线和机器的难度曲线不在同一条轴上。这是「陌生」不作为比喻、而作为数值出现的第一处。而在这一处，「陌生」不是解释，是测量结果的名字。这两者的区别，就是本文的要点。

可观测之处 ② 对表述的敏感度

第二处是把同一件事换个写法，答案会不会变。人也会被题目的表述影响。题干语序或选项顺序改变正确率，这类结果在教育测量那边由来已久。不同的是量级。

2023年10月发表的提示词格式敏感度研究，正面测了这个量级。造出若干语义相同的提示词格式再比较表现，在 LLaMA-2-13B 上，格式之间出现了最多76个准确率点的差距。作者还一并放出了快速扫描这种离散度的工具，名字是 FormatSpread。

76个点在人的考试里，会被读成这份卷子有问题。问的是同样的内容，只换答题纸的排版就把分数拉开这么多，我们怀疑的是卷子而不是考生。这里方向反了过来。对格式的敏感成了考生一侧的性质。

  • 「模型做不了这个」的观测，多半是「在这个格式下做不了」。用一种格式得到的失败不是能力的缺席，只是对一个条件的观测。
  • 评测比较要在格式固定之后才成立。把两个用不同格式测出的分数并排摆上的那一刻，比的就不是能力而是格式了。
  • 在运维里格式是合同的一部分。如果改提示词文案被当成「润色措辞」，数值变动的原因就不会留在记录里。

可观测之处 ③ 自我报告的可靠度

第三处是模型讲述自己为何那样回答时，这段讲述是否指向真正的原因。原文在思维链监控上花了不少篇幅，这一处恰好与原文的关切重合。

2023年5月公开、同年入选 NeurIPS 的一项研究把这个问题切窄了来测。方法很简单：调整选择题的选项顺序，让正确答案永远排在第一位，用这种方式在输入里埋入偏置特征。于是两件事同时发生。准确率在 BIG-Bench Hard 的13项任务上最多掉36个百分点，而模型给出的解释一次也没有提到这个偏置。所测的模型是 GPT-3.5 与 Claude 1.0。

这个结果的含义最好切准。它不是说模型撒谎的结果，而是说解释可能与真实原因的清单不一致的结果。类似现象在人身上早有报告。只是人这边的文献把它叫做事后重构自己行为的理由，并且会补充说，这种重构会以一段相当连贯的叙述出现。这里叙述的连贯性保住了，而一个决定性的输入整个掉了出去。

原文的主张与这份材料相遇的地方就在这里。原文写道，可以依赖思维链监控的程度正在逐步下降，理由包括交互边界变得模糊、模型处理自身推理过程的能力提升、不以语言呈现的推理在增加。公开研究说的是另一句话：在2023年那种简单得多的条件下，解释和真实原因就已经分开了。两句话的时点与范围都不同，也谈不上谁驳倒谁。区别在于后一句附着可复现的步骤，前一句没有。

关于内部的主张走到了哪一步

转到层 ⓑ。「模型里面的构造与人不同」这句话属于可解释性研究的地盘。把这个领域实际握住的东西弄清楚，原文那几条内部主张该放进哪一栏也就定了。

稀疏自编码器实际展示了什么

2023年9月公开的一项研究很能说明这个领域的样貌。用稀疏自编码器重构语言模型的内部激活，会得到比既有方法更可解释、更单义的特征集合。可解释性是用自动化的度量来打分的，这部分是真正落成数值的。而在间接宾语识别这个范围很窄的任务上，研究做到了指认出因果上负责的特征。

带了因果干预这一点很重要。「这个特征亮起来那个输出就出现」是相关观察，「关掉这个特征那个输出就消失」是干预，两者的证据分量不同。有了后者，特征才取得解释的资格。

那么，要处理「模型里面有 X」这句话，得先具备什么？三样。

  • X 的可操作定义 - 观察到什么才算 X 存在，这一点必须先于句子定下来。没有定义，也就没有反驳的办法。
  • 因果干预 - 把候选关掉或打开，输出是否按预期改变。只有相关是不能给它命名的。
  • 范围的明示 - 在哪个模型、哪一层、哪个任务上成立。把窄任务上成立的东西搬成整个模型的性质，那一刻它就退回成比喻。
目前握在手里的目前还握不住的
从内部激活中抽出可解释特征集合的流程整个模型计算过程的说明
用自动度量比出比既有方法更单义的结果能直接推广到任意任务的一般化
在窄任务上识别出因果上负责的特征「意图」「目标」这类上层概念所在的位置

所以原文那四条内部主张进的不是「错误」那一栏，而是「目前只能以这种形式处理」那一栏。说价值对齐是模型更内在的属性，在内在性用什么来测还没定下来之前，它是定义的提议而不是观测。这不是批评，而是把句子的种类写下来。一个症状后面挂着好几个原因时该怎么拆，做法与模型忽然开始回答不知道时把原因拆成四路是一样的。

当比喻顶替了解释

轮到层 ⓒ。比喻本身不是问题。「陌生的智能」是个好比喻。它把一组不像人的失败样态捆成一幅画，也起到了不要把人的直觉照搬过来的警示作用。到这里都是收益。

问题出在这个比喻坐上解释的位子的时候。当「因为它是陌生的智能」成了「这个模型为什么错在那么简单的题上」的答案，四件事会同时发生。

  • 把原因的位子填满 - 已经有了一个答案，下一个问题就不出现了。没人再问有没有换格式试过、上下文里进了什么、同样的输入有没有再跑一次。
  • 抹掉反驳的条件 - 没人写下什么样的观测会让「陌生」变成假。没有反驳条件的句子在任何结果下都活得下来，而活下来多少，它就少预测多少。
  • 转移责任 - 如果是一个弄不懂的东西干的，那设计与运维上的选择就退出了讨论。系统提示词、工具定义、检索结果的排序都是人定的，这一层却消失了。
  • 取消测量计划 - 被称作弄不懂的对象是不会有预算的。下个季度要测什么定不下来，于是下一次还是同一句话来作答。

这个结构并不新鲜。无论把组织比作编辑部，还是比作大教堂与集市，比喻能解决什么、又在哪一点变成魔法，位置总是同一个。比喻在指出该往哪儿看的时候是工具，在说别再往那儿看的时候是障碍。

同一个比喻的两种用法当作工具用用来顶替解释
「陌生的智能」不要照搬人的直觉的警示。促使人另外去测错误分布出错原因的答案。让人不再去测
「养出来的」对这不是一套手写规则系统这一事实的概括内部弄不懂的结论。可解释性研究退出讨论
「教它去爱」达成目标与价值判断是两件事，这一区分的开场被读成关于模型情感的主张，与原文的论证相左

反方向的化约 - 「不过是统计」

方向相反的那句话做的是同一件事。「说到底不过是在挑下一个词的概率。」作为对训练目标函数的描述，这句话是准确的。问题在下一步。一旦这句准确的描述被当成停止观测的理由，上一节那四件事会原样发生一遍。

把两种化约并排摆开就看得见对称。一边是「弄不懂所以别看了」，另一边是「全都懂了所以别看了」。结论相反，行为却相同。两边都取消了下一次观测。

轴「陌生的智能」一侧的化约「不过是统计」一侧的化约
主张与人根本不同，所以我们的概念用不上只是概率运算，所以不需要另外的解释
对的那一部分失败分布与人不同，这个观测确实存在作为对训练目标函数的描述是准确的
越界的地方没测不同的程度与范围就拿来当结论从目标函数一步跨到行为
相同的后果下一次要测什么定不下来下一次要测什么定不下来

前面提到的 GSM-Symbolic 结果是个不错的试验台。这个结果听起来对两边都方便。一边读成「人不晃机器晃」，另一边读成「所以那不是推理」。可是摘要真正写下的，是在某个特定变形下表现变化了这么多的数值。从这个数值走到「有推理还是没推理」的那条路，落在摘要文面之外，而过这条路时用的，又是比喻。

落到运维，什么才拿得到手

以上这些区分真正派上用场的地方只有一个：模型给出了奇怪的输出，有人问它为什么那样做的那一刻。这个问题无论答「因为是陌生的智能」还是答「因为是概率」，结果都一样。什么都修不了。

能查清的和查不清的

拿得到手的为什么拿得到拿不到的
用户输入全文留在记录里权重内部计算所走的路径
系统提示词及其修订历史是运维方定的值那个答案出现的唯一理由
工具定义与模式版本写在代码里模型意图了什么
采样设置与随机种子是调用参数换个条件会出什么
真正进入上下文的文档及其顺序由检索层构建其中哪些是模型实际用上的
模型标识与版本字符串在响应的元数据里提供方内部改动的时点
请求时刻与重试记录在日志里同一时刻服务端的状态
用同样的输入重跑得到的输出分布是自己就能造出的数值那个分布下周是否还一样

看右边那一栏就明白，原文层 ⓑ 的那些主张为什么在运维里不好直接拿来用。拿不到的东西大多是关于模型内侧的问题。所以在现场取得数值的办法不是往里看，而是把外部条件一项一项固定住再重跑。

六个用来判别的问题

要问的答案分叉意味着什么
同样的输入配同样的设置再跑一次，出的是同样的东西吗不是的话，采样或上下文组装是第一候选原因
只改格式，数值会变吗会变的话，这是表述敏感度的问题而不是能力问题
把上下文里的文档一份份抽掉，在哪一份上翻转翻转那一点上的文档就是直接原因
删掉模型给出的理由再问，答案还一样吗一样的话，那个理由是解释而不是原因
失败发生在人也觉得难的地方，还是人不会错的地方后者属于错误分布的问题，需要单独去测
模型的版本字符串和上次一样吗不一样的话，其余所有比较都失效

这六行是把「它为什么那样做」换成「改什么才会变」的装置。前一个问题出不来答案，后一个问题出得来。而要回答后一个，得有记录。下面是针对一次异常输出留下来就够用的最小项目。

model      : 模型标识与版本字符串
timestamp  : 请求时刻与时区
system     : 系统提示词全文，或其摘要值与长度
input      : 用户输入全文
tools      : 工具定义清单与模式版本
sampling   : temperature, top_p, seed, max_tokens
context    : 真正进入的文档标识及其顺序
output     : 响应全文
retries    : 重试次数与每次尝试的结果
  • 留摘要值也行 - 系统提示词全文不好保存的话，光凭摘要值和长度也能分出是同一份还是不同的一份。
  • 顺序就是数值 - 检索层塞进去的文档，顺序比清单更重要。同一组文档换个顺序就是不同的输入。
  • 没有随机种子就留分布 - 设置固定不了的话，就留下跑若干次的结果分布。一次输出只是一个样本。
  • 版本字符串每次都记 - 提供方那边的变更来得没有预告。版本一变，与此前记录的比较就不成立了。
  • 不要把重试删掉 - 只留成功的响应，失败的分布就没了，而原因待在失败那一侧的时候更多。

读者一侧的标准也在同一个位置。与其分辨一段文字是人写的还是机器写的，不如看它的内容能不能核对，这套从裁定转向核对的标准在这里同样适用。只是对象从文章换成了输出。

能考察的问题和不能考察的问题

「陌生的智能」这个表达几乎总会引向下一个问题：里面有什么？它会感觉吗？它想要吗？这些都是认真的问题，但以目前的形式，观测的步骤并没有被定义出来。写它有和写它没有，在缺少步骤的情况下是同一类陈述。

可以分开的是另一件事：从同一份关切里冒出来的问题当中，哪些挂得上可操作定义，哪些挂不上。

问题现在能处理吗要处理需要什么
自我报告与实际行为是否一致能处理埋入偏置，数一数解释有没有提到它
解释是否指向真实原因能处理删掉或替换所给的理由，看输出会不会变
在特定条件下回避行为是否增多能处理先定义条件与行为，再统计频次
内部是否存在对应人类概念的表征部分能逐个概念定义特征，并推进到因果干预
是否存在主观经验以目前的形式不能观测的步骤本身需要先被定义出来

把最后一行写成「不知道」和写成「没有」是两回事。而原文自己守住了这个区分。小节标题是「教机器去爱」这个比喻，正文却把它转成价值对齐这个术语。也就是说，原文用比喻开门，用可操作的术语往下论证。在转述过程中最常掉掉的，恰恰是第二步。门口的比喻留下、里面的术语没了，读的人就会把比喻当成主张接过去。

把层次写下来能留下什么

归拢一下。原文十七句里具备观测形式的有五句，其中能从外部直接确认的是一句。关于内部的主张有四句，而当下的可解释性研究走到了在窄任务上指认因果负责特征这一步。比喻四句，规范主张两句。

而「与人不同」能落成数值的地方，目前公开的有三处：只留下对人容易的任务之后仍然存在的那堵墙；只改表面就晃动的数值；解释漏掉决定性输入的现象。三处都附着样本与条件，都可以重做一遍。

  • 把层次写下来，下一步该问什么就定了。对观测层问条件，对内部层问定义，对比喻层问它遮住了什么。
  • 没有数值的句子不是假的，是还没有数值的句子。两栏混在一起，等日后数值公开时，读的人会找不到方向。
  • 两个方向的化约造成同一种损失。无论称它弄不懂还是称它全懂，下一次观测被取消这一点是一样的。

陌生这个词不必扔掉。当它是测量结果的名字时，它是准确的词。错误分布与人不同，一句表述就能让数值晃动，自我报告漏掉决定性输入。作为把这三样捆起来叫的名字，「陌生」选得很好。只是当这个词开始顶替测量，同一个词就朝反方向起作用了。区别只有一个：这个词后面有没有跟着一张表。

未能确认的部分

  • 网络安全能力主张的依据 - 关于在入侵与防御上超过人的这一表述，没有给出作为依据的评测。
