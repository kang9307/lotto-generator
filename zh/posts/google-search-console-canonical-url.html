1. 什么是规范 URL (Canonical URL)？

规范 URL (rel="canonical") 是一种 HTML 标签属性。当存在多个拥有相似或完全相同内容的 URL 时，它用于告诉搜索引擎：在这些页面中，应该以哪一个作为"原始"或"代表"页面来建立索引。简单地说，它是一种信号，相当于在告诉搜索引擎：“在这么多页面当中，这一个才是真正的原件！”

例如，下面这些 URL 可能全部指向同一个商品页面。

  • http://www.example.com/product/item
  • https://www.example.com/product/item
  • https://example.com/product/item
  • https://example.com/product/item?ref=banner
  • https://example.com/product/item?utm_source=google

在用户眼中它们都是同一个页面，但搜索引擎会把它们视为彼此独立的多个页面，从而分散 SEO 评分。此时如果设置了规范 URL，就能把分散的评分集中到一个代表性 URL 上，对提升搜索排名有很大帮助。

2. 正确设置规范 URL 的 5 种方法

设置规范 URL 的方法有很多种，需要根据具体场景选择最合适的方式。

方法 1：使用 `rel="canonical"` HTML 标签（最常见的方法）

这是最被广泛使用的方法，在 HTML 文档的 <head> 部分添加 <link> 标签来指定规范 URL。

<head>
    <link rel="canonical" href="https://example.com/代表页面-URL" />
</head>

自引用 (Self-referencing) 规范 URL：即使当前页面本身就是原始页面，也建议把它自己指定为规范 URL。这相当于明确告诉 Google：“没错，这个页面就是原件。”

方法 2：使用 HTTP 头

用于为 PDF、图片等非 HTML 内容指定规范 URL。在服务器配置中向 HTTP 响应头里添加 `Link` 信息。

Link: <https://example.com/downloads/white-paper.pdf>; rel="canonical"

方法 3：使用站点地图 (Sitemap)

被包含在站点地图中的 URL 有可能被 Google 视为规范 URL。不过与 `rel="canonical"` 标签相比，这只是一个较弱的信号，因此建议与其他方法配合使用。

方法 4：使用 301 重定向

当需要把重复页面永久迁移到另一个 URL 时使用。301 重定向是告知搜索引擎“旧页面已不存在，新的规范页面在这里”的最强信号。在页面搬迁、域名变更 (http -> https) 等场景下是必备手段。

方法 5：Google Search Console 的 "URL 参数" 工具

这是一项用于指定 Google 如何处理会话 ID、排序、筛选等特定 URL 参数的功能。但该设置会影响整个网站，非专业人员使用时必须格外谨慎。

3. 常见错误与解决方案 (Do's & Don'ts)

规范 URL 设置看似简单，但一旦配置错误反而会对 SEO 产生负面影响。请参考下表，避免常见的错误。

项目 Do (正确做法) ✅ Don't (错误做法) ❌
路径 使用绝对路径
https://...		 使用相对路径
/page.html
位置 仅放置在 <head> 部分 放置在 <body> 部分
数量 每个页面只声明一个规范 URL 声明多个规范 URL
分页 各分页指定自身为规范页，或使用 `rel="prev/next"` 把所有分页 (2、3、4...) 都规范化到第一页
协议 HTTPS 页面把规范 URL 指定为 HTTPS HTTPS 页面把规范 URL 指定为 HTTP

结论

在纷繁复杂的 Web 环境中，规范 URL 设置是一项必不可少的 SEO 工作，它能帮助搜索引擎清晰理解并正确评价你站点的内容。请运用本文介绍的各种方法，解决站内的重复内容问题，把分散的 SEO 评分集中起来，从而提升搜索排名。建议你养成定期查看 Google Search Console "索引 > 页面" 报告的习惯，持续监控规范 URL 相关的问题。
