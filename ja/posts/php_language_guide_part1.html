PHPの紹介

PHPは「PHP: Hypertext Preprocessor」の略で、Webサーバー上で実行されるスクリプト言語です。主にHTML内に埋め込まれ、動的なWebページを生成するために使用されます。

PHPの主な特徴

  • サーバーサイドスクリプティング: コードはサーバー側で実行され、結果のみがクライアントに送信されます。
  • クロスプラットフォーム: Windows、Linux、macOS など様々なOSで実行可能です。
  • データベース統合: MySQL、PostgreSQL、SQLite など多様なデータベースと簡単に連携できます。
  • オープンソース: 無料で使用でき、大規模な開発者コミュニティが存在します。
  • 豊富な機能: ファイルアップロード、メール送信、PDF生成など様々な機能を提供します。

PHPが使用される分野

  • Webアプリケーション開発
  • コンテンツ管理システム（WordPress、Joomla、Drupal）
  • eコマースプラットフォーム（Magento、WooCommerce）
  • フォーラムおよびソーシャルネットワーキングサイト
  • REST APIおよびWebサービス

PHP と他のバックエンド言語の比較

言語 長所 短所
PHP 学習曲線が緩やか、豊富なドキュメント、多くのホスティング対応 一貫性の不足、型安全性の問題（PHP 7以前）
Node.js 非同期処理、JavaScriptエコシステム コールバック地獄、比較的新しい技術
Python 可読性、豊富なライブラリ 速度の問題、マルチスレッドの制限
Ruby エレガントな構文、高い生産性 実行速度が遅い、ホスティング上の制約

PHPのインストールと環境設定

Windows への PHP インストール

  1. PHPのダウンロード

    • PHP公式サイトから最新バージョンをダウンロード
    • Thread Safe バージョン推奨

  2. インストールと設定

    C:\> mkdir C:\PHP
C:\> ダウンロードしたZIPファイルをC:\PHPに解凍
C:\> cd C:\PHP
C:\PHP> copy php.ini-development php.ini

  3. 環境変数の設定

    • システムのプロパティ → 詳細設定 → 環境変数 → Path に C:\PHP を追加

  4. Webサーバー連携

    • Apache、IIS、または内蔵Webサーバーを利用可能

Linux（Ubuntu）への PHP インストール

sudo apt update
sudo apt install php php-cli php-fpm php-mysql php-json php-common

macOS への PHP インストール

brew install php

開発環境の設定

  1. 統合開発環境（IDE）のインストール

    • PHPStorm: 強力な商用IDE
    • Visual Studio Code + PHP 拡張: 無料の代替
    • Sublime Text: 軽量で高速なエディタ

  2. ローカルWebサーバーのインストール

    • XAMPP: Windows、Linux、macOS のすべてに対応
    • WAMP: Windows 専用
    • MAMP: macOS 専用

  3. Composer のインストール（PHPパッケージマネージャ）

    curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer

PHP設定ファイル（php.ini）の主な設定

; メモリ上限
memory_limit = 128M

; 最大実行時間（秒）
max_execution_time = 30

; ファイルアップロード設定
upload_max_filesize = 2M
post_max_size = 8M

; エラー表示設定（開発環境）
display_errors = On
error_reporting = E_ALL

; エラー表示設定（本番環境）
; display_errors = Off
; error_reporting = E_ALL & ~E_DEPRECATED & ~E_STRICT
