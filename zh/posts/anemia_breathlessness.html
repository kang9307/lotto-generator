什么是贫血？

贫血（Anemia）是指血液中红细胞数量或血红蛋白（Hemoglobin）浓度低于正常值的状态。血红蛋白承担着将氧气输送到全身的重要作用，因此一旦出现贫血，组织就无法获得足够的氧气，从而引发多种症状。

正常血红蛋白水平

按年龄和性别划分的正常值

成年男性：血红蛋白低于 13.0 g/dL 即为贫血
非孕成年女性：低于 12.0 g/dL
孕妇：孕早期、孕晚期低于 11.0 g/dL，孕中期低于 10.5 g/dL
※ 儿童和青少年另有按年龄划分的标准（WHO 2024）

贫血严重程度分级

  • 轻度贫血：男性 11.0-12.9 g/dL，非孕妇女 11.0-11.9 g/dL
  • 中度贫血：8.0-10.9 g/dL（男性和非孕妇女）
  • 重度贫血：低于 8.0 g/dL（男性和非孕妇女）
  • 孕妇：轻度 10.0-10.9，中度 7.0-9.9，重度低于 7.0 g/dL

以上数值来自 WHO 2024 年指南（2026-09-29 核对）。各检验室的参考范围和设备不同，最终判定由医务人员做出。儿童另有按年龄划分的标准，本文不涉及。

贫血与气短的关联

为什么贫血会导致呼吸急促？

携氧能力下降

  1. 血红蛋白减少：直接降低氧气输送能力
  2. 组织缺氧：细胞代谢所需氧气供应不足
  3. 代偿机制启动：心脏和肺部被迫加倍工作
  4. 呼吸频率上升：身体通过加快呼吸来弥补缺氧

代偿机制的过程

出现贫血 → 感知组织缺氧 → 心率加快 → 呼吸频率上升 → 出现气短感

气短的特征

贫血引起的气短表现

  • 运动时加重：爬楼梯、快走时症状明显
  • 逐渐加重：呈缓慢进行性恶化
  • 静息时也会出现：重度贫血者即使静坐也感觉气促
  • 伴随症状：常伴有疲劳、头晕、心悸

贫血的主要原因

1. 缺铁性贫血（最常见）

病因

  • 出血：月经过多、胃肠道出血、痔疮等
  • 铁摄入不足：偏食、节食、素食
  • 铁吸收障碍：胃切除术后、消化系统疾病
  • 铁需求增加：怀孕、哺乳、生长发育期

典型症状

  • 异食癖（Pica）：想吃冰块、淀粉等非食物物品
  • 眼睑结膜苍白：下眼睑内侧发白
  • 指甲变化：出现勺状甲（Spoon nail）
  • 不宁腿综合征：双腿发胀、难以安静

2. 维生素 B12 缺乏性贫血

病因

  • 内因子缺乏：萎缩性胃炎、胃切除术后
  • 摄入不足：严格素食者
  • 吸收障碍：克罗恩病、回肠疾病
  • 药物影响：长期服用二甲双胍、质子泵抑制剂

典型症状

  • 巨幼细胞性贫血：红细胞体积大且未成熟
  • 神经症状：手脚麻木、步态异常
  • 舌面变化：舌面光滑发红
  • 认知障碍：记忆力下降、注意力不集中

3. 叶酸缺乏性贫血

病因

  • 摄入不足：蔬菜、水果摄入过少
  • 吸收障碍：乳糜泻、酒精中毒
  • 需求增加：怀孕、哺乳、血液系统疾病
  • 药物影响：甲氨蝶呤、抗癫痫药

4. 慢性疾病性贫血

相关疾病

  • 慢性炎症：类风湿关节炎、炎症性肠病
  • 慢性感染：结核、骨髓炎
  • 恶性肿瘤：各类癌症
  • 肾功能不全：促红细胞生成素不足

贫血的症状与分期进展

早期症状（轻度贫血）

仅在轻微活动时出现的症状

  • 运动时气短：快走或爬楼梯时明显
  • 容易疲劳：比平时更快感到疲倦
  • 注意力下降：工作或学习效率降低
  • 面色苍白：脸、指甲、结膜发白

中度症状

影响日常生活的症状

  • 静息时也气短：不活动也感到憋闷
  • 心悸：心率加快引发的不适
  • 头晕：体位性低血压、眩晕
  • 头痛：大脑供氧不足所致

重度症状（紧急情况）

需要立即就医的症状

  • 静息时呼吸困难：躺下也喘不过气
  • 胸痛：心脏负担过重引起
  • 晕厥：大脑严重缺氧
  • 心衰症状：下肢水肿、夜间呼吸困难

如出现胸痛、晕厥或静息时也气短，请立即拨打当地急救电话或前往急诊。本文不能替代诊断，是否属于急症由医务人员判断。

贫血的诊断方法

1. 基础血液检查

全血细胞计数（CBC）

  • 血红蛋白（Hb）：判断贫血严重程度
  • 红细胞压积（Hct）：红细胞在血液中所占比例
  • 平均红细胞体积（MCV）：红细胞大小
  • 红细胞分布宽度（RDW）：红细胞大小的均一性

按 MCV 分类

小细胞性贫血（MCV < 80）：缺铁性、地中海贫血
正细胞性贫血（MCV 80-100）：慢性疾病性、急性失血性
大细胞性贫血（MCV > 100）：B12、叶酸缺乏性
※ 分界值因检验室标准略有差异

2. 查明病因的进一步检查

铁代谢相关检查

  • 血清铁（Serum Iron）：血液中的铁浓度
  • 总铁结合力（TIBC）：转铁蛋白与铁的结合能力
  • 转铁蛋白饱和度：评估铁储存状态
  • 铁蛋白（Ferritin）：反映储存铁量的指标（常用于鉴别原因，如何解读由医务人员判断）

维生素检查

  • 维生素 B12：血液中 B12 浓度
  • 叶酸：血液中叶酸浓度
  • 同型半胱氨酸：B12、叶酸缺乏时升高
  • 甲基丙二酸：B12 缺乏的特异性指标

3. 出血原因排查

胃肠道检查

  • 粪便潜血检查：胃肠道出血筛查
  • 胃镜：检查上消化道出血
  • 结肠镜：检查下消化道出血
  • 胶囊内镜：诊断小肠出血

妇科检查（女性）

  • 月经量评估：确认是否月经过多
  • 子宫超声：排查子宫肌瘤、子宫腺肌病等
  • 子宫内膜检查：必要时进行活检

贫血的治疗方法

本节仅介绍治疗方式，药物种类、剂量和疗程由医务人员根据诊断结果确定。不建议自行开始服用铁剂或注射药物，也不建议自行调整剂量。

1. 缺铁性贫血的治疗

口服补铁

铁剂的种类、剂量、次数和疗程，由医务人员根据检查结果确定。
韩国疾病管理厅：缺铁性贫血至少需要服用铁剂 6 个月。
※ 疗程因人而异，请勿自行开始、停用或加量。

口服铁剂注意事项

  • 副作用：便秘、腹泻、腹部不适、黑便
  • 妨碍吸收的因素：茶、咖啡、钙、抗酸药
  • 促进吸收的因素：维生素 C、肉类、鱼类

静脉补铁治疗

可能考虑静脉补铁的情形（是否使用由医务人员判断）：
- 无法耐受口服铁剂
- 吸收障碍
- 持续出血
- 需要快速补充

2. 维生素 B12 缺乏的治疗

治疗方案

治疗方式（注射或大剂量口服）、剂量和疗程，取决于病因和检查结果，由医务人员确定。
如内因子缺乏等病因持续存在，可能需要长期治疗（NIH ODS）。

治疗反应评估

  • 早期：网织红细胞倾向于先升高
  • 随后：血红蛋白逐渐上升
  • 恢复：血红蛋白回到正常范围（所需时间因人而异）
  • 神经症状：改善可能较慢或有残留，需要随访观察

3. 叶酸缺乏的治疗

标准治疗

剂量和疗程：由医务人员根据病因和检查结果确定。
备孕或怀孕期间补充叶酸，请与妇产科医生商量。
注意：先确认是否同时存在 B12 缺乏，治疗顺序由医务人员决定。

4. 重度贫血的急诊处理

输血指征

  • 是否输血：不只看血红蛋白数值，而是结合症状和全身状况由医务人员判断
  • 心血管症状：胸痛、呼吸困难、晕厥
  • 血流动力学不稳定：心动过速、低血压
  • 计划手术：术前检查血红蛋白状态，由医疗团队制定应对方案

输血注意事项

  • 缓慢输血：预防心衰
  • 联合利尿剂：避免容量负荷过重
  • 铁负荷过多：反复输血者需考虑去铁治疗

改善生活方式与预防

1. 富含铁的饮食

血红素铁（吸收率高）

  • 红肉：牛肉、羊肉
  • 内脏类：肝、肾
  • 海产：牡蛎、贻贝、沙丁鱼
  • 禽肉：鸡肉、鸭肉

非血红素铁（植物性铁）

  • 叶菜：菠菜、羽衣甘蓝、小白菜
  • 豆类：扁豆、黑豆、豆腐
  • 坚果：芝麻、杏仁、腰果
  • 谷物：藜麦、燕麦、糙米

2. 铁吸收优化

促进吸收的方法

搭配示例：
- 牛肉 + 西兰花（维生素 C）
- 菠菜 + 橙汁
- 扁豆 + 番茄酱
- 豆腐 + 彩椒炒

需要避免的搭配

  • 含铁食物 + 茶/咖啡：间隔一段时间
  • 铁剂 + 钙：错开服用时间
  • 补铁食物 + 牛奶：避免同时摄入

3. 维生素 B12 的来源

动物性食品（主要来源）

  • 鱼类：三文鱼、金枪鱼、沙丁鱼
  • 肉类：牛肉、鸡肉
  • 乳制品：牛奶、奶酪、酸奶
  • 鸡蛋：尤其是蛋黄

素食者的替代方案

  • 强化食品：B12 强化豆奶、谷物
  • 营养酵母：维生素 B12 强化产品
  • 补充剂：定期服用 B12 补充剂

4. 叶酸的来源

天然食品

  • 绿叶蔬菜：菠菜、罗马生菜、芦笋
  • 豆类：扁豆、豌豆、鹰嘴豆
  • 水果：橙子、草莓、哈密瓜
  • 谷物：强化谷物、全谷物

烹饪注意事项

  • 怕热：快速焯水或生食
  • 易溶于水：连汤一起食用
  • 储存：趁新鲜尽早食用

特殊情况下的贫血管理

1. 孕期贫血

生理性变化

  • 血容量增加：孕期增多
  • 相对性贫血：血浆容量增加更多
  • 铁需求增加：美国 NIH 给出的孕期铁 RDA 为 27mg/日（韩国标准另有规定，请咨询医务人员或营养师）

孕期贫血管理

铁和叶酸补充：开始时间和剂量由妇产科医务人员确定。
监测：每次产检时检查血红蛋白
贫血判定：孕早期、孕晚期低于 11.0 g/dL，孕中期低于 10.5 g/dL（WHO 2024）

2. 月经过多引起的贫血

月经过多的判断标准

  • 经量：多到影响日常生活
  • 经期：比平时更长
  • 周期：比平时缩短
  • 影响日常生活：卫生巾更换次数增多

管理方案

  • 妇科就诊：治疗根本病因
  • 补铁：持续性补铁
  • 激素治疗：调节月经量
  • 手术治疗：严重时考虑

3. 老年人贫血

病因特点

  • 慢性疾病：肾病、肿瘤、慢性炎症
  • 药物副作用：阿司匹林、抗凝剂
  • 营养不足：食欲减退、吸收障碍
  • 隐匿性出血：胃肠道肿瘤、痔疮

管理注意事项

  • 查明病因：需要全面检查
  • 药物相互作用：评估与现用药的影响
  • 心血管风险：避免过快纠正
  • 功能评估：考虑日常生活能力

贫血的预防与早期发现

1. 定期健康检查

检查频率

检查间隔因年龄、性别、基础疾病和所用药物而异，由医务人员确定。
孕妇：每次产检检查血红蛋白
慢性病患者和高危人群：按主管医务人员确定的间隔随访

高危人群

  • 女性：月经过多、怀孕、哺乳
  • 素食者：尤其是严格素食者
  • 慢性病患者：肾脏、心脏、消化系统疾病
  • 药物使用者：阿司匹林、抗凝剂

2. 早期症状识别

应立即就医的症状

  • 静息时呼吸困难：不活动也气促
  • 胸痛：胸闷或胸部疼痛
  • 晕厥：意识丧失
  • 重度疲劳：影响日常生活

建议就诊的症状

  • 持续疲劳：持续 2 周以上
  • 运动时气短：比平时更容易气促
  • 面色苍白：脸、指甲、结膜苍白
  • 异常食欲：想吃冰块、淀粉等

贫血与合并症管理

1. 心血管疾病与贫血

相互影响

  • 贫血 → 加重心脏负担：可能恶化心衰
  • 心脏病 → 加重贫血：肾功能下降引起的贫血
  • 药物相互作用：抗凝剂与铁剂

管理原则

  • 渐进式纠正：避免血红蛋白急剧上升
  • 目标血红蛋白：由医务人员按疾病和状态确定（并非越高越好）
  • 液体管理：心力衰竭患者的饮水指导由其主管医务人员确定
  • 定期监测：同时跟踪心功能与贫血

2. 肾病与贫血

发生机制

  • 促红细胞生成素不足：肾脏分泌减少
  • 铁利用障碍：炎症降低铁利用率
  • 毒素蓄积：尿毒症缩短红细胞寿命

治疗方法

  • ESA 治疗：促红细胞生成刺激因子
  • 补铁：主要采用静脉补铁
  • 目标血红蛋白：由医务人员因人而异地确定
  • 副作用监测：血压升高、血栓风险

常见问题（FAQ）

Q1：患有贫血可以运动吗？

A：能否运动取决于贫血的程度和原因，需要医务人员判断。

  • 活动强度：症状较轻时，可就散步、拉伸等低强度活动向医务人员咨询
  • 应避免的活动：会加重头晕、气短的剧烈运动
  • 注意事项：出现头晕或气短加重应立即停止
  • 医生咨询：运动前请与医生沟通

Q2：服用铁剂后便秘加重怎么办？

A：这是常见副作用，但有应对方法。

  • 剂量调整：不要自行更改，请与医务人员商量
  • 更换剂型：是否改用其他剂型，请咨询医务人员
  • 服用方式：是否调整服药间隔，请咨询医务人员
  • 饮食调节：摄入充足水分和纤维
  • 替代方案：是否需要静脉补铁等其他治疗，由医务人员判断

Q3：每次生理期贫血都会加重，该怎么办？

A：重要的是治疗根本原因并进行预防性管理。

  • 妇科检查：确认子宫肌瘤、腺肌症等
  • 月经量调节：激素治疗、曼月乐等
  • 持续补铁：维持铁储备
  • 生活习惯：保持富铁饮食

Q4：素食者也能预防贫血吗？

A：完全可以，但需要更加细致的管理。

  • 多样化铁源：豆类、坚果、叶菜
  • 促进吸收：与富含维生素 C 的食物一起食用
  • 补充 B12：是否需要及如何补充，应在检查后与医务人员商量
  • 定期检查：更频繁地进行血液化验

结语

贫血及由此引发的气短不仅是普通症状，更是身体发出的重要信号。如果出现持续性疲劳或运动时特别气促的情况，请不要只当作体力不足，而应接受专科医生的准确诊断。

贫血因病因不同治疗方法也完全不同，因此准确的诊断至关重要。需要区分是缺铁性贫血、维生素缺乏，还是由其他疾病引起，才能获得适当的治疗。

通过早期发现与合理治疗，贫血是完全可以改善的疾病。平时请保持富含铁的均衡饮食，并通过定期体检来预防和尽早发现贫血。

再次提示：本文仅用于提供一般信息，不能替代诊断或治疗。检查结果的解读，以及药物或补充剂的种类、剂量和疗程，均由医务人员判断。

# 贫血与气短 - 就诊前检查清单

基准日：2026-09-29。本表为一般信息，不能替代诊断或治疗。解读和治疗由医务人员判断。

---

## 1. 需要立即就医的信号

| 信号 | 应对 |
|---|---|
| 静息时也气短 | 立即拨打当地急救电话或前往急诊 |
| 胸痛或胸闷 | 立即拨打当地急救电话或前往急诊 |
| 晕厥 | 立即拨打当地急救电话或前往急诊 |
| 疲劳严重到难以正常生活 | 尽快就诊 |

## 2. 建议咨询医生的症状

- [ ] 疲劳持续 2 周以上
- [ ] 爬楼梯或快走时比平时更容易气短
- [ ] 面色、指甲或下眼睑内侧苍白
- [ ] 特别想吃冰块或淀粉之类的东西

## 3. WHO 2024 血红蛋白判定标准（g/dL）

| 人群 | 判定为贫血 | 轻度 | 中度 | 重度 |
|---|---|---|---|---|
| 成年男性 | 低于 13.0 | 11.0-12.9 | 8.0-10.9 | 低于 8.0 |
| 非孕成年女性 | 低于 12.0 | 11.0-11.9 | 8.0-10.9 | 低于 8.0 |
| 孕妇 | 孕早期、孕晚期低于 11.0 / 孕中期低于 10.5 | 10.0-10.9 | 7.0-9.9 | 低于 7.0 |

各检验室的参考范围和设备不同，最终判定由医务人员做出。

## 4. 就诊时可以问的问题

- [ ] 是否为贫血，程度如何（血红蛋白数值）
- [ ] 根据红细胞大小（MCV），怀疑是哪一类
- [ ] 是否需要做铁（铁蛋白等）、维生素 B12、叶酸检查
- [ ] 是否需要排查出血原因（经量过多、消化道等）
- [ ] 铁剂或注射药物的种类、剂量和疗程如何确定（不要自行决定）
- [ ] 下次检查是什么时候

## 5. 如果正在服用铁剂

| 检查项 | 内容 |
|---|---|
| 常见副作用 | 便秘、腹泻、腹部不适、黑便。严重时请咨询医务人员，不要自行调整 |
| 妨碍吸收的因素 | 茶、咖啡、钙、抗酸药。请间隔一段时间 |
| 促进吸收的因素 | 与富含维生素 C 的食物同食 |
| 服用时长 | 韩国疾病管理厅提示缺铁性贫血至少 6 个月。个人疗程由医务人员确定 |

## 6. 本清单的局限

- 韩国学会诊疗指南的现行推荐未能确认。
- 基因治疗和 HIF-PHI 类药物在韩国的批准和报销情况未能确认更新。
