人类史上1000亿人这个数字是怎么来的 - 推算的输入与假设

起点、人口基准和出生率这三项输入，其中哪一个真正在左右总数

2026-09-05 潮流/文化

人类史上活过1000亿人这句话到处都是。纪录片的旁白里有，天文讲座的开场里有，最近连一个号称从这1000亿人中随机抽一位展示给你的网站，说明文字里也有。句子很短，数字很圆。圆的数字容易被搬运，容易被搬运的数字就会脱离出处四处游走。

可这个值并不是数出来的。有出生登记的时期只占人类史极末端的一小截，其余全是靠计算填补的区间。1000亿不是观测结果，而是模型的产物，模型里装的是人挑选的输入。把那些输入是什么、从哪里来、能摇摆多大逐一追下去，这个数字究竟在说什么就显露出来了。

以下数值均照公开一手资料所载原样引用，并注明是哪个机构在哪一年给出的。资料中没有的值不以推测填补，而是集中放在文末。通过计算得到的派生值，均说明该计算是从哪一个公布数字出发的。

圆数字与真实值之间

引用这一系列数字时最常被参照的一手来源，是美国人口研究机构 Population Reference Bureau 的一篇短解说。标题是「How Many People Have Ever Lived on Earth?」，最新修订版日期为2022年11月15日，作者是 Toshiko Kaneda 和 Carl Haub。

该修订版给出的值是117,020,448,575人，约1170亿，而不是1000亿。取整过程中消失的170亿本身也不是小数目。同一张表里1750年以后出生的人合计约195亿，也就是说为了把数字修得整齐而丢掉的那一块，已经逼近工业化以来全体人类的出生总量。

当然这里不是要计较位数，要点在别处。1000亿这个值既没有发布主体也没有发布时点。没有这些就无从追问它建立在什么假设之上，也就无法与别的数值作比较。失去条件的数字会变成什么样，在一句话要成为命题需要什么里另作过讨论。这里要做的是把条件一项项还原回来。

这个数字不是清点，而是模型

全量登记出生的制度各国不同，但再早也是近代的产物。在此之前的区间根本没有可供清点的原簿。所以求总出生数这件事不是把资料相加，而是用结构去替代不存在的资料。

PRB 使用的结构很简单。把人类史切成若干区间，在每段首尾各钉一个人口基准，再为这段挑一个出生率。于是每段都能算出出生数，全部相加就是总数。

区间出生数 = 该区间的人年 x 出生率 / 1,000

  人年     = 区间长度(年) x 该区间的平均人口
  总出生数 = 所有区间出生数之和

  例) 8000 B.C.E. ~ 1 C.E. 区间
      区间长度      8,000年
      出生率        每千人80
      公布出生数    46,025,332,354
      -> 该值所蕴含的平均人口
         46,025,332,354 / 0.08 / 8,000 = 约7,190万人

在这套结构里，属于观测的只有基准人口，而且近代以前的基准人口本身也是历史人口学的估算值。出生率从头到尾都是假设。PRB 自己并不遮掩这一点。解说文里明明白白写着这项工作半是科学半是技艺，并把结果称为一种半科学方法给出的约1170亿。

模型需要的三项输入

结构简单，输入也就三项。任改一项，总数就会移动。

  • 起点 — 从什么时候起算作人。PRB 2022年版在190,000 B.C.E. 放上2人开始计算。同一机构早先的版本以50,000 B.C. 为出发点
  • 各时期的人口规模 — 50,000 B.C.E. 为200万，8000 B.C.E. 为500万，公元1年为3亿。1950年以后的数值来自联合国经济和社会事务部的统计以及 PRB 自己的世界人口数据表
  • 各时期的出生率 — 解说文写明假定公元1年之前为每千人每年80，其后至1750年为60。表中的出生率一列则是1750年50，1850年和1900年40，1950年在31到38之间，2000年22，2022年17

三项输入性质各异，这一点很关键。第三项根本没有与之对应的观测。没有任何资料直接测量过近代以前的出生率，那个80和60是从人口增长极其缓慢这一事实、以及预期寿命极短这一事实反推着凑出来的值。解说文写道，人类史的大部分时间里出生时预期寿命平均大约只有十岁。

人的边界是定义问题

第一项输入与另外两项性质不同。它不是资料问题，而是定义问题。解剖学意义上的现代人何时出现，是化石与基因两方面都在持续更新讨论的题目，并不存在一个已经敲定的年份。

同一机构换版本时把出发点从50,000 B.C. 挪到190,000 B.C.E.，这件事本身就是证据。一次修订就挪动了14万年。所以这个值与其读作学界的定论，不如读作该修订版采用的一条便宜行事的边界线更准确。所幸如后文所示，这个选择撼动不了总数多少。

同一机构的值在每次修订间也会变

在世比例上也一样。6.8、6.5、6、4这几个百分点并排摆着。这个比例的分子和分母都在动：作为分母的总出生数会被修订，作为分子的当前人口也随取哪一年而不同。所以引用比例时必须一并说明分子用的是哪一年的人口。没有这一项的比例看起来在小数点后互相打架，实际上往往说的是不同年份。

关于起点的争论几乎撼动不了总数

这张表给出的第一个结论与直觉相反。人类起源定在何时是这个题目里被争论最多的项目，然而它对总数的影响在三项输入中最小。

从190,000 B.C.E. 到50,000 B.C.E. 是14万年，占全部时长的四分之三。可这段产生的出生是78亿5610万人，占总数的6.7个百分点。把出发点退回早先版本的50,000 B.C.E.，总数约1091亿；挪到农耕开始前后的8000 B.C.E.，也还有约1080亿。起点线提前或推后18万2千年，变动仍在10个百分点以内。

原因在乘法的结构里。出生数是时长与人口的乘积，而那些区间的人口只有几百到几十万。无论乘上多长的时间，小数乘大数的结果赢不过大数乘小数的结果。决定总数的不是人类存在了多久，而是人口变多之后又维持了多久。

撼动总数的是农耕时期的出生率

归纳起来是这样。争议最大的输入动得最少，最悄无声息滑过去的输入动得最多。把起点挪动14万年只值6.7个百分点，而把无人争论的农耕时期出生率从80设为40，就抽掉19.7个百分点。仅在本文动过手的范围内，总数就在940亿到1330亿之间来回。

1170亿数的是出生，不是一生

这里需要回到定义。模型所数的单位是一次出生。出生之后活了多久不进入这个单位。表的列名本身就是 births 和 number ever born。

然而 PRB 的解说文写道，人类史的大部分时间里出生时预期寿命平均大约只有十岁。预期寿命十岁并不是说人们大体活到十岁就死了。它的意思是相当多的人出生后不久就死去，一部分人活得很长，平均落在那里。这是婴儿死亡占主导的人口才会给出的数值。

而那些孩子每一个都完整地计入了这个总数。也就是说1170亿这个值必须这样读。

  • 所数的对象 — 作为人被生下来这一事件的总次数。活了一天的孩子和活了八十年的老人各算1
  • 包含在内的 — 还没来得及有名字就死去的新生儿，以及所有没有留下记录的出生
  • 不包含在内的 — 死产和流产按通行定义不计为出生，模型的出生率也遵循这一定义
  • 由此而来的含义 — 若从这1170亿里随机抽一人，被抽中概率最高的是没能长到成年就死去的孩子

最后一条是算术而不是感慨。既然总数的73个百分点出自8000 B.C.E. 到1650年之间，而那一时期的预期寿命在十岁上下，结论就跟着出来了。把这个数字读作人类之伟大的习惯，与这个数字实际在数的东西之间，是有距离的。婴儿死亡率的具体假定值在2022年修订版正文中没有以数值形式写出，故另记于文末。

这张表自己就能验算

PRB 这张表的另一个好处，是把输入与结果一并载出，使读者能在表内部完成验算。把各区间的出生数按其出生率和长度倒推回去，就得到该区间所预设的平均人口。前一张表的最后一列就是这个值。

十二个区间中有十个，这个值都老实落在基准人口之间。1200年到1650年区间约为4.734亿，位于两端的4.5亿与5亿之间；1850年到1900年区间约为14.50亿，位于12.65亿与16.56亿之间。结构是一致的。

落在范围之外的两个区间，性质完全不同。一个是2010年到2022年区间，蕴含平均人口约82.86亿，比上限79.635亿高出约4个百分点。这是说得通的那类偏差。这个区间内出生率一路从20降到17，而计算只用了终值17这一个数，低的除数把人口吹大了。4个百分点的偏差出自方法本身的性质。

另一个则是另一种量级。50,000 B.C.E. 到8000 B.C.E. 区间的蕴含平均人口约为34万。这个区间的基准人口两端是200万和500万。蕴含值连下限的六分之一都不到。更何况紧邻的前一个区间190,000 B.C.E. 到50,000 B.C.E. 的蕴含平均人口约为70万，两端基准都更低，蕴含人口却是两倍。等于说在人口增长的区间里，蕴含平均人口反而减少了。

把这个区间重新放回基准人口的范围之内，总数会上升4.8到13.4个百分点。这里没有依据判定哪一边正确，公开资料中也没有写明缘由。但这一处显示出正因为表公开了输入，表自身才变得可以验算。在只载有总数的表里，4个百分点的偏差和六倍的偏差同样都看不见。已发布的数值在重新计算时会怎样改变，在复现案例中另作记述。

一半还活着的说法为何站不住

这个题目上总跟着一个误解：现在活着的人占人类史上活过的人的一半，或者活着的人比死去的人多。Scientific American 在2007年3月1日的文章中把这个说法列为事实判定对象，结论是虚构，并写明当时总出生数为1060亿出头，在世者比例约6个百分点。同一篇文章还介绍了出生过的人有75个百分点如今在世这一变体，并叙述其根源可追溯到1970年代。

流传中的说法已发布的实际值这句话要成立需要什么
现在活着的人占人类史上活过的人的一半2022年时点为6.8个百分点总出生数得约为160亿。而单是1750年以后的出生就已约195亿
活着的人比死去的人多死者与生者约为13.7比1当前人口得超过1000亿
出生过的人有75个百分点如今在世6.8个百分点总出生数得约为107亿
人类史上活过1000亿人按 PRB 2022年为1170亿取整时漏掉的170亿逼近1750年以后的出生总量

值得注意的是，换了发布主体结论也不变。6.8个百分点、6.5个百分点、6个百分点、4个百分点。时点、机构、假设都不同，却全都停在个位数的前段。这么多条路径汇到同一处，就可以认为结论并不依赖于某一个特定假设。这正是把不同推算并排摆开的实质好处。

造成这种错觉的算术结构

为什么一半这种感觉听起来像那么回事。错觉由两种混淆造成。

第一种是把人口与出生混为一谈。人们会想，过去人口少，所以过去出生的人也少。可人口是某一时点的存量，出生是在一段时间里累积的流量。哪怕人口完全不增长，出生也在不断累积。若500万人口在42,000年里一个人都没增加，却始终保持每千人80的出生率，那期间出生的人就有168亿。而人口的头和尾一模一样。

第二种是时长上的扭曲。最近一百年的人口增长在图上过于醒目，右端那道垂直的上扬看起来就像是全部。可按累积和来看，1900年以后的出生约为125亿，占总数的10.7个百分点；只算1950年以后则约为91亿，占7.8个百分点。在图上占据的视觉面积与在累积和中占据的份额，是完全不同的量。眼睛看到的陡坡显示的是人口的变化率，它替代不了铺在下面那片又宽又低的面积。

把分母搞错的三种方式

这类误解基本都发生在分母一侧。作为分子的当前人口人人都知道，出错的是分母。

  • 把人口当作分母 — 拿过去某个时点的人口跟现在的人口比，再用它替代累积出生。被比较的两者根本就不是同一种量
  • 缩短分母的时段 — 只把记得住或学过的历史，大体是数千年这个尺度，放进分母。由于总数的7.7个百分点出自8000 B.C.E. 之前，这种截断本身并不造成很大误差，问题在于连截断的存在都没被意识到
  • 从分母里减掉夭折的孩子 — 数人的时候会无意识地想到成年人。可这个总数数的是出生。按哪一种来数，分母的大小相差很大

6.8个百分点该怎么读

有意思的是，PRB 的解说文并没有把6.8个百分点当作一个小数值来介绍。分母摆的是接近20万年的时段，而此时此刻在世的人却占到其中将近7个百分点，按解说文自己的表述，这反倒是相当大的一个比例。

这两种读法并不矛盾。只是从不同方向看同一个值。

  • 作为对一半之说的回答来读，6.8个百分点很小。那个说法站不住
  • 作为人类史全部时间的分布来读，6.8个百分点很大。20万年里，每十四个人类就有一个挤在当下这一瞬
  • 分开两种读法的是比较对象。前者与总数比，后者与时段比。同一个数字上挂着两句都为真的话
  • 所以比例需要方向。缺了相对于什么这一项，说大说小都成了无法检验的句子

这种结构在人口统计中反复出现。讨论地区层面人口变动的人口趋势分析里也有同样的问题。下降幅度很大这句话和绝对规模很小这句话可以同时为真，究竟在说哪一句，由分母决定。

遇到大数字先问的四件事

能从这个案例中取出来的不是人口学知识，而是一种读法。无论遇到哪一类大数字，先看是否附着这四件事。

  • 定义 — 把什么算作一个单位。1170亿数的是出生事件，不是活完的一生。这一行大约决定了数字一半的含义
  • 区间 — 从何时到何时。首尾两端都要有。PRB 这个值的终点是2022年，2035年和2050年的展望是单独列行的
  • 假设 — 没有观测的那些段落是用什么填的。这里就是各时期的人口基准和各时期的出生率
  • 幅度 — 在合理范围内改动那些假设，数值会走到哪里。本案例中是940亿到1330亿

四行里只要缺一行，这个数字就还不是命题。这不是说它是假的，而是说它的真假无法判定。而一旦把无法判定的句子当成真的用，决策就会一层层堆在它上面。

把四个问题写成一行式样

如果需要把这类数值抄进自己的文档，保持下面这种形式更好。抄写的当下确实麻烦，但日后自己再读那句话时，还留着依据的只有这种形式。

[糟糕的引用]
  人类史上活过1000亿人

[可用的引用]
  人类史上出生的人  117,020,448,575人
    出处   : Population Reference Bureau，2022年11月修订
    作者   : Toshiko Kaneda, Carl Haub
    定义   : 出生事件的件数，与存活时长无关
    区间   : 190,000 B.C.E. ~ 2022年
    假设   : 公元1年前出生率每千人80，其后60
             公元1年世界人口3亿
    幅度   : 改动假设后为940亿 ~ 1330亿
    附注   : 发布主体明确表示方法半是科学半是技艺

把同一种读法搬到别的数字上

这四个问题在人口统计之外照样管用，因为结构是一样的。用假设填补观测够不到的区间，把各段产出相加成一个大数，再把这个数单独摘出来搬走，这种结构到处都是。

  • 市场规模推算 — 用抽样调查加增长率假设填补未观测的区间。增长率假设那一行就能让总额相差好几倍
  • 累计节省额或累计损失额 — 时段取多长决定了总额，而时段通常是标题里第一个被丢掉的
  • 模型性能与费用的数值 — 测量条件一旦掉了，同一个模型的数值也会变成互不相同的说法。那个案例整理在如何连同条件一起读已发布的分数里
  • 人口展望 — PRB 的表后面还接着2035年8,899,000,000、2050年9,752,000,000这样的展望行。这两行是情景而不是观测

共同点只有一个。大数字本身并不携带信息。信息在于造出它的那些输入，以及输入被摇动时数字移动的幅度。1000亿变成1170亿，再变成940亿到1330亿这样一个区间，失去的是简洁，换来的是真正能驾驭这个数字的能力。

未能确认的部分

以下各项无法从一手资料中确定，因此排除在正文之外，也没有以推测填补。

  • 婴儿死亡率的具体假定值 — 2022年修订版正文只写了出生时预期寿命平均约十岁，并未以数值写出各时期的婴儿死亡率。因此1170亿中夭折于婴儿期者的比例在正文中没有写
  • 50,000 - 8000 B.C.E. 区间的推算依据 — 该区间蕴含平均人口低于基准下限的缘由，公开资料中没有说明。所以这一处只记下不一致这个事实，不判定哪一边正确
  • Keyfitz 1966年论文自身的假设 — 总数约690亿和在世比例约4个百分点可以确认，但该论文以哪个时点为出发点、用了什么出生率，原文需付费阅览，故在表中留了破折号
  • 现代人出现时点在学界的共识范围 — PRB 各版本从50,000 B.C. 挪到190,000 B.C.E. 这一事实见于资料，但当前古人类学给出的年代范围本身超出本文查证的范围，因此既没有写成单一年份，也没有写成一个区间
  • Our World in Data 的约1080亿出自哪个版本 — 该页面只给出总数和6.5个百分点这一比例，没有说明起算时点和出生率假设。因此比较表中相应格留空
  • 表中出生率一列与正文表述的吻合 — 解说文正文写的是从2 C.E. 到1750年假定每千人60，而表中1750年那一行是50。计算实际用的是哪一个，此处依照表的列，并把这一情况记在这里
