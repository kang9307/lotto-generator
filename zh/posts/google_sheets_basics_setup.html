开始使用 Google 表格前要先定下的事 — 给用惯 Excel 的人

Google Sheets for Excel Users: What to Decide Before Your First Sheet

2026年8月16日 IT/技术

功能三十分钟就熟，难的是前面那几个决定

用惯 Excel 的人第一次打开 Google 表格，大多半小时之内就上手了。有单元格，公式仍然以等号开头，SUM 和 VLOOKUP 都还在原来的位置。所以讲「该点哪里」的文章其实并不太需要，点几下自己就明白了。

真正事后难以挽回的从来不是功能，而是用哪个账号建的、放在了哪里、把链接给了谁这三件事。它们都在新建一张表的那两秒里被顺手定下，几个月后再以离职、交接、审计或者外泄的形式回来。反过来说，只要开头把这三件事定清楚，剩下的边用边学也来得及。

这篇文章只谈这些决定，以及从 Excel 过来的人必然会撞上一次的差别。文中对行为的描述以 Google 官方帮助文档的记载为依据，时间为2026 年 8 月。但这里不写菜单名称和点击路径。Google 一直在调整编辑器界面，昨天还在某个菜单下的条目，今天可能已经挪到别处。按设置名称去搜索，比记住路径管用得多。

用哪个账号建，是第一个岔路口

这是最常见、也最晚才被发现的失误。当时赶时间，就用当前登录着的账号建了，然后一直用在工作上。文件的所有者就成了那个账号。

  • 用个人账号建的工作资料，公司拿不回来。负责人一换，整个交接就吊在一条共享链接上。那个人一旦断开共享或者清理账号，事情就到此为止了。
  • 用工作账号建的私人资料，离职时会消失。组织停用账号之后，该账号名下的文件就再也访问不到。把个人记账或者履历笔记放在公司账号里的情况，其实比想象中多。
  • 转移所有权没有想象中那么自由。依组织策略，向外部账号转移可能被完全禁止。以为以后能搬，往往就在必须搬的那天发现搬不动。
  • 同时登录多个账号时，同一条链接的表现会不一样。地址里会带上 /u/0、/u/1 这样的编号，收到的链接若带着对方的编号，你这边就会看到没有权限的页面。文件本身没问题，只是你在用另一个身份打开它。
  • 组织账号常常限制对外共享。如果这张表要和外部伙伴一起看，动手前先确认能不能共享。等做完了才发现被挡住，就只能整个搬到别处重做。

判断标准很短：这张表在我离开之后，还需要有人接着用吗？答案若是肯定的，就别从个人账号起步。

放我的云端硬盘还是共享云端硬盘 — 所有权在这里分开

账号定了，下一步是存放位置。Google 官方帮助用归属主体来说明两者的差别：共享云端硬盘中的文件属于团队而非个人，即使成员离开，文件依然留在原处。而「我的云端硬盘」里的文件是绑在建立者身上的。这与其说是功能比较，不如说是在决定这个文件到底是谁的。

  • 一个人用的私人记录，放我的云端硬盘是对的。共享云端硬盘是组织成员伸手可及的空间，不该用来放私人材料。
  • 将来会被交接的工作资料，放共享云端硬盘是对的。「换人之后文件还在」这一条，胜过对面所有的便利理由。
  • 与其以后再搬，不如一开始就建在该在的地方。搬动之后链接虽然还能用，但共享对象和权限会按新位置的规则重新计算，而在这个过程中谁悄悄失去了访问权，是很难被注意到的。
  • 能不能用共享云端硬盘，取决于订阅等级。个人账号根本没有这个概念。如果用的是公司账号却看不到相应条目，那是等级或者管理员策略的问题。
  • 先把文件夹结构建起来。表格很快就会变成几十张。定好新文件落在哪里，比事后整理便宜得多。

与 Excel 真正不同的四件事

对比功能清单收获不大。实际会酿成事故的差别只有四个。

1. 没有保存按钮，取而代之的是版本记录

编辑当下就已生效，不必去找 Ctrl+S。回退的职责由版本记录承担。依官方文档，有三点值得记住：浏览早期版本需要该文件的编辑权限，命名版本每个电子表格最多十五个，而且有些改动根本不会出现在编辑记录里，包括行列的增删、单元格格式的修改，以及由公式更新的数值。正因为最后这一条，「翻记录就都能查到」的想法很危险。重要的节点上，自己动手建一个命名版本。

2. 多人同时编辑是常态而非例外

在 Excel 里共享工作簿是一种特殊状态，在这里它就是日常。两个人同时改同一个单元格并不会锁定，而是后进来的输入留下。所以排序、筛选、插入行这类会动到别人屏幕的操作，不能随手就做。对方的体验是自己正在看的那一行突然跑掉了。

3. 单位是链接，不是文件

你不是在把附件寄出去，而是在授予访问同一份文档的权限。所以发出去之后内容还在变，权限给错了对方就直接改你的原件。要交付定稿时，应该导出 PDF 或者表格文件发过去，而不是发链接。

4. 函数集合重叠但并不一致

熟悉的函数大多都在。但有些函数只有这边才有，反过来像 Power Query 这样的工具只在那一边，需要换个思路解决。如果打算越过公式阶段一路做到自动化，Google 表格自动化完全指南一直讲到 Apps Script 和表单联动，而叠加 AI 功能的部分在Excel 与 Google 表格 AI 自动化指南那边。

过去在 Excel 里怎么做，这里怎么做

不按功能名称、而按手已经记住的动作来对照，迁移所花的时间会明显缩短。

开头顺手做掉、后面会轻松的设置

刚建好表就该动手的东西并不多，下面这些差不多就够了。

  • 把区域设置对上。官方文档说明，更改区域设置和时区会一并改变电子表格默认的货币、日期和数字格式。这项设置附着在文件上，因此无论协作者身在哪个国家，看到的都一样。日期和货币对不上的事故，大半都从这里开始。
  • 把时区对上。它决定 NOW 和 TODAY 返回什么，也决定记录下来的时间意味着什么。只要是处理截止时间的表，这里错了后面全错。
  • 确认函数语言。同一处设置里有一项决定函数名用哪种语言书写。这一项不一致，别人给的公式贴进来就认不出函数名。
  • 看一眼计算设置。重新计算的时机和是否允许迭代计算在这里。如果计算本身要依赖循环引用，得先把后一项打开。
  • 了解自动补全的行为。在同一列输入相似的值会得到后续值的建议。方便，但也会把你没打算要的值确定下来，所以批量录入时先看清建议内容再确认。
  • 离线使用提前开好。依官方文档，需要 Chrome 或者 Microsoft Edge 浏览器加上专用扩展程序，无痕窗口下不起作用，而且每个浏览器配置文件只能有一个账号启用离线。文件太大不会同步，组织管理员也可能把这项功能关掉。等到了机场才想起来要在飞机上打开，就已经晚了。
  • 马上改文件名。等到十来个无标题电子表格堆在一起，连搜索都救不了你。

Excel 没有的三个函数 — ARRAYFORMULA、QUERY、IMPORTRANGE

学会这三个，你才算把表格当成另一种工具，而不是「浏览器里的 Excel」。下面的定义依据官方函数参考的表述。

ARRAYFORMULA — 不用再往下拖公式

官方的定义是：把数组公式返回的值显示到多行和多列，并让非数组函数能够配合数组使用。在编辑公式的过程中按 Ctrl+Shift+Enter 会自动为它加上这层包裹。

=ARRAYFORMULA(B2:B1000 * C2:C1000)

只在一个单元格里写一次，下面的单元格就会自己填满。行数增加也不必重新往下拖，这是它的要点，在多人不断往下追加行的表里尤其管用。但数组公式无法被导出到其他格式。下载成 Excel 文件后发现计算列是空的，事故就出在这里。

QUERY — 在表格里写查询语句

官方的说明是：用 Google Visualization API 查询语言对数据执行查询。语法为 QUERY(数据, 查询语句, [标题行数])，支持 select、where、group by、order by 和 pivot 等子句。

=QUERY(A1:E, "select B, sum(D) where C = '已完成' group by B order by sum(D) desc", 1)

有两处容易绊倒人。查询语句里指代列时用的是 A、B、C 这样的列字母，而不是标题文字。而且官方文档写明，当一列中混有多种数据类型时，占多数的那种类型决定该列的类型。数字列里混进几个文本，那些值就会被悄悄丢掉。查询结果不对时，先去看源列的数据类型。

IMPORTRANGE — 从另一个文档取来一段区域

语法是 IMPORTRANGE(电子表格网址, 区域字符串)。

=IMPORTRANGE("https://docs.google.com/spreadsheets/d/表格ID", "销售!A1:D")

两个文档第一次连接时会出现 #REF! 并提示允许访问，走完这一步数据才会进来。这里正是与个人信息相关的关键处。依官方文档，授权完成后，取数的一方可以从源文件的任何部分导入，这项访问权会一直保留到授权的用户被移出源文件为止，并且计入共享人数上限。公式里只写了 A1:D，并不意味着授权范围就收窄到那四列。

共享权限 — 门要开到多大

这是全文最重要的一节。前面所有设置错了都还能改，而共享一旦错了，东西已经出去了。

角色或设置对方能做什么适合用在哪里
查看者打开阅读，默认还可以下载传阅定稿
评论者阅读、下载并留言，但不能编辑审阅请求，外部反馈
编辑者修改内容，还能继续分享给别人共同创作的文档
所有者全部，包括删除和转移所有权保持只有一个人
受限只有获得访问权的人才能打开应当作为默认设置
知道链接的任何人只要有链接，无需登录即可打开只用于确实可以公开的材料

为什么「知道链接的任何人」危险

官方文档把这个设置描述为拿到链接的人无需登录即可使用该文件。人们之所以误以为它安全，是因为「搜索里不会出现」这个印象，但那是另一回事。

  • 链接会被复制。在聊天里转发一次，控制就结束了，实际上没有办法收回。
  • 不会留下谁打开过的记录。既然不需要登录，也就没有可以对应到某个人的访问行为。
  • 和编辑者权限叠在一起最糟。拿到链接的任何人都能改你的原件，而查看者连版本记录都看不到，因为按官方文档浏览版本需要编辑权限。
  • 为了方便打开之后就再没关掉。这是表格被暴露出去最常见的路径。

处理含个人信息的表格时

只要有一行含姓名、联系方式、住址、账号或者出生日期，这张表就不能按普通文档的标准对待。问题的性质从设置变成了责任。

  • 不要用「知道链接的任何人」。逐个指定需要访问的人，并定期回头看这份名单。多数情况下，离职的人和已经结束合作的伙伴还留在上面。
  • 只保留需要的字段。表里存在的列，最终都会有人看到。目的上并不需要的身份信息，最稳妥的办法是根本不要搬进来。
  • 下载、打印、复制的限制是防失误，不是防外泄。官方文档确认所有者可以控制这些动作，但屏幕依然看得见，截屏也拦不住。
  • 能用有效期就一定给对外共享加上。官方文档写明，有效期功能仅面向符合条件的工作或学校账号提供。个人账号里没有这一项属于正常现象。
  • 不要用 IMPORTRANGE 去取。如前一节所述，授权是以文档为单位的。含个人信息的源文件一旦被授权，整个文档就都在范围之内。
  • 不要散发副本，而是给出汇总。与其整份共享原件，不如把真正需要的汇总数据挪到另一张表再共享那一张。很多时候不给原件访问权，事情照样办得成。
  • 人员一变动就当天清理。打算以后集中处理的计划不会被执行。

新手最容易卡住的几处

有些症状光看表面很难推出原因，下面这五种占了绝大多数。

症状原因该动哪里
合计与屏幕上看到的数值对不上格式只改显示，存下来的值没变要真的改值就用 ROUND
明明是数字却被 SUM 跳过它是以文本形式存着的左对齐就该起疑，用 VALUE 转换
日期的月和日颠倒了区域设置用的是别国的标准文件的区域设置
一粘贴，格式也跟着来了默认粘贴会把值、公式和格式一起搬改用仅粘贴数值
我加了筛选，别人的屏幕也变了筛选器作用于整个文档改用筛选器视图
  • 单元格格式和实际数值是两回事。把格式改成显示两位小数，并不会让底下的数字被四舍五入，这正是把看到的数加起来和实际合计对不上的原因。要真的把值本身取整，得用公式处理。
  • 以文本形式存进来的数字会被悄悄漏掉。这在从其他系统导出的资料和从网页复制来的表格里很常见，前面多半带着一个撇号，或者混进了看不见的空格。
  • 日期显示成五位数字并不是故障。日期在内部是以数字存储的，格式只是把它显示成日期的样子，把格式改回日期就恢复了。想了解这套机制，可以看Excel 序列值与 1900 年闰年缺陷那篇，里面写得比较细。
  • 把粘贴选项分开来用。仅数值、仅格式、仅公式是各自独立的选项。从别人做的表里只想取数值时直接粘贴，颜色、边框、条件格式和数据验证规则会一并跟过来，把原有的规则覆盖掉。
  • 筛选器和筛选器视图完全是两码事。官方文档说明，添加筛选器之后所有能访问该电子表格的人都会看到这个筛选器；而筛选器视图只作用于你自己的视图，多个人可以同时使用各自不同的筛选器视图。文档还写明，即使只有查看权限，也可以建立只有自己能用的临时筛选器视图。在与人共用的表里，把筛选器视图作为默认做法更安全。
  • 整列引用方便但很重。像 A:A 这样整列指代的公式一多，整个文档就会变慢。把数据范围划清楚，或者用 ARRAYFORMULA 只计算需要的那一段。
  • 查找类函数几乎和 Excel 一样。VLOOKUP 系列可以直接沿用，没有新东西要学。报错类型和替代方案整理在VLOOKUP 与 XLOOKUP 完全指南里，如果不熟悉汇总的做法，数据透视表实战指南讲的是同一套概念。

本文不下断言的部分

以下内容本文不作断言。它们会随时间、账号等级或组织策略而变，或者只能在实际界面上确认。

  • 菜单名称与点击路径是有意略去的。Google 一直在调整编辑器的界面结构，按设置名称去搜索比记住路径更耐用。
  • 哪个订阅等级开放哪些功能不在这里断言。像有效期这样的功能，官方只写明面向符合条件的工作或学校账号提供，具体边界要在管理控制台里确认。
  • 为什么你的界面上没有某个按钮，这里无法判断。可能是功能本身没有，也可能是组织管理员关掉了——官方文档写明离线使用可以被管理员限制。
  • 行、列、单元格的上限和性能极限的具体数字没有写。这些数值一直在变，写死一个数字只会让它错着留在这里。
  • 某个具体的 Excel 文件能否无损打开因文件而异。宏以及部分格式和函数会在转换中发生变化，应当保留原件再做测试。
  • 关于个人信息处理的法律判断超出本文范围。这里讲的是设置和习惯，某份资料需要哪些保护措施，属于主管机构的指引和专业人士判断的领域。

常见问题

Q1. 把 Excel 文件放到 Google 表格里打开，还能照原样用吗？

大部分表格和公式都能正常打开。但宏不会跟过来，这里的自动化是 Apps Script 而不是 VBA，需要重写。条件格式、验证规则和个别函数也可能在转换中变化，所以保留原件、另开一份对照检查更稳妥。反方向导出时，要记住用 ARRAYFORMULA 写的数组公式无法被导出这条官方限制。

Q2. 没有保存按钮，我的工作会丢失吗？

编辑即时生效，靠版本记录回退。但浏览版本需要编辑权限，命名版本每个电子表格最多十五个。行列改动、单元格格式修改这类变更不会出现在编辑记录里，所以在需要可靠回退点的时候，自己动手建一个命名版本。

Q3. 用知道链接的任何人来共享安全吗？

官方文档把它描述为拿到链接的人无需登录即可使用该文件。不容易被搜到和别人打不开是两回事。链接会被转发、无法收回，也不留下谁打开过的记录。含个人信息的表格不要用它，逐个指定可以访问的人才是默认做法。

Q4. 有哪些函数是 Excel 没有而 Google 表格才有的？

有三个最具代表性。ARRAYFORMULA 把数组公式的结果铺开到多行多列，并让非数组函数能配合数组使用。QUERY 用 Google Visualization API 查询语言对数据执行查询。IMPORTRANGE 导入另一个电子表格的区域，首次连接要走一步授权。三者在官方函数参考里都有定义。

Q5. 日期显示错乱或者变成数字，是什么原因？

先看区域设置。官方文档说明，更改区域设置和时区会改变默认的货币、日期和数字格式，而这项设置附着在文件上，与协作者所在地无关，对所有人一致。用别国区域设置建的文件，读日期时月和日会颠倒。日期显示成五位数字则是另一回事，只是单元格格式被切换成了数字，存下来的值仍然是日期。

结语

在 Google 表格里真正需要重新学的东西并不多。账号和存放位置决定所有权、版本记录取代了保存而查看它需要编辑权限、区域设置附着在文件上并对所有人一致、共享是开一扇门而不是递出一份副本，以及ARRAYFORMULA、QUERY 和 IMPORTRANGE 用另一种方式接手了 Excel 里的那些活。这五条撑得起其余的部分。

动手之前只定两件事。一是这张表在我不在的时候还需要有人接着用吗，二是里面会不会装进关于人的信息。前者若是肯定的，就别建在个人账号下；后者若是肯定的，就别打开链接共享。事后难以挽回的事情，几乎全都产生在这两处。
