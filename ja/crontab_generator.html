例: 0 9 * * * /path/to/your/script.sh

📖 Cron 特殊文字ガイド

Crontabで使用される特殊文字の意味を学びましょう。

*

アスタリスク (*)

意味: すべての値（ワイルドカード）

例: * * * * * = 毎分実行

,

カンマ (,)

意味: 複数の値を指定

例: 0 9,17 * * * = 午前9時、午後5時

-

ハイフン (-)

意味: 範囲を指定

例: 0 9 * * 1-5 = 平日午前9時

/

スラッシュ (/)

意味: 間隔を指定

例: */15 * * * * = 15分ごと

?

クエスチョンマーク (?)

意味: 無関係（一部の実装で使用）

例: 日または曜日フィールドで使用

L

L (Last)

意味: 最後（拡張cron）

例: 0 0 L * * = 毎月最終日

📦 バックアップ作業のスケジューリング

毎日午前2時のデータベースバックアップ

0 2 * * * /usr/local/bin/backup_db.sh

毎日午前2時にデータベースバックアップスクリプトを実行します。

週末ごとの全体システムバックアップ

0 1 * * 0 /usr/local/bin/full_backup.sh

毎週日曜日午前1時に全体システムバックアップを実行します。

📊 システムモニタリング

5分ごとのシステム状態チェック

*/5 * * * * /usr/local/bin/system_check.sh

5分間隔でシステム状態をモニタリングします。

毎時間のログ分析

0 * * * * /usr/local/bin/analyze_logs.sh

毎時間の正時にログを分析し、異常兆候を検知します。

🔧 システム保守

毎週火曜日午前3時のシステムアップデート

0 3 * * 2 /usr/bin/apt update && /usr/bin/apt upgrade -y

毎週火曜日の早朝にシステムパッケージをアップデートします。

毎月1日の一時ファイル整理

0 4 1 * * /usr/local/bin/cleanup_temp.sh

毎月初日の午前4時に一時ファイルを整理します。

📈 レポート生成

平日午前9時のデイリーレポート

0 9 * * 1-5 /usr/local/bin/daily_report.sh

平日午前9時にデイリー業務レポートを自動生成します。

毎月最終金曜日の月次レポート

0 17 * * 5 [ $(date +\%m) -ne $(date -d '+7 days' +\%m) ] && /usr/local/bin/monthly_report.sh

毎月最終金曜日の午後5時に月次レポートを生成します。

🧹 クリーンアップ作業

毎日深夜0時のログローテーション

0 0 * * * /usr/sbin/logrotate /etc/logrotate.conf

毎日深夜0時にログファイルのローテーションを行います。

週末のディスク容量クリーンアップ

0 2 * * 6,0 /usr/local/bin/disk_cleanup.sh

週末の午前2時に不要なファイルを整理してディスク容量を確保します。

❓ よくある質問

入力したスケジュール情報はサーバーに送信されますか？

いいえ。このツールの式生成と次回実行時刻の計算は、すべてブラウザ内のJavaScriptだけで処理されます。設定した値や生成された式がサーバーに送信・保存されることはありません。

次回実行時刻のプレビューはどのくらい正確ですか？

プレビューはお使いのブラウザのローカルタイムゾーンを基準に計算されるため、サーバーのタイムゾーンが異なる場合は実際の実行時刻とずれることがあります。また、標準の5フィールド構文のみに対応しており、@reboot、MONやJANなどの略称、6フィールド式といった非標準構文はプレビューの対象外です。

生成した式はどのように使いますか？

Linuxサーバーで crontab -e コマンドを実行してエディタを開き、生成された式の後ろに実行するコマンドやスクリプトのパスを付けて1行で追加します。スクリプトは絶対パスで指定し、出力をログファイルに残しておくと、問題が起きたときの原因調査が容易になります。

このポスティングはクーパンパートナーズ活動の一環として、それに伴う一定額の手数料を提供されます。
