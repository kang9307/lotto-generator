1. 2025년 공개와 재조명 — 멀티 LLM 통신의 새로운 질문

일반적으로 복수의 인공지능 모델을 연결하여 단일 모델의 성능적 한계를 극복하려는 시도는 멀티 에이전트 및 앙상블 시스템 구축의 중요한 흐름으로 자리 잡아 왔다. 복수의 대규모 언어 모델(LLM)을 결합하는 멀티 LLM 시스템은 서로 다른 모델이 보유한 상호보완적인 강점을 활용함으로써 개별 모델 단독으로는 도달하기 어려운 수준의 성능과 효율성을 달성하고자 한다. 원문은 멀티 LLM 시스템에 대해 「Multi-LLM systems harness the complementary strengths of diverse Large Language Models, achieving performance and efficiency gains that are not attainable by a single model.」이라고 서술한다.

그러나 지금까지 제안된 거의 모든 멀티 LLM 상호작용 아키텍처는 모델 간 정보 전달 매개체로 사람이 읽을 수 있는 텍스트를 그대로 사용해 왔다. 하나의 모델이 생성한 자연어 문장을 프롬프트 형태로 다음 모델에 전달하는 방식이 사실상의 기본 표준으로 취급되었다. 논문 「Cache-to-Cache: Direct Semantic Communication Between Large Language Models」는 바로 이 전제에 대해 정면으로 의문을 제기하며 출발한 연구다. 저자 목록에는 Tianyu Fu, Zihan Min, Hanling Zhang, Jichao Yan, Guohao Dai, Wanli Ouyang, Yu Wang이 이름을 올렸다.

이 연구는 2026년 가을에 완전히 새로 발표된 단기적 신작이 아니다. 2025년 10월 3일에 최초 판본인 v1이 arXiv에 등록되었으며, 2026년 3월 2일에 v2 개정본이 게시된 연구다. 기술 커뮤니티 GeekNews에서는 「Cache-to-Cache: LLM 간 직접 의미 전달 (2025)」라는 표기로 2025년 연구임을 분명히 명시하여 공유한 바 있다. 이 글의 해석으로는, 최근 추론 효율화와 멀티 모델 파이프라인의 내부 지연 단축에 대한 산업적 관심이 급증하면서 2025년에 제안된 이 논문이 다시금 주목받게 된 것으로 이해할 수 있다.

연구진이 던진 근본적인 질문은 원문 그대로 「Can LLMs communicate beyond text?」(LLM이 텍스트를 넘어서 통신할 수 있는가?)라는 물음으로 압축된다. 사람이 사용하는 문자 인터페이스를 굳이 모델 간 통신에서도 고수할 필요가 있는가라는 문제의식이다. 이 논문은 내부 활성화 상태이자 연산 결과물인 KV-Cache를 직접 교환 매개체로 삼는 새로운 통신 패러다임을 제안하고 그 타당성을 다각도로 검증한다.

이 글의 해석으로는, 기존 자연어 인터페이스는 모델이 연산한 수많은 확률적 가중치와 잠재적 의미 분기를 단 하나의 토큰 경로로 강제 축약하는 정보의 병목점으로 기능해 왔다. 두 모델이 동일하거나 호환 가능한 내부 텐서 연산 프레임워크를 공유할 수 있다면, 굳이 이 병목을 거쳐 언어로 번역했다가 다시 텐서로 역변환하는 단계를 거칠 필요가 없다는 것이 이 연구가 던진 문제의식의 본질이다.

2. 기존 텍스트 통신의 한계 — 정보 손실과 토큰 생성 지연

기존 설계에서 복수의 LLM이 협력하는 방식은 텍스트 통신 패러다임에 강하게 종속되어 있었다. 원문은 기존 설계의 문제를 다음과 같이 명시한다: 「In existing designs, LLMs communicate through text, forcing internal representations to be transformed into output token sequences. This process both loses rich semantic information and incurs token-by-token generation latency.」

원문이 지적한 문제점은 크게 정보 손실과 지연 시간이라는 두 가지 축으로 나뉜다.

  • 내부 표현의 강제 직렬화: 신경망 내부의 고차원 연속 벡터 공간에 존재하는 잠재 의미 표현을 이산적인 출력 토큰 시퀀스로 강제 변환해야 한다.
  • 풍부한 의미 정보의 소실: 텍스트로 표출되는 어휘적 표현의 한계로 인해 모델이 포착한 깊고 풍부한 맥락적 의미가 변환 과정에서 유실된다.
  • 순차적 토큰 생성 지연: 첫 번째 모델이 응답 전체를 토큰 단위로 순차 생성(autoregressive generation)할 때까지 대기해야 하므로 누적 지연 시간이 발생한다.
  • 후속 모델의 재인코딩 부하: 후속 모델은 전달받은 텍스트를 다시 임베딩하고 어텐션 연산을 거쳐 자신의 내부 캐시로 복원하는 중복 과정을 거쳐야 한다.

이 글의 해석으로는, 신경망 내부에서는 수천 차원의 고밀도 텐서로 연산이 이루어지는데 이를 굳이 몇십 바이트의 불연속적인 단어 열로 압축했다가 다시 푸는 과정 자체가 멀티 모델 통신의 심각한 병목으로 작용한다고 볼 수 있다. 텍스트라는 매개체는 인간 사용자를 위한 해석 가능 인터페이스로서는 필수적이지만, 모델과 모델 사이의 연산 상호작용에서는 오히려 정보의 왜곡과 연산 낭비를 강제하는 족쇄가 된다는 점을 원문은 분명히 지적하고 있다.

이 글의 해석으로는, 분산 추론 환경에서 각 모델이 독립적인 파이프라인으로 동작할 때 첫 번째 모델이 수백 토큰에 달하는 긴 설명을 생성한 뒤 이를 네트워크로 전송하고 두 번째 모델이 다시 프리필(prefill) 연산을 수행하는 구조에서는 막대한 메모리 대역폭과 추론 지연이 누적된다. 텍스트 통신 패러다임은 직관적이고 인간 친화적이지만, 모델 간의 순수한 기계적 협업이라는 관점에서는 대단히 비효율적인 인터페이스로 작용할 수 있음을 보여준다.

3. 발상의 검증 — KV-Cache 의미 강화와 오라클 예비 실험

연구진은 본격적인 아키텍처 설계에 앞서, KV-Cache라는 내부 데이터 구조가 과연 상호 모델 통신의 유효한 매개체가 될 수 있는지를 검증하는 예비 실험을 수행했다. 원문은 이 예비 실험을 오라클 실험(oracle experiments)으로 명시한다. 원문은 다음과 같이 기록한다: 「Oracle experiments show that enriching the KV-Cache semantics can improve response quality without increasing cache size, supporting KV-Cache as an effective medium for inter-model communication.」

이 오라클 예비 실험의 발견은 두 가지 중요한 사실을 확립했다.

  • 캐시 크기의 비증가성: KV-Cache의 물리적 크기를 무작정 확장하지 않고도 의미 정보를 풍부하게 강화하는 것이 가능하다는 점이다.
  • 응답 품질의 향상: 캐시의 의미적 밀도를 높였을 때 최종 응답 품질이 뚜렷하게 개선된다는 상관관계를 실증했다는 점이다.
  • 통신 매개체로서의 타당성: KV-Cache가 서로 다른 모델 간의 정보 전송에 있어 효과적이고 실행 가능한 매개체임을 실험적으로 지지했다는 점이다.
  • 설계 방향성의 확립: 중간 텍스트를 완전히 배제하고 캐시 레이어 자체를 연결하는 통신 기법의 이론적 근거를 제공했다는 점이다.

이 글의 해석으로는, 기존 KV-Cache가 단순히 자기회귀 디코딩의 연산 중복을 방지하기 위한 임시 메모리 저장소로만 취급되던 통념을 깨뜨린 결과다. KV-Cache의 내부 표현 자체를 의미론적 전달 단위로 재정의할 수 있다는 실험적 증거가 확보됨으로써 본격적인 아키텍처 제안으로 이어질 수 있었다.

이 글의 해석으로는, 트랜스포머의 어텐션 메커니즘에서 Key와 Value 벡터는 단순한 위치 정보가 아니라 문맥 전체의 의미적 상호작용이 응축된 결과물이다. 오라클 예비 실험이 확인한 바와 같이, 물리적인 캐시 크기 자체를 늘리지 않더라도 캐시 벡터 내부의 의미론적 밀도를 정교하게 보강할 수 있다면 메모리 점유율을 증가시키지 않고도 응답 품질의 유의미한 개선을 이끌어낼 수 있다는 점이 이 연구의 핵심적인 착안점이다.

4. Cache-to-Cache(C2C)의 핵심 아키텍처 — 프로젝션, 융합, 게이팅

예비 실험의 결론을 바탕으로 연구진은 새로운 모델 간 직접 의미 통신 패러다임인 C2C(Cache-to-Cache)를 제안했다. 원문은 제안 기법을 다음과 같이 설명한다: 「Thus, we propose Cache-to-Cache (C2C), a new paradigm for direct semantic communication between LLMs. C2C uses a neural network to project and fuse the source model's KV-cache with that of the target model to enable direct semantic transfer. A learnable gating mechanism selects the target layers that benefit from cache communication.」

원문에 기술된 C2C 아키텍처의 핵심 구성 요소는 크게 두 가지 메커니즘으로 구성된다.

  • 프로젝션 및 융합 신경망: 소스 모델의 KV-Cache를 타깃 모델의 내부 표현 공간으로 투영하고 결합하여 직접적인 의미 전달을 수행하는 신경망이다.
  • 학습 가능한 게이팅 메커니즘: 캐시 통신을 통해 실질적인 성능 이점을 얻을 수 있는 타깃 모델의 특정 레이어를 선별하는 학습 가능한 구조다.
  • 직접 의미 전달 경로: 중간 텍스트 토큰을 외부로 방출하지 않고 소스 모델의 캐시 정보를 타깃 모델의 대응 레이어로 곧바로 주입하는 통로다.
  • 심층 의미 활용성: 원문에 따르면 소스 모델과 타깃 모델 양쪽 모두의 깊고 특화된 의미 표현을 명시적 텍스트 생성 없이 동시에 활용한다.

원문은 텍스트 통신 대비 C2C의 구조적 이점을 명시하며 「C2C utilizes the deep, specialized semantics from both models, while avoiding explicit intermediate text generation.」(C2C는 명시적인 중간 텍스트 생성을 회피하면서 두 모델 모두로부터 깊고 특화된 의미를 활용한다)라고 강조한다.

아래 표는 원문 초록에 공개된 C2C의 핵심 구조적 구성 요소와 그 역할을 정리한 것이다.

구성 요소 원문 표현 원문에 명시된 주요 기능과 역할
프로젝션 및 융합 신경망 a neural network to project and fuse 소스 모델의 KV-Cache를 타깃 모델의 KV-Cache로 투영 및 융합하여 직접적인 의미 전달을 가능하게 함
학습 가능한 게이팅 메커니즘 a learnable gating mechanism 캐시 기반 통신으로부터 실질적인 이득을 얻는 타깃 모델 내부의 특정 레이어들을 선별함

이 글의 해석으로는, 모든 레이어의 캐시를 무차별적으로 덮어쓰거나 결합하는 단순한 방식을 취할 경우 타깃 모델 고유의 주의 집중(attention) 메커니즘이 교란될 위험이 있다. 이를 방지하기 위해 학습 가능한 게이팅 메커니즘을 도입하여 의미 전달의 효용이 입증된 특정 계층만을 선별적으로 연결한 점이 C2C 설계의 핵심적인 안전장치이자 최적화 기법으로 판단된다.

이 글의 해석으로는, 서로 다른 모델 사이에서는 계층별 추상화 수준과 잠재 공간의 기저 벡터가 완전히 일치하지 않는다. 따라서 소스 모델의 캐시를 타깃 모델의 내부 좌표계로 정렬하는 프로젝션 신경망과 함께, 상호작용의 효용이 큰 레이어에만 가중치를 부여하는 학습형 게이팅이 결합됨으로써 불필요한 노이즈 전파를 막고 안정적인 정보 융합이 가능해졌을 것으로 분석된다.

5. 세 가지 정량 평가 성과와 비교축 분석

원문 초록은 C2C의 효과를 증명하기 위해 명확한 정량적 평가 결과를 제시한다. 원문은 다음과 같이 적는다: 「Experiments show that C2C achieves 6.4-14.2% higher average accuracy than individual models. It further outperforms the text communication paradigm by approximately 3.1-5.4%, while delivering an average 2.5x speedup in latency.」

이 실험 결과는 서로 다른 세 가지 비교축을 명확히 구분하여 해석해야 한다. 각 수치는 측정 대상과 기준점이 완전히 다르다.

  • 비교축 1 — 개별 단독 모델 대비 정확도: 단독으로 실행되는 개별 모델과 비교했을 때 C2C는 평균 6.4%에서 14.2% 더 높은 평균 정확도를 달성했다.
  • 개별 모델 대비의 의미: 복수 모델의 내부 표현을 결합함으로써 단일 모델이 갖지 못한 상호보완적 지식을 효과적으로 수용했음을 보여준다.
  • 비교축 2 — 텍스트 통신 패러다임 대비 정확도: 텍스트를 생성하여 주고받는 기존 멀티 LLM 통신 방식과 비교했을 때 C2C는 약 3.1%에서 5.4% 더 우수한 성능을 기록했다.
  • 텍스트 통신 대비의 의미: 중간 텍스트 직렬화 과정에서 유실되던 고차원 잠재 정보가 보존됨으로써 더 정밀한 추론이 가능해졌음을 입증한다.
  • 비교축 3 — 추론 지연 시간 개선 배수: 기존 텍스트 기반 통신 대비 지연 시간(latency) 측면에서 평균 2.5배의 속도 향상(speedup)을 달성했다.
  • 지연 시간 단축의 의미: 소스 모델이 불필요한 토큰 단위 자기회귀 생성을 건너뛰고 캐시를 직접 전달함으로써 전체 파이프라인의 응답 속도가 대폭 개선되었다.

아래 표는 원문에 명시된 세 가지 정량 성과와 그 비교 대상을 대조하여 정리한 것이다.

평가 지표 정량적 성과 수치 원문에 명시된 비교 대상 성과가 갖는 기술적 의미
평균 정확도 향상폭 (단일 모델 기준) 6.4 - 14.2% 향상 개별 모델 (individual models) 단일 모델 단독 실행 대비 상호보완적 지식 융합 효과 실증
평균 정확도 우위 (통신 방식 기준) 약 3.1 - 5.4% 우수 텍스트 통신 패러다임 (text communication paradigm) 텍스트 직렬화로 인한 잠재 정보 손실 방지 효과 입증
추론 지연 시간 개선 (속도 향상) 평균 2.5배 속도 향상 (2.5x speedup) 텍스트 통신 패러다임 (text communication paradigm) 중간 토큰 순차 생성 단계 제거를 통한 통신 지연 단축

이 정량적 수치는 단순한 정확도 개선뿐만 아니라, 기존 멀티 모델 파이프라인의 최대 약점이었던 복수 모델 연쇄 호출 시의 지연 시간 누적 문제를 평균 2.5배 수준으로 경감시켰음을 객관적인 숫자로 제시한다.

이 글의 해석으로는, 개별 모델 대비 6.4-14.2% 향상이라는 수치는 두 모델의 상호보완적 융합이 성공했음을 나타내며, 텍스트 통신 대비 약 3.1-5.4% 우위는 자연어 직렬화 과정에서 유실되던 잠재 정보의 가치가 실제로 존재했음을 정량적으로 증명한다. 여기에 지연 시간 2.5배 속도 향상이 더해짐으로써 정확도 상승과 지연 시간 단축이라는 상충하는 두 목표가 동시에 달성된 것으로 평가할 수 있다.

6. 멀티 LLM 시스템에서의 설계상 이점과 트레이드오프

C2C 연구가 제시한 결과는 멀티 LLM 시스템의 설계 방식에 중대한 전환점을 시사한다. 기존의 파이프라인 구조에서는 각 단계의 모델이 완성된 자연어 문맥을 출력해야만 다음 모델이 작업을 이어받을 수 있었다. C2C는 이 불필요한 디코딩과 재인코딩의 루프를 생략하고 내부 잠재 공간끼리 직접 채널을 형성한다.

원문 서술과 공개 사실에 기반하여 정리할 수 있는 설계적 함의는 다음과 같다.

  • 중간 텍스트 생성의 완전한 생략: 소스 모델이 최종 텍스트 토큰을 autoregressive하게 풀어서 출력할 필요 없이 캐시 상태에서 타깃으로 전송된다.
  • 심층 특화 의미의 보존: 원문이 명시한 바와 같이 소스 모델 내부에서 형성된 고유하고 깊은 특화 지식이 텍스트 어휘의 한계에 갇히지 않고 그대로 전달된다.
  • 네트워크 전송량과 메모리 구조의 변화: 이 글의 해석으로는 텍스트 문자열 대신 고차원 텐서인 KV-Cache를 모델 간에 전송해야 하므로 통신 대역폭과 메모리 버퍼 관리가 새로운 시스템 고려사항이 될 수 있다.
  • 공식 코드 저장소의 개방: 연구진은 해당 연구의 재현과 추가 검증을 위해 공식 코드 저장소를 GitHub(thu-nics/C2C)에 공개했다.

이 글의 해석으로는, C2C 방식이 제공하는 지연 시간 2.5배 단축과 최대 14.2%의 성능 개선은 대단히 매력적이지만 인간 관찰자의 즉각적인 개입과 감사(audit) 측면에서는 다른 평가가 따를 수 있다. 모델 간에 오가는 정보가 사람이 읽을 수 있는 텍스트가 아니라 신경망 잠재 텐서이기 때문에, 중간 과정에서 어떤 추론이 오갔는지를 실시간으로 모니터링하기 위해서는 별도의 디코딩 장치나 검증 인터페이스가 필요해질 수 있다는 점이 시스템 아키텍처 수준에서의 주요 트레이드오프로 분석된다.

이 글의 해석으로는, C2C 패러다임이 확산될 경우 향후 복합 추론 인프라의 주요 병목은 토큰 생성 연산 속도에서 노드 간 고속 텐서 전송 대역폭과 캐시 동기화 인프라로 점차 이동할 것으로 보인다. 자연어가 주는 해석 가능성과 직접 통신이 주는 고효율 지연 단축 사이에서 시스템 설계자가 애플리케이션의 성격에 따라 최적의 통신 프로토콜을 취사선택하는 단계로 나아가게 될 것이다.

7. 확인하지 못한 것

본 기술 분석은 arXiv:2510.03215의 공개 초록을 1차 출처로 작성되었다. 초록에 기재되지 않은 세부 실험 환경과 구현 스펙은 엄격한 사실 확인 원칙에 따라 본문에 단정하여 서술하지 않았으며, 확인하지 못한 항목들은 다음과 같다.

  • 실험에 투입된 구체적인 LLM 모델 명칭: 연구진이 소스 모델과 타깃 모델로 어떤 기종(예: Llama 계열, Mistral 계열, Qwen 계열 등)을 사용했는지와 개별 모델의 파라미터 규모는 초록에 언급되지 않아 확인하지 못했다.
  • 평가에 사용된 벤치마크 데이터셋의 구체적인 명칭: 평균 정확도 향상을 측정한 구체적인 태스크가 상식 추론, 수학, 코딩, 혹은 질의응답 중 어떤 데이터셋을 포함하는지 초록에 명시되지 않아 특정하지 못했다.
  • 하드웨어 인프라 및 통신 대역폭 환경: 실험이 단일 머신 다중 GPU 환경에서 이루어졌는지, 혹은 노드 간 네트워크 환경에서 수행되었는지와 구체적인 하드웨어 가속기 기종은 초록에 제시되지 않아 확인하지 못했다.
  • 게이팅 메커니즘과 프로젝션 레이어의 훈련 비용: 타깃 레이어를 선별하는 게이팅 모듈과 캐시 융합 신경망을 학습시키는 데 소요된 추가적인 연산량과 훈련 데이터셋의 규모는 초록에 기재되지 않아 확인하지 못했다.
  • 이종 아키텍처 간 확장성: 소스 모델과 타깃 모델의 내부 임베딩 차원, 어텐션 헤드 수, 토크나이저 어휘 체계가 완전히 다른 이종 모델 간 통신에 필요한 세부 변환 방식은 초록에 기술되지 않아 확인하지 못했다.
