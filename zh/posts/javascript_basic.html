变量声明 (Variable Declaration)

在 JavaScript 中，可以使用 var、let 和 const 关键字来声明变量。

English: In JavaScript, you can declare variables using the keywords var, let, and const.

// var (函数作用域 - function scope)
var x = 5;

// let (块级作用域 - block scope)
let y = 10;

// const (常量, 不可重新赋值 - constant, cannot be reassigned)
const PI = 3.14;

这三个关键字不只是名字不同。它们在作用域、是否允许重复声明与重新赋值、声明前访问时的行为上都有区别。下表可以一眼看清。

同名重复声明可以(静默覆盖)不可以 (SyntaxError)不可以 (SyntaxError)
声明前访问返回 undefinedReferenceError (TDZ)ReferenceError (TDZ)
声明时必须初始化可省略可省略必须

实务规则很简单：默认用 const 声明，只有确实需要重新赋值时才换成 let，新代码里不再写 var。这样「这个变量以后不会变」的信息就直接体现在代码里，后来读代码的人需要追踪的可变状态也随之减少。等到真正需要重新赋值的那一刻再降级为 let 就够了。

作用域：变量存活的范围

var 是函数作用域，即使在 if 或 for 块里声明，也会跑出块外、在整个函数中都能访问。而 let 和 const 是块级作用域，离开花括号就不存在了。本来只想在块内使用的临时变量却一直活到函数结束，是 bug 的常见源头。

// var: 函数作用域 + 只提升声明(值为 undefined)
function varScope() {
  console.log(typeof value); // "undefined" - 并不会报错
  if (true) {
    var value = 1;
  }
  return value;              // 1 - 在 if 块外仍可访问
}

// let: 块级作用域
function letScope() {
  if (true) {
    let value = 1;
    console.log(value);      // 1
  }
  // console.log(value);     // ReferenceError: value is not defined
}

console.log(varScope());     // 1
letScope();

理解作用域时需要记住的几点：

  • 所有由花括号 { } 包围的块(if、for、while、独立块)都是 let、const 的边界。
  • 内层作用域可以读取外层变量，反过来则不行。
  • 在内层用同名变量再次声明会产生遮蔽(shadowing)，把外层变量挡住。若非有意为之，改个名字更好。
  • 完全省略关键字写成 x = 1，在非严格模式下会创建全局变量。在文件顶部加上 'use strict'，或使用 ES 模块(type="module")，这类失误就会变成报错。

提升与 TDZ(暂时性死区)

JavaScript 引擎在执行代码之前会先处理声明。此时 var 会连同声明一起被初始化为 undefined，所以在声明行之上读取它不会报错，而是得到 undefined。值明明还不存在，程序却继续静默运行，这样的 bug 很难追查。

let 和 const 同样会被提升，但保持未初始化状态。从块的开头到声明行之间的区间称为 TDZ(Temporal Dead Zone，暂时性死区)，在这段区间访问会抛出 ReferenceError。相比静默地使用错误的值，当场报错要安全得多。

// var: 整个循环共享一个变量 → 3, 3, 3
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log('var:', i), 0);
}

// let: 每轮迭代都会创建新的绑定 → 0, 1, 2
for (let j = 0; j < 3; j++) {
  setTimeout(() => console.log('let:', j), 0);
}

这段示例最清楚地展示了 var 与 let 的差异会造成怎样的结果差别。var i 在整个循环中共享同一个变量，回调执行时它已经变成 3。let j 每轮都会创建独立绑定，所以每个回调都记住了自己那一轮的值。过去要用立即执行函数来绕开这个问题，如今只要使用 let 就自然解决了。

const 能挡住什么，挡不住什么

const 的含义不是「值不会变」，而是「不能给这个变量名重新赋另一个值」。用 const 声明对象或数组时，内部的属性和元素依然可以随意修改。想连内容一起冻结需要 Object.freeze()，而它也只冻结一层，属于浅冻结。

const config = { retry: 3 };
config.retry = 5;             // OK - 对象内部的值可以修改
console.log(config.retry);    // 5

// config = { retry: 5 };     // TypeError: Assignment to constant variable.

const frozen = Object.freeze({ retry: 3 });
frozen.retry = 5;             // 非严格模式下会被静默忽略
console.log(frozen.retry);    // 3

总结起来，const 锁定的是绑定，Object.freeze() 锁定的是对象的表层。把两者混为一谈、认为「用了 const 就安全」，就会忽略共享对象在别的函数里被修改的情况。

类型转换：养成显式转换的习惯

JavaScript 在不同类型之间运算时会自动统一类型。看着方便，但规则并不直观，是初学者最容易栽跟头的地方。处理数据时用 Number()、String()、Boolean() 把意图写进代码更安全。

// 字符串 → 数字
console.log(Number("42"));                 // 42
console.log(Number(""));                   // 0    ← 空字符串会变成 0(注意)
console.log(Number("42px"));               // NaN
console.log(parseInt("42px", 10));         // 42   ← 从头能读多少就读多少
console.log(Number.parseFloat("3.14abc")); // 3.14

// 数字 → 字符串
console.log(String(42));       // "42"
console.log((42).toString(2)); // "101010"  ← 二进制字符串

// 隐式类型转换的陷阱
console.log(1 + "2");  // "12"  只要一边是字符串，+ 就变成拼接
console.log("3" - 1);  // 2     - 会先把字符串转成数字
console.log([] + {});  // "[object Object]"
  • 使用 parseInt() 时养成传入第二个参数(进制)的习惯，写成 parseInt("08", 10) 意图才明确。
  • 用户输入值(input.value)永远是字符串。做数值计算前一定要用 Number() 转换。
  • 只有 + 会当作字符串拼接，-、*、/ 都会尝试数字转换。这种不对称正是 "3" - 1 === 2 而 1 + "2" === "12" 的原因。
  • 判断是否为数字请用 Number.isNaN() 和 Number.isFinite()。全局的 isNaN() 会先把参数转成数字再判断，所以 isNaN("abc") 为 true。

truthy 与 falsy，以及 ?? 运算符

放进条件语句时表现得像 false 的值称为 falsy，其余所有值都是 truthy。falsy 值恰好只有八个，整体背下来会很方便。

falsy 值含义容易混淆的 truthy 值
false布尔假值"false"(非空字符串)
0数字零"0"(非空字符串)
-0负零[](空数组)
0nBigInt 零{}(空对象)

const falsyValues = [false, 0, -0, 0n, "", null, undefined, NaN];
console.log(falsyValues.every(v => !v)); // true - 八个全是 falsy

// || 会过滤掉所有 falsy 值，连 0 和 "" 也一并替换
const count1 = 0 || 10;  // 10 ← 通常不是你想要的结果

// ?? 只在 null 或 undefined 时才替换 (ES2020)
const count2 = 0 ?? 10;  // 0  ← 才是想要的结果

console.log(count1, count2); // 10 0

用 || 写「没有值就用默认值」的逻辑时，数字 0 或空字符串这类正常但 falsy 的值也会被默认值覆盖。空值合并运算符 ?? 只针对 null 和 undefined，可以避免这类事故。

运算符与比较：用 === 取代 ==

相等比较 == 在两边类型不同时会先转换其中一边再比较。这套转换规则相当复杂、结果难以预测，是 JavaScript 代码中最常见的逻辑 bug 来源。严格相等 === 只要类型不同就立即返回 false，需要记住的规则只有一条。没有特殊理由的话，请始终使用 === 和 !==。

0 vs ""truefalse空字符串被转换成 0
0 vs falsetruefalse布尔值被转换成数字 0
[] vs falsetruefalse按 [] → "" → 0 依次转换
null vs undefinedtruefalse== 只认为这两者相等
null vs 0falsefalsenull 除 undefined 外与谁都不等

{a:1} vs {a:1}falsefalse对象按引用而非内容比较
 
console.log(1 == "1");            // true  - 字符串被转换成数字
console.log(1 === "1");           // false - 类型不同就一定是 false
console.log(null == undefined);   // true
console.log(null === undefined);  // false
console.log([] == false);         // true  - [] → "" → 0
console.log(0 == "");             // true

console.log(NaN == NaN);          // false - NaN 连自己都不等于
console.log(Number.isNaN(NaN));   // true  - 正确的判断方式
console.log(Object.is(NaN, NaN)); // true  - Object.is 认为 NaN 相等

使用比较运算符时还需要记住这几点。

  • == 唯一有用的场景是 value == null，这是同时检查 null 和 undefined 的简写，被广泛使用。其余情况请用 ===。
  • 对象和数组即使用 === 比较，也只检查引用是否相同。需要比较内容时要逐个属性比较或另写函数。
  • 判断 NaN 请用 Number.isNaN() 或 Object.is()。x === NaN 永远是 false。
  • <、> 这类大小比较与 === 不同，仍会执行类型转换。比较前先用 Number() 统一更安全。

条件语句与循环 (Conditionals and Loops)

条件语句划分程序的流程，循环把同一处理应用到多个值上。条件只有两个分支时用 if...else，要判断一个值属于多个候选中的哪一个时用 switch，只是结果值不同时用三元运算符更易读。

const score = 87;

// if / else if / else
if (score >= 90) {
  console.log("A");
} else if (score >= 80) {
  console.log("B");   // ← 这一行会执行
} else {
  console.log("C");
}

// 三元运算符：选择值时更简洁
const grade = score >= 80 ? "合格" : "不合格";

// switch：漏掉 break 就会向下贯穿
switch (grade) {
  case "合格":
    console.log("恭喜");
    break;
  default:
    console.log("重考");
}

如何选择循环

循环种类不少，但实际常用的只有几种。基本原则是：遍历数组的值用 for...of，遍历对象的键用 for...in。两者名字相近容易混淆，请把用途分清楚。

const scores = [90, 75, 88];

// for...of : 遍历值(推荐用于数组)
for (const s of scores) {
  console.log(s);        // 90, 75, 88
}

// for...in : 遍历键(用于对象，不推荐用于数组)
const user = { name: "张三", age: 25 };
for (const key in user) {
  console.log(key, user[key]);  // name 张三 / age 25
}

// 想同时拿到索引和值就用 entries()
for (const [i, s] of scores.entries()) {
  console.log(i, s);     // 0 90 / 1 75 / 2 88
}

// while: 事先不知道循环次数时
let n = 3;
while (n > 0) {
  n--;
}
  • for...in 用在数组上会把索引以字符串形式返回，还会遍历原型链上的属性，所以不要用于数组。
  • 循环变量默认用 const 声明。for...of 每轮都会创建新绑定，只要不重新赋值，const 就够用。
  • break 会完全中断循环，continue 只跳过当前这一轮。
  • forEach() 内部无法使用 break。需要中途退出时请改用 for...of，或借助 some()、every()。
  • 如果目的是「转换」或「筛选」数组，用 map()、filter() 比手写循环更能表达意图。

English: Functions are important concepts that enhance code reusability.

// 函数声明 (Function Declaration)
function add(a, b) {

默认参数、剩余参数与箭头函数的 this

ES2015 添加了不少让函数写起来更简洁的语法。默认参数、剩余参数和模板字面量几乎出现在所有现代代码中，值得现在就掌握。

// 默认参数 (ES2015)
function greet(name, greeting = "你好") {
  return `${greeting}，${name}`;   // 模板字面量
}
console.log(greet("张三"));        // "你好，张三"

// 剩余参数：把数量不定的实参收集成数组
function sum(...numbers) {
  return numbers.reduce((acc, n) => acc + n, 0);
}
console.log(sum(1, 2, 3, 4));    // 10

// 箭头函数没有自己的 this，直接使用外层的 this
const timer = {
  label: "计时器",
  startArrow() {
    setTimeout(() => console.log(this.label), 0);            // "计时器"
  },
  startFunc() {
    setTimeout(function () { console.log(this.label); }, 0);  // undefined
  }
};
timer.startArrow();
timer.startFunc();
  • 需要在回调里沿用外层对象的 this 时，就选箭头函数。以前常写的 const self = this 和 .bind(this) 都不再需要。
  • 反过来，定义对象方法时不要用箭头函数，因为 this 不会指向该对象。使用简写方法语法(startArrow() { })才是正确做法。
  • 箭头函数的函数体如果是单个表达式，可以省略花括号和 return。一旦写了花括号，就必须写 return。
  • 想直接返回对象字面量要加括号，写成 () => ({ id: 1 })，否则花括号会被当成函数体。

数组与循环 (Arrays and Loops)

使用数组和循环可以高效地处理数据。

// 数组声明
const fruits = ["사과", "바나나", "오렌지"];

// for 循环
for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}

// forEach 方法
fruits.forEach(fruit => {
  console.log(fruit);
});

// map 方法 (返回新数组)
const fruitLengths = fruits.map(fruit => fruit.length);

实际项目中处理数组时，用数组方法的频率远高于 for 循环。因为「想做什么」直接体现在方法名上，读代码的速度会更快。按常用程度整理如下。

  { name: "显示器", price: 300000 }
];

// filter: 把符合条件的元素放进新数组
const cheap = products.filter(p => p.price < 100000);
console.log(cheap.length);   // 2

// map: 转换每个元素
console.log(products.map(p => p.name));  // ["键盘", "鼠标", "显示器"]

// reduce: 归约成一个值(第二个参数是初始值)
const total = products.reduce((acc, p) => acc + p.price, 0);
console.log(total);          // 370000

// find / some / every
console.log(products.find(p => p.price > 100000).name); // "显示器"
console.log(products.some(p => p.price > 100000));      // true
console.log(products.every(p => p.price > 10000));      // true

会改变原数组的方法与不会改变的方法

数组方法最容易出事故的地方，就是分不清哪些方法会直接修改原数组。sort()、reverse()、splice()、push() 会改动原数组，而 map()、filter()、slice()、concat() 会生成新数组。ES2023 新增的 toSorted()、toReversed()、toSpliced()、with() 则是做同样的事却不碰原数组的复制版。

const nums = [3, 1, 2];
const sorted = nums.sort((a, b) => a - b);
console.log(nums, sorted === nums);  // [1,2,3] true ← 原数组被改了

// toSorted 保留原数组并返回新数组 (ES2023)
const base = [3, 1, 2];
const copy = base.toSorted((a, b) => a - b);
console.log(base, copy);             // [3,1,2] [1,2,3]

// 数字排序若不传比较函数，会按字符串排序
console.log([10, 9, 100].sort());               // [10, 100, 9]  ← 陷阱
console.log([10, 9, 100].sort((a, b) => a - b)); // [9, 10, 100]

默认的 sort() 会把每个元素转成字符串后按字典序排列，所以 [10, 9, 100] 会变成 [10, 100, 9]。排序数字时必须传入比较函数 (a, b) => a - b。

操作对象 (Objects)

对象是 键: 值 对的集合，用来把一个事物的多个属性组织在一起。掌握 ES2015 之后新增的解构赋值和展开运算符，处理对象的代码会明显变短。

const user = { name: "张三", age: 25, address: { city: "北京" } };

// 解构赋值 (ES2015)
const { name, age } = user;
console.log(name, age);            // 张三 25

// 用展开运算符复制并覆盖部分字段(原对象不变)
const updated = { ...user, age: 26 };
console.log(updated.age, user.age); // 26 25

// 可选链 (ES2020)：中间层不存在时返回 undefined 而不报错
console.log(user.address?.city);    // "北京"
console.log(user.company?.name);    // undefined

// 遍历键 / 值
console.log(Object.keys(user));     // ["name", "age", "address"]
Object.entries({ a: 1, b: 2 }).forEach(([k, v]) => console.log(k, v));
  • 解构赋值也可以用在函数参数上。写成 function f({ name, age }) { } 就不必记住参数顺序了。
  • 展开运算符 ... 在对象和数组上都能用于复制与合并，后面的值会覆盖前面的值。
  • 可选链 ?. 在读取 API 响应这类可能存在也可能不存在的嵌套数据时特别有用。
  • Object.keys()、Object.values()、Object.entries() 会把对象转成数组，之后可以直接接上数组方法。
  • 要用变量作为键就使用方括号写法：obj[key] 取的是变量的值，而 obj.key 取的是字面量 "key"。

浅拷贝与深拷贝

展开运算符和 Object.assign() 都是浅拷贝：只重建一层，里面的对象和数组仍指向原来的那一份。这正是拷贝嵌套数据后修改内层会连原数据一起改变的原因。

const original = { name: "张三", tags: ["a", "b"] };

const shallow = { ...original };
shallow.tags.push("c");
console.log(original.tags);   // ["a","b","c"] ← 原对象也被改了

const deep = structuredClone(original);  // 深拷贝(现代浏览器、Node 17+)
deep.tags.push("d");
console.log(original.tags.length, deep.tags.length); // 3 4

需要真正的深拷贝时，使用标准内置函数 structuredClone() 最为简单。过去常用的 JSON.parse(JSON.stringify(obj)) 会把 Date 变成字符串，并丢失 undefined、函数、Map 和 Set，因此不推荐。

异步基础：Promise 与 async/await

JavaScript 运行在单线程上，一次只做一件事。为了在等待网络请求这类耗时操作时页面不被卡住，这类操作采用「做完了再通知我」的方式处理。表示这种待定结果的对象就是 Promise，而让 Promise 读起来像同步代码的语法就是 async/await。

function delay(ms, value) {
  return new Promise(resolve => setTimeout(() => resolve(value), ms));
}

// 后一步需要前一步的结果 → 顺序执行(约 100ms)
async function runSequential() {
  const a = await delay(50, "A");
  const b = await delay(50, "B");
  return a + b;
}

// 彼此独立 → 并行执行(约 50ms)
async function runParallel() {
  const [a, b] = await Promise.all([delay(50, "A"), delay(50, "B")]);
  return a + b;
}

// 用 try/catch 捕获错误
async function safeRun() {
  try {
    return await delay(10, "ok");
  } catch (err) {
    console.error("失败:", err);
    return null;
  }
}

runSequential().then(r => console.log("sequential:", r)); // "AB"
runParallel().then(r => console.log("parallel:", r));     // "AB"
safeRun().then(r => console.log("safeRun:", r));          // "ok"
  • await 只能写在 async 函数内部(ES 模块顶层除外)。写在普通函数里会产生语法错误。
  • async 函数永远返回 Promise。即使 return 一个普通值，调用方也要用 await 或 .then() 取出。
  • 把互不依赖的请求用 await 一行行排开会白白变慢。这种情况请用 Promise.all() 打包。
  • 异步函数的错误用 try/catch 捕获。若使用 .then() 链，务必在最后加上 .catch()。

初学者常犯的 12 个错误

下面这些问题，初学 JavaScript 的人几乎都会遇到至少一次。事先了解可以大幅减少调试时间。

  1. 用 === 比较 NaN。 NaN === NaN 是 false。请用 Number.isNaN(x) 或 Object.is(x, NaN)。
  2. 以为 0.1 + 0.2 === 0.3 为 true。 浮点数机制导致实际值是 0.30000000000000004。请设定容差比较，或按整数单位计算。
  3. 习惯性使用 ==。 0 == ""、[] == false 都为 true，很难预测。请把 === 作为默认。
  4. 把对象方法定义成箭头函数。 箭头函数没有自己的 this，作为对象方法时读不到想要的值。反之在回调里箭头函数才是正解。
  5. 把异步结果当同步读取。 fetch() 的下一行还没有值。请用 await 等待，或在 .then() 内处理。
  6. 直接使用 async 函数的返回值。 控制台打印出 Promise { <pending> } 就说明漏写了 await。
  7. 给数字数组调用 sort() 却不传比较函数。 会按字符串排序得到 [10, 100, 9]。请传入 (a, b) => a - b。
  8. 在 map() 回调里漏写 return。 带花括号的箭头函数若没有显式 return，得到的会是一个填满 undefined 的数组。
  9. 用 === 比较对象或数组的内容。 引用不同时，内容相同也是 false。请逐个属性比较。
  10. 把浅拷贝当成深拷贝。 { ...obj } 只复制一层。嵌套结构请用 structuredClone()。
  11. 直接对字符串做运算。 "5" + 3 是 "53"。请先用 Number() 转换再计算。
  12. 用 || 指定默认值。 值为 0 或空字符串时也会被默认值覆盖。请改用 ??。
// 错误 2：浮点数
console.log(0.1 + 0.2);          // 0.30000000000000004
console.log(0.1 + 0.2 === 0.3);  // false

const almostEqual = (a, b) => Math.abs(a - b) < Number.EPSILON;
console.log(almostEqual(0.1 + 0.2, 0.3)); // true

// 金额按最小单位的整数计算后再相除更安全
console.log((0.1 * 10 + 0.2 * 10) / 10);  // 0.3

// 错误 8：map 回调里没有 return
console.log([1, 2, 3].map(n => { n * 2; }));      // [undefined, undefined, undefined]
console.log([1, 2, 3].map(n => n * 2));          // [2, 4, 6]

这些错误大多源于过度信任「JavaScript 会自动帮你处理」的行为。养成把类型转换和引用复制显式写进代码的习惯，一半以上都会消失。

常见问题 (FAQ)

JavaScript中如何声明变量?

可以使用 var、let、const 关键字声明变量。这三者各有不同特性，需要根据场景选择。按实务标准，默认用 const，只有需要重新赋值时才用 let，而 var 因为函数作用域和提升带来的问题，在新代码中不再使用。

JavaScript有哪些基本数据类型?

有字符串(String)、数字(Number)、布尔值(Boolean)、null(没有值)、undefined(未赋值)、对象(Object)，以及唯一且不可变的数据类型 Symbol。再加上处理大整数的 BigInt，原始类型共有 7 种，只有对象是按引用处理的。typeof null 返回 "object" 是语言早期的缺陷，因此要用 === null 判断。

为什么函数在JavaScript中是重要的概念?

函数是提高代码复用性的重要概念。把重复的逻辑写成函数，需要时随时调用即可。而且在 JavaScript 中函数本身就是值，可以存进变量、作为参数传递，这正是 map()、filter() 等高阶函数和事件回调的基础。

数组和循环各自起什么作用?

使用数组和循环可以高效地处理多条数据：把逐个处理会很麻烦的数据放进数组，再用循环遍历处理。不过如果目的是转换或筛选数据，map()、filter()、reduce() 这类数组方法比手写 for 循环更能表达意图。

掌握JavaScript基本语法后能做什么?

如文中所述，掌握 JavaScript 的基本语法后就能开发各种 Web 应用程序，而变量、数据类型、函数、数组和循环正是起点。之后再学会 DOM 操作和 fetch，就能做出真正可用的网页；继续推进到模块和类，就能自然过渡到框架的学习。

掌握 JavaScript 的基本语法后，你就能开发各种 Web 应用程序了。
