売上の82%は小売、営業利益の57%はAWS - アマゾンの本体を開示資料で分解した

同じ会社を売上で見れば流通業、営業利益で見ればクラウド企業になる

2026-07-31 金融・経済

はじめに: 売上ランキングだけで判断するとこの会社を読み違える

世界の企業を売上高で並べた表にアマゾンを探すと、いつも上位にある。そしてその表の業種欄にはたいてい流通あるいは電子商取引と書かれている。売上だけを見るなら間違った分類ではない。

ところが同じ会社の営業利益を同じやり方で分けると、表がひっくり返る。お金が入ってくる通路と、お金が残る通路が別の場所にあるからだ。このずれがこの記事のすべてだ。

まず結論から書く。アマゾンが自ら開示したセグメント表を開いて計算すると、こうなる。

  • 2025年度(12か月、2025年12月31日終了)基準でAWSは売上の17.96%を占め、営業利益の57.03%を生んだ
  • 同じ期間、北米と海外を合わせた残りは売上の82.04%だったが、営業利益は42.97%にとどまった
  • つまりよく引用される「売上18%、利益57%」という一文は2025年度基準では正確だ
  • ところが2026年第2四半期(3か月、2026年6月30日終了)で見ると、同じ比率が売上21.05%、営業利益60.53%へ動いていた
  • だからこの一文を使うときはどの期間かを必ず添えなければならない。期間が抜けた比率は四半期ごとに少しずつずれていく

この記事の性格について。この記事は開示された数字の構造を説明する情報提供目的の文書だ。特定銘柄の買いや売り、目標株価、投資比率についての勧誘ではなく、今後の株価や業績を予測しない。投資判断とその結果についての責任はすべて投資家本人にある。以下のすべての数字は会社が発表した資料から写したもので、比率はその数字から直接計算した。計算過程を本文にそのまま書いておいたので読者が検算できる。

アマゾンの流通戦略そのものを競合と比べる話はコストコはアンチ・アマゾンだで別に扱い、AWSを使う側で料金がどう膨らむかはAIエージェントの6,531ドルのAWS請求書にある。この記事はその二つを繰り返さず、事業部別の収益構造を分解する一点だけを扱う。

2. なぜこの構造が生まれるのか

比率だけを並べると神秘的に見える。ところが二つの事業の費用のつき方を見れば当然の結果だ。

最も直観的な表現はこれだ。営業利益1ドルを作るのに必要な売上を計算してみた。

2026年第2四半期基準、営業利益1ドルを作るのに必要な売上

北米    116,177 / 9,123  = 12.73 ドル
海外     42,197 / 1,717  = 24.58 ドル
AWS      42,232 / 16,621 =  2.54 ドル

海外部門は24.58ドル分を売って1ドルが残る。AWSは2.54ドルで足りる。同じ会社の中で一桁の倍数ではなく10倍近い差がつく。理由はこうだ。

  • 小売は売上が増えれば費用も一緒に増える。商品を一つ多く売れば、その仕入原価がそのままついてきて、梱包材と保管スペースと配送人件費と返品処理費用が後ろにつく
  • その費用の大半が人と物理的な移動に縛られている。物流センターを自動化しても最後の配送区間は依然として人と車両が動く必要がある
  • クラウドは先に建てて後から埋める構造だ。データセンターとサーバーは顧客が来る前にすでに建っていて、その上に顧客を乗せる
  • だからすでに敷かれた設備の稼働率が上がれば追加売上にかかる費用の比率が下がる。サーバー1台に顧客が1つでも10でも、電力と冷房と建物は大きく変わらない
  • ただしこれは永久の法則ではない。上の表で見たとおりAWSの営業利益率は2024年度の37.04%から2025年度の35.43%へ下がったことがある。設備を新しく建てればその設備が埋まるまでは費用が先に増える
  • 逆に海外部門の営業利益率は上がった。2024年度の2.65%から2025年度の2.93%になった。マージンの低い事業だからといって改善しないわけではない

まとめると売上規模と利益貢献がずれるのは事業の優劣ではなく費用構造の違いだ。売上の82%を担う側が会社を回す物理的基盤であり、利益の57%を作る側がその上に乗った別の性質の事業だ。

3. 広告事業が表に見えない理由

アマゾンの話をすると必ず「広告が隠れた稼ぎ頭だ」という言葉が出る。その言葉のどこまでが開示で確認され、どこからが推定なのかを正確に分けるのがこの節の目的だ。

ここからが核心だ。売上は二通りの方法で分けて開示するが、営業利益はセグメント区分でしか分けない。営業利益の表には北米、海外、AWSの三行しかない。広告サービスという行自体がない。したがって次が成り立つ。

  • 広告サービスの売上は開示で確認できる。2026年第2四半期に198億900万ドルで、全体売上の9.87%だ
  • 広告サービスがサブスクリプションサービスより大きい売上項目であることも開示で確認できる。198億900万ドル対137億3,000万ドルだ
  • しかし広告事業の営業利益も営業利益率も開示にない。その売上にどれだけの費用がかかったかが別に報告されないからだ
  • 広告売上はセグメント表の中では北米と海外の行に溶け込んでいる。その配分の内訳はこの記事で確認できなかった
  • したがってネット上で見る「アマゾン広告部門の利益率は何パーセント」という数字は外部推計であり、開示から導かれた値ではない。この記事はその推定をしない

この区別がなぜ重要か。売上は大きく目に見えるのに利益が報告されない項目があると、人はその空欄を自分が信じたい数字で埋める。広告が高マージンだろうという推論自体は合理的かもしれない。サーバーに広告をもう一度表示する費用が、商品をもう一個配送する費用より低いだろうという推測は常識に合う。しかし合理的な推論と確認された事実は別のものであり、表にない欄を埋めた数字に開示という権威を貸してはならない。この記事で広告の利益率を書かない理由がそれだ。

4. 地域区分 - 北米、海外、そしてAWSという非対称

事業部の区分をもう一度見ると妙な点が目につく。二つは地域名なのに一つは事業名だ。北米と海外は地理的な区分で、AWSはサービスの区分だ。この非対称が表を読むときに混乱を生む。

  • 北米と海外は地域で分けられた小売中心の事業部だ。ここに各地域の広告とサブスクリプションの売上も混ざって入る
  • AWSは地域と無関係に一行にまとめられる。アジアの顧客が使うAWSの売上も海外部門ではなくAWSの行に入る
  • だから「海外部門」をアマゾンの国際事業全体と読むと間違う。国際事業のうちクラウドはすでに抜かれている
  • 同じ理由で「北米部門」も米国事業の全体ではない。米国顧客のAWS売上はAWSの行にある

海外部門の収益性は三つの事業部で最も低い。ただし方向は改善の側だ。確認した値を並べるとこうなる。

5. 設備投資と減価償却 - 支出と費用の時差

最近の業績の話には人工知能関連の設備投資が欠かせない。ここで必ず押さえるべき会計構造が一つある。お金が出ていく時点と費用として計上される時点が違うということだ。

  • サーバーやデータセンターを買うのに使った現金はキャッシュフロー計算書の投資活動にその時点の全額が出ていく
  • しかし損益計算書にはその支出が一度に入らない。資産の耐用年数にわたって減価償却費として分けられ複数の期間に配分される
  • そのため設備投資を大きく増やした四半期の営業利益にはその支出の一部しか反映されず、残りは以降の期間の費用として予約される
  • 結果として営業利益と現金支出は互いに違う絵を見せる。片方だけを見ると会社の資金事情を読み違える
  • この構造のため設備投資が利益率に及ぼす影響は時差を置いて到着する。いつどれだけ到着するかは資産の種類と耐用年数の仮定にかかっていて、その仮定は会社が定める

確認した数字は二つだ。ところがこの二つは定義が異なるため直接比較してはならない。この落とし穴が多いので表で分けた。

純利益の数字に注意すべき理由。2026年第2四半期の純利益は626億4,700万ドルと発表され、これは前年同期の181億6,400万ドルの3倍を超える。しかし会社はこの四半期の純利益に営業外の税引前その他収益534億ドルが含まれ、その大部分が特定の投資から生じたと併せて明らかにしている。つまり純利益の大きな部分が本業の営業成果ではない。この記事が純利益ではなく営業利益だけで事業部を比較した理由がここにある。事業構造を見るには営業段階で切る必要がある。

6. 海外の投資家が見落としやすい層

ここまでの表はすべてドル建ての会社の数字だ。米国の外に住む投資家にとっては、その表の外側にさらに層がある。順に押さえる。

6.1 通貨

  • すべての業績はドルで報告される。自国通貨に換算した瞬間為替という変数が結果に割り込む
  • 会社の業績がドル基準で良くなっても換算結果は為替の方向によって変わりうる。逆もまた同じだ
  • この記事が換算額を一度も書いていない理由がこれだ。換算に使う為替の基準時点を明かさない金額は意味がぼやける
  • 換算が必要なら米ドル為替計算機のように基準時点を自分で決めて計算するほうがよい

6.2 税

ここは公式資料で確認したものと確認できなかったものを厳密に分けて書く。

  • 全体像。外国株の譲渡益への課税は上場国ではなく投資家の居住国の制度で決まる。だから重要なのは自分が申告する国のルールだ
  • 国によって異なるもの。申告期限、予定申告の要否、基礎控除、税率、損益通算の可否がいずれも異なる
  • ある国のルールは他国に移らない。他人が申告する国で通用する控除額や税率は、自分の状況について何も語らない。別の国向けに書かれた記事から数字を持ち出さないこと
  • ある国について確認したこと。韓国の国税庁の案内によれば、外国株は予定申告なしに翌年5月の確定申告で申告し、基礎控除は国内株と国外株を合算して年250万ウォン、税率は20%で、同じ課税期間の譲渡差損と差益は通算できる
  • 確認できなかったこと。その税率に加えて地方所得税が別途課されるかは一次資料で確定できなかった。制度の確認が必要だ
  • 確認できなかったこと。為替差益が課税標準にどう反映されるかの具体的な計算方法も確定できなかった。制度の確認が必要だ
  • 確認できなかったこと。配当を受け取った場合の課税方法もこの記事の確認範囲の外だ。制度の確認が必要だ

確認できなかった項目をもっともらしく埋めるより、空欄のまま残して直接確認せよと書くほうが正確だ。税は制度が変わり、変わった事実を知らないまま古いルールで計算すれば実際の損が出る。申告前に税務当局の案内や専門家に確認する手順を飛ばさないことが安全だ。

6.3 配当と時差

  • 配当の支払いの有無と方針はこの記事で確認できなかった。会社の投資家情報ページや年次報告書の配当関連項目で直接確認する必要がある
  • 配当のない銘柄なら保有期間中に現金の流れが発生しない。配当を前提にした資金計画は成り立たない
  • 決算発表は米国市場の取引終了後に出る。他の時間帯ではたいてい翌日未明だ。今回の2026年第2四半期の資料も米国基準で7月30日に公開された
  • だから海外の投資家は発表直後の時間帯に市場へ接近しにくい。情報を確認する時点と対応できる時点の間に構造的な隔たりがある
  • 時間外取引の経路があっても取引条件が通常の取引時間とは異なる。条件は利用する場所で直接確認する必要がある

7. 「利益が一か所から出る」をどう読むか

ここまでが確認された事実だ。残るのはその事実をどう読むかの問題だ。結論から言えばこの構造は良いものでも悪いものでもなく両刃だ。

同じ事実こう読むこともできるしこう読むこともできる
営業利益の60.53%が一つの事業部から出る(2026年第2四半期)現金を生むエンジンが確かだその一か所が揺れれば全社の利益が揺れる
営業利益の増加分の77.94%が一つの事業部から出た(前年同期比)成長の方向がはっきりしている成長の根拠が一つの軸に偏っている
売上の78.95%がマージンの薄い事業だ(2026年第2四半期)利益貢献が大きくなる余地がある規模に比べて利益の回収が遅い
設備投資が大きく増えている需要に応える基盤を先に作る費用が時差を置いて到着する
広告の売上は大きいが利益は開示されない表に出ない貢献があるかもしれない確認できないものは計算に入れられない

表の二つの列はどちらも同じ数字から出る。どちらに読むかは数字が決めてくれない。したがってこの記事が言えるのはここまでだ。

  • 集中は危険でもあり強みでもある。利益が一か所に集まっているという事実自体は中立で、その事業部がどんな状況に置かれるかによって逆方向に作用する
  • 比率は分子と分母が一緒に動く。AWSの比率が上がるのはAWSが大きくなったからかもしれないし、他部門の利益が減ったからかもしれない。比率だけを見てもどちらかは分からない
  • だから比率と絶対金額を常に一緒に見る必要がある。この記事の表に比率と金額を並べて書いた理由だ
  • 一四半期の値で趨勢を断定しないこと。1節で見たとおりAWSの営業利益比率は一年の間に下がったことがある
  • 確認されていない欄を埋めないこと。広告の利益率のように表にない値を入れて計算すれば、その計算の結論は開示ではなく仮定に依存することになる

もう一度明らかにする。この記事は開示資料の構造を説明する情報提供目的の文書であり、特定の銘柄や金融商品の買いまたは売りを勧めない。目標株価や投資比率についての意見も示さず、将来の株価と業績を予測しない。投資判断とそれに伴う結果についての責任はすべて投資家本人にある。数字は発表時点基準であり後に訂正されうるので、実際の判断に使うときは原本の開示を直接確認してほしい。

8. 自分で確認する方法 - どの表を開くべきか

この記事の数字をそのまま信じる必要はない。同じ表を直接開く経路を書いておく。これがこの記事で最も長く役に立つ部分かもしれない。

  1. 会社の投資家情報ページへ行く。四半期の決算資料が集まっている項目を探す
  2. 該当四半期の決算発表資料を開く。本文の要約ではなく後ろについている財務諸表の部分へ下りる
  3. セグメント情報という見出しの表を探す。ここにだけ事業部別の営業利益がある。前の要約にはない
  4. 同じ文書で売上の補足情報の表を探す。ここに商品・サービス種類別の売上がある。営業利益はここにない
  5. より詳しい会計方針と注記が必要なら四半期報告書と年次報告書を見る。決算発表資料より後に出るが内容がより詳細だ

表を開いたとき必ず確認することはこうだ。

  • 期間の定義。3か月か6か月か12か月か、終了日はいつか。同じ文書に複数の期間の列が並んでいて違う列を読みやすい
  • 単位。たいてい百万ドル単位だ。億ドルや他通貨に移し替えるとき桁の事故が最も多く起きる
  • 合計の検算。事業部別の値を足して連結合計と同じか確認する。この記事では四つの期間すべてがこの検算を通った。合計が合わなければ書き写す過程で誤っている
  • 営業利益と純利益の区別。純利益には営業外の項目が混ざる。事業構造を見るときは営業利益で切る
  • 純額か総額か。設備投資のように売却代金を差し引いた純額で表示される項目がある。定義の違う値を引いて増減を作ってはならない
  • 直近12か月基準か会計年度基準か。補足指標には直近12か月基準の値がよく出る。会計年度の値と混ぜて使ってはならない

四半期ごとに変わるものも前もって知っておくとよい。

  • 事業部の区分自体が変わりうる。会社が報告区分を再編すれば過去の数値も新しい区分で表示し直され、そうなると以前の記事に引用された比率とずれる
  • 商品・サービス種類別の項目名も変わりうる。項目が統合されたり分割されたりすると時系列の比較が途切れる
  • 季節性がある。年末商戦を含む四半期とそうでない四半期では小売部門の姿が違う。四半期を比べるときは前年の同じ四半期と比べるのが基本だ
  • 比較基準の数値が訂正されうる。過去期間の数値が調整されれば増減率も一緒に変わる

9. この記事が確認できなかったこと

正直に残す。確認できなかったことを明かすのも資料の一部だ。

  • 2025年度の商品・サービス種類別の売上内訳。開いた資料で項目の値を合算したとき年度合計と一致しなかったため信頼できないと判断してこの記事から外した。2026年第2四半期の内訳は合計が正確に合ったのでそれだけを使った
  • 広告売上が北米と海外の事業部にどう配分されるか。配分の内訳が開示に別途示されておらず、この記事では確認できなかった
  • 減価償却の期間別の反映規模と耐用年数の仮定。注記レベルの情報が必要でこの記事の確認範囲を超えた
  • 地方所得税、為替差益の課税計算方法、配当の課税方法。6節に書いたとおり制度の確認が必要だ
  • 配当の支払いの有無と方針。会社の投資家情報ページで直接確認する必要がある
  • 2026年第3四半期以降の見通し。会社が示す見通し値があってもこの記事は将来の業績を扱わない

最後にこの記事の方法論を一行で要約するとこうだ。数字は会社が発表した資料からのみ持ってきて、比率はその数字から直接計算し、計算過程を本文に書いて検算できるようにし、確認できなかったものは確認できなかったと書いた。投資情報を読むときにこの四つが守られているかを確認する習慣が、どの個別の数字を覚えるよりも長く役に立つ。
