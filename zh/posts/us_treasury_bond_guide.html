美国国债是避险资产为何还会亏损 - 利率、价格、久期与汇率

违约概率低和价格不动是两个不同的说法。本文用计算把这个差距撑开

2026-08-01 金融与经济

引言：安全这个词到底指什么

美国国债被称作避险资产。可是在真正买过的人当中，流传的却是相反的说法：打开账户一看是负数。两种陈述看似矛盾，其实说的是两件不同的事。「安全」问的是发行人会不会按承诺还钱，「亏了」问的是今天在市场上能卖多少钱。这两者本来就不是同一条轴。

本文的论点可以压缩成三句话。

  • 「国债安全」指的是违约概率低，不是价格不动。信用风险和市场风险各自独立存在
  • 亏损大多发生在到期前卖出的时候。持有到期，按名义口径就能拿到承诺的现金流
  • 亏损的大小由久期决定。同样1个百分点的利率变动，对30年期的作用是2年期的八倍以上。而以韩元为本位的投资者还要多背一条汇率的轴

本文把这套算术追到底。「利率上行债券价格下跌」这句话到处都能看到，但把跌多少用数字说清楚的文章很少。所以我直接写了一个计算器跑出结果，再把数字搬进表格。如果还需要先了解债券是什么，请先看债券投资入门和公司债投资。这里不再重复基础，只挖美国国债的价格变动结构这一点。

1. 避险资产为何还会亏损 - 信用风险与价格风险

先把词分开。持有债券的人亏钱的路径大体有两条，这两条的成因和应对完全不同。

  • 信用风险。发行人无法按承诺支付利息或本金。把美国国债称为避险资产时指的正是这条轴，这里的「安全」说的是市场对发行人偿付能力的评价
  • 价格风险（市场风险）。发行人好端端的，但今天市场给出的价格下来了。国债也是每天交易的资产，因而有价格，而这个价格随市场利率不断移动
  • 这两条轴彼此独立。发行人从未动摇过的债券，价格照样可以跌很多。反过来信用在恶化，却因为利率环境而价格撑住的情形也有

这里出现一个决定性的区分。价格风险只在「卖出时」才被确定。

  • 持有到期。债券有到期日，那天发行人归还面值。中间价格显示成什么样都好，按名义口径承诺的利息和本金都会进账。账户上出现过的浮亏，就作为「过去的数字」留在那里
  • 中途卖出。按当天的市场价格卖。这时浮亏变成实亏。本文讨论的亏损几乎全部走这条路径
  • 不过持有到期不是万能的。拿回名义本金和那笔钱的购买力得以维持是两件事。物价上行，同样金额的实际价值就变少
  • 而且持有到期要能选择才成立。急需用钱就等不了到期。这种情况下，持有到期策略只存在于计划书上

归纳起来是这样。「避险资产却亏损了」不是矛盾，而是用一个词覆盖两条轴的结果。发行人是安全的，只是自己卖出那天的价格低于买入时。那么这个价格为什么会变低？下一节就是那套算术。

2. 利率与价格为何反向而行 - 用算术说

债券的票面利率在发行时点被固定。这一个事实造就了其余的一切。

假设买了一只面值100美元、票面利率年4.00%的债券。它每年给4美元直到到期。如果市场上新发的债券给年5.00%，没有人会用100去买给4美元的那只。可是这只债券的票息由合同固定，不可能从4美元往上调。能动的只有价格。价格下来，用这个降低后的价格买入，持有到期的总收益率与新债拉平，交易就在那个点成交。

计算这个点的公式就是现值加总。美国国债每半年付一次息，所以把期间切成半年为单位。

假设 (为展示计算结构而设的值，不是实际市场利率)
  面值        100
  票面利率    年 4.00% (每半年支付 2.00)
  初始市场利率 年 4.00%
  付息        每年 2 次
  基准时点    2026-08-01 撰写 · 非市场数据

--- 发行时点价格 (票面利率 = 市场利率 → 面值) ---
  2年     价格 100.00
  10年    价格 100.00
  30年    价格 100.00

------------------------------------------------------

10年         8.339           8.176           78.90

票面利率与市场利率相等时，价格正好是面值100。这是起跑线。现在只让市场利率动。其他条件全部固定，时间也不流逝，这样就只剩下利率的纯粹效果。

到这里，「利率上行价格下跌」就有了数字。利率上行1个百分点的瞬间，30年期的理论价格从100降到84.55。此时卖出，15.45%的亏损就被确定下来。而发行人那边什么都没发生。

利率上行2.0个百分点-3.72%-14.88%-27.68%2年期挨3个百分点也不如30年期0.5个百分点疼

最后一行是本文最常被质疑的地方。「国债怎么可能跌37%」这个问题的答案来自算术。在假设条件下发生3个百分点的利率上行，30年期的理论价格就是62.58。这不是预测，只是在给定利率下那串现金流的现值是多少的计算结果。

3. 久期 - 同样1个百分点为何按期限疼得不一样

看第2节的表就会发现面对同样的利率变动，不同期限的反应幅度不同。衡量这个差别的数字就是久期。

久期的直觉是「什么时候拿到钱的重心」。30年期在30年后收回本金100。把那个遥远未来的100折算成今天的价值时，贴现率稍有变化结果就差很多。2年期的本金近在眼前，贴现率没有多少发挥余地。所以期限越长对利率越敏感。

  • 麦考利久期。用各笔现金流的现值加权平均得到的平均回收期，单位是「年」
  • 修正久期。把麦考利久期除以(1 + 到期收益率 / 每年付息次数)，从而可以直接读出利率变动1个百分点价格动多少个百分比
  • 凸性。久期是画在曲线上的切线，变动一大就会偏。凸性就是修正这个偏差的二阶项
  • 票面利率越低久期越长。中途返还的利息少，重心就被推向后面
期限麦考利久期修正久期凸性+1个百分点实际价格变动
2年1.942年1.904年4.62-1.88%
10年8.339年8.176年78.90-7.79%
30年17.728年17.380年420.81-15.45%

有一点值得注意。30年期的久期不是30年，而是17.38年。期限和久期不是同一个量。每半年有票息进来，重心就被往前拉。「30年期嘛，利率动1个百分点大概动30%」是错误的算法，实际大约只有一半。

3.1 只用久期算会偏多少

期限      仅久期        久期+凸性          精确值      久期误差(个百分点)
--------------------------------------------------------------------
2年        -1.90%        -1.88%          -1.88%          0.02
10年       -8.18%        -7.78%          -7.79%          0.38
30年      -17.38%       -15.28%         -15.45%          1.93

--- 同样幅度的上行与下行并不对称 (精确重算) ---
期限     -1.00个百分点   +1.00个百分点        合计
------------------------------------------------
2年        +1.93%         -1.88%           0.05
10年       +8.58%         -7.79%           0.79
30年      +19.69%        -15.45%           4.24

上面这一块同时说明两件事。

  • 久期是近似值。2年期的误差是0.02个百分点可以忽略，但30年期上会拉开到1.93个百分点。只信近似就会把结果估得比实际更糟
  • 加上凸性就几乎对上了。30年期上负17.38%收窄到负15.28%，贴近精确值负15.45%
  • 同样幅度的上下并不对称。30年期上利率下行1个百分点是正19.69%，上行1个百分点是负15.45%。合计为正4.24
  • 这个不对称就是凸性的实体。价格与利率的关系不是直线而是下凸的曲线，因此才会出现。期限越长这个效应也越大
  • 不过不能把这个不对称读成「所以长期债更有利」。这是同一期限内部的方向差异，不是在说不同期限之间的优劣

4. 持有到期会怎样 - 向面值收敛

第1节说过「持有到期按名义口径能拿到承诺的钱」。这一点也可以用计算确认。假设利率上行之后就停在原处不动，只让时间流逝看看。

--- 30年期，利率 +1.00个百分点 上行之后 → 此后利率不变的假设 ---
买入价格                    100.00 (按面值100)
利率 +1.00个百分点 之后的价格  84.55
现在卖出                    -15.45  (-15.45%)
持有到期                    票息 2.00 x 60次 + 面值 100 = 220.00 (名义)

--- 即使利率不变，价格也会向面值收敛 ---
  剩余 30年    价格   84.55
  剩余 25年    价格   85.82
  剩余 20年    价格   87.45
  剩余 15年    价格   89.53
  剩余 10年    价格   92.21
  剩余  5年    价格   95.62
  剩余  2年    价格   98.12
  剩余  1年    价格   99.04
  剩余 0.5年   价格   99.51

这张表展示了「持有到期」的结构。即便利率完全不回头，价格也会从84.55爬回100。因为剩余期间变短，需要贴现的期间也随之减少。这叫作向面值收敛（pull to par）。浮亏随时间自然缩小的原因就在这里。

  • 不过这说的是名义金额。30年后的100美元能不能买到今天100美元买到的东西，是另一个问题
  • 而且机会成本还在。被低票息锁住的这段时间里没能买到新发的高票息债券，这个事实不会消失
  • 持有到期以「能够不卖」为前提。生活资金需要的时点与到期日错开，这个策略就不成立
  • 用没有到期日的结构持有，这种收敛就不会以同样的方式起作用。第8节会再谈

5. 美国国债的种类 - 只写核实过的范围

「美国国债」不是一种东西。期限和付息方式不同的品种有好几种，同一个发行人因为久期不同，对利率的反应也完全不同。以下只搬运在美国财政部TreasuryDirect上核实过的范围。

种类期限（官方表述）付息结构上的利率敏感度
Bills（短期）4周至52周，5种期限无票息。折价发行，到期支付面值最低
Notes（中期）2、3、5、7、10年每六个月付息居中
Bonds（长期）载明另外还提供20年期每六个月付息最高
FRN（浮动利率）仅2年每三个月付息结构上较低
TIPS（通胀挂钩）5、10、30年每六个月，固定利率乘以调整后本金对实际利率反应

表里有两格不能照字面读。关于Bonds，官方页面写的是「now offered in 20-year terms, as well」。也就是说这是在原有期限之上又加了20年期的表述。TIPS页面上可以确认30年期限，所以长端确实存在，但本文不对名义Bonds的完整期限清单下断言。发行日程与最低认购单位在打开过的页面上同样没有，因此列为「待核实」。

5.1 通胀挂钩债券（TIPS）的结构

TIPS的运作方式与其他品种有根本区别。TreasuryDirect说明的结构如下。

  • 本金会动。官方说明是「The principal (called par value or face value) of a TIPS goes up with inflation and down with deflation」。也就是物价上行本金增加，下行本金减少
  • 利率固定，利息金额浮动。「TIPS pay a fixed rate of interest every six months until they mature」，但那个固定利率是乘在调整后本金上的，所以实际收到的利息金额会变
  • 到期时有下限。「If the principal is equal to or lower than the original amount, you get the original amount」。即便通缩把本金压到初始金额之下，到期时仍按初始金额支付
  • 期限为5、10、30年。官方表述是「We sell TIPS for a term of 5, 10, or 30 years」
  • 但这个下限说的是到期时点。并不保证中途卖出的价格在初始金额之上。TIPS在中途卖出时同样承担价格风险

这里顺带纠正一个常见误解。不能把TIPS读成「物价上行也不会亏的债券」。只是本金与物价挂钩，市场给出的价格是对实际利率的变化作出反应。名义债券随名义利率晃，TIPS就随实际利率晃。换了一条轴，价格风险并没有消失。

6. 以韩元为本位的投资者多出的第二条轴 - 汇率

到目前为止的计算全部是美元口径。对于用韩元赚钱、用韩元花钱的人来说还要多一条轴。债券上的盈亏与汇率上的盈亏会相乘。

公式很简单。

韩元口径收益率 = (1 + 美元口径收益率) x (1 + 汇率变动率) - 1

  汇率变动率 = 卖出时点汇率 / 买入时点汇率 - 1
  (+)表示美元兑韩元汇率上行 = 韩元走弱 = 韩元折算金额增加
  (-)表示美元兑韩元汇率下行 = 韩元走强 = 韩元折算金额减少

--- 韩元口径收益率矩阵 (全部为假设值) ---
美元收益率     汇率+10%     汇率+5%     汇率 0%     汇率-5%     汇率-10%
------------------------------------------------------------------------
  +5.0%        +15.50%     +10.25%      +5.00%      -0.25%      -5.50%
  +3.0%        +13.30%      +8.15%      +3.00%      -2.15%      -7.30%
   0.0%        +10.00%      +5.00%       0.00%      -5.00%     -10.00%
  -3.0%         +6.70%      +1.85%      -3.00%      -7.85%     -12.70%

--- 刚好抵消美元收益的汇率变动幅度 (盈亏平衡) ---
  美元 +5.0%  →  汇率 -4.76% 时韩元口径打平
  美元 +3.0%  →  汇率 -2.91% 时韩元口径打平
  美元 -3.0%  →  汇率 +3.09% 时韩元口径打平

请看矩阵右上方的对角线。美元口径赚了5%，汇率下跌10%，换成韩元就是负5.50%。债券的判断是对的，韩元账户上照样显示亏损。盈亏平衡点在汇率负4.76%。也就是说5%的美元收益只扛得住4.76%的汇率下跌。

反方向同样成立。把第2节算出的10年期负7.79%叠上汇率看看。

--- 10年期利率 +1.00个百分点 (美元 -7.79%) 乘以汇率的结果 ---
  债券 -7.79%   汇率 +10%   →   韩元口径   +1.43%
  债券 -7.79%   汇率  +5%   →   韩元口径   -3.18%
  债券 -7.79%   汇率   0%   →   韩元口径   -7.79%
  债券 -7.79%   汇率  -5%   →   韩元口径  -12.40%
  债券 -7.79%   汇率 -10%   →   韩元口径  -17.02%

同一只债券、同样的利率变动，韩元口径的结果却从正1.43%一直拉到负17.02%。第一行尤其重要。债券上亏了7.79%，韩元账户却是正的。而最后一行里债券的亏损被放大了一倍以上。

  • 汇率既会遮住债券的盈亏，也会放大它。只看韩元账户上的数字，分不清哪一边是原因
  • 所以必须把两条轴分开记录。买入与卖出时点的美元金额与适用汇率如果不分别留存，事后就无法还原什么对了、什么错了
  • 汇率的变动没有既定方向。本文不预测汇率走向。上表只展示在给定的汇率变动下算术会变成什么样
  • 是否做汇率对冲会改变结构。带对冲的结构减少了汇率这条轴，但会新增对冲成本这一项。不能说哪一种更好，先确认自己手里的是哪一种才是第一步
  • 短期品种并不会让汇率这条轴变小。期限短了久期会缩，但汇率与期限无关，是乘在全部头寸上的。四周期的Bills同样承担百分之百的汇率敞口

最后这一条在实务中最常被忽略。如果自以为买短债是「稳妥」，结果韩元口径的波动反而更大，多半是因为汇率这条轴还在。汇率敞口不会因为久期短就变小。

7. 税务 - 韩国居民口径，已核实与待核实

本节按韩国居民口径撰写，只写在韩国国税厅资料上核实过的范围。海外投资税制的全貌在海外基金投资和美股税务计算里谈得更细，所以这里只把与美国国债直接相关的部分简要整理。

7.1 在国税厅资料上核实到的

  • 境外债券的利息属于利息所得。国税厅在属于金融所得的利息所得项下列举了「在境外金融机构等存款而在境外收取的存款利息与信托收益」和「持有外国法人发行的债券而收取的利息与折价额」
  • 未在韩国境内被源泉扣缴的一律综合课税。国税厅的表述是「作为利息所得而未在韩国境内被源泉扣缴的，一律纳入综合课税对象」
  • 2千万韩元以下也有例外。其指出「未被源泉扣缴的金融所得（例如：境外源泉利息与股息所得）以及出资共同事业者的股息所得，即使在2千万韩元以下也要综合课税」
  • 居民利息所得的源泉扣缴税率。国税厅载明为非营业贷款收益25%、其他利息所得14%
  • 有价证券的买卖差价不属于金融所得。其说明「股票或债券等有价证券的买卖差价不属于金融所得，因而不在金融所得综合课税范围内」

7.2 未能核实、列为「待核实」的

  • 是否含地方所得税。核实过的国税厅页面给出了14%与25%，却没有载明这些数字是否包含地方所得税。因此本文不对实际税负下断言
  • 境外债券买卖差价是否属于转让所得。上述表述只说到「不在金融所得综合课税范围内」。是否按其他所得类别课税，在核实过的资料中没有
  • 汇兑收益如何单独处理。债券本身的汇兑收益如何处理、卖出款项换汇时点的盈亏归入哪一项，在核实过的资料中没有
  • 境外已纳税额抵免的适用方式。在美国被源泉扣缴的情形如何处理，本文未能核实
  • 因持有形态而产生的差异。直接持有与通过基金、交易所交易产品持有在课税方式上如何分野，超出了核实范围

税务结果高度取决于个别情况。所得构成、居民身份认定、账户类型、持有形态都会改变结论。上面标为「已核实」的项目也只是把引用的指引原文搬过来，并不意味着可以原样套用到个人的情形上。实际申报请以国税厅指引和税务专业人士的确认为准。

8. 直接买与通过基金、ETF买 - 结构差异

接触美国国债的路径大体分为直接持有个别债券与通过装了多只债券的产品持有。本文不说哪一种更好。只把结构上有什么不同摆出来。因为利弊会随持有期间、资金计划、税制、成本而因人而异。

  • 反过来个别债券换来到期日，代价是集中在一只标的上，而且期限结构要自己设计
  • 无论哪一种，自己手里那份的久期都必须知道。那个数字就是直接进入第3节计算的输入值
  • 如果是通过产品持有，先在产品资料上确认是不是有到期日的结构、有没有做汇率对冲是第一步

9. 核实流程 - 收益率曲线与官方数据

到这里说的都是结构。要真正核实，就需要知道去哪里看什么。

9.1 收益率曲线怎么读

收益率曲线是把横轴放期限、纵轴放收益率，把同一发行人的债券按期限连起来的图。读的时候的要领如下。

  • 看整条曲线而不是一个点。没有一个叫「美国利率」的单一数字。每个期限都有各自的收益率，重要的是哪一段与自己的久期相接
  • 收益率是价格的另一种表达。曲线上某个点上行，意味着那一段的债券价格下来了。第2节的算术照样适用
  • 曲线形状的变化与平行移动是两回事。本文的计算全部假设了平行移动。实际上短端与长端常常以不同幅度移动，那样各期限的结果就会与表格不同
  • 本文不从曲线预测走向。虽然有从形状解读未来的做法，这里只把它用于「确认自己持有的那段期限的收益率现在在哪里」

9.2 官方数据在哪里

  • 发行条件、种类、期限。美国财政部的TreasuryDirect 可流通国债说明。第5节的表格是在这个页面和TIPS说明上核实的
  • 每日收益率。美国财政部发布Daily Treasury Par Yield Curve Rates（利率统计页面）。不过撰写本文期间未能访问该页面，因而收录的期限区间与编制方法均未核实。所以本文不引用其内容，数字需要各自访问后自行查证
  • 时间序列查询。美国联邦储备体系旗下的公开数据库提供国债收益率的时间序列。这个在撰写期间同样无法访问，因此本文不引用其中任何数值
  • 税制。韩国居民请以韩国国税厅的指引为一手来源。第7节引用的表述即出于此
  • 要点。本文不对2026-08-01当前的利率水平下断言。正文里的4.00%等是为展示计算结构而设的假设值

9.3 买入前核对清单

  1. 确认了要买的是什么种类。Bills、Notes、Bonds、TIPS还是FRN
  2. 确认了期限。并且确认了这个期限与自己的资金计划是否吻合
  3. 确认了久期。是久期不是期限。通过产品持有的话，在资料里找到了组合加权平均久期
  4. 计算了利率上行1个百分点会变成多少。并确认了那个数字自己扛得住
  5. 也算了2个百分点、3个百分点的情景。30年期在假设条件下是负27.68%、负37.42%
  6. 确认了能否持有到期。如果存在中途卖出的可能，就要把第4节的收敛从计划里拿掉
  7. 确认了汇率敞口。是不是做了汇率对冲的结构，如果做了，成本反映在哪里
  8. 计算了汇率负10%的情景。把第6节的矩阵套到了自己的预期收益率上
  9. 确认了期限结构。个别债券有到期日，产品则确认了是不是有到期日的结构
  10. 确认了成本。把买卖成本和持续成本分开确认了
  11. 确认了税制。第7节的「待核实」项目已向国税厅指引或专业人士逐项确认
  12. 建立了记录体系。决定把美元金额与适用汇率分开留存
  13. 用官方数据确认了当前收益率。不是博客或摘要文章，而是在发行方与统计发布方那里看的

10. 计算代码 - 请自己跑一遍

正文中所有数字都是用下面的函数算出来的。它把半年为单位的现金流老老实实地贴现，不需要任何特别的库。

const F = 2; // 每年付息次数 (美国国债每半年一次)

// 债券理论价格：票息现值之和 + 面值现值
function price(face, cpn, ytm, years) {
  const n = Math.round(years * F);
  const c = face * cpn / F;
  const y = ytm / F;
  let p = 0;
  for (let t = 1; t <= n; t++) p += c / Math.pow(1 + y, t);
  return p + face / Math.pow(1 + y, n);
}

// 麦考利久期：以现值加权的平均回收期(年)
function macaulay(face, cpn, ytm, years) {
  const n = Math.round(years * F);
  const c = face * cpn / F;
  const y = ytm / F;
  let pv = 0, w = 0;
  for (let t = 1; t <= n; t++) {
    const v = c / Math.pow(1 + y, t);
    pv += v; w += v * (t / F);
  }
  const vf = face / Math.pow(1 + y, n);
  pv += vf; w += vf * (n / F);
  return w / pv;
}

// 修正久期 = 麦考利久期 / (1 + ytm / F)
// 价格变动率近似 = -修正久期 x 利率变动 + 0.5 x 凸性 x 利率变动^2
// 韩元口径收益率 = (1 + 美元收益率) x (1 + 汇率变动率) - 1

// 验证：price(100, 0.04, 0.05, 30) → 84.55 (与正文第2节一致)

需要注意的一点。这个函数算的是理论价格。实际交易里还会叠加应计利息、买卖价差、结算惯例和税费，所以与屏幕上看到的数值不会完全一致。即便如此，用来估计利率变动会把价格推向哪个方向、推多远已经足够。

12. 归纳 - 几句话

  • 「安全」指的是发行人会还钱。不是价格不动。两条轴各自独立，账户上出现的负数几乎总是第二条轴

  • 以韩元为本位的投资者还多一条轴。汇率不会因为久期短而变小，它是乘在全部头寸上的。债券上负7.79%，换成韩元可能是正1.43%，也可能是负17.02%

- [ ] 也算了 +2个百分点、+3个百分点的情景
- [ ] 确认了能否持有到期 (不能的话把向面值收敛从计划里拿掉)
- [ ] 确认了有无汇率对冲，有的话确认了成本反映的位置
- [ ] 把汇率 -10% 的情景套到了预期收益率上
- [ ] 通过产品持有的话，确认了 **是不是有到期日的结构**
- [ ] 把买卖成本和持续成本分开确认了
- [ ] 税制已向国税厅指引与专业人士逐项确认
- [ ] 决定把美元金额与适用汇率 **分开记录**

## 10. 不要做的事

- 把期限和久期当成同一件事 (30年期的久期是17.38年)
- 把「避险资产」读成价格也不动
- 只看韩元账户数字来评判债券判断的成败 (里面混着汇率)
- 假设短期品种连汇率敞口也变小了
- 把个别债券的向面值收敛原样套到通过产品的持有上
