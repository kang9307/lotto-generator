基金怎么赚钱，决定了创业者拿到什么条件 - 从条文读管理费与业绩报酬

管理费与结果无关照样累积，业绩报酬要越过门槛才开始。这个差别会出现在条款清单的哪里

2026-09-05 金融/经济

第一次拿到条款清单的创业者，多半先看估值。给多少钱，股份要出去多少。可是决定那个数字的并不只有公司自身的状况。把这笔钱带过来的基金是怎么赚钱的，早就已经定下了其中一半。

2026年9月初，美国技术领域的作者阿尼尔·达什发表了一篇讨论风险投资性质变化的随笔，也被译介到韩国开发者社区。论调很强硬：少数几家超大型投资机构如今已不能称为风险投资了。无论是否认同这个结论，其中都含有一处可用条文核对的结构——基金靠两条线赚钱，而这两条线把人推向不同方向。

本文以提供信息为目的，不构成对任何特定产品或公司的投资建议。文中的计算都是为了展示结构而设的虚拟简化示例，并非真实合同条件。个别合同的解释与判断应遵循律师、会计师等专业人士以及主管机关的指引。

缘起 - 这篇随笔说了什么，原文里又没有什么

原文标题是「Cancer Capital」，在韩国以「VC 已经不再是 VC」的标题被介绍。作者主张，随着监管松动，少数几家风险投资机构膨胀成了什么都做的基金，并且在这个过程中，从法律上已经不再是风险投资机构了。

论点的正中央摆着一行算术。管理500亿美元并每年收取2%，那么无论你投的公司是死是活，每年都有10亿美元落进口袋。作者接着谈到政治献金：某家大型投资机构在2026年中期选举周期投入1亿1,530万美元，约为2024年6,300万美元的两倍，占被追踪的加密货币与人工智能企业政治捐款的20%以上。结论是权力关系的倒转：过去创业者创办公司、投资人寻找机会，如今投资机构打出纲领，创业者只是被挑来执行其中一部分的人。

有一点需先讲清。这是一篇随笔。它是论证而非实证研究，因此作者的句子应作为主张而非事实来搬运。原文缺了什么，后面另有一节列出。

不过即便剥掉政治层面的讨论，那行算术依然留着：管理费与结果无关照样累积。本文取走的就是这一行，仅凭它就足以解释创业者拿到的条件为什么会变。

基金靠两条线赚钱

风险投资基金不是公司而是组合，出钱的一方和运作的一方是分开的。韩国「风险投资促进法」第50条第3款这样规定其构成：由作为组合业务执行人、对组合债务承担无限责任的一名以上业务执行组合员，与以出资额为限承担有限责任的有限责任组合员组成。前者通常称为 GP，后者称为 LP。公开募集的风险投资组合，业务执行组合员为一人。

运作方拿到的钱分成两条线。

  • 管理费 - 运作基金的对价。与业绩无关，按约定费率累积，人力成本和办公场地等固定开支由此支应。
  • 业绩报酬 - 收益越过事先约定的门槛之后，从超出部分中提取的份额，与结果挂钩。

两项报酬的风险性质正好相反。管理费接近固定收入，业绩报酬则是次级的成功付费。二者比重偏向哪边，会改变运作者在意什么。若业绩报酬实质上是唯一回报，一切都压在把退出做大上；若光靠管理费就能维持组织，持续把基金做大就成了稳妥选择。

韩国制度是怎么写这两项报酬的

韩国风险投资协会发布的风险投资组合标准章程及其撰写指引里，条文原样列着。费率栏是空的，但结构已经完全暴露出来了。

管理费 - 区间分成两段

标准章程第27条第1款把管理费切成两个区间。

  • 第1项 - 自向中小风险企业部登记之日起至约定年数届满之日，按出资总额的年若干百分比计算。
  • 第2项 - 此后直至解散之日，按投资余额，即各季度末平均余额或每日平均余额的年若干百分比计算。

这个划分正是关键。前一区间的基数是已承诺的总额。钱是否真的进了公司、进去后又怎样，都不进入计算。要到后一区间，基数才转为尚存的投资余额。支付上，第1项按各季度末结算，第2项原则上在大会批准年度决算后支付，但可在二分之一范围内先行支付。

管理费由组合承担。第26条第1款第7项把管理费列入组合运营经费清单，同条第2款则规定，不在该清单上的业务执行费用由业务执行组合员承担。

业绩报酬 - 越过门槛之后才开始

第28条第1款规定，在存续期间内内部收益率超过基准收益率时，经组合员大会批准，将投资收益中约定的比例作为业绩报酬支付给业务执行组合员。基准收益率本身在第2款中同样留成了空栏。

这里用到的词，章程自己下了定义。投资收益是组合资产评估金额减去出资金额与组合运营经费之后的数额；内部收益率是使组合所运作资金的现值与组合员回收金额的现值相等的折现率；基准收益率则是可以支付业绩报酬的门槛收益率。

第3款设有提前支付程序。登记满三年、章程约定的投资期届满且已完成投资义务时，在最终结算前也可按顺序支付业绩报酬。顺序是：先向组合员优先分配，直到累计金额达到出资本金与基准收益率对应金额之和；再在剩余范围内支付业绩报酬；余下的按出资比例分配。第4款依据施行令要求，业务执行组合员须在所收业绩报酬范围内，向主管基金经理等员工发放绩效奖金。

费率栏是空的，并不是遗漏。指引在管理费和业绩报酬两处都加了注记，大意是因无另行规定，由组合员协商设定。也就是说，费率不是法律给定的数值，而是由 LP 与 GP 谈判填入的空格。因此「法律把业绩报酬定为20%」这类说法在这份文件里得不到支持。

存续期也是同样的写法。第14条把它定为自登记之日起的约定年数，可经大会特别决议延长，并在注记中依据施行令写明最低五年以上。管理费在整个存续期内持续累积。

规模对管理费做了什么

费率相同，规模不同，结果也不同。下面是为展示结构而设的虚拟简化示例。税费、中途回收及分段基数变更全部忽略，整个存续期一律按出资总额基数计算。

[假设] 管理费 年2%，存续期 8年

基金A - 出资总额 1,000亿韩元
  年度管理费 =  1,000亿 x 2%  =    20亿韩元
  8年累计                     =   160亿韩元

基金B - 出资总额 1万亿韩元
  年度管理费 = 10,000亿 x 2%  =   200亿韩元
  8年累计                     = 1,600亿韩元

费率相同。变的只有规模。

值得留意的是成本并不跟着规模走。基金大十倍，并不需要十倍的投资经理，因为审一个项目的工夫与投资金额不成正比。所以规模越大，管理费扣掉组织开销后剩下的部分就越大。

原文随笔里的500亿美元和2%，瞄准的正是这个点。不过那个数值是作者为了呈现论点而举的例子，并不是某只具体基金的真实合同条件。金额和费率都会随时点、地区和合同而变。

重要的不是金额而是方向。一旦管理费大到维持组织之外还有富余，把下一只基金做得更大本身就成了合理的选择。业绩报酬要等到回收全部结束后才结算，而管理费从成立后的下一个季度就开始进账。

大基金必须要有大退出的算术

规模改变的不只是管理费，还改变了什么样的公司才适合这个投资组合。这同样是虚拟简化示例。

[假设] 目标是把本金的3倍返还给 LP。
       投出的30家里，有意义的回收出自3家。
       退出时点的持股比例为15%。

基金A - 1,000亿韩元
  所需回收总额 = 3,000亿韩元
  成功3家     -> 每家    1,000亿韩元
  持股15%     -> 企业价值约 6,700亿韩元

基金B - 1万亿韩元
  所需回收总额 = 3万亿韩元
  成功3家     -> 每家    1万亿韩元
  持股15%     -> 企业价值约 6.7万亿韩元

即便目标倍数相同，所需公司的体量也会按基金规模成比例放大。这套算术本身无所谓好坏，它就只是算术。

可是从创业者一侧看，结果就清楚了。年营收100亿韩元、利润稳定的公司是门很好的生意，但在基金B的投资组合里，它是四舍五入就会消失的资产。不是公司不好，而是那只基金的算术里没有它的位置。同一家公司放进基金A，就是有意义的退出候选。

所以「和我们基金不太匹配」这句话，多半不是对公司的评价，而是在讲算术。听到这句话时，有些情况下要改的不是公司，而是该换一个对手方。

创业者拿到的条件在这里分道

前面这些算术会在条款清单的三个位置显形。轮次本身的基础，即种子轮与A、B、C轮的区分、估值怎么算、SAFE、股权结构表，已整理在创业公司融资轮完全指南里。这里只看叠在其上的激励。

增长压力是结构不是偏好

投资人把增长率摆在前面，不是性格问题。要够到上一节算术要求的体量，剩余期限内必须翻多少倍，早就定好了。存续期最低五年，实际会更长，但越往后剩的时间越短。同一家公司，刚成立的基金和临近到期的基金要求的速度并不一样。所以对方基金的成立时间本身就是条件的一部分。

下一轮被当作前提铺在底下

本轮的估值多半是按下一轮会更高这个前提搭起来的。前提守住了，对所有人都好；一旦破了就成了折价轮，届时股权稀释和条款会一起启动。所以读条款清单时，最好把下一轮估值更低时各条款如何运作也一并算出来。在好的情形里，绝大多数条款都安安静静。

清算优先权决定顺序

这是决定公司被出售或清理时谁先拿走多少的条款。韩国的风险投资中常用可赎回可转换优先股，简称 RCPS。顾名思义带有赎回权和转换权，在利润分配和剩余财产分配上都优先于普通股。这一条款的分量，在下一节会以数字显现。

把清算优先权放进数字里看

清算优先权分成两支。参与型先拿到优先份额，之后剩余财产还要按持股比例再分一次。非参与型拿到优先份额就到此为止，但因为带有转换权，若转成普通股按比例分配更多，就会选那一边。下面同样是虚拟简化示例。

[假设] 投资人投入20亿韩元，取得20%的优先股。
       清算优先权为投资本金1倍。不考虑其他轮次与费用。

售价 200亿韩元
  非参与型 : max(20亿, 200亿x20%=40亿)  -> 投资人 40亿 / 普通股 160亿
  参与型   : 20亿 + (180亿x20%=36亿)    -> 投资人 56亿 / 普通股 144亿

售价 100亿韩元
  非参与型 : max(20亿, 100亿x20%=20亿)  -> 投资人 20亿 / 普通股  80亿
  参与型   : 20亿 + (80亿x20%=16亿)     -> 投资人 36亿 / 普通股  64亿

售价 30亿韩元
  非参与型 : max(20亿, 30亿x20%=6亿)    -> 投资人 20亿 / 普通股  10亿
  参与型   : 20亿 + (10亿x20%=2亿)      -> 投资人 22亿 / 普通股   8亿

挪进表里，有一件事就清楚了：售价越低，这一条款的分量越重。以200亿韩元成交时，是否参与只让普通股份额动一成左右；而以30亿韩元成交时，留给普通股的已不到三分之一。

这一段与前面基金的算术接上了。基金越大，以「小额退出」收场的项目占比越高，于是落进这一条款真正起作用区间的概率也随之升高。只拿好的情形接受条件，等于在没算过条款发力区间的情况下签了字。

真实合同比这复杂。优先权倍数可能不是1倍，参与型也可能附带上限，轮次一多还要另行约定后面的轮次是排在前面还是同顺位分配。条件因合同而异，不是可以一概而论的数值。

韩国制度事先堵住的地方

对于「收着管理费却不把钱投出去会怎样」这个问题，韩国制度是有答案的，一共两道机制。

第一道是投资义务比率。标准章程第30条及其注记列出的依据是风险投资促进法第51条、施行令第35条以及「风险投资组合登记与管理规程」第7条。盲池基金或项目基金必须在登记之日起满三年前，以认可的投资方式投出出资承诺额的20%以上；二级市场基金与并购基金在同一期间须达60%以上。投资对象也不敞开：第30条第1款把范围收拢到未上市的创业企业、风险企业以及技术创新型和经营创新型中小企业。

第二道是没投出去的钱要退回。标准章程第35条第2款规定，组合登记满三年且章程约定的投资期也已届满，却仍未投出的出资本金，可经组合员大会特别决议分配给组合员。并附有但书：分配之后出资本金仍须在20亿韩元以上。

为管理人自身利益行事也被条文堵住。法第52条第1款要求业务执行组合员以善良管理人的注意执行业务，第2款禁止为自己或第三人利益使用组合财产、禁止借入资金与提供担保、禁止投资于相互出资限制企业集团所属公司、禁止取得非营业用不动产。组合财产由受托公司另行保管管理。

资金来源也不一样。中小风险企业部在2026年1月23日公布当年第一次定期出资计划时，目标是以母基金出资2万1,000亿韩元，带动组建4万4,000亿韩元的风险基金。按部门划分为中小风险企业部1万6,300亿韩元、文化体育观光部4,990亿韩元、海洋水产部150亿韩元。相当一部分出自财政，上述投资义务与分配约束也就一并跟了过来。

所以原文所针对的美国状况并不能原样搬到韩国，监管的纹理不同。不过管理费与结果无关照样累积这个结构本身是一样的。韩国只是在它之上加装了最低投资比率与未投资本金返还两道刹车。

别的路径 - 放弃什么又得到什么

如果风险投资基金的算术与公司不匹配，就有改变资金进入方式本身的选项。每一种都放弃一些又得到一些，并不存在哪种绝对更优，问题在于是否与公司的成长曲线咬合。

路径股权稀释偿还义务控制权放弃的东西得到的东西
自筹起步无无原样保留速度与可达到的规模没有附加条件的决定权
收入分成融资无按营收比例偿还，总额设上限通常没有董事席位总偿还额大于本金保住股权与控制权的资金
小规模风险基金有无由条款转移一部分股权与部分决定权中等规模退出也成立的算术
大型风险基金有无由条款转移相当部分股权与选择节奏的权利大额资本与后续加注能力
政策与公共资金大体上没有属于贷款性质的则有原样保留选择时机的自由相对较低的融资成本

收入分成融资在韩国还不是熟悉的名字。海外提供方资料里描述的结构是：先拿到资本，每月按营收固定比例偿还，总偿还额设上限，触到上限就结束。上限常被描述为本金的1.2倍到1.5倍，条件不以利率而以总偿还倍数标示。偿还跟着营收走，增长就早点还完，下滑就晚点还完，没有固定到期日。代价是必须已有营收和历史记录，因此在有营收前用不上，融资规模也被营收体量绑住。

通过政府和公共机构而来的资金性质又不同。要还的钱和不用还的钱混在一起，从读公告的顺序就得先分清，这部分另行整理在政策资金不是免费的钱里。个人投资者接近这类资产的路径及其风险，则在众筹与P2P投资完全指南中。

条款清单先读哪里

估值最先撞进眼里，却是最晚敲定的数字。在它之前有该先读的位置。按下面的顺序过一遍，条款清单立在什么样的激励之上就会显露。

顺序项目确认什么为什么这里在先
1基金规模与成立时间总额、登记时点、剩余存续期所要求的退出体量与速度都出自这里
2清算优先权倍数优先到投资本金的几倍为止它决定低售价时普通股的份额
3是否参与及上限是不是参与型，有没有设上限倍数相同结果也会分岔
4各轮之间的顺位后面的轮次是排在前面还是同顺位后续融资进来之后顺序会变
5赎回权的条件何时行使、用什么资金来源没有可分配利润执行就会受限
6后续投资相关条款持股比例维持权与不参与时的不利后果它预先决定了下一轮的谈判力
7共同出售条款谁能拉动出售、谁可以跟着走它规定了退出的决定主体
8董事会与同意权清单预算、招聘、追加投资中哪些需要同意它会改变日常决策的速度

八项看完后还有一件事：把同一份条款清单按两种情形各算一遍。一种是下一轮估值更高，另一种是更低甚至没有下一轮。好的情形里绝大多数条款都安静，条款的性格只在坏的情形里现身。

对手方是什么样的基金，同样是条件的一部分。成立时间、基金规模、剩余存续期通常问一下就知道，这三样决定了上一节的算术。创业公司失败的真正原因里讨论的决策问题与这套条件结构彼此咬合：融资条件一旦强加增长速度，那速度反过来又挤掉决策的余裕。
