검증 Result가 만족스럽지 않다면, 'Generate기' 탭으로 이동하여 더 강력한 Password를 만들어보세요.

Password Generator Use법

  1. Password Length 슬라이더를 Use하여 원하는 Length로 Settings합니다 (6-32자).
  2. Password 옵션을 Select합니다:
    • Include Uppercase: 'A-Z' Range의 영문 Uppercase를 Include합니다.
    • Include Lowercase: 'a-z' Range의 영문 Lowercase를 Include합니다.
    • Include Numbers: '0-9' Range의 Numbers를 Include합니다.
    • 특수 Characters Include: '!@#$%^&*()' 등의 특수 Characters를 Include합니다.
    • 비슷한 Characters Exclude: '1', 'l', 'I', '0', 'O' 등 혼동되기 쉬운 Characters를 Exclude합니다.
  3. "비밀Generate Numbers" 버튼을 클릭하여 Result를 Generate합니다.

Password Result 해석

  • Password Strength: Generate된 Password의 Security 수준을 나타냅니다.
  • Weak (빨간색): Length가 짧거나 Characters 종류가 단Day 유형인 Password입니다.
  • 중간 (Week황색): Minimum 8자 이상이며 2가지 이상의 Characters 유형을 Include합니다.
  • Strong (녹색): Minimum 10자 이상이며 3가지 이상의 Characters 유형을 Include합니다.
  • Very Strong (진한 녹색): Minimum 12자 이상이며 모든 Characters 유형을 Include합니다.

Security Password 팁

  • 다양성: Uppercase, Lowercase, Numbers, Special Characters를 All Include하세요.
  • Length: Minimum 12자 이상의 Password를 Use하세요.
  • 고유성: 각 계정마다 서로 다른 Password를 Use하세요.
  • 정기 변경: Password를 3-6개Month마다 변경하세요.
  • 관리 Tool: Password 관리자를 Use하여 복잡한 Password를 Safely 보관하세요.
