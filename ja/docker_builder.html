📖 Docker 基本概念

Dockerの中核概念を理解して、効果的に活用しましょう。

📦

コンテナ (Container)

アプリケーションと環境をパッケージ化した実行可能なインスタンス
💿

イメージ (Image)

コンテナを作成するための読み取り専用テンプレート
📁

ボリューム (Volume)

コンテナ間のデータ共有のための永続ストレージ
🌐

ネットワーク (Network)

コンテナ間の通信のための仮想ネットワーク
📋

Dockerfile

イメージビルドのためのコマンドスクリプト

🌐 ウェブアプリケーション実行

Nginxウェブサーバー実行

docker run -d --name my-nginx -p 8080:80 -v /host/html:/usr/share/nginx/html nginx:latest
  • -d: バックグラウンドで実行
  • --name my-nginx: コンテナ名を指定
  • -p 8080:80: ホスト8080ポートをコンテナ80ポートに接続
  • -v /host/html:/usr/share/nginx/html: HTMLファイルをマウント

Apacheウェブサーバー（環境変数を含む）

docker run -d --name my-apache -p 8081:80 -e APACHE_SERVER_NAME=localhost -v /host/www:/var/www/html httpd:latest
  • -e APACHE_SERVER_NAME: サーバー名の環境変数を設定
  • httpd:latest: Apache HTTPサーバーイメージ

🗄️ データベース実行

MySQL データベース

docker run -d --name my-mysql -p 3306:3306 -e MYSQL_ROOT_PASSWORD=[YOUR_PASSWORD] -e MYSQL_DATABASE=mydb -v mysql-data:/var/lib/mysql mysql:8.0
  • MYSQL_ROOT_PASSWORD: rootユーザーのパスワード
  • MYSQL_DATABASE: 自動生成するデータベース
  • mysql-data:/var/lib/mysql: データ永続保存のためのボリューム

PostgreSQL データベース

docker run -d --name my-postgres -p 5432:5432 -e POSTGRES_PASSWORD=[YOUR_PASSWORD] -e POSTGRES_DB=mydb -v postgres-data:/var/lib/postgresql/data postgres:15
  • POSTGRES_PASSWORD: PostgreSQL のパスワード
  • POSTGRES_DB: 既定のデータベース名

💻 開発環境設定

Node.js 開発環境

docker run -it --name node-dev -p 3000:3000 -v /host/project:/app -w /app node:18 bash
  • -it: インタラクティブターミナルモード
  • -w /app: 作業ディレクトリを設定
  • bash: シェルコマンドで開始

Python 開発環境

docker run -it --name python-dev -v /host/code:/workspace -w /workspace python:3.11 python
  • python:3.11: Python 3.11 イメージ
  • python: Python インタープリタで開始

🔧 マイクロサービス配備

RESTful API サービス

docker run -d --name api-service --restart=always -p 8000:8000 -e API_KEY=secret -e DB_HOST=db-container --network=app-network my-api:v1.0
  • --restart=always: 常に再起動
  • --network=app-network: ユーザー定義ネットワーク
  • API_KEY, DB_HOST: サービス別の環境変数

ロードバランサー (Nginx)

docker run -d --name load-balancer -p 80:80 -v /host/nginx.conf:/etc/nginx/nginx.conf:ro --network=app-network nginx:alpine
  • nginx.conf:ro: 設定ファイルを読み取り専用でマウント
  • nginx:alpine: 軽量化された Alpine ベースのイメージ

🐳 Docker Compose 例

複雑なマルチコンテナアプリケーションを簡単に管理する方法です。

ウェブアプリケーション + データベース スタック

version: '3.8' services: web: image: nginx:latest ports: - "8080:80" volumes: - ./html:/usr/share/nginx/html depends_on: - db networks: - app-network db: image: mysql:8.0 environment: MYSQL_ROOT_PASSWORD: password MYSQL_DATABASE: webapp volumes: - db-data:/var/lib/mysql networks: - app-network volumes: db-data: networks: app-network:
  • depends_on: サービス間の依存関係を定義
  • networks: サービス間通信のためのネットワーク
  • volumes: データの永続保存
💡 使い方: 上記の内容をdocker-compose.ymlファイルとして保存し、docker-compose up -dコマンドで実行してください。

このポスティングはクーパンパートナーズ活動の一環として、それに伴う一定額の手数料を提供されます。
