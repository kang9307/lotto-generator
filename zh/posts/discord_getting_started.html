Discord 入门 — 从新手前三十分钟卡住的地方讲起

服务器、身份组、通知、语音设置与免费和 Nitro 的边界

2026年8月9日 IT/技术

拿 QQ 群的直觉进来,第一屏就会迷路

第一次用 Discord 的人,卡住的地方几乎是固定的。朋友发来邀请链接,点进服务器,却发现频道列表连一半都看不到;一夜之间堆起几百条通知,烦到想卸载;进了语音频道才发现键盘声和呼吸声一直在往外播;左边竖着排的一列圆圈,完全猜不出是什么。如果只是听说这是游戏玩家用的聊天软件,会更晕——因为 Discord 与其说是聊天软件,不如说是把整栋俱乐部大楼整个交给每个社区的服务,房间、门禁、公告栏一应俱全。

这篇文章只按顺序拆这些卡点:服务器、频道、子区和普通群聊有什么不同;邀请链接怎么用、频道为什么被藏起来;把通知降到人能承受的水平的步骤;麦克风和噪音抑制;屏幕共享;账号安全和未成年人相关的安全设置;最后是怎么建一个自己的服务器。贯穿全文的前提是:Discord 靠几条规则运转,把这几条规则拿在手里,剩下的菜单点一点就能自己弄明白。另外要先说清一点:Discord 在中国大陆的网络环境下通常无法直接访问,本文面向能够正常使用全球服务的读者。

文中的价格和限额数字都以2026年8月为准。Discord 多次调整过上传限额和定价,凡是涉及付费或限额的判断,请以官方说明和你自己付款页面上的数字为最终依据。

服务器、频道、子区 — 把一个群聊拆成许多房间的结构

在 QQ 群或微信群里,所有内容顺着一条时间线往下流:公告、闲聊、提问、截图全混在一起。Discord 把这条流拆开了。服务器(server)是一个社区占用的大楼,里面的每个频道(channel)是专属一个话题的房间。公告进公告频道,闲聊进闲聊频道,截图进图片频道。这里的服务器和机房里的服务器硬件没有关系,它只是社区空间的叫法。左侧竖列里的每个圆圈,就是你加入的一个服务器。

Discord 术语用 QQ/微信类比实际的差别在哪里
服务器一个群把很多群捆在一起的大楼,自带频道、身份组和规则
频道群里的一个话题按话题分开的房间;文字频道和语音频道是两种类型
子区(Thread)某条消息的回复串从一条消息分岔出来的支线会话室,安静后会自动归档
身份组(Role)群主、管理员颗粒度细得多的名牌兼钥匙,连你能不能看见某个频道都由它决定
私信(DM)单独聊天服务器之外的私人对话,谁能给你发是一项可以收紧的设置
@提及@某人分 @用户、@身份组、@everyone 三层,是通知管理的核心单位

除了结构,还有几处体感差别很大。

  • 手机号不会暴露。 Discord 以用户名为基础,在服务器里认识的人看不到你的号码。同一个账号既能混匿名社区又能进朋友圈子,原因就在这里。
  • 加入之前的聊天记录也能看。 普通群聊只显示入群之后的消息,而 Discord 的频道只要权限允许,可以一路翻回第一条。
  • 每个服务器可以用不同的名字。 个人资料是全局的,但昵称和头像可以按服务器覆盖。在游戏服务器和学习小组里当两个人,完全正常。
  • 语音频道是房间,不是通话。 没有拨号和接听,房间一直开着,大家自由进出。这一点改变的东西很多,下面单独用一节来讲。
  • 子区是给支线话题用的。 频道里某个话题聊长了就挪进子区,主频道不会被刷屏。子区安静之后自动折叠归档,连清理都不用。

点了邀请链接,频道却只显示一半的原因

进入 Discord 服务器的标准途径是邀请链接——以 discord.gg/ 开头的地址。点开会出现服务器预览,接受之后你就是成员。这里没有随便逛的公开目录,拿着链接的人就是守门人。入场流程通常是这样的。

  1. 点击链接。 还没有账号的话,这一步会引导注册。链接可能带有效期和使用次数限制,失效了就找对方要一条新的。
  2. 同意规则。 有规模的服务器会在进门后用规则页面或规则频道让你点同意按钮。点之前,大部分频道是锁着的。
  3. 回答入门引导的问题。 有的服务器会让你选择兴趣方向或来意。这里选的答案会直接变成身份组,决定你能看到哪些频道。
  4. 先读公告和指引频道。 哪个频道做什么、身份组怎么领,几乎都写在那里。比直接冲进闲聊频道提问快得多。

身份组是名牌,也是钥匙

进去之后觉得频道少,不是社区冷清,而是你的身份组看不到的频道被藏起来了。Discord 的每个频道都可以按身份组设置浏览和发言权限,对新人只开放最小限度、验证之后再逐步解锁,是接近标准的做法——为的是过滤广告号和骗子号。

  • 身份组是管理员定义的名牌。 可以是新人、常驻、管理这样的等级,也可以是游戏偏好、职业方向这样的分类,各自带颜色,在成员列表里一目了然。
  • 频道看不到,先怀疑身份组。 走验证流程、点反应表情、活跃满一定时间才解锁的频道很常见。方式因服务器而异,写在公告里。
  • 反应表情领身份组是通行惯例。 在指定消息下点表情,对应身份组自动挂上。第一次见会觉得奇怪,在 Discord 里这是再普通不过的机关。
  • @身份组会呼叫该组全员。 领一个身份组,也意味着接受发给这个组的群体呼叫。通知突然变多时,回头看看自己领了哪些身份组。
  • 看不见不是故障。 同一个服务器里,不同人看到的频道数量本来就不同,这是 Discord 的正常状态,重装软件解决不了。

逃出通知地狱的步骤 — 要关的是服务器,不是应用

被 Discord 通知折磨的人,常常把应用通知一刀切关掉,结果连真正点名叫自己的消息也错过,用 Discord 的意义就没了。正解是按服务器收紧。先拧大阀门,要动手的地方其实没几个。

步骤位置操作效果
1右键服务器名称(手机长按) → 通知设置改为仅@提及普通闲聊的通知全部消失,体感收益最大
2同一个通知设置面板开启抑制 @everyone 和 @here群发呼叫安静下来,对爱发广告式公告的服务器特效
3同一个通知设置面板抑制所有身份组提及发给你身份组的群体呼叫不再送达
4右键吵闹的频道 → 静音频道选时长(15分钟到无限期)只有这个频道沉睡,适合赛事、活动期间临时用
5右键服务器名称 → 静音服务器选时长只围观的服务器整个安静,未读标记仍保留
6用户设置 → 通知调整账号级默认值和推送条件对所有服务器生效的最后一道保险

再叠加几个习惯,通知就变回工具。

  • 基本策略:所有服务器仅@提及,重要的才留例外。 每进一个新服务器就顺手做一遍步骤1,通知从一开始就堆不起来。
  • 静音和关闭通知是两回事。 静音只停掉声音和横幅,未读标记还在。连标记都不想看,就在服务器设置里把未读显示也隐藏。
  • 频道静音要善用时长。 只在比赛或活动期间吵的频道,选1小时、8小时、24小时比无限期好,结束后自己恢复。
  • 请勿打扰状态有它的用处。 把状态切成请勿打扰,桌面横幅就完全不弹。开会、上课用它正合适。
  • 手机和电脑的通知是联动的。 在电脑上活跃时,手机推送会被暂缓,这是设计好的默认行为。感觉手机不来通知时,先确认这个机制再怀疑设置。
  • 用好收件箱。 顶部的收件箱图标汇集所有提到你的消息。通知压得再狠,只要扫一眼这里,就不会漏掉找你的人。

语音频道 — 不是打电话,是一直开着的房间

Discord 的语音不是拨号接听那一套。房间全天开着,走进去的瞬间就和里面的人连上了。所以打游戏时挂几个小时语音、学习小组各自做事只保持在线,都是自然的用法。麻烦出在第一次:麦克风完全没被拾取,或者拾取了,但键盘声和生活噪音也一起播了出去。要动的东西集中在一个地方——用户设置里的语音·视频页面。

  • 输入输出设备要明确选中。 停在默认设备上,就会发生插着耳麦却在用笔记本内置麦克风的事故。按名字直接选你要用的设备。
  • 输入灵敏度先用自动。 声音超过阈值才发送。安静环境下自动就够了;有人说你声音断断续续,再切手动、把门槛调低。
  • 担心噪音就用按键说话。 按住指定键才开麦。机械键盘声大的环境、和家人同处一室时,这是最干净的方案。
  • 打开噪音抑制。 语音·视频设置里的噪音抑制能滤掉键盘声、风扇声级别的杂音。开与不开的差别,你自己听不到,对面听得清清楚楚。
  • 回声消除和自动增益保持开启。 它们负责拦住对方的声音从你的扬声器绕回你的麦克风。没出问题就没有动它的理由。
  • 吵的人单独调音量。 在语音频道里右键对方的名字,会出现只对这个人生效的音量滑块,不必动总音量。
  • 分清闭麦和闭听。 麦克风图标切断你的声音;耳机图标连对方的声音也不听了,而且闭听会连带闭麦。

进频道之前,花三十秒先测麦

第一次进语音频道之前花半分钟,第一句话就不会手忙脚乱。

  • 跑一遍语音·视频设置里的麦克风测试。 按下测试按钮说话,自己的声音会原样播回来。这里能听见,频道里就能听见。
  • 看输入电平条动不动。 说话时电平条毫无反应,问题出在设备选择或操作系统的麦克风权限。浏览器版先查地址栏的麦克风许可。
  • 戴耳机。 用扬声器外放,对方的声音会灌进你的麦克风形成回声。回声消除能压一压,耳机才是根治。
  • 第一次进场挑个没人的频道。 独自进一个空语音频道,确认麦克风指示正常再出来。没有人会在意。

屏幕共享免费能做到什么程度

人在语音频道里,按下屏幕按钮,你的画面就会向房间里直播,Discord 把它叫 Go Live。这个功能因游戏直播而生,但拿来做在线辅导、学习小组、代码评审、一起过文档完全够用,而且不装额外软件、免费账号就能用——这个组合比听起来稀罕。

  • 在整个屏幕和单个窗口之间选。 只共享一个窗口,桌面其他位置的消息弹窗和文件名就不会入镜。给外人看时,选窗口是安全默认值。
  • 声音可以一起播。 想把视频或游戏的声音带上,在开始共享的对话框里打开音频共享。个别平台组合对声音采集有限制,正式用之前先试一次。
  • 免费画质上限是 720p、30fps。 讲文档和幻灯片足够;小字多的画面,用窗口共享把它放大占满画幅更实际。
  • 订阅 Nitro 后升到 1080p、60fps,最高 4K。 这条画质分界线连同价格,一起放在下面的表里。
  • 浏览器版的画质调节受限。 经常要共享屏幕的话,装桌面客户端更合适。
  • 手机也能共享屏幕。 手机画面会原样播出,开始前先关掉通知预览才稳妥。

守住账号的设置 — 两步验证和锁私信

Discord 账号上挂着游戏资产和社区身份,是常规的盗号目标。手法也是格式化的:要么用声称送免费 Nitro 的私信链接把你引到假登录页,要么让你扫一个二维码,把登录会话整个端走。防御同样格式化,而且有效。

先说账号本身的锁。

  • 开启两步验证(2FA)。 在用户设置的我的账号页面注册验证器应用。密码就算泄露,没有一次性验证码也登不进来。
  • 保存好备用代码。 开启两步验证时发放的恢复代码要放在安全的地方。手机丢了又没有这些代码,找回账号会非常艰难。
  • 给 Discord 配专用密码。 拿其他网站泄露的密码来撞库,是盗号的经典路径。用密码管理器,这个问题就不存在了。
  • 打算运营服务器,两步验证等于必选。 服务器可以要求管理操作必须开启两步验证,有规模的社区基本都开着这个要求。

再说收窄别人接近你的路径。这些开关全部集中在用户设置的隐私·安全页面。

  • 关掉来自服务器成员的私信。 默认设置下,只要同在一个服务器,陌生人就能给你发私信——诈骗私信大多从这根管子进来。这个开关既可以按服务器设,也可以设为账号默认值。
  • 让陌生人的消息进请求箱。 开启消息请求功能后,非好友的私信先进入等待区,你接受之前,对方连你读没读都不知道。
  • 检查敏感媒体过滤器。 Discord 分别检测色情图像和暴力图像,可以拦截或加模糊处理。成年账号可选档位,青少年账号默认套用保护档。
  • 收窄好友申请的范围。 把任何人都能发申请的默认值,改成好友的好友或同服务器成员。来路不明的申请不断时,先拧这里。
  • 私信里的链接和附件,默认不信。 真正的 Nitro 礼物在 discord.com 域名下打开,改一两个字母的仿冒域名遍地都是。亲眼核对地址的习惯是最好的疫苗。
  • 不要用自己的应用扫别人给的二维码。 Discord 的扫码登录方便,也正因为强大——扫陌生人的码,可能等于把自家大门钥匙递出去。

家长该看的部分 — 年龄标准和家庭中心

Discord 是匿名制的开放社区,围绕未成年人的安全问题是真实存在的,不是杞人忧天。但一刀切禁止很少是可行答案;了解年龄标准和平台提供的保护装置,然后和孩子一起把设置做好,才是现实的答案。

  • 基础年龄标准是13岁,部分国家和地区更高。 例如韩国是14岁。注册时要填出生日期,被判定未达标的账号会被停用。
  • 青少年账号默认带保护。 非好友私信里的敏感图片直接拦截,其他途径的敏感图片加模糊显示——这些是默认值,不是要专门去找的选项。
  • 家庭中心可以把家长和孩子的账号关联起来。 关联后,家长能看到摘要:孩子加入了哪些服务器、最近和谁交谈过。消息正文在设计上就不给家长看,它是用来开启对话的工具,不是监控探头。
  • 风险场景有警示机制。 青少年账号在收到陌生成年人私信等需要警惕的场景时,会收到安全提醒,并附带一键拉黑的引导。
  • 私信和好友申请的限制,和孩子一起设。 上一节的关闭服务器成员私信、收窄好友申请,在青少年账号上效果最大。别偷偷设,讲清理由一起设,才管得久。
  • 加入什么样的服务器才是关键变量。 决定体验的与其说是 Discord 本身,不如说是所进服务器的管理水平。养成问一句邀请链接从哪来的、服务器有没有规则和管理员的习惯,比装十个过滤器都强。

建自己的服务器 — 三个频道就够开张

给朋友圈子或学习小组建服务器,用不了一分钟,而且免费。觉得难,是因为你见过的都是装修成熟的大型服务器——它们当初也是从两三个频道起步的。顺序如下。

  1. 按服务器列表最底下的 + 按钮。 选亲自创建会得到一个空服务器,选用途模板则会得到频道结构现成的服务器。第一次建,用模板找感觉更快。
  2. 频道从三个开始。 一个公告文字频道、一个闲聊文字频道、一个语音频道就够了。频道等需要时再加,比一开始铺满更好整理。
  3. 创建邀请链接时看一眼有效期。 邀请按钮生成的链接默认7天后失效。长期圈子就在链接设置里改成永不过期;怕外流的圈子,改成限制使用次数。
  4. 身份组有两个就能起步。 分出管理员和普通成员就够了。按频道细设权限,等成员多起来、真的需要了再做也不迟。
  5. 规则频道等人多了再建。 十个熟人的圈子摆一份章程太隆重。陌生人开始进来的那一刻,才是引入规则和验证流程的时机。
  6. 要做公开社区,再打开社区功能。 在服务器设置里切换后,会解锁公告频道、加入审核、数据统计这些运营工具。小圈子阶段用不上。

这里不下断言的事项

以下事项本文不下断言。它们随时间、国家和账号状态变化,只有官方说明和你自己的账号页面能给出定值。

  • 以人民币等本币计的确切价格,不下断言。文中金额是美元网页付款口径。Discord 按国家施行本地化定价,iOS、Android 应用内购还会因商店抽成而更贵。付款页面上的数字才是最终值。
  • 上传和画质上限是否维持现状,不下断言。免费上传上限历史上从 8MB 涨到 25MB,又降回 10MB。工作依赖大文件的话,请在自己的账号里确认当前上限。
  • 屏幕共享的同时观看人数上限,不下断言。它随服务器助力等级和频道类型变化,这里不钉死数字。
  • 家庭中心与青少年保护功能的可用范围,不下断言。安全功能有时按地区和应用版本分批推送,实际账号里是否出现对应菜单才是判断标准。
  • 分国家年龄标准表的当前值,不下断言。13岁、14岁是广为公布的数字,但条款和标准表会修订,注册时请查官方帮助中心的文档。
  • Nitro 的免费试用和促销活动,不下断言。这个领域变动频繁,付费前在官方 Nitro 页面确认正在进行的条件才准确。

常见问题

Q1. Discord 免费能用到什么程度?

核心功能全部免费:加入和创建服务器、文字和语音聊天、视频通话、屏幕共享,都不用付费。Nitro 改变的是上限——上传从 10MB 到 500MB,屏幕共享从 720p 到 1080p 以上。目的是和人交流的话,免费档几乎不缺什么。

Q2. 通过邀请链接进了服务器,却只看到几个频道。

不是故障,是身份组的问题。服务器按身份组给频道设浏览权限,对新人只开放最小限度是常见做法。同意规则、回答入门引导、点反应表情等方式领到身份组后,锁住的频道就会打开。方法写在服务器的公告里。

Q3. 通知太多了,怎么减?

不要一刀切关掉应用通知,把服务器通知改成仅@提及才是正解。右键服务器名称(手机长按)打开通知设置即可。再一并打开 @everyone 抑制,吵的频道单独静音,剩下的就只有点名找你的消息。

Q4. 孩子想用 Discord,多少岁可以用?

基础标准是13岁以上,部分国家和地区更高(例如韩国是14岁)。青少年账号默认启用敏感图片过滤;家长关联家庭中心后,能看到孩子所在的服务器和交谈对象的摘要。消息正文不会展示给家长。

Q5. 陌生人私信发来免费 Nitro 的链接。

不要点,举报后拉黑。用免费 Nitro 引到假登录页,是 Discord 上最常见的盗号手法。真正的礼物在 discord.com 域名下打开。关掉来自服务器成员的私信,这类接触本身就会大幅减少。

结语

Discord 真正需要理解的规则没有几条。服务器是捆着许多房间的大楼;频道看不见,是缺一把叫身份组的钥匙;通知按服务器收紧,而不是关应用;语音频道是开着的房间,不是电话;还有,划开免费和 Nitro 的是上限,不是功能。握住这五条,剩下的菜单可以边点边学。

开始时要做的事也可以压缩成两件。一件是第一天就把两步验证和私信接收范围设好;另一件是每进一个新服务器,就顺手把通知改成仅@提及。人们在 Discord 上的糟糕经历,大多从跳过这两处开始。
