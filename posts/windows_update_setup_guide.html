업데이트 설정 화면의 큰 그림 — 무엇을 정하고 무엇은 정할 수 없는가

Windows 11의 업데이트 설정은 시작 > 설정 > Windows 업데이트에서 시작한다. Microsoft의 업데이트 FAQ는 Windows가 장치를 안전하고 최신 상태로 유지하기 위해 업데이트를 자동으로 다운로드하고 설치한다고 설명한다. 같은 문서는 업데이트를 완전히 중지할 수는 없고 일시적으로 중지할 수 있다는 점도 밝힌다. 이 문장이 설정 화면 전체를 읽는 기준이 된다. 화면의 거의 모든 항목은 「받을지 말지」를 정하는 스위치가 아니라 「언제, 어떤 방식으로, 얼마나 늦출 수 있는가」를 정하는 손잡이다.

설정 화면의 항목은 역할로 나누면 세 부류다.

  • 시점을 정하는 항목: 업데이트 일시 중지, 활성 시간, 다시 시작 예약. 설치 자체를 막지 않고 설치·재시작이 일어나는 때를 조정한다.
  • 받는 범위를 정하는 항목: 사용 가능한 즉시 최신 업데이트 받기, 선택적 업데이트. 정기 보안 업데이트 외에 무엇을 더 받는지를 다룬다.
  • 받는 방식을 정하는 항목: 배달 최적화. 같은 업데이트를 어디서 내려받고 얼마나 내보내는지를 정한다.

여기에 사후 도구가 둘 붙는다. 업데이트 기록(설치된 것을 보고 일부를 제거)과 문제 해결(설치가 실패할 때)이다. 아래 표는 항목별로 문서가 적은 위치, 하는 일, 문서에 적힌 한도를 한 번에 정리한 것이다. 각 항목의 조건과 예외는 이어지는 절에서 푼다.

표의 마지막 열에 적힌 값은 모두 문서에서 옮긴 것이다. 일시 중지는 35일, 활성 시간은 기본 오전 8시~오후 5시와 최대 18시간(Learn 문서), 배달 최적화는 월간 업로드 한도 1GB~500GB 설정이다. 완전 중지에 대해서는 FAQ 가 「업데이트를 완전히 중지할 수는 없습니다」라고 적고, 업데이트 설정에 관계없이 결국 업데이트를 다운로드하고 설치해야 한다고 설명한다.

기능 업데이트, 품질 업데이트, 선택적 업데이트 — 무엇이 어떻게 다른가

업데이트 FAQ는 업데이트를 두 종류로 나눈다. 기능 업데이트는 연 1회 릴리스되며 새 기능을 담는다. 품질 업데이트는 그보다 자주 나오며 보안 및 버그 수정을 담는다. 설정 화면에서 일시 중지·활성 시간·다시 시작 예약은 두 종류에 모두 걸린다. FAQ 는 기능 업데이트를 새 기능을 담은 연 1회 릴리스로, 품질 업데이트를 더 자주 제공되는 보안 및 버그 수정으로만 설명하며, 두 종류의 크기나 위험을 서로 비교하지는 않는다.

세 번째 범주인 선택적 업데이트는 월별 누적 업데이트 외에 새로운 기능과 비보안 변경 내용을 제공하는 업데이트로 설명된다. Microsoft Learn 의 「Windows 업데이트 클라이언트 정책 구성」(IT 관리자용 문서)은 「선택적 업데이트 설치는 Windows 업데이트 클라이언트 정책을 사용하여 업데이트를 수신하는 디바이스에 대해 기본적으로 사용하도록 설정되지 않습니다」라고 적는다. 개인 PC 에도 같은 기본값이 적용되는지는 그 문서가 말하지 않는다. 개인 PC에서 이 범주가 어느 화면에 어떻게 표시되는지는 확인한 문서에 없어, 해당 내용은 이 글 끝의 「확인하지 못한 것」에 따로 적었다.

업데이트 일시 중지 — 최대 35일이 의미하는 것

일시 중지는 시작 > 설정 > Windows 업데이트의 업데이트 일시 중지 컨트롤에서 날짜 선택으로 한다. 문서는 현재 날짜로부터 최대 35일까지 일시 중지할 수 있다고 적고, 일정에서는 지원되는 일시 중지 기간 안의 날짜만 고를 수 있다고 한다.

동작 규칙은 네 가지다.

  • 일시 중지 동안: 다시 시작해야 할 수 있는 업데이트는 일시 중지가 끝날 때까지 다운로드되거나 설치되지 않는다. 일시 중지할 때 진행 중이던 업데이트는 취소된다고 문서가 적는다.
  • 일시 중지가 끝나면: 장치는 사용 가능한 최신 업데이트를 확인하고 다운로드하고 설치한다. 늦춘 만큼 밀린 업데이트가 한꺼번에 들어온다는 뜻이다.
  • 연장: 이미 일시 중지된 상태에서 새 종료 날짜를 고르면 오늘부터 최대 35일까지다. 이전에 일시 중지한 기간은 더해지지 않는다. 한도에 도달한 뒤 다시 일시 중지하려면 먼저 최신 업데이트를 설치해야 한다고 FAQ 가 적는다.
  • 아무 것도 하지 않으면: 일시 중지가 만료될 때 업데이트가 자동으로 다시 시작된다. 문서는 이것이 장치를 안전하고 안정적으로 유지하는 데 도움이 된다고 설명한다.

계산 예시를 하나 든다. 2026년 10월 5일에 날짜 선택에서 가능한 가장 먼 날짜를 고르면 35일 뒤인 11월 9일이 종료일이다(10월이 31일까지이므로 5일 + 35일 = 11월 9일, 계산). 이미 일시 중지 중인 10월 20일에 연장한다면 새 종료일은 오늘부터 35일 이내여야 하므로 가장 먼 날짜는 11월 24일이고(계산), 앞선 기간은 합산되지 않는다. 반대로 11월 9일에 한도에 도달한 뒤에는 다시 일시 중지하기 전에 최신 업데이트를 설치해야 한다. IT 관리자용 Learn 문서(Windows 업데이트 클라이언트 정책 구성)에도 비슷한 대목이 있다. 「35일이 지나면 일시 중지 설정이 자동으로 만료되고 … 검사합니다. 이 검사 후 … 업데이트를 다시 일시 중지할 수 있습니다」라는 문장이다. 다만 이것은 정책으로 일시 중지를 구성하는 맥락이어서, 설정 화면의 일시 중지 컨트롤이 똑같이 동작하는지는 알 수 없다. 일시 중지를 반복해 사실상 무기한으로 미루는 용도가 문서의 의도라고 읽을 근거는 없다.

일시 중지 문서는 이 기능이 필요한 장면을 직접 든다. 「여행 중이거나, 컨퍼런스 참석 중이거나, 휴가 중이거나, 중요한 프레젠테이션이나 마감일 중에 방해가 되는 것을 피하고 싶다면」 시간이 더 필요할 때 업데이트를 일시 중지할 수 있다는 것이다. 종료 날짜는 직접 고르므로 달력에 적어 두면 만료 뒤의 확인·다운로드·설치를 예상할 수 있다.

활성 시간 — 자동과 수동, 기본값과 최대 길이

활성 시간은 장치를 쓰고 있을 것으로 예상하는 시간대다. Learn 문서는 업데이트가 활성 시간 밖에서 설치된 뒤 자동으로 다시 시작된다고 설명한다. 즉 활성 시간은 재시작 시점을 밀어내는 장치이지 설치를 막는 장치가 아니다.

Windows 11에서 위치는 설정 > Windows 업데이트 > 고급 옵션 > 활성 시간이다. 활성 시간 조정은 자동으로와 수동으로 중에서 고른다. 자동은 사용 패턴에 따라 Windows가 조정하고, 수동은 시작·종료 시각을 직접 정한다.

  • 기본값: Learn 문서는 PC의 기본 활성 시간을 오전 8시부터 오후 5시까지라고 적는다. 9시간이다(계산).
  • 최대 길이: 같은 문서는 최대 활성 시간 범위가 시작 시각부터 계산된다고 적고, 「Windows 10 버전 1607 및 Windows Server 2016 최대 활성 시간 길이는 12입니다. 이후 버전은 최대 활성 시간 길이 18시간을 지원합니다」라고 밝힌다. 즉 1607 은 12시간이고, 그 다음 버전부터 18시간이다. 18시간 기준으로 시작을 오전 8시로 잡으면 이론상 다음 날 오전 2시까지 걸 수 있다(계산).
  • 범위의 한계: 이 18시간은 IT 관리자용 문서에서 정책 설정 맥락으로 나온 값이다. 개인 PC의 설정 화면에서 같은 값이 그대로 슬라이더 최대치로 나타나는지는 이 문서만으로는 알 수 없다.

Learn 문서는 관리자용 최대 활성 시간 범위 설정의 목적을 「업데이트 설치에 충분한 시간을 허용하면서 사용자 쪽에서 활성 시간 동안 결정의 일부를 유연하게 남겨 두는 것」이라고 설명한다. 이 문서가 개인 설정의 권장 길이를 제시하는 것은 아니다. 개인 사용자 쪽 안내는 FAQ 에 있다. 장치를 사용하지 않을 때만 업데이트를 위해 자동으로 다시 시작하도록 사용 시간을 설정할 수 있다는 문장이다.

다시 시작 예약과 알림 — 재시작을 언제 일으킬지 고르는 법

업데이트 설치가 끝나도 다시 시작해야 적용되는 경우가 있다. FAQ 는 이때 Windows 가 장치가 사용되고 있지 않을 때 다시 시작을 시도하고, 그렇게 할 수 없으면 편리한 시간에 다시 시작하도록 예약하라는 메시지를 표시한다고 설명한다. 언제든 직접 예약하는 방법도 같은 FAQ 에 있다. 시작 > 설정 > Windows 업데이트를 선택하고 다시 시작 예약을 선택한 뒤 편리한 시간을 고르는 것이다. 활성 시간이 「이 시간에는 재시작하지 말라」는 쪽이라면 다시 시작 예약은 「이 시각에 재시작하라」는 쪽이다.

Learn 문서의 재시작 관련 서술 중 개인 사용자에게 의미 있는 부분은 다음과 같다.

  • Windows는 업데이트를 설치한 뒤 활성 시간 밖에서 자동으로 다시 시작하려고 시도한다.
  • 기본 기간인 7일 후에도 다시 시작이 성공하지 못하면 사용자에게 다시 시작이 필요하다는 알림이 표시된다. 「약속된 다시 시작」 절은 같은 내용을 「기본 7일 기간이 끝나면 Windows가 사용자 예약 다시 시작으로 전환됩니다」라고 적는다.
  • 정책 「예약된 자동 업데이트 설치 시 로그온한 사용자가 있을 경우 자동 다시 시작 사용 안 함」의 설명에 따르면, 사용자가 업데이트 알림에서 다시 시작을 예약한 경우 사용자가 지정한 시간에는 사용자가 로그인해 있어도 장치가 다시 시작된다.

두 번째 항목의 7일에는 단서가 붙는다. 같은 문서에서 이 기간을 바꾸는 정책(업데이트를 설치하기 위해 자동 다시 시작하기 전에 기한 지정)과 약속된 다시 시작의 전환 기간을 조정하는 정책은 모두 레거시 정책이며 Windows 11에는 적용되지 않는다고 표시된다. 그래서 Windows 11 설정 화면이 같은 7일을 쓰는지는 문서가 직접 말하지 않는다. 문서에서 확인되는 것은 기본 7일, 그 뒤 사용자 예약 다시 시작으로의 전환까지다.

세 번째 항목은 적용 범위가 좁다. 이 문장은 정책 설명 안에 있고, 문서는 그 정책이 자동 업데이트 구성이 옵션 4 - 자동 다운로드 및 설치 예약으로 설정된 경우에만 적용된다고 밝힌다. 따라서 모든 개인 PC 에서 성립하는 일반 동작으로 읽으면 안 된다. 같은 문서는 이 정책이 설명에 따라 정확히 작동하지 않는다는 점도 적는다.

「사용 가능한 즉시 최신 업데이트 받기」 — 켜면 무엇이 달라지나

Microsoft는 비보안 업데이트를 제어된 기능 출시(CFR)로 점진적으로 배포한다고 문서에서 설명한다. 시작 > 설정 > Windows 업데이트에서 사용 가능한 즉시 최신 업데이트를 받으세요 토글을 켜면 이 과정을 앞당길 수 있다.

  • 보안 업데이트와의 관계: 토글 상태와 관계없이 정기 보안 업데이트는 계속 제공된다. 토글은 보안 패치의 수신 여부를 정하지 않는다.
  • 활성 시간: 문서는 이 설정이 활성 사용 시간을 존중한다고 적는다.
  • 재시작: 재시작이 필요한 일부 업데이트는 다음 누적 업데이트(LCU)와 결합되어 재시작 횟수를 줄인다고 설명된다.
  • 해제: 언제든 비활성화할 수 있다.

문서가 말하는 차이는 비보안 업데이트가 점진 배포(CFR)의 순서를 기다리느냐, 토글로 그 과정을 앞당기느냐이다. 이 토글과 일시 중지를 함께 쓸 때 어느 쪽이 우선하는지는 확인한 문서에 없다.

배달 최적화 — 다른 장치에서 받는 것과 내보내는 양

배달 최적화는 Windows 업데이트, Microsoft Store 앱, 기타 Microsoft 제품을 내려받는 클라우드 기반 시스템이다. 「전달 최적화」로 부르는 경우도 있지만 한국어판 문서의 화면 이름은 「배달 최적화」다. 위치는 시작 > 설정 > Windows 업데이트 > 고급 옵션 > 배달 최적화다.

다운로드 출처는 두 가지 중에서 정한다.

  • 내 로컬 네트워크의 장치만: 같은 공유기에 연결된 다른 PC와 업데이트 조각을 주고받는다.
  • 인터넷 및 로컬 네트워크의 장치: 인터넷상의 다른 장치도 출처가 된다.

대역폭은 두 방식으로 제한한다. 하나는 절대 대역폭(Mbps 단위)이고 다른 하나는 측정된 대역폭의 백분율이다. 문서는 「대역폭 제한은 자동 업데이트 다운로드에 대한 배달 최적화에만 적용됩니다」라고 적고, 설정에서 Windows를 업데이트하거나 앱을 내려받는 식으로 수동 다운로드를 시작하면 설정한 대역폭 제한이 적용되지 않는다고 덧붙인다. 월간 업로드 한도는 이와 별도로 업로드 옵션에서 1GB에서 500GB 사이로 고르며, 위 문장이 이 한도의 적용 범위까지 말하는지는 문서에 없다.

이 절에서 판단이 필요한 쪽은 업로드다. 종량제 회선이나 모바일 핫스팟에 연결된 PC는 월간 업로드 한도를 낮추거나 출처를 로컬 네트워크로 한정해 두면 의도하지 않은 데이터 사용을 줄이는 방향으로 설정을 잡을 수 있다. 다만 어떤 조합이 실제로 몇 MB를 줄이는지는 문서에 수치가 없어 말할 수 없다.

업데이트 기록과 제거 — 되돌리기 전에 알아둘 것

설치된 업데이트는 설정 > Windows 업데이트 > 기록 업데이트에서 본다. 제거 경로는 Microsoft 지원 문서에 시작 > 설정 > Windows 업데이트 > 추가 옵션 > 기록 업데이트 > 업데이트 제거의 순서로 적혀 있다(업데이트 제거는 관련 설정에 있다). 문서는 목록에서 제거할 업데이트를 선택한 다음 제거를 선택하라고 안내하며, 일부 업데이트는 제거할 수 없다고 명시한다. Windows에 접근할 수 없을 때는 복구 환경(Windows RE)에서 문제 해결 > 고급 옵션으로 제거하는 방법이 따로 소개된다.

  1. 문제가 업데이트 직후부터 시작됐는지 시각을 먼저 대조한다. 기록 업데이트 목록에서 증상 시작 시점과 가까운 항목이 있는지 찾는다.
  2. 해당 항목이 제거 가능한지 본다. 문서가 일부 업데이트는 제거할 수 없다고 하므로, 목록에서 제거할 수 없는 항목이 있을 수 있다.
  3. 보안 업데이트라면 제거의 위험을 먼저 이해한다. 문서가 보안 업데이트 제거 전에 위험을 이해하라고 안내한다. 같은 문서는 Windows 11 을 쓰는 경우 먼저 Windows 버전을 다시 설치해 볼 것도 함께 안내한다.
  4. 제거 뒤에는 같은 업데이트가 다시 자동 설치될 수 있으므로 일시 중지의 날짜를 어떻게 쓸지 함께 판단한다. 다만 문서는 제거한 업데이트의 재설치 동작을 상세히 적지 않는다.

성능 문제가 의심되면 작업 관리자로 병목을 먼저 특정하는 절차가 먼저이고, 설정 전반의 점검 목록은 Windows 11 최적화 가이드에 있다. 업데이트 확인을 정기 작업으로 묶는 방법은 Windows 자동화 입문이 다룬다. 업데이트 화면 항목 자체의 설명은 위 절들에서 끝난다.

설치가 실패할 때 확인하는 순서

Microsoft 지원의 업데이트 문제 해결 문서는 기본 해결 방법을 10가지로 제시한다. 순서는 다음과 같다.

순서문서가 제시한 점검보충
1자동화된 문제 해결사 실행설정 > 시스템 > 문제 해결에서 연다
2장치가 제대로 연결되어 있고 인터넷에 연결되어 있는지 확인전원 연결과 인터넷 연결을 확인한다. 안정적인 인터넷 연결이 중요하다
3관리자 권한 확인일부 업데이트에 필요하다
4외부 하드웨어 분리기본 기능에 필요하지 않은 외장형 저장 장치·드라이브·도크 등을 모두 제거하고 업데이트를 다시 실행한다
5업데이트 캐시 초기화손상된 파일이 오류를 일으킬 수 있다
6날짜·시간 설정 확인자동 동기화를 켠다
7타사 드라이버 업데이트제조업체 웹사이트에서 확인한다
8디스크 공간 확보문서는 32비트 16GB, 64비트 20GB 이상이라고 적는다
9업데이트 다시 실행추가 업데이트가 남아 있을 수 있다
10장치 다시 시작변경 사항을 적용한다

문서는 이 열 가지를 「Windows 업데이트 문제를 해결하는 데 도움이 되는 다음 일반적인 문제 해결 단계를 시도해 보세요」라는 문구 아래 1단계부터 번호순으로 제시하며, 시도하기 전에 개인 파일을 백업하라고 먼저 당부한다. 어느 단계의 비용이 낮은지, 어느 단계가 원인이 되는 일이 잦은지는 문서에 적혀 있지 않다. 문서는 오류 코드별 대응(예를 들어 0x8007000d, 0x800705b4)과 DISM·SFC 같은 시스템 파일 복구 도구, 새로 설치 도구를 고급 옵션으로 소개한다. 오류 코드가 화면에 나온다면 그 코드를 문서의 목록에서 먼저 찾는다.

디스크 공간은 기능 업데이트에서 특히 문제가 된다. FAQ는 디스크 공간이 부족하면 파일을 정리하거나 외장 드라이브를 쓰라고 권한다. 여유 공간이 모자란 PC에서는 일시 중지로 시간을 버는 것보다 저장 공간을 먼저 확보해야 같은 실패가 반복되지 않는다.

영구 차단을 쓰지 않는 이유 — 설정이 아니라 시점의 문제로 다루기

업데이트가 불편할 때 그룹 정책이나 레지스트리로 아예 막는 방법을 찾는 사람이 많다. 그 방법은 여기서 다루지 않는다. 이유는 세 가지다.

  • 문서가 정한 기본 방침이 「자동 설치」이고 중지는 일시적인 것으로만 허용된다.
  • Learn 문서는 Windows 레지스트리를 직접 편집하는 방법을 권장하지 않는다고 반복해서 적는다.
  • 재시작이 문제라면 활성 시간·다시 시작 예약으로, 시점이 문제라면 일시 중지로 대부분 해결되며, 그 범위를 넘는 요구는 관리 도구의 영역이다.

관리되는 장치는 관리자가 정한 정책이 우선하고, 설정 화면의 일부 항목이 회색으로 표시되거나 조직이 관리한다는 문구가 나올 수 있다. 이 경우 개인이 바꾸는 것이 아니라 관리자에게 요청하는 것이 맞다. 또 Windows 10은 지원이 2025년 10월 14일에 종료됐다고 문서가 알린다. 아직 Windows 10을 쓰는 장치는 업데이트 설정을 만지기 전에 Windows 11 이전 여부를 먼저 정해야 한다.

확인하지 못한 것

  • 보안 업데이트를 무기한 미루지 말라는 명시적 권고 문장. 일시 중지 문서에는 만료 후 자동 재개가 장치를 안전하고 안정적으로 유지하는 데 도움이 된다는 설명만 있었고, 별도 권고 문장은 찾지 못했다.
  • 일시 중지 한도에 도달한 뒤 다시 일시 중지하기 전에 설치해야 하는 「최신 업데이트」가 정확히 무엇인지, 그리고 IT 관리자용 정책 문서의 35일 만료 후 재일시 중지 문장이 설정 화면에도 똑같이 적용되는지.
  • 개인 PC의 활성 시간 화면에서 최대 길이가 18시간으로 나타나는지(18시간은 Learn의 IT 관리자용 문서 수치). 해당 Learn 문서는 기계 번역본이다.
  • Windows 11 설정 화면에서 자동 재시작이 알림으로 전환되는 기간이 문서의 기본 7일과 같은지(이 기간을 바꾸는 정책이 Windows 11 에는 적용되지 않는 레거시라고 표시되어 있다).
  • 선택적 업데이트가 개인 PC 설정 화면의 어느 항목에 어떻게 표시되는지, 설치 순서.
  • 배달 최적화 옵션별 실제 데이터 절감량. 문서에 수치가 없다.
  • 이 PC에서 화면을 직접 열어 대조하지 못했다. 위치와 명칭은 모두 문서 문구 기준이며 빌드에 따라 다를 수 있다. Windows 10 화면 차이, Insider 채널, 그룹 정책·MDM 구성은 범위에서 제외했다.
