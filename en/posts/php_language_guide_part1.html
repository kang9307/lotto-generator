Introduction to PHP

PHP stands for "PHP: Hypertext Preprocessor" and is a scripting language that runs on the web server. It is typically embedded in HTML to generate dynamic web pages.

Key Features of PHP

  • Server-side scripting: Code runs on the server, and only the resulting output is sent to the client.
  • Cross-platform: Runs on Windows, Linux, macOS, and many other operating systems.
  • Database integration: Integrates easily with MySQL, PostgreSQL, SQLite, and many other databases.
  • Open source: Free to use and backed by a large developer community.
  • Feature rich: Provides built-in support for file uploads, email, PDF generation, and much more.

Where PHP Is Used

  • Web application development
  • Content management systems (WordPress, Joomla, Drupal)
  • E-commerce platforms (Magento, WooCommerce)
  • Forums and social networking sites
  • REST APIs and web services

PHP vs. Other Backend Languages

Language Strengths Weaknesses
PHP Gentle learning curve, abundant documentation, broad hosting support Inconsistent APIs, type-safety issues (prior to PHP 7)
Node.js Asynchronous I/O, rich JavaScript ecosystem Callback hell, relatively new technology
Python Readability, vast library ecosystem Slower performance, GIL-limited multithreading
Ruby Elegant syntax, high developer productivity Slower execution, narrower hosting options

Installing and Configuring PHP

Installing PHP on Windows

  1. Download PHP

    • Download the latest release from the official PHP site
    • The Thread Safe build is recommended

  2. Install and configure

    C:\> mkdir C:\PHP
C:\> Extract the downloaded ZIP file into C:\PHP
C:\> cd C:\PHP
C:\PHP> copy php.ini-development php.ini

  3. Set environment variables

    • System Properties → Advanced → Environment Variables → add C:\PHP to Path

  4. Web server integration

    • Works with Apache, IIS, or PHP's built-in web server

Installing PHP on Linux (Ubuntu)

sudo apt update
sudo apt install php php-cli php-fpm php-mysql php-json php-common

Installing PHP on macOS

brew install php

Setting Up the Development Environment

  1. Install an IDE

    • PHPStorm: a powerful commercial IDE
    • Visual Studio Code + PHP extensions: a free alternative
    • Sublime Text: a lightweight and fast editor

  2. Install a local web server

    • XAMPP: supports Windows, Linux, and macOS
    • WAMP: Windows only
    • MAMP: macOS only

  3. Install Composer (the PHP package manager)

    curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer

Key Settings in php.ini

; Memory limit
memory_limit = 128M

; Maximum execution time (seconds)
max_execution_time = 30

; File upload settings
upload_max_filesize = 2M
post_max_size = 8M

; Error display settings (development)
display_errors = On
error_reporting = E_ALL

; Error display settings (production)
; display_errors = Off
; error_reporting = E_ALL & ~E_DEPRECATED & ~E_STRICT
