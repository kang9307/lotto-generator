はじめに：パッシブ投資の二つの選択肢

「市場平均に勝ち続けることは難しい。市場に連動する運用の方が、長期的には多くの投資家にとって合理的だ」——この考え方が広まるにつれ、パッシブ投資（インデックス投資）が個人投資家に定着しました。その代表的な手段がインデックスファンドとETF（上場投資信託）です。

この二つは「市場指数に連動する」という点では共通しますが、仕組みや使い勝手に重要な違いがあります。どちらが絶対的に優れているというわけではなく、投資家のスタイルや状況によって向き・不向きが異なります。本記事では、取引方法・コスト・税金・自動積立・最低投資額の5つの観点から両者を比較し、どのような人にどちらが向いているかを整理します。税制と取引ルールは日本の制度を前提にしています。

なお、本記事は情報・教育目的であり、特定商品への投資を推奨するものではありません。

インデックスファンドとETFとは

インデックスファンドとは

インデックスファンドとは、日経平均株価やTOPIX、S&P500などの特定の市場指数（インデックス）に連動するように設計された投資信託です。ファンドマネージャーが個別銘柄を選ぶ「アクティブ運用」とは異なり、指数の構成銘柄をその比率通りに保有するため、運用コストが低く、値動きが指数とほぼ一致します。

投資家は証券会社や銀行を通じて購入を申し込み、申込締切後に算出される基準価額で取引が成立します。申込の時点では、いくらで約定するかは分かりません。

ETF（上場投資信託）とは

ETF（Exchange Traded Fund）は、文字通り証券取引所に上場された投資信託です。インデックスファンドと同様に市場指数に連動しますが、株式のように取引所でリアルタイムに売買できる点が根本的な違いです。東証には日経平均株価やTOPIXに連動するETFが数多く上場しており、運用会社ごとに名称が違うため、名前よりも連動対象の指数と信託報酬を先に見る方が確実です。

取引方法の比較 — リアルタイムか1日1回か

両者のいちばん大きな違いはここにあります。

項目インデックスファンドETF
取引の仕組み1日1回、基準価額で約定取引所で市場価格により売買
取引時間申込はいつでも可能。販売会社の締切時刻の前か後かで適用される基準価額が変わる東証の立会時間：前場9:00〜11:30、後場12:30〜15:30（JPX、2026-09-29確認）
価格の透明性基準価額は取引終了後に算出・公表リアルタイムで市場価格を確認可能
換金代金目論見書に記載された受渡日に入金（ファンドごとに異なる）約定した瞬間に価格が確定し、代金は受渡日に入金
注文方法金額指定・口数指定指値・成行などの注文方法が使える

東証の立会時間は2024年11月に延長され、現在の後場は15時30分までです（JPXの「売買立会時」のページ、同ページは2024年11月4日更新）。注文はJPXの案内では午前立会は8時から、午後立会は12時5分から受け付けられます。ETFはこの立会時間内でしか売買できません。

長期の積立投資を目的とする場合、1日1回の基準価額取引で十分なケースがほとんどです。短期の値動きに反応しにくくなる分、かえって続けやすいとも言えます。一方、リアルタイムで価格を見ながら売買したい場合や、特定の価格帯で購入したい場合はETFが有利です。ただし、ETFを株式のように頻繁に売買すると、売買手数料やスプレッドが積み重なり不利になる場合があります。

コスト（信託報酬）の比較

信託報酬と実質コスト

パッシブ投資の最大の魅力の一つが低コストです。信託報酬は保有している間ずっとかかるコストであり、長期運用では複利の力によって小さな差が大きな影響をもたらします。

コスト項目インデックスファンドETF
信託報酬（年率）例：0.1%〜0.5%程度（商品により差）例：0.03%〜0.15%程度（主要指数の大型ETF）
売買手数料なし〜わずか証券会社の売買手数料（証券会社ごとに異なる）
売買スプレッドなしあり（流動性が低いETFは注意）
販売手数料ノーロード（販売手数料なし）の商品が多い（一部あり）なし

表の信託報酬の範囲は理解を助けるための例示で、統計値ではありません。実際の信託報酬は商品ごとに異なり、引き下げられることもあります。信託報酬のみで比較するとETFが低い傾向にありますが、ETFには売買スプレッドが存在し、売買量が少ない小型ETFはスプレッドが広がりやすいため、コストを過小評価しないよう注意が必要です。信託報酬に加えて、ファンドの実際の騰落率と指数の騰落率の差（トラッキングエラー）も見ておくと、指数にどれだけ忠実に連動しているかが分かります。

コストの差がどれくらい積み上がるかをつかむための計算例です。100万円を10年間保有し、信託報酬を差し引く前の利回りを年5%、信託報酬は毎年1回差し引く、税金と売買コストは含めない、という前提で計算すると、信託報酬が年0.1%なら約161.3万円、年0.5%なら約154.9万円で、差は約6.3万円です。利回りが0%でも差は約3.9万円になります。実際の金額は商品と相場によって変わるため、投資前に目論見書と運用報告書で実質コストを確認してください。

税金の比較 — 日本の場合、2026年9月時点

注意：以下は日本の税制の一般的な概要で、2026年9月29日に国税庁・金融庁の案内に合わせて見直しました。税制は改正される場合があります。ご自身に適用される扱いは国税庁や税務署、税理士にご確認ください。

課税口座（特定口座・一般口座）での税金

国税庁のタックスアンサー（No.1463、令和8年4月1日現在の法令等）では、上場株式やETF、公募の株式投資信託は「上場株式等」に区分され、その譲渡所得等は、一般株式等とは別の申告分離課税とされています。上場株式等の譲渡損失を一般株式等の譲渡所得等から差し引くことはできません。

区分売却益（譲渡所得等）分配金（配当等）
国内上場ETF・公募株式投資信託（課税口座）申告分離課税 20.315%（所得税15%＋復興特別所得税0.315%＋住民税5%）20.315%（申告方法により扱いが異なる）
NISA口座非課税（非課税保有限度額の範囲内）非課税（非課税保有限度額の範囲内）

国税庁のタックスアンサーNo.1331によると、上場株式等の配当等について申告分離課税を選んだ場合の税率は20.315%（所得税および復興特別所得税15.315%、地方税5%）です。上場株式等の譲渡損失がある場合は、一定の要件のもとで、申告分離課税を選択した上場株式等の配当所得等から差し引くことができます。日本では、ETFと投資信託で基本的な税率の差はほとんどありません。差が出るのは、どの口座で持つかです。

新しいNISAの枠（2024年1月から）

金融庁のNISA特設ウェブサイトによると、2024年からの新しいNISAの枠は次のとおりです。

  • つみたて投資枠：年間120万円。対象は「長期の積立・分散投資に適した一定の投資信託等」
  • 成長投資枠：年間240万円。つみたて投資枠と併用でき、年間の合計は最大360万円
  • 非課税保有限度額（総枠）：1,800万円（うち成長投資枠は1,200万円まで）

同じページによると、非課税保有期間は無期限となり、制度は恒久化されました。枠を使った商品を売却すると、その商品の簿価分の枠が翌年以降に復活します。iDeCo（個人型確定拠出年金）も税制優遇のある制度ですが、拠出限度額や受取時の課税は別の仕組みです。制度の詳細は金融庁や証券会社の公式情報で確認してください。

最低投資金額の比較

項目インデックスファンドETF
最低投資金額商品・販売会社による（例：100円から）売買単位の口数×価格（例：数百円〜数万円以上）
少額投資金額指定が可能で使いやすい一部の証券会社で売買単位未満の購入に対応
積立のしやすさ毎月定額で設定しやすい口数単位のため指定金額ぴったりになりにくい

インデックスファンド（投資信託）は金額を指定して購入するため、月1,000円・1万円など自分のペースで積み立てやすい設計です。ETFは売買単位の口数で購入するため、ちょうど指定金額ぴったりになりにくいことがあります。ただし、一部の証券会社は売買単位未満の少額購入に対応しています。表の金額は例示で、商品と証券会社によって異なります。

自動積立（定期買付）の比較

会社員や忙しい投資家にとって、自動積立はとても重要な機能です。

項目インデックスファンドETF
自動積立への対応多くの証券会社・銀行で対応対応している証券会社もあるが限定的
設定のしやすさ金額指定で簡単設定証券会社のサービス内容による
ほったらかし投資向いている証券会社の定期買付サービスがあれば可能

毎月自動で一定金額を積み立てる「ドルコスト平均法」を実践したい場合、インデックスファンドは非常に使いやすい設計です。「毎月1万円を自動で積み立て」というシンプルな設定が多くの証券会社で対応しています。NISAのつみたて投資枠も、対象が長期の積立・分散投資に適した一定の投資信託等に絞られているため、この使い方と相性がよい枠です。ETFでも一部の証券会社は定期買付サービスを提供していますが、全社対応ではないため事前確認が必要です。

メリット・デメリットのまとめ

インデックスファンドのメリット・デメリット

  • メリット：自動積立が容易、金額指定で購入しやすい、取引がシンプル、感情的な売買を抑制しやすい、NISAのつみたて投資枠で積み立てやすい
  • デメリット：リアルタイム取引不可、大型ETFより信託報酬が高い場合がある、日中の価格確認ができない、換金代金の入金まで営業日がかかる

ETFのメリット・デメリット

  • メリット：リアルタイム売買が可能、主要指数の大型ETFは信託報酬が非常に低い、透明性が高い（保有資産の毎日開示）、多様な資産クラス・テーマに投資可能
  • デメリット：売買スプレッドや売買手数料が発生する可能性、衝動的な売買リスク、自動積立が限定的、小型ETFは流動性リスクがある

どちらを選ぶべきか — 判断基準

どちらかが絶対的に正しいという答えはありません。ご自身の投資スタイルと状況に合う方を選ぶことが大切です。

あなたの優先事項参考になる選択肢
毎月自動でコツコツ積み立てたいインデックスファンド
コストを徹底的に抑えたいETF（大型指数連動）
手間をかけずほったらかし投資インデックスファンド
多様なテーマ・資産に分散投資したいETF
リアルタイムで価格を見ながら取引したいETF
投資初心者で何から始めればいいか分からないインデックスファンドまたは大型ETF

両方を組み合わせる方法もある

多くの長期投資家が両方を組み合わせて活用しています。たとえば毎月の積立はインデックスファンドで自動化し、まとまった資金が入ったときは低コストETFを追加購入するという方法です。税金の面では、商品の種類よりも「NISAの枠の中で持つか、課税口座で持つか」の方が結果を大きく左右します。どちらの枠でどの商品を買えるかは、金融庁と証券会社の案内で対象商品を確かめてから決めてください。どちらが「最高」かよりも、長く続けられる方法を選ぶことが最も重要です。

まとめ：継続こそ最大の戦略

インデックスファンドとETFはどちらも優れたパッシブ投資手段です。重要な違いは取引方法・コスト・自動積立の便利さで、日本の税制では課税口座ならどちらも20.315%、NISAの枠内ならどちらも非課税という点で大きな差はありません。長期的な資産形成における本質は低コストで分散投資を継続することです。

どちらを選ぶにしても、自分のライフスタイルと投資スタイルに合った方を選び、焦らず長期で続けることが最も大切です。

本記事の数値や税制情報は2026年9月29日時点のもので、商品や時期によって変わる可能性があります。最新情報は必ず公式機関で確認し、必要に応じて専門家にご相談ください。

## 1. 何が違うか（一覧）

| 項目 | インデックスファンド | ETF |
|---|---|---|
| 取引の仕組み | 1日1回、申込締切後に算出される基準価額で約定 | 取引所で市場価格により売買 |
| 取引時間 | 申込はいつでも可能（締切時刻の前後で適用基準価額が変わる） | 東証 前場9:00〜11:30・後場12:30〜15:30 |
| 換金代金 | 目論見書記載の受渡日（ファンドごとに異なる） | 約定時に価格確定、受渡日に入金 |
| 売買コスト | なし〜わずか | 売買手数料、売買スプレッド |
| 販売手数料 | ノーロードの商品が多い（一部あり） | なし |
| 自動積立 | 多くの証券会社・銀行で対応（金額指定） | 証券会社のサービスによる |

信託報酬の例（インデックスファンド年0.1〜0.5%程度、大型ETF年0.03〜0.15%程度）は例示であり、統計値ではありません。

## 2. 自分に合う方を選ぶ

| 自分の状況 | 参考になる選択肢 |
|---|---|
| 毎月自動でコツコツ積み立てたい | インデックスファンド |
| コストを徹底的に抑えたい | ETF（大型指数連動） |
| 手間をかけずほったらかしにしたい | インデックスファンド |
| 多様なテーマ・資産に分散したい | ETF |
| リアルタイムで価格を見ながら売買したい | ETF |
| 投資初心者 | インデックスファンドまたは大型ETF |

## 3. 買う前のチェック

- [ ] 連動対象の指数を目論見書で確認したか（商品名より指数が先）
- [ ] 同じ指数に連動する商品同士で信託報酬を比べたか
- [ ] ETFなら出来高が十分で、売買スプレッドが狭いか
- [ ] トラッキングエラー（ファンドの騰落率と指数の騰落率の差）を見たか
- [ ] 投資信託なら換金代金の受渡日を目論見書で確認したか
- [ ] NISAの枠（つみたて投資枠・成長投資枠）で買えるか、証券会社の案内で確認したか
- [ ] 証券会社の売買手数料・定期買付・売買単位未満の購入サービスを確認したか

## 5. コスト差の感覚をつかむ（計算例）
