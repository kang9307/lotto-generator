貧血とは?

貧血(Anemia)とは、血液中の赤血球数またはヘモグロビン濃度が正常値より低い状態を指します。ヘモグロビンは全身に酸素を運ぶ重要な役割を担っているため、貧血があると組織に十分な酸素が供給されず、さまざまな症状が現れます。

正常なヘモグロビン値

年齢・性別ごとの正常値

成人男性: ヘモグロビン 13.0 g/dL 未満で貧血
非妊娠成人女性: 12.0 g/dL 未満
妊婦: 第1・第3期は 11.0 g/dL 未満、第2期は 10.5 g/dL 未満
※ 小児・青年は年齢別の基準が別にあります(WHO 2024)

貧血の重症度分類

  • 軽度貧血: 男性 11.0-12.9 g/dL、非妊娠女性 11.0-11.9 g/dL
  • 中等度貧血: 8.0-10.9 g/dL(男性・非妊娠女性)
  • 重度貧血: 8.0 g/dL 未満(男性・非妊娠女性)
  • 妊婦: 軽度 10.0-10.9、中等度 7.0-9.9、重度 7.0 g/dL 未満

WHOの2024年ガイドラインの値です(2026-09-29確認)。検査室ごとに基準範囲や機器が異なるため、最終判定は医療者が行います。小児は年齢別の基準が別にあり、この記事では扱いません。

貧血と息切れの関連性

なぜ貧血があると息が切れるのか?

酸素運搬能力の低下

  1. ヘモグロビンの減少: 酸素運搬能力の直接的な低下
  2. 組織の酸素不足: 細胞代謝に必要な酸素供給の不足
  3. 代償機構の作動: 心臓と肺がより強く働こうとする
  4. 呼吸数の増加: 不足した酸素を補おうとする身体の反応

代償機構のプロセス

貧血発生 → 組織の酸素不足を感知 → 心拍数増加 → 呼吸数増加 → 息切れ感

息切れの特徴

貧血による息切れの様相

  • 運動時に悪化: 階段の昇降や早歩きで強くなる
  • 徐々に進行: ゆっくり悪化する傾向
  • 安静時にも発生: 重度貧血ではじっとしていても息切れ
  • 随伴症状: 疲労、めまい、動悸を伴う

貧血の主な原因

1. 鉄欠乏性貧血(最も多い)

原因

  • 出血: 月経過多、消化管出血、痔など
  • 鉄分摂取不足: 偏食、ダイエット、菜食主義
  • 鉄分吸収障害: 胃切除術、消化器疾患
  • 鉄分需要の増加: 妊娠、授乳、成長期

特徴的な症状

  • 異食症(Pica): 氷やデンプンなど異常なものを食べたくなる
  • 眼瞼結膜の蒼白: 下まぶたの内側が白くなる
  • 爪の変化: スプーン状に反る(Spoon nail)
  • むずむず脚症候群: 脚が落ち着かず動かしたくなる

2. ビタミンB12欠乏性貧血

原因

  • 内因子不足: 萎縮性胃炎、胃切除術
  • 摂取不足: 完全菜食主義者
  • 吸収障害: クローン病、回腸疾患
  • 薬剤: メトホルミン、プロトンポンプ阻害薬の長期服用

特徴的な症状

  • 巨赤芽球性貧血: 赤血球が大きく未成熟
  • 神経症状: 手足のしびれ、歩行障害
  • 舌の変化: 舌が滑らかで赤くなる
  • 認知機能障害: 記憶力の低下、集中力の低下

3. 葉酸欠乏性貧血

原因

  • 摂取不足: 野菜・果物の摂取不足
  • 吸収障害: セリアック病、アルコール依存
  • 需要の増加: 妊娠、授乳、血液疾患
  • 薬剤: メトトレキサート、抗けいれん薬

4. 慢性疾患性貧血

原因疾患

  • 慢性炎症: 関節リウマチ、炎症性腸疾患
  • 慢性感染症: 結核、骨髄炎
  • 悪性腫瘍: 各種がん
  • 腎不全: エリスロポエチン不足

貧血の症状と段階別の進行

初期症状(軽度の貧血)

軽い活動時のみ現れる症状

  • 運動時の息切れ: 早歩きや階段昇降のとき
  • 疲れやすさ: 普段より早く疲れる
  • 集中力の低下: 業務や学習能力の低下
  • 蒼白: 顔、爪、結膜が白くなる

中等度症状

日常生活に支障をきたす症状

  • 安静時の息切れ: じっとしていても息苦しい
  • 動悸: 心拍数増加による症状
  • めまい: 起立性低血圧、立ちくらみ
  • 頭痛: 脳への酸素供給不足

重度症状(緊急事態)

直ちに治療が必要な症状

  • 安静時の呼吸困難: 横になっていても息切れ
  • 胸痛: 心臓に負担がかかって生じる痛み
  • 失神: 脳への酸素供給が著しく不足
  • 心不全症状: 下肢のむくみ、夜間の呼吸困難

胸の痛み、失神、安静時でも息が切れる症状があれば、ためらわず救急(119)や救急外来に連絡してください。この記事は診断に代わるものではなく、緊急かどうかは医療者が判断します。

貧血の診断方法

1. 基本の血液検査

全血球計算(CBC)

  • ヘモグロビン(Hb): 貧血の程度を判定
  • ヘマトクリット(Hct): 血液中の赤血球の割合
  • 平均赤血球容積(MCV): 赤血球の大きさ
  • 赤血球分布幅(RDW): 赤血球サイズの均一性

MCVによる分類

小球性貧血(MCV < 80): 鉄欠乏性、地中海貧血
正球性貧血(MCV 80-100): 慢性疾患性、急性出血性
大球性貧血(MCV > 100): B12・葉酸欠乏性
※ 境界値は検査室の基準によって多少異なります

2. 原因究明のための追加検査

鉄関連検査

  • 血清鉄(Serum Iron): 血中の鉄濃度
  • 総鉄結合能(TIBC): トランスフェリンの鉄結合能力
  • トランスフェリン飽和度: 鉄貯蔵状態の評価
  • フェリチン(Ferritin): 貯蔵鉄量を反映する指標(原因の鑑別によく使われ、解釈は医療者が判断)

ビタミン検査

  • ビタミンB12: 血中B12濃度
  • 葉酸: 血中葉酸濃度
  • ホモシステイン: B12・葉酸欠乏時に上昇
  • メチルマロン酸: B12欠乏に特異的

3. 出血原因の検査

消化管検査

  • 便潜血検査: 消化管出血のスクリーニング
  • 胃内視鏡: 上部消化管出血の確認
  • 大腸内視鏡: 下部消化管出血の確認
  • カプセル内視鏡: 小腸出血の診断

婦人科検査(女性)

  • 月経量の評価: 月経過多の確認
  • 子宮超音波: 子宮筋腫、子宮腺筋症など
  • 子宮内膜検査: 必要に応じて組織検査

貧血の治療法

この節は治療の方式を紹介するものです。薬の種類・用量・期間は診断結果に応じて医療者が決めます。鉄剤や注射薬を自分で始めたり、用量を変えたりすることはお勧めしません。

1. 鉄欠乏性貧血の治療

経口鉄剤補充

鉄剤の種類・用量・回数・期間は、診察結果を見て医療者が決めます。
韓国疾病管理庁: 鉄欠乏性貧血では最低6か月間の鉄剤服用が必要と案内しています。
※ 期間は人によって異なるため、自分で開始・中止・増量しません。

経口鉄剤服用時の注意事項

  • 副作用: 便秘、下痢、腹部不快感、黒色便
  • 吸収阻害要因: お茶、コーヒー、カルシウム、制酸薬
  • 吸収促進要因: ビタミンC、肉、魚

静脈内鉄剤治療

静注鉄剤が検討されうる状況(使うかどうかは医療者が判断):
- 経口鉄剤に耐えられない場合
- 吸収障害
- 持続的な出血
- 迅速な補充が必要な場合

2. ビタミンB12欠乏の治療

治療プロトコル

治療方式(注射または高用量の経口)・用量・期間は、原因と検査結果に応じて医療者が決めます。
内因子欠乏のように原因が続く場合は、長期の治療が必要になることがあります(NIH ODS)。

治療反応の評価

  • 初期: 網状赤血球が先に増える傾向
  • その後: ヘモグロビンが徐々に上昇
  • 回復: ヘモグロビンが正常範囲に戻る(所要期間には個人差があります)
  • 神経症状: 改善が遅い、または残ることがあるため経過観察が必要

3. 葉酸欠乏の治療

標準治療

用量・期間: 原因と検査結果に応じて医療者が決めます。
妊娠を計画中または妊娠中の葉酸補充は、産婦人科に相談します。
注意: B12欠乏を伴うかを先に確認し、治療の順序は医療者が決めます。

4. 重度貧血の緊急治療

輸血の適応

  • 輸血の要否: ヘモグロビン値だけでなく症状や全身状態を合わせて医療者が判断
  • 心血管症状: 胸痛、呼吸困難、失神
  • 血行動態不安定: 頻脈、低血圧
  • 手術予定: 手術前にヘモグロビンの状態を確認し、医療チームが対応を計画

輸血時の注意事項

  • ゆっくり輸血: 心不全の予防
  • 利尿剤の併用: 容量負荷の予防
  • 鉄過剰症: 反復輸血時は鉄キレーション療法を検討

生活習慣の改善と予防

1. 鉄分豊富な食事

ヘム鉄(吸収されやすい鉄)

  • 赤身肉: 牛肉、ラム肉
  • 内臓類: レバー、腎臓
  • 魚介類: 牡蠣、ムール貝、いわし
  • 鶏肉類: 鶏肉、鴨肉

非ヘム鉄(植物性の鉄)

  • 葉物野菜: ほうれん草、ケール、チンゲン菜
  • 豆類: レンズ豆、黒豆、豆腐
  • ナッツ類: ごま、アーモンド、カシューナッツ
  • 穀物: キヌア、オートミール、玄米

2. 鉄吸収の最適化

吸収促進の方法

食事の組み合わせ例:
- 牛肉 + ブロッコリー(ビタミンC)
- ほうれん草 + オレンジジュース
- レンズ豆 + トマトソース
- 豆腐 + パプリカ炒め

避けるべき組み合わせ

  • 鉄分食品 + お茶/コーヒー: 時間を空ける
  • 鉄剤 + カルシウム: 別の時間に服用
  • 鉄分食品 + 牛乳: 同時摂取を避ける

3. ビタミンB12の供給源

動物性食品(主な供給源)

  • 魚: サーモン、マグロ、いわし
  • 肉類: 牛肉、鶏肉
  • 乳製品: 牛乳、チーズ、ヨーグルト
  • 卵: 特に卵黄

菜食主義者向けの代替

  • 強化食品: B12強化豆乳、シリアル
  • 栄養酵母: ビタミンB12強化製品
  • サプリメント: 定期的なB12サプリの摂取

4. 葉酸の供給源

天然食品

  • 緑の葉野菜: ほうれん草、ロメインレタス、アスパラガス
  • 豆類: レンズ豆、えんどう豆、ひよこ豆
  • 果物: オレンジ、いちご、メロン
  • 穀物: 強化シリアル、全粒穀物

調理時の注意事項

  • 熱に弱い: さっと湯通し、生食
  • 水に溶けやすい: スープごと摂取
  • 保存: 新鮮なうちに早く食べる

特別な状況での貧血管理

1. 妊娠中の貧血

生理的変化

  • 血液量の増加: 妊娠中に増える
  • 相対的貧血: 血漿量がより多く増える
  • 鉄需要の増加: 米NIHは妊娠中の鉄RDAを27mg/日としています(韓国の基準は別のため医療者・栄養士に相談)

妊娠中の貧血管理

鉄・葉酸の補充: 開始時期と用量は産婦人科の医療者が決めます。
モニタリング: 妊婦健診のたびにヘモグロビンを確認
貧血の判定: 第1・第3期は 11.0 g/dL 未満、第2期は 10.5 g/dL 未満(WHO 2024)

2. 月経過多による貧血

月経過多の基準

  • 月経量: 日常生活に支障が出るほど多い
  • 月経期間: 普段より長く続く
  • 月経周期: 普段より短くなる
  • 日常生活への支障: ナプキン交換頻度の増加

管理方針

  • 婦人科相談: 根本原因の治療
  • 鉄分補充: 継続的な鉄分補充
  • ホルモン治療: 月経量の調整
  • 手術治療: 重症例では検討

3. 高齢者の貧血

原因の特徴

  • 慢性疾患: 腎疾患、がん、慢性炎症
  • 薬剤の副作用: アスピリン、抗凝固薬
  • 栄養不足: 食欲不振、吸収障害
  • 隠れた出血: 消化管がん、痔

管理時の注意点

  • 原因究明: 徹底した検査が必要
  • 薬物相互作用: 既存の服用薬との相互作用
  • 心血管リスク: 急激な補正は避ける
  • 機能評価: 日常生活能力を考慮

貧血の予防と早期発見

1. 定期健康診断

検査の周期

検診の間隔は年齢・性別・基礎疾患・服用薬によって異なり、医療者が決めます。
妊婦: 妊婦健診のたびにヘモグロビンを確認
慢性疾患のある人・高リスク群: 担当の医療者が決めた間隔で追跡

高リスク群

  • 女性: 月経過多、妊娠、授乳
  • 菜食主義者: 特にビーガン
  • 慢性疾患患者: 腎臓、心臓、消化器疾患
  • 薬剤服用者: アスピリン、抗凝固薬

2. 早期症状の認識

直ちに受診が必要な症状

  • 安静時の呼吸困難: じっとしていても息切れ
  • 胸痛: 胸の圧迫感や痛み
  • 失神: 意識を失う場合
  • 強い疲労: 日常生活が不可能なほど

医師の相談が推奨される症状

  • 持続的な疲労: 2週間以上続く
  • 運動時の息切れ: 普段より息切れしやすい
  • 蒼白: 顔、爪、結膜の蒼白
  • 異常な食欲: 氷、デンプンなど

貧血と併存疾患の管理

1. 心血管疾患と貧血

相互の影響

  • 貧血 → 心臓負担の増加: 心不全悪化の可能性
  • 心臓病 → 貧血の悪化: 腎機能低下による貧血
  • 薬物相互作用: 抗凝固薬と鉄剤

管理原則

  • 段階的補正: 急激なヘモグロビン上昇を避ける
  • 目標ヘモグロビン: 疾患・状態ごとに医療者が決める(ただ高くすればよいわけではない)
  • 水分管理: 心不全患者の水分摂取の指針は担当の医療者が決める
  • 定期モニタリング: 心機能と貧血を同時に追跡

2. 腎疾患と貧血

発生機序

  • エリスロポエチン不足: 腎臓で産生されるホルモンの減少
  • 鉄利用障害: 炎症による鉄利用率の低下
  • 毒素蓄積: 尿毒症による赤血球寿命の短縮

治療方法

  • ESA治療: エリスロポエチン刺激因子
  • 鉄分補充: 主に静脈内鉄剤補充を使用
  • 目標ヘモグロビン: 個人ごとに医療者が決める
  • 副作用モニタリング: 血圧上昇、血栓リスク

最新治療法と研究動向

1. 新しい鉄剤

最新の経口鉄剤

  • リポソーム鉄: 新しい剤形の系統(根拠の水準は確認できていません)

新しい静脈内鉄剤

  • カルボキシマルトース第二鉄: 静注鉄剤の一つ
  • イソマルトシド第二鉄: 静注鉄剤の一つ
  • 鉄デキストラン: 静注鉄剤の一つ(どれを使うかは医療者が判断)

2. 次世代治療法

HIF-PHI(Hypoxia-Inducible Factor-Prolyl Hydroxylase Inhibitor)

  • 作用機序: 低酸素応答の活性化
  • 狙い: エリスロポエチン産生の増加を狙う機序(一次情報源は確認できていません)
  • 形態: 経口薬として開発(韓国での承認・保険適用は更新を確認できていません)

遺伝子治療

  • 遺伝性貧血: 地中海貧血、鎌状赤血球症
  • 方法: 遺伝子編集、幹細胞治療
  • 現状: 米FDAが遺伝子編集治療を鎌状赤血球症などに承認(2023年12月に初承認、2026年7月に対象年齢を拡大)。韓国での利用可否は更新を確認できていません

よくある質問(FAQ)

Q1: 貧血があると運動してはいけませんか?

A: 運動してよいかどうかは貧血の程度と原因によって変わるため、医療者の判断が必要です。

  • 活動レベル: 症状が軽ければ散歩やストレッチなど低強度から始めてよいか医療者に相談
  • 避けるべき活動: めまいや息切れを強める激しい運動
  • 注意事項: めまいや息切れが強くなったら直ちに中止
  • 医師相談: 運動前に医師と相談

Q2: 鉄剤を飲むと便秘がひどくなります。

A: よくある副作用ですが対処法があります。

  • 用量調整: 自分で変えず医療者に相談
  • 剤形変更: 別の剤形に変えるか医療者に相談
  • 服用法の調整: 服用間隔を変えるか医療者に相談
  • 食事調整: 十分な水分と食物繊維の摂取
  • 代替策: 静注鉄剤など別の治療が必要かは医療者が判断

Q3: 月経のたびに貧血が悪化します。どうすれば?

A: 根本原因の治療と予防的管理が重要です。

  • 婦人科検診: 子宮筋腫、子宮腺筋症などを確認
  • 月経量調整: ホルモン治療、ミレナなど
  • 鉄分補充: 継続的な鉄分補充
  • 生活習慣: 鉄分豊富な食事の維持

Q4: 菜食主義者ですが貧血を予防できますか?

A: 十分に可能ですがより細やかな管理が必要です。

  • 多様な鉄供給源: 豆類、ナッツ、葉物野菜
  • 吸収促進: ビタミンC豊富な食品と一緒に摂取
  • B12補充: 必要かどうかと方法は検査後に医療者と相談
  • 定期検査: より頻繁に血液検査を受ける

まとめ

貧血とそれに伴う息切れは単なる症状ではなく、身体が発する重要なサインです。特に持続的な疲労感や運動時にやけに息が切れるといった症状があれば、それを単なる体力不足と片付けず、専門医の正確な診断を受けることをお勧めします。

貧血は原因によって治療法が全く異なるため、正確な診断が何より重要です。鉄欠乏性貧血なのか、ビタミン欠乏なのか、あるいは他の疾患によるものなのかを見極めて初めて、適切な治療を受けることができます。

早期発見と適切な治療によって、貧血は十分に改善可能な疾患です。日頃から鉄分豊富でバランスのとれた食事を維持し、定期的な健康診断を通じて貧血を予防し、早期に発見するよう心がけましょう。

あらためてご案内します。この記事は一般的な情報提供を目的としており、診断や治療に代わるものではありません。検査結果の解釈や、薬・サプリメントの種類・用量・期間は医療者が判断します。
