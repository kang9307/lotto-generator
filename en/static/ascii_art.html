❓ FAQ

Is my uploaded image sent to a server?

No. The entire process, from loading the image to rendering the ASCII output, runs inside your browser using the Canvas API, and this page contains no code that transmits your image anywhere. Once you close the tab, the loaded image is gone.

Why does the color disappear when I copy a color-mode result?

In color mode the colors are applied with HTML markup for on-screen display only, so copying the text keeps the characters but drops the color information. To share a colored result, use the save-as-image button to download it as a PNG file.

Why does my ASCII art look stretched or squashed?

ASCII art assumes a monospace font in which every character has the same width. Paste it into a plain-text or code editor and the proportions will hold; word processors and messengers that use proportional fonts will break the alignment. You can also adjust the output width slider to change the size.
