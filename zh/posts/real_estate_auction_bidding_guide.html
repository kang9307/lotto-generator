韩国不动产法拍 - 投标程序与权利分析基础，不核查什么就等于没买便宜

法拍的风险不在价格，而在中标人所承受的权利

2026-07-31 生活/法律

引言：低价中标却仍然亏损的那个节点

先从一个虚构的场景说起。某套公寓以远低于评估价的价格挂出，有人以该价格中标。登记簿上排列着根抵押权和查封，但他听说「反正中标之后都会被涂销」，因此并不觉得是问题。缴款并办完所有权转移之后，住在那套房子里的人上门来要求返还保证金。那个人是在根抵押权设定之前搬进来并办妥迁入登记的承租人，而分配只让他拿回了保证金的一部分。

在这个场景里，中标人做错的不是价格判断。他错在以为登记簿上写着的权利就是全部。更准确地说，他错在不知道因拍卖而消失的权利与转移到中标人身上的权利是两回事。

本文不讲「如何在法拍中买得便宜」。本文讲的是它的反面：不核查什么，买得便宜这件事就不再成立。法拍的风险不在价格，而在被承受的权利，其中相当一部分根本不会出现在登记簿上。因此本文给出的不是收益算法，而是应当核查的项目及其法律依据条号。

适用法域。以下内容仅说明大韩民国的法律。拍卖制度、登记制度与承租人保护机制在各国之间存在根本差异，本文并不描述任何其他国家的强制执行或抵押权实行制度。

免责声明与核实时点。本文为信息提供目的的一般性说明，并非法律咨询。具体标的的权利关系可能因登记时点、案卷记载与现场情况而得出完全不同的判断，因此必须经律师、法务士等专业人士审查。是否投标的判断及其后果完全由本人承担。本文不鼓励任何人参与法拍。

法令会被修订。下文所列条号与内容系2026年7月31日在法制处「易查生活法令信息」的不动产拍卖与住宅租赁项目中核实所得。条文原文及其修订沿革务必在国家法令信息中心直接确认。

1. 法拍不是买卖 — 现状承受与无法撤销的成交

首先需要纠正的，是把法拍看作「法院在卖的便宜房源」这种视角。普通买卖与法拍在交易结构本身上就不同。

普通买卖有出卖人。出卖人是合同当事人，标的有问题时存在可以追责的对象。可以在合同里加特约条款，尾款之前发现问题也还有协商或了结合同的余地。法拍没有这个对象。拍卖是法院推进的执行程序的一部分，中标人不是谈判的对手方，而是程序的参加人。

  • 按现状承受。标的以其原样出售。中标后发现瑕疵，没有可以要求减价的对象
  • 对瑕疵的追责实际上受到限制。难以按照普通买卖的瑕疵担保责任那样去争执。能争到什么程度因案而异，需要专业人士确认
  • 不能因为改变主意而撤销。提交投标表并成为最高价买受申请人之后，程序只会沿着法律规定的轨道运行
  • 无法缴款可能导致丧失已缴的保证金。再拍卖的依据条文是民事执行法第138条。前买受人的保证金如何处理，须直接查阅条文原文
  • 标的带着占有人一并转移。取得所有权与实际能够使用该空间，是两个不同的问题

大多数事故就发生在这里。「反正买得便宜，亏一点也无所谓」这种算法要能成立，前提是知道亏损的上限是多少，而一旦遗漏了被承受的权利，就等于在不知道这个上限的状态下投标。承担一个自己没有量过的金额，并不是买得便宜。

2. 程序流程 — 到哪一步还能回头，从哪一步开始不能

不必背诵程序。只需要知道在每个阶段自己是否还自由，还是已经被绑住。依法制处指引的流程与依据条文如下。

3. 权利分析的核心 — 抹消基准权利与被承受的权利

这里是本文的中心。因拍卖而消灭的权利与转移给中标人的权利之间存在一条分界线。韩国实务中称之为抹消基准权利。

作为基准的登记。依法制处指引，抵押权、查封与假扣押、拍卖开始决定登记中最早登记的那一项构成基准。在登记事项证明书中找出这三类，并指认受理日期最早的一项，就是权利分析的第一个动作。作为依据列出的条文包括民事执行法第88条、第91条、第135条、第144条、第148条等，而各项权利的性质由民法与各特别法规定。

找到基准之后，就把它的上方与下方分开。晚于基准登记的原则上消灭，早于基准登记的则可能被承受。不过这一原则存在例外，也有一些权利根本与顺位无关而被承受。

类别相应权利对中标人意味着什么
原则上消灭抵押权、查封与假扣押通过分配处理并从登记中涂销
晚于基准登记的地上权、地役权土地使用上的限制随之解除
晚于基准登记的租赁权该租赁权本身归于消灭
已提出分配要求的传贷权通过分配处理
担保性预告登记属担保目的，通过分配处理
与顺位无关而承受留置权指引载明其与登记顺位无关而被承受，且不出现在登记簿上
法定地上权无须登记即可成立，因此即使拍得土地也可能对地上建筑物无可奈何
坟墓基地权无须登记即可成立，因此土地的使用可能受限

顺位保全性预告登记一旦转为本登记，可能丧失所有权

阅读此表时有一点需要注意。这是一般性分类，而不是具体案件的结论。名称相同的权利，也会因登记时点、有无分配要求、标的性质而处理不同。而表中标注「原则上」的格子，其含义是存在例外，而不是没有例外。

  • 基准指错，其下的所有判断都会跟着错。第一个动作最为关键
  • 预告登记因属担保性还是顺位保全性而结论完全相反，仅凭登记名称有时无法区分
  • 传贷权的分岔点在于是否提出了分配要求，这必须查阅案卷才能知道
  • 假处分则要看它意图禁止的是什么。为拆除建筑物而申请的，性质完全不同
  • 留置权、法定地上权、坟墓基地权把登记簿读完也发现不了。需要养成单独核查这三项的习惯

4. 具有对抗力的承租人 — 保证金转移到中标人的路径

回到引言的场景。承租人的保证金转移到中标人身上的路径，在三个要素重叠时打开：对抗力、顺位，以及分配。

4.1 对抗力来自事实而非登记

依住宅租赁保护法第3条，对抗力的要件有两项：住宅的交付与居民登记。并且自两项要件均具备的次日凌晨零时起对第三人产生效力，不需要另行登记。

这一句话在法拍中分量极重。对抗力不会记载于登记簿。无论把登记事项证明书读得多细，承租人的迁入日都不会出现。那必须通过拍卖标的明细表、现状调查报告书以及迁入户的核实去查明。

  • 次日凌晨零时这一点会在顺位之争中造成一天之差
  • 指引载明承租人若迁出后再迁入，对抗力将重新产生，也就是顺位会往后退
  • 共同住宅须准确填写栋号与房号，多户住宅则载明仅填地号即可。填写有误存在无法取得对抗力的风险
  • 商用建筑物另适用商用建筑物租赁保护法，第3条、第5条、第8条被列为相关条文，其适用范围的标准需要另行确认

4.2 优先受偿权、分配，以及剩下的那部分

依同法第3条之2，在对抗要件之上再加确定日期，即产生优先受偿权，可以先于后顺位权利人取得保证金的清偿。指引载明确定日期可在邑面事务所、洞居民中心、市郡区派出所、地方法院及其支院、登记所或公证人处取得（第3条之6）。

中标人在这里应当关注的是分配未能覆盖的那部分。若承租人具备对抗力且该对抗力早于基准，未能通过分配收回的保证金可能作为买受人的负担残留下来。反之，若对抗力晚于基准，该租赁权则归入消灭的一侧处理。

  • 不能只看迁入日，须与确定日期、有无分配要求一并查看
  • 即便有确定日期，错过分配要求终期也可能无法参与分配
  • 即便提出了分配要求，在先权利人先行取走后也可能所剩无几
  • 承租人众多的多户住宅，只有把全部承租人整理在一张表上才看得清实情
  • 若想从承租人角度了解保证金的回收程序，可参考保证金返还诉讼与续约请求权的拒绝事由。本文只讨论买受人一侧的核查项目

5. 最优先受偿 — 分配队列的最前排

小额承租人保护制度会改变分配的顺序。其依据是住宅租赁保护法第8条，具体金额由同法施行令第10条与第11条规定。这项制度对中标人之所以重要，理由很简单：可供分配的总额是固定的，最前排由谁占据一旦变化，后排就会有人拿不到，而这一结果可能影响到承受与否。

不要把金额当作固定值。该标准因地区而异，并随施行令修订而变化。而且适用标准本身还可能因合同签订时点与担保物权设定时点而不同。以下数字是2026年7月31日查阅的法制处指引上所载的数值，该指引以总统令第33254号（2023年2月21日）为准列出。务必在国家法令信息中心直接确认现行施行令。

地区划分符合小额承租人的保证金范围可优先受偿的金额
首尔特别市1亿6,500万韩元以下5,500万韩元
过密抑制圈域，世宗、龙仁、华城、金浦1亿4,500万韩元以下4,800万韩元
广域市等地8,500万韩元以下2,800万韩元
其他地区7,500万韩元以下2,500万韩元

比表中数字更重要的是要件。依法制处指引，附有如下条件。

  • 承租人须在拍卖申请登记之前具备住宅交付与居民登记这两项对抗要件
  • 该对抗要件须持续存续至分配要求的终期
  • 行使优先受偿权须向执行法院提出分配要求，或向欠税处分机关申报行使优先权
  • 优先受偿金额若超过住宅价额的二分之一，则限于相当于该二分之一的金额
  • 列出的相关条文为住宅租赁保护法第3条与第8条、同法施行令第10条与第11条、民事执行法第88条与第246条

从中标人的立场看，本节的实务结论只有一句。可以推演分配表将如何编排，但绝不要倚靠这个推演而安心。分配由法院确定，推演一旦落空，其差额就可能以承受的形式回到自己身上。

6. 登记簿上看不到的东西 — 需要到现场核查的风险

第3节表格中「与顺位无关而承受」那一栏之所以可怕，正是因为那些项目不在登记簿上。无论把登记事项证明书读得多仔细都发现不了，必须到现场才看得见。而有时到了现场也仍然看不见。

类型为何不在登记簿上风险何在如何核查
留置权主张它不是须登记的权利指引载明其可与登记顺位无关而被承受。主张金额越大负担越重现场的横幅、告示与门锁，拍卖标的明细表的记载，案卷中有无申报
法定地上权无须登记即可成立即使拍得土地也可能无法拆除地上建筑物，土地的使用价值随之大变土地与建筑物是否同一所有人、哪一方是拍卖对象、建筑物是否已登记
坟墓基地权无须登记即可成立土地的使用可能受限，且不能擅自迁移实地踏勘。即便评估报告书中没有记载也可能存在
未登记建筑物根本没有登记簿是否属于拍卖范围从一开始就有争议，可能变成只拍得土地评估报告书中评估范围外建筑物的记载、现状调查报告书、建筑物台账
实际占有人占有不是登记事项与书面关系不符时交房拖延且成本上升现状调查报告书、迁入户核实、实地走访

处理这五项的原则是一样的：把「已确认不存在」与「未能核查」区分开来。「去了现场但什么也没有」与「没去现场」是完全不同的状态，可是在填写投标表的那一刻，两者都容易被当作「没问题」。

  • 留置权主张仅凭主张本身就会使程序复杂化。不论最终是否被认可，交房都会耗时
  • 土地与建筑物分别拍卖的案件结构完全不同，须从确认拍卖对象是什么开始
  • 现状调查报告书中标注为无法调查的部分是警示信号，意味着法院也未能确认
  • 拖欠的物业费、公用部分欠款这类不是权利但要掏钱的项目也须另行核查
  • 仅凭照片与网络资料下判断不叫核查。核查就是亲自去

7. 投标实务 — 保证金、投标表，以及无法挽回的笔误

权利分析做完之后，剩下的就是程序问题。这里发生的事故性质不同，是手一滑造成的，而不是不懂法造成的，可是后果同样沉重。

7.1 投标方式

依民事执行法第103条，由法院决定拍卖方式。法制处指引所述的两种方式如下。

  • 期日投标。在指定期日到法院填写投标表，连同保证金一并提交给执行官
  • 期间投标。在规定期间内填写投标表，与保证金装入同一信封密封后直接交给执行官，或以挂号邮件寄出
  • 开标由执行官进行，最高价买受申请人的姓名与价格予以公告（民事执行法第115条、民事执行规则第65条与第71条）
  • 指引载明未中标者的保证金将立即退还

7.2 保证金与投标表

需要自行核查的项目。买受申请保证金的金额与缴纳方式，以及投标表的填写方式与能否更正，在撰写本文时未能查阅条文原文加以确认。实务中常被提及的比例是存在的，但此处不作断言。核查途径有两条。其一，该案件的拍卖公告中会载明金额与方式。其二，在国家法令信息中心确认民事执行法与民事执行规则的相应条文，并在大法院电子民愿中心与法院拍卖信息确认表格与程序指引。

关于投标金额的填写，有一个结构必须了解：投标表上写下的金额，提交之后很难收回。写错位数以致填成意图金额十倍的事故为何是致命的，看下面这条链条就清楚了。

  • 写错的金额成为最高价，你成为最高价买受申请人
  • 经拍卖许可决定后确定缴款期限（民事执行法第142条）
  • 由于筹不到那个金额，无法缴纳价款
  • 因未缴款而许可给次顺位买受申请人，或转入再拍卖（民事执行法第138条）
  • 在这一过程中已缴保证金如何处理，须直接查阅民事执行法第138条的条文原文。实务中所称「保证金没收」的结果就来自这里

共同投标与代理投标各有所需的文件与形式。这部分的具体要件本文同样未能以条文核实。事先向相应法院咨询，或查阅法院拍卖信息的指引，才是稳妥的做法。当天少带一份文件而导致投标整体无效，是常有的事。

8. 中标之后 — 缴款、未缴、交付命令与腾房

中标不是结束，而是第二个程序的开始。这里同样存在还能回头的节点与不能回头的节点。

8.1 缴款与权利的取得

  • 拍卖许可决定确定后，在法院指定的期限内缴纳价款（民事执行法第142条）
  • 全额缴纳价款时取得作为拍卖标的的权利（同法第135条），而不是办完登记时
  • 缴款之后嘱托办理所有权转移登记以及不予承受权利的涂销登记（同法第144条）
  • 未能在期限内缴纳的，许可给次顺位买受申请人或决定再拍卖
  • 即便已决定再拍卖，指引载明在再拍卖期日三日前缴纳价款、利息与程序费用即可阻止再拍卖。利息载明为年12%（同法第138条）

8.2 不得擅自驱离占有人

本节的核心一句是：取得所有权并不意味着可以擅自驱离占有人。开门搬走物品或更换门锁，其行为本身就构成法律问题，必须经过法定程序。

  • 占有人拒绝交付的，指引载明可在缴纳价款后六个月内向法院申请交付命令（民事执行法第136条）
  • 一旦错过期间就要走别的程序，因此需要管理好日程
  • 交付命令并非对所有占有人都能一体适用。持有可被承受权源的占有人可能导致不同结论，需要专业人士确认
  • 腾房要花时间与费用，这段期间无法使用标的这一点也应计入负担
  • 若具有对抗力的承租人仍然在住，那么问题从一开始就不是如何让人搬走，而是保证金怎么办

9. 投标前核查清单 — 四份文件各看什么

把前面的内容按文件重新整理。诀窍不是分别看这四份，而是互相对照着看。只出现在其中一份而另一份没有的项目，就是警示信号。

文件何处取得应看的内容
登记事项证明书在互联网登记所自行申领登记种类与受理日期先后、抵押权与查封与拍卖开始决定登记中最早的一项、排在其前的登记及其性质、预告登记的种类、假处分的目的
拍卖标的明细表法院，自拍卖期日前一周起备置（民事执行法第105条）记载为可能承受的权利，承租人的迁入日、确定日期、有无分配要求，特别拍卖条件，有无留置权申报
现状调查报告书法院，自同一时点起备置执行官查明的实际占有关系、租金与保证金（民事执行法第85条）、标注为无法调查的部分
评估报告书法院，自同一时点起备置评估中被排除的部分、估价时点、土地与建筑物的区分、评估范围外建筑物的记载（民事执行法第97条）

对照时特别值得看的组合如下。

  • 把登记事项证明书的登记先后与拍卖标的明细表的承租人迁入日并排放在一起
  • 看拍卖标的明细表的占有人与现状调查报告书的实际占有是否一致
  • 看评估报告书的评估对象与现场所见的实际建筑物是否一致
  • 拍卖标的明细表中出现承受一词时，把整句抄下来并弄清其含义
  • 案件检索与拍卖期日在法院拍卖信息确认

下面这份文档把上述内容整理成可复制的形式。不过全部打上勾并不意味着安全。清单告诉你的是「核查了什么」，而不是「这个标的行不行」。后者不是本文能够裁断的范畴，而属于需要专业人士审查的范畴。

# 韩国不动产法拍 — 投标前核查清单与权利分析基础

> 来源: braindetox.kr — 韩国不动产法拍的投标程序与权利分析基础
> 本文档仅说明大韩民国的法律，不描述任何其他国家的拍卖或抵押权实行制度。
> 核实时点: 2026-07-31 / 依据: 法制处「易查生活法令信息」的不动产拍卖与住宅租赁项目
> 本文档为信息提供目的的一般性整理，并非法律咨询。个别标的的判断须经律师、法务士等专业人士审查，是否投标的判断及其后果由本人承担。
> 法令会被修订。以下条文编号以核实时点为准，现行条文须在国家法令信息中心直接确认。

## 1. 投标前核查清单

### 1-1. 取得四份文件

- [ ] 我自己申领了登记事项证明书（最新本，而非案卷复印件）
- [ ] 我查阅了拍卖标的明细表
- [ ] 我查阅了现状调查报告书
- [ ] 我查阅了评估报告书
- [ ] 我知道后三份文件自拍卖期日前一周起备置，并据此安排了日程（民事执行法第105条）

### 1-2. 权利分析

- [ ] 我在登记簿中找出了抵押权、查封与假扣押、拍卖开始决定登记中最早登记的一项
- [ ] 我列出了排在该基准之前的全部登记
- [ ] 我确认了在先登记中是否有不因拍卖而消灭的
- [ ] 若存在传贷权，我确认了是否提出了分配要求
- [ ] 若存在预告登记，我确认了它是担保性质还是顺位保全性质
- [ ] 若存在假处分，我确认了其目的为何
- [ ] 我另行核查了可能与登记顺位无关而被承受的权利（如留置权）

### 1-3. 承租人

- [ ] 我确认了占有人是谁，是承租人还是所有人
- [ ] 我确认了承租人的迁入日是否早于作为基准的登记
- [ ] 我确认了有无确定日期以及具体日期
- [ ] 我确认了是否提出分配要求，以及是否在分配要求终期内提出
- [ ] 若分配无法收回全部保证金，我追查了差额的去向
- [ ] 我通过迁入户确认书等核实了已登记的住户
- [ ] 若为多户住宅，我梳理了每一户承租人的关系

### 1-4. 现场

- [ ] 我实地去过（没有仅凭照片和书面材料判断）
- [ ] 我确认了实际占有人与书面占有人是否一致
- [ ] 我查看了有无主张留置权的标识（横幅、告示、更换的门锁）
- [ ] 我确认了土地与建筑物的所有人是否相同，以及哪一方是拍卖对象
- [ ] 我核查了有无未登记的建筑物、附属物或加建部分
- [ ] 若涉及土地，我核查了有无坟墓
- [ ] 我核查了有无拖欠的物业费和公用部分欠款

### 1-5. 投标当天

- [ ] 我再次确认了拍卖期日、地点、案号与标的编号
- [ ] 我从拍卖公告中确认了买受申请保证金的金额与缴纳方式
- [ ] 我至少两次核对了投标金额的位数
- [ ] 若为代理投标或共同投标，我事先向法院确认了所需文件
- [ ] 我确认了若中标能否在期限内筹足全部价款

## 2. 消灭的权利与承受的权利

抹消基准权利 = 抵押权、查封与假扣押、拍卖开始决定登记中最早登记的权利

| 类别 | 相应权利 |
| --- | --- |
| 原则上消灭 | 抵押权、查封与假扣押 |
| 原则上消灭 | 晚于基准登记的地上权、地役权 |
| 原则上消灭 | 晚于基准登记的租赁权 |
| 原则上消灭 | 已提出分配要求的传贷权 |
| 原则上消灭 | 担保性预告登记 |
| 与顺位无关而承受 | 留置权 |
| 与顺位无关而承受 | 法定地上权 |
| 与顺位无关而承受 | 坟墓基地权 |
| 在先顺位则承受 | 早于基准登记的地上权、地役权、传贷权、租赁权 |
| 附条件承受 | 顺位保全性预告登记 |
| 附条件承受 | 未提出分配要求的传贷权 |
| 附条件承受 | 土地所有人为拆除建筑物而申请的禁止处分假处分 |

★ 上表为一般性分类。在具体案件中，结论可能因登记时点、有无分配要求、标的性质而不同。不可仅凭表格判断。

## 3. 各份文件应看的内容

| 文件 | 何处取得 | 应看的内容 |
| --- | --- | --- |
| 登记事项证明书 | 互联网登记所 | 登记种类与受理日期的先后、作为基准的登记、排在其前的登记 |
| 拍卖标的明细表 | 法院（拍卖期日前一周起） | 记载为可能承受的权利，承租人的迁入日、确定日期、有无分配要求，特别拍卖条件 |
| 现状调查报告书 | 法院（同一时点起） | 执行官查明的实际占有关系、租金与保证金、标注为无法调查的部分 |
| 评估报告书 | 法院（同一时点起） | 评估中被排除的部分、估价时点、土地与建筑物的区分、评估范围外建筑物的记载 |

★ 要点在于把四份文件互相对照。只出现在一份文件而其他文件没有的项目就是警示信号。

## 4. 登记簿上看不到的风险类型

| 类型 | 为何不在登记簿上 | 风险何在 |
| --- | --- | --- |
| 留置权 | 它不是须登记的权利 | 可能与登记顺位无关而被承受 |
| 法定地上权 | 无须登记即可成立 | 即使拍得土地也可能无法拆除建筑物 |
| 坟墓基地权 | 无须登记即可成立 | 土地的使用可能受限 |
| 未登记建筑物 | 根本没有登记簿 | 是否属于拍卖范围会产生争议 |
| 实际占有人 | 占有不是登记事项 | 与书面关系不符时交房会拖很久 |

| 阶段 | 法律依据 | 能否回头 |
| --- | --- | --- |
| 拍卖开始决定 | 民事执行法第83条、第94条 | 与投标人无关的阶段 |
| 现状调查与评估 | 民事执行法第85条、第97条 | 与投标人无关的阶段 |

| 分配 | 民事执行法第146条、第159条 | 中标人的程序已经结束 |

## 7. 不要做的事

- 只看评估价与最低拍卖价之差就下判断 — 风险在承受的权利，不在价格
- 只看登记事项证明书就结束 — 留置权、法定地上权、坟墓基地权、未登记建筑物都不在登记簿上
- 不去现场 — 实际占有人可能与文件不符
- 略过拍卖标的明细表中「承受」的标注 — 那一行会改变金额
- 只看承租人的迁入日而不确认有无分配要求
- 用过时资料判断小额承租人的标准金额 — 因地区与时点而异，由施行令变更
- 没有资金计划就投标 — 未缴款会导致再拍卖
- 中标后自行驱离占有人 — 必须经过法定程序
- 仅凭本文档就去投标 — 具体标的需要专业人士审查

## 8. 常被误解的要点

- 对抗力来自住宅的交付与居民登记，而非任何登记，且自具备两项要件的次日凌晨零时起对第三人生效（住宅租赁保护法第3条）
- 优先受偿权须在对抗要件之上再加确定日期才产生（同法第3条之2）
- 即便具有对抗力，分配未能覆盖的部分仍可能留给中标人
- 小额承租人的最优先受偿须在拍卖申请登记前具备对抗要件，并提出分配要求（同法第8条）
- 最优先受偿额以住宅价额的二分之一为上限
- 商用建筑物另适用商用建筑物租赁保护法（第3条、第5条、第8条）
- 交付命令可在缴纳价款后六个月内提出申请（民事执行法第136条）

10.2 未能核实的部分 — 需要自行确认的项目

  • 判例。本文未引用任何判例，因为转述无法确认案号的判例本身就构成错误。留置权、法定地上权这类判例积累具有决定意义的领域，务必接受专业人士审查
