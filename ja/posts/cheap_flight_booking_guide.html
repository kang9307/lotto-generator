航空券の値段はなぜ変わり続けるのか - 制御できるものと裏付けの取れない通説

運賃クラスの構造、総額比較の方法、そして一次資料が見つからなかった八つの話

2026-08-01 生活・実用

導入: 同じ便なのに昨日と値段が違う

昨夜チェックしておいた便がある。日付も時刻も便名もそのままなのに、今朝もう一度開くと値段が四万ウォン上がっている。ブラウザを新しく開き、シークレットモードで入り直してみる。値段は変わらない。ここで人の反応はだいたい二つに分かれる。検索履歴のせいだと確信するか、今日は運が悪かったと考えて決済するかだ。

どちらも間違いだと言いたいのではない。ただしどちらも確認されたものではない。そして確認されていない説明を握っていると、実際に制御できるものを見落とす。

この記事は「航空券を安く買う方法」ではない。そういう記事はもう十分すぎるほどあり、その大半は検証されたことのない話を互いに書き写したものだ。この記事がやろうとしているのは一つだけである。値段が決まる仕組みをまず見て、その構造の上で何が制御可能で何が迷信なのかを分けることだ。

結論を先に言えば、実際に節約になる方法は退屈な側にある。総額で比較し、条件を読むことだ。火曜日の午後に決済ボタンを押すことではない。

この記事の調査方法。本文に数字や基準を書くときは、政府・公的機関の一次資料を直接開いて確認したものだけを書いた。開けなかった文書の内容は書き写しておらず、何を確認できなかったかは9節にまとめてある。広く出回っている節約術についても同じ基準を当てはめ、3節の表に一次資料が見つかったかどうかを一行ずつ明示した。

制度に関する部分は大韓民国の基準である。取消手数料、利用者保護、紛争解決手続きに関する内容は、韓国の消費者が韓国で購入する状況を前提としており、引用した出典も韓国政府の文書だ。他の国の読者は、構造の部分は一般的なもの、法制度の部分は管轄に依存するものとして読んでほしい。またこの記事は特定の航空会社、特定の予約サイト、特定のカードを推薦も批判もしない。その判断を下すには、この記事が開けなかった文書をすべて開く必要がある。

あわせて読む記事。旅行中の事故と保険の補償範囲は旅行保険ガイド、事業者との紛争になったときの手続きは消費者紛争解決の手続き、約款条項が無効になる基準は不公正約款と無効、決済通貨が混ざるときの換算は為替レートの理解で扱った。

1. 値段が変わり続ける理由 - 座席ではなく商品を売っている

まず誤解を一つ取り除く必要がある。航空会社は座席を売っているのではない。もちろん最終的に搭乗するのは物理的な座席だが、販売される単位は座席ではなく条件の異なる商品である。

同じエコノミー客室の中でも販売商品は複数に分かれている。業界ではこれを予約クラスまたはブッキングクラスと呼び、普通はアルファベット一文字で区別する。そして各クラスには運賃規則という条件の束が付く。束に含まれるのはおおむね次のようなものだ。

  • 変更の可否と手数料。そもそも変更できない商品、手数料を払えばよい商品、差額だけ払えばよい商品がある
  • 払戻の可否と手数料区分。払戻自体が不可能な商品がある。この場合「安く買った」というのは日程が絶対に変わらないことに賭けたのと同じだ
  • 受託手荷物の有無と個数。表示価格に手荷物がまったく含まれていない商品がある
  • 事前座席指定の可否。無料の商品、有料の商品、空港チェックインまで指定できない商品に分かれる
  • マイル積算率。同じ距離を飛んでも積算される割合が異なり、まったく積算されない商品もある
  • 滞在条件。最低何日以上滞在すること、最大何日を超えないこと、といった条件が付く場合がある

ここまで来ると導入の場面が違って見える。昨日見た値段と今日の値段が違うのは同じ商品の価格が上がったのではなく、昨日残っていた安い条件の商品が売り切れて次の商品だけが残った可能性が高い。だから航空券の値段は滑らかな曲線ではなく階段のように飛び飛びに動く。

1.1 だから予測が不可能である

各クラスに何席ずつ配分するか、いつ配分を見直すかは航空会社内部の需要予測判断だ。そしてその判断基準は消費者に公開されていない。この事実一つが、世に出回る節約術の大半を無力にする。

  • 「N日前に買えば安い」が成り立つには全路線の配分方針が似ている必要があるが、そうである理由がない
  • 同じ路線でも繁忙期と閑散期、観光需要と出張需要の比率によって配分が変わる
  • 値段が上下したという観測は、原因について何も語らない。私が再検索したからかもしれないし、その間に他人が最後の一席を買ったからかもしれない。二つを区別する方法は消費者にはない

構造がこうなら残る選択肢は明らかだ。次の変動を予測しようとせず、いま画面にある商品が何かを正確に把握することである。それは確認可能な作業だ。

付け加えると、航空券が条件の異なる複数の商品として売られているという事実そのものは規制文書でも確認できる。後で引用する公正取引委員会の2016年9月28日発表と韓国消費者院の2016年11月21日報道資料は、いずれも割引航空券という区分と取消時期によって変わる手数料を前提にしている。一つの航空券が一つの価格を持つ品物だったなら出てこない区分だ。

2.2 期待費用という項目

上の表の最後から二番目の行は見慣れないかもしれない。日程が変わる確率に手数料を掛けた値だ。この項目を入れる理由は単純である。

  • 払戻不可運賃の価格は表示額ではない。日程が確実なら表示額で合っているが、確実でなければその分の損失リスクも一緒に買ったことになる
  • 確率を正確に知る必要はない。0かどうかを区別するだけでも判断が変わる。出張が確定していない、子どもがいる、同行者の日程が未定、といった場合pは0ではない
  • 逆にpが0に近ければ払戻不可運賃は本当に安い。この計算は安い券を避けろという話ではなく、いつ安い券が実際に安いのかを分ける道具だ
  • 同じ論理で、旅行保険の旅行中止に関する補償はこのpを下げる方向に働く。補償範囲と条件は旅行保険ガイドで別途扱った

  • 見つからなかったことは偽であることの証明ではない。この記事の調査範囲の外に根拠があるかもしれないし、そもそも企業の価格政策に公開義務はない

  • だからこの記事はこの八つをやれとも、やるなとも言わない。ただしこれらを「節約方法」という名前で呼ぶことはしない

3.1 個人の経験ではなぜ判別できないのか

「私はシークレットモードで開いたら安くなった」という発言は実際の経験だろう。問題は、その経験が二つの異なる説明を区別してくれないところにある。

  • 説明1。検索履歴が価格に反映され、履歴を消したら元の価格が出た
  • 説明2。その間に予約クラスの在庫が変わった。シークレットモードは何の役割も果たしていない
  • 二つの説明は同じ観測を生む。値段が下がったのを見ただけではどちらかは分からない
  • 分けるには同じ時刻に、同じ条件で、対照群を置いて、複数回観測しなければならない。個人が数回経験したことはこの条件を一つも満たさない
  • さらに人は合致した場合だけを記憶する。シークレットモードで開いたのに値段が変わらなかった日は話の種にならず伝わらない

実務的な結論はこうだ。費用のかからない行動なら、やっても構わない。シークレットウィンドウを開くのに3秒しかかからない。問題は、それを「節約法」と呼んだ瞬間、確認可能な節約手段である総額比較と条件確認から注意がそれることだ。時間と注意力は有限で、それをどこに使うかが実際の支出を分ける。

4. 乗継と直行 - 予約番号が一つかどうかがなぜ重要か

乗継便が直行より安いのはよくあることだ。ところがここで比較すべきものは価格だけではない。乗継は時間費用とリスクを一緒に買うことだからである。

4.1 時間費用を数字で入れる

  • 乗継待ち時間はそれ自体が費用だ。往復で8時間追加されるなら、それを休暇日数に換算してみることができる
  • 空港で過ごす時間には食費がかかる。人数の分だけ掛け算される
  • 夜間の乗継は睡眠の損失を生み、到着翌日の予定を失わせる場合がある
  • 乗継地によっては査証や事前入国許可が必要になることがある。これは費用であり失敗リスクでもある。条件は当該国の公館と外務当局の案内で確認する必要がある

4.2 予約番号は一つか、航空券は何枚か

これがこの節の核心だ。見た目には同じ「出発地 → 乗継地 → 目的地」の日程でも、一つの予約として発券されたものと、別々の予約2枚を自分でつないだものはまったく違う商品である。

  • 一つの予約として発券された場合。航空会社はその旅程全体を一つの運送契約として扱う。前の区間が遅れて後の区間に乗り遅れたとき、代替便に関する航空会社の責任範囲が存在する。手荷物も最終目的地まで通し処理される場合が多い
  • 別々に買った2枚をつないだ場合。後の区間の航空会社から見れば前の区間の遅延は乗客個人の事情である。乗り遅れたら券を買い直すことになりうる。手荷物も乗継地で受け取って預け直すのが普通だ
  • 価格比較サイトで際立って安い組み合わせは後者である場合がある。だから画面に「別途発券」やそれに準ずる表示があるかを確認する必要がある
  • 確認方法は、発券後に受け取った電子航空券で予約番号が一つか、航空券番号が何個かを見ることだ
  • 乗継地で入国審査を通る必要があるかも確認項目である。審査を通る必要があるなら必要な乗継時間が大幅に増える

空港ごとに定められた最低乗継時間があり、航空会社とターミナルの組み合わせによって異なる。それより短く自分でつないだ日程で生じた結果は、おおむね乗客の責任として処理される。逆に一つの予約の中で航空会社が提示した接続は、その時間が短くても航空会社が設計したものだ。

この節の限界。手荷物の通し処理と区間をまたぐ責任範囲の具体的な条件は航空会社ごとの運送約款と航空会社間の協定によって変わる。この記事は個別航空会社の運送約款の原文も、国際航空運送協会の関連公開資料も開いて確認できなかったので、ここでは「どこを見るべきか」までを述べ、具体的な条件を断定しない。実際の旅程では発券前に当該航空会社の運送約款で接続便と手荷物の条項を確認する必要がある。

5. 取消・変更の規定 - どこに書かれ、何を見るべきか

取消条件は一か所には書かれていない。三つの層が重なっており、三つが互いに違うことがある。この構造を知らないと「航空会社は払い戻せると言うのに旅行会社はできないと言う」といった状況で何を問うべきか分からない。

層何が書かれているかどこで見るか見落とすとどうなるか
① 航空会社の運送約款運送契約の一般条件。取消・変更・手荷物・遅延時の処理の基本骨格航空会社サイトの約款ページ基本原則を知らないまま個別の案内だけを聞くことになる
② その運賃の運賃規則自分が買った商品にだけ適用される条件。払戻の可否、手数料区分、手荷物の有無決済直前の画面、電子航空券の運賃規則要約最も見落としやすい層。同じ航空会社でも商品ごとに違う
③ 販売元の独自条件旅行会社・販売代行を経た場合の取扱手数料と受付可能時間販売元の利用規約、注文確認メール航空会社の手数料と別に付く。取消窓口が販売元に限定されることもある

5.1 韓国基準で確認できたこと

ここからは実際に開いて確認した一次資料に基づく。二件ある。

  • 公正取引委員会、2016年9月28日発表。韓国国内7社が国際線航空券について取消日から出発日までの期間と関係なく一律の取消手数料を課していた約款を是正した。判断根拠は、この手数料が民法上の損害賠償額の予定に当たるところ、当該約款が取消時点が出発日までの期間が長いほど顧客に不当に過重な損害賠償義務を負わせる条項であって約款法上無効である、というものだった
  • 是正内容。出発91日前の取消は全額払戻とし、出発90日前から出発日までは4区分から7区分に分けて出発日に近いほど手数料率が高くなるようにした。2016年12月31日までにシステムに反映し2017年1月1日から施行する日程だった
  • 韓国消費者院 消費者紛争調停委員会、2016年11月21日報道資料。2016年2月に仁川-香港往復航空券3枚を665,400ウォンで購入した消費者が出発66日前に取り消したところ、航空会社が1人あたり80,000ウォンの取消手数料を課した事案である。調停委員会は上記の是正約款を遡及適用し大人23,000ウォン、小児25,000ウォンずつ払い戻すよう決定した
  • 同じ報道資料は割引航空券について出発日基準91日以前には取消手数料なしで取消可能であり、90日以内には各社が是正した約款による取消手数料を払うと整理している

基準時点に注意。上の二件は2016年と2017年時点の措置である。その後各社が約款を改定した可能性があり、区分数と料率は航空会社ごとに異なる。したがって「出発91日前なら無条件で全額払戻」と覚えてはいけない。この資料が語っているのは「期間と無関係な一律手数料は約款法上問題になりうる」という判断基準と、その基準で争った実際の決定があるという事実だ。自分の航空券の実際の区分と料率は、その航空券の運賃規則で確認する必要がある。

5.2 決済前に残しておくこと

規定を確認することと確認したという事実を証明できることは別だ。後で争いになれば後者が必要になる。

  • 決済直前の画面の運賃規則要約と取消手数料の案内をキャプチャして決済記録と一緒に保管する
  • 販売元を経たなら販売元の取消手数料の案内も別途キャプチャする。航空会社の規定と違うことがある
  • 電子航空券を受け取ったら運賃規則要約、手荷物許容量、予約番号と航空券番号を確認する
  • 取り消すときは取消要請の時刻が残る方法(ウェブの取消受付画面、メール)を使う。電話だけで処理すると時点を証明しにくい
  • 手数料区分が日付で分かれているので一日の差で区分が変わることがある。取消を遅らせる理由がなければ遅らせないほうが有利な構造だ

約款条項がどんな場合に無効になるか、そして事業者との争いになったときにどんな手続きを踏むかは不公正約款と無効の基準と消費者紛争解決の手続きでより詳しく扱った。

6. オーバーブッキング・遅延・欠航 - 何を求められるのか

この節では補償金額を書かない。理由を先に明かす。

韓国には航空交通利用者保護基準という国土交通部の告示がある。国家法令情報センターで照会すると国土交通部告示第2024-519号として2024年9月27日施行という情報が確認できる。しかしこの記事は告示本文の条文を開いて確認できなかった。確認していない条項と金額を書き写せば、その瞬間この記事が次の人を誤らせることになる。だから金額の代わりに確認経路を示す。

6.1 確認経路

  • 国家法令情報センターで「航空交通利用者保護基準」を照会し本文の条文を直接読む。改正で条文が変わっている可能性があるので施行日も一緒に確認する
  • 公正取引委員会の消費者紛争解決基準の告示で航空分野の項目を確認する。この基準は紛争解決のための勧告的性格の基準として知られており、この記事は当該告示の航空別表の本文を開いて確認できなかった
  • 利用した航空会社の運送約款で遅延・欠航・超過販売に関する条項を探す。実際の契約関係はここにある
  • 解決しなければ韓国消費者院の相談と消費者紛争調停委員会の手続きを利用する。5節で引用した決定事例はこの経路から出たものだ

6.2 現場で必ずしておくこと

どの基準が適用されるにせよ、記録がなければ主張を裏付けられない。この部分は基準と無関係に常に有効だ。

  • 理由と時刻を文書で受け取る。遅延・欠航確認書を要請し、理由が何と書かれたかを確認する。気象か整備かによってその後の判断が変わりうる
  • 案内の時刻を記録する。いつ遅延が告知され、いつ代替便を提示されたかを、画面写真やメッセージで残す
  • 提示された代替便の内容を残す。何を提案され何を断ったかが後で争点になる
  • 追加支出の領収書をすべて保管する。宿泊、食事、交通、買い直した券まで含む
  • 超過販売で搭乗を拒否されたならその事実と代替措置の内容を文書で確認してもらう。口頭の約束は残らない
  • 旅行保険に加入しているなら遅延・欠航に関する補償があるかも別途確認する。航空会社の措置と保険金は別の手続きだ

この一覧には共通点がある。すべて空港でしかできないことであり、家に帰った後では作れない。だから基準を覚えるよりこの六行を覚えるほうが実際に役に立つ。

7. マイレージ - 確認できた範囲だけ

マイレージは総額比較を難しくする項目だ。価値が確定していないからである。ここでは構造だけを整理し、特定プログラムの条件は断定しない。

7.1 積算の側

  • 積算はおおむね搭乗区間の距離と予約クラスによって計算される。同じ距離を飛んでも商品によって積算される割合が異なる
  • まったく積算されない運賃がある。安い商品ほどその可能性があるので、積算を期待していたなら決済前に確認する必要がある
  • 積算分を総額計算に入れたいなら控えめに見積もるほうが安全だ。次に見るように価値が固定されていない

7.2 使用の側

  • 特典航空券には別途割り当てられた座席在庫があるのが普通だ。マイルが十分でも希望の日に席がない場合がある
  • マイルで航空券を得ても税金や燃油サーチャージなどは現金負担になる場合がある。だから「タダの航空券」ではない
  • したがってマイルを固定レートで現金換算して比較する計算は成り立たない。交換比が時点と座席の空き具合に左右される
  • 有効期限を定めたプログラムがある。期間と失効の方式はプログラムごとに違うので当該規約で確認する必要がある。この記事は個別プログラムの規約を開いて確認していないので数字を書かない
  • 家族合算、譲渡、提携利用の可否も同様にプログラム別の条件だ。同じ理由でここでは断定しない

まとめると、マイレージは総額比較の補助項目として置くほうがよい。積算率の差のために高い商品を選ぶ判断は、その積算分の価値を確定できるときにだけ成り立つ。そしてたいてい確定できない。

8. 実際に制御可能なもの

ここまでの内容を制御可能性の基準で分けるとこうなる。

区分項目消費者にできること
制御可能日付の柔軟性前後数日を一緒に照会する。階段状の構造では一日の差で別の商品が開いていることがある
制御可能空港の選択代替空港を調べつつアクセス交通費と時間を総額に入れて比較する
制御可能総額比較表示運賃ではなく2節のワークシートで比較する
制御可能条件の確認手荷物・座席・変更・払戻の四つは決済前に必ず読む
制御可能購入経路取消窓口が一層か二層かをあらかじめ知っておく(5節)
制御可能旅程の構造予約番号が一つか、別途発券をつないだものかを確認する(4節)
制御可能証拠の保管規定画面と決済記録、現場の記録を残す
制御不可クラス別の座席配分公開されない。予測を試みないほうが合理的だ
制御不可原油価格・為替燃油サーチャージと海外決済額に影響する。為替の仕組みは別途整理した
制御不可気象・管制・整備備えは6.2節の記録の習慣と保険でのみ可能だ

8.1 予約確定前チェックリスト

決済ボタンを押す前にこの順序で確認する。順序には理由がある。総額を先に確定しないと、その後の項目が比較可能な数字にならないからだ。

[ 決済ボタンを押す前の順序 ]

 3. 機内手荷物 サイズと重量の上限、個数

9. この記事で確認できなかったこと

確認していないことを確認したかのように書けば、この記事も3節で批判した記事と同じになる。限界を明確にしておく。

  • 航空交通利用者保護基準の条文本文。告示番号(国土交通部告示第2024-519号)と施行日(2024年9月27日)までしか確認していない。超過販売・遅延・欠航に関する条項の内容と金額は確認できなかったので本文に書いていない
  • 消費者紛争解決基準の航空部分の別表。当該告示が存在することとその役割までを言及し、別表の条文と数値は開いて確認できなかった
  • 個別航空会社の運送約款・運賃規則・手荷物規定。一つも開いて確認していない。1節と2節の条件一覧は確認すべき項目の一覧であって、特定航空会社の実際の条件ではない
  • 国際航空運送協会の公開資料。4節の手荷物の通し処理と区間をまたぐ責任に関する規則を確認しようとしたが開けなかった。だからその節は確認の方向だけを示した
  • 個別マイレージプログラムの規約。有効期限、失効の方式、合算・譲渡の条件すべて確認しておらず数字を書いていない
  • 3節の八つの話すべて。一つも一次資料を見つけられなかった。表にそのまま書いた
  • 2016年以降の約款改定履歴。5節で引用した是正措置以降に各社が約款をどう変えたかは確認していない。だから基準時点を明示した

確認できなかったものには共通点がある。大半が「向こうが実際にどう定めているか」に関する問いだ。そしてその答えは原則として自分が買おうとしているその航空券の画面と文書に書かれている。他人の要約を読むより自分の画面の条件を読むほうが速く正確な理由がここにある。

結論: 退屈な側が実際に節約になる側だ

整理するとこうなる。航空券の値段は同じ座席の価格が上下するのではなく、条件の異なる商品が順に売り切れていく構造から生まれる。その配分は公開されないので予測は成り立たない。

広まっている節約術八つについて一次資料を探し、一つも見つからなかった。それらが偽だという意味ではないが、検証できない助言には従う根拠もない。

一方で確認可能なものは確かにある。表示運賃ではなく総額で比較すること、そして手荷物・座席・変更・払戻の四つの条件を決済前に読むことだ。2節の架空の例で見たように、表示額が6万ウォン安い商品が総額では20万ウォン高いという結果が出うる。この逆転は要領ではなく算数である。

制度の側でも確認できたことがある。取消時点と無関係な一律手数料は顧客に不当に過重な損害賠償義務を負わせる条項と判断されて是正されたことがあり、その基準で実際の払戻決定が出た事例がある。こうした資料は覚えておくものではなく必要なときに訪ねる先を知っておくことで十分だ。

最後に、いますぐできることが一つある。次に航空券を見るとき、表示運賃を書き留める前に受託手荷物の含まれる個数から確認してみてほしい。その一行が比較の結論を変える場合は思ったより多い。そしてそれは何曜日に接続したかとは何の関係もない。

よくある質問

昨日見た航空券が今日高くなった理由は

同じ座席の値段が上がったのではなく、安い条件の商品が売り切れて次の商品だけが残った可能性が高い。配分方針は公開されないので次の変動を予測する方法はない。代わりに、いま画面にある商品の条件を確認することは可能だ。

シークレットモードは本当に効果があるのか

この記事の調査範囲では一次資料が見つからなかった。観測される現象は在庫消尽の構造でも同じように説明でき、個人の経験だけでは二つの説明を区別できない。費用がかからないのでやっても構わないが、これを節約方法として扱うと総額比較という確認可能な手段から注意がそれる。

手荷物料金はどれくらい差を生むのか

片道料金が区間数と人数の分だけ掛け算されるため、総額で最も大きく開く項目だ。2節の架空の例では大人2名の往復基準で16万ウォンが追加され、それだけで表示額6万ウォンの差が逆転した。

取消手数料で争いになったらどこへ行くのか

まず航空会社の運送約款、その運賃の運賃規則、販売元の独自条件の三層を確認する。解決しなければ韓国消費者院の相談と消費者紛争調停委員会の手続きがある。5節で引用した2016年の決定もこの経路から出た。

遅延・欠航の補償金額がこの記事にないのはなぜか

関連告示の条文本文を開いて確認できなかったからだ。確認していない金額を書くことは誤った案内になる。代わりに6.1節に確認経路を、6.2節に現場で残すべき記録を整理した。

> 出典: braindetox.kr — 航空券の値段はなぜ変わり続けるのか
> 制度の部分は大韓民国の基準。金額と条件は必ず自分の航空券の運賃規則で確認すること。

## 0. 大前提

航空会社は座席ではなく **条件の異なる商品** を売っている。
昨日と値段が違うのはたいてい **安い条件の商品が売り切れた** ということだ。
配分方針は公開されない → **予測不可**。制御可能なのは **総額比較と条件確認** だけ。

## 1. 総額比較ワークシート

| 項目 | 計算式 | 商品A | 商品B |
|---|---|---|---|
| 表示運賃 | x 人数 | | |
| 税金 ・ 燃油サーチャージ ・ 施設使用料 | x 人数 | | |
| 受託手荷物 | 片道料金 x 区間 x 人数 | | |
| 事前座席指定 | 料金 x 区間 x 人数 | | |
| 決済 ・ 発券手数料 | | | |
| 空港アクセス交通費 | 往復 x 人数 | | |
| 深夜到着の宿泊 ・ 交通 | | | |
| **小計(確定費用)** | 合計 | | |
| 日程変更の可能性 p | 0.0 ~ 1.0 | | |
| 変更 ・ 払戻手数料 C | | | |
| **期待費用** | p x C | | |
| **比較総額** | 小計 + (p x C) | | |

**判断**: 比較総額が小さい方。表示運賃が小さい方ではない。
pが0に近ければ払戻不可運賃は実際に安い。pが0でなければそうではない。

## 2. 通説の検証 — 一次資料は見つかったか

| 広まっている話 | 一次資料 | 代わりに確認できたもの |
|---|---|---|
| 検索履歴 ・ シークレットモード | **見つからず** | なし(在庫消尽の構造でも説明可能) |
| 特定の曜日 ・ 時刻 | **見つからず** | なし |
| 出発のちょうどN日前 | **見つからず** | 「N日前」が出る唯一の一次文書の文脈は **取消手数料の区分** |
| VPNでの国変更 | **見つからず** | なし |
| 片道2枚が常に有利 | **見つからず** | なし |
| 24時間以内は無条件無料取消 | **見つからず** | 韓国基準は時期別の差等構造 |
| 公式サイトが常に安い | **見つからず** | 取消手続きの層数は変わる |
| 出発直前の投げ売り | **見つからず** | なし |

**見つからず = 偽の証明ではない。** ただし検証できない助言には従う根拠もない。

- [ ] 6. 払戻 — 可否、時期別の手数料区分
- [ ] 7. 発券主体 — 航空会社の直接販売か販売代行か
- [ ] 8. 取消窓口 — どこに要請するか、受付可能な時間
- [ ] 9. 旅程接続 — 予約番号は1つか、航空券は何枚か
- [ ] 10. 証拠 — 運賃規則 ・ 取消手数料の画面をキャプチャ

## 4. 乗継便で分かれるもの

| 区分 | 一つの予約として発券 | 別々の2枚をつないだもの |
|---|---|---|
| 前区間の遅延で後区間に乗り遅れ | 航空会社の責任範囲が存在 | **乗客個人の事情として処理** |
| 手荷物 | 最終目的地まで通し処理される場合が多い | 乗継地で受け取り預け直す |
| 確認法 | 電子航空券の予約番号 ・ 航空券番号の数 | 同じ |

※ 具体的条件は **航空会社の運送約款** で確認。この文書は確認項目のみを示す。

## 5. 取消 ・ 変更の規定は3層

1. **航空会社の運送約款** — 契約の一般条件
2. **その運賃の運賃規則** — 自分が買った商品にだけ適用(最も見落としやすい)
3. **販売元の独自条件** — 旅行会社の手数料は **航空会社と別に** 付きうる

韓国基準で確認できた一次資料(2016~2017年時点):
- 公正取引委員会 2016-09-28 — 期間と無関係な一律取消手数料は **約款法上無効** と判断、出発 **91日前は全額払戻** + 90日以内は **4~7区分の差等**、2017-01-01施行
- 韓国消費者院 調停委員会 2016-11-21 — 出発66日前の取消事案に大人23,000ウォン ・ 小児25,000ウォンの払戻決定
- ※ **現在の各社の区分 ・ 料率は個別の約款で改めて確認すること**

## 6. 遅延 ・ 欠航 — 金額より記録

**この文書は補償金額を書かない**(告示本文が未確認のため)。

確認経路:
1. 国家法令情報センター → 「航空交通利用者保護基準」本文(国土交通部告示第2024-519号、施行2024-09-27)
2. 公正取引委員会 消費者紛争解決基準 → 航空分野
3. 利用航空会社の運送約款 → 遅延 ・ 欠航 ・ 超過販売の条項
4. 韓国消費者院の相談 → 消費者紛争調停委員会

現場で残すもの:

- [ ] 告知時刻 ・ 代替便の提示内容(画面写真 ・ メッセージ)

## 7. マイレージ — 断定しないこと

- 積算率は **予約クラスごとに異なり**、積算0の運賃もある
- 特典航空券は **座席在庫が別枠**、税金 ・ 燃油サーチャージは現金負担の場合あり
- したがって **固定レートでの現金換算による比較は成り立たない**
- 有効期限 ・ 合算 ・ 譲渡の条件は **当該プログラムの規約で直接確認**

## 8. してはいけないこと

- 表示運賃どうしの比較 — 抜けているものが違う
- 払戻規定を読まずに決済 — 日程が流動的なら実質価格が違う
- キャプチャなしの決済 — 争いになったとき証明するものがない
- 別途発券の乗継を単一旅程と誤解 — 乗り遅れたら券を買い直す
- 検証されていない要領に時間を使う — その時間に総額表を埋めるほうがよい
- 他人の要約で規定を判断 — 自分の航空券の運賃規則が唯一の根拠だ
