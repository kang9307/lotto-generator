血氧饱和度(SpO2)数值怎么读 - 参考范围、数值偏低时、设备出错时

为了不凭一个数字下判断 - 紧急信号、测量可信度、就诊时要说明的信息

2026-08-01 生活/健康

引言：数字出来了，该不该去医院却没出来

把抽屉里那个夹子形状的小设备夹到手指上，屏幕显示94。再测一次是96，又测一次是92。三次测下来，心里反而更不踏实。这个数字算不算低，如果算低是不是现在就该去医院，还是只因为清晨手凉——设备并不告诉你这些。

上网一搜，满屏都是「低于多少就危险」这样的句子。这类句子同时预设了两件事：第一，你手里的这个数字是准的；第二，靠一个数字就能判断状态。 本文正是从怀疑这两点开始的。

血氧饱和度是一个很容易被条件带偏的数值。指尖温度、指甲油、一瞬间的手抖，都会让数字变化。所以本文的目的不是给出一张自我诊断表，而是两件事。

  • 不要错过不该错过的信号。 在某些状态下，该做的不是确认数值，而是先叫人帮忙
  • 分清手里的数值能不能信。 看到偏低的值时，这是先怀疑人还是先怀疑设备的顺序问题
  • 这两件事都不是「低于多少就危险」一行字能替代的。比数值偏低更重要的是症状和趋势——说这就是本文的全部内容也不为过

免责声明。 本文以提供信息为目的，不能代替诊疗。 对个人状态的判断和治疗决定属于医务人员。本文不包含供氧方法、药物名称与剂量，也不包含任何设备品牌或型号。这是刻意的。 如果有症状或者拿不准，请选择联系医疗机构那一边。

1. 出现这些情况请不要再测，直接呼叫急救

首先要改的是顺序。很多人第一反应是「先再测一次看看」，但状态不好的时候，该先做的是求助而不是重测。 重测所花掉的那几分钟是纯粹的损失。

只要符合下面任何一条，无论屏幕上是多少，不等待都更安全。

  • 气短到一句话说不完 —— 每说几个字就必须停下来喘气
  • 安静坐着也觉得呼吸困难 —— 没有活动却气短，这是与平时不同的信号
  • 呼吸的声音或方式与平时明显不同 —— 耸肩喘气，或者伸着脖子呼吸
  • 嘴唇、牙龈或甲床看起来发青或发灰
  • 意识模糊、说话含糊、叫醒后反应迟钝
  • 突然浑身没劲瘫坐下去，或者站不住
  • 胸口有压榨感或被压住般的疼痛
  • 冒冷汗并且脸色改变

在这份清单里，数值不是判断的依据。 只要出现上述任何一条，即使血氧显示96，情况也可能是紧急的。反过来，如果显示89却还能好好走路、说话也很连贯，那么顺序应该是先怀疑设备而不是先怀疑人。 原因在第4节说明。

1.1 在韩国，急救号码是119

先把号码说准。在韩国，急救报警与咨询号码都是119。 过去作为急救医疗咨询电话使用的1339已并入119。 韩国政策简报刊登的政府简报写明，把急救医疗报警号码1339并入119的法律已经施行，并在全国范围内合并运行。如果现在还有资料告诉你紧急时拨1339，那是过时的信息。 不在韩国的读者，请使用所在地区的紧急号码。

由此还引出一个真正有用的事实：119不只是派车的号码。 同一份简报写明，119全年365天24小时承担报警受理与出动、指引与咨询、急救指导以及转送医院的引导。

正因为拿不准，才更可以打这个电话。 很多时间都消耗在「这种程度值得叫救护车吗」的犹豫里。但指引咨询和急救指导本来就在这项服务的职责范围内。并不是必须自己先得出结论，才有资格拨号。 在韩国以外的地区，对当地号码同样适用这个道理。

1.2 现在 / 今天之内 / 记下来以后说

并非所有情况都是急症，也并非所有情况都可以等。大致分层的话是这样。这张表是优先级表，不是诊断表。

情况依据什么判断行动
出现上面清单里的信号症状。 可以不看数值立即呼叫急救
症状不明显但数值一直偏低重测结果是否反复出现当天或尽快预约就诊
有基础疾病且低于自己平时与本人平时数值的差距按与医生约定的方案，没有则去问
没有症状且只低了一次测量条件(手温、指甲油、活动)纠正条件后重测，并记录数值
数值正常但人不舒服症状。 正常数值不是安心的依据与数值无关，去就诊

最后一行尤其重要。落在参考范围内的数字并不能证明「没事」。 这台设备只是估算有多少氧气结合在血红蛋白上，并没有观察身体里发生的全部事情。因为数字好看就推迟已预约的诊疗，是本文不建议的做法。

2. SpO2到底测的是什么

先从名字说起。血氧饱和度是血液中血红蛋白里正在携带氧气的那一部分所占的比例。 美国国立医学图书馆运营的MedlinePlus在介绍血氧水平检查时，把血氧饱和度这一项描述为「测量红细胞携带了多少氧气」。也就是说，它看的不是血液里有多少毫升氧气，而是运输者被装满到什么程度，是一个比值。

夹在手指上的设备得到这个比值的方式并不是抽血。它让光透过手指，读取随每次脉搏而变化的吸收量。 结合了氧气的血红蛋白与没有结合的血红蛋白，对光的吸收特性不同，设备正是利用了这一点。记住这个原理，第4节的整张误差清单就都能自然推出来。

2.1 与动脉血检查有什么不同

医院里有一种检查，是在手腕内侧等处用针采血，取的是动脉血而不是静脉血。按照MedlinePlus同一份说明整理，差别如下。

  • 脉搏血氧仪是一个夹子状的小设备，通常夹在手指上，只估算血氧饱和度这一个值
  • 动脉血检查用针从动脉采血，除饱和度外还同时看血氧分压、二氧化碳以及酸碱平衡
  • 同一份说明写到，当只需要了解血氧水平时，脉搏血氧测定可能是有用的。 也就是说两者不是替代关系，而是用途不同的工具
  • 说明中还写到，从动脉采血通常比一般抽血更不舒服，极少数情况下针可能损伤神经或动脉。这不是随便做的检查
  • 实用的结论是：家里的设备给你「现在值得查一下」的理由，而作为判断依据的精确数值来自医疗机构

体检中常规血液检查的结果如何逐项解读，在体检血液检查结果解读指南中另行讲解。本文不往那个方向展开，只专注于夹在手指上的设备给出的这一个数字。

3. 参考范围 —— 确认到的与没能确认的

这一节是全文最需要谨慎的部分，因为数字一旦写出来，读者就会把它当成分界线。

确认到的。 MedlinePlus把血氧水平检查中血氧饱和度的参考范围写作95至100个百分点。 本文实际打开页面确认过的数值，只有这一个。

不过在把这个数字套到自己身上之前，有几件事需要知道。

  • 这个范围是检查项目的参考标准，并不是按「低于此值就是有病」的用意划出来的界线
  • 家用设备的数值会随测量条件而波动。 同一个人在同一时刻测，换手指、换姿势得到不同数值是常有的事
  • 因此，稍微越出范围的单次数值不能确定什么；反过来，落在范围内的单次数值也不能让人安心
  • 有意义的是本人平时数值与当下数值的差距，以及这个差距是否反复出现。 趋势比单点携带的信息多得多

3.1 有基础疾病时目标可能不同

正在管理慢性呼吸系统疾病或心脏疾病的人，其管理目标有时会与一般标准不同。 有的情况下会按低于一般范围的值来管理，也有相反的情况。

在这里本文不写数字。 因为没能从一手来源直接确认按疾病区分的目标范围。把没确认过的数字写下来，就有可能被某个人直接当成自己的目标值。所以改成这样整理。

  • 如果觉得自己属于这种情况，目标值请与主治医生共同确定，而不是靠搜索。「我的目标范围应该看多少」是一个可以在诊室里问出口的具体问题
  • 如果已有确定的目标，把这个数字和「出现什么情况就联系」的标准一起定下来会更有用
  • 最好避免把一般标准当成自己的目标，因为对有些人来说方向可能是相反的

4. 设备出错的条件 —— 因为用光来测所以会发生的事

把第2节的原理再拿出来。这台设备让光透过手指，读取随脉搏变化的吸收量。 那么误差来源就可以归成三类：挡住光路的、削弱脉搏信号的、晃动信号的。 下表就是这个分类。

条件为什么会成为问题怎么处理
深色指甲油、带闪粉的产品阻挡光的通过，或改变吸收卸掉后重测，不方便就换一根手指
假指甲、光疗甲、甲片装饰在传感器与指甲之间多了一层取下，或换到别的手指
手很凉指端血流减少，脉搏信号变弱捂热之后再测
指端血流偏少的状态可供读取的波形本身就很小手放到心脏高度，摘掉勒紧的戒指
手抖、移动、边说话边测波形被晃动，脉搏识别发生偏差停下来等几秒再读数
脉搏不规则设备更难抓住脉搏周期核对脉率、重复测量、就诊时提及
阳光直射、很强的灯光外部光线进入传感器用手遮住，或到阴凉处测
传感器过松 / 夹得过紧光会漏进来，或血流被压住与手指粗细匹配，不要硬塞到底
运动或爬楼刚结束脉搏和呼吸还没有平复休息几分钟，在静息状态下测

最有用的自我检查只有一个。 设备屏幕上通常也会显示脉率。 把这个数字与你在手腕上摸到的脉搏比一比。两者差别明显时，那次读数最好不要相信。 血氧饱和度和脉率取自同一个波形，设备既然没能正确抓住脉搏，血氧饱和度很可能也一起偏了。只看一个数字发现不了的事情，把两个数字对照就能发现。

4.1 关于肤色，本文能说的部分

与肤色相关的测量误差，是近年监管机构正在处理的议题。美国的监管机构曾发布公告，提议修订建议以改善脉搏血氧仪在各类肤色上的性能，在此之前也发布过关于精度局限的安全提示。

但在写作本文的过程中，未能直接打开该机构的原文页面。 尝试过访问，但没有取回正文内容。因此这里不写「误差为多少个百分点」之类的数字。 写下未经确认的数字，恰恰是本文想要避免的那种做法。

从实用角度留下来的结论，与本文的主旨一致：不要把一个数字当成绝对标准。 如果测量值本身可能存在因人而异的偏差，那么用这一个值来划分是否紧急，从一开始就是脆弱的。把症状和趋势放在一起看，对这类不确定性要稳健得多。

5. 怎样测才可信

测量本身不难，但按顺序来会让数值稳定得多。

  1. 准备好手。 检查指甲油和假指甲，手凉就先捂热。摘掉勒紧的戒指
  2. 先安静下来。 坐着至少休息几分钟。刚爬完楼梯或正在说话时测出的值很难拿来参考
  3. 确定姿势。 把手放在大致与心脏同高的位置，不要让手臂垂着
  4. 等一等。 不要读夹上去立刻跳出的第一个数字，要读数值稳定之后的数字
  5. 核对脉率。 看屏幕上的脉率与手腕脉搏是否接近
  6. 换一根手指再测一次。 如果两次差别很大，那么两次都值得怀疑
  7. 做记录。 不要只写数值，要把时间、姿势、手指、脉率、症状一并写上

关于记录再补充一点。人们通常只记住并写下偏低的数值， 这样以后就看不出趋势了。只有知道自己平时大概是多少，才能判断当下是不是偏低，所以把没有异常时的数值也记上几次，实际上更有用。

6. 数值偏低时的顺序

这一节是本文的执行部分。顺序换了，结果就会不同。

  1. 先看症状。 符合第1节清单就到此为止，立即呼叫急救。不跳过这一步是关键
  2. 怀疑设备和条件。 从上到下过一遍第4节的表格。大多数偏低的数值在这里就能解释
  3. 把手捂热，安静一会儿再测。 然后换一根手指再测一次
  4. 核对脉率。 对不上，就把那次测量当作无效
  5. 做记录。 时间、姿势、手指、数值、脉率、症状
  6. 仍然偏低且反复出现，就预约就诊。 有症状则安排当天

不要做的事。 不要因为看到偏低的数值就自行吸氧。 不要在没有处方的情况下加药或停药。 视具体情况，这两件事都可能反而有害，而本文并不处在能代替你作出该判断的位置。还有一点：症状已经很明显却只顾反复重测，也不要做。那不是确认，是拖延。

症状重测结果最可能的解释行动
有(第1节清单)可以不看与数值无关，可能是紧急情况呼叫急救
无纠正条件后恢复正常很可能是测量条件的问题留下记录，继续观察
无换手指仍然偏低是设备还是实际，无法区分尽快就诊
轻微症状偏低反复出现属于需要查清楚的状态当天就诊，加重则呼叫急救
有数值正常正常数值不是安心的依据按症状来判断

7. 哪些人尤其要留意

这一节不给诊断名。「有这些症状就是这个病」不是本文该做的事，而且这样写出来的文字通常会把人带向错误的安心或不必要的恐惧。取而代之的写法只有一种：「如果符合，就与主治医生一起定好目标值」。

  • 正在接受慢性呼吸系统疾病管理的人。 事先约定好目标范围和联系标准，就能减少半夜盯着数字独自纠结的情形
  • 正在接受心脏疾病管理的人。 还要一并记住：脉搏不规则会降低读数本身的可信度。关于心律不齐的整体内容，另见心房颤动（房颤）完全指南
  • 年长者，或处于康复期的人。 把平时的数值记上几次，就有了判断「比平时低」的依据
  • 被人说睡觉时呼吸经常中断的人。 这种情况与其用家用设备的夜间数值自己下结论，不如去讨论该做什么检查。相关内容见睡眠呼吸暂停指南
  • 吸烟的人。 是否吸烟以及最近一次吸烟的时间，最好列入就诊时要说明的项目
  • 无论哪种情况，定好目标和联系标准都比买设备更优先。 没有标准的数字只会制造焦虑

反方向也要提一句。没有特别原因的人，每天测血氧的理由并不充分。 测得频繁，自然总会出现一次偏低的数值，而这一次就会制造出不必要的担心。这台设备更接近于有理由时才使用的工具，而不是好奇时就拿来用的东西。

8. 家用设备的局限

外形一样，设备的性质却未必一样。本文不提品牌和型号，但可以指出你能自己核实的部分。

  • 经过医疗器械审查的产品，与作为健康管理用品流通的产品是混在一起的。 包装和说明书上的注册或认证标识能显示这个区别。购买前或购买后都可以核实
  • 本文没能从一手来源确认各国注册分类的准确体系。因此不写「几类就可以」这样的标准， 只写请自己去看产品上是否有注册相关标识、说明书里是否有关于精度的记载
  • 它更接近于看变化而不是看绝对值的工具。 用同一台设备、同一根手指、在相似条件下测得的数值互相比较，才会产生信息
  • 设备不同，数值也可能不同。医院测的和家里测的不一致，并不说明其中一个坏了
  • 电池电量不足时数值有时会飘。如果怪异的读数持续出现，先换电池才是正确顺序
  • 设备不是报警装置。 它不是可以指望在你睡着时替你捕捉异常的东西，而这种指望反而会延误真正的应对

9. 就诊时要说明的信息

让家里测的数值在诊室里变得有用的，不是数字本身，而是上下文。 比起「测出来92」，带上下面这些信息要有用得多。

  • 从什么时候开始测出偏低值 —— 日期和大致时段
  • 在什么姿势和情境下测的 —— 静息时、活动之后，还是刚睡醒
  • 一共测了多少次，数值如何分布 —— 最低值、最高值、有代表性的值
  • 同一时刻的脉率，以及与手腕摸到的脉搏是否接近
  • 伴随症状及其变化 —— 气短、咳嗽、胸痛、头晕、水肿、发热
  • 已有的诊断，以及正在服用的药物和近期有过的调整
  • 近期有无发热、感染、手术或长途旅行
  • 是否吸烟以及最近一次吸烟的时间
  • 所用设备的名称，以及是否有注册标识
  • 这些是在家里测的这一事实本身。 设备与条件都和医院不同，这个前提需要传达出去

  • 与肤色相关的误差幅度。 只写了该议题正在被处理这一事实，没有写数字

常见问题

只要在参考范围内就可以放心吗?

很难这么说。这台设备只是估算有多少氧气结合在血红蛋白上，并没有观察身体里发生的全部事情。如果数值正常但有症状，按症状来判断更安全。

测几次比较合适?

出现异常读数时，纠正条件后测两三次，再换一根手指测一次，这样比较实用。再往上重复就容易变成拖延而不是确认。如果有症状，联系比反复测量更优先。

可以在睡觉时测吗?

睡眠中的数值受姿势、手温和传感器脱落的影响很大，变量太多，很难独自解读。 如果想弄清睡眠中呼吸的情况，去讨论该做什么检查是更好的路径。

可以夹在手指以外的地方吗?

每种产品指定的使用部位不同。原则是遵循说明书写明的部位，随意换地方测出的数值很难拿来作比较。

数值好看的话，可以推迟已预约的诊疗吗?

不建议。落在参考范围内的数字不足以成为推迟就诊的理由。 这台设备的数值不是诊疗的替代品，而是就诊时要说明的信息之一。

# 血氧饱和度(SpO2) — 紧急信号 · 测量可信度 · 就诊时要说明的信息

> 来源: braindetox.kr — 血氧饱和度(SpO2)数值怎么读
> 目的: 不是自我诊断，而是「不要错过该就医的时机」
> 本文档仅供参考，不能代替诊疗。判断由医务人员作出。

## 0. 先读这一段

- 不要凭一个数字下判断。要把**症状**和**变化趋势**放在一起看。
- 状态不好时，**先叫人帮忙，而不是再测一次**。
- 在韩国，急救报警与咨询号码是**119**。过去的急救医疗咨询电话1339已并入119。
- 不在韩国时，请使用**当地的紧急号码**。
- 本文档不含供氧剂量、药物名称和设备品牌。这是刻意的。

## 1. 出现这些情况请立即呼叫急救(与数值无关)

只要符合其中一条，就不要再测，直接联系。

- [ ] 气短到**一句话说不完**
- [ ] 安静坐着也感到呼吸困难
- [ ] 呼吸的声音或方式与平时明显不同
- [ ] 嘴唇、牙龈或甲床看起来**发青或发灰**
- [ ] 意识模糊 / 说话含糊 / 叫不太醒
- [ ] 突然瘫软或站不住
- [ ] 胸口有压榨感或被压住般的疼痛
- [ ] 冒冷汗并且脸色改变

**拿不准的时候也可以直接问。** 在韩国，119不仅受理报警和派车，还全天候提供咨询指引、急救指导和转送医院的引导。

## 2. 可信度检查表 — 这个数值能信吗

看到偏低的数值时，先怀疑**设备和测量条件**，而不是先怀疑人。

### 挡住光路的因素

- [ ] 是否卸掉了指甲油(尤其是深色和带闪粉的)
- [ ] 是否取下了假指甲、光疗甲和甲片装饰
- [ ] 手指是否干净(污渍、墨水、染料)

### 让脉搏信号变弱的因素

- [ ] 手是否不凉(凉的话先捂热再测)
- [ ] 手是否放在与心脏差不多的高度
- [ ] 手指上是否有勒得很紧的戒指或束带

### 让信号晃动的因素

- [ ] 测量时是否保持不动
- [ ] 是否一边说话一边测
- [ ] 手抖的话，是否换另一根手指也测过
- [ ] 是否感觉脉搏不规则(设备会更难抓住脉搏)

### 外部条件

- [ ] 是否处在阳光直射或很强的灯光下
- [ ] 传感器是否过松或夹得过紧
- [ ] 是否刚爬完楼梯(先休息几分钟再测)
- [ ] 显示的脉率是否与手腕摸到的脉搏接近(不接近就舍弃该次数值)

**脉率对不上，血氧数值同样不可信。** 两者出自同一个波形。

## 3. 数值偏低时的顺序

1. **先看症状。** 符合第1节任何一条就到此为止，立即呼叫急救。
2. **怀疑设备和条件。** 从头过一遍第2节的检查表。
3. **把手捂热，安静休息一到两分钟后重测。** 再换一根手指测一次。
4. **核对脉率。** 显示脉率与手腕脉搏不一致，就把该次测量视为无效。
5. **做记录。** 时间、姿势、手指、数值、脉率、症状。
6. **仍然偏低且反复出现，就预约就诊。** 有症状则当天就诊。
7. **不要自行处置。** 不要自作主张吸氧，也不要自行加减药物。

## 4. 记录表(照抄填写)

```
日期/时间    :
测量姿势     : 坐位 / 卧位 / 站位
测量前活动   : 静息 / 步行 / 爬楼 / 其他
测量手指     :
手的温度     : 温暖 / 微凉 / 冰凉
指甲油·假指甲 : 无 / 有
SpO2         :        %
脉率(设备)   :        次/分
脉率(手腕)   :        次/分
重复测量     : 1)      2)      3)
伴随症状     : 气短 / 咳嗽 / 胸痛 / 头晕 / 水肿 / 发热 / 无
备注         :
```

## 5. 就诊时要说明的信息

- [ ] **从什么时候**开始测出偏低值(日期、大致时段)
- [ ] 在**什么姿势和情境**下测的(静息 / 活动后 / 刚睡醒)
- [ ] 一共测了**多少次**，数值分布如何(最低、最高、代表值)
- [ ] 同一时刻的**脉率**
- [ ] **伴随症状**及其变化
- [ ] 已有的诊断、**正在服用的药物及近期调整**
- [ ] 近期有无发热、感染、手术或长途旅行
- [ ] **是否吸烟**以及最近一次吸烟的时间
- [ ] 所用设备的名称，以及**是否标注医疗器械注册信息**
- [ ] 这些是在家里测的这一事实本身(设备与条件都和医院不同)

## 6. 不要做的事

- 凭一个数字**自行断定是不是急症**
- 症状已经很明显却**反复重测、白白耗时间**
- 因为数值偏低就**自行吸氧**
- 没有处方就**加药或停药**
- 把网上**「低于多少就危险」这一句话**原样套到自己身上
- 有基础疾病却**把一般参考范围当成自己的目标值**(目标应与主治医生共同确定)
- 因为设备显示的数字好看就**推迟已预约的诊疗**

## 7. 记住这一句

**比数值偏低更重要的是症状和趋势。** 这台设备给你的不是诊断，而是「值得去把当前状态查清楚」的理由。
