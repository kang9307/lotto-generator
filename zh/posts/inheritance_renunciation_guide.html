前言：继承不只是继承财产

家人去世后，悲痛之余随即而来的是法律问题。许多人没有意识到，根据韩国法律，债务也随财产一同被继承。在规定期间内未作任何意思表示，将被视为单纯承认，即无条件继承全部财产和债务（民法第1026条）。若债务超过财产，继承人可能需要用自己的固有财产偿还差额，后果十分严重。

防止这种情况的法律手段正是继承放弃（상속포기）与限定承认（한정승인）。两种制度均旨在保护继承人免受过重债务负担，但其结构、效果及后续影响各有不同。本指南将基于韩国民法，详细说明两种制度的选择时机、3个月期限的意义、家庭法院申报程序、所需文件、多人继承注意事项及特别限定承认制度。

本文聚焦继承放弃与限定承认的程序。如需一并了解三种选择与遗留分，请参阅继承抛弃·限定承认·遗留分全解；遗留分权利人与比例、宪法裁判所2024年4月25日决定（兄弟姐妹遗留分条款违宪）以及2026年3月17日施行的修订民法（遗留分改为价额返还等），请参阅韩国遗留分完全指南。

1. 韩国继承法的三种选择

民法第1019条第1款赋予继承人在知悉继承开始之日起3个月内选择以下三种方式之一的权利。

1.1 单纯承认

单纯承认是指无限制地继承被继承人全部财产和债务。若3个月内不作任何申报，或对继承财产进行处分、消费等行为，将被自动视为单纯承认（民法第1026条）。财产远超债务时适合采用，但反之则对继承人极为不利。

1.2 限定承认

限定承认（民法第1028条）是指接受继承，但仅在继承所得财产范围内偿还债务。若继承财产为1亿韩元，债务为3亿韩元，限定承认后只需用1亿元资产清偿债务，超出部分无需用个人财产偿还。但限定承认后，需依法定程序向债权人发出公告并进行财产清算。

1.3 继承放弃

继承放弃（民法第1041条）是继承人完全拒绝继承的意思表示。放弃后，该继承人被视为从未成为继承人，既不继承财产，也不承担债务。但必须明确：该继承份额将转归其他继承人或下一顺位继承人，这是放弃产生的重要连锁效应。由谁取得取决于家庭构成（参见7.2）。

2. 继承放弃 vs 限定承认：核心比较

3. 不同情况下如何选择

3.1 债务明显超过财产时

两种制度均能保护继承人的个人财产。决定性差异在于对后顺位继承人的影响。放弃的份额归属于剩余继承人；若已无剩余继承人，孙子女或被继承人的父母等下一顺位亲属将成为新的继承人，可能需要重新决定放弃还是限定承认（参见7.2）。为防止这一连锁，由第一顺位继承人选择限定承认并自行清算往往是更现实的方案。

3.2 财产与债务规模不明确时

存在隐性债务或担保债务可能性时，限定承认更为安全。即便事后发现未预料到的债务，超过继承财产的部分也无需承担。单纯承认后发现债务超额，可诉诸特别限定承认，但举证要求严格。

3.3 财产超过债务时

通常选择单纯承认，无需复杂手续。但在决定前，建议核查被继承人是否存在连带保证债务等潜在负债。

4. 申报期限：3个月的含义

民法第1019条第1款规定必须在「知悉继承开始之日起3个月内」申报。

4.1 起算点：「知悉之日」

期间起算点不是被继承人的死亡日期，而是继承人知悉继承开始事实之日。通常为得知死亡消息之日。判例将其解释为继承人同时知晓继承开始原因（死亡）及自身为继承人之日。

4.2 3个月内「提交申报书」即可

只需在3个月内向家庭法院提交申报书即可，法院的审判结果在3个月后作出也不影响效力。

4.3 期间延长申请

根据民法第1019条第1款但书，可由利害关系人或检察官请求，由家庭法院延长期间。同条第2款规定，继承人在承认或放弃之前可以调查继承财产。延长请求最好在3个月届满前提出。财产目录难以迅速确定时可考虑申请延长。

4.4 逾期未申报的后果

3个月内未作任何申报，将依民法第1026条确定为单纯承认，此后原则上无法再申请继承放弃或限定承认。但此时仍可考虑特别限定承认这一救济途径。

5. 特别限定承认：错过期限的救济

民法第1019条第3款规定，即便已被视为单纯承认，在一定条件下仍可例外地申请限定承认。

5.1 申请要件

须同时满足两个条件：(1)在没有重大过失的情况下，不知道继承债务超过继承财产；(2)在知悉该事实之日起3个月内申报。「重大过失」是指稍加注意即可知晓，却疏于注意的情形。举证责任由申请人承担。

5.2 未成年人特别规定

民法第1019条第4款（2022年12月13日新设）为未成年人设有特别规定：未成年继承人在成年（韩国民法第4条规定为19岁）之前单纯承认了债务超过财产的继承的，可在成年后知悉该继承债务超额事实之日起3个月内作出限定承认。未成年时未申请或无法申请第3款特别限定承认的，亦同。

5.3 举证难度

特别限定承认虽为救济手段，但申请获批并不容易。须积极证明「不知情」及「无重大过失」，个人单独操作难度较大，建议寻求律师或法务士等专业人士协助。

6. 家庭法院申报程序

继承放弃和限定承认均须通过向家庭法院申报的方式进行，私下声明不具法律效力。

6.1 管辖法院

向被继承人最后住所地所在的家庭法院（无家庭法院地区则为地方法院或其支院）申报。

6.2 申报书记载内容

申报书须载明：当事人（申请人、被继承人）基本信息；与被继承人的关系；知悉继承开始之日；申请继承放弃或限定承认的意旨和原因；限定承认时须附继承财产目录。

6.3 所需文件（一般情况）

  • 被继承人相关：注销的住民登录谱（抄）本、除籍谱本或关闭的家族关系证明书·基本证明书
  • 继承人相关：住民登录谱本、家族关系证明书、印章证明书（或本人签名事实确认书）
  • 限定承认追加文件：继承财产目录（不动产、存款、债务等清单）
  • 含未成年人时：亲权人等相关文件

韩国政府生活法令信息（2026年8月31日基准）指出，继承放弃申报书须附申报人或代理人的印章证明书。具体文件要求因法院而异，建议事先咨询管辖家庭法院或通过大法院电子家族关系登记系统（efamily.scourt.go.kr）确认。

7. 共同继承与后顺位继承注意事项

7.1 共同继承人与限定承认

共同继承人多人时，限定承认可由全体共同申请，也可各自就其继承份额单独申请。一人限定承认、其余人单纯承认的，仅限定承认者受到保护。

7.2 继承放弃的连锁效应

继承人有数人而其中一人放弃时，其份额依民法第1043条按其他继承人的份额比例归属于该继承人。放弃者被视为自始不是继承人，因此若已无剩余继承人，则由下一顺位的人成为继承人。继承顺位（民法第1000条）如下：

  • 第1顺位：直系卑亲属（子女、孙子女等）及配偶
  • 第2顺位：直系尊亲属（父母、祖父母等）及配偶
  • 第3顺位：兄弟姐妹
  • 第4顺位：四亲等以内旁系血亲

配偶与直系卑亲属或直系尊亲属同为共同继承人，二者皆无时成为单独继承人（民法第1003条第1款），因此只要配偶仍在，继承不会轮到兄弟姐妹。配偶放弃而子女在世时，配偶的份额归属于子女。子女放弃后由谁继承，因家庭构成而异：

  • 有配偶和子女，子女全部放弃：配偶成为单独继承人（大法院2023年3月23日 2020그42 全员合议体决定），变更了此前「配偶与孙子女或直系尊亲属共同继承」的判例。继承债务也全部归属于配偶，因此须同时决定配偶的选择（放弃或限定承认）。
  • 配偶和子女全部放弃：由被继承人的孙子女等下一顺位的人继承（大法院2005年7月22日 2003다43681判决，韩国政府生活法令信息引用）。
  • 没有配偶或配偶也已放弃，且已无剩余直系卑亲属：由直系尊亲属（父母、祖父母）继承；直系尊亲属也没有时为兄弟姐妹，其次为四亲等以内旁系血亲。另外，自始没有直系卑亲属而有配偶的，配偶与直系尊亲属共同继承；直系尊亲属也没有时，配偶单独继承（民法第1003条第1款）。

放弃接连发生时，孙子女、年迈父母、兄弟姐妹可能依次成为继承人，各自需要重新决定。若预计会继承债务，家族成员应共同协商，先确认下一位继承人是谁，再考虑依次放弃或由前一顺位作出限定承认。

8. 限定承认后的清算程序

法院受理限定承认后，继承人须履行向债权人发出公告及清算财产的程序。

8.1 债权人公告·催告

自作出限定承认之日起5日内，须向一般继承债权人和受遗赠人公告限定承认的事实，并告知其在一定期间内申报债权或受遗赠（民法第1032条第1款）。该期间不得少于2个月。公告方法依同条第2款准用的第88条第3款，与法院登记事项的公告方法相同。

8.2 偿还顺序

公告期满后，先清偿有优先受偿权的债权（担保债权等），再按比例偿还一般债权。超过继承财产的债务部分，继承人无需以个人财产偿还。

8.3 清算期间禁止处分财产

公告期间不得擅自处分继承财产。向特定债权人优先偿还或隐匿财产均可能承担法律责任。

9. 常见问题

问：家庭法院的审判必须在3个月内完成吗？

不需要。只需在3个月内提交申报书即可，法院在3个月后作出审判也不影响效力。

问：已经取得部分遗产后放弃继承，需要归还吗？

继承放弃具有溯及效力，视为从未成为继承人。但处分或消费继承财产后，可能成立法定单纯承认，此后无法再申请继承放弃。因此，应在接触任何遗产之前先完成放弃申报。

问：家庭法院会驳回继承放弃申报吗？

材料齐全、在期限内提交的申报一般会被受理。但逾期申报、或已发生视为单纯承认行为的，可能被驳回。

问：有未成年子女时，父母可以代为申报吗？

未成年人由法定代理人（亲权人或监护人）代为申报。若父母与子女存在利益冲突（如子女放弃而父母单纯承认），须申请选任特别代理人。

10. 实务核查清单

  1. 记录得知被继承人死亡的具体日期
  2. 在日历上标注3个月截止日，争取在1至2个月内作出决定
  3. 整理财产（不动产、存款、保险、股票等）与债务（贷款、担保债务等）目录
  4. 比较财产与债务，选择继承放弃、限定承认或单纯承认
  5. 通过安心继承一站式服务（韩国政府24）申请查询财产与债务——申请期限为死亡日所在月末日起1年内
  6. 若有共同继承人，家族共同协商，确认放弃后下一位继承人是谁（7.2）
  7. 确认管辖家庭法院，准备所需文件
  8. 时间紧迫或情况复杂时，及时咨询法律专业人士
  9. 限定承认获批后，完成清算公告与清算程序

| 单纯承认、限定承认、放弃 | 自知悉继承开始之日起3个月（期限内提交申报书即可） | 韩国民法第1019条第1款 |
| 期间延长 | 经利害关系人或检察官请求由家庭法院延长（最好在3个月届满前请求） | 第1019条第1款但书 |
| 特别限定承认 | 无重大过失而不知债务超额的，自知悉之日起3个月 | 第1019条第3款 |
| 未成年继承人的特别限定承认 | 成年（19岁）后自知悉债务超额之日起3个月 | 第1019条第4款 |
| 限定承认后的债权人公告 | 自作出限定承认之日起5日内公告，申报期间不少于2个月 | 第1032条第1款 |
| 安心继承一站式服务申请 | 死亡日所在月末日起1年内 | 政府24 |

---

## 2. 放弃后由谁继承

| 情形 | 下一位继承人 | 依据 |
|---|---|---|
| 有配偶和子女，子女全部放弃 | 配偶单独继承（债务也归配偶） | 大法院2023年3月23日 2020그42 全员合议体决定 |
| 配偶和子女全部放弃 | 孙子女等下一顺位 | 大法院2005年7月22日 2003다43681判决（生活法令信息引用） |
| 没有配偶或配偶也已放弃，且已无剩余直系卑亲属 | 直系尊亲属 → 兄弟姐妹 → 四亲等以内旁系血亲 | 韩国民法第1000条 |
| 自始没有直系卑亲属而有配偶 | 配偶与直系尊亲属共同继承；直系尊亲属也没有时配偶单独继承 | 第1003条第1款 |
| 仅配偶放弃，子女仍在 | 配偶的份额归子女 | 第1043条 |

- [ ] 已用上表确认本家庭构成下放弃后由谁继承
- [ ] 已事先告知将成为继承人的家人（配偶、孙子女、父母等）
- [ ] 家人已共同决定是继续放弃，还是由前一顺位作出限定承认

---

## 3. 死亡后立即核查

- [ ] 已记录知悉死亡（继承开始）之日，并在日历上标注3个月截止日
- [ ] 已通过安心继承一站式服务（政府24）申请查询财产与债务
- [ ] 已整理不动产、存款、保险、股票等财产及贷款、担保债务等债务清单
- [ ] 未出售或使用继承财产（处分、消费可能被视为单纯承认，第1026条）
- [ ] 已比较财产与债务，选定单纯承认、限定承认或放弃

---

## 4. 申报材料核查

- [ ] 管辖：被继承人最后住所地的家庭法院（无家庭法院地区为地方法院或其支院）
- [ ] 被继承人：注销的住民登录谱（抄）本、除籍谱本或关闭的家族关系证明书·基本证明书
- [ ] 继承人：住民登录谱本、家族关系证明书、印章证明书（继承放弃申报须附申报人或代理人的印章证明书——生活法令信息）
- [ ] 限定承认时附继承财产目录
- [ ] 含未成年人时附亲权人、监护人材料，存在利益冲突时选任特别代理人
- [ ] 在线提交时完成大法院电子诉讼门户（ecfs.scourt.go.kr）的认证手续并附电子文件

---

## 5. 限定承认后清算核查

- [ ] 自作出限定承认之日起5日内向债权人、受遗赠人公告（方法准用第88条第3款——与法院登记事项的公告方法相同）
- [ ] 申报期间定为2个月以上
- [ ] 公告期间未处分继承财产，也未只向特定债权人清偿
- [ ] 按优先权债权 → 一般债权的顺序分配清偿

---

## 6. 申报前需再次确认

| 项目 | 状态 | 确认途径 |
|---|---|---|
| 期间延长请求的时限 | 法条未规定，未能核实 | 管辖家庭法院 |
| 能否以本人签名事实确认书代替印章证明书 | 生活法令信息只提及印章证明书 | 管辖家庭法院 |
| 特别限定承认的举证责任 | 未与判例原文核对 | 韩国律师 |

---

## 核心一句

**子女全部放弃时，成为单独继承人的可能是配偶而不是父母。** 放弃前先确认下一位继承人是谁，并先记下3个月截止日。
