PHP Basic Syntax and Data Types

PHP Basic Syntax

PHP Tags

PHP code is enclosed in special opening and closing tags so that the PHP engine can recognize it.

<?php
  // Write your PHP code here
?>

You can also use the short echo tag (enabled by default in PHP 7.0+):

<?= $variable ?>  // Equivalent to <?php echo $variable; ?>

Comments

PHP supports both single-line and multi-line comments.

<?php
// Single-line comment

# Alternative single-line comment style

/*
 Multi-line comment
 written like this
*/
?>

Statement Terminators

In PHP, every statement must end with a semicolon (;).

<?php
echo "Hello";
$x = 5;
$y = 10;
$z = $x + $y;
?>

Mixing PHP and HTML

PHP can be embedded directly inside HTML.

<!DOCTYPE html>
<html>
<head>
    <title>PHP Example</title>
</head>
<body>
    <h1>Hello!</h1>
    <?php
        echo "<p>Today's date is: " . date("Y-m-d") . "</p>";
    ?>
    <p>This is HTML content.</p>
    <p>Current time: <?= date("H:i:s") ?></p>
</body>
</html>

Variables and Data Types

Declaring Variables

In PHP, variables begin with a dollar sign ($) and do not need to have their types declared explicitly.

<?php
$name = "John Doe";    // String
$age = 25;             // Integer
$height = 175.5;       // Float
$isStudent = true;     // Boolean
?>

Variable Naming Rules

  • Variable names must start with a dollar sign ($).
  • The first character after the $ must be a letter or underscore (_).
  • Variable names may contain only letters, digits, and underscores.
  • Variable names are case-sensitive ($name and $Name are different variables).
<?php
$name = "Valid variable name";
$_name = "Valid variable name";
$name1 = "Valid variable name";
$name_1 = "Valid variable name";

// $1name = "Invalid variable name";  // Cannot start with a digit
// $name-1 = "Invalid variable name"; // Hyphens are not allowed
?>

Variable Scope

PHP variables can have one of three scopes:

  1. Local variables: declared inside a function and accessible only within that function.
  2. Global variables: declared outside any function; accessed inside a function using the global keyword.
  3. Static variables: declared inside a function with the static keyword; their value persists across function calls.
<?php
$globalVar = 10;  // Global variable

function testScope() {
    $localVar = 5;  // Local variable
    global $globalVar;  // Access the global variable

    echo "Local variable: $localVar<br>";
    echo "Global variable: $globalVar<br>";

    static $staticVar = 0;  // Static variable
    $staticVar++;
    echo "Static variable: $staticVar<br>";
}

testScope();  // Output: Local 5, Global 10, Static 1
testScope();  // Output: Local 5, Global 10, Static 2

// echo $localVar;  // Error: local variables cannot be accessed outside the function
?>

Superglobal Variables

PHP provides built-in variables that are accessible from any scope:

<?php
// Superglobal variable examples
echo $_SERVER['HTTP_USER_AGENT'];  // Browser information
echo $_GET['name'];                // URL parameters
echo $_POST['email'];              // POST data
echo $_REQUEST['id'];              // GET, POST, and COOKIE data
echo $_SESSION['user_id'];         // Session data
echo $_COOKIE['preference'];       // Cookie data
echo $_FILES['upload'];            // Uploaded file information
echo $_ENV['HOME'];                // Environment variables
?>

Data Types

PHP supports the following primitive data types:

  1. String

    $name = "John Doe";
$address = 'Gangnam-gu, Seoul';  // Single quotes work too

  2. Integer 

    $age = 25;
$negativeNum = -10;
$hex = 0x1A;  // Hexadecimal (value: 26)
$oct = 057;   // Octal (value: 47)
$bin = 0b11;  // Binary (value: 3)

  3. Float (or Double)

    $height = 175.5;
$scientificNotation = 1.5e3;  // 1500

  4. Boolean

    $isActive = true;
$hasPermission = false;

  5. Array

    $colors = array("red", "green", "blue");
$colors = ["red", "green", "blue"];  // PHP 5.4+ short syntax

// Associative array
$person = [
    "name" => "John Doe",
    "age" => 25,
    "city" => "Seoul"
];

  6. Object

    class Person {
    public $name;
    public $age;

    function __construct($name, $age) {
        $this->name = $name;
        $this->age = $age;
    }

    function introduce() {
        return "Hello, I'm {$this->name} and I'm {$this->age} years old.";
    }
}

$person = new Person("John Doe", 25);
echo $person->introduce();

  7. NULL

    $var = NULL;  // Indicates the absence of a value

  8. Resource

    $file = fopen("test.txt", "r");  // File resource

Checking and Converting Types

PHP provides a variety of functions for inspecting and converting the type of a variable.

<?php
$var = "42";

// Type checking
var_dump($var);                // string(2) "42"
echo gettype($var);            // string
echo is_string($var);          // 1 (true)
echo is_int($var);             // (empty output, false)

// Type casting
$varInt = (int)$var;           // Cast to integer
$varFloat = (float)$var;       // Cast to float
$varBool = (bool)$var;         // Cast to boolean
$varString = (string)$varInt;  // Cast to string

// Type-checking functions
echo is_int($varInt);          // 1 (true)
echo is_float($varFloat);      // 1 (true)
echo is_bool($varBool);        // 1 (true)
echo is_string($varString);    // 1 (true)
?>

Constants

Constants are values that cannot be changed once defined. You can define a constant with the define() function or the const keyword.

<?php
// Using the define() function
define("PI", 3.14159);
define("SITE_NAME", "PHP Tutorial");

// Using the const keyword (PHP 5.3+)
const MAX_USERS = 100;
const DB_HOST = "localhost";

echo PI;           // 3.14159
echo SITE_NAME;    // PHP Tutorial
echo MAX_USERS;    // 100

// PI = 3.15;      // Error: constants cannot be modified
?>

Magic Constants

PHP provides a set of special built-in constants known as magic constants:

<?php
echo __LINE__;     // Current line number
echo __FILE__;     // Full path and filename of the current file
echo __DIR__;      // Directory of the current file
echo __FUNCTION__; // Current function name
echo __CLASS__;    // Current class name
echo __METHOD__;   // Current class method name
echo __NAMESPACE__; // Current namespace name
?>
