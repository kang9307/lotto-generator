使用前确认：年龄、账号、实名认证

Daangn面向年满14周岁的手机用户开放。注册过程中必须同意「年满14周岁(必选)」一项，不同意就无法注册。在服务中直接或间接提到自己未满14周岁，使用可能受到限制；实际已满14周岁的用户，可以通过咨询入口提交运营商文件(SKT为使用合同登记事项证明书，LG U+为加入事实确认书，KT为原簿证明书)来申诉。限制期限到提交证明为止，标注为最长1,825天。

账号以手机号作为ID，所以一个手机号只能创建一个账号。更换号码后需要重新做实名认证。如果别人用该号码注册，导致原账号的手机认证失效，该账号会在60天后被自动删除，因此换号后要在期限内用新号码完成认证。

销售另有条件。Daangn帮助中心说明，自2026年7月21日起，根据电子商务法修订，出售二手物品必须完成手机实名认证。已认证的用户无需重复认证，未认证则无法使用销售功能。路径是「我的Daangn → 设置(右上角) → 账号/信息管理 → Daangn实名认证」，或在发布销售帖的界面内完成。

  • 年龄标准：年满14周岁，注册时的同意项为必选。
  • 账号数量：一个手机号对应一个账号。
  • 销售条件：2026年7月21日之后，出售二手物品需要手机实名认证。
  • 登录时的认证要求：从未认证的账号、认证已超过一年的账号、用新设备重新登录时，可能被要求认证。
  • Daangn Pay：按现行法律需要另行认证，见第9节。

发生纠纷时，卖家的电话号码等身份信息只有在卖家同意的情况下才会提供给买家，是否提供由卖家自己选择。上架之前了解这一点，就能清楚实名认证究竟会公开到什么程度。

社区设置与社区认证：30天失效及限制

Daangn的二手交易以本地邻居为前提，所以分成两个步骤。先用「设置我的社区」决定使用哪个区域，再用「社区认证」确认本人确实在该区域。最多可以选择2个社区，建议选择家、公司、学校等常去的地方。系统会结合兴趣，推荐所设社区及其附近的帖子。

社区认证的步骤很短。打开应用底部的「我的Daangn」，点击社区认证按钮，用地图右下角的图标获取当前位置，再点击完成认证按钮。要认证的社区和当前位置不一致就会失败。社区认证只有在本人确实处在想访问的社区时才能获得，把验证码告诉别人让对方代为认证，因有账号被盗风险而被严格禁止。

社区认证大约30天后失效。保持设备GPS开启，应用启动时会自动认证，失效前一天会发送通知。失效后，能做和不能做的事情如下。

状态发送新聊天发布新帖子备注
认证有效可以可以只能在已认证的社区交易
失效后(约30天未认证)不可以不可以已有的聊天室、有意购买者先发来的聊天仍可使用
认证后把该社区从我的社区中删除——48小时内不重新认证可能失效，失效前一天的通知也可能不发送

认证失败时，官方文件列出三种原因。第一，设备的位置权限或精确位置设置处于关闭状态(安卓为「设置 → 位置信息 → 应用权限」，iPhone为「设置 → Daangn → 位置」)。在建筑物内、地下或移动中可能定位不到，建议到窗边或室外重试。第二，要认证的社区与实际位置不同。第三，短时间内在过多社区认证，或用不正常的方式认证，社区认证可能被限制。三种情况都不符合时，通过「我的Daangn → 客服中心」咨询。

  • 想在其他社区交易，要先更改我的社区并在那里认证。认证后即使离开该地区，在认证失效前仍可聊天。
  • 搬家后，把新社区设为我的社区并认证。之前发布的二手帖子可以通过「我的Daangn → 齿轮图标 → 更改二手帖子所在社区」迁移。只有「在售」状态的帖子会迁移，隐藏和删除的帖子除外，并且在该社区发布的帖子会一次性全部改变。社区生活帖子不适用。不需要因为搬家而注销账号。
  • 个人资料上显示的社区认证次数，以最近30天为准。

找物品与出价：搜索、距离筛选与礼仪

搜索从首页右上角的放大镜开始。设置了两个社区时，搜索结果会出现「某社区附近」按钮，可以以所选区域为中心查看周边物品。只想看近处物品，点击「2km以内」，就只保留与卖家距离在2km以内的物品。把排序从「推荐」改为「最近」，会按由近到远排列，两个功能可以同时使用。首页顶部的「附近社区」只汇总较近区域的帖子，但即使完成了社区认证，如果我的社区附近新帖子不足，也可能不显示。

搜索结果的排序，官方文件用三个标准来说明。相关度是搜索意图与帖子内容的关联，时效性是发布及「顶帖」的日期，偏好度是点击、收藏、聊天等用户反应。首页信息流把时效性、兴趣关联(浏览、收藏、聊天记录)和帖子质量(信息是否充实)列为要素。官方文件中没有给出具体的评分公式。

出价对买卖双方都有规则。帖子上有「出价」按钮，表示卖家愿意接受报价，点击按钮就能发送想要的价格。卖家有兴趣会发聊天消息，没有回复就视为被拒绝。没有该按钮的帖子表示卖家不希望被还价，聊天界面顶部会出现「不可出价」标记。

  • 没有真心购买的打算就不要出价。与行情相差太远的价格得不到回复。
  • 对不接受还价的帖子反复出价，可能收到失礼评价，评价累积会使礼仪温度下降，多次发生可能被限制使用服务。
  • 文件明确写道，在没有出价标记的帖子上，要求把运费算进价格、以当面交易为条件压低价格、要求免费赠送，即使谈成也可能受到警告或失礼评价。

写销售帖：路径、类别、照片与展示范围

销售帖在首页的「+ 发帖」(或「+」)→「卖我的东西」中撰写。在标题和详细说明中输入物品信息后，会根据输入内容自动出现推荐类别。说明提到，物品名称、用途、特征写得越具体，推荐越准确。照片通过相机图标，从相册选择或当场拍摄添加，长按照片可以调整顺序。销售技巧文件(FAQ 200)写道，第一张照片同样重要，要突出物品的特点来拍，从不同角度多拍几张，需要说明的部分放大拍摄。

写帖界面下方的「选择帖子展示的社区」，用滑块设定帖子展示的区域范围。帮助文件没有用数字说明这一范围的效果。FAQ 12说明，只有在完成社区认证的地区才能交易。

还有一个功能，只要上传照片，AI就会生成草稿和推荐价格。在写帖界面添加图片后，底部会出现AI撰写的开关，可以开关；如果事先写好的内容因AI撰写而消失，可以用标题和说明输入框右侧的「恢复」按钮找回。照片越能清楚显示是什么物品，如型号、品牌、产品标签、包装盒，准确度越高。官方文件明确写道，AI可能出错，对所发布物品的责任在卖家，所以草稿中的型号、配件、瑕疵描述要亲自核对后再发布。

  • 使用自己拍摄的照片。运营政策指出，不是实物的照片会造成误解。
  • 出售前先清洗或整理干净。说明提到，即使有使用痕迹，干净的物品也会让交易气氛更好。
  • 不要发布与二手交易无关的一般或闲聊帖子。
  • 转卖在Daangn上购买的物品时，要写明转卖原因，并且只能以不高于购买价的价格出售。
  • 现金交易(借钱或放贷等)、药品和医疗器械、未通过国内适合性评估的海外直购设备、政府扶持物资(如Narami大米、地区商品券)被列为禁止交易。禁止交易的物品，在免费赠送或求购帖中也不被允许。

定价标准：确认行情与调整顺序

官方帮助在定价上给出的方法只有一个：在Daangn搜索类似物品，以已成交帖子的价格作为行情。关键是看已成交的帖子，而不是还在出售的帖子的标价。FAQ 200把已成交物品的价格作为了解行情的依据。想尽快卖出，说明建议定得比行情略低。官方文件没有给出具体的降价幅度(例如百分之几)，所以下面的数字只是计算示例。

  1. 搜索类似物品，只挑选已成交的帖子收集价格。优先型号、配件、使用时间相同的帖子。
  2. 查看收集到的价格范围。例如成交价集中在8万到10万韩元之间，中间值附近就是基准(计算示例)。
  3. 瑕疵和缺失的配件要从价格中扣除，同时写进说明。Daangn的争议调解以卖家交易前告知的内容为依据(第6节)。
  4. 长时间卖不出去时，降价并顶帖。降价会向点了收藏的邻居发送降价通知(第7节)。
  5. 说明提到，使用销售助手功能时，会在合适的时机提出基于Daangn行情的折扣价。

是否接受还价由卖家决定。带有出价按钮的帖子表示卖家愿意接受还价；没有按钮的帖子，二手交易运营政策(FAQ 41)把不要求降价列为买家的礼仪。AI推荐价格被描述为基于实际售出的类似物品的价格，所以适合用来和自己查到的行情互相对照。

转卖在Daangn买的东西另有标准：只能以不高于购买价的价格出售。以赚差价为目的的转卖不符合该标准，而作为赠送收到的物品根本不能转卖(第7节)。

说明与瑕疵告知：三级标准

Daangn的礼仪说明写道，没有明示的瑕疵可成为退款理由。另一方面也说明，当面交接的物品，因使用痕迹而退款很困难。把两句话合起来，就是卖家的说明标准：使用痕迹可以不写，瑕疵必须写。那么什么算使用痕迹，什么算瑕疵？Daangn争议调解中心表示，会基于卖家在交易前告知的内容和可客观确认的证据材料给出调解方案，并把状态分为三级。

等级定义电子产品示例服装鞋类示例
使用痕迹正常使用中自然产生的痕迹边框细微划痕、背面日常划痕针织衫自然起球、鞋底一般磨损
轻微瑕疵外观有损伤但功能正常屏幕边角小裂纹(触控、显示正常)、按键凹陷(正常工作)1至2cm的撕裂、明显污渍、纽扣或拉链损坏
严重瑕疵功能异常或难以使用屏幕无法识别、无法开机大面积撕裂的衣物、鞋底脱落的鞋

调解中心的文件写道，轻微瑕疵若在交易前用说明和照片告知，对双方都更安全；严重瑕疵直接影响功能和使用，必须在交易前告知。还有一句说明，买家应在考虑使用痕迹的前提下使用。换成撰写销售帖的角度，就是下面几点。

  • 使用痕迹一行即可。像「有日常划痕」这样写明位置和程度。
  • 轻微瑕疵既用照片展示，也用文字写出。争议调解中心的文件写道，应通过「帖子说明及照片」提前告知。
  • 严重瑕疵必须在交易前告知，争议调解中心的文件如此写道。把它放在说明开头是本文的建议。
  • 使用时长、购买时间、配件(包装盒、充电器等)是买家最先询问的项目，一开始就写上。

调解的局限也已明确。文件写道，气味方面的瑕疵难以客观确认；植物的生长可能性或病虫害，因无法知道问题出现的时间和原因而难以调解。香水的真假可以通过专家意见确认事实，所以可以申请。加工食品方面，销售过期品、声称未开封实际已开封属于可申请的案例，收货后保存不当或原因不明的变质则被归为难以调解的案例。另外，二手交易运营政策(FAQ 41)说明，当面购买的物品因使用痕迹退款很难；在即时购买(安心支付)交易中，若双方无法达成一致，货款会一直由Daangn Pay保管，因此当与帖子不符的物品或仿品、缺少配件、未告知或轻描淡写了对使用影响很大的瑕疵等情形有客观资料证实时，Daangn可按既定程序依职权退款或结算。

预约、成交、顶帖与赠送

交易状态在「我的Daangn → 销售记录」中，点击帖子下方右侧的三个点，选择「改为预约中」或「改为交易完成」。约定确定后改为预约中，有人预约就卖给那个人。运营政策指出，毁约会破坏信任。交易完成或预约中的帖子，可在同一菜单中改回「在售」。FAQ 11说明，交易评价可在「我的Daangn → 销售记录 → 交易完成列表」或「购买记录」中发送(第8节)。

顶帖是把帖子的发布时间更新为最新的功能。顶过的帖子在首页标签中适用个性化推荐，据说能提高售出概率。路径是「我的Daangn → 销售记录 → 帖子的三个点 → 顶帖」，或帖子下方的「顶帖」按钮。限制有三条。

  • 每天最多只能顶6个帖子。
  • 每个帖子最多可顶15次。
  • 顶过一次的帖子，要过一段时间才能再顶。这段时间的长度在官方文件中没有给出数字。

如果顶了15次仍未售出，说明建议隔一段时间后重新发帖。文件建议在新帖中重拍照片使物品更清晰、充实说明、并适当调整价格。降价同时顶帖，会向点了收藏的邻居发送通知，所以在次数有限的情况下，把顶帖与降价结合使用更有效率。由于等待时间没有给出数字，顶满15次所需的时间不做计算。

赠送使用同一个写帖界面：价格输入0韩元，就会自动显示为赠送。选择「接受申请」会开启赠送活动，不聊天而是接受邻居的申请，赠送者从申请者中挑选并先发起聊天。赠送不是先到先得，帖子中可以写明赠送条件。接受赠送的人不能转卖该物品，违反者可能被举报和处罚。假借赠送之名销售物品或要求某种行为的帖子，同样违反运营政策。接受赠送的次数没有限制。官方的销售技巧中也建议，把不好卖但仍可使用的物品改为赠送。

礼仪温度、评价与礼仪评分

礼仪温度是所有用户从36.5度开始、最高可升到99度的指标。获得称赞的礼仪评分和好评会升高，收到失礼评价、差评以及违反运营政策的处罚会降低。可以在个人资料中查看，温度越高表情越像笑脸，越低越像皱眉。对方温度低于36.5度时，官方文件建议仔细查看再次交易意愿率和评价。

分数的变化有时间规则。评分和评价不会立即反映，可能需要7至10天左右。目的是让人无法知道是谁留下了负面评价。越近期收到的评价权重越大，超过3年的评分和评价不再反映。这就是活动稀少时温度可能慢慢下降的原因。文件对影响温度的因素有如下记载。FAQ 135举例说，经常发生纠纷或经常违约的用户，温度会逐渐降低；FAQ 18说明，长期不活动就难以判断信誉，因此降低较早评价的权重。

礼仪评分与交易评价是不同的工具。礼仪评分通过对方个人资料的「称赞礼仪」或「三个点 → 给出失礼评价」留下。称赞评价其他用户也能看到，而失礼评价只有被评价的本人可以看到，是谁留下的以匿名方式处理。一段时间内失礼评价累积可能导致停用，因此说明请求只在必要时留下。与事实不符的失礼评价，可能因虚假评价而受到警告。

  • 适用失礼评价的违约情形：约定时间地点后失联、交易前单方面毁约、没有出现在约定地点。
  • 交易评价通过「我的Daangn」中的「发送评价」(交易完成的销售记录或购买记录)，或聊天室顶部的「发送评价」按钮留下。该按钮在开始聊天30分钟后才会出现。
  • 没有交易却收到要求写评价的通知，不写也没有任何不利。
  • 再次交易意愿率由交易评价计算，至少收到5条评价才会显示。「不错」「最棒」等好评累积会使其升高。

选择交易方式与交易后问题的处理

交易方式由交易双方决定。有当面交易和不见面交易(快递、挂门把手)两种，不见面的交易使用即时购买、安心支付或快递预约，会更安全方便。两种方式最大的区别，是当面交接后发现的瑕疵，Daangn很难提供帮助。二手交易运营政策中「当面交易时」的条目写道，买家想了解物品的运作或穿着效果时，卖家亲自演示或穿戴给买家看会更好；当面购买的物品，因使用痕迹申请退款也很难。不想暴露账号的话，可以用Daangn Pay做简易转账。
