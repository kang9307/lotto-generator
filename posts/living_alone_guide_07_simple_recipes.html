혼자 살아남기 7편: 간단 요리 레시피

요리 못해도 할 수 있는 생존 요리

2026-01-25생활/건강

매일 배달 시키면 돈이...

자취 초반에 요리 못 한다고 매일 배달 시켰어요. 한 달 지나고 카드값 보고 놀랐죠. 그래서 억지로 요리 시작했는데, 생각보다 별거 아니더라고요.

오늘은 진짜 요리 못하는 사람도 할 수 있는 초간단 레시피들을 공유할게요. 라면 끓일 줄 알면 다 할 수 있어요.

1. 계란 요리 3종

계란만 있으면 뭐든 할 수 있어요.

계란후라이 (5분)

재료: 계란, 식용유, 소금

  1. 프라이팬에 기름 살짝 두르기
  2. 약불로 예열 (1분)
  3. 계란 깨서 넣기
  4. 소금 살짝 뿌리기
  5. 흰자가 익으면 완성 (노른자는 취향껏)

팁: 불이 세면 가장자리 타요. 약불이 핵심!

스크램블 에그 (5분)

재료: 계란 2개, 우유 조금, 소금, 버터(없으면 기름)

  1. 계란 + 우유 + 소금 섞기
  2. 약불에 버터 녹이기
  3. 계란물 넣고 젓가락으로 계속 저어주기
  4. 반쯤 익었을 때 불 끄기 (여열로 완성)

팁: 너무 익히면 퍽퍽해요. 촉촉할 때 끄세요.

계란찜 - 전자레인지 버전 (5분)

재료: 계란 2개, 물 또는 육수 100ml, 소금

  1. 그릇에 계란 + 물 + 소금 잘 풀기
  2. 랩 씌우고 이쑤시개로 구멍 몇 개 뚫기
  3. 전자레인지 2분 30초 (700W 기준)
  4. 부족하면 30초씩 추가

2. 밥 요리

간장계란밥 (5분)

재료: 밥, 계란, 간장, 참기름, 김가루

  1. 뜨거운 밥에 계란 올리기
  2. 간장 1스푼, 참기름 조금 넣기
  3. 비비기
  4. 김가루 뿌리면 완성

팁: 파 송송 썰어 넣으면 더 맛있어요.

참치마요덮밥 (5분)

재료: 밥, 참치캔, 마요네즈, 간장, 김가루

  1. 참치 기름 빼기
  2. 참치 + 마요네즈 2스푼 + 간장 조금 섞기
  3. 밥 위에 올리기
  4. 김가루 뿌리면 완성

볶음밥 (10분)

재료: 밥, 계란, 파, 간장, 식용유

  1. 프라이팬에 기름 두르고 파 볶기
  2. 계란 넣고 스크램블
  3. 밥 넣고 같이 볶기
  4. 간장으로 간하기

팁: 냉장고 남은 재료 아무거나 넣어도 돼요.

3. 면 요리

라면 업그레이드 (10분)

기본 + α

  • 계란: 라면 다 익으면 계란 풀어 넣기
  • 치즈: 불 끄고 치즈 올리기
  • 파: 송송 썰어 넣기
  • 떡: 처음부터 같이 끓이기

비빔국수 (10분)

재료: 소면, 고추장, 식초, 설탕, 참기름

  1. 소면 삶고 찬물에 헹구기
  2. 고추장 2스푼 + 식초 1스푼 + 설탕 1스푼 + 참기름 섞기
  3. 면이랑 비비기
  4. 계란 반숙 올리면 더 맛있음

4. 국물 요리

계란국 (10분)

재료: 계란 2개, 물 2컵, 다시다, 소금, 파

  1. 물 + 다시다 끓이기
  2. 끓으면 계란 풀어서 천천히 넣기
  3. 소금으로 간
  4. 파 넣고 완성

김치찌개 - 초간단 버전 (15분)

재료: 김치 1컵, 돼지고기 조금 (없어도 됨), 두부, 물, 고춧가루

  1. 냄비에 기름 두르고 김치 볶기
  2. 고기 있으면 같이 볶기
  3. 물 2컵 붓고 끓이기
  4. 두부 넣고 5분 더
  5. 고춧가루 조금 넣으면 더 맛있음

팁: 신 김치일수록 맛있어요.

5. 반찬/간식

계란말이 (10분)

재료: 계란 3개, 소금, 파(선택)

  1. 계란 + 소금 + 파 섞기
  2. 약불에 기름 두르기
  3. 계란물 1/3 붓고 얇게 펴기
  4. 반쯤 익으면 말기
  5. 한쪽으로 밀고 나머지 계란물 붓기
  6. 반복

토스트 (5분)

재료: 식빵, 버터(또는 마가린), 계란, 치즈

  1. 프라이팬에 버터 녹이기
  2. 식빵 올리고 앞뒤로 굽기
  3. 스크램블 에그 만들어서 올리기
  4. 치즈 올리면 완성

6. 장보기 필수템

이것만 있으면 위의 요리 다 할 수 있어요.

냉장고

  • 계란 (필수!)
  • 파
  • 김치
  • 두부
  • 참치캔

냉동실

  • 냉동밥 or 즉석밥
  • 냉동 야채 믹스

상온 보관

  • 라면
  • 소면
  • 간장, 참기름
  • 고추장
  • 다시다
  • 김가루

7. 요리 꿀팁

  • 약불이 기본: 강불은 초보자의 적. 타기 쉬워요
  • 간은 마지막에: 처음에 짜게 하면 수정 불가
  • 계란은 만능: 뭘 해도 계란 넣으면 맛있어짐
  • 설거지 바로: 요리 끝나면 바로 해야 안 눌러붙음
  • 실패해도 OK: 처음엔 다 그래요. 연습하면 늘어요

마무리

요리는 생각보다 어렵지 않아요. 배달비로 나가는 돈 생각하면 해볼 만해요. 처음엔 계란후라이부터 시작해보세요!
