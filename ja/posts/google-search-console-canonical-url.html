A Complete Guide to Canonical URLs for Google Search Console

ウェブサイトを運営しているなら、「検索エンジン最適化 (SEO)」はもはや選択ではなく必須です。数多くある SEO 要素の中でも canonical URL (正規 URL) の設定は、テクニカル SEO の中でも最も基本的でありながら強力な影響を及ぼす核心要素です。Google Search Console で重複ページの問題に悩んでいる方、サイトの SEO 効率を最大化したい方は、ぜひ最後まで読み進めてください。

1. canonical URL (正規 URL) とは何か?

canonical URL (rel="canonical") とは、類似または同一のコンテンツを持つ複数の URL のうち、検索エンジンに代表として認識させ、インデックスを作成させたい「原本」または「代表」URL を指定するための HTML タグ属性です。端的にいえば、「これだけ多くのページの中で、本当の原本はこのページだよ」と検索エンジンに伝える合図です。

たとえば、以下の URL はすべて同じ商品ページを表示する可能性があります。

  • http://www.example.com/product/item
  • https://www.example.com/product/item
  • https://example.com/product/item
  • https://example.com/product/item?ref=banner
  • https://example.com/product/item?utm_source=google

ユーザーの目にはどれも同じページに見えますが、検索エンジンはこれらをそれぞれ別個のページと認識してしまい、SEO 評価が分散してしまうことがあります。ここで canonical URL を指定すれば、ばらばらに散った評価を 1 つの代表 URL に統合でき、検索順位の向上に大きく役立ちます。

2. 正しい canonical URL の設定方法 5 選

canonical URL の設定方法はいくつかあり、状況に応じて最適な方法を選ぶ必要があります。

方法 1: `rel="canonical"` HTML タグの使用 (もっとも一般的な方法)

最も広く使われる方法で、HTML 文書の <head> セクションに <link> タグを追加して canonical URL を明示します。

<head>
    <link rel="canonical" href="https://example.com/代表ページの-URL" />
</head>

自己参照 (Self-referencing) canonical URL: 現在のページ自身が原本ページである場合にも、自己自身を canonical URL として指定するのが望ましいです。これは Google に対して「このページが原本で間違いない」と明確に伝える役割を果たします。

方法 2: HTTP ヘッダーの使用

PDF や画像ファイルのような HTML 以外のコンテンツに対して canonical URL を指定する際に使用します。サーバー設定で HTTP レスポンスヘッダーに `Link` 情報を追加します。

Link: <https://example.com/downloads/white-paper.pdf>; rel="canonical"

方法 3: サイトマップ (Sitemap) の活用

サイトマップに含まれる URL は、Google によって canonical URL とみなされる可能性があります。ただし、これは `rel="canonical"` タグに比べると弱いシグナルなので、他の方法と併用するのが望ましいです。

方法 4: 301 リダイレクトの使用

重複ページを恒久的に別の URL へ移転させる場合に使用します。301 リダイレクトは、検索エンジンに「以前のページはもう存在せず、新しい正規ページはこちらだよ」と伝える、もっとも強力なシグナルです。ページ移動やドメイン変更 (http → https) などの場面では必須の手法です。

方法 5: Google Search Console の「URL パラメータ」ツール

セッション ID やソート、フィルタリングなど、特定の URL パラメータを Google がどのように処理するかを指定する機能です。ただし、この設定はサイト全体に影響を及ぼす可能性があるため、専門家でない限り使用には細心の注意が必要です。

3. ありがちな失敗と対処法 (Do's & Don'ts)

canonical URL の設定は一見シンプルですが、誤って設定するとかえって SEO に悪影響を与えかねません。以下の表を参考に、よくある失敗を避けましょう。

区分 Do (正しい方法) ✅ Don't (誤った方法) ❌
パス 絶対パスを使用
https://...		 相対パスを使用
/page.html
位置 <head> セクションにのみ配置 <body> セクションに配置
数 1 ページにつき 1 つの canonical URL を宣言 複数の canonical URL を宣言
ページネーション 各ページは自身を canonical に指定するか、`rel="prev/next"` を使用 すべてのページネーション (2, 3, 4...) を最初のページに正規化
プロトコル HTTPS のページは HTTPS を canonical に指定 HTTPS のページに HTTP を canonical として指定

まとめ

canonical URL の設定は、複雑化するウェブ環境で検索エンジンに自分のサイトのコンテンツを正しく理解させ、適切に評価させるための不可欠な SEO 施策です。本記事で紹介した方法を活用してサイト内の重複コンテンツ問題を解消し、分散していた SEO 評価を集約して検索順位の向上につなげましょう。Google Search Console の「ページのインデックス登録」レポートを定期的にチェックし、canonical URL 関連の問題をモニタリングする習慣を身につけることも重要です。
