白天不在家，快递却来了...

上班的人白天很难亲自收快递。常常是已签收的短信到了人却不在，或者楼里没有保安室，没地方寄放。

本文整理了独居者安全收快递和外卖的方法。内容以韩国的快递外卖环境为前提，赔偿标准和申诉流程只写了通过官方说明确认过的部分。

1. 不在家时的快递处理方法

方案1：保安室代收

  • 楼里有保安室的话设为默认
  • 在配送备注写"请放保安室保管"
  • 下班后去取
  • 各楼是否代收不同，先确认物业规定

方案2：智能快递柜

  • 公寓或商住楼有快递柜就用起来
  • 存放位置和取件密码（或验证方式）通常通过短信或App发送
  • 很多地方全天都能取，但运行方式因楼而异

方案3：放门口

  • 在配送备注写"请放门口"
  • 有丢失风险，贵重物品尽量避免
  • 请快递员拍送达照片
  • 按韩国标准条款修订说明，放在与客户约定的地点即视为已交付。约定放门口后如果东西不见了，责任会更难划分，所以务必确认照片

方案4：便利店自提

  • 部分快递公司和卖家支持便利店自提
  • 下单时选择便利店自提
  • 在营业时间内领取

最好选定没人在家也安全的寄放处，比如保安室或快递柜。放门口有丢失风险。

2. 善用配送备注

有效的配送备注

  • "请放保安室保管。房号：000号"
  • "不在家请放门口，并拍送达照片"
  • "请使用快递柜"
  • "送货前请先联系"

注意事项

  • 地址里不要写"独居""一个人住"（安全）
  • 姓名用姓氏+OO，不写全名（例：金OO）
  • 运单上姓名、地址、电话会一起打印，配送备注里不要再多写个人信息

3. 外卖小技巧

一人份外卖

  • 起送价与配送费：因App、商家和时段而异，只点一人份时配送费在总价中的占比可能偏高
  • 份量：只有确定下一餐能吃完时才多点一些（吃不完反而浪费）
  • 优惠：首单优惠、优惠券要先看使用条件

食物保存

  • 不马上吃就放冰箱
  • 面类会泡软变味，尽快吃
  • 第二天吃要充分加热到里面

外卖App使用

  • 比较多个App时把配送费和起送价也算进去
  • 有自取优惠的话可以考虑自己去取
  • 以带图评价为主参考，同时记得有些评价可能是推广

4. 长期不在家

旅行/出差时

  • 有预计到货的快递就申请调整配送日期
  • 暂停定期配送
  • 重要快递拜托家人或朋友代收

5. 安全收快递

不暴露独居

  • 姓名后加敬称或写得性别模糊
  • 快递员上门时表现出"家人会来收"的感觉
  • 避免夜间送货

非接触收件

  • 优先选择放门口（不直接见面）
  • 只通过对讲机沟通
  • 不马上开门，等快递员离开后再取

安全第一。尤其是晚上，一定要确认是不是真的快递员。

6. 快递丢失或损坏时

以下赔偿标准依据韩国公平交易委员会的快递标准条款，以及解释该条款的政府说明（易查生活法令信息）。实际赔偿会因快递公司条款和事故情况而不同。

情况标准需要知道的
运单上没有填写物品价值赔偿上限50万韩元贵重物品可以填写价值并支付加价费用
填写价值并支付加价费用按运送价值区间的最高价值赔偿2020年修订说明介绍为最高可增至300万韩元（区间金额表未核实）
运输中全部丢失退还运费＋按运单价值计算的损失快递公司或员工故意或重大过失时不受上限限制
部分丢失或损坏收件之日起14天内通知快递公司通知过晚责任可能消灭；收件满1年请求权消灭
赔付时间提交损失证明文件之日起30天内先行赔付用于防止快递公司、代理点、快递员互相推诿造成拖延

觉得丢了怎么办

  1. 把签收短信、照片和放置地点的备注截图保存
  2. 立即通知快递公司。通知过晚会难以查明原因和责任，可能被拒赔
  3. 不要只打电话，用短信、App或挂号信等方式留下受理编号和答复记录
  4. 快递公司承认丢失却不赔偿时，致电1372消费者咨询中心（无区号1372）
  5. 之后利用韩国消费者院的救济程序，仍未解决可考虑申请支付令（督促程序）

7. 冒充快递的诈骗短信与运单信息

冒充快递公司的短信诈骗

  • "地址不符无法配送，请修改地址"之类的短信，不要点其中的链接或电话，直接删除
  • 查快递请自己打开快递公司App或下单的商城
  • 不要通过短信链接输入身份认证、证件或金融信息
  • 如果已经点击或怀疑装了恶意App，请拨打韩国互联网振兴院（KISA）118（无区号，免费）咨询。黑客和病毒紧急咨询全年24小时，一般咨询为工作日09:00～18:00

清除运单上的个人信息

  • 贴纸式运单撕下后再丢弃
  • 不好撕的用油性笔等涂掉姓名、地址、电话
  • 条形码里也有信息，要一并清除
  • 放在门口太久的快递会增加信息暴露和被盗风险，建议使用安全的快递柜

8. 购物小技巧

网购

  • 包邮：不要为凑包邮金额买不需要的东西
  • 定期配送：单价因条件而异，自己比较一下
  • 查看评价：看真实购买评价

凌晨配送

  • 生鲜食品用凌晨配送很方便
  • 上班前在门口取件
  • 夏天注意冷冻食品（可能融化）

9. 检查清单

下单时

  • ☐ 认真填写配送备注
  • ☐ 设置不在家时的备选方案（保安室、快递柜、门口等）
  • ☐ 联系电话准确
  • ☐ 贵重物品确认运单是否填写价值

点外卖时

  • ☐ 比较多个App的价格（含配送费）
  • ☐ 确认优惠券/折扣条件
  • ☐ 查看评价

收到之后

  • ☐ 清除运单个人信息后再丢弃
  • ☐ 不点冒充快递的短信链接

总结

独居时快递和外卖是生活的重要部分。管好了很方便，不管理就会导致丢件和个人信息泄露。关键是配送备注，以及丢件时留下记录并尽快通知。

# 安全收快递和外卖检查清单

基准日：2026-09-29。以韩国规则为准，赔偿会因快递公司条款和事故情况而不同。

## 1. 选择不在家时的收件方式

| 情况 | 方式 | 备注 |
|---|---|---|
| 有保安室 | 保安室代收 | 各楼是否代收不同 |
| 有快递柜 | 快递柜 | 位置和密码通过短信或App发送 |
| 都没有 | 放门口＋送达照片 | 贵重物品避免。放在约定地点即视为交付 |
| 长期不在家 | 调整配送日期、暂停定期配送、请家人朋友代收 | |

## 2. 下单时
- [ ] 配送备注写明了具体收件位置
- [ ] 地址没写"独居"，姓名用姓氏+OO
- [ ] 贵重物品确认了运单是否填写价值（未填上限50万韩元）
- [ ] 避开了夜间送货

## 3. 丢失或损坏时的步骤
1. 把签收短信、照片和放置地点备注截图
2. 立即通知快递公司（部分丢失或损坏须在收件之日起14天内通知）
3. 用短信、App或挂号信留下受理编号和答复
4. 快递公司承认却不赔偿时，致电1372消费者咨询中心
5. 利用韩国消费者院的救济程序，仍未解决可考虑申请支付令

标准：提交损失证明文件之日起30天内先行赔付，请求权在收件满1年后消灭。

## 4. 收到之后
- [ ] 撕下或涂掉运单（姓名、地址、电话、条形码）后再丢弃
- [ ] 没有点击"地址不符"之类短信的链接
- [ ] 已点击或怀疑装了App时，拨打118（韩国互联网振兴院）咨询

下次更新条件：标准条款修订、1372或纠纷解决标准变更、118运营时间变更。2020年修订后是否再有修订及加价区间表未能确认。
