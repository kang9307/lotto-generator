理解双相情感障碍与治疗路径 - 当情绪变化成为疾病

这不是可以自行判断的疾病 - 观察、评估，以及通往就诊的路

2026-08-01 生活/健康

引言: 分不清是性格还是病

有些月份一切都顺。凌晨三点睡下，六点睁眼，却不觉得累，把拖了很久的计划一口气全都启动。可是几周之后，什么都做不了。连洗漱都沉重，连关系很好的人发来的消息也回不了。讲述这种经历的人，最后往往会补上同一句话：「我分不清这到底是我的性格，还是生病了。」

对这个问题，网络给出答案给得太轻易。到处都是「情绪起伏大就是躁郁症」这样的说明，让人数一数符合几条的表格也随处可见。这恰恰是本文不打算做的事。双相情感障碍不是靠表面起伏的幅度就能分辨的状态，外观相似的其他状态还有好几种，而最关键的是，本人最看不清自己状态的那段时期，正处在这一疾病的核心。

所以本文只有一个目的。不是让读者自己得出结论，而是缩短通往诊室的距离。值得观察什么、为什么身边人的记忆如此重要、就诊时带上什么能让对话往前推进，这些是本文整理的内容。判定不在这里发生。

本文的性质。本文属于以提供信息为目的的一般健康信息，不能替代医学诊断或治疗。对个人状况的判断与治疗方案，必须通过医疗专业人员的诊疗来决定。本文不涉及药物名称、剂量与服用方法，文中任何内容都不应被当作自我诊断的依据。

出处原则。以下内容只写在直接打开并确认过的范围之内，来源为世界卫生组织、美国国立精神卫生研究所、英国国民保健服务，以及韩国保健福祉部下属的咨询窗口。未能核实的数字和说法一律没有收入。

2. 情绪变化与疾病的界线在哪里

先要理清一件事。情绪时高时低本身并不是病。有好事就高兴、有坏事就低落，是人的基本运作。因为考试结果、分手、升职、搬家而波动几天，也是一样。

公共卫生机构作为疾病来处理的，是结构不同的状态。世界卫生组织把它描述为情绪与精力、活动、思维一同变动的状态。也就是说，变化的不只是情绪，而是存在一个人整体的运作方式作为一整块发生改变的时期。英国国民保健服务说明，这样的时期通常以数天到数周为单位持续，其间稳定的阶段可以持续数周、数月，长则数年。

在这里真正承重的有两条轴。

  • 持续时间。一天之内反复上下，和某种状态持续数天到数周，性质是不同的。世界卫生组织在说明抑郁一侧的发作时，讲的是几乎每天、至少持续两周以上的形态
  • 功能受损。关键在于那段时间里工作、学业、人际关系、金钱管理这些实际生活是否被扰动。心情很差但该做的都做了，和那段时间辞了职、关系断了，是完全不同的两种信息
  • 看的是幅度而不是方向。朝好的方向的变化同样是观察对象。「心情变好了所以没事」这个判断，在这一疾病上尤其容易落空
  • 本人与周围认知的落差。如果本人觉得状态好到顶点、周围却在担心，这种情形反复出现，那么这个落差本身就是值得记录的信息

请不要把这两条轴当成自我判定的工具。持续时间与功能受损是评估的材料，而不是评估本身。同样的时长、同样程度的困难，可能来自完全不同的原因，而把它们分辨开来正是诊疗的内容。上面写下的两条轴，只应被当作提示在诊室里该讲些什么的指引来使用。

3. 躁狂、轻躁狂与抑郁发作中可以观察到什么

这一节刻意写成叙述而不是清单，因为在这个主题上，引导人去数条目的形式是有害的。

3.1 高涨的时期 - 被描述为躁狂的状态

综合世界卫生组织与英国国民保健服务的说明，这段时期被描述为情绪明显高涨、或者相反地容易烦躁，并且精力明显增加。睡得少却不觉得疲惫的状态一并被报告，说话变快、想法一个接一个以致难以停留在一件事上的样子被记述为可观察到的表现。对自己的评价被描述为膨胀到远超平时，而没有充分权衡后果的决定 — 例如无力承担的支出、突然改变的计划 — 被报告为增多。状态较重时，也有与现实不符的确信，或他人并不共享的知觉体验相伴出现的情况。

本文想强调的不是症状清单，而是这段时期的主观体验。它往往不会被本人记成痛苦的时期。相反，它更多被留存为事情顺利、脑子转得快的一段日子。所以当日后在诊室被问到「那时候怎么样」，本人手里并没有可以作为问题上报的材料。这一结构，正是下一节要讲的诊断延迟的根源。

3.2 被描述为轻躁狂的状态

英国国民保健服务按程度区分高涨状态，把相对较轻的一侧以轻躁狂之名加以说明。表现的方向相似，但被记述为强度较弱、生活并未彻底崩塌的形态。问题恰恰在这里。因为生活没有崩塌，它不会被认作就医的理由，周围的人也容易以「最近状态看着不错」一句带过。把它理解为最容易被漏掉的时期更为实用。

3.3 低落的时期 - 被描述为抑郁发作的状态

低落的一侧相对更容易被察觉。世界卫生组织把这段时期说明为情绪低落并对以往感到愉快的事物失去兴趣，几乎每天、至少持续两周以上，同时伴有注意力难以集中、内疚感或无价值感增强、睡眠与食欲改变、精力下降。英国国民保健服务明确指出，这段时期可能出现自伤或自杀的念头。这句话正是本文第1节被放在前面的理由。

重要的是，这两个时期被说明为并非不同的人所患的两种病，而是同一个人的病程中可以交替出现的阶段。因此单看低落的时期，很难与其他状态区分。本文之所以与关于抑郁的文章分开存在，理由就在这里，这也是两篇文章的内容不应叠着读的原因。

4. 诊断为何被延后

这一疾病的诊断延后，不是因为个人的疏忽，而是出于结构性的原因。按顺序看是这样的。

  • 促使人去医院的是低落的时期。因为难受才求助。所以首诊的话题容易只被抑郁一侧填满
  • 高涨的时期不会作为问题被申报。如果它在本人记忆里是「过得不错的时候」，就没有理由在诊室里被提起。医生看不到从未被提及的东西
  • 外观重叠的状态有好几种。英国国民保健服务明确说明，这一疾病在不同人身上表现不同，且症状与其他心理健康状况相似，因此不易辨别
  • 不是一次问诊就能结束的。同一份指引说明，专科医生会经过对情绪、行为、健康状况与家族史的详细确认过程。需要时间不是因为敷衍，而是因为必要

关于确诊需要数年的报告，在多项研究与专业团体的资料中都有提及。不过本文不引用具体的平均年数。因为承载这些数字的一手资料正文未能直接确认，而照抄未经核实的数字有违本文自设的原则。这里需要的结论不是数字，而是方向。如果延后很常见，而其原因在于「高涨的时期不被报告」这一结构，那么打破这一结构的方法也就确定了。把关于高涨时期的信息送进诊室。这个方法就是第9节。

世界卫生组织指出，针对这一疾病的污名与歧视在社区和医疗服务两方面都广泛存在。并且记述全球范围内接受治疗的比例本身偏低。这正是不能把诊断延后只看作个人问题的理由。

5. 治疗路径 - 不是一种，而是组合

公开资料的说明是一致的。不是一种方法，而是多个要素并用的形式。世界卫生组织把有效的管理概括为药物与心理社会干预的组合，并同时提到心理教育、认知行为取向的方法、生活方式调整与同伴支持。英国国民保健服务同样把稳定情绪的药物治疗与谈话治疗并列介绍。美国国立精神卫生研究所记述有效的治疗方案有助于管理症状并改善生活质量。

构成要素公开资料说明的作用常见误解
药物治疗被说明为存在朝向稳定情绪波动方向的治疗。持续使用与按需使用都有被提及「吃药会让情绪消失」 — 被说明的目标不是消除情绪，而是处理波幅
心理社会干预谈话治疗、心理教育、认知行为取向的方法等被说明为并用「咨询是用不了药时才做的」 — 资料把它们并列，而不是当作替代品
生活节律调整规律的睡眠与活动、压力管理等被列为管理的一部分「把生活理顺就行了」 — 资料把它放在辅助的位置
周围的支持同伴支持与家属参与被列为管理的组成部分「家人做得好就能好」 — 支持是帮助治疗，而不是取代治疗

这里必须点明一件事。本文不会说哪一种方法更好。没有这样说的依据，而且一旦这样说，本文就变成了在模仿诊疗。组合的构成与比重因人而异，调整它本身就是治疗的内容。

还有一点。本文不涉及药物的名称、剂量与服用方法。那是把个人状况、其他健康条件与同时使用的药物全部摊开后才能决定的领域，是无法搬进文章里的信息。在网上找某种药的使用体验再往自己身上套，出于同样的理由也是危险的。

5.1 为什么持续很重要

这一疾病被说明为反复好转与恶化的病程。也就是说，此刻状态不错并不意味着治疗结束。美国国立精神卫生研究所记述，这一状况在多数情况下需要长期治疗。把稳定期较长解读为管理正在起作用的信号，更接近事实。

6. 复发与维持治疗 - 好转的时候才是关口

实务上最常发生的是这一幕。状态一稳定，就感觉不到继续治疗的理由。这是可以理解的走向。副作用不舒服，要花钱，跑医院这件事本身也成了不断提醒自己状况的负担。

英国国民保健服务的指引在这一点上很明确。即使感觉好转，在医生告知之前也不要自行停药这句话原样写在那里。

这句话不会被用来吓唬谁。需要的不是恐惧，而是下一步行动。

  • 如果冒出想停下来的念头，就把这个念头在诊室里说出口。这一节的全部就是这句话。要避免的只有把念头藏起来、自己悄悄调整
  • 副作用是拿来报告的，不是拿来忍的。什么、从什么时候起、以什么方式不舒服，这些会成为调整的材料
  • 费用或时间上的负担同样可以成为诊疗的话题。不说出现实的限制，就难以得到贴合现实的方案
  • 如果曾自行减量或漏服，也照实说出来更好。被隐去的信息会让下一次判断出错

复发不是失败。在病程较长的状况里，再次变差是管理过程中会包含的事件。比起是否复发这个事实，多快察觉到复发、多快重新接入治疗才是真正改变结果的部分。帮助这种察觉的，是下一节的记录，以及第8节里周围人的观察。

7. 日常管理 - 是辅助，不是治疗的替代

先把话说死。以下内容不能替代治疗。公共卫生机构提到生活管理的方式，不是把它当作治疗的替代方案，而是当作与治疗并行的要素。把这个顺序颠倒过来是危险的。

英国国民保健服务把保持规律作息、获得充足睡眠、均衡饮食、运动、压力管理列为个人可以做的事，同时也提到避开可能影响情绪的因素。世界卫生组织同样把规律睡眠与身体活动、饮食、减压、情绪监测记述为自我照护的项目。

  • 把睡眠当作固定变量来处理。入睡与起床时间开始摇摆，被报告为状态变化的前兆。如果睡眠本身就是难题，那也是诊疗中要处理的主题(另有关于睡眠问题的文章)
  • 记录越简单，越能长久。一天一行就够：当天的情绪用0到10的数字，加上入睡时间和醒来时间。累积几个月，就是非常有用的材料
  • 记录的目的不是自我判定。它不是让你因为数字连着几天偏高就自行下结论，而是为了在诊室里不必依赖记忆的材料
  • 变化越大的时期，越值得推迟重大决定。换工作、搬家、大额支出、了断关系这类难以回头的决定，放到状态稳定之后更安全
  • 酒精与刺激性物质会让判断变钝。这是公开资料共同建议节制的项目

8. 家人与身边的人能做什么、不该做什么

这一节也许是本文最实用的部分。因为高涨时期本人难以把自己的状态认作问题这一结构，使得身边人的观察成为无可替代的信息。

情况有帮助的回应有害的回应
出现与平时不同的高涨时把观察到的事实连同日期记下来：睡眠、说话速度、支出、计划的变化当场断定「你现在不正常」并挑起争论
低落到什么都做不了时提出具体而小的帮助：一起把就诊预约挂上，或者张罗一顿饭「你要振作」「这是意志问题」 — 把健康状况变成性格缺陷
说想停止治疗时听清理由，并帮他把这个理由在诊室里说出来替他做决定，或者偷偷查证再追问
出现危险信号时不要独自扛，接入第1节的窗口。陪着一起打电话被要求保密就照办。安全在前
照护者自己疲惫不堪时承认消耗并寻找支援。照护不是一个人扛的事一直忍到关系本身断掉

「靠意志挺过去」这句话为何格外有害，值得单独写下来。

  • 它把健康状况重新定义为努力不足。于是求助会让人觉得像在承认失败
  • 它在本已艰难的时期又叠上一层内疚。低落时期内疚感增强，是各份资料共同记述的特征
  • 它是世界卫生组织所指出的污名，在最亲近的关系中被再生产出来的形态
  • 它把制造真正有用信息 — 观察与记录 — 的机会，消耗在争吵上。
  • 在高涨的时期反效果尤其大。说服不是目标，接入治疗才是目标。

补充一点，身边人自身的状态同样是需要管理的对象。长期持续的照护，与关于消耗的文章所处理的问题相重叠。

9. 就诊时要准备的东西

从这里开始可以写成清单，因为这是要带去的材料清单，而不是要数的症状清单。这份准备，正是实际打破前文所说「诊断延后结构」的方法。

  • 情绪记录。一天一行就够。日期、当天情绪的数字，如果有不寻常的事就写一句话
  • 睡眠记录。入睡时间、醒来时间，以及是否有过睡得少却并不疲惫的日子
  • 从什么时候开始。不需要精确日期。「大概从去年秋天起」这样的程度在诊疗中就已经有用
  • 关于高涨时期的备注。这一条最重要。睡眠变短的时期、支出与平时不同的时期、突然把计划铺得很大的时期
  • 身边人的观察。把家人或亲近的人写下的内容一并带去。即使与本人的记忆不符，也照原样带去更好
  • 目前在服用的所有药物。包括与精神健康无关的药。保健食品与中药也写上
  • 其他健康问题。已确诊的疾病，如果有近期检查结果就一并带上
  • 家族史。家人中是否有人因情绪方面的困难接受过治疗。英国国民保健服务说明，专科医生会确认家族史
  • 酒精与咖啡因的摄入情况。它们会影响判断与睡眠，所以照实写下
  • 最担心的那一件事。诊疗时间很短。把最想问的事先写成一行，就能从那里开始谈

就诊之后也有一件要做的事。当天简短记下自己听到了什么。下一次诊疗如果能以「上次说好这样做，结果是这样」开头，对话的密度会完全不同。

10. 结语: 本文的目的不是判别，而是就诊

回到最初的问题：「这到底是性格，还是病。」

本文能给的不是这个问题的答案，而是把这个问题带去的地方。理由前面已经讲完了。这一状况的核心，是本人最看不清自己状态的那段时期，而那段时期恰恰装着评估所需要的信息。也就是说，这是一个仅靠自我观察无法闭合的结构。

于是留下的结论是三句话。

  • 不要凭起伏的幅度自己下结论。那个判断出自诊室，而不是出自本文
  • 把高涨时期的记录留下来。那是打破诊断延后结构唯一确实的方法
  • 如果现在有危险，请停止阅读并联系第1节的窗口。不独自判断是第一原则

再次明确。本文属于以提供信息为目的的一般健康信息，不能替代医学诊断或治疗。文中任何内容都不应被当作自我诊断或治疗决定的依据。对个人状况的判断，以及治疗的开始、变更与停止，都必须通过医疗专业人员的诊疗来进行。相关主题另有关于抑郁、焦虑、成人注意力问题的文章。

## 3. 情绪与睡眠记录格式(一行式)

日期 / 情绪(0~10) / 入睡时间 / 醒来时间 / 备注

格式示例:

**记录的目的不是自我判定。**它不是让你因为数字连着几天偏高就自行下结论，而是为了在诊室里不必依赖记忆。

## 4. 家人与身边的人如何应对

| 情况 | 有帮助的 | 有害的 |
| --- | --- | --- |
| 与平时不同的高涨 | 把事实连同日期记下(睡眠·说话速度·支出·计划) | 当场断定并挑起争论 |
| 低落到什么都做不了 | 具体而小的帮助(一起挂号，张罗一顿饭) | 「你要振作」「这是意志问题」 |
| 说想停止治疗 | 听清理由，帮他**在诊室里说出来** | 替他做决定，或偷偷查证再追问 |
| 出现危险信号 | 接入第1节的窗口，陪着一起打电话 | 被要求保密就照办 |
| 照护者自己疲惫不堪 | 承认消耗并寻找支援 | 一直忍到关系断掉 |

**「靠意志挺过去」为何有害**

- 它把健康状况重新定义为努力不足 → 求助会让人觉得像在承认失败
- 它在本已艰难的时期又叠上一层内疚
- 它让污名在最亲近的关系中被再生产
- 它把制造真正有用信息(观察与记录)的机会消耗在争吵上
- 在高涨的时期反效果尤其大。目标不是说服，而是**接入治疗**

## 5. 需要记住的

- 不要凭起伏的幅度自己下结论
- 高涨的时期本人往往不觉得是问题 → 需要身边人的观察与记录
- 治疗是组合而不是单一方法，公开资料并没有排出高下
- 即使感觉好转，也**不要在未与医生商量的情况下自行调整**
- 日常管理(睡眠·规律·记录)是**辅助**，不是治疗的替代
- 如果现在有危险，请停止阅读并联系第1节的窗口
