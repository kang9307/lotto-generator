智能家居·IoT设备安全完全指南 — 威胁·设置·管理

保护摄像头、门锁、智能音箱的2026年实用安全指南

2026-06-29 IT/技术

前言：家庭网络已成为攻击目标

智能电视、IP摄像头、门锁、智能音箱、扫地机器人、智能插座——2026年，普通家庭的联网设备数量已超过15台。便利性毋庸置疑，但这些设备同时也是攻击者24小时敞开的潜在入口。

2016年，Mirai僵尸网络仅利用出厂默认密码感染了数十万台IoT设备，发动了当时规模最大的DDoS攻击（超过620Gbps）。时隔十年，2026年的调查显示，约20%的IoT设备仍在使用未更改的默认凭据。Mirai的后继者（TurboMirai、Aisuru等）如今已能发动超过20Tbps的攻击。

本指南面向普通用户，无需专业技术知识即可实施。所有内容以2026年6月为基准。

1. 主要IoT安全威胁

1.1 默认凭据被利用

大多数IoT设备出厂时预设了默认管理员凭据，如admin/admin、admin/password或root/1234。各厂商的默认密码列表在互联网上公开可查。Mirai僵尸网络仅凭62种组合就控制了大量IP摄像头和DVR。首次连接设备时是最脆弱的时刻。

1.2 未修补的固件漏洞

IoT固件与普通软件一样会持续发现安全漏洞。一旦漏洞获得CVE编号并公开，运行该固件版本的所有设备都成为已知攻击目标。不更新固件意味着持续暴露于已公开的攻击手段中。停止更新支持（EoL）的设备将永久处于漏洞状态。

1.3 僵尸网络招募

被攻陷的IoT设备往往不是直接被窃取数据，而是被纳入僵尸网络。设备继续正常运行，用户可能数月都不知道设备已被感染。在此期间，设备被攻击者操控，参与DDoS攻击或凭据填充攻击。

1.4 窃听与视频泄露

智能音箱始终保持麦克风激活状态以等待唤醒词。IP摄像头24小时拍摄家庭内部。安全薄弱的设备可能导致私人音频或视频遭到未授权访问。安全性差的IP摄像头画面出现在公共网站的案例每年都有报告。

1.5 横向移动

攻击者常以安全薄弱的IoT设备为跳板，进而入侵同一网络上的电脑、手机或NAS设备。一个被攻陷的智能灯泡看似无害，但它可能成为攻击者进入整个家庭网络的第一个据点。

2. 五项必须安全设置

2.1 为每台设备设置独立强密码

实践方法： 连接新IoT设备时，第一步应立即更改管理员密码。使用大小写字母、数字和符号组合的12位以上密码，且每台设备使用不同密码。可借助密码管理器（1Password、Bitwarden等）轻松管理。

所有设备使用相同密码意味着一旦其中一个泄露，全部设备都面临风险。为每台设备设置独立密码是最基本的IoT安全措施。

2.2 启用双重验证（2FA）

在所有智能家居平台账户（Google Home、Apple Home、Amazon Alexa、Samsung SmartThings等）上启用双重验证。即使密码泄露，双重验证也能阻止账户被盗。基于应用的认证器（Google Authenticator、Microsoft Authenticator等）比短信验证更安全。

2.3 将IoT设备隔离到独立网络

实践方法： 启用路由器的访客Wi-Fi功能，将IoT设备连接到该网络。只需要互联网访问的智能电视、IP摄像头、智能插座等使用访客网络即可。将电脑和手机保留在主网络上。

美国网络安全和基础设施安全局（CISA）官方建议将智能家居设备连接到访客Wi-Fi。网络隔离确保即使IoT设备被感染，也无法扩散到主要设备。高端路由器用户可通过配置VLAN实现更精细的控制。

2.4 定期检查并更新固件

支持自动更新的设备请开启该功能。不支持的设备每月手动检查厂商应用或官网的固件更新。订阅厂商的安全通知邮件可及时获取重要补丁信息。不要忘记更新路由器固件，这是家庭网络中最重要的更新之一。

2.5 禁用UPnP

注意： UPnP（通用即插即用）允许设备自动修改路由器设置。CISA警告，恶意软件可利用UPnP将网络端口暴露于互联网或向其他设备扩散。请在路由器管理界面中禁用UPnP。

部分游戏机或媒体设备可能需要UPnP进行初始设置。设置完成后关闭UPnP，如出现连接问题，只为该设备单独配置端口转发，比保持UPnP常开更安全。

3. 各类设备安全要点

3.1 IP摄像头·智能门铃

  • 立即更改默认密码，使用独立强密码。
  • 在关联应用账户上启用双重验证。
  • 确认存储视频的云服务是否加密。
  • 若无需从外部访问，请禁用远程访问功能。
  • 不使用时利用物理镜头遮盖。

3.2 智能门锁

  • 定期（每3至6个月）更换PIN码。
  • 不再需要的访客码请立即删除。
  • 基于蓝牙或Z-Wave的门锁比直接Wi-Fi连接产品的攻击面更小。
  • 定期查看开锁事件日志。
  • 门锁应用账户必须设置双重验证。

3.3 智能音箱·AI助手

  • 不使用时利用硬件静音按钮关闭麦克风。
  • 定期通过应用查看并删除语音历史记录。
  • 为购物和支付功能设置额外PIN码。
  • 检查语音识别设置，防止陌生声音执行命令。

3.4 智能插座·智能家电

  • 不使用的设备从网络中移除（减少攻击面）。
  • 购买前确认小众品牌低价产品是否提供安全更新支持。
  • 若无需从外部控制，请禁用远程访问功能。

4. 购买前安全检查清单

5. 被攻陷的迹象与应对方法

5.1 主要迹象

  • 异常网络流量： 路由器统计显示上传或下载量远超平时
  • 设备响应变慢： 设备无故变慢或频繁重启
  • 摄像头指示灯意外亮起： 未使用时摄像头LED灯点亮
  • 陌生访问记录： 应用日志显示来自陌生IP地址或位置的访问痕迹
  • 设置被更改： 未经操作的密码或设置发生变化
  • 陌生设备注册： 智能家居应用中出现不认识的设备

5.2 怀疑被攻陷时的立即处置

  1. 立即将可疑设备从网络断开（关闭电源或断开Wi-Fi）。
  2. 在路由器管理界面检查连接设备列表。
  3. 立即更改智能家居平台账户密码。
  4. 对设备进行恢复出厂设置，用新密码重新配置。
  5. 更改路由器管理员密码和Wi-Fi密码。
  6. 检查同一网络上的其他设备。

6. 隐私与云端数据管理

6.1 IoT设备收集的数据

智能音箱将语音命令传输到云端服务器处理。IP摄像头可能将视频存储在云端。智能电视收集收视习惯。扫地机器人可能创建家庭内部地图并上传到服务器。购买前请阅读隐私政策，并在应用设置中关闭不必要的数据共享选项。

6.2 云端安全考量

大多数IoT设备依赖厂商云服务。提供商服务器一旦遭到攻击，所有关联设备和数据都可能受到威胁。可能的情况下，考虑使用Home Assistant等本地处理替代方案。也要考虑产品对云连接的依赖程度——若厂商关闭服务器，纯云依赖设备可能完全无法使用。

6.3 数据最小化原则

在应用设置中关闭功能上非必要的数据共享。定期删除智能音箱的语音历史记录。如果扫地机器人提供仅本地保存地图的选项，请使用该选项而非上传到云端。

7. 安全维护例程

频率检查项目
每月检查路由器和IoT设备固件更新；查看已连接设备列表
每季度更换智能家居平台密码；更换门锁PIN码；删除语音历史
每半年更换Wi-Fi密码；删除未使用设备和应用；确认双重验证状态
购买新设备时立即更改默认密码；安装最新固件；连接到IoT网络

总结：从今天开始的三步行动

IoT安全不是一次性配置就能完成的工作，需要持续的更新与检查。但不必因追求完美安全而放弃所有智能设备。只需做到以下三点，就能防御绝大多数常见攻击：更改默认密码、隔离网络、更新固件。

以2026年6月为基准，IoT安全领域的重要监管动向包括：美国CISA CPG 2.0（2025年12月发布）和英国PSTI法（禁止IoT设备使用通用默认密码）。立即行动：登录路由器管理界面更改默认密码，并将IoT设备迁移到访客Wi-Fi网络。
