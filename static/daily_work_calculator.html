자주 묻는 질문

공수란 무엇인가요? +
공수(工數)는 일용직 근로에서 하루 일한 양을 나타내는 단위입니다. 1공은 하루 풀타임 근무, 0.5공은 반나절 근무를 의미합니다.
데이터는 어디에 저장되나요? +
모든 데이터는 사용자의 브라우저(localStorage)에만 저장됩니다. 서버로 전송되지 않아 개인정보가 안전하게 보호됩니다. 단, 브라우저 데이터를 삭제하면 기록도 함께 삭제됩니다.
공휴일은 자동으로 표시되나요? +
네, 2025년부터 2028년까지의 대한민국 법정 공휴일과 대체공휴일이 달력에 자동으로 빨간색으로 표시됩니다.
여러 현장을 관리할 수 있나요? +
네, 여러 현장을 등록하고 각 현장별로 일당, 야근/철야 배율, 식대, 교통비를 다르게 설정할 수 있습니다. 달력에서 입력할 때 현재 선택된 현장 기준으로 계산됩니다.
