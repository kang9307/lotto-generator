1. Grok 4.7公開と主要ポジショニング

人工知能研究開発企業であるxAIは、2026年9月21日に公式発表を行い、最新の基盤言語モデルであるGrok 4.7を正式にリリースした。今回の公開は、開発者および企業ユーザー向けに複雑なプログラミング作業と高度な知識実務を自律的に遂行させることを主眼に設計されたモデルである。前世代の主力モデルであるGrok 4.6の系統を受け継ぎながら、長時間の多段階推論と自己検証メカニズムを一段と強化した構成となっている。

公式発表資料の中でxAIは、Grok 4.7を「コーディングと知識業務のための最も有能なモデル（most capable model for coding and knowledge work）」と定義した。単発的な対話応答や簡易な文章要約にとどまることなく、エンジニアが数時間にわたり取り組む複雑な障害解析、大規模リファクタリング、システム設計などの実務課題を自律的に完遂させることを目標に学習が行われたと述べている。

一般的に、大規模言語モデルの世代交代に伴う推論能力の向上は、計算リソースの拡大に起因してAPI利用料の引き上げを伴うことが多い。しかしxAIは、Grok 4.7の提供にあたり従来のGrok 4.6と完全に同等の基本価格体系および処理速度を維持することを明記した。商用システムを構築する開発者層に対し、コスト上昇の負担なく最新モデルへの移行を促す経済的配慮がうかがえる。

公式発表を通じて確認されたGrok 4.7の主なポジショニングは以下の通りである。

  • 正式発表日は2026年9月21日であり、高度なソフトウェア開発と知的専門実務を主要な対象領域に定めた。
  • 即時応答速度のみならず、数時間を要する難度の高い問題での自己検証と文脈維持の持続性を強調した。
  • 前世代モデルGrok 4.6と同一のトークン単価および基本推論速度を維持し、運用コストの安定性を確保した。

2. コーディング・ソフトウェア工学ベンチマーク数値

Grok 4.7が達成した性能向上は、xAIが公表したソフトウェア工学分野のベンチマーク数値によって定量的に示されている。中でも開発環境における長時間のコーディング作業を測定するCursorBench 4.0の評価結果が注目を集めている。このテストは、広範なコードベースにおける複数ファイルの整合的修正とテスト通過率を複合的に評価する指標である。

発表データによると、Grok 4.7（xHigh推論設定）はCursorBench 4.0において46.3%の解決率を記録した。これは同ベンチマークにおいて前世代のGrok 4.6（High設定）が記録した40.4%と比較して、5.9ポイントの上昇に相当する。xAIが公開したタスクあたりの平均コストと正解率の散布図では、Grok 4.7が1タスクあたり約6.01ドルの平均費用で46.3%を達成し、費用対効果のフロンティア上に位置することが示されている。

公開リポジトリの不具合修正能力を評価するDeepSWE v1.1においても進展が報告された。高負荷な思考努力を設定した条件（high effort）において、Grok 4.7は71.0%の解決率を記録した。Grok 4.6の65.2%と比較して5.8ポイントの改善である。さらに、コマンドライン端末での多段階実行手順を評価するTerminal-Bench 4.0においても、Grok 4.6の20.3%から38.0%へと大幅な上昇を示した。

ソフトウェア開発領域における主要な検証済み数値は以下の通り整理される。

  • CursorBench 4.0: Grok 4.7が46.3%を達成し、前世代Grok 4.6の40.4%から5.9ポイント上昇した。
  • DeepSWE v1.1: 高負荷推論設定（high effort）において71.0%を記録し、従来の65.2%を上回った。
  • Terminal-Bench 4.0: 端末環境での多段階作業評価において、従来の20.3%から38.0%へと改善した。

3. 専門知識および実務ベンチマーク結果

ソフトウェア開発分野に加え、Grok 4.7のベンチマーク評価にはハードウェア工学、法律実務、臨床医療判断、長時間事務作業など、多岐にわたる専門職領域の実務指標が含まれている。一般的な事実知識の暗記度合いを測るテストを超えて、実社会の専門家が扱う複雑な規約や設計図面に対する論理的推論精度を検証した内容となっている。

電気工学および電子回路設計を対象とするEEBenchにおいて、Grok 4.7は64.0%のスコアを達成した。これは前世代モデルGrok 4.6の53.0%から11.0ポイントの伸長であり、公式比較資料に掲載されたモデル群の中で上位の数値を記録した。電子回路解析や物理的設計制約に対するモデルの論理的正確性が向上していることを示唆している。

法律実務の契約分析や法的推論を評価するHarvey Legal Agent Benchmarkでは19.6%を記録し、Grok 4.6の15.8%を上回った。また、多段階のオフィス実務をシミュレートするAA Briefcase v1.1では1,657点を記録してGrok 4.6の1,546点を超え、専門知識業務を測るGDPval指標でも改善を示した。臨床医学的判断を検証するHealthBench Professionalでは56.7%に達し、従来の48.5%から上昇した。

専門実務領域に関して公式発表に記載された代表的な指標は以下の通りである。

  • EEBench（電気工学）: Grok 4.7が64.0%を記録し、Grok 4.6の53.0%から11.0ポイント上昇した。
  • Harvey Legal Agent Benchmark: 法律実務評価において19.6%を達成し、前世代の15.8%を上回った。
  • 事務および臨床指標: AA Briefcase v1.1で1,657点、HealthBench Professionalで56.7%を記録した。

xAIが公表した主要な性能指標を体系的に比較するため、ソフトウェア開発および専門実務分野の公式数値を一覧表としてまとめる。これらのデータはすべてxAIの公式発表ページに開示された一次情報に基づくものである。

5. アーキテクチャ改善とGrok Botハーネス連携

性能向上をもたらした技術的背景について、原文では基本モデル（ベースモデル）の規模拡大と強化学習（Reinforcement Learning）パイプラインの改良が挙げられている。具体的なパラメータ総数は公表されていないものの、「Grok 4.6と比較してより大規模な新しいベースモデル（new, larger base model compared to Grok 4.6）」を採用したと記載されている。

基盤モデルの拡張に加え、事後学習工程における強化学習が強化された。xAIは、解決に数時間を要する高難度な課題を中心としたデータセットを用いて長期間の強化学習を実施したと説明する。これにより、モデルが作業プロセスの途中で自らの出力結果を自律的に検証する能力（verifying its own work）や、長大なトークン文脈を破綻なく保持する文脈管理能力（managing longer context）を高めたとしている。

さらにGrok 4.7は、xAIの対話型実行基盤であるGrok Botハーネス（Grok Bot harness）の仕様をネイティブに理解するよう事前学習されている。対話インターフェースを通じて複雑なタスクの委託を受けたり外部ツールを呼び出したりする際、ハーネスとの整合性を高めることでツールの誤呼び出しを低減し、一般知識業務における動作安定性を確保する狙いがある。

モデル構造と設計方針の主要な改善点は以下のように要約される。

  • ベースモデル拡張: Grok 4.6より大規模な基盤モデルを採用し、基礎的な表現力を向上させた。
  • 長期間強化学習: 解決に数時間を要する難題を重点的に学習させ、作業の自己検証能力を育成した。
  • ハーネス事前適合: Grok Botハーネスの仕様をネイティブに組み込み、ツール呼び出しの整合性を高めた。

6. 安全性スタックとサイバーセキュリティ自社評価

Grok 4.7の発表において重要な位置を占めているのが、安全性（Safety）とサイバーセキュリティ防護機構に関する記述である。高度な推論モデルが悪意ある攻撃者に悪用されるリスクを防ぎつつ、正規のセキュリティ検証や学術研究活動を不当に阻害しないよう設計された新しいセーフガードスタック（safeguard stack）を導入したと報告されている。

モデルの全体的な安全性についてxAIは、「拒否処理および脱獄耐性において、当社がこれまでにテストした中で最も強力なモデルである（strongest model we've tested on refusals and jailbreak resistance）」と評価している。この言及は独立した外部認証機関によるものではなく、xAI内部の自社測定結果である点に留意して解釈する必要がある。

軍民両用（Dual-use）リスクを伴うサイバーセキュリティ分野に関して、xAIは自社のセキュリティ評価指標であるHackerBench v0.3の結果を提示した。このテストにおいてGrok 4.7は、危険または悪意あるプロンプトのうちわずか3.3%のみを通過させ、高い遮断率を示したと発表した。一方で、合法的な脆弱性診断やセキュリティ調査に対しては過剰な誤遮断を最小限に抑えるよう調整されている。また、LatchBioのバイオ安全性テストで62.4%を記録したほか、防御研究を支援するため選定されたセキュリティパートナーにレッドチーム機能への招待制アクセスを開始したと付け加えている。

安全性およびサイバーセキュリティに関する確定事実は以下の通りである。

  • 自社安全評価: xAIは拒否精度および脱獄耐性の両面で自社テスト中最も堅牢なモデルであると位置づけた。
  • 危険入力の遮断: 自社ベンチマークHackerBench v0.3において、危険プロンプトの通過率を3.3%に抑制した。
  • 研究連携の開始: 防御的セキュリティ研究の推進を目的に、特定パートナーへのレッドチーム機能提供を開始した。

7. 価格体系、オプションおよびAPI提供環境

商用展開における実務的な利点として、xAIはGrok 4.7の基本利用料を前世代のGrok 4.6と完全に同額に据え置く決定を下した。大規模なモデル拡張と学習強化を実施しながらも、基本単価を維持することで開発環境における導入障壁を低減している。

公式発表された標準価格表によると、Grok 4.7のトークン単価は入力100万トークンあたり2ドル（$2 per million input tokens）、出力100万トークンあたり6ドル（$6 per million output tokens）である。さらに、応答速度を最優先するリアルタイムアプリケーション向けに、出力生成速度が2倍となる高速オプション（fast variant）も併せて提供される。この高速オプションは、2倍の処理速度を提供する代わりに単価も2倍（入力4ドル、出力12ドル）に設定されている。

区分 基本モデル（xHigh） 高速オプション（Fast Variant）
入力トークン単価（100万単位） $2.00 $4.00（2倍料金）
出力トークン単価（100万単位） $6.00 $12.00（2倍料金）
出力生成処理速度 Grok 4.6と同等基準 基本モデル比で2倍の出力速度
対応プラットフォーム Cursor, Grok Build, Grok API Cursor, Grok Build, Grok API

利用可能な開発基盤に関して、Grok 4.7は公開初日よりコードエディタのCursorおよびxAIの開発環境であるGrok Buildにおいて即時利用可能となった。また、公式Grok APIコンソールを介したキー発行のほか、外部開発ハーネス、モデルルーター、各社クラウド基盤を通じた順次配信が案内されている。ローカル端末でCLIツールを構成するための公式インストールスクリプトは以下の通り告知された。

curl -fsSL https://x.ai/cli/install.sh | bash

提供形態および経済的諸条件の確定事項は以下の通りまとめられる。

  • 基本価格設定: 入力100万トークンあたり2ドル、出力6ドルとし、前世代Grok 4.6と同一の基準を維持する。
  • 高速オプション: 2倍の応答速度を提供する高速モデルが、2倍の単価設定で選択肢として用意される。
  • 配信チャネル: Cursor、Grok Build、Grok APIコンソールおよび提携クラウド基盤を通じて提供される。

8. 確認できなかった事項

本技術記事では、xAIの公式リリース文章および一次情報に明記された確定的な事実のみを取り扱っている。推測による誤認を排除するため、公式発表において開示されなかった以下の項目については未確認事項として分類し、本節に記録する。

  • Grok 4.7の総パラメータ数および活性化パラメータ規模: 原文ではGrok 4.6より大規模なベースモデルである旨のみが言及されており、正確なパラメータ規模やレイヤー構成数値は公表されていない。
  • 強化学習に投じられた総計算量（FLOPs）およびクラスタ仕様: 使用されたGPU基盤の構成規模、総消費電力、実学習日数などのハードウェア関連数値は開示されていない。
  • 第三者独立監査機関による安全性およびベンチマークの検証報告書: 脱獄耐性やHackerBench v0.3の結果はxAI内部の自社測定に基づくものであり、外部監査機関による査読検証データは発表に含まれていない。
