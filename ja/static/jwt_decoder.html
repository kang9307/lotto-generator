JWTとは何ですか？どこで使われますか？

JWT (JSON Web Token) は二つのシステム間で情報を安全に伝送するためのコンパクトなトークン形式です。header.payload.signature の3部構成で、それぞれBase64URLでエンコードされます。OAuthアクセストークン、セッション代替、API認証、SSOなどで広く使用されます。

HS256とHS512の違いは？

どちらもHMACベースの対称鍵署名ですが、使用するハッシュ関数が異なります。HS256はSHA-256 (256ビット)、HS512はSHA-512 (512ビット) を使用します。HS512の方がより安全ですが、トークンが長く、わずかに遅くなります。秘密鍵はハッシュ出力長以上を推奨します。

「none」アルゴリズムはなぜ非推奨ですか？

alg: none は署名を検証しないオプションです。過去多くのJWTライブラリでこれを悪用したトークン偽造の脆弱性が発見されており、本番環境では必ず無効化すべきです。本ツールはテスト目的のみサポートしています。

トークンデータはサーバーに送信されますか？

いいえ。すべてのデコード・生成・検証はブラウザのWeb Crypto API (window.crypto.subtle) で実行されます。トークン、秘密鍵、ペイロードは外部サーバーへ送信されません。ネットワークタブで確認できます。

exp (有効期限) はどう表示されますか？

JWTの exp、iat、nbf クレームはUnix Epoch秒単位です。本ツールはこれをISO-8601 UTC日付と「2時間後」「3日前 (期限切れ)」のような相対表現に変換して表示します。

jwt.ioとの違いは？

jwt.ioと同じコア機能 (デコード・生成・検証) を提供しながら、4言語UI (日本語・韓国語・英語・中国語)、相対時間の有効期限表示、アプリ内5チャネル共有、モバイル最適化ダークテーマを追加しました。ライブラリ依存なくWeb Crypto APIのみを使用します。

RS256/ES256 (非対称) もサポートしますか？

現バージョンはHMAC系 (HS256/HS512) のみサポートしています。RS256/ES256など非対称アルゴリズムはデコードは可能ですが、署名生成・検証には公開鍵/秘密鍵ペアと専用UIが必要なため、将来のバージョンで追加予定です。
