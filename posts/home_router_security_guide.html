서론: 집 안 가장 취약한 기기, 공유기

가정의 모든 인터넷 트래픽은 공유기 한 대를 통과한다. PC, 스마트폰, TV, 냉장고, IP 카메라까지 — 공유기가 뚫리면 집 안 전체 기기가 위험에 놓인다. 그런데 대부분의 가정에서 공유기는 처음 설치한 이후 한 번도 설정을 손대지 않은 채 몇 년씩 방치된다. 기본 관리자 비밀번호, 오래된 펌웨어, 취약한 암호화 방식이 그대로 유지된다.

2026년 현재, 이 상황을 노리는 공격은 점점 자동화되고 있다. Mirai 봇넷의 변종들은 기본 비밀번호가 설정된 공유기를 인터넷 전체에서 초당 수백만 개씩 스캔하며, 감염된 기기를 DDoS 공격 도구로 전용한다. 2026년 4월에도 복수의 Mirai 변종이 오래된 취약점을 이용해 라우터와 DVR를 동시에 공략한다는 보고가 나왔다. ASUS는 CVSS 9.2점짜리 인증 우회 취약점(CVE-2025-59366)을 2025년 중 긴급 패치했고, TP-Link는 펌웨어 교체 없이 권한 없이 새 펌웨어를 업로드할 수 있는 결함(CVE-2025-15517, CVSS 8.6)을 수정했다. 공유기 보안은 더 이상 IT 전문가만의 영역이 아니다.

이 글은 미국 사이버 보안 기관 CISA의 가이드라인과 최신 보안 연구를 바탕으로, 일반 사용자가 직접 따라 할 수 있는 실용 체크리스트를 중심으로 구성했다. 2026년 6월 기준으로 작성됐으며, 특정 제조사 공격 도구나 타인 기기 침해 방법은 다루지 않는다. 자기 공유기를 스스로 안전하게 만드는 것이 목적이다.

1. 가정용 공유기가 직면한 주요 보안 위협

1.1 기본 비밀번호 — 가장 흔한 침입 경로

공유기 제조사가 출하 시 설정해 둔 기본 관리자 계정(예: admin / admin)은 인터넷에 공개돼 있다. Mirai 봇넷은 바로 이 점을 이용한다. 수십만 대 규모의 봇이 인터넷 전체 IP 대역을 자동으로 스캔해 기본 비밀번호로 로그인을 시도하며, 성공하면 즉시 악성코드를 심고 봇넷에 편입시킨다. 2025년에는 Juniper Networks의 Session Smart Router들도 기본 비밀번호 미변경으로 인해 Mirai에 감염돼 DDoS 공격에 악용됐다는 사례가 보고됐다.

기본 비밀번호만 바꿔도 이런 자동화 공격의 대부분을 차단할 수 있다. 이것이 가장 쉽고 효과적인 첫 번째 조치다.

1.2 펌웨어 취약점 — 꾸준히 발견되는 심각한 결함

공유기 소프트웨어(펌웨어)에는 매년 다수의 보안 취약점이 발견된다. 2025~2026년에만 ASUS, TP-Link, NETGEAR, D-Link 등 주요 제조사에서 인증 우회, 원격 코드 실행, 명령 주입 등 심각도 높은 취약점이 줄줄이 공개됐다. 문제는 많은 사용자가 펌웨어를 업데이트하지 않아 이미 알려진 취약점에 수년째 노출돼 있다는 점이다. 제조사가 지원을 종료한 단종 모델은 더 심각하다 — 취약점이 발견돼도 패치 자체가 나오지 않는다.

1.3 봇넷 감염 — 내 공유기가 DDoS 무기가 된다

공유기가 봇넷에 감염되면 사용자는 대부분 눈치채지 못한다. 인터넷이 다소 느려지는 정도가 전부일 수 있다. 그러나 내부적으로는 공유기가 다른 사이트나 서버를 향해 대규모 트래픽을 발사하는 공격 도구로 사용된다. 2016년 Mirai가 처음 등장했을 때는 기본 비밀번호 목록을 활용해 수십만 대 IoT 기기를 감염시키고 역대 최대 규모 DDoS 공격을 일으켰다. 그 이후로도 수많은 변종이 계속 등장하고 있다.

1.4 중간자 공격과 DNS 하이재킹

공유기의 DNS 설정이 변경되면 공격자는 사용자가 접속하려는 은행 사이트나 쇼핑몰을 가짜 사이트로 유도할 수 있다. WPA2 암호화의 KRACK 취약점처럼 와이파이 연결 자체를 가로채는 공격도 있다. 암호화 수준이 낮거나 원격 관리 기능이 켜져 있으면 공격자가 인터넷을 통해 공유기 설정을 직접 변조할 수 있다.

2. 지금 당장 바꿔야 할 필수 설정 7가지

2.1 관리자 계정 비밀번호 변경

공유기 관리 페이지(보통 192.168.0.1 또는 192.168.1.1)에 접속해 관리자 비밀번호를 즉시 바꿔라. 사용해야 할 비밀번호의 기준은 다음과 같다.

  • 최소 12자 이상, 영문 대소문자·숫자·특수문자 혼합
  • 다른 계정에 사용 중인 비밀번호 재사용 금지
  • 비밀번호 관리자(앱)에 저장해 관리
  • 가능하다면 기본 관리자 아이디(admin)도 변경
주의: 제조사 라벨이나 설명서에 적힌 기본 비밀번호는 절대 그대로 사용하지 말 것. 그 정보는 해커들도 알고 있다.

2.2 와이파이 암호화를 WPA3(또는 WPA2)로 설정

공유기 무선 설정에서 보안 프로토콜을 확인하라. WPA3 Personal이 현재 가장 안전한 옵션이다. WPA3는 SAE(Simultaneous Authentication of Equals) 방식으로 오프라인 비밀번호 크래킹을 구조적으로 차단하며, 각 세션에 독립된 암호화 키를 사용하는 순방향 비밀성(Forward Secrecy)도 제공한다.

구형 기기가 있어 WPA3 전용 모드를 쓰기 어렵다면 WPA3/WPA2 혼합 모드를 선택해도 된다. 절대 피해야 할 설정은 WEP와 WPA(TKIP)다 — 이미 암호가 깨진 것으로 간주해야 한다.

보안 프로토콜안전성권고
WPA3 Personal매우 높음최우선 권장
WPA3/WPA2 혼합높음구형 기기 병행 시 선택
WPA2 (AES/CCMP)보통강력한 비밀번호와 함께 사용
WPA (TKIP)낮음사용 금지
WEP매우 낮음즉시 변경 필요

2.3 SSID(와이파이 이름) 정보 노출 최소화

와이파이 이름(SSID)에 개인 정보나 공유기 모델명을 포함하지 마라. KimFamily_TP-Link_2025 같은 이름은 공격자에게 제조사와 취약점 정보를 그대로 알려준다. 개인 특정이 어려운 중립적인 이름을 사용하는 것이 좋다. SSID 숨기기(Hidden SSID)는 보안 효과가 미미하니 편의성을 위해 공개 설정을 유지해도 무방하다.

2.4 원격 관리(Remote Management) 비활성화

원격 관리 기능은 인터넷 어디서든 공유기 관리 페이지에 접근할 수 있게 해 준다. 편리하지만 동시에 공격자도 같은 경로로 접근할 수 있다. CISA는 이 기능을 비활성화하도록 명확히 권고한다. 꼭 필요한 경우라면 VPN을 통해 접근하는 방법을 대안으로 고려하라.

2.5 WPS 비활성화

WPS(Wi-Fi Protected Setup)는 버튼 한 번으로 기기를 쉽게 연결하는 기능이지만 알려진 보안 취약점이 있다. PIN 방식 WPS는 무차별 대입 공격에 취약하다. 보안을 위해 WPS는 비활성화하고, 와이파이 연결은 비밀번호를 직접 입력해 진행하는 것을 권장한다.

2.6 UPnP 비활성화

UPnP(Universal Plug and Play)는 기기가 공유기에 포트를 자동으로 열도록 요청하는 기능이다. 편리하지만 악성코드가 이 기능을 악용해 외부에서 접근할 포트를 몰래 열어 두는 경우가 있다. 가정용 환경에서 UPnP를 끄더라도 대부분의 서비스는 정상 작동하므로 비활성화를 권장한다.

2.7 펌웨어를 최신 버전으로 업데이트

공유기 관리 페이지의 '펌웨어 업데이트' 또는 '소프트웨어 업데이트' 메뉴에서 최신 버전을 확인하고 적용하라. 자동 업데이트 기능이 있다면 활성화해 두는 것이 좋다. 제조사 지원이 종료된 단종 모델은 보안 패치가 더 이상 제공되지 않으므로, 교체를 진지하게 검토해야 한다.

팁: 공유기 관리자 페이지 접속 주소는 보통 라우터 뒷면 스티커나 설명서에 적혀 있다. 모르면 PC 명령 프롬프트(Windows)나 터미널(Mac/Linux)에서 ipconfig (Windows) 또는 netstat -nr | grep default (Mac)로 기본 게이트웨이 주소를 확인하면 된다.

3. 게스트 네트워크와 IoT 기기 분리

3.1 게스트 네트워크를 반드시 사용해야 하는 이유

대부분의 현대 공유기는 게스트 와이파이 기능을 제공한다. 이를 적극적으로 활용해야 한다. 방문자에게 메인 네트워크 비밀번호를 알려주면 방문자 기기가 집 안 PC, NAS, 프린터 등 내부 기기에 접근할 수 있다. 게스트 네트워크는 인터넷만 제공하고 내부 네트워크 접근을 차단해 이 문제를 해결한다.

3.2 IoT 기기는 게스트 네트워크 또는 전용 SSID로 분리

스마트 TV, 스마트 스피커, IP 카메라, 스마트 가전 등 IoT 기기는 보안 업데이트가 불규칙하거나 제조사가 지원을 조기에 종료하는 경우가 많다. 이런 기기들을 메인 네트워크에 두면 한 기기가 침해됐을 때 PC, 스마트폰 등 중요 기기로 피해가 확산될 수 있다.

해결책은 간단하다. IoT 전용 게스트 네트워크를 만들어 모든 스마트 기기를 거기에 연결한다. 게스트 네트워크 설정에서 '기기 간 통신 차단' 또는 '클라이언트 격리(Client Isolation)' 옵션을 활성화하면 같은 네트워크에 연결된 IoT 기기끼리도 통신이 차단된다.

4. 침입 징후 점검 — 내 공유기가 해킹됐는지 확인하는 법

4.1 이런 징후가 보이면 의심하라

공유기 침해는 대부분 조용히 일어난다. 그러나 다음 징후들이 여러 개 동시에 나타난다면 확인이 필요하다.

  • 관리자 비밀번호가 갑자기 작동하지 않는다 — 공격자가 비밀번호를 바꿔 잠근 것일 수 있다
  • 인터넷 속도가 갑자기 현저히 느려진다 — 봇넷에 편입돼 대역폭이 소모될 때 나타난다
  • 연결된 기기 목록에 모르는 기기가 있다 — 공유기 관리 페이지에서 연결된 기기 목록을 확인해 낯선 MAC 주소나 기기명을 점검한다
  • 브라우저가 엉뚱한 사이트로 자동 이동한다 — DNS 하이재킹의 전형적인 증상이다
  • DNS 설정이 바뀌어 있다 — 관리 페이지에서 DNS 주소를 직접 확인한다
  • 방화벽이 꺼져 있거나 포트포워딩 규칙이 추가돼 있다 — 설정한 적 없는 포트포워딩이 있으면 이상 신호다

4.2 의심될 때 취해야 할 조치

  1. 공유기 관리 페이지에 접속해 연결 기기 목록과 DNS 설정을 확인한다
  2. 접속이 안 된다면 공유기를 공장 초기화(리셋 버튼 10초 이상 누름)한다
  3. 초기화 후 이 가이드의 보안 설정을 처음부터 다시 적용한다
  4. 제조사 공식 사이트에서 최신 펌웨어를 먼저 업데이트한다
  5. 연결했던 기기들의 와이파이 비밀번호도 갱신한다

4.3 정기 점검 습관 만들기

월 1회 정도 공유기 관리 페이지에 들어가 다음을 점검하는 습관을 들이는 것이 좋다. 연결된 기기 목록에 모르는 기기가 없는지, 펌웨어 업데이트가 있는지, 설정이 바뀐 곳은 없는지를 확인한다. 공유기 제조사가 보안 취약점 공지를 이메일로 발송하는 서비스를 제공하면 구독해 두는 것도 좋은 방법이다.

5. 실용 보안 체크리스트

아래 체크리스트를 출력하거나 메모해 두고 하나씩 실행해 보라. 모두 완료하는 데 30분이면 충분하다.

5.1 즉시 실행 체크리스트 (오늘 바로)

  • 공유기 관리 페이지에 접속해 관리자 비밀번호를 강력한 비밀번호로 변경
  • 와이파이 암호화 방식을 WPA3 또는 WPA2(AES)로 확인·변경
  • 와이파이 비밀번호를 12자 이상 강력한 것으로 교체
  • 원격 관리 기능 비활성화 확인
  • WPS 기능 비활성화
  • 최신 펌웨어 업데이트 확인 및 적용

5.2 네트워크 분리 체크리스트 (이번 주 안에)

  • 게스트 네트워크 생성 및 활성화
  • 스마트 TV, AI 스피커 등 IoT 기기를 게스트 네트워크로 이동
  • 게스트 네트워크에서 '클라이언트 격리' 또는 '내부 네트워크 접근 차단' 옵션 활성화
  • 방문자용 와이파이는 별도 게스트 SSID 사용

5.3 지속 관리 체크리스트 (월 1회)

  • 연결된 기기 목록 점검 — 모르는 기기 없는지 확인
  • 펌웨어 최신 버전 여부 확인
  • DNS 설정이 변경됐는지 확인
  • 포트포워딩 규칙 중 설정하지 않은 항목 있는지 확인
  • 제조사 보안 공지 확인

6. 자주 묻는 질문(FAQ)

Q. 공유기 비밀번호와 와이파이 비밀번호는 다른 건가요?

다르다. 공유기 관리자 비밀번호는 공유기 설정 페이지(192.168.x.x)에 로그인할 때 쓰는 것이고, 와이파이 비밀번호는 무선 네트워크에 연결할 때 기기에 입력하는 것이다. 둘 다 강력하게 설정해야 하며, 서로 다른 값을 써야 한다.

Q. 공유기를 바꿔야 할 시기는 언제인가요?

제조사가 펌웨어 보안 업데이트를 더 이상 제공하지 않는 단종 모델이라면 교체를 고려해야 한다. 일반적으로 5년 이상 사용한 공유기는 WPA3 미지원, 보안 패치 종료, 성능 저하 등의 이유로 교체 시점에 해당할 수 있다. 제조사 웹사이트에서 해당 모델의 지원 종료일을 확인해 보라.

Q. SSID를 숨기면(Hidden SSID) 더 안전한가요?

아니다. SSID를 숨기면 일반 목록에는 나타나지 않지만, 공격자는 간단한 도구로 숨겨진 SSID를 탐지할 수 있다. 오히려 숨긴 SSID에 연결하려는 기기들이 SSID를 능동적으로 브로드캐스트해 위치 추적 위험이 높아질 수 있다. 실질적인 보안 효과는 없으니 강력한 비밀번호와 WPA3 암호화에 집중하는 것이 낫다.

Q. 공유기 초기화 후 설정이 모두 사라지면 어떻게 되나요?

공장 초기화 후에는 제조사 기본 설정으로 돌아가므로, 이 가이드의 보안 설정을 처음부터 다시 적용해야 한다. 설정 내용을 미리 메모해 두면 재설정 시간을 줄일 수 있다. 많은 공유기는 설정을 파일로 내보내는 백업 기능도 지원한다.
