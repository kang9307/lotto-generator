狗狗训练基础 - 教什么，改什么

不是让狗听话，而是让狗在可预测的环境中安全生活

2026年8月1日 生活/实用

引言：训练不是「让狗听话」

关于养狗的咨询里出现最多的一句话是「我家狗不听我的」。可是把这句话拆开来看，实际发生的事情通常并不是这样。狗理解了指令却选择拒绝的情况比人们以为的要少，更多的是它从没在那个情境里学过这个信号，或者学过但在那个地点是第一次，或者身体不舒服，或者有一个大得多的需求占满了空间，让信号根本没有落脚的地方。

所以这篇文章不讲「怎么让狗听话」。它把训练的目的放在另一个位置：让狗在一个它能预测的环境里安全地生活，而信号只是服务于这个目的的工具。教「坐」不是为了确认服从，而是为了在大门打开的那一刻它不会冲出去。教「过来」不是为了拥有一只叫得回来的狗，而是为了在它叼起危险物品时能把局面拉回来。

这个视角会改变处理顺序。看到问题行为时，不是从训练开始，而是从分辨原因开始。多数问题行为不是因为训练不足，而是来自需求、健康与环境。给一只疼痛中的狗多教几个指令解决不了任何事，教一只整天无事发生的狗保持安静也一样。

如何阅读本文。这里写的是一般性原理和处理顺序。狗因品种、年龄、性格与既往经历而个体差异极大，同一种方法对某些狗合适，对另一些狗则不合适。此外，登记与安全管理方面的制度可能修订，因此本文的法定义务部分必须连同基准时点一起阅读，并核对最新条文。本文的法律相关表述以2026年8月1日为准，且只描述韩国的制度。身处韩国以外的读者，请把那一节当作「应当在本地查询哪类义务」的例子。

本文不做的事。不推荐任何特定的训练机构、训练师、用品或狗粮。同时攻击性与严重焦虑不在本文范围内。那不是训练议题而是诊疗议题，第1节会先处理这条边界。

1. 训练之前要确认的事 - 应先就诊的信号

首先要分辨的问题是：这个行为是因为没学过而出现的，还是身体或情绪状态制造出来的?把两者混在一起，再好的训练方法也不会有效果，更糟的是狗会带着不适度过这段时间。

实务中最可靠的线索是变化的速度。用几个月慢慢形成的习惯，和上周还好好的、今天忽然不一样的行为，性质完全不同。当「突然」与「以前一直没问题」同时成立时，身体或环境发生变化的可能性大于学习问题。

观察到的行为为何被误读为训练问题首先怀疑什么顺序
原本稳定的如厕忽然失败被读作「变得不听话了」泌尿系统问题、疼痛导致无法保持姿势、老化变化、环境变动先就诊

回避楼梯或沙发被读作「在闹脾气」关节与肌肉骨骼疼痛、视力下降先就诊

1.1 攻击性与严重焦虑不是训练议题

本文最想说清楚的就是这一句：咬人或咬其他动物的行为，以及严重到影响日常生活的焦虑，是需要通过诊疗而非训练来处理的问题。原因有三个。

  • 医学原因确实会藏在下面。疼痛、感觉功能下降、内分泌问题、老年期认知变化以行为形式先表现出来的情况并不少见。不排除这些原因就只处理行为，方向会偏
  • 错误的做法会让情况恶化。对咬的行为施加惩罚，往往先被抹掉的是警告信号。低吼是给人时间后退的信号，压制这个信号会造就不发警告就咬的狗。这是所有训练失败中最危险的一类
  • 事故的代价无法挽回。一旦有人受伤，连狗的去留都会成为问题。这不是可以靠试错学习的领域

因此出现这些信号时顺序很简单：第一，立刻改变环境，让那个情境无法重演。第二，去看主治兽医，确认或排除医学原因。第三，请求转介到能处理行为问题的医院或具备兽医行为学资质的专业人员。这不是靠网络视频或熟人建议自行处理的阶段。

2. 什么造就了学习 - 结果与时机

训练方法数不胜数，但底下的原理很简单：紧跟在行为之后出现的结果，会改变这个行为下一次出现的频率。好结果让它增加，没有结果让它消退，不愉快的结果把它压制下去。训练就是有意识地设计这层关系。

人们最常忽略的是时机。狗不会回溯推理，认为现在这件事和刚才那个动作有关。结果所连接的对象，是结果出现那一刻它正在做的事。几秒钟的差别就能把学习方向整个改变。

  • 如果在狗站起来之后而不是在它坐下的瞬间给零食，被强化的是站起来而不是坐下
  • 如果叫狗过来，然后抓住它做它讨厌的事，被强化的是「不响应召唤」
  • 如果事后发现失误再责骂，狗连接到的不是排泄，而是那一刻的情境，通常就是主人正在靠近
  • 如果在狗吠叫的过程中而不是停止之后开门，被强化的是吠叫

2.1 标记瞬间的装置

解决时机问题的实务办法是先把那个瞬间标记出来。选定一个短促而固定的声音，在想要的行为出现的那一刻发出。这样即使奖励稍晚一点到达，学习仍然固定在那一刻，因为声音已经替代了标记的作用。

  • 标记声必须短促而固定。拖长的夸奖会模糊时间点
  • 标记与奖励之间的间隔一开始控制在1秒以内，等标记稳固后再逐步拉长
  • 发出标记声之后必须有奖励跟上。只标记不兑现会让信号失去意义
  • 奖励是什么由狗决定。对很多狗来说，球、嗅闻的自由、被允许继续往前走，都比食物更有力

2.2 惩罚为何是难用的工具

结果并不只有愉快的一种。但把不愉快的结果当作工具使用，在技术上困难得多，风险也大得多。时机在结构上难以对准，强度难以拿捏，而且无法控制狗把它和什么联系起来。责骂刚靠近的狗，靠近就会减少；在陌生人面前被骂，陌生人就变成了坏信号。

专业学会的公开指南在方向上是明确的。美国兽医行为学会(AVSAB)在其公开立场声明中表示所有的狗只训练都应只使用奖励式方法，并明确反对包括电击项圈、尖刺项圈与窒息链在内的厌恶性手段(2026-08-01核实)。

本文不介绍这类工具的使用方法。上述表述只是转述学会立场这一事实，本文中没有任何涉及体罚或厌恶性刺激的操作步骤。如果你已经尝试过这类方法而情况变得更糟，这本身就是需要寻求专业咨询的状况。

3. 四个基本信号 - 为了安全而非控制

教基本信号的目的不是随意支配狗，而是预先建立一条能在危险时刻介入的通道。所以比起决定教什么，先决定每个信号是为哪种情境准备的更有帮助。

信号实际使用的场合核心原则常见失误
对名字的反应察觉危险时把注意力拉回来的第一步名字之后永远只有好事责骂时也叫名字，信号被污染
坐在门口、电梯、路口制造静止状态先定手势，词语之后再叠加在坐下之前反复说词，信号变模糊
等门打开时、下车时、食物面前时间、距离、干扰分别延长三者同时提高，失败反复出现
过来叼起危险物品时、牵引绳脱开时这个信号之后绝不接不愉快的事叫回后洗澡或结束散步，响应率下降

3.1 一次只提高一个难度维度

练习一直顺利却忽然崩掉，多数原因是同时提高了好几个维度。对狗来说，地点是信号的一部分。在客厅完美的「坐」在散步道上做不到，不是忘了，而是它从没在那个地点学过。

  • 换地点就当作从头开始。不过从第二个地点起会回升得快得多
  • 每次要短。1到3分钟就够，一天分成几次好过一次30分钟
  • 成功率是标准。十次中八次以上就往上一级，五次以下就退一级
  • 以成功收尾。在失败状态结束会拉低下一次的起点
  • 训练零食要从每日喂食量里扣掉。不管理总量，体重问题就会跟上来

4. 如厕训练 - 失败多半是间隔、地点与清洁的问题

如厕训练是新手主人最先碰上、也最常处理错的领域。核心是这一点：多数如厕失败不是狗违反了规则，而是成功的机会不够，或者关于「哪里才是正确位置」的信号本身就模糊。

失败类型实际原因处理方式
一天多次，到处都有间隔 - 机会比膀胱容量所允许的更少先增加机会次数。睡醒后、进食后、玩耍后概率最高
只在指定位置附近失误地点 - 正确区域的边界不清楚把正确区域一开始设得宽一些，提高成功率后再逐步收窄
反复在同一处清洁 - 残留气味把它引回来使用能分解气味成分的清洁方式。普通清洁剂只对人的鼻子有效
只在没人时失误被责骂的经历造成回避人的在场完全停止惩罚，只对成功作出反应
散步时憋着，只在家里排外面还不是让它放松的地方降低社会化负荷。参见第5节

4.1 责骂为什么会适得其反

这部分最好当作机制来理解。把责骂如厕失误时实际发生的事分成两层来看。

  • 时机几乎总是迟的。人发现失误的时点是排泄已经结束之后。如第2节所示，结果附着的是当下的行为，所以狗连接到的不是排泄，而是主人正在靠近
  • 学到的内容是偏的。狗学到的不是「不能在这里排」，而是「不能在人看得见的地方排」。结果就是躲起来排泄，或者在有主人陪同的散步中憋着
  • 最重要的信息消失了。一旦开始躲起来，主人就无法知道失误何时何地发生。记录一断，缩小原因范围的手段也一起消失
  • 回避会蔓延到其他领域。学会回避靠近的人并不会只停留在如厕上，「过来」的可靠性和整体的操作信任度会一起下降

该做的事很简单：在成功概率高的时点创造机会，在成功发生的那个位置立刻作出反应，失败则安静地清理掉。当失败没有反应而成功有反应时，方向会自己确定下来。

5. 社会化 - 不是更多，而是「还好」

当社会化被翻译成「尽量多接触」的那一刻，问题就开始了。社会化的目标不是接触次数，而是「还好」这种经验的累积。这个区别会让结果完全相反。

当狗在无法离开的状态下反复接触它承受不了的刺激时，方向可能是变得更敏感而不是变得迟钝。把幼犬带到人多的地方，让好几个人轮流抱着摸着，常被说成「社会化做得好」，但从狗的角度看，那可能是没有退路的强烈刺激。

5.1 分别调整三个维度

  • 距离。离目标多远。这是最容易控制的维度，也是应当最先调整的
  • 强度。声音看音量，人看动作的突兀程度，其他狗看兴奋度
  • 时间。在那个情境中停留多久。短一些并且好好收尾更好
  • 一次只让一项变难，其余保持容易。三项同时提高，连哪个维度出了问题都无从判断

5.2 负荷过大的信号

狗表达「我不好」的方式通常很安静。看到下面这些信号时，拉开距离或者离开现场才是正确答案，强行让它留下并不是社会化。

  • 压低身体或把尾巴收进去
  • 移开视线并把头保持转向另一边
  • 没有由来地打哈欠或舔嘴唇
  • 身上并没有湿却抖动身体
  • 忽然执着地嗅闻地面
  • 躲到主人身后或转向出口方向
  • 无法像平时那样接过零食

5.3 常常站不住脚的前提

  • 不是每只狗都必须喜欢别的狗。能够不理会擦身而过的狗继续走，就已经是成功
  • 打招呼是选项，不是目标。牵引绳绷紧状态下的正面招呼，在结构上剥夺了狗的回避选项
  • 对很多狗来说，陌生人不加互动地走过去，比伸手抚摸更有用。请访客忽略狗，同样是正当的社会化
  • 声音从低强度开始。如果生活噪音是问题的一部分，实际测一下环境的音量也会有帮助
  • 成犬也不算晚。只是节奏不同，而且过程中包含解开既有经验的部分，所以会慢一些

关于时期。幼犬期存在一个特别重要的社会化窗口，这一点被广泛讨论，但具体的周龄范围以及如何与疫苗接种日程配合，会因个体与当地情况而不同，应与主治兽医商量后决定。美国兽医行为学会就这一主题另设有公开立场声明(Puppy Socialization Position Statement)，其目录可从本文末尾的参考资料进入。本文未能直接打开并核实该文件的正文，因此不写出具体的周龄数字。

6. 散步 - 拉扯不是坏习惯

对于拉扯牵引绳的狗，人们常说「没教好」，但从结构上看，拉扯更接近速度与目的的不匹配，而不是习惯。狗的行走速度比人快，而狗在散步中想要的通常不是移动，而是气味与信息的采集。

  • 存在一个强化拉扯的结构。「一拉就能往前走」的经验反复出现后，拉扯就被学成了有效行为
  • 所以改变结果才是处理的核心。当「绳松就前进、绳紧就停下」的规则保持一致时，方向就会转变
  • 重新定义散步的目的效果也很大。把它看作探索时间而不是要走完的距离，自然就会给出足够的嗅闻时间，而这本身对狗就是很大的奖励
  • 起点最难。刚出家门时兴奋度最高，所以只对这一段降低目标是现实的做法
  • 兴奋度已经上去之后，信号是进不去的。先拉开距离把兴奋度降下来，然后再使用信号

关于器具。本文不推荐任何特定的牵引绳、胸背带或产品。适用性会因狗的体型、颈部与气管状况、年龄以及拉扯强度而有很大差别，某些器具对特定个体可能造成身体负担。器具选择应与亲自看过这只狗的兽医或专业人员商量后决定。另需注意，外出时佩戴牵引绳等安全措施在韩国同时是法定义务(参见第10节)。

7. 分离焦虑 - 是状态，不是习惯

关于独处时吠叫、破坏物品或排泄的问题，最常听到的一句话是「把习惯纠正过来就行了」。有必要说清楚这句话为什么危险。

  • 吠叫、破坏与排泄是结果而不是原因。只压制结果，狗所处的状态原封不动，减少的只是表现
  • 「多放一阵子就习惯了」这种做法可能走向反面。持续暴露在无法承受的强度下，和第5节说的过度暴露是同一种结构
  • 惩罚在这里尤其不合适。给焦虑状态再加上不愉快的结果，会让「被独自留下」这件事变成更坏的信号
  • 长时间强制隔离也不是解法。缩小空间对某些狗有安定作用，另一些狗却会在试图逃出时受伤。个体差异很大，不是可以随意决定的事

7.1 有助于区分的观察

独处时出现的问题并不都是分离相关焦虑，也可能是无聊、未学习，或对外部刺激的反应。下面这些观察有助于区分。

  • 是否只在主人不在时发生，还是有人在家时也有类似行为
  • 是否在出门准备阶段就已经开始。钥匙声或穿鞋的动作是否引发反应
  • 独处期间的哪个时间点会加重。是刚出门后，还是几小时之后
  • 是否与外部刺激联动。是否随着走廊声响或门铃而开始
  • 影像记录是决定性的。没有记录就无法知道无人时的行为，而这份记录在专业咨询中是最重要的材料

这个领域为什么属于专业人员也同样清楚：暴露强度必须按个体精确调整，强度不当的暴露会让状态恶化，而判断是否存在医学并发问题、是否需要配合用药，属于兽医的范畴。用自行摸索的训练去处理并让时间拖长，这期间狗的状态和家人的生活会一起变差。

8. 让家人统一规则

同一个家里，如果每个人的对待方式都不同，规则在狗看来就变成了「偶尔管用的东西」。而偶尔管用的行为，比总是管用的行为更加顽固。这就是家庭共识比训练技术更重要的原因。

最容易理解的例子是餐桌。四个人里三个不给、一个偶尔给，餐桌对狗来说就成了「多半不行但值得一试的地方」。这会形成比所有人都不给强得多的学习。

需要达成共识的项目要定下什么不统一会发生什么
信号用词把词语和手势统一成一种词语有好几个，哪一个都变不可靠
餐桌是完全没有例外，还是在别处单独喂一个人的例外会使整条规则失效
家具使用沙发和床是否允许每个人不同，狗就会对每个人表现不同
回家时的招呼是否等兴奋度降下来再打招呼一个人在门口反应强烈，兴奋就会一直维持
访客应对是把狗隔开，还是请访客忽略它每次都不同，来访本身就变得不可预测
零食总量每日喂食量与训练零食的分配多人各自给，总量就无法管理
散步规则是否执行「一拉就停」的规则因牵狗的人而异，规则就依附于人
孩子的角色孩子不发指令指令无效的经验反复累积，信号会变弱
  • 共识不要只用嘴说，写下来贴出来。交给记忆，几天就散了
  • 规则越少越能维持。守住三条好过定下十条
  • 要改的时候所有人同时改。分批执行会产生和间歇强化一样的结果

9. 与孩子或年长者同住的家庭结构

这一节的目的不是制造恐慌。要点是：多数事件发生在可预测的情境中，而可预测就意味着可以用结构去阻断。依赖人的注意力的做法难以持久，用空间和流程解决更稳定。

  • 指定一个狗可以独处的位置。只有配上「它在那里时谁都不靠近、不触碰」的规则，这件事才有意义
  • 预先建立可以隔开的结构。一道门、一个围栏，在紧急时是最可靠的工具
  • 重新定义看护。待在同一个房间不算看护，处在需要时能插到两者之间的位置才算
  • 进食、睡眠与心爱物品的附近要单独制定接近规则。这是最常产生冲突的三处
  • 与年长者同住时先看跌倒风险。比咬伤更常见的实际危险，是被拉扯或被扑而失去平衡。调整由谁遛狗、如何管理牵引绳，是更现实的措施
  • 教孩子的是「不做什么」而不是「怎么做」。不打扰睡觉的狗，不靠近正在进食的狗，不搂抱，不把脸凑近，不从背后接近
  • 出现第5节的负荷信号时立刻隔开。让狗持续处在「忍着」的状态，是最危险的选择

  • 独处时的问题两周以上没有改善

  • 回避被触碰，或护住某个部位

  • 已经试过好几种办法，却没有一种找到方向

结语：换个顺序，多数事情就不一样了

把本文的要点压成一句话就是：训练是最后一步，不是第一步。看到问题行为时，不要急着找方法，而要守住顺序。先确认健康，再看需求与环境。这两者理顺之后，学习才会有意义地累积起来。

而学习形成的原理比想象中简单：紧跟行为出现的结果会改变下一次，而这个结果落下的时点哪怕偏离几秒，方向就会不同。所以好的训练通常并不精彩。短、频繁、从容易的地方开始，一次只让一件事变难。

最后再强调一次：攻击性与严重焦虑是通过诊疗而非训练处理的问题。准确认识这条边界是本文最实用的部分，也是同时保护狗与人的最短路径。由于个体差异很大、制度也会变动，这里写的内容宜作为起点，并与主治兽医及最新条文一起核实。

与狗共同生活的其他准备也遵循同样的逻辑。预估医疗费负担可参见宠物保险，像暑热这样的季节性风险管理见夏季宠物照护，终将面对的告别流程见宠物身后事。独居环境下的准备则更接近单身家庭与宠物。

## 2. 基本信号练习顺序

原则: 每次要短(1到3分钟) · 每天3次 · 成功率8/10以上进入下一阶段 · 5/10以下退一级 · 以成功收尾。
难度维度一次只提高一项。

### 第1周 — 对名字的反应

用途: 察觉危险时把注意力拉回来的第一步

1. 在安静的房间里叫一次名字
2. 目光相接的那一刻发出标记声
3. 标记后1秒内给奖励
4. 重复10次，记录: ___/10

注意: 责骂时不要叫名字。名字之后永远只有好事。

### 第2周 — 坐 / 等

1. 先定手势。词语在行为出现之后再加
2. 在坐下的那一刻标记，不是在站起来之后
3. 等 从1秒开始。按 时间 → 距离 → 干扰 的顺序，一次只提高一项
4. 记录: 坐 ___/10 · 等 ___秒

### 第3周 — 过来

1. 在牵着绳的状态下从两三步的距离开始
2. 在它跑来的过程中标记，不是在到达之后
3. 需要抓住时，先握住牵引绳并给奖励，然后再移动
4. 记录: ___/10

注意: 不要在 过来 之后接洗澡、结束散步或喂药这类不愉快的事。一旦接上，响应率就会下降。

### 第4周 — 更换地点

按 门口 → 院子 → 散步道 的顺序，把同样的信号从第1周重新开始。
地点一变，就当作难度已经归零。
