60ドルPC の残りの請求書 - 用途を終えたハードウェアが再び使われるとき引っかかるもの

基板の値段は総額ではなく出発点だ。電源と冷却とドライバと電気代に散らばった残りを項目でまとめて読む

2026-09-07 IT・技術

60ドルのゲーミングPC という文が出回った。物は AMD BC-250、もともと暗号資産の採掘機材に入っていた基板である。採掘需要が冷えるとその基板が中古市場に流れ、中に入っているチップが家庭用ゲーム機に使われたAPUを削った物だと知られると、値段の割に性能が良いという評価が付いた。

その文からまず外すべきは数字ではなく、数字に付いている条件だ。60ドルは何の値段なのか。どの市場で、いつの値段なのか。それを払った後に何をさらに買う必要があるのか。三つの問いに答えを付ければ、60ドルは総額ではなく出発点だと分かる。

そしてその先が本題である。用途を終えたハードウェアが再び使われようとするとき実際に引っかかるのは、たいてい価格ではない。ドライバ、ファームウェア、コネクタ規格、文書、そしてそのすべてを人が抱え続けなければならない時間だ。ハードウェアが安くても時間は安くない。

以下の数値には出典の性格を示す欄を付けた。BC-250 は小売製品として発売されたことがなく、メーカーの製品ページも公式仕様表も存在しない。したがってこの記事の仕様と測定値の大半はコミュニティ文書から来た値であり、その事実自体が後の議論の材料になる。

きっかけ - 60ドルは何の値段なのか

きっかけとなった記事の見出しに付いた60ドルは基板一枚の値段である。ストレージも電源もケースも含まない。BC-250 は GDDR6 16GB を基板に実装した状態で出てくるのでメモリを別に買う必要はないが、残りはすべて別である。

条件はさらに二つ付く。一つは市場だ。その値段は特定の中古取引サイトで運が良いときに見つかる値として紹介された。もう一つは時点である。同じ記事が2025年11月時点でよく見る値段を70ドルから100ドルの間と書いた。つまり60ドルは、その記事が書かれた時点ですでに上限ではなく下限、それも運が味方したときの下限だった。

基板の流通の仕方も値段に影響する。コミュニティ文書は、この基板が4Uラックマウントの採掘筐体から取り出されて一枚単位で売られると書いている。筐体を解体して初めて出てくる物なので供給が揃わず、そのため文書自身が価格と在庫が大きく揺れるので現在の出品をよく比較するようにという但し書きを添えている。

この基板が市場に出てきた経路

こうした物がなぜ市場に出るのかは三段階で説明される。採掘基板でもサーバーのリファービッシュでもセットトップボックスでも、経路の形は同じだ。

  • 単一の用途向けに大量生産される — BC-250 は最初から小売販売を想定していない。ラックに何枚も挿して一種類の計算だけをさせるために作られた基板である。だから映像出力が一つしかなく、ストレージスロットも一つだ。足りないのではなく、その用途に必要なかったのである。
  • その用途の採算が消える — 採掘の収益構造が変われば、機材は一夜にして残存価値だけが残る。このとき機材は廃棄されるか、解体されて部品単位に散る。市場に物量が流れ込む時点がここだ。
  • 残存価値はハードウェアにしか残らない — チップもメモリも基板もそのまま使える。しかしドライバ、ファームウェア、文書、保証はもとの用途のためだけに作られたか、そもそも作られていない。この非対称が再利用の実際の難度を作る。

チップ自体の来歴も同じ構造だ。コミュニティ文書は BC-250 のAPUが家庭用ゲーム機に入ったAPUを削った物であり、CPUコア八つのうち二つとGPU演算ユニット十二個が無効化されていると書く。完成品の等級基準に届かなかったダイが別の製品へ流れるのは半導体産業の古い慣行であり、採掘基板はその流れの終着地の一つだった。

ここで一つが決まる。このチップには最初から一般消費者向けソフトウェアの系譜が付いたことがない。ゲーム機の中にあるときはゲーム機メーカーのソフトウェアが、採掘ラックにあるときは採掘ソフトウェアがその場所を埋めていた。どちらの系譜も個人が引き継げるものではない。その空席をコミュニティが埋めているのが今の状態である。

ハードウェア代の外側にある請求書

安いハードウェアを評価するときによく抜け落ちるのは二つの欄だ。一つは一緒に買う必要のある部品、もう一つは時間である。総コストの骨組みを先に立てておくと、各項目がどの欄に入るのかが見えてくる。

総コスト = 基板代
         + 一緒に買う必要のある部品代    (電源 · 冷却 · ストレージ · ケース · 変換器)
         + 電気代 x 使用年数            (稼働率に比例して大きくなる)
         + 設置と維持に入った時間        (領収書には出ないが消えもしない)
         - 使い終わったときに残る値      (非標準の部品ほど 0 に近い)

三行目と四行目がこの記事の残りを引っ張る。下の表は四行目、つまり金額ではなく時間で計算される項目を一つずつ広げたものだ。右の欄には、物を手に入れる前に何を見ればその項目があると分かるのかを書いた。

項目ハードウェア代の他にかかるもの確認方法

最後の行が残りを合計した値だ。時間は領収書に出ないので総コストの計算からいつも抜ける。しかし上の十二行を一つずつ通過するのにかかる時間は実在し、その時間は基板代より高くつくことがある。同じ性能の完成品を買えば十二行がまるごと消える代わりに値段が上がる。二つの選択肢の違いは性能ではなく、お金と時間のどちらを差し出すかである。

単価が下がるのに請求額はそのまま、という現象はハードウェアだけのものではない。単価と総額が別々の場所で決まる構造は、どの領域でも同じ形で現れる。値札が付いている項目が安くなるとき、値札の付いていない項目はそのまま残る。

電源 - コネクタは標準なのに組み立ては標準ではない

電源はこの基板で最もよく引っかかる場所だ。コネクタ自体はグラフィックスカードに使うPCIe 8ピンなので見慣れている。ところが基板にATX電源を入れる信号回路がない。通常のPC組み立てでマザーボードが担っていた役割を、この基板は担わない。コミュニティが別途のアダプタ基板の設計を作って回している理由がこれである。部品一つひとつは標準なのに組み立て手順が標準ではない状態が、この種の物の典型的な姿だ。

電流側の条件はもっと具体的である。コミュニティ文書は12Vレールに最低250W、余裕を見るなら300W以上を挙げる。計算負荷を長くかける使い方ならATX 400W以上か FlexATX 500W級を勧める。そして特定の小型電源二機種については、ゲーム負荷で電源が落ちたり壊れたりした事例が報告されているとして推奨しないと明言している。220Wの負荷をコネクタ一つで引いてくる物なので余裕がない。

変換器についての警告は好みの問題ではなく安全の問題だ。SATA電源コネクタは54W定格なのに、そこからPCIe 8ピンを作り出す変換経路が市場にあり、文書はこれを火災リスクとして名指ししている。配線の太さも16 AWG以上を挙げ、18 AWGでは不足だと書く。定格を超えて使うコネクタは静かに熱を持ち、そして一度に壊れる。

この表で最も重要な行は一番上だ。何もしていないときに85Wから105Wを使う。クロックを下げるツールを入れても65Wを下回ることはあまりない。この一行が後に出てくる用途判定の半分を決める。負荷がかかったときにいくら使うかより、負荷がないときにいくら使うかが常時稼働機器の性格を決めるからだ。

ソフトウェア - ドライバがないという言葉の範囲

ドライバがない、という言葉はふつう少し不便だという意味に読まれる。ここではその意味ではない。範囲を四層に分けるとこうなる。

  • Windows向けGPUドライバがない — コミュニティ文書は、この基板がWindowsを起動しはするがGPUドライバがなく、今後も出ない可能性が高いと書く。グラフィックス支援が抜けた状態で起動するので、画面を使う作業には事実上使えない。選択肢が狭まる程度ではなく、片方がまるごと閉じる。
  • Linuxでもバージョン区間を選ぶ — Mesa は 25.1.3 以上、推奨は 25.1.5 以上である。カーネルは特定区間がGPUドライバの不具合により回避対象として挙げられている。長期サポート版を避けよという案内が付く理由も同じだ。長く変わらない側が美点ではなく欠格になる稀なケースである。
  • ファームウェアを基板に直接書き込む手順が前提になる — 文書は特定バージョンのBIOSとメモリ割り当て設定を推奨構成として挙げる。そのファームウェアはメーカーが配布するものではなく、更新経路もメーカー側にない。
  • 映像のハードウェアエンコードとデコードがない — 該当機能のファームウェアがゲーム機メーカーの所有物であり、この基板では使われない。画面出力はできるが、映像の圧縮と展開をGPUに任せる道が塞がっている。

四番目の項目は用途をまるごと一つ消す。安い機器をメディアサーバーに回そうとする人が真っ先に期待する機能がハードウェアトランスコードであり、それがなければCPUで回すことになる。6コアのZen 2でできない仕事ではないが、その瞬間この基板を選んだ理由だった安いGPUが計算から抜ける。機能一つの不在がハードウェアの強みを無効にする場所がここだ。

二番目の項目の性格も押さえておく価値がある。ふつうのハードウェアは時間が経つほど対応が安定する。ここでは逆に、カーネルが上がるたびに動いていたものが動かなくなることがある。対応が上流のカーネルとグラフィックススタックに入っている一方で、メーカーが退行を追う義務を負わないからだ。だから更新を先送りもできず、無造作にもできない状態が続く。この状態を管理するのに使われるのが、先の表の最後の行、時間である。

性能 - 条件を付けて初めて読める数字

性能の数値は条件なしで運ぶと直ちに歪む。公開されている値を条件と一緒に並べると次のようになる。

項目値測定条件出典の性格
大型オープンワールドのタイトル平均70から90フレーム1080p。中から高の設定コミュニティ測定
アクションのタイトル平均およそ100フレーム1080p。高設定コミュニティ測定
大作ゲーム一般平均60から100フレーム以上1080p。高設定コミュニティ測定
競技性の高いオンラインゲーム平均100フレーム以上1080p。最適化設定コミュニティ測定
性能クラスのたとえ普及帯のグラフィックスカード二種の間比較対象のみ提示。測定条件なしコミュニティの記述
元のゲーム機との関係同格ではないCPUコアとGPUユニットが減っているコミュニティの記述

条件を付けて読むと絵が変わる。値がすべて1080p基準であり、設定は中から高の間だ。4Kや最高設定に当たる値は一覧にない。そして全部が平均フレームである。最低フレームやフレームタイム分布はない。ゲームで体感を左右するのは平均より下位区間なのに、その値が抜けていれば数字は上限しか示さない。

より大きな変数は測定の主体だ。値はすべてコミュニティ測定であり、測定環境も冷却状態もファームウェアのバージョンも人によって違う。先に見たとおり、GPUクロックが周波数調整ツールの有無によって1500MHzと2000MHzの間で分かれる。冷却が足りなければそれすら維持されない。同じ基板でも構成が違えば別物になる。ハードウェアの仕様が性能を決めるのではなく構成の完成度が決める状態であり、これもまた時間の項目として戻ってくる。

電力と寿命 - 年数で割ると順番が入れ替わる

安いハードウェアの実際のコストはたいてい電気代に出る。まず計算の構造から立てておく。

年間電力量(kWh) = 消費電力(W) x 一日の稼働時間(h) x 365 / 1000

  常時稼働 · アイドル 85W :  85 x 24 x 365 / 1000 = 744.6 kWh
  常時稼働 · アイドル 70W :  70 x 24 x 365 / 1000 = 613.2 kWh
  一日3時間 · 負荷 180W   : 180 x  3 x 365 / 1000 = 197.1 kWh
  比較用 · 低消費電力 15W :  15 x 24 x 365 / 1000 = 131.4 kWh

年間料金 = 年間電力量 x kWh あたり単価
  単価は国 · 契約種別 · 使用量区分ごとに違う。
  下の表の 31円 は日本の家庭用のおおよその目安を置いた計算用の仮定値であり、
  料金表の確定値ではない。地域と契約と時間帯によって上下する。

表を並べて読むと構造が見えてくる。常時稼働を前提にすれば、3年分の電気代がハードウェア代と同じ桁に上がる。部品まで揃えた総額を205ドルから370ドル、為替を1ドル150円として3万円台から5万円台半ばと置いても、アイドル85Wで3年回せば電気代がその値を超える。低消費電力機器との差額だけでも3年で約5万7千円開く。この地点で安い側と高い側の順番が入れ替わる。

逆方向も同じ表の中にある。一日三時間だけ使えば3年累計が2万円を下回る。この場合、電気代は順番を変えられない。つまりこのハードウェアの総コストは性能でも値段でもなく稼働率が決める。同じ物がある人には安く、ある人には高い理由がここにある。値段を比べる前に一日何時間つけておくのかを決めなければ比較が成立しない。

寿命も同じ割り算に入る。中古で出た基板は採掘環境ですでに長く回っている。負荷が一定なので熱サイクルが少ない点では有利、総稼働時間が長い点では不利だ。どちらが大きく効くかは個体ごとに違い、保証がないので故障は即全額の損失である。3年を前提に立てた計算が1年で終われば、上の表のすべての欄が三倍悪くなる。初期価格と運用費を一緒に見る計算は家電で総所有コストを見積もるときに使うものと同じ構造であり、ここでは残存寿命という変数が一つ増えるだけだ。

電子廃棄物 - 天秤が一方に傾かない理由

再利用には明確な利得がある。国際的な電子廃棄物の報告書は、2022年の一年間に6,200万トンの電子廃棄物が発生し、これは2010年比で82パーセント増えた量であり、このうち正式に回収されて再資源化されたと記録された割合は22.3パーセントにとどまったと集計した。同じ報告書は2030年に発生量が8,200万トンに達する一方、記録された再資源化率は20パーセントへとむしろ下がると見ている。回収されなかった金属の価値だけで910億ドルと計算されている。

この数字の前では、廃棄寸前の基板を数年長く使うことは明らかに良い側だ。新たに作らなかった分の資源と製造排出がそのまま節約される。とくにこの基板のようにすでに作られ、すでに一度捨てられた物は、製造段階の排出が回収不能な埋没費用なので使用延長の利得が大きい。

ところが天秤の反対側に使用段階がある。旧世代のプロセスから出たチップは同じ仕事をするのにより多くの電力を使う。何もしていないときに85Wを使う機器を3年常時稼働させれば2,200kWhを超える。その電力がどう作られたかによって排出量が変わり、ある地点では製造で節約した利得を使用段階が食ってしまう。天秤の向きを決めるのは三つの変数だ。

  • 稼働率 — 一日何時間つけておくのか。先の表で見たとおり、この値一つで使用段階の大きさが六倍近く変わる。常時稼働と間欠稼働は事実上別の案件である。
  • 代替関係 — この機器が何の代わりになるのか。新しい機器を買わずに済むことと、使っていなかった機器をもう一台つけることは方向が逆だ。再利用という名前が両方に同じく付くことが混乱の原因である。
  • 電源構成 — 同じ1kWhでもどの電源から来たかによって排出が違う。地域と時間帯によって値が変わるので、同じ機器を同じ時間回しても結論が変わりうる。

だからこの案件は、再利用が正しいとか電力効率が優先だとかいう一文では閉じない。三つの変数のうち一つが変わるだけで結論がひっくり返る。結論を先に決めておいて有利な変数だけを選ぶことが、この主題で最もよくある誤りだ。廃棄を遅らせるという名分と電力を節約するという名分は、しばしば互いを相殺する。

どこに合い、どこに合わないのか

ここまでの項目を用途に当てはめると判定が分かれる。判定の根拠は好みではなく、これまでに見た値である。

用途判定理由
間欠稼働の1080pゲーム機合う公開された性能値がすべてこの条件から出ており、稼働率が低いので電気代が順番を変えない
Linuxとグラフィックススタックの実習機合うカーネルとMesaを扱わなければ動かない物なので、学習自体が目的なら障害がそのまま教材になる
オフライン単独作業用の補助機条件付き必要なソフトウェアがLinuxで動き、映像支援を使わない場合に限る
GPU計算の実習条件付き16GBの共有メモリは魅力的だが、このGPU識別子をどのフレームワークがどこまで対応するかによる
常時稼働の低消費電力ホームサーバー合わないアイドル消費電力が65Wを下回ることがあまりない。この用途の核心指標で負ける
メディアサーバーとトランスコード合わないハードウェアのエンコードとデコードがない。安いGPUという長所がこの用途では使われない
Windowsが必要なすべて合わないGPUドライバがなく、出る見通しもない
カーネル水準の保護機構が付いたオンラインゲーム合わないLinuxゲーミング全般の制約をそのまま受ける
無人の遠隔運用合わない映像出力が一つで、ファームウェアとカーネルがコミュニティ管理下にあるため遠隔復旧が難しい
業務用の常時稼働機材合わない保証もサポートも代替調達経路もない。一台止まれば同じ物をまた探すことになる

一覧で注目すべきは常時稼働のホームサーバーが合わない側にある点だ。安い中古ハードウェアをホームサーバーに回すのはよくある選択であり、たいてい合理的なのに、この物はよりによってその条件で最も悪い指標を持っている。アイドル電力が高い機器は常時稼働で損が最も大きい。逆に短く強く使う用途では同じ値が問題にならない。ハードウェアの良し悪しは用途を決めた後でなければ言えない。

似た判断が必要な場面は他にもある。ホームラボで開発環境を組むときも、推論用ハードウェアを選ぶときも、分かれる軸は性能表ではなく帯域と対応エコシステムと常時コストだ。軸の名前が変わるだけで構造は同じである。

同じ構造を持つ他の物

BC-250 は特異な事例ではなく、よくある類型の一事例だ。同じ経路で市場に出てくる物が続いている。

  • 採掘用のグラフィックスカード — 映像出力がそもそもないモデルがあり、あっても保証は終わっている。ファンとサーマル材が消耗した状態で出てくる場合が多く、整備費用が先の表にもう一行付く。
  • エンタープライズサーバーのリファービッシュ — 性能あたりの値段は素晴らしい。代わりに騒音と消費電力が家庭用の基準を超え、レールとラックと特殊規格の電源が付いてくる。常時稼働を前提とする物なので電気代の項目がとくに大きく出る。
  • セットトップボックスとシンクライアント — 大量に出回り、値段がほとんどない。ロックされたブートローダと配布されないファームウェアが壁になる。ハードウェアは健全なのにソフトウェア側の扉が閉じている典型だ。
  • サービスが終わった専用端末 — 部品は無事なのにサーバーが消えている。この場合の障害は機器の中ではなく外にあるので、技術で越えられる壁なのかどうかから分かれる。

四つの場合はすべて一文に要約される。ハードウェアの残存価値は長く残るが、そのハードウェアを使えるようにしていたソフトウェアと文書とサポートは、用途が終わる瞬間に一緒に終わる。再利用の難度は部品の物理的な状態ではなく、この非対称の大きさで決まる。中古品で見かけの状態と実際の残存価値がずれる構造は、中古車を見るとき記録を先に見る理由と同じだ。機械は無事に見えても履歴と書類が値段を決める。

次に似た値段に出会ったとき見る五行

この種の見出しは今後も出てくる。そのとき五行だけ当ててみれば、数字と実際との距離がすぐに現れる。

確認することなぜ今回の事例では
その値段は何の値段か部品の値段とシステムの値段は別の数字だ基板一枚。残りはすべて別
どの市場のいつの値段か中古相場は供給によって大きく揺れる特定の中古サイト。2025年11月時点でよく見る値段はもっと高い
標準規格から何か所外れるか外れた項目ごとに部品と時間が付くケース寸法。電源投入回路。映像出力の個数
ソフトウェアを誰が維持するかメーカーかコミュニティかで寿命が分かれるコミュニティ文書とコミュニティのパッチ
一日何時間つけておくか稼働率が総コストの順番を決めるアイドル電力が高く常時稼働に不利だ

五行のうち最後の二行が安いハードウェアでとくによく抜ける。前の三行は物を手に入れる前に目に見える。後の二行は数か月後に請求書とカーネル更新になって戻ってくる。値段が安いという事実が愉快な理由はその値段が前の三行にしか掛かっていないからであり、失望が後から来る理由は後の二行がそのとき到着するからだ。

この五行は結論の代わりにはならない。ある人には五行を全部通した後でもこの物が合う。短く使い、Linuxをすでに扱っていて、構成すること自体を楽しむ場合だ。別の人には最初の一行で終わる。五行の使い道はその分かれ目が購入の前に見えるようにすることであり、一方へ追い立てることではない。

確認できなかったこと

以下の項目は一次資料で文面を確定できなかったため本文に入れなかった。理由を併記する。

  • きっかけ記事の本文 — 原文のページがアクセス制限で応答し、本文を開けなかった。60ドルが基板単体の値段だということ、2025年11月時点でよく見る値段が70から100ドルだという時点情報は、要約記事に書かれた内容であり二次資料である。
  • メーカー公式の仕様 — BC-250 の公式製品ページや仕様表に当たる場所を見つけられなかった。本文のコア数、演算ユニット数、クロック、設計電力はすべてコミュニティ文書の値である。この不在自体は本文の三番目の節の論拠として使った。
  • コミュニティ文書内の値の不一致 — 電力の文書の一行が演算ユニット40個基準の持続負荷を書いているのに、同じ文書の仕様ページは24個と書く。どちらがこの基板の値なのか判別する根拠を見つけられず、本文の表には電力の値だけを移してユニット数は付けなかった。
  • アイドル電力の実際の範囲 — 周波数調整ツールを入れたときの値が資料によって50から65Wと65から85Wに分かれる。測定条件が同じかどうか判別できず、本文にはより保守的な側だけを記した。
  • 電気料金の単価 — 本文の表のkWhあたり31円は計算用の仮定値である。現行料金表の区分別単価を一次資料で確定できなかったため、実際の料金の代わりに桁だけを示した。日本の家庭用料金は契約種別と時間帯で単価が動くので、同じ1kWhでも位置によって値が違う。
  • 中古個体の残存寿命 — 採掘環境の総稼働時間と故障率についての公開統計を見つけられなかった。本文で寿命は計算の構造としてのみ扱い、確率や期待寿命は書かなかった。
  • 再利用の環境上の損益分岐点 — 製造段階の排出と使用段階の排出を同じ基準で比較した、この機器についてのライフサイクル評価を見つけられなかった。そのため九番目の節は天秤の向きを変数としてのみ記し、損益分岐の時点を数字で提示しなかった。
