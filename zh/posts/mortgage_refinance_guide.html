引言：减轻利息负担的机会——韩国住宅贷款转贷

对于韩国大多数家庭而言，住房抵押贷款（주택담보대출，简称「주담대」）是最大的债务。利率哪怕只有细微的差异，在数十年的贷款周期中也可能导致数百万甚至数千万韩元的利息差距。韩国在线一站式转贷平台于2023年5月从信用贷款起步，2024年1月扩展至住宅抵押贷款，使借款人通过手机应用就能比较多家金融机构的利率，并轻松完成转贷。

然而，流程简化并不意味着转贷总是合算的。提前还款手续费、DSR监管、登记费用、贷款期限重置等诸多因素都需要仔细评估。本文基于韩国权威公共机构的信息，梳理住宅抵押贷款转贷制度，重点帮助读者区分转贷真正有利的情形和不宜转贷的情形。

注意：本文最初于2026年6月撰写，监管、提前还款手续费及转贷平台相关事实已于2026年9月29日根据韩国金融委员会和韩国银行原文重新核实。韩国银行基准利率于2026年8月27日调整为年3.00%。金融环境随时变化。实际决策前请务必通过金融监督院金融商品综合比较公示（finlife.fss.or.kr）或相关金融机构直接确认最新信息。

1. 转贷（大换贷款）是什么

转贷（대환대출，大换贷款）是指将现有贷款替换为另一家金融机构条件更优惠的贷款。住宅抵押贷款转贷的情形下，借款人以新贷款还清旧贷款，实质上是旧贷款的全额提前偿还和新贷款的重新发放，因此可能产生提前还款手续费，同时触发新一轮的DSR审核。

1.1 为何需要转贷

  • 弥合利率差距：在高利率时期办理的贷款可能远高于当前市场利率，转贷可减轻利息负担。
  • 浮动利率转固定利率：在担忧利率上升时，转为固定利率可使每月还款额更可预测。
  • 还款方式变更：从到期一次性还款改为等额本息或等额本金方式，加快本金偿还。
  • 调整贷款额度：若房产价值上涨，可能通过转贷获取额外资金。但在线转贷平台不允许增额转贷，新贷款额度限于原贷款剩余金额以内（金融委员会，2024年1月9日）。

1.2 在线一站式转贷平台

韩国在线转贷平台2023年从个人信用贷款起步，2024年1月扩展至住宅抵押贷款和租赁贷款。金融委员会主导制度设计，金融结算院运营系统，Toss、KakaoPay、Naver Pay、Finda（핀다）等金融科技平台及众多银行参与其中。

该平台的核心是MyData（我的数据）集成：平台自动获取现有贷款信息，在同一界面显示多家机构的竞争报价，申请、提交材料、电子签约和放款均在同一数字流程中完成，无需到银行网点办理。

根据韩国金融委员会公告核实的开通时间与使用条件如下（2026年9月29日核实）：

3. 转贷条件与DSR监管

3.1 基本资格条件

  • 须有正在还款中的住宅抵押贷款
  • 符合新金融机构的LTV（抵押认定比率）要求：管制地区住宅抵押贷款自2025年10月16日起为40%，其他地区因地区和物件类型而异
  • DSR（총부채원리금상환비율）不超过40%（通常所说的第一金融圈水平，2026年6月撰写时数值）
  • 满足金融机构的信用评分要求（因机构而异）
  • 最低贷款金额：通常为2000万~3000万韩元以上

3.2 DSR是什么

DSR（总债务本息偿还比率）是全部贷款年度本息还款额占年收入的比例。韩国第一金融圈（银行）通常要求DSR不超过40%，超出则无法获批新贷款（包括转贷）。第二金融圈上限通常为50%。由于转贷被视为新贷款，申请时将按当前收入和全部债务重新计算DSR。

3.3 压力DSR第三阶段及此后的收紧

压力DSR是在实际利率基础上叠加假设的「压力利率」来计算DSR的方式，按当前利率能通过DSR要求，加上压力利率后也可能无法通过。韩国第三阶段于2025年5月20日确定发布，2025年7月1日起实施，基本压力利率为1.50%。

  • 首都圈及管制地区住宅抵押贷款：根据2025年10月15日的对策，压力利率下限由1.5%上调至3.0%（2025年10月16日起实施）
  • 地方（首尔、京畿、仁川以外）住宅抵押贷款：第二阶段压力利率0.75%适用至2025年12月底；金融委员会于2025年12月10日表示，2026年上半年（1月1日至6月30日）仍计划适用第二阶段。

因为转贷会触发基于当前收入和债务的全新DSR评估，若贷款实行后收入下降或其他债务增加，即使原贷款审核时DSR有充足余量，也可能在转贷审核中被拒。建议提前自行计算DSR后再申请。

3.4 转贷时是否也适用监管规定（2026年9月29日核实）

韩国金融委员会解释称，转贷是由新金融机构发放的新贷款，因此金融机构在转贷时点重新计算LTV是依据各业务领域监管规定的当然措施（2025年10月27日）。也就是说，转贷原则上应视为重新审核的新贷款，而非旧贷款的延续。按监管项目整理原文确认内容如下：

监管措施原文关于转贷的内容依据
管制地区住宅抵押贷款LTV 40%（2025年10月16日起）转贷时也曾适用收紧后的40%；自2025年10月27日起，管制地区内住宅抵押贷款不增额转贷时，可适用该贷款发放时点的LTV监管比率，但仅限于「适用生活稳定资金用途住宅抵押贷款1亿韩元限额标准的借款人」金融委员会 2025年10月27日

首都圈及管制地区住宅抵押贷款上限6亿/4亿/2亿韩元作为购房用途住宅抵押贷款上限发布；所核实原文未说明如何适用于转贷金融委员会 2025年10月15日

在线转贷平台不允许增额转贷，新贷款额度限于原贷款剩余金额以内金融委员会 2024年1月9日

原文未单独涉及转贷的监管措施，无法断定是否适用。申请前请向拟转入的金融机构确认：①适用哪个时点的LTV；②加算多少压力利率；③是否适用住宅抵押贷款上限。

4. 提前还款手续费——核心成本计算

4.1 什么是提前还款手续费

提前还款手续费（중도상환수수료）是借款人在贷款到期前全额或部分偿还本金时须向金融机构支付的费用，用于补偿金融机构损失的预期利息收入。转贷需要全额提前偿还旧贷款，因此提前还款手续费通常是转贷最大的成本项目。

4.2 2025年以来的费率大幅下调

据韩国金融委员会介绍，自2025年1月13日起新签订的贷款，提前还款手续费只能在资金运用受阻产生的机会成本、贷款相关行政及招揽费用等实际成本范围内收取。五大商业银行住宅抵押贷款平均费率下调如下（2025年1月9日发布）：

  • 固定利率贷款：平均0.65%（从1.4%下调）
  • 浮动利率贷款：平均0.65%（从1.2%下调）

2025年1月13日前签订的贷款适用该合同本身的约定，而非调整后的费率。各金融机构的费率在各金融协会网站公示；金融委员会还宣布，互助金融机构也将自2026年1月1日起实施仅反映实际成本的提前还款手续费改革（2025年12月30日发布）。请查阅您的贷款合同确认具体数值。

4.3 计算公式

提前还款手续费 = 提前还款金额 × 手续费率 × （剩余期限 ÷ 贷款期限）

举例：贷款本金3亿韩元，手续费率0.65%，30年期贷款，1年后全额偿还：3亿 × 0.0065 × (29/30) ≈ 约188万韩元手续费。将此费用与转贷节省的利息进行比较，即可判断实际收益。

4.4 免除条件

  • 3年规定：据韩国金融委员会介绍，根据韩国《金融消费者保护法》，提前还款手续费可在消费者自贷款日起3年内还款时收取。这并非「大多数金融机构予以免除」的惯例，而是可收费期限本身由法律限定为自贷款日起3年。
  • 年度10%额度：每年偿还初始贷款本金10%以内，通常可免手续费（因金融机构和合同而异）。
  • 特别活动：部分金融机构会不定期推出限时提前还款手续费减免活动（条件随时变化，请以合同为准）。

5. 转贷办理流程：分步指南

5.1 申请前准备（转贷前必须确认）

  1. 了解当前贷款条件：确认现行利率（固定/浮动）、剩余本金、到期日、提前还款手续费率
  2. 提前计算DSR：用年收入除以全部贷款年度本息还款总额
  3. 估算节省利息：利率差 × 剩余年数 × 剩余本金（粗略估算）
  4. 核算全部转贷成本：提前还款手续费＋登记费（抵押权注销·设立）＋印花税等附加费用

5.2 在线申请流程

  1. 打开平台应用：在Toss、KakaoPay、Finda（핀다）、KakaoBank（카카오뱅크）等应用中选择「贷款转换」
  2. 授权MyData访问：自动获取现有贷款信息（需对金融机构授权）
  3. 比较利率：查看参与机构的预计利率、额度和条件（此阶段不影响信用评分）
  4. 选择产品并申请：选定金融机构→提交在线审核申请→上传所需材料（在职证明、收入证明等）
  5. 电子签约：审核通过后完成新贷款电子合同签署
  6. 新贷款实行·旧贷款自动还清：新贷款资金到账后旧贷款自动偿还
  7. 登记变更：注销旧抵押权并设立新抵押权（耗时数天至数周，产生相关费用）

6. 转贷合算情形与不宜转贷情形

6.1 转贷合算的情形

  • 新利率比现行利率低0.5个百分点以上，节省利息明显超过转贷成本
  • 自贷款日起已满3年，不再属于可收取提前还款手续费的期限，或剩余手续费极低
  • 贷款剩余期限在10年以上，节省效果能充分累积
  • 希望转为长期固定利率以对冲利率上升风险
  • DSR余量充足，信用评分良好

6.2 需谨慎的情形

  • 贷款剩余期限短（3~5年内），节省利息不足以覆盖转贷成本
  • 提前还款手续费较高而利率差较小，损益平衡点遥远
  • 收入减少导致DSR升高，可能无法通过审核
  • 登记费等附加费用高于预期
  • 预期利率将进一步下降，维持浮动利率可能更有利

7. 常见误区与注意事项

7.1 总成本计算的误区

许多借款人只看利率差而低估了总成本。实际需要考虑的成本项目：

  • 提前还款手续费：按剩余期限比例计算
  • 抵押权注销·设立登记费：法务师费用＋登记许可税·地方教育税等（通常数十万韩元）
  • 印花税：依据贷款金额，从数万到数十万韩元不等
  • 评估费：部分金融机构要求重新评估房产价值

7.2 DSR重新评估风险

转贷申请将触发基于当前收入和债务的全新DSR评估。若贷款实行后收入减少（换工作、自营业务下滑）或其他债务增加（信用卡额度、汽车贷款、透支额度），即使原贷款审核轻松通过，转贷也可能被拒。自营业者和自由职业者尤其需注意收入证明的变动。

7.3 贷款期限重置

转贷意味着新的还款期限。不是延续旧贷款的剩余期限，而是重新设定，在某些情况下最长可设30年。延长期限虽降低月供，但会增加总利息。评估节省效果时，应使用与现有贷款相同的剩余期限进行比较，避免因期限延长而误判获益。

结论：先算账，再转贷

住宅抵押贷款转贷是减轻利息负担的机会，但并非无条件合算。提前还款手续费、DSR重新评估、登记费用、贷款期限重置等因素均需综合计算，才能确认实际收益。

最关键的是损益平衡点分析：节省的总利息（年度节省 × 剩余年数）是否明确超过全部转贷成本（提前还款手续费＋附加费用）？由于提前还款手续费仅在自贷款日起3年内还款时收取，请在3年节点前后将手续费与节省的利息并列计算。另请注意，在线转贷平台须在原住宅抵押贷款发放满6个月后才能使用。

在线一站式转贷平台使利率比较和申请流程大为简化。建议比较至少三个平台，最终通过金融监督院官方比较公示进行交叉核实。住宅贷款是数十年的财务承诺，请在充分信息和必要专业咨询的基础上审慎决策。

## 2. 申请资格检查

- [ ] 原住宅抵押贷款是否已满6个月（在线平台使用条件）
- [ ] 是否在原贷款剩余金额以内、不增额转贷（在线平台不可增额）
- [ ] 抵押住宅是否可查询市价
- [ ] 是否确认抵押住宅位于管制地区（若是则LTV 40%，另需确认是否符合不增额转贷特例）
- [ ] 是否按当前收入和负债重新计算DSR（计算时会加上压力利率）

---

## 3. 需向拟转入金融机构确认的事项

- [ ] 适用哪个时点的LTV（当前还是原贷款发放时点）
- [ ] DSR计算时加算多少压力利率
- [ ] 首都圈及管制地区住宅抵押贷款上限（6亿/4亿/2亿韩元）是否适用于本次转贷
- [ ] 利率方式（固定/浮动）及贷款期限如何重新确定

---

## 4. 损益计算

| 步骤 | 计算 |
|---|---|
| 提前还款手续费 | 提前还款金额 × 手续费率 × （剩余期限 ÷ 贷款期限） |
| 示例 | 3亿韩元 × 0.65% × (29/30) ≈ 188万韩元 |
| 附加费用 | 抵押权注销及设立登记费 + 印花税 + （如需）评估费 |
| 节省利息 | 利率差 × 剩余本金 × 剩余年数（估算） |
| 判断 | 节省利息是否大于提前还款手续费 + 附加费用，损益平衡点在何时 |

- [ ] 自贷款日起是否已满3年（已满则不再收取提前还款手续费）
- [ ] 若为2025-01-13前签订的合同，是否已确认该合同约定的费率
- [ ] 是否因延长新贷款期限只看月供下降而忽略总利息

---

## 5. 决策表

| 您的情况 | 首先查看 |
|---|---|
| 新利率低0.5个百分点以上且剩余期限10年以上 | 含手续费和附加费用的损益平衡点 |
| 自贷款日起即将满3年 | 比较3年节点前后的手续费差异 |
| 剩余期限3~5年以内 | 节省利息可能低于成本 |
| 收入减少或其他债务增加 | DSR重新评估结果 |
| 需要额外资金 | 在线平台不可增额 - 另行咨询 |
