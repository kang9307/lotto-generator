출발점 — 케이블인가, PC 인가, 공유기 포트인가

유선 연결 문제는 원인이 케이블, PC 의 어댑터, 공유기의 포트, 그 바깥의 모뎀과 통신사 가운데 어디에 있는지를 가르는 일에서 시작한다. Microsoft 이더넷 문제 해결 문서는 이 구분을 공유기 쪽, PC 쪽, 다른 PC 의 세 구역으로 나누어 안내한다. 한 번에 하나의 구역만 바꾸어 보는 것이 이 구성의 요점이다. 문서는 유선 연결을 집의 공유기에 케이블 한쪽 끝을, PC 의 이더넷 포트에 다른 쪽 끝을 꽂아 빠른 인터넷 연결을 얻는 방법으로 소개하며, PC 에 이더넷 포트가 없을 때는 USB 이더넷 어댑터를 고려할 수 있다고 적는다.

문서가 공유기 쪽에서 가장 먼저 보라고 하는 것은 케이블과 포트다. 이더넷 케이블이 공유기와 PC 의 이더넷 포트에 모두 단단히 꽂혀 있는지 확인하고, 공유기 쪽에서는 모뎀을 연결하는 Internet 포트가 아니라 일반 이더넷 포트에 꽂았는지 확인한다. 케이블 하나로 안 되고 가까이 다른 케이블이 있다면 그것으로 바꿔 보고, 되면 처음 케이블에 문제가 있을 수 있다고 한다. 공유기가 Wi-Fi 도 지원하면 Wi-Fi 로 연결해 보라는 안내도 있는데, 인터넷 연결을 얻는 동시에 문제의 근원을 좁히는 방법이라고 설명한다.

마지막 구역은 다른 PC 다. 집에 다른 Windows PC 와 USB 이더넷 어댑터가 있으면 그 PC 로 같은 네트워크에 연결해 본다. 연결되면 문제는 처음 PC 쪽에 있을 가능성이 높고, 두 PC 모두 이더넷에 연결되지 않으면 공유기, 통신사, USB 이더넷 어댑터 중 하나에 문제가 있을 수 있다고 문서는 설명한다.

  • 케이블 양끝 확인: 공유기와 PC 의 이더넷 포트에 단단히 꽂혀 있는지 본다(Microsoft).
  • 포트 종류 확인: 공유기에서 모뎀 연결용 Internet 포트가 아닌 이더넷 포트에 꽂았는지 본다(Microsoft).
  • 다른 케이블 시험: 다른 이더넷 케이블로 되면 첫 케이블이 문제일 수 있다(Microsoft).
  • Wi-Fi 나 다른 PC 로 비교: 같은 공유기에 Wi-Fi 로 접속하거나 다른 PC 로 연결해 문제의 위치를 좁힌다(Microsoft).

속도 측정 결과로 문제를 좁히는 방법은 인터넷 속도 측정 가이드에서 다룬다. 이 글은 케이블 등급과 점검 순서에 집중한다.

0단계 — 연결 상태 확인과 모뎀·공유기 재시작

PC 에서 먼저 볼 것은 설정의 네트워크 및 인터넷 화면 맨 위에 표시되는 이더넷 연결 상태다. Microsoft 문서는 Windows 11 에서 이름 아래에 연결됨이 표시되어야 한다고 하고, Windows 10 에서는 네트워크 연결 아래에 인터넷에 연결되어 있음이 표시되어야 한다고 적는다. 조치 필요 같은 오류가 보이면 이더넷을 선택해 이더넷 연결 설정을 확인하라고 안내한다.

같은 문서는 공유기 쪽 점검으로 모뎀과 무선 공유기의 재시작도 든다. 라우터와 모뎀의 전원 코드를 뽑고, 모뎀에 백업 배터리가 있어 불이 켜진 채라면 배터리를 빼고, 최소 30초 정도 기다린다. 이후 모뎀을 먼저 꽂아 표시등 깜박임이 멈추기를 기다린 뒤 라우터를 꽂고, 몇 분 뒤 두 장비가 완전히 켜지면 PC 에서 이더넷으로 다시 접속한다. 이 순서와 대기 시간은 Microsoft 문서의 서술이며, 다른 제조사 문서는 켜는 순서와 대기 시간을 다르게 적기도 한다. 케이블 모뎀과 공유기가 합쳐진 장비는 그 한 대만 같은 절차로 재시작한다.

  • Windows 11 의 정상 표시: 네트워크 및 인터넷 화면에서 이더넷 이름 아래에 연결됨이 보인다.
  • Windows 10 의 정상 표시: 네트워크 연결 아래에 인터넷에 연결되어 있음이 보인다.
  • 오류 표시: 조치 필요 같은 문구가 있으면 이더넷을 선택해 설정을 본다.
  • 재시작 순서: 문서 기준으로 모뎀을 먼저 연결하고 표시등이 멈추면 라우터를 연결한다.

포트 LED 해석 — 색의 의미는 모델마다 다르다

랜포트의 불빛은 링크가 잡혔는지와 어느 속도로 잡혔는지를 보여 주지만, 색과 의미의 대응은 제조사와 모델에 따라 다르다. Intel 지원 문서가 Ethernet Server Adapter I210-T1 에 대해 적은 값을 아래 표로 옮긴다. 이 표는 해당 어댑터의 설명이며, 다른 어댑터나 공유기·스위치 포트에 그대로 적용하는 근거가 되지는 않는다.

LED상태I210-T1 문서의 의미
링크/활동꺼짐링크 없음(No Link)
링크/활동켜짐링크 연결(Link)
링크/활동깜박임데이터 활동(Activity)
속도켜지지 않음10Mb/s
속도초록100Mb/s
속도황색1Gb/s

이 표에서 초록은 100Mb/s, 황색은 1Gb/s 이다. 초록이면 기가비트라는 식의 일반 규칙은 이 문서에서 확인되지 않으며, 오히려 이 어댑터에서는 반대다. 따라서 LED 색만 보고 속도를 단정하지 말고, 해당 장치의 설명서에서 색과 속도의 대응을 찾아야 한다. LED 가 아예 꺼져 있는 경우의 해석도 모델에 따라 다르며, 위 표에서는 링크/활동 LED 가 꺼지면 링크가 없다는 뜻이다.

  • 링크/활동 LED: 꺼짐은 링크 없음, 켜짐은 링크, 깜박임은 활동이다(I210-T1).
  • 속도 LED: 켜지지 않으면 10Mb/s, 초록이면 100Mb/s, 황색이면 1Gb/s 다(I210-T1).
  • 모델별 차이: 같은 색이 다른 모델에서는 다른 속도를 뜻할 수 있으므로 설명서를 본다.
  • 색만으로의 단정 금지: 색과 속도의 대응은 해당 장치의 설명서에서 확인한다.

증상 1 — 1Gbps 가 100Mbps 로 고정될 때

기가비트 회선을 쓰는데 링크가 100Mbps 에 머무는 증상을 Intel 지원 문서(000058908)는 케이블 문제가 가장 흔하다고 설명한다. 문서의 표현으로는 불량이 난 Cat5e 나 Cat6 케이블도 대개 100Mbps 로는 계속 동작한다. 그래서 링크가 완전히 끊기지 않아 케이블 문제를 놓치기 쉽다. 의자 바퀴에 눌리거나 밟힌 케이블처럼 물리적 손상이 성능을 떨어뜨릴 수 있다는 사례도 문서에 있다.

문서가 제시하는 대응은 세 갈래다. 첫째는 케이블을 Cat6 이상으로 교체하는 것이다. 각 케이블에 Cat6 또는 Cat7 로 표기되어 있는지 확인하고, 커넥터가 딸깍 소리가 날 만큼 확실히 결합되었는지 본다. 둘째는 어댑터 설정이다. 장치 관리자의 고급 탭에서 Speed & Duplex 를 자동 협상(Auto Negotiation)으로 두는데, 문서는 기가비트 속도에는 이것이 올바른 설정이라고 말한다. 셋째는 장비 쪽이다. 액세스 포인트, 허브, 스위치, 공유기의 다른 포트에 꽂아 보고 네트워크 장비의 전원을 껐다 켠다.

마지막으로 컴퓨터를 모뎀에 직접 연결해 시험하는 방법이 있다. 문서는 검증된 Cat6 케이블로 직결해 보라고 하며, 그 목적을 중간 장비나 케이블이 문제에 관련되어 있는지 가리는 것이라고 설명한다. 앞서 본 Microsoft 문서의 다른 케이블 시험과 같이 한 번에 한 요소만 바꾸는 방식이다.

  • 케이블 교체: 불량 케이블도 100Mbps 로는 동작할 수 있으므로 Cat6 이상 케이블로 바꿔 본다.
  • 케이블 표기 확인: 각 케이블에 Cat6 또는 Cat7 가 적혀 있는지 본다.
  • 커넥터 결합: 딸깍 소리가 날 만큼 확실히 꽂는다.
  • 자동 협상: 장치 관리자 고급 탭의 Speed & Duplex 가 자동 협상인지 본다.
  • 다른 포트와 직결 시험: 공유기·스위치의 다른 포트를 쓰고, 검증된 케이블로 모뎀에 직결해 본다.

케이블 등급 — Cat5e·Cat6·Cat6a 규격 차이

케이블 등급은 지원하는 대역폭과 10기가비트 이더넷(10GBASE-T)을 얼마나 먼 거리까지 실을 수 있는지로 구분된다. 아래 표는 TIA-568 요약에서 확인한 값이다. 규격 본문은 유료 문서라 직접 열어 보지 못했으며, 이 표는 요약 수준의 값임을 밝혀 둔다.

등급최대 대역폭1000BASE-T10GBASE-T
Cat5e100MHz100m 지원공식 지원 없음
Cat6250MHz100m 지원일반 환경에서 최대 55m
Cat6a500MHz100m 지원100m 전 구간

길이 한도는 채널 전체에 적용되는 값이다. 100m 는 건물 벽 안의 영구 링크 90m 와 양 끝의 패치 코드 합계 10m 를 더한 값으로 요약된다. 따라서 책상 위의 패치 코드를 길게 쓰면 영구 링크에 남은 여유가 줄어든다. 표의 값만 보면 세 등급 모두 1000BASE-T 를 100m 까지 지원하므로, 규격상 등급 차이가 뚜렷이 드러나는 곳은 10GBASE-T 다. 가정에서 1Gbps 를 쓰는 데는 Cat5e 도 규격상 충분하다는 것이 표의 의미이며, 그럼에도 Intel 문서가 교체 대상으로 Cat6 이상을 권하는 것은 불량이 난 케이블의 사례를 바탕으로 한 안내다.

  • Cat5e: 최대 100MHz 이며 1000BASE-T 를 100m 까지 지원하지만 10GBASE-T 는 공식 지원하지 않는다.
  • Cat6: 최대 250MHz 이며 10GBASE-T 는 일반 환경에서 최대 55m 까지 지원한다.
  • Cat6a: 최대 500MHz 이며 10GBASE-T 를 100m 전 구간에서 지원한다.
  • 채널 길이: 영구 링크 90m 와 패치 코드 10m 를 합쳐 100m 가 한도다.

증상 2 — 연결 자체가 안 될 때 Windows 문서의 순서

케이블을 바꿔도 연결이 되지 않으면 PC 쪽 소프트웨어를 본다. Microsoft 문서는 Windows 11 에서는 먼저 도움말 보기 앱의 네트워크 및 인터넷 문제 해결사를, Windows 10 에서는 설정의 네트워크 및 인터넷, 상태에서 네트워크 문제 해결사를 실행하라고 안내한다. 그다음 단계는 영향 범위가 작은 것에서 큰 것 순서다.

첫째는 명령어다. 관리자 권한 명령 프롬프트에서 netsh winsock reset, netsh int ip reset, ipconfig /release, ipconfig /renew, ipconfig /flushdns 를 이 순서대로 실행한 뒤 문제가 풀렸는지 본다. 문서는 이 명령들이 TCP/IP 스택을 수동으로 재설정하고, IP 주소를 해제·갱신하고, DNS 클라이언트 캐시를 비우는 것이라고 설명한다. 둘째는 이더넷 어댑터 드라이버의 제거다. 장치 관리자의 네트워크 어댑터에서 이더넷 어댑터를 골라 장치 제거를 선택하고 이 장치의 드라이버를 제거하려고 시도 항목에 체크한 뒤 재시작하면 Windows 가 최신 드라이버를 자동 설치한다. 문서는 최근 업데이트 뒤에 연결이 멈춘 경우에 고려하라고 하고, 인터넷이 안 되는 PC 라면 다른 PC 에서 제조사 드라이버를 받아 USB 에 담아 두라고 당부한다. 이를 위해서는 PC 제조사와 모델명 또는 모델 번호를 알고 있어야 한다. 드라이버를 지운 뒤에도 Windows 가 드라이버를 자동으로 설치하지 않으면, 미리 저장해 둔 백업 드라이버를 설치한다.

마지막은 네트워크 초기화다. 문서는 이것을 앞 단계가 모두 소용없을 때의 마지막 수단으로 둔다. 설치된 네트워크 어댑터와 그 설정을 제거했다가 재시작 후 기본값으로 다시 설치하며, Windows 11 은 설정의 네트워크 및 인터넷, 고급 네트워크 설정, 네트워크 초기화에서, Windows 10 은 상태, 네트워크 초기화에서 실행한다. VPN 클라이언트나 Hyper-V 가상 스위치를 다시 설정해야 할 수 있고, 알려진 네트워크가 공용 프로필로 바뀔 수 있다는 부작용이 문서에 적혀 있다. 한편 문서는 이 방법이 Windows 10 에서 11 로 올린 뒤의 연결 문제나, 인터넷에는 접속되는데 공유 네트워크 드라이브에는 접속되지 않는 문제에도 도움이 될 수 있다고 한다.

  • 문제 해결사: Windows 11 은 도움말 보기 앱, Windows 10 은 설정의 상태 화면에서 실행한다.
  • 명령 순서: winsock reset, int ip reset, release, renew, flushdns 를 차례로 실행한다.
  • 드라이버 제거: 장치 제거에서 드라이버 제거 항목에 체크하고 재시작하며, 백업 드라이버를 미리 받아 둔다.
  • 네트워크 초기화: 마지막 수단으로 쓰며 어댑터와 설정이 기본값으로 돌아간다.
  • 초기화 부작용: VPN 과 가상 스위치 재설정이 필요할 수 있고 네트워크가 공용 프로필로 바뀔 수 있다.
  • Wi-Fi 로 시험: 공유기가 Wi-Fi 를 지원하면 연결해 보아 이더넷만의 문제인지 가른다.

어댑터 설정과 장비 점검 — 자동 협상과 다른 포트

어댑터가 협상한 속도와 이중 통신 방식이 맞지 않으면 링크가 불안정해진다. Intel 문서(000005593)에는 이중 통신 방식 불일치를 알리는 LINK_DUPLEX_MISMATCH 메시지가 나오며, 이때 링크 속도 탭에서 속도와 이중 통신 설정을 적절히 바꾸라고 안내한다. 이는 이벤트 로그 메시지의 설명이며, 이 문서만으로 어떤 설정이 언제 실패하는지를 일반화할 수는 없다.

Intel 문서(000058908)는 기가비트에서는 Speed & Duplex 를 자동 협상으로 두는 것이 올바르다고 하며, 1.0 Gbps 전용 항목이 보여야 한다는 생각이 오해라고 지적한다. 장비 쪽에서는 포트를 바꿔 보고 장비 전원을 껐다 켜며, 문서의 표현대로 허브나 스위치, 공유기의 다른 포트를 시험한다. 장비를 바꾸기 전에 어느 요소가 원인인지 한 번에 하나씩 가려야 하며, 이것이 두 회사 문서가 공통으로 쓰는 방법이다.

  • 링크 속도 탭: 이중 통신 방식 불일치 메시지가 나오면 속도와 이중 통신 설정을 확인한다(Intel).
  • 자동 협상 유지: 기가비트에서는 Auto Negotiation 이 올바른 설정이다(Intel).
  • 설정 위치: Speed & Duplex 항목은 장치 관리자의 어댑터 고급 탭에 있다(Intel).
  • 다른 포트와 장비 재시작: 공유기·스위치의 다른 포트를 쓰고 장비 전원을 껐다 켠다(Intel).

점검 순서 정리

위의 문서들을 합치면 한 번에 하나만 바꾸는 순서가 나온다. 비용이 적고 되돌리기 쉬운 것부터 하고, 설정을 지우는 단계는 마지막에 둔다. 아래 순서는 이 글이 문서들의 권고를 배열한 것이며 한 문서가 이 순서를 그대로 제시하지는 않는다.

  • 1. 케이블 양끝과 공유기 포트 종류(Internet 포트가 아닌지)를 확인한다.
  • 2. 다른 이더넷 케이블로 바꿔 시험한다. 되면 처음 케이블이 문제일 수 있다.
  • 3. 설정의 네트워크 및 인터넷에서 연결 상태를 보고, 공유기의 다른 포트로 옮겨 본다.
  • 4. 모뎀과 공유기를 재시작하거나, 모뎀에 직결해 시험한다.
  • 5. Windows 명령 다섯 개를 순서대로 실행하고, 필요하면 드라이버를 제거한 뒤 재시작한다.
  • 6. 마지막으로 네트워크 초기화를 쓰며, 이후 VPN 같은 소프트웨어를 다시 설정한다.

확인하지 못한 것

  • LED 색과 링크 속도의 일반 대응은 확인하지 못했다. Intel 문서에서 확인한 것은 I210-T1 한 모델의 값뿐이다.
  • Windows 에서 현재 링크 속도를 보는 메뉴 경로는 Microsoft 이더넷 문제 해결 문서에 나오지 않아 확인하지 못했다.
  • 1000BASE-T 와 100BASE-TX 가 케이블의 몇 가닥을 쓰는지, 한 가닥이 끊기면 속도가 어떻게 되는지는 열린 공식 출처에서 확인하지 못했다.
  • 케이블의 최소 굴곡 반경, Cat6 의 내부 십자 분리대 유무, 외래 누화 차폐의 정도는 열린 공식 출처에서 확인하지 못했다.
  • 속도를 1.0 Gbps 로 강제로 지정했을 때 협상이 실패하는지는 확인하지 못했다. Intel 문서가 말하는 것은 자동 협상이 올바른 설정이라는 점까지다.
  • 통신사(KT 등)의 유선 인터넷 점검 안내는 본문을 확인할 수 있는 출처가 없어 이 글의 근거에서 뺐다.
  • TIA-568 규격 본문과 IEEE 802.3 규격 본문은 직접 열어 보지 못했고, 등급별 값은 요약 수준으로 확인했다.
