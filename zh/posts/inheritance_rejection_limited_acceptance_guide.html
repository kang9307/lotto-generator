引言：继承既是祝福也是风险——继承债务的现实

一提到继承，人们常常会联想到承继父母所留下财产的温馨画面。然而在现实中，反而因父母留下的债务而让子女陷入痛苦的案例屡见不鲜。据称韩国国内继承抛弃（상속포기）及限定承认（한정승인）的申请件数呈增长之势，本文首次发布时（2026年4月）介绍称，截至2024年每年受理的申请超过约5万件（该数字在2026年9月更新时未能以司法年鉴原始资料再次核实）。这一数字表明，继承已不再是"得到就好的东西"，而是一项"必须慎重判断的法律抉择"。

特别是当被继承人（已故者）留下的债务多于财产时，继承人若未在3个月内申请限定承认或继承抛弃，便会被视为单纯承认（단순승인），从而承担无限责任。也就是说，可能出现必须以子女的资产和工资来偿还父母债务的情况。本文将综合整理在面对继承时务必了解的单纯承认·限定承认·继承抛弃的区别、3个月期限的准确含义、申请流程，以及遗留分（유류분）请求的方法。

1. 单纯承认 vs 限定承认 vs 继承抛弃

继承人须自知悉被继承人死亡之日起3个月内作出选择的三种方案，在韩国《民法》第1019条至第1044条中有明确规定。准确理解各自的性质与法律效果，是保护财产的第一步。

1.1 单纯承认：自动承继，无限责任

单纯承认（단순승인）是指继承人不受限制地原样承继被继承人的权利与义务。若无另行申请，3个月期限届满后即被自动视为单纯承认，故又被称为"法定单纯承认"。单纯承认的核心在于"无限责任"。若继承财产为5000万韩元，而债务高达2亿韩元，那么差额1亿5000万韩元将由继承人以其个人财产清偿。

此外，继承人若处分、隐匿或不正当消费了继承财产，即便此前已办理限定承认或继承抛弃，也可能转为单纯承认（《民法》第1026条），故须格外留意。典型情形如取用被继承人的存款，或出售其不动产等行为。

1.2 限定承认：在继承财产范围内清偿

限定承认（한정승인）是指声明"仅以所承继财产的范围为限清偿债务"的制度。若继承财产为5000万韩元，而债务达2亿韩元，则仅以5000万韩元清偿给债权人，其余1亿5000万韩元的清偿义务归于消灭。继承人的个人财产因此得到保护。

限定承认最大的优点在于，当继承财产究竟多于还是少于债务尚不明确时仍可适用。只要先办理限定承认，若财产多于债务，余下部分仍可继承；若债务更多，也能守住自己的财产。不过，由于后续的财产清单编制、公告、清偿程序等操作复杂，建议寻求专业人士协助。

1.3 继承抛弃：抛弃继承权本身

继承抛弃（상속포기）是指抛弃继承人的身份本身。也就是表明财产与债务一概不接受的意思表示。一经抛弃原则上不得撤回（《民法》第1024条），且在该顺位中抛弃继承的继承人被视为自始即非继承人。

须注意的是，先顺位继承人全部抛弃后，继承权可能移转至下一顺位继承人。因此在债务繁多的继承场合，常会一并考虑由下一顺位继承人依次抛弃，或由部分继承人办理限定承认。不过，韩国大法院在2023年3月23日的全员合议体决定（2020그42）中认定，被继承人的配偶与子女中子女全部抛弃继承时，配偶成为单独继承人，从而变更了配偶与孙子女或直系尊亲属成为共同继承人的原有判例。谁会成为下一位继承人因家庭构成而异，申请前须先确认。

2. 3个月期限——自知悉继承开始之日起算

在继承相关法律中，最为关键的词莫过于"3个月"。错过此期限后大部分救济手段都将消失，因此必须准确理解"知悉之日"的含义。

2.1 "知悉之日"的准确含义

《民法》第1019条第1项规定，继承人可"自知悉继承开始之日起3个月内"办理限定承认或继承抛弃。此处的"知悉之日"并非仅指得知被继承人死亡的日期，而是指"知悉自己已成为继承人"的日期。

  • 一般情形：被继承人的死亡日=知悉之日（家庭关系中大多一致）
  • 因先顺位者抛弃而成为继承人的情形：收到先顺位者抛弃事实通知之日
  • 家庭断绝·旅居海外等情形：迟延知悉死亡事实的实际日期（须举证）
  • 未成年人·受监护人：自法定代理人知悉之日起算

3个月的计算依照《民法》第157条，自"知悉之日的翌日起"起算。例如1月15日为知悉之日，则期限截至4月15日24时。若未能在期限内申请，即被视为单纯承认，连同债务一并承继，务须注意。

2.2 特别限定承认（自知悉债务超过之日起3个月）

特别限定承认（특별한정승인，《民法》第1019条第3项）是为错过3个月期限的继承人设立的救济制度。若"继承人非因重大过失而未能在3个月内知悉继承债务超过继承财产的事实"，则可自知悉该事实之日起3个月内申请限定承认。

例如，父母去世后已进入单纯承认状态，2年后突然收到债权人通知称继承了2亿韩元债务，则自通知日起3个月内可申请特别限定承认。不过"无重大过失"的要件较为严格，若完全未进行基本调查，则较难被认可。

法条中并无"5年"之类的期间上限。期限为自知悉继承债务超过继承财产之事实之日起3个月。此外，未成年继承人在成年前对债务超过财产的继承作出单纯承认的，可在成年后自知悉该事实之日起3个月内办理限定承认（韩国《民法》第1019条第4项，韩国"易查生活法令信息"2026-09-29确认）。

2.3 错过期限时的应对

若已错过3个月期限，应按以下顺序考虑应对方案。

  • 审视特别限定承认：如迟延知悉债务超出财产的经过合理，可申请特别限定承认
  • 债务不存在确认诉讼：若被继承人的债务已届时效完成，可主张消灭
  • 个人更生·破产：统筹处理包括继承债务在内的个人债务
  • 与债权人协商：协商部分减免或分期清偿

3. 申请流程与所需材料

限定承认与继承抛弃均须以书面形式申报，并向管辖法院提交申请书。也可通过韩国大法院电子诉讼门户（ecfs.scourt.go.kr）的家事诉讼·非讼材料提交菜单提交。

3.1 管辖法院（被继承人住所地所在的家庭法院）

申请管辖为"继承开始地的家庭法院"，即通常为管辖被继承人最后住所地的家庭法院。若首尔居民要处理生前居住在釜山的父母的继承，则须向釜山家庭法院提交申请。管辖错误可能被移送或驳回，故须准确确认户籍登记住址。

3.2 申请书格式

可在韩国大法院电子诉讼门户的"格式汇总"中下载继承限定承认或继承抛弃申报书。主要附件材料如下。

  • 共通材料：被继承人基本证明书·家族关系证明书·住民登记注销者抄本（载明死亡）
  • 继承人材料：本人基本证明书·家族关系证明书·住民登记抄本
  • 限定承认追加：财产清单（区分积极财产·消极财产编制）
  • 代理申请：委托书·印章证明书

3.3 手续费（印花税·送达费）

申请费用本身并不高。本文首次发布时（2026年4月）介绍的是印花税5,000韩元、送达费每名继承人约30,000韩元左右（5,200韩元 × 5~6次）。由于每次送达费金额由法院调整，这些数值为2026年4月时点（未能确认更新），申请前应通过管辖家庭法院或电子诉讼门户的印花税·送达费说明加以确认。律师·法务士的受任费用因案件和事务所而异（首次发布时介绍为约30万韩元~200万韩元）。由于限定承认涉及财产清单编制及债权人公告程序较为复杂，可考虑寻求专业人士协助。

4. 遗留分请求——继承人的最低限度权利

遗留分（유류분）是指即使被继承人生前赠与或以遗嘱处分致使继承财产枯竭，仍对一定范围的继承人最低限度予以保障的财产性权利。韩国宪法法院在2024年4月25日的决定（2020헌가4等）中宣告规定兄弟姐妹遗留分的《民法》第1112条第4项违宪，该项因此失效。同一决定认定第1112条第1项至第3项及第1118条不符合宪法，在立法者于2025年12月31日前修改之前继续适用；并认定第1113条·第1114条·第1115条·第1116条不违宪。

此决定之后，韩国《民法》已修订（法律第21454号，2026年3月17日公布并施行）。根据修订理由，为反映宪法法院决定的宗旨，不仅直系尊亲属，直系卑亲属·配偶等所有继承人如严重违反对被继承人的扶养义务等，家庭法院均可宣告丧失继承权；作为对特别扶养被继承人或对其财产的维持·增加作出特别贡献之报偿而作出的赠与·遗赠，不再视为特别受益。韩国"易查生活法令信息"（2026年8月31日基准）目前将遗留分权利人说明为身为被继承人直系卑亲属·直系尊亲属·配偶的继承人。

4.1 遗留分比例（配偶·直系卑亲属1/2，直系尊亲属1/3）

遗留分按"法定继承份额的一定比例"计算。《民法》第1112条规定如下。

  • 配偶·直系卑亲属（子女·孙子女）：法定继承份额的1/2
  • 直系尊亲属（父母·祖父母）：法定继承份额的1/3
  • 兄弟姐妹：无遗留分（因2024年4月25日宪法法院违宪决定，第1112条第4项失效）

例如，一个有配偶与2名子女的家庭中，若被继承人在继承开始前1年内将全部财产12亿韩元悉数赠与第三人（假定无其他财产·债务·特别受益的简化示例），则配偶的法定继承份额为12亿 ×（1.5/3.5）= 约5亿1,400万韩元，遗留分为其1/2，即约2亿5,700万韩元。每名子女的法定继承份额为12亿 ×（1/3.5）= 约3亿4,300万韩元，遗留分为1/2，即约1亿7,100万韩元。

4.2 遗留分请求的消灭时效（1年/10年）

遗留分返还请求权适用较短的消灭时效，故须迅速应对。根据《民法》第1117条，在下列两个期间中先到来者消灭。

  • 短期时效（1年）：自知悉继承开始及应返还的赠与或遗赠之日起1年
  • 长期时效（10年）：自继承开始之日起10年

特别是1年的短期时效极为短暂，一旦得知父母生前赠与或遗嘱内容对自己不利，应立即开展赠与记录追查及诉讼准备。

4.3 生前赠与计入到什么程度

对非共同继承人的赠与，原则上仅将继承开始前1年内作出的部分计入遗留分核算。但当事人双方明知会损害遗留分权利人而赠与的，1年以前的赠与也要计入（韩国《民法》第1114条）。相反，共同继承人所受的特别受益（生前赠与），不论是否在继承开始1年以前作出、是否明知会造成损害，均计入基础财产（韩国大法院1996年2月9日宣告95다17885号判决，据"易查生活法令信息"引用）。此外，2026年修订的《民法》规定，作为贡献报偿而作出的赠与·遗赠不视为特别受益（第1008条但书），并将遗留分不足额的返还方式规定为价额返还（第1115条第1项）。修订条款适用于何时开始的继承取决于附则，实际案件中应以继承开始日为准向专业人士确认。

遗留分请求诉讼涉及赠与财产时价鉴定、特别受益认定与否、贡献分反映等众多争点，所需时间与结果因案而异，最终由法院判断。建议在提交诉状前咨询律师，先确认预期返还额与适用条文。

结论：面对继承，当下应做的5件事

继承是在情感难熬之际仍要求作出重大法律判断的复杂领域。须在3个月这一短暂期限内核查财产与债务，并在单纯承认·限定承认·继承抛弃中判断何者为最佳选择。此外，若因赠与或遗嘱而致自己的份额被不当削减，则应以遗留分请求来守护最低限度的权利。

现列出可即刻付诸实施的5件事。第一，在取得死亡诊断书的同时，将"知悉之日"标记在日历上，并明确计算3个月期限。第二，被继承人的金融财产查询可利用金融监督院的"继承人金融交易综合查询服务"——银行·保险·信用卡·证券记录可一次性核查。第三，不动产等其他信息可通过"安心继承一站式服务"（政府24）申请，金融·国税·土地·建筑物·汽车·国民年金等20类可一次性查询。申请期限为自死亡日所属月份的最后一天起1年内，可前往市·区厅或行政福利中心办理，或在政府24在线申请（在线仅限第1·2顺位继承人，政府24于2026-09-29确认）。第四，只要对债务稍有怀疑，请先考虑限定承认——若财产多于债务，剩余财产仍可继承。不过其涉及财产清单编制·公告等程序负担，请与专业人士商量。第五，若存在赠与·遗嘱事实，请牢记遗留分请求的1年时效并咨询律师。对有准备者而言，继承是捍卫权利的手段；对疏于应对者而言，则可能成为终身的枷锁。

⚠️ 再次提示 — 本文为关于韩国法律的一般信息，并非针对个案的法律意见。继承抛弃·限定承认·遗留分能否适用及其结果，取决于事实关系与适用条文（含修订《民法》的适用时点），最终由法院判断。实际申请前，请咨询韩国律师、法务士或大韩法律救助公团（132）。

# 韩国继承抛弃·限定承认·遗留分核对表 - 期限、选择、请求

基准日: 2026-09-29
本文为基于韩国《民法》的一般信息，不构成法律意见。个案结论由法院判断，实际申请前请咨询韩国律师、法务士或大韩法律救助公团（132）。

---

## 1. 期限一览

| 项目 | 期限 | 依据 |
|---|---|---|
| 限定承认·继承抛弃 | 自知悉继承开始之日起3个月 | 韩国《民法》第1019条第1项 |
| 特别限定承认 | 非因重大过失而不知债务超过事实的，自知悉该事实之日起3个月（无"5年"之类上限） | 韩国《民法》第1019条第3项 |
| 未成年继承人的特别限定承认 | 成年后自知悉债务超过事实之日起3个月 | 韩国《民法》第1019条第4项 |
| 安心继承一站式服务申请 | 自死亡日所属月份最后一天起1年内 | 政府24 |
| 遗留分返还请求 | 自知悉继承开始及应返还的赠与·遗赠之日起1年；自继承开始起10年 | 韩国《民法》第1117条 |

---

## 2. 去世后立即核对

- [ ] 确定"知悉之日"，并在日历上标出3个月期限（首日不计，自次日起算，《民法》第157条）
- [ ] 如因先顺位继承人抛弃而成为继承人，已按收到通知之日重新计算
- [ ] 已申请安心继承一站式服务（金融·国税·土地·建筑物·汽车·国民年金等20类）
- [ ] 未处分继承财产，如提取存款、出售不动产等（可能被视为单纯承认，《民法》第1026条）
- [ ] 已将积极财产与消极财产（债务）分开编制清单
- [ ] 已确认管辖法院（继承开始地，通常为被继承人最后住所地的家庭法院）

---

## 3. 选择判断表

| 情形 | 优先考虑的选择 | 注意 |
|---|---|---|
| 财产明确多于债务 | 单纯承认（无需申报） | 3个月届满即自动视为单纯承认 |
| 不确定财产与债务孰多 | 限定承认 | 财产清单编制·公告等程序负担 |
| 债务明显远多于财产 | 继承抛弃 | 可能移转至下一顺位继承人 |
| 配偶与子女中子女全部抛弃 | 配偶成为单独继承人 | 韩国大法院2023年3月23日全员合议体决定（2020그42） |
| 3个月后才知悉债务超过 | 特别限定承认 | "无重大过失"要件严格 |

---

## 4. 申请材料核对

- [ ] 被继承人：基本证明书·家族关系证明书·住民登记注销者抄本（载明死亡）
- [ ] 继承人本人：基本证明书·家族关系证明书·住民登记抄本
- [ ] 限定承认需附财产清单（区分积极财产·消极财产）
- [ ] 代理申请需委托书·印章证明书
- [ ] 提交途径：管辖家庭法院或韩国大法院电子诉讼门户（ecfs.scourt.go.kr）

---

## 5. 遗留分核对

| 权利人 | 遗留分 | 依据 |
|---|---|---|
| 配偶·直系卑亲属 | 法定继承份额的1/2 | 韩国《民法》第1112条 |
| 直系尊亲属 | 法定继承份额的1/3 | 韩国《民法》第1112条 |
| 兄弟姐妹 | 无 | 韩国宪法法院2024年4月25日决定（2020헌가4等，第1112条第4项违宪） |

- [ ] 对第三人的赠与仅计入继承开始前1年内的部分（双方明知损害而赠与的，更早的也计入，《民法》第1114条）
- [ ] 共同继承人所受特别受益不论时期均已计入（韩国大法院1996年2月9日宣告95다17885号判决）
- [ ] 已反映修订《民法》（法律第21454号，2026年3月17日公布并施行）：贡献报偿赠与·遗赠不计入特别受益、价额返还、继承权丧失对象扩大
- [ ] 已根据附则与继承开始日向专业人士确认修订条款是否适用于本次继承
- [ ] 已记录1年期限的起算日（同时知悉继承开始与赠与·遗赠之日）

---

## 6. 申请前需再次确认的数值

| 数值 | 状态 | 确认途径 |
|---|---|---|
| 印花税5,000韩元 | 2026年4月时点（未能确认更新） | 管辖家庭法院、电子诉讼门户 |
| 每次送达费5,200韩元 × 5~6次 | 2026年4月时点（未能确认更新） | 管辖家庭法院、电子诉讼门户 |
| 修订《民法》附则的适用时点 | 未与原文对照 | 韩国国家法令信息中心 |

---

## 核心一句

**3个月不是从"死亡日"起算，而是从"知悉自己成为继承人之日"起算。** 怀疑有债务时先考虑限定承认；遗留分请先盯住1年期限。
