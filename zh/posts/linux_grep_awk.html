Linux 文本处理深度解析：掌握 Grep 与 AWK

在 Linux 及 Unix 系列系统中，文本数据是运维的核心。日志文件、配置文件、命令输出等一切都以文本形式存在，而能够高效处理文本的能力，对系统管理员、开发者和数据分析师来说都是必备技能。本文将详细介绍 Linux 下最强大、使用最广泛的文本处理工具——grep 与 awk，从基本用法到高级应用全面解析。熟练运用这两个工具，可以自动化复杂的文本处理任务，从海量数据中快速提取所需信息，并高效地完成系统监控与分析工作。

Grep（Global Regular Expression Print）命令深度解析

grep 是一个强大的命令行工具，用于从文件或标准输入中查找并输出与特定模式（主要是正则表达式）匹配的行。从简单的字符串搜索到复杂的模式匹配，它都能提供丰富的功能。

基本用法

grep [选项] 模式 [文件...]
  • [选项]：用于控制搜索行为的各种选项。
  • 模式：需要搜索的字符串或正则表达式。
  • [文件...]：搜索目标文件。省略时则使用标准输入（stdin）。

常用且实用的选项详解

选项 说明 示例
-i（--ignore-case） 不区分大小写进行搜索。 grep -i "error" log.txt
-n（--line-number） 同时输出匹配行的行号。 grep -n "warning" log.txt
-v（--invert-match） 仅搜索与模式不匹配的行。 grep -v "success" log.txt
-c（--count） 仅输出与模式匹配的行的总数。 grep -c "debug" app.log
-l（--files-with-matches） 仅输出包含匹配行的文件名（不输出内容）。 grep -l "TODO" *.java
-L（--files-without-match） 仅输出不包含匹配行的文件名。 grep -L "FINAL_VERSION" *.txt
-r 或 -R（--recursive） 递归搜索指定目录及其所有子目录。 grep -r "config_value" /etc/project/
-w（--word-regexp） 仅在模式作为独立单词（word）匹配时才搜索（以空格或特殊字符为分隔）。 grep -w "main" program.c（main_function 匹配，print_main 不匹配）
-x（--line-regexp） 仅在模式与整行完全匹配时才搜索。 grep -x "localhost:8080" access.log
-E（--extended-regexp） 使用扩展正则表达式（ERE），等同于 egrep 命令。 `grep -E "error
-F（--fixed-strings） 将模式视为固定字符串而非正则表达式（特殊字符也作为普通字符处理）。 grep -F "*ERROR*" log.txt（将 * 作为字面字符搜索）
-A NUM（--after-context=NUM） 输出匹配行及其后 NUM 行。 grep -A 2 "Exception" error.log
-B NUM（--before-context=NUM） 输出匹配行及其前 NUM 行。 grep -B 3 "SEGFAULT" core_dump.txt
-C NUM（--context=NUM） 输出匹配行及其前后 NUM 行（类似 -A NUM -B NUM）。 grep -C 1 "critical error" system.log
--color=auto 以不同颜色高亮显示搜索到的模式（大多数系统默认已启用）。 grep --color=auto "pattern" file.txt
-o（--only-matching） 只输出匹配的部分而非整行。每个匹配单独占一行。 grep -o -E "[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}" access.log

Grep 与正则表达式（Regular Expressions）

grep 真正的强大之处在于与正则表达式配合使用时才能充分发挥。正则表达式是一种用来描述文本特定模式的形式化语言。

  • 基本正则表达式（BRE - Basic Regular Expressions）：grep 的默认模式。使用 *、.、^、$、[]、\ 等元字符。+、?、|、() 等部分元字符需要在前面加上 \ 才具有特殊含义（例如 \+、\?、\|、\(\)）。
  • 扩展正则表达式（ERE - Extended Regular Expressions）：使用 grep -E 或 egrep。在 BRE 所有功能之外，+、?、|、() 等无需 \ 即可直接使用，表达更加简洁。

主要正则表达式元字符与组成元素：

元字符/构成要素 说明 BRE 示例（必要时加 \） ERE 示例（grep -E）
. 匹配任意单个字符（不含换行符） a.c a.c
* 匹配前面的字符出现 0 次或多次 ab*c（ac、abc、abbc...） ab*c
+ 匹配前面的字符出现 1 次或多次（ERE） ab\+c ab+c（abc、abbc...）
? 匹配前面的字符出现 0 次或 1 次（ERE） ab\?c ab?c（ac、abc）
^ 匹配行首 ^start ^start
$ 匹配行尾 end$ end$
[abc] 匹配方括号中任意一个字符（a 或 b 或 c） [aeiou] [aeiou]
[^abc] 匹配方括号中字符之外的任意字符 [^0-9]（排除数字） [^0-9]
[a-z] 匹配 a 到 z 范围内的任意字符（范围指定） [A-Za-z0-9] [A-Za-z0-9]
|（BRE） |（ERE） OR 条件。匹配前或后的模式 apple|orange `apple
\(...\)（BRE） (...)（ERE） 分组。将模式的一部分分组以限定作用范围或用于反向引用 \(ab\)\+ (ab)+
{n} 前面的字符恰好重复 n 次（ERE） a\{3\} a{3}（aaa）
{n,} 前面的字符重复 n 次或更多（ERE） a\{2,\} a{2,}（aa、aaa...）
{n,m} 前面的字符重复 n 次以上、m 次以下（ERE） a\{2,4\} a{2,4}（aa、aaa、aaaa）
\b 单词边界（word boundary），表示单词的开头或结尾（GNU grep） \bword\b \bword\b
\w 单词字符（字母、数字、下划线）。类似 [A-Za-z0-9_]（GNU grep） \w+ \w+
\s 空白字符（空格、制表符等）（GNU grep） \s* \s*

实际应用示例扩展

  1. 从日志文件中提取特定日期的错误消息：

    # 搜索 2025 年 7 月 20 日发生的 ERROR 消息
grep "2025-07-20" /var/log/syslog | grep "ERROR"
# 或者使用正则表达式一次性搜索（使用 ERE）
grep -E "^2025-07-20.*ERROR" /var/log/syslog

  2. 查找特定用户（例如 'nginx'）的进程并确认 CPU/内存使用量：

    ps aux | grep "^nginx" # 查找以 nginx 开头的用户名进程
# 从 ps aux 输出中只过滤第一个字段为 'nginx' 的行
ps aux | grep -E "^nginx\s+"

  3. 在配置文件中只查看实际配置值（排除注释行和空行）：

    grep -v -E "^\s*#|^\s*$" /etc/ssh/sshd_config
# ^\s*# : 可能以空格开头的注释行
# ^\s*$ : 只有空格或完全为空的空行
# | : OR 条件
# -v : 排除上述模式

  4. 在源代码中查找函数定义（例如匹配 'function_name(' 模式）：

    grep -E -n -r "my_function\s*\(" ./src_directory/
# -n: 显示行号，-r: 搜索子目录
# \s*\( : 匹配函数名后可能有空格并紧跟左括号的模式

  5. 仅提取 IP 地址：

    grep -E -o "([0-9]{1,3}\.){3}[0-9]{1,3}" access.log
# -o: 只输出匹配的部分
# ([0-9]{1,3}\.){3} : 1~3 位数字加点号（.）重复 3 次（例如 192.168.1.）
# [0-9]{1,3} : 最后的 1~3 位数字（例如 100）

  6. 仅在特定扩展名的文件中搜索：

    grep "search_term" --include=\*.{c,h} -r ./project_dir/
# 使用 --include 仅搜索 .c 或 .h 文件
grep "api_key" --exclude-dir=node_modules -r .
# 使用 --exclude-dir 将特定目录（node_modules）排除在搜索之外

AWK 命令深度解析

awk 是一种用于模式搜索和文本/数据处理的强大编程语言。它尤其擅长处理以列（column）为基础的数据并生成报表。它拥有类似 C 语言的语法结构，支持复杂的条件处理、运算以及字符串函数等。

AWK 程序的基本结构

pattern { action }
  • pattern：决定对哪些行执行 action 的条件。省略时，对所有行执行 action。
    • 正则表达式：/regex/
    • 比较表达式：$1 == "ERROR"、$3 > 100
    • 字符串匹配：$2 ~ "pattern"（匹配）、$2 !~ "pattern"（不匹配）
    • 特殊模式：BEGIN、END
  • action：写在花括号 {} 内，由一个或多个以分号（;）分隔的 awk 命令组成。省略时，默认动作是 print $0（输出当前整行）。

特殊模式：

  • BEGIN { actions }：在读取输入文件之前执行一次，用于变量初始化、输出表头等。
  • END { actions }：在所有输入文件处理结束后执行一次，用于统计汇总、输出摘要报告等。

字段处理与分隔符

awk 会将输入行自动拆分为字段（field）。

  • $0：表示当前处理的整行。
  • $1、$2、$3 等：表示第一、第二、第三个字段。
  • 字段分隔符（Field Separator）：
    • FS（Input Field Separator）：输入字段分隔符，默认值为空白（空格、制表符）。
      • 通过命令行 -F 选项指定：awk -F, '{print $1}' data.csv（逗号分隔的 CSV 文件）
      • 在 BEGIN 块中设置：awk 'BEGIN { FS = ":" } {print $1, $7}' /etc/passwd（冒号分隔的文件）
    • OFS（Output Field Separator）：输出字段分隔符，默认值为空格。
      • 在 BEGIN 块中设置：awk 'BEGIN { OFS = "\t" } {print $1, $2}' file.txt（以制表符分隔输出）
# 从 /etc/passwd 文件中提取用户名（第一个字段）和 shell（第七个字段），以冒号为分隔符
awk -F: '{print "User:", $1, "Shell:", $7}' /etc/passwd

# 从 CSV 文件中输出第一和第三字段，以制表符分隔
awk -F, 'BEGIN{OFS="\t"} {print $1, $3}' data.csv

条件语句与模式详解

awk 可以通过多种条件与模式，对符合条件的行执行特定动作。

  • 正则表达式模式：

    # 输出包含 'error' 或 'fail'（不区分大小写）的行
/[Ee]rror|[Ff]ail/ {print $0}

    （在 shell 中执行时）

    awk '/[Ee]rror|[Ff]ail/ {print $0}' log.txt

  • 比较表达式模式：

    # 仅输出第三字段值大于 100 的行
$3 > 100 {print "Large Value Found:", $0}

    （在 shell 中执行时）

    awk '$3 > 100 {print "Large Value Found:", $0}' data.txt

    # 仅输出第一个字段恰好等于 "user_admin" 的行的第二和第四字段
$1 == "user_admin" {print $2, $4}

    （在 shell 中执行时）

    awk '$1 == "user_admin" {print $2, $4}' users.txt

  • 范围模式：对从特定起始模式到特定结束模式之间的所有行执行动作。

    # 输出从 "START_SECTION" 行到 "END_SECTION" 行之间的内容
/START_SECTION/,/END_SECTION/ {print}

    （在 shell 中执行时）

    awk '/START_SECTION/,/END_SECTION/ {print}' config.file

  • 逻辑运算符：可以使用 &&（AND）、||（OR）、!（NOT）构造复合条件。

    # 输出第一字段为 "admin" 且第四字段大于 0 的行
$1 == "admin" && $4 > 0 {print $0}

    （在 shell 中执行时）

    awk '$1 == "admin" && $4 > 0 {print $0}' access_records.txt

  • 动作内的条件语句（if-else）：

    {
    if ($3 > 1000) {
        status = "High"
    } else if ($3 > 500) {
        status = "Medium"
    } else {
        status = "Low"
    }
    print $1, $2, $3, status
}

    （在 shell 中执行时）

    awk '{
    if ($3 > 1000) {
        status = "High"
    } else if ($3 > 500) {
        status = "Medium"
    } else {
        status = "Low"
    }
    print $1, $2, $3, status
}' resource_usage.txt

主要内置变量

awk 提供了各种内置变量，以便更方便地进行编程。

变量名 说明 示例（在 shell 中执行时）
NR Number of Records。截至当前已处理的总记录（行）数。 awk '{print NR, $0}' file.txt（带行号输出）
FNR File Number of Record。当前文件内已处理的记录（行）数，处理多个文件时非常有用。 awk '{print FILENAME, FNR, $0}' file1.txt file2.txt
NF Number of Fields。当前记录（行）的字段数。 awk '{print "Line", NR, "has", NF, "fields:", $0}' file.txt
FILENAME 当前正在处理的输入文件名。 awk '/error/ {print FILENAME, ":", $0}' *.log
FS Input Field Separator。输入字段分隔符（默认：空白）。 awk -F';' '{print $1}' data.csv <br> awk 'BEGIN{FS=";"} {print $1}' data.csv
OFS Output Field Separator。输出字段分隔符（默认：空格）。 awk 'BEGIN{OFS=","} {print $1, $2}' file.txt（以逗号分隔输出）
RS Record Separator。输入记录分隔符（默认：换行符 \n）。 awk 'BEGIN{RS="\n\n"} {print $1}' paragraphs.txt（以空行分隔的段落处理）
ORS Output Record Separator。输出记录分隔符（默认：换行符 \n）。 awk 'BEGIN{ORS=";"} {print $1}' items.txt（以分号作为记录分隔输出）
ARGC Argument Count。命令行参数的数量。 awk 'BEGIN{print "ARGC:", ARGC}' file.txt
ARGV Argument Vector。保存命令行参数的数组。ARGV[0] 是 awk 本身。 awk 'BEGIN{for(i=0;i<ARGC;i++) print ARGV[i]}' file.txt
ENVIRON 可访问环境变量的关联数组。 awk 'BEGIN{print "User:", ENVIRON["USER"]}'

AWK 脚本编程：变量、数组、循环

awk 不仅能用于简单的过滤，还提供了作为脚本语言的丰富功能。

  • 变量的使用：

    # 计算第三字段的总和
{ sum += $3 } END { print "Total Sum:", sum }

    （在 shell 中执行时）

    awk '{ sum += $3 } END { print "Total Sum:", sum }' numbers.txt

  • 关联数组（Associative Arrays）：awk 的数组不仅支持数字索引，还支持字符串索引。

    # 统计第一字段（例如 IP 地址）的出现次数
{ counts[$1]++ } END { for (ip in counts) print ip, "occurred", counts[ip], "times" }

    （在 shell 中执行时）

    awk '{ counts[$1]++ } END { for (ip in counts) print ip, "occurred", counts[ip], "times" }' access.log

  • 循环（Loops）：可以使用 for 循环和 while 循环。

    # 倒序输出每行的所有字段
{
    for (i = NF; i >= 1; i--) {
        printf "%s ", $i
    }
    printf "\n" # 或 print ""
}

    （在 shell 中执行时）

    awk '{
    for (i = NF; i >= 1; i--) {
        printf "%s ", $i
    }
    printf "\n" # 或 print ""
}' data.txt

    # 从 1 到 5 输出数字（在 BEGIN 块中）
BEGIN { i=1; while(i<=5) { print i; i++ } }

    （在 shell 中执行时）

    awk 'BEGIN { i=1; while(i<=5) { print i; i++ } }'

  • 用户自定义函数（User-Defined Functions）：

    function format_size(bytes,    suffix_idx, suffixes) { # 局部变量通过附加参数声明
    suffixes = "Bytes KB MB GB TB PB"
    split(suffixes, suffix_array, " ")
    suffix_idx = 1
    while (bytes >= 1024 && suffix_idx < length(suffix_array)) {
        bytes /= 1024
        suffix_idx++
    }
    return sprintf("%.2f %s", bytes, suffix_array[suffix_idx])
}

# 将文件大小（ls -l 的第 5 字段）格式化为易读形式（NR > 1 排除表头）
# 在 shell 中执行的示例
# ls -l | awk '
# function format_size(bytes, suffix_idx, suffixes) {
#     suffixes = "Bytes KB MB GB TB PB"; split(suffixes, suffix_array, " "); suffix_idx = 1
#     while (bytes >= 1024 && suffix_idx < length(suffix_array)) { bytes /= 1024; suffix_idx++ }
#     return sprintf("%.2f %s", bytes, suffix_array[suffix_idx])
# }
# NR > 1 {print $9, format_size($5)}'

    （下面提供上面 ls -l 示例的可在 shell 中直接执行的完整形式）

    ls -l | awk '
function format_size(bytes,    suffix_idx, suffixes) {
    # 将局部变量通过额外的参数声明是一个良好的习惯。
    # 把 suffixes、suffix_idx 声明为参数，以便作为局部变量使用。
    # 调用函数时无需为这些额外参数传递实际值。
    suffixes = "Bytes KB MB GB TB PB"
    split(suffixes, suffix_array, " ")
    suffix_idx = 1
    while (bytes >= 1024 && suffix_idx < length(suffix_array)) {
        bytes /= 1024
        suffix_idx++
    }
    return sprintf("%.2f %s", bytes, suffix_array[suffix_idx])
}
NR > 1 {print $9, format_size($5)}'

实战应用示例深度解析

系统监控

  1. 查找内存使用率超过特定阈值（例如 5.0%）的进程（输出 PID、内存使用率和命令）：

    ps aux | awk 'NR > 1 && $4 > 5.0 {printf "PID: %s, %%MEM: %s, CMD: %s\n", $2, $4, $11}'
# NR > 1 : 排除表头行
# $4 > 5.0 : 第 4 字段（内存使用率）大于 5.0
# printf : 格式化输出

  2. 查找磁盘使用率超过 90% 的分区（输出文件系统、使用率、挂载点）：

    df -h | awk 'NR > 1 && int($5) > 90 {print "FS:", $1, "| Usage:", $5, "| Mounted on:", $6}'
# int($5) : 去除百分号（%）并转换为整数（在 GNU awk 中也可使用 $5+0）
# df -P | awk 'NR > 1 && $5+0 > 90 {print $1, $5, $6}' # POSIX 兼容写法，自动去除 %

  3. 查看使用特定端口（例如 80）的网络连接状态：

    netstat -tulnp | grep ":80\s" | awk '{print $4, $5, $7}'
# $4: 本地地址, $5: 远程地址, $7: PID/程序名

日志分析

  1. 从 Web 服务器日志（common log format）中提取特定时间段（例如 10 点到 11 点之间）的 404 错误日志并输出请求路径：

    # 例如：20/Jul/2025:10:00:00 到 20/Jul/2025:10:59:59
grep "20/Jul/2025:10:" access.log | awk '$9 == "404" {print $1, $4, $7, $9}'
# $1: IP, $4: 时间戳, $7: 请求路径, $9: 状态码

  2. 按 IP 地址统计访问次数并输出前 10 个 IP：

    awk '{print $1}' access.log | sort | uniq -c | sort -nr | head -n 10
# awk '{print $1}' : 仅提取第一个字段（IP 地址）
# sort : 对 IP 地址排序
# uniq -c : 去重并计数
# sort -nr : 按数字降序排序（访问最多者优先）
# head -n 10 : 仅输出前 10 个

    也可以仅通过 AWK 实现：

    awk '{ip_counts[$1]++} END {for (ip in ip_counts) print ip_counts[ip], ip}' access.log | sort -nr | head -n 10

  3. 从 SSH 登录失败日志中提取尝试过的用户名和 IP 地址：

    grep "Failed password" /var/log/auth.log | awk '{print "User:", $(NF-5), "IP:", $(NF-3)}'
# 假设日志格式为 "Failed password for invalid user admin from 1.2.3.4 port 12345 ssh2"
# $(NF-5) : 倒数第 6 个字段（用户名）
# $(NF-3) : 倒数第 4 个字段（IP 地址）
# 字段号可能因日志格式不同而变化。
# 例如：“Failed password for root from 116.37.102.13 port 40940 ssh2”
# 这种情况则为 awk '{print "User:", $9, "IP:", $11}'

数据处理与转换

  1. 从 CSV 文件中提取满足特定条件（例如第 3 列值为 "Completed"）的行，将第 1 列与第 5 列保存为新的 CSV 文件：

    awk -F, '$3 == "Completed" {print $1 "," $5}' input.csv > output.csv

    或使用 OFS：

    awk -F, 'BEGIN{OFS=","} $3 == "Completed" {print $1, $5}' input.csv > output.csv

  2. 从文本文件中提取所有邮箱地址并排序、去重（每行一个）：

    grep -E -o "\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,6}\b" file.txt | sort | uniq
# grep -o : 仅输出匹配的部分
# \b : 单词边界
# [A-Za-z0-9._%+-]+ : 用户名部分
# @ : 分隔符
# [A-Za-z0-9.-]+ : 域名部分
# \.[A-Za-z]{2,6} : 顶级域名部分（例如 .com、.co.kr）

  3. 对数字列表文件中的每个数字求平方并输出：

    # numbers.txt 内容示例：
# 1
# 5
# 10

    awk '{print $1, "squared is", $1*$1}' numbers.txt

    输出：

    # 1 squared is 1
# 5 squared is 25
# 10 squared is 100

  4. 计算多个文件中特定列的合计（例如每个文件的第 2 列之和以及总合计）：

    # data1.txt:
# itemA 10
# itemB 20
# data2.txt:
# itemC 30
# itemD 40

    使用 GNU Awk 扩展：

    awk '
    { current_sum += $2 }
    ENDFILE { # GNU Awk 扩展，每个文件处理结束后执行
        print "Sum for", FILENAME, ":", current_sum
        total_sum += current_sum
        current_sum = 0 # 为下一个文件初始化
    }
    END {
        print "Grand Total:", total_sum
    }
' data*.txt

    POSIX 兼容写法（使用 FNR）：

    awk '
    FNR == 1 && NR != 1 { # 新文件开始（排除第一个文件）
        print "Sum for", prev_filename, ":", current_sum
        total_sum += current_sum
        current_sum = 0
    }
    { current_sum += $2; prev_filename = FILENAME }
    END {
        print "Sum for", prev_filename, ":", current_sum # 最后一个文件的合计
        total_sum += current_sum
        print "Grand Total:", total_sum
    }
' data*.txt

Grep 与 AWK 的组合使用

先使用 grep 进行初步筛选，再通过管道（|）把结果交给 awk 做二次处理，是非常高效的工作流。

# 从 /var/log/secure 的 "Accepted publickey" 日志中仅提取用户名和 IP 地址
grep "Accepted publickey" /var/log/secure | awk '{print "User:", $9, "IP:", $11, "Port:", $13}'

# 在当前目录下的 C 源文件（*.c）中查找包含 "include" 单词的行，
# 并从这些行中提取文件名、行号以及 #include 后面的头文件名
grep -Hn "include" *.c | awk -F'[:<>]' '{print "File: " $1 ", Line: " $2 ", Header: " $4}'
# grep -H: 输出文件名，-n: 输出行号
# awk -F'[:<>]': 使用冒号（:）、左尖括号（<）、右尖括号（>）作为分隔符
# 例如：main.c:10:#include <stdio.h> -> $1=main.c, $2=10, $3=#include , $4=stdio.h

结语

grep 与 awk 在 Linux/Unix 环境下的文本处理中如同瑞士军刀般不可或缺。grep 凭借强大的模式搜索能力可以快速找到所需信息，而 awk 则专精于结构化数据处理和生成报表。深入理解这两种工具的各种选项、正则表达式以及 awk 的编程功能，并加以组合使用，即便面对复杂且海量的文本数据，也能轻松将其加工为所需形式并进行分析。

当然，对于非常复杂的逻辑或大规模数据处理，Python、Perl 等通用脚本语言可能更为合适；但是，对于大多数日常的系统管理、日志分析和简单的数据转换工作，仅凭 grep 和 awk 就足以高效完成。持续练习并将其应用到各种实际问题中，是掌握这些工具的最佳方法。
