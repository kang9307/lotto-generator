适用范围与免责。本文讲的是大韩民国税制，以适用于韩国居民为前提。内容仅供参考，不构成税务意见。税法会修订，同一制度下的适用也会因个人的居民身份、持有结构以及与其他所得的关系而不同。个案判断与实际申报，务必向韩国国税厅或税务专业人士确认。正文中所有交易记录与金额均为为展示计算结构而构造的假设数据，并非真实账户或特定个人的交易。本文不推荐任何券商、计算器服务或税务事务所。

引言：计算器给你答案，却不告诉你前提

卖掉了海外股票，想知道该缴多少税。一搜就能找到好几个计算器。填入买入金额和卖出金额，税额就出来了。到这一步看起来毫无问题。

问题在于同一份交易记录在不同工具里可能得出不同数字。而大多数计算器不会解释这个数字是怎么来的。输入框只有两三个，但计算真正需要作出的决定远不止这些。剩下的那些，都是工具替你定好的前提。

本文的论点不是「别用计算器」，而是如果不知道计算器假设了什么，你就没有理由相信它给出的数字。所以本文不替你算税，而是让你把计算结构亲手走一遍。懂了结构，结果不对劲时你能察觉，也知道该去问谁。

先把结论摆出来。针对后文构造的一份假设交易记录，只把前提改成三种后算出的税额是这样的。

  • 按先买入的先卖出处理，每批买入各用其成交时点汇率换算，得637,995韩元
  • 用全部买入的韩元加权平均单价作为取得成本，得678,095韩元
  • 先算外币口径损益，再按卖出日汇率一次性换算，得441,505韩元

交易记录一个字都没改。变的只是前提，而最大值是最小值的1.536倍，差额为236,590韩元。

2. 到底对什么征税 - 先看结构

韩国国税厅公布的股票等转让所得税计算结构是下面这个顺序。这个流程本身是已确认的。

  1. 转让价额 — 卖出的金额
  2. 减 必要费用 — 取得成本 + 转让费用
  3. = 转让差益（所得额）
  4. 减 基本扣除 — 按国税厅指引，境内外股票合并每年250万韩元
  5. = 应税所得额
  6. × 税率
  7. = 应纳税额
  8. 减 抵免与减免税额 = 确定税额

从中可以直接读出几个性质。

  • 征税对象是「差益」，不是「卖出金额」。卖了1亿韩元，但当初是9,900万韩元买的，差益就是100万韩元
  • 基本扣除按年计。不是按标的，而是从整个纳税期间合并后的所得额里一次性扣掉
  • 差益小于基本扣除时应税所得额为0。后面的计算会真的走进这个区间
  • 税率乘的是应税所得额，不是转让差益，即扣除之后的金额。把顺序颠倒过来，税就算多了
  • 必要费用分两块。买入付出的（取得成本）和卖出花掉的（转让费用）分别进入

结构就这么简单。麻烦的是生成填入这个公式的数值的过程，因为海外股票是用外币交易的。要填进以韩元记账的申报表，就必须在某处做换算，而从那一刻起就出现了选择。

3. 汇率至少出现三次

海外股票的计算与境内股票的决定性差异就在这里。同样的美元金额，用哪一天的汇率，换出来的韩元金额就不一样。而且汇率不止出现一次。

出现的位置换算什么在此分岔的选择影响
① 买入时点支出的外币 → 韩元取得成本成交日还是结算日。是否逐笔单独换算取得成本变大则差益变小，税也变少
② 卖出时点收到的外币 → 韩元转让价额同样的问题。以及是否与买入采用同一口径转让价额变大则差益变大，税也变多
③ 申报时点确定申报表上填写的韩元金额用①②各自换算后的值，还是先算外币损益再一次性换算仅这一个选择就能整体改变应税所得额

第三处最重要，也最常被误解。比较两条计算路径。

  • 路径1 — 各自换算后相减。用买入时点汇率造出韩元取得成本，用卖出时点汇率造出韩元转让价额，然后韩元对韩元相减。此时持有期间的汇率变动会原封不动地反映进差益
  • 路径2 — 先用外币相减再换算。先算出美元口径的损益，只把这笔损益换算一次。此时汇率变动只乘在损益上，本金部分的汇兑差从计算中消失了
  • 两条路径只有在汇率完全没动时才给出相同的值。汇率一动，必然分岔
  • 即便股价按美元口径原地不动，在路径1下只要汇率上行，就会产生韩元口径的差益。这是海外股票税务中最常见的意外
  • 反过来，美元上赚了钱但汇率大幅下行时，路径1下的差益可能缩水甚至消失

标记为需确认的项目。究竟哪条路径才是实际适用的方式，以及基准日是成交日还是结算日，本文不写成定论。因为没能打开法条原文页面。确认路径有两条：在韩国国家法令信息中心直接查阅所得税法相关条文，或把自己的交易形态提交给韩国国税厅咨询渠道去问。下面的计算不是在主张哪一条正确，而是要显示两种方式的结果差距有多大。

4. 取得成本怎么定 - 当你分多次买入时

一次买入、一次卖光的话没什么可纠结的。但现实中分多次买入、只卖出一部分是常态。这时必须先确定卖掉的股票算是哪一批买入的，才能得出取得成本。

有两种代表性方法。

  • 先进先出。把先买入的视为先卖出。由于各批买入的时点不同，实际上就会逐批使用其各自时点的汇率
  • 移动平均（加权平均）。算出全部买入的平均单价，再乘以卖出数量。平均是按美元算还是按韩元算，又是一个岔口

两种方法也会让剩余持仓的取得成本不同。也就是说，变的不只是今年的税，将来卖出剩余部分时的税同样会变。只盯着一年做比较，这一层是看不见的。

究竟适用哪种方法，本文未能从一手来源确定。所以不下断言，而是只用计算展示方法确实会改变结果。仅此一点，实务含义就已经足够：不公开自身方法的工具，其结果无法验证。

5. 损益通算的范围到哪里

这里有确认到的内容。在韩国国税厅指引页面上直接确认到的范围如下。

  • 允许境内股票与境外股票之间损益通算。适用时点为2020年1月1日以后的转让
  • 基本扣除为境内外股票合并每年250万韩元。不是境内一份250万、境外再一份250万
  • 重要的限定条件。同一份指引附有「不属于股票转让所得税征税对象的境内股票，不能与境外股票损益通算」这一条件

第三条正是计算器容易漏掉的地方。并非所有境内股票都能纳入通算。必须先判定该境内股票本身是否属于转让所得税征税范围，而这一判定取决于持股比例、标的性质等条件，是个人很难独自拿准的领域。

  • 如果只是把「境内亏损○○韩元」随手填进计算器，该工具不可能替你判定过是否属于征税对象，它只是原样相信了你的输入
  • 把不能通算的亏损通算了，应税所得额就会比实际偏小，这个结果会在申报环节出问题
  • 反过来，漏掉了本可通算的亏损，就会多缴税
  • 亏损卖出本身在何时、如何进行属于策略层面，不在本文范围内。该主题在亏损卖出与税务抵销的结构中另行讨论
  • 通算与否若不明确，向韩国国税厅确认最为稳妥。这不是个人凭感觉可以下的判断

5.1 通过基金持有的海外股票不在本文范围内

整理一个容易混淆的边界。直接买卖海外股票与通过海外基金间接持有，二者的课税体系不同。

  • 本文处理的是直接投资的转让所得，即在本人账户中买卖标的的情形
  • 通过基金的间接投资按股息所得体系处理，计算结构本身就不一样。那一侧已在海外基金投资与税制中单独整理，此处不再重复
  • 同样一句「投资了海外股票」，装在哪个容器里，适用的规定就不同。挑选计算器时，先把这一点对上

读法是这样的。第一段是把每笔交易按其时点的假设汇率换算成韩元。2月的买入是100股乘100美元再加25美元手续费，共10,025美元，乘以1,300得到13,032,500韩元。

第二段是按先进先出造出卖掉的150股的取得成本的过程。先买的2月那批100股全部出清，缺的50股从4月那批里补。4月的30美元手续费中只分摊了一半即15美元，因为100股里只出去了50股。两行相加得21,152,750韩元。

7. 分步税额计算与验算

现在把这些值填进前面的计算结构。所有中间数字一个不藏，全部摊开。计算器不给你看的，正是这些格子。

STEP BY STEP  (method A)

  1  proceeds       150 sh x USD 130.00 x 1380.00       = KRW 26,910,000
  2  selling cost   USD 48.75 x 1380.00                 = KRW 67,275
  3  acquisition    see lot table above                 = KRW 21,152,750
  4  gain           step1 - step2 - step3               = KRW 5,689,975
  5  deduction      assumed annual basic deduction      = KRW 2,500,000
  6  tax base       step4 - step5, floored at zero      = KRW 3,189,975
  7  tax            step6 x 20 percent                  = KRW 637,995
     local income tax is a separate item, excluded here

SAME TRADES, THREE ASSUMPTIONS

  method                        acquisition       gain    tax base        tax
  ------------------------------------------------------------------------
  A. FIFO, per-lot fx            21,152,750  5,689,975   3,189,975    637,995
  B. moving average in KRW       20,952,250  5,890,475   3,390,475    678,095
  C. net USD first, one fx       22,135,200  4,707,525   2,207,525    441,505

  spread between highest and lowest tax : KRW 236,590
  highest is 1.536 times the lowest
  the trades never changed. only the assumptions did.

RECHECK  (method A recomputed from scratch, different arithmetic path)
  lot 1  (100 x 100.00 + 25.00) x 1300.00 = 13,032,500
  lot 2  ( 50 x 120.00 + 15.00) x 1350.00 = 8,120,250
  cost   = 21,152,750   matches method A : true
  gain   = 5,689,975   matches method A : true
  tax    = 637,995   matches method A : true

逐步来看，每一行都对应前一节计算结构中的某一步。

  • 第1步 转让价额。150股乘130美元为19,500美元，乘以假设汇率1,380得26,910,000韩元
  • 第2步 转让费用。卖出手续费48.75美元按同一汇率折算为67,275韩元
  • 第3步 取得成本。前面造出的21,152,750韩元
  • 第4步 转让差益。26,910,000 − 67,275 − 21,152,750 = 5,689,975韩元
  • 第5步 基本扣除。按国税厅指引为250万韩元。此处假设当年没有其他股票转让，故全额适用
  • 第6步 应税所得额。5,689,975 − 2,500,000 = 3,189,975韩元。为负则视为0
  • 第7步 应纳税额。3,189,975的20%即637,995韩元

验算段是用另一条算术路径把同样的值再求了一遍。程序用循环得出的值，与把公式直接展开写出来的值，三个项目全部一致。没有这道确认，就没有办法筛掉计算本身的错误。

这次计算里塞进去的前提清单。① 适用20%税率 ② 250万韩元基本扣除可全额使用 ③ 当年没有其他股票转让 ④ 交易手续费全额被认定为必要费用 ⑤ 汇率是任意设定的数值 ⑥ 排除地方所得税 ⑦ 未反映按元截尾等舍入规则 ⑧ 假设满足居民要件。八项里只有第②项是从原文确定下来的。这意味着计算器悄悄替你定好的格子有这么多。

7.1 三个前提造成的差距

再看一遍对比表。相同的交易，不同的前提。

  • A（先进先出、逐笔汇率）取得成本21,152,750韩元 → 税额637,995韩元
  • B（韩元加权平均）取得成本20,952,250韩元 → 税额678,095韩元。90美元买入的低价那批混进平均里，把取得成本拉低了，差益相应变大
  • C（先算外币损益，只换算一次）取得成本22,135,200韩元 → 税额441,505韩元。持有期间的汇率上行从计算中脱落，差益在三者中最小
  • A与B相差40,100韩元，A与C相差196,490韩元。汇率处理方式造成的差距，远大于取得成本算法造成的差距
  • 买入次数越多、持有期越长，且期间汇率波动越大，这个差距还会进一步拉开

  • 汇率从1,250韩元到1,470韩元，上涨17.6%。而税额增加了647%
  • 之所以被放大，是因为250万韩元的基本扣除是固定金额。当差益落在扣除额附近时，稍微增加一点，应税所得额就会成倍跳涨

9. 手续费与各项费用 - 必要费用的边界

计算结构里确认到的，只到必要费用由「取得成本 + 转让费用」构成这一层。具体某个项目该归入哪一边，以及什么能扣、什么不能扣，未能从一手来源确定。

不过从结构上可以明确的东西还是有的。

  • 必要费用变大，转让差益就变小。也就是说，漏掉费用就会多缴税
  • 上面的假设计算中，买入手续费加进了取得成本，卖出手续费作为转让费用扣除。这是为了做算例而采取的处理，并非对可扣范围下的断言
  • 买入手续费在部分卖出时需要分摊。前面计算中4月买入手续费30美元只体现了15美元，就是这个处理
  • 手续费若是用外币支付的，本身也是换算对象。也就是说第3节的汇率问题同样适用于手续费
  • 实务中常被提及的项目包括买卖手续费、当地交易税或印花税性质的费用、换汇过程中产生的费用等，但各自能否扣除需向韩国国税厅确认
  • 要主张费用，凭证必须留存。最好事先确认券商的交易明细里这些项目是否分开列示

注意。本节的目的不是教人如何做大费用以减税。什么能算必要费用是由规定决定的，不是可选项。本节的目的是让你去确认计算器的输入框里到底有没有手续费这一项，如果有，它把这笔钱送进了取得成本还是转让费用。

11. 股息所得完全是另一条轨道

持有海外股票可能产生两类课税事由。把这两者混在一起，计算从一开始就错了。

  • 转让所得。卖出时产生，本文讲的全部都是它。对差益课税，并且有基本扣除和损益通算这两个装置
  • 股息所得。持有期间收到分红时产生。计算结构根本不同。基准是收到的金额而非差益，而且转让所得的250万韩元基本扣除在这里不适用
  • 两者互不通算。分红拿得多不会让转让差益变小，出了转让亏损也不会让股息税变少
  • 需确认。股息所得的预扣税率、金融所得合并计税的门槛、境外已缴税款的处理方式，本文未能从一手来源确认，因此不写数值
  • 不过有一点结构性认知值得记住。境外派发分红时，有可能是在当地已经扣过税之后才入账的。这种情况在韩国境内如何处理会成为另一个议题，所以需要确认分红入账明细里是否区分了税前与税后金额
  • 不要把分红金额填进转让税计算器，反之亦然。挑选工具时，先确认它是为哪一类所得而做的

常见问题

海外股票转让所得税按什么顺序计算

韩国国税厅公布的计算结构是转让价额 − 必要费用（取得成本 + 转让费用）= 转让差益 − 基本扣除 = 应税所得额 × 税率 = 应纳税额 − 抵免减免 = 确定税额。按国税厅指引，基本扣除为境内外股票合并每年250万韩元。结构虽简单，但生成填入公式的数值的过程里藏着好几个前提。个案需向韩国国税厅或税务专业人士确认。

汇率该用买入日的还是卖出日的

本文不把这个答案写成定论，因为没能打开法条原文页面。已确认的是汇率会在买入、卖出、申报三个位置出现，并且逐笔换算与先算损益再一次性换算这两种做法，在假设计算中造成了将近20万韩元的差距。实际口径请向韩国国税厅或国家法令信息中心确认。

分多次买入后只卖出一部分时取得成本怎么定

这一项同样未能从一手来源确定。在假设计算中，先进先出法得出取得成本21,152,750韩元，韩元加权平均法得出20,952,250韩元，反映到税额上是40,100韩元的差距。买入次数、持有期与汇率波动幅度越大，差距越宽。适用方法需向韩国国税厅确认。

韩国境内股票的亏损能和海外股票的收益合并吗

在韩国国税厅指引中确认到的范围是允许境内外股票损益通算，适用于2020年1月1日以后的转让。但附有「不属于股票转让所得税征税对象的境内股票不能与境外股票通算」这一限定条件。既然并非所有境内股票都能通算，向韩国国税厅确认自己的标的是否属于征税对象才稳妥。

这是在说不要用计算器吗

不是。是说要让自己处在能验证结果的状态。至少不公开汇率适用时点、取得成本分摊方法、通算与扣除处理这三点的工具，其结果只能算参考值。同一份假设交易记录只改前提时，税额拉开了1.536倍。把结构走一遍，就能分清哪一格是事实、哪一格是选择。

## 10. 不要混淆

- 转让所得与股息所得是**两条轨道**，互不通算
- 250万韩元基本扣除是**转让所得**的装置，不适用于股息所得
- 直接投资（转让所得）与通过基金持有（股息所得）**适用规定不同**
- 基本扣除不按标的计，而是从**整个纳税期间合并的所得额**里扣一次
- 税率乘的不是转让差益，而是**扣除之后的应税所得额**
- 征税对象不是卖出金额，而是**差益**

## 11. 不要这么做

- 照搬没有出处和基准时点的税率、扣除数字
- 不加验证就把计算器结果抄进申报表
- 把本文档的假设金额当作自己的税额使用
- 把分红金额输入转让税工具
- 自行断定通算是否可行
- 不看查阅时点就使用过时资料里的数字
