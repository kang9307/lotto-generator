🐧 Preparing the Operating System

Step 1: Install the Operating System

Install one of the supported operating systems:

  • Ubuntu 20.04 LTS / 22.04 LTS
  • CentOS 8 / Rocky Linux 8
  • Red Hat Enterprise Linux 8/9

Step 2: Set the Hostname

# Set hostname on each node
sudo hostnamectl set-hostname ceph-node01
sudo hostnamectl set-hostname ceph-node02
sudo hostnamectl set-hostname ceph-node03

# Edit /etc/hosts on every node
sudo cat >> /etc/hosts << EOF
192.168.1.10 ceph-node01
192.168.1.11 ceph-node02
192.168.1.12 ceph-node03
EOF

Step 3: Configure the Firewall

# Ubuntu/Debian
sudo ufw allow 6789/tcp
sudo ufw allow 6800:7300/tcp
sudo ufw allow 3300/tcp

# CentOS/RHEL
sudo firewall-cmd --permanent --add-port=6789/tcp
sudo firewall-cmd --permanent --add-port=6800-7300/tcp
sudo firewall-cmd --permanent --add-port=3300/tcp
sudo firewall-cmd --reload

🔧 Installing Ceph

Step 4: Add the Ceph Repository

# Ubuntu/Debian
curl -fsSL https://download.ceph.com/keys/release.asc | sudo apt-key add -
echo "deb https://download.ceph.com/debian-squid/ $(lsb_release -sc) main" | sudo tee /etc/apt/sources.list.d/ceph.list
sudo apt update

# CentOS/RHEL
sudo dnf install -y centos-release-ceph-squid
sudo dnf update

Step 5: Install cephadm

# Ubuntu/Debian
sudo apt install -y cephadm

# CentOS/RHEL
sudo dnf install -y cephadm

# Verify the installation
cephadm version
⚠️ Caution: All nodes must install the same Ceph version. A version mismatch can cause cluster problems.

🚀 Bootstrapping the Cluster

Step 6: Initialize the Cluster on the First Node

# Run this on the first node
sudo cephadm bootstrap --mon-ip 192.168.1.10 --initial-dashboard-user admin --initial-dashboard-password [YOUR_SECURE_PASSWORD]

# Sample output:
# Ceph Dashboard is now available at:
#      URL: https://ceph-node01:8443/
#      User: admin
#      Password: [YOUR_SECURE_PASSWORD]

Step 7: Install the Ceph CLI

# On the first node
sudo cephadm install ceph-common

# Check cluster status
sudo ceph -s

📡 Adding More Nodes

Step 8: Copy the SSH Key

# Generate a key on the first node
ssh-keygen -t rsa -b 4096 -f ~/.ssh/id_rsa -N ""

# Copy it to the other nodes
ssh-copy-id root@ceph-node02
ssh-copy-id root@ceph-node03

Step 9: Add the Nodes

# Add the second and third nodes
sudo ceph orch host add ceph-node02 192.168.1.11
sudo ceph orch host add ceph-node03 192.168.1.12

# Verify the host list
sudo ceph orch host ls

💽 Creating OSDs

Step 10: List Available Disks

# Show available disks
sudo ceph orch device ls

# Sample output:
# HOST        PATH      TYPE  SIZE  DEVICE_ID  MODEL        VENDOR
# ceph-node01 /dev/sdb  hdd   1.0T  WD1003FZEX  WD1003FZEX   ATA
# ceph-node01 /dev/sdc  hdd   1.0T  WD1003FZEX  WD1003FZEX   ATA

Step 11: Create OSDs

# Automatically create OSDs on every available disk
sudo ceph orch apply osd --all-available-devices

# Or create OSDs on specific disks
sudo ceph orch daemon add osd ceph-node01:/dev/sdb
sudo ceph orch daemon add osd ceph-node01:/dev/sdc

# Verify OSD status
sudo ceph osd tree

🔍 Configuring Monitors and Managers

Step 12: Deploy Additional Monitors

# Deploy monitors to three nodes
sudo ceph orch apply mon --placement="3 ceph-node01,ceph-node02,ceph-node03"

# Check monitor status
sudo ceph mon stat

Step 13: Configure Managers

# Deploy managers on two nodes (HA configuration)
sudo ceph orch apply mgr --placement="2 ceph-node01,ceph-node02"

# Check manager status
sudo ceph mgr stat

🌐 Configuring the Dashboard

Step 14: Enable the Dashboard Module

# Enable the dashboard module
sudo ceph mgr module enable dashboard

# Generate a self-signed SSL certificate for the dashboard
sudo ceph dashboard create-self-signed-cert

# Create a dashboard user
sudo ceph dashboard ac-user-create admin -i password.txt administrator

Step 15: Access the Dashboard

# Check the dashboard URL
sudo ceph mgr services

# Open in your browser:
# https://ceph-node01:8443/
# User: admin
# Password: (the password you set)

🧪 Testing the Cluster

Step 16: Verify Cluster Health

# Overall cluster status
sudo ceph -s

# Detailed health information
sudo ceph health detail

# OSD status
sudo ceph osd stat
sudo ceph osd tree

# Monitor status
sudo ceph mon stat
sudo ceph quorum_status

Step 17: Create a Pool and Run a Test

# Create a test pool
sudo ceph osd pool create test-pool 32 32

# Write an object to the pool
echo "Hello Ceph!" | sudo rados put hello-object -p test-pool

# Read the object back
sudo rados get hello-object -p test-pool -

# Delete the pool when done testing
sudo ceph osd pool delete test-pool test-pool --yes-i-really-really-mean-it

🎯 Creating Baseline Pools

Step 18: Create the RBD Pool

# Create the RBD pool
sudo ceph osd pool create rbd 32 32
sudo ceph osd pool application enable rbd rbd
sudo rbd pool init rbd

# Create a test image
sudo rbd create --size 1024 rbd/test-image

# List images
sudo rbd ls rbd

Step 19: Set Up CephFS (Optional)

# Create CephFS pools
sudo ceph osd pool create cephfs-data 64 64
sudo ceph osd pool create cephfs-metadata 32 32

# Create the file system
sudo ceph fs new cephfs cephfs-metadata cephfs-data

# Deploy MDSs
sudo ceph orch apply mds cephfs --placement="2 ceph-node01,ceph-node02"

# Check file system status
sudo ceph fs status

📊 Performance and Health Monitoring

✅ Post-Install Checklist:
  • All nodes are connected to the cluster
  • All OSDs are in the up and in state
  • Monitor quorum has been established
  • The dashboard is reachable
  • Test pool creation and deletion both succeed

🔍 Ongoing Monitoring Commands

# Live cluster status monitoring
sudo ceph -w

# View performance statistics
sudo ceph osd perf
sudo ceph pg dump | grep -v "active+clean"

# View capacity usage
sudo ceph df
sudo ceph osd df

🛠️ Troubleshooting Guide

⚠️ Common Issues and Resolutions

  • Cluster status is HEALTH_WARN: Run ceph health detail for specifics
  • An OSD is down: Check the disk and network on that node
  • Monitor quorum problems: Verify inter-monitor networking and time synchronization
  • Abnormal PG states: Wait for automatic PG recovery or perform recovery manually

🔧 Useful Debugging Commands

# Check logs
sudo cephadm logs -f

# Restart a service
sudo systemctl restart ceph-osd@0

# Inspect configuration
sudo ceph config dump

Your Ceph cluster installation is complete! You now have a stable, scalable distributed storage system ready to run. Keep the cluster safe by monitoring and backing it up regularly.
