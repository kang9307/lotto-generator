1. 2026년 9월 22일 샤오미 MiMo-V2.6 시리즈 공개와 배경

샤오미 공식 개발자 업데이트 문서(mimo.mi.com)에 따르면, 2026년 9월 22일 샤오미는 대규모 멀티모달 파운데이션 인공지능 모델 제품군인 「MiMo-V2.6 Series」를 공식 공개했다. 이번 릴리스는 텍스트 처리에 국한되었던 전통적 거대언어모델의 범위를 확장하여 시각과 청각을 아우르는 복합 모달리티 처리 역량을 오픈소스 생태계에 제공하는 것을 핵심 지향점으로 삼고 있다.

원문은 이번 모델 제품군이 텍스트, 이미지, 영상, 오디오를 통합적으로 이해하며 복합적인 프로그래밍 코딩 작업, 외부 API 도구 호출, 컴퓨터 인터페이스 직접 조작 등을 수행할 수 있도록 엔드투엔드 파이프라인으로 훈련되었다고 명시한다. 특히 상용 서비스 환경에 대응하기 위해 고성능 플래그십 모델인 MiMo-V2.6-Pro와 비용 효율성을 지향하는 Flash 버전으로 세분화하여 선보였다.

인공지능 연구 커뮤니티에서 이번 발표가 큰 주목을 받은 이유는 단순히 거대한 매개변수 규모 때문만이 아니다. 모델의 가중치를 오픈소스 라이선스인 MIT 라이선스로 배포함과 동시에, 그동안 세부 사항이 베일에 싸여 있던 사후 훈련(Post-training) 단계의 강화학습(Reinforcement Learning, RL) 알고리즘 구성과 정책 개선 기법을 상세히 기술한 모델 카드를 함께 공개했기 때문이다.

일반적으로 최신 파운데이션 모델들은 사전 훈련(Pre-training) 규모를 키우는 방식에서 사후 정렬 및 추론 역량을 강화하는 강화학습 중심 체계로 무게중심을 이동하고 있다. 샤오미가 공개한 이번 모델 역시 단순한 지도 미세조정(SFT) 수준에 머무르지 않고, 복잡한 다중 에이전트 추론 환경에서 스스로 해법을 검증하고 궤적을 수정하는 4가지 강화학습 메커니즘을 전면에 내세웠다.

  • 공식 공개 시점: 2026년 9월 22일 공식 모델 업데이트 공지를 통해 발표됨
  • 제품군 라인업: 고성능 중심의 MiMo-V2.6-Pro 및 비용 효율 지향의 Flash 모델 구성

2. MiMo-V2.6-Pro 핵심 아키텍처와 기본 사양

Hugging Face 공식 저장소(XiaomiMiMo/MiMo-V2.6-Pro-RL)에 등재된 모델 카드 명세에 따르면, 플래그십 모델인 MiMo-V2.6-Pro는 희소 전문가 혼합(Sparse Mixture-of-Experts, Sparse MoE) 아키텍처를 기반으로 설계되었다. 총 파라미터는 1조 200억 개(1.02T, 1.02 Trillion) 규모이며, 단일 연산 패스에서 실제로 라우팅되어 활성화되는 파라미터는 420억 개(42B, 42 Billion) 수준으로 제어된다.

이러한 희소 MoE 설계는 전체 매개변수가 보유한 지식 표현력을 극대화하면서도, 매 토큰을 생성할 때 투입되는 부동소수점 연산량(FLOPs)을 조 단위 모델 대비 획기적으로 낮추는 전형적인 구조적 선택이다. 활성 파라미터가 42B 수준으로 유지됨에 따라, 단일 추론 노드에서 요구되는 메모리 대역폭과 연산 지연 시간을 실무 서빙 허용 범위 내로 억제할 수 있게 된다.

컨텍스트 윈도우(Context Window)는 최대 100만(1M) 토큰을 지원한다. 장문 컨텍스트 처리는 장시간 녹화된 비디오 파일의 프레임 시퀀스 분석, 고음질 장시간 오디오 트랙의 연속 청취, 방대한 소스코드 레포지토리 전반을 아우르는 크로스 파일 분석 작업에서 필수적인 선결 조건이다. MiMo-V2.6-Pro는 이러한 1M 토큰의 맥락을 단일 프롬프트 인터페이스에서 직접 수용한다.

모달리티 지원 측면에서는 텍스트, 이미지, 비디오, 오디오의 4개 도메인을 네이티브 수준으로 통합 수용한다. 별도의 독립형 인코더 파이프라인을 사후 결합하는 형태를 넘어, 멀티모달 입력 토큰이 트랜스포머 백본 내부에서 직접 교차 주의집중(Cross-attention)을 형성하도록 유기적으로 설계되었다.

  • 희소 라우팅 메커니즘: 1.02T 총 파라미터 중 42B 활성 파라미터만 선별 연산
  • 대규모 컨텍스트 확장: 최대 100만 토큰에 이르는 단일 문맥 메모리 공간 확보
  • 통합 모달리티 백본: 텍스트·이미지·영상·오디오를 아우르는 다중 감각 입력 처리
  • 개방형 생태계 라이선스: 상용 제약 없는 완전한 MIT 라이선스 기반 배포

3. 4대 강화학습(RL) 기법 — GRPO와 GRS의 구조

샤오미 MiMo-V2.6의 기술적 차별성을 규정짓는 핵심 축은 사후 훈련 파이프라인에 배치된 4대 강화학습 알고리즘이다. 공식 모델 카드에 기재된 원문 정의에 따르면, 연구팀은 대규모 정책 최적화와 안정적인 보상 형성을 위해 Group Relative Policy Optimization(GRPO)과 Groupwise Reward Synthesis(GRS)를 전면 배치했다.

첫 번째 기법인 GRPO는 단일 프롬프트에 대한 무작위 탐색을 대규모 그룹 단위로 묶어 비동기적으로 정책을 갱신하는 기법이다. 원문은 GRPO를 「1,568 프롬프트 × 16 롤아웃 비동기 대규모 배치(Asynchronous large batch with 1,568 prompts × 16 rollouts)」로 명시하고 있다. 프롬프트 하나당 16개의 독립된 탐색 궤적을 병렬로 생성하고, 총 1,568개의 프롬프트를 한데 묶어 대규모 그룹 단위의 상대적 비교를 수행한다.

일반적으로 강화학습에서 개별 궤적에 절대적인 보상 점수를 부여하는 방식은 보상 모델의 편향이나 스케일 변동에 극도로 취약하다. GRPO는 동일한 입력 프롬프트에서 도출된 16개의 출력 결과 간의 상대적 우열을 그룹 정규화(Group Normalization) 형태로 계산함으로써, 외부 비평자(Critic) 모델의 파라미터 오버헤드 없이도 안정적인 정책 그래디언트를 도출하도록 돕는다.

두 번째 기법인 GRS(Groupwise Reward Synthesis)는 보상 모델의 일반화 한계를 보완하기 위해 도입되었다. 원문은 GRS를 「대비되는 롤아웃으로 작업별 평가 기준 구축(Constructing task-specific evaluation criteria through contrasting rollouts)」으로 정의한다. 정형화된 단일 채점 함수에 의존하지 않고, 모델이 생성해 낸 다양한 성공과 실패 궤적들을 대조 분석하여 해당 작업의 맥락에 최적화된 동적 평가 잣대를 합성해 낸다.

이 글의 해석으로는, GRPO와 GRS의 결합은 사전에 정의하기 어려운 고난도 멀티모달 추론 태스크에서 자율적인 검증 체계를 확립하기 위한 시도로 분석된다. 1,568개에 달하는 거대 배치에서 쏟아지는 수만 개의 대조군 궤적을 바탕으로 보상 기준을 스스로 합성함으로써 보상 해킹(Reward Hacking) 가능성을 원천적으로 희석시킨다.

  • GRPO 비동기 배치 규모: 1,568개 입력 프롬프트와 프롬프트당 16개 롤아웃 연계
  • 상대적 정책 평가: 절대 점수 추정 대신 그룹 내부의 상대적 우위를 기준으로 그래디언트 산출
  • GRS 동적 기준 수립: 성공 궤적과 실패 궤적의 대비를 통해 작업별 맞춤 채점 기준 합성
  • 보상 왜곡 방지: 정적 보상 모델이 유발하는 점수 조작 및 비정상적 패턴 고착 방지

4. GAR과 MOPD2를 통한 정책 개선과 교사 증류

MiMo-V2.6 사후 훈련 파이프라인의 후반부를 지탱하는 알고리즘은 Groupwise Advantage Redistribution(GAR)과 Multi-Prefix Multi-Teacher On-Policy Distillation(MOPD2)이다. 이 두 기법은 탐색 과정에서 확보된 유효 궤적의 품질을 차등화하고, 다중 교사 모델의 지식을 손실 없이 이식하는 역할을 맡는다.

세 번째 기법인 GAR(Groupwise Advantage Redistribution)은 원문에서 「통과한 궤적 순위 매김 후 품질 높은 솔루션으로 이점 이동(Ranking passed trajectories and shifting advantage toward higher-quality solutions)」으로 명시되어 있다. 이진화된 정답 여부(Pass/Fail)만을 기준으로 삼을 경우, 정답을 맞혔더라도 불필요하게 복잡하거나 비효율적인 우회 경로를 거친 궤적에도 동일한 보상이 주어지는 결함이 발생한다.

GAR은 테스트를 통과한 모든 유효 궤적에 대해 2차 순위 평가를 수행한다. 논리 전개의 간결성, 추론 단계의 엄밀성, 토큰 소모의 경제성을 종합하여 상위 궤적으로 판정된 솔루션에 어드밴티지(Advantage) 가중치를 집중적으로 재분배한다. 이를 통해 모델은 정답을 도출하는 것에 안주하지 않고, 가장 우아하고 직관적인 풀이 경로를 우선적으로 강화하게 된다.

네 번째 기법인 MOPD2(Multi-Prefix Multi-Teacher On-Policy Distillation)는 지식 증류의 안정성을 비약적으로 끌어올리는 기법이다. 원문은 이를 「자율 학생 롤아웃 + 교사 접두사 결합(Combining autonomous student rollouts with teacher prefixes)」으로 정의한다. 기존의 지식 증류가 고정된 교사 모델의 출력 분포를 학생 모델이 수동적으로 모방하는 방식이었다면, MOPD2는 학생 모델의 온폴리시(On-policy) 생성 과정에 교사의 안내를 동적으로 주입한다.

이 방식에서는 학생 모델이 자율적으로 롤아웃을 수행하다가 복잡한 분기점에 도달했을 때 다중 교사 모델이 제공하는 가이드 접두사(Prefix)를 결합하여 탐색을 이어간다. 이는 모델이 자신이 밟아보지 않은 낯선 궤적의 분포를 외우는 대신, 실제 생성 경로 위에서 오류를 즉각 교정하고 최적 경로를 체득하도록 유도하는 진화된 증류 기법이다.

  • 통과 궤적의 품질 차등화: 단순 성공 여부를 넘어 솔루션의 정밀도와 간결성을 기준으로 순위 산정
  • 어드밴티지 재분배 메커니즘: 상위 품질 궤적에 학습 이점을 몰아주어 고품질 추론 패턴 유도
  • 온폴리시 증류의 진화: 학생 모델의 실제 생성 흐름 속에서 다중 교사의 안내 접두사 유기적 결합
  • 분포 불일치 해소: 전통적 오프폴리시 지식 증류에서 발생하던 교사-학생 간 정책 분포 괴리 극복

5. 자기개선 루프의 지향점 — 추론 경로 단축과 토큰 효율성

Hugging Face 모델 카드에 명시된 MiMo-V2.6 강화학습 체계의 궁극적인 설계 목표는 매우 명확하다. 원문은 RL 최적화의 지향점을 「자기개선 루프를 통해 더 짧은 경로와 작업당 더 적은 토큰으로 유도(Guiding through a self-improvement loop toward shorter paths and fewer tokens per task)」하는 데 두었다고 직접 적고 있다.

일반적으로 추론 특화형 모델(Reasoning Model)들은 사유 연쇄(Chain-of-Thought)를 길게 늘어뜨릴수록 벤치마크 점수가 상승하는 경향을 보인다. 그러나 실무 서비스 관점에서 무분별하게 길어지는 사고 과정은 치명적인 시스템 오버헤드를 유발한다. 단일 질문에 응답하기 위해 수천 개의 불필요한 추론 토큰을 소모하면 응답 대기 시간이 폭증하고, 서빙 인프라의 GPU 메모리 점유율이 급증하여 운영 비용이 기하급수적으로 늘어난다.

샤오미 연구진은 자기개선 루프(Self-improvement loop)에 추론 길이와 토큰 소모량에 대한 페널티 및 보상 함수를 결합한 것으로 보인다. 정답에 도달하는 데 성공한 여러 경로 중에서도 가장 압축적이고 핵심적인 연산 단계만을 남기도록 지속적인 반복 훈련을 가한 것이다. 그 결과 모델은 복잡한 다단계 문제를 해결할 때도 장황한 방황 없이 직선적인 해법을 구성하게 된다.

이 글의 해석으로는, 이러한 토큰 효율성 중심의 강화학습 정렬은 클라우드 API 서비스와 온디바이스(On-device) 연동 환경을 동시에 고려하는 샤오미의 하드웨어 생태계 전략과도 깊은 연관이 있는 것으로 풀이된다. 작업당 소모되는 토큰 수를 줄이는 것은 엔드포인트 기기의 배터리 소모와 발열을 줄이고, 클라우드 인프라의 처리 단가를 물리적으로 절감하는 유일한 길이기 때문이다.

  • 추론 경로 압축: 동일한 논리적 결론에 도달하는 복수의 경로 중 최단 거리 궤적 선호 유도
  • 작업당 토큰 절감: 불필요한 혼잣말이나 중복된 검증 단계를 최소화하여 토큰 소모 억제
  • 서빙 레이턴시 개선: 생성 토큰 수 감소를 통한 초기 응답 시간 및 전체 요청 처리 지연 단축
  • 운영 비용 최적화: 입출력 토큰 총량을 줄임으로써 서비스 배포 및 유지보수 인프라 부담 경감

6. Artificial Analysis 지표와 공개 가중치 모델 비교

인공지능 모델 벤치마크 및 경제성 분석 기관인 Artificial Analysis 발표에 따르면(2차 출처), MiMo-V2.6-Pro는 독자적인 인공지능 종합 평가 척도인 인텔리전스 인덱스(Intelligence Index) 평가에서 46점(원 GeekNews 커뮤니티 요약 표기 기준 46.32점)을 기록했다. 이는 외부 평가 기관이 측정한 공인 수치로서 주목할 만한 성과다.

Artificial Analysis는 MiMo-V2.6-Pro가 기록한 46점이 가중치를 대외에 완전히 개방한 오픈 웨이트(Open-weights) 모델 진영 전체를 통틀어 가장 높은 최고점에 해당한다고 밝혔다. 독점적 상용 API 형태로만 서비스되는 폐쇄형 프런티어 모델들과 비교해도 매우 근접한 성능 밴드를 형성하고 있는 것으로 나타났다.

해당 기관이 제시한 동일 인텔리전스 인덱스 지표상의 타사 주요 모델 점수 분포를 중립적으로 살펴보면 다음과 같다. 최상위권에서는 Claude Fable 5.1과 GPT-6 Astra가 53점을 획득하여 공동 1위를 형성하고 있으며, 그 뒤를 이어 Claude Opus 5가 51점, Meta Muse Spark 1.3이 48점, GPT-5.6 Sol이 47점을 기록한 것으로 보고되었다. MiMo-V2.6-Pro는 이들 프런티어 상용 모델의 바로 뒤를 잇는 46점을 마크했다.

7. 확인하지 못한 것

본 기술 분석은 공식 릴리스 공지 및 모델 카드 등 1차 출처 문서와 신뢰성 있는 인공지능 분석 기관의 발표 자료를 바탕으로 구성되었다. 그러나 공개된 문서의 범위 한계로 인하여 명확히 검증하지 못한 세부 사항들은 임의로 추정하지 않고 본 절에 객관적으로 기록한다.

  • 공식 공지에서 플래그십 Pro 모델과 함께 언급된 비용 효율형 파생 모델 「MiMo-V2.6-Flash」의 구체적인 총 매개변수 수치, 활성 전문가 수, 양자화 포맷 등 세부 아키텍처 스펙은 공개 문서에 명시되지 않아 확인하지 못했다.
  • Artificial Analysis의 인텔리전스 인덱스 평가에 대한 2차 발표 자료 외에, 평가 당시 사용된 개별 세부 벤치마크 테스트셋 구성 비율이나 원천 프롬프트 데이터의 공개 트윗 원본 문맥은 직접 열람하지 못하여 확인하지 못했다.
  • GRPO 대규모 배치 훈련(1,568 프롬프트 × 16 롤아웃)을 수행할 당시 동원된 물리적 GPU 클러스터의 구체적인 하드웨어 칩 기종, 총 가속기 수량, 상호 연결 대역폭 등 인프라 세부 명세는 모델 카드에 기술되어 있지 않아 확인하지 못했다.
  • 비디오 및 오디오 등 비정형 연속 신호를 텍스트 토큰 시퀀스와 정렬하기 위해 사용된 각 모달리티별 전용 인코더의 세부 파라미터 크기나 압축 프레임레이트는 릴리스 문서에 기재되지 않아 확인하지 못했다.
