机票价格为何一直在变 - 你真正能控制的和查不到依据的说法

舱位结构、总价比较方法，以及八条找不到一手依据的流行说法

2026-08-01 生活实用

引子：同一个航班，今天的价格和昨天不一样

昨晚看好了一个航班。日期、时刻、航班号都没变，今天早上再打开，价格涨了四万韩元。换一个新的浏览器窗口，切到无痕模式再进去看，价格没变。到这一步，人们的反应大致分成两类：要么确信是搜索记录造成的，要么觉得今天运气不好，付款了事。

我不是要说这两种反应都错。而是这两种说法都不是经过确认的解释。抓着一个没有确认的解释不放，结果就是错过那些真正能控制的部分。

这篇文章不是「机票怎么买更便宜」。那类文章已经多得溢出来了，其中大部分只是把从未被验证过的说法互相抄来抄去。这篇文章只做一件事：先看清价格是怎么形成的，然后在这个结构之上，把可控的东西和迷信分开。

先说结论，真正省钱的方法在枯燥的那一边：按总价比较，把条件读清楚。而不是在周二下午按下付款键。

本文的调查方式。正文中凡是写出数字或标准的地方，都只写我们亲自打开确认过的政府和公共机构一手资料。打不开的文件，其内容不予转述，没能确认的部分单独列在第9节。对于流传甚广的省钱窍门也适用同一标准，所以第3节的表格里逐行标明是否找到了一手依据。

制度部分为大韩民国标准。关于退票手续费、旅客保护和纠纷解决程序的内容，均以韩国消费者在韩国购买为前提，引用的出处也是韩国政府文件。其他国家的读者请把结构性内容视为通用，把法律制度内容视为受管辖地限制。本文同样不推荐也不批评任何特定航空公司、订票网站或银行卡。要做那样的判断，就必须打开本文没能打开的全部文件。

延伸阅读。旅途中出事时保险的保障范围见旅行保险指南，与商家发生纠纷时的程序见消费者纠纷解决程序，格式条款何时无效见不公平条款与无效，支付货币混杂时的换算见读懂汇率。

1. 价格一直在变的原因 - 卖的是产品，不是座位

先要清掉一个误解：航空公司卖的不是座位。当然最终坐上去的是一个物理座位，但真正被销售的单位不是座位，而是条件各不相同的产品。

在同一个经济舱客舱里，在售的产品也被切成了好几个。业内把它们叫做预订舱位，通常用一个字母区分，每个舱位都附带一组叫做运价规则的条件。这组条件大致包括这些内容。

  • 能否改期以及手续费。有的产品根本不能改，有的交手续费就行，有的只补差价
  • 能否退票以及手续费区间。有的产品根本不能退。这种情况下所谓「买得便宜」，等于拿钱赌行程绝对不会变
  • 是否含托运行李及件数。有的产品标示价格里完全不含行李额
  • 能否预选座位。有的免费，有的收费，有的要到机场值机时才能选
  • 里程累积比例。飞同样的距离，累积比例不同，也有完全不累积的产品
  • 停留条件。有些票价会附加最少停留多少天、最多不超过多少天之类的条件

看到这里，引子里的场景就变了。昨天看到的价格和今天不同，多半不是同一个产品涨价了，而是昨天还剩着的便宜条件产品卖完了，只剩下下一个产品。所以机票价格不是一条平滑的曲线，而是像台阶一样一跳一跳地动。

1.1 所以它无法被预测

每个舱位分多少座位、什么时候重新调整分配，属于航空公司内部的需求预测判断。而这个判断的依据不对消费者公开。仅这一条事实，就让市面上大部分省钱窍门失去了效力。

  • 「提前N天买最便宜」要成立，前提是所有航线的分配策略相似，而没有理由如此
  • 即便同一条航线，旺季与淡季、旅游需求与商务需求的比例不同，分配也随之变化
  • 观察到价格涨跌，这件事本身对原因一无所言。可能是因为我重新搜了一次，也可能是这期间别人买走了最后一个便宜座位。消费者没有办法把两者分开

结构既然如此，剩下的选择就很清楚：不要试图预测下一次变动，而要准确弄清此刻屏幕上的产品是什么。这件事是可以确认的。

补充一点，机票被作为条件不同的多个产品来销售，这一事实本身在监管文件里也能得到印证。后面要引用的韩国公平交易委员会2016年9月28日发布，以及韩国消费者院2016年11月21日的新闻稿，都以折扣机票这一分类和随取消时点变化的手续费为前提。如果一张机票就是一件只有一个价格的商品，这样的区分根本不会出现。

2. 便宜票里少了什么 - 为什么必须按总价比较

标示票价低，很多时候意味着包含的东西更少。所以比较两个产品时，拿标示票价相减，答案几乎总是错的。下面整理了需要加回来的项目。

需要确认的项目为什么要计入总价在哪里确认
托运行李如果含件数为0，费用会按航段和人数成倍放大。这是总价差距拉得最开的一项运价规则、航空公司行李说明
随身行李尺寸或重量上限偏低，就得在机场改为托运，而那时的费用通常更贵航空公司行李规定
预选座位有同行者时它实际上成了必须支出，并按人数放大运价规则、预订页面
改期手续费行程不确定时，这是有实际发生可能的成本运价规则、运输总条件
退票手续费不可退产品一旦取消就是全额损失，这也必须计入成本运价规则、销售方取消条款
里程累积比例累积会拉低总价，但其价值并不确定，需要谨慎处理（第7节）里程计划条款
支付与出票手续费不同销售渠道可能加收，有时到最后一屏才出现支付页面的最终金额
税费、燃油附加费、机场设施费有时含在标示价里有时不含，两个网站的标示价可能根本不是同一个东西支付页面的最终金额
往返机场的交通费备选机场看着便宜，但要加上往返交通费和移动时间，并按人数放大自行计算
深夜落地的成本落地时公共交通已停运，住宿或深夜交通就成了事实上的强制支出自行计算

2.1 计算示例

下表中的数字是为了演示计算方法而虚构的数值，不是真实售价，不是任何真实的支付记录，也与任何特定航空公司无关。场景设定为两名成人往返。

项目产品A（标示票价 189,000韩元）产品B（标示票价 249,000韩元）
标示票价 × 2人378,000韩元498,000韩元
税费与燃油附加费 × 2人92,000韩元92,000韩元
托运行李不含 → 单程40,000 × 2航段 × 2人 = 160,000韩元含1件 → 0韩元
预选座位收费12,000 × 2航段 × 2人 = 48,000韩元免费 → 0韩元
往返机场交通费备选机场 → 往返18,000 × 2人 = 36,000韩元0韩元
小计（确定成本）714,000韩元590,000韩元
行程改变概率 p = 0.2，手续费 C不可退 → C = 470,000，期望成本 94,000韩元手续费 60,000 → 期望成本 12,000韩元
比较总价808,000韩元602,000韩元

只看标示票价，A便宜6万韩元。只加上确定成本，A就贵了12万韩元。再把行程改变的可能性算进去，贵出20万韩元以上。这个反转不是什么特例，而是标示票价各自扣掉了不同东西之后自然产生的结果。

2.2 期望成本这一项

上表倒数第二行可能有点陌生，它是行程改变的概率乘以手续费。加入这一项的理由很简单。

  • 不可退票价的价格不是它的标价。行程确定时标价是对的；不确定时，你同时买下了那部分损失风险
  • 不需要知道准确的概率。光是区分它是不是0，判断就会不同。出差尚未定下来、带着孩子、同行者日期未定，这些情况下p都不是0
  • 反过来，p接近0时不可退票价确实更便宜。这个计算不是叫你避开便宜票，而是用来分辨便宜票何时才真的便宜
  • 同理，旅行保险中与行程取消相关的保障，作用就是把这个p往下压。保障范围和条件在旅行保险指南中另行讨论

3. 检验流行说法 - 用表格标明是否找到一手依据

这是本文最重要的部分。对于作为机票省钱窍门广为流传的那些说法，我们逐条确认了政府、公共机构或监管部门的公开资料中是否存在支持它的一手依据。结果照实写在下面。

搜索记录和Cookie会推高价格 / 无痕模式更便宜未找到没有。所观察到的现象，用第1节的库存耗尽结构同样可以解释

八条全都没找到。准确地读懂这个结果很重要。

  • 没找到不等于证明它是假的。依据可能存在于本文调查范围之外，何况企业的定价政策本来就没有公开义务
  • 同时，它也不是真的证明。而在消费者所处的情境里，这两者实质上是一回事。无法验证的建议，没有可以据以决定要不要照做的依据
  • 所以本文既不叫你去做这八件事，也不叫你别做。只是不会用「省钱方法」这个名字来称呼它们

3.1 为什么个人经验判别不了

「我用无痕模式打开就便宜了」这句话，多半是真实经历。问题在于这段经历无法区分两种不同的解释。

  • 解释一。搜索记录被反映到价格里，清掉记录后原价就出来了
  • 解释二。这期间预订舱位的库存变了，无痕模式什么作用都没起
  • 两种解释会产生同样的观察。光看到价格降了，判断不出是哪一种
  • 要分开就必须在同一时刻、同样条件、设置对照、反复观测。个人经历过的那几次，一个条件都不满足
  • 更何况人只会记住对上的那几次。无痕模式打开后价格纹丝不动的那天不构成谈资，也就传不出去

实务上的结论是：不花成本的行为，做了也无妨。开一个无痕窗口只要三秒。问题在于把它称作「省钱法」的那一刻，注意力就从可验证的省钱手段——总价比较和条件确认——上移开了。时间和注意力是有限的，把它们花在哪里，决定了你实际付出多少。

4. 中转与直飞 - 为什么订座编号是不是一个很重要

中转比直飞便宜是常有的事。但这里要比较的不只是价格，因为中转是把时间成本和风险一起买了下来。

4.1 把时间成本换成数字

  • 中转等待时间本身就是成本。如果往返多出8小时，可以换算成假期天数来看
  • 在机场度过的时间要花餐费，并按人数放大
  • 夜间中转造成睡眠损失，有时还会让你失去落地次日的行程
  • 视中转地不同，可能需要签证或事先入境许可。这既是成本也是失败风险，条件需要在该国使领馆和外交主管部门的说明中确认

4.2 订座编号是一个，还是机票有好几张

这是本节的核心。屏幕上看起来一模一样的「出发地 → 中转地 → 目的地」行程，作为一个订座出票的，和你自己把两个独立订座拼起来的，是完全不同的产品。

  • 作为一个订座出票时。航空公司把整段行程视为一份运输合同。前一段延误导致错过后一段时，航空公司在改签方面存在既定的责任范围。行李也常常直挂到最终目的地
  • 把分开买的两张拼起来时。在后一段航空公司看来，前一段的延误属于旅客个人的原因。错过了可能要重新买票。行李通常也要在中转地取出后重新托运
  • 比价网站上格外便宜的组合有时正是后一种。所以要确认页面上有没有「分开出票」或类似措辞的提示
  • 确认方法是看出票后拿到的电子客票，检查订座编号是不是一个、票号有几个
  • 还要确认中转是否需要过入境检查。如果需要，所需的中转时间会大幅增加

各机场都设有最短衔接时间，并且随航空公司与航站楼组合而不同。比它更短、由旅客自行拼接的行程所产生的后果，通常按旅客自负处理。反过来，同一订座内由航空公司给出的衔接，即便时间很紧，也是航空公司自己设计的。

本节的局限。行李直挂处理与跨航段责任范围的具体条件，会随各航空公司的运输总条件以及航空公司之间的协议而不同。本文没能打开任何一家航空公司运输总条件的原文，也没能打开国际航空运输协会的相关公开资料，所以这里只讲到「该看哪里」为止，不对具体条件下定论。实际出行时，请在出票前查阅该航空公司运输总条件中的衔接航班与行李条款。

5. 退改规定 - 写在哪里，该看什么

取消条件不写在一个地方。它有三层，而且三层之间可能互相不一致。不了解这个结构，遇到「航空公司说能退，旅行社说不能退」的情况，就不知道该追问什么。

层级写了什么在哪里看漏看会怎样
① 航空公司运输总条件运输合同的一般条件：取消、改期、行李、延误处理的基本骨架航空公司网站的条款页面在不知道基准原则的情况下，只能听到零散的个案答复
② 该票价的运价规则只适用于你所买产品的条件：能否退票、手续费分档、是否含行李支付前的最后一屏、电子客票上的运价规则摘要最容易漏看的一层。同一家航空公司内，产品与产品之间也不同
③ 销售方自有条款经旅行社或代销购买时的操作手续费与受理时间销售方使用条款、订单确认邮件它会与航空公司手续费分开另加，取消渠道也可能被限定在销售方

5.1 按韩国标准确认到的内容

从这里开始，内容依据的是我们实际打开确认过的一手资料，共两件。

  • 韩国公平交易委员会，2016年9月28日发布。七家韩国国内航空公司对国际航线机票不论取消日距出发日多久都一律收取同样取消手续费的条款被责令整改。判断依据是，该费用属于民法上的违约金预定，而该条款在取消时点距出发日越长时，使顾客承担了不当过重的损害赔偿义务，因而依格式条款法无效
  • 整改内容本身。出发前91天以上取消全额退款；出发前90天至出发日之间划分为四到七个区间，越接近出发日费率越高。计划在2016年12月31日前完成系统调整，自2017年1月1日起施行
  • 韩国消费者院 消费者纠纷调解委员会，2016年11月21日新闻稿。一位消费者在2016年2月以665,400韩元购买了三张仁川至香港的往返机票，在出发前66天取消，航空公司收取了每人80,000韩元的取消手续费。调解委员会将上述整改后的条款溯及适用，决定每名成人退还23,000韩元、每名儿童退还25,000韩元
  • 同一份新闻稿把折扣机票归纳为：以出发日为准91天以前可以无手续费取消，90天以内则按各航空公司整改后的条款支付取消手续费

注意基准时点。上述两件是2016年和2017年时点的措施。此后各航空公司可能又修订过条款，而且区间数量与费率各家不同。因此不能把它记成「出发前91天一律全额退款」。这些资料真正告诉你的是「与时点无关的一律手续费在格式条款法下可能构成问题」这一判断标准，以及依此标准争议并作出实际决定的先例存在。你自己那张机票的实际区间与费率，必须在该机票的运价规则里确认。

5.2 付款前要留下的东西

确认了规定，和能够证明你确认过，是两回事。日后一旦起争议，需要的是后者。

  • 把支付前最后一屏的运价规则摘要和取消手续费说明截图下来，和支付记录一起保存
  • 如果经过销售方，另外单独截图销售方的取消手续费说明。它可能与航空公司规定不同
  • 收到电子客票后，确认运价规则摘要、行李额、订座编号与票号
  • 取消时使用能留下申请时间的方式（网页取消受理页面、邮件）。只打电话处理很难证明时点
  • 由于手续费按日期分档，差一天就可能落到另一档。没有理由拖延的话，这个结构本身就在奖励不拖延

格式条款在什么情况下无效，以及与商家发生争议时该走什么程序，在不公平条款与无效标准和消费者纠纷解决程序中有更详细的讨论。

6. 超售、延误与取消 - 你可以要求什么

本节不写赔偿金额。先说明理由。

韩国有一份国土交通部告示，中文可称为航空交通利用者保护基准。在韩国国家法令信息中心查询，可以确认它是国土交通部告示第2024-519号，2024年9月27日施行。但本文没能打开该告示正文的条文。把没有读过的条款和金额抄过来，那一刻这篇文章就会把下一位读者带偏。所以我们给出的是查证路径，而不是数字。

6.1 查证路径

  • 在韩国国家法令信息中心查询该保护基准，直接阅读正文条文。修订可能改变了条文，所以要一并确认施行日期
  • 查看韩国公平交易委员会消费者纠纷解决基准告示中的航空部分。该基准被认为具有建议性质，本文没能打开该告示的航空附表正文
  • 在你所乘航空公司的运输总条件中找到延误、取消、超售相关条款。真正的合同关系在那里
  • 仍未解决时，使用韩国消费者院的咨询与消费者纠纷调解委员会程序。第5节引用的决定先例就出自这条路径

6.2 在机场现场必须做的事

无论最终适用哪套标准，没有记录就无法支撑主张。这一部分与标准无关，永远有效。

  • 把原因和时间拿到书面材料上。索取延误或取消证明，并确认原因被写成了什么。是天气还是机务，会改变之后的判断
  • 记录告知的时间。延误何时公布、何时给出替代航班，用页面照片或消息留存
  • 留下给出的替代方案内容。你被提供了什么、拒绝了什么，日后会成为争点
  • 保存所有额外支出的票据。包括住宿、餐饮、交通，以及重新购买的机票
  • 如果因超售被拒绝登机，请把该事实与所提供的补救措施拿到书面确认。口头承诺不会留下痕迹
  • 如果买了旅行保险，另外确认是否包含延误与取消的保障。航空公司的处置与保险理赔是两条独立程序

这份清单有个共同点：全都只能在机场做，回到家以后再也造不出来。所以记住这六行，比背下任何标准都更管用。

7. 里程 - 只写确认过的范围

里程会让总价比较变得困难，因为它的价值并不确定。这里只整理结构，不对任何具体计划的条件下定论。

7.1 累积一侧

  • 累积通常按航段距离与预订舱位计算。飞同样的距离，产品不同，累积比例也不同
  • 有些票价完全不累积。越便宜的产品越有这种可能，如果你本来指望累积，付款前就要确认
  • 若想把累积算进总价，估得保守一些更安全。理由见下

7.2 使用一侧

  • 兑换机票通常来自单独划出的座位库存。里程够，不代表你想要的日期有位子
  • 即便用里程换到机票，税费和燃油附加费等往往仍需现金支付。所以它不是「免费机票」
  • 因此用固定汇率把里程折成现金来比较的算法并不成立。兑换比取决于时点与座位供给
  • 有些计划设有有效期。期限和失效方式各计划不同，必须在该计划条款中确认。本文没有打开任何具体计划的条款，因此不写数字
  • 家庭合并、转让、合作伙伴使用与否，同样属于各计划自定条件。基于同样理由，这里不下定论

归纳起来，里程更适合放在总价比较的辅助项位置。因为累积比例的差异而选择更贵的产品，只有在你能确定那部分累积价值时才成立。而通常你确定不了。

结论：枯燥的那一边才是省钱的那一边

归纳一下。机票价格来自这样一个结构：不是同一个座位在涨跌，而是条件不同的产品按顺序被卖光。分配不对外公布，所以预测根本无从谈起。

我们为八条广为流传的省钱窍门寻找一手依据，一条都没找到。这不等于说它们是假的，但无法验证的建议，也没有可以据以照做的依据。

而可以验证的东西确实存在：按总价而不是标示票价比较，以及在付款前读完行李、座位、改期、退票这四项条件。正如第2节虚构示例所示，标价便宜6万韩元的产品，在总价上可能贵出20万韩元。这个反转不是窍门，是算术。

制度层面也有确认到的东西。与取消时点无关的一律手续费，曾被认定为使顾客承担不当过重损害赔偿义务的条款并被整改，而且依此标准作出过实际的退款决定。这类资料不必背下来，知道需要时该去哪里找就够了。

最后有一件现在就能做的事：下次看机票时，在写下标示票价之前，先确认包含的托运行李件数。就这一行，改变比较结论的次数比想象中多。而它和你星期几上网完全无关。

常见问题

昨天看的机票今天变贵的原因是什么

多半不是同一个座位涨价，而是便宜条件的产品卖完了，只剩下下一个产品。分配策略不公开，所以没有办法预测下一次变动。但确认此刻屏幕上产品的条件是可以做到的。

无痕模式真的有效吗

在本文的调查范围内没有找到一手依据。所观察到的现象用库存耗尽结构同样可以解释，仅凭个人经验无法区分两种解释。它不花钱，想用可以用，但把它当成省钱方法，就会让注意力离开总价比较这个可验证的手段。

行李费能造成多大差别

单程费用会按航段数和人数成倍放大，是总价上差距拉得最开的一项。第2节的虚构示例中，两名成人往返增加了16万韩元，仅此一项就把6万韩元的标价差距反转了。

退票手续费起了争议该去哪里

先确认三层：航空公司运输总条件、该票价的运价规则、销售方自有条款。仍未解决时，有韩国消费者院的咨询与消费者纠纷调解委员会程序。第5节引用的2016年决定也出自这条路径。

为什么本文没有延误与取消的赔偿金额

因为没能打开相关告示的条文正文。写下没有读过的金额会构成错误指引。作为替代，6.1节给出查证路径，6.2节列出在现场应当留存的记录。

# 机票总价比较 & 下单前确认 — 复制可用

> 出处: braindetox.kr — 机票价格为何一直在变
> 制度部分为大韩民国标准。金额与条件请务必在自己机票的运价规则中确认。
> 把这份文件贴给AI，写「按我的行程把这张表填好」即可。

## 0. 前提

航空公司卖的不是座位，而是 **条件不同的产品**。
今天价格和昨天不同，通常意味着 **便宜条件的产品卖完了**。
分配策略不公开 → **无法预测**。可控的只有 **总价比较与条件确认**。

## 1. 总价比较工作表

| 项目 | 算式 | 产品A | 产品B |
|---|---|---|---|
| 标示票价 | x 人数 | | |
| 税费 · 燃油附加费 · 机场设施费 | x 人数 | | |
| 托运行李 | 单程费用 x 航段 x 人数 | | |
| 预选座位 | 费用 x 航段 x 人数 | | |
| 支付 · 出票手续费 | | | |
| 往返机场交通费 | 往返 x 人数 | | |
| 深夜落地住宿 · 交通 | | | |
| **小计（确定成本）** | 合计 | | |
| 行程改变概率 p | 0.0 ~ 1.0 | | |
| 改期 · 退票手续费 C | | | |
| **期望成本** | p x C | | |
| **比较总价** | 小计 + (p x C) | | |

**判断**：比较总价小的一方，而不是标示票价小的一方。
p接近0时不可退票价确实更便宜；p不为0时则不然。

## 2. 流行说法核查 — 是否找到一手依据

| 广为流传的说法 | 一手依据 | 反而确认到的东西 |
|---|---|---|
| 搜索记录 · 无痕模式 | **未找到** | 没有（库存耗尽结构同样可解释） |
| 特定星期 · 时段 | **未找到** | 没有 |
| 正好提前N天 | **未找到** | 「提前N天」在一手文件中出现的唯一语境是 **退票手续费分档** |
| VPN切换国家 | **未找到** | 没有 |
| 两张单程永远更划算 | **未找到** | 没有 |
| 24小时内一律免费取消 | **未找到** | 韩国标准是按时期分档的结构 |
| 官网永远最便宜 | **未找到** | 取消流程的层数确实会变 |
| 临近起飞甩卖 | **未找到** | 没有 |

**未找到不等于证明为假。** 但无法验证的建议也没有照做的依据。

| 行李 | 常直挂至最终目的地 | 中转地取出后重新托运 |
| 确认方法 | 电子客票上的订座编号与票号数量 | 相同 |

1. **航空公司运输总条件** — 合同的一般条件
2. **该票价的运价规则** — 只适用于你买的产品（最容易漏看）
3. **销售方自有条款** — 旅行社手续费可能 **与航空公司分开** 另收

- 韩国消费者院调解委员会 2016-11-21 — 出发前66天取消一案，决定每名成人退还23,000韩元、每名儿童退还25,000韩元

## 7. 里程 — 不要下定论

- 累积比例 **随预订舱位不同**，也有完全不累积的票价
- 兑换机票来自 **单独座位库存**，税费与附加费常需现金支付
- 因此 **用固定汇率折成现金来比较并不成立**
- 有效期 · 合并 · 转让条件必须在 **该计划条款中直接确认**

## 8. 不要做的事

- 拿标示票价互相比较 — 它们扣掉的东西不一样
- 不读退票规则就付款 — 行程不定时实际价格不同
- 不截图就付款 — 起争议时没有可以出示的东西
- 把分开出票当成单一行程 — 错过一段就要重新买票
- 把时间花在未经验证的窍门上 — 那段时间用来填总价表更划算
- 用别人的摘要判断规则 — 自己机票的运价规则才是唯一依据
