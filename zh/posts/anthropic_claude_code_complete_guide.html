Anthropic Claude Code 完全指南：AI 编码助手的全部奥秘

Complete Guide to Anthropic Claude Code: Everything About AI Coding Assistant

2025-12-25 IT/技术

Claude Code 是 Anthropic 官方开发的 AI 编码助手 CLI（Command Line Interface，命令行界面）工具。它在终端中运行，可帮助开发者将想法快速转化为代码、修复 Bug、浏览代码库，带来革命性的开发体验。本指南将详细介绍 Claude Code，从安装到高级功能应有尽有。

English: Claude Code is the official AI coding assistant CLI tool developed by Anthropic. It operates in the terminal and provides revolutionary assistance to developers in quickly converting ideas into code, fixing bugs, and navigating codebases. This guide covers everything from installation to advanced features of Claude Code in detail.

1. 什么是 Claude Code？

1.1 核心概念

Claude Code 是一款基于智能体架构的终端原生 AI 工具。与传统的 IDE 插件不同，Claude Code 直接在终端中运行，可以自主完成文件编辑、命令执行、Git 提交创建等任务。

┌─────────────────────────────────────────────────────────┐
│                  Claude Code 架构                          │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   [用户] ─────────────────────────────── [终端]          │
│       │                                       │         │
│       ▼                                       ▼         │
│   自然语言指令  ────────────► Claude Code 引擎          │
│                                      │                  │
│                    ┌─────────────────┼─────────────────┐│
│                    ▼                 ▼                 ▼│
│               [读取文件]      [修改代码]      [执行命令]  │
│               [搜索/分析]     [编写测试]      [Git 操作]  │
│                                                         │
└─────────────────────────────────────────────────────────┘

1.2 主要特性

  • 终端原生：直接在终端运行，而非依赖 IDE
  • 智能体模式：自主规划并执行任务
  • 管道支持：遵循 Unix 哲学，可与其他工具协同
  • 直接执行：支持文件编辑、命令执行、创建 Git 提交
  • 上下文感知：理解整个代码库后再作业

1.3 典型使用场景

使用场景 说明 示例指令
代码生成 根据自然语言描述编写代码 "帮我生成用户认证 API 端点"
Bug 修复 错误分析与自动修复 "帮我修复 TypeError 报错"
重构 改善代码质量 "请将此函数转换为 TypeScript"
测试编写 自动生成单元测试 "为此模块编写测试代码"
文档编写 生成代码注释及 README "请为本项目撰写 README"

2. 安装与上手

2.1 安装方式

Claude Code 支持多种安装方式：

macOS / Linux / WSL（推荐）

# 官方安装脚本
curl -fsSL https://claude.ai/install.sh | bash

Windows PowerShell

# 在 PowerShell 中执行
irm https://claude.ai/install.ps1 | iex

Homebrew (macOS)

# 通过 Homebrew 安装
brew install --cask claude-code

NPM

# 通过 NPM 安装
npm install -g @anthropic-ai/claude-code

2.2 首次运行

# 进入项目目录
cd your-project

# 启动 Claude Code
claude

# 首次运行需要登录
/login

2.3 系统要求

  • 操作系统：macOS 10.15+、Windows 10+、Linux（Ubuntu 20.04+）
  • Node.js：18.0 及以上（通过 NPM 安装时）
  • 内存：建议至少 4GB RAM
  • 网络：需稳定的互联网连接

之后即可通过 /commit "修复 Bug" 的形式调用。

5. MCP（Model Context Protocol）服务器集成

5.1 什么是 MCP？

MCP 是一套开放协议，用于将外部工具和数据源接入 Claude Code。可与 GitHub、Jira、Slack 等多种服务进行集成。

5.2 安装 MCP 服务器

# 添加 HTTP 服务器
claude mcp add --transport http notion https://mcp.notion.com/mcp

# 添加 SSE 服务器
claude mcp add --transport sse asana https://mcp.asana.com/sse

# 添加本地 Stdio 服务器
claude mcp add --transport stdio airtable \
  --env AIRTABLE_API_KEY=YOUR_KEY \
  -- npx -y airtable-mcp-server

5.3 MCP 管理命令

# 列出所有服务器
claude mcp list

# 查看指定服务器信息
claude mcp get github

# 移除服务器
claude mcp remove github

# 在会话中管理
/mcp

5.4 热门 MCP 服务器

服务器 用途
GitHub 仓库、Issue、PR 管理
Sentry 错误监控与分析
Notion 文档及数据库访问
Jira 项目管理及 Issue 追踪
PostgreSQL 数据库查询与管理
Slack 团队沟通集成
Google Drive 文件存储与共享
Figma 设计资源访问

6. Skills 功能

6.1 什么是 Skills？

Skills 是 Claude 可自动发现并使用的可复用能力单元。它可以包含执行特定任务所需的说明、模板、脚本等内容。

6.2 Skill 结构

my-skill/
├── SKILL.md          # 必需：技能定义
├── reference.md      # 可选：参考文档
├── examples.md       # 可选：使用示例
├── scripts/
│   └── helper.py     # 可选：辅助脚本
└── templates/
    └── template.txt  # 可选：模板文件

6.3 编写 SKILL.md

---
name: pdf-processing
description: 从 PDF 文件提取文本、填写表单、合并 PDF。在处理 PDF 文件时使用。
allowed-tools: Read, Grep, Glob
---

# PDF 处理

## 指令

1. 使用 PyPDF 或 pdfplumber 库
2. 提取文本时保留布局
3. 包含错误处理
4. 报告处理结果

6.4 Skills 存放位置

  • 项目级：.claude/skills/skill-name/
  • 用户级：~/.claude/skills/skill-name/

7. Hooks 功能

7.1 什么是 Hooks？

Hooks 是在特定事件发生时自动执行的自定义 Shell 命令，对于工作流自动化非常实用。

7.2 Hook 事件类型

事件 说明 使用场景
PreToolUse 工具执行前 阻止特定操作
PostToolUse 工具执行后 自动代码格式化
PermissionRequest 权限请求时 权限日志记录
UserPromptSubmit 用户提交提示时 输入校验
Notification 发送通知时 外部通知联动
Stop 响应完成时 完成提醒
SessionStart 会话启动时 环境初始化
SessionEnd 会话结束时 清理工作

7.3 Hooks 配置示例

{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          {
            "type": "command",
            "command": "jq -r '.tool_input.command' >> ~/.claude/bash-log.txt"
          }
        ]
      }
    ],
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "npx prettier --write \"$file_path\""
          }
        ]
      }
    ]
  }
}

7.4 实际应用场景

  • 代码格式化：保存 TypeScript / JavaScript 文件时自动格式化
  • 文件保护：阻止生产环境文件的修改
  • 日志记录：记录所有 Bash 命令
  • Lint 检查：文件修改后自动运行 Lint

9. 设置与配置

9.1 配置文件位置

  • 用户级配置：~/.claude/settings.json
  • 项目级配置：.claude/settings.json
  • 本地配置：.claude/settings.local.json（Git 忽略）

9.2 主要配置项

{
  "permissions": {
    "allow": [
      "Bash(npm run test:*)",
      "Read(~/.zshrc)"
    ],
    "deny": [
      "Bash(curl:*)",
      "Read(./.env)"
    ],
    "additionalDirectories": ["../docs/"],
    "defaultMode": "acceptEdits"
  },
  "env": {
    "NODE_ENV": "production",
    "CUSTOM_VAR": "value"
  },
  "model": "claude-sonnet-4-5-20250929",
  "outputStyle": "Explanatory",
  "sandbox": {
    "enabled": true,
    "autoAllowBashIfSandboxed": true
  },
  "attribution": {
    "commit": "Generated with Claude Code",
    "pr": "Generated with Claude Code"
  }
}

10. 安全与权限管理

10.1 三层权限体系

工具类型 示例 是否需要批准
只读 读取文件、Grep、Glob 否
Bash 命令 执行 Shell 命令 是
文件修改 写入、编辑文件 是

10.2 权限规则配置

{
  "permissions": {
    "allow": [
      "Bash(npm run build)",
      "Bash(npm run test:*)",
      "Read(./src/**)"
    ],
    "deny": [
      "Bash(curl:*)",
      "Bash(rm -rf:*)",
      "Read(./.env)",
      "Read(./.env.*)",
      "Read(./secrets/**)"
    ]
  }
}

10.3 权限模式

  • default：每次使用工具时请求权限
  • acceptEdits：文件编辑自动批准
  • plan：仅分析，不可修改
  • bypassPermissions：所有权限自动批准（请谨慎使用！）
# 切换权限模式
claude --permission-mode plan
claude --permission-mode acceptEdits

10.4 安全最佳实践

  • 将敏感文件（.env、credentials.json 等）加入 deny 列表
  • 只读 Skills 使用 allowed-tools: Read, Grep, Glob 限制
  • 定期通过 /permissions 审查权限
  • 在生产环境中启用沙箱模式
