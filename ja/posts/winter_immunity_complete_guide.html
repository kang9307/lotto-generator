冬の「免疫力」について言えること、言えないこと

冬は風邪やインフルエンザなどの呼吸器感染症が増え、「免疫力を高めよう」という言葉が増えます。しかし「免疫力」は医学用語というより日常的な表現に近く、免疫系は異なる細胞や器官が協力して働く複合的な仕組みなので、サプリメント1つや食品1つで「高めた」と言うのは困難です。この記事は「免疫力強化」の効能を断定せず、確認できたことと確認できなかったことを分けて整理します。

以前の版には、サプリメントの「TOP 7」と1日の推奨量、「日照が減るとビタミンD合成が80%減少」「睡眠が5時間未満なら感染リスク5.5倍」といった数値がありました。出典を確認できなかった数値と効能の断定は、2026年9月29日の更新で削除または緩和しました。冬に最も実用的な備えは、予防接種の確認、手洗い、具合が悪いときに休むこと、そして受診が必要な兆候を知ることです。

冬に感染が増えて見える理由:確認できたこととできないこと

冬に呼吸器感染症が増える理由を1つの原因で説明するのは困難です。以前の版は下の要因ごとに具体的な数値を記載していましたが、今回1次情報で確認できた範囲は次のとおりです。

要因確認できたこと限界・以前の版の訂正
屋内での接触の増加CDCの予防指針は、具合の悪い人との密接な接触を減らし、新鮮な外気を取り入れるか空気を浄化するよう案内しています。以前の「飛沫感染の確率が3~5倍」は出典を見つけられず削除しました。
日照の減少日光を浴びる機会が少ない冬にビタミンDが不足しやすいことは、当サイトのビタミンDの記事で扱った内容と同じです。「合成量80%減少」は削除し、不足が感染リスクを高めるとは断定しません。
低温・乾燥した空気以前の版にあった「末梢血管の収縮で免疫細胞の移動が制限される」「粘膜の乾燥でウイルスが侵入しやすい」は、今回根拠を確認できませんでした。事実として引用せず削除しました。
運動量の減少WHOは成人に週150分以上の中強度の身体活動を推奨しています。「NK細胞・T細胞の機能が20~30%低下」は出典を見つけられず削除しました。

まとめると、「冬だから免疫力が落ちる」と断定する根拠は確認できず、接触・換気・接種のように行動で減らせる要因が実用的な対象です。

予防接種:韓国の2026~2027シーズンのインフルエンザ・新型コロナ・肺炎球菌

冬の感染症予防で最も確認されている手段は予防接種です。以下は韓国疾病管理庁(KDCA)が発表した2026~2027シーズンの国家予防接種の内容で、2026年9月29日に確認しました。以前の版の接種時期(「10~11月」)や「70~90%予防」といった数値はシーズンごとに異なるため、固定の数値としては記載しません。これは韓国の制度の説明であり、他の国では各国のスケジュールに従ってください。

ワクチン国家予防接種の対象・日程確認する点
インフルエンザ生後6か月~14歳(2012.1.1~2026.8.31生まれ)、妊婦、65歳以上。子どもと妊婦は2026年9月21日から接種を開始し、接種期間は2027年4月30日までです。65歳以上は、75歳以上が10月12日、70~74歳が10月15日、65~69歳が10月19日からです。対象外は有料接種です。CDCは米国で生後6か月以上のすべての人に毎シーズンの接種を推奨しています。
新型コロナ2026年時点で65歳以上(1961.12.31以前生まれ)、免疫低下者、感染に脆弱な施設の入院・入所者。KDCAの予防接種ポータルには、70歳以上が10月12日、65~69歳が10月15日から2027年6月30日までと記載されています。KDCAの報道資料は、65歳以上はインフルエンザと同じ日程で10月12日からと記載しており、資料の間で表記が異なります。ご自身の日程は予防接種ポータルで確認してください。
肺炎球菌65歳以上の成人の国家予防接種(23価多糖体ワクチン)は、1961年12月31日以前に生まれた人が支援対象です。すでに65歳以降に接種した場合は追加接種は不要と案内されています。以前の「慢性疾患のある人が対象」は今回確認できませんでした。慢性疾患がある場合は保健所や医療従事者に相談してください。

以前の版にあった帯状疱疹ワクチンの「90%以上予防」という数値は今回確認できず削除しました。対象かどうかと接種歴は、KDCAの予防接種ポータルや保健所で確認してください。

風邪とインフルの見分け方、受診が必要な兆候

CDCは風邪とインフルエンザを、始まり方と症状の強さで比べています。以下は傾向であり、症状だけで原因のウイルスを断定することはできません。

項目風邪インフルエンザ
始まり方徐々に始まります。急に始まります。
発熱まれです。よくあり、3~4日続きます。ただしインフルエンザでも全員が発熱するわけではありません。
体の痛み・筋肉痛軽いです。よくあり、しばしば強いです。

成人が風邪をひく回数はCDCによると年平均2~3回で、よくひくからといってすぐに免疫が弱いとは限りません。

成人がすぐに受診すべき兆候(CDC)

  • 呼吸困難や息切れ
  • 胸や腹部の持続する痛み・圧迫感
  • けいれん
  • 強い筋肉痛
  • よくなりかけてから再び悪化する症状

子どもですぐに受診すべき兆候(CDC)

  • 速い呼吸や呼吸困難
  • 唇や顔が青紫色になる
  • 胸の痛み
  • けいれん
  • 生後12週未満の乳児のあらゆる発熱
  • 薬で下がらない40°C(104°F)以上の高熱

先に受診すべき場合

  • 熱や咳が長引く、または原因不明の体重減少を伴うとき
  • 中耳炎・肺炎・副鼻腔炎を繰り返す、または回復が極端に遅いとき
  • 免疫抑制薬・ステロイド・抗がん剤を服用中、または糖尿病などの基礎疾患があるとき

具合が悪いときはCDCの指針どおり家にとどまり、他の人との接触を減らしてください。症状の判断や薬の服用は医師・薬剤師に相談して決めます。

根拠のある生活要因:睡眠・運動・ストレス

以下は、この記事と同じ結論でまとめた当サイトの免疫力管理の記事で確認した範囲です。いずれも観察研究が多く、原因を断定できない点とあわせて読む必要があります。

要因確認できたこと限界・以前の版の訂正
睡眠Prather ら(2015):手首の活動量計で測った睡眠が1日5時間未満の群は、7時間超の群に比べ、ライノウイルス曝露後に風邪を発症するオッズ比が約4.5倍でした。睡眠を増やせば風邪が減ることを直接試した結果ではありません。「6時間未満4.2倍・5時間未満5.5倍・抗体50%減少」は削除しました。
運動WHOは成人に、週150分以上の中強度の身体活動と週2日以上の筋力運動を推奨しています。「ウォーキングでNK細胞活性30%増加」「Jカーブ」の断定は削除しました。体の痛みや発熱があるときは休みます。
慢性的なストレスCohen ら(2012, PNAS):長く続いたストレスは、その後の風邪のリスクが高いことと関連していました。「瞑想10~20分でコルチゾール23%減少」は出典を見つけられず削除しました。ストレスで日常が崩れるほどなら専門家に相談してください。

深呼吸、散歩、人との交流、十分な休息のように日常でできる方法が基本であり、特定の呼吸法や時間を効果の根拠としては示しません。

栄養素とサプリメント:確認できたこと、できなかったこと

栄養素が不足しないように摂ることと、多く摂って免疫を高めることは別の話です。以前の版の「必須サプリメント TOP 7」の見出しと1日の推奨量の数値は削除し、栄養素ごとの1日の必要量と上限は、韓国保健福祉部の「2025 韓国人の栄養素摂取基準」で年齢・性別ごとに確認するよう案内します。

成分確認できたこと確認できなかったこと・以前の版の訂正
ビタミンD韓国食品医薬品安全処(MFDS)の機能性は、カルシウム・リンの吸収と利用、骨の形成と維持などです。成人の耐容上限量は1日4,000 IU(NIH ODS)です。呼吸器感染症の予防はメタ分析の結果が一貫せず、2025年に更新されたメタ分析でも一般集団での予防効果は統計的に有意ではありませんでした。米国内分泌学会の2024年ガイドラインは、健康な成人の日常的な血中検査を勧めていません。「2,000~4,000 IU推奨」「最適40~60 ng/mL」「42%減少」は削除しました。
ビタミンCCochrane のレビュー:一般集団での定期的な摂取は風邪の発生を減らさず、症状の期間が成人で約8%、子どもで約14%短くなっただけでした。マラソンのような短期の高強度の身体的ストレスを受ける集団でのみ、発生リスクが半分になりました。「1,000~2,000 mg」の推奨量は削除しました。
亜鉛MFDSの機能性表示に「正常な免疫機能に必要」があります。不足しないよう必要量を満たすという意味です。「風邪が1~2日短縮」「傷の回復が25%短縮」は確認できず削除しました。高用量は耐容上限量を確認して避けます。
プロバイオティクスMFDSの機能性は、乳酸菌の増殖と有害菌の抑制、排便活動、腸の健康です。免疫増強として認められたものではありません。「腸が免疫の70%」「推奨菌株」「100億~500億CFU」は削除しました。
オメガ3青魚はバランスの取れた食事の一部です。「EPA+DHA 2,000~3,000 mg」という免疫向けの推奨量は根拠を見つけられず削除しました。
エルダーベリー今回、1次情報で確認できたものはありません。「インフルエンザの複製抑制」「300~600 mg」は確認できず削除しました。
ベータグルカン今回、1次情報で確認できたものはありません。「マクロファージ・NK細胞の活性化」「250~500 mg」は確認できず削除しました。

まず食品で満たし、サプリメントは欠乏が疑われるときや、妊娠・授乳中、慢性疾患、服用中の薬があるときに、医師・薬剤師に相談したうえで決めます。ビタミンDはビタミンDの記事、免疫全般は免疫力管理の記事で、同じ結論でまとめています。

手洗い・換気・食事:日常でできること

以下の行動はCDCの予防指針で確認したものです。以前の版の室温(20~22°C)・湿度(40~60%)・微小粒子の基準・「2時間ごとに10分換気」・「マスク着用」は、今回根拠を確認できなかったため、数値とともに削除しました。

感染予防の行動(CDC)

  • 石けんと水でこまめに手を洗い、ない場合はアルコール手指消毒剤を使います。
  • 咳やくしゃみのときはティッシュで鼻と口を覆い、ティッシュは捨てます。
  • 具合が悪いときは家にとどまり、症状が改善し、解熱剤なしで熱が下がってから少なくとも24時間たって活動を再開します。
  • ドアノブなど、よく触れる表面をこまめに拭きます。
  • 外気を取り入れるか室内の空気を浄化して、空気の質を改善します。

食事

  • 野菜・果物・全粒穀物・魚・豆類・乳製品をまんべんなく食べるバランスの取れた食事が基本です。
  • 以前の版の「免疫スーパーフード」の表と「1日の食事例」は、特定の食品の効能を断定する表現だったため削除しました。
  • 発酵食品は塩分が多いことがあるので、量を調整します。

年代によって変わる点

  • 乳幼児・子ども:予防接種のスケジュールを守ることが最も重要です。サプリメントやプロバイオティクスは小児科の受診時に相談します。
  • 青少年:バランスの取れた食事、規則的な身体活動、手洗いの習慣が基本です。以前の版の年齢別の睡眠時間の数値は確認できず削除しました。
  • 成人:睡眠や食事の時間が不規則になりがちです。接種歴を点検し、定期的に健康診断を受けます。
  • 65歳以上:インフルエンザ・新型コロナ・肺炎球菌の国家予防接種の対象かどうかを確認してください。慢性疾患がある場合は、食事や運動の調整を受診時に相談します。

よくある質問

Q1: 冬は免疫力が特に弱くなりますか?

A: 冬に呼吸器感染症が増えて見えるのは事実ですが、原因が1つに確認されたわけではありません。以前の数値(ビタミンD合成80%減少、飛沫感染3~5倍など)は出典を確認できず削除しました。接種の確認、手洗い、具合が悪いときに休むことが実用的な備えです。

Q2: 冬にビタミンDを必ず摂る必要がありますか?

A: 一般集団で呼吸器感染症を予防するという根拠は統計的に有意ではなく、米国内分泌学会の2024年ガイドラインは健康な成人の日常的な血中検査を勧めていません。成人の上限は1日4,000 IU(NIH ODS)で、欠乏のリスクが高い場合は医療従事者に相談してください。

Q3: 風邪とインフルエンザはどう見分けますか?

A: CDCの基準では、インフルエンザは急に始まり発熱と強い体の痛みがよくあり、風邪は徐々に始まり発熱はまれです。ただし症状だけでは断定できないので、医療従事者の判断に従ってください。

Q4: 睡眠が足りないと感染しやすくなりますか?

A: Prather ら(2015)では、睡眠が1日5時間未満の群の風邪発症オッズ比が、7時間超の群の約4.5倍でした。ただし睡眠を増やせば風邪が減ることを直接試した結果ではありません。

Q5: どんな症状ならすぐ病院に行くべきですか?

A: 呼吸困難、胸や腹部の持続する痛みや圧迫感、けいれん、強い筋肉痛、よくなりかけてから再び悪化する症状は、すぐに受診すべき兆候としてCDCが示しています。基礎疾患があるか免疫抑制薬を服用中なら、より早めに相談してください。

結論

冬の感染予防は、サプリメント1つではなく、確認された手段を押さえることです。要点は次のとおりです。

  1. 予防接種:2026~2027シーズンのインフルエンザ・新型コロナ・肺炎球菌について、ご自身が対象かどうかと日程を確認します。
  2. 感染予防の行動:手洗い、咳エチケット、換気、具合が悪いときに家にとどまることを守ります。
  3. 兆候を知る:呼吸困難・胸の痛み・けいれんのような兆候があれば、すぐに受診します。
  4. 睡眠・運動・ストレス:確認された関連性の範囲でのみ期待し、効果を断定しません。
  5. サプリメントは相談後に:「免疫強化」という広告文句が、MFDSが認めた機能性の範囲内かを確認します。

医学的免責事項: 本記事は教育および情報提供を目的として作成されており、医学的助言に代わるものではありません。健康上の問題があるか薬を服用中の場合は、必ず医療従事者にご相談ください。

# 冬の感染予防チェックリスト - 接種・兆候・サプリメントの判断

基準日: 2026-09-29
このチェックリストは一般的な情報であり、診断や治療に代わるものではありません。韓国の制度の説明です。対象と日程は、KDCAの予防接種ポータルなどでご自身の場合を確認してください。

---

## 1. 接種の確認表(2026~2027シーズン、韓国)

| ワクチン | 国家予防接種の対象・日程 |
|---|---|
| インフルエンザ | 生後6か月~14歳(2012.1.1~2026.8.31生まれ)、妊婦、65歳以上。子どもと妊婦は2026年9月21日から接種を開始し、接種期間は2027年4月30日までです。65歳以上は、75歳以上が10月12日、70~74歳が10月15日、65~69歳が10月19日からです。 |
| 新型コロナ | 2026年時点で65歳以上(1961.12.31以前生まれ)、免疫低下者、感染に脆弱な施設の入院・入所者。KDCAの予防接種ポータルには、70歳以上が10月12日、65~69歳が10月15日から2027年6月30日までと記載されています。 |
| 肺炎球菌 | 65歳以上の成人の国家予防接種(23価多糖体ワクチン)は、1961年12月31日以前に生まれた人が支援対象です。すでに65歳以降に接種した場合は追加接種は不要と案内されています。 |

## 2. 風邪とインフルの見分け方

| 項目 | 風邪 | インフルエンザ |
|---|---|---|
| 始まり方 | 徐々に始まります。 | 急に始まります。 |
| 発熱 | まれです。 | よくあり、3~4日続きます。ただしインフルエンザでも全員が発熱するわけではありません。 |
| 体の痛み・筋肉痛 | 軽いです。 | よくあり、しばしば強いです。 |

## 3. すぐに受診すべき兆候

**成人がすぐに受診すべき兆候(CDC)**

- [ ] 呼吸困難や息切れ
- [ ] 胸や腹部の持続する痛み・圧迫感
- [ ] けいれん
- [ ] 強い筋肉痛
- [ ] よくなりかけてから再び悪化する症状

**子どもですぐに受診すべき兆候(CDC)**

- [ ] 速い呼吸や呼吸困難
- [ ] 唇や顔が青紫色になる
- [ ] 胸の痛み
- [ ] けいれん
- [ ] 生後12週未満の乳児のあらゆる発熱
- [ ] 薬で下がらない40°C(104°F)以上の高熱

**先に受診すべき場合**

- [ ] 熱や咳が長引く、または原因不明の体重減少を伴うとき
- [ ] 中耳炎・肺炎・副鼻腔炎を繰り返す、または回復が極端に遅いとき
- [ ] 免疫抑制薬・ステロイド・抗がん剤を服用中、または糖尿病などの基礎疾患があるとき

## 4. サプリメントの判断表

| 成分 | 確認できたこと |
|---|---|
| ビタミンD | 韓国食品医薬品安全処(MFDS)の機能性は、カルシウム・リンの吸収と利用、骨の形成と維持などです。成人の耐容上限量は1日4,000 IU(NIH ODS)です。 |
| ビタミンC | Cochrane のレビュー:一般集団での定期的な摂取は風邪の発生を減らさず、症状の期間が成人で約8%、子どもで約14%短くなっただけでした。マラソンのような短期の高強度の身体的ストレスを受ける集団でのみ、発生リスクが半分になりました。 |
| 亜鉛 | MFDSの機能性表示に「正常な免疫機能に必要」があります。不足しないよう必要量を満たすという意味です。 |
| プロバイオティクス | MFDSの機能性は、乳酸菌の増殖と有害菌の抑制、排便活動、腸の健康です。 |
| オメガ3 | 青魚はバランスの取れた食事の一部です。 |
| エルダーベリー | 今回、1次情報で確認できたものはありません。 |
| ベータグルカン | 今回、1次情報で確認できたものはありません。 |

## 5. 日常の行動チェック

- [ ] 石けんと水でこまめに手を洗い、ない場合はアルコール手指消毒剤を使います。
- [ ] 咳やくしゃみのときはティッシュで鼻と口を覆い、ティッシュは捨てます。
- [ ] 具合が悪いときは家にとどまり、症状が改善し、解熱剤なしで熱が下がってから少なくとも24時間たって活動を再開します。
- [ ] ドアノブなど、よく触れる表面をこまめに拭きます。
- [ ] 外気を取り入れるか室内の空気を浄化して、空気の質を改善します。
