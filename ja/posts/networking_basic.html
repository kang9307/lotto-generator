TCP/IP ネットワーク基礎

TCP/IP Networking Basics

2025-06-01 開発・インフラ

ネットワークは現代のコンピューティング環境の中核です。本記事では TCP/IP ネットワークの基本概念と動作原理について見ていきます。

English: Networking is the core of modern computing environments. This article explores the basic concepts and operating principles of TCP/IP networks.

TCP/IP プロトコルスタック (TCP/IP Protocol Stack)

TCP/IP プロトコルスタックは 4 つの層で構成されます。

English: The TCP/IP protocol stack consists of 4 layers:

  1. アプリケーション層 (Application Layer): HTTP、FTP、DNS、SMTP など
  2. トランスポート層 (Transport Layer): TCP、UDP
  3. インターネット層 (Internet Layer): IP、ICMP、ARP
  4. ネットワークインターフェース層 (Network Interface Layer): イーサネット、Wi-Fi など

IP アドレス (IP Address)

IP アドレスはネットワーク上のデバイスを識別する一意のアドレスです。

English: An IP address is a unique address that identifies a device on a network.

IPv4 (Internet Protocol version 4)

IPv4 アドレスは 32 ビットで構成され、通常はドットで区切られた 4 つの数字で表現されます。

English: IPv4 addresses are 32-bit and typically represented as four numbers separated by dots.

192.168.1.1

IPv6 (Internet Protocol version 6)

IPv6 アドレスは 128 ビットで構成され、コロンで区切られた 8 つの 16 進数グループで表現されます。

English: IPv6 addresses are 128-bit and represented as eight groups of hexadecimal digits separated by colons. 

2001:0db8:85a3:0000:0000:8a2e:0370:7334

サブネットマスク (Subnet Mask)

サブネットマスクは、IP アドレスのうちネットワーク部分とホスト部分を区別するために使われます。

English: A subnet mask is used to distinguish the network portion from the host portion in an IP address.

IP アドレス (IP Address): 192.168.1.10
サブネットマスク (Subnet Mask): 255.255.255.0
ネットワークアドレス (Network Address): 192.168.1.0

ポート番号 (Port Numbers)

ポート番号は特定のプロセスを識別するために使われます。代表的なウェルノウンポート番号は以下のとおりです。

English: Port numbers are used to identify specific processes. Well-known port numbers include:

  • HTTP: 80
  • HTTPS: 443
  • FTP: 21
  • SSH: 22
  • SMTP: 25
  • DNS: 53

ネットワークコマンド (Network Commands)

ネットワークのトラブル調査に役立つコマンドは以下のとおりです。

English: Useful commands for diagnosing network problems include:

# ホストへの接続テスト (Test connection to a host)
ping google.com

# ネットワーク経路のトレース (Trace network path)
traceroute google.com

# ネットワークインターフェース情報の表示 (Display network interface information)
ifconfig    # Unix/Linux
ipconfig    # Windows

# DNS の問い合わせ (DNS lookup)
nslookup google.com

ネットワークの基本概念を理解しておくと、さまざまなネットワーク上の問題をより効果的に解決できるようになります。

English: Understanding the basic concepts of networking allows you to solve various network problems more effectively.
