Krea 2 — 12B 오픈 가중치 이미지 생성 모델이 생태계에 주는 의미

120억 파라미터 Diffusion Transformer의 오픈화 — 연구·파인튜닝·로컬 실행 생태계가 어떻게 달라지나

2026-06-27 IT/기술

서론: 이미지 생성 모델에도 오픈 가중치의 물결이 왔다

2026년 6월 23일, Krea AI가 Krea 2의 가중치를 Hugging Face에 공개했다. 120억(12B) 파라미터 규모의 Diffusion Transformer 기반 텍스트-이미지 생성 모델이다. 언어 모델 세계에서는 DeepSeek·Qwen·Llama 계열이 오픈 가중치를 당연한 것처럼 만들어 왔지만, 이미지 생성 분야는 달랐다. Midjourney는 여전히 완전 폐쇄형이고, Stable Diffusion 계열이 오픈 진영을 이끌어 왔으며, FLUX(Black Forest Labs)가 2024년 말 이 흐름에 새 힘을 실어줬다. Krea 2는 그 뒤를 잇는 사례다.

그런데 이번 공개가 단순히 "또 하나의 오픈 모델이 나왔다"는 이야기로 끝나지 않는 이유가 있다. Krea 2는 처음부터 scratch로 설계된 12B 규모 모델이고, 비증류 베이스(Raw)와 속도 최적화 체크포인트(Turbo) 두 가지를 동시에 내놓았으며, 상세한 기술 보고서까지 함께 공개했다. 이미지·멀티미디어 분야에서 중간 학습 단계 체크포인트까지 공개하는 것은 드문 일이라는 평가가 나오는 이유다.

이 글은 Krea 2가 정확히 무엇인지, 어떤 기술적 선택을 했는지, 그리고 이 공개가 이미지 생성 생태계 — 연구, 파인튜닝, 로컬 실행 — 에 무엇을 의미하는지를 본인 시각으로 정직하게 풀어 본다. 2026년 6월 기준이다.

1. Krea 2란 — 스크래치에서 만든 12B DiT 모델

Krea AI는 실시간 이미지 생성 캔버스로 알려진 스타트업이다. Krea 2는 그들이 처음으로 외부에 오픈 가중치로 공개하는 파운데이션 이미지 모델이다.

1.1 아키텍처: Diffusion Transformer

Krea 2의 핵심 구조는 Diffusion Transformer(DiT)다. FLUX나 SD3 계열이 택한 방향과 맥을 같이하면서도, Krea는 기존 체크포인트를 이어받지 않고 처음부터 설계했다. 주목할 기술 선택은 다음과 같다.

  • 주의 메커니즘: Gated Sigmoid Attention을 적용한 GQA(Grouped Query Attention) 구조로 계산 효율과 학습 안정성을 잡았다.
  • MLP: SwiGLU 레이어, 4배 확장 계수.
  • 텍스트 인코더: Qwen 3 VL을 채택했다. 다국어 지원과 풍부한 입력 표현 공간이 이유로 꼽힌다.
  • 자동 인코더: Qwen Image VAE와 FLUX 2 VAE를 결합해 사용한다.
  • 정규화: Zero-center RMSNorm과 QKNorm.

파라미터 수는 기술 보고서 기준 12B(120억)으로 알려져 있다. 아키텍처 선택 자체보다 인상적인 것은 학습 파이프라인의 세밀함이다.

1.2 5단계 학습 파이프라인

Krea 2의 학습은 단순히 "대량 데이터를 넣고 돌렸다"가 아니다. 사전학습 → 중간 학습 → 감독 파인튜닝(SFT) → 선호 최적화(PO) → 강화학습(RL)의 5단계 파이프라인을 거쳤다. 각 단계가 의미 있는 이유를 짚어 보자.

  • 사전학습: 256px → 512px → 1024px 해상도 순으로 점진적으로 높이는 커리큘럼 방식을 썼다. 초기 수렴 가속을 위해 iREPA를 첫 에폭에만 사용하고 이후 제거하는 방식이 흥미롭다.
  • 중간 학습: 고품질 데이터를 선별해 사전학습과 지도 학습 사이의 다리 역할을 한다. 이 단계 체크포인트까지 공개한 것이 이미지 생성 분야에서 드문 결정이다.
  • 감독 파인튜닝(SFT): 소규모 정제 데이터셋으로 미적 품질을 높인다. 도메인별 SFT 체크포인트의 모델 병합 전략도 포함된다.
  • 선호 최적화(PO): 합성 선호도 쌍과 인간 주석을 결합한 STPO(안정화된 DPO 변형)로 정책 편향을 줄인다.
  • 강화학습(RL): 미적 품질·프롬프트 추종·텍스트 렌더링·아티팩트 감지 4개 보상 모델을 동시에 쓰는 Multi-reward GRPO 방식이다.

한 가지 데이터 원칙이 눈에 띈다. "사전학습 데이터에 AI 생성 이미지를 넣지 않았다"는 것이다. 합성 데이터가 모델 품질의 천장을 낮춘다는 판단으로, 이는 언어 모델 쪽에서도 논쟁이 활발한 주제다. 이미지 생성 모델에서 이 원칙을 명시한 것은 장기적 품질 관리에 대한 입장 표명이다.

1.3 두 가지 체크포인트: Raw와 Turbo

Krea 2는 하나의 모델이 아니라 두 체크포인트로 구성된다.

  • Krea 2 Raw: 증류 없는 원본 체크포인트. LoRA 파인튜닝과 도메인 특화 후처리 연구를 위한 재료다. 자동차·건축·광고처럼 특정 도메인에 최적화된 변형을 만들려는 개발자를 겨냥한다.
  • Krea 2 Turbo: TDM(Trajectory Distribution Matching) 기법으로 증류해 8스텝에 2K 해상도 이미지를 약 2초에 생성한다. Classifier-Free Guidance를 비활성화해 속도를 극대화했다. 소비자용 하드웨어에서 실용적인 속도다.

권장 워크플로는 Raw에서 LoRA를 훈련한 뒤, 그 LoRA를 Turbo에 적용해 빠른 추론을 하는 방식이다. 베이스 모델과 추론 최적화 모델을 분리 공개한 이 결정은 연구자와 실무자 모두를 배려한 설계다.

2. 오픈 가중치가 이미지 생성 생태계에 주는 의미

Krea 2가 단순히 좋은 모델인 것을 넘어, 오픈 가중치라는 사실이 왜 중요한가. 세 가지 축으로 나눠 보자.

2.1 연구: 재현성과 탐구의 출발점

이미지 생성 연구에서 오픈 가중치는 단순한 공짜 API 이상이다. 가중치에 접근할 수 있어야 새로운 훈련 기법을 적용하고, 기존 방법과 비교하고, 재현 가능한 실험을 설계할 수 있다. 폐쇄형 모델로는 "이 결과가 왜 나왔나"를 검증하기 어렵다.

Krea가 기술 보고서와 함께 중간 학습 단계 체크포인트까지 공개한 것은 이 맥락에서 특히 값지다. 사전학습과 SFT 사이의 중간 체크포인트는 학습 단계별 모델 행동 변화를 실험하는 데 쓸 수 있다. 언어 모델 연구에서 이런 자료가 얼마나 소중한지를 생각하면, 이미지 생성 분야에서 같은 수준의 공개가 이루어졌다는 것은 의미가 있다.

또한 Krea의 기술 보고서는 인프라까지 공개한다. Kubernetes, Weka 파일시스템, PostgreSQL 기반 데이터 시스템의 구체적 구성이 문서화되어 있어, 유사한 규모의 훈련 인프라를 설계하려는 팀에 실질적 참고가 된다.

2.2 파인튜닝: 도메인 특화의 장벽을 낮추다

오픈 가중치의 두 번째 의미는 파인튜닝이다. 폐쇄형 이미지 생성 API에서 스타일 커스터마이즈는 한계가 있다. 특정 브랜드 비주얼, 특정 예술 스타일, 의료·산업용 도메인 이미지처럼 일반 모델이 제대로 다루지 못하는 영역에서는 파인튜닝이 필수다.

Krea 2 Raw는 이 용도를 직접 겨냥한다. LoRA 훈련이 가능한 베이스를 공개했다는 것은 개인 창작자부터 스튜디오까지 자체 데이터로 특화 모델을 만들 수 있음을 의미한다. 자동차 디자인, 건축 시각화, 광고 이미지처럼 특정 미학이 일관되어야 하는 분야에서 이 자유는 크다. 파인튜닝 결과를 Turbo에 적용해 빠른 추론까지 이어지는 워크플로는 실무 도입 장벽도 낮춘다.

Krea가 기술 보고서에서 향후 과제로 제안한 "MOPD(다중 교사 정책 내 증류)"도 주목할 만하다. 도메인별 RL 전문가를 회귀 위험 없이 훈련할 수 있도록 하는 이 방향은, 파인튜닝 생태계를 더 체계적으로 지원하려는 의도를 보인다.

2.3 로컬 실행: 프라이버시와 비용 통제

세 번째 의미는 로컬 실행이다. 이미지 생성도 언어 모델과 같은 이유로 로컬 실행이 중요한 상황이 있다.

첫째, 생성할 이미지의 시각적 컨셉이나 참조 자료가 외부 서버로 나가면 곤란한 경우다. 미출시 제품 디자인, 기밀 건축 도면, 의료 시각화처럼 보안이 중요한 작업이 해당한다. 둘째, 고볼륨 생성이 필요한 경우 API 과금이 아니라 보유 하드웨어 비용으로 전환할 수 있다. Krea 2 Turbo가 소비자용 하드웨어에서 2초 내 2K 이미지를 생성한다는 사실은 이 선택지를 현실적으로 만든다.

커뮤니티 반응에서도 ComfyUI 통합 논의와 GGUF 변환본이 빠르게 나온 것은 로컬 실행 수요가 실재함을 보여준다. 오픈 가중치가 공개되면 커뮤니티가 다양한 양자화·최적화 변형을 만들어 내는 것이 이제 패턴이 됐다.

3. 라이선스: 오픈인가, 제한적인가

Krea 2를 둘러싼 논쟁 중 가장 실질적인 것은 라이선스다. Krea는 이를 "커뮤니티 라이선스"라고 부르지만, MIT나 Apache 2.0 같은 완전 개방형과는 거리가 있다.

3.1 커뮤니티 라이선스 핵심 조건

  • 개인 및 50석 미만 팀: 상업적 사용 무상 허용.
  • 50석 이상 조직, SSO 통합, SLA, 커스텀 데이터 계약: 유료 엔터프라이즈 계약 필요.
  • 연매출 100만 달러 초과 시 상업적 사용 불가(일부 조건에 따라 다름).
  • 콘텐츠 필터링 안전장치 구현 의무.

GeekNews(news.hada.io) 댓글에서 가장 많이 제기된 비판도 이 지점이다. "연매출 100만 달러 초과 시 상업 사용이 불가하다면 진정한 오픈소스가 아니다"라는 지적이다. OSI(Open Source Initiative) 정의에서 오픈소스 라이선스는 어떤 사람이나 그룹을 차별해선 안 된다. 이 기준으로 보면 Krea 2 커뮤니티 라이선스는 오픈소스가 아니다.

3.2 이 라이선스를 어떻게 읽어야 하나

본인 해석은 이렇다. Krea 2의 라이선스는 개인 창작자·연구자·소규모 스튜디오에게는 매우 관대하다. 이들이 원하는 파인튜닝·로컬 실행·상업적 활용이 모두 허용된다. 그러나 대규모 상업 배포를 계획하는 기업에게는 제약이 있으며, 사전 검토가 필수다.

이 구조는 Krea가 커뮤니티와의 관계와 상업적 지속 가능성 사이의 균형을 의도적으로 설정한 결과다. Meta의 Llama 라이선스처럼 오픈 가중치지만 완전 개방이 아닌 "제한적 오픈" 모델이 이미지 생성 분야에도 정착하는 흐름이다. 이것이 나쁜 것인지, 현실적인 것인지는 관점에 따라 다르지만, 라이선스 세부 조건을 읽지 않고 "오픈 가중치니까 자유롭게 쓸 수 있겠지"라고 가정하는 것은 위험하다.

4. 폐쇄형 모델 대비 장단점 — Midjourney와의 비교를 중심으로

이미지 생성 시장에서 Midjourney는 여전히 폐쇄형의 대표 주자다. 품질과 일관성에서 강한 평판을 유지하면서도 가중치 접근은 전혀 허용하지 않는다. Krea 2와의 차이를 솔직하게 정리해 보자.

4.1 Krea 2의 강점

커스터마이즈 자유도가 가장 크다. Midjourney의 스타일 참조 파라미터(--sref)는 편리하지만 모델이 "스타일"을 해석하는 방식을 통제할 수 없다. Krea 2에서 Raw 체크포인트로 LoRA를 훈련하면 특정 도메인의 시각 언어를 모델 수준에서 내재화할 수 있다. 이 차이는 정밀한 브랜드 비주얼이나 도메인 특화 용도에서 결정적이다.

속도도 눈에 띈다. Krea 2 Turbo가 소비자 하드웨어에서 2K 이미지를 2초에 생성한다는 것은 실시간에 가까운 이터레이션이 가능함을 의미한다. Midjourney의 큐 방식과 근본적으로 다른 경험이다.

프라이버시와 데이터 통제도 중요하다. 로컬 실행이 가능하면 생성 프롬프트와 참조 이미지가 외부 서버를 거치지 않는다. 이는 규제 산업이나 기밀 프로젝트에서 폐쇄형 서비스가 줄 수 없는 보증이다.

4.2 Krea 2의 한계

객관적으로 말해야 한다. 기본 이미지 품질에서 Midjourney는 여전히 강하다. Artificial Analysis 리더보드에서 Krea 2가 독립 연구소 모델 중 2위를 기록한 것은 인상적이지만, 전체 리더보드 1위가 아니다. 기본 설정에서 꺼내는 "기본 아름다운 이미지"의 일관성에서 Midjourney의 쌓인 노하우는 무시할 수 없다.

이미지-이미지 편집과 고급 편집 기능에서도 커뮤니티 평가는 경쟁 모델 대비 아직 부족하다는 의견이 있다. 텍스트-이미지 생성에 초점이 맞춰진 현재 공개 범위에서 비롯된 한계다.

또한 로컬 실행의 하드웨어 요건도 현실이다. 12B 모델을 빠르게 돌리려면 충분한 VRAM이 필요하다. GGUF 변환 같은 커뮤니티 최적화가 나오고 있지만, "소비자 하드웨어"가 현실적으로 어느 수준을 의미하는지는 직접 확인해야 한다.

5. AI 이미지 모델의 오픈화 흐름 — 어디서 왔고 어디로 가나

Krea 2를 고립된 사건으로 보지 않으려면, 더 넓은 맥락을 봐야 한다. 이미지 생성 모델의 오픈화 흐름은 어디서 왔고 Krea 2는 그 흐름 안에서 어떤 의미인가.

5.1 FLUX가 연 새 챕터

2024년 Black Forest Labs의 FLUX는 Stable Diffusion 이후 오픈 이미지 생성의 기준점을 새로 세웠다. DiT 아키텍처, 높은 프롬프트 충실도, 상업 사용 가능한 라이선스 조합이 개발자 생태계에 빠르게 채택됐다. Krea 2는 이 흐름의 연장선에 있다. 다만 FLUX가 "오픈 가중치 + 유료 API" 조합을 택한 반면, Krea 2는 커뮤니티가 직접 가중치를 받아 실행하는 데 더 열려 있다.

5.2 독립 연구소가 프론티어급 모델을 공개한다는 것

Krea AI는 대형 AI 기업이 아니다. 작은 팀이 프론티어급 12B 모델을 처음부터 설계·훈련해 공개했다는 사실이 중요하다. 이는 이미지 생성 분야에서 "대형 자본이 있어야 좋은 모델을 만들 수 있다"는 가정을 흔드는 사례다. 물론 12B는 절대적으로 거대한 모델이 아니고, 훈련 인프라도 중소 규모다. 그러나 Artificial Analysis 리더보드 독립 연구소 2위라는 결과는, 아키텍처 선택과 학습 파이프라인의 정교함이 순수한 규모 경쟁을 어느 정도 상쇄할 수 있음을 보여준다.

5.3 라이선스 복잡화의 흐름

그러나 이미지 생성 모델 오픈화에서 한 가지 흐름도 함께 읽어야 한다. 라이선스의 복잡화다. Stable Diffusion 초기의 단순 CC 계열에서 점점 세밀한 조건이 붙는 방향으로 이동하고 있다. Llama의 사용량 기반 제약, FLUX의 용도별 구분, Krea의 규모 기반 제약이 그 예다. "오픈 가중치"와 "오픈소스"는 다르고, 각 모델의 조건을 꼼꼼히 읽어야 하는 시대가 됐다. 이 복잡성을 소화하는 비용이 커뮤니티에 전가되는 측면도 있다.

장기적으로, 이미지 생성 생태계에서 오픈 가중치의 정착은 연구와 파인튜닝 생태계를 언어 모델과 유사한 방식으로 성숙시킬 것으로 본다. 수백 개의 특화 LoRA, 커뮤니티 최적화, 독립 파인튜닝 서비스가 Krea 2를 기반으로 등장할 것이다. 그것이 오픈 가중치 공개의 실질적 파급이다.

6. 성능과 프롬프트 충실도 — 현재 알 수 있는 것

기술 수치는 명확하게 정리하고, 불확실한 것은 불확실하다고 말한다.

6.1 확인된 벤치마크

Krea의 공식 발표 기준으로, Krea 2는 Artificial Analysis 텍스트-이미지 리더보드 상위 10위권, 독립 연구소 모델 중 2위를 기록했다. 이 리더보드는 텍스트-이미지 정렬, 이미지 품질, 다양성 등 복합 기준을 사용한다. 2위라는 위치가 1위가 아님을 솔직히 말하는 것도 중요하다.

프롬프트 충실도와 관련해 Krea의 설계 원칙 중 주목할 것은 프롬프트 확장(Prompt Expansion)이다. 짧고 단순한 사용자 입력을 모델 친화적인 상세한 캡션으로 변환하는 기능인데, SFT와 RL 파이프라인으로 훈련되어 있다. 이 과정에서 다양성 보상(DINOv3 embedding diversity score)을 사용해 단일 스타일로 수렴하는 것을 막는다. 즉 같은 프롬프트에 대해 다양한 시각적 해석이 나오도록 설계됐다는 의미다.

6.2 불확실한 것

Krea 2의 성능 주장 중 독립 검증이 덜 된 부분도 있다. 특히 특정 미학 스타일에서의 일관성, 복잡한 합성 장면에서의 프롬프트 충실도, 다국어 프롬프트 품질 등은 개인 사용자 수준에서 직접 테스트해 봐야 알 수 있다. Krea의 스타일 참조 시스템이 "콘텐츠 누출을 최소화한다"고 설명하지만, 그 효과가 모든 스타일 유형에서 일관하는지는 경험적 검증이 필요하다.

7. 실무 활용 — 어디에, 어떻게 쓸 것인가

Krea 2를 실제로 도입한다면 어디서 쓸 것인가. 본인 판단을 정리해 보자.

7.1 Krea 2가 진짜 강한 상황

도메인 특화 파인튜닝이 필요한 팀이 첫 번째다. 특정 브랜드 비주얼 아이덴티티, 건축·제품 디자인 스타일, 또는 일반 모델이 잘 모르는 전문 분야 이미지를 생성해야 한다면 Raw에서 LoRA 훈련 후 Turbo에 적용하는 워크플로가 매력적이다. 폐쇄형 API로는 이 레벨의 커스터마이즈가 불가능하다.

빠른 이터레이션이 필요한 창작자도 수혜를 받는다. 2초 내 2K 이미지는 아이디어 탐색 속도를 근본적으로 바꾼다. 최종 이미지를 고품질로 뽑기 전 방향성을 빠르게 탐색하는 용도로 Turbo가 적합하다.

연구자에게는 중간 학습 체크포인트와 기술 보고서가 값지다. 이미지 생성 모델의 학습 단계별 행동을 연구하거나, 새로운 학습 기법의 기반으로 사용하려는 연구팀에 Krea 2는 드문 자료를 제공한다.

7.2 신중해야 할 상황

대규모 상업 배포를 계획하는 기업은 라이선스를 먼저 읽어야 한다. 50석 이상 또는 일정 매출 이상이면 엔터프라이즈 계약이 필요하다. "오픈이니까 자유롭게"라는 가정으로 도입했다가 나중에 계약 문제가 생길 수 있다.

또한 기본 품질이 절대적으로 최우선인 용도 — 최종 광고 크리에이티브, 출판물 이미지 — 에서는 여전히 여러 모델을 비교하는 것이 안전하다. Krea 2가 리더보드 독립 연구소 2위인 것과, 본인의 특정 용도에서 1위인 것은 다른 이야기다.

8. 결론 — 이미지 생성 오픈화의 한 이정표

Krea 2는 이미지 생성 모델 오픈화 흐름에서 의미 있는 이정표다. 12B 파라미터, 처음부터 설계한 DiT 아키텍처, Raw·Turbo 이중 체크포인트, 상세한 기술 보고서까지 — 단순히 가중치를 공개한 것이 아니라 생태계와의 진지한 대화를 시도한 공개다.

2026년 6월 기준으로 이 공개가 의미하는 것을 세 문장으로 압축하면 이렇다. 연구자는 이미지 생성 모델의 학습 내부를 들여다볼 드문 기회를 얻었다. 개발자와 창작자는 로컬에서 돌리고 파인튜닝할 수 있는 경쟁력 있는 12B 이미지 모델을 손에 넣었다. 그리고 AI 이미지 생성 생태계는 폐쇄형과 오픈형의 경계가 더 복잡해지는 시대로 진입했다.

라이선스 조건을 꼼꼼히 읽고, 본인 용도에서 직접 테스트하고, 결과를 근거로 판단하는 것이 지금 할 수 있는 가장 합리적인 접근이다.
