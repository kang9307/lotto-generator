子网(Subnet)이란?

子网은 IP 网络의 논리적 分钟할입니다. 子网팅을 通过 하나의 큰 网络를 여러 개의 작은 网络로 나눌 수 있으며, 이는 网络 관리와 효율성을 향상시킵니다.

周요 용어

  • IP地址: 인터넷 프로토콜에 使用되는 地址로, 장치를 식별하는 고유 号码입니다.
  • 子网掩码: IP地址에서 网络 부分钟과 主机 부分钟을 구分钟하는 值입니다.
  • CIDR (Classless Inter-Domain Routing): IP地址 할당 방법으로, /24와 같은 접두사 长度로 표현됩니다.
  • 网络地址: 해당 子网의 첫 번째 地址로, 主机 부分钟이 全部 0인 地址입니다.
  • 广播地址: 해당 子网의 最后一个 地址로, 主机 부分钟이 全部 1인 地址입니다.

子网计算器 使用법

  1. IP地址 输入 필드에 유효한 IPv4 地址를 输入합니다 (是: 192.168.1.0).
  2. CIDR表示法 또는 子网掩码 중 하나를 选择하여 输入합니다:
    • CIDR: 드롭다운 목록에서 적절한 프리픽스 长度를 选择합니다 (是: /24).
    • 子网掩码: 유효한 子网掩码를 输入합니다 (是: 255.255.255.0).
  3. "计算" 버튼을 클릭하여 结果를 确认합니다.

计算 结果 해석

  • 网络地址: 해당 子网의 开始 地址입니다.
  • 广播地址: 해당 子网의 最后一个 地址입니다.
  • 主机 수: 网络 내에서 使用 可用한 IP地址의 수입니다 (网络地址와 广播地址 排除).
  • 主机范围: 실제로 장치에 할당할 수 있는 IP地址의 范围입니다.
  • 바이너리 표현: IP地址와 子网掩码의 2진수 표현입니다.
