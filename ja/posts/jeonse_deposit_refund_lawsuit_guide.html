序論：チョンセ詐欺・逆チョンセ以後の保証金返還の現実

2022年から本格化した韓国のチョンセ（전세）詐欺事態と逆チョンセ難以降、契約が終わっても保証金を期限どおりに返してもらえない賃借人が増えました。被害規模を示す保証事故の統計は毎年変わるため、最新の数値はHUG（住宅都市保証公社）と国土交通部の発表で確認してください。チョンセ詐欺の被害を受けた場合、「チョンセ詐欺被害者支援及び住居安定に関する特別法」の有効期間が2027年5月31日まで延長され、それまで被害者決定を申請できます。ただし、2025年6月1日以降に初めて賃貸借契約を結んだ賃借人は適用対象から除かれます（大韓民国政策ブリーフィング、2025-05-02）。

契約満了を迎えても、賃貸人が「次の入居者が見つからないと返せない」「資金がない」と言って返還を先延ばしにする例が珍しくなくなりました。保証金が拘束されて新居を契約できなかったり、ローンの利息ばかり膨らんだりする被害も生じます。このような状況では、待っているだけでは賃借人の権利を守るのは難しいのが実情です。

以下では、韓国の制度に基づき、賃借権登記命令、内容証明、支払命令、本案訴訟、強制執行までの保証金返還手続を段階ごとに整理します。法令・印紙額・送達料は2026年9月29日時点の国家法令情報センターの現行条文と「探しやすい生活法令情報」に従い、公式の根拠がない期間・費用の例は別途表示しています。借主の権利全般は賃貸借保護法・借主の権利 完全ガイド、契約段階の確認は2026年チョンセ・ウォルセ契約チェックリストで扱っています。

1. 保証金返還を求める前の準備段階

訴訟の前に整えておくべき準備があります。この段階を逃すと、契約が自動的に延長されたり、対抗力と優先弁済権を失ったりして、法的に不利な立場に置かれることがあります。

1.1 契約終了前の更新拒絶の通知

韓国の住宅賃貸借保護法第6条第1項は、賃貸人が賃貸借期間終了の6か月前から2か月前までに更新拒絶の通知をしなかった場合、また賃借人が期間終了の2か月前までに通知しなかった場合に、従前と同一の条件で再び賃貸借したものとみなすと定めています（黙示的更新）。この場合の存続期間は2年とみなされます（同条第2項）。

  • 通知時期：賃借人は満了の2か月前までに更新しない旨を伝えなければなりません。この「2か月前まで」は2020年6月9日改正の条文です（国家法令情報センター、2026-09-29確認）
  • 通知方法：ショートメッセージ、カカオトーク、メールも可能ですが、到達の事実と内容を残すには内容証明郵便が最も確実な証拠になります
  • 文言の例：「契約を更新せず、満了日に保証金全額の返還を求めます」のように、更新拒絶と返還請求を併せて明確に書きます
  • 黙示的更新になった場合：賃借人はいつでも契約解止を通知でき、賃貸人がその通知を受けた日から3か月が経過すると解止の効力が生じます（第6条の2）
  • 証拠の保存：発送の領収書、配達の記録、返信のスクリーンショットなどは別のフォルダーに保管します

1.2 賃借権登記命令の申立て（対抗力の維持）

契約が終了したのに保証金を返してもらえないまま引っ越さなければならない場合は、まず賃借権登記命令を検討します。賃借権登記を済ませれば、その後転居して対抗要件を失っても、すでに取得した対抗力と優先弁済権は失われません（住宅賃貸借保護法第3条の3第5項）。逆に登記が完了する前に転出するとこの保護を失うおそれがあるため、登記事項証明書で「住宅賃借権」の記載を確認してから引っ越すのが安全です。

  • 申立先：賃借住宅の所在地を管轄する地方法院・地方法院支院または市・郡法院（第3条の3第1項）
  • 要件と書類：賃貸借終了後に保証金が返還されない場合に申し立て、申立ての理由と賃借権登記の原因となった事実を疎明しなければなりません（同条第1項・第2項）。賃貸借契約書の写し、住民登録謄本、建物の登記事項証明書など正確な添付書類は申立先の法院の案内で確認します
  • 送達前の執行：2023年4月18日の改正で民事執行法第292条第3項が準用され、決定が賃貸人に送達される前でも賃借権登記を執行できるようになりました（同条第3項）
  • 費用：申立てと登記にかかった費用は賃貸人に請求できます（同条第8項）。印紙・送達料・登録免許税など実際の納付額は法院の案内で確認します
  • 所要期間：決定と登記までの期間は法院の事情によって異なるため、引っ越しの日程は登記完了を確認した後に組むのが安全です
  • 注意事項：登記完了前に転出すると対抗力が消滅するおそれがあります。必ず登記事項証明書で「住宅賃借権」の記載を確認してから転出します

1.3 内容証明の発送

内容証明郵便はそれ自体に強制力はありませんが、後の訴訟で賃借人が保証金の返還を正式に請求したことを示す資料になります。履行を請求する内容証明は韓国民法第174条の「催告」となり得ますが、6か月以内に裁判上の請求・差押え・仮差押えなどをしなければ時効中断の効力はありません。書き方と発送手順は内容証明（내용증명）作成法 完全ガイドで詳しく整理しています。

  • 記載内容：契約の概要、満了日、返還を求める金額、返還期限（例：到達後14日）、不履行の場合に予定する法的手続
  • 発送方法：郵便局の窓口またはインターネット郵便局から発送できます
  • 費用：韓国郵政事業本部の案内（2026-09-29確認）では、通常郵便500ウォン（25g以下の規格）＋書留2,400ウォン＋内容証明手数料が謄本1枚1,300ウォン（1枚を超えるごとに650ウォン）です。A4で1枚なら4,200ウォン、2枚なら4,850ウォンで、重さや付加サービスで変わります
  • 保管：発送後に戻される謄本と領収書は訴訟の証拠になるため、必ず保管します

2. 支払命令の申立て（簡易手続）

支払命令は、金銭などの支払いを目的とする請求について、法院が債務者を審尋せず債権者の申立てだけで発する命令です（韓国民事訴訟法第462条・第467条）。金額と債権関係が明確な保証金返還の事案でまず検討できます。ただし、大韓民国内で公示送達以外の方法で送達できる場合に限られるため（第462条ただし書）、賃貸人の住所を知っている必要があります。

2.1 申立方法と必要書類

支払命令は韓国法院の電子訴訟（ecfs.scourt.go.kr）でも申し立てることができ、法院に出向かずに進められます。

  • 管轄法院：債務者（賃貸人）の普通裁判籍所在地の地方法院、または民事訴訟法第7条〜第9条・第12条・第18条による管轄法院の専属管轄です（第463条）
  • 必要書類：支払命令申立書とともに、賃貸借契約書の写し、内容証明の写し、賃借権登記関連書類、不動産登記事項証明書などを請求を裏付ける資料として提出します
  • 作成のポイント：元金と遅延損害金を記載します。金銭債務不履行の損害賠償額は約定がなければ民法上の法定利率年5%により（民法第379条・第397条）、支払命令申立書のような訴状に準ずる書面が債務者に送達された翌日からは年12%です（訴訟促進等に関する特例法第3条第1項）。起算日は事案によって異なり得ます
  • 電子訴訟：法院に行かずに申し立て、進行状況を確認できます。電子文書で提出すると印紙額の10分の9に当たる印紙だけを貼ります（民事訴訟等印紙法第16条）

2.2 印紙額・送達料（2026年9月確認）

支払命令申立書には、訴状に貼る印紙額の10分の1に当たる印紙を貼ります（民事訴訟等印紙法第7条第2項）。2026年9月29日時点の計算は次のとおりです。

  • 訴状の印紙額：訴額1千万ウォン未満は1万分の50、1千万ウォン以上1億ウォン未満は1万分の45に5,000ウォンを加えた額、1億ウォン以上10億ウォン未満は1万分の40に55,000ウォンを加えた額、10億ウォン以上は1万分の35に555,000ウォンを加えた額です。1千ウォン未満は1千ウォンとし、1千ウォン以上は100ウォン未満を切り捨てます（同法第2条）
  • 例（保証金1億ウォン）：訴状の印紙額455,000ウォンの10分の1である45,500ウォンが支払命令の印紙額です。電子訴訟ならその10分の9（約4万1千ウォン）です
  • 送達料：1回分の送達料×当事者数×6回分です。1回分は5,640ウォンと案内されており（探しやすい生活法令情報、2026-09-15基準）、賃借人と賃貸人の2人なら67,680ウォンです
  • 異議で訴訟に移行した場合：訴状の印紙額からすでに貼った印紙額を差し引いた額を補正しなければなりません（民事訴訟法第473条第1項、印紙法第7条第3項）。1億ウォンの例なら455,000−45,500＝409,500ウォンで、期間内に補正しなければ申立書は却下されます（第473条第2項）
  • 合計の例（保証金1億ウォン、書面提出）：支払命令段階の印紙45,500ウォン＋送達料67,680ウォン＝約11万3千ウォンです

2.3 異議申立てと訴訟への移行

債務者が支払命令の送達を受けた日から2週間以内に異議申立てをすると、支払命令はその範囲で効力を失い（民事訴訟法第470条第1項）、支払命令を申し立てた時に訴えが提起されたものとみなされます（第472条第2項）。

  • 異議申立期間：支払命令の送達を受けた日から2週間以内で、不変期間です（第470条）
  • 異議がない場合：支払命令は確定判決と同じ効力を持ちます（第474条）。確定した支払命令に基づく強制執行は、原則として執行文の付与を受けずに支払命令の正本で行います（民事執行法第58条第1項）
  • 異議がある場合：訴訟に移行し、印紙が補正されると記録が管轄法院に送られます（第473条第3項）。督促手続の費用は訴訟費用の一部となります（同条第4項）
  • 送達できない場合：支払命令は公示送達ではできません。法院から住所補正命令を受けた債権者は訴え提起の申立てができ、公示送達によらなければ送達できない場合は法院が職権で事件を訴訟手続に付すことができます（第466条）。賃貸人と連絡が取れないなら、最初から本案訴訟を起こす方法も検討します

3. 保証金返還請求の本案訴訟

支払命令に異議が出た場合や最初から訴訟を選ぶ場合は、正式な民事訴訟として進みます。時間と費用はかかりますが、証拠調べと弁論を経て判決を受けます。請求額が3,000万ウォン以下の金銭請求の第1審事件は少額事件として扱われ（少額事件審判規則第1条の2）、その手続は少額訴訟完全ガイド2026にまとめています。

3.1 訴状作成のポイント

訴状には請求の趣旨と請求の原因を明確に記載し、証拠資料を併せて提出します。

  • 請求の趣旨の例：「被告は原告に対し○○○ウォン及びこれに対する○年○月○日から本件訴状副本送達日までは年5%、その翌日から支払済みまでは年12%の各割合による金員を支払え」
  • 請求の原因：賃貸借契約の締結、期間満了、保証金返還義務の発生、返還請求と不履行の事実を時系列で記述します
  • 添付証拠：賃貸借契約書、内容証明、登記事項証明書、賃借権登記命令の決定文、ショートメッセージ・カカオトークのやり取り、振込記録
  • 遅延損害金の利率：訴状またはこれに準ずる書面が債務者に送達された翌日から年12%です（訴訟促進等に関する特例法第3条第1項、2019年6月1日施行の法定利率規定）。ただし、債務者が履行義務の存否や範囲を争うことが相当と認められる場合は、その範囲で適用されません（同条第2項）
  • 弁護士への依頼：保証金の額が大きい場合やチョンセ詐欺の疑いがある場合は専門家への相談を勧めます。報酬は事務所ごとに定めるため、依頼前に書面の契約で確認します

3.2 予想される所要期間

以下の期間は旧版に載せていた一般的な例で、法院の統計に裏付けられた数値ではありません（2026年4月時点、更新未確認）。実際の期間は法院の事情と事件の複雑さによって大きく異なります。

  • 訴状受理〜被告の答弁書提出：約1〜2か月
  • 第1回弁論期日：訴状受理後2〜3か月の時点
  • 追加の弁論・証拠調べ：2〜3回、期日の間隔は1〜2か月
  • 判決言渡し：弁論終結後2〜4週間
  • 全体：単純な事件は6か月前後、賃貸人が争う事件や公示送達が必要な事件は1年以上
  • 控訴する場合：さらに数か月から1年以上かかることがあります

3.3 勝訴と実際の回収は別物

契約書・賃借権登記・内容証明のように証拠がそろった事件では、判決を得ること自体より、判決後に実際にお金を回収する方が難しい場合が少なくありません。旧版にあった「第1審勝訴率約92%」「実際の回収率55〜65%」は出典を確認できなかったため削除しました。

  • 回収に失敗する主な原因：(1)賃貸人の無資力・破産、(2)先順位の根抵当権の過多、(3)競売の流札の繰り返し
  • 保全処分：判決前に賃貸人が財産を処分するおそれがあれば、仮差押えで財産を押さえる方法を検討します
  • 執行の準備：金銭の支払いを命じる執行権原を得たら、債務者の普通裁判籍所在地の法院に財産明示を申し立てることができます（民事執行法第61条）

4. 強制執行（判決後）

確定判決や確定した支払命令などの執行権原を得たら、これに基づいて強制執行を申し立てることができます。実際に保証金を取り戻す段階です。

4.1 不動産の強制競売

賃貸人所有の賃借住宅やほかの不動産に対する強制競売は、最も直接的な回収手段です。

  • 申立先：不動産所在地を管轄する地方法院
  • 必要書類：執行力のある正本（判決は執行文の付与を受けたもの、確定した支払命令は原則として正本そのもの）、送達証明、登記事項証明書など
  • 反対義務の履行は不要：賃借人が賃借住宅について保証金返還請求訴訟の確定判決などの執行権原で競売を申し立てる場合、住宅を明け渡す反対義務の履行や履行の提供は執行開始の要件とされません（住宅賃貸借保護法第3条の2第1項）。ただし、優先弁済権で保証金を受け取るには住宅を買受人に引き渡さなければなりません（同条第3項）
  • 費用：競売申立登記の登録免許税は債権額の1千分の2で（地方税法第28条第1項第1号ラ目）、地方教育税がその100分の20なので（第151条第1項第2号）、合計で債権額の0.24%です。競売の予納金は法院が定めるため、申立先の法院に問い合わせます
  • 配当順位：抵当権・租税債権などの先順位が優先され、賃借人は対抗要件と確定日付に基づく優先弁済権の順位で配当を受けます。少額賃借人の最優先弁済の基準は賃貸借保護法・借主の権利 完全ガイドを参照してください
  • 期間と流札：申立てから配当までの期間や、流札時に最低売却価格を引き下げる割合は法院や事件ごとに異なるため、売却期日の公告で確認します。先順位の債権が多いと配当を受けられないことがあります

4.2 預金・給与の差押え

不動産以外にも、賃貸人の預金、給与、事業収入などの金銭債権に強制執行ができます。ただし、法が定める生計費相当額は差し押さえることができず、その基準額は2026年2月1日から引き上げられました。

  • 債権差押え及び取立命令：第三債務者（銀行など）から直接取り立てられるようにする命令です。決定までの期間は法院の事情によって異なります
  • 財産照会：財産明示手続で債務者が提出した財産目録だけでは足りない場合などに、債権者の申立てにより金融機関などに債務者名義の財産を照会します。照会先を特定し、費用を予納しなければなりません（民事執行法第74条）
  • 給与差押えの限度：給与債権の2分の1は差し押さえることができません。その2分の1の額が月250万ウォンに満たなければ250万ウォンまで差押えが禁止され、月300万ウォンを超えれば300万ウォンに（2分の1の額−300万ウォン）の2分の1を加えた額までだけ差押えが禁止されます（民事執行法第246条第1項第4号、施行令第3条・第4条）。250万ウォンの基準は2026年2月1日以降に受け付けた差押命令から適用されます（従前は185万ウォン）
  • 差押禁止の預金：個人別残高250万ウォン以下の預金などは差し押さえることができず（施行令第7条）、差押禁止の生計費だけを預け入れる「生計費口座」制度も新設されました（民事執行法第246条の2、施行令第8条）
  • 事業者の売上の差押え：カード売上債権、賃料収入、取引先の未収金も対象になり得ます
  • 実務のヒント：取引銀行が分かっていれば、複数の銀行に同時に申し立てるのが効果的です

4.3 チョンセ保証金返還保証の活用

契約時にHUG（住宅都市保証公社）やSGIソウル保証などのチョンセ保証金返還保証に加入していれば、賃貸人を相手にした長い訴訟の代わりに保証機関に保証の履行を請求できます。要件と書類は保証約款に従うため、請求前に保証機関で現在の基準を確認する必要があります。

  • 履行請求の要件：保証約款とHUGの案内に従います。旧版は「契約満了後1か月経過、賃借権登記命令の完了」を要件として案内しており（2026年4月時点、更新未確認）、請求前にHUGで現在の要件を確認します
  • 必要書類：保証書、賃貸借契約書、賃借権登記関連書類、住民登録謄本など（2026年4月時点、更新未確認）
  • 支払時期：保証事故が起きてから保証金を受け取るまで数か月かかることがあるため、引っ越しやローンの日程に余裕を持たせます
  • 求償権：保証機関は賃借人に支払った後、賃貸人に求償権を行使します
  • 加入基準：HUGの返還保証のチョンセ価率基準は、新規契約に2023年5月1日から90%が適用されています（大韓民国政策ブリーフィング、2023-02-02）。保証料率年0.115〜0.154%は2022年11月の政策ブリーフィング資料に基づくため、加入前に現在の料率を確認します
  • ほかの保証機関：SGIソウル保証など他機関の商品は要件と限度が異なるため、その機関の約款で確認します

結論：保証金を早く回収するための5段階戦略

チョンセ保証金の返還は感情ではなく手続の勝負です。賃貸人との交渉だけに時間を使うより、期限に合わせて法的手続を踏んでいく方が、結果的に回収を早められます。一般的な流れは次のとおりです。

  • 第1段階（満了6か月前〜2か月前）：遅くとも満了2か月前までに更新拒絶の意思を通知し、返還保証の加入有無を確認します
  • 第2段階（満了前後）：返還を求める内容証明を送り、新居の契約と引っ越しの日程を立てます
  • 第3段階（満了直後）：賃借権登記命令を申し立て（引っ越し前に登記を確認）、返還保証の加入者は保証機関で請求手続を確認します
  • 第4段階（その後）：返還保証の未加入者は、賃貸人の住所が分かれば支払命令、分からないか争いが大きければ訴訟を起こします。内容証明で催告したなら6か月以内に後続手続をとります
  • 第5段階（執行権原の取得後）：不動産の強制競売と債権差押えを申し立て、必要なら財産明示・財産照会で執行対象を探します

最も大切な原則は「遅滞なく、証拠とともに」進めることです。ここで扱った内容は一般的な情報提供を目的とするもので、法律相談ではありません。同じ手続でも個別の事実関係によって結果が変わるため、一人で進めるのが難しければ、弁護士、大韓法律救助公団（局番なし132）、住宅賃貸借紛争調停委員会、HUGのチョンセ被害支援センターなどに相談してください。

# チョンセ保証金返還手続チェックリスト（韓国基準）

基準日：2026-09-29。法令・印紙額・送達料は韓国の国家法令情報センターと「探しやすい生活法令情報」で確認した値です。一般的な情報であり、法律相談ではありません。個別の事案は弁護士や大韓法律救助公団（132）に相談してください。

## 1. 段階別チェックリスト

### 満了前
- [ ] 満了2か月前までに更新しない旨を通知した（住宅賃貸借保護法第6条第1項）
- [ ] 到達と内容が残る方法（内容証明など）で通知した
- [ ] 返還保証の加入有無と保証機関を確認した
- [ ] 黙示的更新になった場合：解止通知から3か月経過で効力発生（第6条の2）

### 満了直後・引っ越し前
- [ ] 賃借権登記命令を申し立てた（住宅所在地を管轄する地方法院・支院・市郡法院）
- [ ] 登記事項証明書で「住宅賃借権」の記載を確認してから引っ越す
- [ ] 申立て・登記費用の領収書を保管した（賃貸人に請求可能、第3条の3第8項）
- [ ] 返還を求める内容証明を送った（催告後6か月以内に後続手続がなければ時効中断の効力なし、民法第174条）

### 回収手続
- [ ] 賃貸人の住所が分かる → 支払命令を検討（公示送達でしか送達できなければ不可）
- [ ] 住所が分からない・争いが大きい → 本案訴訟を検討
- [ ] 請求額3,000万ウォン以下 → 少額事件（少額事件審判規則第1条の2）
- [ ] 判決前の財産処分が心配 → 仮差押えを検討

### 執行権原の取得後
- [ ] 確定した支払命令は原則として執行文なしで正本により執行（民事執行法第58条）
- [ ] 賃借住宅の競売申立てで先に明け渡す必要はない（住宅賃貸借保護法第3条の2第1項）
- [ ] ただし優先弁済で配当を受けるには住宅の引渡しが必要（同条第3項）
- [ ] 財産が見つからなければ財産明示（第61条）→ 財産照会（第74条）
