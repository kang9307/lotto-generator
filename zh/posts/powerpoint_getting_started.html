先确定的事 - 基准版本与「做什么、为什么、在哪里」

第一次使用 PowerPoint 的人遇到困难，往往不是因为功能不够，而是不知道该用哪个菜单、按什么顺序。在没有安装相同字体的电脑上打开文件，字体、版式和样式可能发生变化，文档说明嵌入字体就是防止这种情况的办法。下面按照制作一套幻灯片的顺序，逐项写明做什么、为什么在这一步做、在哪个菜单里做。

  • 基准产品：Windows 版 Microsoft 365 的 PowerPoint。新建演示文稿、主题和文件大小文档的适用产品列表中还列有 PowerPoint 2024、2021、2019、2016，PDF 文档的列表中还列有 Mac 版产品。
  • 菜单写法与 macOS：按「选项卡 > 按钮」的顺序书写，例如「开始 > 新建幻灯片」。名称是把韩语文档的措辞译成中文的结果，与中文界面略有出入时，以项目的位置为线索。仅在文档单独写出 macOS 路径的项目（保存为 PDF、关闭母版视图、对象对齐的智能参考线）上补充差异，其他 macOS 与网页版的差异不在讨论范围内。
  • 范围：只涉及文档能够确认的项目（新建演示文稿、版式、幻灯片母版、主题、对象对齐、每张幻灯片的文字量、演示快捷键、演示者视图、PDF、嵌入字体、文件大小），无法确认的项目不以推测补足。

实际的工作顺序是新建演示文稿、1、2、撰写内容、3 和 4 的练习、5、6、7 的发布准备。新建演示文稿的做法是打开 PowerPoint，在侧窗格中选择新建，具体菜单写在下面的版式一节。跳过 1 直接从 2 开始，同样能做出文件。不过文档把母版描述为增加一致性、统一形态的工具，所以打算使用共用样式时，先打开母版的顺序与文档的说明相符。

幻灯片版式 - 为每张幻灯片选的框架

文档对版式的定义是：PowerPoint 的每个主题都包含一组幻灯片版式，即为幻灯片内容预先定义好的排布。版式中的占位符框，是放置文本、视频、图片、图表等内容的空间。因此选择类似「标题和内容」的框架，标题框与正文框的位置和大小就已固定，使用者只需往里填写。

  • 开始新演示文稿时：打开 PowerPoint，在侧窗格中选择新建。要从头制作选择空白演示文稿，要用现成设计选择其中一个模板，想看 PowerPoint 的使用提示则选择导览，再选择创建。文档补充说，也可以从 Microsoft Create 中专业设计的模板开始。添加幻灯片时，在侧窗格的缩略图中选择新幻灯片要接在其后的那一张，再在开始选项卡的幻灯片部分选择新建幻灯片。内容通过在文本框中放置光标输入，格式则选中文本后在开始选项卡的字体部分设置。图片从插入选项卡的图像部分添加，形状、图标、3D 模型、SmartArt 和图表则在插图部分。
  • 为新幻灯片选择版式时：在开始选项卡中选择新建幻灯片，再选取想要的版式。新幻灯片添加的那一刻，框架就确定了。
  • 更改已有幻灯片的框架时：先选中幻灯片，再在开始 > 幻灯片版式中选择想要的版式。
  • 版面变乱时：选择开始 > 重置，即可恢复原版式。文档写明，此操作不会删除已添加的内容。
  • 占位符的作用：按文档的定义，占位符是放置文本、视频、图片、图表等内容的固定位置。位置固定，所以不必每次重画文本框，就能把同类内容放在同一位置。手工绘制的文本框如何响应母版的更改，文档中无法确认。在版式中添加、编辑或删除占位符的方法另有文档介绍，未查阅。
  • 版式中包含的内容：文档写明，版式中有放置文本、视频、图片、图表、形状、剪贴画、背景等的占位符，并且包含主题颜色、字体和效果等格式。文档举出的预定义版式例子有用来开头的标题幻灯片、常规的标题和内容、并排的比较，以及带标题的图片。标准版式是在普通视图的开始选项卡中点击版式，选取最适合幻灯片内容的那一个。
  • 形状与图片的对齐：要选中多个对象，先选第一个对象，再按住 Ctrl 键选其他对象。图片使用图片格式选项卡，形状、文本框或 WordArt 使用形状格式选项卡，在排列组中选择对齐，再从菜单中选择左对齐、居中对齐、右对齐、顶端对齐、居中对齐或底端对齐。文档把居中对齐列了两次，说明分别是穿过对象中心的垂直对齐和穿过对象中间的水平对齐。对齐选项不可用时，可能只选了一个对象。要让对象间距相等，选中三个或更多对象，再选择横向分布或纵向分布。要选中被文本遮住或叠放在后面的对象，在开始选项卡中选择选择，再选择选择对象，然后在对象上方画出一个框。对于 macOS 版 PowerPoint，文档介绍了在形状格式选项卡 > 对齐中选择对齐幻灯片的方法，以及拖动对象时出现的智能参考线（视图菜单 > 网格和参考线 > 智能参考线）。
  • 每张幻灯片的文字量：文档没有给出行数或字数之类的数字。在要求保持文本简单、尽量减少幻灯片文本量的条目下，文档说要使用项目符号或短句，并让每一行保持为一行（不换行），理由是希望观众听演讲而不是读屏幕。文档还指出，有些投影仪会裁掉幻灯片边缘，长句可能被截断。字体方面，要选 Arial 或 Calibri 这类简单字体，避开很细或装饰性的字体，并说不要使用小于 18pt 的字号（观众离得远的大房间还要更大）。文档还建议在背景色和文字颜色之间使用高对比度（主题会自动设置浅色背景配深色文字，或深色背景配浅色文字的对比），并检查拼写和语法。

幻灯片母版 - 为什么要先定

按文档的说法，幻灯片母版是为颜色、字体、标题、徽标等样式增加一致性、统一演示文稿形态的工具。同一文档还写道，在母版中可以编辑颜色、字体和效果，移动、隐藏或显示占位符，并把幻灯片方向从纵向改为横向（或相反）。文档还写明可以创建一个或多个母版，并介绍了更改完成后保存为可重复使用的模板的方法（文件 > 另存为，把文件类型改为模板）。

「为什么先定」，文档的答案在母版的定义里。母版是为颜色、字体、标题、徽标等样式增加一致性、统一演示文稿形态的工具，所以把共用样式放在母版中确定，与文档的说明相符。文档没有说明在母版中所做的更改如何传到已有的幻灯片。

  1. 在视图选项卡中选择幻灯片母版。文档中 Windows 与 macOS 写的是同一个选项卡名称。
  2. 在幻灯片缩略图窗格中，母版是上方较大的幻灯片图像，与之相连的版式排在其下。要删除内置版式，先选中要删除的版式，再在幻灯片母版选项卡中选择删除。
  3. 在母版中更改颜色、字体和效果。幻灯片方向则在幻灯片母版选项卡中选择幻灯片大小 > 自定义幻灯片大小，再选择方向。
  4. 按需要移动、隐藏或显示占位符。特定类型的幻灯片是否显示页脚（幻灯片编号、日期和页脚文本占位符），要在缩略图窗格中选中幻灯片版式，再在幻灯片母版选项卡中勾选或清除页脚来决定。
  5. 工作结束后，在幻灯片母版选项卡中选择关闭母版视图。macOS 上同一位置是关闭母版。
  • 通过主题更改颜色和字体：按母版文档指向的另一篇文档《使用主题为幻灯片添加颜色和设计》，PowerPoint 提供带有协调配色方案、背景、字体样式和占位符布局的设计主题。开始新演示文稿时可在文件 > 新建中选择主题，之后可在设计选项卡中选择喜欢的颜色、字体和效果的主题，或在变体组中应用其他颜色变体。变体组的向下箭头中可以选择颜色、字体、效果和背景样式，或自行定制，完成后在主题组的向下箭头中选择保存当前主题并命名，它就会出现在主题组的自定义标题之下。文档写明，这些内置主题适用于宽屏（16:9）和标准屏幕（4:3）两种演示文稿；如果看不到变体，可能是因为正在使用自定义主题或为旧版本设计的旧主题，或者是从使用这类主题的演示文稿中导入了部分幻灯片。
  • 没有触及母版的幻灯片：已有幻灯片上单独设置的格式，可能不受母版更改影响而保留下来。文档没有明说这一点，所以更改母版后，打开几张幻灯片核对外观更稳妥。用 Shift+F5 在放映画面中查看是较快的办法。
  • 一个演示文稿中有多个母版：在幻灯片缩略图窗格中点击新母版要出现的位置，再在幻灯片母版选项卡中选择插入幻灯片母版。另有一篇题为《在一个演示文稿中使用多个幻灯片母版》的文档，未查阅。

开始演讲 - 放映快捷键与演示者视图

演示用的快捷键，只写 Microsoft 支持网站快捷键文档中能够确认的内容。文档分别介绍 Windows、macOS 和网页版，并写明演示中打开快捷键列表的按键不同：Windows 是 F1，macOS 是斜杠（/）。以下写法以 Windows 为准。

按键动作（文档措辞）使用场合
F5从头开始放映演示文稿从第一张开始完整排练或正式演讲
Shift+F5从当前幻灯片开始放映演示文稿立即在放映画面中查看正在编辑的幻灯片
Alt+F5在演示者视图中开始放映演示文稿一边看备注和计时器一边练习
Esc结束放映演示文稿退出放映，回到编辑画面
N、Enter、Page Down、右箭头、下箭头、空格键执行下一个动画或前进到下一张幻灯片向前翻页时
P、Page Up、左箭头、上箭头、Backspace执行上一个动画或返回上一张幻灯片往回翻页时
B 或句号(.)显示黑色空白幻灯片，或从中返回想让观众的视线集中到讲者身上时
W 或逗号(,)显示白色空白幻灯片，或从中返回用明亮的背景暂时清空画面时

编辑时最常用的是 F5 与 Shift+F5 的区别。若正在处理第15张，F5 需要从第1张翻到第15张，Shift+F5 则直接从第15张开始。切换到下一张或上一张的按键，已按文档措辞写在表的最后两行。同一文档还写明，要跳到特定幻灯片，输入幻灯片编号后按 Enter 键；所有幻灯片对话框用 Ctrl+S，第一张幻灯片用 Home，最后一张用 End。文档还写明，放映过程中 Ctrl+L 启动激光笔，Ctrl+P 把指针改为笔，按 E 键可以清除屏幕上的批注。

  • 打开演示者视图的方法：在幻灯片放映选项卡中勾选使用演示者视图复选框，选择显示演示者视图的显示器，然后按 F5 或选择从头开始。
  • 演示者视图中显示的内容：当前幻灯片、下一张幻灯片和演讲者备注。文档写道，可以用幻灯片编号旁的箭头在幻灯片之间移动，暂停或重置计时器，查看当前时间，放大或缩小备注字体，使用绘图与激光笔工具，放大幻灯片，并暂时让屏幕变黑。
  • 为什么使用：快捷键文档把演示者视图解释为：在一块屏幕（例如笔记本电脑）上连同演讲者备注查看演示文稿，观众则在另一块屏幕上看不带备注的演示文稿。
  • 只有一台显示器时：连接到第二个显示器后，开始幻灯片放映时会自动显示演示者视图。如果没有自动启动，就在幻灯片放映选项卡中勾选使用演示者视图复选框，并选择主显示器。即使只有一个显示器，快捷键文档也写明，要在演示者视图中开始放映，可以按 Alt+F5。在演示者视图内部，用 F6 键在各个区域之间循环，用 Tab 键在区域内的工具之间循环，用 Esc 键关闭演示者视图。
  • 备注与幻灯片之间的移动：演示者视图文档写明，用预览图标可以显示演示文稿的所有幻灯片，并迅速跳到其他幻灯片。添加演讲者备注的方法在题为《开始演示并在演示者视图中查看备注》的另一篇文档中，未查阅。

保存或导出为 PDF

PDF 保存文档列出的适用产品有：Microsoft 365 的 PowerPoint、Mac 版 Microsoft 365 的 PowerPoint、PowerPoint 2024、Mac 版 PowerPoint 2024、PowerPoint 2021、Mac 版 PowerPoint 2021、PowerPoint 2019、PowerPoint 2016。文档说明，把演示文稿保存为 PDF 文件会固定格式和版式，没有 PowerPoint 的人也能查看幻灯片，但无法修改。

  1. 选择文件 > 导出，再选择创建 PDF/XPS 文档，然后选择创建 PDF/XPS。
  2. 选好保存位置，输入文件名。
  3. 决定最终 PDF 的外观。在优化中，需要高质量（例如打印）时选标准，想让文件更小时选最小文件大小。
  4. 选择发布。
  • 选项按钮：在同一对话框中选择选项，可设置演示文稿在 PDF 中的呈现方式，文档举出的例子有：只保存当前幻灯片或用起止编号设定范围，不保存幻灯片而只保存备注、讲义或大纲视图，每页放几张幻灯片，以及在 PDF 中包含幻灯片边框、隐藏的幻灯片、备注、墨迹、文档属性和文档结构标记。
  • macOS：选择文件 > 另存为并把文件格式设为 PDF，或选择文件 > 导出并在文件格式菜单中选 PDF。两种方法文档中都有写。
  • 标准与最小文件大小的选择：需要打印质量就选标准，邮件附件等容量限制优先时选最小文件大小。两种设置在结果文件上究竟差多少，文档中没有数字。
  • 发送 PDF 之前要看的：是否包含隐藏幻灯片、是否出现幻灯片边框，都在选项中决定。把导出的 PDF 打开一遍，核对页数和字体外观后再发送更稳妥。
  • 需要修改 PDF 时：PDF 文档写明，保存为 PDF 的文件只能查看，不能修改。如何编辑 PDF 本身，在PDF 编辑入门一文中说明。

字体在另一台电脑上出错时 - 嵌入字体保存

文档列出的嵌入字体有用的情形有两种：使用了非标准字体，以及预计其他人会离线编辑或查看演示文稿。把演示文件通过邮件发送或拷到另一台电脑上打开，都属于这两种情形。字体出错的问题，出在只有制作文件的电脑才有的字体在对方电脑上缺失，而嵌入保存就是把该字体一并装进文件的设置。文档提到，近年来 Office 字体已迁移到云端，能上网的 Office 订阅用户无需嵌入；但使用非标准字体，或其他人需要离线编辑、查看时，嵌入仍然有用。文档还补充说，把自定义字体嵌入文档，也有助于在线转换为 PDF 时避免字体被替换。

  1. 选择文件选项卡，再选择选项。
  2. 在左侧选择保存。
  3. 勾选将字体嵌入文件复选框。其他 Microsoft 文档把同一项写作「在文件中嵌入字体」，或写作「共享此演示文稿时保持保真度」下的嵌入字体，因此不同文档和版本的写法可能略有差异。
  4. 选择确定。
  • 仅嵌入演示文稿中使用的字符：文件大小会减小，但编辑会受限。适合对方只需打开查看的情形。
  • 嵌入所有字符（最适合他人编辑）：对方可能修改内容时，文档推荐这一项。文件会变大。
  • 无法嵌入的字体：部分 TrueType 字体因字体制作者的权限设置而无法嵌入。文档介绍，可在 Windows 控制面板的字体项中查看字体是否可嵌入的信息。
  • Mac 用户：文档把 Mac 版 Microsoft 365 的 Word、Mac 版 Microsoft 365 的 PowerPoint、Mac 版 PowerPoint 2024、Mac 版 PowerPoint 2021 列为支持对象，并写明应使用 OpenType（.OTF）或 TrueType（.TTF）格式，避免 PostScript（.PFB、.PFM）。
  • 与文件大小的平衡：较大的字体会使文件大小显著增加，如果成为问题，文档建议改用其他字体替代。

嵌入字体与保存为 PDF 目的不同。对方必须打开并编辑文件，就用嵌入字体；只要外观一致，就用 PDF。两者并用，就能分别做出编辑版和提交版。

文件大小文档的适用产品为 Microsoft 365 的 PowerPoint、PowerPoint 2024、2021、2019、2016。文档介绍的方法见下表。文档还写明，演示文稿中有音频或视频时，压缩媒体可以大幅减小文件。

工作顺序检查 - 从头到尾

  1. 打开 PowerPoint，在侧窗格中选择新建 > 空白演示文稿，然后立刻打开视图 > 幻灯片母版。
  2. 在母版中确定颜色、字体、标题形状和徽标，并把不需要的占位符隐藏起来。
  3. 用关闭母版视图回到编辑画面。
  4. 在开始 > 新建幻灯片中选择适合内容的版式，添加幻灯片。
  5. 版面变乱的幻灯片，用开始 > 重置恢复原样。
  6. 用 Shift+F5 查看当前幻灯片，用 F5 在放映画面中查看全部。
  7. 演讲前夕，在文件 > 选项 > 保存中决定是否嵌入字体，提交版则通过文件 > 导出制作 PDF。若有大图片，先进行图片压缩。

这个顺序的依据是各项目相互依赖的方向。母版是版式的基础，版式是幻灯片的框架，而嵌入字体、PDF、压缩是对完成内容所做的收尾。越难撤销的操作越放在后面。文档写明删除编辑数据和裁剪区域无法恢复，因此压缩前复制原文件，是最后一个检查项。
