5월과 달라진 것 — 이름부터 바뀌었다

이 글의 초판은 2026년 5월에 Sora 2·Veo 3·Runway Gen-4·Pika 2.0 네 종을 놓고 썼다. 석 달 만에 그 네 이름 중 셋이 낡았다.

  • Veo 3는 폐기 표시가 붙었다. Gemini API 가격 문서에서 Veo 3와 Veo 2는 deprecated로 분류되어 있고 종료일이 2026년 6월 30일로 적혀 있다. 현행은 Veo 3.1이다.
  • Runway는 Gen-4.5를 냈다. API 모델 목록의 주력 텍스트·이미지 입력 모델은 gen4.5이고, Gen-4 계열은 gen4_turbo가 이미지 입력용으로 남아 있다.
  • Pika는 2.5로 올라갔다. 가격 페이지의 모든 요금제가 Pika 2.5 기준으로 표기되어 있고, 무료 요금제는 480p로 제한된다.
  • Sora 2는 초당 과금이 명확해졌다. 구독 요금제로 뭉뚱그려 설명하던 것이 API 가격표에 초당 달러로 정리됐다.
  • 중국계와 후발 주자가 표에 들어올 만큼 문서화됐다. Seedance 2.5, Wan 2.7, Hailuo 2.3, HappyHorse 1.1이 5월 시점에는 없었거나 문서가 부실했다.

영상 생성 모델의 세대 교체 주기는 언어 모델보다 짧다. 언어 모델 쪽 판도는 2026 AI 모델 종합 비교에 따로 정리해 두었는데, 그쪽은 폐기 예고가 몇 달 전에 나오는 데 반해 영상 쪽은 새 버전이 나오면 구 버전 문서가 조용히 deprecated로 바뀌는 식이다. 도구 이름을 문서에 박아둔 매뉴얼은 분기마다 깨진다고 보는 편이 낫다.

워터마크와 생성물 표시

완성본에 로고가 박히느냐는 요금제 문제지만, 보이지 않는 표식은 요금제로 해결되지 않는다. Google은 Veo로 만든 영상에 SynthID 워터마크가 들어간다고 문서에 적어 두었다. 이는 유료 등급에서도 마찬가지다.

  • Veo 3.1 전 등급 — 문서에 「Veo로 만든 영상은 SynthID로 워터마크된다」고 명시.
  • Pika 무료 — 다운로드에 워터마크가 붙고 상업 이용 불가.
  • Pika 유료 — Standard 이상 워터마크 없음.
  • Runway 유료 — Standard 이상 워터마크 없음.
  • 그 외 — 워터마크 정책을 문서로 확인하지 못했다.

눈에 보이는 워터마크와 눈에 안 보이는 워터마크는 목적이 다르다. 전자는 무료 이용자를 유료로 끌어올리는 장치이고, 후자는 이 영상이 AI로 만들어졌음을 나중에 판별하기 위한 장치다. 후자를 지우는 것을 전제로 한 워크플로는 약관 위반이 되기 쉽고, 플랫폼에 따라서는 표시 의무 자체가 규제 대상이다. 생성 콘텐츠의 표시 의무가 어떻게 정리되고 있는지는 멀티모달 AI가 바꾸는 콘텐츠 제작의 미래에서 관련 맥락을 다뤘다.

OpenAI Sora 2 — 초당 과금과 16·20초

Sora 2의 성격은 가격표 한 줄로 요약된다. sora-2는 720p 단일 등급에 초당 $0.10이고, 그 위로 sora-2-pro가 720p $0.30, 1024p $0.50, 1080p $0.70으로 올라간다. 해상도를 올릴 때마다 단가가 계단식으로 뛰는 구조라, 최종 해상도를 미리 정해 두지 않으면 예산이 흔들린다.

길이는 16초와 20초 두 가지다. 임의의 초를 지정하는 방식이 아니다. 15초 광고를 만들 때 16초를 뽑아 1초를 잘라내야 하고, 그 1초분도 과금된다. 6초 컷을 많이 쓰는 SNS 작업에서는 이 구조가 불리하다.

  • 과금 — 초당 달러. 배치로 돌리면 정확히 절반이다.
  • 해상도 — 세로 720x1280 / 가로 1280x720이 기본, Pro에서 1024·1080 계열 추가.
  • 입력 — 텍스트가 필수, 이미지는 jpeg·png·webp, 영상은 확장과 편집에 사용.
  • 엔드포인트 — v1/videos 전용이며 다른 엔드포인트는 지원하지 않는다.
  • 오디오 — API 문서에 생성 관련 서술이 없다.

ByteDance Seedance 2.5 — 30초 원테이크, 가격은 아직

2026년 7월 31일 발표된 Seedance 2.5는 이 표에서 한 번에 뽑는 길이가 가장 긴 모델이다. 발표문에 적힌 값은 세 가지다. 한 번 생성에 최대 30초, 다회 확장 가능, 그리고 한 번의 요청에 이미지 30장·영상 클립 10개·오디오 클립 10개를 참조로 받는다.

다만 공개 단가가 없다. 발표문에도, BytePlus ModelArk 가격 문서에도 Seedance 2.5의 초당 가격이 없다. API에 대해서는 「BytePlus ModelArk를 통해 곧 제공」이라고만 적혀 있고, 현재 이용 경로로 Jimeng AI와 Doubao Pro를 든다.

한편 Runway API 모델 목록에는 seedance2·seedance2_fast·seedance2_mini 세 종류가 초당 크레딧과 함께 이미 올라와 있다. 「곧 제공」과 「이미 제공 중」이 동시에 성립하는 상태인데, Runway 문서의 seedance2가 2.5를 가리키는지 그 이전 세대를 가리키는지는 문서상 구분되지 않는다. 이 글의 가격표에서 Seedance 2.5의 직접 단가를 빈칸으로 둔 이유다.

  • 길이 — 한 번에 최대 30초, 다회 확장.
  • 참조 — 이미지 30 · 영상 10 · 오디오 10.
  • 오디오 — 영상과 통합 생성.
  • 가격 — 공식 미공개.
  • API — 공식 발표는 「곧」, 유통 경로에는 이미 등재.

30초 원테이크가 편집 공정에서 실제로 무엇을 바꾸는지, 5초 클립을 이어붙이던 방식과 무엇이 달라지는지는 Seedance 2.5 단독 분석에 정리해 두었다. 여기서는 비교표의 한 행으로만 다룬다.

Kling · Hailuo · Wan — 중국계 세 갈래

중국계 영상 모델은 문서화 수준이 극단적으로 갈린다. Alibaba Wan은 모델별 길이·해상도·오디오·리전을 표로 낸 반면, Kuaishou Kling은 가격 페이지와 개발자 문서 모두 외부에서 열리지 않았다.

Alibaba Wan — 다섯 세대를 동시에

Wan은 세대와 입력 방식의 곱으로 모델이 갈린다. 2.7·2.6·2.5·2.2·2.1이 동시에 살아 있고, 각각 t2v(텍스트)·i2v(이미지)·r2v(참조)·kf2v(첫끝 프레임)·videoedit·animate로 나뉜다.

  • wan2.7-t2v — 2~15초, 720P·1080P, 오디오 동반, 다중 샷 서사.
  • wan2.6-t2v — 5·10·15초, 720P·1080P, 오디오 동반.
  • wan2.5-t2v-preview — 5·10초, 480P부터 1080P까지.
  • wan2.2-t2v-plus — 5초, 480P·1080P, 무음.
  • wan2.2-animate-move — 2초 초과 30초 미만, 720P, 이미지와 영상 입력.
  • wan2.6-t2v-us — 미국 리전 전용 ID.

가장 실용적인 특징은 15초 다중 샷이다. 8초 단위로 끊기는 모델과 달리 한 요청에서 장면 전환이 있는 15초를 만든다. 단점은 공개 단가가 모델 문서에 없다는 것이다.

MiniMax Hailuo — 규격이 단순하다

Hailuo는 선택지가 세 가지로 고정되어 있다. 768P 6초, 768P 10초, 1080P 6초다. 현행 MiniMax-Hailuo-2.3과 병행 제공되는 MiniMax-Hailuo-02가 같은 규격이고, 구세대 T2V-01·T2V-01-Director는 720P 6초 단일 규격이다.

  • 1080P를 고르면 길이가 6초로 묶인다.
  • 10초가 필요하면 768P로 내려가야 한다.
  • API 문서에 오디오 항목이 없다.
  • 공개 단가 표는 확인하지 못했다.

Kuaishou Kling — 이름만 남긴다

Kling은 이 분야에서 자주 언급되지만, 가격 페이지와 개발자 문서가 모두 HTTP 446을 반환해 값을 얻지 못했다. 검색으로 나오는 요금제 숫자들은 서로 어긋나 있어 옮기지 않았다. 이 글의 표에 Kling의 숫자가 하나도 없는 것은 그래서다.

HappyHorse — 표에 새로 들어온 이름

Alibaba Model Studio 모델 목록에는 happyhorse-1.1-t2v·-i2v·-r2v와 happyhorse-1.0-video-edit가 올라와 있다. Runway API 가격표에도 happyhorse_1_0이 720p 초당 15크레딧, 1080p 초당 30크레딧으로 등재되어 있다. Alibaba가 Wan과 별개로 운영하는 영상 모델 계열인데, 사양 표는 아직 문서에서 확인되지 않는다.

Pika와 Luma — 가장 싼 쪽과 가장 비싼 쪽

이 두 회사는 같은 구독 모델을 쓰면서 가격대가 정반대다. Pika는 연간 청구 기준 월 $8부터 시작하고, Luma는 가장 낮은 등급이 월 $30이며 무료 등급이 없다.

무료 등급이 480p로 묶이고 워터마크가 붙는 구조라, Pika는 사실상 Standard부터가 시작이다. 그 대신 월 $8은 이 표에서 가장 낮은 유료 진입선이다.

Luma Dream Machine

  • Plus — 월 $30, 연간 청구 시 월 $25, 10,000크레딧, 상업 이용 표기.

Luma 가격 페이지는 해상도·워터마크·모델 버전별 구분을 적지 않는다. 크레딧 숫자만 크게 적혀 있어서, 클립 한 편이 몇 크레딧인지 모르면 10,000이라는 숫자가 많은 건지 적은 건지 판단할 수 없다. 이 점이 Runway와 결정적으로 다르다. Runway는 API 문서에서 크레딧을 $0.01로 못 박아 두었다.

국내에서 이 도구들을 업무에 넣을 때 걸리는 지점은 화질이 아니라 접근성과 계약이다. Google Gemini API는 제공 지역 목록에 한국이 들어 있어 Veo 3.1을 API로 붙이는 데 지역 제약이 없다. 나머지 제공사는 공식 지역 문서를 찾지 못했으므로, 결제 단계에서 막히는지 무료 등급으로 먼저 확인하는 편이 빠르다.

국내 광고·교육 영상에 쓸 때 실제로 문제가 되는 것은 생성물 표시와 초상·음성 쪽이다. AI로 만든 영상임을 알리는 표시 의무가 정비되고 있고, 실존 인물과 닮은 얼굴이나 목소리를 쓰면 표시 여부와 무관하게 별도 문제가 된다.

  • 지역 — Veo는 한국이 제공 지역 목록에 있다. 나머지는 무료 등급으로 가입 가부를 먼저 확인한다.
  • 결제 — 법인카드 국적과 계정 국가가 다르면 막히는 사례가 있다. 결제 수단을 먼저 등록해 본다.
  • 표시 — AI 생성물임을 알리는 표시를 어디에 넣을지 납품 규격에 미리 적는다.
  • 초상·음성 — 실존 인물을 연상시키는 얼굴·목소리는 표시와 별개로 동의 문제가 남는다.
  • 학습 활용 — 클라이언트 소재를 넣는다면 무료 등급을 피한다. Gemini는 무료 등급에서 입력이 제품 개선에 쓰인다고 명시한다.
  • 워터마크 — Veo 산출물에는 SynthID가 들어간다. 지우는 것을 전제로 한 공정은 만들지 않는다.
  • 납품 해상도 — 방송·옥외는 1080p 이상을 요구하는 경우가 많다. 등급 선택이 여기서 결정된다.
  • 재현성 — 같은 프롬프트로 며칠 뒤 다시 뽑아야 할 수 있다. 프롬프트와 참조 파일, 모델 ID를 함께 보관한다.

고르기 전 점검 순서

화질은 문서로 검증되지 않는다. 그래서 후보를 두세 개로 좁힌 다음은 자기 소재로 직접 재는 것 외에 방법이 없다. 순서는 이렇다.

  1. 완성본 규격을 먼저 못 박는다. 길이, 해상도, 화면비, 음성 유무. 이게 정해져야 표에서 후보가 걸러진다.
  2. 길이 단위를 확인한다. 16초 단위 모델로 15초 광고를 만들면 매번 1초분을 버린다.
  3. 같은 프롬프트를 후보 전부에 5회씩 넣는다. 1회 결과는 표본 하나일 뿐이다.
  4. 실패한 회차를 따로 보관한다. 평균보다 실패 양상이 선택의 근거가 된다.
  5. 재시도 횟수를 센다. 초당 단가가 싸도 세 번 다시 돌리면 비싼 모델보다 비싸진다.
  6. 소요 시간을 잰다. 마감이 촉박한 작업에서는 생성 대기가 단가보다 크게 작용한다.
  7. 약관의 상업 이용 조항을 계약 전에 읽는다. 납품 후에 읽으면 늦다.
  8. 학습 활용 조항을 클라이언트에게 공유한다. 고객사 소재가 들어가면 이건 협의 사항이다.
  9. 결과물에 워터마크가 들어가는지 확인한다. 보이는 것과 안 보이는 것 둘 다.
  10. 모델 ID와 프롬프트를 산출물과 함께 남긴다. 재작업 요청이 오면 이게 없으면 처음부터 다시다.

여기서 3번과 5번이 핵심이다. 초당 단가는 표에 적힌 값이지만, 실제 비용은 「완성품 하나를 얻기까지 몇 초를 태웠는가」다. 두 값의 차이가 세 배 넘게 벌어지는 경우가 드물지 않다. 도구를 고르는 기준으로 삼아야 하는 것은 후자다.

위 표들의 빈칸에 대응하는 목록이다. 여기 적힌 항목은 값이 나쁘다는 뜻이 아니라, 제조사 문서에서 값을 얻지 못했다는 뜻이다.

  • Wan 계열 공개 단가 — 모델 사양 문서에는 길이·해상도·리전이 있으나 단가가 없고, 모델 가격 문서에는 영상 항목 자체가 없다.

  • Sora 지원 국가 — OpenAI 도움말 문서가 HTTP 403을 반환했다.
  • Sora 출력물 권리 조항 — OpenAI 이용약관 페이지가 HTTP 403을 반환했다.
  • Sora 2의 오디오 생성 여부 — API 문서에 관련 서술이 없다. 없다는 뜻이 아니라 문서에 없다는 뜻이다.
  • Pika 이용약관 전문 — 약관 페이지 본문이 렌더링되지 않았다. 상업 이용 조건은 가격 페이지 표기만 인용했다.
  • Runway gen4.5의 길이·해상도 — 모델 상세 문서를 열지 못했다. 가격표의 초당 크레딧만 확인된다.
  • Luma의 해상도·워터마크·모델 버전 — 가격 페이지가 크레딧 수만 표기한다.
  • 크레딧과 초의 환산 — Runway는 API 문서에서 크레딧을 $0.01로 명시하지만, Pika와 Luma는 클립 한 편이 몇 크레딧인지 밝히지 않는다.
  • 화질·물리 정확도·텍스트 렌더링 — 어느 벤더도 공식 문서에 수치를 내지 않았다. 순위를 매길 근거가 없다.
  • 언어별 자막·간판 정확도 — 한국어·일본어·중국어 처리 품질을 문서로 낸 벤더가 없다.
  • Runway·Pika·Luma·MiniMax의 제공 지역 — 공식 지역 목록 문서를 찾지 못했다.

목록이 긴 것 자체가 이 시장의 상태를 보여준다. 언어 모델 쪽은 벤더 대부분이 가격·컨텍스트·폐기 일정을 문서로 낸다. 영상 쪽은 아직 그 수준이 아니다. 계약 규모가 커진다면 표의 빈칸을 서면으로 받아 두는 편이 안전하다.

### 문서로 확인된 것

- **Runway** — 회사가 입력물·출력물 소유권을 주장하지 않음. 약관 준수 시 상업적 이용을 제한하지 않음. 다만 입력물과 출력물에 대해 회사가 비독점·취소 불가·영구·전 세계·무상·양도 및 재실시 가능한 이용 허락을 받으며, 이는 모델 개선 목적을 포함
- **Google Gemini API** — 생성 결과물에 소유권을 주장하지 않음. 무료 등급은 입력과 응답을 제품 개선에 사용하고 사람이 검토할 수 있으므로 민감·기밀·개인정보 금지. 유료 등급은 제품 개선에 사용하지 않음. 유럽경제지역·스위스·영국 사용자 대상 서비스는 유료 서비스만 사용
- **Pika** — 무료 등급은 워터마크가 붙고 상업 이용 불가, 유료 플랜부터 가능
- **Luma** — Plus 이상에 상업 이용 표기
- **Veo 3.1** — 전 등급 산출물에 SynthID 워터마크
