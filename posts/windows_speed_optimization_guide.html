윈도우 느려짐 해결하는 법 - 원인 진단부터 단계별 최적화

작업 관리자로 병목을 먼저 특정하고 원인별로 처방하는 트러블슈팅 절차

2026-07-26 IT/기술

이 게시물은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.

서론: 느려진 PC에 설정부터 손대면 안 되는 이유

부팅에 3분이 걸리고, 브라우저 탭 몇 개를 여는 것만으로 화면이 멈칫거린다. 이럴 때 대부분은 검색해서 나오는 최적화 팁을 위에서부터 순서대로 적용한다. 시각 효과를 끄고, 임시 파일을 지우고, 서비스를 몇 개 종료한다. 그런데 체감이 그대로다. 원인이 다른 곳에 있었기 때문이다. 메모리가 부족해서 느린 PC에 시각 효과를 꺼봐야 달라지는 것이 거의 없고, 저장장치가 병목인데 시작 프로그램만 정리하면 부팅만 조금 빨라질 뿐 사용 중 멈칫거림은 그대로 남는다.

그래서 이 글은 설정 카탈로그가 아니라 진단 절차로 구성했다. 먼저 작업 관리자로 CPU, 메모리, 디스크, GPU 중 무엇이 병목인지 특정하고, 그 결과에 따라 어떤 단계를 밟을지 고르는 순서다. 각 단계마다 예상 소요시간과 난이도를 붙였고, 효과가 거의 없거나 오히려 위험한 항목은 따로 떼어 경고로 정리했다. 설정 항목 자체를 하나씩 훑어보고 싶다면 윈도우 11 최적화 완벽 가이드가 그 역할을 맡고 있으니 이 글과 함께 보면 된다. 이 글은 그 반대편, 즉 증상에서 출발해 원인을 좁혀 가는 쪽을 다룬다.

준비물과 사전 확인

  • 여유 시간 1~2시간: 업데이트와 검사에 대기 시간이 길게 잡힌다. 급한 작업이 있는 날은 시작하지 않는 편이 낫다.
  • 안정적인 전원: 노트북이라면 반드시 충전기를 연결한다. 업데이트 도중 전원이 끊기면 복구가 번거로워진다.
  • 중요 파일 백업: 뒤쪽 단계에 초기화가 포함된다. 시작 전에 문서, 사진, 프로젝트 폴더를 외장 저장장치나 클라우드로 복사해 둔다.
  • 내 PC 사양 메모: 설정 → 시스템 → 정보에서 프로세서, 설치된 RAM 용량을 확인하고 적어 둔다. 판단 근거가 된다.
  • 시스템 디스크 종류 확인: 시작 메뉴에서 드라이브 조각 모음 및 최적화를 열면 미디어 유형 열에 하드 디스크 드라이브 또는 반도체 드라이브로 표시된다. 이 한 줄이 이 글 전체에서 가장 중요한 정보다.
  • 암호화 복구 키: 장치 암호화가 켜져 있다면 복구 키를 마이크로소프트 계정에서 미리 확인해 둔다.

사전 확인에서 시스템 디스크가 하드 디스크 드라이브(HDD)로 나왔다면, 아래 단계들은 어디까지나 응급 처치다. 근본 해결은 저장장치 교체이므로 이 경우 SSD 교체·업그레이드 하는 법을 먼저 읽고 계획을 세우는 편이 시간을 아낀다.

Step 1. 작업 관리자로 병목을 특정한다 (10분 / 난이도 하)

모든 판단의 출발점이다. Ctrl + Shift + Esc를 눌러 작업 관리자를 연다. 성능 탭에서 전체 수치를, 프로세스 탭에서 범인을 본다. 프로세스 탭은 열 머리글을 클릭하면 사용률 순으로 정렬된다.

1.1 무엇이 100%에 붙어 있는지 본다

PC를 켜고 아무 작업도 하지 않은 상태에서 3~5분 정도 그대로 두고 관찰한다. 부팅 직후에는 업데이트 확인이나 백신 검사가 돌기 때문에 잠시 수치가 높은 것이 정상이며, 이 시간이 지나도 특정 항목이 계속 붙어 있으면 그것이 병목이다.

1.2 디스크 100%일 때 프로세스 이름을 본다

디스크가 병목이라면 프로세스 탭에서 디스크 열을 기준으로 정렬해 상위 항목의 이름을 확인한다. 자주 지목되는 이름은 다음과 같다.

  • Windows 모듈 설치 관리자 · 서비스 호스트(Windows Update): 업데이트 다운로드·설치 중. 끝날 때까지 두면 정상화된다.
  • Antimalware Service Executable: 백신 검사 중. 예약 검사 시간을 사용하지 않는 시간대로 옮기는 것이 정공법이다.
  • Microsoft Windows Search 색인 생성기: 파일 인덱싱. 대량의 파일을 새로 복사한 직후에는 며칠간 활동이 잦다.
  • 서비스 호스트(SysMain): 자주 쓰는 앱을 미리 메모리에 올려 두는 기능. SSD에서는 부담이 적지만 느린 HDD에서는 디스크 활동을 키우는 요인으로 지목된다.
  • OneDrive·구글 드라이브 등 동기화 클라이언트: 대량 동기화 중. 일시 중지하면 즉시 내려간다.

여기서 중요한 판단이 하나 나온다. 위 목록 중 어느 것도 눈에 띄지 않는데 디스크가 상시 100%이고, 사전 확인에서 시스템 디스크가 HDD로 나왔다면 이것은 고장이 아니라 성능 한계다. 소프트웨어 조정으로 얻을 수 있는 개선폭이 크지 않다.

Step 2. 시작 프로그램을 정리한다 (10분 / 난이도 하)

부팅이 느리고 로그인 직후 몇 분간 반응이 없는 증상에 가장 직접적으로 듣는 단계다. 작업 관리자 왼쪽 메뉴에서 시작 앱을 선택하면 부팅 시 자동 실행되는 목록과 각 항목의 시작 시 영향도가 표시된다. 끄고 싶은 항목을 마우스 오른쪽 버튼으로 클릭하고 사용 안 함을 선택한다.

기준은 단순하다. 이름을 보고 무엇인지 알 수 있고, 부팅 직후에 쓰지 않는 앱만 끈다. 메신저, 클라우드 동기화 도구, 게임 런처, 각종 업데이트 도우미, 프린터·주변기기 제조사 유틸리티가 대표적인 후보다. 여기서 끄더라도 프로그램이 삭제되는 것은 아니며 필요할 때 직접 실행하면 그대로 동작한다.

반대로 건드리지 말아야 할 것도 분명하다. 백신·보안 소프트웨어, 그래픽 드라이버 제어판, 노트북 제조사의 전원·팬·키보드 제어 도구, 오디오 드라이버 관련 항목은 켜 둔다. 이름만 봐서 정체를 모르겠는 항목은 그대로 두는 것이 안전하다. 잘 모르는 항목을 무더기로 끄는 것보다, 확실히 아는 항목 서너 개를 끄는 쪽이 부작용 없이 효과를 얻는 방법이다.

Step 3. 백그라운드에서 도는 것을 줄인다 (20분 / 난이도 하)

CPU나 메모리가 병목일 때 유효한 단계다. 순서대로 진행한다.

  1. 지금 열려 있는 것부터 닫는다: 브라우저 탭 수십 개는 그 자체로 메모리를 크게 잡아먹는다. 자주 보는 페이지는 즐겨찾기로 옮기고 탭을 닫는다.
  2. 안 쓰는 앱을 제거한다: 설정 → 앱 → 설치된 앱에서 크기와 설치 날짜를 기준으로 정렬해 본다. 몇 년째 실행한 적 없는 프로그램, 예전에 딸려 들어온 툴바·PC 관리 도구는 지운다. 프로그램 제거는 파일 삭제보다 안전하고 되돌리기도 쉽다.
  3. 개별 앱의 백그라운드 실행 권한을 조정한다: 설정 → 앱 → 설치된 앱에서 개별 앱의 고급 옵션에 들어가면 백그라운드 앱 권한을 설정할 수 있다. 알림이 필요 없는 앱은 사용 안 함으로 둔다.
  4. 클라우드 동기화를 일시 중지한다: 작업 중 체감 속도가 급격히 떨어질 때 동기화 클라이언트를 잠시 멈춰 보면 원인 여부를 바로 알 수 있다.
  5. 재부팅한다: 며칠씩 절전만 반복한 PC는 재부팅 한 번으로 상당 부분 회복되는 경우가 흔하다. 종료 후 다시 켜기가 아니라 다시 시작을 선택해야 완전한 재부팅이 된다.

Step 4. 저장공간을 확보한다 (20~40분 / 난이도 하)

시스템 디스크가 거의 가득 차면 임시 파일 생성과 가상 메모리 운용에 여유가 없어져 전반적인 반응이 나빠진다. 마이크로소프트도 디스크 여유 공간 확보를 성능 개선 항목으로 안내한다.

도구는 윈도우에 내장된 저장 공간 센스를 쓴다. 설정 → 시스템 → 저장소로 들어가 저장 공간 센스를 켜고 지금 실행을 누르면 임시 파일과 휴지통, 다운로드 폴더의 오래된 항목을 정리한다. 자동 실행 주기와 휴지통·다운로드 폴더 보관 기간도 여기서 조정한다. 저장 공간 센스는 시스템 드라이브(보통 C:)를 대상으로 동작한다.

같은 저장소 화면에서 임시 파일 항목을 직접 열면 어떤 종류가 얼마나 차지하는지 목록으로 확인할 수 있다. 이전 윈도우 설치 파일이 남아 있으면 수십 GB 단위로 회수되기도 한다. 다만 이 항목을 지우면 이전 버전으로 되돌리는 기능을 쓸 수 없게 되므로, 업그레이드 직후라면 며칠 사용해 보고 문제가 없을 때 지운다.

정리 후 시스템 드라이브 여유 공간이 전체의 10~15% 이상, 최소 수십 GB 확보되도록 하는 것을 목표로 잡으면 무난하다. 정리해도 공간이 나오지 않는다면 사진·영상 같은 대용량 파일을 외장 저장장치나 다른 드라이브로 옮기는 쪽이 빠르다.

Step 5. 전원 모드와 시각 효과를 조정한다 (5분 / 난이도 하)

노트북에서 특히 체감 차이가 큰 항목이다. 설정 → 시스템 → 전원 및 배터리에서 전원 모드를 최고 성능으로 바꾼다. 배터리 절약 모드로 오래 쓰던 노트북이라면 이 한 가지로 반응 속도가 눈에 띄게 달라지기도 한다. 대신 배터리 소모와 발열, 팬 소음이 늘어나므로 외출 시에는 균형 조정 또는 전원 효율성으로 되돌리는 것이 낫다.

시각 효과는 시작 메뉴에서 Windows의 모양 및 성능 조정을 검색해 열고, 시각 효과 탭에서 최적 성능으로 조정을 선택한다. 사양이 낮은 PC에서는 창 전환과 메뉴 표시가 즉각적으로 바뀌어 체감이 개선된다. 다만 이 설정은 애니메이션을 없애 반응이 빨라 보이게 하는 성격이 강하고, 실제 연산 성능이 늘어나는 것은 아니다. 화면이 투박해지는 것이 싫다면 사용자 지정에서 창을 최소화/최대화할 때 애니메이션 효과와 미리 보기 사용 정도만 꺼도 대부분의 이득을 얻는다.

Step 6. 윈도우 업데이트와 드라이버를 최신으로 맞춘다 (30분~1시간 / 난이도 중)

업데이트가 밀려 있으면 그 자체로 백그라운드 활동이 계속 발생하고, 이미 수정된 성능 문제를 그대로 안고 쓰게 된다. 설정 → Windows 업데이트에서 업데이트 확인을 눌러 남은 항목을 모두 설치하고 재부팅한다. 같은 화면의 고급 옵션 → 선택적 업데이트에는 드라이버 업데이트가 따로 들어 있는 경우가 있으니 함께 확인한다.

그래픽만 유독 느리거나 특정 게임·영상에서만 문제가 있다면 그래픽 드라이버가 우선 후보다. 이때는 검색으로 나오는 드라이버 모음 사이트가 아니라 GPU 제조사 또는 PC·노트북 제조사의 공식 지원 페이지에서 내려받는다. 노트북은 제조사가 자체 검증한 드라이버를 배포하는 경우가 많아 제조사 버전이 더 안정적인 경우가 흔하다.

업데이트를 마쳤다면 SSD 사용자라면 시작 메뉴에서 드라이브 조각 모음 및 최적화를 열어 최적화를 한 번 실행해 둔다. 최신 윈도우는 저장장치 종류를 인식해 HDD에는 조각 모음을, SSD에는 TRIM 작업을 알아서 수행하므로 사용자가 종류를 구분해 걱정할 필요는 없다.

Step 7. 악성코드를 검사한다 (30분~2시간 / 난이도 하)

CPU가 이유 없이 높고, 팬이 계속 돌고, 브라우저에 낯선 확장 프로그램이나 시작 페이지가 생겼다면 이 단계를 건너뛰면 안 된다. 설정 → 개인 정보 및 보안 → Windows 보안 → 바이러스 및 위협 방지에서 빠른 검사를 먼저 돌리고, 의심이 남으면 검사 옵션에서 전체 검사를 선택한다. 전체 검사는 오래 걸리므로 사용하지 않는 시간에 걸어 두는 편이 낫다.

백신을 여러 개 설치하는 것은 피한다. 실시간 감시가 서로 충돌하면서 오히려 시스템이 느려지고 오탐이 늘어난다. 윈도우 기본 보안 기능으로 충분한 경우가 많고, 별도 제품을 쓴다면 하나만 남기는 것이 원칙이다.

Step 8. 최후 수단 - 이 PC 초기화 (1~3시간 / 난이도 중)

여기까지 왔는데도 개선이 없고, 작업 관리자상으로는 특별히 자원을 잡아먹는 프로세스가 보이지 않는다면 누적된 설정과 잔여 소프트웨어가 원인일 가능성이 있다. 이때 이 PC 초기화가 선택지가 된다. 설정 → 시스템 → 복구에서 실행하며, 내 파일 유지와 모든 항목 제거 중 하나를 고른다.

내 파일 유지를 선택하면 문서·사진 같은 개인 파일은 남기고 윈도우를 다시 설치한다. 다만 설치했던 앱과 드라이버, 변경한 설정은 제거된다는 점을 반드시 이해하고 시작해야 한다. 초기화 후 다시 설치해야 할 프로그램 목록과 라이선스 키, 브라우저 로그인 정보를 먼저 정리해 두면 복구 시간이 크게 줄어든다.

시작 전 체크리스트는 세 가지다. 첫째, 개인 파일을 외부에 백업한다. 내 파일 유지 옵션이 있어도 백업은 별도로 해 둔다. 둘째, 장치가 암호화되어 있다면 복구 키를 확보한다. 셋째, 노트북은 충전기를 연결한다. 초기화는 되돌릴 수 없는 작업이므로 이 세 가지가 준비되지 않았다면 시작하지 않는다.

자주 하는 실수

  • 진단 없이 팁부터 적용하기: 원인을 모른 채 열 가지 설정을 한 번에 바꾸면 효과가 있어도 무엇 덕분인지 알 수 없고, 문제가 생겨도 어디를 되돌려야 할지 모른다. 한 번에 하나씩, 바꾸고 확인한다.
  • 레지스트리 클리너 사용: 마이크로소프트는 레지스트리 정리 유틸리티 사용을 지원하지 않는다는 정책을 공개해 두고 있다. 잘못된 항목이 삭제되면 프로그램 실행 불가나 부팅 불가로 이어져 운영체제 재설치가 필요할 수 있다. 성능이 좋아진다는 검증된 근거도 부족하다.
  • 정체불명의 최적화 프로그램 설치: 무료 배포되는 PC 가속·정리 도구 중 일부는 광고 삽입이나 원치 않는 소프트웨어 설치를 동반하는 사례가 보고된다. 느려진 PC를 고치려다 감시 대상 프로그램을 하나 더 늘리는 결과가 되기 쉽다.
  • 서비스 목록에서 아는 것 없이 대량 종료: 인터넷에 도는 서비스 종료 목록을 그대로 따라 하면 네트워크·인쇄·오디오·업데이트가 한꺼번에 죽는 일이 생긴다. 체감 이득은 작고 복구 비용은 크다.
  • 가상 메모리를 임의로 0이나 고정값으로 변경: 자동 관리가 기본값이며, 근거 없이 만지면 특정 프로그램에서 메모리 부족 오류가 발생할 수 있다.
  • 백신 여러 개 동시 설치: 실시간 감시 충돌로 오히려 느려지는 대표적인 사례다.
  • 초기화 전 백업 생략: 내 파일 유지 옵션을 믿고 백업을 건너뛰었다가 복구 불가 상황을 맞는 경우가 나온다.

안 해도 되는 것

널리 퍼져 있지만 최신 윈도우 환경에서 효용이 낮거나 이미 자동화된 항목들이다. 시간을 아끼기 위해 정리해 둔다.

  • SSD에 조각 모음 강제 실행: 윈도우가 저장장치 종류를 판별해 SSD에는 TRIM을 수행한다. 별도 도구로 조각 모음을 반복하는 것은 득이 없다.
  • 시스템 서비스 대량 비활성화: 앞서 언급했듯 위험 대비 이득이 작다. 성능 문제가 특정 서비스에서 확인된 경우에만 그 서비스 하나를 다룬다.
  • 매일 임시 파일 청소: 저장 공간 센스를 켜 두면 알아서 처리된다. 공간이 부족할 때만 확인하면 충분하다.
  • 부팅 시간 단축을 노린 극단적 설정 변경: 부팅이 20초에서 15초가 되는 것보다, 사용 중 멈칫거림을 없애는 편이 체감에 훨씬 크게 기여한다.

안전 주의사항

  • 레지스트리 편집기는 원칙적으로 열지 않는다: 특정 문제 해결을 위한 공식 문서의 안내를 따르는 경우가 아니라면 손대지 않는다. 부득이하게 수정한다면 해당 키를 먼저 내보내기로 백업한다.
  • 서비스를 종료할 때는 사용 안 함이 아니라 수동부터: 문제가 생겼을 때 되돌리기 쉽다. 종료한 서비스 이름과 원래 상태를 메모해 둔다.
  • 드라이버는 공식 경로에서만: 검색 결과 상단의 드라이버 통합 다운로드 사이트는 번들 소프트웨어와 변조 위험이 있다.
  • 업데이트·초기화 중 전원을 끊지 않는다: 진행 중 강제 종료는 부팅 불가로 이어질 수 있다.
  • 되돌릴 지점을 만들어 둔다: 큰 변경 전 시스템 복원 지점을 만들어 두면 문제 발생 시 되돌릴 여지가 생긴다.

여기서부터는 하드웨어 또는 전문가 영역

소프트웨어 조정으로 해결되지 않는 구간이 분명히 있다. 아래에 해당하면 설정을 더 만지는 대신 하드웨어를 검토하거나 서비스센터에 맡기는 편이 합리적이다.

  • 시스템 디스크가 HDD인 경우: 이 글에서 가장 확실한 처방이다. 회전식 HDD에서 SSD로 바꾸면 부팅과 프로그램 실행 체감이 다른 어떤 설정 변경보다 크게 달라진다. 절차는 SSD 교체·업그레이드 하는 법에 규격 확인부터 데이터 이전까지 단계별로 정리해 두었다.
  • 메모리가 상시 80~90%를 넘는 경우: 브라우저 탭을 줄여도 여유가 나지 않는다면 램 증설이 답이다. 노트북은 램이 메인보드에 납땜되어 증설이 불가능한 모델도 있으므로 구매 전 제조사 사양을 확인한다.
  • 발열·소음이 심하고 잠시 후 느려지는 경우: 먼지 누적이나 서멀 그리스 경화로 인한 성능 제한이 의심된다. 분해가 필요한 작업이며, 보증 기간 중이라면 직접 열지 말고 서비스센터에 맡긴다.
  • 부팅 실패, 파란 화면, 알 수 없는 오류음이 반복되는 경우: 저장장치나 메모리 하드웨어 이상 가능성이 있다. 이 상태에서 최적화 작업을 계속하면 데이터 손실 위험이 커진다. 먼저 데이터를 백업하고 점검을 받는다.
  • 10년 가까이 된 PC로 최신 작업을 하려는 경우: 어떤 최적화도 세대 차이를 메우지 못한다. 이때는 맥북과 윈도우 노트북 비교처럼 교체 자체를 비교 검토하는 편이 낫다.

결론

느려진 윈도우를 되살리는 순서는 정해져 있다. 먼저 작업 관리자로 CPU, 메모리, 디스크, GPU 중 무엇이 병목인지 특정한다. 이 한 단계만 제대로 해도 이후에 쓸 시간의 절반이 줄어든다. 그다음 부팅이 문제면 시작 프로그램을, 사용 중 멈칫거림이 문제면 백그라운드 앱과 메모리를, 전반적인 굼뜸이면 저장공간과 전원 모드를 손본다. 업데이트와 드라이버를 최신으로 맞추고, 악성코드 검사로 외부 요인을 배제한 뒤에도 답이 없을 때 비로소 초기화를 꺼낸다.

반대로 하지 말아야 할 것도 명확하다. 레지스트리 클리너와 출처 불명의 최적화 프로그램은 얻는 것보다 잃을 위험이 크다. 서비스 대량 종료 역시 체감 이득은 미미하고 복구 비용은 크다. 그리고 시스템 디스크가 HDD라면, 어떤 설정 조합도 저장장치 교체를 대신하지 못한다는 점을 인정하는 편이 시간과 비용 모두를 아낀다.

이 글은 증상에서 원인을 좁혀 가는 트러블슈팅 관점을 다뤘다. 개별 설정 항목을 하나씩 살펴보고 싶다면 윈도우 11 최적화 완벽 가이드를, 하드웨어 교체가 결론이라면 SSD 교체·업그레이드 하는 법을, 정리 작업 자체를 자동화하고 싶다면 윈도우 작업 자동화 입문 가이드를 이어서 보면 된다.

안내: 이 글은 일반 사용자 환경을 기준으로 한 정보 제공용 안내이며, 특정 제품이나 유료 소프트웨어를 추천하지 않는다. 메뉴 이름과 위치는 윈도우 버전과 업데이트 시점, 제조사 커스터마이징에 따라 다를 수 있으므로 화면과 다르면 설정 검색창에서 항목명을 검색해 확인하기 바란다. 초기화, 드라이버 교체, 하드웨어 분해 등 되돌리기 어려운 작업은 반드시 데이터 백업 후 진행해야 하며, 그 결과에 대한 책임은 사용자 본인에게 있다. 보증 기간 중인 기기의 분해는 보증이 종료될 수 있으므로 제조사 서비스센터를 이용하는 것이 안전하다.
