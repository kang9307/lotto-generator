LGモニター接続で同意なくインストールされる「LG Monitor App Installer」

Windows Update経由で同意画面なしにアプリがインストールされ、McAfeeを宣伝すると報じられた - 何が問題で、どう対応すべきか

2026年7月20日 IT・技術

序論：何が報じられ、なぜ重要なのか

2026年7月、海外の技術系コミュニティやメディアである事例が拡散した。LG UltraGearシリーズのモニターをWindows PCに接続すると、ユーザーが要求も承認もしていない「LG Monitor App Installer」というアプリがWindows Update経由で自動的にインストールされ、その後McAfeeのサブスクリプションを宣伝するポップアップが表示されるというものだ。報道によれば、この現象を最初に具体的に文書化したのはRedditのr/pcmasterraceにいたユーザーMags_Smashで、複数のLG UltraGearモニターを接続した後にこの挙動に気づいたという。その後、ハードウェア専門メディアGamers Nexusが独自の再現テストを行い、連続32回の起動のうち31回でMcAfeeのプロモーションが表示されたと報告した。

本稿はこの報道をなぞるだけの場ではない。筆者はこの件を「LGを非難するための材料」としてではなく、「Windowsがハードウェアメーカーのソフトウェアをユーザーの明示的な同意なしにインストールできる構造そのもの」を検証する機会として扱いたい。実際、同様の仕組みはAlienwareやASUS製品でも報告されており、これは特定ブランドの逸脱ではなく、Windowsエコシステム全体に組み込まれた構造的な問題である可能性が高い。以下では、まず報じられた事実関係を整理し、なぜこれが問題なのか、なぜこうした慣行が存在するのか、そしてユーザーが今何をできるのかを、2026年7月時点の情報として整理する。

1. 報じられた事実関係

1.1 どのように発覚したか

報道を総合すると、事の経緯は次の通りだ。ユーザーがLG UltraGearモニター(約1,200ドルのUltraGear 34GX900A-Bや、3年前に購入した旧型のUltraFine 32UN880-Bなど、新旧を問わず複数の機種で確認されている)をWindows PCに接続すると、Windowsの信頼性モニター(Reliability History)にLGElectronics.LGMonitorAppというパッケージのインストール記録が残る。このインストールは確認ダイアログや同意手続きなしに、バックグラウンドで行われたと報じられている。Gamers Nexusの検証では、このアプリがインストールされた後、McAfeeの無料体験に関するポップアップが連続32回の起動中31回で表示されたとされ、単発の偶然ではなく、事実上常時露出する広告チャネルに近いことが確認された。

1.2 何がインストールされ、何にアクセスできるのか

さらに注目すべきは権限の範囲だ。プライバシー専門メディアPrivacy Guidesの報道によれば、Microsoft Storeに登録されたLG Monitor App Installerのアプリ一覧には「すべてのシステムリソース(all system resources)」およびインターネット接続へのアクセス権限が明記されていた。モニターの設定アプリとしては広範な権限である。同報道は、この程度の権限と常時のインターネットアクセスが組み合わさると、理論上は表示される広告が別のものに差し替えられたり、データが外部に送信されたりする可能性も排除できないと指摘している。ただし、これはあくまで権限構造上の懸念として提起されたものであり、実際の悪用事例が確認されたわけではない点は明確にしておく必要がある。

2. なぜ問題なのか - 同意なきインストールが侵害するもの

2.1 ユーザーの制御権と同意の原則

この件でまず指摘すべきは、性能上の不具合やセキュリティの脆弱性ではなく「同意」の問題だ。ユーザーが購入したのはモニターであり、ソフトウェアのサブスクリプションではない。にもかかわらず、ケーブルを接続するという物理的な行為だけで、別途の確認なしに新しいアプリケーションがインストールされるという結果につながったと報じられている。これは多くのユーザーが抱く「ドライバーは必要なときに静かに、機能のためだけにインストールされるもの」という一般的な期待から外れている。

2.2 バンドルウェア・ブロートウェアという古い問題の新しい顔

バンドルウェア(同梱ソフト)やブロートウェアはPC業界にとって目新しい言葉ではない。新しいノートPCを買ったら見慣れないアイコンがずらりと並んでいた、という経験は多くの人にあるだろう。今回の事例が異なるのは配布のタイミングだ。従来のバンドルウェアは「工場出荷時」にあらかじめインストールされているのが一般的で、少なくとも購入という一つの明確な時点にその是非が含まれていた。一方、今回のケースはすでに使用中のPC、すでに設定を終えたシステムに、モニターを買い替えたというだけの理由で事後的に入り込む。ユーザーには、購入時点で同意または拒否する機会すら与えられていなかったことになる。

2.3 セキュリティの観点 - 広範な権限と静かな配布の組み合わせ

セキュリティの観点では権限の広さが核心となる。「すべてのシステムリソース」と常時のインターネットアクセスを持つアプリが、ユーザーが認識しないままバックグラウンドで動作しているという事実自体が、攻撃対象領域(アタックサーフェス)の拡大を意味する。このアプリが実際に悪意ある挙動をしたという証拠は報道時点でなかったが、「権限は広いのにユーザーはその存在すら知らなかった」という組み合わせは、最小権限の原則(principle of least privilege)に照らして望ましくない。モニターの明るさや解像度を設定するアプリが、なぜ「すべてのシステムリソース」にアクセスする必要があるのか、説明が求められる。

3. こうした慣行が存在する背景

3.1 OEM-マイクロソフト間のデバイスメタデータ配布チャネル

この現象の技術的な根っこは、Windowsの「デバイスメタデータ」に基づくソフトウェア配布の仕組みにある。Windowsは新しいハードウェアが接続されると、そのデバイスのメタデータをマイクロソフトのサーバーに照会し、メーカーが登録しておいた「付属アプリ(companion app)」がMicrosoft Storeにあるかどうかを確認し、自動的にダウンロードする機能を持つ(一般に「Device Setup Manager」あるいはデバイスメタデータ取得機能と呼ばれる)。本来の趣旨は、ユーザーがドライバーやユーティリティを自分で探し回らなくて済むようにする利便性機能だ。問題は、このチャネルが「ドライバー」だけでなく、メーカーが登録した任意の「アプリ」まで同じ方式で配布できてしまう点にある。利便性機能の設計が、同意なきソフトウェア配布の通路としても使われ得る構造になっているわけだ。

3.2 なぜMcAfeeなのか - 収益化バンドルの経済学

なぜよりによってMcAfeeなのか。OEMとセキュリティソフト企業の間のプリロード・プロモーション提携は、数十年続く収益モデルだ。新しいPCにウイルス対策ソフトの体験版をあらかじめ入れておき、体験期間が終われば有料版への乗り換えを促す方式は、PCメーカーの長年の副収入源だった。今回の事例が示すのは、この提携マーケティングのモデルが、新品PCの販売時点を超えて「Windows Updateという常時稼働のチャネル」にまで拡張されたという点だ。モニターを新しく買って接続するだけで、同じ種類のプロモーション収益構造に組み込まれ得るということになる。

4. ユーザーの対応法 - 今すぐできること

4.1 インストール済みアプリを確認する

まず確認から始めよう。設定 > アプリ > インストールされているアプリで「LG Monitor App」またはそれに類する名称を検索し、不要であれば削除する。信頼性モニター(コントロールパネル > セキュリティとメンテナンス > 信頼性モニター、または実行ウィンドウでperfmon /rel)を確認すれば、いつ何がインストールされたかの履歴を確認でき、知らないうちに入り込んだソフトウェアを見つけるのに役立つ。

4.2 Windows Update経由の自動インストールを無効にする

再発を防ぐには、ハードウェア接続をきっかけにアプリが自動的にダウンロードされる機能そのものを無効化する必要がある。Windows 10/11のProエディション以上では、gpedit.msc(ローカルグループポリシーエディター)を開き、「コンピューターの構成 > 管理用テンプレート > システム > デバイスのインストール」に進み、「インターネットからのデバイスメタデータの取得を防止する」ポリシーを有効にする。このポリシーは基本的なドライバーのインストールは妨げずに、デバイスメタデータに紐づいたメーカーアプリがSYSTEM権限で自動インストールされる経路だけを遮断する。グループポリシーエディターのないHomeエディションでは、設定 > システム > バージョン情報 > システムの詳細設定 > ハードウェアタブ > 「デバイスのインストール設定」で「いいえ」を選び、新しいデバイスに対するアプリやアイコンの自動ダウンロードをオフにすることで、同様の効果が得られる。ただしこの設定を無効にすると、本当に必要なドライバーやユーティリティの自動取得もできなくなるというトレードオフがある点は留意すべきだ。皮肉なことに、このトレードオフ自体が「きめ細かい同意の選択肢がない」という今回の問題の核心をそのまま体現している。

4.3 スタートアップアプリを整理する

インストールを防いだ、あるいはすでに削除した場合でも、タスクマネージャー > スタートアップアプリのタブで、見慣れない項目が起動時に自動実行される設定になっていないか定期的に確認する習慣が役立つ。特にモニターやグラフィックカード、周辺機器を交換した直後は一度確認することを勧める。

5. 類似事例から見る一般化 - LGだけの問題ではない

5.1 AlienwareやASUSにも見られる同じ仕組み

この件を取り上げた複数のメディアは、これがLGだけの問題ではないと指摘している。同様の方式でAlienwareのモニターを接続するとAlienware Command Centerがインストールされ、削除しても再インストールされるという報告がある。ASUSも同じハードウェア連動型の配布方式でArmoury Crateをインストールしているとされる。つまり「Windowsのデバイスメタデータチャネル」という同じ構造を複数のメーカーが利用しており、LGの事例はその中でもMcAfeeのプロモーションという目立つ付加要素のために特に注目された部類と言える。

5.2 メーカー製バンドルウェアの長い歴史

メーカー製バンドルウェアの歴史はさらに長い。2000年代から2010年代のPC業界では、新しいノートPCにウイルス対策ソフトの体験版、見慣れないツールバー、メーカー独自のユーティリティがぎっしり入っているのが当たり前だった。2015年には、レノボがノートPCに「Superfish」という広告ソフトウェアを事前インストールしていたことが発覚し、HTTPS通信まで傍受し得るセキュリティ上の欠陥として国際的な波紋を呼んだ事例もあった。今回のLGの事例が異なるのは配布のタイミングが「工場出荷時」から「Windows Updateという常時チャネル」に移った点だけで、根本的な動機(副収入)とユーザー体験(望まないソフトウェア)は大きく変わっていない。歴史が示すのは、こうした慣行は物議を醸すたびに一時的に鎮まりながらも、チャネルを変えて再び現れてきたということだ。

6. メーカーとマイクロソフトに求められる透明性

報道された時点まで、LGとマイクロソフトの双方ともこの件について公式な見解を示していないとされる。どの機種が影響を受けるのか、McAfeeのプロモーションだけを個別に無効化できるのか、配布自体を中止できるのかについて、公式な説明はない状態だ。筆者の見解では、今回の件が求めているものは明確だ。第一に、ハードウェアの機能と無関係なプロモーション目的のソフトウェアは、デバイスメタデータチャネルで配布すべきではない。第二に、配布するとしても、少なくとも初回起動時に明示的な同意画面を経るべきだ。第三に、Microsoft Storeのアプリ一覧に表示される権限情報が実際のアプリの挙動と一致しているかどうか、マイクロソフトの審査プロセスがより厳格になる必要がある。利便性機能が信頼を損なう形で使われれば、結局ユーザーは本当に必要な自動更新まで無効化する方向に反応することになり、それはメーカーとプラットフォームの双方にとって長期的な損失となる。

結論

まとめると、2026年7月時点で確認できる事実は、LGモニターをWindows PCに接続すると「LG Monitor App Installer」が同意手続きなしにWindows Update経由でインストールされ、その後McAfeeのプロモーションポップアップが繰り返し表示されるということ、そしてこのアプリがMicrosoft Storeの登録情報上、広範な権限を要求しているということだ。これはLGという個別ブランドの逸脱というより、Windowsのデバイスメタデータに基づく自動インストールの仕組みと、OEMのプロモーションバンドルという慣行が組み合わさって表面化した事例と見るのが正確だろう。

今すぐできる実践は三つある。一つ、インストール済みアプリと信頼性モニターを確認し、自分のPCにも該当アプリがあるかどうか点検する。二つ、必要であればグループポリシーまたはデバイスのインストール設定で、デバイスメタデータに基づく自動アプリインストールを無効にする。三つ、以降もハードウェアを交換するたびに、スタートアップアプリや新しくインストールされたアプリを習慣的に確認する。公式な対応が出るまでは、ユーザー自身が制御権を取り戻すことが最も現実的な防御線となる。
