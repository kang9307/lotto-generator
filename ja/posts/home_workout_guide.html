2026-08-01 生活・実用

はじめに: 自宅での運動は、たいてい強く始めすぎて崩れる

自宅で運動を始めた経験のある人の話は、だいたい同じ形をしている。最初の週は意欲があり計画より多くやる。2週目に体が重く、どこかが痛む。3週目に一日抜け、その一日が二日になり、4週目には「自分は意志が弱い」という結論だけが残る。ところがこの経路をもう一度見ると、失敗した地点は4週目ではなく最初の週である。

自宅での運動には、ジムにはない条件が一つある。ブレーキがないということだ。器具が重量を制限してくれるわけでもなく、そばでフォームを見てくれる人もおらず、今日はここまでと区切ってくれる授業時間もない。強度を決めることも止めることも、すべて自分で行うしかない。この記事がルーティンの一覧ではなく規則を扱う理由がそこにある。

扱う範囲を先に狭めておく。この記事は自宅で、器具なしに、自重で行う場合だけを見る。バーベルやマシンを使う種目、ジムでのプログラム設計、重量を増やす一般原理については初心者のための筋力トレーニング入門ですでに扱っているので、ここでは繰り返さない。

  • この記事が渡すもの、その一。 始める前に自分で確認する一覧と、運動中に直ちに止めるべき兆候
  • その二。 出典を明示できる機関勧告の最低線が正確にいくつなのか
  • その三。 何をいつどれだけ増やすかについての一度に一つだけという規則と、それを確認する記録用紙

逆にこの記事が渡さないものも明確にしておく。体重が何週間で何キログラム減るといった数値は書かない。 そうした結果は個人差が非常に大きく、この記事が確認した一次資料の中でそのような約束を裏づける根拠を探していないからだ。特定の器具やアプリケーション、サプリメント、商業プログラムも推奨しない。

1. 始める前の確認 - まず相談が必要な場合

運動の話でこの項目はたいてい最後に小さな字で付く。順序は入れ替えたほうがよい。ある人にとっては「何をするか」より「今始めてよいか」が先だからである。

以下は、始める前に医療の専門家と相談したほうが安全な状態である。当てはまる項目があるからといって運動ができないという意味ではない。どの種類をどの強度で行うかを決めるのに専門家の判断が必要だという意味である。

この記事の性格。 この記事は一般的な情報提供を目的としており、診断や治療に代わるものではない。 適切な運動の種類と量は、年齢、基礎疾患、服用中の薬、最近のけがの経歴によって変わる。下の表に当てはまる項目があれば、始める前に医療の専門家に相談し、この記事の内容よりその判断を優先してほしい。

数値の出典。 この記事で週あたりの時間と頻度を扱う数値はすべて第2節の表にまとめてあり、各行に出典を付けている。その表の外に出てくる数字は計算の出発点として示した仮定値であり、機関の勧告ではない。

1.1 運動中に直ちに中止すべき兆候

以下は「少しきつい」と区別すべき兆候である。息が切れて脚が重いのは運動の一部だが、下の項目は運動の一部ではない。 現れたらその場で運動を終える。

  • 胸の痛み、圧迫感、締めつけられる感じ - 強度に関係なく直ちに中止
  • めまい、失神しそうな感じ、視界がぼやける - 座るか横になり、まず安全を確保する
  • 普段とは違う程度の息苦しさ - 休んでも息切れが収まらない場合を含む
  • 関節に出る鋭い痛み、刺すような痛み - 筋肉の張りとは性質の異なる痛み
  • 片側の手足のしびれや脱力、ろれつが回らない - 左右非対称の症状は特に注意
  • 不規則な脈、または激しい動悸 - 運動をやめたあとも続く場合
  • 冷や汗を伴う吐き気 - 単なる疲労とは異なる組み合わせ

この一覧は「参考として様子を見よ」ではない。直ちに中止し、症状が続くか繰り返す場合は受診せよという意味である。特に胸の症状と神経に関わる症状は時間が重要な場合があるので、少し休めば治るだろうと片づけないほうが安全だ。

3. 強度を測る方法 - 機器なしで判断する

第2節の勧告は「中強度」と「高強度」を区別する。ところが自宅にはたいてい測定機器がない。幸い強度の判断は機器なしでも実用的な水準で可能である。もっとも広く使われるのが、話せる程度を見る方法だ。

原理は単純である。運動強度が上がると呼吸が速くなり、呼吸が速くなると言葉をつなげられる長さが短くなる。文をどこまで続けて話せるかがおおよその目盛りになる。

区分話せる程度体感自宅での例
低強度歌を歌える呼吸がほとんど変わらないゆっくり歩く、軽い家事、ストレッチ
中強度会話はできるが歌は難しい少し息が上がり体が温まる速歩き、その場足踏み、階段の上り下り
高強度数語以上を続けて話しにくいはっきり息が上がり汗が出る速い全身動作、短い区間の反復
過度言葉が出ずフォームが崩れるめまいや吐き気があるここは目標区間ではない。直ちに下げる
  • 同じ動作でも人によって強度が違う。 速歩きがある人には中強度で、ある人には高強度である。動作の名前ではなく自分の呼吸で判断する
  • 体感強度を一緒に記録すると役に立つ。 とても楽から最大までを自分で1から10で付け、同じ動作でその数字が下がるかを見る。絶対値より推移が情報である
  • 高強度は必須ではない。 第2節の表のとおり中強度だけでも勧告範囲を満たせるし、高強度1分は中強度2分に換算される
  • トークテストは精密な測定ではない。 話しにくい条件や呼吸器の疾患がある場合は、この方法の信頼度が落ちる
  • 第1節の中止の兆候は強度の判断より常に優先する。 まだ中強度なのにという判断で兆候を無視しない

心拍数の式を期待していたなら、それがこの記事にない理由は第2.1節に書いてある。確認できなかった式を数字として示さないことがこの記事の原則である。正確な目標心拍数の区間が必要な状況なら、それはたいてい個別の相談が必要な状況でもある。

4. 自重運動の四つの系統 - 押す・引く・下半身・体幹

自宅で行う動作を選ぶとき、名前を覚える方式は長続きしない。代わりに四つの系統に分けて各系統から一つずつ選ぶ方式のほうが管理しやすい。片方に偏っているかがすぐ見えるからである。

下の表は系統ごとに代表的な動作と、やさしい変形、難しい変形を整理したものだ。変形があるという事実そのものがこの節の要点である。同じ系統の中で難度を上下できれば、無理をせずに続けられる。

系統代表的な動作よりやさしい変形より難しい変形
押す腕立て伏せ壁や机に手をつく、膝をつく手の位置を狭める、足を高くする
引くタオルやバンドを引く動作可動域を狭め張力を下げる張力を高め静止時間を延ばす
下半身椅子から立ち座り、スクワット椅子につかまる、座面を高くする深さを増す、片脚の比重を高める
体幹プランク、寝て行う腹部の動作膝をつく、保持時間を短くする保持時間を延ばす、支持点を減らす

4.1 押す - 肩と手首が先である

  • 手首・肘・肩が一直線に整列するよう手の位置を取る。手が前や横に開きすぎると肩に負荷が集まる
  • 胴体は一つの塊として維持する。腰が下に落ちたり尻が上に突き出たりすると、負荷が腰に移る
  • 下りるときに息を吸い、押し上げるときに吐く。 力を使う区間で息を止めない
  • 可動域より整列が先である。深く下りられなくても、整列が保てる範囲で反復するほうがよい

4.2 引く - 自宅でもっとも抜けやすい系統

  • 自宅では引く動作が抜けやすい。 押すと下半身は自重でできるのに、引くにはつかむものが必要だからだ。タオルを両手で持ち互いに反対方向へ引く方法でも代用できる
  • 肩を耳のほうへ上げない。 引くときは肩を下と後ろへ下げて固定してから始める
  • 引くときに吐き、戻すときに吸う。 戻る区間を急に放さない
  • 首に力が入るなら強度が過剰である。張力を下げるか範囲を狭める

4.3 下半身 - 膝ではなく股関節から

  • 動きを股関節から始める。 尻を後ろへ送りながら座る順序が先で、膝はあとから付いてくる
  • 膝がつま先と同じ方向を向くようにする。内側へ崩れるのがもっとも多い問題である
  • 下りるときに吸い、立つときに吐く。 立ち上がる最後に腰を反らせすぎない
  • 椅子を使えば難度を正確に調節できる。座面が高いほどやさしくなるので、座布団一枚でも段階が作れる

4.4 体幹 - 時間より姿勢が先

  • 腰を過度に反らせたり丸めたりしない。 骨盤と肋骨の間隔を一定に保つ感覚で構える
  • 保持している間、息を止めない。 浅く規則的に呼吸を続けるのが原則である
  • 保持時間は姿勢が保てる間までである。姿勢が崩れたあとの時間は記録に残るだけで効果には残らない
  • 首に痛みが出たら直ちに中止する。体幹の動作で首が痛いのは、たいてい強度の問題ではなく姿勢の問題である

この記事が扱わない動作。 空中へ跳び上がる動作、逆立ちの系統、反動を大きく使う全身動作、関節を限界まで曲げたりひねったりする動作は扱わない。けがの危険が相対的に大きく、フォームを見てくれる人がいない環境では自分で修正しにくいからである。上の四つの系統だけでも第2節の表の筋力の項目は満たせる。

5. 漸進性過負荷 - 一度に一つだけ変える

運動が同じ場所にとどまらないためには、負荷が少しずつ上がる必要がある。問題は上げられる取っ手が複数あることだ。回数、セット、休息、難度、時間。これらを一度にいじると総負荷は掛け算で増える。

だから規則は2行で済む。順序を守る。そして同じ週に二つを変えない。

  1. フォームを安定させる - これが済むまでは何も増やさない
  2. 反復回数を増やす - もっとも小さい単位の変化なので戻すのも簡単だ
  3. セット数を増やす - 総時間も一緒に増える点を併せて見る
  4. セット間の休息を短くする - 重さを増やさずに強度を上げる方法である
  5. 動作の難度を上げる - 最後の取っ手だ。上げれば回数は下げ直す
何をいつ増やすかどれだけ注意
反復回数決めた回数をフォームを崩さずに2回連続のセッションでこなせたとき1セットに1~2回最後の反復で崩れるならまだ早い
セット数回数をさらに増やすのが負担になったとき一度に1セット総時間が急増するので週単位で確認
休息時間全セットをこなしても余裕があるとき一度に10~15秒呼吸が戻らないなら元に戻す
動作の難度上の三つをすべて調整したあと一つの動作ずつ難度を上げたら回数を下げて再開する
有酸素の時間終えた翌日の生活に支障がないとき一度に5分週単位の総量で判断する

一度に一つだけ変える理由は二つある。第一に、体が受ける総負荷が想定より大きく増える。 セットを一つ増やしながら難度まで上げると、体感は2倍ではなくそれ以上になる。自宅での運動の失敗談の大半がこの区間に集まっている。

第二に、原因を判別できなくなる。 翌週に膝が痛み始めたとしよう。セットも増やし難度も上げていたなら、何を戻すべきか分からない。一つだけ変えていたなら戻すものも一つだ。記録が意味を持つのもこの地点である。

  • 戻すことは規則の一部である。フォームが崩れたら直ちに前の段階へ戻る。失敗ではなく手順だ
  • 3日以上休んだなら一段下から再開する。抜けた分を取り戻そうとする試みがもっとも危険である
  • 痛みがある間は増やさない。 痛みのある状態での増加は規則違反として扱うほうが安全だ

7. 回復 - 休息日、睡眠、そして痛みという合図

運動の効果は運動している間ではなくその合間に作られる。だから休息日を「やらなかった日」と数えると計画が狂う。休息日は実行項目である。

回復の区間でもっとも重要な判断は筋肉痛と痛みを区別することだ。二つを同じものとして扱うと、両方向の誤りが起きる。正常な筋肉痛に驚いて中断するか、扱うべき痛みを我慢して続けるかである。

比較項目よくある筋肉痛に近い痛みとして扱うべき
位置筋肉の部位に全体的に関節や特定の一点に
左右両側が同じくらい片側だけ
性質張ってだるい感じ鋭く刺す、またはしびれる
動かすとき軽く動かすと少し楽になる動かすほど強くなる
経過数日で減っていく減らない、または腫れや熱感を伴う
  • 休息日に完全に横になる必要はない。 軽く歩いたりストレッチしたりする程度の活動は休息と衝突しない
  • 同じ部位を続けて強く使わない。 第6節の例で筋力を A と B に分けた理由である
  • 睡眠が不足している週には増やさない。 回復条件が悪い状態での増加は負荷だけが残る
  • 痛みがあればその部位を使う動作を外し、他の系統を維持する。全体を中断するよりよい
  • 治らない、あるいは繰り返す痛みは受診の対象である。自分で原因を推定して試し続けない

ここで一つ押さえておきたいことがある。筋肉痛の程度は運動の効果を測る目盛りではない。 痛くなかったから無駄だったわけでもなく、たくさん痛かったからよくやったわけでもない。効果を見るには第10節の記録を見る必要がある。

8. 続ける構造 - 意志ではなく構造を変える

続けられない理由を意志に求めると対策が出てこない。もっと強く決意することは実行可能な措置ではないからだ。代わりに実行を妨げる条件と、実行を促す条件を変えるほうが扱いやすい。

この節は動機づけの話ではない。決定しなければならない回数を減らす設計の話である。毎回「今日やるかやらないか、何をするか、何セットやるか」を決めていると、その決定の費用そのものが離脱の原因になる。

  • 最小単位をあらかじめ決めておく。 調子の悪い日に実行するごく小さな版を決めておけば、その日の選択肢が全部か無かではなくなる
  • 時間と場所を固定する。 いつやるかを毎回決めなくてよければ、決定が一つ減る
  • 準備の摩擦をなくす。 マットを出し服を探す段階が長いほど始める確率は下がる。目に見える場所に置くだけで足りることも多い
  • 計画を週単位で見る。 一日できなかったという事実より、その週に何セッションできたかが管理可能な指標である
  • 復帰の規則を先に作る。 第5節の「一段下から再開」がその規則だ。規則があれば復帰に判断が要らない

まとめるとこうなる。続ける人は意志が強い人ではなく、決定を減らせる構造を持っている人である場合が多い。そしてその構造が働いているかは次の節の記録で確認する。

9. よくある失敗 - 大半は最初の2週間で決まる

以下は自宅での運動で繰り返し観察される失敗である。共通点は序盤で決まることであり、だからこそ序盤に気をつけるだけでかなりの部分を避けられる。

失敗何が起きるか代わりにすること
最初の週から全力2週目に筋肉痛と疲労が重なり3週目に離脱最初の2週間は増やさない区間として固定
フォームより回数を優先記録は伸びるが負荷が意図しない場所へ行くフォームが保てる範囲までで反復
痛みを我慢して継続回復期間が長引き結局もっと長く休む痛みは中止の合図として扱い、必要なら受診
有酸素だけ、または筋力だけ第2節の勧告の半分にしか従わない週単位で両方が入るよう配置
同じ週に複数を増やす結果が悪かったとき原因が分からない第5節の順序どおり一度に一つだけ
数日抜けたから最初から繰り返し序盤だけやって終わる一段下から続けて再開
  • 昨日できなかったから今日は倍という補正がもっとも危険である。負荷は繰り越されない
  • 動画の中の速度をそのまま追うこともよくある罠だ。速度は難度の一部なので自分の速度に落として行う
  • 運動の前後の痛みを区別しないことも問題である。始めるときから痛かったなら、それは運動が作った痛みではない
  • 記録なしに勘で増やすことは結局無理につながる。次の節がその対策である

10. 記録と点検 - 何を書けば進歩が見えるか

運動記録というと、たいてい体重から書く。ところが体重は実行量とのつながりが緩く変動要因が多いため、短期のフィードバックには使いにくい。実行を調節するのに使える値は別にある。

  • 4週間で変えた項目が4個以下か - 週に一つを超えたなら増やす速度が速かった合図である

11. よくある質問

Q1. 1日10分ずつ分けて行ってもよいか

第2節の表の数値は週単位の総量として示されている。一度にまとめて行うべきという条件が付いていないので、分けて積み上げる方式そのものを排除する根拠は、この記事が確認した資料にはない。ただし筋力の項目は性格が違う。1セット8~12回の反復という形が併せて示されているので、時間を細かく刻むよりセット単位を守るほうが勧告に近い。

Q2. 器具を買わないと始められないのか

第4節の四つの系統は器具なしでも構成が可能である。引くだけつかむものが必要だが、タオルで代用できる。この記事は特定の器具やアプリケーション、サプリメントを推奨しない。器具をそろえることが開始を先延ばしにする理由になる例は実際に多く、第8節の観点から見ればそれは開始の摩擦を増やす決定である。

Q3. 毎日やらないと効果がないのか

第2節の表は筋力運動を週2日以上として示しており、毎日とは示していない。有酸素も週あたりの総量として示される。第7節で扱ったとおり回復の区間が必要で、特に開始の段階では毎日やろうとする計画そのものが離脱の原因になることが多い。休息日を計画に含めるほうが実行率には有利である。

Q4. 年齢が高いが筋力運動をしてよいのか

第2節の表では満65歳以上にも筋力運動を週2回以上が示され、そこに平衡性の運動を週3日以上が加わる。つまり年齢が筋力運動を排除する条件としては示されていない。ただし第1節の表の項目、特に最近の転倒やバランスの不安に当てはまるなら、始める前の相談が必要だ。平衡性を扱う要素が先に必要な場合があるからである。

Q5. やせるまでどれくらいかかるのか

この記事は期間と体重の変化量を結びつけた数値を示さない。 そうした数値は個人差が非常に大きく、この記事が確認した一次資料の中で裏づけを探していないからだ。代わりに第10節の指標を勧める。実行率、同じ動作での体感強度の変化、四つの系統の均衡。この三つは週単位で確認でき、次の行動を変えられる情報である。

結論: 最低線を知り、その下から始める

自宅での運動でもっともよく失敗する地点は種目の選択ではない。開始の強度と増やす速度である。だからこの記事はルーティンの代わりに二つを残す。一つは第2節の表、つまり出典を持つ最低線が正確にいくつなのか。もう一つは第5節の規則、つまり一度に一つだけ変えるということだ。

順序をもう一度整理するとこうなる。第1節で始めてよいかを確認する。第2節で最低線を知る。第3節で強度を判断する。第4節で四つの系統から選ぶ。第6節の例で低く出発する。第5節の規則で上げる。第7節で回復を管理し、第10節の記録で来週を決める。

そしてこのすべてに先立つものが一つある。運動中に危険な兆候が現れたら直ちに止めることである。どんな計画も、どんな記録も、それより優先しない。

免責。 この記事は一般的な情報提供を目的としており、適切な運動の種類と量は個人の健康状態によって変わる。診断・治療・処方に代わるものではない。 第1節に当てはまる項目があるとき、または運動中に危険な兆候が現れたときは医療の専門家に相談してほしい。本文の勧告数値は下記の参考資料で確認したものであり、確認日以降に各機関の指針が更新される場合がある。

## 1. 始める前に相談が必要な場合 (一つでも当てはまるなら先に相談)

- [ ] 心血管疾患と診断されたことがある、または胸の痛み・圧迫感を感じたことがある
- [ ] 血圧・血糖・心臓に関する薬を服用している
- [ ] 膝・腰・肩に痛みがある、または関節の疾患と診断されている
- [ ] 妊娠中である、または出産して間もない
- [ ] 最近手術を受けた、または入院治療を終えたばかりである
- [ ] 65歳以上で、最近転倒したことがある、またはバランスに不安がある
- [ ] めまいや失神を経験したことがある
- [ ] 長期間ほとんど動いていない状態から、いきなり強度の高い運動を始めようとしている

当てはまる項目があっても、運動ができないという意味ではありません。どの種類をどの強度で行うかを決めるのに、専門家の判断が必要だという意味です。

## 2. 運動中に直ちに中止して受診すべき兆候

- [ ] 胸の痛み、圧迫感、締めつけられる感じ
- [ ] めまい、失神しそうな感じ、視界がぼやける
- [ ] 普段とは違う程度の息苦しさ、休んでも収まらない息切れ
- [ ] 関節の鋭い痛み、刺すような痛み
- [ ] 片側の手足のしびれ、脱力、ろれつが回らない
- [ ] 不規則な脈、激しい動悸
- [ ] 冷や汗を伴う吐き気

この一覧は「様子を見る」ためのものではなく「直ちに中止する」ためのものです。運動をやめ、症状が続くか繰り返す場合は受診してください。

```
  日  休息

  この区間の目標は「抜けないこと」ひとつだけです。
  2週間まるごと満たせたら、そこで初めて一つだけ増やします。

3~4週目  (一度に一つだけ変える)
  変更する項目: セット数のみ、2から3へ。有酸素の時間と動作の難度はそのまま。
  月  筋力 A   3セット                                    約20分
  火  有酸素                                              約20分
  水  休息
  木  筋力 B   3セット                                    約20分
  金  有酸素                                              約25分

  日  休息

  セットを増やしたなら次の変更は有酸素の時間、
  その次は動作の難度という順に一つずつ。同じ週に二つは変えません。
```

## 5. 増やし方の規則 (一度に一つだけ)

変える順序
1. フォームを安定させる — これが済むまでは何も増やさない
2. 反復回数を増やす
3. セット数を増やす
4. セット間の休息を短くする
5. 動作の難度を上げる

| 何を | いつ増やすか | どれだけ | 注意 |
| --- | --- | --- | --- |
| 反復回数 | 決めた回数をフォームを崩さずに2回連続のセッションでこなせたとき | 1セットあたり1~2回 | 最後の反復でフォームが崩れるなら、すでに超えている |
| セット数 | 反復回数をさらに増やすのが負担になったとき | 一度に1セット | 総時間が急に増えるので週単位で確認する |
| 休息時間 | 全セットをこなしても余裕があるとき | 一度に10~15秒 | 呼吸が戻らないなら元に戻す |
| 動作の難度 | 上の三つを調整し終えたあと | 一つの動作ずつ | 難度を上げたら回数は下げ直す |
| 有酸素の時間 | 終えた翌日に支障がないとき | 一度に5分 | 週単位の総量で見る |

戻す規則
- フォームが崩れたら直ちに前の段階に戻します。戻すことは失敗ではなく、規則の一部です
- 3日以上休んでから復帰するときは、最後にやっていた量の一段下から再開します
- 痛みがあるときは増やしません。痛みのある状態での増加は規則違反です

## 6. 週間記録用紙

```
週: ____週目          期間: ____.__.__ ~ ____.__.__

日付    やったこと    動作・セット・回数        体感強度(1~10)    終わった後の状態
----    ----------    ---------------------    --------------    ------------------
  /     筋力 A        押す 3x8  下半身 3x10
  /     有酸素        歩行 20分
  /     休息
  /     筋力 B
  /     有酸素
  /
  /

今週予定したセッション数: ___     実際に行ったセッション数: ___

変えたもの (週に一つだけ):
  [ ] 何も変えず   [ ] 回数   [ ] セット   [ ] 休息   [ ] 難度   [ ] 有酸素の時間

体の兆候:
  [ ] 関節の痛みなし       [ ] 痛みがあった → どこ: ________
  [ ] 翌日の生活に支障なし  [ ] 支障あり
  [ ] 睡眠はいつも通り     [ ] 悪化した

来週変える一つ: ________________________
```

記録するときの原則
- うまくいった日ではなく、やった日をすべて書きます。抜けた日の空白がいちばん多くの情報を与えます
- 体感強度は数字の正確さではなく推移を見ます。同じ動作で体感が下がったなら、それが進歩です
- 体重はこの表に入れません。この表は実行量と体の兆候を追うためのものです

## 7. 4週ごとに回す点検表

- [ ] 4週間で計画したセッションのうち何パーセントを実際に行ったか (実行率が最初の指標)
- [ ] 同じ動作・同じ回数で、体感強度は下がったか
- [ ] 押す・引く・下半身・体幹の四つがすべて入っているか、片方に偏っていないか
- [ ] 有酸素と筋力のどちらか一方だけになっていないか
- [ ] この4週で変えた項目は4個以下か (週に一つを超えたなら速すぎた)
- [ ] 残っている痛みはあるか — あるなら次の4週は増やさず維持する
- [ ] 休息日を実際に休んだか
- [ ] 記録が空白の週はあるか — その週に何があったかを一行書く

## 8. やってはいけないこと

- 最初の週から全力で行うこと — 自宅での運動が崩れる最も多い経路です
- フォームより回数を優先すること — 崩れたフォームで埋めた回数は記録に残るだけで進歩ではありません
- 痛みを我慢して続けること — 痛みは情報であって、乗り越える対象ではありません
- 同じ週に二つ以上増やすこと — 何が効いて何が無理だったのか判別できなくなります
- 有酸素だけ、あるいは筋力だけを行うこと — 機関の勧告は両方を並べて示しています
- 数日抜けたからと最初からやり直すこと — 一段下から続ければ済みます
- 特定の器具・アプリ・サプリメントがなければ始められないと考えること — 始めるのに要るのは場所と時間です
