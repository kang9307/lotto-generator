序論: 料金こそアーキテクチャだ

2026年のAI開発で、モデル選択はもはや「どれが一番賢いか」だけの問題ではない。同じ機能を作っても、どのAPIを使うかで月々の請求が10倍以上変わる。とりわけB2B製品やスタートアップのように呼び出し量が大きいワークロードでは、100万トークンあたりの単価(per 1M tokens)がそのまま単位経済性を決め、単位経済性が事業の存続を決める。

以下では、2026年9月29日時点で各社の公式価格ページに載っている主要LLM API料金をinput/outputに分けて一表にまとめ、コンテキストウィンドウ・マルチモーダル・キャッシュ割引という別の軸も併せて見る。その上で「最高性能 vs コスパ vs オープン」の三つの道に分けて用途別の候補を絞り、キャッシュとルーティングでコストを削る実戦テクニックを整理する。

料金変動の免責(重要): 以下のすべての数値は2026年9月29日時点の各社公式価格ページの値だ。LLM API単価は四半期・月単位で頻繁に変わり、プロモーション・地域・ティアによって異なり、キャッシュ・バッチ割引の構造もモデルごとに違う。表には終了日が明示された期間限定の単価(GPT-5.6 Solは少なくとも2026年11月21日まで、Gemini 3.8・3.7 Flashは2026年12月31日まで)と時間帯によって2倍に跳ねる単価(DeepSeek)が混ざっており、同じ行でもいつ呼び出すかで請求額が変わる。実際の導入・見積もりの前には、必ず各プロバイダの公式価格ページで最新単価をもう一度確かめること。ここに載せた単価は意思決定の出発点であって、契約単価の根拠ではない。

2. 料金以外の比較軸 - コンテキスト・マルチモーダル・キャッシュ

単価だけ見ても全体の半分しか見えない。実際のコストと適合性は次の三つの軸で分かれる。

2.1 コンテキストウィンドウと「長コンテキストプレミアム」

コンテキストウィンドウは一回のリクエストに入れられる入力の量だ。注意すべきは長コンテキストプレミアムである。OpenAIはGPT-6の三モデルもGPT-5.6・GPT-5.5も、入力が272Kを超えると入力とキャッシュが2倍、出力が1.5倍になる構造だ(GPT-6 Solなら$4.00/$15.00)。Gemini 3.1 Proは200Kを超えると$4.00/$18.00に、Grok 4.7は200K以上で$4.00/$12.00に上がる。一方AnthropicはClaude 4.6以降のモデルについて、100万トークン全体を標準単価で課金すると価格ページに書いている。長い文書を丸ごと入れるワークロードなら、このプレミアム構造が実効単価を左右する - 表の最初の二列だけで見積もると、実際の請求と2倍近くずれることがある。

2.2 マルチモーダル対応

テキストだけなら関係ないが、画像・音声・文書を扱うならマルチモーダル対応が選択肢を絞る。Gemini 2.5 Flashはテキスト・画像・動画の入力を$0.30、音声入力を$1.00で受け、マルチモーダルのコスパが良い。GPT-6の三モデルとGPT-5 miniもテキストと画像の入力を受ける。画像トークンは別途計算され、高解像度の入力はトークン消費が大きく増えうるため、マルチモーダルのワークロードをテキスト単価だけで見積もってはいけない。

2.3 キャッシュ割引と速度

同じプレフィックス(システムプロンプト、長い参照文書、ツール定義)を繰り返し送るワークロードでは、プロンプトキャッシュがコストを大きく下げる。ただし割引幅と規則はベンダーごとに違う。Anthropicはキャッシュヒットを基本入力の0.1倍で課金するが、Opus 5.5は0.05倍、Fable 5.1は0.025倍で、キャッシュ書き込みには5分で1.25倍・1時間で2倍が付く。OpenAIはキャッシュ済み入力を定価の10%、キャッシュ書き込みを1.25倍で課金する(GPT-6基準)。GoogleはGemini 3.8 Flashのキャッシュ入力が$0.075で定価の10%だが、100万トークンあたり1時間$0.50の保管料が別に付く。xAI Grok 4.7はキャッシュ入力が定価の25%、DeepSeek V4.1 Flashは約2%、GLM-5.3は約19%だ。バッチ処理はAnthropic・OpenAI・Googleのいずれも標準価の50%だ。また低遅延が重要なリアルタイムUXでは、Haiku 4.5・Gemini 2.5 Flash・GPT-5 miniのような小型で速いモデルが有利だ。速度と単価はおおむね同じ方向に動く - 小さく安いモデルほど速い傾向がある。

3. 用途別おすすめ - 最高性能 vs コスパ vs オープン

正解は単一のモデルではなく、ワークロードごとの配置だ。三つの道に整理する。

3.1 最高性能 - 複雑な推論・高リスクのコード

正確さがそのまま信頼で、ミスのコストが大きい領域 - 本番マイグレーション、セキュリティに敏感なコード、長期の自律エージェント - ではフラッグシップが安全だ。Anthropicは大半の作業をClaude Opus 5.5(input $4.00・output $20.00)から始め、要求の大きい推論と長期のエージェント作業にはClaude Fable 5.1(input $10.00・output $50.00)を使うよう案内している。OpenAIはGPT-6 Astra(input $10.00・output $50.00)を最も難しい作業向けの最上位モデルと説明し、前世代のGPT-5.6 Solはプロモーション価格の$4.00・$20.00だ。さらに高い側にはセキュリティ研究向けのGPT-5.6 Cyber(input $12.50・output $75.00)がある。output単価が高いので、長い出力が多いエージェントのワークロードではトークンの暴走を防ぐ上限設計が重要だ。Claude Sonnet 5.5とGPT-6 Solはどちらもinput $2.00・output $10.00で上位帯の中では単価が低く、コストに敏感でも高い性能が要る場合の均衡点だ。

3.2 コスパ - 大量呼び出し・リアルタイム応答

分類・要約・抽出・定型応答のように難度が低く呼び出し量が大きい作業は、小型・低価格モデルが正解だ。主要クローズド勢の中ではGPT-6 Luna(input $0.10・output $0.50)が表で最も低く、GPT-5.6 Luna(input $0.20・output $1.20)、Gemini 3.5 Flash-Lite(input $0.30・output $2.50)、Gemini 3.8 Flash(input $0.75・output $3.75)が続く - ただし3.8 Flashの単価は2026年12月31日までしか適用されず、翌年から2倍になる。旧世代のGemini 2.5 Flash(input $0.30・output $2.50)とGPT-5 mini(input $0.25・output $2.00)も価格表に残っている。Claude Haiku 4.5(input $1.00・output $5.00)は低遅延が要るリアルタイムUXに向くが、Anthropicは後継のHaiku 5.5を「数週間のうちに」出すと予告しており、Haiku 4.5の引退は2026年10月15日より早くないとだけ告知されている。Grok系は4.3がinput $1.25・output $2.50、4.7がinput $2.00・output $6.00だ。

3.3 オープンウェイト - 最安・データ統制

コストの底を狙う場合や、データを外部に出しにくい場合はオープンウェイト系が魅力的だ。DeepSeek V4.1 Flashはホスト型API基準で非ピークinput $0.15・output $0.60と最安圏だが、ピーク時間帯には$0.30・$1.20と2倍になるので、「最も安いモデル」という言葉が一日中正しいわけではない。旧モデル名deepseek-v4-flashで送ったリクエストもV4.1 Flashが処理し、同じ単価で請求される。GLM系は5.3と5.1がどちらもinput $1.40・output $4.40で、小型のGLM-5.3-Flashは$0.15・$0.50だ。Kimi K2.7 Codeはinput $0.95・output $4.00でコンテキスト262,144、上位のKimi K3は$3.00・$15.00でコンテキスト1,048,576だ。ただしオープンウェイトの本当の利点である自前ホスティングはGPUの資本・運用負担を伴うので、ホスト型の単価が安いことと自前運用が安いことは別の損益分岐の計算だ。

4. コスト削減の実戦テクニック

同じモデルを使っても、設計でコストを大きく減らせる。

4.1 プロンプトキャッシュを設計段階で組み込む

システムプロンプト・ツール定義・長い参照文書のように変わらないプレフィックスを前に、毎回変わる質問を後ろに置けばキャッシュヒット率が上がる。キャッシュはプレフィックス一致なので、先頭にタイムスタンプやUUIDが一つ混ざるだけでキャッシュが壊れる。チャットボット・RAG・エージェントのように固定コンテキストが反復するパターンでは、キャッシュだけでinputコストを大きく下げられる。キャッシュ書き込みに割増が付くベンダー(Anthropic・OpenAI)や保管料が付くベンダー(Google)では、一度使って捨てるキャッシュがかえって損になることがある。

4.2 モデルルーティング - 易しいものは安く、難しいものは高く

すべてのリクエストをフラッグシップに送るのが最もよくある無駄だ。難度の分類器を置き、易しい作業はGPT-6 Luna・Gemini 3.5 Flash-Lite・Haiku 4.5のような小型モデルへ、複雑な推論・高リスクだけをフラッグシップへ送れば平均単価が急減する。プロバイダ非依存のゲートウェイで抽象化すれば、価格が変わったときのモデル交換が書き直しではなく設定変更になる。

4.3 outputを減らし、バッチを活用する

output単価はinputより3〜6倍高いので、不必要に冗長な出力を減らすだけでコストが下がる。定型出力(JSONスキーマ)で無駄をなくし、推論トークンが多すぎるモデルは努力レベルを下げて見えないoutputを抑える。遅延に鈍感な大量作業はバッチAPI(Anthropic・OpenAI・Googleいずれも50%割引)で処理すれば単価が半分になる。

5. 結論 - 単価表でなく実効コストで判断せよ

2026年のLLM市場は、フラッグシップが上で性能を競い、小型・オープンモデルが下で単価を崩す両極構造だ。9月末の世代交代も同じ方向を向いている — Claude Opus 5.5はOpus 5より安く、GPT-6 LunaはGPT-5.6 Lunaの半分の単価で出た。要は単一の単価表を覚えることではなく、自分のワークロードのinput:output比とキャッシュヒット率を掛けた実効コストで比べることだ。同じ「100万トークン5ドル」でも、キャッシュがよく効くRAGと推論トークンが暴走するエージェントでは実際の請求がまったく違う。

今週やる具体的な三手: 第一に、代表的なトラフィック100件の実際のinput・outputトークンを測り、モデル別の実効単価を計算する。第二に、固定プレフィックスにキャッシュを適用してヒット率を確かめる。第三に、易しい作業を小型モデルへ振り分けるゲートウェイを置き、フラッグシップの比重を減らす。そして何より、このページのすべての単価は2026年9月29日時点のもので、プロモーション・時点によって変わるため、見積もりの前に公式価格ページを必ずもう一度確かめること。

# LLM API 費用見積もりチェックリスト — 単価表を請求書に変える前に

基準日: 2026-09-29

> 出典: braindetox.kr — 2026 AI API料金比較
> 単価は各社の公式価格ページ基準(USD、100万トークンあたり)で、頻繁に変わります。見積もり前に公式ページを開き直してください。

## 1. モデル候補を選ぶ前に

- [ ] 代表的なリクエスト100件の実際のinput・outputトークンを測った
- [ ] input:output比を計算した(要約・抽出はinput寄り、コード・エージェントはoutput寄り)
- [ ] 入力長の最大値を確かめた — 下の2の境界を超えるかを見る
- [ ] 同じプレフィックスが繰り返されるか確かめた(キャッシュ候補)
- [ ] 即時の応答が要らない作業を分けた(バッチ候補)

## 2. 長コンテキストの境界 — 超えると単価が変わる

| ベンダー | 境界 | 超えると |
|---|---|---|
| OpenAI (GPT-6・GPT-5.6・GPT-5.5) | 入力272K超 | リクエスト全体が入力・キャッシュ2倍、出力1.5倍 |
| Google (Gemini 3.1 Pro・2.5 Pro) | プロンプト200K超 | 区間単価を適用(3.1 Pro は $4.00/$18.00) |
| xAI (Grok 4.7・4.3) | プロンプト200K以上 | リクエストの全トークンに長コンテキスト単価 |
| Anthropic (Claude 4.6 以降) | なし | 100万トークン全体が標準単価 |

## 3. キャッシュの規則 — ベンダーごとに違う

| ベンダー | キャッシュヒット(読み出し) | 書き込み・保管 |
|---|---|---|
| Anthropic | 基本入力の0.1倍(Opus 5.5 は0.05倍、Fable 5.1 は0.025倍) | 5分1.25倍・1時間2倍 |
| OpenAI | 定価の10% | 書き込み1.25倍(GPT-6基準) |
| Google | Gemini 3.8 Flash $0.075(定価の10%) | 100万トークンあたり1時間 $0.50 の保管料 |
| xAI | Grok 4.7 定価の25% | — |
| DeepSeek | V4.1 Flash 約2%($0.003) | — |
| Z.ai | GLM-5.3 約19%($0.26) | 保管料は「期間限定無料」 |

- [ ] 書き込みに割増があるベンダーで、一度しか使わないキャッシュを作っていないか
- [ ] プレフィックスの先頭にタイムスタンプやUUIDが混ざってキャッシュが壊れていないか

## 4. 期間限定単価と時間帯単価

- [ ] GPT-5.6 Sol $4.00/$20.00 — 少なくとも2026-11-21までのプロモーション。その後の単価でも予算を組んだ
- [ ] Gemini 3.8・3.7 Flash $0.75/$3.75 — 2026-12-31まで。2027-01-01から $1.50/$7.50
- [ ] DeepSeek — ピーク(UTC 月〜金 01:00-04:00、06:00-10:00)は2倍。リアルタイムサービスはピーク単価で計算した
- [ ] 予告だけのモデル(Claude Haiku 5.5)は予算に入れていない

## 5. バッチとルーティング

- [ ] バッチ可能な作業を50%割引の経路(Anthropic・OpenAI・Google のバッチ、OpenAI・Google の Flex)に回した
- [ ] 易しい作業を小型モデル(GPT-6 Luna $0.10/$0.50、Gemini 3.5 Flash-Lite $0.30/$2.50、Haiku 4.5 $1.00/$5.00 など)へ送る規則を置いた
- [ ] モデル交換が設定変更で済むようゲートウェイで抽象化した

## 6. 実効単価の計算式

```
月額 = (月のinputトークン × (1 − キャッシュヒット率) × input単価
       + 月のinputトークン × キャッシュヒット率 × キャッシュ単価
       + 月のoutputトークン × output単価) × (1 + 再試行率)
```

- 長コンテキストの境界を超えるリクエストは、そのリクエスト全体を長コンテキスト単価で計算し直す
- バッチに回す分は、そのベンダーのバッチ単価で別に計算する

## 7. 計算し直すべき時点

- ベンダーが新しいモデルやティアを出したとき(予告された Claude Haiku 5.5 など)
- 期間限定単価の期限が過ぎたとき(2026-11-21、2026-12-31)
- 使っているモデルの引退予定日が告知されたとき(Claude Haiku 4.5 は2026-10-15より早くない)
- 価格表からモデルが消えたり名前が変わったりしたとき(DeepSeek V4 Flash → V4.1 Flash のように)
