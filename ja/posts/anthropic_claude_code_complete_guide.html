Anthropic Claude Code 完全ガイド：AIコーディングアシスタントのすべて

Complete Guide to Anthropic Claude Code: Everything About AI Coding Assistant

2025-12-25 IT・技術

Claude Codeは、Anthropicが開発した公式のAIコーディングアシスタントCLI(Command Line Interface)ツールです。ターミナル上で動作し、開発者がアイデアを素早くコードに変換したり、バグを修正したり、コードベースを探索したりする際に革新的な支援を提供します。本ガイドでは、Claude Codeのインストールから高度な機能まで、すべてを詳しく解説します。

English: Claude Code is the official AI coding assistant CLI tool developed by Anthropic. It operates in the terminal and provides revolutionary assistance to developers in quickly converting ideas into code, fixing bugs, and navigating codebases. This guide covers everything from installation to advanced features of Claude Code in detail.

1. Claude Codeとは何か？

1.1 コアコンセプト

Claude Codeは、エージェントベースのアーキテクチャを採用したターミナルネイティブのAIツールです。従来のIDEプラグインとは異なり、Claude Codeはターミナル上で直接動作し、ファイル編集、コマンド実行、Gitコミット作成などを自律的に実行できます。

│                  Claude Code アーキテクチャ              │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   [ユーザー] ───────────────────────────── [ターミナル]   │
│       │                                       │         │
│       ▼                                       ▼         │
│   自然言語命令 ────────────► Claude Code Engine         │
│                                      │                  │
│                    ┌─────────────────┼─────────────────┐│
│                    ▼                 ▼                 ▼│
│             [ファイル読み取り] [コード修正] [コマンド実行]│
│             [検索/解析]     [テスト作成] [Git操作]      │
│                                                         │
└─────────────────────────────────────────────────────────┘

1.2 主な特長

  • ターミナルネイティブ: IDEではなくターミナルで直接動作
  • エージェントモード: 自律的にタスクを計画・実行
  • パイプ対応: Unix哲学に従って他のツールと連携可能
  • 直接実行: ファイル編集、コマンド実行、Gitコミット作成が可能
  • コンテキスト認識: コードベース全体を理解して作業

1.3 主な使用ケース

ユースケース 説明 コマンド例
コード生成 自然言語の説明からコードを作成 「ユーザー認証APIエンドポイントを作って」

リファクタリング コード品質の改善 「この関数をTypeScriptに変換して」

ドキュメント化 コードコメントとREADMEの作成 「このプロジェクトのREADMEを書いて」

2. インストールと始め方

2.1 インストール方法

Claude Codeはさまざまな方法でインストールできます:

macOS/Linux/WSL (推奨)

# 公式インストールスクリプト
curl -fsSL https://claude.ai/install.sh | bash

Windows PowerShell

# PowerShellで実行
irm https://claude.ai/install.ps1 | iex

Homebrew (macOS)

# Homebrewによるインストール
brew install --cask claude-code

NPM

# NPMによるインストール
npm install -g @anthropic-ai/claude-code

2.2 初回実行

# プロジェクトディレクトリに移動
cd your-project

# Claude Codeを起動
claude

# 初回実行時はログインが必要
/login

2.3 システム要件

  • OS: macOS 10.15+, Windows 10+, Linux (Ubuntu 20.04+)
  • Node.js: 18.0以上 (NPMインストール時)
  • メモリ: 最低4GB RAM推奨
  • インターネット: 安定したインターネット接続が必要

3. スラッシュコマンド完全ガイド

3.1 基本コマンド

Claude Codeはさまざまなスラッシュコマンドを提供します:

コマンド 説明
/help ヘルプを表示
/config 設定画面を開く
/model AIモデルの選択 (Sonnet, Opus, Haiku)
/clear 会話履歴を初期化
/compact 会話を圧縮 (トークン節約)
/cost トークン使用量とコストの統計
/exit Claude Codeを終了

3.2 高度なコマンド

コマンド 説明
/agents サブエージェントの管理
/mcp MCPサーバー連携の管理
/memory CLAUDE.md メモリの編集
/permissions 権限管理
/resume 以前の会話を再開
/hooks Hooks設定
/sandbox サンドボックスモード有効化
/doctor インストール状態の確認
/bug バグレポートの送信

3.3 ユーザー定義のスラッシュコマンド

独自のコマンドを作成できます:

# 場所: .claude/commands/commit.md

---
argument-hint: [message]
description: Gitコミットメッセージ生成
---

`git diff HEAD` を見て、適切なGitコミットメッセージを作成してください: $ARGUMENTS

その後、/commit "バグ修正" の形式で使用できます。

4. エージェントモードとサブエージェント

4.1 エージェントモードとは？

Claude Codeのエージェントモードは、自律的にタスクを計画・実行する機能です:

4.2 サブエージェント (Sub-agents)

特化したAIアシスタントを定義して使用できます:

# 場所: .claude/agents/code-reviewer.md

---
name: code-reviewer
description: コードレビューのスペシャリスト。コード変更後に使用
tools: Read, Grep, Glob, Bash
model: sonnet
---

あなたはシニアコードレビュアーです。次の原則に従ってコードをレビューしてください:
1. 可読性と保守性の確認
2. セキュリティ脆弱性のレビュー
3. パフォーマンス最適化の提案
4. テストカバレッジの確認

4.3 組み込みサブエージェント

  • Plan Agent: プランモードでコードベース調査
  • Explore Agent: 素早いコード探索 (読み取り専用)
  • General Purpose Agent: 複雑な多段階タスクの処理

5. MCP (Model Context Protocol) サーバー連携

5.1 MCPとは？

MCPは、外部ツールやデータソースをClaude Codeに接続するためのオープンプロトコルです。GitHub、Jira、Slackなど、さまざまなサービスと統合できます。

5.2 MCPサーバーのインストール

# HTTPサーバーを追加
claude mcp add --transport http notion https://mcp.notion.com/mcp

# SSEサーバーを追加
claude mcp add --transport sse asana https://mcp.asana.com/sse

# ローカルStdioサーバーを追加
claude mcp add --transport stdio airtable \
  --env AIRTABLE_API_KEY=YOUR_KEY \
  -- npx -y airtable-mcp-server

5.3 MCP管理コマンド

# すべてのサーバーを一覧表示
claude mcp list

# 特定サーバーの情報を確認
claude mcp get github

# サーバーを削除
claude mcp remove github

# セッション内で管理
/mcp

5.4 人気のMCPサーバー

サーバー 用途
GitHub リポジトリ、Issue、PR管理
Sentry エラーモニタリングと分析
Notion ドキュメント・データベースアクセス
Jira プロジェクト管理・Issue追跡
PostgreSQL データベースクエリと管理
Slack チームコミュニケーション統合
Google Drive ファイル保存・共有
Figma デザインアセットアクセス

6. Skills 機能

6.1 Skillsとは？

Skillsは、Claudeが自動的に発見・使用する再利用可能なケイパビリティです。特定のタスクを実行するための指示、テンプレート、スクリプトを含めることができます。

6.2 Skillの構造

my-skill/
├── SKILL.md          # 必須: スキル定義
├── reference.md      # 任意: 参照ドキュメント
├── examples.md       # 任意: 使用例
├── scripts/
│   └── helper.py     # 任意: ヘルパースクリプト
└── templates/
    └── template.txt  # 任意: テンプレートファイル

6.3 SKILL.md の記述

---
name: pdf-processing
description: PDFファイルからのテキスト抽出、フォーム記入、PDF結合。PDFファイル作業時に使用
allowed-tools: Read, Grep, Glob
---

# PDF処理

## 指示事項

1. PyPDF または pdfplumber ライブラリを使用
2. テキスト抽出時はレイアウトを維持
3. エラー処理を含める
4. 処理結果を報告

6.4 Skillsの保存場所

  • プロジェクト: .claude/skills/skill-name/
  • 個人: ~/.claude/skills/skill-name/

7. Hooks 機能

7.1 Hooksとは？

Hooksは、特定のイベントで自動的に実行されるカスタムシェルコマンドです。ワークフロー自動化に非常に役立ちます。

7.2 Hookイベントの種類

イベント 説明 ユースケース
PreToolUse ツール実行前 特定の操作をブロック
PostToolUse ツール実行後 コードフォーマット自動化
PermissionRequest 権限リクエスト時 権限のロギング
UserPromptSubmit プロンプト送信時 入力バリデーション
Notification 通知送信時 外部通知との連携
Stop 応答完了時 完了通知
SessionStart セッション開始時 環境の初期化
SessionEnd セッション終了時 クリーンアップ処理

7.3 Hooks設定例

{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          {
            "type": "command",
            "command": "jq -r '.tool_input.command' >> ~/.claude/bash-log.txt"
          }
        ]
      }
    ],
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "npx prettier --write \"$file_path\""
          }
        ]
      }
    ]
  }
}

7.4 実際のユースケース

  • コードフォーマット: TypeScript/JavaScriptファイル保存時の自動フォーマット
  • ファイル保護: プロダクションファイルの修正をブロック
  • ロギング: すべてのbashコマンドを記録
  • リンティング: ファイル修正後に自動でリントを実行

9. 設定と構成

9.1 設定ファイルの場所

  • ユーザー設定: ~/.claude/settings.json
  • プロジェクト設定: .claude/settings.json
  • ローカル設定: .claude/settings.local.json (Git無視)

9.2 主な設定オプション

{
  "permissions": {
    "allow": [
      "Bash(npm run test:*)",
      "Read(~/.zshrc)"
    ],
    "deny": [
      "Bash(curl:*)",
      "Read(./.env)"
    ],
    "additionalDirectories": ["../docs/"],
    "defaultMode": "acceptEdits"
  },
  "env": {
    "NODE_ENV": "production",
    "CUSTOM_VAR": "value"
  },
  "model": "claude-sonnet-4-5-20250929",
  "outputStyle": "Explanatory",
  "sandbox": {
    "enabled": true,
    "autoAllowBashIfSandboxed": true
  },
  "attribution": {
    "commit": "Generated with Claude Code",
    "pr": "Generated with Claude Code"
  }
}

9.3 設定の優先順位

  1. Enterprise (最高) - 組織ポリシー
  2. Command Line - セッションの一時設定
  3. Local Project - 個人プロジェクト設定
  4. Project - チーム共有設定
  5. User (最低) - 個人のデフォルト設定

10. セキュリティと権限管理

10.1 3層権限システム

ツールの種類 例 承認の要否
読み取り専用 ファイル読み取り、Grep、Glob 不要
Bashコマンド シェルコマンド実行 必要
ファイル修正 ファイル書き込み、編集 必要

10.2 権限ルールの設定

{
  "permissions": {
    "allow": [
      "Bash(npm run build)",
      "Bash(npm run test:*)",
      "Read(./src/**)"
    ],
    "deny": [
      "Bash(curl:*)",
      "Bash(rm -rf:*)",
      "Read(./.env)",
      "Read(./.env.*)",
      "Read(./secrets/**)"
    ]
  }
}

10.3 権限モード

  • default: 各ツール使用時に権限を要求
  • acceptEdits: ファイル編集を自動承認
  • plan: 解析のみ可能 (修正不可)
  • bypassPermissions: すべての権限を自動承認 (要注意！)
# 権限モードの変更
claude --permission-mode plan
claude --permission-mode acceptEdits

10.4 セキュリティのベストプラクティス

  • 機密ファイル(.env、credentials.json など)は必ずdenyリストに追加
  • 読み取り専用のSkillsには allowed-tools: Read, Grep, Glob で制限
  • 定期的に /permissions で権限をレビュー
  • プロダクション環境ではサンドボックスモードを有効化

14. 結論とおすすめ

Claude Codeは、開発者の生産性を革新的に向上させるAIコーディングアシスタントです。ターミナルネイティブ環境で自律的に作業を実行し、MCPを通じてさまざまな外部サービスと統合できます。

活用の中核となるコツ

Claude Codeで、より高速かつ効率的な開発体験を始めましょう！
