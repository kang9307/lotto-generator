查看计算公式与依据

本工具完全按照以下公式计算。

输入费用 = 输入 token × 每月请求次数 ÷ 1,000,000 × 输入单价 × 缓存系数 输出费用 = 输出 token × 每月请求次数 ÷ 1,000,000 × 输出单价 月度费用 = 输入费用 + 输出费用 缓存系数 = 1 − 0.9 × 缓存命中率
  • 单价单位：所有单价均为每 100 万（1M）token 的美元金额。
  • 缓存系数：Anthropic、OpenAI 与 Google 均按普通输入单价的约 10% 计费缓存输入。命中率为 h 时，输入费用变为 (1−h) + 0.1h = 1 − 0.9h 倍。
  • 输出费用：输出 token 不适用缓存，因此无论命中率多少都按全价计费。
  • Claude Sonnet 5：按标准单价 $3 / $15 显示。2026-08-31 之前可能另有 $2 / $10 的推广单价。
  • 未包含项：批处理 API 的 50% 折扣、超过 200K 的长上下文加价、缓存写入溢价，以及图像与音频等多模态 token。
  • 货币：仅提供 USD 口径。汇率每日变动，换算成本币的金额很快就会失真，因此刻意不予提供。

价格数据已与各厂商官方价目表以及 2026 年 7 月的价格汇总资料交叉核对。
