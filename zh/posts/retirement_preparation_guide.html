为何要现在开始准备退休

韩国是全球老龄化速度最快的国家之一。65岁以上人口占比已超过20%，进入超老龄社会，平均预期寿命也已超过83岁。要在退休后安稳度过20至30年，需要系统的财务规划。

问题在于，仅靠国民年金很难覆盖全部养老生活费。韩国国民年金公团国民年金研究院于2025年12月31日发布的国民养老保障面板调查（2024年第10次附加调查）显示，50岁以上受访者认为夫妻的适当养老生活费为每月298.1万韩元。而国民年金43%的收入替代率是以参保40年为前提的数值。本文梳理韩国养老安全网的结构，帮助读者按自身情况开始准备。本文于2026年6月首次撰写，2026年9月29日与政府及公共机构的说明重新核对并修正了数值，变动内容汇总在下方的更新记录中。

韩国退休收入三层结构

韩国的养老收入体系通常被描述为“三层养老金结构”。各层作用不同，三层一起积累才能形成稳定的养老收入。此外，面向收入和资产较少的65岁以上老人发放的基础年金构成了最底层的保障。

第一层：国民年金（公共年金） — 国家运营的基本收入保障
第二层：退休年金（DB/DC/IRP） — 雇主与员工共同积累的职业年金
第三层：个人年金（年金储蓄·年金保险） — 自己额外积累的自愿储蓄
底层：基础年金 — 向收入认定额不超过选定标准额的65岁以上老人发放

第一层 — 国民年金

韩国国民年金是居住在韩国、18岁以上未满60岁的国民原则上须参加的公共年金。2025年3月20日国会通过的国民年金法修正案自2026年1月1日起施行：2025年以前为9%的缴费率在2026年变为9.5%，此后每年提高0.5个百分点，2033年起适用13%。以参保40年为基准的收入替代率自2026年起定为43%，国家保障支付年金的条款也写入了法律。作为缴费计算基础的标准月收入额，2026年7月至2027年6月的上限为659万韩元、下限为41万韩元（国民年金公团说明，2026-09-29确认）。详情见韩国国民年金指南。

领取老龄年金需参保满10年（120个月），开始领取年龄按出生年份而定：1961至1964年出生者为63岁，1965至1968年出生者为64岁，1969年以后出生者为65岁。保健福祉部自2026年1月起按上一年消费者物价涨幅2.1%上调了国民年金给付（2026-01-09新闻稿）。初稿所写的平均领取额（整体每月约70万韩元，参保20年以上者每月约112万韩元）在本次更新中未能与公团公布的统计重新核对（2026年6月数据，未确认更新）。个人的预计领取额最好通过国民年金公团的“我的年金查询”确认。

要点：假设夫妻二人各领取每月112万韩元，合计为224万韩元。与国民养老保障面板调查中夫妻适当养老生活费298.1万韩元相比，每月缺口为74.1万韩元。这个缺口需要由第二层和第三层来填补。

支撑第一层的底层 — 基础年金

基础年金发放给收入认定额不超过选定标准额的65岁以上老人。据保健福祉部介绍，2026年选定标准额为单人家庭每月247万韩元、夫妻家庭每月395.2万韩元（2026-01-02新闻稿）。基准年金额按上一年物价涨幅2.1%，由2025年的34.251万韩元上调至2026年的34.97万韩元（2026-01-09新闻稿）；按韩国政策简报的说明，夫妻二人同时领取时合计最多为55.952万韩元。收入认定额是把收入与折算为收入的财产合计后的金额，实际基础年金额还会结合基准年金额和国民年金给付额等确定，并非人人都能领到最高额。是否符合条件可通过福利门户“福祉路”的模拟计算或居民中心确认。

第二层 — 退休年金（DB、DC、IRP）

退休年金是把员工退休后将领取的退休给付预先存放在公司以外金融机构的制度。按运用主体和给付确定方式分为三种。

类型运用主体收益特点
DB型（确定给付）雇主确定（以工资为准）适合长期在职、工资持续上涨者
DC型（确定缴费）员工随运用结果变动适合经常跳槽、积极投资者
IRP（个人型）员工随运用结果变动可接收退休金、追加缴费、享受税额抵免

IRP（个人型退休年金）是用于接收退休金或在职期间追加缴费的账户。与年金储蓄合计每年最多可缴1,800万韩元，其中可享受税额抵免的部分与年金储蓄合计最多900万韩元。55岁以后申请年金领取且开户满5年后按年金方式领取时，将预扣年金所得税（按领取时年龄为5%、4%、3%，含地方所得税为5.5%、4.4%、3.3%）。已享受税额抵免的资金若以非年金方式取出，将征收15%的其他所得税（含地方所得税16.5%）。转入账户的退休金（递延退休所得）按年金领取时，只需缴纳原退休所得税的70%（按领取年次为60%、50%）（韩国国税厅说明，2026-09-29确认）。

据韩国雇用劳动部介绍，自2022年4月14日起，退休给付原则上支付到员工本人名下的IRP账户。55岁以后退休、退休给付不超过公告金额（300万韩元）等情况除外。此外，自2022年7月12日起，DC型和IRP引入了事前指定运用制度（默认选项）：员工未选定积累金的运用产品时，资金将按事先确定的方式自动运用，DB型不在适用范围内（雇用劳动部2022-07-05新闻稿）。建议向开户金融机构确认自己账户指定的是哪种事前指定运用方式。

第三层 — 个人年金（年金储蓄·年金保险）

个人年金是在国民年金和退休年金之外自行积累的重要补充，主要分为年金储蓄（基金、保险、信托）和个人年金保险。

据韩国国税厅说明，年金储蓄每年最多600万韩元、与IRP合计每年最多900万韩元可享受税额抵免。总工资5,500万韩元（综合所得金额4,500万韩元）以下者抵免率为15%，超过者为12%。常见的16.5%、13.2%是在此基础上加上地方所得税（所得税的10%）后的数值。具体规则见年金储蓄·IRP节税指南。

年总工资税额抵免率最高抵免额（缴满900万韩元）
5,500万韩元以下15%（含地方所得税16.5%）135万韩元（含地方所得税148.5万韩元）
超过5,500万韩元12%（含地方所得税13.2%）108万韩元（含地方所得税118.8万韩元）

年金储蓄的核心优势是税额抵免＋递延纳税：缴费时获得抵免、运用收益递延纳税、领取时适用较低的年金所得税，三重效果兼得。但若以非年金方式中途取出或解约，已享受抵免的缴费额和运用收益将一律按15%的其他所得税分离课税，因此以长期持有为前提。韩国存款保险公社说明，退休年金和年金储蓄即使在同一金融机构内，也与普通存款分开、各自最多保护1亿韩元（参见存款利率比较指南，2026-09-29确认）。账户中的哪些产品属于保护对象，需要向开户金融机构确认。

测算所需退休资金

估算退休后所需的总资金是养老准备的起点。可以先参考权威调查给出的生活费水平。下表为国民年金研究院国民养老保障面板调查（2024年第10次附加调查，对象为50岁以上家庭成员）中受访者认为的每月养老生活费。

类别最低养老生活费适当养老生活费
个人每月139.2万韩元每月197.6万韩元
夫妻每月216.6万韩元每月298.1万韩元

来源：国民年金公团新闻稿（2025-12-31）。这是汇总受访者主观认识的数值，实际所需金额会因生活水平、居住地和健康状况而有很大差异。套用下面的公式，可以定出大致目标。

所需退休资金 =（每月生活费 — 年金领取额）× 12 × 退休后预计年数

示例：夫妻每月生活费300万韩元，国民年金合计220万韩元，假设退休后生活25年
→（300万 — 220万）× 12 × 25 = 至少需要2.4亿韩元（不含物价上涨和医疗费）

使用国民年金公团网站的“我的年金查询”服务，可按参保期间查询预计领取额。韩国金融监督院的综合年金门户也能一次查看个人年金、退休年金的参加情况和预计领取额。

考虑物价上涨

简单计算中容易漏掉的是物价上涨。假设年通胀2%，20年后的100万韩元购买力只相当于现在的约67万韩元。国民年金和基础年金每年按上一年消费者物价涨幅调整，但个人储蓄和投资收益若跑不赢通胀，实际价值就会缩水。长期养老资金规划应以实际收益率 = 名义收益率 — 通胀率为基准。

退休后医疗费准备

养老准备中出人意料地容易被忽视的是医疗费。一生医疗费的相当部分集中在65岁以后。虽有健康保险，但医保外费用、自付部分、长期护理和看护费用都需要另外准备。

转为健康保险地区参保人

从公司退休后，可能会转为健康保险的地区参保人。地区参保人的保费不仅按收入，还按财产等计算，退休后的保费反而可能高于在职时。建议提前测算，并向韩国国民健康保险公团确认能否登记为被抚养人。

实损保险·看护保险

实损医疗保险是补偿医保外自付费用的核心保险。年纪越大越难投保、保费也越高，因此原则是趁年轻投保并长期保持。为应对痴呆、中风等需要长期看护的情况，也可以考虑长期护理保险或看护保险。但任何保险都应仔细比较保障内容、免责期和续保条件，并在咨询专业人士后再投保。

住房规划 — 房子是资产还是成本

在韩国，住房是退休财务规划中最大的变量之一。有自住房可以节省居住成本，但资产集中在房地产上时流动性较低。可考虑的选项如下。

  • 住房年金：房主以住房作担保、继续居住的同时终身按月领取年金、由国家担保的制度，由韩国住房金融公社运营。参加条件为夫妻中1人年满55岁，且夫妻合计拥有公示价格12亿韩元以下的住房；拥有多套住房者，只要合计价格不超过12亿韩元也可参加。参保住房须由参保人或配偶实际居住（完成住民登记迁入）（韩国住房金融公社说明，2026-09-29确认）。
  • 缩小住房：出售较大住房、换住小户型，把差价用作养老资金。管理负担也会减轻，但需要考虑地区和生活配套的变化。
  • 公共租赁住房：考虑长期公共租赁（国民租赁、幸福住宅等），可降低居住成本，把更多资金投向其他资产。

各年龄段退休财务规划路线图

不同年龄段应侧重的养老策略不同。以下为一般性指引，需要按个人情况调整。

20至30岁 — 养成习惯

  • 出现无收入期间时，确认能否通过国民年金自愿参保或补缴（追后缴纳）让参保期间保持连续
  • 开设年金储蓄（基金）账户，哪怕每月小额也要开始 — 最大化复利时间
  • 开设IRP账户，在税额抵免限额内缴费
  • 尽早投保实损保险并保持

40岁 — 加速积累

  • 考虑用满年金储蓄＋IRP合计每年900万韩元的税额抵免额度
  • 检查退休年金的投资组合以及默认选项（事前指定运用方式）的指定内容
  • 查询国民年金预计领取额，并确认可以补缴的期间
  • 重新计算所需养老资金目标

50岁 — 过渡准备

  • 资产配置趋于保守 — 逐步降低股票比重，提高债券和稳健资产比重
  • 比较国民年金提前与延后领取的方案（延后每月加算0.6%，最长5年）
  • 测算转为地区参保后的健康保险保费
  • 提前查询住房年金预计领取额（夫妻中1人年满55岁即可参加）
  • 明确退休时间和生活方式

60岁以后 — 领取最优化

  • 确定国民年金开始领取时间（考虑健康和预期寿命）
  • 设置年金储蓄·IRP的年金领取（需满55岁且开户满5年；递延退休所得领取年次越长，税负由70%降至60%、50%）
  • 私人年金所得每年超过1,500万韩元时，确认选择综合课税还是15%分离课税
  • 65岁以后比较基础年金选定标准额（2026年单人每月247万韩元）与本人收入认定额，并考虑参加住房年金

节税策略 — 善用养老金账户

用好养老金账户，可以在缴费到领取的各个阶段大幅减税。以下数值依据2026年9月29日确认的韩国国税厅说明。

  • 用好税额抵免额度：年金储蓄600万韩元＋IRP 300万韩元＝合计缴费900万韩元，最多可抵免135万韩元（含地方所得税148.5万韩元）（总工资5,500万韩元以下；要拿满需有相应的应纳税额）
  • 递延纳税效果：运用收益在领取前不纳税，复利效果更大
  • 年金领取税率较低：按年金领取只需按年龄缴纳5%、4%、3%的年金所得税；以非年金方式取出则征收15%的其他所得税
  • 分离课税标准：扣除递延退休所得等后的私人年金所得每年不超过1,500万韩元时可选择分离课税，超过时在综合课税与15%分离课税之间选择
  • 与账户外利息比较：普通存款利息预扣15.4%（含地方所得税），利息、股息等金融所得每年超过2,000万韩元时适用金融所得综合课税（参见存款指南）

常见失误与注意事项

  • 国民年金缴费中断：跳槽、育儿假、转为自由职业等造成的停缴期间累积起来，会减少领取额。请向国民年金公团（韩国境内1355）确认，无收入期间能否自愿参保、未缴期间能否补缴。60岁以后可通过自愿继续参保把期间延长到65岁。
  • 马上花掉退休金：自2022年4月14日起，退休给付原则上支付到IRP账户。若立即一次性取出，需全额缴纳退休所得税，也错过按年金领取时的减免（只按退休所得税的70%课税）。更重要的是养老资金就此消失。
  • 提前解约年金储蓄：以非年金方式取出或解约时，已享受抵免的缴费额和运用收益一律按15%的其他所得税（含地方所得税16.5%）分离课税。中途解约前务必算清得失。
  • 集中于单一资产：养老资金集中在房地产或个别股票上，容易遭遇流动性危机。应坚持分散投资原则。
  • 忽视通胀：不考虑物价上涨，实际购买力下降会让计划落空。

总结 — 今天就能做的3件事

养老准备中，今天迈出的第一步比完美的计划更重要。读完本文后，建议今天就做以下3件事。

  1. 在国民年金公团查询预计领取额：确认自己的缴费记录和预计领取额，就能明确第二层、第三层需要准备多少。
  2. 检查年金储蓄或IRP账户：还没有的话可考虑开户；已有的话确认税额抵免额度和默认选项的指定内容。由于中途解约代价较大，只放入到退休前都不会动用的钱。
  3. 预约CFP或金融机构咨询：符合个人收入、资产和家庭情况的定制规划需要专业咨询。可通过韩国金融监督院客服中心（1332）查询获许可的机构。

## 3. 分层检查

### 第一层 国民年金·基础年金
- [ ] 是否已通过国民年金公团“我的年金查询”查到预计领取额
- [ ] 是否确认了自己的开始领取年龄（1961至1964年出生63岁，1965至1968年出生64岁，1969年以后出生65岁）
- [ ] 是否确认无收入期间能否自愿参保、未缴期间能否补缴
- [ ] 是否比较了提前与延后领取（延后每月加算0.6%，最长5年）
- [ ] 65岁以后是否把收入认定额与基础年金选定标准额作了比较（福祉路模拟计算）

### 第二层 退休年金
- [ ] 是否清楚自己的制度是DB、DC还是IRP
- [ ] 是否确认了DC·IRP账户指定的默认选项（事前指定运用方式）
- [ ] 是否知道退休给付原则上支付到IRP（2022-04-14起；55岁以后退休、300万韩元以下等除外）
- [ ] 是否知道转入IRP的退休金按年金领取时只按退休所得税的70%（按年次60%、50%）缴纳

### 第三层 个人年金
- [ ] 是否确认了自己的总工资是否在5,500万韩元以下
- [ ] 缴费额是否在抵免对象限额（合计900万韩元）以内，应纳税额是否足以用满抵免
- [ ] 是否只放入到退休前都不会动用的钱（非年金方式领取须缴15%其他所得税）

## 4. 领取阶段决策表

| 情况 | 需要确认的事项 |
|---|---|
| 私人年金所得每年不超过1,500万韩元 | 可选择分离课税 |
| 私人年金所得每年超过1,500万韩元 | 在综合课税与15%分离课税之间选择 |
| 开始领取年金储蓄·IRP | 55岁以后申请 + 开户满5年 |
| 有房但现金流不足 | 确认住房年金条件（55岁、公示价格12亿韩元、实际居住） |
| 养老金账户外的利息·股息每年超过2,000万韩元 | 确认是否适用金融所得综合课税 |
