SSH / DevOps Tool

SSH config 生成器

~/.ssh/config をビジュアルに作成しましょう。
複数ホスト・ProxyJump・ポートフォワーディングまでこれ一つで。

🎯
プリセットシナリオ

よく使う構成をワンクリックで追加します(既存ホストは保持)。

☁️ AWS EC2

User=ec2-user、.pemキー、ServerAlive

🌊 DigitalOcean

User=root、ed25519キー

🛡️ 踏み台 + 内部サーバー

Bastion → 内部 (ProxyJump)

🔌 開発機 + ポート転送

LocalForward 8080:localhost:80

⚙️
グローバルオプション (Host *)
🖥️
ホスト (0)

サーバーごとに1件追加します。Host エイリアスは ssh myserver のように使います。

📄
~/.ssh/config プレビュー 
# 上でホストを追加するとここに表示されます。
次のステップ: ダウンロードしたファイルを ~/.ssh/config として保存し、パーミッションを設定します。
chmod 600 ~/.ssh/config  ·  chmod 700 ~/.ssh
