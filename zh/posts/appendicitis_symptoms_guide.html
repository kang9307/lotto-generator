阑尾炎（盲肠炎）的早期症状与应对 - 什么时候必须去急诊

不要自己判断，记住那些不能错过的信号

2026-07-31 生活/健康

引言：是该忍的肚子疼，还是该去的肚子疼

晚饭之后肚子就一直沉甸甸的。胸骨下方发堵，也没胃口，想着大概是积食，就躺下了。半夜又醒过来，这次疼的地方和刚才不一样。变成右下方一阵阵地刺痛，翻身或者咳嗽的时候更明显。这个点是要去急诊，还是忍到早上去附近的诊所就行？

这篇文章写给站在这个岔路口的人。而它的论点不是「来看看是不是阑尾炎」，而是「别自己下判断」。看起来顺序颠倒，理由却很清楚。韩国疾病管理厅国家健康信息门户的急性阑尾炎文档写明，症状不典型的患者占全部患者的三分之一。美国国立医学图书馆的MedlinePlus也指出，并非每位患者都会出现全部这些症状。英国NHS的Appendicitis页面上有一句更直接的话：没有一项检查能永远显示出是否为阑尾炎。连配备检查设备的医院都不会靠单一结果下定论的病，在家按一按肚子当然分辨不出来。

于是这篇文章的目的收窄为一件事：不要错过该去医院的时机。下面的内容都是围绕这个目的排列的。

  • 最前面放不能拖延的信号。哪怕其他都不看，也希望这份清单留下来
  • 接着用资料说明为什么这种病尤其不适合自行判断。典型的顺序，以及常见的不按顺序发展的情况，一并交代
  • 最后整理让就诊更高效的准备。从什么时候开始疼、疼的位置怎么转移，这些正是诊断真正会用到的信息

免责声明。本文仅以提供信息为目的，不能替代医学诊断或治疗。正文中的任何内容都不应作为自我诊断或自我治疗的依据。出现症状时原则上应当接受医务人员的诊疗，是否服药以及治疗方案由医务人员在查体和检查之后决定。韩国的急救报警与咨询电话是119，若在其他国家请使用当地的急救电话。

1. 出现这些情况不要拖延，立刻去急诊

先把清单放出来。以下每一条都是所查阅的公开医疗资料明确指引采取紧急处理的项目，没有笔者自行添加的内容。只要有一条符合，更好的做法是停止自己去缩小病因范围。

  • 腹痛剧烈。NHS把剧烈腹痛列为需要立即急救处理的情况
  • 疼痛随时间加重，或者一直不见好。NHS对这种情况指引紧急就诊
  • 从肚脐周围开始的疼痛转移到了右下腹。位置发生转移本身就被当作一个信号
  • 按压腹部后松手时更痛。国家健康信息门户称之为反跳痛，并把它记为阑尾炎进展时出现的体征
  • 走路、咳嗽、打喷嚏或深呼吸时疼痛加剧。这是美国NIDDK列出的特征
  • 有发热。包括低热逐渐上升的过程
  • 呕吐持续，什么都咽不下去
  • 疼痛越过右下腹扩散到整个腹部。或者一度减轻后又变得剧烈得多

最后一条值得单独强调。NHS说明，阑尾破裂之后疼痛可能短暂缓解，随后变成扩散至整个腹部的剧痛。也就是说，突然不疼了并不能作为放心的理由，反而要留意紧随其后的变化。

1.1 必须立即拨打急救电话的三种情况

NHS把下面三条列为脓毒症的征象，并指引这种情况不要去找预约，而要立即拨打急救电话。

  • 意识模糊。包括言语不清或认不出人的情况
  • 皮肤出现花斑，或比平时苍白
  • 呼吸困难
看到的情况资料指引的应对依据资料
剧烈腹痛立即急救处理NHS Appendicitis
意识下降、皮肤花斑或苍白、呼吸困难立即急救处理（脓毒症征象）NHS Appendicitis
疼痛逐渐加重或不消退紧急就诊NHS Appendicitis
疼痛转移到右下腹紧急就诊NHS Appendicitis
怀疑阑尾炎的各种情形立即就诊或前往急诊NIH NIDDK
疼痛扩散到整个腹部、高热、心跳加快被记述为穿孔时的表现韩国国家健康信息门户

联系方式。韩国的急救报警与咨询电话只有119一个。过去使用的急救医疗信息中心号码已经并入119，现在不再使用。119不仅受理报警和派车，还负责急救咨询与转运医院指引。想提前查好附近的急诊，可以在中央急救医疗中心运营的急救医疗门户上确认。若在韩国以外，请使用当地的急救电话。韩国的号码在境外无法接通。

2. 阑尾是什么，为什么会发炎

民间常说盲肠穿了，但国家健康信息门户写明，这个俗称在医学上并不准确。真正发炎的并不是盲肠本身，而是连在盲肠上的一根细管，也就是阑尾。

MedlinePlus把阑尾描述为连在大肠起始部的一个小的管状器官，位置在腹部右下方，并写明它没有已知的功能。右下腹之所以被反复提及，原因就在这里。

炎症的起点是梗阻。MedlinePlus说明，阑尾内部的梗阻会引起阑尾炎，而梗阻会导致压力升高、血流障碍和炎症。至于是什么堵住的，各份资料的表述略有不同。

  • 国家健康信息门户写明阑尾周围淋巴组织过度增生最为常见（60个百分点）
  • 同一份资料把干硬粪便堵住阑尾开口的情况列为35个百分点
  • 此外还列举了异物、炎症性狭窄、寄生虫、肿瘤等原因
  • NIDDK提到的梗阻原因是干硬粪便或增生物，以及感染导致阑尾壁组织增大
  • 上述比例出自国家健康信息门户的文档，而该文档并未另行标明调查年份或对象人群

了解了结构，也就自然明白时间为什么是关键。在一根堵住的管子里压力持续升高、血流变差，管壁能撑住的时间是有限的。后面关于穿孔和腹膜炎的内容，正是从这里接下去的。

3. 症状的典型顺序 - 以及不典型的那三分之一

先看典型的情况。国家健康信息门户描述的经过是这样的。起初食欲下降、出现恶心，随后上腹部疼痛。这个疼痛经由肚脐周围转变为右下腹疼痛。接着右下腹压痛变得明显，出现反跳痛，并逐渐出现低热，有时伴有寒意。

NHS的说明在大框架上一致。它写道疼痛始于腹部中间、肚脐周围，并在数小时后转移到右下方。NIDDK对疼痛的性质说得更具体：可能从肚脐附近开始并向下向右移动，可能突然开始，在活动、深呼吸、咳嗽或打喷嚏时加剧，并且可能先于其他症状出现，在数小时内加重。

阶段常被描述的表现此时要注意的地方
早期食欲下降、恶心、胸骨下或肚脐周围模糊的疼痛最容易被当成积食带过去的阶段
数小时后疼痛经肚脐周围转移到右下腹位置转移本身就被当作信号
进展右下腹压痛、松手时疼痛、低热与寒意同时观察活动、咳嗽、深呼吸是否加重
伴随恶心、呕吐、便秘或腹泻、排气困难、腹部胀满有肠道症状并不代表不是阑尾炎
穿孔时疼痛扩散到整个下腹或整个腹部、高热、心跳加快也可能先短暂缓解再度加重

3.1 然而不按这个顺序发展的情况并不少见

这是全文最重要的一段。上面的顺序是参考用的地图，而不是判定标准。资料把例外的规模写得很清楚。

  • 国家健康信息门户写明症状不典型的患者占全部患者的三分之一
  • 儿童被描述为早期总想睡、对刺激敏感、食欲下降，随后迅速进展出现呕吐、发热和疼痛
  • 老年人常常不出现典型症状，病程快，并发症也更容易发生。NHS补充说老年人可能出现突然的意识混乱
  • 妊娠期随着胎儿长大，阑尾被向上推移，到妊娠末期会位于右上腹。这意味着疼痛的位置本身发生了改变
  • NHS同样写明，孕妇、幼儿和老年人的疼痛可能更轻、出现更慢，或者在别的位置被感觉到

归纳起来是这样。按典型顺序发展时容易识别，但反过来并不成立。没有按顺序发展并不能作为不是阑尾炎的依据。而这些例外偏偏集中在难以用言语描述症状的儿童、信号模糊的老年人、疼痛位置发生转移的孕妇身上。自行判断之所以危险，原因就在这里。

4. 容易混淆的情况 - 正因如此才需要就诊

先把这一节的目的说清楚。下面的表格不是让人自己去分辨。恰恰相反。它要展示重叠项有多少，从而导向这个结论：分辨这件事是查体和检查的工作。

NIDDK列出的可能与阑尾炎混淆的情况包括腹腔粘连、炎症性肠病、肠梗阻、盆腔炎和泌尿系结石。医院做尿检的目的也正是排除膀胱感染或结石等其他原因，对女性还可能加做妊娠试验。

重叠的情况哪里相似为什么自己分不出来
肠胃炎腹痛、恶心、呕吐、腹泻、低热同时出现阑尾炎也可能伴有呕吐和腹泻
便秘腹部沉重，感觉排便后会舒服些NIDDK把这种感觉也列为阑尾炎的症状之一
泌尿系结石侧腹与下腹的剧烈疼痛属于需要通过尿检等排除的对象
妇科疾病下腹这个位置重叠盆腔炎在鉴别名单中，并会同时使用妊娠试验
肠梗阻腹痛、呕吐、排气困难它在鉴别名单中，且需要另一套急救判断标准

看完表格就明白「这不过是肠胃炎」这种判断为什么危险。不是因为有重叠的症状，而是因为几乎没有不重叠的症状。恶心呕吐、腹泻便秘，连低热都可能出现在两边。剩下的差别只有疼痛的位置、性质以及随时间的变化，而这些恰恰是要有人亲手按压腹部并结合检查结果一起读，才会产生意义的信息。

5. 医院里到底做什么

去了之后感觉没做什么，时间却拖得很长，这就是急诊。知道原因再去，心里会踏实一些。NIDDK介绍的诊断路径由问诊、体格检查、实验室检查、影像检查四层构成，而它们是以相互补充的方式使用的。

步骤做什么为什么做
问诊疼痛何时开始、有多严重、确切在哪里，以及基础病和既往手术随时间的变化构成判断的骨架
体格检查确认右下腹疼痛，轻轻按压或晃动腹部各处，抬腿时按压右膝查看炎症所在位置以及有无腹膜刺激
血液检查确认白细胞计数NIDDK把白细胞升高记为感染的信号
尿检与妊娠试验排除其他原因为了甄别膀胱感染、泌尿系结石等
影像检查超声、MRI、CT超声不使用射线，是婴幼儿、儿童、青年和孕妇的首选影像检查

国家健康信息门户写明，体格检查中麦氏点有无压痛很重要。它位于肚脐与骨盆前方突出骨点连线的外侧三分之一处。不过这同样是由检查者用手确认的体征，而不是让人自己按下去下判断的项目。

影像检查的选择也有顺序。NIDDK把MRI介绍为CT的安全可靠替代方案，并写明在儿童中为减少射线暴露，只有在超声和MRI之后才推荐CT。「为什么不直接给我做CT」这个疑问的答案就在这里。

  • 检查之所以分成好几层，道理很简单：单独一层无法定论
  • NHS明确写道没有一项检查能永远显示出是否为阑尾炎
  • 所以仅凭血液数值正常这一点，推不出可以放心的结论
  • 反过来仅凭数值偏高这一点，也不能确诊阑尾炎
  • 在医院里等待的时间，多半是这些层次正在被一层层叠起来

5.1 关于打分的工具

临床上也会使用把问诊、查体和检查所见逐项打分以估计风险的工具。不过本文不列出这类工具的条目，理由有三个。

  • 这些工具的设计前提是由亲手按压过腹部的医务人员来使用。压痛和反跳痛这类条目，一旦由自己来打分，含义就变了
  • 分数是参考而非判定。因为分数低就推迟就诊，与本文的目的正好相反
  • 所查阅的公开资料把诊断说明为问诊、查体、检查与影像的综合，没有一份指引患者自己去打分

6. 治疗的选择 - 手术与抗生素

治疗这一段不给出哪一种更好的推荐。这是要与看过查体和检查结果的医务人员商量决定的事，不属于本文能给出答案的范围。

  • 国家健康信息门户写明急性阑尾炎的治疗以手术为原则
  • MedlinePlus写道治疗几乎总是包括切除阑尾
  • NIDDK写明部分轻症病例可以仅用抗生素治疗
  • NHS写道在感染尚未扩散且手术风险高的情况下可以考虑抗生素，并提到阑尾周围形成包块时采取先用抗生素、之后再手术的方式

手术方式也不止一种。NIDDK并列说明了通过小切口置入器械的腹腔镜方式和在右下腹做一个较大切口的开腹方式。国家健康信息门户也写道，为了少留瘢痕并加快恢复，有些情况会采用腹腔镜手术。对于已经穿孔并形成腹膜炎的情况，NIDDK写明会立即实施清洗腹腔内部的手术，而形成脓肿时则采取把脓引流出来使其愈合的方式。

决定因素分成这么多条，所以患者一方要准备的不是结论，而是问题。以下是商量时值得询问的条目。

  • 我现在的状态看起来处于哪个阶段，有没有穿孔或脓肿的迹象
  • 选择您建议的方式的理由是什么
  • 是否有不考虑其他选项的原因
  • 各种方式在恢复时间和回到日常生活的时点上有什么不同
  • 如果现在推迟决定会有什么变化，可以等多久

7. 拖延会带来什么不同

这一节不是为了吓唬谁，而是照资料原样说明时间为什么是变量。

MedlinePlus的说明最为简洁：梗阻若不处理，阑尾可能破裂并使感染扩散到腹腔，这就是被称为腹膜炎的状态。NHS把腹膜炎说明为腹腔内层膜的感染，并补充说破裂的阑尾可能造成积脓形成脓肿。国家健康信息门户写明，穿孔时疼痛不再局限于右下腹，而是扩散到整个下腹或整个腹部，并出现高热和心跳加快。

  • 国家健康信息门户写道非穿孔性阑尾炎中5个百分点会出现并发症，而存在组织坏死或穿孔时并发症发生率可达30个百分点
  • 同一份资料把手术部位的皮肤感染率记为：单纯性阑尾炎4至8个百分点，穿孔性10至20个百分点
  • 总体穿孔率被记为约25个百分点，而10岁以下为35至60个百分点，50岁以上为60至75个百分点，明显更高
  • 同一份文档写道从症状开始起3日内若不接受手术，阑尾就会破裂。这是原样转述该资料的表述，不应当作预测个人病程的数值来使用
  • 以上数值全部出自国家健康信息门户的文档，而该文档并未另行标明调查年份或对象人群

不过为了平衡，也把同一份资料的另一句话一起抄过来。上面写着多数患者在症状出现后12至18小时内前往医疗机构。也就是说，这是一种人们大体上能及时就医的病。真正成为问题的是没能进入这个多数的情况，而正如上一节所见，这些情况集中在症状不典型的那三分之一，以及儿童、老年人和孕妇身上。穿孔率被记为格外高的年龄段正是10岁以下与50岁以上，这也是同一件事的另一个角度。

这一节该怎么读。上面的数字不是此刻你的概率。它们是资料中群体层面的描述，而且带着未标明调查年份与对象这一局限。要从这里带走的不是数字本身，而是方向：时间越久，可选项越少，而且对儿童和老年人来说时间走得更快。

8. 恢复，以及需要再次就医的信号

做完手术之后，接下来关心的是什么时候能恢复原样。资料的记述整体上是乐观的。

  • NIDDK写明术后通常可以从阑尾炎完全康复，无需改变饮食、运动或生活方式
  • 同一份资料给出的活动限制期为腹腔镜手术后3至5天，开腹手术后10至14天
  • NHS写道多数人在1至2周内恢复，阑尾破裂的情况则需要更久
  • 恢复时间因手术方式与是否穿孔而不同，所以出院时拿到的说明优先于本文

关于需要再次就医的信号，这里写得谨慎一些，因为资料明确列出的项目与应当交给出院说明的部分并不相同。

  • NHS把切除阑尾的部位形成脓肿列为术后并发症。这是积脓的状态，不是可以放着不管的事
  • 发热再次上升或腹痛再次加重这类变化，应当视为偏离恢复过程的信号
  • 无论是否做过手术，只要第1节的急救信号再次出现，就照原样套用同一套标准
  • 若是仅用抗生素治疗的情况，最好事先问清症状再次出现时该怎么办
  • 什么算正常经过、什么不算，这条界线因手术方式和个人状态而异，所以原则上遵循出院时拿到的标准

9. 就诊前值得整理好的东西

正如第5节所见，诊断的第一层是问诊。NIDDK列出的问题是腹痛何时开始、有多严重、确切在哪里，以及有哪些其他疾病和手术史。可是肚子疼得心神不宁地赶到急诊时，偏偏就是这些基本内容想不起来。事先写下来，就诊就会快很多。

项目记录什么填写示例
起病时间第一次感到不适的日期与时刻昨晚8点左右
最初部位与当前部位一开始疼的位置，以及现在最疼的位置从胸骨下开始，现在是右下腹
转移时刻如果位置移动了，是什么时候今天凌晨3点左右
强度变化随时间变强还是变弱一直变强，曾缓解一次后更痛
加重因素做什么时更痛走路时、咳嗽时
伴随症状发热、寒战、恶心、呕吐、腹泻、便秘、排尿改变低热，呕吐2次
最后一餐吃了什么，什么时候吃的昨晚7点吃饭，之后只喝水
已服药物名称与时间。止痛药、退热药、抗酸药、助消化药全部今天凌晨1点止痛药1片
基础疾病、手术史、过敏史正在治疗的疾病、做过的手术、药物过敏无，或写病名与药名

这张表里尤其要留心的一栏是已服药物。本文不提供吃药或不吃药的指示，是否服药是要与医务人员商量的问题。但如果已经吃了，把这件事如实说出来确实很重要。诊断依赖疼痛的强度、位置以及随时间的变化，而医务人员只有知道这些信息是否受到药物影响，才能正确解读。

  • 记在手机里就够了。疼得厉害时记忆会变模糊
  • 如果有人陪同，为本人说不出话的情况做准备，把同样的内容共享一份
  • 如果是幼儿，就把从什么时候开始不吃东西、和平时有什么不一样连同时刻一起记下
  • 若有妊娠可能，知道末次月经的开始日会让检查的判断更快
  • 如果已经在其他医院做过检查，也把那些结果和时间一并告知

10. 小结 - 这篇文章想留下的一句话

关于阑尾炎，被搜索得最多的问题是「这是不是盲肠炎」。可是顺着资料看下来，反而更清楚为什么这个问题在家里难以回答。连配备检查设备的医院都不靠单一检查下定论，不按典型顺序发展的患者达到三分之一，而例外集中的对象偏偏是儿童、老年人和孕妇。

  • 需要知道的是病名之外的东西，也就是该去医院的时机
  • 只要第1节的信号出现一条，就停止自己去缩小范围
  • 疼痛突然减轻不是放心的理由
  • 让就诊提前的最实用准备是写下从什么时候起、哪里疼、怎么变化的

再次声明。本文以提供信息为目的写成，不能替代医学诊断或治疗。关于具体症状的判断，以及关于药物或手术的决定，必须与医务人员商量。若判断为紧急情况，在韩国请使用119或就近的急诊，在境外请使用当地的急救电话。

# 阑尾炎 — 判断是否去急诊的备忘与就诊准备表

来源：braindetox.kr — 阑尾炎的早期症状与应对
依据：韩国疾病管理厅 国家健康信息门户「急性阑尾炎」 · NHS Appendicitis · MedlinePlus Appendicitis · NIH NIDDK Appendicitis（均于2026-07-31确认）

注意：本文档仅供信息参考，不能替代诊疗。它不是自我诊断工具。
判断属于医务人员，这份备忘的唯一目的是不要错过该去医院的时机。

## 0. 这份备忘怎么用

- 这些表格不是「判断自己是不是阑尾炎」的工具，而是让就诊提前的备忘。
- 下面的信号只要出现一条，就停止自己分辨，交给医务人员。
- 韩国的急救报警与咨询电话是119。119不仅受理报警和派车，还负责电话咨询与转运医院指引。
- 若身在韩国以外，请使用当地的急救电话。韩国的号码在境外无法接通。
- 最近的急诊在哪里，要在身体出问题之前就查好。等疼起来再找就晚了。

## 1. 不要拖延，立刻去急诊 — 出现任一条即可

- [ ] 腹痛剧烈
- [ ] 疼痛随时间加重，或者一直不消退
- [ ] 从肚脐周围开始的疼痛转移到了右下腹
- [ ] 按压腹部后松手时更痛
- [ ] 走路、咳嗽、打喷嚏或深呼吸时疼痛加剧
- [ ] 有发热
- [ ] 呕吐持续，什么都咽不下去
- [ ] 疼痛越过右下腹，扩散到整个腹部
- [ ] 疼痛一度减轻后又变得剧烈得多

## 2. 立即呼叫急救 — 出现这三条中任一条

- [ ] 意识模糊、言语不清或认不出人
- [ ] 皮肤出现花斑，或比平时苍白
- [ ] 呼吸困难

NHS将这三条列为脓毒症的可能征象，并指引立即拨打急救电话。

## 3. 即使症状轻也不能轻视的情况

- 儿童 — 早期表现为总想睡、对刺激敏感、食欲下降，随后进展迅速
- 老年人 — 常常不出现典型症状，病程快，且容易发生并发症
- 妊娠期 — 随着妊娠进展阑尾被向上推移，疼痛的位置可能改变
- 已经服过止痛药的人 — 把药名和服药时间如实告知医务人员

## 4. 就诊时要说明的信息 — 事先写好

| 项目 | 记录什么 | 填写示例 |
| --- | --- | --- |
| 起病时间 | 第一次感到不适的日期与时刻 | 昨晚8点左右 |
| 最初部位 | 一开始疼的位置 | 胸骨下与肚脐之间 |
| 当前部位 | 现在最疼的位置 | 右下腹 |
| 是否转移 | 位置有没有移动，何时移动 | 今天凌晨3点左右移动 |
| 强度变化 | 随时间变强还是变弱 | 一直变强，曾缓解一次后更痛 |
| 加重因素 | 做什么时更痛 | 走路时、咳嗽时 |
| 伴随症状 | 发热、寒战、恶心、呕吐、腹泻、便秘、排尿改变 | 低热，呕吐2次 |
| 最后一餐 | 吃了什么，什么时候吃的 | 昨晚7点吃饭，之后只喝水 |
| 最后排便 | 时间与性状 | 今天早上，稀便 |
| 已服药物 | 名称与时间。止痛药、退热药、抗酸药、助消化药全部 | 今天凌晨1点止痛药1片 |
| 基础疾病 | 正在治疗的疾病与既往手术 | 无，或写病名 |
| 过敏史 | 药物过敏 | 无，或写药名 |
| 妊娠可能 | 末次月经开始日 | 日期 |

## 5. 容易混淆的情况 — 不是用来自行鉴别，而是需要就诊的理由

| 重叠的情况 | 哪里相似 | 为什么自己分不出来 |
| --- | --- | --- |
| 胃肠炎 | 腹痛、恶心、呕吐、腹泻、低热同时出现 | 阑尾炎早期也可能出现腹泻和呕吐 |
| 便秘 | 腹部沉重，感觉排便后会舒服些 | 排便后会舒服的感觉在阑尾炎中同样有报告 |
| 泌尿系结石 | 侧腹与下腹疼痛，疼痛剧烈 | 属于需要通过尿检等排除的对象 |
| 妇科疾病 | 下腹这个位置重叠 | 盆腔炎在鉴别名单中，并会同时使用妊娠试验 |
| 肠梗阻、炎症性肠病、腹腔粘连 | 腹痛与排便异常 | 都在鉴别名单中，需要影像检查 |

## 6. 不要做的事

- 吃了止痛药再观望 — 如果吃了，一定要说出来。要不要吃不由自己决定，与医务人员商量
- 自行买抗生素服用 — 治疗方案要在查体和检查之后才确定
- 想靠偏方或食疗压下去 — 所查阅的资料中，没有任何一处支持发炎的阑尾能这样痊愈
- 因为疼痛突然减轻就放心 — 有报告显示穿孔后疼痛会短暂缓解，随后扩散到整个腹部
- 用网上的评分表给自己下判断 — 临床使用的工具，前提是由亲自查体的医务人员来用
- 只相信一项检查结果 — NHS写明，没有一项检查能永远显示出是否为阑尾炎

## 7. 资料中的数字 — 照出处原样

以下数值均出自韩国疾病管理厅 国家健康信息门户「急性阑尾炎」（2026-07-31确认）。
该文档并未另行标明调查年份或对象人群。

- 症状不典型的患者占全部患者的三分之一
- 阑尾梗阻的原因中，周围淋巴组织过度增生占60个百分点，干硬粪便占35个百分点
- 多发于十几岁至二十几岁，二十岁出头最为常见
- 10岁以下或50岁以上的患者约占全部患者的10个百分点
- 总体穿孔率约为25个百分点，10岁以下为35至60个百分点，50岁以上为60至75个百分点
- 非穿孔性阑尾炎中5个百分点出现并发症，若有组织坏死或穿孔则可达30个百分点
- 多数患者在症状出现后12至18小时内前往医疗机构

MedlinePlus写明该病在10岁至30岁人群中更常见。该页面同样未标明期间与对象人群。

## 8. 一句话

阑尾炎不是自己能分辨的病。表现不典型的情况并不少见，因此需要知道的不是病名，而是该去医院的时机。
