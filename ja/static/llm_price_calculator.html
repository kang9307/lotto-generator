計算式と根拠を見る

本ツールは次の計算式をそのまま使用しています。

入力コスト = 入力トークン × 月間リクエスト数 ÷ 1,000,000 × 入力単価 × キャッシュ係数 出力コスト = 出力トークン × 月間リクエスト数 ÷ 1,000,000 × 出力単価 月額コスト = 入力コスト + 出力コスト キャッシュ係数 = 1 − 0.9 × キャッシュヒット率
  • 単価の単位: すべての単価は 100 万（1M）トークンあたりの USD です。
  • キャッシュ係数: Anthropic・OpenAI・Google はいずれもキャッシュ済み入力を通常単価の約 10% で課金します。ヒット率 h のとき入力コストは (1−h) + 0.1h = 1 − 0.9h 倍になります。
  • 出力コスト: 出力トークンにはキャッシュが適用されないため、ヒット率に関係なく全額課金されます。
  • Claude Sonnet 5: 標準単価 $3 / $15 で表示しています。2026-08-31 まで $2 / $10 の導入価格が別途適用される場合があります。
  • 除外項目: バッチ API の 50% 割引、200K 超の長文コンテキスト追加料金、キャッシュ書き込みのプレミアム、画像・音声などのマルチモーダルトークンは反映していません。
  • 通貨: USD 基準のみです。為替レートは日々変動し換算額がすぐ古くなるため、意図的に掲載していません。

価格データは各ベンダーの公式価格表と、2026 年 7 月時点の価格集計資料を突き合わせて確認しています。
