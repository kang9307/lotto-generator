혼자 살아남기 10편: 안전하게 혼자 살기

1인 가구 필수 안전 수칙

2026-01-25생활/건강
⚠️ 건강 정보 안내 — 이 글은 일반적인 정보 제공을 목적으로 하며 의학적 진단이나 치료를 대체하지 않습니다. 증상이 있거나 판단이 필요한 경우 의료진과 상담하세요.

마지막 갱신 2026-09-29 · 갱신 이력부터 보기

🚨 긴급 연락처

  • 경찰: 112
  • 소방/응급: 119
  • 여성긴급전화: 1366 (365일 24시간, 스토킹·가정폭력·성폭력 피해 상담)
  • 범죄피해자 지원(한국범죄피해자지원중앙센터): 1577-1295

혼자 살면 안전이 제일 중요해요

자취하면서 무서웠던 적 있으시죠? 밤에 이상한 소리 들리거나, 누가 문을 두드리거나... 혼자 사는 만큼 안전에 더 신경 써야 해요.

오늘은 1인 가구가 반드시 알아야 할 안전 수칙을 정리했어요.

1. 현관 보안

기본 수칙

  • 이중 잠금: 자물쇠 + 체인 둘 다 사용
  • 잠금 확인: 자기 전, 외출 전 반드시 확인
  • 도어스토퍼: 저렴하게 보안 강화 가능
  • 문틈 막기: 밖에서 안이 보이면 안 됨

디지털 도어락

  • 비밀번호 정기적으로 변경
  • 생일, 전화번호 같은 쉬운 번호 피하기
  • 비밀번호 입력할 때 가리고 누르기

인터폰/초인종

  • 모르는 사람 절대 바로 문 열지 않기
  • 인터폰으로 먼저 확인
  • 택배/점검 사칭 조심 (회사에 확인 전화)

도어락 교체, 초인종·CCTV 설치처럼 집을 손대는 조치는 임대차 계약 내용과 임대인·관리사무소의 동의 여부에 따라 달라져요. 세입자가 직접 바꿔도 되는지는 사안마다 다르니, 계약서를 확인하고 먼저 물어본 뒤 진행하세요. 공용부위(공동현관·복도) 설비는 관리 주체가 따로 있어요.

문을 열기 전 항상 "누구세요?"부터! 그리고 혼자 산다고 말하지 마세요.

2. 혼자 사는 티 안 내기

일상에서

  • 신발: 현관에 남성 신발 하나 놔두기 (심리적 억제)
  • 세탁물: 베란다에 남성 옷 널기
  • 택배: 수령인 이름 모호하게 (성+OO)
  • 우편함: 자주 비우기 (쌓이면 부재 티남)

이런 방법들은 보조 수단이에요. 효과를 확인한 공식 자료는 찾지 못했으니, 잠금·확인 같은 기본 수칙을 대신하지는 못해요.

SNS 주의

  • 실시간 위치 공유 안 하기
  • 집 내부 사진 올릴 때 주소 노출 주의
  • "지금 여행 중" 실시간으로 안 올리기

3. 야간 안전

귀가할 때

  • 밝은 길로 다니기
  • 이어폰 양쪽 다 끼지 않기 (주변 소리 들어야 함)
  • 뒤따라오는 사람 있으면 편의점 등 들어가기
  • 건물 들어갈 때 뒤 확인하고 들어가기

집에서

  • 잠자기 전 문/창문 잠금 확인
  • 휴대폰 충전해두기 (비상시 연락)
  • 침대 옆에 손전등 두기

4. 화재 대비

예방

  • 외출 시 전열기구 끄기 (히터, 다리미)
  • 가스 불 사용 후 밸브 잠그기
  • 콘센트 문어발 사용 자제
  • 소화기 위치 파악

주택용 소방시설은 소방청 안내 기준으로 소화기는 세대별·층별 1개 이상, 단독경보형감지기는 구획된 실마다 설치하고, 소화기는 압력게이지가 초록색 범위인지 보고 사용기한(약 10년)을 확인해요. 세부 기준은 시·도 조례를 따르고, 임차 주택의 설치·교체는 임대인에게 확인하세요. 화재·가스 등 비상 상황 절차는 19편: 비상 상황 대처에 정리했어요.

화재 발생 시

  • 119 신고
  • 낮은 자세로 대피 (연기 피해)
  • 젖은 수건으로 코/입 막기
  • 비상구로 대피 (엘리베이터 절대 금지)
  • 대피 경로 미리 파악해두기

입주 첫날 비상구 위치와 소화기 위치를 꼭 확인하세요!

5. 비상 연락망

미리 준비

  • 가족 연락처 단축번호 저장
  • 가까운 친구 연락처
  • 관리사무소/집주인 연락처
  • 가까운 병원, 약국 위치 파악

위치 공유

  • 신뢰하는 가족/친구에게 집 주소 알려두기
  • 앱으로 위치 공유 설정 (신뢰하는 사람에게만)

6. 유용한 안전 앱

  • 지자체 안심귀가 서비스: 제공 여부와 방식이 지역마다 달라서 거주지 지자체 누리집에서 확인
  • 긴급신고 바로앱: 112·119 신고를 통합한 행정안전부 앱, 통화가 어려운 상황에서도 그림·문구를 골라 신고
  • 행정안전부 안전디딤돌: 재난 알림 (19편 참고)

7. 안전 용품

추천 아이템

  • 도어스토퍼: 문 강제 개방 방지
  • 창문 잠금장치: 추가 보안
  • 소화기: 소형 가정용
  • 손전등: 정전 대비
  • 구급함: 기본 응급용품

스토킹이 의심될 때 - 상담과 신고

같은 사람이 반복해서 따라오거나, 원치 않는 연락을 계속하거나, 집·직장 근처에서 기다린다면 스토킹을 의심해볼 수 있어요. 스토킹은 「스토킹범죄의 처벌 등에 관한 법률」이 다루는 범죄예요.

  • 지금 위협이 있거나 문 앞에 있다: 문을 열지 말고 즉시 112
  • 상담·긴급 보호가 필요하다: 여성긴급전화 1366 (365일 24시간, 채팅 상담도 운영, 긴급피난처 연계)
  • 기록 보관: 문자·통화 기록·사진은 지우지 말고 남겨두면 상담·신고 때 설명하기 쉬워요

판단이 서지 않아도 상담부터 해도 괜찮아요. 신고 요령과 번호 전체 표는 19편에 있어요.

8. 안전 체크리스트

매일

  • ☐ 외출 전 문 잠금 확인
  • ☐ 자기 전 문/창문 확인
  • ☐ 휴대폰 충전

정기적으로

  • ☐ 도어락 비밀번호 변경
  • ☐ 비상 연락처 업데이트
  • ☐ 비상구 경로 확인

갱신 이력

# 혼자 사는 집 안전 점검표

기준일: 2026-09-29. 한국 기준이며, 위협이 급박하면 판단하지 말고 112 또는 119에 신고합니다.

## 1. 번호 결정표

| 상황 | 번호 | 비고 |
|---|---|---|
| 범죄·침입·스토킹 위협이 지금 있다 | 112 | 문을 열지 않고 신고 |
| 화재·구조·구급 | 119 | 엘리베이터 대신 계단 |
| 스토킹·가정폭력·성폭력 피해 상담, 긴급 보호 | 1366 | 여성긴급전화, 365일 24시간, 여성가족부 |
| 범죄 피해 지원 | 1577-1295 | 한국범죄피해자지원중앙센터 |
| 재난 알림, 112·119 앱 신고 | 앱 | 안전디딤돌, 긴급신고 바로앱 |

## 2. 매일
- [ ] 외출 전 문 잠금 확인
- [ ] 자기 전 문·창문 확인
- [ ] 휴대폰 충전

## 3. 정기적으로
- [ ] 도어락 비밀번호 변경 (생일·전화번호 금지)
- [ ] 비상 연락처 업데이트
- [ ] 비상구 경로·소화기 위치 확인
- [ ] 소화기 압력게이지와 사용기한(약 10년) 확인, 단독경보형감지기 구획된 실마다 설치 여부 확인

## 4. 집을 손대기 전에
- [ ] 도어락·초인종·CCTV 교체는 임대차 계약과 임대인·관리사무소 동의 여부를 먼저 확인 (사안마다 다름)

## 5. 스토킹이 의심될 때
- [ ] 지금 위협이 있으면 문을 열지 말고 112
- [ ] 상담·긴급 보호는 1366
- [ ] 문자·통화 기록·사진은 지우지 말고 보관

다음 갱신 조건: 1366·범죄피해자지원 번호 변경, 신고 앱 개편, 소방청 설치 기준 개정.
