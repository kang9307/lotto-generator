肩周炎（粘连性关节囊炎）完全指南 — 症状、分期、治疗与康复运动

病因、风险因素、三阶段进程、症状自我识别、治疗方案及居家康复运动一站式指南

2026-06-28 生活/健康

引言：肩膀"冻住"是什么感受

某天早晨，你向后伸手系安全带时突然一阵剧痛；几周后，抬起手臂超过肩膀高度变得几乎不可能，甚至夜间翻身都会痛醒。这种经历比你想象的要普遍：粘连性关节囊炎（Adhesive Capsulitis），俗称肩周炎（英文名"Frozen Shoulder：冻结肩"），影响着约2%至5%的成年人。

"肩周炎"在中文语境中泛指肩关节周围组织的慢性炎症与粘连，医学上特指粘连性关节囊炎这一明确病种。本文基于2026年6月的医疗信息（NHS、Mayo Clinic、AAOS等机构），以一般健康信息形式整理了肩周炎的病因、三个进展阶段、症状、治疗方案及居家康复运动。

重要提示：本文仅供一般健康信息参考，不构成医学诊断、处方或治疗建议。如有持续肩部疼痛或活动受限，请务必就诊骨科或运动医学专科医生。

1. 什么是肩周炎

肩周炎是指包裹肩关节的关节囊发生慢性炎症，导致关节囊增厚、纤维化并与周围组织粘连，从而使肩关节活动范围显著减小的一种病症。

正常的肩关节囊柔软而宽松，允许手臂在各个方向自由活动。患肩周炎时，关节囊如同收缩的口袋般束缚肩关节，使前屈、外展、内外旋等所有方向的活动均受到限制。

原发性（特发性）肩周炎无明显外伤诱因，自发产生。继发性肩周炎则发生在肩部手术、骨折、脑卒中后长期制动等使肩关节长时间无法活动的情况之后。

2. 病因与风险因素 — 糖尿病、甲状腺疾病与中年人群

肩周炎的确切病因尚未完全明确，但以下风险因素被证实会显著提高发病率。

2.1 糖尿病 — 最强相关风险因素

糖尿病（尤其是2型）是与肩周炎最密切相关的全身性疾病。糖尿病患者肩周炎发病率约为10%至20%，是普通人群（2%至5%）的3至5倍。糖尿病患者症状往往更重、持续时间更长、对治疗反应更慢。血糖控制越好，康复速度越快，因此肩周炎治疗期间务必同步管理血糖。

2.2 甲状腺疾病

甲状腺功能减退（桥本甲状腺炎等）和甲状腺功能亢进（格雷夫斯病等）均与肩周炎风险增加有关。甲状腺激素对结缔组织代谢的影响可能是其中的机制。

2.3 年龄与性别

肩周炎最常见于40至60岁人群，女性略多于男性。围绝经期前后的激素变化可能使关节囊对炎症的敏感性增加。

2.4 长期制动

肩袖手术恢复期、肱骨骨折、脑卒中后上肢长期不动等情况均可导致继发性肩周炎。前臂或腕部骨折后长时间使用吊带也是已知风险因素。

2.5 其他相关因素

  • 帕金森病、心血管疾病病史
  • 对侧肩曾患肩周炎（约17%患者对侧肩也会受累）
  • 既往肩部外伤或手术
  • 长期久坐少动的生活方式

3. 三个阶段的进展 — 炎症期、冻结期、解冻期

肩周炎通常经历以下三个阶段，总病程一般为1至3年，但个体差异较大。

阶段名称主要特征持续时间
第一期炎症期（Freezing）疼痛逐渐加重，活动范围开始下降6周至9个月
第二期冻结期（Frozen）疼痛稍有减轻，但肩关节最为僵硬4至12个月
第三期解冻期（Thawing）活动范围逐渐恢复，疼痛持续改善5个月至2年

3.1 第一期 — 炎症期

疼痛由轻到重逐渐发展，抬手或后伸时出现锐痛，夜间痛明显，患侧卧位时尤其难以入睡。此阶段活动范围也开始下降。强行牵拉可能加重炎症，应在耐受范围内做轻柔的活动度训练，并配合消炎镇痛治疗。

3.2 第二期 — 冻结期

疼痛较第一期略有减轻，但肩关节僵硬程度达到最高峰。前屈、外展、旋转各方向均受到严重限制，即使他人协助活动仍十分困难。穿脱衣物、梳头、向后取物等日常动作均受影响。此阶段坚持规律的拉伸和物理治疗至关重要。

3.3 第三期 — 解冻期

肩关节活动范围开始逐渐恢复，疼痛持续减轻。在拉伸基础上加入肌力训练有助于加速完全康复。未经积极治疗的部分患者，数年后活动范围仍可能无法完全恢复正常。

4. 症状与自我识别

肩周炎的两个核心症状是肩部疼痛和关节活动受限。

4.1 主要症状

  • 肩部深层钝痛，可放射至上臂（三角肌区域）
  • 夜间痛 — 患侧卧位时加重
  • 手臂难以向前、向侧、向后或向上抬起
  • 日常动作受限：穿衬衫、系文胸、梳头、背手等
  • 由他人协助活动时也受到限制（被动活动范围也下降）

4.2 与肩袖损伤的鉴别

肩周炎与肩袖损伤（肩袖撕裂、肩袖肌腱炎）症状相似，容易混淆。最关键的鉴别点是被动活动范围。

特征肩周炎肩袖撕裂
被动活动范围受限（他人协助也难以活动）相对保留（他人托举可活动）
疼痛性质持续钝痛，夜间加重特定动作（上举）时锐痛
起病方式缓慢进展可急性发作或外伤后出现
肌力减退因痛受限，实际肌力保留真性肌力下降明显

准确鉴别需要医生体格检查及X线、MRI等影像学检查。肩部疼痛持续数周以上应及时就医。

5. 治疗方案 — 分阶段处理

肩周炎治疗根据所处阶段和严重程度而有所不同。保守治疗是首选，长期无效时才考虑手术。

5.1 拉伸与物理治疗

改善关节活动范围的牵伸训练（拉伸）是肩周炎治疗的核心。原则是在疼痛耐受范围内温和地拉伸，过度激进的牵拉在炎症期可能加重症状。物理治疗师可制定个体化方案，并结合超声波、热疗、手法治疗等提高疗效。

5.2 药物治疗（NSAIDs）

非甾体抗炎药（NSAIDs：布洛芬、萘普生等）可短期缓解疼痛和减轻炎症。长期服用有胃肠道及心血管风险，需遵医嘱使用。

5.3 糖皮质激素关节内注射

关节腔内注射皮质类固醇（激素）可有效减轻炎症和疼痛，尤其在炎症期效果较显著。注射次数和间隔由医生个体化决定，不建议多次盲目注射。糖尿病患者注射后可能出现短暂血糖升高，需监测。

5.4 关节囊水压扩张术

在影像引导下向关节囊注入生理盐水（可含激素），使关节囊物理性扩张，以松解粘连。适用于常规注射和物理治疗效果不足的患者。

5.5 麻醉下手法松解（MUA）

在全身或区域麻醉下，由医生强力活动肩关节以打断粘连。现多被关节镜手术取代，但部分机构仍在使用。

5.6 关节镜下关节囊松解术（手术）

经过6至12个月积极保守治疗仍无足够改善时考虑手术。通过关节镜切断增厚挛缩的关节囊，术后仍需配合物理治疗以维持并提升活动范围。

6. 居家康复运动

以下运动是肩周炎康复中常用的拉伸动作。运动前用热敷（热毛巾、热水袋）热敷肩部10至15分钟有助于提高柔韧性。出现明显疼痛时立即停止，具体运动方案请在物理治疗师指导下制定。

6.1 钟摆运动

健侧手扶桌面，身体向前倾，患侧手臂自然下垂。利用身体微微摆动带动手臂做前后、左右、画圆等小幅度运动，不主动用肩部肌肉发力。该动作利用重力牵引关节，炎症期也可安全开始。每次1至2分钟，每日2至3次。

6.2 外旋拉伸

站在门框旁，肘关节弯曲90度，手掌向前。前臂贴着门框，身体缓慢向反方向旋转，直至感到肩前方有拉伸感。保持20至30秒后放松，重复3至5次。

6.3 毛巾内旋拉伸

双手在背后各握住毛巾一端（健侧手在上，患侧手在下）。健侧手缓慢向上拉动毛巾，带动患侧肩膀内旋拉伸。感到拉伸感后保持20至30秒，重复3至5次。

6.4 手指爬墙

面对墙壁站立，用患侧手指触墙，手指缓慢向上"爬行"至感到拉伸。保持10至15秒后缓慢放下。可分别从正面（前屈）和侧面（外展）两个方向练习。

6.5 交叉拉伸

用健侧手轻轻握住患侧肘部上方，将患侧手臂向胸前横向拉伸，感到肩后方有拉伸感后保持20至30秒，重复3至5次。

7. 恢复周期与预后

接受适当治疗后大多数肩周炎患者可以康复，但需要时间。总体来说，多数患者在1至3年内症状明显改善。若未接受积极治疗或合并糖尿病控制不良，恢复时间可能延长，部分患者活动范围可能无法完全恢复正常。

有助于加快康复的因素：

  • 症状出现后尽早就诊，明确诊断
  • 坚持规律物理治疗
  • 糖尿病患者严格控制血糖
  • 在无痛范围内保持肩部活动，避免完全制动
  • 家庭锻炼计划保持一致性
