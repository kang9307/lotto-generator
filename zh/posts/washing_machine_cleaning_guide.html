洗衣机内筒清洗方法 - 分步去除异味与霉菌的保养指南

从筒自洁程序到门封圈、洗涤剂盒与排水过滤器

2026年7月26日 生活

引言：出现这些信号就该清洗了

刚洗好的毛巾带着一股霉味。深色衣物上粘着黑色碎屑。打开滚筒门时涌出类似下水道的气味。掀开门封圈，内侧密布黑点。只要中了其中一条，问题多半不在洗衣液品牌，而是内筒本身已经被污染。洗衣机长期提供水分、洗涤剂残留、绒毛与皮脂，正是微生物膜（生物膜）扎根的理想环境。洗衣机表面的微生物定植、生物膜形成以及由此产生的异味，在学术研究中已被反复讨论。

好消息是，多数情况都能在家解决。需要的只是一份被允许使用的清洁剂、几条旧毛巾，以及花大约三十分钟去手工清理水流够不到的四个位置。本文按顺序梳理准备物品、分步操作、常见错误、必须守住的安全底线，以及何时该停手请人上门。如果还处在换机阶段，可以先看洗衣机选购完全指南。所有内容之上只有一条原则：你自己的使用说明书优先于本文，因为各品牌允许的清洁剂并不一致。

1. 异味与霉菌从何而来 - 三个原因

1.1 残水与密闭

程序结束后，外筒、排水管和门封圈折缝里仍留有水。此时立刻关门，内部就变成温暖、潮湿、避光的空间，正是霉菌和细菌最喜欢的条件。LG建议洗涤后打开机门与洗涤剂抽屉，让内部干燥；三星同样建议每次洗后让机门与洗涤剂盒保持开启。异味问题有一半，就取决于这个习惯。

1.2 洗涤剂与柔顺剂投放过量

多倒一点似乎更干净，实际上漂洗带不走的表面活性剂与柔顺剂成分会残留在筒壁上，成为微生物的养分与粘附层。柔顺剂尤其麻烦，其油性基质会在洗涤剂盒与通道里形成黏稠残垢。按标示用量投放，甚至略少一点，对控制异味更有利。

1.3 长期只用低温洗涤

低温洗涤省电又护衣，但在卫生层面是有代价的。该领域的综述指出，降低洗涤温度可能有利于微生物在洗衣机内部及衣物上的存活。如果平时以冷水洗为主，就应当缩短而不是拉长自洁程序的间隔。

3. 第1步 - 运行筒自洁程序 （耗时1~4小时・难度 低）

先把筒内清空，绝不能带着衣物运行。程序名称因品牌而异，可能叫筒自洁、自动清洗、筒清洁或桶洗净。

3.1 滚筒洗衣机

  1. 把滚筒完全清空。
  2. 在进水之前把清洁剂投入洗涤剂盒或直接放进滚筒。
  3. 选择筒自洁（自动清洗）程序并启动。
  4. 结束后开着门，让内部自然干燥。

按LG的说明，筒清洁程序会供应热水并维持在约60摄氏度，建议每洗涤30次或显示屏出现tcL提示时运行。程序时长因机型而异，滚筒机耗时数小时也很常见。

3.2 波轮洗衣机

  1. 清空内筒，注水至最高水位。
  2. 水满后投入清洁剂，短暂搅拌使其溶解，再浸泡20~30分钟。
  3. 用筒自洁程序或标准程序完整运行一遍。
  4. 若浮起的污垢较多，再单独加洗一次漂洗。

记住这个顺序差异即可：滚筒先放清洁剂，波轮先注水。波轮浸泡面积大，泡洗有效；滚筒是用少量水翻滚清洗，清洁剂必须事先溶解好。

3.3 如果机器没有自洁程序

波轮机可用最高水位加热水的标准程序替代。滚筒机则可在空载状态下单独运行最高温度程序。不过机器支持的最高温度以及是否允许空载运行，都要先查说明书。

4. 第2步 - 清理门封圈折缝 （15分钟・难度 低・仅滚筒机）

这是滚筒洗衣机最大的异味来源，而自洁程序的水流并不能真正冲到折缝内侧，必须用手完成。

  1. 用手指把门封圈的唇边掀开，不要用力硬拽。
  2. 清出积水、头发、硬币、纽扣和其他异物。
  3. 用蘸了清洁液的布把折缝面整圈擦一遍，有黑点就用软毛刷刷。
  4. 用干毛巾彻底吸干水分，然后让机门保持敞开。

三星建议滚筒机型的门封条每周清洁一次，小心掀开门封圈，擦拭折缝内侧并彻底晾干。LG同样建议用布擦拭门封圈表面，并掀开唇边清理下方。已经渗进橡胶的黑色霉斑可能无法完全擦掉，这属于外观问题，并非故障。

5. 第3步 - 拆下洗涤剂盒清洗 （10分钟・难度 低）

洗涤剂与柔顺剂结块堵住通道后，实际投放量会减少，残渣不断堆积。这是第二大异味源。

  1. 把抽屉拉到底，按下解锁位置取出。
  2. 拆下所有可拆的隔板与柔顺剂盖帽。
  3. 放入温水浸泡软化，再用软毛刷刷洗。
  4. 连抽屉插入位置的机身腔体顶面也要刷到，这里最常被忽略。
  5. 彻底晾干后装回，平时让抽屉留一条缝。

三星建议大约每月一次取下洗涤剂抽屉，用温水冲洗并以软毛刷清除会影响性能的残留物。

6. 第4步 - 清理排水过滤器与绒毛网 （15分钟・难度 中）

滚筒机底部小盖板后面是排水泵过滤器。绒毛、头发和硬币在此堆积，会直接造成排水不畅与强烈异味。

  1. 先拔掉电源插头，并在程序结束后再操作。
  2. 打开底部盖板，地面垫好毛巾并放置浅盆。
  3. 若有应急排水软管，先拔塞放掉存水。水量往往超出预期。
  4. 逆时针旋出过滤器，清除异物后用流水冲洗。
  5. 用手电照亮过滤器腔体内部，清掉残留杂物。
  6. 把过滤器完全拧紧装回并合上盖板，拧不紧就会漏水。

三星建议滚筒机型的杂物过滤器至少每月清洗一次，或每洗涤40次清洗一次。波轮机没有底部排水过滤器，取而代之的是筒体上方的绒毛过滤网，取出冲洗即可。这也是波轮机用户最容易遗漏的部位。

7. 第5步 - 养成每天一分钟的干燥习惯 （1分钟・难度 低）

前面都做了，习惯不改的话，几周就会打回原形。守住以下四条就够。

  • 洗涤结束后让机门与洗涤剂盒保持敞开。家中有幼儿或宠物可能钻进滚筒时，可使用只留缝隙的门挡，并管控洗衣区域的出入。
  • 用干毛巾把门封圈下方的积水擦一遍。
  • 洗好的衣物立即取出。湿衣物闷在筒里，当天就会串上异味。
  • 不要把洗衣机当脏衣篮，长期堆放待洗衣物。

如果洗衣机安装在潮湿的生活阳台，通风与除湿同样重要。夏季湿度管理已在除湿机选购完全指南中单独讨论。

8. 清洗周期一览

部位建议周期依据与备注
筒自洁程序每月一次或每使用30次LG为30次或tcL提示，三星为每月一次
门封圈（滚筒）每周一次三星建议。擦完必须彻底干燥
洗涤剂盒每月一次拆下后温水加软毛刷
排水过滤器（滚筒）每月一次或每40次洗涤三星建议
绒毛过滤网（波轮）两周至一个月一次按积尘量调整
开门与开抽屉晾干每次洗涤后LG与三星共同建议

若以低温洗涤为主、家庭成员四人以上、与宠物同住，或安装环境潮湿，把上述周期缩短约三分之一到一半会更稳妥。

9. 五个常见错误

9.1 以为跑一次自洁就完事

长期积累的生物膜不会一次脱净。LG建议在已有异味时连续三周每周运行一次筒清洁程序。第一次之后出现黑色碎屑，说明污垢正在剥落，加洗一次漂洗后继续下一轮即可。

9.2 跳过水流够不到的地方

门封圈折缝、洗涤剂盒后方通道、排水过滤器。这三处任何程序都无法自动清洁，异味残留的案例几乎都出在这里。

9.3 洗涤剂倒得很大方

过量投放只会增加残留，反而让异味更重。按标示用量投放；在水质较软的地区，稍微减量通常也不会明显影响洗净度。

9.4 洗完立刻关门

最常见也最关键的错误。密闭加残水加余温，本身就是霉菌的培养条件。

9.5 用钢丝球或强效药剂猛刷

不锈钢内筒和橡胶门封圈一旦被划伤，反而更容易挂脏。软布加软毛刷已经足够。

⚠ 安全警告 - 氯系漂白剂与酸性清洁剂绝对不可混用。
氯系漂白剂与柠檬酸、白醋等酸性清洁剂混合使用，可能释放有毒的氯气。包括美国华盛顿州卫生部在内的公共卫生机构，反复警告不要将漂白剂与其他清洁剂混合。接触后可能出现咳嗽，眼、鼻、咽喉刺激，呼吸困难与胸闷，高浓度下甚至可能致命。不只是同时投放，前后接连使用同样危险。如果要更换清洁剂种类，必须先充分漂洗并排空，且至少间隔一个完整程序。操作全程务必通风，一旦出现不适应立即离开现场。

10. 安全注意事项 - 不可逾越的界线

  • 禁止混合清洁剂。如上方警告所述，漂白剂配柠檬酸、漂白剂配白醋、漂白剂配酸性除垢剂，这些组合一律避免。
  • 只用厂商允许的清洁剂。LG推荐氧系洗衣机专用清洁剂，并提醒氯系与酸性清洁剂可能造成内部变色和腐蚀，应当避免；三星则说明异味严重时可将液态氯系漂白剂倒入洗涤剂投放口。各品牌标准确实不同，说明书才是最终依据。
  • 不要用高泡洗涤剂做自洁。泡沫过多被指可能导致机器漏水。厨房洗洁精和手洗专用洗剂都不适合用于清洁程序。
  • 拆过滤器盖板前先断电。这是与积水打交道的部位，务必拔掉插头再操作，切勿湿手触碰插座。
  • 禁止拆解线路、电机与水泵。用户可自行打开的范围仅限洗涤剂盒、门封圈和排水过滤器盖板，再往里属于售后范畴。
  • 必须通风，尽量减少皮肤接触。戴橡胶手套，开窗或开启排风后再作业，作业期间让儿童与宠物远离。

11. 何时该请专业拆洗或报修

出现以下情况，就已超出自行清洁的范围。

  • 连续三周自洁并手工清理四个部位后，黑色碎屑仍持续出现。
  • 使用年限长，且从未做过拆机清洗。
  • 排水不畅，或运行中向地面漏水。
  • 脱水时出现金属摩擦声、剧烈震动或刮擦声。
  • 无法开机，或错误代码反复出现。
  • 衣物上不断沾到类似油污的斑迹。

排水不良、漏水、异响和电气异常属于维修范畴而非清洁范畴，应优先联系厂商售后。若纯粹出于卫生目的做拆机清洗，可以选择专业机构，但务必先确认保修期是否还在，因为非官方拆解可能影响保修条件。预约时先问清楚：是完整取出内筒，还是仅做药剂清洗；作业后是否包含试机与漏水检查。同类季节性家电的自助保养，可参考空调自己清洗的方法。

12. 结语 - 用三十分钟的例行流程收尾

归纳起来是这样。第一，每月跑一次筒自洁程序。滚筒机先放清洁剂，波轮机先注水至最高水位再溶解浸泡。第二，手工清理程序够不到的三个位置：门封圈折缝、洗涤剂盒及其后方通道、排水过滤器。这三处决定了大约九成的效果。第三，每天投入一分钟。洗完打开机门与洗涤剂盒，擦掉门封圈下的积水，衣物立即取出。第四，洗涤剂严格按标示用量。倒得越多残留越多，异味也越重。

然后是安全。氯系漂白剂与酸性清洁剂，在任何情况下都不可混用。只使用说明书允许的清洁剂，并记住各品牌标准确实存在差异。如果异味已经形成，就不要指望一次搞定，按每周一次连续三周观察变化。若黑色碎屑始终不停，或出现排水、漏水、异响等症状，那就是停止自行清洁、转而联系售后或专业拆洗的时点。内筒清洗本身并不是高难度作业，勤做、短做、不漏掉任何一处，就是全部要领。

说明： 本文是关于家用洗衣机一般保养方法的信息性内容。不同机型与品牌在推荐清洁剂、程序名称、清洗周期以及可拆卸范围上均有差异，因此务必优先查阅产品使用说明书。本文不推荐任何特定产品或品牌，也不对因擅自拆解或使用厂商不推荐的清洁剂而造成的产品损坏、保修受限或安全事故承担责任。使用化学清洁剂期间若出现呼吸困难等不适，应立即通风并离开现场，必要时寻求医疗帮助。
