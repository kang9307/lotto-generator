育児費用と政府支援制度 - 韓国でもらえるのに申請せず逃す支援をなくす方法

申請主義と期限、そして毎年変わる金額との付き合い方

2026-07-31 暮らしの実用

はじめに: それは期限が過ぎているのでできません

役所の窓口で最も聞きたくない一文がある。その項目は申請期限が過ぎているのでできません。資格がなかったわけでもなく、書類が足りなかったわけでもない。ただそういうものがあると知らず、知ったときには遅かっただけである。お金がなくて受け取れなかったのではなく情報がなくて受け取れなかったという点で、この損はとりわけ悔しい。

育児費用を扱う記事はたいてい「いくらかかる」で始まる。その数字はそれぞれの事情によってあまりに大きく変わるので、実のところあまり役に立たない。この記事は別のところに焦点を置く。もらえるのに申請しないために受け取れないものをなくすことである。

そのためには韓国の制度が持つ三つの性質を先に知る必要がある。この三行がこの記事のすべてだと言ってもよい。

  • 申請主義である。資格を備えることと実際に受け取ることは違う。その間をつなぐのは申請という行為ひとつだけで、それを代わりにやってくれる人はいない
  • 期限がある。ある項目は期限を過ぎると遡及されない。バウチャーのように使わなければ消滅する形もある
  • 毎年変わる。金額も、年齢要件も、申請方法も変わる。昨年基準で立てた計画が今年は違っているということがよくある

だからこの記事は金額を覚えさせるための記事ではない。いつ何を確認すべきかを残すための記事である。金額は一年で古くなるが、確認する習慣は子どもが学校に上がるまで使える。

適用範囲と免責。この記事は韓国の制度のみを説明する。他の国にお住まいの場合、ここの数字はその国には当てはまらない。情報提供を目的としており、法律、税務、行政の助言ではなく、個別の事案についての判断でもない。ここに記したすべての金額と要件は2026年7月31日時点で公式資料から確認したものであり、以後変更されうる。実際の支給の可否と金額は、所得、世帯構成、居住地、雇用形態、申請時期によって異なる。申請の前に必ず担当機関で自分の要件を確認すること。

確認できなかったものは書かなかった。一次資料から数字を確定できなかった項目は推測で埋めず、確認が必要と記して確認経路だけを示した。第10節にその一覧をまとめてある。この記事にない項目が存在しないという意味ではなく、筆者が確認できなかったという意味である。

1. 育児費用を三つの区間に分ける

費用をひとかたまりで見ると対応ができない。時期ごとに大きな費用の性格が違い、公的支援がつく地点も違うからである。大きく三つの区間に分けると、何をいつ確認すべきかが見えてくる。

区間費用の性格公的支援がつく地点確認時期
妊娠・出産短く重い。診療と出産に集中し、期間が決まっている診療費支援、出産関連の休暇と給付妊娠が確認された直後
乳幼児期毎月繰り返す。保育の形によって総額が大きく分かれる現金給付、保育支援、労働時間の制度出生届の時点
就学前施設利用料と時間費用が混ざる。親の就業形態と絡む保育・教育支援、預かりサービス、税額控除施設利用を変える時点

この表で最も重要な欄はいちばん右である。支援制度はおおむね「状態が変わる時点」で申請または届け出るようになっている。妊娠を確認したとき、子が生まれたとき、施設に通い始めたとき、辞めたとき、引っ越したときである。この時点を逃すと、その間の期間の支援がまるごと空くことが起きる。

逆に言えば確認すべき瞬間はそれほど多くない。毎日ニュースを追う必要はなく、右の四つか五つの時点で一度ずつ公式窓口を開いてみればおおむね拾える。

2. 妊娠・出産 - 診療費支援から確認する

妊娠の区間でまず確認すべきは健康保険の妊娠・出産診療費支援である。国民健康保険公団と政府24の案内を基準に妊娠1回あたり100万ウォンが支援され、多胎妊娠の場合は140万ウォンである。分娩の取扱いが手薄な地域に居住する場合は20万ウォンが追加され、単胎120万ウォン、多胎160万ウォンになる。

この項目が最初に来る理由は金額が大きいからではなく期限が付いているからである。支援金は利用券の形で与えられ、使用期間内に使わなかった残額は消滅する。資格があっても、申請をしていても、期間内に使わなければ消えるという意味である。

  • 使用終了日は必ず公団に直接確認すること。確認した公式資料の間でも、終了日の基準が「出産日から1年」と「分娩予定日または出産日から2年」のように異なって表記されていた。こうした項目は他人の要約ではなく自分の利用券の実際の終了日を見るべきである
  • 多胎かどうかと分娩取扱いの手薄な地域に当たるかを申請段階で伝える必要がある。追加支援は該当の事実が反映されて初めて付く
  • すでに当該のカードを持っているなら、カードの発給手続きなしにバウチャーの申請だけすればよいという案内がある
  • 出産予定日の前後には産前産後休暇と育児休業が続く。この二つは第5節で別に扱う
  • 配偶者出産休暇の日数と申請期限はこの記事では確認できなかった。雇用労働部と雇用保険で確認すること

この区間の原則をひとつ。妊娠・出産区間の支援は期間型が多い。つまり「受け取った」で終わらず「期間内に使った」まで行って完結する。申請したその日に使用開始日と終了日をカレンダーに書いておくことが、この区間でできる最も実質的な守りである。

3. 現金給付 - 児童手当と親給付

子が生まれた後に毎月入ってくる性格の支援である。確認できた二つの柱は親給付と児童手当である。下の表の数字はすべて基準年度と出典を併記した。そのまま覚えるのではなく、申請時点で再確認する用途に使ってほしい。

制度対象金額基準出典
親給付0歳 (0か月から11か月)月100万ウォン2023年施行、整理時点で継続保健福祉部
親給付1歳 (12か月から23か月)月50万ウォン2023年施行、整理時点で継続保健福祉部
児童手当9歳未満 / 首都圏月10万ウォン2026年保健福祉部 (2026-04-23)
児童手当9歳未満 / 首都圏以外月10万5千ウォン2026年保健福祉部 (2026-04-23)
児童手当9歳未満 / 人口減少地域の優遇月11万ウォン (地域商品券12万ウォン)2026年保健福祉部 (2026-04-23)
児童手当9歳未満 / 人口減少地域の特別月12万ウォン (地域商品券13万ウォン)2026年保健福祉部 (2026-04-23)

児童手当で注目すべきは年齢が毎年上がるという点である。保健福祉部の資料を基準に、2026年は9歳未満、2027年は10歳未満、2028年は11歳未満、2029年は12歳未満、2030年は13歳未満へと毎年一歳ずつ拡大される。今は対象でなくても数年後には対象になりうるという意味であり、逆に「うちの子は年齢を超えている」という判断が来年には誤りになりうる。

  • 同じ資料ですでに児童手当を受け取っていた世帯には拡大分が別途の申請なしに支給され、2017年1月生まれから2018年3月生まれまでの約43万人に1月分から3月分が遡って支給された
  • ただしこれはすでに受給中の人に適用された例外であって、初めて受け取る人に申請が不要という意味ではない
  • 親給付は保健福祉部の案内上現金またはバウチャー(保育料・終日制の預かり)から選ぶ仕組みである。保育施設に通うから支援が消えるのではなく形が変わる
  • 申請は邑面洞の住民センターの訪問または福祉路のオンラインで可能という案内がある
  • 親給付の申請期限と遡及規定は確認できなかった。「遅く申請しても遡るだろう」と仮定せず、福祉路や住民センターで確認すること

4. 保育・教育 - どこに通うかで分かれる

乳幼児期の支援の構造は単純な原理の上に立っている。施設を利用すれば施設の側に、利用しなければ家庭の側に支援が付く。保育施設や幼稚園に通えば保育料や幼児学費の形の支援が、通わなければ家庭養育の側の支援が対応する。

ここで実務的に重要なのは金額ではなく重ねて受け取れない構造があるという点である。同じ性格の支援を二つの経路で同時に受けるようには設計されていないので、両者の間を行き来するときは変更届が必要である。この届出を落とすのがこの区間の代表的な事故である。

  • 施設の利用を始めるときに支援方式が変わる。届け出なければ受け取る金額がずれる
  • 施設を辞めるときも同じである。このときは家庭養育の側に戻す届出が必要である
  • 同じ期間に同じ性格の支援を二重に受ける仕組みはないと見るほうが安全である。重複の可否は申請窓口で確認すること
  • 途中で辞めたり移ったりする月は日割り計算や精算が生じうる。後から返還を求められないよう、その都度届け出るほうがよい
  • 家庭養育手当の金額と年齢区分、保育施設の保育料と幼稚園の幼児学費の年齢別単価はこの記事では確認できなかった。子育てポータル、福祉路、教育庁、住民センターで確認すること
  • 子育て支援サービスの所得基準と自己負担の割合も確認できなかった。別に確認が必要な項目である

5. 仕事と育児 - 育児休業と労働時間短縮

お金に換算されないが実際には最も大きい項目が時間である。そしてその時間を制度にするのが育児休業と育児期の労働時間短縮である。雇用労働部が案内した2025年施行の基準で確認できた内容は次のとおりである。

項目確認内容施行時点出典
育児休業給付の上限1から3か月 月250万ウォン2025-01-01雇用労働部
育児休業給付の上限4から6か月 月200万ウォン2025-01-01雇用労働部
育児休業給付の上限7か月目以降 月160万ウォン2025-01-01雇用労働部

表を読むときに必ず区別すべきことがある。上の金額は上限額であって受取額ではない。実際の支給額は通常賃金と個人別の算定基準によって決まるので、上限額をそのまま家計の計画に入れるとずれる。

  • 事後支給金の廃止は体感の大きい変化である。以前は一部を復職後に受け取っていたが、いまは休業中に全額が支給されるという案内である
  • 1年6か月への延長には要件がある。「無条件で1年6か月」ではなく、夫婦がそれぞれ一定期間以上使う場合などが条件である。自分が当たるかの確認が必要である
  • 労働時間短縮の対象年齢が小学6年生まで上がった。保育施設の時期だけの制度ではないという意味であり、小学校低学年の預かりの空白に使えるカードになる
  • 育児期労働時間短縮給付の実際の計算は確認できなかった。参照した公式資料の間で基準金額の表記が互いに異なっていたため確定しなかった。雇用労働部と雇用保険で自分の基準で確認すること
  • 受給には雇用保険に関する要件が別にある。在職中でも自動的になるわけではない

6. 税金 - 年末調整で子どもが置かれる位置

現金として入ってくるわけではないが少なく納める形で戻ってくるのが税金の側である。国税庁の案内で確認できた項目は次のとおりである。

項目確認内容出典
子女税額控除8歳以上の基本控除対象の子1人 年25万ウォン国税庁
子女税額控除2人 年55万ウォン国税庁
子女税額控除3人以上 年55万ウォン + 3人を超える1人あたり40万ウォン国税庁
出産・養子縁組の税額控除第1子30万ウォン、第2子50万ウォン、第3子以降70万ウォン国税庁
産後ケア施設の費用医療費控除の対象、出産1回あたり200万ウォンが限度国税庁

ここで見落としやすいのは年齢の区分である。子女税額控除は8歳以上を基準に案内されている。つまり乳幼児期には現金給付が、その後は税額控除が主にかみ合う構造だと見ると理解しやすい。「子どもがいるのだから当然控除される」のではなく年齢によって適用される項目が違う。

  • 産後ケア施設の費用が医療費控除の対象である点はよく抜け落ちる。領収書をとっておくのが実質的な対応である
  • 年末調整の簡素化資料にすべての医療費が自動で入るわけではない。漏れた項目は自分で領収書を提出する必要がある
  • 出産・養子縁組の税額控除はその年度にだけ適用される性格なので、その年の年末調整で必ず反映しなければならない
  • 医療費税額控除の控除率と最低の使用要件、就学前の子の教育費控除の限度はこの記事では確認できなかった。国税庁で確認すること

7. 逃しやすいもの - 申請主義、期限、遡及

この節がこの記事の核である。期限を過ぎると取り返せないものから順に並べる。

  • 1. 期間内に使わなければ消滅するもの。診療費支援のように利用券の形で与えられる項目がここに属する。申請を終えていても使わなければ消える。まっさきにカレンダーに書くべき項目である
  • 2. 申請してはじめて始まるもの。現金給付のほとんどがそうである。出生届を出したからといって自動的についてこない。出生届の時点で一緒に処理する一覧をあらかじめ作っておくことが最善の守りである
  • 3. 状態が変わったら届け出るもの。施設利用の開始と中止、引っ越し、口座変更がここに属する。届け出なければ受け取れないか、誤って受け取り後で返さなければならない
  • 4. 毎年あらためて確認すべきもの。金額と年齢要件は変わる。昨年は対象でなくても今年は対象でありうるし、その逆もある
  • 5. 遡及の可否は項目ごとに違う。ある項目は遅く申請しても一部が遡り、ある項目はそうでない。「あとでまとめて受け取ればよい」は危うい仮定であり、申請窓口で項目ごとに確認する必要がある
  • 6. 確認は他人の要約ではなく公式の窓口で。制度が毎年変わるため、検索で出てきた要約が昨年基準である可能性が常にある。日付が書かれていない要約は信頼の対象ではない

8. 自治体の支援 - 全国基準というものがない

国の制度とは別に、地方自治体が独自に運営する支援がある。ここで必ず押さえるべき構造がひとつある。自治体の支援には全国共通の基準がない。項目も、金額も、申請窓口も、資格要件も地域ごとに異なる。

だからこの記事は特定の地域の金額を例として挙げない。ある地域の数字を書き写した瞬間、それを読んだ別の地域の人が「うちもそれくらい出るのだろう」と誤解するからである。これは助けではなく害である。

  • 確認は住民登録上の居住地を基準に行う。市郡区役所のサイトで出産または養育の項目を探すのが最も確実である
  • 福祉路で地域を指定して検索する方法もある。国の制度と地域の制度をひとつの画面でざっと見られる
  • 引っ越すときが最も危ない。前の地域にあった項目が新しい地域にはなかったり、新しい地域にしかない項目を知らずに通り過ぎたりする。転入届を出すついでに一度ざっと見ること
  • 自治体の項目には居住期間の要件が付く場合がありうる。申請資格と期限を一緒に確認する必要がある
  • 同じ名前の支援でも国の制度と自治体の制度が別でありうる。名前だけ見て「すでに受けているもの」と流さないこと

9. 時期別の申請手続きチェックリスト

ここまでの内容を時点の順に並べ直した。この一覧をそのまま持って窓口に行くことがこの記事の使い方である。下のコピーできる資料にも同じ内容が入っている。

9.1 妊娠を確認した直後

  • 妊娠・出産診療費支援を申請し、使用開始日と終了日をカレンダーに書く
  • 多胎かどうかと分娩取扱いの手薄な地域に当たるかを申請段階で伝える
  • 在職中なら妊娠期の労働時間短縮が使えるかを会社に確認する

9.2 出産予定日より前

  • 産前産後休暇と育児休業の計画を会社と整理し、一括申請の可否を確認する
  • 夫婦で育児休業をどう分けるか決める。期間延長の要件と直結する
  • 配偶者出産休暇の日数と申請期限を機関に確認する

9.3 出生届の時点 (最も重要)

  • 出生届と同時に申請できる項目を一度に処理する
  • 児童手当と親給付を申請する
  • 初対面に関する支援の該当有無と金額を窓口で確認する
  • 居住自治体の出産関連項目を別に確認する

9.4 乳幼児期とその後

  • 親給付を現金で受け取るかバウチャーで受け取るか決める
  • 施設の利用を始めるときや辞めるときに変更届を出す
  • 口座変更や引っ越しがあれば支給情報を更新する
  • 年の初めにその年の変更点を一度確認し、年末調整で子ども関連の控除をもれなく反映する

# 育児費用と公的支援 — 時期別の申請チェックリスト

出典: braindetox.kr
適用範囲: 韓国の制度のみ。他国の制度を説明するものではない。
整理時点: 2026-07-31
性格: 情報提供のための要約であり、助言でも受給資格の判定でもない。個別の要件、最終的な金額、申請可否は必ず担当機関で確認すること。
警告: 以下の数字は整理時点の公式資料に基づく。金額と年齢要件は毎年変わる。

## 0. 五つの原則

1. 韓国の育児支援はほとんどが申請主義である。資格があることと受け取ることは別である。
2. 期限がある。期限を過ぎると遡って支給されない項目がある。
3. 金額と年齢要件は毎年変わる。暗記せず、確認する時期を決めておく。
4. 国の制度と自治体の制度は別である。自治体の項目は地域ごとに異なる。
5. 金額を覚えるより、いつ何を確認すべきかを知るほうが長く役に立つ。

## 1. 時期別の申請チェックリスト

### 1-1. 妊娠が確認された直後

- [ ] 健康保険の妊娠・出産診療費支援を申請した
- [ ] 多胎妊娠であることを申請段階で伝えた
- [ ] 分娩取扱いが手薄な地域に該当するか確認した
- [ ] 使用開始日と使用終了日をカレンダーに書いた (期間内の未使用分は消滅する)
- [ ] 資料によって終了日の表記が異なるため、公団に直接確認した
- [ ] 就業中であれば、妊娠期の労働時間短縮が使えるか会社に確認した

### 1-2. 出産予定日より前

- [ ] 産前産後休暇と育児休業の使用計画を会社と整理した
- [ ] 出産休暇と育児休業をまとめて申請する方法を確認した
- [ ] 配偶者出産休暇の日数と申請期限を機関に確認した
- [ ] 夫婦で育児休業をどう分けるか決めた (取得可能期間に影響する)
- [ ] 雇用保険の被保険期間など、給付の受給要件を確認した

### 1-3. 出生届の時点 — ここが最も重要である

- [ ] 出生届と同時に申請できる項目を一度に処理した
- [ ] 児童手当を申請した
- [ ] 親給付を申請した
- [ ] 初対面利用券の該当有無と金額を機関に確認した
- [ ] 居住自治体の出産関連支援項目を別途確認した
- [ ] 各項目の申請期限と遡及の規定をメモした

### 1-4. 生後0か月から23か月

- [ ] 親給付を現金で受け取るか保育バウチャーで受け取るか決めた
- [ ] 保育施設の利用を開始または中止する際に支援方式の変更を届け出た
- [ ] 児童手当が毎月正常に支給されているか確認した
- [ ] 口座変更や転居があった場合に支給情報を更新した

### 1-5. 満2歳以降から就学前まで

- [ ] 保育施設、幼稚園、家庭保育のどれかによって支援項目が変わることを確認した
- [ ] 施設を利用しない期間に該当する支援項目を確認した
- [ ] 施設の利用開始や退所の際に変更届を出した
- [ ] 子育て支援サービスの利用資格と自己負担の基準を確認した

### 1-6. 毎年繰り返すこと

- [ ] 年の初めにその年の変更点を一度確認した
- [ ] 年末調整で子ども関連の控除項目をもれなく反映した
- [ ] 医療費の資料が国税庁の簡素化資料から漏れていないか確認した
- [ ] 転居した場合は自治体の支援項目を確認し直した
- [ ] 子どもの年齢が変わることで新たに生じる項目と消える項目を確認した

## 5. よくある五つの失敗

1. 出生届だけ出して、児童手当や親給付の申請を別途行わなかった場合
2. 診療費のバウチャーを期限内に使い切れず消滅させた場合
3. 保育施設に通い始めたのに支援方式の変更届を出さなかった場合
4. 転居した後に新しい自治体の支援項目を確認しなかった場合
5. 昨年基準の金額をそのまま信じて今年の計画を立てた場合

## 6. 免責

この文書は情報提供を目的とする。法律、税務、行政の助言ではない。すべての金額と要件は整理時点の公式資料に基づくものであり、その後変更されうる。実際の支給の可否と金額は、所得、世帯構成、居住地、雇用形態、申請時期によって異なる。申請の前に必ず担当機関で確認すること。

よくある質問

韓国の育児支援金は申請しなくても自動で支給されるのか?

おおむねそうではない。韓国の育児関連支援はほとんどが申請主義で運営される。出生届を出したからといって現金給付が自動的についてくるわけではない。例外はある。保健福祉部の2026年4月23日の資料によれば、児童手当の拡大時にすでに受け取っていた世帯には別途の申請なしに支給された。ただしこれは受給中の人に適用された例外である。

韓国の児童手当は2026年に何歳まで受け取れるのか?

同じ資料を基準に2026年は9歳未満で、以後毎年一歳ずつ上がり2030年には13歳未満まで拡大される。金額は居住地域によって首都圏の月10万ウォンから人口減少地域の特別地域の月12万ウォンまで分かれる。この数字は整理時点の基準なので申請の前に再確認すること。

韓国の親給付は保育施設に通っても受け取れるのか?

保健福祉部の案内上現金またはバウチャーから選ぶ仕組みなので、支援がなくなるのではなく形が変わる。重要なのは変更届である。利用を始めるときや辞めるときに届け出ないと金額がずれたり、後で精算の問題が生じたりしうる。細かい取り扱いは福祉路や住民センターで確認すること。

韓国の育児休業給付はいくら支給されるのか?

雇用労働部の2025年1月1日施行の基準で1から3か月は月250万ウォン、4から6か月は月200万ウォン、7か月目以降は月160万ウォンが上限で、事後支給金は廃止された。これは上限額であって受取額ではない。実際の金額は通常賃金と個人別の算定基準によって変わり、雇用保険に関する要件も別にある。

韓国の自治体の支援金はどこで確認するのか?

住民登録上の居住地の市郡区役所のサイトが最も確実で、福祉路で地域を指定して検索することもできる。自治体の支援は地域ごとに項目と金額が異なり全国基準が存在しない。特に引っ越し直後に確認を落としやすいので、転入届のときに一緒にざっと見ておくこと。
