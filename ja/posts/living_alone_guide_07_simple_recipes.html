料理できなくても作れる生存料理

毎日デリバリーするとお金が...

一人暮らし始めた頃、料理できないからって毎日デリバリー頼んでました。1ヶ月後のクレジットカード請求見てびっくり。だから無理やり料理始めたら、思ったより簡単でした。

今日は本当に料理できない人でも作れる超簡単レシピを共有します。お湯を沸かせれば全部できます。

1. 卵料理3種

卵さえあれば何でもできます。

目玉焼き（5分）

材料：卵、油、塩

  1. フライパンに油を少し入れる
  2. 弱火で予熱（1分）
  3. 卵を割り入れる
  4. 塩を少々振る
  5. 白身が固まったら完成（黄身はお好みで）

コツ：火が強いと端が焦げます。弱火がポイント！

スクランブルエッグ（5分）

材料：卵2個、牛乳少々、塩、バター（なければ油）

  1. 卵＋牛乳＋塩を混ぜる
  2. 弱火でバターを溶かす
  3. 卵液を入れて箸でずっとかき混ぜる
  4. 半熟で火を止める（余熱で完成）

コツ：火を通しすぎるとパサパサに。しっとりしてるうちに止めて。

茶碗蒸し - レンジ版（5分）

材料：卵2個、水または出汁100ml、塩

  1. 器に卵＋水＋塩をよく溶く
  2. ラップして爪楊枝で穴を数カ所開ける
  3. 電子レンジ2分30秒（700W基準）
  4. 足りなければ30秒ずつ追加

2. ご飯もの

卵かけご飯（5分）

材料：ご飯、卵、醤油、ごま油、海苔

  1. 熱々ご飯に卵をのせる
  2. 醤油大さじ1、ごま油少々入れる
  3. 混ぜる
  4. 海苔をかければ完成

コツ：ネギを刻んで入れるともっと美味しい。

ツナマヨ丼（5分）

材料：ご飯、ツナ缶、マヨネーズ、醤油、海苔

  1. ツナの油を切る
  2. ツナ＋マヨ大さじ2＋醤油少々を混ぜる
  3. ご飯の上にのせる
  4. 海苔をかければ完成

チャーハン（10分）

材料：ご飯、卵、ネギ、醤油、油

  1. フライパンに油を入れてネギを炒める
  2. 卵を入れてスクランブル
  3. ご飯を入れて一緒に炒める
  4. 醤油で味付け

コツ：冷蔵庫の残り物何でも入れてOK。

3. 麺料理

インスタント麺アレンジ（10分）

基本＋α

  • 卵：麺が茹で上がったら卵を溶き入れる
  • チーズ：火を止めてチーズをのせる
  • ネギ：刻んで入れる
  • 餅：最初から一緒に茹でる

辛い和え麺（10分）

材料：そうめん、コチュジャン、酢、砂糖、ごま油

  1. そうめんを茹でて冷水で洗う
  2. コチュジャン大さじ2＋酢大さじ1＋砂糖大さじ1＋ごま油を混ぜる
  3. 麺と和える
  4. 半熟卵をのせるともっと美味しい

4. 汁物

卵スープ（10分）

材料：卵2個、水2カップ、だしの素、塩、ネギ

  1. 水＋だしの素を沸かす
  2. 沸騰したら溶き卵をゆっくり入れる
  3. 塩で味付け
  4. ネギを入れて完成

キムチチゲ - 超簡単版（15分）

材料：キムチ1カップ、豚肉少々（なくてもOK）、豆腐、水、粉唐辛子

  1. 鍋に油を入れてキムチを炒める
  2. 肉があれば一緒に炒める
  3. 水2カップ入れて沸かす
  4. 豆腐を入れて5分
  5. 粉唐辛子少々入れるともっと美味しい

コツ：古くて酸っぱいキムチほど美味しい。

5. おかず・おやつ

卵焼き（10分）

材料：卵3個、塩、ネギ（お好みで）

  1. 卵＋塩＋ネギを混ぜる
  2. 弱火で油を入れる
  3. 卵液の1/3を入れて薄く広げる
  4. 半熟で巻く
  5. 端に寄せて残りの卵液を入れる
  6. 繰り返す

トースト（5分）

材料：食パン、バター、卵、チーズ

  1. フライパンでバターを溶かす
  2. パンを入れて両面焼く
  3. スクランブルエッグを作ってのせる
  4. チーズをのせて完成

6. 買い物必須アイテム

これがあれば上の料理全部作れます。

冷蔵庫

  • 卵（必須！）
  • ネギ
  • キムチ
  • 豆腐
  • ツナ缶

冷凍庫

  • 冷凍ご飯 or パックご飯
  • 冷凍野菜ミックス

常温保存

  • インスタント麺
  • そうめん
  • 醤油、ごま油
  • コチュジャン
  • だしの素
  • 海苔

7. 料理のコツ

  • 弱火が基本：強火は初心者の敵。焦げやすい
  • 味付けは最後に：最初に濃くすると修正不可
  • 卵は万能：何にでも卵を入れれば美味しくなる
  • すぐ洗い物：料理終わったらすぐ洗わないとこびりつく
  • 失敗してもOK：最初はみんなそう。練習すれば上手くなる

まとめ

料理は思ったより難しくないです。デリバリー代を考えたらやってみる価値あり。まずは目玉焼きから始めてみて！
