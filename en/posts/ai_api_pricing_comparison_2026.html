Introduction: Pricing Is Architecture

In 2026, choosing an AI model is no longer just about "which one is smartest." Build the same feature on two different APIs and the monthly bill can differ by more than 10x. For high-volume workloads - B2B products and startups especially - the per-million-token rate sets your unit economics, and unit economics decide whether the business survives.

Below, the major LLM API prices as of September 29, 2026, taken from each provider's official pricing page, are gathered into one table split by input and output, followed by the other axes that matter: context window, multimodal support and caching discounts. After that come use-case candidates across three lanes - top performance, best value, and open - and practical tips for cutting cost with caching and routing.

Pricing disclaimer (important): Every figure below is the value on each provider's official pricing page as of September 29, 2026. LLM API rates change frequently - quarterly or monthly - and vary by promotion, region and tier, with cache and batch discount structures differing per model. The table mixes in time-limited rates with stated end dates (GPT-5.6 Sol through at least November 21, 2026; Gemini 3.8 and 3.7 Flash through December 31, 2026) and rates that double by time of day (DeepSeek), so even one row can bill differently depending on when you call it. Before any real adoption or quote, check the latest rates on each provider's official pricing page again. The rates here are a starting point for decisions, not a basis for contract pricing.

2. Beyond Price - Context, Multimodal, Caching

Rates alone tell half the story. Real cost and fit diverge along three more axes.

2.1 Context Window and the "Long-Context Premium"

The context window is how much input fits in one request. Watch the long-context premium: at OpenAI, the three GPT-6 models as well as GPT-5.6 and GPT-5.5 move to 2x input and cache and 1.5x output once input passes 272K ($4.00/$15.00 on GPT-6 Sol). Gemini 3.1 Pro rises to $4.00/$18.00 above 200K, and Grok 4.7 to $4.00/$12.00 at 200K and above. Anthropic, by contrast, states on its pricing page that Claude 4.6 and later models bill the full one-million-token context at the standard rate. If your workload feeds whole long documents, this premium structure drives your effective rate - quote from the first two columns alone and the real bill can come in close to double.

2.2 Multimodal Support

Irrelevant if you handle text only, but decisive for images, audio and documents. Gemini 2.5 Flash takes text, image and video input at $0.30 and audio input at $1.00, making it strong value for multimodal. The three GPT-6 models and GPT-5 mini also take text and image input. Image tokens are billed separately, and high-resolution inputs can consume far more tokens, so never estimate multimodal cost from the text rate alone.

2.3 Caching Discounts and Speed

For workloads that resend the same prefix (system prompt, long reference docs, tool definitions), prompt caching cuts cost sharply. The size of the discount and the rules differ by vendor. Anthropic bills a cache hit at 0.1x base input, but 0.05x on Opus 5.5 and 0.025x on Fable 5.1, and adds 1.25x for a 5-minute cache write and 2x for a 1-hour write. OpenAI bills cached input at 10% of list and cache writes at 1.25x (on GPT-6). Google's Gemini 3.8 Flash cached input is $0.075, 10% of list, but carries a separate storage fee of $0.50 per million tokens per hour. xAI Grok 4.7 bills cached input at 25% of list, DeepSeek V4.1 Flash at about 2% and GLM-5.3 at about 19%. Batch processing is 50% of standard at Anthropic, OpenAI and Google alike. Where low latency matters for real-time UX, small fast models like Haiku 4.5, Gemini 2.5 Flash and GPT-5 mini win. Speed and price usually move together - smaller, cheaper models tend to be faster.

3. Use-Case Picks - Top Performance vs Value vs Open

The answer is not a single model but per-workload placement. Three lanes.

3.1 Top Performance - Complex Reasoning, High-Stakes Code

Where accuracy is trust and mistakes are expensive - production migrations, security-sensitive code, long-horizon autonomous agents - flagships are the safe choice. Anthropic suggests starting most workloads on Claude Opus 5.5 ($4.00 input / $20.00 output) and using Claude Fable 5.1 ($10.00 input / $50.00 output) for demanding reasoning and long-horizon agent work. OpenAI describes GPT-6 Astra ($10.00 input / $50.00 output) as its top model for the hardest work, and the previous-generation GPT-5.6 Sol is on a promotional $4.00 / $20.00. Higher still is the security-research model GPT-5.6 Cyber ($12.50 input / $75.00 output). Output is pricey, so agent workloads with frequent long outputs need a cap to stop token runaway. Claude Sonnet 5.5 and GPT-6 Sol are both $2.00 input / $10.00 output, the low-rate end of the top tier and a balance point when you need high performance but are cost-sensitive.

3.2 Best Value - High Volume, Real-Time Replies

Low-difficulty, high-volume tasks - classification, summarization, extraction, structured replies - belong on small, cheap models. Among the major closed models, GPT-6 Luna ($0.10 input / $0.50 output) is the low end of this table, followed by GPT-5.6 Luna ($0.20 input / $1.20 output), Gemini 3.5 Flash-Lite ($0.30 input / $2.50 output) and Gemini 3.8 Flash ($0.75 input / $3.75 output) - though the 3.8 Flash rate holds only through December 31, 2026 and doubles the following year. From earlier generations, Gemini 2.5 Flash ($0.30 input / $2.50 output) and GPT-5 mini ($0.25 input / $2.00 output) are still on the price lists. Claude Haiku 4.5 ($1.00 input / $5.00 output) suits low-latency real-time UX, but Anthropic has announced a successor, Haiku 5.5, for "the coming weeks", and Haiku 4.5's retirement is only promised as not sooner than October 15, 2026. Among the Grok models, 4.3 is $1.25 input / $2.50 output and 4.7 is $2.00 input / $6.00 output.

3.3 Open-Weight - Lowest Cost, Data Control

If you want the cost floor or can't send data outside, open-weight models are attractive. DeepSeek V4.1 Flash sits near the floor at $0.15 input / $0.60 output off-peak on its hosted API, but doubles to $0.30 / $1.20 during peak hours - so "the cheapest model" is not true around the clock. Requests sent to the old model name deepseek-v4-flash are also served by V4.1 Flash at the same rate. The GLM family prices 5.3 and 5.1 identically at $1.40 input / $4.40 output, and the small GLM-5.3-Flash is $0.15 / $0.50. Kimi K2.7 Code is $0.95 input / $4.00 output with a 262,144-token context, and the larger Kimi K3 is $3.00 / $15.00 with a 1,048,576-token context. The real open-weight advantage - self-hosting - carries GPU capital and operations overhead, so a cheap hosted rate and cheap self-hosting are separate break-even calculations.

4. Practical Cost-Cutting Tips

Even on the same model, design can cut cost substantially.

4.1 Bake Prompt Caching In From the Start

Put unchanging prefixes - system prompt, tool definitions, long reference docs - first, and the per-request question last, to raise cache hit rate. Caching is prefix-matched, so a single timestamp or UUID slipped into the front breaks the cache. For chatbots, RAG and agents with a repeated fixed context, caching alone cuts input cost sharply. With vendors that charge extra to write the cache (Anthropic, OpenAI) or charge for storage (Google), a cache used once and thrown away can end up costing more.

4.2 Model Routing - Cheap for Easy, Pricey for Hard

Sending every request to a flagship is the most common waste. Add a difficulty classifier, route easy work to small models like GPT-6 Luna, Gemini 3.5 Flash-Lite or Haiku 4.5, and reserve the flagship for complex reasoning and high-stakes work; average rates drop fast. A provider-agnostic gateway turns a price-driven model swap into a config change rather than a rewrite.

4.3 Trim Output and Use Batches

Output is 3 to 6 times pricier than input, so trimming needlessly verbose output alone reduces cost. Use structured output (JSON schema) to cut filler, and lower the effort level on models that over-emit reasoning tokens to control invisible output. Latency-tolerant bulk work goes through batch APIs (50% off at Anthropic, OpenAI and Google), halving the rate.

5. Conclusion - Judge by Effective Cost, Not the Sticker Table

The 2026 LLM market is bipolar: flagships fight for performance at the top while small and open models collapse rates at the bottom. The late-September generation change points the same way — Claude Opus 5.5 launched cheaper than Opus 5, and GPT-6 Luna at half the rate of GPT-5.6 Luna. The point is not to memorize a single rate table but to compare effective cost - each rate multiplied by your own input-to-output ratio and cache hit rate. The same "$5 per million" produces a wildly different bill for a cache-friendly RAG versus an agent whose reasoning tokens run away.

Three concrete moves this week: first, measure the real input and output tokens of 100 representative requests and compute the effective rate per model. Second, apply caching to fixed prefixes and verify the hit rate. Third, add a gateway that routes easy work to small models and shrinks your flagship share. And above all, remember that every rate on this page is as of September 29, 2026 and shifts with promotions and timing - check the official pricing page again before any quote.

# LLM API Cost Estimate Checklist — Before a Rate Table Becomes an Invoice

As of: 2026-09-29

> Source: braindetox.kr — 2026 AI API Pricing Comparison
> Rates are from each provider's official pricing page (USD per million tokens) and change often. Reopen the official page before quoting.

## 1. Before picking candidate models

- [ ] Measured the real input and output tokens of 100 representative requests
- [ ] Computed the input:output ratio (summarization and extraction lean input; code and agents lean output)
- [ ] Checked the maximum input length — see whether it crosses the thresholds in section 2
- [ ] Checked whether the same prefix repeats (caching candidate)
- [ ] Separated out work that does not need an immediate answer (batch candidate)

## 2. Long-context thresholds — cross them and the rate changes

| Vendor | Threshold | Once crossed |
|---|---|---|
| OpenAI (GPT-6, GPT-5.6, GPT-5.5) | Input above 272K | Whole request at 2x input and cache, 1.5x output |
| Google (Gemini 3.1 Pro, 2.5 Pro) | Prompt above 200K | Tiered rate (3.1 Pro $4.00/$18.00) |
| xAI (Grok 4.7, 4.3) | Prompt at 200K and above | Long-context rate on every token of the request |
| Anthropic (Claude 4.6 and later) | None | Full 1M context at the standard rate |

## 3. Cache rules — they differ by vendor

| Vendor | Cache hit (read) | Cache write and storage |
|---|---|---|
| Anthropic | 0.1x base input (Opus 5.5 0.05x, Fable 5.1 0.025x) | 1.25x for 5 min · 2x for 1 hour |
| OpenAI | 10% of list | Writes 1.25x (GPT-6) |
| Google | Gemini 3.8 Flash $0.075 (10% of list) | $0.50 per million tokens per hour storage |
| xAI | Grok 4.7 25% of list | — |
| DeepSeek | V4.1 Flash about 2% ($0.003) | — |
| Z.ai | GLM-5.3 about 19% ($0.26) | Storage "limited-time free" |

- [ ] Not creating single-use caches with a vendor that charges extra to write the cache
- [ ] No timestamp or UUID near the front of the prefix breaking the cache

## 4. Time-limited and time-of-day rates

- [ ] GPT-5.6 Sol $4.00/$20.00 — promotional through at least 2026-11-21. Budgeted for the later rate as well
- [ ] Gemini 3.8 and 3.7 Flash $0.75/$3.75 — through 2026-12-31, then $1.50/$7.50 from 2027-01-01
- [ ] DeepSeek — doubles at peak (UTC Mon-Fri 01:00-04:00, 06:00-10:00). Real-time services costed at the peak rate
- [ ] Announced-only models (Claude Haiku 5.5) kept out of the budget

## 5. Batch and routing

- [ ] Batchable work sent through the 50% discount route (Anthropic, OpenAI and Google batch; OpenAI and Google Flex)
- [ ] A rule routes easy work to small models (GPT-6 Luna $0.10/$0.50, Gemini 3.5 Flash-Lite $0.30/$2.50, Haiku 4.5 $1.00/$5.00 and so on)
- [ ] Abstracted behind a gateway so a model swap is a config change

## 6. Effective-rate formula

```
monthly cost = (monthly input tokens × (1 − cache hit rate) × input rate
              + monthly input tokens × cache hit rate × cache rate
              + monthly output tokens × output rate) × (1 + retry rate)
```

- Recompute any request that crosses a long-context threshold at the long-context rate for the whole request
- Compute the batched share separately at that vendor's batch rate

## 7. When to recompute

- When a vendor ships a new model or tier (such as the announced Claude Haiku 5.5)
- When a time-limited rate expires (2026-11-21, 2026-12-31)
- When a retirement date is announced for a model you use (Claude Haiku 4.5: not sooner than 2026-10-15)
- When a model leaves the price list or is renamed (as with DeepSeek V4 Flash to V4.1 Flash)
