はじめに：ログ、サーバーのブラックボックス

ログはサーバーで起こる全てを記録します。トラブルシューティング、セキュリティ監査、パフォーマンス分析に必須です。

1. 主要ログファイル

/var/log/syslog        # システムログ
/var/log/auth.log      # 認証ログ
/var/log/kern.log      # カーネルログ

2. journalctl

journalctl -f           # リアルタイム
journalctl -u nginx     # サービスログ
journalctl -p err       # エラー優先度

3. logrotate

/var/log/nginx/*.log {
    daily
    rotate 14
    compress
}

4. リアルタイムモニタリング

tail -f /var/log/syslog | grep -i error

まとめ

ログ管理とモニタリングはサーバー運用の核心です。次回はバックアップと復旧戦略を解説します。
