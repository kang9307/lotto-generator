この記事は、Microsoftのイーサネット問題解決文書、Intelのサポート文書(000038520・000058908・000005593)、TIA-568のケーブル規格の要約で確認できた内容だけを扱い、範囲は有線LANの接続不可と100Mbps固定の診断です。

出発点 - ケーブルか、PCか、ルーターのポートか

有線接続の問題は、原因がケーブル、PCのアダプター、ルーターのポート、その先のモデムや通信事業者のどこにあるのかを切り分けることから始まります。Microsoftのイーサネット問題解決文書は、この切り分けをルーター側、PC側、別のPCの3つの区域に分けて案内しています。文書は有線接続を、自宅のルーターにケーブルの一方を、PCのイーサネットポートにもう一方を差して高速なインターネット接続を得る方法として紹介し、PCにイーサネットポートがなければUSBイーサネットアダプターを検討できると書いています。

文書がルーター側で最初に見るよう求めているのは、ケーブルとポートです。イーサネットケーブルがルーターとPCの両方のイーサネットポートにしっかり差さっているか確認し、ルーター側ではモデムを繋ぐインターネットポートではなく通常のイーサネットポートに差しているかを確認します。ケーブル1本で繋がらず、近くに別のケーブルがあるなら替えて試し、繋がれば最初のケーブルに問題がある可能性があると文書は述べています。ルーターがWi-Fiに対応しているなら、Wi-Fiで接続してみるという案内もあり、インターネット接続を得ると同時に問題の根源を絞り込める方法だと説明しています。

最後の区域は別のPCです。自宅に別のWindows PCとUSBイーサネットアダプターがあれば、そのPCで同じネットワークに接続してみます。繋がれば原因は最初のPC側にある可能性が高く、どちらのPCもイーサネットに繋がらなければ、ルーター、通信事業者、USBイーサネットアダプターのいずれかに問題があるかもしれないと文書は説明しています。

  • ケーブル両端の確認: ルーターとPCのイーサネットポートにしっかり差さっているか確認します(Microsoft)。
  • ポートの種類の確認: ルーターでモデム接続用のインターネットポートに差していないか確認します(Microsoft)。
  • 別のケーブルでの試験: 別のイーサネットケーブルで繋がるなら、最初のケーブルに問題がある可能性があります(Microsoft)。
  • Wi-Fiや別のPCとの比較: 同じルーターにWi-Fiで接続するか、別のPCから接続して、問題の場所を絞ります(Microsoft)。

速度の測定結果から問題を絞る方法は、インターネット速度測定ガイドで扱っています。この記事は、ケーブル規格と点検の手順に絞ります。

0段階 - 接続状態の確認とモデム・ルーターの再起動

PCでまず見るのは、設定のネットワークとインターネット画面の最上部に表示されるイーサネットの接続状態です。Microsoftの文書は、Windows 11では名前の下に接続済みと表示されるはずで、Windows 10ではネットワーク接続の下にインターネットに接続されていますと表示されるはずだと書いています。操作が必要などのエラーが出ていれば、イーサネットを選んでイーサネットの接続設定を確認するよう案内しています。

同じ文書は、ルーター側の点検としてモデムと無線ルーターの再起動も挙げています。ルーターとモデムの電源コードを抜き、モデムにバックアップ電池があって表示灯がついたままなら電池を外し、最低30秒程度待ちます。その後モデムを先に差して表示灯の点滅が止まるのを待ち、ルーターを差して、数分後に2台が完全に起動したらPCからイーサネットで再び接続します。この順序と待ち時間はMicrosoft文書の記述であり、他のメーカーの文書では電源を入れる順序や待ち時間が異なる場合があります。ケーブルモデムとルーターが一体になった機器は、その1台だけを同じ手順で再起動します。

  • Windows 11の正常な表示: ネットワークとインターネット画面で、イーサネット名の下に接続済みと表示されます。
  • Windows 10の正常な表示: ネットワーク接続の下にインターネットに接続されていますと表示されます。
  • エラー表示: 操作が必要などの文言があれば、イーサネットを選んで設定を見ます。
  • 再起動の順序: 文書によれば、モデムを先に接続し、表示灯が止まったらルーターを接続します。

ポートLEDの読み方 - 色の意味は機種ごとに異なる

LANポートの点灯は、リンクが確立されたかどうかと、どの速度で確立されたかを示しますが、色と意味の対応はメーカーと機種によって異なります。Intelのサポート文書がEthernet Server Adapter I210-T1について記している内容を、下の表に写します。この表はそのアダプターの説明であり、他のアダプターやルーター・スイッチのポートにそのまま当てはめる根拠にはなりません。

LED状態I210-T1文書での意味
リンク/アクティビティ消灯リンクなし(No Link)
リンク/アクティビティ点灯リンクあり(Link)
リンク/アクティビティ点滅通信中(Activity)
速度点灯しない10Mb/s
速度緑100Mb/s
速度黄色(アンバー)1Gb/s

この表では、緑が100Mb/s、アンバーが1Gb/sです。緑ならギガビットという一般則はこの文書では確認できず、このアダプターではむしろ逆です。したがってLEDの色だけで速度を断定せず、該当する機器の取扱説明書で色と速度の対応を調べる必要があります。

  • リンク/アクティビティLED: 消灯はリンクなし、点灯はリンクあり、点滅は通信中です(I210-T1)。
  • 速度LED: 点灯しなければ10Mb/s、緑なら100Mb/s、アンバーなら1Gb/sです(I210-T1)。
  • 機種ごとの違い: 同じ色が別の機種では別の速度を意味することがあるため、取扱説明書を見ます。
  • 色だけでの断定は避ける: 色と速度の対応は、該当する機器の取扱説明書で確認します。

症状1 - 1Gbpsが100Mbpsに固定されるとき

ギガビット回線なのにリンクが100Mbpsにとどまる症状について、Intelのサポート文書(000058908)は、ケーブルの問題が最も多いと説明しています。文書の表現では、不良になったCat5eやCat6ケーブルも、たいてい100Mbpsでは動作し続けます。椅子のキャスターで轢いたり踏んだりしたケーブルのように、物理的な損傷が性能を落とし得るという例も文書にあります。

文書が示す対処は3つの方向に分かれます。1つ目は、ケーブルをCat6以上に交換することです。各ケーブルにCat6またはCat7と表記されているか確認し、コネクターがカチッと音がするほどしっかり差さっているかを見ます。2つ目は、アダプターの設定です。デバイスマネージャーの詳細設定タブでSpeed & Duplexを自動ネゴシエーション(Auto Negotiation)にしておきますが、文書はギガビット速度ではこれが正しい設定だと述べています。3つ目は、機器側です。アクセスポイント、ハブ、スイッチ、ルーターの別のポートに差し替え、ネットワーク機器の電源を入れ直します。

最後に、コンピューターをモデムに直接つないで試す方法があります。文書は動作が確認済みのCat6ケーブルで直結するよう案内し、その目的を、中間の機器やケーブルが問題に関わっているかを切り分けることだと説明しています。

  • ケーブルの交換: 不良ケーブルでも100Mbpsでは動くことがあるため、Cat6以上のケーブルに替えて試します。
  • ケーブル表記の確認: 各ケーブルにCat6またはCat7と印字されているか見ます。
  • コネクターの差し込み: カチッと音がするほどしっかり差し込みます。
  • 自動ネゴシエーション: デバイスマネージャーの詳細設定タブでSpeed & Duplexが自動ネゴシエーションか見ます。
  • 別のポートと直結の試験: ルーターやスイッチの別のポートを使い、確認済みのケーブルでモデムに直結して試します。

ケーブル規格 - Cat5e・Cat6・Cat6aの違い

ケーブルの規格は、対応する帯域幅と、10ギガビットイーサネット(10GBASE-T)をどこまでの距離で運べるかで区別されます。下の表は、TIA-568の要約で確認した値です。規格の本文は有料の文書で、直接開いて確認することはできなかったため、この表が要約の水準であることを断っておきます。

規格最大帯域幅1000BASE-T10GBASE-T
Cat5e100MHz100mまで対応公式サポートなし
Cat6250MHz100mまで対応一般的な環境で最大55m
Cat6a500MHz100mまで対応100m全区間

長さの上限はチャンネル全体に適用される値です。100mは、建物の壁の中の永久リンク90mと、両端のパッチコードの合計10mを足した値として要約されています。表の値だけを見れば、3つの規格はいずれも1000BASE-Tを100mまでサポートするため、規格上の違いがはっきり現れるのは10GBASE-Tです。家庭で1Gbpsを使うだけなら、Cat5eでも規格上は足りるというのが表の意味であり、それでもIntelの文書が交換先にCat6以上を勧めているのは、不良になったケーブルの事例に基づく案内です。

  • Cat5e: 最大100MHzで、1000BASE-Tは100mまで対応しますが、10GBASE-Tは公式にはサポートされません。
  • Cat6: 最大250MHzで、10GBASE-Tは一般的な環境で最大55mまで対応します。
  • Cat6a: 最大500MHzで、10GBASE-Tを100m全区間でサポートします。
  • チャンネルの長さ: 永久リンク90mとパッチコード10mを合わせた100mが上限です。

症状2 - 接続そのものができないとき Windows文書の手順

ケーブルを替えても接続できないなら、PC側のソフトウェアを見ます。Microsoftの文書は、Windows 11ではまずGet Helpアプリのネットワークとインターネットのトラブルシューティングツールを、Windows 10では設定のネットワークとインターネット、状態にあるネットワークのトラブルシューティングツールを実行するよう案内しています。その後の手順は、影響の小さいものから大きいものへの順です。

1つ目はコマンドです。管理者権限のコマンドプロンプトでnetsh winsock reset、netsh int ip reset、ipconfig /release、ipconfig /renew、ipconfig /flushdnsをこの順に実行し、問題が解決したかを見ます。文書は、これらのコマンドがTCP/IPスタックを手動でリセットし、IPアドレスを解放して更新し、DNSクライアントのキャッシュを消去するものだと説明しています。2つ目は、イーサネットアダプターのドライバーの削除です。デバイスマネージャーのネットワークアダプターからイーサネットアダプターを選んでデバイスのアンインストールを選び、このデバイスのドライバーを削除しようとするの項目にチェックを入れて再起動すると、Windowsが最新のドライバーを自動でインストールします。文書は、最近のアップデートの後に接続が止まった場合に検討するよう述べ、インターネットに出られないPCなら、別のPCでメーカーのドライバーを入手してUSBメモリーに入れておくよう注意しています。そのためには、PCのメーカーとモデル名または型番を知っている必要があります。ドライバーを削除してもWindowsが自動でドライバーをインストールしない場合は、事前に保存しておいたバックアップのドライバーをインストールします。

最後はネットワークリセットです。文書は、これを前の手順がすべて役に立たないときの最後の手段としています。インストール済みのネットワークアダプターとその設定を削除し、再起動後に既定値で再インストールするもので、Windows 11では設定のネットワークとインターネット、ネットワークの詳細設定、ネットワークのリセットから、Windows 10では状態、ネットワークのリセットから実行します。VPNクライアントやHyper-Vの仮想スイッチを設定し直す必要がある場合があり、既知のネットワークがパブリックのプロファイルに切り替わることがあるという副作用が、文書に書かれています。なお文書は、この方法がWindows 10から11へ更新した後の接続の問題や、インターネットには接続できるのに共有ネットワークドライブに接続できない問題にも役立つ場合があると述べています。

  • トラブルシューティングツール: Windows 11はGet Helpアプリから、Windows 10は設定の状態画面から実行します。
  • コマンドの順序: winsock reset、int ip reset、release、renew、flushdnsを順に実行します。
  • ドライバーの削除: デバイスのアンインストールでドライバー削除の項目にチェックを入れて再起動し、バックアップのドライバーを事前に入手しておきます。
  • ネットワークリセット: 最後の手段として使い、アダプターと設定が既定値に戻ります。
  • リセットの副作用: VPNや仮想スイッチの設定し直しが必要になることがあり、ネットワークがパブリックのプロファイルに変わることがあります。
  • Wi-Fiでの試験: ルーターがWi-Fiに対応していれば接続してみて、イーサネットだけの問題かを切り分けます。

アダプター設定と機器の点検 - 自動ネゴシエーションと別のポート

アダプターがネゴシエーションした速度と通信方式(デュプレックス)が合わないと、リンクが不安定になります。Intelの文書(000005593)には、デュプレックスの不一致を知らせるLINK_DUPLEX_MISMATCHというメッセージが載っており、その際はリンク速度タブで速度とデュプレックスの設定を適切に変更するよう案内しています。これはイベントログのメッセージの説明であり、この文書だけで、どの設定がどんなときに失敗するかを一般化することはできません。

Intelの文書(000058908)は、ギガビットではSpeed & Duplexを自動ネゴシエーションにしておくのが正しいと述べ、1.0 Gbps専用の項目が表示されるはずだという考えは誤解だと指摘しています。機器側では、ポートを替えて機器の電源を入れ直し、文書の表現どおりハブ、スイッチ、ルーターの別のポートを試します。機器を交換する前に、原因となっている要素を一度に1つずつ切り分けるべきで、これが両社の文書が共通して使っている方法です。

  • リンク速度タブ: デュプレックス不一致のメッセージが出たら、速度とデュプレックスの設定を確認します(Intel)。
  • 自動ネゴシエーションの維持: ギガビットではAuto Negotiationが正しい設定です(Intel)。
  • 設定の場所: Speed & Duplexの項目は、デバイスマネージャーのアダプターの詳細設定タブにあります(Intel)。
  • 別のポートと機器の再起動: ルーターやスイッチの別のポートを使い、機器の電源を入れ直します(Intel)。

点検手順のまとめ

ここまでの文書を合わせると、一度に1つだけ変える手順が見えてきます。費用が少なく元に戻しやすいものから始め、設定を消す段階は最後に置きます。下の手順は、この記事が文書の推奨を並べたものであり、1つの文書がこの順序をそのまま示しているわけではありません。

  • 1. ケーブルの両端とルーターのポートの種類(インターネットポートではないか)を確認します。
  • 2. 別のイーサネットケーブルに替えて試します。繋がれば、最初のケーブルに問題がある可能性があります。
  • 3. 設定のネットワークとインターネットで接続状態を見て、ルーターの別のポートに移してみます。
  • 4. モデムとルーターを再起動するか、モデムに直結して試します。
  • 5. Windowsのコマンド5つを順に実行し、必要ならドライバーを削除して再起動します。
  • 6. 最後にネットワークリセットを使い、その後VPNなどのソフトウェアを設定し直します。

確認できなかったこと

  • LEDの色とリンク速度の一般的な対応は確認できませんでした。Intelの文書で確認できたのは、I210-T1という1機種の値だけです。
  • Windowsで現在のリンク速度を見るメニューの経路は、Microsoftのイーサネット問題解決文書に出てこないため、確認できませんでした。
  • 1000BASE-Tと100BASE-TXがケーブルの何本の線を使うか、1本が断線すると速度がどうなるかは、開けた公式の出典では確認できませんでした。
  • ケーブルの最小曲げ半径、Cat6の内部の十字セパレーターの有無、外来クロストークのシールドの程度は、開けた公式の出典では確認できませんでした。
  • 速度を1.0 Gbpsに強制指定したときにネゴシエーションが失敗するかどうかは確認できませんでした。Intelの文書が述べているのは、自動ネゴシエーションが正しい設定だという点までです。
  • KTなど通信事業者の有線インターネット点検の案内は、本文を確認できる出典がないため、この記事の根拠から外しました。
  • TIA-568とIEEE 802.3の規格本文は直接開いて確認できず、規格ごとの値は要約の水準で確認しました。
