What is a subnet?

A subnet is a logical subdivision of an IP network. Subnetting lets you split one large network into several smaller ones, which improves network management and efficiency.

Key Terms

  • IP Address: An address used by the Internet Protocol - a unique number that identifies a device.
  • Subnet Mask: A value that distinguishes the network portion from the host portion of an IP address.
  • CIDR (Classless Inter-Domain Routing): A method of IP assignment expressed as a prefix length such as /24.
  • Network Address: The first address of a subnet, where all host bits are 0.
  • Broadcast Address: The last address of a subnet, where all host bits are 1.

How to Use the Subnet Calculator

  1. Enter a valid IPv4 address in the IP Address field (e.g., 192.168.1.0).
  2. Choose either CIDR notation or subnet mask to specify the network size:
    • CIDR: Pick an appropriate prefix length from the dropdown (e.g., /24).
    • Subnet Mask: Enter a valid subnet mask (e.g., 255.255.255.0).
  3. Click the "Calculate" button to see the results.

Interpreting the Results

  • Network Address: The starting address of the subnet.
  • Broadcast Address: The last address of the subnet.
  • Usable Hosts: The number of IP addresses that can be assigned within the network (excluding the network and broadcast addresses).
  • Host Range: The range of IP addresses that can actually be assigned to devices.
  • Binary: The binary representation of the IP address and subnet mask.
