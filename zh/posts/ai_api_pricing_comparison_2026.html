引言：价格就是架构

在2026年的AI开发中，选模型早已不只是「哪个最聪明」的问题。同一个功能，用哪家API，月账单可能相差10倍以上。尤其是B2B产品或初创公司这类调用量大的工作负载，每百万Token单价（per 1M tokens）直接决定单位经济性，而单位经济性决定业务能否活下去。

下面把2026年9月29日各厂商官方价格页上的主流LLM API价格按输入/输出拆开汇总成一张表，并一起看上下文窗口、多模态与缓存折扣这几条维度。随后按「最高性能 vs 性价比 vs 开源」三条路线筛出候选，再整理用缓存与路由压成本的实战技巧。

价格变动免责（重要）：以下所有数值均为2026年9月29日各厂商官方价格页上的数值。LLM API单价按季、按月频繁变动，因促销、地区与档位而不同，缓存与批处理折扣结构也因模型而异。表中混有写明截止日期的限时单价（GPT-5.6 Sol至少到2026年11月21日，Gemini 3.8与3.7 Flash到2026年12月31日）以及按时段翻倍的单价（DeepSeek），同一行在不同时间调用，账单也会不同。正式接入或报价前，务必在各厂商官方价格页再次核对最新单价。这里列出的单价是决策的起点，不是合同单价的依据。

2. 价格之外的维度 - 上下文·多模态·缓存

只看单价只看到一半。实际成本与适配度还要看下面三条维度。

2.1 上下文窗口与「长上下文溢价」

上下文窗口是一次请求能放进的输入量。要注意的是长上下文溢价。OpenAI的GPT-6三个模型以及GPT-5.6、GPT-5.5，输入一旦超过272K，输入与缓存变2倍、输出变1.5倍（GPT-6 Sol为$4.00/$15.00）。Gemini 3.1 Pro超过200K后涨到$4.00/$18.00，Grok 4.7在200K及以上涨到$4.00/$12.00。相反，Anthropic在价格文档中写明，Claude 4.6及以后模型的整个百万Token都按标准价计费。如果工作负载要整篇塞进长文档，这种溢价结构会左右有效单价——只看表的前两列报价，实际账单可能差到接近两倍。

2.2 多模态支持

只处理文本就无所谓，但要处理图像、音频、文档时，多模态支持会收窄选择。Gemini 2.5 Flash的文本、图像、视频输入为$0.30，音频输入为$1.00，多模态性价比好。GPT-6三个模型与GPT-5 mini也接受文本与图像输入。图像Token单独计算，高分辨率输入的Token消耗可能大增，因此多模态工作负载不能只按文本单价估算成本。

2.3 缓存折扣与速度

对于反复发送相同前缀（系统提示、长参考文档、工具定义）的工作负载，提示缓存能大幅降低成本。不过折扣幅度与规则因厂商而异。Anthropic把缓存命中按基础输入的0.1倍计费，但Opus 5.5为0.05倍、Fable 5.1为0.025倍，写入缓存则5分钟加到1.25倍、1小时加到2倍。OpenAI把缓存输入按定价的10%、缓存写入按1.25倍计费（以GPT-6为准）。Google的Gemini 3.8 Flash缓存输入为$0.075，是定价的10%，但另收每百万Token每小时$0.50的存储费。xAI Grok 4.7的缓存输入为定价的25%，DeepSeek V4.1 Flash约为2%，GLM-5.3约为19%。批处理在Anthropic、OpenAI、Google都是标准价的50%。另外，在低延迟要紧的实时UX里，Haiku 4.5、Gemini 2.5 Flash、GPT-5 mini这类小而快的模型更有利。速度与单价大体同向——越小越便宜的模型往往越快。

3. 按用途推荐 - 最高性能 vs 性价比 vs 开源

答案不是单一模型，而是按工作负载来配置。分三条路线整理。

3.1 最高性能 - 复杂推理·高风险代码

在准确就是信任、出错代价高的领域——生产迁移、安全敏感代码、长时自主智能体——旗舰更稳妥。Anthropic建议多数任务从Claude Opus 5.5（输入$4.00·输出$20.00）开始，要求高的推理与长时智能体任务则用Claude Fable 5.1（输入$10.00·输出$50.00）。OpenAI把GPT-6 Astra（输入$10.00·输出$50.00）说成面向最难任务的顶级模型，上一代的GPT-5.6 Sol为促销价$4.00·$20.00。更贵的一档是面向安全研究的GPT-5.6 Cyber（输入$12.50·输出$75.00）。输出单价高，长输出频繁的智能体工作负载需要设上限防止Token失控。Claude Sonnet 5.5与GPT-6 Sol都是输入$2.00·输出$10.00，在上位档中单价较低，是既在意成本又需要高性能时的平衡点。

3.2 性价比 - 大量调用·实时响应

分类、摘要、抽取、结构化回复这类难度低、调用量大的任务，小型低价模型才是正解。主流闭源中，GPT-6 Luna（输入$0.10·输出$0.50）在表中最低，其后是GPT-5.6 Luna（输入$0.20·输出$1.20）、Gemini 3.5 Flash-Lite（输入$0.30·输出$2.50）与Gemini 3.8 Flash（输入$0.75·输出$3.75）——不过3.8 Flash的单价只适用到2026年12月31日，次年起翻倍。上一代的Gemini 2.5 Flash（输入$0.30·输出$2.50）与GPT-5 mini（输入$0.25·输出$2.00）仍在价格表上。Claude Haiku 4.5（输入$1.00·输出$5.00）适合要求低延迟的实时UX，但Anthropic已预告后继Haiku 5.5将在「未来几周内」推出，Haiku 4.5的退役只公告为不早于2026年10月15日。Grok系列中4.3为输入$1.25·输出$2.50，4.7为输入$2.00·输出$6.00。

3.3 开源权重 - 最低价·数据掌控

想压到成本底线，或数据不便外发时，开源权重系列很有吸引力。DeepSeek V4.1 Flash按托管API计非高峰为输入$0.15·输出$0.60，处于最低价区间，但高峰时段翻倍到$0.30·$1.20，所以「最便宜的模型」并不是全天成立。用旧模型名deepseek-v4-flash发送的请求也由V4.1 Flash处理，按同样单价计费。GLM系列的5.3与5.1都是输入$1.40·输出$4.40，小型的GLM-5.3-Flash为$0.15·$0.50。Kimi K2.7 Code为输入$0.95·输出$4.00、上下文262,144，上位的Kimi K3为$3.00·$15.00、上下文1,048,576。不过开源权重真正的优势——自建托管——伴随GPU资本与运维负担，托管单价便宜与自建便宜是两笔不同的盈亏平衡计算。

4. 降本实战技巧

即使用同一个模型，也能靠设计大幅降低成本。

4.1 在设计阶段就嵌入提示缓存

把系统提示、工具定义、长参考文档这类不变的前缀放前面，每次都变的问题放后面，缓存命中率就会上升。缓存按前缀匹配，开头混进一个时间戳或UUID，缓存就失效。聊天机器人、RAG、智能体这类固定上下文反复出现的模式，仅靠缓存就能大幅降低输入成本。在写入缓存要加价的厂商（Anthropic、OpenAI）或收存储费的厂商（Google）那里，用一次就丢的缓存反而可能吃亏。

4.2 模型路由 - 易任务用便宜的，难任务用贵的

把所有请求都发给旗舰是最常见的浪费。设一个难度分类器，把易任务发给GPT-6 Luna、Gemini 3.5 Flash-Lite、Haiku 4.5这类小模型，只把复杂推理与高风险任务交给旗舰，平均单价会骤降。用与厂商无关的网关做抽象，价格变动时更换模型就从重写变成改配置。

4.3 削减输出，善用批处理

输出单价比输入贵3到6倍，光是去掉不必要的冗长输出就能降成本。用结构化输出（JSON schema）去掉废话，对推理Token过多的模型调低努力程度，控制看不见的输出。对延迟不敏感的大批量任务走批处理API（Anthropic、OpenAI、Google都是五折），单价减半。

5. 结论 - 以有效成本而非标价表来判断

2026年的LLM市场是两极结构：旗舰在上面拼性能，小型与开源模型在下面拉低单价。9月底的换代也是同一方向——Claude Opus 5.5以低于Opus 5的价格推出，GPT-6 Luna的单价是GPT-5.6 Luna的一半。关键不是背一张单价表，而是用自己工作负载的输入对输出比与缓存命中率相乘得出的有效成本来比较。同样是「每百万Token 5美元」，缓存命中好的RAG与推理Token失控的智能体，实际账单完全不同。

本周可做的三件具体事：第一，测量100条代表性请求的实际输入与输出Token，计算各模型的有效单价。第二，对固定前缀启用缓存并检查命中率。第三，设一个把易任务路由到小模型的网关，降低旗舰的占比。最重要的是，本页所有单价均为2026年9月29日的数值，会随促销与时点变化，报价前务必再次核对官方价格页。

# LLM API 成本估算检查表 — 把单价表变成账单之前

基准日：2026-09-29

> 来源: braindetox.kr — 2026 AI API价格对比
> 单价以各厂商官方价格页为准（美元，每百万Token），变动频繁。报价前请重新打开官方页面。

## 1. 挑选候选模型之前

- [ ] 测量了100条代表性请求的实际输入与输出Token
- [ ] 算出了输入对输出比（摘要、抽取偏输入；代码、智能体偏输出）
- [ ] 确认了输入长度的最大值 — 看是否越过下面第2节的界线
- [ ] 确认了相同前缀是否反复出现（缓存候选）
- [ ] 把不需要立即返回的任务单独分出来（批处理候选）

## 2. 长上下文界线 — 越过就换单价

| 厂商 | 界线 | 越过之后 |
|---|---|---|
| OpenAI（GPT-6、GPT-5.6、GPT-5.5） | 输入超过272K | 整个请求的输入与缓存2倍、输出1.5倍 |
| Google（Gemini 3.1 Pro、2.5 Pro） | 提示超过200K | 适用分段单价（3.1 Pro 为 $4.00/$18.00） |
| xAI（Grok 4.7、4.3） | 提示达到200K及以上 | 请求的全部Token按长上下文单价 |
| Anthropic（Claude 4.6 及以后） | 无 | 整个百万Token按标准单价 |

## 3. 缓存规则 — 因厂商而异

| 厂商 | 缓存命中（读取） | 写入与存储 |
|---|---|---|
| Anthropic | 基础输入的0.1倍（Opus 5.5 为0.05倍，Fable 5.1 为0.025倍） | 5分钟1.25倍、1小时2倍 |
| OpenAI | 定价的10% | 写入1.25倍（以GPT-6为准） |
| Google | Gemini 3.8 Flash $0.075（定价的10%） | 每百万Token每小时 $0.50 存储费 |

- [ ] 前缀开头有没有混进时间戳或UUID导致缓存失效

## 4. 限时单价与时段单价

- [ ] GPT-5.6 Sol $4.00/$20.00 — 至少到2026-11-21的促销。也按之后的单价做了预算
- [ ] Gemini 3.8、3.7 Flash $0.75/$3.75 — 到2026-12-31，2027-01-01起 $1.50/$7.50
- [ ] DeepSeek — 高峰（UTC 周一至周五 01:00-04:00、06:00-10:00）翻倍。实时服务按高峰单价计算
- [ ] 只有预告的模型（Claude Haiku 5.5）没有写进预算

## 5. 批处理与路由

- [ ] 可批处理的任务走了五折通道（Anthropic、OpenAI、Google 的批处理，OpenAI、Google 的 Flex）
- [ ] 设了把易任务发给小模型的规则（GPT-6 Luna $0.10/$0.50、Gemini 3.5 Flash-Lite $0.30/$2.50、Haiku 4.5 $1.00/$5.00 等）
- [ ] 用网关做了抽象，换模型只需改配置

## 6. 有效单价计算式

```
月成本 = (月输入Token × (1 − 缓存命中率) × 输入单价
        + 月输入Token × 缓存命中率 × 缓存单价
        + 月输出Token × 输出单价) × (1 + 重试率)
```

- 越过长上下文界线的请求，把整个请求按长上下文单价重算
- 走批处理的部分，按该厂商的批处理单价单独计算

## 7. 需要重算的时点

- 厂商推出新模型或新档位时（如已预告的 Claude Haiku 5.5）
- 限时单价到期时（2026-11-21、2026-12-31）
- 所用模型公布退役日期时（Claude Haiku 4.5 不早于2026-10-15）
- 价格表上的模型下架或改名时（如 DeepSeek V4 Flash → V4.1 Flash）
