Formula and assumptions

The calculator applies exactly this formula.

input cost = input tokens × monthly requests ÷ 1,000,000 × input rate × cache factor output cost = output tokens × monthly requests ÷ 1,000,000 × output rate monthly = input cost + output cost cache factor = 1 − 0.9 × cache hit rate
  • Rate unit: every rate is USD per 1 million (1M) tokens.
  • Cache factor: Anthropic, OpenAI and Google all bill cached input at roughly 10% of the standard input rate. At hit rate h the input cost becomes (1−h) + 0.1h = 1 − 0.9h.
  • Output cost: caching does not apply to output tokens, so output is billed in full regardless of the hit rate.
  • Claude Sonnet 5: shown at the standard $3 / $15 rate. A separate $2 / $10 introductory rate may apply through 2026-08-31.
  • Not included: the 50% batch API discount, long context surcharges above 200K tokens, cache write premiums, and multimodal image or audio tokens.
  • Currency: USD only. Exchange rates move daily, so a converted local amount would go stale quickly and is deliberately omitted.

Pricing data was cross-checked against each vendor official price list and independent price trackers published in July 2026.
