ペットの葬送 - 韓国の制度と手続き、そして残される人

決まった手続きがあると先に知っておけば、最もつらい時間に決めることが減る

2026-08-01 生活/実用

はじめに: 検索窓は開いたのに、何を入れればいいのか分からないとき

明け方に目が覚めて、あるいは病院から戻る車のなかで、人はたいていしばらく何もできずに座っている。そしてしばらくして携帯電話をつける。検索窓は開いたのに何を入力すればいいのか分からない。いま何をすべきなのか、何をしていいのか。そんなことを考えられる状態ではないからだ。

この記事はその瞬間のために書いた。悲しみを整理する方法を教える記事ではない。悲しみは整理すべき問題ではない。ただ、その状態でも決めなければならないことがいくつかあり、幸いなことにその決定の大半はすでに決まった手続きのなかにある。何を選ぶか悩む項目より、順番どおりに進めればよい項目のほうがはるかに多い。

この記事の主張は一つだ。「葬儀をどう行うか」ではなく、「決まった手続きがある」という事実そのものを先に知っておくことが重要だ。それを知っていれば、最もつらい瞬間に下すべき決定の数が減る。決定が減れば、その分だけその子のそばにいる時間が増える。

まず一つだけ。いま悲しみが大きいなら、それはおかしなことではない。一緒に暮らした時間が長いほど、最期が突然であるほどなおさらだ。この記事の最後の部分は手続きではなく残される人の話だ。いますぐ何をすべきかだけが必要なら、次の章へ進んでかまわない。あとで戻ってきても遅くない。

読む前に。ここに書いた制度と法令条文は韓国の法律と行政運用を対象とし、2026年8月1日時点で政府の公式資料から確認した内容である。法令と地方自治体の条例は改正される。とくに処理方法の細部基準、過怠料の金額、申告手続きは変わり得る。実際に進める前に管轄の市・郡・区役所と国家法令情報センターで現行規定を再確認してほしい。この記事は情報提供のためのものであり法律相談ではない。

確認できなかったことは確認できなかったと書いた。この記事には「要確認」と表示した項目がいくつかある。それらは公式資料で直接確認できなかったものなので、必要なら示した経路で自分で確認してほしい。特定の業者や商品はこの記事では言及しない。費用も公式の価格資料がないため断定しない。

1. いますぐ何をすればよいか

まず知っておくべきはこれだ。韓国の法律が数分以内に行うよう求めていることはない。人の葬儀のように死亡診断書を数時間以内に取らなければならないとか、数日以内に埋葬申告をしなければならないといった切迫した手続きはペットにはない。唯一期限が付いているのは動物登録の抹消申告一つで、その期限も三十日だ。

だから最初の数時間はお別れに使ってかまわない。それが手続きを遅らせるわけではない。そのあとにすべきことは以下の順で進めればよい。

亡くなった直後の時間順（推奨）

  0 ～ 2時間   急がない。お別れの時間をとる。
               写真を残したければ残す。あとで悔やまないように。

  当日         遺体を涼しい場所に寝かせ、柔らかい布で包む。
               直射日光と暖房を避ける。箱やキャリーに寝かせてもよい。
               動物病院で亡くなったなら、引き取るかどうかを病院にはっきり伝える。

  1 ～ 3日     法律が認める三つの処理方法のうち一つを決める。
               葬墓施設を使うなら許可の有無を公式システムでまず確認する。
               保管できる時間は季節と室温で変わるので問い合わせる。

  三十日以内   動物登録の対象だったなら抹消（変更）申告を行う。
               オンラインまたは市・郡・区役所の訪問。

  その後       遺骨をどうするかはいま決めなくてよい。
               決定を先送りすることも一つの選択である。

1.1 遺体の安置について

  • 涼しく日陰になる場所に寝かせる。直射日光が入る窓際、床暖房の効いた床、暖房器具の近くは避ける
  • 柔らかい布やタオルで包む。普段使っていた毛布を使う人が多い。そうしてかまわない
  • 体液が出ることがある。驚かなくてよい。自然な過程であり、吸水できる布を下に敷いておけばよい
  • どれだけ保管できるかは季節と室温によって大きく変わる。ここに「何時間」と断定して書かない。利用する施設や診てもらっていた動物病院に尋ねるのが正確だ
  • ほかにペットがいるなら、最後のお別れをさせてあげる人が多い。これは義務ではなく選択である
  • 死後硬直が始まると姿勢を変えにくくなる。楽な姿勢で寝かせておくほうが後で扱いやすい

1.2 動物病院で亡くなった場合に必ず伝えるべきこと

この項目が実務上もっとも重要だ。動物病院で死亡した場合、遺体を引き取るか病院に預けるかを飼い主が選べる。ところがこの選択は自動的には行われない。

  • 法制処の案内によれば、動物病院で死亡したペットの遺体は医療廃棄物に分類され、病院が自ら処理するか廃棄物処理業者に委託することができる
  • 同時に飼い主が望めば引き取ることができる。引き取った後は生活廃棄物として排出するか、許可を受けた動物葬墓施設を利用できる
  • 問題は動転した状態で何も言わなければ病院の通常の手順で進むことがあるという点だ
  • だから連れて帰りたいならその場ではっきり伝えなければならない。言葉が出てこなければ、一緒に行った人が代わりに言ってもよい
  • ペットが高齢または闘病中ならこの判断を家族とあらかじめ決めておくほうがよい。8章で改めて扱う

2. 法律が認める三つの処理方法

ここからがこの記事の核心だ。韓国でペットの遺体を処理する合法的な方法は三つあり、それぞれ根拠となる法令条文がある。法制処が運営する生活法令情報ポータルで確認した内容である。

2.1 動物葬墓施設を利用する方法

  • 「動物保護法」は動物葬墓業を許可を受けなければならない営業と定めている。法制処の案内は第69条第1項第4号を根拠として示す
  • 施設で行われる処理方式は施行規則第38条第4号のイ目・ウ目・エ目に該当するものと案内されている。通常は火葬、乾燥葬、水分解葬と呼ばれる
  • 火葬は熱で焼く方式、乾燥葬は乾燥・滅菌して粉砕する方式、水分解葬はアルカリ溶液と熱で分解する方式として知られている。ただし各方式の法令上の定義文はこの記事を書く際に条文全文を直接開けなかったため、正確な表現は要確認である
  • 重要なのは許可を受けた施設かどうかだ。確認方法は5章で扱う

2.2 生活廃棄物として排出する方法

この項目は読むのがつらいかもしれない。「従量制袋」という言葉が与える感じのためだ。その感情は自然なものであり、ここでそれを説得しようとはしない。ただ事実は事実として書く。

  • 「廃棄物管理法」第2条は動物の死体を廃棄物の例示として明示しており、事業場廃棄物でないものは生活廃棄物に分類される
  • したがってペットの遺体は生活廃棄物に該当し、同法第14条により地方自治体の条例が定める方法で排出できる。通常は生活ごみの従量制袋に入れて排出する方式である
  • これは法が定めた合法的な方法の一つだ。この方法を選んだからといって愛情が少なかったわけではない。経済的な事情、地域に施設がない事情、体力的に移動が難しい事情はよくある
  • 排出方法の細部は地方自治体ごとに条例が異なる。袋の種類、排出場所、事前申告の要否が分かれ得るため、居住地の市・郡・区役所に確認する必要がある
  • 一部の地方自治体は別途の収集手続きや案内を運用することもある。ただし地域差が大きいため具体的な運用方式は要確認である

2.3 医療廃棄物として処理する方法

  • 「廃棄物管理法」上の医療廃棄物とは、保健・医療機関、動物病院、試験・検査機関などから排出される廃棄物のうち特別な管理が必要なものをいう
  • 動物病院で死亡したペットの遺体はこれに該当し、病院が自ら処理するか廃棄物処理業者または廃棄物処理施設の設置・運営者に委託して処理する
  • 根拠として示される条文は「廃棄物管理法」第2条と第18条第1項、施行令別表1第10号と別表2第2号ア目、施行規則別表3第6号である
  • この方法は飼い主が別途行う手続きがほとんどない。病院に預ける意思を伝えることで終わる
  • ただし遺骨を返してもらうことはできない。その点を知ったうえで選ぶ必要がある

3. 勝手に埋めてはいけない理由

もっとも多く調べられる項目でありながら、もっとも誤解の多い項目でもある。庭に埋めてあげること、よく行っていた山に埋めてあげることは韓国の法律では認められていない。自分の所有地であっても例外ではない。

3.1 法的根拠

  • 「廃棄物管理法」第8条第1項は指定された場所以外に廃棄物を捨てる行為を禁じている
  • 同法第8条第2項は許可・承認を受けたり申告した廃棄物処理施設でない場所で埋め立てたり焼却したりする行為を禁じている
  • 法制処の案内はこれらの条項とあわせて「軽犯罪処罰法」第3条第1項第11号と同法施行令第2条、そして「廃棄物管理法」第68条第3項第1号を関連根拠として示す
  • 処罰の水準はこの記事では断定しない。反則金と過怠料の規定は存在するが金額は法令改正によって変わり得るため、必要なら国家法令情報センターで現行条文を直接確認してほしい

3.2 処罰より重要な理由

この記事は「どうすれば問題にならないか」を扱わない。そうした案内はしない。代わりになぜこの規定が存在するのかを書く。

  • 土壌と地下水の汚染。遺体が分解する過程で出る物質が土に染み込み、それが地下水に流れ込むことがある。水源保護区域や河川の近くであれば影響はより直接的だ
  • 薬物の残留。闘病中だったなら抗がん剤、鎮静剤、安楽死に使われた薬物が体内に残っていることがある。この成分が土壌に出れば他の動物や植物に影響を与える
  • 感染性疾患。死因が感染性疾患だった場合、遺体が病原体の経路になり得る
  • 掘り返される問題。浅く埋めた遺体が野生動物や他の犬によって露出することは実際に起きる。埋めた人がそれを再び見ることになる状況がもっともつらい
  • 土地の所有は永続的ではない。引っ越したり所有者が変わったりすれば、その場所がどうなるかを制御できなくなる
  • 公園・登山道・河川は明白に禁止される。私有地でない場所は議論の余地がない

すでに埋めてしまった場合。この記事を読む時点ですでにそうした人がいるかもしれない。知らずにしたことだ。それ自体を責めることではない。これからどうするか気になるなら、管轄の市・郡・区役所の環境担当部署に状況を説明して問い合わせるのがもっとも確実だ。ここで勝手に「こうすればよい」と書かない理由は、地域と状況によって答えが異なるからである。

4. 動物登録の抹消 - 手続きと期限

動物登録をしたペットだったなら死亡の事実を申告しなければならない。これがこの記事で唯一法定期限が付いている項目である。

  • 期限は死亡後三十日以内だ。法制処の生活法令情報ポータルで確認した内容である
  • 根拠条文は「動物保護法」第15条第2項第2号と同法施行令第11条第1項第8号として案内されている
  • 申告しない場合は「動物保護法」第101条第4項第1号による過怠料の対象になり得る。金額はこの記事では断定しない。改正され得るため現行条文を確認してほしい
  • 申告方法は二つある。国家動物保護情報システムのサイトからオンライン申告するか、市・郡・区役所を直接訪問する
  • オンライン申告には本人確認が必要だ。登録当時の所有者名義で進めるのが原則である
  • 登録番号が分からなければシステムで登録情報をまず照会できる。動物登録証や登録当時に受け取った書類を探しておくと進めやすい

4.1 この期限が思ったより早く過ぎる理由

三十日は短くは見えない。ところが実際には悲しみのなかで何日がどう過ぎたのか分からないまま過ぎる。そしてふと思い出したときにはすでに一か月を超えている場合が多い。

  • 葬儀を終えて戻った日にカレンダーや携帯電話の通知に書いておくことだけでも忘れずに済む
  • 家族がいるならほかの人に頼んでもよい。本人確認の問題でオンラインが難しければ訪問申告が可能だ
  • 体内埋め込み型の登録チップを入れていた場合、チップがどう処理されるかは施設ごとに異なり得る。火葬時の回収の可否、返却の可否は要確認項目なので、利用する施設に直接尋ねてほしい

5. 許可を受けた施設を確認する方法

葬墓施設を利用すると決めたならまず確認すべきはその施設が許可を受けた場所かどうかである。これは検索結果や広告で判断することではなく、公式システムで直接照会すればよいことだ。

5.1 照会の経路

農林畜産検疫本部が運営する国家動物保護情報システムで照会する。2026年8月1日時点で直接開いて確認した画面構造は次のとおりである。

5.2 一覧で何を見るか

  • その施設が一覧にあるか。これが最初の確認だ。一覧になければ許可の有無を別途確認する必要がある
  • 取扱業種が何か。一覧には葬儀、火葬、納骨といった細部の取扱業種が表示される。火葬のみを行う施設と納骨まで可能な施設は異なる。遺骨を施設に置きたいならこの項目を見る必要がある
  • 所在地。移動距離と時間は実際に大きな問題になる。とくに遺体を自分で運ばなければならない場合はそうだ
  • 電話番号とホームページ。問い合わせは一覧に表示された連絡先で行うのが安全だ
  • 一覧に出てこない場合は管轄の市・郡・区役所の動物担当部署に問い合わせて実際の許可の有無を確認する。一覧の更新時点に差があり得るためだ

この記事は特定の業者を勧めない。業者名、価格、口コミをこの記事に書かない理由は二つある。第一に、公式に確認できる価格資料がない。第二に、こうした状況で特定の業者へ誘導する記事はそれ自体に問題がある。一覧で自分で確認し、自分で電話して尋ねることがもっとも安全な方法だ。

電話で尋ねること。総費用と含まれる項目、追加で発生し得る費用、個別火葬か合同火葬か、飼い主が立ち会えるか、遺骨を引き取れるか、予約が必要か、遺体をどう運ぶべきか。口頭の案内と実際の請求が食い違わないよう、書面やメッセージで残してほしいと依頼するのがよい。

葬墓施設を利用すると決めたなら、いくつかを選ぶことになる。その選択肢の名前と違いを先に知っておけば、電話を持って説明を聞きながら決めなくて済む。

6.1 遺骨をどうするか

この決定はいま行わなくてよい。多くの人が遺骨を持ち帰ったあと、数か月経ってからどうするかを決める。それが遅いわけではない。

  • 自宅での保管。骨壺に入れて家に置く方式だ。もっとも多く選ばれる
  • 施設での納骨。葬墓施設の納骨空間に安置する方式だ。前述のとおり納骨が可能な施設かどうかを一覧で確認する必要がある。期間と更新条件は施設ごとに異なる
  • メモリアルストーンなどへの加工。遺骨を固めて形を作る方式が知られているが、規格や規制の有無は要確認である
  • 散骨（自然に撒くこと）。人の遺骨については「葬事等に関する法律」が規律するが、ペットの遺骨の散骨に関する規定はこの記事を書く際に確認できなかった。要確認の項目である。行おうとするなら管轄の地方自治体と利用した葬墓施設の双方にまず問い合わせてほしい
  • 樹木葬の形の安置。同様にペットを対象とする制度の法的根拠は要確認である

6.2 書類について

  • 施設によっては火葬または葬儀の確認書類を発行する場合がある。ただしこれが法令上の義務かどうかは確認できなかった。要確認の項目である
  • ペット保険に加入していたなら保険会社が求める書類があり得る。何が必要かは加入した保険会社に問い合わせる。関連する内容はペット保険の選び方で扱った
  • 動物登録の抹消申告時に別途の証憑が必要かどうかは地方自治体ごとに異なり得るため、申告前に確認するほうがよい

7. 残される人 - 悲しみは問題ではない

ここまでが手続きだ。ところが手続きが終わっても残るものがある。むしろ手続きが終わったあとのほうがつらい場合が多い。すべきことがある間は耐えていて、それが終わるとそこでようやく実感が来るからだ。

7.1 ペットロスは正常な悲嘆である

  • 悲しみの大きさは関係の大きさに比例する。一緒に暮らした時間、頼っていた度合い、日常で占めていた位置によって異なる。何年も毎日同じ時間に散歩していた関係なら、その時間帯ごとに不在を感じるのは当然だ
  • 体に出る反応もよくある。眠れない、食欲がない、理由もなく涙が出る、集中できない。すべて悲嘆の過程でよく現れる
  • 罪悪感は悲嘆でもっともよくある感情の一つだ。もっと早く気づいていたら、あの決定をしなかったら、という考えが繰り返される。この記事はそうした考えをあおらない。当時知り得た情報で下した決定を、いま知っている情報で判断するのは公正ではない
  • 「早く乗り越えなければ」という圧力は役に立たない。悲嘆に決まった期間はない。数週間で落ち着く人もいれば何年もかかる人もいる。どちらもおかしくない
  • 周囲の反応に傷つくこともよくある。「動物じゃないか」「また飼えばいい」といった言葉は実際によく聞く。その言葉がつらく感じられる理由は喪失が認められなかったからだ。その感情自体が間違っているのではない
  • 同じ経験をした人と話すことが助けになる場合が多い。理解される経験そのものが悲嘆で大きな役割を果たす

7.2 子どもにどう説明するか

  • ありのままに話すほうがよい。「眠った」「遠くへ旅に出た」といった婉曲な表現は幼い子どもを混乱させる。眠ることを怖がるようになったり、いつか帰ってくると待ち続けたりすることがある
  • 子どもの年齢に合った言葉で説明する。死が何かを説明しにくいなら「もう痛くないよ」「もう会うことはできないよ」程度でも十分だ
  • 子どもが自分のせいだと感じないようにすることが重要だ。子どもは自分の行動と出来事を結びつけがちである。「あなたのせいではない」とはっきり伝えるのがよい
  • 子どもなりのお別れをさせてあげる。絵を描く、手紙を書く、一緒に写真を整理する。どれも助けになる
  • 大人が泣く姿を見せてもかまわない。悲しんでよいことなのだと学ぶ機会になる
  • 新しいペットを急いで迎えることは、子どもには「代わりがきく」というメッセージとして読まれ得る。時間を置くほうがよい

7.3 残されたほかのペット

  • 一緒に暮らしていた動物も変化を見せる。食欲が落ちる、活動が減る、特定の場所を探し回る、普段より多く鳴くといった例が報告されている
  • 日常のリズムを保つことが助けになる。散歩の時間、食事の時間を大きく変えないほうがよい
  • 食欲の低下や活動の減少が数日以上続くなら悲嘆の反応ではなく病気の可能性がある。獣医師の診察を受けるのが安全だ
  • 飼い主の状態は伝わる。残された動物が不安そうに見えるなら、それは飼い主の変化に反応しているのかもしれない

助けが必要なとき。悲しみそのものは治療すべき病ではない。ただし日常生活がかなりの期間維持できない、眠れない状態が続く、自分を傷つけたいという考えが浮かぶのであれば、そのときは一人で耐えないほうがよい。居住地の精神保健福祉センターや精神科で相談を受けられる。助けを求めることは弱さではなく合理的な判断である。

運営機関と連絡先、支援プログラムは地域と時期によって変わる。正確な連絡先は居住地の地方自治体のサイトや保健所で確認してほしい。この記事に特定の番号を書かない理由は、相談電話の番号が統合されたり変更されたりすることが実際にあるからだ。

8. あらかじめ準備しておくとよいこと

この章はいますぐ必要な人よりも、まだ時間がある人のためのものだ。ペットが高齢または闘病中なら、ここまで読んでおくだけでも後で大きく違う。

理由は単純だ。もっともつらい瞬間には判断力が落ちる。そのときに一から調べ始めれば、決めるべきことが一度に押し寄せる。あらかじめ知っておけば、その瞬間にはすでに決めておいたことを実行するだけで済む。

8.1 いま確認しておくこと

  • 居住地の近くの許可を受けた葬墓施設をあらかじめ照会しておく。国家動物保護情報システムで地域から検索すればよい。移動距離と連絡先をメモしておくだけでも十分だ
  • 動物登録番号を探しておく。動物登録証や登録当時の書類をどこに置いたかをいま確認しておく
  • かかりつけの動物病院にあらかじめ尋ねる。病院で死亡した場合の手順、遺体の引き取りの可否、時間帯ごとの対応がどうなるか
  • 家族とあらかじめ話す。どの方法にするか、誰が連絡を担当するか、費用はどうするか。その瞬間に家族間で意見が分かれることが実際に多い
  • 移動方法を考えておく。車がないならどう運ぶか、公共交通機関の利用が可能か、施設が搬送を支援するか
  • ペット保険があるなら必要な書類をあらかじめ確認しておく

8.2 先送りすると後悔すること

  • 写真と動画。健康なときの姿、平凡な日常の姿が後でもっとも大切になる。特別な瞬間だけを残さなくてよい
  • 肉球のスタンプや毛の一房。残しておきたいと思う人が多いが、後ではできないことだ
  • 声の録音。写真は多いのに音がなくて残念に思う場合がよくある
  • 名前を呼ぶ動画。反応する姿が入った短い動画一つが長く残る
  • 一緒に写った写真。撮ってあげるばかりで一緒に写った写真がない場合が意外に多い

9. よくある質問

亡くなった直後の数時間以内にすべきことはあるか

韓国の法律が数分、数時間以内に行うよう定めたことはない。唯一の法定期限は動物登録の抹消申告の三十日である。ただし動物病院で亡くなった場合、遺体を引き取るかどうかはその場で伝えなければ病院の手順どおりに進むのを防げない。

週末や明け方に亡くなった場合は

遺体を涼しい場所に保管して翌日に連絡してもよい。ただし保管できる時間は季節と室温に大きく左右されるためこの記事では断定しない。二十四時間問い合わせが可能な施設があるかどうかは、照会した一覧の連絡先で確認してほしい。

費用はどのくらいかかるか

この記事では金額を書かない。確認された公式の価格資料がないからだ。施設、地域、体重、選んだ方式（個別・合同）、納骨の有無によって変わる。電話で総額と含まれる項目、追加費用を確認し、メッセージや書面で残してほしいと依頼するのが安全だ。

動物登録をしていないが抹消申告は必要か

登録していなければ抹消する対象がない。ただし登録の有無を覚えていないなら国家動物保護情報システムで照会してみることができる。過去に代行機関を通じて登録した場合、本人が覚えていないこともある。

去勢や安楽死の決定がずっと心に引っかかる

悲嘆の過程で非常によくある反応だ。いま知っていることで当時の決定を判断するのは公正ではない。この考えが繰り返されて日常が難しいほどなら相談を受けてみることが助けになる。それは弱さではなく回復のための実用的な選択である。

10. まとめ

  • 急ぐことはほとんどない。法定期限があるのは動物登録の抹消申告一つで、それも三十日だ
  • 病院で亡くなったなら、引き取るかどうかだけはその場で伝えなければならない。これが唯一時間に関わる項目だ
  • 合法的な処理方法は三つである。葬墓施設、生活廃棄物、医療廃棄物。それぞれに根拠条文がある
  • 勝手に埋めることは認められない。自分の土地でも同じだ。処罰より土壌・地下水・薬物残留の問題が実質的な理由である
  • 葬墓施設は公式システムで許可の有無をまず照会する。取扱業種まで確認すれば無駄足を減らせる
  • 遺骨をどうするかは後で決めてよい。先送りも選択だ
  • 制度は改正される。進める前に管轄の市・郡・区役所と国家法令情報センターで現行規定を確認する
  • そして悲しみは問題ではない。決まった期間もなく決まった形もない。つらければ助けを求めてよい

# ペットの葬送 実務シート（韓国の制度、2026-08-01時点）

## 0. 一行要約

韓国の法律が数分以内に行うよう求めていることはない。法定期限が付いているのは動物登録の抹消申告一つで三十日である。ただし動物病院で亡くなった場合、遺体を引き取るかどうかだけはその場で伝えなければならない。

## 1. 亡くなった直後の時間順

| 時点 | すること | 急ぐべきか | 備考 |
|---|---|---|---|
| 0～2時間 | お別れ、写真 | いいえ | 法が求める時限はない |
| 当日 | 遺体の安置 | 推奨 | 涼しい場所、直射日光と暖房を避け、布で包む |
| 当日（病院で死亡） | 引き取りの意思を伝える | **はい** | 伝えなければ病院の手順で進むことがある |
| 1～3日 | 処理方法の決定 | 推奨 | 下記の三つから選ぶ |
| 1～3日 | 施設の許可の確認 | 推奨 | 国家動物保護情報システムで照会 |
| 三十日以内 | 動物登録の抹消申告 | **はい（法定期限）** | オンラインまたは市・郡・区役所 |
| その後 | 遺骨の扱いの決定 | いいえ | 先送りしてよい決定 |

保管できる時間は季節と室温によって大きく変わる。ここに時間は書かない。利用する施設や診てもらっていた動物病院に問い合わせること。

## 2. 法律が認める三つの処理方法

| 方法 | どのような場合 | 根拠法令と条文 | 確認先 |
|---|---|---|---|
| 動物葬墓施設の利用（火葬・乾燥葬・水分解葬） | 葬儀を行いたいとき | 動物保護法第69条第1項第4号 / 動物保護法施行規則第38条第4号のイ目・ウ目・エ目 | 国家動物保護情報システムの許可施設照会 |
| 生活廃棄物としての排出（従量制袋） | 自宅などで死亡し葬墓施設を利用しないとき | 廃棄物管理法第2条第1号・第2号 / 同法第14条第1項・第2項・第5項 | 居住地の地方自治体の条例 |
| 医療廃棄物としての処理 | 動物病院で死亡し病院に預けるとき | 廃棄物管理法第2条、第18条第1項 / 施行令別表1第10号、別表2第2号ア目 / 施行規則別表3第6号 | 当該の動物病院 |

条番号の出典は法制処「探しやすい生活法令情報」である。条文全文は国家法令情報センターで確認すること。

## 3. 勝手に埋めてはいけない根拠

| 項目 | 関連条文 |
|---|---|
| 指定場所以外への投棄の禁止 | 廃棄物管理法第8条第1項 |
| 許可・承認・申告施設以外での埋立て・焼却の禁止 | 廃棄物管理法第8条第2項 |
| 関連罰則 | 廃棄物管理法第68条第3項第1号 |
| 軽犯罪関連 | 軽犯罪処罰法第3条第1項第11号、同法施行令第2条 |

- 自分の所有地であっても例外ではない
- 過怠料・反則金の金額は改正され得るため、国家法令情報センターの現行条文を確認すること
- 処罰以外の実質的理由: 土壌・地下水の汚染、薬物の残留、感染性疾患、掘り返し、土地所有の非永続性

## 4. 動物登録の抹消申告

| 項目 | 内容 |
|---|---|
| 期限 | 死亡後三十日以内 |
| 根拠 | 動物保護法第15条第2項第2号 / 同法施行令第11条第1項第8号 |
| 未申告の場合 | 動物保護法第101条第4項第1号（金額は現行条文を確認） |
| 方法 | 国家動物保護情報システムのオンライン申告または市・郡・区役所の訪問 |
| 必要なもの | 動物登録番号。分からなければシステムで登録情報を照会 |

## 5. 許可施設の確認経路

1. 国家動物保護情報システムに接続
2.「営業者」メニューに入る
3.「ペット営業者案内」で業種「葬墓業」を選択
4. 道・市、市・郡・区を指定するか業者名で検索
5. 結果で取扱業種、業者名、電話番号、所在地、ホームページを確認
6. 必要ならエクセルをダウンロード
7. 一覧になければ管轄の市・郡・区役所の動物担当部署に問い合わせる

確認することは二つ: 一覧にあるか、取扱業種が何か（火葬のみか納骨まで可能か）。

## 6. 電話で尋ねる項目

- 総費用と含まれる項目
- 追加で発生し得る費用
- 個別火葬か合同火葬か
- 飼い主の立ち会いの可否
- 遺骨の引き取りの可否
- 予約の要否
- 遺体の運搬方法
- 口頭の案内をメッセージや書面で残してもらえるか

費用は確認された公式の価格資料がない。業者ごとに異なる。

## 7. 個別火葬と合同火葬

| 区分 | 個別火葬 | 合同火葬 |
|---|---|---|
| 進め方 | 一頭ずつ単独 | 複数を一緒に |
| 遺骨の引き取り | 可能なのが一般的 | 個別の引き取りは難しいのが一般的 |
| 飼い主の立ち会い | 施設によって可能 | 一般に該当しない |
| 所要時間 | 相対的に長い | 相対的に短い |
| 費用 | 業者ごとに異なる | 業者ごとに異なる |

この二つの用語が法令上定義された表現かどうかは要確認。

## 8. あらかじめ準備しておくとよいこと

- [ ] 居住地近くの許可葬墓施設の一覧をメモ（国家動物保護情報システム）
- [ ] 動物登録番号の確認（動物登録証または登録書類）
- [ ] 病院で死亡した場合の引き取りを家族とあらかじめ決める
- [ ] 居住地の生活廃棄物の排出基準を確認（市・郡・区役所の条例）
- [ ] 移動手段の決定（車、公共交通機関、施設の搬送支援の有無）
- [ ] 抹消申告の方法を把握
- [ ] ペット保険の請求に必要な書類を確認
- [ ] 写真、動画、声の録音、肉球のスタンプ、一緒に写った写真

## 9.「要確認」として残した項目

| 項目 | 確認経路 |
|---|---|
| 動物保護法第69条の条文全文、施行規則第38条第4号の正確な文言 | 国家法令情報センター |
| 動物葬墓施設の設置距離制限など立地規定の条番号 | 国家法令情報センターまたは管轄の市・郡・区役所 |
| 個別火葬・合同火葬が法令上定義された用語かどうか | 国家法令情報センター |
| 火葬・葬儀の確認書類の発行が法令上の義務かどうか | 利用する施設または管轄の市・郡・区役所 |
| ペットの遺骨の散骨・樹木葬に関する規定 | 管轄の地方自治体および利用する葬墓施設 |
| 体内埋め込み型登録チップの火葬時の処理方式 | 利用する葬墓施設 |
| 地方自治体ごとの生活廃棄物の排出細部基準 | 居住地の市・郡・区役所の条例 |
| 過怠料・反則金の現行金額 | 国家法令情報センターの現行条文 |

## 10. 残される人へ

- ペットロスは正常な悲嘆である。決まった期間も決まった形もない
- 罪悪感はよくある感情だ。当時知り得た情報で下した決定を、いま知っている情報で判断するのは公正ではない
- 「早く乗り越えろ」という圧力は役に立たない
- 子どもにはありのままに、年齢に合った言葉で。婉曲な表現に注意。「あなたのせいではない」とはっきり伝える
- 残されたほかのペットの食欲・活動の低下が数日以上続けば獣医師の診察を
- 日常がかなりの期間維持できない、または自分を傷つけたいという考えが浮かぶなら、居住地の精神保健福祉センターや精神科で相談を。連絡先は地方自治体のサイトや保健所で確認
