JavaScript 基础语法整理

JavaScript Basic Syntax

2025-06-01 开发/基础设施

JavaScript 是 Web 开发中使用最广泛的编程语言。本文将介绍 JavaScript 的基本语法与核心概念。

English: JavaScript is the most widely used programming language in web development. This article explains the basic syntax and key concepts of JavaScript.

变量声明 (Variable Declaration)

在 JavaScript 中，可以使用 var、let 和 const 关键字来声明变量。

English: In JavaScript, you can declare variables using the keywords var, let, and const.

// var (函数作用域 - function scope)
var x = 5;

// let (块级作用域 - block scope)
let y = 10;

// const (常量, 不可重新赋值 - constant, cannot be reassigned)
const PI = 3.14;

数据类型 (Data Types)

JavaScript 的基本数据类型如下：

English: JavaScript has the following basic data types:

  • String: 字符串 (text)
  • Number: 数字 (numbers)
  • Boolean: 布尔值 (true/false)
  • null: 无值 (no value)
  • undefined: 未赋值 (unassigned value)
  • Object: 对象 (objects)
  • Symbol: 唯一且不可变的数据类型 (unique and immutable data type)
let name = "홍길동";  // String
let age = 25;         // Number
let isActive = true;  // Boolean
let user = {          // Object
  name: "홍길동",
  age: 25
};

函数 (Functions)

函数是提高代码复用性的重要概念。

English: Functions are important concepts that enhance code reusability.

// 函数声明 (Function Declaration)
function add(a, b) {
  return a + b;
}

// 函数表达式 (Function Expression)
const multiply = function(a, b) {
  return a * b;
};

// 箭头函数 (Arrow Function)
const divide = (a, b) => a / b;

数组与循环 (Arrays and Loops)

使用数组和循环可以高效地处理数据。

// 数组声明
const fruits = ["사과", "바나나", "오렌지"];

// for 循环
for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}

// forEach 方法
fruits.forEach(fruit => {
  console.log(fruit);
});

// map 方法 (返回新数组)
const fruitLengths = fruits.map(fruit => fruit.length);

掌握 JavaScript 的基本语法后，你就能开发各种 Web 应用程序了。
