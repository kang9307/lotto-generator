Ceph 的核心技术之一 —— CRUSH(Controlled, Scalable, Decentralized Placement of Replicated Data)算法,是一种决定分布式存储中如何放置和管理数据的创新技术。本指南将通俗易懂地讲解 CRUSH 算法的工作原理和实际实现方法。

English: The CRUSH (Controlled, Scalable, Decentralized Placement of Replicated Data) algorithm is one of Ceph's core technologies that determines how data is placed and managed in distributed storage systems. This guide provides an easy-to-understand explanation of CRUSH algorithm principles and practical implementation methods.

🎯 什么是 CRUSH 算法?

CRUSH 是 Ceph 分布式存储系统中决定数据存储位置的核心算法。与传统的中心化元数据服务器方式不同,CRUSH 通过数学计算来决定数据位置,因此具有出色的扩展性和性能。

CRUSH 的主要特性

  • 分布式处理:无需中心服务器,每个客户端可独立计算数据位置
  • 可扩展性:能够线性扩展到数千个存储节点
  • 故障恢复:自动绕开故障节点进行数据放置
  • 基于策略:可根据业务需求灵活配置放置策略

CRUSH Map 的组成要素

组成要素 说明 示例
Device 实际的存储设备 (OSD) osd.0, osd.1, osd.2...

⚙️ CRUSH 算法的运行原理

CRUSH 算法通过以下步骤决定数据放置:

1. 哈希计算

对对象名称和池 ID 进行哈希运算,生成唯一的 placement group (PG)。

# 伪代码示例
def calculate_pg(object_name, pool_id, pg_num):
    hash_value = hash(object_name + str(pool_id))
    pg_id = hash_value % pg_num
    return pg_id

2. 应用 CRUSH Rule

根据放置策略选择合适的 OSD。

# CRUSH Rule 示例
rule replicated_rule {
    ruleset 0
    type replicated
    min_size 1
    max_size 10
    step take default
    step chooseleaf firstn 0 type host
    step emit
}

3. 考虑故障域

确保副本不会被放置在同一物理位置。

🔧 CRUSH Map 实际配置方法

查看当前 CRUSH Map

# 获取 CRUSH Map
ceph osd getcrushmap -o crushmap.bin
crushtool -d crushmap.bin -o crushmap.txt
cat crushmap.txt

# 查看简单的树状结构
ceph osd tree

添加新主机

# 将新主机添加到 CRUSH Map
ceph osd crush add-bucket new-host host
ceph osd crush move new-host root=default

# 将 OSD 添加到新主机
ceph osd crush add osd.8 1.0 host=new-host

创建自定义 CRUSH Rule

# 为 SSD 专用池创建 CRUSH Rule
ceph osd crush rule create-simple ssd-rule default host firstn

# 为纠删码创建 CRUSH Rule
ceph osd crush rule create-erasure ec-rule ec-profile

📊 CRUSH 算法性能优化

通过调整 Weight 实现负载均衡

根据存储容量比例设置每个 OSD 的权重,即可实现均衡的数据分布。

# 基于容量调整 OSD 权重
ceph osd crush reweight osd.0 1.8  # 1.8TB 容量
ceph osd crush reweight osd.1 3.6  # 3.6TB 容量

# 基于使用率自动调整
ceph osd reweight-by-utilization 110

监控数据分布状态

命令 用途 主要指标
ceph osd df 查看 OSD 使用率 Size、Use%、Var
ceph pg stat 查看 PG 状态 active+clean 比例
ceph osd utilization 不均衡分析 标准差、平均值

🚨 常见 CRUSH 问题排查

数据不均衡问题

# 诊断不均衡
ceph osd df | sort -k7 -n

# 重新调整权重
for osd in $(ceph osd ls); do
    size=$(ceph osd df | grep "osd.$osd" | awk '{print $2}')
    weight=$(echo "scale=2; $size/1024/1024" | bc)
    ceph osd crush reweight osd.$osd $weight
done

rule geo_replicated_rule {

    type replicated
    min_size 1
    max_size 10
    step take datacenter1

    step emit
