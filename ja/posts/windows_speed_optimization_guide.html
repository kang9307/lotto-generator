Windowsが重い時の対処法 - 原因の切り分けから段階別の最適化まで

タスクマネージャーでボトルネックを先に特定し、原因別に対処するトラブルシューティング手順

2026年7月26日 IT・技術

はじめに: 重くなったPCで設定から触ってはいけない理由

起動に3分かかる。ブラウザのタブをいくつか開いただけで画面がもたつく。こういうとき多くの人は、検索して出てくる最適化のコツを上から順に適用する。視覚効果を切り、一時ファイルを消し、サービスをいくつか止める。ところが体感は変わらない。原因が別の場所にあったからだ。メモリ不足で重いPCの視覚効果を切ってもほとんど変わらないし、ストレージがボトルネックなのにスタートアップアプリだけ整理しても、起動が少し速くなるだけで使用中のもたつきはそのまま残る。

そこで本記事は設定カタログではなく診断手順として構成した。まずタスクマネージャーでCPU・メモリ・ディスク・GPUのどれがボトルネックかを特定し、その結果に応じてどのステップを踏むかを選ぶ順序である。各ステップに想定所要時間と難易度を付し、効果が乏しい項目やむしろ危険な項目は別立ての警告としてまとめた。設定項目そのものを一つずつ見ていきたい場合はWindows 11最適化完全ガイドがその役割を担っているので、本記事と併せて読むとよい。本記事はその反対側、つまり症状から出発して原因を絞り込む側を扱う。

準備するもの・事前確認

  • 1~2時間の余裕: 更新とスキャンで待ち時間が長く取られる。急ぎの作業がある日には始めないほうがよい。
  • 安定した電源: ノートパソコンなら必ず充電器を接続する。更新の途中で電源が切れると復旧が面倒になる。
  • 重要ファイルのバックアップ: 後半のステップに初期化が含まれる。開始前に書類・写真・作業フォルダーを外付けストレージかクラウドへコピーしておく。
  • 自分のPC仕様のメモ: 設定 → システム → バージョン情報でプロセッサーと搭載メモリ容量を確認して控える。後の判断根拠になる。
  • システムドライブの種類の確認: スタートメニューからドライブのデフラグと最適化を開くと、メディアの種類の列にハードディスクドライブまたはソリッドステートドライブと表示される。この一行が本記事全体で最も重要な情報だ。
  • 暗号化の回復キー: デバイスの暗号化が有効なら、回復キーをMicrosoftアカウントで事前に確認しておく。

事前確認でシステムドライブがハードディスクドライブ(HDD)だった場合、以下の手順はあくまで応急処置である。根本的な解決はストレージの交換なので、その場合はSSDの交換・増設のやり方を先に読んで計画を立てるほうが時間を節約できる。

Step 1. タスクマネージャーでボトルネックを特定する (10分 / 難易度 低)

すべての判断の出発点である。Ctrl + Shift + Escでタスクマネージャーを開く。パフォーマンスタブで全体の数値を、プロセスタブで犯人を見る。プロセスタブは列見出しをクリックすると使用率順に並べ替えられる。

1.1 何が100%に張り付いているかを見る

PCを起動し、何も操作しない状態で3~5分ほどそのまま観察する。起動直後は更新確認やウイルス対策のスキャンが走るため一時的に数値が高いのは正常で、この時間を過ぎても特定の項目が張り付いたままなら、それがボトルネックだ。

ボトルネック代表的な症状本記事での行き先
CPUが常時80%以上全体的に反応が鈍い、ファン音、発熱Step 2・3・7
メモリが常時80~90%以上タブ・アプリ切り替え時のもたつき、再描画の遅延Step 3・ハードウェアの判断
ディスクが常時100%起動とアプリ実行が極端に遅い、カーソルが回り続けるStep 1.2・4・ハードウェアの判断
GPUだけ高いゲームや動画再生時のみ問題、通常作業は正常Step 6(グラフィックドライバー)
すべて低いのに遅い特定のソフトだけ遅い、ネットだけ遅いStep 6・7、ネットワークは別途点検

1.2 ディスク100%ならプロセス名を見る

ディスクがボトルネックなら、プロセスタブでディスク列を基準に並べ替え、上位の名前を確認する。よく挙がる名前は次のとおりだ。

  • Windows モジュール インストーラー / サービス ホスト(Windows Update): 更新のダウンロード・インストール中。終わるまで待てば落ち着く。
  • Antimalware Service Executable: ウイルス対策のスキャン中。予定スキャンの時刻を使わない時間帯へ移すのが正攻法だ。
  • Microsoft Windows Search インデクサー: ファイルの索引作成。大量のファイルをコピーした直後は数日間活動が活発になる。
  • サービス ホスト(SysMain): よく使うアプリを事前にメモリへ載せる機能。SSDでは負担が小さいが、遅いHDDではディスク活動を増やす要因として指摘される。
  • OneDriveやGoogleドライブなどの同期クライアント: 大量同期の最中。一時停止すればすぐ下がる。

ここで重要な判断が一つ出てくる。上のいずれも目立たないのにディスクが常時100%で、事前確認でシステムドライブがHDDだった場合、これは故障ではなく性能の限界である。ソフト側の調整で得られる改善幅は大きくない。

Step 2. スタートアップアプリを整理する (10分 / 難易度 低)

起動が遅く、サインイン直後に数分間反応がない症状に最も直接効くステップだ。タスクマネージャー左側のメニューからスタートアップアプリを選ぶと、起動時に自動実行される一覧と各項目のスタートアップへの影響が表示される。止めたい項目を右クリックし、無効にするを選ぶ。

基準は単純だ。名前を見て何か分かり、起動直後に使わないアプリだけを切る。メッセンジャー、クラウド同期ツール、ゲームランチャー、各種アップデート補助、プリンターや周辺機器メーカーのユーティリティが代表的な候補である。ここで無効にしてもプログラムが削除されるわけではなく、必要なときに自分で起動すればそのまま動く。

逆に触ってはいけないものもはっきりしている。ウイルス対策・セキュリティソフト、グラフィックドライバーのコントロールパネル、ノートパソコンメーカーの電源・ファン・キーボード制御ツール、オーディオドライバー関連の項目は有効のままにする。名前だけでは正体が分からない項目はそのままにしておくのが安全だ。よく分からない項目をまとめて切るより、確実に分かる項目を三つ四つ切るほうが、副作用なく効果を得る方法である。

Step 3. バックグラウンドで動くものを減らす (20分 / 難易度 低)

CPUやメモリがボトルネックのときに効くステップだ。順に進める。

  1. いま開いているものから閉じる: ブラウザのタブが数十個あるだけでメモリを大きく消費する。よく見るページはブックマークに移してタブを閉じる。
  2. 使っていないアプリを削除する: 設定 → アプリ → インストールされているアプリで、サイズとインストール日を基準に並べ替えてみる。何年も起動していないプログラム、以前ついてきたツールバーやPC管理ソフトは消す。プログラムのアンインストールはファイル削除より安全で戻しやすい。
  3. 個別アプリのバックグラウンド実行権限を調整する: インストールされているアプリから個別アプリの詳細オプションに入ると、バックグラウンドアプリのアクセス許可を設定できる。通知が不要なアプリは許可しないにしておく。
  4. クラウド同期を一時停止する: 作業中に体感速度が急に落ちるとき、同期クライアントを少し止めてみれば原因かどうかがすぐ分かる。
  5. 再起動する: 何日もスリープだけを繰り返したPCは、再起動一回でかなり回復することが多い。シャットダウンして電源を入れ直すのではなく、再起動を選ぶと完全な再起動になる。

Step 4. 空き容量を確保する (20~40分 / 難易度 低)

システムドライブがほぼ埋まると、一時ファイルの生成や仮想メモリの運用に余裕がなくなり、全体の反応が悪くなる。マイクロソフトもディスクの空き容量確保を性能改善の項目として案内している。

道具はWindows標準のストレージセンサーを使う。設定 → システム → ストレージに入りストレージセンサーを有効にして今すぐ実行を押すと、一時ファイルとごみ箱、ダウンロードフォルダーの古い項目を整理する。自動実行の頻度、ごみ箱・ダウンロードフォルダーの保持期間もここで調整する。ストレージセンサーはシステムドライブ(通常はC:)を対象に動作する。

同じストレージ画面で一時ファイルの項目を直接開くと、どの種類がどれだけ占めているかを一覧で確認できる。以前のWindowsインストールが残っていれば数十GB単位で回収できることもある。ただしこの項目を消すと以前のバージョンへ戻す機能が使えなくなるため、アップグレード直後なら数日使ってみて問題がないときに消す。

整理後はシステムドライブの空き容量が全体の10~15%以上、最低でも数十GB確保されることを目標にすれば無難だ。整理しても容量が出ない場合は、写真や動画などの大容量ファイルを外付けストレージや別のドライブへ移すほうが早い。

Step 5. 電源モードと視覚効果を調整する (5分 / 難易度 低)

ノートパソコンで特に体感差が大きい項目だ。設定 → システム → 電源とバッテリーで電源モードを最適なパフォーマンスに変える。バッテリー節約モードで長く使ってきたノートパソコンなら、これ一つで反応速度が目に見えて変わることもある。代わりにバッテリー消費と発熱、ファン音が増えるので、外出時はバランスまたは最適な電力効率に戻すほうがよい。

視覚効果はスタートメニューでWindowsのパフォーマンスと外観の調整を検索して開き、視覚効果タブでパフォーマンスを優先するを選ぶ。低スペックPCではウィンドウ切り替えやメニュー表示が即座になり体感が改善する。ただしこの設定はアニメーションをなくして反応が速く見えるようにする性格が強く、実際の演算性能が増えるわけではない。画面が素っ気なくなるのが嫌なら、カスタムでウィンドウを最大化または最小化するときにアニメーションで表示するとアイコンの代わりに縮小版を表示するを切るだけでも大半の利得は得られる。

Step 6. Windowsとドライバーを最新にする (30分~1時間 / 難易度 中)

更新がたまっていると、それ自体がバックグラウンド活動を出し続け、すでに修正済みの性能問題を抱えたまま使うことになる。設定 → Windows Updateで更新プログラムのチェックを押し、残りをすべてインストールして再起動する。同じ画面の詳細オプション → オプションの更新プログラムにドライバー更新が別途入っていることがあるので併せて確認する。

グラフィックだけ極端に遅い、特定のゲームや動画でだけ問題があるなら、グラフィックドライバーが最優先の候補だ。このときは検索で出てくるドライバーまとめサイトではなく、GPUメーカーまたはPC・ノートパソコンメーカーの公式サポートページから入手する。ノートパソコンはメーカーが自社検証したドライバーを配布していることが多く、メーカー版のほうが安定している場合が多い。

更新が終わったら、SSD利用者はスタートメニューからドライブのデフラグと最適化を開き、最適化を一度実行しておく。最近のWindowsはストレージの種類を認識してHDDにはデフラグを、SSDにはTRIMを自動で行うため、利用者が種類を区別して心配する必要はない。

Step 7. マルウェアを検査する (30分~2時間 / 難易度 低)

理由もなくCPUが高い、ファンが回り続ける、ブラウザに見慣れない拡張機能やスタートページができた場合、このステップを飛ばしてはいけない。設定 → プライバシーとセキュリティ → Windowsセキュリティ → ウイルスと脅威の防止でクイックスキャンをまず実行し、疑いが残ればスキャンのオプションでフルスキャンを選ぶ。フルスキャンは長時間かかるので、使わない時間帯に走らせるほうがよい。

ウイルス対策ソフトを複数入れるのは避ける。リアルタイム監視が互いに衝突してかえって重くなり、誤検知も増える。Windows標準のセキュリティ機能で十分な場合が多く、別製品を使うなら一つだけ残すのが原則である。

Step 8. 最後の手段 - このPCを初期状態に戻す (1~3時間 / 難易度 中)

ここまで来ても改善がなく、タスクマネージャー上では特に資源を食うプロセスが見当たらないなら、積み重なった設定と残留ソフトが原因である可能性がある。このときこのPCを初期状態に戻すが選択肢になる。設定 → システム → 回復から実行し、個人用ファイルを保持するとすべて削除するのどちらかを選ぶ。

個人用ファイルを保持するを選ぶと、書類や写真などの個人ファイルは残してWindowsを再インストールする。ただしインストールしていたアプリやドライバー、変更した設定は削除される点を必ず理解して始める必要がある。初期化後に入れ直すプログラムの一覧とライセンスキー、ブラウザのログイン情報を先に整理しておくと復旧時間が大きく縮む。

開始前のチェックは三つだ。第一に、個人ファイルを外部にバックアップする。個人用ファイルを保持するオプションがあってもバックアップは別途行う。第二に、デバイスが暗号化されているなら回復キーを確保する。第三に、ノートパソコンは充電器を接続する。初期化は取り消せない作業なので、この三つが整っていないなら始めない。

よくある失敗

  • 診断なしでコツから適用する: 原因が分からないまま十個の設定を一度に変えると、効果があっても何のおかげか分からず、問題が起きてもどこを戻せばよいか分からない。一度に一つずつ、変えて確認する。
  • レジストリクリーナーの使用: マイクロソフトはレジストリ整理ユーティリティの使用をサポートしないという方針を公開している。誤った変更は深刻な不安定を招き、最悪の場合オペレーティングシステムの再インストールが必要になり得る。性能が良くなるという検証された根拠も乏しい。
  • 正体不明の最適化ソフトのインストール: 無料配布のPC高速化・整理ツールの一部は、広告の挿入や不要ソフトの同時インストールを伴う事例が報告されている。重くなったPCを直そうとして、監視対象のソフトを一つ増やす結果になりやすい。
  • サービス一覧を分からずまとめて停止: ネットに出回るサービス停止リストをそのまま真似すると、ネットワーク・印刷・オーディオ・更新が一度に止まることがある。体感の利得は小さく復旧の手間は大きい。
  • 仮想メモリを勝手に0や固定値に変更: 自動管理が既定であり、根拠なく触ると特定のソフトでメモリ不足エラーが発生し得る。
  • ウイルス対策ソフトの同時多重インストール: リアルタイム監視の衝突でかえって遅くなる代表例だ。
  • 初期化前のバックアップ省略: 個人用ファイルを保持するオプションを信じてバックアップを飛ばし、復旧不能に陥る事例が出ている。

やらなくてよいこと

広く知られているが、最近のWindows環境では効用が低いか、すでに自動化されている項目である。時間を節約するために整理しておく。

  • SSDへのデフラグの強制実行: Windowsがストレージの種類を判別してSSDにはTRIMを行う。別のツールでデフラグを繰り返すのは得がない。
  • システムサービスの大量無効化: 前述のとおり危険に対して利得が小さい。性能問題が特定のサービスで確認された場合にのみ、そのサービス一つを扱う。
  • 毎日の一時ファイル掃除: ストレージセンサーを有効にしておけば自動で処理される。容量が足りないときだけ確認すれば十分だ。
  • 起動時間短縮を狙った極端な設定変更: 起動が20秒から15秒になるより、使用中のもたつきをなくすほうが体感にはるかに大きく寄与する。

安全上の注意

  • レジストリエディターは原則として開かない: 特定の問題解決のために公式文書の案内に従う場合を除き、触らない。やむを得ず修正するなら、該当キーをまずエクスポートしてバックアップする。
  • サービスを止めるときは無効ではなく手動から: 問題が起きたとき戻しやすい。止めたサービス名と元の状態を控えておく。
  • ドライバーは公式経路からのみ: 検索結果上位のドライバー一括ダウンロードサイトは、バンドルソフトや改ざんのリスクがある。
  • 更新・初期化の途中で電源を切らない: 進行中の強制終了は起動不能につながり得る。
  • 戻せる地点を作っておく: 大きな変更の前に復元ポイントを作っておけば、問題発生時に戻す余地が生まれる。

ここからはハードウェアまたは専門家の領域

ソフト側の調整では解決しない区間が確かにある。以下に当てはまるなら、設定をさらに触るより、ハードウェアを検討するか修理窓口に任せるほうが合理的だ。

  • システムドライブがHDDの場合: 本記事で最も確実な処方である。回転式HDDからSSDに替えると、起動とアプリ実行の体感が他のどの設定変更よりも大きく変わる。手順はSSDの交換・増設のやり方に、規格の確認からデータ移行まで段階的にまとめてある。
  • メモリが常時80~90%を超える場合: ブラウザのタブを減らしても余裕が出ないなら、メモリ増設が答えだ。ノートパソコンはメモリが基板に直付けで増設不可のモデルもあるため、購入前にメーカー仕様を確認する。
  • 発熱・騒音が激しく、しばらくすると遅くなる場合: ほこりの蓄積やサーマルグリスの硬化による性能制限が疑われる。分解が必要な作業であり、保証期間中なら自分で開けずに修理窓口に任せる。
  • 起動失敗、ブルースクリーン、不明なビープ音が繰り返される場合: ストレージやメモリのハードウェア異常の可能性がある。この状態で最適化作業を続けるとデータ損失のリスクが高まる。まずデータをバックアップして点検を受ける。
  • 10年近く前のPCで最新の作業をしようとする場合: どんな最適化も世代差は埋められない。このときはMacBook vs Windowsノートパソコン 2026年完全比較のように、買い替え自体を比較検討するほうがよい。

結論

重くなったWindowsを立て直す順序は決まっている。まずタスクマネージャーでCPU・メモリ・ディスク・GPUのどれがボトルネックかを特定する。この一段階をきちんと踏むだけで、以後に使う時間の半分が減る。次に、起動が問題ならスタートアップアプリを、使用中のもたつきが問題ならバックグラウンドアプリとメモリを、全体的な鈍さなら空き容量と電源モードを扱う。更新とドライバーを最新に合わせ、マルウェア検査で外部要因を排除したうえで答えが出ないとき、はじめて初期化を持ち出す。

逆にやってはいけないことも明確だ。レジストリクリーナーと出所不明の最適化ソフトは、得るものより失う危険のほうが大きい。サービスの大量停止も体感の利得はわずかで復旧の手間は大きい。そしてシステムドライブがHDDなら、どんな設定の組み合わせもストレージ交換の代わりにはならないと認めるほうが、時間も費用も節約できる。

本記事は症状から原因を絞り込むトラブルシューティングの視点を扱った。個々の設定項目を順に見ていきたいならWindows 11最適化完全ガイドを、ハードウェア交換が結論ならSSDの交換・増設のやり方を、整理作業自体を自動化したいならWindows作業自動化入門ガイドを続けて読むとよい。

ご案内: 本記事は一般利用者の環境を基準とした情報提供用の案内であり、特定の製品や有料ソフトを推奨するものではない。メニュー名と位置はWindowsのバージョンや更新時点、メーカーのカスタマイズによって異なり得るため、画面と違う場合は設定の検索欄で項目名を検索して確認されたい。初期化、ドライバー交換、ハードウェアの分解など戻しにくい作業は必ずデータのバックアップ後に行う必要があり、その結果に対する責任は利用者本人にある。保証期間中の機器の分解は保証が終了し得るため、メーカーの修理窓口を利用するのが安全である。
