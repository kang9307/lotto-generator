引言：为何现在需要一份中枢对比

2026年上半年的AI模型市场，比一年前拥挤得多。Anthropic的Claude Opus 5、OpenAI的GPT-5.5、Google的Gemini 3.1 Pro、xAI的Grok 4.3争夺闭源旗舰的顶端，其下则有DeepSeek V4、GLM 5.2、Kimi K2.7-Code、MiniMax-M3等中国开源权重模型，以价格与开放性从侧翼突破。选择多了，「到底该用哪个」这个问题反而更难回答。

本文就是回答该问题的中枢指南。它将各模型的基准、上下文、价格与优势汇成一张表，再落实为按用途的推荐：编程用哪个、推理用哪个、实时用哪个。我们以公开基准与价格为依据而非广告文案，对不确定之处则明确标注「截至某时」。编程工具对比、图像生成器对比、ChatGPT对比Claude、API价格等细分主题在各自的文章中深入展开，本文负责绘制整体地图。

2. Claude Opus 5 - 新的默认模型，也是编程与智能体的强者

Anthropic的Claude Opus 5于2026年7月24日发布，并在同日成为Anthropic的新默认（default）模型：在Claude Max上为默认，在Claude Pro上为最强模型。核心在于以接近顶级能力模型Fable 5的智能、却只需一半价格提供。API价格为输入5美元/输出25美元（每百万token），与上一代Opus 4.8相同（Fable 5为10/50美元），并新增effort档位（low、medium、high、xhigh、max），可按任务直接调节成本与性能。若需更快响应，可用比标准约快2.5倍的Fast模式（价格约为2倍）。

据其官方公布，它在编程与智能体基准上表现突出：在Frontier-Bench v0.1（SWE）上超过Opus 4.8的两倍，在CursorBench 3.2上以最大effort达到Fable 5峰值的0.5%以内且成本减半，在ARC-AGI 3上约为次优模型的三倍，在计算机操作基准OSWorld 2.0上以约三分之一的成本超越Fable 5。不过这些数字大多为Anthropic自行公布，仍需独立验证；且在网络攻击利用等部分项目上仍落后，官方也一并说明了这些局限。兄弟阵容从顶级能力的Fable 5、新默认旗舰Opus 5、中端Sonnet 5到轻量Haiku 4.5；上一代Opus 4.8是同价位的旧默认。对于大多数日常与编程工作，若看重准确与成本的平衡，Opus 5是首选。更深入的编程工具对比见编程AI工具对比一文。

3. GPT-5.5 - 智能体工作流与多模态

OpenAI的GPT-5.5以约60分稳居最上层，仅略低于Claude Opus 4.8。其强项是智能体工作流与广泛的多模态处理。它在终端与工具调用密集的任务上表现出色，OpenAI生态（插件、工具、各类集成）之广，在落地中也是优势。

价格据报道约为输入5~10美元/输出30~40美元（每百万token），各来源有差异，采用前请确认最新官方价。若你看重通用广度与生态，且团队已绑定OpenAI工具链，GPT-5.5是自然之选。ChatGPT对比Claude的正面较量在另一篇文章中更详细展开。

更新（2026年7月）：OpenAI于2026年7月9日发布了GPT-5.5的后续机型——GPT-5.6 Sol、Terra、Luna三层阵容。三个模型共享约105万token上下文与12.8万token输出上限、2026年2月16日知识截止日期，max推理强度与ultra模式仅在最高层Sol上开放。据报道每百万token价格为Sol 5/30美元、Terra 2.5/15美元、Luna 1/6美元；其中Terra据称在保持与GPT-5.5相当性能的同时价格便宜约一半，这可能使「通用与生态」这一轴的默认选择从GPT-5.5转向Terra。Responses API还新增了Programmatic Tool Calling，让模型可直接编写代码来编排工具调用。不过需要注意，OpenAI自行公布的基准测试（如Sol在Agents' Last Exam上据称领先Claude Fable 5的数字）目前仍未经独立验证。详见GPT-5.6正式发布分析一文。

4. Gemini 3.1 Pro - 推理、多模态与长上下文

Google的Gemini 3.1 Pro在纯推理上领先。GPQA Diamond 94.3%、ARC-AGI-2 77.1%，在高难推理基准上达到顶级水平；SWE-bench Verified也有80.6%，在编程上同样具竞争力。再加上100万（1M）token上下文，可将数百页文档或大型代码库整段处理而无需切分。

另一差异点是原生多模态：文本、图像、音频、视频与代码在同一模型中处理，并与Google Workspace（文档、邮件、表格）原生集成，直接融入业务流程。API价格约为输入2美元/输出12美元（每百万token），对超过200K token的大型提示则升至约4/18美元。若任务核心是高难推理、长文档与多模态输入，Gemini 3.1 Pro最强。

更新（2026年7月21日）：Google在Gemini 3.1 Pro之下新增了小型、快速、低延迟档位。Gemini 3.6 Flash定价为输入1.50美元/输出7.50美元（每百万token），较此前9.00美元的输出价有所下调，知识截止为2026年3月；其编程与智能体基准有所提升（DeepSWE 49%、OSWorld-Verified 83.0%），适合对延迟敏感的智能体工作负载。Gemini 3.5 Flash-Lite定价为输入0.30美元/输出2.50美元，每秒可输出约350个token，是超轻量、超高速模型，并支持最小/低/高三档思考强度调节。安全专项试点Gemini 3.5 Flash Cyber专注于漏洞检测与修补（与CodeMender联动），目前仅限政府与受信任合作伙伴的有限试用。作为参考，更高阶的Gemini 3.5 Pro仍处于合作伙伴测试阶段，尚未正式发布。

5. Grok 4.3 - 实时数据与社交

xAI的Grok 4.3的决定性差异点是实时性。它能直接接入X（Twitter）实时数据，擅长反映刚发生的事件、舆情与趋势的调研与社交内容。当其他模型受训练截止时间所限时，Grok能回答「现在正在发生什么」。

价格也很激进：约输入1.25美元/输出2.50美元（每百万token），并提供1M上下文，使大规模实时调研的成本负担较小。不过编程与推理的绝对质量由Claude与Gemini更强，因此无需把「最新信息、社交动向」并非核心的一般任务也都压给Grok。按用途分工才合理。

6. 中国开源权重 - 以价格与开放性的侧翼进攻

闭源旗舰之下最热闹的，是中国开源权重阵营。DeepSeek V4默认提供1M上下文，同时将价格压到输入0.14~0.44美元/输出0.28~0.87美元（每百万token）的水平。GLM 5.2（智谱）是聚焦1M上下文与自主编程智能体的开源权重模型；Kimi K2.7-Code（月之暗面）主打token效率；MiniMax-M3则同时主张价格与性能。

开源权重的真正价值不只在单价。你可以下载权重并在自有基础设施上直接托管，使代码与提示不外流到第三方API。对隐私与合规敏感的团队，以及希望自行掌控高吞吐工作负载盈亏平衡的团队，这是决定性的选择。绝对顶级质量仍由闭源旗舰占优，但差距收窄得比多数人预期更快。详细价格走势在API价格对比一文与各中国模型分析文中深入展开。

7. 按用途推荐 - 何时用什么

任何对比的结论都不是「选一个」，而是「按用途部署」。各工作负载的推荐如下。

  • 编程、自主智能体与大多数日常：Claude Opus 5。新默认模型带来长循环可靠性、编程基准前列与前沿级性价比。若要进一步省成本，DeepSeek V4、GLM 5.2为替代。
  • 高难推理与研究：Gemini 3.1 Pro。GPQA、ARC-AGI-2领先，配1M上下文可整段处理长资料。
  • 实时信息、社交与趋势：Grok 4.3。直接接入X实时数据，定价激进。
  • 多模态（图像、音频、视频）：Gemini 3.1 Pro或GPT-5.5。一个模型处理多种模态。
  • 低延迟、轻量、成本高效：Gemini 3.6 Flash、3.5 Flash-Lite（2026年7月新增，输入约1.50~0.30美元/输出约7.50~2.50美元）。同类小型模型还包括GPT-5.6 Luna（约1/6美元）、Claude Haiku 4.5（约1/5美元）。
  • 通用与生态集成：GPT-5.5（若看重成本，2026年7月推出的GPT-5.6 Terra也是有力选项，较GPT-5.5便宜约一半）。工具与插件广，智能体工作流强。
  • 成本最优、隐私、自托管：中国开源权重（DeepSeek V4、GLM 5.2、Kimi、MiniMax）。token单价低，权重在自己手中。
  • 长文档与大型代码库：1M上下文模型（Gemini 3.1 Pro、Grok 4.3、DeepSeek V4、GLM 5.2）。

现实的运行方式是双栈/多栈。在与厂商无关的网关之后设计，按任务类型切换后端便从重写变为改配置。图像生成属于另一类模型，在图像生成器对比一文中单独展开。

8. 对比时的注意事项

基准数字有用，但也有陷阱。其一，基准不等于你的工作负载。SWE-bench高分不保证能解你代码库里棘手的边角案例。其二，标价不等于实付价。缓存、批处理、长上下文附加费与推理力度设置，都会显著改变实际账单。其三，版本变化很快。本文基准日之后，新版本与降价仍会接连而来。

因此推荐的流程很明确：用你自己的50~200个真实任务构建黄金集，在同等条件下让候选模型同台比拼，亲自测量质量、token消耗、时延与成本。你的数据，而非厂商营销，才是最可信的依据。

9. 结论 - 2026年7月的地图

2026年7月的AI模型版图，是「按维度各有冠军」的时代，而非「单一最强」。编程、智能体与大多数日常归Claude Opus 5，推理、多模态与上下文归Gemini 3.1 Pro，通用与生态归GPT-5.5与新推出的GPT-5.6，实时归Grok 4.3，价格与开放性归中国开源权重。正确答案不是「只用一个」，而是「按工作负载部署最契合的模型」。

再次强调，本对比基于2026年7月，模型、基准与价格变化很快。请以本文为起点，再深入到编程工具对比、图像生成器对比、ChatGPT对比Claude、API价格对比等细分文章，亲自验证最契合你工作负载的结论。
