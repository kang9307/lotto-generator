引言：继承是顺位与份额的问题

当至亲离世，悲伤尚未平复，一个现实的问题便随之而来：谁来继承、继承多少?继承看似属于情感领域，但在法律上，它沿着两条轴线被相对清晰地搭建起来——谁成为继承人(顺位)，以及各自继承多少(法定继承份额)。若没有遗嘱，或遗嘱未就全部财产作出安排，剩余财产便依民法规定的顺位与份额进行分割。

本文以韩国民法为准，依次梳理继承顺位、配偶的特殊地位、法定继承份额与配偶5成加算、实际份额计算示例、代袭继承与同时死亡推定，以及守护继承人最低份额的特留分。不过，此处所介绍的属于一般原则；在个案中，贡献份额、特别受益、继承资格丧失、放弃继承等变量都可能改变结果。需先行说明，本文以信息提供为目的，不能替代针对具体个案的法律咨询意见。

1. 继承顺位——谁成为继承人

民法明确规定了血亲继承人的顺位。核心原则是：只要有一名先顺位继承人存在，后顺位便不能继承。顺位如下。

  • 第一顺位——直系卑属： 子女、孙子女等下一世代。有子女时，孙子女原则上不成为继承人。
  • 第二顺位——直系尊属： 父母、祖父母等上一世代。在完全没有直系卑属时成为继承人。
  • 第三顺位——兄弟姐妹： 在既无直系卑属亦无直系尊属时成为继承人。
  • 第四顺位——四亲等以内的旁系血亲： 叔伯姑舅姨、堂表兄弟姐妹等。在先顺位继承人与配偶皆无时成为继承人。

同一顺位有多人时，他们成为共同继承人。例如有三名子女，则三名子女同为第一顺位继承人。亲等不同时较近者优先(如子女优先于孙子女)，亲等相同时多人共同继承。

2. 配偶的特殊地位

配偶与上述血亲顺位分开处理。有直系卑属时，配偶与直系卑属成为共同继承人；无直系卑属而有直系尊属时，与直系尊属成为共同继承人。既无直系卑属亦无直系尊属时，配偶单独继承全部。也就是说，配偶始终排在兄弟姐妹与四亲等旁系血亲之前，实际上几乎总处于继承人的地位。

此处的配偶指法律上婚姻的配偶。事实婚关系可能依财产分割等其他法理处理，但据了解，其原则上不属于本文所述法定继承份额的当然继承人，故需个别确认。

3. 法定继承份额与配偶的5成加算

共同继承人之间的份额原则上均等。有多名子女时各自获得相同份额。但配偶有特别规定：配偶与直系卑属或直系尊属共同继承时，在其份额基础上加算5成(50百分比)。即若把一名子女的份额记为1，配偶则按1.5计算。

共同继承构成份额比例
配偶 + 1名子女配偶 1.5 : 子女 1 (= 3/5 : 2/5)
配偶 + 2名子女配偶 1.5 : 子女 1 : 子女 1 (= 3/7 : 2/7 : 2/7)
配偶 + 3名子女配偶 1.5 : 每名子女 1 (= 3/9 : 各 2/9)
配偶 + 父母(无子女)配偶 1.5 : 父·母 各1
配偶单独(无直系亲属)配偶 100百分比

如表所示，配偶与两名子女继承时，将整体分为7份，配偶得3份，两名子女各得2份。5成加算仅适用于与直系卑属或直系尊属的共同继承；配偶单独继承时，则根本无需加算这一概念。

4. 法定继承份额计算示例

用具体数字来确认。假设继承财产为7亿韩元，由配偶与两名子女共同继承。

继承人份额金额(以7亿韩元为准)
配偶3/7约3亿韩元
子女A2/7约2亿韩元
子女B2/7约2亿韩元

若没有子女，而由配偶与被继承人的父母继承，则比例为配偶 1.5 : 父 1 : 母 1，将整体分为3.5份。配偶得1.5/3.5(= 3/7)，父母各得1/3.5(= 2/7)。可见继承人构成一变，分母便随之改变，因此先确定谁是继承人(顺位)再计算份额的顺序至关重要。

分情形计算——继承人构成一变，分母随之改变

同样一笔财产，继承人构成不同，结果会有多大差别？以下用五个情形作比较。为便于对照，各情形均假设继承财产为7亿韩元，且完全没有债务、遗嘱、贡献份额与特别受益。

情形继承人构成份额金额(以7亿韩元为准)
情形A配偶 + 2名子女配偶 3/7，子女各 2/7配偶3亿，子女各2亿韩元
情形B配偶 + 父母(无子女)配偶 3/7，父·母各 2/7配偶3亿，父母各2亿韩元
情形C3名子女(无配偶)各 1/3各约2亿3,333万韩元
情形D配偶单独(无直系亲属)1/17亿韩元全部
情形E2名兄弟姐妹(无配偶与直系亲属)各 1/2各3亿5,000万韩元
  • 情形A(配偶 + 2名子女)： 以1.5 + 1 + 1 = 3.5为分母，为消去小数在两侧乘以2，换算为7。配偶得3/7 = 3亿韩元，两名子女各得2/7 = 2亿韩元。
  • 情形B(配偶 + 父母)： 唯有一名子女也没有时，父母方成为第二顺位继承人。分母为1.5 + 1 + 1 = 3.5，与情形A相同，故结果比例同样是3/7 : 2/7 : 2/7。若父母仅一方在世，分母变为1.5 + 1 = 2.5，配偶得3/5，父母得2/5。
  • 情形C(3名子女，无配偶)： 即配偶先行去世或已离婚的情形。既无5成加算的对象，三名子女便均等各得1/3。子女的性别、婚否、是否同住，均不影响法定继承份额。
  • 情形D(配偶单独)： 既无直系卑属亦无直系尊属时，配偶单独继承全部。兄弟姐妹后于配偶，故此情形下分文不得。
  • 情形E(仅兄弟姐妹)： 唯有配偶、直系卑属、直系尊属皆无时，第三顺位的兄弟姐妹才成为继承人。因属同一顺位，按人数均等分配。

五个情形显示：顺序并非先算金额，而是先确定继承人名单，再立起份额的分母。不过在实际案件中，还要叠加继承债务与丧葬费、贡献份额与特别受益、遗嘱内容，最终到手的份额可能因此改变。

5. 代袭继承——先亡继承人的份额

代袭继承是指本应成为继承人的直系卑属或兄弟姐妹，在继承开始(被继承人死亡)前已死亡或丧失继承资格时，由其直系卑属或配偶代替其顺位成为继承人的制度。常见例子是：祖父去世前父亲已先行去世，则父亲本应获得的份额由孙子女(以及父亲的配偶，即儿媳)承接。

在代袭继承中，代袭继承人所得的总额原则上与已死亡继承人(被代袭者)在世时本应获得的份额相同，再由代袭继承人之间按各自的继承份额进一步分配。若有多名孙子女，则由孙子女均等分配父亲的份额；若儿媳一并在列，则按5成加算原则分配。

6. 同时死亡推定与代袭继承

因事故等导致多人一同死亡、无法确定谁先死亡时，民法推定他们同时死亡。其宗旨在于：当死亡先后无法证明时，将其作为同时死亡处理在结果上最为公平。被推定同时死亡者之间，原则上互不发生继承。

不过，就代袭继承而言有一点须留意。判例在被继承人与被代袭者(如父与子)被推定为同时死亡的情形下，仍承认代袭继承。例如祖父与父亲在同一事故中被推定同时死亡时，孙子女可代袭父亲而继承祖父的财产。此类个案常有争议，务必获取专业判断方为稳妥。

7. 特留分——继承人的最低份额

被继承人可通过遗嘱或生前赠与自由处分财产，但若因此将某位继承人完全排除，可能危及其余家属的生计。为防止这一情形，法律为一定范围的继承人认可了作为最低保障份额的特留分。一般所知的特留分比例如下。

继承人特留分比例
直系卑属法定继承份额的1/2
配偶法定继承份额的1/2
直系尊属法定继承份额的1/3
兄弟姐妹因2024年违宪裁定而废止

值得关注的变化在于兄弟姐妹的特留分。宪法裁判所已于2024年4月裁定规定兄弟姐妹特留分的条款违宪，据此，在该裁定之后开始的继承中，兄弟姐妹不再能主张特留分。此外，法院还指出缺乏使特留分丧失的事由及反映贡献份额的规定属于宪法不合致，相关立法整备一直在推进——因此特留分是近年变动较大的领域，须予留意。特留分的结构与返还请求方法，在特留分完全指南中有更详细的说明。

8. 继承程序概览——承认·放弃·限定承认

继承在被继承人死亡的瞬间即无须另行程序而自动开始。问题在于，继承财产中可能包含债务(消极财产)。此时继承人有三种选择。

  • 单纯承认： 原样承继财产与债务。若不作任何申报而逾期，可能被视为单纯承认。
  • 限定承认： 仅在所继承财产的限度内清偿被继承人的债务。在债务可能多于财产时采用。
  • 放弃继承： 视为自始不曾为继承人，既不承继财产也不承继债务。

限定承认与放弃继承须自获知继承开始之日起的法定期间内向家庭法院申报。逾期将被作为单纯承认处理，可能连债务一并承继，因此期限管理极为重要。确切的期间、程序与所需文件因个案而异，须向法院、法务士或律师确认。相关程序可一并参考放弃继承·限定承认指南与遗产税·赠与税指南，有助于理解全貌。

9. 继承开始后有期限的程序

继承中最危险的，是因不知情而错过的期限。自继承开始(死亡)之时起，多项程序便以各自不同的起算点与期间同时运转，其中放弃继承、限定承认与税务申报一旦逾期便难以挽回。主要期限归纳如下。

程序期限起算点
死亡申报1个月以内获知死亡事实之日
放弃继承·限定承认申报3个月以内获知继承开始之日
安心继承一站式服务申请1年以内死亡日所属月份的最后一日
遗产税申报·缴纳6个月以内继承开始日所属月份的最后一日
取得税申报·缴纳(不动产·汽车等)6个月以内继承开始日
  • 死亡申报1个月： 《家族关系登记等相关法律》规定，应自获知死亡事实之日起1个月内附具诊断书或检验书办理申报；无正当理由迟延的，据介绍可被处以罚款。
  • 放弃继承·限定承认3个月： 须自获知继承开始之日起3个月内向家庭法院申报。该期间称为熟虑期间，据介绍如有事由，可在期间届满前向法院请求延长。
  • 特别限定承认： 若非因重大过失而未能在3个月内知悉债务多于财产，则设有例外：可自知悉该事实之日起在法定期间内办理限定承认。要件严格，务必经专业人士确认。
  • 遗产税6个月： 须自继承开始日所属月份的最后一日起6个月内向主管税务署申报并缴纳。被继承人或继承人在境外有住所的，期间另有更长规定。
  • 取得税6个月： 继承不动产、汽车等取得税应税对象的，据介绍须自继承开始日起6个月(有境外住所继承人的为9个月)内申报缴纳。
  • 继承登记： 并非明定法定期限的程序，但拖延登记会阻断财产处分与担保设定，期间若有继承人去世，权利关系将更趋复杂，故与税务申报一并办理更为稳妥。

期限与起算点可能因法令修订而变化，「获知之日」究竟为何时，更是个案中常有争议的焦点。若日期计算含糊，切勿自行判断，宜向家庭法院、税务署或专业人士确认。

10. 继承人调查与继承财产的确认方法

纵然知晓顺位与份额，若不清楚继承的到底是什么，也无从判断应当承认还是放弃。为此，韩国政府运营安心继承一站式服务(死亡者及被监护人等财产查询统合处理)，可一次性查询死亡者的金融交易明细、土地、汽车、税金、养老金参保与否等。既可前往市·区厅或邑·面·洞行政福利中心申请，也可在政府24经简易认证或证书登录后在线申请；办理死亡申报时一并受理，程序会简便许多。

以下是继承开始后宜按顺序核对的清单。因个案所需项目不同，与其照搬，不如用作查漏补缺的工具。

  • 多开具几份死亡诊断书·尸体检验书，因部分机构要求提交原件，往往需要数份。
  • 自获知死亡事实之日起1个月内，向主管市·区或邑·面·洞办妥死亡申报。
  • 随死亡申报一并申请安心继承一站式服务，受理财产查询。
  • 开具被继承人的基本证明书·家族关系证明书·婚姻关系证明书·除籍誊本，确定继承人范围。
  • 核查有无被遗漏的继承人，如婚外子女、经认领的子女、养子女、前次婚姻所生子女等。
  • 确认有无先于被继承人死亡的子女或兄弟姐妹，若有则查明代袭继承的对象。
  • 取得金融查询结果，将存款·保险·证券与贷款·信用卡债务分为积极财产与消极财产加以梳理。
  • 不动产应调取登记事项证明书，确认抵押权·假扣押等权利关系。
  • 确认国税·地方税欠缴情况，以及被继承人是否负有保证债务。保证往往难以在查询结果中显现，是典型的盲区。
  • 清点汽车·工程机械·会员权·知识产权等容易被遗忘的名下财产。
  • 确认是否尚有应收款项，如未申领的保险金·退职金·遗属养老金等。
  • 确认遗嘱是否存在。依自书证书·公证证书等方式不同，可能需经法院的检认程序。
  • 若债务看似多于财产，应在3个月期限内考虑放弃继承或限定承认。
  • 须注意先顺位继承人全体放弃后债务可能转移至下一顺位，故应连同后顺位继承人一并判断。
  • 若有继承人受过生前赠与，可考量特别受益；若有继承人在看护·扶养或财产形成上特别出力，则可考量贡献份额是否有主张空间。
  • 协商达成后制作继承财产分割协议书，由继承人全体盖章。须留意全体一致同意为原则。
  • 自继承开始日所属月份的最后一日起6个月内办妥遗产税申报；不动产·汽车则自继承开始日起6个月内办妥取得税申报。
  • 在税务处理的同时推进继承登记·名义转移；协商破裂时，可考虑家庭法院的继承财产分割审判。

11. 贡献份额与特别受益——调整法定继承份额的变量

迄今所述的法定继承份额只是起点，并非最终结论。为在共同继承人之间求得衡平，民法设有两项调整机制；实务中相当一部分继承纠纷，正是围绕这两者展开。

  • 特别受益： 共同继承人中若有人自被继承人处取得生前赠与或遗赠，该部分视为提前领取的继承份额。据说明，其计算方式为「(继承财产的价额 + 各继承人的特别受益价额) × 各自的继承份额比率 - 本人所受特别受益的价额」。
  • 贡献份额： 认可于在相当期间内以同住·看护等方式特别扶养被继承人，或对财产的维持·增加有特别贡献的继承人。据说明，其计算方式为「(继承财产的价额 - 贡献份额) × 各自的继承份额比率 + 贡献者的贡献份额」，即先划出贡献份额，再分配其余部分。
  • 评估时点： 据说明，核算具体继承份额时，原则上以继承开始时点评估继承财产与特别受益财产。多年前受赠的不动产究竟以何时为准估价，常成为争点。
  • 协商与审判： 贡献份额由共同继承人协商确定；协商不成时，由家庭法院斟酌贡献的时期·方法·程度及继承财产状况等予以认定。是否属于「特别」贡献乃核心争点，因此看护记录、汇款明细、参与经营的凭证等客观材料尤为重要。

归纳而言，按法定继承份额算出的数字并非就此定案，反映特别受益与贡献份额后的具体继承份额才是实际分配的依据。此一领域事实争议大、个案判断各异，若金额差距较大，宜及早寻求专业人士协助。

12. 结语——先确定顺位

继承中要做的第一件事，是确定谁是继承人——即顺位。顺位确定，分母方能确定，在此之上才能适用配偶5成加算来计算各人的法定继承份额。归纳而言：其一，确认从第一顺位直系卑属到第四顺位旁系血亲的顺位；其二，弄清配偶与谁共同继承并反映加算；其三，若有先亡继承人则审视代袭继承；其四，若某位继承人被排除则考虑特留分，若债务沉重则考虑限定承认与放弃继承。

然而在实际案件中，贡献份额、特别受益、继承资格丧失、遗嘱效力、尚未确定的立法等诸多变量交织在一起，仅凭本文的一般原则往往难以得出结论。若面临重大财产决定，请仅将本文用于把握大局，具体判断务必咨询律师、法务士等专业人士。
