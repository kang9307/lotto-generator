血中酸素飽和度(SpO2)の数値の読み方 - 基準範囲、低く出たとき、機器が間違うとき

数値ひとつで判断しないために - 緊急サイン、測定の信頼性、受診時に伝える情報

2026-08-01 健康・暮らし

はじめに: 数値は出たが、受診すべきかは出てこない

引き出しにあったクリップ状の機器を指に挟んだ。94と出た。測り直すと96、もう一度測ると92。三回測るあいだに気持ちだけが落ち着かなくなった。この数値は低いのか、低いとして今すぐ病院に行くべきなのか、それとも明け方で手が冷たいだけなのか。機器はそこを教えてくれない。

検索すると「いくつ以下なら危険」という一文がいくらでも出てくる。その一文は二つのことを同時に前提にしている。第一に、手元のその数値が正確だということ。第二に、数値ひとつで状態を判断できるということ。 この記事は、その両方を疑うところから始まる。

血中酸素飽和度は条件で簡単に揺れる値である。指先の温度、マニキュア、わずかな震えといったものが数値を動かす。だからこの記事の目的は自己診断表を作ることではない。目的は二つである。

  • 見逃してはいけないサインを見逃さないこと。 ある状態では、数値を確認しているのではなく助けを呼ぶのが先である
  • 手元の数値を信じてよいかを分けること。 低い値を見たとき、人を疑うか機器を疑うかという順序の問題である
  • そのどちらも「いくつ以下なら危険」の一行では代替できない。低い数値よりも症状と推移が重要であるというのが、この記事のほぼすべてだと言ってよい

免責事項。 この記事は情報提供を目的としており、診療の代わりにはならない。 個人の状態についての判断と治療の決定は医療者が行う。この記事には酸素の投与方法、薬の名前と用量、特定機器のブランドやモデルは入っていない。意図的に入れていない。 症状があるか判断がつかない場合は、医療機関に連絡する側を選んでほしい。

1. この状態なら測り直さずに救急通報

まず順序を変える必要がある。多くの人は「とりあえずもう一度測ろう」から始めるが、状態が悪いときは測り直しではなく助けを求めるのが先である。測り直すあいだに流れる数分がそのまま損失になる。

以下の状態のうち一つでも当てはまるなら、画面の数値がいくつであっても待たない方が安全である。

  • 息が切れて一文を最後まで言えない — 数語ごとに切って息を継がなければならない状態
  • じっと座っているのに息苦しい — 動いていないのに息が切れるのは普段と違う信号である
  • 呼吸の音や様子が普段と明らかに違う — 肩を上下させる、首を伸ばして息をする
  • 唇・歯ぐき・爪の下が青白い、または灰色がかって見える
  • 意識がもうろうとする、ろれつが回らない、起こしても反応が鈍い
  • 急に力が抜けて座り込む、立っていられない
  • 胸が締めつけられる、押しつぶされるような痛みがある
  • 冷や汗が出て顔色が変わる

この一覧において数値は判断の根拠ではない。 上のいずれかがあれば、酸素飽和度が96と出ていても状況は急かもしれない。逆に89と出ているのにきちんと歩き、話も普通に続くなら、人よりも機器を先に疑うのが順序である。理由は4節で扱う。

1.1 韓国の緊急通報番号は119である

番号から正確にしておこう。韓国の救急通報・相談番号は119である。かつて救急医療案内電話として使われていた1339は119に統合された。韓国の政策ブリーフィングに掲載された政府ブリーフィングは、救急医療通報番号1339を119に統合する内容の法律が施行され、全国で統合運用中であると記している。今も緊急時に1339を押すよう案内している資料が残っているなら、それは古い情報である。韓国以外にいる読者は、その地域の緊急通報番号を使えばよい。

そしてここから実際に役立つ事実が一つ出てくる。119は出動だけの番号ではない。 同じブリーフィングは、119が1年365日24時間、通報の受付と出動、案内と相談、応急処置の指導、搬送先病院の案内を担うと記している。

判断がつかないときこそ問い合わせてよい。「この程度で呼んでよいのか」で迷って時間を使ってしまう場合が多い。しかし案内・相談と応急処置の指導は、その業務範囲に含まれている。行くべきかどうかを自分で結論づけてから呼ぶものではない。 韓国以外でも、その地域の番号について同じ理屈が当てはまる。

すべての状況が緊急なわけでも、すべてが待ってよいわけでもない。おおまかに層を分けるとこうなる。この表は診断表ではなく優先順位表である。

状況何を見て判断するか行動

症状は明らかでないが数値が低いままだ測り直しの再現性当日または早期に受診を予約

最後の行が特に重要である。基準範囲内の数値は「大丈夫だ」という証明ではない。 この機器は酸素がヘモグロビンにどれだけ結合しているかを推定するだけで、体で起きていることの全体を見ているわけではない。数値がよいことを理由に予約した診療を先送りするのは、この記事が勧めないことである。

2. SpO2は正確には何を測る数値なのか

名前から解いていこう。酸素飽和度とは血液中のヘモグロビンのうち、酸素を運んでいるものの割合である。米国国立医学図書館が運営するMedlinePlusは、血中酸素値の検査を説明する中で酸素飽和度の項目を「赤血球がどれだけ酸素を運んでいるかを測るもの」と記している。つまり血液の中に酸素が何ミリリットル入っているかではなく、運搬役がどれだけ埋まっているかを見る比率の値である。

指に挟む機器がこの比率を割り出す方法は採血ではない。指に光を通し、脈が打つたびに変化する吸収量を読む。 酸素を結合したヘモグロビンとそうでないヘモグロビンとで光の吸収の性質が違うことを利用している。この原理を覚えておけば、4節の誤差一覧はすべて自然に導かれる。

2.1 動脈血の検査と何が違うのか

医療機関で手首の内側などから針で採血して行う検査がある。静脈ではなく動脈から採る検査である。MedlinePlusの同じ説明に沿って整理すると、違いはこうなる。

  • パルスオキシメーターはクリップのような小さな機器をたいてい指に挟んで使い、酸素飽和度という値ひとつを推定する
  • 動脈血の検査は動脈から針で採血し、酸素飽和度だけでなく血中酸素分圧、二酸化炭素、酸塩基平衡まで併せて見る
  • 同じ説明は、血中酸素値だけがわかればよい場合にはパルスオキシメトリーが有用な場合があると記している。つまり両者は代替品ではなく用途の異なる道具である
  • 動脈からの採血は一般的な採血より不快であり、ごくまれに神経や動脈が損傷しうることも併記されている。気軽に行う検査ではない
  • 実務的な結論。自宅の機器は「今確かめる理由」を与え、判断の根拠となる精密な値は医療機関から出る

健康診断で受ける一般的な血液検査の結果を項目別に読む方法は健康診断の血液検査結果の読み方ガイドで別に扱っている。この記事はそちらには踏み込まず、指に挟む機器が出す数値ひとつに集中する。

3. 基準範囲 - 確認できたことと確認できなかったこと

この節がこの記事でもっとも慎重を要する部分である。数字を書いた瞬間、読む側はそれを境界線として読むからである。

確認できたこと。 MedlinePlusは血中酸素値の検査における酸素飽和度の基準範囲を95から100パーセントと記している。この記事が実際にページを開いて確認した数値はこれ一つである。

ただしこの数字を自分の体に当てはめる前に、知っておくべきことがある。

  • この範囲は検査項目の参考基準であって、「これを下回れば病気」という境界線として作られたものではない
  • 家庭用機器の値は測定条件で揺れる。 同じ人が同じ時刻に測っても、指や姿勢によって値が変わることはよくある
  • したがって範囲をわずかに外れた値ひとつで状態は確定できない。逆に範囲内の値ひとつで安心することもできない
  • 意味があるのは本人の普段の値と今の値の差、そしてその差が繰り返されるかである。一点よりも推移の方が情報量が多い

3.1 持病があれば目標が異なることがある

慢性の呼吸器疾患や心疾患がある人は、管理目標が一般的な基準と異なって設定される場合がある。 一般基準より低い値を目標に管理する状況もあれば、その逆もある。

ここでこの記事は数字を書かない。 疾患別の目標範囲を一次情報源で直接確認できなかったからである。確認できていない数字を書いておくと、それが誰かの目標値としてそのまま使われる危険がある。代わりにこう整理する。

  • 該当すると思うなら、目標値は検索で決めず主治医と決める。「私の目標範囲はいくつと考えればよいですか」は診察室で聞ける具体的な質問である
  • 決まった目標があるなら、その数字と併せて「どうなったら連絡するか」という基準まで一緒に決めておく方が役に立つ
  • 一般基準を自分の目標にするのは避けた方がよい。 人によって方向が逆になりうるからである

4. 機器が間違う条件 - 光で測るがゆえに起きること

2節で見た原理をもう一度取り出そう。この機器は指に光を通し、脈に合わせて変化する吸収量を読む。 そうすると誤差の原因は三種類に整理される。光の通り道をふさぐもの、脈の信号を弱くするもの、信号を揺らすもの。 下の表がその分類である。

条件なぜ問題になるかどうするか
濃いマニキュア、ラメ入りの製品光の通過を妨げ、吸収を変える落として測り直し、難しければ別の指
つけ爪、ジェルネイル、爪の装飾センサーと爪のあいだに層ができる外すか、別の指で測る
冷たい手指先の血流が減り脈の信号が弱くなる温めてから測り直す
指先の血流が少ない状態読むべき波形そのものが小さい手を心臓の高さに、締めつける指輪を外す
震え、動き、話しながらの測定波形が揺れ脈の認識がずれる止まって数秒待ってから値を読む
不規則な脈機器が脈の周期をとらえにくくなる脈拍を照合、繰り返し測定、受診時に伝える
直射日光、とても明るい照明外部の光がセンサーに入る手を覆うか、日陰で測る
緩いセンサー / 締めつけすぎのセンサー光が漏れる、あるいは血流を押さえてしまう指の太さに合わせ、奥まで押し込まない
運動や階段の直後脈と呼吸がまだ落ち着いていない数分休んで安静時に測る

もっとも役立つ自己点検が一つある。 機器の画面にはたいてい脈拍も一緒に出る。その値を手首で直接取った脈と比べてみてほしい。両者が大きく違うなら、その測定は信頼しない方がよい。 酸素飽和度と脈拍は同じ波形から取り出す値なので、脈をきちんととらえられていないなら酸素飽和度も一緒にずれている可能性が高い。数値ひとつでは分からなかったことが、二つの数値を照合すると分かる。

4.1 肌の色についてこの記事が言えること

肌の色による測定誤差は、近年の規制当局が扱っている論点である。米国の規制当局が肌の色の幅全体でパルスオキシメーターの性能を改善するための勧告改定を提案したという発表があり、それに先立って精度の限界に関する安全性の案内も出ている。

ただしこの記事を書く過程で当該機関の原文ページを直接開けなかった。 接続は試みたが本文を受け取れなかった。そのため誤差が何パーセントポイントといった数字はここに書かない。 確認できていない数字を書くことは、この記事が避けようとしているまさにその行為だからである。

実務的に残る結論はこの記事の論旨と同じである。数値ひとつを絶対的な基準として使わないこと。 測定値に人によって異なる偏差がありうるなら、その値ひとつで緊急か否かを分ける方法はもともと危うい。症状と推移を併せて見る方法は、この種の不確かさにはるかに強い。

5. 信頼できる測り方

測定そのものは難しくないが、順序を守ると値がずっと揺れにくくなる。

  1. 手を整える。 マニキュアやつけ爪を確認し、手が冷たければ温める。締めつける指輪は外す
  2. 安静にする。 座って最低でも数分休む。階段を上った直後や会話中に測った値は参考にしにくい
  3. 姿勢を決める。 手を心臓の高さくらいに置き、腕を垂らしたままにしない
  4. 待つ。 挟んですぐ出る最初の数字ではなく、値が安定してからの数字を読む
  5. 脈拍を照合する。 画面の脈拍と手首の脈が近いかを見る
  6. 指を変えてもう一度測る。 値が大きく違うなら両方とも疑いの対象である
  7. 記録する。 値だけ書かず、時刻・姿勢・指・脈拍・症状を一緒に書く

記録について一つ付け加える。人はたいてい低い値だけを覚えて記録する。 するとあとから推移が見られない。普段の値がどの程度かを知ってはじめて今の値が低いかどうか判断できるので、異常のないときの値も何回か書いておく方が実際には役に立つ。

6. 低く出たときの手順

この節がこの記事の実行部分である。順序を変えると結果が変わる。

  1. まず症状を見る。 1節の一覧に当てはまるならここで止めて救急通報。この段階を飛ばさないことが核心である
  2. 機器と条件を疑う。 4節の表を上から順に見ていく。低い値の大半はここで説明がつく
  3. 手を温め、安静にしてから測り直す。 指を変えてもう一度
  4. 脈拍を照合する。 ずれていればその測定はなかったものとみなす
  5. 記録する。 時刻、姿勢、指、値、脈拍、症状
  6. それでも低い状態が繰り返すなら受診を予約する。 症状があるなら当日に

しないこと。 低い値を見たからと酸素を自己判断で使わない。 処方なしに薬を増やしたり中止したりしない。 この二つは状態によってはかえって害になりうるし、この記事はその判断を代わりにできる立場にない。もう一つ、症状がはっきりしているのに測り直しばかり繰り返すこともしない。それは確認ではなく遅延である。

7. とくに気をつけたい人

この節では診断名を付けない。「こういう症状ならこの病気です」はこの記事の仕事ではないし、そう書かれた文章はたいてい人を誤った安心か不要な恐怖へ連れていく。代わりに「該当するなら主治医と目標値を決めておく」という形でだけ書く。

  • 慢性の呼吸器疾患で管理を受けている人。 目標範囲と連絡の基準をあらかじめ決めておけば、夜中に数値を見て一人で悩む状況を減らせる
  • 心疾患で管理を受けている人。 脈が不規則だと測定値の信頼性そのものが下がる点も併せて覚えておくとよい。不整脈全般は心房細動・不整脈 完全ガイドで別に扱っている
  • 高齢の方、または回復期にある人。 普段の値を何回か記録しておけば「普段より低い」を判断する根拠ができる
  • 睡眠中に呼吸がよく止まっていると言われる人。 この場合は家庭用機器の夜間の数値で自分で結論を出すより、必要な検査を相談する方がよい。関連内容は睡眠時無呼吸症候群ガイドにある
  • 喫煙する人。 喫煙の有無と直近に吸った時刻は、受診時に伝える項目に入れておくとよい
  • いずれの場合も機器を買うことより、目標と連絡の基準を決めておくことが先である。基準のない数字は不安だけを生む

逆方向も押さえておこう。特別な事情のない人が毎日酸素飽和度を測る理由は大きくない。 頻繁に測れば自然と低い値が一度は出るし、その一度が不要な心配を作る。この機器は気になったときではなく、理由があるときに使う道具に近い。

8. 家庭用機器の限界

同じ形をしていても機器の性格は同じではない。この記事ではブランドやモデルには触れないが、確認できることは押さえておける。

  • 医療機器として審査を経た製品と、健康管理用として流通する製品が混在している。 箱や説明書の承認・認証の表示がその区別を示す。購入の前でも後でも確認できる項目である
  • この記事は各国の承認区分の正確な分類体系を一次情報源で確認できなかった。そのため「何等級ならよい」といった基準は書かない。 代わりに製品に承認関連の表示があるか、説明書に精度に関する記載があるかを自分で見るとだけ書く
  • 絶対値よりも変化を見る用途に近い。同じ機器で、同じ指で、似た条件で測った値どうしを比べるときに情報が生まれる
  • 機器が違えば値も違いうる。医療機関で測った値と自宅で測った値が違うからといって、どちらかが壊れているわけではない
  • 電池が弱ると値が揺れる場合がある。おかしな値が続くならまず電池を交換してみるのが順序である
  • 機器は警報装置ではない。 眠っているあいだの異常をとらえてくれると期待して使う物ではないし、その期待はむしろ対応を遅らせる

9. 受診時に伝える情報

自宅で測った値を診察室で役立つものにするのは、数値そのものではなく文脈である。「92が出ました」よりも、以下の情報が付いている方がはるかに有用である。

  • いつから低く出はじめたか — 日付とおおよその時間帯
  • どの姿勢・状況で測ったか — 安静時か、動いた後か、起床直後か
  • 何回測り、値がどうばらついたか — 最低値、最高値、代表的な値
  • 同じ時刻の脈拍数、そして手首で取った脈と近かったか
  • 随伴症状とその変化 — 息切れ、咳、胸痛、めまい、むくみ、発熱
  • 既存の診断名と服用中の薬、最近変わったもの
  • 最近の発熱・感染・手術・長距離移動の有無
  • 喫煙の有無と直近に吸った時刻
  • 使った機器の製品名と承認表示の有無
  • 自宅で測った値であるという事実そのもの。 機器と条件が医療機関とは異なるという前提が伝わる必要がある

下のコピー用ドキュメントに、これらの項目を空欄の書式として入れてある。記憶に頼って話すより、書いて持っていく方が正確である。

10. この記事が確認できたことと、できなかったこと

医療情報を扱う文章でこの区別を書いておかないと、読む側はすべての文が同じ重みを持つと誤解する。だから分けて書く。

10.1 一次情報源で直接確認できたこと

  • 酸素飽和度の定義と基準範囲95から100パーセント — MedlinePlusの血中酸素値の検査の文書
  • パルスオキシメトリーと動脈血の検査の違い、動脈採血の不快さとまれな危険 — 同じ文書
  • 1339の119統合と119の業務範囲 — 韓国の政策ブリーフィングに掲載された政府ブリーフィング

10.2 確認できなかったため書かなかったこと

  • 機器の精度の許容誤差。 規制当局のページを開けなかったため、パーセントポイントの数値を書いていない
  • 肌の色による誤差の大きさ。 論点が扱われているという事実だけを書き、数字は書いていない
  • 疾患別の目標酸素飽和度の範囲。 原文確認に失敗したため数字を書かず、主治医と決めるという文で代えた
  • 家庭用機器の承認区分の分類。 正確な体系を確認できなかったため、表示を自分で見るという案内で代えた
  • 韓国の国家健康情報ポータルの該当項目と、英国の保健当局の患者向け案内文書は本文を開けなかった。 そのため引用していない

この一覧が長いことは、この記事の弱点のように見えるかもしれない。しかし確認できていない数字をもっともらしく書いておく方がはるかに危険である。 とくにこの主題では、誤った境界線ひとつが受診を遅らせたり不要な恐怖を作ったりする。

よくある質問

基準範囲内なら安心してよいか?

そうとは言いにくい。この機器はヘモグロビンに酸素がどれだけ結合しているかを推定するだけで、体で起きていることの全体を見ていない。数値が正常でも症状があるなら症状を基準に判断する方が安全である。

何回測るのが適当か?

おかしな値が出たときは条件を直して二、三回、指を変えてもう一回くらいが実用的である。それ以上繰り返すのは確認ではなく遅延になりやすい。症状があるなら繰り返し測定より連絡が先である。

寝ているあいだに測ってもよいか?

就寝中の値は姿勢や手の温度、センサーの外れの影響を大きく受ける。一人で解釈するには変数が多すぎる。 睡眠中の呼吸について確かめたいことがあるなら、必要な検査を相談する方がよい。

指以外の場所に挟んでもよいか?

製品ごとに指定された使用部位が異なる。説明書に書かれた部位に従うことが原則であり、勝手に別の場所で測った値は比較の対象にしにくい。

数値がよければ予約した診療を先送りしてよいか?

勧めない。基準範囲内の数値は診療を先送りする根拠にならない。 この機器の値は診療の代替物ではなく、受診時に伝える情報の一つである。

# 血中酸素飽和度(SpO2) — 緊急サイン · 測定の信頼性 · 受診時に伝える情報

> 出典: braindetox.kr — 血中酸素飽和度(SpO2)の数値の読み方
> 目的: 自己診断ではなく「受診すべき時を逃さない」ための整理
> この文書は情報提供が目的であり、診療の代わりにはならない。判断は医療者が行う。

## 0. はじめに読むこと

- 数値ひとつで判断しない。**症状**と**推移**を合わせて見る。
- 状態が悪いときは、測り直すより**助けを呼ぶことが先**である。
- 韓国の救急通報・相談番号は**119**である。かつての救急医療案内電話1339は119に統合された。
- 韓国以外にいる場合は**現地の緊急通報番号**を使う。
- この文書には酸素の投与量、薬の名前、機器のブランドが入っていない。意図的に入れていない。

## 1. この状態なら迷わず救急通報(数値と無関係に)

ひとつでも当てはまるなら、測り直さずに連絡する。

- [ ] 息が切れて**一文を最後まで言えない**
- [ ] じっと座っているのに息苦しい
- [ ] 呼吸の音や様子が普段と明らかに違う
- [ ] 唇・歯ぐき・爪の下が**青白い、または灰色がかって**見える
- [ ] 意識がもうろうとする / ろれつが回らない / 起こしても反応が鈍い
- [ ] 急に力が抜けて座り込む
- [ ] 胸が締めつけられる、押しつぶされるような痛みがある
- [ ] 冷や汗が出て顔色が変わる

**判断がつかないときも問い合わせてよい。** 韓国の119は通報受付と出動だけでなく、案内・相談、応急処置の指導、搬送先病院の案内までを24時間担っている。

## 2. 測定の信頼性チェック — この数値を信じてよいか

低い数値が出たら、人よりも**機器と測定条件を先に**疑う。

### 光の通り道をふさぐもの

- [ ] マニキュア(特に濃い色・ラメ)を落としたか
- [ ] つけ爪・ジェルネイル・爪の装飾を外したか
- [ ] 指が清潔か(汚れ、インク、染料)

### 脈の信号が弱くなるもの

- [ ] 手が冷たくないか(冷たければ温めてから測り直す)
- [ ] 手を心臓の高さに置いているか
- [ ] 指を強く締めつける指輪やバンドがないか

### 信号を揺らすもの

- [ ] 動かずにじっとしていたか
- [ ] 話しながら測っていないか
- [ ] 手の震えがあるなら別の指でも測ったか
- [ ] 脈が不規則に感じられないか(機器が脈をとらえにくくなる)

### 外的な条件

- [ ] 直射日光やとても明るい照明の下ではないか
- [ ] センサーが緩すぎたり締めつけすぎたりしていないか
- [ ] 階段を上った直後ではないか(数分は休んでから測る)
- [ ] 表示された脈拍が手首の脈と近いか(違えばその数値は捨てる)

**脈拍がずれていれば酸素飽和度も信用できない。** 同じ波形から出る値だからである。

## 3. 低く出たときの手順

1. **まず症状を見る。** 1番の項目に当てはまるならここで止めて救急通報。
2. **機器と条件を疑う。** 2番のチェックを上から順に確認する。
3. **手を温め、1〜2分安静にしてから測り直す。** 指を変えてもう一度。
4. **脈拍を照合する。** 表示脈拍と手首の脈が違えばその測定は無効とみなす。
5. **記録する。** 時刻・姿勢・指・数値・脈拍・症状。
6. **それでも低い状態が繰り返すなら受診を予約する。** 症状があるなら当日に。
7. **自己処置はしない。** 酸素を自分の判断で使わない。薬を増減しない。

## 4. 記録フォーム(そのまま写して埋める)

```
日付/時刻   :
測定姿勢    : 座位 / 臥位 / 立位
直前の行動  : 安静 / 歩行 / 階段 / その他

マニキュア・つけ爪 : なし / あり
SpO2        :        %

脈拍(手首)  :        回/分

随伴症状    : 息切れ / 咳 / 胸痛 / めまい / むくみ / 発熱 / なし
備考        :
```

## 5. 受診時に伝える情報

- [ ] **いつから**低く出はじめたか(日付、おおよその時間帯)
- [ ] **どの姿勢・状況**で測ったか(安静時 / 動いた後 / 起床直後)
- [ ] **何回**測り、値がどうばらついたか(最低・最高・代表値)
- [ ] 同じ時刻の**脈拍数**
- [ ] **随伴症状**とその変化
- [ ] 既存の診断名、**服用中の薬と最近の変更**
- [ ] 最近の発熱・感染・手術・長距離移動の有無
- [ ] **喫煙の有無**と直近に吸った時刻
- [ ] 使った機器の製品名と**医療機器としての承認表示の有無**
- [ ] 自宅で測った値であるという事実そのもの(機器と条件が医療機関とは異なる)

## 6. してはいけないこと

- 数値ひとつで**緊急かどうかを自分で確定**すること
- 症状がはっきりしているのに**測り直しを繰り返して時間を使う**こと
- 低い値が出たからと**酸素を自己判断で使う**こと
- 処方なしに**薬を増やしたり中止したりする**こと
- インターネットの**「いくつ以下なら危険」という一文**をそのまま自分に当てはめること
- 持病があるのに**一般的な基準値を自分の目標にする**こと(目標は主治医と決める)
- 機器の数値が良いことを理由に**予約した診療を先送りする**こと

## 7. 覚えておく一文

**低い数値よりも重要なのは症状と推移である。** この機器が与えるのは診断ではなく「今の状態を確かめる理由」である。
