チョンセとは何か、なぜ詐欺が起きるのか

チョンセ（전세）は韓国独自の住宅賃貸制度です。入居者が物件価格の50〜80%程度の高額な保証金（チョンセ金）を家主に預け、月家賃なしで居住します。契約終了時に保証金が全額返還されます。韓国では歴史的に家主が入居者の保証金を物件購入・投資に活用してきた背景があります。

問題は、物件価格が下落したとき、または家主がゼロエクイティで複数物件を購入する「無資本ギャップ投資」を行ったときに発生します。家主に保証金を返還する能力がなくなると、入居者が多大な損害を被ります。2020年代前半には韓国社会で深刻な問題となり、2023年6月に「チョンセ詐欺被害者支援および住居安定に関する特別法」が施行されました。2026年現在もその支援は継続・拡充されています。

1. チョンセ詐欺の主な6つの手口

1.1 カンツォンチョンセ（깡통전세 / 空き缶チョンセ）

物件の市場価格がチョンセ保証金と同額またはそれ以下になった状態です。チョンセ価格率（チョンセ金÷売買価格）が80%以上の場合、危険信号とされます。物件を売却しても保証金を全額返還できません。

1.2 無資本ギャップ投資詐欺

売買価格とチョンセ価格の差額（ギャップ）だけを使って複数の物件を購入し、チョンセで貸し出す投資手法です。物件価格が上昇すれば差益を得られますが、下落した場合は保証金を返還できなくなります。複数物件・複数被害者が同時に発生する「組織的チョンセ詐欺」につながるケースが多くあります。

1.3 二重契約・重複契約

1つの物件で複数の入居者と同時にチョンセ契約を結び、保証金を二重に受け取る手口です。所有者でない人物が所有者を装うケースや、既存の入居者が家主の同意なく転貸するケースも含まれます。一度に多数の被害者が発生するのが特徴です。

1.4 信託不動産詐欺

信託会社が法的所有権を持つ物件で、信託会社の同意なく家主がチョンセ契約を締結する手口です。信託登記のある物件では、家主単独でのチョンセ契約は法的に無効となる場合があり、入居者が保護されないリスクがあります。

1.5 対抗力の時差を悪用した詐欺

韓国の法律では、入居者の対抗力（第三者に対する権利主張）は転入申告の翌日0時から発生します。家主が保証金を受け取った当日に根抵当権を設定したり所有権を移転したりすると、そちらが先順位となり、入居者の権利が後順位に押し出されます。

1.6 委任状・印鑑証明の偽造詐欺

登記上の所有者の委任状や印鑑証明を偽造・盗用して所有者を装い、契約を締結する手口です。不動産業者を通じた契約でも、身分証と登記上の所有者の一致を直接確認することが不可欠です。

2. 契約前の予防チェックリスト

2.1 登記簿を3回確認する

登記事項全部証明書（등기사항전부증명서 / 登記簿）は、契約前・契約当日・残金支払日の計3回発行して確認することが基本です。大韓民国法院インターネット登記所（iros.go.kr）で約700ウォンで発行できます。確認事項は以下の通りです。

  • 甲区（所有権）：登記上の所有者と契約相手方の一致、仮差押・差押・競売開始決定の有無
  • 乙区（所有権以外）：根抵当権・信託登記の有無と債権最高額
  • 信託登記がある場合：必ず信託会社の同意書を要求する
根抵当権の債権最高額＋チョンセ保証金が物件の時価の70〜80%を超える場合、競売になっても保証金を全額回収できないリスクがあります。この場合は署名しないことを強く推奨します。

2.2 家主の身元を直接確認する

家主の身分証と登記簿上の氏名・住所を照合します。代理人と契約する場合は、公証された委任状と原本の印鑑証明書（인감증명서）を必ず要求してください。家主に直接電話して確認することも有効です。

2.3 チョンセ価格率の確認

国土交通部の実際取引価格公開システム（rt.molit.go.kr）やHUGの安心チョンセアプリで、近隣の実取引売買価格に対するチョンセ保証金の比率を確認してください。チョンセ価格率80%以上は危険域とされています。

2.4 建築物台帳・納税証明書の確認

政府24（gov.kr）から建築物台帳を入手し、違反建築物でないことを確認します。家主の未納税金がある場合、租税債権が入居者の保証金より優先される場合があるため、納税証明書（미납세금 없음 확인서）の提出も求めることをお勧めします。

3. 契約後の必須手続き：転入申告と確定日付

3.1 転入申告（전입신고）

残金支払い・引越し当日に住民センター（주민센터）または政府24でオンライン手続きを行います。転入申告の翌日0時から対抗力が発生します。申告が遅れるほど、その間に設定された権利に後順位となるリスクが生じます。

3.2 確定日付（확정일자）

賃貸借契約書に住民センター・登記所または政府24でオンラインによる確定日付印の付与を受けます。確定日付の取得日を基準に優先弁済権（競売時における他の債権者より先に保証金を回収する権利）が発生します。

転入申告と確定日付は残金支払日・引越し当日に同時に処理するのが最も安全です。どちらか一方でも遅れると、その間に設定された権利に権利の順位で負ける可能性があります。

4. チョンセ保証保険：HUG・HF・SGI 比較

チョンセ保証保険は、賃貸借契約終了時に家主が保証金を返還しない場合に保証機関が代わりに支払う制度です。2026年時点では以下の3機関が取り扱っています。

機関 HUG（住宅都市保証公社） HF（韓国住宅金融公社） SGI（ソウル保証保険）
対象 個人入居者 チョンセローン連動 公認仲介士通じた個人
主な必須条件 転入申告＋確定日付 ローン実行＋転入 転入申告＋確定日付
加入期限 契約期間の1/2経過前 ローン実行時 契約期間内の一定期間
問い合わせ先 khug.or.kr / 1566-9009 hf.go.kr / 1688-8114 sgi.co.kr / 1670-7000
加入可否・保証料は物件の種類・保証金額・チョンセ価格率によって異なります。必ず各機関のウェブサイトまたは窓口で加入可否を事前に確認してください。

5. 被害発生後の対処：賃借権登記命令

5.1 賃借権登記命令（임차권등기명령）とは

賃貸借契約が満了したにもかかわらず家主が保証金を返還しない場合、賃借人が裁判所に申請して物件の登記簿に賃借権を登記する制度です（住宅賃貸借保護法第3条の3）。登記完了後は転居しても対抗力と優先弁済権が維持されます。

5.2 申請手順

  1. 賃貸借契約書・登記簿・住民登録謄本（転入確認）・確定日付付与確認書などの書類を準備します。
  2. 物件所在地を管轄する地方裁判所（本院・支院を含む）に申請書を提出します。
  3. 大韓民国法院電子訴訟（efiling.scourt.go.kr）でオンライン申請も可能です。
  4. 印紙代約1,800ウォン・送達料約31,200ウォンを支払います。
  5. 裁判所の決定後、登記所への登記嘱託が行われます。登記簿の再発行で完了を確認してください。
賃借権登記完了前に転居すると対抗力が消滅する可能性があります。登記完了前に転居が必要な場合は、まず大韓法律救助公団（電話132）に相談してください。

6. チョンセ詐欺特別法と被害者支援制度

6.1 特別法の概要

「チョンセ詐欺被害者支援および住居安定に関する特別法」は2023年6月に施行されました。2026年時点では、被害者認定申請・支援の有効期限は2027年5月31日まで延長されています。2025年5月31日以前に最初の賃貸借契約を締結した入居者に適用されます。

6.2 被害者認定の申請方法

居住地の管轄市・郡・区役所またはチョンセ詐欺被害支援管理システム（jeonse.kgeop.go.kr）から申請できます。HUGのチョンセ詐欺予防センター（khug.or.kr/jeonse）でも関連情報を確認できます。

6.3 被害者認定時の主な支援内容

  • 競売・公売の猶予および優先買取権：被害物件の競売・公売において被害者に優先落札の機会が与えられます。
  • 低金利への借換えローン：住宅都市基金等を活用した低金利ローンへの切り替え支援が受けられます。
  • 公共賃貸住宅への移転支援：緊急公共賃貸住宅への優先入居権が付与されます。
  • 法律支援：大韓法律救助公団による無料の民事訴訟（保証金返還請求訴訟等）、法務士連携による低コストの法務手続き支援が受けられます。
  • 心理・福祉支援：被害者へのカウンセリングおよび福祉連携サービスが提供されます。

6.4 在韓外国人向け情報

外国人登録を完了し、居住地に住所を登録している外国人入居者は、住宅賃貸借保護法の保護を受けられる場合があります。チョンセ保証保険や賃借権登記命令も利用できる可能性があります。ただし条件が複雑なため、契約前に必ず大韓法律救助公団（電話132、klac.or.kr）または弁護士にご相談ください。

7. 被害発生後の緊急対応手順

  1. 証拠の保全：賃貸借契約書・振込確認書・メッセージ履歴・すべてのバージョンの登記簿を保管します。
  2. 転居を保留：賃借権登記完了前の転居は対抗力を失わせます。
  3. 賃借権登記命令を申請：管轄地方裁判所または電子訴訟サイトで即時申請します。
  4. 大韓法律救助公団に無料法律支援を依頼：電話132またはklac.or.krへ。
  5. チョンセ詐欺被害者認定の申請：市・郡・区役所またはjeonse.kgeop.go.krで申請します。
  6. 警察への届出：詐欺の疑いが明らかな場合は警察（電話112）に刑事告訴します。
  7. HUGへの保証金返還請求：チョンセ保証保険に加入している場合は速やかに請求します。
