Claude Opus 5 登場 - Fable 5級の知能を半額で

effortダイヤルが開くコスト調整の時代、発表数値はどう読むべきか

2026年7月25日 IT・技術

序論: 再び登場したOpus、今回は価格表が核心だ

2026年7月24日、AnthropicがClaude Opus 5を公開した。今回の発表の焦点は新たな最高性能モデルの登場ではなく、価格に対する知能である。同社の発表によれば、Opus 5は上位フラッグシップのClaude Fable 5に近い知能を半額で提供することを目指す。価格は入力100万トークンあたり5ドル・出力100万トークンあたり25ドルで、前世代のOpus 4.8と同じに設定された。Fable 5の定価(入力10ドル・出力50ドル)と比べると、トークン単価が半分という意味だ。

注目すべきは今世代で新たに付いたeffortダイヤルである。一つのモデルをlowからmaxまで複数段階で調整し、性能とトークン消費を引き換える構造で、チャットボット時代の単一モデル選択とは趣が異なる。本稿では発表された仕様とベンチマークを整理し、effortダイヤルが実務で何を意味するのか、どのワークロードにOpus 5を使うのが合理的か、そして自社発表の数値をどこまで信じるべきかを、実務の視点で見ていく。なおMythos 5・Fable 5・Sonnet 5に続き、2か月足らずで登場した4番目のモデルという点で、今回の発表はAnthropicのリリース速度そのものを示す出来事でもある。

1. 何が出たか - 仕様の整理

発表と後続報道を突き合わせて核心を整理すると以下の通りである。数値はいずれも同社発表基準だ。

1.1 価格と位置づけ - Opus 4.8と同じ値でより高い知能

Opus 5は入力100万トークンあたり5ドル・出力25ドルで、値はOpus 4.8とまったく同じだ。つまりAnthropicの論理は価格は据え置いて知能だけを引き上げたというものである。配置の面ではClaude Maxの新しい既定モデルであり、Claude Proで選べる最も強力なモデルとして位置づけられ、コンテキストウィンドウは100万トークン級と紹介された。開発者はAPIでclaude-opus-5としてすぐに呼び出せる。

1.2 effortダイヤル - 一つのモデル、五つの段階

今世代で最も目立つ変化はeffort設定だ。発表によればlow・medium・high・xhigh・maxの5段階で調整でき、Anthropicは大半の作業にlowかmediumを、コーディング作業にはxhighを推奨するとしている。effortを上げるとモデルがより多くの推論とトークンを使って品質を高め、下げるとトークンとコストを節約してより速く安く答えを出す。要するにモデルを選ぶのではなく、同じモデルの強度を選ぶ方式へ重心が移ったわけだ。

1.3 Fastモードと付加機能

発表によれば新しいFastモードは標準比で約2.5倍の速度を出す代わりに基本価格の2倍を課す。遅延が体験を左右する対話型ツールや締め切りが厳しい作業で、速度をコストで買う選択肢だ。このほかAPIには自動フォールバックルーティング、プロンプトキャッシュを壊さずに会話の途中でツールを差し替える機能などが併せて提供されるとされる。いずれも単発の応答品質よりエージェントが長く回るワークフローの運用性を狙った機能と読める。

2. effortダイヤルの実際の意味

2.1 コスト予測可能性という課題

企業がLLMを大規模に組み込む際、最大の悩みの一つがコスト予測である。同じプロンプトでも、モデルがどれだけ長く推論するかによってトークン消費が何倍も変わるからだ。effortダイヤルはこの変動を運用者が事前に制御できるようにする仕組みと見ることができる。低リスク・大量の作業はlow・mediumで束ねて単価を抑え、難しいコーディングや設計判断だけxhigh・maxに上げるという方針を、コードレベルで掛けられるという意味だ。

2.2 モデルルーティングをモデルの中に取り込む

これまで実務では、安価な小型モデルと高価なフラッグシップを状況に応じて切り替えるルーティング設計がコスト最適化の要だった。effortダイヤルはこのルーティングの相当部分を一つのモデルの中で処理しようという試みだ。異なるモデルを行き来する際の品質のばらつきや統合負担を減らせる点は利点だが、逆に本当に安価な大量処理には依然としてHaiku級の小型モデルの方が合う場合があり、ダイヤル一つですべての階層を置き換えると見るのは早計である。

4. 競合モデルとの位置づけ

4.1 同じAnthropicのラインナップの中で

Opus 5の最も直接的な比較対象は自社モデルだ。Opus 4.8とは値が同じなので事実上無償アップグレードの性格であり、Fable 5とは知能差を縮めつつ価格を半分に下げた関係にある。整理すると以下の通りだ。

Claude Opus 5$5$25Fable 5に近い・半額、effortダイヤル

4.2 OpenAI・グーグルと比べると

他社モデルは同じ乾いた基準でのみ言及する。OpenAIはGPT-5.6系列を最上位のGPT-5.6 Solから低遅延・低価格のGPT-5.6 Lunaまでティア分けしており、上の表が示すようにDeepSWE v1.1のような一部のコーディング指標ではSolがOpus 5より高く報告された。グーグルは最近Gemini 3.6 Flash・Gemini 3.5 Flash-Liteなど低遅延の小型モデル側に力を入れている。つまり3社のアプローチは少しずつ異なる。Anthropicは高性能モデルにダイヤルを付けてコスト幅を広げる方向、グーグルは小型・高速の等級を強化する方向、OpenAIはティア自体を細かく分ける方向に重心を置いた形だ。どのアプローチが優れていると断じるより、自分のワークロードがどの軸に敏感かをまず見るのが実用的である。

5. 実務活用の視点 - どこに使うか

5.1 Opus 5が適した作業

effortダイヤルと100万トークン級のコンテキストを踏まえると、Opus 5は長いコードベースを扱うエージェントコーディング、多段階リファクタリング、複雑な文書・データ分析のように、一つの呼び出しの中で深い推論が必要な作業に特に適している。Fable 5級の品質が必要だが予算が負担だった区間を半額でカバーできる点が実質的な利点だ。コーディング作業ならAnthropic推奨どおりxhighから試し、品質が十分なら段階を下げてコストを削るチューニングが可能である。

5.2 慎重に扱うべき区間

逆に分類・ルーティング・要約のように正解が明確で大量に反復される低難度作業なら、Opus 5のmaxではなくlow・mediumに抑えて使うか、いっそHaiku級の小型モデルを使う方が単価の面で有利な場合がある。Fastモードも価格が2倍なので、速度が本当に売上・体験に直結する区間にのみ選択的に入れるのが合理的だ。結局effortとFastはタダではなく、コストを上乗せして性能・速度を買う取っ手だという点を忘れない運用が必要である。

6. 批判的に見るなら - 発表数値の限界

今回の発表で最も注意して読むべき部分はベンチマークだ。示された点数の多くはメーカーが自社の条件で測定した値であり、比較対象・プロンプト・effort設定が有利に合わせられた可能性を排除できない。実際、DeepSWE v1.1のように競合モデルの方が高い指標が同じ発表内に共存し、一部の報道はeffortを最大に上げてもコストだけ増えて点数が下がる指標があったと指摘する。またAnthropic自身、脆弱性のエクスプロイトなどセキュリティ領域では上位モデルに依然として劣ると述べている。つまり半額でFable 5級という一行の要約は平均的な印象にすぎず、すべての作業で成り立つ保証ではない。導入を検討するなら、マーケティングの表ではなく自分の業務サンプルで品質・コスト・遅延を直接測定したうえで、低リスクの区間から広げていく方式が安全だ。

結論

Claude Opus 5の核心は新たな最高記録ではなく価格表とダイヤルである。Opus 4.8と同じ値で知能を引き上げ、effort 5段階とFastモードでコスト・速度の幅を広げたという点で、今回の発表は競争の重心が誰が最も賢いかから、誰が同じ知能をより安く予測可能に売るかへ移りつつあることを示している。グーグルが小型・高速の等級を、OpenAIが細かいティアを推す流れと並べて見ると、方向は異なるが目的地は似ている。実務者がすべきことは明確だ。発表数値は参考線にとどめ、自分のワークロードを難易度別に分けてeffortダイヤルを実データでチューニングし、半額という文言の裏にある条件を自ら検証することである。2026年7月時点で、AIモデル競争はスペック表ではなくコストの取っ手を競う局面に入った。
