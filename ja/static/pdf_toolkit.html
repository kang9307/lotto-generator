🔒 なぜ安全なのか

多くのオンラインPDFサービスはファイルをサーバーへアップロードしてから処理し、結果を返します。便利ですが、契約書・身分証のコピー・給与明細のように他人に見せられない書類となると話は別です。このツールはその工程を最初からなくしました。

  • File APIで読むだけです。 ブラウザがファイルを読んでメモリに載せるだけで、どのアドレスにも送信しません。
  • 結果もブラウザが作ります。 結合したPDFはこのページのJavaScriptが組み立て、ダウンロードはメモリ上の一時アドレスを開いているだけです。
  • ネットワークに出るのはプログラムだけです。 ページを開くときにPDF処理ライブラリを一度取得する以外、書類に関する通信はありません。
  • タブを閉じれば消えます。 サーバーはもちろん、ブラウザの保存領域にも書類を残しません。

自分で確かめたい場合は、ブラウザの開発者ツール（F12）のネットワークタブを開いたまま結合を実行してみてください。ファイルをやり取りするリクエストは1件も現れません。

機能ごとの使い方と出力ファイル名
  • 結合 — PDFを複数入れて矢印で順序を整え、結合するを押します。結果は merged.pdf として保存されます。
  • 分割 — 範囲を「1-3,5,8-10」のように書くか、ページ画像をクリックして選びます。1つのPDFなら pages_1-3,5,8-10.pdf、1ページずつなら ファイル名_p1.pdf の形になります。
  • ページ編集 — ページを選んで回転・削除を適用し、各ページの ◀ ▶ で順序を変えます。結果は ファイル名_edited.pdf です。
  • 画像 → PDF — 写真を順番に入れ、用紙・向き・余白を選びます。結果は images.pdf です。
知っておきたい制限
  • パスワード付きPDFは開けません。 閲覧パスワードや権限パスワードが設定された文書は構造自体が暗号化されており読み込めません。元のアプリでパスワードを解除してからお試しください。
  • しおり・注釈・フォーム・電子署名は失われることがあります。 ページを複製して新しい文書を作る方式のため、文書単位で付いていた情報は引き継がれません。電子署名のある文書は編集すると署名が壊れます。
  • 大きなファイルは端末性能に左右されます。 合計50MBを超えると警告が出ます。処理はすべてこの端末で行われるため、メモリが足りないとタブが重くなります。
  • プレビューは先頭のみ描画します。 ページ数が非常に多い場合は先頭200ページまで画像を描き、残りはページ番号で表示します。抽出や編集自体はすべてのページに適用されます。
  • 文字認識（OCR）や圧縮はありません。 このツールはページ単位の再構成に集中しており、スキャン画像から文字を取り出したり容量を減らす機能はありません。
大切な書類は原本を残しておいてください。 このツールは元のファイルを書き換えず新しいファイルを作りますが、結果を確認するまでは原本を消さないほうが安全です。ブラウザの拡張機能や広告ブロッカーが処理ライブラリを遮ると動作しないことがあります。
