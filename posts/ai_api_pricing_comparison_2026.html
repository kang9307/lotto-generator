2026 AI API 가격 비교 - 백만 토큰 단가 총정리

GPT·Claude·Gemini·Grok와 오픈모델의 input·output 단가, 컨텍스트, 멀티모달, 캐싱 할인을 한 표로 - 개발자·스타트업을 위한 가성비 가이드

2026-06-15 IT/기술

이 게시물은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.

서론: 가격이 곧 아키텍처다

2026년의 AI 개발에서 모델 선택은 더 이상 "어느 게 제일 똑똑한가"만의 문제가 아니다. 같은 기능을 만들더라도 어떤 API를 쓰느냐에 따라 월 청구서가 10배 넘게 갈린다. 특히 B2B 제품이나 스타트업처럼 호출량이 큰 워크로드에서는, 백만 토큰당 단가(per 1M tokens)가 곧 단위 경제성을 결정하고, 단위 경제성이 곧 사업의 생존을 결정한다.

이 글은 2026년 8월 24일 확인 기준의 주요 LLM API 가격을 input/output로 나눠 한 표에 모으고, 컨텍스트 윈도·멀티모달·캐싱 할인이라는 다른 축까지 함께 본다. 그다음 "최고 성능 vs 가성비 vs 오픈"이라는 세 갈래로 용도별 추천을 제시하고, 캐싱과 라우팅으로 비용을 깎는 실전 팁을 정리한다.

가격 변동 면책(중요): 아래 모든 수치는 2026년 8월 24일 확인 기준의 공식 가격으로 정리한 것이다. LLM API 단가는 분기·월 단위로 자주 바뀌고, 프로모션·지역·등급에 따라 다르며, 캐시·배치 할인 구조도 모델마다 다르다. 표 안에는 종료일이 명시된 한시 프로모션 단가(GPT-5.6 Sol, Gemini 3.7 Flash)와 시간대에 따라 두 배로 뛰는 단가(DeepSeek)가 섞여 있어, 같은 행이라도 언제 호출하느냐에 따라 청구액이 달라진다. 실제 도입·견적 전에는 반드시 각 제공사의 공식 가격 페이지에서 최신 단가를 재확인해야 한다. 이 글은 의사결정의 출발점이지, 계약 단가의 근거가 아니다.

2. 가격 외 비교축 - 컨텍스트·멀티모달·캐싱

단가만 보면 그림이 반쪽이다. 실제 비용과 적합성은 다음 세 축에서 갈린다.

2.1 컨텍스트 윈도와 "긴 컨텍스트 프리미엄"

컨텍스트 윈도는 한 요청에 넣을 수 있는 입력 분량이다. 주의할 점은 긴 컨텍스트 프리미엄이다. GPT-5.5는 272K를 넘으면 단가가 한 단계 올라가고, GPT-5.6 세대는 Sol·Terra·Luna 모두 긴 컨텍스트 구간에 별도 단가(각각 $8.00/$30.00, $4.00/$18.00, $0.40/$1.80)를 둔다. Gemini 2.5 Pro는 200K를 넘으면 $2.50/$15.00으로, Grok 4.6은 200K 이상에서 $4.00/$12.00으로 오른다. 반면 Claude 계열에는 이런 구간별 할증이 가격표에 걸려 있지 않다. 긴 문서를 통째로 넣는 워크로드라면 이 프리미엄 구조가 실효 단가를 좌우한다 - 표의 앞 두 열만 보고 견적을 잡으면 실제 청구서와 두 배 넘게 어긋날 수 있다.

2.2 멀티모달 지원

텍스트만 다룬다면 무관하지만, 이미지·오디오·문서를 다룬다면 멀티모달 지원이 선택지를 좁힌다. Gemini 2.5 Flash는 텍스트·비전·오디오·함수호출·정형출력을 저가로 지원해 멀티모달 가성비가 좋다. GPT-5 mini도 텍스트·비전·함수호출을 지원한다. 이미지 토큰은 별도로 계산되며, 고해상도 입력은 토큰 소비가 크게 늘 수 있으므로 멀티모달 워크로드는 텍스트 단가만으로 비용을 추정하면 안 된다.

2.3 캐싱 할인과 속도

같은 프리픽스(시스템 프롬프트, 긴 참조 문서, 도구 정의)를 반복 전송하는 워크로드에서는 프롬프트 캐싱이 비용을 크게 줄인다. 여러 제공사가 캐시 적중 시 input 단가를 약 90% 깎아, 캐시된 토큰을 정가의 약 10분의 1로 청구한다. 또한 저지연이 중요한 실시간 UX에서는 Haiku 4.5·Gemini 2.5 Flash·GPT-5 mini 같은 소형·빠른 모델이 유리하다. 속도와 단가는 대체로 같은 방향으로 움직인다 - 작고 싼 모델이 대체로 빠르다.

3. 용도별 추천 - 최고 성능 vs 가성비 vs 오픈

정답은 단일 모델이 아니라 워크로드별 배치다. 세 갈래로 정리한다.

3.1 최고 성능 - 복잡 추론·고위험 코드

정확성이 곧 신뢰이고 실수 비용이 큰 영역 - 프로덕션 마이그레이션, 보안 민감 코드, 장기 자율 에이전트 - 에서는 플래그십이 안전하다. 현행 세대에서는 Claude Opus 5(input $5.00·output $25.00)와 GPT-5.6 Sol(input $4.00·output $20.00)이 대표 선택지이고, 더 비싼 축으로 GPT-5.6 Cyber(input $12.50·output $75.00)와 Claude Fable 5(input $10.00·output $50.00)가 있다. output 단가가 높으므로, 긴 출력이 잦은 에이전트 워크로드에서는 토큰 폭주를 막는 상한 설계가 중요하다. Claude Sonnet 5는 input $2.00·output $10.00으로 상위권 중에서는 단가가 낮은 축이라, 비용 민감하면서도 높은 성능이 필요한 경우의 균형점이다 - 도입가가 그대로 정가로 굳은 경우이기도 하다.

3.2 가성비 - 대량 호출·실시간 응답

분류·요약·추출·정형 응답처럼 난도가 낮고 호출량이 큰 작업은 소형·저가 모델이 정답이다. 현행 세대에서는 GPT-5.6 Luna(input $0.20·output $1.20)가 표 안에서 가장 낮은 축이고, Gemini 3.5 Flash-Lite(input $0.30·output $2.50)와 Gemini 3.7 Flash(input $0.75·output $3.75)가 뒤를 잇는다 - 다만 3.7 Flash의 단가는 2026년 12월 31일까지만 보장되고 이듬해부터 두 배가 된다. 이전 세대인 Gemini 2.5 Flash(input $0.30·output $2.50)와 GPT-5 mini(input $0.25·output $2.00)도 가성비와 멀티모달을 동시에 잡는다. Claude Haiku 4.5(input $1.00·output $5.00)는 저지연이 필요한 실시간 UX에 좋다. Grok 계열은 4.3이 input $1.25·output $2.50, 4.6이 input $2.00·output $6.00으로, 세대가 올라가며 단가도 함께 올랐다.

3.3 오픈웨이트 - 최저가·데이터 통제

비용 바닥을 노리거나 데이터를 외부로 보내기 곤란하다면 오픈웨이트 계열이 매력적이다. DeepSeek V4 Flash는 호스티드 API 기준 비피크 input $0.22·output $0.66로 여전히 최저가권이지만, 피크 시간대에는 $0.44·$1.32로 두 배가 되므로 「가장 싼 모델」이라는 말이 하루 종일 참인 것은 아니다. GLM 계열은 5.1과 5.3이 모두 input $1.40·output $4.40이고, Kimi K2.7(input $0.95·output $4.00, 256K, 자동 캐싱)의 단가는 2026년 6월 확인값이라 이번 갱신에서 재확인하지 못했다. 다만 오픈웨이트의 진짜 이점인 자체 호스팅은 GPU 자본·운영 부담을 동반하므로, 호스티드 단가가 싸다는 것과 자체 운영이 싸다는 것은 별개의 손익분기 계산이다.

4. 비용 절감 실전 팁

같은 모델을 쓰더라도 설계로 비용을 크게 줄일 수 있다.

4.1 프롬프트 캐싱을 설계 단계에서 끼워라

시스템 프롬프트·도구 정의·긴 참조 문서처럼 변하지 않는 프리픽스를 앞에, 매 요청 바뀌는 질문을 뒤에 두면 캐시 적중률이 올라간다. 캐싱은 프리픽스 매칭이라, 앞쪽에 타임스탬프나 UUID 하나만 섞여도 캐시가 깨진다. 챗봇·RAG·에이전트처럼 고정 컨텍스트가 반복되는 패턴에서는 캐싱만으로 input 비용을 크게 줄일 수 있다.

4.2 모델 라우팅 - 쉬운 건 싸게, 어려운 건 비싸게

모든 요청을 플래그십에 보내는 것은 가장 흔한 낭비다. 난도 분류기를 두고, 쉬운 작업은 Gemini 2.5 Flash·GPT-5 mini·Haiku 4.5 같은 소형 모델로, 복잡 추론·고위험만 플래그십으로 보내면 평균 단가가 급감한다. 공급자 비종속 게이트웨이로 추상화하면, 가격이 바뀌었을 때 모델 교체가 재작성이 아니라 설정 변경이 된다.

4.3 output를 줄이고, 배치를 활용하라

output 단가가 input보다 3~6배 비싸므로, 불필요하게 장황한 출력을 줄이는 것만으로 비용이 준다. 정형 출력(JSON 스키마)으로 군더더기를 없애고, 추론 토큰이 과한 모델은 노력 수준을 낮춰 보이지 않는 output을 통제한다. 지연에 둔감한 대량 작업은 여러 제공사의 배치 API(대체로 50% 할인)로 처리하면 단가가 절반이 된다.

5. 결론 - 단가표가 아니라 실효 비용으로 판단하라

2026년의 LLM 시장은 플래그십이 위에서 성능을 다투고, 소형·오픈모델이 아래에서 단가를 무너뜨리는 양극 구조다. 핵심은 단일 단가표를 외우는 게 아니라, 본인 워크로드의 input:output 비율과 캐시 적중률을 곱한 실효 비용으로 비교하는 것이다. 같은 "백만 토큰 5달러"라도, 캐싱이 잘 먹는 RAG와 추론 토큰이 폭주하는 에이전트의 실제 청구서는 전혀 다르다.

이번 주에 할 구체적 수 세 가지: 첫째, 본인 대표 트래픽 100건의 실제 input·output 토큰을 측정해 모델별 실효 단가를 계산하라. 둘째, 고정 프리픽스에 캐싱을 적용하고 적중률을 확인하라. 셋째, 쉬운 작업을 소형 모델로 라우팅하는 게이트웨이를 두고 플래그십 비중을 줄여라. 그리고 무엇보다, 이 글의 모든 단가는 2026년 8월 24일 확인 기준이며 프로모션·시점에 따라 달라지므로, 견적 전 공식 가격 페이지를 반드시 재확인하라.
