从频率比出发，乐理就变成了规则

八度2:1、纯五度3:2，以及半音为何成了2的12次方根 - 看懂十二平均律这个妥协，剩下的就都变成规则

2026年8月23日 趋势与文化

引言：难的不是概念，是名字

能读代码却读不了乐谱的人不少。可是一个一个问下去，很少有人卡在概念上。真正绊住人的是名字。

看看「纯五度」这个词。纯是什么意思、五在数什么、度是角度还是等级，这个名字一样都没说。「增四度」和「减五度」在键盘上是同一个声音，名字却不一样。

这些名字并不是一次设计出来的。用字母记音的习惯在6世纪成形，把音高固定在线上的记谱在11世纪扎根，今天使用的律制则是很久以后才成为标准。不同时代的决定就这样层层叠在一起，术语之间没有一致性反倒是自然的。想一想向后兼容坚持了二十轮的 API，感觉就出来了。

问题在于，多数入门材料都先教这些名字。把顺序倒过来会快得多。底下只有一样东西，就是频率比，其余全是由它推出来的规则。这篇文章就按这个顺序走：先是比，然后是律制、音阶、和弦、记谱、节奏。最后我还写了这套办法在哪里失效。音乐不是数学，抽掉这一点，这类解释就只剩一半。

从底层说起：音高就是每秒振动的次数

声音是空气压力的变化。这种变化规律地重复时，人就把它听成有音高的声音。一秒重复多少次就是频率，单位是赫兹。

基准点只需定一个。国际标准 ISO 16 把高音谱表上的 A，也就是 A4，定为 440Hz。它于1955年被采纳，在1975年版中得到重申，并要求调律精度在0.5Hz以内。这个数值本身没有物理必然性，它是一项约定。在标准确立之前，欧洲各乐团的基准音在不同城市之间并不一样。

有了一个基准和一条规则，其余音的频率就全都算得出来。MIDI 给每个音配一个0到127的整数，并把 A4 放在69号。

f(n) = 440 * 2 ** ((n - 69) / 12)

f(60) = 261.63 Hz   // 中央C，C4
f(0)  =   8.18 Hz
f(127) = 12543.85 Hz

这条短短的式子里已经藏了两件要紧的事。

  • 音高不是线性的，而是指数的。升高一个八度，频率不是加上一个固定量，而是变成两倍。低八度里的一格与高八度里的一格，用赫兹去量大小完全不同
  • 指数里嵌着一个12。这个12是从哪儿来的，就是本文中间那一大块。它是算出来的结果，不是谁挑的惯例

我们说音程可以相加相减，但实际发生的是比例的相乘。取对数就变成相加，所以后面才需要音分这个单位。

泛音造就了协和

拨一根弦，出来的不止一个频率。基频 f 之外，2f、3f、4f、5f 这些整数倍成分会一起响。这就是泛音列。哪些泛音出来、出来得多强，决定了音色，同一个 A4 在小提琴和单簧管上听起来不同的原因就在这里。两个音同时发声时泛音之间发生的事，才是协和的真正来历。

2:1 为何听起来像同一个音

频率成2:1时，上面那个音的泛音集合会成为下面那个音泛音集合的子集。220Hz 的泛音是220、440、660、880，440Hz 的泛音是440、880、1320。上方成分全都已经存在于下方。没有一个成分是新碰撞出来的。

所以八度听起来不像另一个音，更像同一个音换了高度。音名只用七个、每个八度重复一遍的习惯正是由此而生。名字重复不是偷懒，而是对物理事实的反映。

比例越复杂，听感越粗糙

到了3:2，也就是纯五度，重合虽比八度少，但仍然不少。220Hz 与330Hz 的泛音在660Hz 相遇，又在1320Hz 相遇。往4:3、5:4、6:5 走下去，相遇的点越来越稀疏，取而代之的是彼此不重合却靠得很近的成分越来越多。

靠得很近的两个成分会产生拍音。当这个间距落进人耳的临界频带，听起来就粗糙。Plomp 与 Levelt 1965年发表在美国声学学会会刊上的临界带宽研究用实验把这层关系理清了，要点有两条。

  • 不协和感最强的位置大约在临界带宽的四分之一附近。比这更近或更远，粗糙感都会减弱
  • 临界带宽在100~1000Hz 区间大致恒定在100Hz 左右，再往上则随频率成比例变宽。低音区把和弦叠得太密会发浑，原因就在这里

归纳起来是这样。简单整数比听着悦耳，不是因为数字漂亮，而是因为泛音要么重合、要么离得足够远，粗糙的拍音就没机会出现。这是物理与听觉生理的事，不是算术美学。不过这套解释也有边界，后面会另外交代。

十二平均律是一种妥协

这篇文章只带走一节的话，就带走这一节。为什么任何调上都能弹同一首曲子，为此又让出了什么，都在这里分道。

把五度叠十二次并不回到八度

只信3:2，来造一批音看看。从任意一个音开始不断叠纯五度，第十二次会回到起始音上方七个八度的附近。是附近。

(3/2) ** 12 = 129.746...
2 ** 7      = 128

129.746 / 128 = 531441 / 524288 = 1.013643...
= 约 23.46 音分

大约是四分之一个半音。这个误差有名字，叫毕达哥拉斯音差。

这不是算错，而是改不掉的性质。2 和 3 是不同的质数。不存在一组自然数指数，能让3的幂等于2的幂。五度叠得再多，也永远没有一次会正好落在八度上，只有近似。

那么让出了什么

选择只有两个：守住纯净的比例而放弃转调，或者把比例稍稍拧歪一点而换来转调。历史上长期使用的古律制选了前者。它们在某些调上响得极为清澈，走到远关系调就会冒出难以忍受的音程。

十二平均律选了后者。只把八度保持为精确的2:1，中间切成比例相同的十二份。一份就是一个半音，比值是2的12次方根，约 1.059463。为什么是开方而不是除法？因为音高是指数的，乘十二次必须正好等于2。

这样一来，无论从哪个音出发，往上走七个半音总能得到同一比值的五度。转调变成了移动数组下标。键盘乐器不必再为每个调重新调律，很久以后 MIDI 的整数表示也是搭在这个决定之上的。

用音分量一量偏差有多大

音分是用对数度量音程的单位。一个八度是1200音分，平均律的半音正好100音分。它由 Alexander J. Ellis 在19世纪引入。它把比例的乘法变成加法，比较偏差时很好用。

这张表要读出的是偏差并不均匀。五度的误差只有两音分上下，实际上听不出来。可三度差到14~16音分，大得多。钢琴上的大三和弦比纯律三和弦听着略微紧绷，并不是错觉。

所以音高可以自由调节的乐器和人声，没有理由死守平均律。合唱团或弦乐四重奏在演奏中一点点把和弦往纯律方向拉，正是在把平均律在三度上让出去的东西拿回来。

为什么偏偏是十二

要把八度等分，分成几份好？判断标准很明确：哪种份数能凑出最接近纯五度（701.955音分）的组合。把等分数逐一增大、每次找最接近的值，画面是这样的。

  • 5等分：差18.0音分 / 7等分：16.2音分 / 10等分：18.0音分
  • 12等分：1.96音分
  • 17等分：3.9音分 / 19等分：7.2音分 / 22等分：7.1音分 - 全都不如十二
  • 24等分：1.96音分。它是十二的倍数，五度误差与十二完全相同。把份数切细一倍，五度并不会变好

小于十二的任何等分，都无法把五度控制在16音分以内。到了十二，它忽然掉到两音分以下。十二不是什么神秘数字，而是小数字里几乎唯一能用的解。把十二的来由弄明白，剩下的全部变成数组问题。

音阶就是音程的数组

西方音阶不用满十二个音，而是从中挑七个。怎么挑就是音阶的本体，而挑法用一个数组就能写下。

大调音阶  = [2, 2, 1, 2, 2, 2, 1]   // 以半音计，合为12
自然小调  = [2, 1, 2, 2, 1, 2, 2]

这一个数组一次解开三件事。

  • 调性就是起点。同一个数组从 C 开始就是 C 大调，从 G 开始就是 G 大调。数组相同，只是偏移量不同
  • 调号是算出来的结果。G 大调里有升 F 并不是要背的事实。从 G 出发走 2-2-1-2-2-2-1，第六个音必须是升 F，最后一步才会正好是半音。调号里的升号每上行五度就多一个，也是同一套计算在重复
  • 调式就是旋转。把大调数组向左转五格，得到 2-1-2-2-1-2-2，正是自然小调。所以 C 大调和 A 小调用同一批音，因为它们是同一个循环数组的不同入口

背下七个调式名字，和旋转一个数组，是完全不同的两件事。前者是记忆，后者是 rotate(scale, n) 一行。剩下的问题是为什么偏偏是这个数组，上一节给了答案：按这个数组挑七个音，能在其中造出尽可能多的纯五度与纯四度。从十二个音里随便抓七个是达不到的。

和弦是把音程叠起来

三和弦就是在音阶数组里隔一个取一个、取出三个。用下标写是 [0, 2, 4]。从根音起以半音计，结果是这样。

  • 大三和弦 [0, 4, 7] - 大三度上再叠小三度。频率上大致是4:5:6
  • 小三和弦 [0, 3, 7] - 小三度上再叠大三度。大致是10:12:15
  • 减三和弦 [0, 3, 6] - 两个小三度
  • 增三和弦 [0, 4, 8] - 两个大三度

大和弦与小和弦的差别只在中间那一个音，而且只差一个半音，第一次看到时会觉得意外。明亮与黯淡这整套印象差异，全部出自一个半音。

再往上叠一层就成了七和弦。[0, 4, 7, 11] 是大七和弦，[0, 4, 7, 10] 是属七和弦。属七和弦里，三音与七音之间隔着六个半音，也就是增四度。在十二平均律中这个音程的比值正好是 √2。它是唯一把八度精确对半分开的音程，按前面的泛音逻辑看，它重合的成分最少。所以它听着不稳定，而这份不稳定要求被解决。所谓和声进行，很大一部分就是制造并释放这种张力。

定下一个调，七个和弦就跟着来了。从音阶的每个音出发按同样方式叠即可，结果用罗马数字写出来就是 I、ii、iii、IV、V、vi、vii°。大写是大和弦，小写是小和弦，°是减和弦。它是从数组里自动长出来的结果，不是另外要背的清单。和弦记号同样是压缩写法，Cmaj7 无非是以 C 为根音叠出 [0, 4, 7, 11] 的一条指令。

记谱法之所以让人困惑，是有历史原因的

记谱法不是设计出来的格式，而是被长期打补丁的格式。每个看着别扭的地方都有来由，知道来由之后大多就说得通了。

  • 为什么音名是七个（A~G）。用拉丁字母记音的习惯可以上溯到6世纪初的波爱修。在十二音体系整理出来之前，名字先给了七音体系，其余五个音后来才以升降号挂在既有名字上补进去。七不是因为自然，而是因为它先到
  • 为什么是五线谱。11世纪的圭多·达莱佐把画线固定音高的做法确立了下来。在此之前的记谱只是粗略标出旋律的升降。do-re-mi 这套唱名也出自他手，取自一首拉丁圣咏每一行的第一个音节，而第一个音节原本不是 do 而是 ut
  • 为什么纵向位置不是线性的。在五线谱上往上挪一格，有时是半音，有时是全音。因为五线谱画的是七音体系而不是十二音体系。半音的信息由调号与临时记号另外叠上去。数据分在两层里，初学者最常卡住的正是这一处
  • 为什么降号长得像字母 b。它本来就是 b。中世纪出现了把 B 音降半音来唱的做法，因为听着柔和，就叫它圆 b（b molle），这个圆 b 后来变成了♭。没有降下来的原本的 B 是方 b（b durum），♮与♯就是从它分出来的
  • 为什么升 F 与降 G 声音相同却名字不同。这叫等音。在十二平均律里它们是同一个频率，在纯律里则不是。名字继承的是律制尚未合流那个时代的区分。今天这个区分还留着，是因为功能不同：这个音是要往上走还是往下走，就写在名字里
  • 为什么有调号和反复记号。调号是把升号在开头声明一次，省得每次遇到 F 都写一遍。反复记号则是手抄年代的压缩，那时纸张和抄写时间都很贵

把记谱法看成为旧媒介优化过的存储格式，大部分就都解释得通了。它朝着人易读、省纸、便于手抄的方向演化，从来没有一次是朝着便于机器解析的方向做的。

节奏是另一根轴

如果说音高是频率轴，节奏就是时间轴。两根轴彼此独立，规则也完全不同。结构本身反倒是节奏这边更简单。

  • 音符时值按2的幂次划分。全音符、二分音符、四分音符、八分音符，是二进制细分
  • 附点表示1.5倍。附点四分音符是四分音符的1.5倍，加两个附点是1.75倍。这是把等比级数搬进了记号
  • 三连音是从二进制细分里逃出来的装置。在只能对半分的体系里要做三等分，就得有一套单独的记法
  • 拍号是对细分规则的声明。六八拍有六个八分音符，但实际感受是三个一组、共两组。同样是六个，怎么分组决定了乐种的味道
  • 切分是去打乱对强拍的预期。必须先有关于强拍在哪里的共识，打乱才成立

最后一条很关键。切分并不能仅靠时值来定义，它是只有当听者脑中已经有一张节拍网格时才成立的效果。那张网格不在谱面上，而在惯例里。从这里开始，用结构去解释就渐渐力不从心了。

类比失效的地方

读到这里如果归纳成「音乐说到底就是数学」，那就错了，而且恰好反了。数学只解释材料的性质，音乐讲的是拿这些材料去做什么。这里只举四处失效的地方。

其一、对协和的偏好并不普遍

用泛音重合来解释协和，这套逻辑在物理上很牢固。但它并不等于「人人都更喜欢协和音」。2016年发表在 Nature 上的研究报告说，几乎没有接触过西方音乐的亚马逊齐马内人，把协和和弦与不协和和弦评价为差不多同样悦耳。同一项研究里，玻利维亚城市居民与美国听众则明显偏好协和。作者写道，对协和的偏好看来是在接触某类多声部音乐的过程中形成的。

其二、十二平均律不是世界标准

印度尼西亚甘美兰的斯连德罗（五音）与佩洛格（七音）不是等分音阶，也没有标准调律。每一套乐器都在自己内部调好，村子不同，同名的音实际高度也不同。而且成对的乐器还会被刻意调得相差几个音分以制造拍音，那种颤动被视为美。这正是前面被称作粗糙成因的同一个现象。阿拉伯、土耳其、波斯一系的马卡姆则使用小于半音的音程。西方十二音体系不是普遍语法，只是众多解法中的一种。

其三、真实乐器并不按理论值调律

钢琴最典型。琴弦有刚性，泛音会比整数倍略高一些，这个现象叫非谐性。所以调律师会把八度调得比理论值更宽。低音区比平均律偏低、高音区偏高的这一偏差，以1930年代测量它的人命名，叫雷尔斯巴克曲线。反过来说就是：调得好的钢琴，并不是严格遵守十二平均律的钢琴。

其四、理论是事后的描述

和声学的规则不是哪个委员会定的，而是把特定时期欧洲音乐中反复观察到的模式后来整理出来的东西。它更像风格指南而不是编译器。破了规则的音乐并不会自动变成坏音乐，事实上音乐史相当大的一部分正是朝着破规则的方向走的。

这上面还要再加一条。同一份乐谱交给两位演奏者，出来的是两种音乐。细微的时间偏移、力度的变化、音色、乐句在哪里断开。这层没有写在谱面上的东西，对听者来说占了一半以上。懂结构是懂材料，懂了材料并不等于会做菜。实时插进演奏里的生成模型撞上的墙，归根到底也是这一层。

没能确认的部分

本文的数值要么在公开标准文件和论文里核实过，要么直接由比例算出。没能填上的地方如下。

  • ISO 16 只确认到1975年版。之后是否有修订版，除了目录上的标注之外没能进一步确认
  • 没有写十二平均律是何时成为标准的。理论描述与实务落地之间隔了很长时间，各地区、各乐器的转换时点也不一致，而我没能找到可以据以确定的一手材料
  • 泛音重合理论究竟能解释多少协和知觉，最新的综合结论没能确认。文中写下的只有 Plomp 与 Levelt 的临界频带关系和齐马内研究的结果
  • 没有给出雷尔斯巴克曲线的具体音分值。那是随琴的个体和调律师而变的数值
  • 音分值的精度。表中的值按 1200 × log₂（比值）计算并写到小数点后三位，但这不表示真实乐器能保持那种精度
  • 临界带宽的数字取自1965年那项研究的报告值，没有与其后的研究做对照

从哪里开始

只给一条顺序上的建议。先动手摸声音，名字留到后面再贴。先背名字这个顺序，正是把这门东西搞难的元凶。

  • 自己造频率是第一步。发出一个正弦波，把频率乘2试试，乘1.5试试，乘1.26（2的4/12次方，大三度）试试。先把比例在耳朵里过一遍，后面就都变轻松了
  • 接下来是数组。用代码跑一遍 [2,2,1,2,2,2,1]，看看十二个音里挑中了哪些，挪动起点做转调，旋转数组做调式。二十行就够
  • 和弦从套下标开始。把 [0,2,4] 套到音阶数组上取出三和弦，再用耳朵去分辨 [0,4,7] 和 [0,3,7] 的差别。亲耳听见一个半音把印象翻过来，胜过十行解释
  • 节奏单独处理。不要和音高搅在一起。做一张四分音符的网格，在上面把音挪一格做出切分就够了
  • 记谱法放到最后。在懂结构的状态下学记号，几天就够；从记号学起，要几个月。顺序就是全部

会用 MIDI 会更占便宜。音符号码是整数，上面这些实验就全变成了数组操作。发声的部分，浏览器内置的音频 API 一个就够；想直接看波形，也可以从在浏览器里运行的音频编辑器这类免安装的工具起步。

最后说一句。这套办法对快速理解乐理很好，但对写出音乐本身还不够。懂结构会让你看清为什么会这样，要背的东西大幅减少，读别的资料时也不至于迷路。这套办法的份额到此为止。剩下的部分，由听的时间和上手摸的时间来填。无论用生成工具还是自己弹，这一部分都不会缩水。
