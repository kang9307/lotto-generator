高血压管理 DASH 饮食法完全指南：降压饮食的全部内容

引言：什么是 DASH 饮食法？

DASH(Dietary Approaches to Stop Hypertension)饮食法是一种饮食模式，在美国国立卫生研究院(NIH)下属机构资助的临床试验中得到检验，目的是降低高血压。美国国家心肺血液研究所(NHLBI)把 DASH 介绍为“一种灵活而均衡的饮食计划，帮助建立终身适用的有益心脏健康的饮食方式”。

高血压诊疗指南把 DASH 这类健康饮食模式，与体重控制、限钠、节酒、运动一起，列为生活方式干预的基础。但生活方式干预是与药物治疗并行的，并不能替代药物。本文不承诺血压能降多少。

DASH 饮食法的科学依据

主要研究结果

最初的 DASH 研究 (1997)

  • 参与者：459 名成年人。先从美国常见的标准饮食开始，之后随机分配到对照饮食、水果蔬菜饮食或复合饮食
  • 时长：8 周
  • 结果：复合饮食(增加水果、蔬菜、低脂乳制品，减少饱和脂肪和总脂肪)比对照饮食的收缩压多降 5.5mmHg、舒张压多降 3.0mmHg
  • 高血压参与者：收缩压低 11.4mmHg，舒张压低 5.5mmHg

DASH-钠研究 (2001)

  • 参与者：412 名成年人。分配到对照饮食或 DASH 饮食，并按随机顺序各摄入高、中、低三种钠水平各 30 天
  • 仅减少钠时：从高水平降到中等水平，收缩压在对照饮食中下降 2.1mmHg，在 DASH 饮食中下降 1.3mmHg，更低的水平还会进一步下降
  • DASH 与低钠同时进行时：与高钠对照饮食相比，无高血压者的收缩压低 7.1mmHg，有高血压者低 11.5mmHg

关于成分的说明

NHLBI 把 DASH 饮食描述为饱和脂肪和反式脂肪少，而钾、钙、镁、膳食纤维和蛋白质丰富。各成分对降压各贡献多少，本文没有确认，因此不下断言。

DASH 饮食法的核心原则

基本构成要素

以下份数是 NHLBI 以每天 2,000 千卡为基准给出的数值。一份的具体分量请按 NHLBI 的说明表执行。所需热量因年龄、体型和活动量而异，个人标准最好与医务人员或营养师一起确定。

1. 蔬菜和水果 (蔬菜每天 4-5 份，水果每天 4-5 份)

推荐食物：
- 水果：苹果、香蕉、橙子、莓类、甜瓜
- 蔬菜：西兰花、菠菜、胡萝卜、番茄、红薯

2. 谷物 (每天 6-8 份，以全谷物为主)

  • 糙米、燕麦、藜麦、全麦面包
  • 选择全谷物而不是精制谷物

3. 肉类、禽类和鱼 (每天 6 份以内)

  • 鸡胸肉、鱼、豆类、坚果
  • 选择饱和脂肪少的蛋白质

4. 低脂或脱脂乳制品 (每天 2-3 份)

  • 低脂牛奶、酸奶、奶酪
  • 钙和蛋白质的来源

5. 坚果、种子和干豆 (每周 4-5 份)

  • 杏仁、核桃、葵花籽
  • 油脂类每天最多 2-3 份

需要限制的食物

钠 (每天 2,300mg 为标准目标，1,500mg 为更低的目标)

NHLBI 把 2,300mg 作为标准目标，并说明每天 1,500mg 比 2,300mg 能让血压降得更多。世界卫生组织(WHO)建议成年人每天钠摄入量低于 2,000mg(食盐 5g)。适合自己的目标请与医务人员一起确定。

高钠食物：
- 加工肉类 (火腿、香肠、培根)
- 方便食品
- 罐头制品
- 快餐
- 过量用盐

饱和脂肪

  • 限制红肉
  • 黄油、奶酪等动物性脂肪
  • 棕榈油、椰子油

糖和甜食 (按 NHLBI 的标准每周 5 份以内)

  • 含糖饮料
  • 饼干、蛋糕、糖果
  • 精制谷物

分阶段的 DASH 饮食实践指南

以下阶段和周数是本文为帮助实践而编排的示例，并不是研究中验证过的日程。

第 1 阶段：分析当前饮食习惯 (第 1 周)

记录饮食日记

  • 记录所有食物和饮料
  • 确认钠含量
  • 计算水果、蔬菜的摄入量

测量血压

  • 在同一时间段、同样条件下测量
  • 测量次数和目标血压按医务人员的指导执行
  • 做好记录表，就诊时带上

第 2 阶段：开始逐步改变 (第 2-4 周)

每周目标示例

第2周：
- 增加水果摄入量
- 用糙米替换一部分白米饭
- 减少加工食品

第3周：
- 增加蔬菜摄入量 (每餐 2 种以上)
- 开始吃坚果零食
- 减少盐和汤汁的摄入

第4周：
- 改用低脂乳制品
- 用鱼或鸡肉替代红肉
- 减少外出就餐

第 3 阶段：完整执行 DASH 饮食法 (第 5 周以后)

每日菜单示例

以下只是展示搭配结构的示例。热量和分量因人而异，请不要照搬，而要与营养师一起调整。

早餐

  • 燕麦粥 + 香蕉 + 杏仁
  • 低脂牛奶 1 杯
  • 蓝莓

午餐

  • 糙米饭
  • 烤三文鱼 (香草调味)
  • 西兰花胡萝卜炒菜
  • 沙拉 (橄榄油酱汁)

晚餐

  • 藜麦
  • 烤鸡胸肉
  • 烤红薯
  • 菠菜沙拉

加餐

  • 希腊酸奶 + 草莓
  • 或苹果 + 杏仁酱

减少钠摄入的实用方法

改进烹饪方法

代替盐使用的调味料

  1. 香草和香料

    • 罗勒、牛至、百里香
    • 大蒜、姜、胡椒
    • 红椒粉、孜然、姜黄

  2. 利用酸味调料

    • 柠檬汁、青柠汁
    • 醋 (香醋、苹果醋)
    • 番茄基底的酱汁

  3. 天然鲜味

    • 海带、鳀鱼熬的汤底
    • 蘑菇熬的汤
    • 洋葱、芹菜打底

购物技巧

阅读标签

  • 把产品标签上的钠含量(mg)与每天的目标对照
  • “无钠”“低钠”这类标示的标准因国家而异，本文不列出数值

优先选择新鲜食物

  • 未经加工的新鲜肉类和鱼
  • 冷冻蔬菜 (未添加盐的)
  • 用新鲜水果代替罐头

研究证实的血压变化及其局限

已经证实的

  • 最初的 DASH 研究(1997)：复合饮食比对照饮食收缩压低 5.5mmHg、舒张压低 3.0mmHg，高血压参与者低 11.4/5.5mmHg
  • DASH-钠研究(2001)：DASH 与低钠同时进行时，与高钠对照饮食相比，无高血压者收缩压低 7.1mmHg，有高血压者低 11.5mmHg

本文不列数值的内容

  • 对胆固醇、甘油三酯、糖尿病风险、减重、认知功能和中风风险的效果，本次更新未能对照一手来源确认，因此删除了数值
  • 血压开始下降的时间和效果达到最大的时间同样因人而异，因此不承诺固定期限
  • 研究结果是获得供餐的参与者群体的平均值，并不意味着您个人的血压也会降低同样的幅度

实践中常见的困难与对策

挑战 1：对咸味的渴望

应对策略

  1. 逐步减少：用几周的时间一点一点减少盐
  2. 味觉适应期：适应新的味道可能需要时间，时长因人而异
  3. 尝试替代调味料：尝试各种香草和香料

挑战 2：外出就餐的困难

实用技巧

在餐厅：
- 要求酱汁和调味汁分开放
- 选择烤、蒸的菜
- 汤汁剩下不喝
- 控制分量 (一半打包)

挑战 3：忙碌日常中的实践

节省时间的策略

  1. 周末备餐

    • 提前切好蔬菜
    • 提前煮好谷物冷藏保存
    • 提前做好调味酱

  2. 便捷的 DASH 食品

    • 冷冻水果和蔬菜
    • 预洗好的沙拉
    • 全谷物即食产品

特殊情况下的 DASH 饮食法

以下三种情况，在改变饮食之前都应先咨询主治医务人员。

糖尿病患者

碳水化合物管理

  • 分散吃水果的时间
  • 选择血糖指数低的水果
  • 与蛋白质一起食用

肾脏疾病患者的注意事项

需要限制钾的情况

  • DASH 饮食含钾较多，必须先咨询医生再实施
  • 是否限制高钾水果和蔬菜由医务人员判断
  • 定期抽血检查

孕期

不要自行开始

  • 孕期的血压管理和饮食请与产科医生商量
  • 保证充足的热量和营养摄入是首要的
  • 如果血压偏高，不要自己限制饮食，应去就诊

习惯养成的方法

分阶段适应

保留弹性

  • 允许偶尔破例

  • 测量血压的频率按医务人员的指导执行
  • 抽血检查的频率也与医务人员商定
  • 目标在就诊时一起重新设定

DASH 饮食法 vs 其他饮食法

与地中海饮食的比较

项目 DASH 地中海饮食
主要目的 降低血压 心血管健康
脂肪摄入 以低脂为主 富含橄榄油
饮酒 最好减少或不喝 传统饮食包含适量(并非建议开始饮酒)
谷物 强调全谷物 包含全谷物

与低碳高脂饮食的区别

DASH 的特点

  • 有关于血压的临床试验证据
  • 各类食物的份数标准具体
  • 与低碳高脂饮食直接比较的证据，本次未能确认

选择标准

  • 以高血压为主要问题：与医务人员商量是否采用 DASH
  • 急需减重的情况：咨询医生后再决定

常见问题 (FAQ)

Q1: DASH 饮食法的效果从什么时候开始显现？

A: 没有固定的时间。最初的研究是提供 8 周的饮食后进行比较，每个人的反应不同。请定期测量并记录血压，就诊时一起确认。

Q2: 正在服用降压药，可以采用 DASH 饮食法吗？

A: 生活方式干预通常与药物治疗并行，但开始之前请先咨询医务人员。改变饮食可能使血压发生变化，请测量并记录，未经医务人员指示，不要自行减少或停用药物。患有肾脏疾病或正在服用影响钾的药物时，尤其需要先咨询。

Q3: 突然减少钠会有问题吗？

A: 一开始可能觉得食物味道淡，一点一点减少会更容易适应。如果出现头晕等不适，或者因心脏、肾脏疾病或服用利尿剂而收到过钠的调整指示，请咨询医务人员。

Q4: 用 DASH 饮食法可以减重吗？

A: DASH 不是为减重设计的饮食，而是针对血压的饮食模式。本文不承诺减重幅度。如果目标是控制体重，请与医务人员或营养师一起确定热量标准。

Q5: 经常外出就餐的上班族也能做到吗？

A: 有可行的办法。点餐时选择烤或蒸的菜，要求酱汁分开放，汤汁剩下不喝，并控制分量。

Q6: 费用会很高吗？

A: 这取决于食材和季节，本文不断言是否能省钱。减少加工食品和外出就餐，多用应季水果蔬菜，可以控制负担。

结论

DASH 饮食法是在临床试验中证实可以降低血压的饮食模式，是高血压管理的生活方式干预之一。它不能替代药物治疗，效果的大小因人而异。

实践时：

  1. 逐步改变：分阶段执行，而不是突然改变
  2. 可持续性：追求坚持而不是完美
  3. 个性化：根据自己的情况调整
  4. 专业咨询：定期与医务人员沟通

  • Han 等，基层医疗中高血压生活方式干预综述(Ewha Med J 2025;48(4):e56) - 引用了韩国高血压学会 2018 年指南“每天食盐低于 6g(钠约 2.4g)”的建议(2026-09-29 确认): e-emj.org
📋 可直接带走的检查清单 dash_diet_guide.md 
# DASH 饮食法实践检查表

基准日：2026-09-29

本表只转录了正文中的事实。它不能替代诊断或治疗，正在服用的药物，未经医务人员指示，不要自行减量或停用。

---

## 1. 开始前的确认

| 项目 | 是 / 否 | 如果符合 |
|---|---|---|
| 是否正在服用降压药 | | 改变饮食前先咨询医务人员，不要自行调整药物 |
| 是否患有肾脏疾病 | | DASH 饮食含钾较多，先咨询医生再开始 |
| 是否患有糖尿病 | | 与医务人员一起调整吃水果的方式 |
| 是否正处于孕期 | | 咨询产科医生，不要自行限制饮食 |
| 是否有血压记录 | | 在同一时间段、同样条件下测量并记录 |

---

## 2. 每日构成 (NHLBI，按 2,000 千卡)

| 食物类别 | 目标 |
|---|---|
| 谷物(以全谷物为主) | 每天 6-8 份 |
| 蔬菜 | 每天 4-5 份 |
| 水果 | 每天 4-5 份 |
| 低脂或脱脂乳制品 | 每天 2-3 份 |
| 肉类、禽类和鱼 | 每天 6 份以内 |
| 油脂类 | 每天 2-3 份 |
| 坚果、种子、干豆 | 每周 4-5 份 |
| 甜食 | 每周 5 份以内 |

一份的分量按 NHLBI 的说明表执行。所需热量因人而异。

---

## 3. 钠标准对比

| 来源 | 标准 |
|---|---|
| NHLBI | 每天 2,300mg 为标准目标，说明 1,500mg 能让血压降得更多 |
| WHO | 成年人每天钠低于 2,000mg(食盐 5g) |
| 韩国高血压学会 2018 年指南(Ewha Med J 2025 综述引用) | 每天食盐低于 6g(钠约 2.4g) |

适合自己的目标与医务人员一起确定。韩国最新指南正文中的数值未能确认。

---

## 4. 试验中证实的血压变化 (群体平均)

| 研究 | 对比 | 结果(收缩压) |
|---|---|---|
| 最初的 DASH(1997，459 人) | 复合饮食 vs 对照饮食 | 低 5.5mmHg(高血压组低 11.4mmHg) |
| DASH-钠(2001，412 人) | DASH+低钠 vs 对照饮食+高钠 | 无高血压低 7.1mmHg，有高血压低 11.5mmHg |

这并不意味着您个人的血压会降低同样的幅度。
