はじめに：韓国で今、家庭用太陽光が注目される理由

電気料金の累進制、カーボンニュートラル政策、そして太陽光モジュール価格の低下が重なり、韓国では家庭用太陽光が一部の先進的なユーザーだけのものから、一般家庭の現実的な選択肢へと変わりつつある。産業通商資源部と韓国エネルギー公団 新再生エネルギーセンター（KNREC）が主管する住宅支援事業（주택지원사업）を利用すれば、設置費用の多くを補助金で賄うことができる。

2026年時点では、3kWシステムの自己負担が200万ウォン前後まで下がるケースも報告されており、投資対効果が現実的な水準に近づいている。ただし補助金は予算が尽きれば終了し、自治体ごとの上乗せ支援額にも差がある。このガイドでは、誇張なく現状と注意点を整理する。

1. 韓国の家庭用太陽光制度の概要

1.1 グリーンホーム住宅支援事業（韓国エネルギー公団）

韓国エネルギー公団KNRECが運営するグリーンホーム住宅支援事業（주택지원사업）は、単独住宅に太陽光・太陽熱・地熱などの再生可能エネルギー設備を設置する際、設置費の一部を国が補助する代表的な制度だ。申請はグリーンホームポータル（nr.energy.or.kr）から行い、登録参加業者のリストから施工業者を選んで設置後、補助金を受け取る仕組みになっている。

  • 対象住宅：韓国電力（KEPCO）との契約種別が「주택용（住宅用）」の単独住宅（国・地方自治体所有建物は対象外）
  • 対象設備：自家消費用の太陽光・太陽熱・小型風力・地熱など
  • 申請時期：年度初めに参加業者募集後、順次受付。予算消化で終了
  • 支援水準：年度ごとに改定される単価基準（最新公告を必ず確認のこと）

1.2 自治体による追加補助金

国の補助金に加え、ソウル・京畿・釜山などの自治体が独自の追加補助金を設けている。2026年時点でソウル市のベランダ型ミニ太陽光補助金は最大42万ウォン、釜山・大邱・光州などは30〜50万ウォン程度と言われているが、事業の種類や自治体によって異なる。正確な金額は管轄市・郡・区のホームページや担当窓口に直接問い合わせること。

2. 設置費用と補助金

2.1 単独住宅向け3kWシステム

家庭用太陽光の基準となるのは3kWシステムだ。2026年の政府告示基準で3kW住宅用太陽光の工事費上限は約493万ウォンとされる。ここから国の補助金を差し引いた自己負担は概ね150〜250万ウォン程度になるが、地域・業者・設置条件（屋根の種類・構造・アクセス性）によって変わる。

容量工事費目安補助後自己負担目安主な用途
3 kW約490〜500万ウォン約150〜250万ウォン一般的な戸建て住宅
5 kW約700〜800万ウォン約300〜400万ウォン電力消費の多い家庭
0.3〜0.5 kW（ベランダ型）約30〜60万ウォン補助後は少額マンション向けミニ太陽光

上記金額はあくまで参考推定値です。実際の費用は施工業者から見積もりを取得して確認してください。

2.2 申請手順

  1. グリーンホームポータル（nr.energy.or.kr）にアクセスし、地域の参加登録業者を確認
  2. 登録業者に設置申請・見積もり依頼（複数社比較を推奨）
  3. 設置契約を締結して施工
  4. 韓国電力（KEPCO）との系統連係および電気安全公社による検査
  5. 検査合格後、補助金が支給される（エネルギー公団→業者経由、または直接支給）
  6. 自治体の追加補助金は管轄市・郡・区に別途申請

3. 発電量と自家消費

3.1 地域別の発電量目安

太陽光の発電量は地域の日照量に大きく左右される。韓国では南部の方が中部より有利だ。

  • 中部（ソウル・京畿・江原）：日平均日射時間 約3.5〜4.0時間、3kWで月間発電量 約270〜320kWh
  • 南部（釜山・慶南・全南）：日平均日射時間 約4.0〜5.0時間、3kWで月間発電量 約310〜370kWh
  • 済州島：最も日射に恵まれ、年間発電量の期待値が最も高い

屋根の傾斜（15〜45度が理想）、方位角（真南向きが理想）、影の有無も発電量に大きく影響する。曇り・雨天でも散乱光で少量発電するが、晴天比で10〜30%程度に落ちる。

3.2 系統連係型の自家消費の仕組み

韓国の家庭用太陽光はほとんどが系統連係型（グリッド連係）で設置される。発電した電力はまず自宅で自家消費し、余った電力はKEPCOの電力系統に逆潮流する。余剰電力は現金で売買するのではなく、相殺処理（ネットメータリング）として翌月の電気代から差し引かれる仕組みだ。

  • 昼間に発電 → 自家消費 → 請求電力量が減少
  • 発電量が消費量を超えた場合 → 余剰電力を系統へ → 翌月のクレジットとして計上
  • 夜間・曇天時 → 通常通りKEPCOから受電

4. 電気代の節約効果

4.1 節約シミュレーション（参考）

韓国の住宅用電気料金は累進制のため、消費量が多いご家庭ほど太陽光による節約効果が大きい。3kWシステムで月間約300kWh発電した場合の目安：

  • 消費量少（月300kWh以下）：月間節約額 約2〜4万ウォン（累進効果は小）
  • 消費量中（400〜600kWh）：月間節約額 約4〜7万ウォン（累進区分の大幅削減）
  • 消費量多（600kWh超）：月間節約額 約7〜10万ウォン以上（最高累進区分の回避）

上記は一般的な参考推定値であり、実際の節約額は使用時間帯・季節・料金体系の変更などにより異なります。KNRECやKEPCOのシミュレーションツールで個別に試算することをお勧めします。

4.2 投資回収期間

自己負担200万ウォン、年間節約額50万ウォンを前提とした単純計算では、投資回収期間は約4年となる。パネル寿命が25年以上あるため長期的には有利な投資と言えるが、実際の回収期間は電気料金の変動・インバータ交換費用・設置条件によって異なる。

5. マンション・共同住宅向けの太陽光

5.1 ベランダ型ミニ太陽光とは

マンションや多世帯住宅に住む方向けの選択肢がベランダ型ミニ太陽光だ。300〜500W級の小型モジュールをバルコニーの手すりや窓枠に設置し、コンセントに差し込むだけで自家発電が始まる製品もある。月間の節約効果は1〜2万ウォン程度と控えめだが、初期費用が低く設置も手軽という利点がある。

5.2 自治体のミニ太陽光支援事業

ソウルの蘆原区・道峰区などいくつかの自治体が独自のベランダ型ミニ太陽光普及事業を行っており、補助金は地域によって20〜50万ウォン程度だ。申込期間が限られているため、対象地域の住民は自治体のホームページまたはエネルギー担当窓口に事業の日程を確認することをお勧めする。

  • 設置前の確認事項：マンション管理規約・入居者代表会の承認要否・バルコニーの構造と耐荷重
  • インバータ接続方式：コンセント直結型（手軽）とKEPCO計量器連動型に分かれる
  • 発電量の目安：300Wパネル1枚で月間約20〜30kWh（晴天の多い月の場合）

5.3 マンション屋上への集合太陽光

入居者代表会議の決議によりマンション屋上に太陽光を設置し、共用部の電気代節減に活かす事例も増えている。この場合は建物支援事業など別の補助制度を利用し、節約分は管理費の削減という形で住民に還元される。

6. 太陽光システムの維持管理と耐用年数

6.1 日常的なメンテナンス

太陽光システムの日常的なメンテナンスは他の設備と比べてシンプルだ。

  • パネル清掃（年1〜2回）：ホコリ・黄砂・鳥の糞などを水で洗い流す。柔らかいブラシと水が推奨で、高圧洗浄機は使わないこと。
  • 発電量モニタリング（月1回）：インバータの表示またはスマートフォンアプリで月間発電量を確認し、急激な低下がないかチェックする。
  • 影の確認（年1回）：周辺の木の成長や建物の増築により新たな影が生じていないか確認する。
  • 配線・接続箱の目視点検（専門家、年1回）：政府支援事業で設置した場合、義務A/S期間中は業者が点検を行う。

6.2 主要部品の耐用年数

  • 太陽光モジュール：製品保証25〜30年。年間発電量の低下率は一般的に0.3〜0.7%/年程度。
  • インバータ：10〜15年が目安。交換費用は機種によって50〜150万ウォン程度。
  • 配線・接続箱：インバータと同等か、それ以上の期間使用可能。

7. 設置前のチェックリスト

  • 屋根の向き：真南向きを基準に東西それぞれ30度以内が理想
  • 屋根の傾斜：15〜45度が最適
  • 影の有無：日中を通じて障害物の影が当たらないか確認
  • 屋根面積：3kWシステムには約18〜24m²が必要（パネルの種類による）
  • 屋根の構造：種類（スレート・セメント瓦・金属屋根など）と強度を確認。老朽化している場合は補強が必要な場合も
  • 電力契約：KEPCO「住宅用」契約であることの確認
  • 所有権：賃貸の場合は家主の同意が必要
  • 業者選定：エネルギー公団の参加登録業者リストを活用し、複数社から見積もりを取得
