Interactive

Audio Visualizer

Analyze your microphone or a music file in real time and watch it drawn on screen.
Four modes: bars, circle, waveform and blob.

🔒 Everything runs inside this browser. Your microphone audio and the music file you choose are never uploaded, stored or recorded. The data disappears the moment you close this page.
⚠️ This browser does not support the Web Audio API. Please open the page in a recent version of Chrome, Edge, Firefox or Safari.
🎚️ Step 1 · Choose an input source

About the microphone permission — When you press the button below, the browser asks for microphone access. If you allow it, only the frequencies of the surrounding sound feed the animation. Nothing is recorded or sent anywhere. Declining is fine as well. You can keep using the audio file mode instead.

Your file is never uploaded — Pick a music file from your device and it is played and analyzed in browser memory only. MP3, WAV, OGG, M4A and any other format your browser can play are supported.

Start an input source and the canvas will react to sound.

In fullscreen only the visualization fills the screen. No ads are shown, and you can leave with the ESC key or the button in the top left corner.

📖 How to use
  1. Pick Microphone or Audio file in step 1.
  2. Allow the microphone permission, or select a file and press play.
  3. Switch freely between the bars, circle, waveform and blob tabs.
  4. Tune sensitivity, response, bar count and the color theme to your taste.
  5. Go fullscreen for the big picture and keep your favourite frame with Save frame.
