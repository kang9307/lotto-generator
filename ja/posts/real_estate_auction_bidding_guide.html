韓国の不動産競売 - 入札手続と権利分析の基礎、何を確認しなければ安く買ったことにならないか

競売の危険は価格ではなく落札者が引き受ける権利にある

2026-07-31 暮らしと法律

序論: 安く落札しても損になる地点

仮想の場面から始めよう。あるマンションが鑑定価格よりかなり低い価格で出され、誰かがその価格で落札した。登記簿には根抵当権と差押えが並んでいたが、「どうせ落札されれば全部消える」と聞いていたので問題には見えなかった。代金を納めて所有権の移転を受けた後、その家に住んでいた人が訪ねてきて保証金を返してほしいと言う。その人は根抵当権が設定される前に引っ越してきて転入届を済ませた賃借人であり、配当では保証金の一部しか受け取れていなかった。

この場面で落札者が誤ったのは価格の判断ではない。登記簿に書かれた権利がすべてだと考えたことが誤りだった。より正確には、落札で消える権利と落札者に移る権利が別々にあるという事実を知らなかったことが誤りだった。

この記事は「競売で安く買う方法」を扱わない。扱うのは反対側である。何を確認しなければ安く買ったことにならないのか。競売の危険は価格にはない。引き受ける権利にあり、そのかなりの部分は登記簿に現れない。だからこの記事が与えるのは収益の計算法ではなく、確認すべき項目とその根拠となる法令の条番号である。

適用される法域。以下はすべて大韓民国の法律のみを説明する。競売制度、登記制度、賃借人保護の仕組みは国ごとに根本的に異なり、これは他国の競売手続や担保権実行手続を説明するものではない。

免責および確認時点。この記事は情報提供を目的とした一般的な説明であり、法律相談ではない。個別物件の権利関係は登記の時点、事件記録の記載、現地の状況によって全く異なる判断になりうるため、弁護士・法務士などの専門家の検討を受ける必要がある。入札するかどうかの判断とその結果は全面的に本人の責任である。この記事は競売への参加を勧めるものではない。

法令は改正される。以下に記した条番号と内容は2026年7月31日に法制処「探しやすい生活法令情報」の不動産競売・住宅賃貸借の項目で確認したものである。条文の原文と改正履歴は必ず国家法令情報センターで直接確認する必要がある。

1. 競売は売買ではない - 現状引受けと引き返せない契約

まず正すべきは、競売を「裁判所が売る安い物件」と見る視点である。通常の売買と競売は取引の構造そのものが違う。

通常の売買には売主がいる。売主は契約の当事者であり、物件に問題があれば責任を問う相手が存在する。契約書に特約を入れることもでき、残代金の前に問題が明らかになれば交渉したり契約を整理したりする余地もある。競売にはその相手がいない。売却は裁判所が進める執行手続の一部であり、落札者は交渉の相手ではなく手続の参加者である。

  • 現状のまま引き受ける。物件はあるがままに売却される。落札後に見つけた瑕疵を理由に値引きを求める相手がいない
  • 瑕疵に対する責任追及が事実上制限される。通常の売買の瑕疵担保責任と同じやり方で争うことは難しい。どこまで争えるかは事案ごとに異なるため専門家の確認が必要である
  • 気が変わったからといって契約を撤回できない。入札票を出して最高価買受申出人になれば、その後は手続が法の定める軌道でのみ動く
  • 代金を納められなければ納めた保証を失う構造につながりうる。再売却の根拠条文は民事執行法第138条である。従前の買受人の保証をどう扱うかは条文の原文を直接確認する必要がある
  • 占有者がいるまま移ってくる。所有権を得ることと実際にその空間を使えることは別の問題である

ここで大半の事故が起きる。「安く買ったのだから多少損しても構わない」という計算が成り立つには損の最大値がいくらか知っていなければならないのに、引き受ける権利を落とすとその最大値を知らないまま入札することになる。知らない金額を引き受けることは安く買うことではない。

2. 手続の流れ - どこまで引き返せてどこから引き返せないか

手続を暗記する必要はない。各段階で自分がまだ自由か、すでに縛られているかだけ分かればよい。法制処の案内による流れと根拠条文は次のとおりである。

3. 権利分析の心臓 - 抹消基準権利と引き受ける権利

ここがこの記事の中心である。落札で消滅する権利と落札者に移る権利を分ける基準がある。韓国の実務で「抹消基準権利」と呼ばれるものである。

基準となる登記。法制処の案内によれば、（根）抵当権、（仮）差押え、競売開始決定登記のうち最も早く登記された権利が基準となる。登記事項証明書でこの三種類を探し、受付日付が最も早いものを押さえることが権利分析の最初の動作である。根拠として示された条文は民事執行法第88条・第91条・第135条・第144条・第148条などであり、個別の権利の性質は民法と各特別法が定める。

基準を見つけたらその上と下を分ける。基準より後に登記されたものは原則として消滅し、先のものは引き受けられうる。ただしこの原則には例外があり、そもそも順位と無関係に引き受けられるものもある。

区分該当する権利落札者にとって何を意味するか
原則として消滅（根）抵当権、（仮）差押え配当で整理され登記から消される
基準より後に登記された地上権・地役権土地利用の制約が解ける
基準より後に登記された賃借権その賃借権自体は消滅する
配当要求をした傳貰権配当で整理される

表を読むときの注意点がある。これは一般的な分類であって個別事件の結論ではない。同じ名前の権利でも登記の時点、配当要求の有無、物件の性質によって扱いが変わる。そして表で「原則として」という語が付いた欄は例外が存在するという意味であって、例外がないという意味ではない。

  • 基準を誤って押さえるとその下のすべての判断が一緒に誤る。最初の動作が最も重要である
  • 仮登記は担保仮登記か順位保全の仮登記かによって結論が正反対になる。登記の名称だけでは区別できない場合がある
  • 傳貰権は配当要求をしたかが分かれ道である。事件記録を見なければ分からない
  • 仮処分は何を禁じようとする仮処分かを見なければならない。建物撤去のためのものなら性格が全く異なる
  • 留置権・法定地上権・墳墓基地権は登記簿を全部読んでも発見されない。この三つだけを別に点検する習慣が必要である

4. 対抗力ある賃借人 - 保証金が落札者に移る経路

序論の場面に戻ろう。賃借人の保証金が落札者に移る経路は三つの要素が重なるときに開く。対抗力、順位、そして配当である。

4.1 対抗力は登記ではなく事実で生じる

住宅賃貸借保護法第3条によれば、対抗力の要件は二つである。住宅の引渡しと住民登録である。そして両方の要件を満たした翌日の午前0時から第三者に効力が生じる。別途の登記は必要ない。

この一文が競売で持つ重みは大きい。対抗力は登記簿に記録されない。登記事項証明書をいくら精密に読んでも賃借人の転入日は現れない。それは売却物件明細書と現況調査報告書、そして転入世帯の確認を通じて突き止めなければならない。

  • 要件を満たした翌日の午前0時という点が順位争いで一日の差を生む
  • 賃借人が転出してから再び転入すれば対抗力が新たに生じると案内されている。順位が後ろに下がるという意味である
  • 共同住宅は棟・号数を正確に記載する必要があり、多世帯住宅は地番だけでもよいと案内されている。記載の誤りがあれば対抗力を得られない危険がある
  • 店舗建物は商業用建物賃貸借保護法が別に適用される。第3条、第5条、第8条が関連条文として示されており、適用範囲に関する基準は別途の確認が必要である

4.2 優先弁済権と配当、そして残る部分

同法第3条の2によれば、対抗要件に確定日付が加われば優先弁済権が生じる。後順位の権利者より先に保証金の弁済を受けられる権利である。確定日付は邑・面事務所、洞住民センター、市・郡・区の出張所、地方裁判所とその支院、登記所、公証人から受けられると案内されている（第3条の6）。

ここで落札者が注目すべき地点は配当で全部受け取れなかった部分である。賃借人が対抗力を備えており、その対抗力が基準より先であれば、配当で回収できなかった保証金が買受人の負担として残りうる。反対に対抗力が基準より後であれば、その賃借権は消滅の側に整理される。

  • 転入日だけを見てはならない。確定日付と配当要求の有無を併せて見る必要がある
  • 確定日付があっても配当要求の終期を過ぎれば配当に参加できないことがある
  • 配当要求をしていても先順位の権利者が先に持っていけば残らないことがある
  • 賃借人が複数いる多世帯住宅は全員の関係を一枚に整理して初めて実体が見える
  • 賃借人側の視点で保証金の回収手続が気になるなら保証金返還訴訟と契約更新請求権の拒絶事由を参考にできる。この記事は買受人側の確認項目のみを扱う

5. 最優先弁済 - 配当の一番前の席

少額賃借人の保護制度は配当の順序を変える。住宅賃貸借保護法第8条に根拠を置き、具体的な金額は同法施行令第10条と第11条が定める。落札者にこの制度が重要な理由は単純である。配当を受ける総額は決まっているのに、一番前の席を誰が取るかが変われば後ろで受け取れない人が生じ、その結果が引受けの有無に影響しうるからである。

金額を断定しないこと。この基準は地域によって異なり施行令の改正で変わる。そして契約の時点と担保物権の設定時点によって適用される基準そのものが変わりうる。以下の数字は2026年7月31日に閲覧した法制処の案内に記されていた値であり、その案内は大統領令第33254号（2023年2月21日）を基準として示していた。必ず国家法令情報センターで現行の施行令を直接確認する必要がある。

ソウル特別市1億6,500万ウォン以下5,500万ウォン

  • 賃借人は競売申請の登記前に対抗要件である住宅の引渡しと住民登録を備えなければならない
  • その対抗要件は配当要求の終期まで継続して存続しなければならない
  • 優先弁済権を行使するには執行裁判所に配当要求をするか滞納処分庁に優先権の行使を届け出る必要がある
  • 優先弁済の金額が住宅価額の2分の1を超えればその2分の1に相当する金額までに制限される
  • 関連条文として住宅賃貸借保護法第3条・第8条、同法施行令第10条・第11条、民事執行法第88条・第246条が示されている

落札者の立場でこの節の実務的な結論は一つである。配当表がどう組まれるかを推定してみるにせよ、その推定に寄りかかって安心しないこと。配当は裁判所が確定するものであり、推定が外れればその差が引受けとして返ってきうる。

6. 登記簿に現れないもの - 現地で確認する危険

3節の表の「順位と無関係に引受け」の欄が恐ろしい理由はそれらが登記簿にないからである。登記事項証明書をいくら丁寧に読んでも発見されない。現地に行かなければ見えない。そして現地に行っても見えないことがある。

類型なぜ登記簿にないか何が危険かどう確認するか
留置権の主張登記する権利ではない登記の順位と無関係に引き受けられうると案内されている。主張金額が大きいほど負担が増す現地の横断幕・掲示物・施錠、売却物件明細書の記載、事件記録の届出の有無
法定地上権登記なく成立しうる土地を落札しても地上の建物を撤去できないことがある。土地の利用価値が大きく変わる土地と建物の所有者が同じか、どちらが売却対象か、建物の登記の有無
墳墓基地権登記なく成立しうる土地の利用が制約されうる。勝手に移すことはできない現地の踏査。鑑定評価書に記載がなくても存在しうる
未登記建物登記簿そのものがない売却対象に含まれるかどうかから争いになる。土地だけを落札する結果になりうる鑑定評価書の提示外建物の記載、現況調査報告書、建築物台帳
実際の占有者占有は登記事項ではない書類上の関係と異なると明渡しが長引き費用が増える現況調査報告書、転入世帯の確認、現地訪問

この五つを扱う原則は同じである。ないと確認されたものと確認できなかったものを区別することである。「現地に行ったが何もなかった」と「現地に行かなかった」は全く異なる状態なのに、入札票を書くときは両方とも「問題なし」として扱われやすい。

  • 留置権の主張は主張それ自体で手続を複雑にする。認められるかどうかとは別に明渡しに時間がかかる
  • 土地と建物が別々に売却される事件は構造が全く異なる。何が売却対象かから確認する必要がある
  • 現況調査報告書に調査不能と記された部分は危険信号である。裁判所も確認できなかったという意味である
  • 管理費の滞納、共用部分の未納額のように権利ではないが金が出ていく項目も別に点検する必要がある
  • 写真とインターネットの資料だけで判断することは確認ではない。確認とは直接行くことである

7. 入札の実務 - 保証、入札票、そして引き返せない誤記

権利分析が終わったら次は手続の問題である。ここで起きる事故は性格が異なる。法を知らないからではなく手が滑って起きる事故である。ところが結果は同じように重い。

7.1 入札の方式

民事執行法第103条により裁判所が売却方法を定める。法制処の案内による二つの方式は次のとおりである。

  • 期日入札。指定された期日に裁判所に出席して入札票を作成し、保証とともに執行官に提出する
  • 期間入札。定められた期間に入札票を作成し、保証と同じ封筒に入れて封をした後、執行官に直接提出するか書留郵便で送る
  • 開札は執行官が行い、最高価買受申出人の氏名と価格が公告される（民事執行法第115条、民事執行規則第65条・第71条）
  • 落札しなかった者の保証は直ちに返還されると案内されている

7.2 保証と入札票

確認が必要な項目。買受申出保証の金額と提出方法、そして入札票の記載方式と訂正の可否は、この記事を書きながら条文の原文を開いて確認できなかった。実務でよく言われる比率があるがここでは断定しない。確認の経路は二つである。第一に、当該事件の売却期日の公告に金額と方法が表示される。第二に、民事執行法と民事執行規則の該当条文を国家法令情報センターで確認し、書式と手続の案内は大法院 電子民願センターと裁判所競売情報で確認する。

入札価格の記載について必ず知っておくべき構造が一つある。入札票に書いた金額は提出した後で戻すことが難しい。桁を誤って意図した金額の十倍を書く事故がなぜ致命的なのかは、次の連鎖を見れば分かる。

  • 誤って書いた金額が最高価となり最高価買受申出人になる
  • 売却許可決定を経て代金支払の期限が定まる（民事執行法第142条）
  • その金額を調達できないので代金を納められない
  • 未納なので次順位買受申出人に許可されるか再売却に移る（民事執行法第138条）
  • この過程ですでに納めた保証をどう扱うかは民事執行法第138条の条文の原文を直接確認する必要がある。実務で「保証金の没収」と呼ばれる結果がここから出る

共同入札と代理入札にもそれぞれ必要な書類と形式がある。この部分の具体的な要件もこの記事では条文で確認できなかった。該当の裁判所に事前に問い合わせるか裁判所競売情報の案内を確認するのが安全である。当日に書類が一つ欠けて入札そのものが無効になることはよくある。

8. 落札の後 - 代金納付、未納、引渡命令と明渡し

落札は終わりではなく二番目の手続の始まりである。ここでも引き返せる地点と引き返せない地点が分かれる。

8.1 代金納付と権利の取得

  • 売却許可決定が確定すれば裁判所が定めた期限に代金を納める（民事執行法第142条）
  • 代金を全部納めた時に売却の目的である権利を取得する（同法第135条）。登記を終えた時ではない
  • 代金の納付後、所有権移転登記と引き受けない権利の抹消登記が嘱託される（同法第144条）
  • 期限内に納められなければ次順位買受申出人に売却を許可するか再売却を決定する
  • 再売却が決定されても再売却期日の3日前までに代金と利息、手続費用を納めれば再売却を防げると案内されている。利息は年12パーセントと示されている（同法第138条）

8.2 占有者を勝手に退去させることはできない

この節の核心の一文はこれである。所有権を取得しても占有者を勝手に退去させることはできない。扉を開けて荷物を運び出したり施錠を替えたりする行為はそれ自体が法的な問題になる。必ず法の定める手続を経なければならない。

  • 占有者が引渡しを拒めば代金を納めた後6か月以内に裁判所へ引渡命令を申し立てられると案内されている（民事執行法第136条）
  • 期間を逃せば別の手続を踏むことになるため日程の管理が必要である
  • 引渡命令がすべての占有者に通じるわけではない。引き受けられる権原を持つ占有者であれば結論が変わりうるため専門家の確認が必要である
  • 明渡しには時間と費用がかかる。その期間に物件を使えないという点も負担に含まれる
  • 対抗力ある賃借人が残っている場合なら、そもそも退去させる問題ではなく保証金をどうするかの問題になる

9. 入札前の確認チェックリスト - 四つの書類で見るもの

ここまでの内容を書類の単位で整理し直す。四つの書類をそれぞれ見るのではなく互いに突き合わせることが要領である。一つの書類にだけあって他の書類にない項目が危険信号である。

## 1. 入札前の確認チェックリスト

### 1-1. 書類の入手（四つ）

- [ ] 登記事項証明書を自分で取得した（事件記録の写しではなく最新のもの）
- [ ] 売却物件明細書を閲覧した
- [ ] 現況調査報告書を閲覧した
- [ ] 鑑定評価書を閲覧した
- [ ] 右の三つは売却期日の一週間前から備え置かれることを知り、日程を合わせて確認した（民事執行法第105条）

### 1-2. 権利分析

- [ ] 登記簿で（根）抵当権・（仮）差押え・競売開始決定登記のうち最も早く登記されたものを見つけた
- [ ] その基準より前の登記を全部書き出した
- [ ] 前順位の登記のうち落札で消滅しないものがあるか確認した
- [ ] 傳貰権があるなら配当要求をしたか確認した
- [ ] 仮登記があるなら担保仮登記か順位保全の仮登記かを確認した
- [ ] 仮処分があるならその目的が何かを確認した
- [ ] 登記の順位と無関係に引き受ける可能性のある権利（留置権など）を別に点検した

### 1-3. 賃借人

- [ ] 占有者が誰か、賃借人か所有者かを確認した
- [ ] 賃借人の転入日が基準となる登記より前かを確認した
- [ ] 確定日付の有無とその日付を確認した
- [ ] 配当要求をしたか、配当要求の終期内に行ったかを確認した
- [ ] 配当で保証金全額を回収できない場合、その差額がどこへ行くかを確認した
- [ ] 転入世帯確認書などで届出のある世帯を確認した
- [ ] 多世帯住宅なら世帯ごとの賃借人全員の関係を確認した

### 1-4. 現地

- [ ] 実際に行った（写真と書類だけで判断しなかった）
- [ ] 実際の占有者と書類上の占有者が同じか確認した
- [ ] 留置権主張の表示（横断幕・掲示物・施錠）があるか確認した
- [ ] 土地と建物の所有者が同じか、どちらが売却対象かを確認した
- [ ] 未登記の建物・付属物・増築部分があるか確認した
- [ ] 墳墓があるか確認した（土地の場合）
- [ ] 管理費の滞納、共用部分の未納額があるか確認した

### 1-5. 入札当日

- [ ] 売却期日・場所・事件番号・物件番号を再確認した
- [ ] 買受申出保証の金額と提出方法を売却期日の公告で確認した
- [ ] 入札票に書く金額の桁を二回以上確認した
- [ ] 代理入札・共同入札なら必要書類を裁判所に事前に確認した
- [ ] 落札した場合、代金全額を期限内に調達できるか確認した

## 2. 消滅する権利と引き受ける権利

抹消基準権利 = （根）抵当権、（仮）差押え、競売開始決定登記のうち最も早く登記された権利

| 区分 | 該当する権利 |
| --- | --- |
| 原則として消滅 | （根）抵当権、（仮）差押え |
| 原則として消滅 | 基準より後に登記された地上権・地役権 |
| 原則として消滅 | 基準より後に登記された賃借権 |
| 原則として消滅 | 配当要求をした傳貰権 |
| 原則として消滅 | 担保仮登記 |
| 順位と無関係に引受け | 留置権 |
| 順位と無関係に引受け | 法定地上権 |
| 順位と無関係に引受け | 墳墓基地権 |
| 前順位なら引受け | 基準より先に登記された地上権・地役権・傳貰権・賃借権 |
| 条件付きで引受け | 順位保全のための仮登記 |
| 条件付きで引受け | 配当要求をしていない傳貰権 |
| 条件付きで引受け | 土地所有者の建物撤去のための処分禁止仮処分 |

## 7. してはならないこと

- 鑑定価格と最低売却価格の差だけを見て判断すること — 危険は価格ではなく引き受ける権利にある
- 登記事項証明書だけで終えること — 留置権・法定地上権・墳墓基地権・未登記建物は登記簿にない
- 現地に行かないこと — 実際の占有者と書類が異なる場合がある
- 売却物件明細書の「引受」の表示を読み流すこと — その一行が金額を変える
- 賃借人の転入日だけを見て配当要求の有無を確認しないこと
- 少額賃借人の基準金額を古い資料で判断すること — 地域と時点によって異なり施行令で変わる
- 代金の調達計画なしに入札すること — 未納は再売却につながる
- 落札後に占有者を勝手に退去させること — 法の定める手続を経る必要がある
- この文書だけを見て入札すること — 個別物件は専門家の検討が必要である

## 8. よく誤解される点

- 対抗力は登記ではなく住宅の引渡しと住民登録で生じ、要件を満たした翌日の午前0時から第三者に効力がある（住宅賃貸借保護法第3条）
- 優先弁済権は対抗要件に確定日付が加わって初めて生じる（同法第3条の2）
- 対抗力があっても配当で保証金を全額受け取れなければ、受け取れなかった部分が落札者に残りうる
- 少額賃借人の最優先弁済は競売申請の登記前に対抗要件を備え、配当要求をする必要がある（同法第8条）
- 最優先弁済額には住宅価額の2分の1という限度がある
- 店舗は商業用建物賃貸借保護法が別に適用される（第3条、第5条、第8条）
- 引渡命令は代金を納めた後6か月以内に申し立てられる（民事執行法第136条）
