本文只涉及从Microsoft支持文档(help/10741)、TP-Link FAQ(138、1556)和ASUS FAQ 1030641中直接确认的内容，范围是家用路由器无法连接、网速变慢与掉线的排查。

出发点 - 先把症状分成三类并找出边界

路由器问题表现为连不上、变慢、掉线三者之一，每种症状最先要看的地方不同。不过，三份文档开头提出的问题是一致的：异常只出现在一台设备上，还是出现在所有设备上。边界一旦确定，怀疑对象就缩小到终端、路由器，或者调制解调器及其后面的线路。

ASUS文档说明，无线设备无法上网时，应打开路由器的网页界面，在网络地图中查看互联网是否显示为断开，并确认有线设备是否同样无法上网。如果符合其中任何一条，就转到另外讲解互联网接入失败的文档。文档还建议，如果运营商的调制解调器自带Wi-Fi，可以先连接这个Wi-Fi试试。通过调制解调器的Wi-Fi能上网，就去查看路由器的互联网状态；连调制解调器的Wi-Fi也上不了网，则应联系运营商。

Microsoft文档给出两种对照方法。一种是让另一台笔记本或手机连接同一网络，若能连上，文档认为问题很可能出在最初使用的设备上。另一种是用ipconfig找到默认网关地址并对它执行ping。有回复说明到路由器的连接正常，问题可能在调制解调器或运营商；没有回复，就用网线把电脑直接接到调制解调器，若这样能上网，文档判断问题出在Wi-Fi路由器。

  • 与其他设备对照：让另一台笔记本或手机连接同一Wi-Fi，看是否出现相同症状(Microsoft)。
  • 同时检查有线设备：有线设备同样无法上网，就按互联网接入问题而不是无线问题处理(ASUS)。
  • 对默认网关执行ping：有回复说明到路由器为止的连接正常(Microsoft)。
  • 直连调制解调器或使用其Wi-Fi测试：通过调制解调器能否上网来区分路由器与线路(Microsoft和ASUS)。

只针对网速慢的五步缩小法，请参阅网速测试指南。本文集中讲按症状(无法连接、网速变慢、掉线)的排查顺序，以及各厂商文档彼此说法不同的地方。

断电重启 - 两份官方文档的顺序与等待时间并不一致

路由器与调制解调器断电再通电的做法常被当作唯一标准，但直接查阅的两份文档在通电顺序和等待时间上并不相同。Microsoft支持文档(第4步)先接通调制解调器，TP-Link FAQ(第5步)则先开路由器。ASUS FAQ 1030641没有讲断电重启的步骤。下表照实转录了各文档的表述。

文档关机方式关机后等待通电顺序通电后等待
Microsoft支持 (help/10741)拔掉路由器和调制解调器的电源线。若调制解调器有备用电池且指示灯仍亮，则取出电池至少30秒左右先接通调制解调器，指示灯停止闪烁后再接通路由器等待几分钟，让调制解调器和路由器完全启动
TP-Link FAQ (138、1556)同时关闭调制解调器和路由器1分钟先开路由器，等电源指示灯常亮约2分钟，再开调制解调器等调制解调器指示灯稳定约2分钟，再多等1至2分钟后检查
ASUS FAQ 1030641未收录该步骤---

两份文档为何给出相反的顺序，任何一份都没有解释，本文也未能确认原因。如果使用的是TP-Link路由器，应遵循该厂商文档的顺序；手头没有厂商文档时，则遵循属于Windows一侧指引的Microsoft文档顺序，这才是忠于出处的做法。从这两份文档中，看不出哪一种顺序更好。

Microsoft文档还补充了几个条件。如果是光猫与Wi-Fi路由器合一的设备，只需对这一台设备做同样的重启。重启会让连接同一Wi-Fi的所有设备暂时断开，文档说明其目的是与运营商建立新的连接。设备是否就绪，则通过两台设备的状态指示灯来判断。

  • 一体机设备：调制解调器和路由器合一的设备，只重启这一台(Microsoft)。
  • 备用电池：拔掉电源后调制解调器指示灯仍亮，就取出电池，等待后再装回(Microsoft)。
  • 所有设备暂时断开：重启期间，同一Wi-Fi上的所有设备都会暂时断线(Microsoft)。
  • 检查结果的时间：TP-Link要求最后一台设备开机后再多等1至2分钟，再检查网络。

症状一 - 连上了Wi-Fi却无法上网

Windows在Wi-Fi名称下显示“无Internet”时，Microsoft文档称之为受限连接(limited connectivity)。电脑已连上本地网络，可能还看得到同一网络中的其他设备，但浏览网页、收发邮件、观看流媒体这类需要互联网的操作无法进行。该提示是Windows向互联网上的服务器发送一个很小的HTTP请求，没有收到任何响应时出现的。

文档给出的检查顺序相当简单。先关闭Wi-Fi再打开并重新连接。接着在管理员命令提示符中用ipconfig /release和ipconfig /renew刷新IP配置，并用ipconfig /flushdns清空DNS缓存。然后在设置的代理页面中，关闭已开启的手动代理。据文档所述，若这一步解决了问题，连接图标会在几秒内变化。

若仍不行，就直接查看IP地址和DNS服务器。文档解释说，形如169.254.x.x的地址表示Windows没有从路由器获得地址；在不使用静态IP的网络中，应查阅路由器文档确认DHCP是否已启用。对于DNS，用ipconfig /all | findstr /c:"DNS Servers"找到地址并对其执行ping。如果电脑有有效IP却无法ping通DNS服务器，文档建议换用另一个公共DNS地址再试。

  • 重新连接Wi-Fi：关闭再打开Wi-Fi，重新连接无线网络。
  • 刷新IP：先执行ipconfig /release，再执行ipconfig /renew。
  • 清空DNS缓存：执行ipconfig /flushdns。
  • 检查代理：在设置的网络和Internet、代理中关闭手动代理。
  • 169.254.x.x地址：说明没有从路由器获得IP，应检查DHCP设置。

确认WAN口IP - TP-Link文档的分支

TP-Link FAQ针对已完成设置却仍无法上网的路由器，要求先登录管理页面，在Advanced > Status中查看Internet IP地址。文档把这个值描述为判断问题出在路由器一侧还是调制解调器一侧的起点。据文档所述，大多数TP-Link路由器默认的LAN IP是192.168.0.1或192.168.1.1。

按文档的措辞，0.0.0.0表示路由器没有从调制解调器获得有效地址。文档中没有依据可以据此直接判定为线路故障。文档要求先检查的是网线连接、直连调制解调器测试、MAC地址克隆、LAN IP冲突和上网方式，其摘要也只是说问题很可能出在与调制解调器的连接或物理配置上。下表转录了文档的分支与步骤顺序。

Internet IP状态文档的说明文档给出的处理顺序
0.0.0.0路由器没有从调制解调器获得有效地址1) 确认调制解调器已用网线接在WAN/Internet口 2) 将电脑直连调制解调器测试(不行就重启调制解调器，仍不行则联系运营商) 3) 克隆MAC地址 4) 更改路由器LAN IP 5) 重启调制解调器和路由器 6) 确认上网方式
有有效公网IP但无法上网已获得地址，但无法访问互联网1) 手动设置DNS服务器 2) 重启调制解调器和路由器 3) 恢复出厂设置并重新配置
以上步骤均无效联系TP-Link技术支持准备好当前的Internet IP、调制解调器型号及其为线缆还是DSL类型、已尝试过的步骤

0.0.0.0分支中的具体步骤有文档自己的条件。MAC地址克隆之所以使用，是因为部分运营商会把上网权限绑定到某台设备的MAC地址；在通过有线以太网连接路由器的电脑上，进入Advanced > Network > Internet的MAC Clone部分，选择Use Current Computer MAC Address并保存。更改LAN IP则源于这样的说明：如果调制解调器或DSL猫路由一体机使用相同网段，两台设备会冲突，因此要在Advanced > Network > LAN中改成如192.168.2.1的地址。

在有有效IP的分支中，文档说明在Advanced > Network > DHCP Server中把首选DNS填为8.8.8.8、备用DNS填为8.8.4.4，并称8.8.8.8是Google运营的公共DNS服务器。上网方式需要向运营商确认，文档以Dynamic IP、PPPoE、Static IP为例，并指出设置错误就无法连接。

  • 0.0.0.0的含义：路由器没有从调制解调器获得有效地址，原因需按文档列出的六项依次排查。
  • MAC克隆的条件：文档特别提醒必须通过有线连接操作。
  • LAN IP冲突：调制解调器一侧的设备使用相同网段时，把路由器LAN IP改到别的网段。
  • 手动设置DNS：有有效IP却无法上网时，文档最先给出的处理。

症状二 - 网速慢时的距离、频段与信道带宽

对于已连上网络但速度很慢的情况，Windows文档列出三件事：确认设备靠近路由器、没有遮挡以检查信号强度；在任务管理器中结束占用大量网络带宽的后台进程；让另一台设备连接同一Wi-Fi。另一台设备也慢的话，路由器可能需要维护或更换。同一文档的通用步骤中还有一项：如果路由器把2.4GHz和5GHz显示为两个独立网络，就试着连接另一个。

ASUS文档这样描述两个频段：2.4GHz信号传得更远，但比5GHz慢；5GHz传输距离较短，速度可以更快。连接不稳定时，先确认设备连接的是2.4GHz还是5GHz，以及掉线时与路由器的距离。文档建议把路由器放在靠近设备的地方，尽量放在空间中央、家具较少且没有墙壁阻隔的开阔位置。

信道带宽和信道在路由器网页界面的Wireless > General中按频段分别设置。信道带宽会影响无线速度和信号稳定性，ASUS路由器默认自动调整信道带宽。文档记载的默认信道带宽是：2.4GHz为20/40MHz，5GHz为20/40/80MHz，6GHz为20/40/80/160/320MHz。控制信道默认为自动，若与附近无线设备使用相同信道，可能产生干扰并降低速度，因此可以改用干扰较少的信道。在5GHz上，文档介绍的做法是取消勾选Auto select channel including DFS channels，再选择其他信道。

  • 信号强度：让设备靠近路由器，并移开障碍物(Microsoft)。
  • 后台程序：在任务管理器(Ctrl+Shift+Esc)中结束占用大量带宽的进程(Microsoft)。
  • 切换频段：2.4GHz与5GHz分别显示时，尝试连接另一个(Microsoft)。
  • 默认信道带宽：2.4GHz为20/40MHz，5GHz为20/40/80MHz，自动调整，只能在网页界面修改(ASUS)。
  • 更改控制信道：从自动改为较空闲的信道，支持的信道因各国法规而异(ASUS)。

症状三 - 频繁掉线时的ASUS排查顺序

ASUS FAQ 1030641为无线设备频繁掉线列出了九个步骤。前六步针对路由器，第七步针对环境，第八步针对终端，第九步是恢复出厂设置。文档指出，部分无线功能会因固件版本而异，设置界面按固件3.0.0.6.102_35404及以上与更早版本分为两种。信道带宽和控制信道只能在网页界面修改，不能在应用中修改。

  • 1. 更新固件：在网页界面的Network Map中点击固件版本查看，或在ASUS Router应用的Settings > Firmware Upgrade > Check Firmware Version中查看。
  • 2. 把信道带宽恢复为默认：默认是自动调整，它会影响速度和稳定性。
  • 3. 换用干扰较少的控制信道：默认为Auto，在Wireless > General中按频段设置。
  • 4. 关闭Smart Connect：这样可以为每个频段分别设置不同的Wi-Fi名称和密码。
  • 5. 调整天线角度：试试45度、90度等角度，各型号的推荐摆放请参阅用户手册。
  • 6. 把路由器移到设备附近：避免信号传输距离影响信号强度。
  • 7. 减少环境干扰：文档列举的干扰源有微波炉、冰箱、无绳电话、电源箱，遮挡物有铁柜、铁门、水泥墙、封闭的柜子、地面和沙发后面。
  • 8. 更新终端的驱动程序或固件：对象包括笔记本、智能手机、USB无线网卡和游戏机，更新事宜向设备厂商咨询。

第九步的恢复出厂设置在第8节介绍。文档在第七步指出的环境因素中，还有石膏、木板、铁丝网之类密度较高的建筑材料。文中只说这些材料可能影响Wi-Fi信号穿透，并未给出衰减的具体数值。

Windows一侧也有与掉线相关的设置。Microsoft文档称，Wi-Fi频繁掉线时，在控制面板的电源选项中选中所用的电源计划，然后在高级电源设置的Wireless Adapter Settings下，把Power Saving Mode改为Maximum Performance。另一个单独步骤是在设备管理器中打开Wi-Fi适配器属性，在电源管理选项卡里取消勾选允许计算机关闭此设备以节约电源。同一项目还建议更改路由器信道以减少干扰。

终端侧排查 - Windows文档的步骤

如果路由器看起来正常，接下来检查终端。Microsoft文档的通用步骤共十三步，按从简单到影响较大的顺序排列。文档称，在Windows 11上先运行获取帮助应用中的网络和Internet疑难解答，在Windows 10上则在设置的网络和Internet、状态中运行网络疑难解答。

前面的步骤是状态检查：在任务栏的网络图标中确认Wi-Fi已开启并显示已连接，确认飞行模式已关闭。接着在设置的网络和Internet、Wi-Fi、管理已知网络中忘记该网络，再重新输入密码连接。文档还提到适配器不支持网络所用频率的情形，例如适配器只支持2.4GHz，而网络使用5GHz，这时网络不会出现在列表中。在少见的驱动程序过滤掉该频率的情况下，应在设备管理器中打开适配器属性的高级选项卡，检查Wireless Mode或Band设置是否允许网络所用的频率。

后面的步骤改动幅度更大。在管理员命令提示符中，依次执行netsh winsock reset、netsh int ip reset、ipconfig /release、ipconfig /renew和ipconfig /flushdns。之后是卸载驱动程序并重启，文档提醒事先从电脑厂商网站备好驱动程序作为备份。文档称，如果网络在最近一次更新之后无法正常工作，可以考虑这个方法。

  • Wi-Fi状态：确认Wi-Fi已开启，名称下方显示已连接。
  • 飞行模式：在设置的网络和Internet中确认已关闭。
  • 忘记已知网络：在Manage known networks中点击Forget，然后重新连接。
  • 命令顺序：依次执行winsock reset、int ip reset、release、renew、flushdns。
  • 卸载驱动：勾选Attempt to remove the driver for this device后卸载，再重启。
  • 关闭节能：在设备管理器的电源管理选项卡中，取消允许计算机关闭此设备的勾选。

恢复 - 恢复出厂与网络重置放在最后

三份文档都把恢复出厂设置放在最后。ASUS文档要求按住RESET按钮约5到10秒，电源指示灯开始闪烁时松开。此时所有指示灯熄灭属于正常现象，因为路由器正在自行重启；等电源灯和Wi-Fi灯重新亮起后，再进入管理界面。文档还注明按钮位置因型号略有不同，需查看用户手册。恢复后所有设置都会被清除，需要在网页界面或应用中重新运行快速互联网设置(QIS)。

如果标准的恢复出厂没有解决问题，ASUS文档在另一份文档中介绍了硬恢复出厂(Hard Factory Reset)，并附有适用型号列表。在TP-Link文档中，恢复出厂同样是DNS设置和重启之后的最后一项，恢复后需要从头重新配置路由器。Windows的网络重置是与之对应的终端侧最后手段：Windows 11在设置的网络和Internet、高级网络设置、网络重置中执行，Windows 10在状态、网络重置中执行。

网络重置有副作用。已安装的网络适配器及其设置会被删除，重启后以默认值重新安装，因此VPN客户端、Hyper-V虚拟交换机之类的软件可能需要重新设置。已知网络可能全部被切换为公用网络配置文件，在公用配置文件下，电脑不会被其他设备发现。文档补充说，这个方法也可能有助于解决从Windows 10升级到Windows 11后的连接问题，以及无法访问共享网络驱动器的问题。

  • ASUS恢复出厂：按RESET约5到10秒，电源灯开始闪烁时松开，等电源灯和Wi-Fi灯重新亮起。
  • 恢复之后：所有设置都已清除，需通过QIS重新设置互联网和Wi-Fi。
  • Windows网络重置：上述步骤无效时的最后手段，适配器与设置恢复默认值。
  • 认证问题：密码正确却被拒绝时，Microsoft文档列出重启或恢复出厂路由器以及更新固件。
