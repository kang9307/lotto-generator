빠른 답 — 조건이 정해지면 도구는 거의 정해진다

도구 선택은 취향 문제로 보이지만, 제약 두 개만 확정하면 후보가 두세 개로 줄어듭니다. 첫째, 편집기를 바꿀 수 있는가. 둘째, 지출에 상한을 걸어야 하는가. 이 둘이 정해지고 나서 모델 성능을 보면 됩니다. 반대로 하면 성능 좋은 도구를 골라 놓고 조직 승인에서 막힙니다.

  • 편집기를 못 바꾼다 → GitHub Copilot, JetBrains AI, Amazon Q Developer. 기존 IDE에 붙습니다
  • 편집기를 바꿔도 된다 → Cursor, Devin Desktop, Zed. 전용 편집기가 후보가 됩니다
  • 터미널과 CI에서 돌려야 한다 → Claude Code, OpenAI Codex CLI, Gemini CLI
  • 모델 제공자를 우리가 고르고 싶다 → Cline, Zed, Aider. 자기 API 키를 꽂는 구조입니다
  • 이미 AWS 계약이 있고 벤더 추가가 번거롭다 → Amazon Q Developer. 기존 AWS 청구서에 합류합니다
  • 지출 상한이 반드시 필요하다 → GitHub Copilot(예산·알림), Claude for Teams·Enterprise(시트 할당량과 지출 한도), Amazon Q Developer(좌석 정액)
  • 월 지출을 1달러 단위로 읽고 싶다 → JetBrains AI. 1 크레딧이 1달러로 고정돼 있어 환산이 필요 없습니다
  • 돈을 거의 안 쓰고 시작하고 싶다 → Gemini CLI(구글 계정 로그인으로 하루 1,000요청), Copilot Free(월 2,000 코드 완성), Cline·Aider(도구는 무료, 모델만 종량)

여기서 이미 답이 나왔다면 아래는 근거를 확인하는 용도로 읽으면 됩니다. 답이 안 나왔다면 5번과 7번 절이 결정을 만들어 줄 겁니다.

2026년 5월 이후 실제로 바뀐 것

이 글의 첫 판은 2026년 5월이었습니다. 석 달 사이에 요금제 구조가 바뀌었고, 도구 하나는 이름이 없어졌습니다.

Windsurf가 Devin Desktop이 됐다

2026년 6월 2일 Cognition이 Windsurf를 Devin Desktop으로 개편했습니다. 기존 사용자에게는 자동 업데이트로 내려갔고 요금제와 설정은 그대로 유지됩니다. 로컬 에이전트였던 Cascade는 7월 1일까지만 동작하고, 그 뒤에는 Rust로 다시 작성한 Devin Local을 써야 합니다. 개편의 핵심은 이름이 아니라 여러 에이전트를 칸반 보드에서 관리하는 Agent Command Center와 에이전트끼리 맥락을 공유하는 Spaces입니다. 단일 편집기에서 에이전트 오케스트레이터로 성격이 옮겨간 셈입니다.

실무에서 걸리는 건 자동화입니다. CI 파이프라인이나 스크립트에서 cascade를 직접 호출하고 있었다면 그 호출은 이미 끊겼습니다. Windsurf 시절 문서 링크를 사내 위키에 박아 뒀다면 devin.ai로 넘어가므로 앵커도 같이 정리해야 합니다.

GitHub Copilot이 프리미엄 요청에서 AI 크레딧으로 옮겨갔다

예전 Copilot은 「Pro 월 300 프리미엄 요청」처럼 요청 수로 셌습니다. 지금은 요금제마다 달러로 표기된 AI 크레딧이 붙습니다. Pro는 월 10달러에 15달러어치, Pro+는 39달러에 70달러어치, Max는 100달러에 200달러어치입니다. 개인 요금제에 Max(월 100달러)가 새로 생겼고 Business·Enterprise에는 조직 단위 크레딧 풀이 붙습니다.

요청 수에서 금액으로 바뀐 건 사용자에게 유리한 변화입니다. 요청 수 시절에는 모델별 배수를 알아야 잔량을 계산할 수 있었는데, 이제 남은 크레딧이 그대로 남은 돈입니다. 다만 비싼 모델을 쓰면 같은 요청이라도 크레딧이 빨리 줄어듭니다. Copilot 코드 리뷰에는 2026년 6월 1일부터 모델 배수 13이 적용됩니다.

Cursor 개인 요금제가 세 단계로 늘었다

월 20달러 Pro 위에 Pro Plus 월 60달러와 Ultra 월 200달러가 생겼습니다. 각각 서드파티 모델 사용량이 20달러, 70달러, 400달러어치 포함됩니다. Ultra는 200달러를 내고 400달러어치를 쓰는 구조라 단가만 보면 가장 유리하지만, 그만큼 쓰지 않으면 그냥 200달러를 버리는 요금제입니다.

Copilot 무료·개인 요금제의 학습 기본값이 바뀌었다

2026년 4월 24일부터 GitHub는 Free와 Pro 사용자의 입력·출력·코드 조각과 관련 맥락을 AI 모델 학습에 쓸 수 있게 정책을 바꿨습니다. 설정에 「Allow GitHub to use my data for AI model training」 토글이 있고 끄는 건 사용자 몫입니다. Business와 Enterprise 고객 데이터는 학습에 쓰지 않는다고 같은 문서가 명시합니다. 개인 요금제로 회사 코드를 만지는 관행이 있다면 이 한 줄이 도입 검토에서 가장 먼저 걸립니다.

크레딧을 읽는 요령

JetBrains의 방식이 가장 읽기 쉽습니다. 1 크레딧이 1달러로 못 박혀 있어서 남은 크레딧이 곧 남은 돈입니다. 공식 문서는 1크레딧으로 할 수 있는 일의 대략치도 제시합니다. AI 채팅에서 코드 생성 약 10회, 편집기 내 코드 생성 약 40회, 코드 설명 약 25회, 문서 작성 약 280회, 커밋 메시지 생성 약 140회입니다. 같은 1달러가 커밋 메시지 140개를 사고 채팅 코드 생성 10개를 삽니다. 이 14배 차이가 크레딧 과금의 본질입니다.

Copilot도 크레딧을 달러로 표기하지만 모델 배수가 따로 있습니다. 문서는 「각 모델에는 복잡도와 자원 사용량에 따른 프리미엄 요청 배수가 있다」고 설명하고, 코드 리뷰 기능은 2026년 6월 1일부터 배수 13이 적용된다고 못 박았습니다. 코드 리뷰를 PR마다 자동으로 돌리도록 걸어 두면 크레딧이 예상보다 훨씬 빨리 마릅니다.

여기서 도출되는 운영 원칙은 단순합니다. 비싼 기능은 사람이 명시적으로 부를 때만 돌게 하고, 자동 트리거는 싼 기능에만 건다. 이 원칙을 지키지 않으면 크레딧 잔량 그래프가 월초 일주일 만에 절벽처럼 떨어집니다.

토큰 단가에서 조직 단위 예산까지 거슬러 올라가는 설계는 AI 토큰 비용을 조직 단위로 통제하기에서 따로 다뤘습니다.

이 표에서 갈리는 지점

빈칸이 많은 행일수록 도입 후 예산 회의에서 설명하기 어려워집니다. 특히 Cursor의 팀 분석은 활동량 지표에 집중돼 있고 지출 내역은 그 화면에 없습니다. 채팅 몇 번, 탭 완성 몇 건, AI가 쓴 라인 비율은 나오는데 누가 얼마를 썼는지가 같은 자리에 없습니다. 활동은 보이고 돈은 안 보이는 구조라, 초과 청구가 나왔을 때 원인을 사람 단위로 특정하기 어렵습니다.

반대편 끝이 Claude Code입니다. /usage가 세션 토큰 통계와 요금제 잔량을 함께 보여 주고, 최근 사용량을 스킬·서브에이전트·플러그인·MCP 서버별로 쪼개 비중을 표시합니다. 긴 컨텍스트나 캐시 미스가 최근 사용량의 10% 이상을 차지하면 그것도 따로 표시합니다. 조직 쪽은 OpenTelemetry로 claude_code.cost.usage(USD), claude_code.token.usage, claude_code.lines_of_code.count 같은 지표를 자체 관측 스택으로 내보낼 수 있습니다. 벤더 대시보드를 기다리지 않고 사내 Grafana에 개발자별 비용 패널을 세울 수 있는 유일한 축입니다.

공식 문서가 제시하는 기준선도 유용합니다. 기업 배포 평균이 개발자 1인당 활동일 약 13달러, 월 150~250달러이고, 사용자의 90%는 활동일 30달러 미만이라고 적혀 있습니다. 이 숫자는 견적이 아니라 파일럿 결과를 대조할 기준으로 쓰는 게 맞습니다. 우리 팀 평균이 활동일 40달러로 나왔다면 사용 패턴에 문제가 있는 것이고, 5달러로 나왔다면 도구가 실제로 안 쓰이고 있는 것입니다.

금액이 아예 표시되지 않는 도구에서 비용을 스스로 재는 방법은 AI 코딩 도구에서 금액이 사라졌다에 절차로 정리해 뒀습니다.

컨텍스트가 비용이 되는 구간

에이전트형 도구에서 비용을 키우는 건 모델이 아니라 습관입니다. Claude Code 공식 문서가 짚는 원인은 구체적입니다.

  • 긴 세션. 전체 대화가 매 요청에 실려 나가므로, 하루 종일 열어 둔 세션에서 한 줄짜리 질문을 해도 그날 대화 전체분의 사용량이 발생합니다
  • 캐시 미스. 캐시 수명을 넘겨 쉬었다가 보낸 첫 메시지는 전체 컨텍스트를 다시 처리합니다. 구독에서는 1시간, usage credits를 쓰기 시작하면 5분, API 키나 클라우드 제공자에서는 기본 5분입니다
  • MCP 서버 과다. 도구 정의가 컨텍스트를 잡아먹습니다. 문서는 gh·aws·gcloud 같은 CLI 도구가 MCP 서버보다 컨텍스트 효율이 낫다고 권합니다
  • 에이전트 팀. 팀원이 플랜 모드로 돌 때 표준 세션 대비 약 7배 토큰을 씁니다. 기본값이 꺼져 있는 이유입니다
  • 큰 컨텍스트 압축. /compact는 요약할 대화를 읽어야 하므로 그 자체가 큰 요청입니다. 연속성이 필요 없으면 비용이 0인 /clear가 낫습니다

도구 선정 회의를 세 번 하는 것보다 2주 파일럿 한 번이 정확합니다. 조건은 하나입니다. 측정 항목을 시작 전에 정할 것. 끝나고 나서 정하면 기준이 결과에 끌려갑니다.

파일럿 운영 규칙

  • 인원은 5~8명. 그중 절반은 도구에 회의적인 사람으로 채웁니다. 열성 사용자만 넣으면 결과가 항상 좋게 나옵니다
  • 같은 작업을 두 도구로 시키지 마세요. 시간이 두 배 드는데 비교 정보는 별로 안 늘어납니다. 도구별로 다른 작업 유형을 맡기는 편이 낫습니다
  • 1주차가 끝나면 사용량 화면을 팀에 공개합니다. 지출이 보이는 순간 습관이 바뀝니다
  • 온보딩 문서 첫 페이지에 /clear·/compact 같은 컨텍스트 관리 명령과 모델 선택 기준을 적습니다

  • 끝나고 나서 계약하지 말고, 파일럿 중에 상한 설정과 지출 리포트를 실제로 눌러 봅니다. 화면이 있다는 것과 쓸 만하다는 건 다릅니다
  • 파일럿 리포지터리는 실제 업무 코드로 잡습니다. 샘플 프로젝트에서는 컨텍스트가 작아 비용도 품질도 실제와 다르게 나옵니다

MCP 서버 설정MCP를 지원하는 도구끼리는 옮겨진다낮다
CI 파이프라인 연동호출 명령이 도구 고유다높다. Cascade 종료 때 실제로 문제가 된 지점이다
팀의 사용 습관안 옮겨진다가장 비싸다
사용량·비용 이력대개 안 옮겨진다기준선을 다시 쌓아야 한다
편집기 자체를 바꾼 경우확장·단축키·설정이 전부 걸린다높다

이탈 비용을 낮추는 실용적인 방법은 두 가지입니다. 첫째, 자동화는 도구 명령이 아니라 셸 스크립트를 호출하게 만듭니다. 스크립트 안에서만 도구를 부르면 교체할 때 파일 하나만 고치면 됩니다. Cascade가 종료됐을 때 파이프라인에서 직접 호출하던 팀만 급해졌습니다. 둘째, 지침은 리포지터리에 커밋합니다. 도구 계정 안에만 있는 설정은 계약이 끝나면 같이 사라집니다.

한국에서 도입할 때

가격표가 전부 달러라 국내 도입에서는 표에 없는 항목이 결정을 좌우합니다.

결제와 경비 처리

  • 대부분 해외 사업자 결제라 원화 환산 시점과 카드사 해외 수수료가 매달 붙습니다. 표에 적힌 달러 금액과 회계에 찍히는 금액이 다릅니다
  • 세금계산서 대신 인보이스만 나오는 경우가 많습니다. 경비 처리 절차를 결제 전에 확인하는 편이 낫습니다
  • 연간 결제 할인이 큰 곳이 있습니다. Claude Pro는 연간 결제 시 월 17달러(200달러 선결제), 월납은 20달러입니다. Team Standard는 연간 좌석 20달러, 월납 25달러입니다
  • 이미 AWS 계약이 있으면 Amazon Q Developer가 절차상 가장 짧습니다. 기존 청구서에 합류하므로 신규 벤더 등록과 결제 수단 추가가 없습니다. 도구 성능과 무관하게 이 한 가지로 결정이 나는 조직이 있습니다

법인 도입에서 자주 걸리는 것

  • 개인 요금제를 각자 결제하고 경비 처리하는 방식은 편해 보이지만, GitHub Copilot Free·Pro의 학습 기본값 때문에 회사 코드를 다루는 용도로는 맞지 않습니다. 조직 요금제로 올려야 정책을 강제할 수 있습니다
  • 망분리 환경에서는 도구가 외부로 어떤 요청을 보내는지 목록이 필요합니다. Claude Code는 텔레메트리·오류 보고·피드백 전송을 각각 환경 변수로 끌 수 있고 한 번에 끄는 변수도 있습니다. 방화벽 정책을 쓸 때 이 목록이 근거가 됩니다
  • 감사 대응이 필요하면 화면만 있는 도구는 곤란합니다. 사용자별 지출을 CSV나 API로 뽑을 수 있는지를 계약 전에 확인하세요
  • 좌석 수가 적은 팀은 최소 계약 조건을 확인해야 합니다. Zed Business는 주문서 계약 기준 최소 25석이고, 그 미만은 셀프서브로 처리합니다
  • SSO를 붙일 계획이면 요금제 등급을 먼저 봅니다. 대부분의 도구에서 SSO·SCIM은 팀 이상 등급에만 열립니다
  • 퇴사·이동이 잦은 조직은 좌석 회수 절차를 계약 시점에 확인하세요. 좌석 정액 도구에서는 회수가 늦으면 그대로 비용입니다

실무 조합

국내 중소 개발 조직에서 승인까지 가장 빨리 가는 조합은 좌석 정액 도구를 전원에게 깔고, 에이전트형은 소수에게 별도 승인입니다. 전자는 예산이 고정이라 설명이 쉽고, 후자는 인원이 적어 초과분이 통제됩니다. 반대로 전원에게 종량제 도구를 열면 두 번째 달 청구서에서 문제가 생깁니다.

확인하지 못한 것

아래 항목은 공개 페이지에서 값을 얻지 못해 표를 비워 두었습니다.

  • Gemini Code Assist Standard·Enterprise 좌석 단가 — 가격 페이지의 표가 열리지 않았습니다. Gemini CLI의 무료 구간과 오픈소스 여부는 저장소에서 확인했지만 유료 좌석 단가는 비워 뒀습니다
  • Cline ClinePass 월 구독 금액 — 정액 구독이 존재한다는 설명은 있으나 금액이 공개 페이지에 없습니다
  • Cline Enterprise 가격 — 영업 문의로만 안내됩니다
  • Cursor Enterprise 좌석 단가 — 문의 대상입니다
  • Copilot Business·Enterprise에 포함되는 AI 크레딧 금액 — 문서가 「조직 단위 크레딧 풀」로만 설명하고 금액을 밝히지 않습니다
  • Claude Max 20x의 정확한 월 단가 — 가격 페이지가 Max 5x와 20x를 모두 「$100부터」로 표기합니다
  • OpenAI Codex(ChatGPT Business·Enterprise)의 학습 사용 기본값 — 해당 정책 페이지에 접근하지 못했습니다. 11번 표에서 이 행을 비워 둔 이유입니다
  • Devin Desktop의 메시지당 실제 소진량 — 「모델·작업 크기·복잡도에 따라 다르다」는 설명만 있습니다
  • 각 도구의 감사 로그 보존 기간 — Claude Code 외에는 공개 문서에서 확인되지 않았습니다

자주 묻는 질문

하나만 골라야 한다면 무엇을 봐야 하나요

편집기를 바꿀 수 있는지, 지출 상한이 필요한지 두 가지를 먼저 확정하세요. 이 둘로 후보가 두세 개로 줄고, 그다음에 모델 성능을 비교하면 됩니다. 성능부터 보면 좋은 도구를 골라 놓고 조직 승인에서 막힙니다.

정액제인데 왜 한도에 걸리나요

지금 개인 요금제는 대부분 정액 안에 사용량 예산이 들어 있습니다. Copilot Pro는 월 10달러에 15달러어치 크레딧, Cursor Pro는 20달러에 20달러어치 모델 사용량, JetBrains AI Pro는 10달러에 10크레딧, Zed Pro는 10달러에 5달러어치 토큰입니다. 예산을 다 쓰면 한도에 걸리거나 초과분이 청구됩니다.

여러 도구를 같이 쓰면 낭비 아닌가요

축이 다르면 낭비가 아닙니다. 편집기 내장형 하나와 터미널·에이전트형 하나는 하는 일이 겹치지 않습니다. 같은 축의 도구 두 개를 두는 게 낭비입니다.

오픈소스 도구를 쓰면 데이터가 안전한가요

클라이언트가 오픈소스라는 것과 데이터가 학습에 안 쓰인다는 것은 별개입니다. Cline·Gemini CLI·Aider 모두 프롬프트는 모델 제공자 서버로 갑니다. 확인해야 할 문서는 그 제공자의 약관입니다.
