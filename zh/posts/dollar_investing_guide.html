前言：美元投资为何在韩国备受关注

2025至2026年间，韩元/美元汇率多次突破1,400至1,500韩元关口，创下全球金融危机以来的历史新高（2026年6月发布时的表述）。此轮韩元大幅贬值引发了韩国个人投资者对美元投资和汇率套利（利用汇率波动获取收益的策略）的广泛关注。

美元投资不仅是追求收益的手段，也是分散以韩元资产为主的投资组合的防御工具。美元作为全球储备货币，在经济不确定性上升时往往因避险需求而走强。然而，汇率下跌时，持有美元的投资者将以韩元计算发生本金损失。本指南从韩国居民的视角，整理美元投资的主要方式、汇率影响因素、成本与税务以及风险。税务与存款保险均以韩国制度（个人居民）为准。

美元投资的四种主要方式

投资美元的方式大致可分为四种。安全性、收益性、流动性和入门门槛各不相同，先了解哪种方式符合自己的目的和情况最为重要。

外汇活期账户

外汇活期账户是可自由存取款的美元银行账户，大多数韩国主要银行均可开立，买卖美元时适用该银行的挂牌汇率。年利率约为0~1%（2026年6月基准），较低，但持有美元后可在汇率上涨时获得汇差收益。

  • 优点：存取款自由，门槛低，受存款保险保护（与同一银行的韩元存款合计，每人最高1亿韩元，按韩元折算）
  • 缺点：利率极低，汇率下跌时以韩元计算发生本金损失
  • 适合人群：有海外消费、汇款等实际需求，或希望长期持有美元者

美元定期存款

美元定期存款是将美元在固定期限内（如3个月至1年）存放，以换取相对较高利率的产品。利率通常与美国联邦储备委员会（Fed）政策利率挂钩，在2024至2026年高利率环境下，部分韩国银行提供的年利率曾接近4%（2026年6月发布时的表述，当前利率请另行查阅各银行公示）。提前支取通常会受到利率下调的处罚。

  • 优点：利率高于活期账户，银行产品相对安全
  • 缺点：提前支取受罚，存款期间流动性受限，汇率下跌时本金损失
  • 适合人群：希望在固定期限内持有美元并获取利息者

美元RP（回购协议）

美元RP是证券公司将客户的美元资金投资于美元计价的国债或优质债券，并在约定期限后按约定收益率回购的产品。韩国开发研究院（KDI）经济信息中心2019年的专栏介绍称，美元RP的收益率可能高于外汇存款。但韩国存款保险公社将回购协议（RP）列为不受保护的产品，因此不能期待与银行存款同等的本金安全。RP的收益在韩国所得税法上作为利息所得（债券·证券的附回购条件买卖差价）征税。

  • 优点：收益率可能略高于外汇存款，适合短期运用
  • 缺点：不受存款保险保障（存款保险公社分类），存在发行方信用风险
  • 适合人群：已持有证券账户、希望短期运用美元者

美元ETF（交易所交易基金）

在韩国上市的美元ETF是追踪韩元/美元汇率的交易所交易基金，可在韩国交易所像股票一样买卖。产品名称中含有「美国美元期货」的期货型ETF是典型类型。汇率上涨则获利，下跌则亏损。杠杆ETF每日追踪2倍收益，风险显著放大。反向ETF则是在汇率下跌时获利的产品。其征税方式与银行外汇存款不同（见税务一节的美元ETF项目）。

  • 优点：门槛低，可通过证券账户便捷操作，流动性高
  • 缺点：产生管理费，存在追踪误差，杠杆产品高风险，汇率收益也可能被征税
  • 适合人群：有股票投资经验、希望对韩元/美元汇率方向进行投资者

影响汇率的主要因素

汇率是美元投资中最关键的变量，由多种宏观经济因素共同作用决定，即使是专业人士也很难准确预测短期走向。了解主要影响因素有助于解读汇率新闻，但不代表能够准确预测。

韩美利差

当美国Fed政策利率显著高于韩国央行（BOK）利率时，美元资产的利率吸引力增大，美元需求增加，推动韩元/美元汇率上升（韩元贬值）。2022至2025年韩美利率长期倒挂，是韩元走弱的主要结构性原因之一。

经常账户与贸易收支

韩国出口扩大、美元流入国内时，韩元需求增加，汇率趋于下降（韩元升值）。反之，进口超过出口，或出口企业倾向于持有而非换汇，则形成韩元贬值压力。全球贸易摩擦和韩国出口走弱会显著施压韩元。

全球风险情绪

地缘政治风险或金融市场动荡加剧时，投资者倾向于流入美元等避险资产，使包括韩元在内的新兴市场货币承压。市场趋于平稳时，资金回流高收益资产，韩元可能回升。

外资资本流动

外国投资者大规模抛售韩国股票或债券时，将韩元换成美元，形成韩元贬值压力。外资流入则起相反效果。这类资本流动可引发难以预测的短期汇率剧烈波动。

核心要点：汇率同时受利率、贸易、资本、情绪等众多因素影响。依赖单一指标或新闻判断方向极为危险。

换汇手续费与实际成本

换汇手续费是开始美元投资时容易忽视的成本。即使看起来很少，如果支付的成本超过投资收益，实际收益就会减少。

外汇价差（手续费）

韩国银行在公布作为基准的买卖基准汇率的同时，还分别公布「买入现钞」「卖出现钞」「汇出汇款」「汇入汇款」时的汇率。客户买入美元时适用的汇率与买卖基准汇率之差就是「价差」，也就是通常所说的换汇手续费。价差幅度因银行、币种和交易方式（现钞，还是转入外汇存款或汇款）而不同，并且随时变动，并不是可以当作固定数字记住的值。交易时查看该银行的挂牌汇率表最为准确。

降低手续费的方法

汇率优惠并不是给汇率本身打折，而是减免价差的一部分。即使看到高优惠率的广告，也要同时确认该优惠适用于哪种汇率（现钞还是汇款）的价差、享受优惠的条件是什么（通过网银或APP申请、主要往来银行业绩等），才能知道实际成本。韩国银行联合会外汇指南（exchange.kfb.or.kr）可比较各银行的网络换汇手续费。现金换汇与转入外汇存款的手续费结构可能不同，交易前请查阅条款。

成本计算公式

买入美元时实际适用的汇率为买卖基准汇率 + 价差 × (1 − 优惠率)，再乘以美元金额，就是需要支付的韩元。之后把美元卖回韩元时，则反向适用买卖基准汇率 − 价差 × (1 − 优惠率)。也就是说，即使汇率完全不变，一买一卖之间就已经亏掉了双向的价差。交易金额越大、买卖次数越多，这项成本就越大。

税务——汇差收益、利息收入与美元ETF

美元投资的税务因产品而异。银行外汇存款要把汇差收益和利息分开看，美元RP和美元ETF则另有规则。以下以韩国个人居民为准。

汇差收益——普通外汇存款不属于征税对象

韩国所得税法在第16条逐项列举应征税的利息所得。与存款相关、被列入其中的是「存款利息」，因汇率上涨而使韩元折算金额增加的差额并不在列。列举转让所得的第94条中也不包括外币本身。因此，个人通过银行外汇活期账户或美元定期存款买卖美元所获得的汇差收益，既不征利息所得税，也不征转让所得税。以1美元=1,300韩元买入、1,500韩元卖出，其差额不征税，只对持有期间产生的利息征税。

但有例外。如果金融机构把外汇存款与远期外汇等衍生品捆绑在一起、实际上锁定收益，那么根据所得税法第16条第1款第13项及其施行令第26条第5款，该衍生品产生的收益也按利息所得征税。凡是宣传「确定收益」的外汇产品，购买前应向金融机构确认其征税类别。通过美元ETF或基金获得的汇率收益，征税方式也不同（见下方美元ETF项目）。

利息收入——15.4%预扣税

外汇存款利息在所得税法上属于存款利息，按预扣税率14%（第129条）加上地方所得税，合计15.4%，由金融机构扣除后再入账（韩国国税厅说明：利息所得的14%，含个人地方所得税为15.4%预扣）。利息不多时税务影响也小，但比较产品时应以税后金额而非税前利率为准。美元RP的收益也属于所得税法第16条第1款第8项的附回购条件买卖差价，归为利息所得。

金融所得综合课税

利息、股息等金融所得（不含免税及无条件分离课税部分）的年度合计超过2,000万韩元时，需进行综合课税；在此以下则以预扣完成纳税（韩国国税厅说明）。外汇存款利息、美元RP收益以及美元ETF中被征税的所得，都计入这一合计。像在海外金融机构账户中收到的利息这类未在韩国国内预扣的金融所得，无论金额多少都属于综合课税对象。金融所得规模较大时，建议咨询税务专业人士。

美元ETF——持有期间课税

在韩国上市的美元ETF并不是按1:1追踪韩国股价指数的「国内股票型ETF」，因此适用韩国交易所说明中的「其他ETF」征税规则。其他ETF自2010年7月起实行持有期间课税，以卖出时的买卖差价与持有期间课税标准基准价格增加额（课标增额）中较小的金额为基准，预扣15.4%（股息所得税14%+地方所得税1.4%）。分配金同样适用15.4%。最大的区别在于：银行外汇存款的汇差收益不征税，但通过ETF获得的汇率收益可能被征税。

美元投资的主要风险

美元投资有时看起来很有吸引力，但必须先理解其中的风险。

汇率波动风险——本金损失

最大的风险是汇率波动。购入美元后若韩元/美元汇率下跌，以韩元计算将发生本金损失。例如以1美元=1,500韩元购入1,000美元（150万韩元），若汇率跌至1,300韩元，持有资产折算仅剩130万韩元，损失20万韩元，且利息收益可能无法弥补这一损失。

时机风险

在汇率高位买入美元并不意味着汇率会继续上涨。美联储降息、韩国经济好转、贸易顺差扩大等因素叠加，可能导致汇率急剧回落，使高位入场者遭受较大损失。

机会成本

持有美元期间，放弃了将资金投入韩元资产可能获得的收益。若汇率横盘，则只能获得存款利息，无汇差收益。

杠杆ETF风险

美元杠杆ETF和反向ETF对大多数普通投资者并不适合。杠杆产品每日追踪2倍收益，在波动或横盘市场中，本金可能因复利效应而快速缩水。

入门实践策略

对入门者而言，从「分散投资组合」而非「押中时机的投机」角度看待美元投资更为现实。

分批购入策略

与其一次性将大笔资金换成美元，不如考虑每月或每季度固定金额分批换汇。这样可以平均购入成本，降低在某一不利汇率下集中入场的风险。但分批越多，换汇次数也越多，按照上面的计算公式，每次都会产生价差，这一点也要一并考虑。

明确目的与配置比例

首先明确美元投资的目的。若有海外旅游、汇款或子女留学等实际需求，按需配置是合理选择。若纯粹出于资产分散目的，先确定总资产中外汇资产占多少比例，是分散的起点。合适的比例因收入、负债以及今后使用的币种而差异很大，没有适合所有人的数字，必要时建议咨询专业顾问。

存款保险与安全性

银行的外汇活期账户和美元定期存款属于存款保险保护对象。据韩国存款保险公社说明，自2025年9月1日起保护限额提高到每家金融机构每人1亿韩元（本金与规定利息合计），此前开立的存款同样最高保护1亿韩元。外汇存款以保险金支付公告日为基准，按该金融机构首次公布的电汇买入汇率折算成韩元后，与同一金融机构的韩元存款合计，最高保护1亿韩元。因此即使美元余额相同，韩元折算金额也会随汇率变化。相反，美元RP和美元ETF等金融投资产品不在保护范围内。入门者较现实的顺序是：在保护限额内先从银行外汇存款开始，充分理解额外风险后再考虑RP或ETF。

常见误区

"汇率已经很高，肯定还会涨"

高汇率不代表必然继续上涨。美国降息、韩国经济复苏、贸易顺差扩大等因素叠加时，汇率可能急速下跌。汇率走势连市场专家的看法也常常分歧。

"美元存款利率总是高于韩元存款"

美元存款利率反映美国政策利率。Fed降息时，美元存款利率随之下降。相较韩元存款的利率优势会因市场环境变化而缩小甚至消失。

"汇差收益免税，所以美元投资没有风险"

汇差收益免税是银行外汇存款的优势，并不能直接套用到美元ETF上。而且若汇率逆向波动导致本金损失，任何税收优惠都无法弥补亏损。税收优惠与安全性不可混为一谈。

结语——从目的与风险出发

美元投资在分散投资组合和守护购买力方面是有意义的手段。但汇率难以预测，在高汇率时买入美元后若汇率下跌，就会发生本金损失。同样是美元，放在银行外汇存款、RP还是ETF中，税务与存款保险完全不同。

入门者较现实的做法是：先明确目的（实际需求还是资产分散），规划美元占总资产的比例，再从外汇活期账户或美元定期存款等风险相对较低的产品起步。专注于短期汇率时机的投机做法，本金损失风险很大。

# 美元投资检查表 - 按下换汇按钮之前

基准日: 2026-09-29
以韩国制度、个人居民为准。仅供信息和教育目的，不构成投资建议或金融、税务建议。不推荐任何特定银行或产品，也不提供汇率预测或买入时机。
税务与保护限额依据韩国国家法令信息中心（所得税法）、国税厅、存款保险公社和韩国交易所的说明，法令变化时随之改变。

---

## 1. 当前基准数字

| 项目 | 数值 | 依据 |
|---|---|---|
| 银行外汇存款的汇差收益 | 不属于征税对象（不在利息所得、转让所得的列举项目中） | 所得税法第16条、第94条 |
| 例外：外汇存款+远期外汇等衍生品捆绑产品 | 衍生品收益也按利息所得征税 | 所得税法第16条第1款第13项、施行令第26条第5款 |
| 外汇存款利息 | 预扣14%（含地方所得税15.4%） | 所得税法第129条、韩国国税厅 |
| 美元RP收益 | 利息所得（附回购条件买卖差价） | 所得税法第16条第1款第8项 |
| 韩国上市的美元ETF | 其他ETF持有期间课税：以买卖差价与课标增额中较小者为基准15.4%，分配金15.4% | 韩国交易所 |
| 金融所得综合课税标准 | 利息、股息等年度合计超过2,000万韩元 | 韩国国税厅 |
| 外汇存款的存款保险 | 每家金融机构每人1亿韩元（本金+规定利息，与韩元存款合计，2025-09-01起） | 韩国存款保险公社 |
| 外汇存款的韩元折算标准 | 保险金支付公告日该金融机构首次公布的电汇买入汇率 | 韩国存款保险公社 |
| 美元RP、美元ETF的存款保险 | 不保障 | 韩国存款保险公社 |

---

## 2. 哪种方式适合 - 判断表

| 我的情况 | 先看的方式 | 理由 |
|---|---|---|
| 很快要用美元（海外支付、汇款） | 外汇活期账户 | 存取自由，受存款保险保护 |
| 想把美元存放一段时间并获得利息 | 美元定期存款 | 有利息，受存款保险保护；确认提前支取的不利条件 |
| 有证券账户，想短期运用 | 美元RP | 不受存款保险保障，收益属于利息所得 |
| 想通过股票账户投资汇率方向 | 美元ETF | 不受存款保险保障，汇率收益也可能被征税 |
| 想用杠杆或反向产品博取高收益 | 重新考虑 | 追踪每日2倍收益，在波动行情中本金可能快速缩水 |

---

## 3. 换汇成本检查

- [ ] 是否在交易银行的挂牌汇率表上，同时查看了买卖基准汇率和自己实际适用的汇率（现钞，还是汇款、转入外汇存款）
- [ ] 计算时是否清楚优惠率作用于价差而不是汇率本身
- [ ] 是否确认了优惠适用于哪种交易方式，以及需要什么条件（网银或APP申请、主要往来银行业绩等）
- [ ] 是否把买入和卖回时各产生一次价差计算在内
- [ ] 是否在韩国银行联合会外汇指南（exchange.kfb.or.kr）比较了各银行的网络换汇手续费

计算公式：买入适用汇率 = 买卖基准汇率 + 价差 × (1 − 优惠率) / 卖出适用汇率 = 买卖基准汇率 − 价差 × (1 − 优惠率)

---

## 4. 税务检查

- [ ] 如果是银行外汇存款：是否按汇差收益免税、只有利息被扣15.4%的前提计算了税后金额
- [ ] 如果是宣传「确定收益」的外汇产品：是否向金融机构确认了是否捆绑远期外汇等衍生品以及征税类别
- [ ] 如果是美元ETF：是否计入了以买卖差价与课标增额中较小者为基准的15.4%预扣
- [ ] 外汇存款利息、RP收益和ETF应税所得合计的金融所得，是否可能超过每年2,000万韩元 → 可能的话请咨询专业人士
- [ ] 是否有像海外账户利息这样未在韩国国内预扣的金融所得 → 无论金额多少都属于综合课税对象

---

## 5. 安全性检查

- [ ] 在同一家银行的韩元存款与外汇存款（按韩元折算）合计是否超过1亿韩元 → 超出部分不受保护
- [ ] 是否考虑到即使美元余额相同，韩元折算金额也会随汇率变化
- [ ] 是否在清楚RP、ETF不受存款保险保障的前提下确定了配置比例

---

## 6. 风险与配置

- [ ] 是否接受：若韩元/美元汇率跌破买入汇率，以韩元计算会发生本金损失
- [ ] 是否先写下了目的（实际需求还是资产分散）
- [ ] 是否根据收入、负债以及今后使用的币种来确定外汇资产占总资产的比例（没有适合所有人的数字）
- [ ] 如果分批换汇，是否计算了每次换汇都会产生价差

---

## 7. 何时重新确认

- 韩国所得税法修订，利息所得列举项目、预扣税率（14%、15.4%）或金融所得综合课税标准（2,000万韩元）发生变化时
- 所得税法施行令或韩国交易所说明变更，导致其他ETF征税方式变化时
- 存款保险限额（1亿韩元）或外汇存款的韩元折算标准发生变化时
- 韩国国税厅就外汇存款与远期外汇捆绑产品的征税作出新的解释时
