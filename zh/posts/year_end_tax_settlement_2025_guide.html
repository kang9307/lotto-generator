📋 年终结算基本概念：所得扣除 vs 税额扣除

要真正理解年终结算，必须清楚所得扣除（소득공제）和税额扣除（세액공제）的区别。

所得扣除（Income Deduction）

┌──────────────────────────────────────────┐
│         所得扣除计算结构                  │
├──────────────────────────────────────────┤
│  总工资                                  │
│  - 工薪所得扣除                          │
│  = 工薪所得金额                          │
│  - 所得扣除（人员·养老·保险·信用卡等）  │
│  = 课税标准                              │
│  × 税率（6~45%）                         │
│  = 应纳税额                              │
└──────────────────────────────────────────┘

核心：所得扣除是减少计算税金基础的课税标准。税率越高，节税效果越大。

税额扣除（Tax Credit）

┌──────────────────────────────────────────┐
│         税额扣除计算结构                  │
├──────────────────────────────────────────┤
│  应纳税额                                │
│  - 税额扣除（子女·养老账户·医疗费等）   │
│  = 确定税额                              │
│  - 已缴税额（源泉扣缴）                 │
│  = 差额税额（退税或追缴）               │
└──────────────────────────────────────────┘

核心：税额扣除是从计算出的税金中直接减免。与收入水平无关，节税效果相同。

示例：100万韩元的节税效果比较

类别 总工资4,000万韩元（税率15%） 总工资8,000万韩元（税率24%）
所得扣除100万韩元 节税15万韩元 节税24万韩元
税额扣除100万韩元 节税100万韩元 节税100万韩元

# 信用卡最优使用模拟器
def calculate_card_deduction(annual_salary, credit_usage, debit_usage, traditional_market, public_transport):
    """
    年终结算信用卡所得扣除计算器

    Args:
        annual_salary: 年总工资（韩元）
        credit_usage: 信用卡使用额（韩元）
        debit_usage: 借记卡使用额（韩元）
        traditional_market: 传统市场消费额（韩元）
        public_transport: 公共交通消费额（韩元）

    Returns:
        所得扣除金额（韩元）
    """
    # 最低使用金额（总工资的25%）
    min_usage = annual_salary * 0.25

    total_usage = credit_usage + debit_usage + traditional_market + public_transport

    if total_usage < min_usage:
        return 0

    # 超过部分计算
    excess_usage = total_usage - min_usage

    # 扣除计算
    deduction = 0
    deduction += credit_usage * 0.15  # 信用卡 15%
    deduction += debit_usage * 0.30   # 借记卡 30%
    deduction += traditional_market * 0.50  # 传统市场 50%
    deduction += public_transport * 0.80    # 公共交通 80%

    # 适用额度限制（按总工资分级）
    if annual_salary <= 70000000:  # 7,000万韩元以下
        limit = 3000000
    elif annual_salary <= 120000000:  # 1.2亿韩元以下
        limit = 2500000
    else:
        limit = 2000000

    return min(deduction, limit)

# 使用示例
salary = 50000000  # 年薪5,000万韩元
credit = 5000000   # 信用卡500万韩元
debit = 10000000   # 借记卡1,000万韩元
market = 2000000   # 传统市场200万韩元
transport = 1200000  # 公共交通120万韩元

total_deduction = calculate_card_deduction(salary, credit, debit, market, transport)
print(f"预计所得扣除额: {total_deduction:,}韩元")
# 输出: 预计所得扣除额: 3,000,000韩元（适用额度限制）

# 医疗费税额扣除优化模拟器
def optimize_medical_expense(annual_salary, family_expenses):
    """
    按家庭成员最优分配医疗费，最大化税额扣除

    Args:
        annual_salary: 年总工资
        family_expenses: {
            'self': 本人医疗费,
            'spouse': 配偶医疗费,
            'parents': 父母医疗费（65岁以上）,
            'children': 子女医疗费
        }

    Returns:
        最大税额扣除金额
    """
    threshold = annual_salary * 0.03  # 最低使用金额（3%）

    # 本人 + 65岁以上 + 残障人士：无限额
    unlimited = family_expenses.get('self', 0) + family_expenses.get('parents', 0)

    # 一般抚养家属：700万韩元限额
    limited = min(family_expenses.get('spouse', 0) + family_expenses.get('children', 0), 7000000)

    total_medical = unlimited + limited

    if total_medical <= threshold:
        return 0

    # 超过部分按15%税额扣除
    deduction_amount = (total_medical - threshold) * 0.15

    return deduction_amount

# 使用示例
expenses = {
    'self': 500000,      # 本人50万韩元
    'spouse': 800000,    # 配偶80万韩元
    'parents': 3000000,  # 父母300万韩元（65岁以上）
    'children': 400000   # 子女40万韩元
}

tax_credit = optimize_medical_expense(50000000, expenses)
print(f"医疗费税额扣除: {tax_credit:,}韩元")
# 输出: 医疗费税额扣除: 472,500韩元

# 养老账户最优缴纳模拟器
def optimize_pension_contribution(annual_salary, age):
    """
    计算养老账户最优缴纳额

    Args:
        annual_salary: 年总工资
        age: 年龄

    Returns:
        dict: {
            'pension_saving': 养老储蓄建议缴纳额,
            'irp': IRP建议缴纳额,
            'tax_credit': 预计税额扣除
        }
    """
    if annual_salary <= 55000000:
        tax_rate = 0.165  # 16.5%
    else:
        tax_rate = 0.132  # 13.2%

    # 50岁以下：养老储蓄600万韩元 + IRP 300万韩元
    # 50岁以上：养老储蓄600万韩元 + IRP 900万韩元（退休准备）
    if age < 50:
        pension_saving = 6000000
        irp = 3000000
    else:
        pension_saving = 6000000
        irp = 9000000

    total_contribution = pension_saving + irp
    tax_credit = min(total_contribution, 9000000) * tax_rate

    return {
        'pension_saving': pension_saving,
        'irp': irp,
        'total': total_contribution,
        'tax_credit': tax_credit
    }

# 使用示例
result = optimize_pension_contribution(60000000, 35)
