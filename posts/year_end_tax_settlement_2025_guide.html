📋 연말정산 기본 개념: 소득공제 vs 세액공제

연말정산을 제대로 이해하려면 소득공제와 세액공제의 차이를 명확히 알아야 합니다.

소득공제 (Income Deduction)

┌──────────────────────────────────────────┐
│         소득공제 계산 구조                │
├──────────────────────────────────────────┤
│  총급여액                                │
│  - 근로소득공제                          │
│  = 근로소득금액                          │
│  - 소득공제 (인적·연금·보험·카드 등)    │
│  = 과세표준                              │
│  × 세율 (6~45%)                         │
│  = 산출세액                              │
└──────────────────────────────────────────┘

핵심: 소득공제는 세금을 계산하는 기준이 되는 과세표준을 줄여줍니다. 세율이 높을수록 절세 효과가 큽니다.

세액공제 (Tax Credit)

┌──────────────────────────────────────────┐
│         세액공제 계산 구조                │
├──────────────────────────────────────────┤
│  산출세액                                │
│  - 세액공제 (자녀·연금계좌·의료비 등)   │
│  = 결정세액                              │
│  - 기납부세액 (원천징수)                 │
│  = 차감징수세액 (환급 또는 추가납부)     │
└──────────────────────────────────────────┘

핵심: 세액공제는 계산된 세금에서 직접 차감됩니다. 소득 수준과 관계없이 동일한 절세 효과를 받습니다.

예시: 100만원의 절세 효과 비교

구분 총급여 4천만원 (세율 15%) 총급여 8천만원 (세율 24%)
소득공제 100만원 15만원 절세 24만원 절세
세액공제 100만원 100만원 절세 100만원 절세

신용카드 소득공제는 가장 기본적이면서도 놓치기 쉬운 항목입니다.

최적 사용 전략

# 신용카드 최적 사용 시뮬레이터
def calculate_card_deduction(annual_salary, credit_usage, debit_usage, traditional_market, public_transport):
    """
    연말정산 신용카드 소득공제 계산기

    Args:
        annual_salary: 연 총급여 (원)
        credit_usage: 신용카드 사용액 (원)
        debit_usage: 체크카드 사용액 (원)
        traditional_market: 전통시장 사용액 (원)
        public_transport: 대중교통 사용액 (원)

    Returns:
        소득공제 금액 (원)
    """
    # 최저 사용금액 (총급여의 25%)
    min_usage = annual_salary * 0.25

    total_usage = credit_usage + debit_usage + traditional_market + public_transport

    if total_usage < min_usage:
        return 0

    # 초과 사용분 계산
    excess_usage = total_usage - min_usage

    # 공제 계산
    deduction = 0
    deduction += credit_usage * 0.15  # 신용카드 15%
    deduction += debit_usage * 0.30   # 체크카드 30%
    deduction += traditional_market * 0.50  # 전통시장 50%
    deduction += public_transport * 0.80    # 대중교통 80%

    # 한도 적용 (총급여별 차등)
    if annual_salary <= 70000000:  # 7천만원 이하
        limit = 3000000
    elif annual_salary <= 120000000:  # 1억2천만원 이하
        limit = 2500000
    else:
        limit = 2000000

    return min(deduction, limit)

# 사용 예시
salary = 50000000  # 연봉 5천만원
credit = 5000000   # 신용카드 500만원
debit = 10000000   # 체크카드 1000만원
market = 2000000   # 전통시장 200만원
transport = 1200000  # 대중교통 120만원

total_deduction = calculate_card_deduction(salary, credit, debit, market, transport)
print(f"예상 소득공제액: {total_deduction:,}원")
# 출력: 예상 소득공제액: 3,000,000원 (한도 적용)

실전 팁: 연말 카드 사용 전략

12월 전략적 소비 체크리스트

  1. 총 사용액이 총급여 25%를 초과했는지 확인
  2. 초과하지 않았다면 → 신용카드로 필요한 물품 구매
  3. 초과했다면 → 체크카드·전통시장·대중교통 우선 사용
  4. 공제 한도(300만원)에 근접했다면 → 내년 1월로 소비 연기

의료비 절세 전략

# 의료비 세액공제 최적화 시뮬레이터
def optimize_medical_expense(annual_salary, family_expenses):
    """
    가족 구성원별 의료비를 최적 배분하여 세액공제 극대화

    Args:
        annual_salary: 연 총급여
        family_expenses: {
            'self': 본인 의료비,
            'spouse': 배우자 의료비,
            'parents': 부모 의료비 (65세 이상),
            'children': 자녀 의료비
        }

    Returns:
        최대 세액공제 금액
    """
    threshold = annual_salary * 0.03  # 최저 사용금액 (3%)

    # 본인 + 65세 이상 + 장애인: 한도 없음
    unlimited = family_expenses.get('self', 0) + family_expenses.get('parents', 0)

    # 일반 부양가족: 700만원 한도
    limited = min(family_expenses.get('spouse', 0) + family_expenses.get('children', 0), 7000000)

    total_medical = unlimited + limited

    if total_medical <= threshold:
        return 0

    # 초과분에 대해 15% 세액공제
    deduction_amount = (total_medical - threshold) * 0.15

    return deduction_amount

# 사용 예시
expenses = {
    'self': 500000,      # 본인 50만원
    'spouse': 800000,    # 배우자 80만원
    'parents': 3000000,  # 부모 300만원 (65세 이상)
    'children': 400000   # 자녀 40만원
}

tax_credit = optimize_medical_expense(50000000, expenses)
print(f"의료비 세액공제: {tax_credit:,}원")
# 출력: 의료비 세액공제: 472,500원

# 연금계좌 최적 납입 시뮬레이터
def optimize_pension_contribution(annual_salary, age):
    """
    연금계좌 최적 납입액 계산

    Args:
        annual_salary: 연 총급여
        age: 나이

    Returns:
        dict: {
            'pension_saving': 연금저축 권장 납입액,
            'irp': IRP 권장 납입액,
            'tax_credit': 예상 세액공제
        }
    """
    if annual_salary <= 55000000:
        tax_rate = 0.165  # 16.5%
    else:
        tax_rate = 0.132  # 13.2%

    # 50세 미만: 연금저축 600만원 + IRP 300만원
    # 50세 이상: 연금저축 600만원 + IRP 900만원 (은퇴 준비)
    if age < 50:
        pension_saving = 6000000
        irp = 3000000
    else:
        pension_saving = 6000000
        irp = 9000000

    total_contribution = pension_saving + irp
    tax_credit = min(total_contribution, 9000000) * tax_rate

    return {
        'pension_saving': pension_saving,
        'irp': irp,
        'total': total_contribution,
        'tax_credit': tax_credit
    }

# 사용 예시
result = optimize_pension_contribution(60000000, 35)
print(f"연금저축: {result['pension_saving']:,}원")
print(f"IRP: {result['irp']:,}원")
print(f"세액공제: {result['tax_credit']:,}원")
# 출력:
# 연금저축: 6,000,000원
# IRP: 3,000,000원
# 세액공제: 1,188,000원
