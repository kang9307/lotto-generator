Why convert between YAML and JSON?

Modern DevOps and SRE workflows lean on the same data model expressed in two formats. Kubernetes manifests, docker-compose.yml, GitHub Actions workflows, Helm charts and Ansible playbooks are written in YAML, while API responses, environment variables, CI variable injection and jq pipelines all speak JSON. This tool bridges the two formats and surfaces indentation and quoting errors immediately.

  • Live conversion · Runs as you type and highlights the failing line (browser-only, nothing is sent to a server).
  • Auto-detect input · A leading { or [ is treated as JSON, anything else as YAML.
  • Alphabetical key sort · Object keys are sorted so that diffs and code reviews stay clean.
  • YAML 1.2 strict mode · Disables the legacy yes/no/on/off boolean coercion so Kubernetes manifests stay safe.
  • Indentation · Choose 2 or 4 spaces (the YAML spec recommends 2).

Frequently asked questions

Does the converted data leave my browser?

No. Everything happens locally with the js-yaml library. There are no network calls, so internal manifests and sensitive secret keys stay on your machine.

Can it handle large files?

Files up to a few megabytes convert instantly. For files larger than 10 MB the browser may pause for a moment, so we recommend turning off live conversion and triggering it manually with the swap button.

What is the difference between YAML 1.1 and YAML 1.2?

YAML 1.1 treats yes/no/on/off/y/n as booleans and accepts sexagesimal numbers (60:00=3600). YAML 1.2 only recognises true/false. Many real-world Kubernetes incidents come from version: yes being silently coerced to true; the strict mode toggle prevents that.

Does it support multi-document YAML (separated by ---)?

Yes. Multi-document YAML is converted into a JSON array. Conversely, a top-level JSON array becomes a multi-document YAML when converted back.

Are YAML anchors and aliases supported?

Yes. &ref definitions and *ref references parse correctly and are expanded into plain values during conversion to JSON.

Can I download the result as a file?

Yes. Use the 💾 button in the output pane to save the result as .json or .yaml.
