Menu names and shortcut keys in this article are carried over as they are written in the Korean-language Microsoft Support documents. The baseline is PowerPoint for Microsoft 365 on Windows, and the documents were read on October 5, 2026. No update date for any of those documents could be confirmed. Ribbon names and menu positions can change with the version and with updates, so when the screen differs from what is written here, the matching item in the official document is the thing to look up again. The guidance rests on what the documents say, not on watching a screen, and the items the documents could not confirm are gathered in the section near the end titled What could not be confirmed. Those items get no standards and no numbers in the body.

Decide first: the baseline version and the three questions of what, why and where

A first-time PowerPoint user rarely gets stuck because a feature is missing; more often the person does not know which menu to use, or in what order. When a file is opened on a PC that does not have the same fonts installed, the fonts, layout and styles can change, and the document explains that embedding fonts is the way to prevent that. The sections below follow the order in which one deck is built, and for every item they say what is done, why it is done at that point, and which menu it lives in.

  • Baseline product: PowerPoint for Microsoft 365 on Windows. The applies-to lists in the documents on creating a presentation, themes and file size also name PowerPoint 2024, 2021, 2019 and 2016, and the list in the PDF document also names the Mac products.
  • Menu notation and macOS: Steps are written as tab > button, for example Home > New Slide, and the names are the ones used in the Korean documents. Where an English interface uses a different label, the position of the item is the reliable guide. A macOS difference is added only where a document spells out a separate macOS route (saving as PDF, closing the master view, and the smart guides for aligning objects). Other macOS and web differences are not covered.
  • Scope: Only the items that the documents support are covered: creating a presentation, layouts, the slide master, themes, aligning objects, the amount of text per slide, presentation shortcuts, Presenter View, PDF, font embedding and file size. Items that could not be confirmed are not filled in with guesses.

The order for building one deck at a glance

The table below gives the working order and the menu location of each step. Adding animations is missing from it because it falls outside what the documents confirmed. The order is not something the documents prescribe; it is arranged along the direction in which the items depend on one another.

OrderWhat to doWhy at this pointWhere (as the document words it)
1Set colors, fonts and the logo in the slide masterThe document describes the master as the tool that adds consistency to styles such as color, fonts, titles and logos and unifies the form of the presentationView > Slide Master
2Choose a layout for each slideThe placeholder arrangement for text, pictures and charts is already definedHome > New Slide / Home > Slide Layout
3Learn how to run the showKnowing the start, end and blank-screen keys means no hunting for the mouse mid-talkF5 · Shift+F5 · Esc and others

The reason the master comes first is summed up in one sentence of the document that describes it: it adds consistency to color, fonts, titles, logos and other styles and unifies the form of the presentation.

The actual working order is creating a new presentation, then 1, then 2, then writing the content, then practicing with 3 and 4, then preparing for distribution with 5, 6 and 7. A new presentation is started by opening PowerPoint and selecting New in the side pane, and the menus are given in the layout section below. Skipping step 1 and starting from step 2 still produces a file. Because the document describes the master as the tool that adds consistency and unifies the form, however, opening the master first matches the document's description for anyone who intends to use shared styles.

Slide layouts: the frame chosen for each slide

The document defines a layout this way. Each theme in PowerPoint contains a set of slide layouts, which are predefined arrangements for slide content. The placeholder boxes inside a layout are spaces for placing text, video, pictures, charts and similar content. Choosing a frame such as one with a title and content therefore means that the position and size of the title box and the body box are already fixed, and the user fills them in.

  • When starting a new presentation: Open PowerPoint and select New in the side pane. To build the presentation from scratch select Blank Presentation, to use a ready-made design select one of the templates, and to see tips on using PowerPoint select Take a tour and then Create. The document adds that one can also start from professionally designed templates on Microsoft Create. To add a slide, pick in the side-pane thumbnails the slide that the new slide should follow, and on the Home tab select New Slide in the Slides section. Content goes in by placing the cursor in a text box and typing, and formatting is set by selecting the text and using the Font section of the Home tab. Pictures are added from the Images section of the Insert tab, and shapes, icons, 3D models, SmartArt and charts from the Illustrations section.
  • When choosing a layout for a new slide: On the Home tab select New Slide and then pick the layout wanted. The frame is decided at the moment the new slide is added.
  • When changing the frame of a slide already made: Select the slide and then choose the layout under Home > Slide Layout. The same list of layouts appears, and the chosen one replaces the current frame.
  • When a slide has lost its shape: Selecting Home > Reset returns it to the original layout. The document states that this action does not delete content that has been added. It is the button for moving boxes around and resizing them freely and then returning them to their original positions.
  • What a placeholder is for: In the document, a placeholder is a fixed slot into which content such as text, video, pictures or charts goes. Because the slots are fixed, the same kind of content can be placed in the same position on every slide without drawing new boxes each time. How a hand-drawn text box reacts to a change in the master could not be confirmed from the documents. How to add, edit or remove placeholders in a layout is in a separate document that was not read.
  • What a layout contains: The document says a layout has placeholders for text, video, pictures, charts, shapes, clip art, backgrounds and so on, and that it also carries formatting such as theme colors, fonts and effects. Its examples of predefined layouts are a title slide to start with, the usual title and content layout, a comparison layout with items side by side, and a picture with caption. A standard layout is chosen by clicking Layout on the Home tab in Normal view and picking the one that best suits the content of the slide.
  • Aligning shapes and pictures: To select several objects, select the first object and then hold Ctrl while selecting the others. For pictures use the Picture Format tab, and for shapes, text boxes or WordArt use the Shape Format tab; in the Arrange group select Align and then choose Align Left, Align Center, Align Right, Align Top, Align Middle or Align Bottom from the menu. The document lists the centered option twice, and its descriptions are alignment vertically through the center of the objects and alignment horizontally through the middle of the objects. If the align options are unavailable, only one item may be selected. To space objects evenly, select three or more and choose Distribute Horizontally or Distribute Vertically. To select an object hidden behind text or stacked behind another, choose Select on the Home tab, choose Select Objects, and then draw a box over the objects. For PowerPoint on macOS the document describes choosing Align to Slide under Shape Format > Align, and the smart guides that appear when an object is dragged (View menu > Grid and Guides > Smart Guides).
  • The amount of text on one slide: The document gives no numbers such as a count of lines or words. Under the item that says to keep text simple and minimize the amount of text on the slide, it says to use bullets or short sentences and to keep each line to one line (no text wrapping), and the reason it gives is that the audience should listen to the presentation instead of reading the screen. It also points out that some projectors crop the edges of a slide, so long sentences may be cut off. For fonts it says to choose simple ones such as Arial or Calibri and to avoid very thin or decorative fonts, and it says to avoid font sizes smaller than 18 pt (and to go larger for a big room where the audience is far away). It also says to use high contrast between the background color and the text color (a theme automatically sets the contrast between a light background with dark text or a dark background with light text), and to check spelling and grammar.

The slide master: why it is set first

According to the document, the slide master is the tool that adds consistency to color, fonts, titles, logos and other styles and unifies the form of the presentation. The same document says that in the master it is possible to edit colors, fonts and effects, to move, hide or show placeholders, and to change the slide orientation from portrait to landscape or the reverse. The document also says that one or more masters can be created, and it explains how to save the result as a template for reuse after the changes (File > Save As, changing the file type to a template).

The document's answer to the question of why it comes first lies in the definition of the master. It is a tool that adds consistency to color, fonts, titles, logos and other styles and unifies the form of the presentation, so settling the shared styles in the master matches the document's description. The document does not explain how a change made in the master reaches slides that already exist.

  1. On the View tab select Slide Master. The documents give the same tab name for both Windows and macOS.
  2. In the slide thumbnail pane, the master is the larger slide image at the top, and the layouts connected to it are placed below it. To remove a built-in layout, select the layout to delete and choose Delete on the Slide Master tab.
  3. In the master, change the colors, fonts and effects. The slide orientation is set by choosing Slide Size > Custom Slide Size on the Slide Master tab and picking the orientation.
  4. Move, hide or show the placeholders that are needed. Whether the footer (slide number, date and footer text placeholders) appears on a given type of slide is decided by selecting the slide layout in the thumbnail pane and then checking or clearing Footers on the Slide Master tab.
  5. When the work is done, choose Close Master View on the Slide Master tab. On macOS the same position holds Close Master.
  • Changing colors and fonts through a theme: According to "Add color and design to your slides with Themes", the separate document that the master document points to, PowerPoint provides design themes with coordinated color schemes, backgrounds, font styles and placeholder placement. When starting a new presentation a theme can be picked under File > New, and later on the Design tab a theme with the colors, fonts and effects wanted is chosen, or a different color variation is applied from the Variants group. The Variants down arrow opens Colors, Fonts, Effects and Background Styles to choose from or customize, and when finished, choosing Save Current Theme from the Themes down arrow and giving it a name makes it appear in the Themes group under a Custom header. The document says these built-in themes work for both widescreen (16:9) and standard screen (4:3) presentations, and that if no variants are shown, it may be because a custom theme or an older theme designed for earlier versions is in use, or because slides were imported from a presentation that uses such a theme.
  • Slides the master did not touch: Formatting applied individually on slides that already exist can remain independent of a master change. The document does not state this, so after changing the master it is safer to open a few slides and check the look. Pressing Shift+F5 to view the slide in show mode is a quick way to do it.
  • More than one master in a presentation: In the slide thumbnail pane click where the new master should appear, and choose Insert Slide Master on the Slide Master tab. A separate document titled "Use multiple slide masters in one presentation" exists but was not read.

Starting the talk: slide show shortcuts and Presenter View

The presentation shortcuts below are only those confirmed in the Microsoft Support shortcut document. The document covers Windows, macOS and the web separately, and it says that the key for opening the list of shortcuts during a presentation differs: F1 on Windows and the slash (/) on macOS. The notation below is for Windows.

KeyAction (document wording)When it is used
F5Starts the presentation from the beginningA full rehearsal or the talk itself from the first slide
Shift+F5Starts the presentation from the current slideChecking at once how the slide being edited looks in show mode
Alt+F5Starts the presentation in Presenter ViewPracticing while watching the notes and the timer
EscEnds the presentationLeaving the show and returning to the editing screen
N, Enter, Page Down, Right Arrow, Down Arrow, SpacebarPerforms the next animation or advances to the next slideMoving forward
P, Page Up, Left Arrow, Up Arrow, BackspacePerforms the previous animation or returns to the previous slideGoing back
B or period (.)Shows a black blank slide, or returns from itDrawing the audience attention to the speaker

The difference between F5 and Shift+F5 is the one used most while editing. If the slide being worked on is number 15, F5 requires advancing from slide 1 up to 15, while Shift+F5 starts right at 15. The keys for moving to the next or previous slide are in the last two rows of the table, in the document's wording. The same document adds that to go to a particular slide you type the slide number and then press Enter, that Ctrl+S shows the All Slides dialog box, and that Home goes to the first slide and End to the last. It also says that during the show Ctrl+L starts the laser pointer, Ctrl+P changes the pointer to a pen, and E erases the on-screen annotations.

  • How to turn on Presenter View: On the Slide Show tab select the Use Presenter View checkbox, choose the monitor on which Presenter View should appear, and then press F5 or select From Beginning.
  • What shows in Presenter View: The current slide, the next slide and the speaker notes. The document says it is possible to move between slides with the arrows next to the slide number, pause or reset the timer, check the current time, enlarge or reduce the notes font, use the drawing and laser pointer tools, zoom into a slide, and temporarily blank the screen.
  • Why it is used: The shortcut document explains Presenter View as a way for one screen (for example a laptop) to show the presentation together with the speaker notes while the audience sees the presentation without notes on another screen.
  • With a single monitor: When a second display is connected, Presenter View appears automatically when the slide show starts. If it does not start automatically, select the Use Presenter View checkbox on the Slide Show tab and choose the primary monitor. Even with only one display, the shortcut document says to press Alt+F5 to start the presentation in Presenter View. Within Presenter View, F6 cycles between the areas, Tab cycles through the tools within an area, and Esc closes Presenter View.
  • Notes and moving between slides: The Presenter View document says the preview icon shows all the slides in the presentation so that one can move quickly to another slide. How to add speaker notes is in a separate document titled "Start the presentation and see your notes in Presenter view", which was not read.

Saving or exporting as PDF

The PDF document lists these as its applies-to products: PowerPoint for Microsoft 365, PowerPoint for Microsoft 365 for Mac, PowerPoint 2024, PowerPoint 2024 for Mac, PowerPoint 2021, PowerPoint 2021 for Mac, PowerPoint 2019 and PowerPoint 2016. The document explains that saving a presentation as a PDF file fixes the formatting and layout, and that people can view the slides even without PowerPoint but cannot change them.

  1. Select File > Export, then select Create PDF/XPS Document and then select Create PDF/XPS.
  2. Choose the save location and type the file name.
  3. Decide how the final PDF should look. Under Optimize, Standard is for when high quality is needed, such as for printing, and Minimum size is for when the file should be smaller.
  4. Select Publish.
  • The Options button: Choosing Options in the same dialog sets how the presentation appears as a PDF, and the document gives these examples: saving only the current slide or setting a range by start and end numbers, saving only notes, handouts or outline view instead of the slides, the number of slides per page, and including slide borders, hidden slides, notes, ink, document properties and document structure tags in the PDF.
  • macOS: Either choose File > Save As and set the file format to PDF, or choose File > Export and pick PDF in the file format menu. Both routes are written in the document.
  • Choosing between Standard and Minimum size: Standard when print quality is needed, and Minimum size when a size limit such as an e-mail attachment limit takes priority. The document gives no figures for how much the two settings differ in the resulting file.
  • What to look at before sending a PDF: Whether hidden slides are included and whether slide borders appear are decided in the options. Opening the exported PDF once to check the page count and the look of the fonts before sending is the safer habit.
  • When a PDF must be edited: The PDF document says that a file saved as PDF can only be viewed and not changed. How to edit a PDF itself is covered in the PDF editing basics article.

When fonts break on another PC: saving with fonts embedded

The situations the document gives as ones in which embedding fonts is useful are two. One is when a nonstandard font is used, and the other is when other people are expected to edit or view the presentation offline. Sending a deck by e-mail or carrying it to another PC to open fits both. The font problem arises when a font that exists only on the PC that made the file is missing on the other PC, and saving with fonts embedded is the setting that packs that font into the file as well. The document notes that Office fonts have recently moved to the cloud, so Office subscribers with Internet access do not need to embed them, and that embedding is still useful when a nonstandard font is used or when others need to edit or view the presentation offline. It adds that embedding custom fonts in a document also helps when it is converted to a PDF file online.

  1. Select the File tab and then select Options.
  2. Select Save on the left.
  3. Select the embed-fonts-in-the-file checkbox. Another Microsoft document words the same item as embedding fonts in the file, or as Embed fonts under Preserve fidelity when sharing this presentation, so the wording can differ slightly by document and version.
  4. Select OK.
  • Embed only the characters used in the presentation: This reduces the file size but limits editing. It suits cases in which the recipient only needs to open and view the deck.
  • Embed all characters (best for editing by other people): This is the choice the document recommends when the recipient may change the content. The file becomes larger.
  • Fonts that cannot be embedded: Some TrueType fonts cannot be embedded because of the permission settings of the font creator. The document says that information on whether a font can be embedded is shown in the Fonts item of the Windows Control Panel.
  • Mac users: The document lists Word for Microsoft 365 for Mac, PowerPoint for Microsoft 365 for Mac, PowerPoint 2024 for Mac and PowerPoint 2021 for Mac as supported, and it says to use the OpenType (.OTF) or TrueType (.TTF) format and to avoid PostScript (.PFB, .PFM).
  • Balancing against file size: A large font can greatly increase the file size, and the document advises substituting another font if that becomes a problem.

Font embedding and PDF saving serve different purposes. If the other person must open and edit the file, font embedding fits, and if only the appearance must stay the same, PDF fits. Using both makes it possible to produce an editable copy and a submission copy separately.

Reducing file size: picture compression and settings

The applies-to list of the file size document is PowerPoint for Microsoft 365, PowerPoint 2024, 2021, 2019 and 2016. The methods the document introduces are in the table below. It also says that when a presentation contains audio or video, compressing the media can reduce the file size considerably.

Compress picturesPicture Format tab > Adjust group > Compress PicturesSelect delete cropped areas of pictures, and for resolution use the default resolutionIf Apply only to this picture is not selected, it applies to all pictures
Delete editing dataFile > Options > Advanced > Image Size and QualitySelect discard editing data, and choose a default resolution of 150 ppi or lowerDeleted editing data cannot be restored
Optimize embedded fontsFile > Options > SaveEmbed fonts in the file, then embed only the characters used in the presentationEditing by other people is limited
Compress mediaThe audio and video compression featureThe menu position was not confirmed-
  • How picture compression works: Deleting cropped areas removes from the file the data of the parts of a picture that were cropped out of view. The document explains that, by default, editing an image keeps the data of the original, that deleting this data makes the edits impossible to restore but reduces the file size, and that lowering the default resolution of images also reduces the overall file size.
  • What 150 ppi or lower means: The document says to choose a default resolution of 150 ppi or lower. For pictures that need print quality, a low value can affect image quality, but the limit of that effect could not be confirmed in the document.
  • Work that cannot be undone: Deleting editing data or cropped areas cannot be reversed, according to the document. Copying the original under a separate name before reducing is the safer order.
  • The conflict with font embedding: Embedding fonts adds stability but enlarges the file, and to shrink it the setting has to be changed to embed only the characters used. The two are balanced on the same settings screen.
  • The link to PDF: The PDF document says to choose Minimum size under Optimize to make the file smaller, and gives sending it as an e-mail attachment as the example.

Checking the order from start to finish

  1. Open PowerPoint, select New in the side pane and then Blank Presentation, and open View > Slide Master right away.
  2. In the master, settle the colors, fonts, title shape and logo, and hide the placeholders that are not needed.
  3. Return to the editing screen with Close Master View.
  4. From Home > New Slide, choose a layout that suits the content and add the slide.
  5. Return a slide whose shape has gone wrong to its original with Home > Reset.
  6. Check the current slide with Shift+F5 and the whole deck with F5 in show mode.
  7. Just before the talk, decide font embedding under File > Options > Save, and for the submission copy make a PDF through File > Export. If there are large pictures, apply picture compression first.

The basis of this order is the direction in which each item depends on another. The master is the base of the layouts, the layout is the frame of a slide, and font embedding, PDF and compression are finishing steps applied to completed content. The harder an operation is to undo, the later it is placed. Deleting editing data and deleting cropped areas cannot be restored, according to the document, so copying the original beforehand is the last check item.
