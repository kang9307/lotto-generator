PHP 基础语法与数据类型

PHP 基本语法

PHP 标签

PHP 代码由特殊的起始和结束标签包裹,以便 PHP 引擎能够识别代码。

<?php
  // 编写 PHP 代码
?>

或使用短 echo 标签(PHP 7.0+ 默认启用):

<?= $变量 ?>  // 等同于 <?php echo $变量; ?>

注释

PHP 同时支持单行注释和多行注释。

<?php
// 单行注释

# 另一种单行注释风格

/*
 多行注释
 这样书写
*/
?>

语句分隔符

在 PHP 中,每条语句必须以分号(;)结尾。

<?php
echo "你好";
$x = 5;
$y = 10;
$z = $x + $y;
?>

PHP 与 HTML 混合使用

PHP 可以轻松嵌入到 HTML 中。

<!DOCTYPE html>
<html>
<head>
    <title>PHP 示例</title>
</head>
<body>
    <h1>你好!</h1>
    <?php
        echo "<p>今天的日期是: " . date("Y-m-d") . "</p>";
    ?>
    <p>这是 HTML 内容。</p>
    <p>当前时间: <?= date("H:i:s") ?></p>
</body>
</html>

变量与数据类型

变量声明

在 PHP 中,变量以美元符号($)开头,不需要显式声明类型。

<?php
$name = "张三";         // 字符串
$age = 25;             // 整数
$height = 175.5;       // 浮点数
$isStudent = true;     // 布尔值
?>

变量命名规则

  • 变量名必须以美元符号($)开头。
  • 变量名必须以字母或下划线(_)开头。
  • 变量名只能包含字母、数字和下划线。
  • 变量名区分大小写($name 和 $Name 是不同的变量)。
<?php
$name = "有效的变量名";
$_name = "有效的变量名";
$name1 = "有效的变量名";
$name_1 = "有效的变量名";

// $1name = "无效的变量名";  // 不能以数字开头
// $name-1 = "无效的变量名"; // 不能使用连字符
?>

变量作用域

PHP 中的变量可以有三种作用域:

  1. 局部变量:在函数内部声明的变量,只能在函数内部访问。
  2. 全局变量:在函数外部声明的变量,在函数内部需使用 global 关键字才能访问。
  3. 静态变量:在函数内使用 static 关键字声明的变量,即使函数执行结束也会保留其值。
<?php
$globalVar = 10;  // 全局变量

function testScope() {
    $localVar = 5;  // 局部变量
    global $globalVar;  // 访问全局变量

    echo "局部变量: $localVar<br>";
    echo "全局变量: $globalVar<br>";

    static $staticVar = 0;  // 静态变量
    $staticVar++;
    echo "静态变量: $staticVar<br>";
}

testScope();  // 输出: 局部变量: 5, 全局变量: 10, 静态变量: 1
testScope();  // 输出: 局部变量: 5, 全局变量: 10, 静态变量: 2

// echo $localVar;  // 错误:局部变量在函数外部无法访问
?>

超全局变量

PHP 提供了一组可全局访问的内置变量:

<?php
// 超全局变量示例
echo $_SERVER['HTTP_USER_AGENT'];  // 浏览器信息
echo $_GET['name'];                // URL 参数
echo $_POST['email'];              // POST 数据
echo $_REQUEST['id'];              // GET、POST、COOKIE 数据
echo $_SESSION['user_id'];         // 会话数据
echo $_COOKIE['preference'];       // Cookie 数据
echo $_FILES['upload'];            // 上传文件信息
echo $_ENV['HOME'];                // 环境变量
?>

数据类型

PHP 支持以下基本数据类型:

  1. 字符串(String)

    $name = "张三";
$address = '北京市朝阳区';  // 也可使用单引号

  2. 整数(Integer) 

    $age = 25;
$negativeNum = -10;
$hex = 0x1A;  // 十六进制(值: 26)
$oct = 057;   // 八进制(值: 47)
$bin = 0b11;  // 二进制(值: 3)

  3. 浮点数(Float 或 Double)

    $height = 175.5;
$scientificNotation = 1.5e3;  // 1500

  4. 布尔值(Boolean)

    $isActive = true;
$hasPermission = false;

  5. 数组(Array)

    $colors = array("红", "绿", "蓝");
$colors = ["红", "绿", "蓝"];  // PHP 5.4+ 简写语法

// 关联数组
$person = [
    "name" => "张三",
    "age" => 25,
    "city" => "北京"
];

  6. 对象(Object)

    class Person {
    public $name;
    public $age;

    function __construct($name, $age) {
        $this->name = $name;
        $this->age = $age;
    }

    function introduce() {
        return "你好,我叫 {$this->name},今年 {$this->age} 岁。";
    }
}

$person = new Person("张三", 25);
echo $person->introduce();

  7. NULL

    $var = NULL;  // 表示没有值

  8. 资源(Resource)

    $file = fopen("test.txt", "r");  // 文件资源

类型检查与转换

PHP 提供了多种用于检查和转换变量类型的函数。

<?php
$var = "42";

// 类型检查
var_dump($var);                // string(2) "42"
echo gettype($var);            // string
echo is_string($var);          // 1 (true)
echo is_int($var);             // (空输出,false)

// 类型转换
$varInt = (int)$var;           // 转换为整数
$varFloat = (float)$var;       // 转换为浮点数
$varBool = (bool)$var;         // 转换为布尔值
$varString = (string)$varInt;  // 转换为字符串

// 类型检查函数
echo is_int($varInt);          // 1 (true)
echo is_float($varFloat);      // 1 (true)
echo is_bool($varBool);        // 1 (true)
echo is_string($varString);    // 1 (true)
?>

常量

常量是一旦定义就无法更改的值。常量可以使用 define() 函数或 const 关键字定义。

<?php
// 使用 define() 函数
define("PI", 3.14159);
define("SITE_NAME", "PHP 教程");

// 使用 const 关键字 (PHP 5.3+)
const MAX_USERS = 100;
const DB_HOST = "localhost";

echo PI;           // 3.14159
echo SITE_NAME;    // PHP 教程
echo MAX_USERS;    // 100

// PI = 3.15;      // 错误:常量不可修改
?>

魔术常量

PHP 提供了一组特殊的内置常量(魔术常量):

<?php
echo __LINE__;     // 当前行号
echo __FILE__;     // 当前文件的完整路径和文件名
echo __DIR__;      // 当前文件所在目录
echo __FUNCTION__; // 当前函数名
echo __CLASS__;    // 当前类名
echo __METHOD__;   // 当前类的方法名
echo __NAMESPACE__; // 当前命名空间名
?>
