이 테스트 결과를 진단으로 믿어도 되나요?

아니요. 이 테스트는 이시하라 방식을 본뜬 참고용 선별 테스트입니다. 화면의 색 재현은 기기마다 달라 인쇄된 정식 검사표와 같은 정확도를 낼 수 없으므로, 색각 이상이 의심되면 안과에서 정식 검사를 받으세요.

모니터나 화면 설정이 결과에 영향을 주나요?

예. 디스플레이의 색 표현 범위와 밝기, 야간 모드나 블루라이트 필터 같은 색 보정 기능이 색 구분에 직접 영향을 줍니다. 테스트 전에 화면 밝기를 충분히 올리고 색 필터 기능은 끄는 것이 좋습니다.

내 답변이나 결과가 어딘가로 전송되나요?

아니요. 색판 생성부터 채점까지 모두 브라우저 안에서 처리되며, 답변이나 결과를 외부로 보내는 코드가 없습니다. 결과가 공유되는 것은 결과 화면의 복사·공유 버튼을 직접 눌렀을 때뿐입니다.
