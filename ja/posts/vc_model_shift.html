きっかけ - エッセイが述べたこと、そして原文にないこと

原文の題は「Cancer Capital」であり、韓国には「VC はもはや VC ではない」という見出しで紹介された。筆者は、規制が緩むなかで少数のベンチャーキャピタルが何でもやるファンドへと膨らみ、その過程で法的にはベンチャーキャピタルであることをやめた、と主張する。

主張の中心に置かれているのは算数一行である。500億ドルを運用して年2パーセントを受け取れば、投資した会社が生きようが死のうが毎年10億ドルが手に入るというものだ。筆者はここに政治資金の話を接ぐ。ある大型投資会社が2026年の中間選挙サイクルに1億1,530万ドルを拠出し、これは2024年の6,300万ドルのおよそ二倍であり、追跡対象となった暗号資産および人工知能企業の政治献金のうち20パーセントを超える取り分だと書いている。結論は権力関係の逆転である。かつては創業者が会社をつくり投資家が機会を探したのに対し、いまは投資会社が綱領を掲げ、創業者はそれを遂行する者として選ばれる、というのだ。

性格をはっきりさせておくべきことがある。これはエッセイである。論証であって実証研究ではない。したがって筆者の文は事実としてではなく主張として運ばれなければならない。何が原文にないのかは後段に別途記した。

ただし政治的な議論を取り除いても算数一行は残る。管理報酬は結果と無関係に積み上がるということ。この記事が引き取るのはその一行であり、その一行だけでも創業者の受け取る条件がなぜ変わるのかは説明できる。

ファンドは二つの流れで稼ぐ

ベンチャーファンドは会社ではなく組合である。資金を出す側と運用する側が分かれている。「ベンチャー投資促進に関する法律」第50条第3項はその構成をこう定める。組合の業務執行者として組合の債務に無限責任を負う1人以上の業務執行組合員と、出資価額を限度として有限責任を負う有限責任組合員で構成する。前者を一般に GP、後者を LP と呼ぶ。公募ベンチャー投資組合であれば業務執行組合員は1人である。

運用する側が受け取る金銭は二つの流れに分かれる。

  • 管理報酬 - ファンドを運用する対価。成果と無関係に定められた料率で積み上がる。人件費や事務所などの固定費をここから賄う。
  • 成功報酬 - 収益があらかじめ定めた敷居を超えたとき、その超過分から取る取り分。結果に連動する。

二つの報酬はリスクの性格が正反対である。管理報酬は固定収入に近く、成功報酬は劣後する成功払いである。この二つの比重がどちらに傾くかによって、運用する人が何に気を配るのかが変わる。成功報酬が実質的に唯一の報酬であれば、回収を大きくすることにすべてが懸かる。管理報酬だけで組織が維持されるなら、ファンドを大きくし続けることが安定した選択になる。

韓国の制度はこの二つの報酬をどう書いているか

韓国ベンチャーキャピタル協会が出したベンチャー投資組合の標準規約と、その作成案内書に条文がそのまま載っている。料率の欄は空いているが、構造は完全に露わになっている。

管理報酬 - 区間が二つに分かれる

標準規約第27条第1項は管理報酬を二つの区間に割る。

  • 第1号 - 中小ベンチャー企業部に登録した日から定められた年数が経つ日までは、出資金総額の年何パーセント。
  • 第2号 - その後解散する日までは、投資残額、すなわち各四半期末の平均残額または日々の平均残額の年何パーセント。

この区分が核心である。前の区間の基準は約定された総額だ。その資金が実際に会社へ入ったのか、入ってどうなったのかは計算に入ってこない。後の区間になって初めて基準が残っている投資残額へ移る。支払いは第1号が各四半期末、第2号は事業年度決算に対する組合員総会の承認後が原則だが、2分の1の範囲で前もって支払える。

管理報酬は組合が負担する。第26条第1項第7号が組合運営経費の一覧に管理報酬を載せており、同条第2項は、その一覧にない業務執行費用は業務執行組合員が負担すると定める。

成功報酬 - 敷居を超えた後から

第28条第1項は、存続期間中に内部収益率が基準収益率を超えれば、組合員総会の承認を経て投資収益の定められた比率を業務執行組合員に成功報酬として支払うと定める。基準収益率そのものも第2項で空欄のまま残されている。

ここで使われる言葉は規約自身が定義する。投資収益は組合資産の評価金額から出資金額と組合運営経費を差し引いた金額であり、内部収益率は組合が運用した資金の現在価値と組合員が回収する金額の現在価値を等しくする割引率であり、基準収益率は成功報酬を支払える敷居となる収益率である。

第3項には早期支払いの手続きがある。登録後3年が過ぎ、規約の定める投資期間も過ぎ、投資義務を満たした場合には、最終決算前でも順序を守って成功報酬を支払える。順序はこうだ。まず組合員へ配分した累積金額が出資元本と基準収益率に相当する金額の合計に達するまで組合員へ優先配分し、そのうえで残る範囲から成功報酬を支払い、残余は出資比率に応じて分ける。第4項は施行令を受けて、業務執行組合員が受け取った成功報酬の範囲内で代表ファンドマネージャーなど役職員へ成果給として支払うよう定めている。

料率の欄が空いているのは欠落ではない。案内書は管理報酬と成功報酬のそれぞれに、別途の規定がないため組合員間の協議によって設定する、という趣旨の注記を付している。料率は法が与える値ではなく、LP と GP が交渉して埋める欄だという意味だ。したがって「法が成功報酬を20パーセントと定めている」という類の説明は、この文書では裏づけられない。

存続期間も同じやり方である。第14条は登録日から定められた年数とし、総会の特別決議で延長できるようにしたうえで、注記に施行令を根拠として最低5年以上と記した。管理報酬はその存続期間を通じて積み上がる。

標準規約の条文何を定めるか創業者の側から見ると
第14条 存続期間登録日から定められた年数、特別決議で延長。最低5年以上残り期間が短いファンドほど回収を急ぐ
第26条 組合運営経費管理報酬を含む組合負担の費用一覧管理報酬は組合財産から出ていく
第27条 管理報酬前の区間は出資金総額基準、後の区間は投資残額基準初期は執行の有無と無関係に積み上がる
第28条 成功報酬内部収益率が基準収益率を超えた後、総会承認で支払い大きな回収が出て初めて運用者の報酬が増える
第30条 投資の方法非上場の創業企業やベンチャー企業などに投資対象を限定ファンドはどこにでも入れられるわけではない
第35条 配分原則未投資の出資元本を組合員へ返す配分の根拠運用されなかった資金は戻りうる

規模が管理報酬にもたらすもの

料率が同じでも規模が違えば結果は違う。以下は構造を示すための仮想の単純な例である。税や中途回収、区間ごとの基準変更をすべて無視し、全区間に出資金総額基準を当てはめた。

[前提] 管理報酬 年2%、存続期間8年

ファンドA - 出資金総額 1,000億ウォン
  年間の管理報酬 =  1,000億 x 2%  =    20億ウォン
  8年の累積                       =   160億ウォン

ファンドB - 出資金総額 1兆ウォン
  年間の管理報酬 = 10,000億 x 2%  =   200億ウォン
  8年の累積                       = 1,600億ウォン

料率は同じ。変わったのは規模だけである。

目を留めるべきは費用が規模についていかないという点である。ファンドが十倍になったからといって審査担当が十倍必要になるわけではない。一件を検討する手間は投資金額に比例しないからだ。だから規模が大きくなるほど、管理報酬から組織の維持費を引いて残る取り分が大きくなる。

原文のエッセイの500億ドルと2パーセントは、まさにこの地点を狙った数字である。ただしその値は筆者が論旨を示すために挙げた例であって、特定のファンドの実際の契約条件ではない。金額も料率も時点と地域と契約によって変わる。

重要なのは金額ではなく方向である。管理報酬が組織を維持してなお余るほど大きくなれば、次のファンドをより大きくすることがそれ自体で合理的な選択になる。成功報酬は回収がすべて終わってから精算されるのに対し、管理報酬は結成の翌四半期から入ってくるからだ。

大きなファンドが大きな回収を必要とする算数

規模は管理報酬だけを変えるのではない。どんな会社がポートフォリオに合うのかを変える。これも仮想の単純な例である。

[前提] LP に元本の3倍を返すことを目標とする。
       投資した30社のうち意味のある回収は3社から出る。
       回収時点の持分比率は15%。

ファンドA - 1,000億ウォン
  必要な回収総額 = 3,000億ウォン
  成功3社       -> 1社あたり   1,000億ウォン
  持分15%       -> 企業価値 約 6,700億ウォン

ファンドB - 1兆ウォン
  必要な回収総額 = 3兆ウォン
  成功3社       -> 1社あたり   1兆ウォン
  持分15%       -> 企業価値 約 6.7兆ウォン

同じ倍率を目標にしても、必要な会社の大きさがファンド規模に比例して大きくなる。この算数に善し悪しはない。ただの算数である。

ところが創業者の側から見ると結果ははっきりする。年商100億ウォンで利益が安定して出る会社は立派な事業だ。しかしファンドBのポートフォリオでは四捨五入すると消える資産である。会社が悪いからではない。そのファンドの算数に居場所がないからだ。同じ会社がファンドAでは意味のある回収候補になる。

だから「うちのファンドとは合わない」という言葉は、たいてい会社に対する評価ではなく算数の話である。その言葉を聞いたとき、直すべきは会社ではなく相手を替えることだという場合がある。

創業者の受け取る条件はここで分かれる

ここまでの算数はタームシートの三か所で姿を現す。ラウンドそのものの基礎、すなわちシードとシリーズA・B・Cの区分やバリュエーションの計算、SAFE、キャップテーブルはスタートアップ投資ラウンド完全ガイドに整理してある。ここではその上に乗る誘因だけを見る。

成長圧力は好みではなく構造である

投資家が成長率を前面に出すのは性格の問題ではない。前節の算数が求める大きさに届くには、残された期間で何倍にならねばならないかがすでに決まっているからだ。存続期間は最低5年で実際にはそれより長く取られるが、後半に行くほど残り時間は短くなる。同じ会社でも、結成したばかりのファンドと満期の近いファンドでは求める速度が違う。だから相手ファンドの結成時期は条件の一部である。

次のラウンドが前提として敷かれる

いまのラウンドのバリュエーションは、たいてい次のラウンドがより高いことを前提に組まれる。前提が守られれば全員にとってよい。崩れればダウンラウンドになり、そのとき持分の希薄化と条項が同時に動く。だからタームシートを読むときは、次のラウンドがより低い場合に各条項がどう作動するかを併せて計算しておくほうがよい。よいシナリオではほとんどの条項は黙っている。

清算優先権が順序を決める

会社が売られたり整理されたりするとき、誰がいくらを先に持っていくのかを決める条項である。韓国のベンチャー投資では償還転換優先株、略して RCPS の形が広く使われる。名前のとおり償還権と転換権を持ち、利益配当と残余財産の分配で普通株に先んじる。この条項の重みは次節で数字として現れる。

清算優先権を数字に置いて見る

清算優先権は二つに分かれる。参加型は優先分を受け取ったうえで残余財産も持分比率に応じて分け合う。非参加型は優先分を受け取ればそこで終わりだが、転換権があるので普通株に換えて持分比率どおり受け取るほうが大きければそちらを選ぶ。以下は再び仮想の単純な例である。

[前提] 投資家が20億ウォンを入れて持分20%を優先株で受け取った。
       清算優先権は投資元本1倍。他のラウンドと費用はないものとする。

売却価格 200億ウォン
  非参加型 : max(20億, 200億x20%=40億)  -> 投資家 40億 / 普通株 160億
  参加型   : 20億 + (180億x20%=36億)    -> 投資家 56億 / 普通株 144億

売却価格 100億ウォン
  非参加型 : max(20億, 100億x20%=20億)  -> 投資家 20億 / 普通株  80億
  参加型   : 20億 + (80億x20%=16億)     -> 投資家 36億 / 普通株  64億

売却価格 30億ウォン
  非参加型 : max(20億, 30億x20%=6億)    -> 投資家 20億 / 普通株  10億
  参加型   : 20億 + (10億x20%=2億)      -> 投資家 22億 / 普通株   8億

表に移すと一つのことが鮮明になる。売却価格が低いほどこの条項の重みが増す。200億ウォンで売れる場合、参加の有無は普通株の取り分を1割ほど動かすにとどまるが、30億ウォンで売れる場合は普通株に残るものが3分の1を下回る。

200億ウォン160億ウォン144億ウォン16億ウォン
100億ウォン80億ウォン64億ウォン16億ウォン

30億ウォン10億ウォン8億ウォン2億ウォン

この箇所が前のファンドの算数とつながる。大きなファンドほど「小さな回収」で終わる案件の比重が増すので、この条項が実際に効いてくる区間に入る確率も一緒に高まる。よいシナリオだけを置いて条件を受け入れれば、条項が働く区間を計算しないまま署名することになる。

実際の契約はこれより複雑である。優先権の倍率が1倍でないこともあり、参加型でも上限が付くことがあり、ラウンドが複数あれば後のラウンドが先に持っていくのか同じ順位で分けるのかが別途定められる。条件は契約ごとに違うので、一般化できる値ではない。

韓国の制度があらかじめ塞いだ場所

「管理報酬を受け取りながら資金を動かさなければどうなるのか」に対して、韓国の制度は答えを持っている。二つの仕掛けである。

一つ目は投資義務比率である。標準規約第30条とその注記は、根拠としてベンチャー投資促進に関する法律第51条、施行令第35条、「ベンチャー投資組合の登録および管理規程」第7条を挙げる。ブラインドファンドやプロジェクトファンドは、登録日から3年を経過する日までに認められた投資方法で出資約定額の20パーセント以上を投資しなければならない。セカンダリーおよび買収合併ファンドは同じ期間に60パーセント以上である。投資対象も開かれてはいない。第30条第1項は、証券市場に上場していない創業企業、ベンチャー企業、技術革新型および経営革新型の中小企業に範囲を絞る。

二つ目は動かさなかった資金の返還である。標準規約第35条第2項は、組合登録後3年が過ぎ規約の定める投資期間まで過ぎたのに投資されなかった出資元本を、組合員総会の特別決議で組合員へ配分できるようにした。配分した後も出資元本は20億ウォン以上でなければならないという但し書きが付く。

運用者自身の利益のための行為も条文で塞がれている。法第52条第1項は業務執行組合員に善良な管理者の注意をもって業務を執行するよう求め、第2項は自己または第三者の利益のために組合財産を用いること、資金の借入れと支払保証と担保の提供、相互出資制限企業集団に属する会社への投資、非業務用不動産の取得を禁じる。組合財産は受託会社が別に保管し管理する。

資金の出どころも異なる。中小ベンチャー企業部は2026年1月23日、その年の第1次定時出資計画を出しながら、母体ファンド2兆1,000億ウォンの出資でベンチャーファンド4兆4,000億ウォンを組成することを目標として示した。省庁別では中小ベンチャー企業部1兆6,300億ウォン、文化体育観光部4,990億ウォン、海洋水産部150億ウォンである。相当な取り分が財政から出る構造であり、だからこそ右のような投資義務と配分の規律が併せて付いてくる。

したがって原文のエッセイが狙った米国の状況をそのまま韓国に移すことはできない。規制の肌理が違う。ただし管理報酬が結果と無関係に積み上がるという構造そのものは同じである。韓国はその上に、最低投資比率と未投資元本の返還というブレーキを掛けているにすぎない。

別の経路 - 何を手放し何を得るのか

ベンチャーファンドの算数が会社に合わないのであれば、資金の入れ方そのものを変える選択肢がある。それぞれが何かを手放し何かを得る。どれかが優れているのではなく、会社の成長曲線と噛み合うかどうかの問題である。

経路持分の希薄化返済義務支配権手放すもの得るもの
ブートストラップなしなしそのまま維持速度と到達しうる規模条件のない決定権
売上連動型ファイナンスなし売上比率で返済、総額に上限おおむね取締役の席なし総返済額が元本より大きい持分と支配を保った資金
小規模ベンチャーファンドありなし条項で一部移転持分と一部の決定権中規模の回収も有効な算数
大型ベンチャーファンドありなし条項で相当部分が移転持分と速度の選択権大規模な資本と追加投資の余力
政策・公共資金おおむねなし融資の性格なら ありそのまま維持時期を選ぶ自由相対的に低い資金調達費用

売上連動型ファイナンスは韓国ではまだなじみのある名ではない。海外の提供事業者の紹介資料で説明されている構造はこうだ。資本を先に受け取り、毎月の売上の一定比率で返していくが、総返済額に上限を置き、その上限に達すれば終わる。上限は元本の1.2倍から1.5倍の範囲として説明されることが多く、利率ではなく総返済倍率として条件が示される。売上が増えれば早く終わり、減れば遅く終わるので固定の返済期日がない。その代わり売上とその実績が必要なので売上以前の段階では使えず、調達規模も売上の大きさに縛られる。

政府や公共機関を通じた資金は性格がまた異なる。返す資金と返さない資金が混ざっているので公告を読む順序から切り分けねばならないが、その部分は政策資金はタダのお金ではないに別途整理してある。個人投資家の側から近づく経路とその危険はクラウドファンディング・P2P投資完全ガイドにある。

タームシートで先に読む場所

バリュエーションは真っ先に目に入るが、最も遅く確定する数字である。それより先に読むべき場所がある。以下の順に押さえれば、タームシートがどんな誘因の上に立っているのかが見えてくる。

順序項目何を確認するかなぜここが先か
1ファンドの規模と結成時期総額、登録時期、残る存続期間求められる回収の大きさと速度がここから出る
2清算優先権の倍率投資元本の何倍まで優先するのか低い売却価格での普通株の取り分を決める
3参加の有無と上限参加型か、上限が付いているか同じ倍率でも結果が分かれる
4ラウンド間の順位後のラウンドが先んじるのか、同順位か追加投資の後に順序が変わる
5償還権の条件いつ、どの原資で行使されるのか配当可能利益がなければ実行が制約される
6追加投資に関する条項持分比率維持権と不参加時の不利益次のラウンドの交渉力をあらかじめ決める
7共同売却に関する条項売却を誰が引けて誰が付いていくのか出口の決定主体を定める
8取締役会と同意権の一覧予算・採用・追加投資のどれが同意の対象か日常の意思決定の速度を変える

八つの項目をすべて見た後に、もう一つやることがある。同じタームシートを二つのシナリオで計算してみることである。一つは次のラウンドがより高い場合、もう一つはより低いか、そもそも成立しない場合だ。よいシナリオではほとんどの条項は静かである。条項の性格は悪いシナリオでしか現れない。

相手がどんなファンドなのかも条件の一部である。結成時期、ファンド規模、残る存続期間はたいてい尋ねれば分かり、この三つが前節の算数を決める。スタートアップが失敗する本当の理由で扱った意思決定の問題と、この条件の構造は互いに噛み合っている。調達条件が成長速度を強いれば、その速度がふたたび意思決定の余裕を削るからだ。
