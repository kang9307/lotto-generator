一句关于60美元游戏电脑的说法传了开来。东西是 AMD BC-250，原本装在加密货币挖矿设备里的一块主板。挖矿需求冷下来之后，这些板子流入二手市场，而当人们发现里面那颗芯片是家用游戏主机所用APU的削减版本时，性价比很高这句评价就贴了上去。

从这句话里首先该拆出来的不是数字，而是钉在数字上的条件。60美元是什么东西的价格。在哪个市场、什么时候的价格。付完之后还得再买什么。给这三个问题补上答案，60美元就不再是总价，而是起步价。

而接下来才是正题。用途结束的硬件想要被重新使用时，真正卡住它的通常不是价格。是驱动、固件、接口规格、文档，以及必须由人一直抱着这些东西的时间。硬件便宜，不代表时间便宜。

缘起 - 60美元究竟是什么的价格

作为缘起的那篇文章，标题里的60美元是一块板子的价格。不含存储、不含电源、不含机箱。BC-250 出厂时 GDDR6 16GB 已经焊在板上，所以不用单独买内存，但其余全部另算。

还有两个条件跟在后面。一个是市场：那个价格被描述成在某个二手交易网站上运气好时才能碰到的数字。另一个是时点：同一篇文章把常见价格写成2025年11月时的70到100美元之间。也就是说，60美元在那篇文章写下来的时候就已经不是上限而是下限，而且是运气站在你这边时的下限。

板子的流通方式也会影响价格。社区文档写道，这种板子是从4U机架式挖矿机箱里拆出来后单块出售的。要有人拆解机箱才会有货，供给因此并不均匀，所以文档自己也加了一句提醒：价格和库存波动很大，务必仔细比较当前在售的条目。

这块板子是怎么流到市场上的

这类东西为什么会流到市场上，可以分三步来说。挖矿主板也好，服务器翻新机也好，机顶盒也好，路径的形状是一样的。

  • 为单一用途大批量生产 — BC-250 从一开始就没打算零售。它是为了插满一整个机架、只跑一种计算而造的板子。所以视频输出只有一个，存储插槽也只有一个。这不是缺陷，而是原本的用途用不上。
  • 那个用途的经济性消失 — 挖矿的收益结构一变，设备一夜之间就只剩残值。这时设备要么被报废，要么被拆解成零件散开。市场上货量涌出来的时点就在这里。
  • 残值只留在硬件上 — 芯片、内存、电路板都还能用。可是驱动、固件、文档、保修，要么只为原来的用途而做，要么根本就没做过。这种不对称造就了再利用的真实难度。

芯片本身的来历也是同样的结构。社区文档写道，BC-250 的APU是家用游戏主机所用APU的削减版本，八个CPU核心中有两个、以及十二个GPU计算单元被关闭。达不到旗舰产品等级的晶片被引流到另一种产品，这是半导体行业由来已久的做法，而挖矿主板正是这条水流的终点之一。

有一件事从一开始就定了。这颗芯片从来没有过面向普通消费者的软件谱系。在主机里由主机厂商的软件填满那个位置，在挖矿机架里则由挖矿软件填满。两条谱系都不是个人能继承的。今天的状态，是社区在填补那个空位。

硬件价格之外的那张账单

评估便宜硬件时，通常会漏掉两栏。一栏是必须一起买的配件，另一栏是时间。先把总成本的骨架搭出来，就能看清每一项落在哪一栏。

总成本 = 板子价格
       + 必须一起买的配件         (电源 · 散热 · 存储 · 机箱 · 转接器)
       + 电费 x 使用年数          (与开机率成正比地变大)
       + 装机与维护花掉的时间       (不印在收据上，也不会消失)
       - 用完之后还剩下的价值       (越是非标准的部件越接近 0)

第三行和第四行拉着本文的其余部分往前走。下面这张表把第四行，也就是用时间而不是用钱计算的项目，一条条展开。右栏写的是：在东西到手之前，看什么就能知道这一项存不存在。

最后一行是其余各行的总和。时间不印在收据上，所以总是从总成本的计算里掉出去。可是逐条通过上面十二行所花的时间是真实存在的，而且可能比板子本身还贵。买一台同等性能的成品，这十二行会整块消失，代价是价格上去。两个选项的差别不在性能，而在你愿意交出钱还是时间。

单价在降、账单却没变，这种现象不是硬件独有的。单价与总额在不同地方被决定的结构在任何领域都以同样的形状出现。贴着价签的那一项变便宜时，没贴价签的那一项原封不动。

供电 - 接口是标准的，装机流程却不是

供电是这块板子上最常卡住的地方。接口本身是显卡上用的 PCIe 8针，并不陌生。问题是板上没有启动ATX电源的信号电路。普通装机里由主板承担的角色，这块板子不承担。社区之所以做出并流传自己的转接板设计，原因就在这里。每个零件单看都是标准的，装机流程却不是标准的，这是这类东西的典型样貌。

电流方面的条件更具体。社区文档给出的是12V输出至少250W，要留余量则是300W以上。如果是长时间跑计算负载，建议ATX 400W以上或500W级的 FlexATX。文档还点名两款小型电源，说有报告称它们在游戏负载下会断电甚至损坏，因此不推荐。220W的负载要靠一个接口拉进来，本来就没有余地。

关于转接的警告不是口味问题，而是安全问题。SATA供电接口额定54W，市面上却有从那条路径造出 PCIe 8针的转接，文档把它点名为火灾风险。线径也要求16 AWG以上，明说18 AWG不够。超出额定使用的接口会安静地发热，然后一次性失效。

待机，加了调频工具65到85W装了能动态降低GPU频率的工具

这张表里最重要的是第一行。什么都不做时要吃掉85到105瓦。加上降频工具，也很少能到65瓦以下。这一行决定了后面用途判定的一半。因为决定一台常年开机设备性格的，不是有负载时吃多少，而是没负载时吃多少。

软件 - 没有驱动这句话的实际范围

没有驱动这句话，通常被读成有点不方便。这里不是那个意思。把范围分成四层来看是这样的。

  • 没有Windows下的GPU驱动 — 社区文档写道，这块板子确实能启动 Windows，但没有GPU驱动，而且今后大概率也不会有。它在没有图形加速的状态下启动，凡是要用到屏幕的工作基本都做不了。这不是选项变窄，而是整整一边被关上。
  • 就算在Linux下也要挑版本区间 — Mesa 要25.1.3以上，推荐25.1.5以上。内核则有特定区间因为GPU驱动故障被列为需要避开的对象。建议避开长期支持版的理由也一样。这是少见的、长期不变反而成为不合格项而非优点的情形。
  • 把固件直接写进板子成了前提 — 文档把某个特定版本的BIOS与显存分配设置列为推荐配置。那个固件不是厂商发布的，厂商那边也没有更新渠道。
  • 没有视频的硬件编码与解码 — 相关模块的固件归主机厂商所有，在这块板子上用不上。画面输出没问题，但把视频压缩与解压交给GPU的那条路被堵住了。

第四项直接抹掉一整个用途。想把便宜设备改成媒体服务器的人，最先期待的功能就是硬件转码，没有它就只能用CPU来跑。六核 Zen 2 并非做不到，但那一刻，选中这块板子的理由——便宜的GPU——就退出了计算。一个功能的缺席让硬件的长处失效，说的就是这个位置。

第二项的性质也值得记下来。普通硬件是时间越久支持越稳。这里却相反，内核每往上升一次，本来能用的东西就可能不能用。支持位于上游内核与图形栈里，而没有厂商负有追修回归问题的义务。于是更新既不能一直推迟，也不能随手就做。管理这个状态所消耗的，正是前面那张表的最后一行：时间。

性能 - 必须带上条件才读得懂的数字

性能数值一旦脱离条件被搬运，立刻就会失真。把公开的数值和条件一起摆出来是这样的。

项目数值测量条件出处性质
大型开放世界作品平均70到90帧1080p。中到高画质社区测量
动作类作品平均约100帧1080p。高画质社区测量
大作游戏一般情况平均60到100帧以上1080p。高画质社区测量
竞技类网络游戏平均100帧以上1080p。优化过的设置社区测量
性能档位的类比介于两款主流显卡之间只给了对比对象，没有测量条件社区描述

带上条件再读，画面就变了。数值全部以1080p为基准，画质设置在中到高之间。对应4K或最高画质的数值一个都没有。而且全部是平均帧。最低帧和帧时间分布都没有。决定游戏手感的是低于平均的那一段，缺了那个值，数字就只显示上限。

更大的变量是测量的主体。这些数值全部来自社区测量，而测试环境、散热状况、固件版本因人而异。如前所述，GPU频率会因为有没有调频工具而在1500MHz与2000MHz之间分开。散热不够时连那个都维持不住。同一块板子，配置不同就成了不同的东西。决定性能的不是硬件规格，而是配置的完成度，而这一点同样会以时间这一项回到账上。

功耗与寿命 - 按年份一除，顺序就翻转

便宜硬件的真实成本，多半出现在电费上。先把计算结构搭起来。

年用电量(kWh) = 功率(W) x 每天运行小时数(h) x 365 / 1000

  常年开机 · 待机 85W :  85 x 24 x 365 / 1000 = 744.6 kWh
  常年开机 · 待机 70W :  70 x 24 x 365 / 1000 = 613.2 kWh
  每天3小时 · 负载180W: 180 x  3 x 365 / 1000 = 197.1 kWh
  对照 · 低功耗设备15W:  15 x 24 x 365 / 1000 = 131.4 kWh

年电费 = 年用电量 x 每千瓦时单价
  单价因国家 · 合同类别 · 用电量档位而不同。
  下表的 0.6 元是按居民阶梯电价的大致水平设定的计算用假设值，
  不是任何电价表上的确定数字。各地与各档位都会上下浮动。
情景年用电量年电费(按假设单价)三年累计
常年开机。待机85W744.6 kWh约446.8元约1,340元
常年开机。调频后70W613.2 kWh约367.9元约1,104元

把几行并在一起读，结构就出来了。以常年开机为前提，三年的电费会升到与硬件价格同一个数量级。配件齐全后的总额是205到370美元，按1美元约7.2元折算大致是1,500元到2,700元；待机85瓦跑三年的电费约1,340元，已经踩到这个区间的下沿。仅与低功耗设备的差额，三年就拉开约1,100元。电价更高的地区，这个交叉点会来得更早，便宜的一方与贵的一方在那里换位。

反方向也在同一张表里。每天只用三小时，三年累计不到400元。这种情况下电费改变不了顺序。也就是说，这套硬件的总成本不是由性能或价格决定，而是由开机率决定。在比价之前先定下每天开多少小时，比较才成立。

寿命也进入同一道除法。二手流出的板子已经在挖矿环境里跑了很久。负载恒定意味着热循环少，这一点有利；总运行时长很长，这一点不利。哪一边影响更大因个体而异，而且没有保修，一坏就是全额损失。按三年做的计算如果一年就结束，上表里每一格都会差三倍。把购入价与运行费放在一起看的算法，和给家电估算总拥有成本时用的是同一套结构，只是这里多了一个剩余寿命的变量。

电子垃圾 - 天平为什么不会一边倒

再利用有明确的收益。国际电子垃圾报告统计，2022年一年产生了6,200万吨电子垃圾，比2010年增加了82个百分点，其中被正式回收并有记录地再资源化的比例只有22.3个百分点。同一份报告预计，到2030年产生量将达到8,200万吨，而有记录的再资源化率反而降到20个百分点。仅未被回收的金属价值就估算为910亿美元。

面对这些数字，把一块即将报废的板子多用几年，显然是好的一边。没有新造出来的那部分资源和制造排放就这样省了下来。尤其是这种已经被制造出来、也已经被丢弃过一次的东西，制造阶段的排放属于无法收回的沉没成本，延长使用的收益因此更大。

可是天平的另一边是使用阶段。旧制程出来的芯片，做同样的活要吃更多电。一台什么都不做也要85瓦的机器，常年开机三年会超过2,200千瓦时。这些电是怎么发出来的，会改变附着其上的排放量，而到了某个点，使用阶段就把制造上省下来的收益吃掉了。决定天平朝向的是三个变量。

  • 开机率 — 每天开几个小时。如前表所示，仅这一个变量就能让使用阶段的体量相差接近六倍。常年开机与间歇使用实际上是两件事。
  • 替代关系 — 这台设备替掉了什么。少买一台新设备，和多开一台本来闲置的设备，方向是相反的。混乱之所以产生，是因为两种情况都被叫作再利用。
  • 电源结构 — 同样一千瓦时，来自什么发电方式，排放并不相同。它随地区和时段变化，所以同一台设备跑同样时长，结论也可能不同。

所以这件事不会用再利用是对的、或者能效优先这样一句话收尾。三个变量里只要变一个，结论就翻过来。先定好结论、再挑对自己有利的变量，是这个主题上最常见的错误。两条理由经常互相抵消。

适合什么，不适合什么

把前面的项目代入具体用途，判定就分开了。判定的依据不是偏好，而是前面已经确立的数值。

用途判定理由
间歇使用的1080p游戏机适合公开的性能数值全部来自这个条件，而且开机率低，电费改变不了顺序
Linux与图形栈的练手机适合不动内核和Mesa就跑不起来，所以当学习本身就是目的时，障碍直接变成教材
离线独立作业的副机有条件仅限所需软件能在Linux上跑、且不依赖视频加速的情况
GPU计算练习有条件16GB共享内存很有吸引力，但要看哪些框架支持这个GPU标识、支持到什么程度
常年开机的低功耗家庭服务器不适合待机功耗很少能低于65瓦。在这个用途的核心指标上输了
媒体服务器与转码不适合没有硬件编码与解码。便宜GPU这个长处在这个用途里用不上
任何需要Windows的场景不适合没有GPU驱动，也看不到会有的迹象
带内核级保护机制的网络游戏不适合照单全收 Linux 游戏整体上的限制
无人值守的远程运行不适合只有一个视频输出，固件与内核又在社区维护之下，远程恢复很难
业务用的常驻设备不适合保修、支持、替代采购渠道全都没有。停一台就得再去找同样的东西

这份清单里值得注意的是，常年开机的家庭服务器落在不适合那一边。把便宜的二手硬件改成家庭服务器是很常见的选择，通常也很合理，可这件东西偏偏在那个条件下拿着最差的指标。反过来，在短时间高强度使用的用途里，同一个数值就不成问题。硬件的好坏，要先把用途定下来才说得出口。

需要做类似判断的场合还有别的。用家庭实验室搭开发环境时也好，挑推理用硬件时也好，真正拉开差距的不是规格表，而是带宽、支持生态和常驻成本。轴的名字换了，结构还是同一个。

结构相同的其他东西

BC-250 不是奇特的个案，而是一种常见类型里的一例。沿同一条路径流到市场上的东西一直都有。

  • 挖矿用显卡 — 有的型号根本没有视频输出，有输出的保修也早已结束。风扇和导热材料多半已经损耗，于是前面那张表上又多出一行整备费用。
  • 企业级服务器翻新机 — 每份性能的价格非常漂亮。代价是噪音与功耗都超过家用的容忍度，还要跟来导轨、机柜和特殊规格的电源。因为它本来就以常年运行为前提，电费那一项会显得特别大。
  • 机顶盒与瘦客户机 — 出货量巨大，价格几乎为零。锁死的引导程序和不再发布的固件成了那堵墙。这是硬件完好、软件那扇门却关着的典型。
  • 服务已终止的专用终端 — 零件都还在，服务器却没了。这种情况下障碍在设备之外而不是设备之内，所以第一步要判断的是它是不是技术能翻过去的墙。

这四种情况都能收进一句话。硬件的残值能留很久，但让那件硬件可用的软件、文档和支持，在用途结束的那一刻就一起结束了。再利用的难度不由零件的物理状态决定，而由这种不对称的大小决定。二手物品上外观与实际残值对不上的结构，和看二手车时先看记录的理由是一样的。机器看着完好，定价的却是履历和文件。

下次遇到类似价格时该看的五行

这类标题今后还会出现。那时只要套上五行，数字与实际之间的距离就会立刻显形。

要确认的为什么本例中
这个价格是什么的价格零件价与整机价是两个数字一块板子。其余全部另算
哪个市场、什么时候的价格二手行情随供给剧烈波动某个二手网站。2025年11月时常见价格更高
偏离标准规格几处每偏离一处，就跟来一份配件和一段时间机箱尺寸。开机电路。视频输出数量
软件由谁维护是厂商还是社区，决定它还能用多久社区文档与社区补丁
每天打算开几个小时开机率决定总成本的排序待机功耗高，对常年开机不利

五行里，最后两行在便宜硬件上尤其经常被漏掉。前三行在东西到手之前就看得见。后两行会在几个月后以电费单和内核更新的形式回来。便宜之所以让人愉快，是因为它只挂在前三行上。

这五行代替不了结论。对有些人来说，五行全部走完之后这件东西依然合适：用得短、本来就熟悉 Linux、并且享受折腾配置这件事本身。对另一些人来说，第一行就结束了。五行的用处在于让这个分岔在掏钱之前就显出来，而不是把人往某一边赶。

没能确认的部分

下面这些条目因为无法在一手资料里确定原文，所以没有写进正文。理由一并列出。

  • 缘起文章的正文 — 原文页面以访问限制作出响应，正文没能打开。60美元指的是裸板价格，以及2025年11月时常见价格为70到100美元这一时点信息，来自一篇二手的摘要文章。
  • 厂商官方规格 — 没能找到 BC-250 的官方产品页面或规格表所在。正文中的核心数、计算单元数、频率、设计功耗全部是社区文档的数值。这个缺失本身被用作第三节的论据。
  • 社区文档内部的数值不一致 — 功耗文档中有一行按40个计算单元写持续负载，而同一套文档的规格页写的是24个。没能找到判断哪一个属于这块板子的依据，所以正文表格里只搬了功耗数值，没有附上单元数。
  • 待机功耗的实际范围 — 加了调频工具之后的数值，在不同资料里分成50到65瓦与65到85瓦两种。无法判断测量条件是否相同，正文只写了更保守的那一档。
  • 电价单价 — 正文表格里每千瓦时0.6元是计算用的假设值。没能在一手资料里确定现行电价表的分档单价，因此只呈现数量级而非实际账单。居民电价普遍采用阶梯制，同样一千瓦时会因为落在哪一档而价格不同。
  • 二手个体的剩余寿命 — 没能找到关于挖矿环境总运行时长与故障率的公开统计。正文里寿命只作为计算结构处理，没有写出概率或期望寿命。
  • 再利用在环境上的盈亏平衡点 — 没能找到把制造阶段排放与使用阶段排放放在同一基准上比较、且针对这台设备的生命周期评估。因此第九节只写了让天平倾斜的变量，没有以数字给出平衡点。
