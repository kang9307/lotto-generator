1. 什么是劳动奖励金（근로장려금）？

1.1 制度目的 — 促进劳动 + 低收入现金援助

劳动奖励金（근로장려금 / EITC, Earned Income Tax Credit）是2009年引入的负（-）所得税概念福利制度。其宗旨是"在劳动获取收入的同时，对收入处于一定水平以下的家庭发放现金，以提升劳动意愿并弥补实际收入"。换言之，它并非单纯的现金福利，而是仅面向"从事劳动的低收入群体"发放的制度，因此完全无收入的无业者（完全没有劳动、事业、宗教人员收入的人）不是支付对象。与失业补助金不同，它不要求处于失业状态，并且可与基础生活保障对象同时领取。

以2026年（2025年归属部分）为准，最高支付额为330万韩元（双职工户），全国受益者约450万户，国税厅每年公布的劳动奖励金支付总额约达6万亿韩元左右。只要属于既非"收入恰好为0而无法领取"，也非"月收入过高而无法领取"的"从事劳动的低收入群体"区间的国民，均可申请。

1.2 与子女奖励金（자녀장려금）的区别 — 可同时领取

劳动奖励金（근로장려금）与子女奖励金（자녀장려금 / CTC, Child Tax Credit）是不同的制度。劳动奖励金基于户收入与财产，子女奖励金基于是否有扶养子女，条件符合时两者可同时领取。子女奖励金每名扶养子女最高100万韩元（2026年基准），按子女人数累计发放。例如，抚养2名子女的单职工户可领取劳动奖励金285万韩元 + 子女奖励金200万韩元 = 合计485万韩元的情况并不罕见。由于一次申请即可同时处理，无需单独提交两次。

2. 申请资格要件

2.1 收入要件 — 各户类型上限

各户的年总收入必须低于标准金额。此处的总收入并非单纯的月薪，而是工薪收入 + 事业收入 + 宗教人员收入 + 利息/分红 + 其他收入的合计金额。若有配偶，则以夫妻合算为基准。

  • 独立户（단독가구）：年总收入低于2,200万韩元（月均约183万韩元）
  • 单职工户（홑벌이가구）：年总收入低于3,200万韩元（月均约266万韩元）
  • 双职工户（맞벌이가구）：年总收入低于4,400万韩元（月均约366万韩元，夫妻合算）

尤其需要注意的是，工薪收入、事业收入、宗教人员收入中至少要有一项。仅有利息、分红而完全不劳动者不属于支付对象。此外，副业收入（如仅周末送外卖）也会被认定为事业收入，从而具备资格。

2.2 财产要件 — 1.7亿 / 2.4亿标准

以2026年为准，财产要件须低于2.4亿韩元才具备资格，其中1.7亿韩元以上~2.4亿韩元以下区间将按测算额的50%减额发放。

  • 低于1.7亿韩元：全额支付测算额 ✅
  • 1.7亿韩元以上~低于2.4亿韩元：仅支付测算额的50% ⚠️
  • 2.4亿韩元以上：不符合资格，不予支付 ❌

2.3 排除对象 — 以下人员无法申请

即便满足收入、财产要件，符合以下任一项者将被排除出支付对象。

  • 非韩国国籍者：但本人或配偶为韩国国籍者，或拥有韩国国籍扶养子女的情况例外（部分外国人配偶家庭可认定）
  • 常用职工月平均500万韩元以上：年薪基准约6,000万韩元以上的工薪劳动者，本人或配偶任一方符合此条件即全部淘汰
  • 律师、注册会计师、税务师、法务师、医师、药师、兽医等专业个体经营者：原则上排除专业职独立经营者
  • 租税条约缔约国非居民：长期滞留海外或无法证明国内居住事实者
  • 被他人扶养者：已作为其他家庭的扶养亲属登记者

2.4 各收入类型适用标准

劳动奖励金支付额测算基准的"总工资额等"根据收入类型权重不同。

  • 工薪收入：按总工资额原样反映
  • 事业收入：收入金额 × 各行业调整率（15~90%）适用。例如批发零售业仅将收入金额的20%认定为"总工资额等"
  • 宗教人员收入：按总支付额反映（扣除经费前）
  • 其他收入、利息、分红：不计入支付额测算收入，但计入资格判定用总收入

也就是说，拥有个体工商户登记的自营业者，即使实际营业额较高，通过行业调整率换算为劳动奖励金基准时，往往会被换算成相当低的收入，因此具备资格的情况比想象中多。

3. 户类型判定 — 最容易混淆的部分

3.1 独立 vs 单职工 vs 双职工

户类型由配偶、扶养子女、70岁以上直系尊亲的组合决定。由于此判定左右支付额，必须准确理解。

户类型 条件 最高支付额
独立户（단독가구）无配偶 + 无扶养子女 + 无同住70岁以上直系尊亲165万韩元
单职工户（홑벌이가구）有配偶（年总工资低于300万韩元）或有扶养子女，或同住70岁以上直系尊亲285万韩元
双职工户（맞벌이가구）有配偶 + 配偶年总工资300万韩元以上330万韩元

3.2 配偶收入300万韩元标准的重要性

最常被混淆的就是这个"300万韩元"。即使有配偶，若年工薪收入（总工资）低于300万韩元，则归类为"单职工户（홑벌이가구）"；若300万韩元以上则为"双职工户（맞벌이가구）"。300万韩元相当于月25万韩元水平，仅打零工或短期兼职的配偶会被归为单职工，上限下降至285万韩元。反之，若配偶为正式职员则成为双职工，上限提高至330万韩元，但夫妻合计总收入上限也扩展到4,400万韩元，反而更容易领取。

3.3 扶养子女、70岁以上直系尊亲条件

  • 扶养子女：2007-01-02 之后出生（18岁以下）+ 年收入100万韩元以下。即使户籍地址不同，也可通过实际扶养事实举证
  • 70岁以上直系尊亲：1955-01-01 以前出生的父母或祖父母 + 年收入100万韩元以下 + 户籍上同居或可证明直接扶养
  • 只要有扶养子女或直系尊亲，即使无配偶也可被认定为单职工户，上限可提升至285万韩元

4. 支付额测算原理 — 三段梯形公式

4.1 递增、平稳、递减的结构

劳动奖励金设计为梯形结构："工作越多领的钱越多（递增），一定区间领取最高额（平稳），收入再高就逐步减少（递减）"。这与"防止抑制劳动意愿"的制度目的相关 — 收入为0则支付为0（必须工作才能领取），一定水平内赚得越多领得越多，超过该水平逐渐减少，超过一定上限则无法领取。

区间①  递增区间：收入0韩元 → phaseInEnd
         → 支付额 = (收入 ÷ phaseInEnd) × 最高额（线性递增）

区间②  平稳区间：phaseInEnd → plateauEnd
         → 支付额 = 最高额（固定）

区间③  递减区间：plateauEnd → phaseOutEnd
         → 支付额 = 最高额 × (1 − (收入−plateauEnd) ÷ (phaseOutEnd−plateauEnd))

区间④  超过 phaseOutEnd：0韩元（不符合资格）

各户类型的区间界限值如下。

户类型 递增结束（phaseInEnd） 平稳结束（plateauEnd） 递减结束（phaseOutEnd） 最高额
独立户（단독가구）400万韩元900万韩元2,200万韩元165万韩元
单职工户（홑벌이가구）700万韩元1,400万韩元3,200万韩元285万韩元
双职工户（맞벌이가구）800万韩元1,700万韩元4,400万韩元330万韩元

4.2 独立户（단독가구）示例 — 总收入500万韩元 → 165万韩元（平稳区间）

  • 总收入500万韩元位于独立户递增结束（400万）~平稳结束（900万）之间 → 平稳区间
  • 支付额 = 最高额原值 = 165万韩元
  • 若财产低于1.7亿则原样领取，1.7亿~2.4亿则减至82.5万韩元

4.3 单职工户（홑벌이가구）示例 — 总收入2,500万韩元 → 约170万韩元（递减区间）

  • 总收入2,500万韩元位于单职工平稳结束（1,400万）~递减结束（3,200万）之间 → 递减区间
  • 递减比例 = 1 − (2,500 − 1,400) ÷ (3,200 − 1,400) = 1 − 0.611 = 0.389
  • 支付额 = 285万 × 0.389 ≈ 110.8万韩元（准确数值请用计算器确认）

4.4 双职工户（맞벌이가구）示例 — 总收入3,000万韩元 → 约330万韩元（平稳区间附近）

  • 总收入3,000万韩元位于双职工平稳结束（1,700万）~递减结束（4,400万）之间 → 递减区间
  • 递减比例 = 1 − (3,000 − 1,700) ÷ (4,400 − 1,700) = 1 − 0.481 = 0.519
  • 支付额 = 330万 × 0.519 ≈ 171.2万韩元
  • 双职工户须落入平稳区间（800~1,700万韩元）才能足额领取330万韩元

5. 财产判定标准

5.1 计入财产的项目

"户财产"合计本人、配偶、扶养子女、直系尊亲等户成员全体的财产。涵盖范围如下。

  • 住宅、建筑、土地：以公示价格为准。无论是否为自住用住宅，所有持有部分均计入
  • 全税保证金：作为承租人交付的保证金也计入财产（即使本人是租客亦然）
  • 存款、定期存款、股票、债券、基金：2025年6月1日基准余额
  • 汽车：以登记时价计。营业用除外，部分轻型车另行标准
  • 保险：按退保金基准估值
  • 会员权：高尔夫、公寓酒店、健身会员权基准时价
  • 虚拟资产：须根据最新征税体系确认纳入范围的演变

5.2 评估方法 — 公示价格 vs 市价

财产评估的关键在于"以什么价格评估什么"。大体上以公示价格与基准时价为主，估值通常低于市场价。

  • 住宅、土地 → 公示价格（国土交通部每年4月公告）。约为实际交易价的60~80%
  • 汽车 → 车辆价值表或登记税课税标准
  • 存款 → 余额（不含利息）
  • 全税保证金 → 租赁合同上的金额

5.3 财产基准日 — 2025年6月1日

2026年定期申请（2025年归属）的财产基准日为2025年6月1日。以该时点的财产状态判定资格，因此即便2025年7月以后出售了住宅，只要6月1日时点仍持有则依然计入财产。相反，若2025年5月已售出则从财产中排除。

5.4 1.7亿~2.4亿区间50%减额注意

若财产为1.7亿韩元以上，低于2.4亿韩元，按收入基准可领金额将恰好减半支付。例如，按收入基准有资格领取285万韩元的单职工户，若财产为1.9亿韩元，实际领取额为142.5万韩元。接近1.7亿界限的家庭，稍微降低财产评估即可变为全额支付，因此务必确认公示价格的最新状态。

6. 申请方法实操

6.1 Hometax（홈택스）申请6步骤

  1. 访问 Hometax（홈택스） → 使用共同认证、金融认证或简便认证登录
  2. 进入"申请/提交 → 劳动/子女奖励金申请"菜单
  3. 确认预填的通知对象信息（自动查询本人及户成员）
  4. 审核收入、财产自动汇总结果 → 需要补充、修改时点击"修改"
  5. 输入本人名义账户用于收款 → 点击申请按钮
  6. 确认受理编号，通过短信或通知信息接收受理完成通知

6.2 Sontax（손택스）移动应用

仅通过智能手机即可完成申请的Sontax（손택스）应用最为便捷。在应用商店搜索"손택스"并安装，通过简便认证可在2~3分钟内完成受理。通知对象只需点击Kakao Talk通知信息按钮即可直接跳转Sontax，几乎达到自动化水平。

6.3 ARS电话申请 — 1544-9944

为照顾老年人与数字弱势群体，运营国税厅ARS 1544-9944。拨打电话后仅需输入身份证号与通知上的个别认证号即可完成申请，无需任何附加资料。耗时1~2分钟，最为迅速。

6.4 书面申请 — 邮寄、到访

可填写通知书附带的申请表后邮寄至管辖税务署民愿室或到访提交。但处理时间较电子申请更长，请尽量使用Hometax、Sontax或ARS。

6.5 即便未收到通知也可申请的情况

即使被国税厅自动通知对象遗漏，也可自行申请。在Hometax选择"劳动/子女奖励金申请 — 非通知对象"，直接输入收入、财产、户成员信息即可。特别是以下情况通知书常未送达。

  • 因新入职或跳槽，上年度无工薪收入者
  • 搬家后国税厅资料尚未更新者
  • 个体工商户登记后首次申报的自营业者
  • 外国人配偶家庭资料关联延迟者

7. 申请期间完整整理

7.1 定期申请 — 2026年5月1日 ~ 6月1日

最标准的申请途径。以2025年归属收入、财产为准审核，预计支付日为2026年8月末。

  • 申请期间：2026-05-01 ~ 2026-06-01
  • 审核期间：6月~7月（约2个月）
  • 支付日：2026年8月末一次性汇入本人账户

7.2 期限后申请（기한후신청） — 6月2日 ~ 11月30日（10%减额）

若错过定期申请期间，可在6月2日至11月30日进行期限后申请（기한후신청）。但支付额将减少10%发放。原本应领165万韩元者变为148.5万韩元，330万韩元者变为297万韩元。支付日因申请时点有所差异，一般在申请后3~4个月内。

7.3 半期申请（반기신청 / 仅限工薪劳动者）

仅有工薪收入的家庭可选择年1次定期申请之外的按半期申请（반기신청）。可更早领取，并将支付额分两次领取。

  • 上半年部分（1~6月收入）：申请 2026-09-01 ~ 09-15 → 支付 2026年12月末（测算额的35%）
  • 下半年部分（7~12月收入）：申请 2027-03-01 ~ 03-15 → 支付 2027年6月末（剩余65%结算）
  • 结算完成时若与实际测算额存在差异，将追缴或追加支付

拥有事业收入或宗教人员收入的家庭无法使用半期申请，仅能选择定期申请。

8. 常见问题 Q&A

Q1. 能否与子女奖励金（자녀장려금）同时领取？

可以。劳动奖励金（근로장려금）与子女奖励金（자녀장려금）按各自标准单独测算后一同发放。若是扶养2名子女的单职工户，可领取劳动奖励金285万韩元 + 子女奖励金最高200万韩元（每人100万韩元）= 合计最高485万韩元。一次申请即审核两种奖励金，无需单独受理。

Q2. 无业者也能领取吗？

不能。劳动奖励金是为"从事劳动的低收入群体"设立的制度，归属年度内必须至少有工薪、事业、宗教人员收入中的一项。仅有利息、分红或仅领年金者不符合。即使是短期兼职收入100万韩元也可获得资格，因此哪怕有极少的工薪收入也请尝试申请。

Q3. 去年未领取的劳动奖励金，现在还能追溯吗？

可以。可通过5年内的更正请求进行追溯申请。例如2021年归属部分（2022年5月应申请部分）可在2027年5月前申请。但户构成与财产变动的举证可能较为复杂，请咨询国税咨询中心（☎126）或管辖税务署。

Q4. 外国人也能领取吗？

有条件地可以。限于本人或配偶为韩国国籍者，或拥有韩国国籍扶养子女的外国人方可申请。纯外国人夫妇组成的家庭因不符合国籍要件，非支付对象。

Q5. 收款账户有什么条件？

必须是申请人本人名义的账户。不能指定配偶、子女、亲属名义的账户。若无账户，可使用通知书附带的邮寄支付申请书以挂号邮件领取，但因有遗失风险并不推荐。

Q6. 财产中会包括父母的房子吗？

仅计入本人所有部分。若只是居住在父母名义的住宅中，该住宅不计入财产。但若父母作为70岁以上直系尊亲被纳入户成员，则父母的财产也会一并合算。共有名义的住宅仅按本人持有份额计入财产。

Q7. 申请后能否修改支付金额？

在申请期间内可自由修改。通过Hometax的"申请明细查询/修改"菜单可修正收入、财产、户成员信息。申请期间结束后则须经更正请求流程，因此期限内的最终确认十分重要。

9. 2026年主要变化

  • 最高支付额上调：独立户从原150万韩元上调至165万韩元（上调10%）。单职工260万→285万、双职工300万→330万，全户类型均有上调
  • 半期申请扩大：面向原工薪劳动者的半期申请流程简化，Sontax移动一站式化
  • 财产标准：1.7亿（全额基准）、2.4亿（淘汰基准）于2026年维持不变。受公示价格上涨影响，事实上有缓和效果
  • 强化电子支付：邮寄支付比例缩减，引导必须登记账户
  • 外国人凭证简化：出入境滞留资料自动关联，缩短外国人配偶家庭审核时间

  3. 通知书（Kakao Talk/邮寄）是否送达 — 从4月中旬开始发送，遗失可在Hometax查询
  4. 确认户类型 — 用计算器再次核实属于独立户/单职工户/双职工户
  5. 收入汇总 — 工薪、事业、宗教人员收入 + 利息、分红全部合算（夫妻合算）
  6. 整理财产清单 — 住宅、全税保证金、存款、车辆、保险均计入，确认1.7亿/2.4亿界限
  7. 扶养子女、直系尊亲要件 — 年收入100万韩元以下 + 同住情况核查
  8. 准备本人名义账户 — 解除休眠账户，提前在Hometax保存
  9. 确认子女奖励金同时申请 — 有扶养子女时核查是否自动包含
