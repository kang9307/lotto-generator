❓ 자주 묻는 질문

환율 계산기는 몇 개국 통화를 지원하나요? +
USD(달러), JPY(엔화), EUR(유로), CNY(위안), GBP(파운드), THB(바트), PHP(페소), IDR(루피아), TWD(대만달러), VND(동) 10개국 주요 통화를 지원합니다.
환율 정보는 얼마나 자주 업데이트되나요? +
페이지를 열 때마다 exchangerate-api.com의 실시간 환율을 가져옵니다. 실제 은행 환율과는 약간 차이가 있을 수 있습니다.
양방향 변환이 되나요? +
네, 해외 통화 → 원화, 원화 → 해외 통화 양방향 변환을 지원합니다. 통화 선택 후 ⇅ 버튼을 누르세요.
회원가입이 필요한가요? +
아니요. 회원가입이나 로그인 없이 즉시 사용 가능한 100% 무료 도구입니다.
오프라인에서도 사용할 수 있나요? +
한 번 환율을 가져온 후 캐시된 환율로 오프라인 계산이 가능합니다. 새 환율은 인터넷 연결 후 새로고침하세요.
