不会做饭也能做的生存料理

2026年1月25日生活/健康
⚠️ 健康信息提示 — 本文仅供一般信息参考，不能替代医学诊断或治疗。如有症状或需要判断，请咨询医务人员。

天天点外卖钱包遭不住...

刚开始独居的时候，因为不会做饭天天点外卖。一个月后看信用卡账单吓了一跳。所以被迫开始做饭，发现其实没那么难。

今天分享真的不会做饭的人也能做的超简单食谱。会烧开水就能做。

1. 三种鸡蛋料理

有鸡蛋就能做任何事。

煎蛋（5分钟）

材料：鸡蛋、油、盐

  1. 锅里放一点油
  2. 小火预热（1分钟）
  3. 打入鸡蛋
  4. 撒点盐
  5. 蛋白凝固就好（蛋黄看喜好）

技巧：火大边缘会焦。小火是关键！

炒蛋（5分钟）

材料：鸡蛋2个、一点牛奶、盐、黄油（没有用油）

  1. 鸡蛋+牛奶+盐搅匀
  2. 小火融化黄油
  3. 倒入蛋液用筷子不停搅
  4. 半熟时关火（余热会继续加热）

技巧：太熟会变干。还湿润的时候就关火。

蒸蛋 - 微波炉版（5分钟）

材料：鸡蛋2个、水或高汤100ml、盐

  1. 碗里打散鸡蛋+水+盐
  2. 盖保鲜膜，用牙签戳几个洞
  3. 微波炉2分30秒（700W）
  4. 不够再加30秒

2. 米饭料理

酱油蛋拌饭（5分钟）

材料：米饭、鸡蛋、酱油、香油、海苔碎

  1. 热米饭上打一个蛋
  2. 加1勺酱油、一点香油
  3. 拌匀
  4. 撒海苔碎完成

技巧：加点葱花更好吃。

金枪鱼沙拉饭（5分钟）

材料：米饭、金枪鱼罐头、蛋黄酱、酱油、海苔碎

  1. 沥干金枪鱼的油
  2. 金枪鱼+2勺蛋黄酱+一点酱油拌匀
  3. 铺在米饭上
  4. 撒海苔碎完成

炒饭（10分钟）

材料：米饭、鸡蛋、葱、酱油、油

  1. 锅里放油炒葱
  2. 打入鸡蛋炒散
  3. 加米饭一起炒
  4. 酱油调味

技巧：冰箱剩菜随便加都行。

3. 面条料理

方便面升级版（10分钟）

基础+加料

  • 鸡蛋：面熟了打入蛋液搅散
  • 芝士：关火放芝士片
  • 葱：切碎加入
  • 年糕：一开始就一起煮

辣拌面（10分钟）

材料：细面、辣酱、醋、糖、香油

  1. 煮面过冷水
  2. 2勺辣酱+1勺醋+1勺糖+香油调酱
  3. 和面拌匀
  4. 加个溏心蛋更好吃

4. 汤类

蛋花汤（10分钟）

材料：鸡蛋2个、水2杯、鸡精、盐、葱

  1. 水+鸡精烧开
  2. 开了慢慢倒入打散的蛋液
  3. 盐调味
  4. 加葱完成

泡菜汤 - 超简版（15分钟）

材料：泡菜1杯、五花肉少量（没有也行）、豆腐、水、辣椒粉

  1. 锅里放油炒泡菜
  2. 有肉一起炒
  3. 加2杯水烧开
  4. 加豆腐煮5分钟
  5. 加点辣椒粉更好吃

技巧：越酸的泡菜越好吃。

5. 配菜/小吃

厚蛋烧（10分钟）

材料：鸡蛋3个、盐、葱（可选）

  1. 鸡蛋+盐+葱搅匀
  2. 小火放油
  3. 倒1/3蛋液铺薄
  4. 半熟时卷起来
  5. 推到一边再倒蛋液
  6. 重复

煎吐司（5分钟）

材料：吐司、黄油、鸡蛋、芝士

  1. 锅里融化黄油
  2. 吐司两面煎
  3. 做个炒蛋铺上
  4. 放芝士完成

6. 购物必备

有这些就能做上面所有菜。

冷藏

  • 鸡蛋（必备！）
  • 葱
  • 泡菜
  • 豆腐
  • 金枪鱼罐头

冷冻

  • 冷冻米饭或速食米饭
  • 冷冻蔬菜

常温

  • 方便面
  • 细面
  • 酱油、香油
  • 辣酱
  • 鸡精
  • 海苔碎

7. 做饭技巧

  • 小火为主：大火是新手的敌人，容易焦
  • 最后调味：一开始太咸没法改
  • 鸡蛋万能：加个蛋什么都好吃
  • 立刻洗碗：做完饭马上洗不然粘住
  • 失败没关系：谁都这样，练着就好了

总结

做饭没那么难。想想外卖费，值得试试。从煎蛋开始吧！
