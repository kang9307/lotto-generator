昼間は家にいないのに荷物が...

会社勤めだと、昼間に荷物を直接受け取るのは難しいものです。配達完了の通知が来たのに不在だったり、管理人室のない建物で預け先に困ったりすることはよくあります。

一人暮らしの人が宅配や出前を安全に受け取る方法をまとめました。この記事は韓国の宅配・デリバリー事情が前提で、賠償基準や届け出の手順は公的な案内で確認できた内容だけを書いています。

1. 不在時の荷物の対処法

オプション1：管理人室での預かり

  • 管理人室がある建物ならデフォルトに設定
  • 配送メモに「管理人室に預けてください」と書く
  • 帰宅後に受け取る
  • 預かりの可否は建物ごとに異なるので、管理規約を先に確認

オプション2：宅配ボックス

  • マンション・オフィステルに宅配ボックスがあれば活用
  • 保管場所と暗証番号（または認証方法）はSMSやアプリで案内されるのが一般的
  • 時間を問わず受け取れる所が多いが、運用は建物ごとに異なる

オプション3：置き配

  • 配送メモに「玄関前に置いてください」と書く
  • 紛失リスクがあるので高価な品物は避ける
  • 配達完了の写真をお願いする
  • 標準約款の改正案内によると、顧客と合意した場所に置けば引き渡しが済んだものとみなされます。置き配に合意して荷物が消えた場合は責任を切り分けにくくなるので、写真を必ず確認しましょう

オプション4：コンビニ受け取り

  • 一部の配送業者・販売店はコンビニ受け取りに対応
  • 注文時にコンビニ受け取りを選ぶ
  • 営業時間内に受け取る

管理人室や宅配ボックスのように、人がいなくても安全に預けられる場所を決めておくほうが安心です。置き配は紛失のリスクがあります。

2. 配送メモの活用

効果的な配送メモ

  • 「管理人室に預けてください。部屋番号：000号」
  • 「不在時は玄関前に置き、配達完了の写真をお願いします」
  • 「宅配ボックスをご利用ください」
  • 「配達前にご連絡ください」

注意事項

  • 住所欄に「一人暮らし」と書かない（防犯）
  • 名前はフルネームより苗字＋○○で（例：金○○）
  • 送り状には名前・住所・電話番号がまとめて印字されるので、配送メモに余計な個人情報を足さない

3. デリバリー食のコツ

一人分の出前

  • 最低注文金額と配送料：アプリ・店・時間帯で異なり、一人分だと代金に占める配送料の割合が大きくなることがある
  • 量の調整：次の食事で確実に食べ切れる量のときだけ多めに頼む（残すと無駄）
  • 割引：初回割引やクーポンは条件を確認して使う

食べ物の保管

  • すぐ食べないなら冷蔵庫へ
  • 麺類は伸びるので早めに食べる
  • 翌日食べるなら中まで十分に温め直す

デリバリーアプリの活用

  • 複数のアプリを比較する際は配送料と最低注文金額も含めて見る
  • テイクアウト割引があれば自分で取りに行くことも検討
  • レビューは写真付きを中心に見るが、宣伝目的のレビューもあり得ると心得る

4. 長期不在のとき

旅行・出張のとき

  • 届く予定の荷物があれば配送日の調整を依頼
  • 定期便を一時停止
  • 大事な荷物は家族・知人に頼む

5. 安全に荷物を受け取る

一人暮らしと悟られない

  • 名前に「様」を付ける、または性別があいまいに見えるようにする
  • 配達員が来たら「家族が受け取ります」という雰囲気を出す
  • 夜間の配達は避ける

非対面での受け取り

  • 置き配を選ぶ（直接会わない）
  • インターホン越しにだけ話す
  • すぐにドアを開けず、配達員が去ってから受け取る

安全が最優先です。特に夜は本当に配達員かどうか必ず確認してください。

6. 荷物が紛失・破損したとき

以下の賠償基準は、韓国の公正取引委員会が定める宅配便標準約款と、それを解説した政府の案内（やさしい生活法令情報）に基づきます。実際の賠償は配送業者の約款や事故の状況によって変わることがあります。

状況基準知っておくこと
送り状に品物の価額を書かなかった賠償限度額は50万ウォン高額品は価額を記載して割増料金を払う方法がある
価額を記載し割増料金を払った運送価額区間ごとの最高価額まで2020年の改正案内では最高300万ウォンまで拡大すると紹介された（区間ごとの金額表は未確認）
輸送中に全部紛失運賃の返還＋送り状記載価額に基づく損害額業者や従業員の故意・重過失なら限度なしで賠償
一部の紛失・破損受け取り日から14日以内に業者へ通知通知が遅れると責任が消滅することがある。請求権は受け取りから1年で消滅
賠償の時期損害立証書類の提出日から30日以内に優先賠償業者・代理店・配達員の間の責任のなすり合いによる遅れを防ぐ規定

紛失したかもしれないときの手順

  1. 配達完了のメッセージ・写真・置き場所のメモを画面キャプチャで残す
  2. すぐに配送業者へ連絡する。通知が遅れると原因と責任を判断しにくくなり、賠償を断られることがある
  3. 電話だけで済ませず、受付番号と回答をメッセージ・アプリ・内容証明郵便などの記録に残す
  4. 業者が紛失を認めたのに賠償しない場合は、1372消費者相談センター（市外局番なし1372）に相談
  5. その後、韓国消費者院の被害救済手続きを利用し、それでも解決しなければ支払督促（督促手続）を検討

7. 宅配を装った詐欺メッセージと送り状の情報

宅配業者を装うスミッシング

  • 「住所不一致で配達できません。住所を修正してください」のようなメッセージのURLや電話番号は押さず削除
  • 荷物の追跡は宅配業者のアプリや注文したショップで自分から行う
  • 本人確認・身分証・金融情報をメッセージのリンクから入力しない
  • すでに押してしまった、またはアプリが入った疑いがあるときは、韓国インターネット振興院（KISA）の118（市外局番なし・無料）に相談。ハッキング・ウイルスの緊急相談は365日24時間、一般相談は平日09:00～18:00

送り状の個人情報を消す

  • シールタイプの送り状は剥がして捨てる
  • 剥がしにくいときは油性ペンなどで名前・住所・電話番号を塗りつぶす
  • バーコードにも情報が入っているので、バーコードも一緒に消す
  • 玄関前に長く置いた荷物は情報露出や盗難のリスクが高まるため、安全な宅配ボックスの利用が勧められている

8. ショッピングのコツ

オンラインショッピング

  • 送料無料：送料無料の金額に合わせるために不要な物を買わない
  • 定期便：条件によって単価が変わるので自分で比較する
  • レビュー確認：実購入レビューを確認する

早朝配送の活用

  • 生鮮食品は早朝配送が便利
  • 出勤前に玄関前で受け取る
  • 夏は冷凍食品に注意（溶けることがある）

9. チェックリスト

荷物を注文するとき

  • ☐ 配送メモを丁寧に書く
  • ☐ 不在時の代替先を設定（管理人室・宅配ボックス・玄関前など）
  • ☐ 連絡先を正確に
  • ☐ 高額品は送り状の価額記載を確認

デリバリー食のとき

  • ☐ 複数アプリの価格（配送料込み）を比較
  • ☐ クーポン・割引の条件を確認
  • ☐ レビューを確認

受け取ったあと

  • ☐ 送り状の個人情報を消してから捨てる
  • ☐ 宅配を装ったメッセージのリンクは押さない

まとめ

一人暮らしでは宅配とデリバリーが生活の大きな部分を占めます。うまく受け取れば便利ですが、管理しないと紛失や個人情報の露出につながります。ポイントは配送メモと、紛失時に記録を残してすぐ連絡することです。

次回は安全な一人暮らしを取り上げます。

# 宅配・デリバリーを安全に受け取る点検表

基準日：2026-09-29。韓国の基準です。賠償は配送業者の約款や事故の状況によって変わることがあります。

## 1. 不在時の受け取り方を選ぶ

| 状況 | 方法 | 備考 |
|---|---|---|
| 管理人室がある | 管理人室で預かり | 可否は建物ごとに異なる |
| 宅配ボックスがある | 宅配ボックス | 場所と暗証番号はSMSやアプリで案内 |
| どちらもない | 置き配＋配達完了写真 | 高額品は避ける。合意した場所に置けば引き渡し完了とみなされる |
| 長期不在 | 配送日の調整、定期便の一時停止、家族・知人に代理受け取り | |

## 2. 注文するとき
- [ ] 配送メモに受け取り場所を具体的に書いた
- [ ] 住所に「一人暮らし」と書かず、名前は苗字＋○○にした
- [ ] 高額品は送り状の価額記載を確認した（未記載なら賠償限度50万ウォン）
- [ ] 夜間の配達は避けた

## 3. 紛失・破損したときの手順
1. 配達完了のメッセージ・写真・置き場所のメモをキャプチャする
2. すぐ配送業者に連絡する（一部の紛失・破損は受け取り日から14日以内に通知）
3. 受付番号と回答をメッセージ・アプリ・内容証明郵便で残す
4. 業者が認めても賠償しないときは1372消費者相談センターに相談する
5. 韓国消費者院の被害救済手続きを利用し、解決しなければ支払督促を検討する

基準：損害立証書類の提出日から30日以内に優先賠償、請求権は受け取りから1年。

## 4. 受け取ったあと
- [ ] 送り状（名前・住所・電話番号・バーコード）を剥がすか消してから捨てた
- [ ] 「住所不一致」のようなメッセージのリンクを押していない
- [ ] 押した、またはアプリが入った疑いがあれば118（韓国インターネット振興院）に相談する

次の更新条件：標準約款の改正、1372・紛争解決基準の変更、118の運営時間の変更。2020年改正後の追加改正の有無と割増料金の区間表は確認できていません。
