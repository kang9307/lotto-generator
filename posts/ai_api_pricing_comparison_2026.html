서론: 가격이 곧 아키텍처다

2026년의 AI 개발에서 모델 선택은 더 이상 "어느 게 제일 똑똑한가"만의 문제가 아니다. 같은 기능을 만들더라도 어떤 API를 쓰느냐에 따라 월 청구서가 10배 넘게 갈린다. 특히 B2B 제품이나 스타트업처럼 호출량이 큰 워크로드에서는, 백만 토큰당 단가(per 1M tokens)가 곧 단위 경제성을 결정하고, 단위 경제성이 곧 사업의 생존을 결정한다.

아래에서는 2026년 9월 29일 각 사 공식 가격 페이지 기준의 주요 LLM API 가격을 input/output로 나눠 한 표에 모으고, 컨텍스트 윈도·멀티모달·캐싱 할인이라는 다른 축까지 함께 본다. 그다음 "최고 성능 vs 가성비 vs 오픈"이라는 세 갈래로 용도별 후보를 추리고, 캐싱과 라우팅으로 비용을 깎는 실전 팁을 정리한다.

가격 변동 면책(중요): 아래 모든 수치는 2026년 9월 29일 기준 각 사 공식 가격 페이지의 값이다. LLM API 단가는 분기·월 단위로 자주 바뀌고, 프로모션·지역·등급에 따라 다르며, 캐시·배치 할인 구조도 모델마다 다르다. 표 안에는 종료일이 명시된 한시 단가(GPT-5.6 Sol은 최소 2026년 11월 21일까지, Gemini 3.8·3.7 Flash는 2026년 12월 31일까지)와 시간대에 따라 두 배로 뛰는 단가(DeepSeek)가 섞여 있어, 같은 행이라도 언제 호출하느냐에 따라 청구액이 달라진다. 실제 도입·견적 전에는 반드시 각 제공사의 공식 가격 페이지에서 최신 단가를 다시 확인해야 한다. 여기 적은 단가는 의사결정의 출발점이지, 계약 단가의 근거가 아니다.

2. 가격 외 비교축 - 컨텍스트·멀티모달·캐싱

단가만 보면 그림이 반쪽이다. 실제 비용과 적합성은 다음 세 축에서 갈린다.

2.1 컨텍스트 윈도와 "긴 컨텍스트 프리미엄"

컨텍스트 윈도는 한 요청에 넣을 수 있는 입력 분량이다. 주의할 점은 긴 컨텍스트 프리미엄이다. OpenAI는 GPT-6 세 모델과 GPT-5.6·GPT-5.5 모두 입력 272K를 넘기면 입력·캐시가 2배, 출력이 1.5배가 되는 구조다(GPT-6 Sol 기준 $4.00/$15.00). Gemini 3.1 Pro는 200K를 넘으면 $4.00/$18.00으로, Grok 4.7은 200K 이상에서 $4.00/$12.00으로 오른다. 반면 Anthropic은 Claude 4.6 이후 모델에 대해 100만 토큰 전체를 표준 단가로 받는다고 가격 문서에 적고 있다. 긴 문서를 통째로 넣는 워크로드라면 이 프리미엄 구조가 실효 단가를 좌우한다 - 표의 앞 두 열만 보고 견적을 잡으면 실제 청구서와 두 배 가까이 어긋날 수 있다.

2.2 멀티모달 지원

텍스트만 다룬다면 무관하지만, 이미지·오디오·문서를 다룬다면 멀티모달 지원이 선택지를 좁힌다. Gemini 2.5 Flash는 텍스트·이미지·영상 입력을 $0.30에, 오디오 입력을 $1.00에 받아 멀티모달 가성비가 좋다. GPT-6 세 모델과 GPT-5 mini도 텍스트와 이미지 입력을 받는다. 이미지 토큰은 별도로 계산되며, 고해상도 입력은 토큰 소비가 크게 늘 수 있으므로 멀티모달 워크로드는 텍스트 단가만으로 비용을 추정하면 안 된다.

2.3 캐싱 할인과 속도

같은 프리픽스(시스템 프롬프트, 긴 참조 문서, 도구 정의)를 반복 전송하는 워크로드에서는 프롬프트 캐싱이 비용을 크게 줄인다. 다만 할인 폭과 규칙은 벤더마다 다르다. Anthropic은 캐시 적중을 기본 입력의 0.1배로 받되 Opus 5.5는 0.05배, Fable 5.1은 0.025배이고, 캐시 기록에는 5분 1.25배·1시간 2배가 붙는다. OpenAI는 캐시된 입력을 정가의 10%로, 캐시 기록을 1.25배로 받는다(GPT-6 기준). Google은 Gemini 3.8 Flash의 캐시 입력이 $0.075로 정가의 10%이지만 100만 토큰당 시간당 $0.50의 보관료가 따로 붙는다. xAI Grok 4.7은 캐시 입력이 정가의 25%, DeepSeek V4.1 Flash는 약 2%, GLM-5.3은 약 19%다. 배치 처리는 Anthropic·OpenAI·Google 모두 표준가의 50%다. 또한 저지연이 중요한 실시간 UX에서는 Haiku 4.5·Gemini 2.5 Flash·GPT-5 mini 같은 소형·빠른 모델이 유리하다. 속도와 단가는 대체로 같은 방향으로 움직인다 - 작고 싼 모델이 대체로 빠르다.

3. 용도별 추천 - 최고 성능 vs 가성비 vs 오픈

정답은 단일 모델이 아니라 워크로드별 배치다. 세 갈래로 정리한다.

3.1 최고 성능 - 복잡 추론·고위험 코드

정확성이 곧 신뢰이고 실수 비용이 큰 영역 - 프로덕션 마이그레이션, 보안 민감 코드, 장기 자율 에이전트 - 에서는 플래그십이 안전하다. Anthropic은 대부분의 작업을 Claude Opus 5.5(input $4.00·output $20.00)에서 시작하고, 요구가 큰 추론과 장기 에이전트 작업에는 Claude Fable 5.1(input $10.00·output $50.00)을 쓰라고 안내한다. OpenAI는 GPT-6 Astra(input $10.00·output $50.00)를 가장 어려운 작업용 최상위 모델로 설명하고, 이전 세대의 GPT-5.6 Sol은 프로모션 단가 $4.00·$20.00이다. 더 비싼 축으로 보안 연구용 GPT-5.6 Cyber(input $12.50·output $75.00)가 있다. output 단가가 높으므로, 긴 출력이 잦은 에이전트 워크로드에서는 토큰 폭주를 막는 상한 설계가 중요하다. Claude Sonnet 5.5와 GPT-6 Sol은 둘 다 input $2.00·output $10.00으로 상위권 중 단가가 낮은 축이라, 비용 민감하면서도 높은 성능이 필요한 경우의 균형점이다.

3.2 가성비 - 대량 호출·실시간 응답

분류·요약·추출·정형 응답처럼 난도가 낮고 호출량이 큰 작업은 소형·저가 모델이 정답이다. 메이저 폐쇄형 가운데서는 GPT-6 Luna(input $0.10·output $0.50)가 표 안에서 가장 낮은 축이고, GPT-5.6 Luna(input $0.20·output $1.20), Gemini 3.5 Flash-Lite(input $0.30·output $2.50), Gemini 3.8 Flash(input $0.75·output $3.75)가 뒤를 잇는다 - 다만 3.8 Flash의 단가는 2026년 12월 31일까지만 적용되고 이듬해부터 두 배가 된다. 이전 세대인 Gemini 2.5 Flash(input $0.30·output $2.50)와 GPT-5 mini(input $0.25·output $2.00)도 여전히 가격표에 있다. Claude Haiku 4.5(input $1.00·output $5.00)는 저지연이 필요한 실시간 UX에 좋지만, Anthropic이 후속 Haiku 5.5를 「수 주 안에」 내놓겠다고 예고했고 Haiku 4.5의 은퇴는 2026년 10월 15일보다 이르지 않다고만 공지돼 있다. Grok 계열은 4.3이 input $1.25·output $2.50, 4.7이 input $2.00·output $6.00이다.

3.3 오픈웨이트 - 최저가·데이터 통제

비용 바닥을 노리거나 데이터를 외부로 보내기 곤란하다면 오픈웨이트 계열이 매력적이다. DeepSeek V4.1 Flash는 호스티드 API 기준 비피크 input $0.15·output $0.60로 최저가권이지만, 피크 시간대에는 $0.30·$1.20으로 두 배가 되므로 「가장 싼 모델」이라는 말이 하루 종일 참인 것은 아니다. 옛 모델명 deepseek-v4-flash로 보낸 요청도 V4.1 Flash가 처리하고 같은 단가로 청구된다. GLM 계열은 5.3과 5.1이 모두 input $1.40·output $4.40이고, 소형 GLM-5.3-Flash는 $0.15·$0.50이다. Kimi K2.7 Code는 input $0.95·output $4.00에 컨텍스트 262,144, 상위 Kimi K3는 $3.00·$15.00에 컨텍스트 1,048,576이다. 다만 오픈웨이트의 진짜 이점인 자체 호스팅은 GPU 자본·운영 부담을 동반하므로, 호스티드 단가가 싸다는 것과 자체 운영이 싸다는 것은 별개의 손익분기 계산이다.

4. 비용 절감 실전 팁

같은 모델을 쓰더라도 설계로 비용을 크게 줄일 수 있다.

4.1 프롬프트 캐싱을 설계 단계에서 끼워라

시스템 프롬프트·도구 정의·긴 참조 문서처럼 변하지 않는 프리픽스를 앞에, 매 요청 바뀌는 질문을 뒤에 두면 캐시 적중률이 올라간다. 캐싱은 프리픽스 매칭이라, 앞쪽에 타임스탬프나 UUID 하나만 섞여도 캐시가 깨진다. 챗봇·RAG·에이전트처럼 고정 컨텍스트가 반복되는 패턴에서는 캐싱만으로 input 비용을 크게 줄일 수 있다. 캐시 기록에 할증이 붙는 벤더(Anthropic·OpenAI)나 보관료가 붙는 벤더(Google)에서는 한 번 쓰고 버리는 캐시가 오히려 손해일 수 있다.

4.2 모델 라우팅 - 쉬운 건 싸게, 어려운 건 비싸게

모든 요청을 플래그십에 보내는 것은 가장 흔한 낭비다. 난도 분류기를 두고, 쉬운 작업은 GPT-6 Luna·Gemini 3.5 Flash-Lite·Haiku 4.5 같은 소형 모델로, 복잡 추론·고위험만 플래그십으로 보내면 평균 단가가 급감한다. 공급자 비종속 게이트웨이로 추상화하면, 가격이 바뀌었을 때 모델 교체가 재작성이 아니라 설정 변경이 된다.

4.3 output를 줄이고, 배치를 활용하라

output 단가가 input보다 3~6배 비싸므로, 불필요하게 장황한 출력을 줄이는 것만으로 비용이 준다. 정형 출력(JSON 스키마)으로 군더더기를 없애고, 추론 토큰이 과한 모델은 노력 수준을 낮춰 보이지 않는 output을 통제한다. 지연에 둔감한 대량 작업은 배치 API(Anthropic·OpenAI·Google 모두 50% 할인)로 처리하면 단가가 절반이 된다.

5. 결론 - 단가표가 아니라 실효 비용으로 판단하라

2026년의 LLM 시장은 플래그십이 위에서 성능을 다투고, 소형·오픈모델이 아래에서 단가를 무너뜨리는 양극 구조다. 9월 말의 세대 교체도 같은 방향이다 — Claude Opus 5.5는 Opus 5보다 싸게, GPT-6 Luna는 GPT-5.6 Luna의 절반 단가로 나왔다. 핵심은 단일 단가표를 외우는 게 아니라, 자기 워크로드의 input:output 비율과 캐시 적중률을 곱한 실효 비용으로 비교하는 것이다. 같은 "백만 토큰 5달러"라도, 캐싱이 잘 먹는 RAG와 추론 토큰이 폭주하는 에이전트의 실제 청구서는 전혀 다르다.

이번 주에 할 구체적 수 세 가지: 첫째, 대표 트래픽 100건의 실제 input·output 토큰을 측정해 모델별 실효 단가를 계산하라. 둘째, 고정 프리픽스에 캐싱을 적용하고 적중률을 확인하라. 셋째, 쉬운 작업을 소형 모델로 라우팅하는 게이트웨이를 두고 플래그십 비중을 줄여라. 그리고 무엇보다, 이 페이지의 모든 단가는 2026년 9월 29일 기준이며 프로모션·시점에 따라 달라지므로, 견적 전 공식 가격 페이지를 반드시 다시 확인하라.

# LLM API 비용 견적 점검표 — 단가표를 청구서로 바꾸기 전에

기준일: 2026-09-29

> 출처: braindetox.kr — 2026 AI API 가격 비교
> 단가는 각 사 공식 가격 페이지 기준(USD, 백만 토큰당)이며 자주 바뀝니다. 견적 전 공식 페이지를 다시 여세요.

## 1. 모델 후보를 고르기 전에

- [ ] 대표 요청 100건의 실제 input·output 토큰을 쟀다
- [ ] input:output 비율을 계산했다 (요약·추출은 input, 코드·에이전트는 output 쪽이 크다)
- [ ] 입력 길이의 최댓값을 확인했다 — 아래 2번의 경계를 넘는지 본다
- [ ] 같은 프리픽스가 반복되는지 확인했다 (캐시 후보)
- [ ] 즉시 응답이 필요 없는 작업을 따로 분리했다 (배치 후보)

## 2. 긴 컨텍스트 경계 — 넘으면 단가가 바뀐다

| 벤더 | 경계 | 넘으면 |
|---|---|---|
| OpenAI (GPT-6 · GPT-5.6 · GPT-5.5) | 입력 272K 초과 | 요청 전체가 입력·캐시 2배, 출력 1.5배 |
| Google (Gemini 3.1 Pro · 2.5 Pro) | 프롬프트 200K 초과 | 구간 단가 적용 (3.1 Pro $4.00/$18.00) |
| xAI (Grok 4.7 · 4.3) | 프롬프트 200K 이상 | 요청의 모든 토큰에 긴 컨텍스트 단가 |
| Anthropic (Claude 4.6 이후) | 없음 | 100만 토큰 전체가 표준 단가 |

## 3. 캐시 규칙 — 벤더마다 다르다

| 벤더 | 캐시 적중(읽기) | 캐시 기록·보관 |
|---|---|---|
| Anthropic | 기본 입력의 0.1배 (Opus 5.5 0.05배, Fable 5.1 0.025배) | 5분 1.25배 · 1시간 2배 |
| OpenAI | 정가의 10% | 기록 1.25배 (GPT-6 기준) |
| Google | Gemini 3.8 Flash $0.075 (정가의 10%) | 100만 토큰당 시간당 $0.50 보관료 |
| xAI | Grok 4.7 정가의 25% | — |
| DeepSeek | V4.1 Flash 약 2% ($0.003) | — |
| Z.ai | GLM-5.3 약 19% ($0.26) | 보관료 「한시 무료」 |

- [ ] 캐시 기록 할증이 있는 벤더에서, 한 번만 쓰는 캐시를 만들고 있지 않은가
- [ ] 프리픽스 앞쪽에 타임스탬프·UUID가 섞여 캐시가 깨지고 있지 않은가

## 4. 한시 단가와 시간대 단가

- [ ] GPT-5.6 Sol $4.00/$20.00 — 최소 2026-11-21까지의 프로모션. 이후 단가로도 예산을 잡아 두었다
- [ ] Gemini 3.8·3.7 Flash $0.75/$3.75 — 2026-12-31까지. 2027-01-01부터 $1.50/$7.50
- [ ] DeepSeek — 피크(UTC 월~금 01:00-04:00, 06:00-10:00)에는 두 배. 실시간 서비스는 피크 단가로 계산했다
- [ ] 예고만 있는 모델(Claude Haiku 5.5)은 예산에 넣지 않았다

## 5. 배치와 라우팅

- [ ] 배치 가능한 작업을 50% 할인 경로(Anthropic·OpenAI·Google 배치, OpenAI·Google Flex)로 보냈다
- [ ] 쉬운 작업을 소형 모델(GPT-6 Luna $0.10/$0.50, Gemini 3.5 Flash-Lite $0.30/$2.50, Haiku 4.5 $1.00/$5.00 등)로 보내는 규칙을 두었다
- [ ] 모델 교체가 설정 변경으로 끝나도록 게이트웨이로 추상화했다

## 6. 실효 단가 계산식

```
월 비용 = (월 input 토큰 × (1 − 캐시 적중률) × input 단가
         + 월 input 토큰 × 캐시 적중률 × 캐시 단가
         + 월 output 토큰 × output 단가) × (1 + 재시도율)
```

- 긴 컨텍스트 경계를 넘는 요청은 그 요청 전체를 긴 컨텍스트 단가로 다시 계산한다
- 배치로 보내는 몫은 해당 벤더의 배치 단가로 따로 계산한다

## 7. 다시 계산해야 하는 시점

- 벤더가 새 모델이나 새 티어를 냈을 때 (예고된 Claude Haiku 5.5 등)
- 한시 단가의 기한이 지났을 때 (2026-11-21, 2026-12-31)
- 쓰던 모델의 은퇴 예정일이 공지됐을 때 (Claude Haiku 4.5는 2026-10-15보다 이르지 않음)
- 가격표에서 모델이 빠지거나 이름이 바뀌었을 때 (DeepSeek V4 Flash → V4.1 Flash처럼)
