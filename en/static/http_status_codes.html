How are HTTP status codes structured?

Every HTTP response starts with a 3-digit status code. The first digit indicates the category: 1xx (Informational), 2xx (Success), 3xx (Redirection), 4xx (Client Error), 5xx (Server Error). The standard is defined in RFC 9110, and additional codes are registered with IANA.

What is the difference between 401 and 403?

401 Unauthorized means "not authenticated" - login is required or the token is missing/expired. 403 Forbidden means "authenticated but no permission" - the logged-in user is not allowed to access this resource.

301 vs 302 - which one should I use?

301 Moved Permanently is a permanent redirect; search engines update their index to the new URL. 302 Found is a temporary redirect; engines keep the old URL. If you need to preserve the HTTP method and body, use 307/308 instead.

502 vs 504 - what is the difference?

Both are gateway/proxy errors. 502 Bad Gateway means the proxy received an invalid response from the upstream server. 504 Gateway Timeout means the upstream did not respond in time. Both are common with Nginx reverse proxies.

When should I return 422 Unprocessable Content?

When the request syntax (JSON) is correct but semantic validation fails. Examples: invalid email format, password too short. 400 Bad Request is for syntax errors, while 422 is for semantic errors.

What is 418 I'm a teapot?

An April Fools' joke code from RFC 2324 (Hyper Text Coffee Pot Control Protocol, 1998). It is not a standard HTTP code, though some libraries and frameworks still support it. It is generally not used in production.
