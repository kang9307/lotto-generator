📋 年末調整の基本概念：所得控除（소득공제） vs 税額控除（세액공제）

年末調整を正しく理解するには、所得控除（소득공제）と税額控除（세액공제）の違いを明確に知る必要があります。

所得控除（소득공제 / Income Deduction）

┌──────────────────────────────────────────┐
│         所得控除の計算構造                │
├──────────────────────────────────────────┤
│  総給与額                                │
│  - 勤労所得控除                          │
│  = 勤労所得金額                          │
│  - 所得控除（人的・年金・保険・カード等）│
│  = 課税標準                              │
│  × 税率（6～45%）                       │
│  = 算出税額                              │
└──────────────────────────────────────────┘

ポイント：所得控除は税金を計算する基準となる課税標準を引き下げます。税率が高いほど節税効果が大きくなります。

税額控除（세액공제 / Tax Credit）

┌──────────────────────────────────────────┐
│         税額控除の計算構造                │
├──────────────────────────────────────────┤
│  算出税額                                │
│  - 税額控除（子女・年金口座・医療費等）  │
│  = 決定税額                              │
│  - 既納付税額（源泉徴収）                │
│  = 差引徴収税額（還付または追加納付）    │
└──────────────────────────────────────────┘

ポイント：税額控除は計算された税金から直接差し引かれます。所得水準に関係なく同一の節税効果が得られます。

例：100万ウォンの節税効果比較

区分 総給与4,000万ウォン（税率15%） 総給与8,000万ウォン（税率24%）
所得控除100万ウォン 15万ウォン節税 24万ウォン節税
税額控除100万ウォン 100万ウォン節税 100万ウォン節税

# クレジットカード最適活用シミュレーター
def calculate_card_deduction(annual_salary, credit_usage, debit_usage, traditional_market, public_transport):
    """
    年末調整 クレジットカード所得控除計算機

    Args:
        annual_salary: 年間総給与 (ウォン)
        credit_usage: クレジットカード使用額 (ウォン)
        debit_usage: チェックカード使用額 (ウォン)
        traditional_market: 伝統市場での使用額 (ウォン)
        public_transport: 公共交通機関の使用額 (ウォン)

    Returns:
        所得控除金額 (ウォン)
    """
    # 最低使用金額 (総給与の25%)
    min_usage = annual_salary * 0.25

    total_usage = credit_usage + debit_usage + traditional_market + public_transport

    if total_usage < min_usage:
        return 0

    # 超過使用分の計算
    excess_usage = total_usage - min_usage

    # 控除計算
    deduction = 0
    deduction += credit_usage * 0.15  # クレジットカード 15%
    deduction += debit_usage * 0.30   # チェックカード 30%
    deduction += traditional_market * 0.50  # 伝統市場 50%
    deduction += public_transport * 0.80    # 公共交通機関 80%

    # 限度額適用 (総給与別の差等)
    if annual_salary <= 70000000:  # 7,000万ウォン以下
        limit = 3000000
    elif annual_salary <= 120000000:  # 1億2,000万ウォン以下
        limit = 2500000
    else:
        limit = 2000000

    return min(deduction, limit)

# 使用例
salary = 50000000  # 年俸5,000万ウォン
credit = 5000000   # クレジットカード500万ウォン
debit = 10000000   # チェックカード1,000万ウォン
market = 2000000   # 伝統市場200万ウォン
transport = 1200000  # 公共交通機関120万ウォン

total_deduction = calculate_card_deduction(salary, credit, debit, market, transport)
print(f"予想所得控除額: {total_deduction:,}ウォン")
# 出力: 予想所得控除額: 3,000,000ウォン (限度額適用)

# 医療費税額控除最適化シミュレーター
def optimize_medical_expense(annual_salary, family_expenses):
    """
    家族構成員別の医療費を最適配分して税額控除を最大化

    Args:
        annual_salary: 年間総給与
        family_expenses: {
            'self': 本人の医療費,
            'spouse': 配偶者の医療費,
            'parents': 親の医療費 (65歳以上),
            'children': 子どもの医療費
        }

    Returns:
        最大税額控除金額
    """
    threshold = annual_salary * 0.03  # 最低使用金額 (3%)

    # 本人 + 65歳以上 + 障害者: 限度なし
    unlimited = family_expenses.get('self', 0) + family_expenses.get('parents', 0)

    # 一般扶養家族: 700万ウォン限度
    limited = min(family_expenses.get('spouse', 0) + family_expenses.get('children', 0), 7000000)

    total_medical = unlimited + limited

    if total_medical <= threshold:
        return 0

    # 超過分に対して15%税額控除
    deduction_amount = (total_medical - threshold) * 0.15

    return deduction_amount

# 使用例
expenses = {
    'self': 500000,      # 本人50万ウォン
    'spouse': 800000,    # 配偶者80万ウォン
    'parents': 3000000,  # 親300万ウォン (65歳以上)
    'children': 400000   # 子ども40万ウォン
}

tax_credit = optimize_medical_expense(50000000, expenses)
print(f"医療費税額控除: {tax_credit:,}ウォン")
# 出力: 医療費税額控除: 472,500ウォン

# 年金口座最適納入シミュレーター
def optimize_pension_contribution(annual_salary, age):
    """
    年金口座の最適納入額を計算

    Args:
        annual_salary: 年間総給与
        age: 年齢

    Returns:
        dict: {
            'pension_saving': 年金貯蓄の推奨納入額,
            'irp': IRPの推奨納入額,
            'tax_credit': 予想税額控除
        }
    """
    if annual_salary <= 55000000:
        tax_rate = 0.165  # 16.5%
    else:
        tax_rate = 0.132  # 13.2%

    # 50歳未満: 年金貯蓄600万ウォン + IRP 300万ウォン
    # 50歳以上: 年金貯蓄600万ウォン + IRP 900万ウォン (退職準備)
    if age < 50:
        pension_saving = 6000000
        irp = 3000000
    else:
        pension_saving = 6000000
        irp = 9000000

    total_contribution = pension_saving + irp
    tax_credit = min(total_contribution, 9000000) * tax_rate

    return {
        'pension_saving': pension_saving,
        'irp': irp,
        'total': total_contribution,
        'tax_credit': tax_credit
    }

# 使用例
