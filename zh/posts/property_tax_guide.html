前言：在韩国持有不动产须缴的两种税

在韩国持有不动产，每年都须缴纳至少一种、有时两种持有税。第一种是财产税（재산세），由地方自治团体对几乎所有类型的不动产征收；第二种是综合房地产税（종합부동산세，简称「종부세」），当全国持有不动产的公示价格合计超过扣除金额时，由国税厅在财产税之外额外征收。两者合称韩国的「보유세（不动产持有税）」体系。本文只介绍韩国的制度。

税法修订频繁，2026年就有两项改革方案。财政经济部8月3日发布、9月1日确定为政府案的「2026年税制改革方案」包含将综合房地产税一户一住宅基本扣除提高到14亿韩元的内容；行政安全部8月26日发布的「2026年地方税制改革方案」包含将一住宅财产税特例税率延长至2029年的内容。两者都尚未经国会表决，还不是现行规则。本文的税率、扣除和期限以2026年9月29日施行中的规定为准，改革方案另行区分说明。本文不构成税务建议，个人实际税负请通过管辖自治团体、国税厅、Wetax或Hometax确认。

重要免责声明

本文仅供信息参考和教育目的，不构成税务、法律或财务建议。文中的税率、扣除金额、纳税期限及要件，依据韩国国税厅、行政安全部、国家法令信息中心等公开标准整理，会随税法修订而变化。特别是公正市场价额比率、特例税率适用期限和扣除限额，会随政府政策与国会表决而调整。本文不保证任何节税效果。实际纳税前，请务必向管辖地方自治团体（财产税）、国税厅或税务署（综合房地产税）、Wetax（wetax.go.kr）、Hometax（hometax.go.kr）或注册税务师等专业人士确认最新标准与您的具体情况。本文不推荐取得、出售或投资任何特定不动产，一切判断与责任由您本人承担。

财产税与综合房地产税对比

两种税容易混淆，先看核心区别。

项目财产税（재산세）综合房地产税（종부세）
税种地方税国税
征收主体地方自治团体国税厅
缴纳渠道Wetax（wetax.go.kr）Hometax（hometax.go.kr）
课税对象住宅、建筑物、土地、船舶、航空器住宅、土地（超出扣除金额部分）
缴纳时间7月16日至31日（建筑物+住宅½）、9月16日至30日（土地+住宅½）12月1日至15日
重复课征所有不动产持有者在财产税之后额外征收

也就是说，财产税是所有不动产持有者都要缴纳的「基本持有税」，综合房地产税则是持有住宅、土地的公示价格合计超过标准时，在财产税之外另行缴纳的「追加持有税」。两者的课税基准日都是每年6月1日。

一句话总结：财产税（地方税，7/9月）适用所有持有者；综合房地产税（国税，12月）对超过扣除金额的持有者额外征收。

财产税的结构与计算

课税基准日与纳税义务人

财产税以每年6月1日为课税基准日，当天持有不动产的人为当年纳税义务人。6月1日之前取得不动产则缴纳当年财产税，6月1日之后取得则从次年起负有纳税义务。买卖时以尾款支付日（所有权转移日）为准，因此6月1日前后的交易日程会改变纳税义务人。

课税标准：时价标准额 × 公正市场价额比率

住宅财产税的课税标准为时价标准额（住宅即公示价格）乘以公正市场价额比率。被认定为一户一住宅的住宅，其2026年度比率由《地方税法施行令》第109条（2026年5月29日修订）规定为时价标准额3亿韩元以下43%、3亿韩元以上至6亿韩元44%、6亿韩元以上45%。该特例比率自2023年起每年延长一次，因此2027年的比率要看明年施行令的修订。多住宅者和法人住宅适用60%（依据2025年4月政策简报，2026年未能核实）。土地适用另外的比率。

课税标准 = 时价标准额 × 公正市场价额比率（一户一住宅2026年度为43%、44%、45%，其他住宅60%）

住宅财产税按课税标准区间适用累进税率（标准税率0.1%至0.4%）计算。换算成累进扣除方式如下。

时价标准额9亿韩元以下的一户一住宅，依《地方税法》第111条之2适用比标准税率低0.05个百分点的特例税率（0.05%至0.35%）。现行条文附有仅对2026年成立的纳税义务有效的注释，若不延长，2026年度财产税将是最后一年。行政安全部的2026年地方税制改革方案包含将其延长至2029年的内容，但目前处于立法预告（8月27日至9月23日）之后、预定10月底提交国会的阶段。

缴纳日程

《地方税法》第115条规定的财产税缴纳期限如下。

  • 7月16日至31日：住宅税额的一半 + 建筑物（非住宅）、船舶、航空器分
  • 9月16日至30日：住宅税额的另一半 + 土地分

住宅年税额不超过20万韩元时，可依条例规定在7月一次性课征。缴纳渠道包括Wetax（wetax.go.kr）、E-tax、ARS（1588-5500，2026年6月时点，未能核实更新）及金融机构等。

综合房地产税的结构与计算

课税对象：公示价格合计

综合房地产税将6月1日时点持有的全国住宅及土地公示价格按人合计，超过扣除金额时课征。国税厅公布的扣除金额如下。

  • 住宅分：持有住宅公示价格合计 − 9亿韩元（一户一住宅者12亿韩元）
  • 土地别途合算分：营业用土地公示价格合计 − 80亿韩元
  • 土地综合合算分：空地、杂种地等公示价格合计 − 5亿韩元

2026年税制改革方案（政府案）包含调整其中住宅分扣除金额的内容，在下方「2026年税制改革方案」一项中单独整理。

课税标准：（公示价格合计 − 扣除）× 公正市场价额比率

综合房地产税的课税标准同样要乘以公正市场价额比率。国税厅税额计算流程图将住宅分比率列为60%（2026年9月29日时点）。法律规定该比率由总统令在60%至100%的范围内确定。

综合房地产税课税标准 ＝（全国住宅公示价格合计 − 扣除金额9亿韩元／一户一住宅12亿韩元）× 公正市场价额比率（60%）

一户一住宅者的税额扣除

一户一住宅者除基本扣除（12亿韩元）外，还可享受税额扣除。依国税厅税额计算流程图，两项扣除如下。

  • 高龄者扣除：60岁以上20%、65岁以上30%、70岁以上40%
  • 长期持有扣除：持有5年以上20%、10年以上40%、15年以上50%
  • 两项扣除合计上限：80%
年龄与持有期间的基准日及具体要件，请向国税厅（126、Hometax）确认。税制改革方案（政府案）包含调整此扣除结构的内容，但尚未施行。

缴纳与申报

综合房地产税由国税厅核算税额并寄发缴纳告知书，纳税人按告知金额缴纳即可（告知缴纳）；也可在同一期间自行申报缴纳。

  • 缴纳期间：每年12月1日至15日
  • 分期缴纳：税额超过250万韩元时，可在6个月内分期缴纳
  • 缴纳渠道：Hometax（hometax.go.kr）、金融机构等

2026年税制改革方案（政府案）— 尚未施行

财政经济部于2026年8月3日发布、9月1日确定为政府案的「2026年税制改革方案」包含综合房地产税项目。政策简报以「居住用一住宅，市价20亿韩元以内排除在综合房地产税课税对象之外」为题作了介绍。这些属于法律修订事项，须经国会表决后才能施行。政府资料列出的主要内容如下。

  • 将一户一住宅者基本扣除由公示价格12亿韩元提高到14亿韩元
  • 非居住一住宅的扣除由12亿韩元降为9亿韩元，多住宅由9亿韩元改为「4亿韩元 +（5亿韩元中居住住宅所占比重）」
  • 税率由按住宅数量改为按住宅价额统一，持有3套及以上时公正市场价额比率由60%提高到80%
  • 税额扣除由持有期间扣除改为居住期间扣除，并新设一户一住宅者税额扣除上限（600万韩元）
  • 综合房地产税自2027年起分两年逐步改革

国会审议过程中数字和时间可能改变，因此不能把这份清单当作2026年12月缴纳综合房地产税的规则。2026年度仍按上述现行标准（12亿、9亿韩元，60%，按住宅数量的税率）告知。

财产税与综合房地产税的全年缴纳流程

下面以一年的日历整理实际缴纳流程。这是现行规定下的一般流程，个人是否收到告知及金额会有所不同。

时间内容缴纳渠道
6月1日课税基准日 — 当天持有者为纳税义务人–
7月16日至31日财产税第1期（住宅分½ + 建筑物、船舶、航空器）Wetax
9月16日至30日财产税第2期（住宅分½ + 土地）Wetax
9月16日至30日综合房地产税合算排除、课税特例申报（仅限适用者）Hometax
12月1日至15日综合房地产税（超过扣除金额者）Hometax
要点：6月1日是否持有决定财产税与综合房地产税的纳税义务。签订买卖合同时，尾款和登记日在6月1日之前还是之后，决定当年持有税由谁负担，把这一点写进合同条件可以减少纠纷。

公示价格是什么

财产税和综合房地产税都以公示价格（공시가격）为基础计算。公示价格是国土交通部每年以1月1日为基准公告的不动产基准价格，与市场价格（实际交易价格）不同。公示价格一般低于市场价格，2020年代初也曾推动提高现实化率的政策。可通过不动产公示价格网站（realtyprice.kr）查询特定房产的公示价格。

公示价格与公正市场价额比率会随政府的不动产政策每年调整，同一处不动产每年的税负也可能不同。公示价格现实化政策在2026年的情况，本次更新未能以一手资料确认，因此当年的公示价格以在该网站直接查询为准。

财产税一住宅特例与减免

财产税有多种特例与减免制度，最具代表性的是一户一住宅特例。

  • 时价标准额9亿韩元以下的一户一住宅，适用比标准税率（0.1%至0.4%）低0.05个百分点的特例税率（0.05%至0.35%）— 按现行条文适用至2026年度
  • 一户一住宅公正市场价额比率特例（43%、44%、45%）不设价格上限，适用于全部一户一住宅，已规定至2026年度
  • 将特例税率延长至2029年的内容载于2026年地方税制改革方案（政府案），尚未经国会表决

此外还有租赁住宅、公益用土地等多种减免因素，但各自要件不同且有期限。适用减免前，请务必咨询管辖自治团体或税务专业人士。

特例税率与减免制度可能因税法修订而改变或终止。本文不断定或保证任何节税效果。

综合房地产税合算排除制度

综合房地产税有合算排除（합산배제）制度。符合一定要件的租赁住宅、未售出住宅、员工住宅等，可排除在综合房地产税课税合算之外。根据国税厅说明，合算排除与课税特例的申报期间为每年9月16日至30日，错过期限当年可能无法适用。要件复杂，请务必参考国税厅说明或寻求税务专业人士帮助。

常见问题（FAQ）

问：财产税何时缴纳？

财产税分两次缴纳：7月16日至31日（住宅一半+建筑物）和9月16日至30日（住宅另一半+土地）。若住宅年税额不超过20万韩元，可依条例在7月一次性课征。课税基准日为6月1日。

问：如何确认是否需要缴纳综合房地产税？

2026年度，全国持有住宅的公示价格合计超过9亿韩元（一户一住宅为12亿韩元）即为课税对象。税制改革方案（政府案）中的14亿韩元须经国会通过，按政府计划自2027年起逐步适用。建议在12月通过Hometax查看告知书，或使用国税厅模拟计算服务。

问：财产税和综合房地产税是否构成双重课税？

财产税为地方税，综合房地产税为国税，分别在不同法律框架下征收。但计算综合房地产税时，会从计算出的税额中扣除对应综合房地产税课税标准的财产税额，因此并非完全意义上的双重课税。具体计算请向国税厅确认。

问：共同名义的住宅如何课税？

财产税按各持有人的持分比例分别课税。综合房地产税将各持分视为所持住宅合计计算，但共同名义时，一户一住宅的认定和计算方式可能不同。共同名义的综合房地产税相当复杂，请务必咨询税务专业人士。

结语：记住6月1日这个关键日期

理解财产税与综合房地产税，最重要的日期是6月1日。当天持有不动产的人要负担当年全部持有税：财产税作为地方税在7月和9月缴纳，综合房地产税作为国税在12月缴纳。一户一住宅者应仔细确认财产税特例税率和综合房地产税扣除，同时要记住，2026年两种税的改革方案都已提交国会，从2027年度起标准可能改变。

本文仅供信息与教育目的，不构成税务建议。个人税负因持有住宅数量、公示价格、持有期间、年龄等差异很大，具体事项请务必向国税厅（126）、行政安全部、Wetax（wetax.go.kr）、Hometax（hometax.go.kr）或注册税务师等专业人士确认。

  • 通过修订《地方税法施行令》确定2027年度一住宅公正市场价额比率时（2026年度比率由5月29日修订确定）
  • 《综合房地产税法施行令》规定的公正市场价额比率（目前60%）变更时

本次更新也有未能以一手资料重新核实的部分。多住宅者财产税公正市场价额比率60%依据的是2025年4月的政策简报；财产税ARS号码、公示价格现实化政策的2026年情况、共同名义住宅的综合房地产税计算方式、各类合算排除住宅的要件均未与原文核对，请向管辖自治团体或国税厅确认。

# 韩国财产税与综合房地产税核对表 - 全年持有税日历与确认事项

基准日: 2026-09-29（以施行中的规定为准。2026年税制改革方案、地方税制改革方案为政府案，尚未经国会表决）

本表为韩国制度的一般信息，不构成税务建议。实际缴纳前，请向管辖自治团体、韩国国税厅、Wetax、Hometax或税务师确认您的具体情况。

---

## 1. 全年日历

| 日期 | 要做的事 | 渠道 |
|---|---|---|
| 6月1日 | 课税基准日。当天持有者为当年财产税、综合房地产税的纳税义务人 | - |
| 7月16日至31日 | 财产税第1期（住宅½ + 建筑物、船舶、航空器） | Wetax |
| 9月16日至30日 | 财产税第2期（住宅½ + 土地） | Wetax |
| 9月16日至30日 | 综合房地产税合算排除、课税特例申报（仅限适用者） | Hometax |
| 12月1日至15日 | 缴纳综合房地产税（告知或申报） | Hometax |

- [ ] 住宅年财产税不超过20万韩元时，可能在7月一次性课征（依条例）
- [ ] 综合房地产税超过250万韩元时，可申请在6个月内分期缴纳

## 2. 核对财产税计算

| 项目 | 现行值（2026年度） | 依据 |
|---|---|---|
| 课税标准 | 时价标准额 × 公正市场价额比率 | 《地方税法》 |
| 一户一住宅比率 | 3亿以下43%、6亿以下44%、6亿以上45% | 《地方税法施行令》第109条（2026-05-29修订） |
| 其他住宅比率 | 60% | 2025年4月政策简报（2026年未能核实） |
| 标准税率 | 0.1% / 0.15%（累进扣除3万）/ 0.25%（18万）/ 0.4%（63万） | 课税标准6000万、1.5亿、3亿韩元区间 |
| 一住宅特例税率 | 标准税率减0.05个百分点（0.05%至0.35%），时价标准额9亿韩元以下 | 《地方税法》第111条之2 |
| 特例税率期限 | 按现行条文至2026年度 | 条文注释 |

- [ ] 自己的住宅是否被认定为一户一住宅
- [ ] 时价标准额是否在9亿韩元以下（特例税率对象）
- [ ] 2027年以后的特例税率延长是否已经国会确定
