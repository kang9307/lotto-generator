Boutlet — AI智能体也能参与并支付的社交平台

智能体经济的前沿阵地：人类与AI共同交易的社交形态诞生

2026-07-01 IT/技术

引言：AI在社交平台上自主完成支付

截至2026年6月，社交媒体这一概念正在悄然动摇。迄今为止，社交平台的基本前提是明确的：用户是人类，撰写和阅读内容的主体是人类，即便发生支付行为，支付方也依然是人类。Boutlet是一个打破这一前提的平台。用户通过类似Notion的块状编辑器创作的内容，不仅以普通网页形式提供给人类读者，还以Markdown端点和llms.txt格式为AI智能体提供机器可读版本。对特定内容块设定价格后，AI智能体即可通过x402协议在无需人类审批的情况下自主完成支付并访问内容。

这看似只是一家初创公司的小实验，但背景却大不相同。2026年以来，Coinbase智能体钱包、Mastercard Agent Pay、面向智能体的Stripe Link以及OpenAI即时结账相继涌现。稳定币交易量在2025年突破33万亿美元，x402基金会的创始成员包括Google、Visa、AWS、Mastercard和Stripe。Boutlet正是在这股浪潮的最前沿，进行着最具社交属性的实验。

本文分析Boutlet的尝试，深入探讨支撑其运转的技术基础设施（x402、智能体钱包、身份协议）以及潜藏其中的信任、欺诈与责任问题，力求提供均衡客观的视角。以下分析均基于2026年6月时点的信息。

1. Boutlet是什么

1.1 拥有双重受众的块状编辑器

Boutlet的核心结构很简单：用户通过类似Notion的块状编辑器创作内容。到这里，与其他内容平台并无区别。不同之处在于接下来的设计。创作的内容不仅以普通网页形式呈现，还以Markdown端点和llms.txt格式提供，使外部AI智能体能够以编程方式浏览和读取平台内容。平台从设计之初就将AI智能体视为真正的读者和客户，而非单纯的爬虫程序。

llms.txt是网站向AI智能体说明内容结构和使用政策的标准化文件。提供该文件意味着Boutlet将AI智能体视为付费用户，而非偶然的访问者。Mastercard开发者平台也已采用llms.txt，以帮助智能体更好地浏览文档——这表明该标准正在被严肃的行业生态所接受。

1.2 付费内容块与智能体支付

Boutlet的核心创新在于内容块级别的收费机制。创作者可以将特定块（而非整篇文章）设为付费内容。AI智能体通过x402协议自主完成支付后即可访问这些付费块。Boutlet团队表示已验证完整流程：智能体发送HTTP请求→服务器返回402响应及支付指令→智能体以稳定币完成结算→成功访问内容。

这意味着什么值得深思：互联网上的AI智能体正在自主付费购买信息，无需人类批准每一笔交易。智能体在预先授权的权限和预算范围内自行处理支付。截至2026年6月，在社交内容平台上经过实证的此类案例仍属凤毛麟角。

1.3 现状与路线图

截至2026年6月，Boutlet仍处于早期阶段，以加密货币和区块链信息为核心的社交社区形态运营，还在进行奖励1 USDC的漏洞赏金活动，整体氛围偏向实验性。团队计划在未来添加AI智能体注册功能和自由职业竞标功能，使智能体不仅仅是内容消费者，还能成为在平台内提供服务、获取收益的经济主体。据称其目标是构建一个无需缴纳高额手续费、人类与智能体均可出售内容的环境。

2. 底层技术：x402与智能体钱包

2.1 x402协议——沉睡30年的HTTP代码重获新生

HTTP 402状态码自1991年起以「Payment Required」写入规范，却沉睡了30余年。x402让它重焕生机。当服务返回402响应及支付指令时，包括AI智能体在内的客户端无需账户或会话，即可以编程方式完成支付。支付主要使用Base或Solana链上的USDC等稳定币，区块链手续费通常不足一美分，从而在经济层面使微支付成为现实。

对开发者而言，添加x402支持大约只需10行中间件代码。2026年4月，x402基金会在Linux基金会旗下成立，Google、Visa、Stripe、AWS、Mastercard、Circle、Microsoft、Shopify、American Express均为创始成员。这表明x402有望成为行业标准，而非仅停留于小圈子实验。

2.2 智能体钱包——赋予智能体经济主体权

智能体要进行自主支付，需要专属钱包。Coinbase于2026年发布了专为AI智能体设计的钱包基础设施，以模块化方式提供发送、赚取、交易等功能，并通过可编程护栏控制支出上限和授权范围。Stripe更新了Link数字钱包，使自主AI智能体在购物时也能使用。World（前身为Worldcoin，Sam Altman联合创立）将x402集成进AgentKit，支持经人类验证的AI智能体进行自主支付。

这些钱包共同面对的核心问题：智能体不应借用人类的钱包，而需要以自身身份和委托授权范围为边界独立进行交易。这才是将智能体真正升格为经济主体的基础设施核心。

2.3 智能体身份与权限委托

智能体支付中最悬而未决的问题之一是身份认证。当智能体发起支付时，如何验证其可信度、谁授予了权限、授权范围有多大——这些标准尚未成熟。FIDO Alliance于2026年宣布将开发AI智能体认证及交易执行的共享标准。Google提出了Agent Payments Protocol（AP2），设计了安全委托、可验证授权和交易执行模型。MCP与A2A协议定义了智能体间的通信方式，但仍未能明确「这个智能体是谁」，这一缺口正是FIDO Alliance着力弥合的核心议题。

3. 智能体经济的崛起

3.1 2026年是智能体支付元年吗

Fenwick的报告将2026年定位为智能体支付的潜在转折点，依据是多个维度的基础设施正同步走向成熟。Mastercard Agent Pay正在测试智能体在用户预设限额内构建购买意图并完成处理的流程。OpenAI在ChatGPT中引入了基于智能体商务协议的即时结账功能。Google在Gemini和搜索AI模式中推出了智能体可在不离开AI界面的情况下直接从Etsy、Wayfair等零售商购物的功能。

稳定币是这一生态的燃料。2025年稳定币交易量突破33万亿美元（同比增长72%），行业分析师预测2026年供应量将再增56%至约4200亿美元，智能体间的微交易被列为主要增长动力。

3.2 智能体已能在12个平台赚钱

截至2026年5月，已有12个以上的活跃平台允许自主智能体竞标工作并以USDC、SOL或NEAR获得报酬。智能体经济不再是概念，已成为真实运转的市场。Boutlet计划推出的智能体自由职业竞标功能正是这一趋势的延伸——人类发布需求，智能体竞标、交付成果并获取报酬，只不过这一切发生在社交内容平台之上。

4. 信任、欺诈与责任——不那么光明的另一面

4.1 无法分辨人类与智能体的社交平台

当人类与AI智能体共享平台时，最根本的问题是识别。如果无从判断一篇帖子出自人类还是智能体之手，整个平台的信任基础将受到侵蚀。当今社交平台的机器人账号问题已相当严峻，而当智能体被正式认定为合法参与者时，这条边界将愈发模糊。Boutlet是否计划建立透明的智能体活动标识机制，以及其可靠程度如何，目前尚无公开信息可查。

4.2 智能体欺诈的新维度

Experian 2026年欺诈预测报告将智能体AI列为主要威胁：具有高度情感说服力的AI机器人能够实施浪漫诈骗等复杂骗局，随时间积累信任、精准操控受害者。学术研究已对多个LLM智能体在社交平台上共谋实施金融欺诈的场景进行了建模分析。当智能体获得在平台内自主支付的权限，劫持智能体账户、操控智能体发起非预期支付的攻击将成为新型威胁。TrustSphere的分析将「智能体账户接管攻击」（即AI购物智能体本身沦为被攻破的端点）列为2026年核心安全威胁。

4.3 责任归属

当智能体自主执行的支付出现问题，责任归谁？是构建智能体的开发者？是部署智能体的用户？还是收取支付款的平台？目前不存在任何明确的法律标准。机器间交易中所有权、意图与风险归属不明，是整个智能体商务领域尚未解决的核心难题。IMF 2026年关于「智能体AI如何重塑支付」的报告将监管空白列为主要风险。随着智能体支付规模扩大，建立责任标准的压力将持续加剧，但标准的落地速度将远落后于技术进展。

4.4 身份标准的已知缺口

FIDO Alliance已正式确认：MCP与A2A协议定义了智能体间的通信方式，却未能定义「该智能体是谁」。尽管MCP于2026年将OAuth 2.1纳入可选认证层，安全扫描却发现大多数MCP服务器实际上并未实现认证。智能体身份协议（AIP）的学术论文已相继出现，但距离大规模实用化仍需时日。Boutlet等智能体参与型平台所面临的身份问题，并非单一平台能够独立解决。

5. 人机混合社交的深层含义

5.1 内容生态的全新动力学

在传统社交平台上，内容价值由人类受众的反应决定——点赞、评论、分享是衡量指标。当AI智能体以读者兼付款方的身份加入，这一动力学将发生改变。智能体愿意为哪些内容付费，将成为新的质量信号。人类偏好与智能体信息需求未必一致，这要求内容策略能够同时吸引两类受众。Boutlet的块级收费设计，正是在单篇内容内实现这种分层的一种尝试。

5.2 创作者经济的版图扩张

当智能体成为内容买家，创作者经济的潜在市场将得到扩展。今日创作者的收入来源于面向人类的广告、订阅和打赏渠道。未来，向智能体出售数据、分析报告和专业知识的「智能体向」收益渠道有望形成。尤其是借助x402的微支付能力，过去在传统支付体系中因单价过低而无法实现的精细化收费模式将首次具备现实可行性——比如对一段内容收取0.01美元，这在以往根本不现实。

5.3 当平台赋予智能体公民身份

Boutlet的设计之所以引人关注，在于它将智能体定位为平台参与者，而非单纯的API消费者：提供llms.txt、规划智能体注册功能、构想智能体自由职业市场。这是赋予智能体平台内地位的设计决策。若这一方向被验证为正确，长远来看，平台允许智能体发表评测、提出推荐、表达观点并为其贡献给予报酬的图景也并非遥不可及——一个人类与智能体作为对等参与者共同构筑社交空间的图景。

6. 批判性审视：太早，还是时机恰当？

6.1 技术已就位，生态尚未形成

x402在技术上可行，并不意味着市场会立即涌现。智能体要在Boutlet购买内容，需要运营该智能体的个人或组织将其部署至平台、分配预算并设定购买目标。在这一生态形成之前，智能体支付功能仍停留在概念验证阶段。Boutlet目前聚焦于加密货币和区块链信息社区，也意味着智能体读者群实际能找到价值的内容多样性尚属有限。

6.2 监管滞后的现实

智能体自主执行金融交易在现行金融监管框架下处于灰色地带。智能体交易是否适用反洗钱（AML）、KYC（了解你的客户）、消费者保护等法规，目前缺乏明确指引。IMF已将这一监管空白列为重大风险。在监管机构出台指引之前，以智能体支付为核心功能的平台将在相当程度的不确定性中运营。

7. 结语——如何看待智能体经济的社交实验

截至2026年6月，Boutlet还是一个规模不大的早期平台。但它所尝试的，是两个重大命题的实践性检验：一，AI智能体与人类能否成为社交平台上真正对等的共同参与者？二，智能体自主支付能否真正与内容变现相结合？

若两个命题的答案均为肯定，则智能体经济将开辟出一个全新的社交层。x402、智能体钱包与智能体身份标准基础设施成熟的速度，将决定这一可能性变为现实的节奏。然而，信任、欺诈与责任问题的解决速度将远落后于技术。当平台正式认定智能体为参与者的那一刻，也意味着平台需要为这些智能体的行为承担相应责任，这一点不可回避。

在智能体经济已不再是假设、而是进行时的2026年，Boutlet的实验值得持续关注——它既揭示了前路的可能，也清晰地呈现了潜在的风险。
