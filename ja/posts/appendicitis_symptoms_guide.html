虫垂炎(盲腸)の初期症状と対応 - いつ救急外来へ行くべきか

自分で判断せず、見逃してはいけない徴候を知っておく

2026-07-31 健康・暮らし

はじめに: 我慢する腹痛か、行くべき腹痛か

夕食のあとからおなかが重かった。みぞおちのあたりが詰まった感じで食欲もないので、消化不良だろうと思って横になる。夜中に目が覚めると、痛む場所がさっきと違う。今度は右の下のほうがずきずきして、寝返りを打ったり咳をしたりすると強くなる。この時刻に救急外来まで行くことなのか、朝まで待って近所の医院へ行けばよいことなのか。

この記事はその分かれ道に立つ人のためのものである。そして論旨は「虫垂炎かどうか調べよう」ではなく「自分で判断しないでおこう」である。順序が逆に見えるが理由ははっきりしている。韓国疾病管理庁 国家健康情報ポータルの急性虫垂炎の文書は、症状があいまいな患者が全体の3分の1に達すると記している。米国国立医学図書館のMedlinePlusも、すべての患者がこれらの症状を全部もつわけではないと述べる。英国NHSのAppendicitisにはもっと直接的な一文がある。虫垂炎があるかどうかを常に示せる検査はないというものだ。検査設備のある病院でもひとつの結果で確定しない病気を、自宅でおなかを触るだけで見分けられるはずがない。

そこでこの記事の目的はひとつに絞られる。受診の時機を逃さないことである。以下はその目的に合わせて並べた。

  • まずためらってはいけない徴候を置く。ほかを読まなくてもこの一覧だけは残ってほしい
  • 次になぜこの病気はとりわけ自己判断が危ういのかを資料で示す。典型的な順番と、その順番を踏まない例をあわせて扱う
  • 最後に受診を効率よくする準備を整理する。いつから痛いか、場所がどう移ったかは実際の診断に使われる

免責。この記事は情報提供を目的としており、医学的な診断や治療の代わりにはならない。本文のいかなる内容も自己診断や自己治療の根拠として用いてはならない。症状があるなら医療者の診療を受けるのが原則であり、薬の服用の可否や治療方針は診察と検査を経て医療者が決める。韓国の救急通報・相談番号は119であり、それ以外の国にいるならその国の救急番号を使う。

1. こういうときはためらわず救急外来へ

まず一覧から置く。以下は確認した公的医療資料が緊急の対応を案内した項目であり、筆者が勝手に付け足したものはない。ひとつでも当てはまるなら、原因を自分で絞り込もうとするのをやめるほうがよい。

  • 腹痛が強い。NHSは強い腹痛をただちに救急対応が必要な状況として挙げる
  • 痛みが時間とともに悪化する、あるいは治まらない。NHSはこの場合に緊急の受診を案内する
  • へその周りで始まった痛みが右下腹部へ移った。場所が移ること自体がひとつの徴候として扱われる
  • おなかを押して離すときにより痛い。国家健康情報ポータルはこれを反跳痛と呼び、虫垂炎の進行時に現れる所見として記す
  • 歩く、咳をする、くしゃみをする、深く息を吸うと痛みが強まる。米国NIDDKが挙げる特徴である
  • 発熱がある。微熱がしだいに上がる経過も含まれる
  • 嘔吐が続き、何も飲み込めない
  • 痛みが右下腹部を越えて腹部全体へ広がった。あるいは一度和らいでから再びはるかに強くなった

最後の項目は別に強調しておく価値がある。NHSは虫垂が破れたあと痛みが一時的に和らぎ、その後に腹部全体へ広がる強い痛みになると説明している。つまり急に楽になったという事実が安心の根拠にはならない。むしろその直後の変化を注意深く見るべきである。

NHSは以下の三つを敗血症の徴候として挙げ、この場合は予約を探すのではなくただちに救急番号へ連絡するよう案内している。

  • 意識がもうろうとする。話がはっきりしない、人が分からないといった場合を含む
  • 皮膚がまだらになる、あるいは普段より青白い
  • 息がしづらい
見えていること資料が案内する対応根拠資料
強い腹痛ただちに救急対応NHS Appendicitis
意識低下、まだらまたは青白い皮膚、呼吸困難ただちに救急対応(敗血症の徴候)NHS Appendicitis
痛みがしだいに悪化する、または消えない緊急の受診NHS Appendicitis

連絡先。韓国の救急通報・相談番号は119ひとつである。かつて使われていた救急医療情報センターの番号は119へ統合され、いまは使われていない。119は通報の受付と出動だけでなく、救急相談と搬送先病院の案内まで担う。近くの救急外来をあらかじめ調べておきたいなら、中央救急医療センターが運営する救急医療ポータルで確認できる。韓国以外にいるならその国の救急番号を使う。韓国の番号は国外では通じない。

2. 虫垂とは何で、なぜ炎症が起きるのか

日本語でも韓国語でも俗に盲腸と呼ぶが、国家健康情報ポータルはその通称が医学的に正確な用語ではないと記している。実際に炎症が起きるのは盲腸そのものではなく、盲腸に付いた細い管、すなわち虫垂である。

MedlinePlusは虫垂を大腸の最初の部分に付いた小さな管状の器官と説明し、位置は腹部の右下で、知られている機能はないと記す。右下腹部がよく話題になる理由はここにある。

炎症の出発点は詰まりである。MedlinePlusは、虫垂内部の閉塞が虫垂炎を引き起こし、その閉塞が内圧の上昇、血流の問題、炎症につながると説明する。何が詰まらせるかについては資料ごとに表現が少し異なる。

  • 国家健康情報ポータルは虫垂周囲のリンパ組織の過剰増殖が最も多い(60パーセント)と記す
  • 同じ資料は硬い便が虫垂の入口をふさぐ場合を35パーセントとして挙げる
  • そのほか異物、炎症性の狭窄、寄生虫、腫瘍などが原因として列挙される
  • NIDDKは硬い便や増殖物、そして感染によって虫垂の壁の組織が大きくなることを閉塞の原因として挙げる
  • 上の比率は国家健康情報ポータルの文書に載る値であり、同文書に調査年や対象集団は別途明記されていない

構造が分かると、なぜ時間が問題になるのかも自然に理解できる。詰まった管の中で圧が上がり続け血流が悪くなれば、その壁が持ちこたえるのには限界がある。あとに出てくる穿孔と腹膜炎の話はここからつながる。

3. 症状の典型的な順番 - そして典型的でない3分の1

まず典型的な場合から見る。国家健康情報ポータルが記す経過はこうである。はじめに食欲が落ちて吐き気が始まり、そのあと上腹部の痛みが現れる。その痛みがへその周りを経て右下腹部の痛みへ変わる。続いて右下腹部の圧痛がはっきりし、反跳痛が現れ、しだいに微熱が上がり寒気を感じることもある。

NHSの説明も大枠は同じである。痛みがおなかの真ん中、へその周りで始まり、数時間後に右下へ移ると記す。NIDDKは痛みの性格をより具体的に挙げる。へその近くで始まって下の右のほうへ移りうること、突然始まりうること、動いたり深く息を吸ったり咳やくしゃみをしたりすると強まること、ほかの症状より先に現れて数時間のうちに悪化しうることである。

段階よく記述される様相このとき注意する点
早い時期食欲低下、吐き気、みぞおちやへその周りの漠然とした痛み消化不良として片づけやすい区間である
数時間後痛みがへその周りを経て右下腹部へ移動場所が移ったこと自体が徴候として扱われる
進行右下腹部の圧痛、押して離すときの痛み、微熱と寒気動作・咳・深呼吸で強まるかをあわせて見る
併発吐き気、嘔吐、便秘または下痢、ガスが出にくい、おなかが張る腸の症状があるからといって虫垂炎でないとは言えない
穿孔時痛みが下腹部全体または腹部全体へ拡散、高熱、速い心拍一時的に痛みが和らいでから再び強まることもある

3.1 ところがこの順番を踏まない例が珍しくない

ここがこの記事でもっとも重要な箇所である。上の順番は参考用の地図であって判定基準ではない。資料は例外の大きさをはっきり記している。

  • 国家健康情報ポータルは症状があいまいな患者が全体の3分の1に達すると記す
  • 小児は初期にしきりに眠たがり、刺激に敏感で食欲が落ちてから、急速に進んで嘔吐・発熱・痛みが現れる様相が記述されている
  • 高齢者は典型的な症状が現れないことが多く、経過が速く合併症が生じやすいと書かれている。NHSは高齢者で突然の混乱が現れうると付け加える
  • 妊娠中は胎児が育つにつれて虫垂が上へ押し上げられ、妊娠末期には右上腹部に位置するようになると記述される。痛む場所そのものが変わるという意味である
  • NHSも妊婦、幼い子ども、高齢者では痛みがより軽かったりゆっくり現れたり別の位置で感じられたりしうると記す

整理するとこうなる。典型的な順番を踏めば気づきやすいが、その逆は成り立たない。順番を踏まなかったことは虫垂炎でない根拠にはならない。そしてその例外が集まる対象が、よりによって症状を言葉で説明しにくい小児、信号がぼやける高齢者、場所が移った妊婦である。自己判断が危ういのはここに理由がある。

4. 紛らわしいもの - だからこそ受診が要る

この節の目的を先にはっきりさせておく。下の表は自分で見分けよという意味ではない。逆である。重なる項目がこれほど多いという事実を示し、だからこそ見分ける作業は診察と検査の仕事だという結論に至るための表である。

NIDDKは虫垂炎と紛らわしい状態として腹腔内癒着、炎症性腸疾患、腸閉塞、骨盤内炎症性疾患、尿路結石を挙げる。病院で尿検査を行う理由も膀胱の感染や尿路結石といった別の原因を除外するためであり、女性には妊娠反応検査を併せて行うこともある。

重なるものどこが似ているかなぜ自分では分けられないか
胃腸炎腹痛、吐き気、嘔吐、下痢、微熱が同時に現れる虫垂炎でも嘔吐と下痢を伴いうる
便秘おなかが重く、排便すれば楽になりそうに感じるNIDDKは排便すれば楽になりそうな感覚を虫垂炎の症状としても挙げる
尿路結石側腹部と下腹部の強い痛み尿検査などで除外の過程を経る対象である
婦人科の病態下腹部という位置が重なる骨盤内炎症性疾患が鑑別に挙がり妊娠反応検査も併用される
腸閉塞腹痛、嘔吐、ガスが出にくい鑑別に挙がり独自の救急判断基準が要る

表を見ると「これはただの胃腸炎だ」という判断がなぜ危ういかが浮かび上がる。重なる症状があるからではなく、重ならない症状がないからである。吐き気と嘔吐、下痢と便秘、微熱まですべて両側に現れうる。残る違いは痛みの位置と性格、時間による変化だが、これこそ直接おなかを触り検査結果とあわせて読んではじめて意味が生じる情報である。

5. 病院では何をするのか

行ってみると大したことをしていないようで時間だけかかるのが救急外来である。理由を知って行けばいらだちも減る。NIDDKが紹介する診断の道筋は問診、身体診察、検査室検査、画像検査の四つの層でできており、これらは互いを補う形で使われる。

段階何をするかなぜするか
問診痛みがいつ始まったか、どれほど強いか、正確にどこか、持病と過去の手術時間による変化が判断の骨組みになる
身体診察右下腹部の痛みの確認、腹部をやさしく押したり揺らしたり、脚を上げるときに右膝を押す炎症のある位置と腹膜刺激の有無を見る
血液検査白血球数の確認NIDDKは白血球増加を感染の徴候として記す
尿検査・妊娠反応別の原因の除外膀胱の感染や尿路結石などを見分けるためである
画像検査超音波、MRI、CT超音波は放射線がなく、乳幼児・小児・若年成人・妊婦で最初の画像検査として使われる

国家健康情報ポータルは身体診察でマックバーニー点の圧痛の有無が重要だと記す。へそと骨盤の前方に突き出た骨を結ぶ線の外側3分の1の地点である。ただしこれも診察者が手で確認する所見であって、自分で押して判定せよという項目ではない。

画像検査の選択にも順序がある。NIDDKはMRIをCTの安全で信頼できる代替として紹介し、小児では放射線被曝を減らすため超音波とMRIを経てからCTを勧めると記す。「なぜすぐCTを撮ってくれないのか」と思うときの答えがここにある。

  • 検査が何層にもなる理由は単純で、ひとつの層だけでは確定しないからである
  • NHSは虫垂炎があるかどうかを常に示せる検査はないと明記する
  • だから血液の数値が正常だという事実ひとつで安心してよいという結論は出ない
  • 逆に数値が高いという事実ひとつで虫垂炎が確定するわけでもない
  • 病院で時間がかかるのは、たいていこの層を積んでいる最中だからである

5.1 点数をつける道具について

臨床には、問診・診察・検査所見を項目ごとに点数化して危険度を見積もる道具が使われることもある。ただしこの記事はそうした道具の項目を並べない。理由は三つある。

  • それらの道具はおなかを直接触った医療者が使うことを前提に設計されている。圧痛や反跳痛のような項目は自分でつけた瞬間に意味が変わる
  • 点数は判定ではなく参考である。低く出たからと受診を先延ばしにすれば、この記事の目的と正反対になる
  • 確認した公的資料は診断を問診・診察・検査・画像の総合として説明し、患者が自分で点数をつける手順を案内していない

6. 治療の選択 - 手術と抗菌薬

治療の話はどちらがよいという推奨をせずに整理する。これは診察と検査の結果を見た医療者と相談して決めることであり、この記事が答えを決められる領域ではない。

  • 国家健康情報ポータルは急性虫垂炎の治療は手術が原則と記す
  • MedlinePlusは治療はほぼ常に虫垂の切除を伴うと述べる
  • NIDDKは一部の軽い症例は抗菌薬のみで治療されうると記す
  • NHSは感染が広がっておらず手術のリスクが高い場合に抗菌薬を検討しうると述べ、虫垂の周囲に腫瘤ができた場合はまず抗菌薬を使いのちに手術する方式を挙げる

手術の方法もひとつではない。NIDDKは小さな切開から器具を入れる腹腔鏡の方式と右下腹部に一度の大きな切開を行う開腹の方式を並べて説明する。国家健康情報ポータルも、傷あとを小さく残し回復を早めるために腹腔鏡手術を行う場合があると記す。すでに穿孔して腹膜炎になった場合についてはNIDDKが腹腔内部を洗浄する手術をただちに行うと記し、膿瘍ができた場合には膿を排出させて治す方式を挙げる。

決定要因がこれだけ枝分かれするので、患者の側が準備するのは結論ではなく質問である。以下は相談のときに尋ねる価値のある項目だ。

  • いまの自分の状態はどの段階に見えるのか、穿孔や膿瘍の所見はあるのか
  • 提案された方法を選んだ理由は何か
  • ほかの選択肢を検討しなかった理由はあるのか
  • それぞれの方法で回復期間と日常に戻る時期はどう違うのか
  • いま決定を先延ばしにすると何が変わるのか、どれくらい待てるのか

7. 先延ばしにすると何が変わるのか

この節は怖がらせるために書くのではない。なぜ時間が変数なのかを資料のまま写す。

MedlinePlusの説明がもっとも簡潔である。閉塞が治療されなければ虫垂が破れて感染が腹腔へ広がりうるし、これが腹膜炎と呼ばれる状態であるという。NHSは腹膜炎を腹部の内側の膜の感染と説明し、破れた虫垂によって膿がたまり膿瘍ができうると付け加える。国家健康情報ポータルは穿孔時に痛みが右下腹部にとどまらず下腹部全体または腹部全体へ拡散し、高熱が出て心拍が速くなると記す。

  • 国家健康情報ポータルは非穿孔性虫垂炎の5パーセントで合併症が生じるが、組織壊死や穿孔がある場合には合併症発生率が30パーセントに達することもあると記す
  • 同じ資料は手術部位の皮膚感染率を、単純な虫垂炎で4から8パーセント、穿孔性で10から20パーセントと記述する
  • 全体の穿孔率は約25パーセントと書かれ、10歳未満は35から60パーセント、50歳以上は60から75パーセントとより高く記述される
  • 同じ文書は症状が始まった時点から3日以内に手術を受けなければ虫垂が破れることになると記す。これは当該資料の記述をそのまま写したものであり、個人の経過を予測する数値として使うものではない
  • 上の数値はすべて国家健康情報ポータルの文書に載る値であり、同文書に調査年や対象集団は別途明記されていない

ただし均衡のために同じ資料の別の一文もあわせて写す。多くの患者は症状発現後12時間から18時間以内に医療機関を受診すると書かれている。つまりこの病気は、人々がおおむね間に合って病院へ行く病気である。問題になるのはその大多数に入れない場合であり、前節で見たとおりその場合が集まるのが症状のあいまいな3分の1と小児・高齢者・妊婦である。穿孔率がとりわけ高く記述される年齢層が10歳未満と50歳以上だという点も、同じ話を別の角度からしている。

この節の読み方。上の数字はいまのあなたの確率ではない。資料に載る集団レベルの記述であり、調査年と対象が明記されていないという限界もある。ここから持ち帰るべきは数字そのものではなく方向である。時間がたつほど選択肢が減るということ、そして小児と高齢者には時間がより速く流れるということだ。

8. 回復と、再び受診すべき徴候

手術を受けたなら次に気になるのはいつ元どおりになるかである。資料の記述はおおむね楽観的だ。

  • NIDDKは手術後はたいてい虫垂炎から完全に回復し、食事・運動・生活様式を変える必要はないと記す
  • 同じ資料は活動制限の期間として腹腔鏡手術後は3から5日、開腹手術後は10から14日を挙げる
  • NHSは多くは1から2週間で回復し、虫垂が破れた場合はより長くかかると記す
  • 回復期間は手術方法と穿孔の有無で分かれるので、退院時に受けた案内がこの記事より優先する

再び受診すべき徴候については慎重に書く。確認した資料が明示した項目と、退院案内に委ねるべき部分が異なるからである。

  • NHSは手術後の合併症として虫垂を取り除いた場所に膿瘍ができる場合を挙げる。膿がたまる状態なので放置してよいものではない
  • 熱が再び上がる、おなかの痛みが再び強まるといった変化は、回復経過から外れた徴候として扱うべきである
  • 手術の有無にかかわらず1節の救急徴候が再び現れたなら、同じ基準をそのまま当てはめる
  • 抗菌薬のみで治療した場合なら、症状が再び現れたときの対応をあらかじめ尋ねておくほうがよい
  • 何が正常な経過で何がそうでないかの境界は手術方法と個人の状態によって変わるので、退院時に受けた基準に従うのが原則である

9. 受診の前に整理しておくとよいこと

5節で見たとおり診断の最初の層は問診である。NIDDKが挙げる質問は痛みがいつ始まったか、どれほど強いか、正確にどこか、ほかの疾患と手術歴は何かである。ところがおなかが痛くて余裕のない状態で救急外来に着くと、まさにこの基本的なことが思い出せない。あらかじめ書いておけば受診が速くなる。

項目書くこと記入例
発症時刻最初に異変を感じた日付と時刻昨夜8時ごろ
最初の位置と現在の位置はじめに痛かった場所と、いま最も痛い場所みぞおち付近で始まり、いまは右下腹部
移動の時刻場所が移ったならいつ今日の午前3時ごろ
強さの変化時間とともに強まるか弱まるかずっと強まる、一度和らいで再び悪化
悪化要因何をすると痛いか歩くとき、咳をするとき
併発症状発熱、悪寒、吐き気、嘔吐、下痢、便秘、排尿の変化微熱、嘔吐2回
最後の食事何をいつ食べたか昨夜7時に食事、以後は水のみ
服用した薬名前と時刻。鎮痛薬・解熱薬・制酸薬・消化薬すべて今日の午前1時に鎮痛薬1錠
基礎疾患・手術歴・アレルギー持病、受けた手術、薬物アレルギーなし、または病名・薬の名前

この表でとくに気をつける欄は服用した薬である。この記事は薬を飲めとも飲むなとも指示しない。服用の可否は医療者と相談する問題である。ただしすでに飲んだのならその事実をそのまま伝えることは確かに重要である。診断が痛みの強さと位置、時間による変化に依拠するのに、その情報が薬の影響を受けたかどうかを医療者が知らなければ正しく読めないからだ。

  • メモは携帯電話に書いていくだけで十分である。痛みが強まると記憶があいまいになる
  • 付き添いがいるなら本人が話しづらいときに備えて同じ内容を共有しておく
  • 幼い子どもならいつから食べなくなったか、普段と何が違うかを時刻とともに書く
  • 妊娠の可能性があるなら最終月経の開始日を把握しておくと検査の判断が速くなる
  • ほかの病院ですでに検査を受けているならその結果と時刻もあわせて伝える

10. まとめ - この記事が残したい一行

虫垂炎についてもっとも多く検索される問いは「これは盲腸ですか」である。ところが資料をたどると、その問いに自宅で答えるのがなぜ難しいのかがかえってはっきりする。検査設備のある病院でも単一の検査で確定せず、典型的な順番を踏まない患者が3分の1に達し、例外が集まる対象がよりによって小児・高齢者・妊婦である。

  • 知っておくべきは病名ではなく受診の時機である
  • 1節の徴候がひとつでもあるなら自分で絞り込もうとするのをやめる
  • 痛みが急に楽になったことは安心の根拠ではない
  • 受診を早めるもっとも実用的な準備はいつから、どこが、どう変わったかを書いていくことである

もう一度の免責。この記事は情報提供を目的として書かれており、医学的な診断や治療の代わりにはならない。個々の症状についての判断と、薬や手術に関する決定は必ず医療者と相談すること。緊急と判断したなら韓国では119または最寄りの救急外来を利用し、国外では現地の救急番号を利用する。

# 虫垂炎 — 救急外来を判断するためのメモと受診準備シート

出典: braindetox.kr — 虫垂炎の初期症状と対応
根拠: 韓国疾病管理庁 国家健康情報ポータル「急性虫垂炎」 · NHS Appendicitis · MedlinePlus Appendicitis · NIH NIDDK Appendicitis (いずれも2026-07-31確認)

注意: この文書は情報提供が目的であり、診療の代わりにはならない。自己診断のための道具ではない。
判断は医療者のものであり、このメモの目的は受診の時機を逃さないことだけである。

## 0. このメモの使い方

- ここにある表は「虫垂炎かどうかを見分ける道具」ではない。受診を早めるためのメモである。
- 下の徴候がひとつでも当てはまるなら、自分で見分けようとするのをやめて医療者に委ねる。
- 韓国の救急通報・相談番号は119である。119は通報の受付と出動だけでなく、相談と搬送先病院の案内まで担う。
- 韓国以外にいるなら、その国の救急番号を使う。韓国の番号は国外では通じない。
- 最寄りの救急外来の場所は、具合が悪くなる前に調べておく。痛くなってから探し始めると遅い。

## 1. ためらわず救急外来へ — ひとつでも当てはまるなら

- [ ] 腹痛が強い
- [ ] 痛みが時間とともに悪化する、あるいは消えない
- [ ] へその周りで始まった痛みが右下腹部へ移った
- [ ] おなかを押して離すときにより痛い
- [ ] 歩く、咳をする、くしゃみをする、深く息を吸うと痛みが強まる
- [ ] 発熱がある
- [ ] 嘔吐が続き、何も飲み込めない
- [ ] 痛みが右下腹部を越えて腹部全体に広がった
- [ ] 痛みが一度和らいでから、再びはるかに強くなった

## 2. ただちに救急要請 — この三つのいずれかが見えたら

- [ ] 意識がもうろうとする、話がはっきりしない、人が分からない
- [ ] 皮膚がまだらになる、あるいは普段より青白い
- [ ] 息がしづらい

NHSはこの三つを敗血症の徴候として挙げ、ただちに救急番号へ連絡するよう案内している。

## 3. 症状が軽くても軽く見てはいけない場合

- 小児 — 初期にしきりに眠たがり、刺激に敏感になり、食欲が落ちてから急速に進む経過が報告されている
- 高齢者 — 典型的な症状が現れないことが多く、経過が速く、合併症が生じやすい
- 妊娠中 — 妊娠が進むと虫垂が上へ押し上げられ、痛む場所が変わりうる
- すでに鎮痛薬を飲んだ場合 — 薬の名前と時刻をそのまま医療者に伝える

## 4. 受診時に伝える情報 — あらかじめ書いておく

| 項目 | 書くこと | 記入例 |
| --- | --- | --- |
| 発症時刻 | 最初に異変を感じた日付と時刻 | 昨夜8時ごろ |
| 最初の場所 | はじめに痛かった場所 | みぞおちとへその間 |
| 現在の場所 | いま最も痛い場所 | 右下腹部 |
| 移動の有無 | 場所が移ったか、いつ | 今日の午前3時ごろ移動 |
| 強さの変化 | 時間とともに強まるか弱まるか | ずっと強まる、一度和らいで再び悪化 |
| 悪化要因 | 何をすると痛いか | 歩くとき、咳をするとき |
| 併発症状 | 発熱、悪寒、吐き気、嘔吐、下痢、便秘、排尿の変化 | 微熱、嘔吐2回 |
| 最後の食事 | 何をいつ食べたか | 昨夜7時に食事、以後は水のみ |
| 最後の排便 | 時刻と性状 | 今朝、軟便 |
| 服用した薬 | 名前と時刻。鎮痛薬、解熱薬、制酸薬、消化薬すべて | 今日の午前1時に鎮痛薬1錠 |
| 基礎疾患 | いま治療中の病気と過去の手術 | なし、または病名 |
| アレルギー | 薬物アレルギー | なし、または薬の名前 |
| 妊娠の可能性 | 最終月経の開始日 | 日付 |

## 5. 紛らわしいもの — 見分けるためではなく、受診が必要な理由として

| 重なる病態 | どこが似ているか | なぜ自分では分けられないか |
| --- | --- | --- |
| 胃腸炎 | 腹痛、吐き気、嘔吐、下痢、微熱が同時に出る | 虫垂炎の初期にも下痢や嘔吐が出うる |
| 便秘 | おなかが重く、排便すれば楽になりそうに感じる | 排便で楽になりそうな感覚は虫垂炎でも報告されている |
| 尿路結石 | 側腹部と下腹部の痛み、強い痛み | 尿検査などで除外の過程を経る対象である |
| 婦人科の病態 | 下腹部という場所が重なる | 骨盤内炎症性疾患が鑑別に含まれ、妊娠反応検査も併用される |
| 腸閉塞、炎症性腸疾患、腹腔内癒着 | 腹痛と排便の異常 | いずれも鑑別に挙がり、画像検査が必要である |

## 6. してはいけないこと

- 鎮痛薬を飲んで様子を見ること — 飲んだなら必ず伝える。飲むかどうかを自分で決めず医療者と相談する
- 抗菌薬を自分で手に入れて飲むこと — 治療方針は診察と検査のあとに決まる
- 民間療法や食事療法で治めようとすること — 炎症を起こした虫垂がそれで治るという根拠は、確認した資料のどこにもない
- 痛みが急に楽になったからと安心すること — 穿孔したあとに一時的に和らぎ、腹部全体へ広がる経過が報告されている
- ネットの点数表で自分を判定すること — 臨床で使う道具は、腹部を直接診た医療者を前提に作られている
- ひとつの検査結果だけを信じること — NHSは虫垂炎を常に示せる単一の検査はないと記している

## 7. 資料に載っている数値 — 出典のまま

以下の値はすべて韓国疾病管理庁 国家健康情報ポータル「急性虫垂炎」(2026-07-31確認)に記載されたものである。
同文書に調査年や対象集団は別途明記されていない。

- 症状があいまいな患者が全体の3分の1に達する
- 虫垂閉塞の原因は、周囲のリンパ組織の過剰増殖が60パーセント、硬い便が35パーセントと記されている
- 10代から20代に多く、20代前半が最も多い
- 10歳未満または50歳以上の患者は全体の約10パーセントを占める
- 全体の穿孔率は約25パーセント、10歳未満は35から60パーセント、50歳以上は60から75パーセントと記されている
- 非穿孔性虫垂炎では5パーセントに合併症が生じ、組織壊死や穿孔があると30パーセントに達することもある
- 多くの患者は症状発現後12時間から18時間以内に医療機関を受診する

MedlinePlusは10歳から30歳の人に多いと記している。こちらの文書にも期間や対象集団の明記はない。

## 8. 一行の要約

虫垂炎は自分で見分けられる病気ではない。あいまいな経過が珍しくないため、知っておくべきは病名ではなく受診の時機である。
