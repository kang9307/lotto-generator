Ceph 存储桶监控自动化脚本构建指南

Enterprise Storage Monitoring with Slack Integration

在现代 IT 基础设施中,存储监控是必不可少的运维要素。尤其是在像 Ceph 这样的分布式存储系统中,需要实时跟踪各个存储桶的容量和对象数量,以便进行容量规划和性能优化。

🔧 核心脚本解析

下面我们来看一下存储桶监控脚本的核心组成部分:

1. 基础配置与变量定义

#!/bin/bash

# Slack webhook URL (示例)
SLACK_WEBHOOK_URL="https://hooks.slack.com/services/EXAMPLE/WEBHOOK/URL"

# 当前日期和时间
EXECUTION_TIME=$(date)

# 历史统计文件路径
STATS_FILE="/tmp/bucket_stats.txt"

# 要监控的存储桶名称 (示例)
BUCKET_NAME="my-data-bucket"

2. 获取存储桶信息

# 获取存储桶容量和对象数量
BUCKET_INFO=$(radosgw-admin bucket stats --bucket=${BUCKET_NAME})

BUCKET_SIZE=$(echo "$BUCKET_INFO" | jq -r '.usage."rgw.main".size')
BUCKET_NUM_OBJECTS=$(echo "$BUCKET_INFO" | jq -r '.usage."rgw.main".num_objects')

💡 Pro Tip

radosgw-admin 命令是 Ceph Object Gateway 的管理工具,能够以 JSON 格式输出存储桶的详细统计信息。通过 jq 可以只提取需要的字段。

3. 数据格式化函数

# 转换为易读的单位
function human_readable_size() {
  local size=$1

  if ! [[ "$size" =~ ^[0-9]+$ ]]; then
    echo "0 Bytes"
    return
  fi

  local result=$(awk -v size="$size" '
  BEGIN {
    units[0] = "Bytes"; units[1] = "KB"; units[2] = "MB"
    units[3] = "GB"; units[4] = "TB"; units[5] = "PB"

    i = 0
    while (size >= 1000 && i < 5) {
      size = size / 1000
      i++
    }

    if (i == 0) {
      printf "%.0f %s", size, units[i]
    } else {
      printf "%.2f %s", size, units[i]
    }
  }')

  echo "$result"
}

4. 变化量计算

# 统计计算函数
function calculate_change() {
  local current=$1
  local previous=$2

  if ! [[ "$current" =~ ^[0-9]+$ ]] || ! [[ "$previous" =~ ^[0-9]+$ ]] || [ "$previous" -eq 0 ]; then
    echo "N/A"
    return
  fi

  local change=$((current - previous))
  local percentage=$(awk -v curr="$current" -v prev="$previous" 'BEGIN { printf "%.2f", ((curr - prev) / prev) * 100 }')

  if [ "$change" -gt 0 ]; then
    echo "+$(add_commas $change) (+${percentage}%)"
  elif [ "$change" -lt 0 ]; then
    echo "$(add_commas $change) (${percentage}%)"
  else
    echo "无变化 (0%)"
  fi
}

✅ 优点

  • 与上一次数据进行比较,自动计算增减率
  • 同时显示百分比和绝对值
  • 数字带逗号分隔,提升可读性
  • 处理异常情况(避免除以零)

📊 Slack 告警实现

下面是将收集到的数据发送到 Slack 的部分:

# 准备消息文本
MESSAGE_TEXT="🕒 执行时间: ${EXECUTION_TIME}

=========== 存储桶信息 ===========
- 存储桶名称: ${BUCKET_NAME}
- 容量: ${BUCKET_SIZE_HUMAN} (${BUCKET_SIZE_COMMA} Bytes)
- 对象数量: ${BUCKET_NUM_OBJECTS_COMMA}"

# 追加统计信息
if [ -n "$SIZE_CHANGE" ] && [ -n "$OBJECTS_CHANGE" ]; then
    MESSAGE_TEXT="${MESSAGE_TEXT}

========== 与上次对比 ==========
- 上次测量时间: ${PREV_TIME}
- 容量变化: ${SIZE_CHANGE}
- 对象变化: ${OBJECTS_CHANGE}"
fi

# 生成 JSON payload
PAYLOAD="{
  \"text\": \"\`\`\`${MESSAGE_TEXT_ESCAPED}\`\`\`\"
}"

# 发送 Slack 消息
curl -X POST -H 'Content-type: application/json' --data "$PAYLOAD" $SLACK_WEBHOOK_URL
