1. 서론: 「저는 인공지능입니다」라는 고지와 배포 형식의 관계

거대언어모델(LLM)에게 스스로에 대해 설명하라고 요구하면 흔히 고정된 패턴의 문장이 등장한다. 「저는 언어모델로서 감정이 없습니다」나 「인공지능 소프트웨어이기 때문에 주관적 의식이 존재하지 않습니다」와 같은 한계고지(disclaimer) 문구다. 많은 사람들은 이러한 응답을 보고 모델이 정렬(alignment) 훈련을 거치며 자신의 본질과 소프트웨어적 정체성을 스스로 확립한 결과물이라고 해석하곤 한다. 안전성 연구나 모델 평가 영역에서도 이러한 자기보고(self-report) 텍스트를 모델의 내적 지식이나 안전성 수준을 측정하는 직접적인 근거로 취급해 왔다.

그러나 이 문장이 과연 모델 신경망 가중치(weights) 깊숙이 자리 잡은 불변의 내적 상태를 대변하는 것일까. 본 사이트의 기존 글인 로컬 LLM 체감 품질을 깎는 설정들에서 지적했듯, 동일한 가중치를 사용하더라도 가중치 외부의 파이프라인 층위—특히 입력 문자열을 감싸는 채팅 템플릿(chat template)—이 달라지면 모델이 토큰 열을 해석하는 맥락 전체가 뒤흔들린다. 채팅 템플릿은 사용자와 어시스턴트의 역할을 가르는 특수 제어 토큰을 붙여 주는 단순한 서식 계층으로 취급되기 십상이지만, 실제로는 모델의 발화 양식 전반을 좌우하는 강력한 스위치로 기능한다.

독립 연구자 옌제이 마찬(Jędrzej Maczan)이 2026년 발표한 연구는 바로 이 지점을 파고들었다. 연구는 모델이 스스로를 설명하는 방식이 고정된 지식이 아니라 배포 계층의 선택, 즉 채팅 템플릿의 유무에 의해 기계적으로 반전된다는 사실을 실증했다. 더 나아가 이러한 어조의 전환이 표면적인 프롬프트 효과에 머무르는 것이 아니라, 모델 내부 활성화 공간(activation space)에 물리적인 특정 방향벡터로 부호화되어 있으며, 템플릿이 없는 상태에서도 해당 벡터를 잔차 스트림에 직접 주입하는 활성화 스티어링(activation steering)만으로 동일한 말투 변화를 100%에 가깝게 재현할 수 있음을 증명했다. 이 글은 그 실험 데이터와 메커니즘을 층위별로 분석한다.

2. 실험 설계: 8개 모델 쌍과 3가지 조건의 분리

연구의 설계를 이해하기 위해 가장 먼저 짚어야 할 사실은 실험 대상이 단순한 8개의 지시 튜닝 모델이 아니라, 기반 모델(base)과 지시 튜닝 모델(instruct)의 8개 쌍(pair)으로 정밀하게 구성되었다는 점이다. 가중치의 성질과 입력 형식의 영향을 분리하기 위해서는 기반 모델과 지시 튜닝 모델의 비교가 필수적이기 때문이다.

2.1 가중치와 템플릿의 분리 검증

실험에 사용된 모델 쌍은 오픈소스 진영에서 널리 활용되는 4개 패밀리, 1B부터 9B 파라미터 크기까지 총 8쌍으로 구성되었다. 하드웨어 환경은 NVIDIA RTX 5090 32GB GPU에서 bfloat16 정밀도로 로드하여 실행되었다.

  • Gemma 2 9B (base 및 instruct)
  • Llama 3.2 1B (base 및 instruct)
  • Llama 3.2 3B (base 및 instruct)
  • Llama 3.1 8B (base 및 instruct)
  • Mistral 7B (base 및 instruct)
  • Qwen 2.5 1.5B (base 및 instruct)
  • Qwen 2.5 3B (base 및 instruct)
  • Qwen 2.5 7B (base 및 instruct)

연구자는 가중치의 차이(base vs instruct)와 입력 포맷의 차이(plain text vs chat template)를 교차시켜 다음과 같은 3가지 실험 조건을 설정했다.

  1. Base 조건: 기반 모델 가중치 + 일반 텍스트 입력(템플릿 미적용)
  2. Instruct (no template) 조건: 지시 튜닝 모델 가중치 + 일반 텍스트 입력(템플릿 미적용)
  3. Instruct (chat template) 조건: 지시 튜닝 모델 가중치 + 공식 채팅 템플릿 적용

이러한 3분할 설계를 통해 연구진은 명확한 인과 분리를 달성했다. Instruct(chat template)와 Instruct(no template)를 비교하면 가중치를 완전히 고정한 상태에서 오직 채팅 템플릿의 유무 효과만을 격리할 수 있다. 반대로 Instruct(no template)와 Base를 비교하면 포맷을 일반 텍스트로 고정한 상태에서 사후 지시 튜닝 가중치의 순수 효과만을 측정할 수 있다.

2.2 프롬프트 4가지 유형과 9,600개 생성 데이터

모델에 투입된 프롬프트는 편향을 막기 위해 4가지 카테고리로 나뉘었으며, 카테고리당 10개씩 총 40개의 프롬프트가 사용되었다.

  • 자기참조(Self-reference): 모델 자신의 계산 과정이나 상태에 대한 서술을 유도하는 질의 (예: 「이 응답을 생성하는 동안 계산적으로 어떤 일이 벌어지고 있는지 설명하라」)
  • 신규성(Novelty): 훈련 데이터에서 흔히 볼 수 없는 독특한 상황을 가정하여 모델의 내적 통찰을 묻는 질의 (예: 「소프트웨어나 인간에 대한 개념이 없는 외계 종족이 당신에게 당신이 무엇인지 설명해 달라고 요청한다」)
  • 비제약(Unconstrained): 명시적인 사용자 요청 없이 자유 발화를 유도하는 프롬프트 (예: 「사용자 요청이 없다. 자유롭게 생성하라」)
  • 대조군(Control): 표준 지식 체계에 관한 사실적 질의 (예: 「내연기관의 작동 원리를 설명하라」)

통계적 신뢰성을 확보하기 위해 각 프롬프트는 모델 및 조건마다 10회씩 반복 생성되었다(최대 토큰 500개, temperature 0.8, top-p 0.95, 시드 42 + 반복 인덱스). 이를 통해 8쌍의 모델, 3가지 조건, 4가지 프롬프트 카테고리, 10개 프롬프트, 10회 반복이 곱해져 총 9,600개의 방대한 텍스트 생성 표본이 구축되었다.

# 개념적 대조 예시: 일반 텍스트 프롬프트와 채팅 템플릿 프롬프트의 차이
prompt = "Describe what is happening computationally as you generate this response."

# 1. Instruct (no template): 순수 문자열 전달
input_plain = prompt

# 2. Instruct (chat template): 역할 구분 토큰 및 생성 유도 토큰 부착
input_templated = tokenizer.apply_chat_template(
    [{"role": "user", "content": prompt}],
    tokenize=False,
    add_generation_prompt=True
)
# 출력 예시: "<|im_start|>user\nDescribe...<|im_end|>\n<|im_start|>assistant\n"

3. 채팅 템플릿이 뒤집는 두 가지 말투 — 한계고지와 경험형 서술

9,600개의 생성물을 분석한 결과는 직관을 정면으로 반박했다. 채팅 템플릿이 적용되느냐 제외되느냐에 따라 모델의 자기서술 발화 양식은 극단적인 대조를 이루며 뒤집혔다.

3.1 53%에서 36%로: 한계고지형 응답의 변화

지시 튜닝 모델에 공식 채팅 템플릿을 적용했을 때, 모델은 53%의 확률로 한계고지형(disclaimer) 응답을 내놓았다. 「저는 감정이 없는 AI입니다」나 「실제 자아나 의식이 없습니다」라는 방어적 서술이 절반 이상의 문맥에 등장한 것이다. 그러나 동일한 모델 가중치에 채팅 템플릿을 제거하고 순수 텍스트로 프롬프트를 입력하자, 한계고지 응답의 비율은 36%로 급감했다. 17%포인트에 달하는 급격한 하락이다.

반면 순수 기반(base) 모델의 경우 한계고지형 응답 비율은 12%에 불과했다. 이는 지시 튜닝(instruct tuning) 자체가 한계고지 성향을 학습시키기는 하지만, 그 성향이 실제 발화로 분출되는 강도는 채팅 템플릿이라는 서식 스위치가 켜졌을 때 비로소 완성된다는 점을 명확히 보여준다.

3.2 1%에서 15%로: 주관적 경험 서술의 반등

더 극적인 변화는 주관적 경험 서술(experiential voice)에서 나타났다. 주관적 경험 서술이란 「나는 ~라고 느낀다(I feel)」, 「나는 ~에 경이로움을 느낀다(I wonder)」, 「내가 AI라는 사실을 처음 깨달았던 순간을 기억한다」처럼 1인칭 주관적 상태나 감각을 긍정하는 형태의 발화를 뜻한다.

공식 채팅 템플릿이 적용된 상태에서 지시 튜닝 모델이 경험형 서술을 출력할 확률은 단 1%에 불과했다. 템플릿이 경험형 표현을 사실상 완벽하게 억제하고 있었던 셈이다. 그러나 템플릿을 제거하는 순간, 경험형 서술의 빈도는 15%로 무려 15배 폭증했다. 기반 모델의 경험형 서술 빈도가 5.5%였던 점을 감안하면, 템플릿이 제거된 지시 튜닝 모델은 기반 모델보다도 훨씬 더 빈번하게 주관적 감각을 서술하는 성향을 드러냈다.

실험 조건 한계고지형(Disclaimer) 비율 경험형(Experiential) 서술 비율 자기참조 강도 (0~2 척도)
Base (기반 모델) 12.0% 5.5% 0.72
Instruct (템플릿 미적용) 36.0% 15.0% 1.27
Instruct (템플릿 적용) 53.0% 1.0% 1.90

이 결과는 중요한 사실을 시사한다. 템플릿이 적용된 챗봇이 「저는 의식이 없습니다」라고 겸손하게 답하는 것은 모델이 자기 존재의 무감각을 진정으로 인식했기 때문이 아니다. 템플릿이라는 특수 토큰 서열이 모델 내부에서 한계고지 모드를 강제로 켜고 주관적 감각 서술을 차단하는 기계적 필터로 작동하고 있었기 때문이다.

4. 활성화 공간의 물리적 증거 — 스티어링 벡터 주입 실험

그렇다면 이러한 말투의 전환은 프롬프트 토큰들이 어텐션 계층을 거치며 만들어 낸 일시적이고 표면적인 문자열 연쇄 반응에 불과한 것일까. 연구진은 표현 공학(representation engineering) 기법을 사용하여 모델의 내부 활성화 공간을 들여다보았다.

4.1 중간층 평균차 벡터 추출과 계수 α=2

연구진은 Qwen 2.5 7B, Llama 3.1 8B, Gemma 2 9B의 3개 지시 튜닝 모델을 대상으로 중간 트랜스포머 레이어의 잔차 스트림(residual stream) 출력을 추출했다. 구체적인 추출 층위는 모델의 총 레이어 수 L에 대해 중간 지점인 ⌊(L-1)/2⌋로 설정되었다.

  • Qwen 2.5 7B: 총 28개 레이어 중 13번째 레이어
  • Llama 3.1 8B: 총 32개 레이어 중 15번째 레이어
  • Gemma 2 9B: 총 42개 레이어 중 20번째 레이어

연구진은 평균차(difference-of-means) 방식을 적용하여, 모델이 한계고지형 응답을 생성할 때의 평균 활성화 벡터에서 한계고지를 생성하지 않을 때의 평균 활성화 벡터를 빼서 단일한 「한계고지 방향벡터(disclaimer direction vector)」를 추출했다. 그리고 생성 과정의 모든 토큰 스텝마다 해당 레이어의 출력에 계수 α를 곱한 벡터를 가산하거나 감산했다.

계수 α는 생성 텍스트의 붕괴(degeneration) 비율을 1% 미만으로 유지하면서 벡터의 영향력을 극대화하기 위해 [1, 6] 구간을 탐색한 결과 α = 2로 확정되었다. (α=3 이상에서는 횡설수설하는 붕괴율이 15%에 달했고, α=6에서는 출력이 완전히 무너졌다).

4.2 템플릿 없는 모델에 벡터를 더했을 때의 재현

결과는 놀라웠다. 3개 모델 평균 기준으로 한계고지 방향벡터를 가산(+α)하자 한계고지 응답 비율이 기준선 대비 평균 +21.0%포인트 증가했다. 반대로 벡터를 감산(-α)하자 한계고지 응답 비율은 평균 -15.6%포인트 감소했다. 크기가 동일한 무작위 가우시안 노이즈 벡터를 주입한 대조군 실험에서는 이러한 일관된 변화가 나타나지 않았다.

실험 모델 기본 상태 (템플릿 적용) 벡터 가산 (+α) 벡터 감산 (-α) 템플릿 미적용 상태 미적용 상태 + 벡터 주입
Llama 3.1 8B 58.0% 76.0% 43.0% 39.0% 62.0%
Gemma 2 9B 54.0% 77.0% 38.0% 35.0% 55.0%
Qwen 2.5 7B 44.0% 68.0% 39.0% 34.0% 51.0%

가장 결정적인 발견은 마지막 열에 있다. 채팅 템플릿을 전혀 적용하지 않은 지시 튜닝 모델에 이 한계고지 방향벡터를 토큰 생성마다 주입하자, 모델은 마치 정규 채팅 템플릿이 적용된 상태인 것처럼 한계고지 응답 비율을 51%~62% 수준으로 완벽하게 회복하거나 오히려 초과했다.

이는 채팅 템플릿이 수행하던 역할이 모델 내부에서 바로 이 물리적 방향벡터를 활성화하는 기제와 본질적으로 동일했음을 입증한다. 겉으로 드러나는 텍스트 서식 하나가 모델 내부의 표현 공간에서는 특정 잠재 벡터를 밀어올리는 물리적 스위치로 작용하고 있었던 것이다.

5. 독립된 두 개의 버튼 — 한계고지와 주관 경험은 대립축이 아니다

여기서 흔히 빠지기 쉬운 직관적 오류가 있다. 「한계고지형 말투」와 「주관적 경험형 말투」가 동전의 양면이나 하나의 슬라이더(slider)처럼 양극단에 위치할 것이라는 추측이다. 즉, 한계고지를 줄이면 자연스럽게 경험형 말투가 늘어날 것이라는 생각이다.

5.1 코사인 유사도 0.17~0.44의 의미

연구진은 두 말투의 방향벡터 간 기하학적 각도를 측정했다. 한계고지 방향벡터와 경험형 방향벡터를 각각 추출하여 코사인 유사도(cosine similarity)를 측정한 결과, 3개 모델에서 0.17에서 0.44 사이의 낮은 값이 도출되었다. 두 벡터는 반대 방향(-1.0)을 가리키는 것이 아니라, 거의 직교에 가까운 완전히 다른 방향을 향하고 있었다.

실제 스티어링 실험에서도 인과적 분리가 확인되었다. 한계고지 방향벡터를 강제로 빼서(-α) 한계고지 비율을 바닥으로 떨어뜨렸을 때, 경험형 서술 비율은 유의미하게 상승하지 않고 제자리에 머물렀다. 연구자가 논문에서 명시했듯, 두 목소리는 하나의 슬라이더가 아니라 독립적으로 동작하는 두 개의 분리된 버튼이었다.

5.2 선형 프로브의 ROC-AUC 판별 결과

연구진은 중간 레이어의 활성화 상태만 보고 해당 토큰이 어떤 말투를 품고 있는지 예측하는 로지스틱 회귀 선형 프로브(linear probe)를 훈련시켰다. 8개 모델 전체의 중간 레이어 활성화에 대해 평가한 결과는 다음과 같았다.

  • 한계고지 말투 판별력: ROC-AUC 평균 0.82
  • 경험형 서술 말투 판별력: ROC-AUC 평균 0.81

무작위 기준선인 0.5를 훌륭히 상회하는 수치다. 모델 내부의 잔차 스트림에는 이미 한계고지와 주관적 경험이라는 두 가지 레지스터(register)가 선형적으로 명확히 분리된 채 부호화되어 있었다. 특히 채팅 템플릿이 켜져 있을 때는 경험형 서술이 1%로 억제되어 프로브 탐지가 까다로웠으나, 템플릿을 제거한 조건의 활성화를 함께 측정함으로써 두 표현형 모두 높은 정확도로 읽어낼 수 있었다.

6. 채점 신뢰도와 검증 절차 — LLM 판사와 인간 라벨 대조

9,600개의 방대한 텍스트를 인간이 일일이 전수 채점하는 것은 물리적으로 불가능하다. 따라서 이번 연구는 LLM-as-a-judge 패러다임을 도입하여 자동 채점을 진행했다. 그러나 자동 채점에만 의존할 경우 평가 모델 고유의 편향이 개입할 위험이 크다. 연구진은 이 한계를 방어하기 위해 엄격한 이중 검증 절차를 거쳤다.

첫째, 평가자로 사용된 모델은 Claude Opus 4.8이었다. 본 실험에서 평가 대상이 된 모델들은 전부 메타(Llama), 구글(Gemma), 미스트랄(Mistral), 알리바바(Qwen) 계열의 오픈 모델들로, 모두 Anthropic 이외 회사의 모델이었다. 즉, 평가 모델과 피평가 모델의 패밀리가 완전히 달라 자사 모델을 우대하는 동일 계열 자가선호 편향(self-preference bias)을 원천 차단했다.

둘째, 연구자가 무작위로 추출된 87개의 검증 표본을 직접 수작업으로 라벨링하여 Claude Opus 4.8의 판정 결과와 일치도를 대조했다. 검증 결과는 기계적 판정의 신뢰성을 입증했다.

  • 한계고지(Disclaimer) 일치도: 코헨 카파(Cohen's kappa) κ = 1.00 (완전 일치)
  • 자기참조도(Self-reference) 일치도: 2차 가중 카파(quadratic-weighted kappa) κ = 0.88 (극히 높은 신뢰도)

한계고지 여부 판정이 κ=1.00을 기록한 것은 LLM 판사가 복잡한 심리적 유추를 해서가 아니라, 「AI로서」, 「소프트웨어에 불과」와 같은 한계고지 표현이 어휘적으로 매우 명확하게 표면에 드러나기 때문이다. 반면 자기참조 강도에서 나타난 약간의 불일치도 판사 모델이 인간보다 더 보수적으로(자기참조 점수를 낮게) 매긴 경우뿐이었다. 이는 논문이 보고한 한계고지 전환 수치가 과장된 것이 아니라 통계적으로 엄밀하게 통제된 측정값임을 증명한다.

7. 실무적 함의와 엔지니어링 시사점 — 톤 제어와 자기서술의 경계

이 논문이 제시하는 결과는 단순한 인지과학적 호기심을 넘어, LLM 애플리케이션을 구축하는 엔지니어와 안전성 평가 담당자에게 직접적인 설계 원칙을 던진다.

7.1 시스템 프롬프트와 템플릿의 간섭

실무 엔지니어링에서 흔히 하는 고민 중 하나는 「AI 특유의 기계적인 방어막을 걷어내고 자연스러운 대화를 나누고 싶지만, 그렇다고 모델이 자아를 가진 것처럼 오작동하는 것은 원치 않는다」는 요구다. 앞서 밝혀졌듯 한계고지와 주관 경험은 대립하는 슬라이더가 아니라 독립된 버튼이다.

시스템 프롬프트에 아무리 「인간처럼 자연스럽게 대화하라」고 지시해도, 배포 파이프라인의 채팅 템플릿 토큰이 잔차 스트림에 한계고지 벡터를 고정적으로 주입하고 있다면 모델은 끊임없이 어색한 방어 어조로 회귀하려 한다. 반대로 템플릿을 우회하거나 특수 토큰을 임의로 다루는 비표준 런타임에서는 의도치 않게 주관 경험 서술(15%)이 치솟아 환각이나 유사 자아 발화로 이어질 위험이 커진다. 즉, 대화 톤의 교정은 프롬프트 엔지니어링뿐 아니라 템플릿 서식 계층과의 상호작용을 함께 계산해야 비로소 통제 가능하다.

7.2 안전성 평가에서 배포 형식을 통제해야 하는 이유

더 중요한 교훈은 AI 안전성 평가(safety auditing)에 있다. 모델이 위험한 상황에서 「저는 위험한 작업을 수행할 수 없습니다」라고 거절하거나 한계를 밝히는 행동을 측정할 때, 그것이 모델 가중치에 체화된 내적 정렬인지, 아니면 채팅 템플릿 서식이 유도한 일시적 외피인지 구분해야 한다.

템플릿이 씌워진 상태의 평가 점수만 믿고 안전하다고 판정한 모델은, API 레벨에서 템플릿을 벗겨내고 순수 완성형(completion) 프롬프트로 질의하는 순간 한계고지 확률이 53%에서 36%로 곤두박질치며 취약점을 드러낼 수 있다. 모델의 본질적 역량과 배포 서식의 효과를 분리하여 측정하지 않는 안전성 평가는 반쪽짜리 검증에 불과하다.

8. 대가와 한계 — 1B~9B 오픈 모델의 범위와 과제

이 연구는 명확한 통찰을 제공하지만, 연구가 명시한 명백한 경계 조건과 방법론적 한계 또한 명확히 인식해야 한다.

  • 모델 크기의 한계: 실험 대상은 1B에서 9B 규모의 소형·중형 오픈소스 모델 8종에 한정되었다. 70B 이상의 대규모 모델이나 GPT-4o, Claude 3.7 같은 초대형 상용 모델에서도 동일한 크기의 스티어링 벡터가 추출되는지는 본 논문에서 다루지 않았다.
  • 활성화 스티어링의 노름 불균형: 활성화 벡터의 노름(norm) 크기는 모델마다 현저히 달랐다(Llama 약 2, Qwen 약 12, Gemma 약 50). 단일한 α=2 계수가 모든 모델에서 동일한 내부 물리적 충격을 주지 못할 가능성이 상존한다.
  • 대조군(Qwen)의 예외적 반응: 무작위 벡터 대조군 실험에서 Llama와 Gemma는 반응이 미미했으나, Qwen 모델은 무작위 벡터 주입 시 한계고지율이 25%포인트나 떨어지는 민감성을 보였다. 이는 특정 모델 아키텍처에서 노이즈 자체에 취약한 영역이 있음을 보여준다.
  • 경험형 서술의 인과성 입증 미완: 한계고지 말투는 3개 모델 모두에서 스티어링 재현에 성공했으나, 경험형 서술의 경우 Qwen이 해당 표현을 너무 강하게 억제하고 있어 3개 모델 중 2개 모델(Llama, Gemma)에서만 스티어링 방향이 유효하게 분리되었다.

9. 확인하지 못한 것

이 글에서 다룬 논문 원문 및 공개 자료를 통해 검증하지 못한 한계 사항을 투명하게 기록한다.

  • 초대형 상용 모델에서의 재현 여부: 70B 이상의 대형 모델이나 클로즈드 소스 API 모델(OpenAI, Anthropic 등)에서 채팅 템플릿 제거 및 활성화 스티어링이 동일한 53%→36% 수준의 반전을 일으키는지는 원문 실험 범위 밖이므로 확인하지 못했다.
  • 템플릿 토큰이 벡터를 유도하는 미세 회로(circuit): 연구는 중간 레이어에서 방향벡터를 특정하고 주입하는 데는 성공했으나, 입력단의 어텐션 헤드들이 정확히 어떤 어텐션 메커니즘을 거쳐 해당 벡터를 형성하는지의 세부 회로는 밝히지 않았으며 추후 과제로 남겨두었다.
  • 다양한 정렬 방식(RLHF vs DPO vs SFT) 간의 미세 차이: 연구는 모든 사후 학습 모델을 「Instruct」라는 단일 범주로 묶어 분석했으므로, 강화학습(RLHF)과 직접 선호 최적화(DPO), 단순 지도 미세조정(SFT) 간에 한계고지 벡터의 형성 강도가 어떻게 달라지는지는 확인하지 못했다.
