PHP Operators and Control Structures

Operators

PHP offers a wide variety of operators for manipulating variables and values.

Arithmetic Operators

<?php
$a = 10;
$b = 3;

echo $a + $b;  // Addition: 13
echo $a - $b;  // Subtraction: 7
echo $a * $b;  // Multiplication: 30
echo $a / $b;  // Division: 3.3333...
echo $a % $b;  // Modulus: 1
echo $a ** $b; // Exponentiation: 1000 (PHP 5.6+)
?>

Assignment Operators

<?php
$a = 10;      // Basic assignment
$a += 5;      // Same as $a = $a + 5 (result: 15)
$a -= 3;      // Same as $a = $a - 3 (result: 12)
$a *= 2;      // Same as $a = $a * 2 (result: 24)
$a /= 4;      // Same as $a = $a / 4 (result: 6)
$a %= 4;      // Same as $a = $a % 4 (result: 2)
$a **= 3;     // Same as $a = $a ** 3 (result: 8)
?>

String Operators

<?php
$a = "Hello";
$b = " World";

$c = $a . $b;        // String concatenation: "Hello World"
$a .= $b;            // Same as $a = $a . $b: "Hello World"
?>

Comparison Operators

<?php
$a = 10;
$b = 5;
$c = "10";

var_dump($a == $c);   // Loose comparison (value only): bool(true)
var_dump($a === $c);  // Strict comparison (value and type): bool(false)
var_dump($a != $b);   // Loose inequality: bool(true)
var_dump($a !== $c);  // Strict inequality: bool(true)
var_dump($a < $b);    // less than: bool(false)
var_dump($a > $b);    // greater than: bool(true)
var_dump($a <= $b);   // less than or equal to: bool(false)
var_dump($a >= $b);   // greater than or equal to: bool(true)
var_dump($a <=> $b);  // Spaceship operator (PHP 7+): int(1)
                      // Returns 1 if $a > $b, 0 if equal, -1 if less
?>

Increment/Decrement Operators

<?php
$a = 5;

echo $a++;  // Post-increment: prints 5, then $a becomes 6
echo ++$a;  // Pre-increment: $a becomes 7, then prints 7
echo $a--;  // Post-decrement: prints 7, then $a becomes 6
echo --$a;  // Pre-decrement: $a becomes 5, then prints 5
?>

Logical Operators

<?php
$a = true;
$b = false;

var_dump($a && $b);  // AND: bool(false)
var_dump($a || $b);  // OR: bool(true)
var_dump($a and $b); // AND (lower precedence): bool(false)
var_dump($a or $b);  // OR (lower precedence): bool(true)
var_dump(!$a);       // NOT: bool(false)
var_dump($a xor $b); // XOR (exclusive OR): bool(true)
?>

Bitwise Operators

<?php
$a = 5;     // Binary: 101
$b = 3;     // Binary: 011

echo $a & $b;   // Bitwise AND: 1 (binary: 001)
echo $a | $b;   // Bitwise OR: 7 (binary: 111)
echo $a ^ $b;   // Bitwise XOR: 6 (binary: 110)
echo ~$a;       // Bitwise NOT: -6 (binary: ...11010)
echo $a << 1;   // Left shift: 10 (binary: 1010)
echo $a >> 1;   // Right shift: 2 (binary: 10)
?>

Array Operators

<?php
$a = ["name" => "John", "age" => 25];
$b = ["name" => "Mike", "city" => "Seoul"];

$c = $a + $b;  // Union: ["name" => "John", "age" => 25, "city" => "Seoul"]
                // For shared keys, the value from the first array is kept

var_dump($a == $b);   // Checks if the same key/value pairs exist: bool(false)
var_dump($a === $b);  // Checks key/value pairs, order, and types: bool(false)
var_dump($a != $b);   // Checks for different key/value pairs: bool(true)
var_dump($a <> $b);   // Same as $a != $b: bool(true)
var_dump($a !== $b);  // True if any key/value pair, order, or type differs: bool(true)
?>

Ternary Operator

<?php
$age = 20;
$status = ($age >= 18) ? "Adult" : "Minor";  // Adult

// Nested ternary
$age = 65;
$category = ($age < 18) ? "Minor" : (($age < 65) ? "Adult" : "Senior");  // Senior

// Null coalescing operator (PHP 7+)
$username = $_GET["user"] ?? "Guest";  // Assigns "Guest" if $_GET["user"] is null
?>

Type Casting Operators

<?php
$str = "42";
$num = (int)$str;    // String to integer: 42
$float = (float)$str;  // String to float: 42.0
$bool = (bool)$str;    // String to boolean: true
$array = (array)$str;  // String to array: ["42"]
$obj = (object)["name" => "John"];  // Array to object
?>

Operator Precedence

PHP operators have a defined precedence, and you can use parentheses to control it explicitly.

<?php
$result = 5 + 3 * 2;        // 11 (multiplication is evaluated first)
$result = (5 + 3) * 2;      // 16 (parentheses are evaluated first)
$result = 5 + 3 * 2 - 4 / 2; // 9 (5 + 6 - 2 = 9)
?>

Conditional Statements

if Statement

<?php
$age = 18;

if ($age >= 18) {
    echo "You are an adult.";
}

// Braces may be omitted when the body is a single statement
if ($age >= 18)
    echo "You are an adult.";
?>

if-else Statement

<?php
$age = 16;

if ($age >= 18) {
    echo "You are an adult.";
} else {
    echo "You are a minor.";
}
?>

if-elseif-else Statement

<?php
$score = 85;

if ($score >= 90) {
    echo "Grade A";
} elseif ($score >= 80) {
    echo "Grade B";
} elseif ($score >= 70) {
    echo "Grade C";
} elseif ($score >= 60) {
    echo "Grade D";
} else {
    echo "Grade F";
}
?>

switch Statement

<?php
$day = 3;

switch ($day) {
    case 1:
        echo "Monday";
        break;
    case 2:
        echo "Tuesday";
        break;
    case 3:
        echo "Wednesday";
        break;
    case 4:
        echo "Thursday";
        break;
    case 5:
        echo "Friday";
        break;
    case 6:
    case 7:
        echo "Weekend";
        break;
    default:
        echo "Invalid day";
}
?>

match Expression (PHP 8.0+)

<?php
$day = 3;

$dayName = match($day) {
    1 => "Monday",
    2 => "Tuesday",
    3 => "Wednesday",
    4 => "Thursday",
    5 => "Friday",
    6, 7 => "Weekend",
    default => "Invalid day"
};

echo $dayName;  // Wednesday
?>

Conditional Expression with the Ternary Operator

<?php
$age = 20;
$status = ($age >= 18) ? "Adult" : "Minor";
echo $status;  // Adult
?>

Null Coalescing Operator (PHP 7+)

<?php
// Equivalent to isset($_GET["user"]) ? $_GET["user"] : "Guest"
$username = $_GET["user"] ?? "Guest";

// Checking multiple variables
$name = $firstName ?? $lastName ?? "No name";
?>

Null-Safe Operator (PHP 8+)

<?php
$user = null;
$name = $user?->name;  // $name is null if $user is null; no error is raised

$users = null;
$firstUserName = $users[0]?->name;  // null, no error raised

$callback = null;
$result = $callback?->call();  // null, no error raised
?>

Loops

for Loop

<?php
for ($i = 0; $i < 5; $i++) {
    echo "Number: $i<br>";
}
?>

while Loop

<?php
$i = 0;
while ($i < 5) {
    echo "Number: $i<br>";
    $i++;
}
?>

do-while Loop

<?php
$i = 0;
do {
    echo "Number: $i<br>";
    $i++;
} while ($i < 5);
?>

foreach Loop

<?php
$colors = ["red", "green", "blue"];

// Values only
foreach ($colors as $color) {
    echo "$color<br>";
}

// Both keys and values
$person = [
    "name" => "John Doe",
    "age" => 25,
    "city" => "Seoul"
];

foreach ($person as $key => $value) {
    echo "$key: $value<br>";
}
?>

break and continue

<?php
// break example
for ($i = 0; $i < 10; $i++) {
    if ($i == 5) {
        break;  // Exit the loop
    }
    echo $i;  // Prints only 0, 1, 2, 3, 4
}

// continue example
for ($i = 0; $i < 10; $i++) {
    if ($i % 2 == 0) {
        continue;  // Skip the current iteration
    }
    echo $i;  // Prints only 1, 3, 5, 7, 9
}
?>

Nested Loops

<?php
// Print multiplication tables
for ($i = 2; $i <= 9; $i++) {
    echo "Table of $i<br>";
    for ($j = 1; $j <= 9; $j++) {
        echo "$i × $j = " . ($i * $j) . "<br>";
    }
    echo "<br>";
}
?>

Loop Labels and Nested Flow Control

<?php
outer: for ($i = 0; $i < 5; $i++) {
    for ($j = 0; $j < 5; $j++) {
        if ($i * $j > 10) {
            break outer;  // Break out of the outer loop
        }
        echo "($i, $j) = " . ($i * $j) . "<br>";
    }
}
?>

Other Control Structures

require and include

<?php
// If the file is missing, a fatal error is raised (script stops)
require 'header.php';

// If the file is missing, only a warning is raised (script continues)
include 'sidebar.php';

// Includes the file every time, even if it has already been included
require 'config.php';
require 'config.php';  // Executed twice

// Does not include the file again if it has already been included
require_once 'functions.php';
require_once 'functions.php';  // Executed only once

include_once 'footer.php';
include_once 'footer.php';  // Executed only once
?>

goto (PHP 5.3+)

<?php
goto a;
echo "This line will not run.";

a:
echo "Jumped here using a goto statement.";

// Using goto inside a loop
for ($i = 0; $i < 10; $i++) {
    if ($i == 5) {
        goto end;
    }
}

end:
echo "Jumped out of the loop.";
?>

Closures and Anonymous Functions

<?php
// Assign an anonymous function to a variable
$greet = function($name) {
    return "Hello, $name!";
};

echo $greet("John");  // Hello, John!

// Closure (an anonymous function that uses outer variables)
$message = "Nice to meet you";
$greet = function($name) use ($message) {
    return "$message, $name!";
};

echo $greet("John");  // Nice to meet you, John!

// Using with array functions
$numbers = [1, 2, 3, 4, 5];
$doubled = array_map(function($n) {
    return $n * 2;
}, $numbers);  // [2, 4, 6, 8, 10]
?>

Arrow Functions (PHP 7.4+)

<?php
// Traditional anonymous function
$double = function($n) {
    return $n * 2;
};

// Arrow function
$double = fn($n) => $n * 2;

// Arrow functions automatically capture outer variables
$factor = 3;
$triple = fn($n) => $n * $factor;

// Using with array functions
$numbers = [1, 2, 3, 4, 5];
$squared = array_map(fn($n) => $n ** 2, $numbers);  // [1, 4, 9, 16, 25]
?>
