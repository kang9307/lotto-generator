スマートフォン位置追跡ブロック完全ガイド

設定・アプリ権限・広告ID・位置履歴・ストーカーウェア確認まで — 自分のプライバシーを守る実践的方法

2026-06-28 IT・技術

はじめに：GPSだけが問題ではない

スマートフォンを持ち歩くだけで、移動履歴が記録されている。それはGPSだけの話ではない。位置追跡は複数の経路を通じて同時に行われている。このガイドでは各追跡経路を理解した上で、iOSとAndroidで段階的にブロックする方法を解説する。2026年6月時点の最新設定を反映しており、自分自身のプライバシーを守る合法的な方法に焦点を当てている。

注意：このガイドは自身のデバイスと個人情報を保護する目的のみで作成されています。他者の監視を逃れる目的や、第三者の追跡を助ける目的での使用は、関連法律に違反する可能性があります。

1. スマートフォンが位置を把握する仕組み

スマートフォンが位置を特定する方法は主に4つある。

1.1 GPS（衛星測位）

衛星信号を受信して現在地を特定する最も精度の高い方法だ。屋外では数メートルの精度を発揮するが、屋内では弱くなる。GPSをオフにするとこの経路は遮断されるが、他の経路は残る。

1.2 Wi-Fi信号三角測量

周辺のWi-FiルーターのMACアドレスと信号強度をデータベースと照合して位置を推定する。屋内でも機能し、精度は数十〜数百メートル程度だ。重要なのは、Wi-Fiネットワークに接続していなくても、Wi-Fiスキャン機能が有効なら追跡が可能という点だ。

1.3 基地局（セルタワー）測位

携帯キャリアはデバイスがどの基地局に接続しているかを把握し、数ブロック〜数キロメートルの精度で位置を推定できる。SIMカードが入っている限り、キャリアはこの情報を保持する。2026年初頭にAppleは「精密な位置情報を制限」機能を導入し、キャリアが取得できる位置情報の精度を下げられるようになった。

1.4 アプリと広告追跡

位置情報の権限を持つアプリはGPS・Wi-Fi・基地局データを活用して位置を収集する。広告ネットワークは広告識別子（iOSのIDFA、AndroidのGAID）を使って複数のアプリやウェブサイトをまたいでユーザーの行動と移動パターンを追跡し、ターゲット広告に活用する。

2. iOSの位置情報権限管理

iPhoneでの位置追跡管理の中心は設定 → プライバシーとセキュリティ → 位置情報サービスだ。

2.1 アプリごとの権限設定

位置情報サービスの一覧から各アプリのアクセスレベルを設定できる。選択肢は3つだ。

  • 許可しない：アプリが位置情報にアクセスできない。位置情報が不要なアプリにはこれを選ぶ。
  • このAppの使用中のみ許可：アプリが起動中のみアクセス可能。配達・ナビ・天気アプリなどに適切だ。
  • 常に許可：バックグラウンドでも位置情報を収集できる。本当に必要な場合（盗難追跡アプリなど）のみ許可する。
実践のヒント：インストール済みのアプリを全てチェックし、「常に許可」になっているものを「このAppの使用中のみ」または「許可しない」に変更しましょう。バックグラウンドで位置情報が本当に必要なアプリは非常に少ないはずです。

2.2 正確な位置情報をオフにする

iOS 14以降、アプリごとに正確な位置情報（Precise Location）のオン・オフを切り替えられる。オフにすると、アプリは正確な座標ではなく大まかな地区レベルの位置情報しか受け取れなくなる。天気・ニュース・フードデリバリーアプリなど、正確な住所が必須でないアプリには正確な位置情報をオフにするとよい。

2.3 アプリのトラッキングを制限（ATT）

iOS 14.5以降、アプリが他社のアプリやウェブサイトをまたいでユーザーを追跡するには必ず許可を求める必要がある。設定 → プライバシーとセキュリティ → トラッキングで「Appにトラッキングの許可を求めることを許可」をオフにすると、すべてのトラッキング要求が自動的に拒否される。

2.4 キャリアへの精密位置情報を制限（2026年新機能）

2026年初頭にAppleが導入した機能だ。設定 → モバイル通信 → 通信のオプションで「精密な位置情報を制限」をオンにすると、携帯キャリアが把握できる位置情報の精度が下がる。正確な住所ではなく大まかな地区レベルになる。この設定はアプリの位置情報サービスとは別に機能する。

2.5 システムサービスの位置情報を制限

位置情報サービスの最下部にある「システムサービス」から、Appleの内部サービスが位置情報を使う方法を調整できる。「よく利用する場所」（頻繁に訪れる場所の記録）はオフにすることを推奨する。「位置情報に基づくApple広告」と「位置情報に基づく提案」もオフにするとAppleに送られる位置データが減る。

3. Androidの位置情報権限管理

メーカーによってメニューのパスが若干異なるが基本構造は同じだ。設定 → 位置情報で全体を管理する。

3.1 アプリごとの権限設定

設定 → 位置情報 → アプリの権限で各アプリのアクセスレベルを調整する。選択肢はiOSに似ている。

  • 常に許可：バックグラウンドでのアクセスを許可。最小限にすべきだ。
  • アプリ使用中のみ許可：起動中のみアクセス可能。ほとんどのアプリに適切だ。
  • 今回のみ：今回のみ許可し、次回また確認する。
  • 許可しない：位置情報アクセスを完全にブロック。

3.2 正確な位置情報 vs. おおよその位置情報

Android 12以降、アプリへの権限付与時に「正確な位置情報」と「おおよその位置情報」を別々に選択できる。正確な位置情報はGPSレベルの精度、おおよその位置情報は数キロメートルの半径だ。一般的な場所の情報は必要だが正確な住所は不要なアプリには「おおよその位置情報」を選ぶとよい。

3.3 Android 17の位置情報透明性強化（2026年）

2026年にリリースされたAndroid 17では、カメラ・マイクと同様に非システムアプリが位置情報にアクセスすると通知バーに持続的なインジケータが表示されるようになった。また、正確な位置情報とおおよその位置情報の選択UIが視覚的により明確になった。

3.4 Wi-FiスキャンとBluetoothスキャンをオフにする

設定 → 位置情報 → 位置情報サービス（または「位置情報の精度を改善」）でWi-FiスキャンとBluetoothスキャンを無効化できる。これらの機能はWi-FiやBluetoothがオフでも周辺信号をスキャンして位置精度を高めるために使われる。プライバシーを重視するなら両方オフにすることを推奨する。ただし屋内での位置精度がやや低下する場合がある。

3.5 Google位置情報履歴をオフにする

Googleアカウントと連携したAndroidでは、Googleマップのタイムラインに移動経路が記録されることがある。オフにするにはGoogleマップアプリでプロフィール写真 → 「マップ内のあなたのデータ」 → 「位置情報履歴」 → 「オフにする」を選択する。既存の記録も同じメニューから「位置情報履歴をすべて削除」で消せる。

4. 広告識別子（ID）のリセットと削除

広告IDはアプリが複数のサービスをまたいでユーザーを追跡するために使う固有の番号だ。リセットすると既存の行動プロファイルとの紐付けが切れる。

4.1 iOSでの広告識別子リセット

設定 → プライバシーとセキュリティ → Apple広告でパーソナライズド広告をオフにできる。識別子自体をリセットするには設定 → 一般 → 転送またはiPhoneをリセット → リセット → 広告識別子をリセットを選択する。

4.2 Androidでの広告ID削除

設定 → Google → すべてのサービス → 広告で広告IDのリセットまたは削除ができる。Android 14以降では広告IDの削除オプションがあり、削除するとアプリにはIDの代わりにゼロだけの文字列が返され、クロスアプリ追跡が事実上不可能になる。

5. 位置情報履歴の削除

5.1 Googleタイムライン

myaccount.google.com → データとプライバシー → 位置情報履歴から機能をオフにして既存データを削除できる。自動削除期間を3か月または18か月に設定すると古いデータが自動的に消去される。

5.2 Appleよく利用する場所の削除

iPhoneは頻繁に訪れる場所を「よく利用する場所」として保存する。設定 → プライバシーとセキュリティ → 位置情報サービス → システムサービス → よく利用する場所から確認・削除、または機能自体をオフにできる。このデータはデバイス上に暗号化して保存されるが、機能をオフにすれば今後の収集を止められる。

6. ストーカーウェアの確認

ストーカーウェアとは被害者が知らないうちにインストールされ、位置情報・通話・メッセージをリアルタイムで外部に送信する監視アプリだ。親密なパートナーによる暴力、職場での監視、未成年者の無断モニタリングなどの文脈で悪用される事例が報告されている。

6.1 Androidでの確認方法

  • 設定 → アプリ → すべてのアプリでリストを確認し、見慣れない不審なアプリを探す。
  • バッテリー使用量とデータ使用量で異常に多く消費するアプリを確認する。
  • アクセシビリティサービスとデバイス管理者アプリに見知らぬ項目がないか確認する。
  • Google Play プロテクトのスキャンを実行する。
参考：EFF（電子フロンティア財団）のモバイル位置追跡ガイドでは、監視されていると疑う人々に向けた具体的なアドバイスも提供しています。

6.2 iOSでの確認方法

iOSは構造上、脱獄していないデバイスへのサードパーティ製ストーカーウェアのインストールが非常に難しい。ただしApple IDのファミリー共有や「探す」アプリの位置情報共有機能が本人の意図に反してオンになっている場合がある。設定 → [自分の名前] → 探すと設定 → プライバシーとセキュリティ → 位置情報サービスを確認しよう。脱獄したデバイスは例外的に脆弱だ。

6.3 疑いがある場合の最善策

ストーカーウェアが疑われるが特定のアプリを見つけられない場合、初期化（ファクトリーリセット）が最も確実な除去方法だ。事前に写真や連絡先を別途バックアップし、クラウドバックアップに問題のアプリが含まれないよう注意すること。

7. 家族間の位置情報共有の両面

7.1 公式ツールを活用する

Appleファミリー共有とGoogle Family Linkは透明性のある公式ツールだ。位置情報を共有されている側も共有されていることを確認でき、双方が設定を見られるよう設計されている。こうした相互認識の上での位置情報共有と、こっそりインストールする監視アプリは法的・倫理的に明確に異なる。

7.2 年齢に応じた調整

子どもが成長するにつれて位置情報共有の範囲を縮小し、信頼と対話で補っていくことが推奨される。共有を続けるなら、その理由と方法を子どもに率直に伝えることが長期的な信頼関係に良い影響を与える。

8. その他のプライバシー対策

  • Wi-Fi MACアドレスのランダム化：現代のiOSとAndroidはデフォルトでWi-Fiプローブリクエストにランダムなアドレスを使用する。iOS 18以降では約2週間ごとにデバイスのMACアドレスが変わり、商業的なWi-Fi分析システムによる追跡が難しくなる。
  • 信頼できるVPNの使用：VPNはIPアドレスに基づく位置推定を困難にするが、VPN自体がデータを収集する可能性があるため、信頼できるプロバイダを選ぶ必要がある。
  • 不要なアプリの削除：アプリがなければ権限もない。使っていないアプリは削除しよう。
  • オフライン時の機内モード：機内モードはGPS・Wi-Fi・Bluetooth・モバイル通信を全て遮断するが、通信も切れる。
  • ブラウザの位置情報権限管理：ウェブサイトもブラウザ経由で位置情報を要求できる。ブラウザ設定で位置情報を「毎回確認」または「ブロック」に設定しよう。

よくある質問（FAQ）

GPSをオフにすれば位置追跡は完全に止まりますか？

いいえ。Wi-Fi三角測量、Bluetoothビーコン、基地局は引き続き機能します。位置情報サービス自体をオフにし、Wi-FiスキャンとBluetoothスキャンも無効化することで大幅に追跡を制限できます。

「このAppの使用中のみ許可」で十分ですか？

「常に許可」よりはるかに安全で、バックグラウンドでの収集を防ぎます。信頼できないアプリには「許可しない」が最も安全です。

広告IDをリセットするとどんな効果がありますか？

広告ネットワークが蓄積してきた行動・位置プロファイルとデバイスの紐付けが切れます。Android 14以降ではIDを完全削除することでより強力な保護が得られます。

まとめ：優先順位付きアクションリスト

  1. 全アプリの位置情報権限を確認 — 「常に許可」を最小化し「許可しない」を増やす
  2. アプリトラッキングをオフに（iOS：ATT）または広告IDを削除（Android）
  3. Wi-FiスキャンとBluetoothスキャンをオフに（Android）
  4. Googleタイムラインと「よく利用する場所」をオフにし既存記録を削除
  5. iOSシステムサービスの位置情報項目を整理
  6. インストール済みアプリを確認 — 見知らぬアプリを削除

位置情報のプライバシーは一度設定すれば終わりではない。新しいアプリをインストールするたびに権限の要求を注意深く確認し、OSアップデート後に設定が変わっていないか定期的に見直す習慣が重要だ。
