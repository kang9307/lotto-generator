精通ChatGPT - 实战应用策略

Mastering ChatGPT - Practical Usage Strategies

2026-01-22 IT/技术

引言：您真的会用ChatGPT吗？

在第1篇中，我们介绍了提示词工程的基本原则和模式。本篇将聚焦于最常用的AI——ChatGPT，深入探讨实战应用策略。坦白说，如果您只是把ChatGPT当作"搜索替代品"或"简单问答工具"来使用，那么您只发挥了这个工具潜力的10%都不到。

我一开始也是这样。"ChatGPT？不就是有问题就问一下吗？"这是我最初的想法。但当我设置了Custom Instructions、亲手制作了GPTs、并系统性地应用到工作中后，我的想法完全改变了。正确使用的话，它真的能提供私人助理级别的帮助。

ChatGPT的特点与优势

让我们先来整理一下ChatGPT与其他AI工具相比有哪些特点。只有了解工具的特性，才能制定相应的策略。

对话式上下文保持

ChatGPT最大的优势在于它能记住对话上下文。在一次对话会话中，它能记住之前交流的内容，并在此基础上继续对话。善加利用这一点，复杂的项目也可以分阶段推进。

举个例子，假设要撰写一份商业计划书。在第一条消息中说明商业项目和背景，在第二条消息中请求市场分析，在第三条消息中请求财务计划...ChatGPT会持续保持最初说明的商业项目背景，生成一致的内容。

多样的输出格式支持

不仅是文本，还可以获得代码、表格、Markdown、JSON等多种格式的输出结果。特别是要求以代码块形式输出时，会整理成便于复制的形式；要求以表格形式输出时，会生成整洁的Markdown表格。

多模态功能 (GPT-4o)

最新的GPT-4o模型能够理解和分析图像。您可以展示截图并问"这个UI有什么问题？"，上传手写便签照片并说"帮我整理一下"，展示图表并说"分析一下这个数据"等。这个功能确实能大大提高工作效率。

插件与集成功能

ChatGPT Plus用户可以使用网页浏览、代码执行（Code Interpreter）、图像生成（DALL-E）等多种功能。特别是Code Interpreter在数据分析工作中威力巨大。只需上传Excel文件，它就能分析数据并进行可视化。

GPT-4与GPT-4o比较

让我们来了解一下ChatGPT中可选的两个主要模型。根据情况选择不同的模型，输出质量可能会有所不同。

项目 GPT-4 GPT-4o
响应速度 相对较慢 快2倍以上
多模态 以文本为主 图像、语音整合支持
推理能力 优秀 与GPT-4相当或略有提升
成本(API) 相对较高 便宜50%
上下文长度 8K/32K 128K
推荐用途 复杂推理、长文写作 一般对话、图像分析、实时应用

根据我个人的经验，大多数日常工作用GPT-4o就足够了。得益于快速的响应速度，工作流程不会中断，这点很好。不过在非常复杂的逻辑推理或细微语感很重要的写作任务中，GPT-4似乎能给出略好一些的结果。

针对ChatGPT优化的提示词写作方法

在第1篇学到的基本原则之上，我们来添加一些专门针对ChatGPT的技巧。

利用系统消息

在对话开始时用"你是~"这样的角色设定开头，这个角色会在整个对话中保持。善用这一点，就不需要每次都解释背景了。

你是一位有10年经验的UX设计师和可用性专家。
接下来我会给你展示app截图或线框图，
请从可用性角度给出反馈。
反馈请按"优点/改进点/具体建议"的格式整理。

这样开始后，之后只需要上传截图，它就会自动按设定的格式给出反馈。

设计对话流程

复杂的任务不要一次性全部请求，而是设计对话流程。最大限度地利用ChatGPT的上下文保持功能。

[第1步 - 设定背景]
我是一家B2B SaaS创业公司的营销负责人。
我们的产品是中小企业HR管理解决方案，
主要目标客户是50-200人规模企业的人事负责人。
请记住这个背景。

[第2步 - 具体请求]
在这个背景下，请为LinkedIn内容系列做规划。
4周内每周2篇，共8篇内容的主题建议。

[第3步 - 深化]
我喜欢第2个主题。请用这个写一份实际发布的初稿。

[第4步 - 完善]
请改成更轻松的语气。适当加入一些emoji。

使用"Let's think step by step"

让ChatGPT逐步思考可以获得更准确的答案。特别在数学问题或需要逻辑推理的问题上很有效。

请解答以下问题。但不要直接给出答案，
请逐步展示思考过程：

"A公司的销售额比去年增长了20%，
B公司增长了15%。
如果去年A公司的销售额是B公司的80%，
那么今年两家公司的销售额比例是多少？"

提供Few-shot示例

展示几个期望输出的示例，ChatGPT会学习这些模式并产出类似质量的结果。

请按以下格式撰写产品描述。

[示例1]
产品：无线耳机
描述：为日常添加音乐。轻轻戴上，开启属于自己的音轨。
通勤路上变成演唱会现场，咖啡店变成录音室。

[示例2]
产品：智能手表
描述：手腕上的聪明助理。消息、健康、日程一目了然。
忙碌生活中的一瞥就能确认一切。

[请求]
产品：移动电源
请按上述风格撰写产品描述。

使用Custom Instructions

如果您是ChatGPT Plus用户，Custom Instructions是必须设置的功能。这是一个预先设置"关于我的信息"和"期望的回复风格"的功能，会自动应用于所有对话。

Custom Instructions设置位置

点击ChatGPT界面左下角的个人头像，选择"Customize ChatGPT"或"自定义设置"。有两个输入框：

  • What would you like ChatGPT to know about you? - 关于我的信息
  • How would you like ChatGPT to respond? - 期望的回复风格

有效的Custom Instructions示例

关于我的信息（示例）：

我是一名在中国工作的30多岁创业公司营销人员。
- 主要负责B2B SaaS产品的内容营销
- 博客、新闻稿、社交媒体内容制作是主要工作
- 数据分析技能：Excel中级、SQL基础
- 英语阅读可以，但商务英语写作不太熟练
- 总是很忙，重视效率

期望的回复风格（示例）：

- 请用中文回答（如需英文原文请并列）
- 先说重点，补充说明放后面（倒金字塔结构）
- 省略不必要的寒暄和免责声明
- 包含具体示例和行动项
- 使用表格和列表提高可读性
- 长度根据请求决定，默认中等长度
- 优先从营销角度给出实用建议

这样设置好之后，就不需要每次重复说"请用中文回答"、"只说重点"了。特别是在工作中反复使用ChatGPT时，节省时间的效果非常显著。

创建和使用GPTs

GPTs是一种创建针对特定目的定制化ChatGPT版本的功能。不需要复杂的编程，任何人都可以创建，创建好的GPTs可以与团队成员分享或发布到GPT Store。

需要创建GPTs的场景

  • 反复请求类似类型的任务时
  • 需要基于特定文档或数据回答时
  • 需要保持一致的输出格式时
  • 整个团队需要以一致的方式使用AI时

GPTs创建实践

例如，让我们创建一个"博客文章大纲生成器"。

第1步：打开GPTs编辑器

在ChatGPT左侧菜单中点击"Explore GPTs"，然后点击右上角的"+ Create"按钮。

第2步：基本设置

Name：博客大纲大师
Description：生成SEO优化的博客文章大纲。
输入主题后，会建议标题、H2/H3结构和各部分的核心要点。

第3步：撰写Instructions

你是SEO和内容营销专家。
当用户输入博客主题时，按以下格式提供大纲：

1. 标题建议（3个，吸引点击且包含关键词）
2. 元描述（160字以内）
3. 目标关键词（1个主关键词 + 3个次关键词）
4. H2/H3结构（至少5个H2部分）
5. 各部分核心要点（每部分3个要点）
6. 内部链接建议（3个相关主题）
7. CTA（行动号召）建议

大纲总是以表格形式整齐呈现。
用中文回答，使用SEO友好的自然表达。

第4步：上传知识库（可选）

上传公司风格指南、现有博客文章集、目标关键词列表等PDF或文本文件，GPT会参考这些生成更一致的结果。

有用的GPTs应用创意

  • 会议记录整理器：粘贴会议录音内容，生成摘要、行动项、负责人整理
  • 代码审查员：粘贴代码，提供潜在bug、改进点、最佳实践建议
  • 邮件语气调节器：将写好的邮件转换成礼貌/轻松/坚定的语气
  • 面试准备教练：输入应聘公司和职位，提供预期问题和答案指导
  • 数据解读器：粘贴Excel数据，提供洞察和可视化建议

各业务场景的ChatGPT应用示例

现在让我们看看在实际业务场景中如何应用ChatGPT的具体示例。

写作业务

应用场景： 企业博客初稿撰写

请按以下条件撰写企业博客初稿：

主题：远程办公环境下的有效团队沟通
目标读者：创业公司创始人和团队负责人
语气风格：专业又亲切，分享经验的感觉
篇幅：2000字左右
包含内容：
- 远程办公沟通的3个挑战
- 各挑战的实际解决方案和工具推荐
- 自然提及我们公司（协作工具SaaS公司）的产品
- 读者可以立即实践的行动项

文章结构：
1. 吸引人的开头（问题或引起共鸣的情境描述）
2. 正文（问题-解决方案结构）
3. 产品提及（不要像广告一样）
4. 结尾（鼓励 + CTA）

编程业务

应用场景： 现有代码重构请求

请重构以下Python代码。

当前代码：
[粘贴代码]

要求：
1. 遵守PEP 8风格指南
2. 将函数分解成更小的单元
3. 添加类型提示
4. 改进错误处理
5. 添加文档字符串

重构后：
- 对比展示修改前/后的代码
- 解释每个修改"为什么"要这样改
- 如果有其他可改进的地方请提出建议

数据分析业务

应用场景： 营销数据分析（使用Code Interpreter）

[上传Excel文件后]

这是过去6个月的营销活动绩效数据。

请进行以下分析：
1. 按渠道计算和比较ROAS（广告支出回报率）
2. 月度趋势可视化（折线图）
3. 选定TOP 5最佳表现活动的标准和列表
4. 识别成本效益低的活动
5. 下个月预算分配建议

分析结果将在营销团队周会上汇报。
请将洞察整理成非专业人士也能理解的水平。

翻译业务

应用场景： 商务邮件英文翻译

请将以下中文邮件翻译成英文。

原文：
[中文邮件内容]

翻译要求：
- 保持商务正式语气
- 中式表达（如："辛苦了"）要转换成符合英语商务惯例的表达
- 日期/时间转换为美国东部时间(EST)
- 翻译模糊的部分用[原文: ~]标注并提供替代方案

另外：
- 如果有母语者看起来别扭的表达请指出
- 如果有可以改得更专业的句子请提出建议

ChatGPT的局限性和注意事项

要有效利用ChatGPT，也必须清楚了解它的局限性。盲目信任反而可能出问题。

必须核实事实

ChatGPT有时会生成看似合理但实际错误的信息。特别是具体的数字、日期、引用等必须另行验证。我最初也直接使用了ChatGPT提供的统计数据，后来发现要么找不到出处，要么数字不对。

提示： 重要的事实可以问"请告诉我这个信息的来源"。如果ChatGPT不能明确提供来源，就需要自己验证。

最新信息的局限

ChatGPT的训练数据有截止时间。最新新闻、实时股价、最近发布的产品信息等可能不准确。开启网页浏览功能可以在一定程度上弥补，但对于时效性重要的信息仍需另行搜索。

个人信息和机密信息注意

输入到ChatGPT的内容可能被用于模型训练。原则上不要输入公司机密、客户个人信息、敏感商业数据。企业使用建议选择ChatGPT Enterprise或通过API使用。

提示： 在设置中关闭"Chat History & Training"选项可以使对话内容不被用于训练。但这并不是完全的机密保障，敏感信息仍需注意。

创作物的版权问题

AI生成内容的版权问题在法律上尚不明确。建议商业用途的内容不要直接使用AI生成物，而是作为参考资料，由人类进行修改/完善。

警惕过度依赖

过度依赖ChatGPT可能会削弱自己的思考能力和创造力。AI是工具，最终判断和责任在于人类，请不要忘记这一点。特别是在重要决策中，要参考AI输出，但必须加入自己的判断。

总结：ChatGPT应用的下一步

让我们总结一下本文的内容：

  • ChatGPT的优势：上下文保持、多样输出格式、多模态、插件
  • GPT-4和GPT-4o：根据情况选择
  • 提示词优化：角色设定、对话流程设计、step by step、few-shot
  • Custom Instructions：设定关于我的信息 + 期望的回复风格
  • GPTs：为重复任务创建定制化AI
  • 业务应用：写作、编程、分析、翻译等具体示例
  • 注意事项：核实事实、个人信息、警惕过度依赖

ChatGPT的应用没有标准答案。希望您参考本文介绍的方法，找到适合自己的应用方式。重要的是持续实验，将有效的提示词保存下来，逐步完善。

AI工具正在快速发展。今天学到的内容几个月后可能需要更新。但基本原则——清晰沟通、提供背景、具体描述需求的能力——无论什么样的AI出现都将持续有效。
