📖 Cron 특수 文字 가이드

Crontab에서 使用되는 특수 文字들의 의미를 알아보세요.

*

애스터리스크 (*)

의미: 모든 値 (와日드카드)

例: * * * * * = 매分 실행

,

쉼표 (,)

의미: 여러 値 지정

例: 0 9,17 * * * = 오전 9시, 오후 5시

-

하이픈 (-)

의미: 範囲 지정

例: 0 9 * * 1-5 = 평日 오전 9시

/

슬래시 (/)

의미: 간격 지정

例: */15 * * * * = 15分마다

?

물음표 (?)

의미: 무관 (一部 구현에서)

例: 日 또는 요日 필드에서 使用

L

L (Last)

의미: 最後 (확장 cron)

例: 0 0 L * * = 매月 最後 날

📦 백업 작업 스케줄링

매日 새벽 2시 데이터베이스 백업

0 2 * * * /usr/local/bin/backup_db.sh

매日 오전 2시에 데이터베이스 백업 스크립트를 실행합니다.

週말마다 全体 시스템 백업

0 1 * * 0 /usr/local/bin/full_backup.sh

매週 日요日 오전 1시에 全体 시스템 백업을 수행합니다.

📊 시스템 모니터링

5分마다 시스템 상태 체크

*/5 * * * * /usr/local/bin/system_check.sh

5分 간격으로 시스템 상태를 모니터링합니다.

매時間 로그 分석

0 * * * * /usr/local/bin/analyze_logs.sh

매時間 정시에 로그를 分석하여 이상 징후를 탐지합니다.

🔧 시스템 유지보수

매週 화요日 오전 3시 시스템 アップデート

0 3 * * 2 /usr/bin/apt update && /usr/bin/apt upgrade -y

매週 화요日 새벽에 시스템 패키지를 アップデート합니다.

매月 1日 임시 파日 정리

0 4 1 * * /usr/local/bin/cleanup_temp.sh

매月 첫째 날 오전 4시에 임시 파日들을 정리합니다.

📈 보고서 生成

평日 오전 9시 日日 보고서

0 9 * * 1-5 /usr/local/bin/daily_report.sh

평日 오전 9시에 日日 업무 보고서를 자동 生成합니다.

매月 最後 금요日 月간 리포트

0 17 * * 5 [ $(date +\%m) -ne $(date -d '+7 days' +\%m) ] && /usr/local/bin/monthly_report.sh

매月 最後 금요日 오후 5시에 月간 보고서를 生成합니다.

🧹 정리 작업

매日 자정 로그 로테이션

0 0 * * * /usr/sbin/logrotate /etc/logrotate.conf

매日 자정에 로그 파日 로테이션을 수행합니다.

週말 디스크 공간 정리

0 2 * * 6,0 /usr/local/bin/disk_cleanup.sh

週말 새벽 2시에 불필요한 파日을 정리하여 디스크 공간을 확보합니다.

이 포스팅은 쿠팡 파트너스 활동의 日환으로, 이에 따른 日정액의 수수료를 제공받습니다.
