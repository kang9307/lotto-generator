高血圧管理のためのDASH食事療法 完全ガイド:血圧を下げる食事のすべて

はじめに:DASH食事療法とは?

DASH(Dietary Approaches to Stop Hypertension)食事療法は、高血圧を下げるために米国立衛生研究所(NIH)傘下の機関が支援した臨床試験で検証された食事パターンです。米国立心肺血液研究所(NHLBI)は、DASHを「生涯続けられる心臓に優しい食生活をつくる、柔軟でバランスのとれた食事計画」と紹介しています。

高血圧の診療ガイドラインは、体重管理、ナトリウム制限、節酒、運動とともに、DASHのような健康的な食事パターンを生活習慣改善の基本として勧めています。ただし生活習慣の改善は薬物療法と並行するもので、薬の代わりにはなりません。この記事は血圧がどれだけ下がるかを約束しません。

DASH食事療法の科学的根拠

主な研究結果

オリジナルのDASH研究 (1997)

  • 参加者:成人459人。米国の標準的な食事から始め、その後、対照食・果物と野菜の食事・複合食のいずれかに無作為に割り付け
  • 期間:8週間
  • 結果:複合食(果物・野菜・低脂肪乳製品を増やし、飽和脂肪と総脂肪を減らした食事)は、対照食より収縮期血圧が5.5mmHg、拡張期血圧が3.0mmHg低くなりました
  • 高血圧の参加者:収縮期血圧が11.4mmHg、拡張期血圧が5.5mmHg低くなりました

DASH-ナトリウム研究 (2001)

  • 参加者:成人412人。対照食またはDASH食に割り付け、高・中・低のナトリウム水準を各30日間、無作為な順序で摂取
  • ナトリウムだけを減らした場合:高い水準から中間の水準に減らすと、収縮期血圧は対照食で2.1mmHg、DASH食で1.3mmHg下がり、さらに低い水準で追加の低下がみられました
  • DASHと低ナトリウムを併用した場合:ナトリウムが高い対照食と比べ、収縮期血圧が高血圧のない人で7.1mmHg、高血圧のある人で11.5mmHg低くなりました

成分についての説明

NHLBIはDASHの食事を、飽和脂肪とトランス脂肪が少なく、カリウム・カルシウム・マグネシウム・食物繊維・たんぱく質が豊富な食事と説明しています。どの成分が血圧低下にどれだけ寄与するかは、この記事では確認できていないため断定しません。

DASH食事療法の基本原則

基本構成要素

以下のサービング数は、NHLBIが1日2,000kcalを基準に示した値です。1サービングの正確な量はNHLBIの案内表に従ってください。必要なエネルギーは年齢・体格・活動量で異なるため、個人の基準は医療従事者や栄養士と決めるのがよいでしょう。

1. 野菜と果物 (野菜1日4-5サービング、果物1日4-5サービング)

推奨食品:
- 果物:りんご、バナナ、オレンジ、ベリー類、メロン
- 野菜:ブロッコリー、ほうれん草、にんじん、トマト、さつまいも

2. 穀物 (1日6-8サービング、全粒穀物中心)

  • 玄米、オーツ麦、キヌア、全粒粉パン
  • 精製された穀物の代わりに全粒穀物を選ぶ

3. 肉・鶏肉・魚 (1日6サービング以下)

  • 鶏むね肉、魚、豆類、ナッツ類
  • 飽和脂肪の少ないたんぱく質を選ぶ

4. 低脂肪または無脂肪の乳製品 (1日2-3サービング)

  • 低脂肪牛乳、ヨーグルト、チーズ
  • カルシウムとたんぱく質の供給源

5. ナッツ・種子・乾燥豆 (週4-5サービング)

  • アーモンド、くるみ、ひまわりの種
  • 油脂類は1日2-3サービングまで

制限すべき食品

ナトリウム (1日2,300mgが標準目標、1,500mgはより低い目標)

NHLBIは2,300mgを標準目標とし、1日1,500mgなら2,300mgのときより血圧がさらに下がると案内しています。世界保健機関(WHO)は、成人に1日ナトリウム2,000mg(食塩5g)未満を推奨しています。自分に合う目標は医療従事者と決めてください。

高ナトリウム食品:
- 加工肉 (ハム、ソーセージ、ベーコン)
- インスタント食品
- 缶詰製品
- ファストフード
- 過度な塩の使用

飽和脂肪

  • 赤身肉を控える
  • バター、チーズなどの動物性脂肪
  • パーム油、ココナッツオイル

砂糖と甘いもの (NHLBIの基準では週5サービング以下)

  • 砂糖入り飲料
  • お菓子、ケーキ、キャンディ
  • 精製された穀物

段階別DASH食事療法 実践ガイド

以下の段階と週の区切りは、実践を助けるためにこの記事が組んだ例であり、研究で検証されたスケジュールではありません。

ステップ1:現在の食習慣の分析 (1週目)

食事日記をつける

  • すべての飲食物を記録
  • ナトリウム含有量を確認
  • 果物・野菜の摂取量を計算

血圧測定

  • 同じ時間帯・同じ条件で測定
  • 測定回数と目標血圧は医療従事者の案内に従う
  • 記録表をつけて診察時に持参

ステップ2:段階的な変化の開始 (2-4週目)

週ごとの目標例

2週目:
- 果物の摂取量を増やす
- 白米の一部を玄米に置き換える
- 加工食品を減らす

3週目:
- 野菜の摂取量を増やす (毎食2種類以上)
- ナッツのおやつを始める
- 塩とスープの汁の摂取量を減らす

4週目:
- 低脂肪乳製品に切り替える
- 赤身肉を魚・鶏肉に置き換える
- 外食の頻度を減らす

ステップ3:完全なDASH食事療法の適用 (5週目以降)

1日の食事例

以下は構成を示す例です。エネルギーや量は人によって異なるため、そのまま真似せず栄養士と調整してください。

朝食

  • オートミール + バナナ + アーモンド
  • 低脂肪牛乳1カップ
  • ブルーベリー

昼食

  • 玄米ご飯
  • 焼きサーモン (ハーブ味付け)
  • ブロッコリーとにんじんの炒め物
  • サラダ (オリーブオイルドレッシング)

夕食

  • キヌア
  • 鶏むね肉のグリル
  • 焼きさつまいも
  • ほうれん草サラダ

間食

  • ギリシャヨーグルト + いちご
  • またはりんご + アーモンドバター

ナトリウムを減らす実用的な方法

調理法の改善

塩の代わりに使う調味料

  1. ハーブとスパイス

    • バジル、オレガノ、タイム
    • にんにく、しょうが、こしょう
    • パプリカ、クミン、ターメリック

  2. 酸味料の活用

    • レモン、ライムの果汁
    • 酢 (バルサミコ、りんご酢)
    • トマトベースのソース

  3. 天然のうま味

    • 昆布、煮干しのだし
    • きのこのだし
    • 玉ねぎ、セロリのベース

買い物のコツ

ラベルの読み方

  • 製品ラベルのナトリウムmgを、1日の目標と見比べる
  • 「無ナトリウム」「低ナトリウム」といった強調表示の基準は国によって異なるため、この記事では数値を載せません

生鮮食品を優先して選ぶ

  • 加工されていない新鮮な肉・魚
  • 冷凍野菜 (塩を添加していないもの)
  • 缶詰の代わりに新鮮な果物

研究で確認された血圧の変化とその限界

確認されたこと

  • オリジナルのDASH研究(1997):複合食は対照食より収縮期血圧が5.5mmHg、拡張期血圧が3.0mmHg低く、高血圧の参加者では11.4/5.5mmHg低くなりました
  • DASH-ナトリウム研究(2001):DASHと低ナトリウムを併用すると、ナトリウムが高い対照食より収縮期血圧が高血圧のない人で7.1mmHg、ある人で11.5mmHg低くなりました

この記事が数値を載せないこと

  • コレステロール、中性脂肪、糖尿病リスク、減量、認知機能、脳卒中リスクへの効果は、今回の更新で一次情報により確認できなかったため、数値を削除しました
  • 血圧が下がり始める時期や効果が最大になる時期も人によって異なるため、決まった期間は約束しません
  • 研究結果は、食事を提供された参加者グループの平均です。あなた自身の血圧が同じだけ下がるという意味ではありません

実践中によくある困難と解決策

課題1:塩味への渇望

解決策

  1. 段階的な減塩:数週間かけて少しずつ塩を減らす
  2. 味覚の適応期間:新しい味に慣れるまで時間がかかることがあり、期間は人によって異なります
  3. 代替調味料を試す:さまざまなハーブとスパイスを試す

課題2:外食の難しさ

実用的なヒント

レストランでは:
- ドレッシングとソースは別添えで頼む
- 焼き物・蒸し料理を選ぶ
- スープの汁は残す
- 量を調整する (半分を持ち帰る)

課題3:忙しい日常での実践

時間節約の戦略

  1. 週末の食事準備

    • 野菜を切っておく
    • 穀物を先に調理して冷蔵保存
    • たれを作り置きする

  2. 手軽なDASH食品

    • 冷凍の果物と野菜
    • 洗浄済みサラダ
    • 全粒穀物のインスタント製品

特別な状況でのDASH食事療法

以下の3つの場合は、いずれも食事を変える前に担当の医療従事者に相談してください。

糖尿病のある方

炭水化物の管理

  • 果物を食べる時間を分散する
  • 血糖指数の低い果物を選ぶ
  • たんぱく質と一緒に摂る

腎臓病のある方の注意事項

カリウム制限が必要な場合

  • DASHはカリウムの多い食事なので、必ず医師に相談してから実施
  • 高カリウムの果物・野菜を制限するかどうかは医療従事者が判断
  • 定期的な血液検査

妊娠中

自己判断で始めない

  • 妊娠中の血圧管理と食事は産婦人科医に相談
  • 十分なエネルギーと栄養の摂取が優先
  • 血圧が高く出たら、自分で食事を制限せずに受診

長期的な成功のための戦略

習慣形成の方法

段階的に身につける

初期:意識的な努力が必要
中期:少しずつ自然になる
その後:習慣として定着 (かかる期間は人によって異なる)

ご褒美システム

  • 週の目標を達成したら食べ物以外のご褒美
  • 進捗の可視化 (グラフ、アプリ)
  • 家族や友人と一緒に実践

持続可能な実践

柔軟性を持たせる

  • ほとんどの食事でDASHのガイドラインを守る
  • たまの例外は許容する
  • 完璧主義より継続を重視

定期的な点検

  • 血圧測定の頻度は医療従事者の案内に従う
  • 血液検査の頻度も医療従事者と決める
  • 目標は診察のときに一緒に見直す

DASH食事療法 vs その他の食事法

地中海式食事との比較

項目 DASH 地中海式
主な目的 血圧を下げる 心血管の健康
脂肪の摂取 低脂肪が中心 オリーブオイルが豊富
飲酒 減らすかやめるのが望ましい 伝統的な食事には適量が含まれる(飲酒を始めることを勧めるものではない)
穀物 全粒穀物を重視 全粒穀物を含む

低糖質・高脂質食との違い

DASHの特徴

  • 血圧に関する臨床試験の根拠がある
  • 食品群ごとのサービング基準が具体的
  • 低糖質・高脂質食との直接比較の根拠は、今回は確認できなかった

選択基準

  • 高血圧が主な問題:DASHを医療従事者と相談
  • 急ぎで減量したい場合:医師に相談してから決定

よくある質問 (FAQ)

Q1: DASH食事療法の効果はいつから現れますか?

A: 決まった時期はありません。オリジナルの研究は8週間食事を提供して比較したもので、反応は人によって異なります。血圧を定期的に測って記録し、診察のときに確認してください。

Q2: 降圧薬を服用中でもDASH食事療法をしてよいですか?

A: 生活習慣の改善は薬物療法と併用するのが一般的ですが、始める前に医療従事者に相談してください。食事を変えると血圧が変わることがあるので、測定して記録し、薬は医療従事者の指示なしに減らしたりやめたりしないでください。腎臓病がある方やカリウムに影響する薬を服用中の方は、特に先に相談が必要です。

Q3: ナトリウムを急に減らしても問題ありませんか?

A: 最初は味が薄く感じられることがあるので、少しずつ減らすと慣れやすくなります。めまいなどの不調が出たり、心臓・腎臓の病気や利尿薬の服用でナトリウム調整の指示を受けたことがある場合は、医療従事者に相談してください。

Q4: DASH食事療法で減量もできますか?

A: DASHは減量食としてではなく、血圧のための食事パターンとして設計されたものです。この記事は減量幅を約束しません。体重管理が目的なら、エネルギーの基準を医療従事者や栄養士と決めてください。

Q5: 外食の多い会社員でも実践できますか?

A: 工夫できる方法があります。注文時は焼き物や蒸し料理を選び、ソースは別添えで頼み、スープの汁は残し、量を調整してください。

Q6: 費用は高くなりますか?

A: 食材や時期によって異なるため、この記事は節約になるかどうかを断定しません。加工食品や外食を減らし、旬の果物・野菜を活用すれば、負担を調整できます。

まとめ

DASH食事療法は、臨床試験で血圧の低下が確認された食事パターンであり、高血圧管理の生活習慣改善のひとつです。薬物療法の代わりにはならず、効果の大きさは人によって異なります。

実践するときは:

  1. 段階的な変化:急な変化より段階的な適用
  2. 持続可能性:完璧さより継続を重視
  3. 個人に合わせる:自分の状況に合わせて調整
  4. 専門家への相談:定期的に医療従事者に相談

医学的免責事項:本記事は教育および情報提供を目的として作成されたものであり、医学的助言の代わりにはなりません。高血圧やその他の健康上の問題がある場合は、必ず医療従事者にご相談ください。服用中の薬は、医療従事者の指示なしにやめたり減らしたりしないでください。

参考資料

  • 米国立心肺血液研究所(NHLBI) DASH食事プラン - 2,000kcal基準で穀物6~8、野菜4~5、果物4~5、低脂肪乳製品2~3サービング(週にナッツ・種子・乾燥豆4~5、甘いもの5以下)と、ナトリウム2,300mg・1,500mgの基準(2026-09-29確認): nhlbi.nih.gov

  • Sacks ほか、DASH-Sodium臨床試験(N Engl J Med 2001) - 参加者412人、3つのナトリウム水準を各30日摂取、DASHと低ナトリウムの併用で対照食・高ナトリウムより収縮期が7.1mmHg(高血圧なし)・11.5mmHg(高血圧あり)低かったとする抄録(2026-09-29確認): pubmed.ncbi.nlm.nih.gov

# DASH食事療法 実践チェックリスト

基準日: 2026-09-29

この表は本文の事実だけを移したものです。診断や治療の代わりにはならず、服用中の薬は医療従事者の指示なしに減らしたりやめたりしません。

---

## 1. 始める前の確認

| 項目 | はい / いいえ | 該当する場合 |
|---|---|---|
| 降圧薬を服用中か | | 食事を変える前に医療従事者に相談し、薬は自己判断で調整しない |
| 腎臓病があるか | | DASHはカリウムの多い食事なので、医師に相談してから開始 |
| 糖尿病があるか | | 果物の摂り方を医療従事者と調整 |
| 妊娠中か | | 産婦人科医に相談し、自己判断で食事を制限しない |
| 血圧の記録があるか | | 同じ時間帯・同じ条件で測って記録 |

---

## 2. 1日の構成 (NHLBI、2,000kcal基準)

| 食品群 | 目標 |
|---|---|
| 穀物(全粒穀物中心) | 1日6-8サービング |
| 野菜 | 1日4-5サービング |
| 果物 | 1日4-5サービング |
| 低脂肪・無脂肪の乳製品 | 1日2-3サービング |
| 肉・鶏肉・魚 | 1日6サービング以下 |
| 油脂類 | 1日2-3サービング |
| ナッツ・種子・乾燥豆 | 週4-5サービング |
| 甘いもの | 週5サービング以下 |

1サービングの量はNHLBIの案内表に従います。必要なエネルギーは人によって異なります。

---

## 3. ナトリウム基準の比較

| 出典 | 基準 |
|---|---|
| NHLBI | 1日2,300mgが標準目標、1,500mgは血圧をさらに下げると案内 |
| WHO | 成人は1日ナトリウム2,000mg(食塩5g)未満 |
| 韓国高血圧学会2018年ガイドライン(Ewha Med J 2025レビューが引用) | 食塩1日6g未満(ナトリウム約2.4g) |

自分に合う目標は医療従事者と決めます。韓国の最新ガイドライン本文の数値は確認できていません。

---

## 4. 研究で確認された血圧の変化 (集団の平均)

| 研究 | 比較 | 結果(収縮期血圧) |
|---|---|---|
| オリジナルDASH(1997、459人) | 複合食 vs 対照食 | 5.5mmHg低い(高血圧群は11.4mmHg) |
| DASH-ナトリウム(2001、412人) | DASH+低ナトリウム vs 対照食+高ナトリウム | 高血圧なし7.1mmHg、あり11.5mmHg低い |

自分の血圧が同じ幅で下がるという意味ではありません。

---

## 5. 毎週の点検

- [ ] 食事日記をつけた
- [ ] 血圧を同じ条件で測って記録した
- [ ] 塩・スープの汁・加工食品を先週より減らした
- [ ] 野菜・果物・全粒穀物を増やした
- [ ] 外食のときソースを別添えにし、汁を残した
- [ ] 次の診察に記録表を持っていく
