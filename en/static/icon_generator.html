📋 How to Use

  1. Click the icon buttons on each tool to download individually, or click "Download All Icons".
  2. Copy the downloaded files into the static/images/ folder.
  3. File names are set automatically:
    • random_menu_icon_192.png, random_menu_icon_512.png, random_menu_og.png
    • nickname_icon_192.png, nickname_icon_512.png, nickname_og.png
    • age_icon_192.png, age_icon_512.png, age_calculator_og.png
    • char_counter_icon_192.png, char_counter_icon_512.png, char_counter_og.png
    • token_counter_icon_192.png, token_counter_icon_512.png, token_counter_og.png
  4. Push the changes to GitHub to apply them.

FAQ

What can I create with this tool?

It draws PWA icons (192×192, 512×512) and OG images (1200×1200) for the braindetox.kr toolset on a browser canvas, and lets you download each one as a PNG file. Both individual downloads and a download-all option are supported.

Are the images uploaded to a server?

No. Every icon is rendered locally with the browser Canvas API, and the download files are generated inside your browser as well. No data is sent to any server.

Can I upload my own PNG and convert it into icons?

Not in the current version. This tool only generates a predefined set of tool icons and does not offer an upload or conversion feature for user images.
