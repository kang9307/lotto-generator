引言：什么是内容证明？

本文介绍的是韩国的制度。韩国的内容证明（내용증명）是由邮局证明寄件人在何时向收件人寄出了何种内容文书的邮政制度。韩国《邮政法施行规则》将其定义为：以挂号处理为前提，通过邮局窗口或信息通信网，由邮局证明寄件人在何时向收件人寄出了何种内容文书这一事实的特殊处理制度（第25条第1款第4项第1目）。具体处理办法规定在同一规则第46条至第55条。发生法律纠纷时，它是客观留下"我确实已将这些内容通知对方"这一事实的最基本手段。

很多人把内容证明当作单纯的"警告函"，但更重要的是，它能留下意思表示已经到达对方的事实。有相对人的意思表示自到达相对人时起生效（韩国《民法》第111条第1款），因此对于解除合同通知、请求履行债务、拒绝续租、要求修补瑕疵等改变法律关系的通知而言，关键在于证明"已送达"，而不只是"已寄出"。内容证明由邮局证明寄送事实和文书内容，若再加上投递证明，还能证明投递日期和签收人，因此被广泛用于预防纠纷、管理消灭时效和保全证据。

本文依次整理内容证明的法律效力、撰写方法、邮局寄送流程与费用，以及寄出后的应对步骤。费用与规定为2026年9月29日根据韩国邮政事业本部网站和韩国国家法令信息中心的现行条文重新确认的数值。文中的范本仅为示例，如案情复杂或金额较大，寻求专业人士帮助更为稳妥。

1. 内容证明的法律效力与使用案例

1.1 法院认可的证据价值

内容证明本身并不像判决那样可以据以强制执行。但在诉讼中，它是证明通知事实的有力证据。韩国大法院判示："记载催告意思表示的内容证明邮件已寄出且未被退回的，除有特别情况外，应视为于当时送达。"（大法院1997年2月25日宣告96다38322判决）。由于未被退回的内容证明可视为当时已送达，对方仅凭"没有收到"的主张难以推翻。反之，如果因收件人不在等原因被退回，就难以依靠这一推定，因此务必确认是否被退回。

内容证明具有法律意义的典型场景如下。

  • 为中断消灭时效而进行的催告：请求履行的内容证明可能构成韩国《民法》上的"催告"。但韩国《民法》第174条规定，催告后6个月内未进行裁判上的请求、参加破产程序、为和解而传唤、任意出庭、扣押或假扣押、假处分的，不发生时效中断的效力。也就是说，仅凭内容证明并不能确定地中断时效，必须在6个月内采取诉讼、支付命令、假扣押等后续程序。6个月从何时起算可能因案情产生争议，留出余地更为稳妥。
  • 履行迟延的起点：未定履行期限的债务，债务人自收到履行请求时起承担迟延责任（韩国《民法》第387条第2款）。对于这类债务，内容证明送达的时间点可能成为计算迟延损害金的基准。有确定期限的债务，自期限届至时起承担迟延责任（同条第1款）。
  • 证明解除·终止的意思表示：解除或终止以对相对人的意思表示为之（韩国《民法》第543条第1款），以履行迟延为由解除合同时，原则上须先定相当期间催告履行（韩国《民法》第544条）。催告和解除通知何时送达，可以用内容证明留下记录。
  • 具有确定日期的证书：韩国《民法》附则第3条第4款规定，公务机关在私文书上证明某事项并记入的日期为确定日期；邮局会在内容文书上记载寄送年月日及作为内容证明邮件寄送的意旨（《邮政法施行规则》第52条第1款）。在债权转让通知等须有确定日期的证书才能对抗第三人的情形下（韩国《民法》第450条第2款），常使用内容证明，原因即在于此。具体案件是否满足要件，请向专业人士确认。

1.2 5种实际使用案例

实务中常使用内容证明的典型情形如下。

  • 债权催收及借款返还请求：个人之间的借贷还款延迟时，写明本金、利息和还款期限，正式请求履行。此后在申请支付命令或提起民事诉讼时，可作为显示请求经过的材料，也可能具有前述催告的意义。
  • 全租（전세）保证金返还请求：租赁结束后保证金未被返还时，明确留下请求返还的意思。它并非申请租赁权登记命令或提起保证金返还诉讼时法律要求的必经程序，但常被用作证明合同终止和请求返还事实的材料。租赁权登记命令、返还保证等租客一方的完整流程，请参阅租赁保护法·租客权利完全指南。
  • 应对解雇及拖欠工资：劳动者收到解雇通知或工资、离职金被拖欠时，用于要求复职或支付拖欠工资。在向劳动委员会申请救济或向雇佣劳动部投诉时，可作为一并提交的材料。
  • 合同解除及瑕疵担保责任请求：在买卖、承揽、租赁合同中，以对方债务不履行为由解除或终止合同，或就标的物瑕疵请求修补、减价、损害赔偿时使用。
  • 针对网络帖子的删除·赔偿请求：认为自己因社交媒体或网络社区的帖子受到损害时，有时也用来请求删除、更正或损害赔偿。此时同样应避免断定性地指责对方或转述有问题的帖子内容，只写明帖子的位置、时间和请求事项较为稳妥。

2. 内容证明撰写方法 — 实战范本与必备要素

内容证明没有法定的固定格式。不过，韩国《邮政法施行规则》对纸张规格、文字更正方法、姓名和地址的书写设有规定，并规定不受理内容违反公共秩序或善良风俗的文书（第46条第1款）。由于这是可能作为证据使用的文书，应完整写入必备要素，并谨慎选择措辞。

2.1 必须记载的事项

要发挥证据作用，最好写入以下事项。

  • 寄件人信息：准确写明姓名（或法人名称）、地址和联系方式。像居民登录号码这样通知不需要的个人信息，不写更为稳妥。
  • 收件人信息：准确写明姓名（或法人名称）和地址。内容文书原本、副本和信封上记载的寄件人与收件人姓名、地址必须一致（《邮政法施行规则》第51条第1款）。地址错误导致退回时难以证明送达，因此应根据合同、登记事项证明书等依据再次确认。
  • 标题：用一行写明文书目的，如"全租保证金返还请求""借款偿还催告""合同解除通知"等。
  • 正文：按事实经过（何时、何人、何事、如何、为何）、要求事项、履行期限、未履行时拟采取的程序的顺序组织。以客观事实为依据具体书写。
  • 撰写日期：写明年、月、日。公认的基准是邮局记载的寄送年月日，因此撰写日期与实际寄送日期不宜相差太远。
  • 签名或盖章：在原本上写明寄件人姓名并签名或盖章。法人使用法人印章或使用印章。由于副本必须是原本的复印件（第49条第1款），应在原本签名盖章后再复印制作副本。

2.2 有效措辞的技巧

仅满足形式要件并不等于写出了好的内容证明。遵守以下原则，可以在减少不必要争议的同时清楚传达要求。

  • 避免情绪化表达：情绪化、侮辱性的表达可能对寄件人不利，视措辞还可能演变为侮辱或名誉毁损问题。应保持客观、事务性的语气。
  • 明确具体金额与期限：不要写"在相当期间内还款"，而应具体写明，例如"请于○○○○年○月○日前将5,000,000韩元汇入下列账户"。如果是以解除合同为前提的催告，最好给予履行所需的相当期间（韩国《民法》第544条）。
  • 提出法律依据：准确引用相关法律（韩国《民法》《住宅租赁保护法》等）及条文，可使要求的依据更加清楚。与其勉强加入没有把握的条文，不如准确写明事实。
  • 平实地说明后续程序：如实写明拟采取的程序，例如"如期限内未履行，将申请支付命令或提起民事诉讼等法律程序"。夸大的威胁，或以"不付钱就刑事告诉"等方式将要求与刑事程序相交换的措辞，可能引起误解、扩大纠纷，应当避免。
  • 集中于一件事：不要把多个事项混在一份文书中，应按事项分别撰写，使争点清楚。

3. 邮局寄送流程与费用

内容证明必须通过邮局窗口或网上邮局以挂号方式寄出，普通信件或单纯的挂号信无法证明文书内容。事先了解流程和费用，可以避免在窗口重新准备材料。

3.1 准备原本1份和副本2份

在窗口寄送时，需提交内容文书原本及其副本2份（《邮政法施行规则》第48条第1款）。各份文书的用途如下。

  • 原本 — 寄给收件人：邮局核对原本与副本后，在每份上记载寄送年月日、作为内容证明邮件寄送的意旨和邮局名称（第52条第1款），原本由寄件人在经办职员可见之处装入信封并封口（第52条第4款）。
  • 副本1份 — 退还寄件人：领回记载有证明的副本并保管。这是诉讼中要作为证据提交的文书，应另行妥善保管，避免遗失。
  • 副本1份 — 邮局保管：邮局自寄送次日起保管3年（第48条第3款）。寄件人不需要副本的，也可以只提交1份副本（同款但书）。

副本必须是原本的复印件，原本和副本均使用宽210mm、高297mm的纸张制作（第49条第1款）。更正文字时，须在页边或末尾空白处写明"更正""插入"或"删除"字样及字数，并盖章、按指印或签名（第50条第1款）；受理后不得请求变更姓名、地址或更正文字（第50条第3款）。向多人寄送相同内容时，可以使用同文内容证明（第47条）。

自寄送次日起3年内，寄件人或收件人可以向邮局请求查阅副本（第55条）或再证明（第54条），对内容证明邮件的投递证明也可以在同样的3年内于寄送后请求（第59条但书）。由于邮局保管有副本，即使寄件人遗失了自己的副本，在此期间内仍有办法重新取得证明。

3.2 费用（2026年9月29日确认）

内容证明的费用是邮资加上挂号手续费和内容证明手续费。在韩国邮政事业本部网站确认的现行金额如下。

项目金额备注
普通邮资（标准规格，超过5g至25g）500韩元自2026年7月1日起适用。5g以下470韩元，超过25g至50g为520韩元
挂号手续费每件2,400韩元加计于邮资
内容证明手续费副本1页1,300韩元，每超过1页加650韩元加计于邮资及挂号手续费。双面书写按2页计算（施行规则第53条第1款）
投递证明（寄送时·寄送后）每件1,600韩元寄送时申请的投递证明加计于往返邮资及挂号手续费
再证明·查阅副本各为内容证明手续费的一半自寄送次日起3年内请求

按此表计算，A4纸1页的内容证明以25g以下标准信封在窗口寄送时为500韩元＋2,400韩元＋1,300韩元＝4,200韩元；如为2页，内容证明手续费为1,950韩元，合计4,850韩元。寄送时一并申请投递证明会增加1,600韩元，并且按照收费表备注以往返邮资为基准计算，因此合计金额以窗口确认为准。费用会因重量、规格和附加服务而不同，并会不定期调整。

投递证明是由投递邮局证明邮件的投递日期和收件人并通知寄件人的制度（施行规则第25条第1款第4项第3目），投递证明书以邮寄方式送达，寄件人希望时也可以通过电子方式接收（第58条）。即使有前述判例上的推定，在投递日期可能产生争议的案件中，一并申请更有利于证明送达。

3.3 通过网上邮局寄送内容证明

不去邮局，也可以在韩国网上邮局（epost.go.kr）申请内容证明。施行规则将内容证明定义为"通过邮局窗口或信息通信网"寄送的制度，并在2025年8月18日的修订中新设了电子邮件方式内容证明的提交与保管规定。使用流程大致如下。

  • 第1步 — 登录：以会员身份登录网上邮局。身份验证方式按页面提示进行。
  • 第2步 — 选择申请菜单：在内容证明申请菜单中输入寄件人和收件人信息。菜单名称和位置可能随网站改版而变化。
  • 第3步 — 提交文书：在页面上直接撰写文书或以文件形式上传。以电子邮件方式寄送的内容证明，须按照邮政事业本部长的告示提交电子文件形式的内容文书（第48条第1款但书）。
  • 第4步 — 付款与寄送：支付费用后，由邮局负责打印和寄送。根据网上邮局的说明，从申请日起到寄出约需1至3天。
  • 第5步 — 查询与再证明：已寄出的内容证明自受理次日起3年内可在网上邮局免费查询，需要副本再证明时另行申请。

自2026年4月1日起，以电子文件形式提交的内容文书也由邮局自寄送次日起保管3年，该文件与寄给收件人的内容文书视为同一（第48条第4款）。网上申请时收取的制作手续费等详细费用本次未能确认，请在付款页面确认合计金额。

4. 内容证明后的法律应对阶段

内容证明本身并不能终结纠纷，更接近于进入正式法律程序之前的一个阶段。事先了解对方不回应时会接续哪些程序，便于管理期限。

4.1 无回应时申请支付命令

内容证明送达后对方仍不回应也不履行时，首先可以考虑的程序是支付命令（督促程序）。支付命令是法院根据债权人的申请，针对以支付金钱或其他一定数量的替代物、有价证券为目的的请求所发出的命令（韩国《民事诉讼法》第462条）。与普通诉讼相比，其特点如下。

  • 费用：支付命令申请书须粘贴相当于起诉状印花金额十分之一的印花（韩国《民事诉讼等印花法》第7条第2款）。例如请求1,000万韩元时，起诉状印花金额为1,000万韩元×万分之45＋5,000韩元＝5万韩元（同法第2条第1款第2项），因此支付命令的印花金额为5,000韩元。送达费另计。
  • 书面程序：支付命令不经询问债务人即可作出（韩国《民事诉讼法》第467条）。作出决定所需时间因法院情况和送达状况而异。
  • 确定后即为执行依据：未提出异议、撤回异议或驳回异议的决定确定时，支付命令与确定判决具有同等效力（同法第474条）。
  • 提出异议时转入诉讼：债务人自收到支付命令之日起2周内提出异议的，支付命令在该范围内失去效力（第470条第1款），并视为在申请支付命令时已提起诉讼（第472条第2款）。此时须补缴与起诉状印花金额的差额（第473条第1款）。
  • 需要知道对方地址：只有在韩国境内能以公示送达以外的方式送达时，才能作出支付命令（第462条但书）。如果不知道对方地址，这一程序可能并不适合。

支付命令也可以通过韩国法院电子诉讼网站（ecfs.scourt.go.kr）申请，内容证明可作为显示请求经过的附件材料。全租保证金案件从诉讼到强制执行的流程，在全租（전세）保证金返还诉讼 A to Z中有更详细的介绍。

4.2 作为诉前阶段的策略性运用

内容证明既是法律程序的前置阶段，也有以下用途。

  • 协商的契机：收到内容证明的对方有时会主动联系或同意协商。如果在这一阶段达成和解，可以节省诉讼的时间和费用。
  • 确认对方主张：对方对内容证明的答复（回复的内容证明、电子邮件或短信回复）可成为以书面形式记录对方立场的材料。
  • 申请假扣押·假处分的材料：在本案诉讼前申请保全对方财产的假扣押、假处分时，内容证明可作为疏明债权存在及请求经过的材料之一。
  • 与刑事程序的关系：在涉嫌诈骗、侵占等的案件中，内容证明及对方的反应有时会作为参考材料提交。但仅凭不回应或回避并不能认定犯罪，判断由侦查机关和法院作出。
  • 诉讼时作为书证提交：民事诉讼开始后，内容证明作为书证提交，用于证明请求原因事实和履行请求的经过。

结论：有效利用内容证明的5大原则

内容证明是普通人也能自行撰写和寄送的便利法律手段，也是在纠纷中证明通知事实的公信证据。以上内容可归纳为五项原则。

第一，保持基于事实的客观陈述。情绪化表达或夸大主张可能对寄件人不利。第二，写明具体金额、期限和依据，让对方清楚知道应在何时之前做什么。第三，确认收件人的准确地址。一旦被退回就难以依靠送达推定，而且原本、副本和信封上的姓名、地址也必须一致。

第四，如果投递日期可能产生争议，请一并申请投递证明。寄送时申请的手续费为每件1,600韩元，寄送后3年内也可以请求。第五，事先规划后续程序和期限。催告只有在6个月内接续裁判上的请求或扣押、假扣押等，才能维持时效中断的效力，因此要事先确定支付命令、假扣押、本案诉讼的顺序和时间，内容证明才不会流于空话。

本文仅供一般信息参考，不构成法律意见。法律和邮资可能变化，即使是同样的内容证明，法律效果也会因个案事实而不同。如案情复杂或金额较大，请咨询韩国律师、法务士、大韩法律救助公团等专业人士或公共机构。

## 2. 撰写前检查

- [ ] 已根据合同、登记事项证明书等依据再次确认收件人姓名和地址
- [ ] 原本、副本和信封上的寄件人、收件人姓名与地址一致（施行规则第51条）
- [ ] 标题用一行写明目的（例：全租保证金返还请求）
- [ ] 依次写明事实经过、要求事项、金额、履行期限、未履行时拟采取的程序
- [ ] 删除了居民登录号码等通知不需要的个人信息
- [ ] 没有情绪化或侮辱性表达、夸大的威胁，也没有将要求与刑事告诉相交换的措辞
- [ ] 如为以解除为前提的催告，已给予相当的履行期间（韩国《民法》第544条）
- [ ] 一份文书只写一件事

## 3. 窗口办理

- [ ] 使用A4（210mm×297mm）纸张制作（施行规则第49条）
- [ ] 已准备签名盖章的原本1份，以及复印该原本而成的副本2份（第48条、第49条）
- [ ] 如有更正的文字，已在空白处写明"更正""插入""删除"及字数，并盖章、按指印或签名（第50条）
- [ ] 知道受理后不能再修改姓名、地址或文字，已确认最终版本（第50条第3款）
- [ ] 如投递日期可能产生争议，已一并申请投递证明
- [ ] 已将退回的副本（记载证明）另行保管

## 4. 寄出后

- [ ] 已确认是否被退回（被退回则难以依靠送达推定，大法院96다38322）
- [ ] 已在日历上标出催告后6个月届满之日（韩国《民法》第174条）
- [ ] 如对方不回应，已决定何时采取支付命令、假扣押或诉讼中的哪一项
- [ ] 知道对方地址（只能公示送达时不适合支付命令，韩国《民事诉讼法》第462条但书）
- [ ] 如遗失副本，可在寄送次日起3年内请求查阅或再证明
