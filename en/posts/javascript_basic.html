JavaScript Basic Syntax Guide

A quick reference to JavaScript fundamentals

2025-06-01 Dev & Infra

JavaScript is the most widely used programming language in web development. This article walks through the core syntax and key concepts you need to know to get started.

Variable Declaration

In JavaScript, you can declare variables using the var, let, and const keywords.

// var (function scope)
var x = 5;

// let (block scope)
let y = 10;

// const (constant, cannot be reassigned)
const PI = 3.14;

Data Types

JavaScript provides the following basic data types:

  • String: text values
  • Number: numeric values
  • Boolean: logical values (true/false)
  • null: an intentional absence of value
  • undefined: a variable that has not been assigned a value
  • Object: collections of key-value pairs
  • Symbol: a unique and immutable primitive type
let name = "John Doe";  // String
let age = 25;           // Number
let isActive = true;    // Boolean
let user = {            // Object
  name: "John Doe",
  age: 25
};

Functions

Functions are a key concept that improves code reusability.

// Function Declaration
function add(a, b) {
  return a + b;
}

// Function Expression
const multiply = function(a, b) {
  return a * b;
};

// Arrow Function
const divide = (a, b) => a / b;

Arrays and Loops

Arrays and loops let you process collections of data efficiently.

// Array declaration
const fruits = ["apple", "banana", "orange"];

// for loop
for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}

// forEach method
fruits.forEach(fruit => {
  console.log(fruit);
});

// map method (returns a new array)
const fruitLengths = fruits.map(fruit => fruit.length);

Once you have the fundamentals of JavaScript down, you can build a wide range of web applications on top of them.
