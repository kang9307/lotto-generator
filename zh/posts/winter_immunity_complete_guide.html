冬季「免疫力」能说的与不能说的

冬季感冒和流感等呼吸道感染增多，「要提高免疫力」的说法也随之增多。但「免疫力」更像日常用语而不是医学术语，免疫系统是由不同细胞和器官共同运作的复合体系，很难说某一种补充剂或某一种食物「提高」了免疫力。本文不断言「增强免疫力」的功效，而是把已确认的与未确认的内容分开整理。

旧版有补充剂「TOP 7」及每日推荐量，以及「日照减少则维生素D合成减少80%」「睡眠不足5小时感染风险5.5倍」等数字。未能确认出处的数字和功效断言，已在2026年9月29日的更新中删除或弱化。冬季最实际的准备，是确认疫苗接种、洗手、生病时休息，以及了解需要就医的信号。

冬季感染看起来增多的原因：已确认与未确认

冬季呼吸道感染增多很难用单一原因来解释。旧版给下列每个因素都写了具体数字，这次以一手资料确认的范围如下。

因素已确认的内容局限与对旧版的更正
室内接触增多CDC 的预防指引建议减少与患病者的密切接触，并引入新鲜室外空气或净化室内空气。旧版的「飞沫感染概率上升3~5倍」未能找到出处，已删除。
日照减少冬季晒太阳少，维生素D容易不足，这与本站维生素D文章所述一致。「合成量减少80%」已删除，也不断言不足会提高感染风险。
低温、干燥的空气旧版所写「外周血管收缩限制免疫细胞移动」「黏膜干燥使病毒易于侵入」，这次未能确认依据。不作为事实引用，已删除。
运动量减少WHO 建议成人每周至少进行150分钟中等强度身体活动。「NK细胞、T细胞功能下降20~30%」未能找到出处，已删除。

总之，没有确认到可以断言「因为是冬季所以免疫力下降」的依据，接触、通风、疫苗接种这类可以通过行为减少的因素才是实用的对象。

疫苗接种：韩国2026~2027流感季的流感、新冠、肺炎球菌

预防冬季传染病，证据最确立的手段是疫苗接种。以下是韩国疾病管理厅(KDCA)公布的2026~2027流感季国家接种计划，于2026年9月29日确认。旧版的接种时间（「10~11月」）和「预防70~90%」等数字每个流感季都会变化，因此不作为固定数字列出。以下是韩国的制度说明，在其他国家请遵循当地的接种计划。

疫苗国家接种的对象与日程需要确认的地方
流感出生满6个月至14岁（2012.1.1~2026.8.31出生）的儿童、孕妇、65岁以上人群。儿童和孕妇自2026年9月21日起接种，接种期到2027年4月30日。65岁以上人群中，75岁以上自10月12日，70~74岁自10月15日，65~69岁自10月19日起。不在对象范围内则为自费接种。CDC 建议美国6个月以上的所有人每个流感季都接种。
新冠2026年时65岁以上（1961.12.31之前出生）、免疫低下者、感染脆弱机构的住院·入住者。KDCA 预防接种网站写明70岁以上自10月12日、65~69岁自10月15日起，到2027年6月30日。KDCA 新闻稿写的是65岁以上与流感同一日程，自10月12日起，资料之间写法不同。本人的日程请在预防接种网站确认。
肺炎球菌65岁以上成人国家接种（23价多糖疫苗）以1961年12月31日之前出生者为资助对象。已在65岁之后接种过的人，据称无需再次接种。旧版的「慢性病患者为对象」这次未能确认。有慢性病的人请咨询保健所或医护人员。

旧版中带状疱疹疫苗「预防90%以上」的数字这次未能确认，已删除。是否属于对象以及接种记录，请在 KDCA 预防接种网站或保健所确认。

感冒与流感的区分，以及需要就医的信号

CDC 从起病方式和症状强度来比较感冒与流感。以下只是倾向，仅凭症状不能断定是哪种病毒。

项目感冒流感
起病逐渐开始。突然开始。
发热少见。常见，持续3~4天。不过并非所有流感患者都发热。
身体酸痛、肌肉痛轻微。常见，往往较重。

据 CDC，成人每年平均感冒2~3次，因此感冒频繁并不等于免疫力弱。

成人需要立即就医的信号(CDC)

  • 呼吸困难或气短
  • 胸部或腹部持续疼痛、压迫感
  • 抽搐
  • 严重的肌肉痛
  • 好转后又再次恶化的症状

儿童需要立即就医的信号(CDC)

  • 呼吸急促或呼吸困难
  • 嘴唇或面部发青
  • 胸痛
  • 抽搐
  • 不满12周的婴儿出现任何发热
  • 用药后仍不退的40°C(104°F)以上高热

应先就医的情况

  • 发热或咳嗽久久不愈，或伴有不明原因的体重下降
  • 中耳炎、肺炎、鼻窦炎反复出现，或恢复格外缓慢
  • 正在服用免疫抑制剂、类固醇、抗癌药，或有糖尿病等基础疾病

生病时请按 CDC 指引留在家中，减少与他人接触。症状判断和用药请与医生、药师商量后决定。

有证据的生活因素：睡眠、运动、压力

以下是本站得出相同结论的免疫力管理文章中已确认的范围。多为观察性研究，因此不能断言因果，需要一并阅读。

因素已确认的内容局限与对旧版的更正
睡眠Prather 等(2015)：用腕式活动记录仪测得每晚睡眠不足5小时的人群，接触鼻病毒后发生感冒的比值比约为睡眠超过7小时人群的4.5倍。并不是直接检验增加睡眠能否减少感冒的结果。「不足6小时4.2倍、不足5小时5.5倍、抗体减少50%」已删除。
运动WHO 建议成人每周至少150分钟中等强度身体活动，以及每周至少2天肌肉力量训练。「步行使NK细胞活性增加30%」和「J型曲线」的断言已删除。有身体酸痛或发热时要休息。
慢性压力Cohen 等(2012, PNAS)：长期持续的压力与之后感冒风险较高有关。「冥想10~20分钟使皮质醇下降23%」未能找到出处，已删除。如果压力已使日常生活失序，请咨询专业人士。

深呼吸、散步、与人交往、充分休息等日常可做的方法是基本，不把特定的呼吸法或时长作为功效的依据。

营养素与补充剂：已确认与未确认的内容

为了不缺乏而摄入营养素，与多摄入以提高免疫力，是两回事。旧版「必备营养补剂 TOP 7」的标题和每日推荐量数字已删除，各营养素的每日需要量和上限，请在韩国保健福祉部《2025 韩国人营养素摄入标准》中按年龄、性别确认。

成分已确认的内容未确认的内容与更正
维生素D韩国食品医药品安全处(MFDS)认定的功能包括钙、磷的吸收与利用，以及骨骼的形成与维持等。成人可耐受最高摄入量为每天4,000 IU(NIH ODS)。预防呼吸道感染的荟萃分析结果不一致，2025年更新的荟萃分析中，一般人群的预防效果也没有统计学意义。美国内分泌学会2024年指南不建议健康成人常规检测血液水平。「推荐2,000~4,000 IU」「最佳40~60 ng/mL」「减少42%」已删除。
维生素CCochrane 综述：一般人群定期服用并未减少感冒发生，只使症状持续时间在成人中缩短约8%、儿童约14%。只有在马拉松等短期高强度身体压力人群中，发生风险才减半。「1,000~2,000 mg」的推荐量已删除。
锌MFDS 的功能标示中有「正常免疫功能所需」。意思是补足需要量以免缺乏。「感冒缩短1~2天」「伤口愈合缩短25%」未能确认，已删除。高剂量应确认可耐受最高摄入量并避免。
益生菌MFDS 认定的功能是乳酸菌增殖、抑制有害菌、排便活动、肠道健康。并非被认定的增强免疫功能。「肠道占免疫力70%」「推荐菌株」「100亿~500亿CFU」已删除。
Omega-3青背鱼是均衡饮食的一部分。「EPA+DHA 2,000~3,000 mg」的免疫用推荐量未能找到依据，已删除。
接骨木莓这次没有用一手资料确认到的内容。「抑制流感病毒复制」「300~600 mg」未能确认，已删除。
β-葡聚糖这次没有用一手资料确认到的内容。「激活巨噬细胞、NK细胞」「250~500 mg」未能确认，已删除。

先从食物中补足，补充剂在怀疑缺乏，或怀孕、哺乳、有慢性病、正在服药时，与医生、药师商量后再决定。维生素D见维生素D文章，免疫整体见免疫力管理文章，结论一致。

洗手、通风与饮食：日常能做的事

以下行为是在 CDC 预防指引中确认的。旧版的室内温度(20~22°C)、湿度(40~60%)、细颗粒物标准、「每2小时通风10分钟」和「佩戴口罩」这次未能确认依据，已连同数字一并删除。

预防感染的行为(CDC)

  • 经常用肥皂和水洗手，没有条件时使用含酒精的免洗洗手液。
  • 咳嗽或打喷嚏时用纸巾遮住口鼻，并把纸巾扔掉。
  • 生病时留在家中，待症状好转、且不靠退烧药也已退烧至少24小时后再恢复活动。
  • 经常擦拭门把手等常接触的表面。
  • 引入室外新鲜空气或净化室内空气，以改善空气质量。

饮食

  • 均衡摄入蔬菜、水果、全谷物、鱼、豆类和乳制品的均衡饮食是基础。
  • 旧版的「增强免疫力超级食物」表和「每日饮食示例」断言了特定食物的功效，已删除。
  • 发酵食品可能含钠较多，请控制食用量。

不同年龄段的差异

  • 婴幼儿、儿童：遵守疫苗接种计划最重要。补充剂和益生菌请在儿科就诊时商量。
  • 青少年：均衡饮食、规律的身体活动和洗手习惯是基础。旧版各年龄段睡眠时长的数字未能确认，已删除。
  • 成人：睡眠和进餐时间容易变得不规律。请核对接种记录并定期体检。
  • 65岁以上：请确认是否属于流感、新冠、肺炎球菌国家接种的对象。有慢性病的人，饮食和运动的调整请在就诊时商量。

常见问题

Q1: 冬季免疫力会特别弱吗？

A: 冬季呼吸道感染看起来确实增多，但并未确认单一原因。旧版的数字（维生素D合成减少80%、飞沫感染3~5倍等）未能确认出处，已删除。确认接种、洗手、生病时休息是实用的准备。

Q2: 冬季一定要吃维生素D吗？

A: 在一般人群中预防呼吸道感染的证据没有统计学意义，美国内分泌学会2024年指南不建议健康成人常规检测血液水平。成人上限为每天4,000 IU(NIH ODS)；如果缺乏风险较高，请咨询医护人员。

Q3: 感冒和流感怎么区分？

A: 按 CDC 标准，流感突然起病，发热和严重酸痛常见；感冒逐渐起病，发热少见。但仅凭症状无法断定，请遵循医护人员的判断。

Q4: 睡眠不足会更容易感染吗？

A: 在 Prather 等(2015)的研究中，每晚睡眠不足5小时人群的感冒比值比约为睡眠超过7小时人群的4.5倍。但这并不是直接检验增加睡眠能否减少感冒的结果。

Q5: 出现什么症状要立刻去医院？

A: CDC 提出的应立即就医的信号包括呼吸困难、胸部或腹部持续的疼痛或压迫感、抽搐、严重的肌肉痛，以及好转后又再次恶化的症状。有基础疾病或正在服用免疫抑制剂的人，请更早咨询。

结论

预防冬季感染不是靠某一种补充剂，而是做好已确认的手段。要点如下。

  1. 疫苗接种：确认自己是否属于2026~2027流感季流感、新冠、肺炎球菌疫苗的对象及日程。
  2. 预防感染的行为：坚持洗手、咳嗽礼仪、通风，以及生病时留在家中。
  3. 了解信号：出现呼吸困难、胸痛、抽搐等信号，立即就医。
  4. 睡眠、运动、压力：只在已确认的关联程度上抱有期待，不断言功效。
  5. 补充剂先咨询：确认「增强免疫」的广告用语是否在 MFDS 认定的功能范围内。

# 冬季感染预防清单 - 接种、信号、补充剂判断

基准日：2026-09-29
本清单是一般性信息，不能替代诊断或治疗。以下是韩国的制度说明，对象与日程请在 KDCA 预防接种网站等处按本人情况确认。

---

## 1. 接种确认表（2026~2027流感季，韩国）

| 疫苗 | 国家接种的对象与日程 |
|---|---|
| 流感 | 出生满6个月至14岁（2012.1.1~2026.8.31出生）的儿童、孕妇、65岁以上人群。儿童和孕妇自2026年9月21日起接种，接种期到2027年4月30日。65岁以上人群中，75岁以上自10月12日，70~74岁自10月15日，65~69岁自10月19日起。 |
| 新冠 | 2026年时65岁以上（1961.12.31之前出生）、免疫低下者、感染脆弱机构的住院·入住者。KDCA 预防接种网站写明70岁以上自10月12日、65~69岁自10月15日起，到2027年6月30日。 |
| 肺炎球菌 | 65岁以上成人国家接种（23价多糖疫苗）以1961年12月31日之前出生者为资助对象。已在65岁之后接种过的人，据称无需再次接种。 |

## 2. 感冒与流感的区分

| 项目 | 感冒 | 流感 |
|---|---|---|
| 起病 | 逐渐开始。 | 突然开始。 |
| 发热 | 少见。 | 常见，持续3~4天。不过并非所有流感患者都发热。 |
| 身体酸痛、肌肉痛 | 轻微。 | 常见，往往较重。 |

## 3. 需要立即就医的信号

**成人需要立即就医的信号(CDC)**

- [ ] 呼吸困难或气短
- [ ] 胸部或腹部持续疼痛、压迫感
- [ ] 抽搐
- [ ] 严重的肌肉痛
- [ ] 好转后又再次恶化的症状

**儿童需要立即就医的信号(CDC)**

- [ ] 呼吸急促或呼吸困难
- [ ] 嘴唇或面部发青
- [ ] 胸痛
- [ ] 抽搐
- [ ] 不满12周的婴儿出现任何发热
- [ ] 用药后仍不退的40°C(104°F)以上高热

**应先就医的情况**

- [ ] 发热或咳嗽久久不愈，或伴有不明原因的体重下降
- [ ] 中耳炎、肺炎、鼻窦炎反复出现，或恢复格外缓慢
- [ ] 正在服用免疫抑制剂、类固醇、抗癌药，或有糖尿病等基础疾病

## 4. 补充剂判断表

| 成分 | 已确认的内容 |
|---|---|
| 维生素D | 韩国食品医药品安全处(MFDS)认定的功能包括钙、磷的吸收与利用，以及骨骼的形成与维持等。成人可耐受最高摄入量为每天4,000 IU(NIH ODS)。 |
| 维生素C | Cochrane 综述：一般人群定期服用并未减少感冒发生，只使症状持续时间在成人中缩短约8%、儿童约14%。只有在马拉松等短期高强度身体压力人群中，发生风险才减半。 |
| 锌 | MFDS 的功能标示中有「正常免疫功能所需」。意思是补足需要量以免缺乏。 |
| 益生菌 | MFDS 认定的功能是乳酸菌增殖、抑制有害菌、排便活动、肠道健康。 |
| Omega-3 | 青背鱼是均衡饮食的一部分。 |
| 接骨木莓 | 这次没有用一手资料确认到的内容。 |
| β-葡聚糖 | 这次没有用一手资料确认到的内容。 |

## 5. 日常行为检查

- [ ] 经常用肥皂和水洗手，没有条件时使用含酒精的免洗洗手液。
- [ ] 咳嗽或打喷嚏时用纸巾遮住口鼻，并把纸巾扔掉。
- [ ] 生病时留在家中，待症状好转、且不靠退烧药也已退烧至少24小时后再恢复活动。
- [ ] 经常擦拭门把手等常接触的表面。
- [ ] 引入室外新鲜空气或净化室内空气，以改善空气质量。
