Core Concepts: Sodeuggongje vs. Se-aek Gongje

To truly understand yeonmal jeongsang, you need to clearly grasp the difference between sodeuggongje (income deduction) and se-aek gongje (tax credit).

Sodeuggongje (Income Deduction)

+------------------------------------------+
|    Sodeuggongje Calculation Flow          |
+------------------------------------------+
|  Total Gross Pay                          |
|  - Geulloso-deuk Gongje (Earned Income    |
|    Deduction)                             |
|  = Geulloso-deuk Geum-aek (Earned Income  |
|    Amount)                                |
|  - Sodeuggongje (Personal, Pension,       |
|    Insurance, Card, etc.)                 |
|  = Gwase Pyojun (Taxable Base)            |
|  x Tax Rate (6%-45%)                      |
|  = Sanchul Se-aek (Computed Tax)          |
+------------------------------------------+

Key point: Sodeuggongje reduces the gwase pyojun (taxable base) used to calculate your tax. The higher your tax bracket, the greater the savings.

Se-aek Gongje (Tax Credit)

+------------------------------------------+
|    Se-aek Gongje Calculation Flow         |
+------------------------------------------+
|  Sanchul Se-aek (Computed Tax)            |
|  - Se-aek Gongje (Child, Pension Account, |
|    Medical, etc.)                         |
|  = Gyeoljeong Se-aek (Determined Tax)     |
|  - Ginapbu Se-aek (Tax Already Withheld)  |
|  = Final Amount (Refund or Additional     |
|    Payment)                               |
+------------------------------------------+

Key point: Se-aek gongje is subtracted directly from your computed tax. It provides the same savings regardless of your income level.

Public transit (daejunggyo-tong) 80% Additional KRW 1M Major increase for 2025

Optimal Usage Strategy

# Credit Card Deduction Optimization Simulator
def calculate_card_deduction(annual_salary, credit_usage, debit_usage, traditional_market, public_transport):
    """
    Yeonmal jeongsang credit card sodeuggongje calculator

    Args:
        annual_salary: Annual gross pay (KRW)
        credit_usage: Credit card spending (KRW)
        debit_usage: Debit card spending (KRW)
        traditional_market: Traditional market spending (KRW)
        public_transport: Public transit spending (KRW)

    Returns:
        Sodeuggongje amount (KRW)
    """
    # Minimum spending threshold (25% of gross pay)
    min_usage = annual_salary * 0.25

    total_usage = credit_usage + debit_usage + traditional_market + public_transport

    if total_usage < min_usage:
        return 0

    # Calculate excess spending
    excess_usage = total_usage - min_usage

    # Calculate deductions
    deduction = 0
    deduction += credit_usage * 0.15  # Credit card 15%
    deduction += debit_usage * 0.30   # Debit card 30%
    deduction += traditional_market * 0.50  # Traditional market 50%
    deduction += public_transport * 0.80    # Public transit 80%

    # Apply limits (varies by gross pay)
    if annual_salary <= 70000000:  # KRW 70M or less
        limit = 3000000
    elif annual_salary <= 120000000:  # KRW 120M or less
        limit = 2500000
    else:
        limit = 2000000

    return min(deduction, limit)

# Example usage
salary = 50000000  # KRW 50M annual salary
credit = 5000000   # KRW 5M credit card
debit = 10000000   # KRW 10M debit card
market = 2000000   # KRW 2M traditional market
transport = 1200000  # KRW 1.2M public transit

total_deduction = calculate_card_deduction(salary, credit, debit, market, transport)
print(f"Estimated sodeuggongje: {total_deduction:,} KRW")
# Output: Estimated sodeuggongje: 3,000,000 KRW (limit applied)

  • Pharmacy medicines: Prescription drugs + over-the-counter medicines

  • Hearing aids: No limit

Medical Expense Optimization Strategy

# Medical Expense Se-aek Gongje Optimization Simulator
def optimize_medical_expense(annual_salary, family_expenses):
    """
    Optimize se-aek gongje by distributing family medical expenses

    Args:
        annual_salary: Annual gross pay
        family_expenses: {
            'self': Personal medical expenses,
            'spouse': Spouse medical expenses,
            'parents': Parent medical expenses (age 65+),
            'children': Child medical expenses
        }

    Returns:
        Maximum se-aek gongje amount
    """
    threshold = annual_salary * 0.03  # Minimum threshold (3%)

    # Self + age 65+ + disability: no limit
    unlimited = family_expenses.get('self', 0) + family_expenses.get('parents', 0)

    # General dependents: KRW 7M limit
    limited = min(family_expenses.get('spouse', 0) + family_expenses.get('children', 0), 7000000)

    total_medical = unlimited + limited

    if total_medical <= threshold:
        return 0

    # 15% se-aek gongje on the excess
    deduction_amount = (total_medical - threshold) * 0.15

    return deduction_amount

# Example usage
expenses = {
    'self': 500000,      # KRW 500K personal
    'spouse': 800000,    # KRW 800K spouse
    'parents': 3000000,  # KRW 3M parents (age 65+)
    'children': 400000   # KRW 400K children
}

tax_credit = optimize_medical_expense(50000000, expenses)
print(f"Medical se-aek gongje: {tax_credit:,} KRW")
# Output: Medical se-aek gongje: 472,500 KRW

Optimal Contribution Strategy

# Pension Account Optimal Contribution Simulator
def optimize_pension_contribution(annual_salary, age):
    """
    Calculate optimal pension account contributions

    Args:
        annual_salary: Annual gross pay
        age: Age

    Returns:
        dict: {
            'pension_saving': Recommended yeongeumjeochuk contribution,
            'irp': Recommended IRP contribution,
            'tax_credit': Estimated se-aek gongje
        }
    """
    if annual_salary <= 55000000:
        tax_rate = 0.165  # 16.5%
    else:
        tax_rate = 0.132  # 13.2%

    # Under 50: Pension savings KRW 6M + IRP KRW 3M
    # 50 and over: Pension savings KRW 6M + IRP KRW 9M (retirement prep)
    if age < 50:
        pension_saving = 6000000
        irp = 3000000
    else:
        pension_saving = 6000000
        irp = 9000000

    total_contribution = pension_saving + irp
    tax_credit = min(total_contribution, 9000000) * tax_rate

    return {
        'pension_saving': pension_saving,
        'irp': irp,
        'total': total_contribution,
        'tax_credit': tax_credit
    }

# Example usage
result = optimize_pension_contribution(60000000, 35)
print(f"Yeongeumjeochuk: {result['pension_saving']:,} KRW")
print(f"IRP: {result['irp']:,} KRW")
print(f"Se-aek gongje: {result['tax_credit']:,} KRW")

# Yeongeumjeochuk: 6,000,000 KRW
# IRP: 3,000,000 KRW
