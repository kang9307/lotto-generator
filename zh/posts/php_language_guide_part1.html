PHP 简介

PHP 是 "PHP: Hypertext Preprocessor" 的缩写,是一种在 Web 服务器上执行的脚本语言。它主要嵌入在 HTML 中,用于生成动态网页。

PHP 的主要特点

  • 服务器端脚本:代码在服务器上执行,仅将结果传送给客户端。
  • 跨平台:可在 Windows、Linux、macOS 等多种操作系统上运行。
  • 数据库集成:可轻松与 MySQL、PostgreSQL、SQLite 等多种数据库对接。
  • 开源:免费使用,拥有庞大的开发者社区。
  • 功能丰富:提供文件上传、邮件发送、PDF 生成等丰富功能。

PHP 的应用领域

  • Web 应用开发
  • 内容管理系统(WordPress、Joomla、Drupal)
  • 电子商务平台(Magento、WooCommerce)
  • 论坛与社交网络网站
  • REST API 与 Web 服务

PHP 与其他后端语言对比

语言 优点 缺点
PHP 学习曲线平缓、文档丰富、主机托管支持广泛 一致性不足、类型安全问题(PHP 7 之前)
Node.js 异步处理、JavaScript 生态系统 回调地狱、相对较新的技术
Python 可读性好、库丰富多样 速度问题、多线程受限
Ruby 语法优雅、生产力高 执行速度较慢、主机托管受限

PHP 安装与环境配置

在 Windows 上安装 PHP

  1. 下载 PHP

    • 从 PHP 官方网站 下载最新版本
    • 建议选择 Thread Safe 版本

  2. 安装与设置

    C:\> mkdir C:\PHP
C:\> 将下载的 ZIP 文件解压到 C:\PHP
C:\> cd C:\PHP
C:\PHP> copy php.ini-development php.ini

  3. 配置环境变量

    • 系统属性 → 高级 → 环境变量 → 在 Path 中添加 C:\PHP

  4. 与 Web 服务器集成

    • 可使用 Apache、IIS 或 PHP 内置 Web 服务器

在 Linux(Ubuntu)上安装 PHP

sudo apt update
sudo apt install php php-cli php-fpm php-mysql php-json php-common

在 macOS 上安装 PHP

brew install php

开发环境配置

  1. 安装集成开发环境(IDE)

    • PHPStorm:功能强大的商业 IDE
    • Visual Studio Code + PHP 扩展:免费替代方案
    • Sublime Text:轻量快速的编辑器

  2. 安装本地 Web 服务器

    • XAMPP:支持 Windows、Linux、macOS
    • WAMP:仅适用于 Windows
    • MAMP:仅适用于 macOS

  3. 安装 Composer(PHP 包管理器)

    curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer

PHP 配置文件(php.ini)主要设置

; 内存限制
memory_limit = 128M

; 最大执行时间(秒)
max_execution_time = 30

; 文件上传设置
upload_max_filesize = 2M
post_max_size = 8M

; 错误显示设置(开发环境)
display_errors = On
error_reporting = E_ALL

; 错误显示设置(生产环境)
; display_errors = Off
; error_reporting = E_ALL & ~E_DEPRECATED & ~E_STRICT
