PMI(采购经理人指数)读懂指南 - 制造业·服务业·投资应用

用50这一临界值提前读懂经济走向 - 从新订单到ISM·S&P Global·RatingDog PMI

引言：为何每月第一周，市场都会对一个数字做出反应

每到月初第一周，财经新闻总会出现「ISM制造业指数超预期」或「中国PMI表现低迷」之类的标题。然而，这一个数字为何能在短时间内牵动国债收益率、股市乃至汇率，却很少被解释清楚。PMI(Purchasing Managers' Index，采购经理人指数)是一种调查型指标，直接询问工厂或服务企业的采购主管一个简单问题：与上月相比，情况是变好了还是变差了。它并非复杂的统计模型，而是把一线的真实感受直接转化为数字，这正是它比实际生产、出口统计早数周乃至数月发布的原因。

本文以2026年7月为基准，梳理PMI是如何构建的、为何「50」这一临界值如此重要、ISM·S&P Global·中国的PMI彼此有何差异，以及个人应如何解读这一数字而不至于草率下结论。需要说明的是，本文是帮助理解PMI这一指标本身的经济教育内容，并非针对任何具体投资方向的建议。

1. PMI是什么 - 基于调查的扩散指数

1.1 询问谁，询问什么

PMI起源于一项月度调查，询问制造业或服务业企业的采购经理，新订单、产量、就业、库存、供应商交货时间等项目较上月是改善、持平还是恶化。受访者只需回答方向，而无需提供精确的销售额或产量数字，因此调查耗时短，回收与汇总也能快速完成。汇总后的回答不再体现单个企业的具体情况，而是以极短的时滞反映整个行业的景气感受。

1.2 扩散指数(diffusion index)的计算方法

PMI是统计学中所说的扩散指数。计算公式很简单：将回答「改善」的比例乘以1，「持平」的比例乘以0.5，「恶化」的比例乘以0，再将三者相加。例如，若30%的受访者回答改善、50%持平、20%恶化，指数即为30 + (50×0.5) + (20×0) = 55。正因如此，PMI的取值始终介于0到100之间，当改善与恶化的回答恰好各占一半、其余为持平时，理论上会收敛在50附近。

2. 50这一临界值的含义

2.1 划分扩张与收缩的分界线

阅读PMI时首先要看的不是小数点后的数字，而是50这条分界线。高于50，意味着当月景气较上月扩张(改善)；低于50，意味着收缩(恶化)。恰好为50，则表示与上月相比基本没有变化。这里的关键在于，PMI体现的不是「景气的绝对水平」，而是「较上月的方向与变化速度」。PMI从48升至52，并不代表景气突然大幅好转，而应解读为从收缩转向扩张的方向性信号。

2.2 离50越远，信号越强

数值离50越远，说明当月的变化幅度越大。55比52意味着有更多受访者报告改善；45比48意味着更大范围内出现了恶化。不过也要记住，PMI数值本身并不直接等同于GDP增速那样的实际数量级。因此在实际应用中，比起单月的PMI水平，更应关注较上月、较去年同期的方向转变，以及连续数月的趋势变化。

3. 拆解细分指标 - 新订单·生产·就业·库存·供应商交货

3.1 各项指标说明了什么

PMI的头条数字由多个细分指标组合而成。具有代表性的包括新订单(未来生产的领先信号)、生产/产出(当前开工水平)、就业(招聘或裁员动向)、库存(原材料·成品库存变化)、供应商交货时间(原材料采购延迟程度)。其中值得注意的是供应商交货时间：交货变慢乍看之下是负面信号，但实际上被解读为需求集中、供应链趋于繁忙的表现，因此计入扩张一侧的得分。也就是说，每个细分指标的「好坏」解读方向并不相同，如果只看头条数字，很容易遗漏大量信息。

3.2 不同机构的权重差异 - ISM对比S&P Global

在这一点上，不同机构的计算方式出现分歧。美国ISM制造业PMI对新订单、生产、就业、供应商交货、库存五项采用均等的20%权重。而S&P Global(原Markit)制造业PMI则采用差异化权重：新订单30%、产出25%、就业20%、供应商交货时间15%、库存10%。即便是同一月份、针对不同国家计算出的指标，其计算理念本身也存在差异，了解这一点有助于减少简单跨国比较PMI时产生的误读。

4. 制造业PMI对比服务业PMI对比综合PMI

4.1 制造业与服务业的走势并不相同

制造业PMI是上述五项指标的组合，而服务业PMI的结构略有不同。S&P Global服务业PMI的头条指标是商业活动指数(Business Activity Index)，其核心是一个单一的扩散指数，询问较上月相比业务活动(销售额/交易量)是增加还是减少。此外还会单独发布新业务、就业、未完成订单等分项指标。制造业与服务业在经济周期中往往走势不同：制造业对全球需求、贸易和库存周期更为敏感，因此往往率先转向、率先反弹；服务业则与内需消费和就业挂钩，走势相对平稳。

4.2 综合PMI呈现的全景

综合PMI(Composite PMI)是将制造业与服务业指数按产出占比加权平均得出的结果。由于服务业在大多数发达经济体GDP中所占比重远高于制造业，综合PMI往往更多受服务业走势主导。因此，如果只看制造业PMI来判断景气，可能会忽略以服务业为主的发达经济体的真实走势，把制造业、服务业、综合三项指标结合起来看更为稳妥。

5. 三大代表性PMI对比 - ISM·S&P Global·中国的两个PMI

5.1 ISM制造业PMI(美国)

美国ISM制造业PMI由供应管理协会(Institute for Supply Management)发布，通常在每月第一个工作日前后公布，是当月最早发布的经济指标之一。例如，2026年6月ISM制造业PMI报53.3%，较5月下降0.7个百分点，但仍连续第6个月保持扩张，整体经济也处于连续第20个月的扩张阶段。ISM还会另外每月发布服务业PMI(原非制造业指数，NMI)。

5.2 S&P Global PMI(覆盖全球45个经济体)

S&P Global PMI以相同方法论调查全球45个经济体、30个行业。每个国家的样本由400多家企业组成，力求反映该行业的真实结构，调查问卷在每月下旬回收处理。值得一提的是，在终值公布之前，S&P Global会基于相当一部分回复先行公布快讯(初步估计)PMI，通常在月中发布，比政府官方统计早数周，成为市场广泛参考的景气信号。

5.3 中国的两个PMI - 国家统计局(NBS)与RatingDog(原财新/Caixin)

中国存在两个PMI，二者常常呈现不同的图景。国家统计局(NBS)发布的官方PMI调查约3,200家企业，大型企业与国有企业的占比相对较高。另一项调查样本约650家企业，民营及出口导向型中小企业占比更高，长期以来被称为「财新(Caixin)PMI」，但自2025年8月起因赞助方更替，更名为「RatingDog China PMI」(负责调查与汇编的S&P Global及其方法论保持不变)。当两项指标出现背离时，可解读为大型国有部门与民营出口部门之间存在景气温差的信号。

6. PMI为何作为「领先指标」而重要

6.1 先于实体指标出现的感受型信号

PMI之所以被称为领先指标(leading indicator)，原因在于其统计生成方式本身。GDP、工业生产等「硬」指标必须汇总实际的交易和生产记录，因此发布往往要滞后数周甚至数月。而PMI是询问采购经理主观感受的调查，回收与汇总速度快，因此成为每月最早公布的经济数据之一。采购经理在实际订单到来之前，从下单计划阶段就已能感知需求变化，这种感受往往先于实体指标变动。

6.2 与GDP、就业等滞后指标的关系

正因如此，市场参与者与央行不必等待GDP公布，就能借助PMI提前判断该季度的经济走向。ISM甚至会公布PMI水平与历史实际GDP增速之间的经验关系，将某一PMI读数大致换算为对应的年化GDP增速。但需要明确的是，这只是基于历史相关性的参考性估算，并非精确预测未来GDP的公式。

7. PMI发布对市场与利率的影响

7.1 债券·股票·汇率的反应路径

PMI是少数在发布后立即引发债券、股票、外汇市场反应的指标之一。强于预期的PMI往往意味着经济扩张和物价上行压力，从而推高国债收益率；弱于预期的PMI则往往加剧经济放缓的担忧，压低利率。当新订单这类领先性较强的细分指标出现大幅波动时，市场的反应有时甚至比头条数字更为敏感。

7.2 央行制定货币政策的参考依据

央行在制定货币政策时也会将PMI作为参考资料。若PMI连续数月保持在50以上，且新订单与就业同步改善，则支持经济稳健的判断更具说服力；反之，若PMI跌破50且新订单大幅下滑，市场对经济放缓及宽松货币政策的预期往往会升温。不过需要注意的是，利率决策绝非仅凭PMI一项指标做出，而是与物价、就业等指标综合解读的结果。

8. 个人如何在实践中读懂PMI

8.1 检查清单 - 不要只看头条数字

  • 首先确认头条数字是高于还是低于50，以及较上月方向是否发生转变。
  • 确认新订单这类领先性较强的细分指标是否与头条数字方向一致(若细分指标出现背离，头条数字的可信度可能下降)。
  • 不要只看单月数值，应结合近3~6个月的趋势一起观察。
  • 制造业、服务业、综合指标应一并参考，跨国比较时需确认调查机构(ISM还是S&P Global)是否相同。

8.2 局限性 - 调查本身固有的制约

PMI固有的局限性也很明显。调查回答反映的是「主观感受」而非实际销售额或产量，因此容易受心理因素、季节性事件、一次性新闻的影响。各国受访样本相对较小，通常只有数百家企业，单月数值可能出现较大噪音。此外，快讯(初步)值在终值中被小幅修正的情况也并不罕见。应始终牢记，PMI展现的是方向和扩散程度，而非对增长绝对规模的精确测量。

结语 - PMI，每月最先该确认的数字

PMI并非复杂的模型，它源自「较上月是否变好」这一简单问题，但正是这种简单，使其比其他任何指标都更早揭示经济走向。将50这一临界值，与新订单这类领先性较强的细分指标，以及ISM·S&P Global·中国不同PMI所呈现的温差结合起来阅读，就能在每月初铺天盖地的PMI新闻标题背后，捕捉到真正的信号。若能养成同时阅读GDP·经济增长率指标解读指南以及就业、物价指标的习惯，便能更立体地把握经济走势。
