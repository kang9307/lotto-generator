Windows 보안 앱과 Defender 바이러스 백신 — 명칭과 적용 범위

Windows 에서 기본으로 동작하는 백신은 두 개의 이름으로 나뉜다. 사용자가 여는 화면은 Windows 보안 앱이고, 파일을 검사하고 위협을 처리하는 엔진은 Microsoft Defender 바이러스 백신이다. 개요 문서는 Defender 바이러스 백신이 Windows 10, Windows 11, Windows Server 버전에서 사용할 수 있고 Windows 에 기본 제공된다고 설명한다. 같은 문서는 이 제품을 엔드포인트용 Microsoft Defender 의 차세대 보호 구성 요소로 소개하며, 기계 학습·빅데이터 분석·위협 방지 연구·Microsoft 클라우드 인프라를 결합해 장치를 보호한다고 적는다.

Windows 보안 앱을 끄는 것과 엔진을 끄는 것은 다르다. 문서는 Windows 보안 앱을 사용하지 않도록 설정해도 Defender 바이러스 백신이나 Windows 방화벽이 비활성화되지는 않는다고 밝힌다. 다만 앱을 끄거나 관련 그룹 정책으로 시작과 실행을 막으면 앱이 설치된 백신과 방화벽 제품에 대해 부실하거나 부정확한 정보를 보여 줄 수 있고, 비 Microsoft 백신을 제거할 때 Defender 가 다시 사용 설정되지 않을 수도 있다. 문서는 앱을 끄면 장치의 보호 수준이 크게 낮아져 맬웨어 감염으로 이어질 수 있다고 경고한다.

  • 적용 운영체제: 호환성 문서의 지원 목록은 Windows 11, Windows 10, Windows Server 2016 이상, Windows Server 버전 1803 이상, Azure Stack HCI OS 버전 23H2 이상이다. Windows 보안 앱에서 검사, 업데이트 확인, 제외, 랜섬웨어 보호를 관리하는 기능은 Windows 10 버전 1703 이상에서 제공된다. Windows Server 에는 오프라인 검사가 해당되지 않는다.
  • 프로세스와 서비스: 작업 관리자의 세부 정보 탭에서 MsMpEng.exe(서비스 이름 WinDefend)가 보이면 엔진이 실행 중이다. 이 밖에 Microsoft Defender 핵심 서비스 MdCoreSvc(MpDefenderCoreService.exe), 네트워크 실시간 검사 서비스 WdNisSvc(NisSrv.exe), 명령줄 유틸리티 MpCmdRun.exe가 있다.
  • 서비스 수정 금지: 호환성 문서는 wscsvc, SecurityHealthService, MsSense, Sense, WinDefend, MsMpEng 서비스와 프로세스를 사용하지 않도록 설정하거나 중지하거나 수정하지 말라고 권고한다. 수동으로 수정하면 장치가 심각하게 불안정해질 수 있다고 적는다.
  • 정책으로 관리되는 장치: 그룹 정책으로 설정을 구성하고 배포하면 Windows 보안 앱의 바이러스 및 위협 방지 설정이 회색으로 표시되어 개별 엔드포인트에서 바꿀 수 없다. 그룹 정책 개체의 변경이 장치에 먼저 배포되어야 Windows 설정에 반영된다.

백신과 악성코드 대응의 배경 지식은 개인 사이버보안 기초 완전 가이드와 악성코드와 랜섬웨어 대응에 따로 정리되어 있다.

Windows 보안 앱 진입과 바이러스 및 위협 방지 화면

시작 메뉴에서 Windows 보안을 검색해 앱을 열고 바이러스 및 위협 방지를 선택한다. 문서는 같은 화면으로 가는 길로 바이러스 및 위협 방지 타일(또는 왼쪽 메뉴 모음의 방패 아이콘)도 안내한다. 검사 실행, 보안 인텔리전스 업데이트 확인, 실시간 보호 확인, 제외 추가, 위협 탐지 기록 검토, 랜섬웨어 보호 구성이 모두 이 화면에서 이루어진다.

  • 빠른 검사와 검사 옵션: 빠른 검사를 선택하면 검사가 시작되고, 전체 검사처럼 다른 유형은 검사 옵션에서 고른다.
  • 바이러스 및 위협 방지 업데이트: 설치된 보안 인텔리전스(예전 명칭은 정의 버전)의 버전과 다운로드 날짜가 표시된다. 업데이트 확인을 선택하면 새 보호 업데이트를 내려받는다.
  • 바이러스 및 위협 방지 설정: 설정 관리로 들어가 실시간 보호 스위치와 제외 항목을 다룬다.
  • 보호 기록: 최근 항목이 모두 나열된다. 오프라인 검사의 결과도 이곳에서 확인한다.
  • 랜섬웨어 보호: 랜섬웨어 보호 관리에서 제어된 폴더 액세스를 설정하고, 랜섬웨어 데이터 복구에서 OneDrive 계정을 연결하거나 설정한다.
  • 공급자 관리: 「누가 나를 보호하나요?」 아래의 공급자 관리를 선택하면 보안 공급자 페이지의 바이러스 백신 항목에 「Microsoft Defender 바이러스 백신이 켜져 있습니다」가 표시되어야 한다.
  • 작업 관리자 확인: 세부 정보 탭에서 MsMpEng.exe를 찾는 방법으로도 엔진이 실행 중인지 볼 수 있다.

업데이트 확인에는 조건이 하나 있다. 장치가 WSUS 나 소프트웨어 업데이트 지점을 가리키고 Windows 업데이트 정책이 「3 - 자동 다운로드 및 설치 알림」으로 설정된 경우, 업데이트 확인을 선택하면 사용 가능한 모든 Defender 업데이트(보안 인텔리전스, 엔진, 플랫폼)가 설치된다.

보호 설정 — 실시간 보호·클라우드 제공 보호·자동 샘플 제출·변조 방지

바이러스 및 위협 방지 설정 아래의 설정 관리를 열면 핵심 보호 기능의 스위치가 나온다. 문서에 근거가 있는 항목은 네 가지다.

실시간 보호는 파일을 열고 닫을 때, 그리고 사용자가 폴더로 이동할 때마다 파일을 검토하는 항상 켜진 보호다. 바이러스 및 위협 방지 설정에서 실시간 보호 스위치를 켜기로 전환해 확인한다. 이 스위치를 해제하면 잠시 후 자동으로 다시 켜지는데, 문서는 이 자동 사용이 맬웨어와 위협으로부터 보호되도록 하기 위한 것이라고 설명한다.

클라우드 제공 보호는 MAPS(Microsoft Advanced Protection Service)라고도 부르는 클라우드 보호 서비스로, 표준 실시간 보호를 향상한다. 이 서비스 덕분에 단일 엔드포인트가 감염되기 전에도 새로운 위협을 신속하게 식별할 수 있다고 문서는 적는다. 클라우드 서비스는 클라우드에 저장된 파일만 보호하는 것이 아니라, 분산 리소스와 기계 학습으로 기존 보안 인텔리전스 업데이트보다 훨씬 빠르게 보호를 전달하는 방식이다. 클라우드 보호는 기본적으로 사용하도록 설정되어 있고, 문서는 이를 계속 켜 두는 것을 권장한다. 엔드포인트용 Microsoft Defender 의 일부 기능이 클라우드 보호가 켜져 있을 때만 작동하기 때문이다. 관리되지 않는 기기에서는 설정 관리에서 클라우드 제공 보호와 자동 샘플 제출을 켠다. Windows 보안 앱에는 클라우드 보호 수준을 정하는 설정이 없다.

자동 샘플 제출은 파일과 실행 파일을 Defender 클라우드 서비스로 보내 분석하게 하는 기능이다. 클라우드 보호를 사용하지만 독립 실행형 설정으로도 구성할 수 있다. 관리 도구에서는 샘플 제출 동의를 「안전한 샘플을 자동으로 보냅니다」(기본값)와 「모든 샘플 자동 보내기」 중에서 고른다. 그룹 정책 설명에 따르면 안전한 샘플 전송은 대부분의 샘플을 자동으로 보내되 개인 정보가 포함될 가능성이 높은 파일은 사용자에게 추가 확인을 요구한다.

변조 방지는 중요한 보안 설정이 비활성화되거나 변경되는 것을 방지하는 데 도움을 준다. 문서는 공격자가 사이버 공격 중 기기의 보안 기능을 꺼서 데이터에 접근하고 악성코드를 설치하려 한다는 점을 배경으로 설명한다. 켜져 있을 때 바꿀 수 없는 항목으로 문서는 바이러스 및 위협 방지, 실시간 보호, 동작 모니터링, IOAV 를 포함한 백신 보호, 클라우드 보호, 보안 인텔리전스 업데이트, 감지된 위협에 대한 자동 작업, 보관된 파일 검사를 나열한다. 제외 항목을 수정하거나 추가할 수 없고, 레지스트리로 Defender 설정을 고치려는 시도도 차단된다. 그룹 정책 같은 관리 도구로 한 변경은 성공한 것처럼 보일 수 있지만 변조 방지가 그것을 막는다. 변경이 필요하면 문제 해결 모드로 변조 방지를 일시적으로 비활성화한다. 변조 방지는 비 Microsoft 백신이 Windows 보안 앱에 등록되는 방식에는 간섭하지 않는다.

기능 문서의 서술 기본값과 권고 함께 알아 둘 조건
실시간 보호 파일을 열고 닫을 때와 폴더로 이동할 때 파일을 검토 끄면 잠시 후 자동으로 다시 켜짐 제어된 폴더 액세스는 실시간 보호가 켜져 있어야 동작
클라우드 제공 보호 MAPS 로 새로운 위협을 신속하게 식별 기본적으로 사용 설정, 켜 두는 것을 권장 변조 방지를 켜면 꺼져 있던 클라우드 제공 보호가 자동으로 켜짐(플랫폼 4.18.2111.5 이후)
자동 샘플 제출 파일과 실행 파일을 클라우드 서비스로 보내 분석 동의 설정의 기본값은 안전한 샘플 자동 전송 클라우드 보호를 사용하지만 독립 설정으로도 구성 가능
변조 방지 중요한 보안 설정이 비활성화되거나 변경되는 것을 방지하는 데 도움 — 변경이 필요하면 문제 해결 모드로 일시 비활성화

이 가운데 문서가 켜 두라고 직접 권장하는 항목은 클라우드 보호다. 수동 모드로 Defender 를 쓰거나 블록 모드의 EDR 을 쓴다면 실시간 보호, 클라우드 제공 보호, 제한된 주기적 검사를 끄지 말라는 호환성 문서의 별도 권고도 있다.

검사 방식 — 빠른 검사·전체 검사·사용자 지정 검사·오프라인 검사

요청 기반 검사 문서는 빠른 검사, 전체 검사, 사용자 지정 검사의 세 유형을 구분한다. 검사는 즉시 시작되며 위치나 형식 같은 매개 변수를 정의할 수 있다. 이와 별도로 Windows 보안 앱의 검사 옵션에는 오프라인 검사가 있다.

빠른 검사는 레지스트리 키와 알려진 Windows 시작 폴더처럼 시스템 시작에 등록된 맬웨어가 있을 수 있는 모든 위치를 확인한다. 예약 검사 문서는 장치의 프로세스, 메모리, 프로필, 특정 위치를 확인한다고 설명하고, 마운트된 USB 드라이브 같은 이동식 장치에도 실행된다고 적는다. 항상 켜진 실시간 보호와 결합하면 시스템과 커널 수준에서 시작하는 맬웨어에 대한 강력한 보호를 제공한다. 두 문서 모두 대부분의 경우 빠른 검사로 충분하며 예약 검사와 주문형 검사에 권장되는 옵션이라고 말한다. 악성 파일이 빠른 검사에 포함되지 않은 위치에 저장될 수 있어도, 실시간 보호는 열리고 닫히는 모든 파일과 사용자가 접근하는 폴더의 파일을 검사한다.

전체 검사는 빠른 검사로 시작한 다음 마운트된 모든 고정 디스크와 이동식·네트워크 드라이브를 검사한다. 검사할 데이터의 양과 유형에 따라 몇 시간 또는 며칠이 걸릴 수 있다. 검사가 시작될 때 설치된 보안 인텔리전스를 쓰므로, 검사 중에 새 업데이트가 나오면 거기 담긴 새 위협을 찾으려면 전체 검사를 한 번 더 해야 한다. 시간과 리소스 때문에 일반적으로 전체 검사를 예약하지 않는 것이 좋다고 문서는 안내한다. 예약된 전체 검사 중에 장치가 전원에서 분리되어 배터리로 돌아가면 검사가 이벤트 1002 와 함께 중지되고, 다음 예약 시간에 다시 실행된다.

사용자 지정 검사는 지정한 파일과 폴더에서 실행된다. 문서의 예로는 USB 드라이브나 로컬 드라이브의 특정 폴더가 있다. 이동식 장치에 맬웨어가 있는지 확인하려는 상황에 문서가 권하는 유형이다.

Microsoft Defender 오프라인 검사는 신뢰할 수 있는 환경에서 부팅해 실행하는 맬웨어 방지 도구다. 검사가 일반 Windows 커널 밖에서 실행되므로, 마스터 부팅 레코드(MBR)를 감염시키거나 덮어쓰는 바이러스와 루트킷처럼 Windows 셸을 우회하려는 맬웨어를 대상으로 삼을 수 있다. 감염이 의심될 때나 맬웨어가 발생한 뒤 엔드포인트가 깨끗한지 철저히 확인하려 할 때 사용한다. 실행 경로는 Windows 보안 앱의 바이러스 및 위협 방지, 검사 옵션에서 Microsoft Defender 오프라인 검사를 선택하고 지금 검사를 누르는 것이다. 작업을 저장하라는 메시지에서 검사를 선택하고, 장치 변경 권한을 묻는 프롬프트에서 예를 선택하면 로그아웃되고 Windows 가 1분 이내에 종료된다는 안내가 나온다. 검사 전에 파일을 저장하고 실행 중인 프로그램을 닫아야 하며, 검사에는 약 15분이 걸린다. 끝나면 엔드포인트가 다시 시작되고 Windows 가 정상적으로 로드된다. 결과는 보호 기록에서 보고, 이벤트 뷰어의 Microsoft-Windows-Windows Defender/Operational 로그에서 이벤트 ID 2030 으로 오프라인 검사 구성을 확인할 수 있다.

검사 유형 문서가 서술한 범위 시작 방법 소요 시간과 조건
빠른 검사 시스템 시작에 등록된 위치(레지스트리 키, 알려진 시작 폴더), 마운트된 이동식 장치 빠른 검사 단추, MpCmdRun.exe -Scan -ScanType 1 대부분의 경우 충분하며 예약 검사에 권장
전체 검사 빠른 검사 후 마운트된 모든 고정 디스크와 이동식·네트워크 드라이브 검사 옵션에서 전체 검사 선택 몇 시간 또는 며칠, 일반적으로 예약 비권장
사용자 지정 검사 지정한 파일과 폴더 검사 옵션에서 선택 —
오프라인 검사 일반 Windows 커널 밖에서 실행, MBR 을 노리는 바이러스와 루트킷 대상 검사 옵션에서 Microsoft Defender 오프라인 검사, Start-MpWDOScan 약 15분, 재시작 필요, WinRE 와 BitLocker 조건 충족

오프라인 검사는 선행 조건이 다섯 가지다.

  • 하드웨어: x64 Windows 11 과 x64/x86 Windows 10 에서 쓸 수 있다. ARM Windows 11, ARM Windows 10, Windows Server 재고 유지 단위(SKU)에는 적용되지 않는다.
  • 계정과 모드: 로컬 관리자 권한으로 로그인해야 하고, Defender 바이러스 백신이 수동 모드가 아닌 기본 백신이어야 한다.
  • WinRE: Windows 복구 환경(WinRE)이 사용 설정되어 있어야 한다. 꺼져 있으면 오프라인 검사가 실행되지 않고 오류 메시지도 나오지 않으며, 수동으로 다시 시작해도 아무 일이 일어나지 않는다. 상태는 reagentc /info로 확인하고, 사용 안 함이면 reagentc /enable로 켠다.
  • BitLocker: 시스템 드라이브에서 BitLocker 를 쓰고 있으면 오프라인 검사 전에 BitLocker 보호를 일시 중단한다. 그러지 않으면 오프라인 환경으로 다시 시작할 때 BitLocker 복구 키를 입력하라는 메시지가 나올 수 있다.
  • 업데이트: 평소 방식대로 플랫폼, 엔진, 보안 인텔리전스 업데이트를 받아 둔다. 최신 보호 업데이트는 Microsoft 맬웨어 보호 센터에서 수동으로 내려받아 설치할 수도 있다.

타사 백신을 설치했을 때의 세 가지 모드

호환성 문서는 Defender 바이러스 백신이 활성 모드, 수동 모드, 사용 안 함 중 하나로 동작한다고 설명한다. 활성 모드에서는 Defender 가 장치의 기본 백신이며 파일이 검사되고 위협이 수정되며 탐지 결과가 보안 보고서와 Windows 보안 앱에 나열된다. 수동 모드에서는 Defender 가 기본 백신이 아니어서 파일을 검사하고 감지한 위협을 보고하지만 위협을 제거하지는 않는다. 사용 안 함 또는 제거됨 상태에서는 파일이 검사되지 않고 위협이 제거되지 않으며, 문서는 Defender 를 끄거나 제거하지 않는 것을 일반적으로 권장한다.

수동 모드는 일반적으로 엔드포인트용 Defender 에 온보딩된 엔드포인트에서만 설정할 수 있다. 수동 모드로 동작하려면 다른 백신이 기본 백신으로 설치되어 있고, 엔드포인트가 온보딩되어 있고, Windows 보안 Center Service 가 사용 설정되어 있어야 한다. 아래 표는 문서가 정리한 시나리오다.

기본 백신 엔드포인트용 Defender 온보딩 스마트 앱 제어 Defender 바이러스 백신 상태
Microsoft Defender 바이러스 백신 예 켜기, 평가 또는 끄기 활성 모드
Microsoft Defender 바이러스 백신 아니요 끄기 또는 평가 활성 모드
Microsoft Defender 바이러스 백신 아니요 켜기 하이브리드 모델
비 Microsoft 백신 예 또는 아니요 평가 또는 켜기 수동 모드
비 Microsoft 백신 아니요 끄기 사용 안 함
  • 기본 동작: Windows 10과 11에서 비 Microsoft 백신이 기본 백신이면 Defender 는 사용 안 함 모드가 되고, 이 전환은 자동으로 일어난다. 스마트 앱 제어를 켜면 사용 안 함 대신 수동 모드가 되는데, 문서는 이것이 엔드포인트용 Defender 온보딩 장치의 수동 모드와 다르다고 구분한다.
  • 제한된 주기적 검사: 다른 백신을 설치하면 Defender 는 자동으로 자신을 사용하지 않도록 설정하고 Windows 보안 앱에 그렇게 표시한다. 이때 제한된 주기적 검사를 사용하도록 설정할 수 있는 스위치가 나타난다.
  • 다시 켜지는 조건: 비 Microsoft 백신이 만료되거나 제거되거나 실시간 보호를 멈추면 Defender 가 자동으로 다시 사용 설정될 수 있다.
  • 두 엔진의 충돌: Windows 클라이언트에서 Windows 보안 Center Service 를 꺼 두면 Defender 가 타사 백신의 설치를 감지하지 못하고 활성 상태로 남는다. 둘 다 실시간 보호를 제공하려 하므로 성능에 영향을 주며 지원되지 않는 구성이라고 문서는 적는다.

Windows Server 는 다르다. Windows Server 2016 이상과 버전 1803 이상, Azure Stack HCI OS 23H2 이상에서는 비 Microsoft 백신을 설치해도 Defender 가 자동으로 수동 모드가 되지 않으며, 표에는 「사용 안 함(수동으로 설정)」으로 적혀 있다. 비 Microsoft 백신을 쓰는 서버에서는 관리자 권한 PowerShell 로 Uninstall-WindowsFeature Windows-Defender(Windows Server 2016 은 Windows-Defender-Gui도 함께)를 실행해 Defender 를 제거할 수 있고, 서버를 다시 시작해야 제거가 끝난다. 온보딩된 서버를 수동 모드로 두려면 레지스트리 HKLM\SOFTWARE\Policies\Microsoft\Windows Advanced Threat Protection의 ForceDefenderPassiveMode 값을 DWORD 1 로 설정하며, 온보딩 전에 지정해야 한다.

제외 설정과 랜섬웨어 보호 — 제어된 폴더 액세스

제외는 바이러스 및 위협 방지 설정의 설정 관리에서 시작한다. 제외 섹션의 제외 추가 또는 제거를 선택하고 + 제외 추가를 누르면 다음 선택지가 나온다.

  • 파일 또는 폴더: 경로 제외라고도 부른다.
  • 파일 형식: 확장자별 제외이며, 위치와 관계없이 그 확장자를 가진 모든 파일에 적용된다.
  • 프로세스: 지정한 프로세스가 연 파일에 대한 제외다. 프로세스 자체는 제외되지 않으므로, 프로세스를 제외하려면 파일 또는 폴더 제외를 쓴다.

변조 방지 문서의 모드 설명에는 변조 방지가 켜져 있으면 제외 항목을 수정하거나 추가할 수 없다는 항목이 들어 있다. 제외는 검사 범위를 줄이는 설정이므로, 필요한 경로만 좁게 지정하는 편이 안전하다.

제어된 폴더 액세스(CFA)는 랜섬웨어로부터 파일을 보호하는 Defender 바이러스 백신의 기능이며 엔드포인트용 Defender 의 공격 표면 감소 기능 중 하나다. 랜섬웨어 보호의 랜섬웨어 보호 관리에서 켠다.

  • 구성 요소: 보호된 폴더(신뢰할 수 없는 앱이 파일을 수정하거나 삭제할 수 없는 폴더), 신뢰할 수 있는 앱(보호된 폴더의 파일을 바꿀 수 있는 앱), 디스크 섹터(부팅 레코드를 저장하는 낮은 수준의 섹터)로 이루어진다. 신뢰할 수 없는 앱이 시도하면 CFA 가 시도를 막고 알림을 띄울 수 있으며, Windows 보안 앱의 보호 기록에 항목이 남는다.
  • 기본값과 모드: CFA 는 기본적으로 꺼져 있다. Windows 보안 앱은 켜기(사용·차단 모드)와 끄기만 지원하고, 감사 모드와 디스크 수정 전용 모드는 PowerShell, 그룹 정책, Intune 같은 다른 방법으로 설정한다. Microsoft 는 감사 모드로 영향을 평가한 뒤 사용(차단) 모드로 옮기기를 권장한다.
  • 기본 보호 위치: 하드 드라이브 부팅 섹터, 그리고 사용자 계정과 시스템 계정의 Documents, Favorites, Music, Pictures, Videos 폴더와 C:\Users\Public 아래의 Documents, Music, Pictures, Videos 폴더다. 폴더가 리디렉션되면 리디렉션된 위치를 보호하는데, 문서의 예는 OneDrive 폴더 리디렉션이 문서·사진·바탕 화면 폴더를 OneDrive 폴더로 옮긴 경우다. 기본 목록은 수정할 수 없고 폴더를 더 추가할 수는 있다.
  • 동작 조건: Defender 바이러스 백신이 기본 백신이며 활성 모드여야 하고 실시간 보호가 켜져 있어야 한다. 수동 모드, 블록 모드 EDR 이 있는 수동 모드, 제한된 주기적 검사, 끄기에서는 작동하지 않는다.

신뢰할 수 있는 앱은 Defender 가 .exe, .scr, .dll 같은 모든 실행 파일을 평가해 보급률과 평판에 따라 대부분 자동으로 신뢰한다. 자동 신뢰 목록은 Windows 보안 앱이나 관련 cmdlet 에 표시되지 않으며, 신뢰할 수 있는 앱이 차단될 때만 허용 목록에 추가하면 된다. 허용 앱은 위치까지 지정해야 하고, 경로의 폴더 부분에는 환경 변수와 와일드카드(*)를 쓸 수 있다. 반면 보호할 폴더를 추가할 때는 네트워크 공유와 매핑된 드라이브, 환경 변수를 쓸 수 있지만 와일드카드는 쓸 수 없고, 로컬 공유 경로(루프백)는 추가하지 말고 로컬 경로를 써야 한다. 공유 네트워크 폴더를 보호하면 신뢰할 수 없는 프로세스가 접근할 때 네트워크 성능이 크게 떨어질 수 있다고 문서는 경고한다.

PowerShell 로 상태 확인과 검사 실행

화면을 열지 않고도 상태를 확인할 수 있다. 호환성 문서는 AMRunningMode 값으로 Defender 의 모드를 확인하라고 안내하고, 제어된 폴더 액세스 문서는 관리자 권한 PowerShell 에서 현재 CFA 모드와 기본 보호 폴더를 조회하는 명령을 안내한다.

Get-MpComputerStatus | select AMRunningMode
                    Get-MpPreference | Format-Table EnableControlledFolderAccess
                    (Get-MpPreference).ControlledFolderAccessDefaultProtectedFolders
  • AMRunningMode: 「일반」은 Defender 가 활성 모드로 실행 중이라는 뜻이다. 「수동」은 실행되지만 기본 백신이 아니라는 뜻이고, 「EDR 차단 모드」는 블록 모드의 EDR 이 사용되고 있다는 뜻이다. 「SxS 수동 모드」는 다른 백신과 함께 실행되며 제한된 주기적 검사가 사용된다는 뜻이다.
  • EnableControlledFolderAccess: 0 또는 Disabled 가 기본값이고 1 Enabled, 2 AuditMode, 3 BlockDiskModificationOnly, 4 AuditDiskModificationOnly 가 이어진다. 기본 보호 폴더 목록은 CFA 가 켜져 있을 때만 반환된다.

검사는 Start-MpScan으로 시작하고, 오프라인 검사는 Start-MpWDOScan으로 시작한다. 후자는 장치를 격리된 환경으로 다시 부팅해 지속되는 맬웨어를 찾는다.

Start-MpScan
                    Start-MpWDOScan

CFA 를 감사 모드로 먼저 켜려면 Set-MpPreference -EnableControlledFolderAccess AuditMode를 쓴다. 보호할 폴더를 기존 목록에 더하려면 Set-MpPreference 가 아니라 Add-MpPreference -ControlledFolderAccessProtectedFolders를 써야 하는데, Set-MpPreference 는 기존 값을 지정한 값으로 덮어쓰기 때문이다. WMI 의 오프라인 검사 호출(MSFT_MpWDOScan)은 실행 즉시 엔드포인트를 다시 시작하므로 파일을 먼저 저장해야 한다.

확인하지 못한 것

  • Windows 보안 앱의 한국어 문구가 문서마다 달라 「누가 나를 보호하나요?」와 「나를 보호하는 사람은 누구인가요?」로 갈린다. 화면의 실제 문구는 Windows 빌드에 따라 다를 수 있다.
  • 변조 방지가 켜진 장치에서 Windows 보안 앱으로 제외를 추가할 때 어떻게 처리되는지에 대한 구체적 절차.
  • Windows 10 버전 1703 미만에서의 화면 구성과 메뉴 위치.
  • Windows 보안 앱의 자동 샘플 제출 스위치가 처음부터 켜져 있는지 여부. 문서가 기본값으로 밝히는 것은 클라우드 보호의 사용 설정과 관리 도구의 샘플 제출 동의 설정이다.
  • 제한된 주기적 검사가 어떤 주기와 범위로 실행되는지에 대한 서술.
  • 특정 타사 백신 제품별 충돌 사례와 자원 사용량.

참고 자료

  • Windows에서 바이러스 백신 Microsoft Defender 개요 — 명칭, 서비스, 모드 비교.
  • Windows 보안 앱의 Microsoft Defender 바이러스 백신 — 검사, 업데이트, 실시간 보호, 제외, 보호 기록.
  • 요청 기반 Microsoft Defender 바이러스 백신 검사 구성 및 실행 — 주문형 검사와 PowerShell.
  • 예약된 Microsoft Defender 바이러스 백신의 빠른 검사 또는 전체 검사 정보 — 검사 유형 비교.
  • 다른 보안 제품과의 바이러스 백신 호환성 Microsoft Defender — 활성·수동·사용 안 함 모드.
  • Microsoft Defender 오프라인 검사의 결과 실행 및 검토 — 선행 조건과 실행 절차.
  • 변조 방지 개요 — 변조 방지 모드와 요구 사항.
  • CFA(제어된 폴더 액세스) 개요 — 보호된 폴더와 신뢰할 수 있는 앱.
  • CFA(제어된 폴더 액세스) 구성 — 모드 값과 PowerShell 명령.
  • Microsoft Defender 안티바이러스에서 클라우드 보호 설정 — 클라우드 보호와 샘플 제출.
